Enumeration Block 1:
དེ་ལ་རྣམ་པར་དག་པ་ནི་མདོར་བསྡུ་ན་རྣམ་པ་གཉིས་ཏེ། རང་བཞིན་གྱིས་རྣམ་པར་དག་པ་དང་། དྲི་མ་མེད་པའི་རྣམ་པར་དག་པའོ། །

Enumeration Block 2:
ཚིགས་སུ་བཅད་པ་གཉིས་པོ་འདིའི་དོན་ནི་མདོར་བསྡུ་ན། ཚིགས་སུ་བཅད་པ་བརྒྱད་ཀྱིས་རིག་པར་བྱ་སྟེ། །

Enumeration Block 3:
དེ་ལ་ལས་ཀྱི་དོན་ལས་བརྩམས༌[^874]ཏེ་ཚིགས་སུ་བཅད་པ་གསུམ་སྟེ།

Enumeration Block 4:
ཚིགས་སུ་བཅད་པ་གསུམ་པོ་འདིའི་དོན་ནི་མདོར་བསྡུ་ན། ཚིགས་སུ་བཅད་པ་བརྒྱད་ཀྱིས་རིག་པར་བྱ་སྟེ།

Enumeration Block 5:
ཚིགས་སུ་བཅད་པ་འདིའི་དོན་ནི་མདོར་བསྡུ་ན་ཚིགས་སུ་བཅད་པ་བརྒྱད་ཀྱིས་རིག་པར་བྱ་སྟེ།
