Enumeration Block 1:
བསྟན་པའི་དགོས་པ༌[^817]སྡུད་པའི་ཚིགས་སུ་བཅད་པ་གཉིས་ཏེ། གཅིག་གིས་ནི་དྲིས་ལ། གཉིས་པས༌[^818]ནི་ལན་བསྟན་པའོ། །

Enumeration Block 2:
ཚིགས་སུ་བཅད་པ་གཉིས་པོ་འདིའི༌[^822]དོན་ནི་མདོར་བསྡུས་ཏེ་ཚིགས་སུ་བཅད་པ་བཅུས་རིག་པར་བྱ་སྟེ།

Enumeration Block 3:
དེ་ཡང་མདོར་བསྡུ༌[^834]ན་དོན་རྣམ་པ་བརྒྱད་ཀྱི་དབང་དུ་བྱས་ཏེ་རིག་པར་བྱ་སྟེ། །

Enumeration Block 4:
ཚིགས་སུ་བཅད་པ་འདིས༌[^836]ནི་གོ་རིམས་ཇི་ལྟ་བ་བཞིན་དུ་དོན་བརྒྱད་པོ་འདི་དག་བསྟན་ཏེ། འདི་ལྟ་སྟེ། ངོ་བོའི་དོན་དང་། རྒྱུའི་དོན་དང་། འབྲས་བུའི་དོན་དང་། ལས་ཀྱི༌[^837]དོན་དང་། ལྡན་པའི་དོན་དང་། འཇུག་པའི་དོན་དང་། རྟག་པའི་དོན་དང་། བསམ་གྱིས་མི་ཁྱབ་པའི་དོན་ནོ། །

Enumeration Block 5:
ཡེ་ཤེས་ནི་རྣམ་པ་གཉིས་ཏེ། འཇིག་རྟེན་ལས་འདས་པའི་རྣམ་པར་རྟོག་པ༌[^841]མེད་པ་དང་། དེའི་རྗེས༌[^842]ལས་ཐོབ་པའི་འཇིག་རྟེན་པའོ། །

Enumeration Block 6:
དེའི་འབྲས་བུ་ནི་རྣམ་པ་གཉིས་ཏེ། ཉོན་མོངས་པའི་སྒྲིབ་པ་དང་བྲལ་བ་དང་། ཤེས་བྱའི་སྒྲིབ་པ་དང་བྲལ་བའི་བྲལ་བ་རྣམ་པ༌[^844]གཉིས་སོ། །

Enumeration Block 7:
ཚིགས་སུ་བཅད་པ་འདིའི་དོན་ནི་མདོར་བསྡུ༌[^847]ན་ཚིགས་སུ་བཅད་པ་བཞིས་རིག་པར་བྱ་སྟེ།

Enumeration Block 8:
རྣམ་པར་དག་པ་ནི་མདོར་བསྡུ་ན་རྣམ་པ་གཉིས་ཏེ། རང་བཞིན་གྱིས་རྣམ་པར་དག་པ་དང་། དྲི་མ་མེད་པའི་རྣམ་པར་དག་པའོ། །

Enumeration Block 9:
ཚིགས་སུ་བཅད་པ་གཉིས་པོ་འདིའི་དོན་ནི་མདོར་བསྡུ་ན། ཚིགས་སུ་བཅད་པ་བརྒྱད་ཀྱིས་རིག་པར་བྱ་སྟེ། །
