[^71]: གང་དག་གིས་ ༼སྣར། པེ།༽ གང་དག་
[^72]: རྣམས་ཀྱི་ ༼སྣར། པེ།༽ རྣམས་ཀྱིས་
[^73]: བསམ་པ་དང་ ༼སྣར། པེ།༽ བསམ་པ་

[^82]: མི་རྟེན་ ༼སྣར།༽ ཡང་མི་བརྟེན་ ༼པེ།༽ མི་བརྟེན་

[^132]: བསྩོགས་ ༼སྣར། པེ།༽ གསོགས་
[^133]: ཕམ་པ་ནི་ ༼སྣར། པེ།༽ ཕམ་པ་
[^134]: ཉིད་ཀྱིས་ ༼སྣར། པེ།༽ ཉིད་ཀྱི་
[^135]: རིག་པར་བྱ་སྟེ། ༼སྣར།༽ རིག་པརབྱའོ། །[^136]: དཀྲིས་པ་མཚུངས་པས་བསམས་ ༼སྣར། པེ།༽ དཀྲིས་པ་མཚུངསཔ་བསམ་
[^137]: གཏི་མུག་གི་ ༼སྣར། པེ།༽ གཏི་མུག་གིས་
[^138]: འགྱུར་བར་ ༼སྣར།༽ འགྱུར་བའི་
[^139]: ནི་ ༼སྣར། པེ།༽ ན་
[^140]: འབྱུང་ ༼སྣར། པེ།༽ བྱུང་
[^141]: ཆེན་པོར་འགྱུར་བར་ ༼སྣར། པེ།༽ ཆེན་པོརགྱུར་པར་
[^142]: བྱ་བ་ནི་ ༼སྣར། པེ།༽ བྱ་བ་
[^143]: ན་ ༼སྣར། པེ།༽ ནི་
[^144]: རྒ་ཤི་སྐྱེད་པའི་ ༼སྣར། པེ།༽ རྒ་ཤིསྐྱེ་བའི་
[^145]: བསྲུང་བའི་ ༼སྣར། པེ།༽ སྲུང་བའི་
[^146]: སྲུང་བ་ ༼སྣར། པེ།༽ བསྲུང་བ་
[^147]: པར་ ༼སྣར། པེ།༽ པ་ལ་
[^148]: འབྱུང་བ་ ༼སྣར། པེ།༽ འབྱུང་
[^149]: དེ་ ༼སྣར། པེ།༽ དེའི་
[^150]: དུ་ཕྱིར་འཆོས་པའོ། ༼སྣར། པེ།༽ དུ་ཕྱིརའཆོས་སོ།
[^151]: ཐོག་མར་བདག་ ༼སྣར། པེ།༽ ཐོགམ་བར་དག་
[^152]: གཞི་ཡང་ཡང་ ༼སྣར། པེ།༽ གཞི་ཡང་
[^153]: ཆོས་བཞིན་དུ་ཕྱིར་ ༼སྣར། པེ།༽ ཆོས་བཞིན་དུ་
[^154]: ལྡན་པ་ ༼སྣར། པེ།༽ ལྡན་
[^155]: བསོད་ཉམས་ ༼སྣར། པེ།༽ བསོད་ནམས་
[^156]: སྤོངས་པའི་ ༼སྣར། པེ།༽ སྤངས་པའི་
[^157]: སྟི་ ༼སྣར། པེ།༽ བསྟི་
[^158]: འཕྲོགས་པའི་ ༼སྣར།༽ འཕྲོག་པའི་
[^159]: ཕོངས་ ༼སྣར། པེ།༽ འཕོངས་
[^160]: ཚུལ་ཁྲིམས་ཀྱི་དོན་གྱི་མདོ་ ༼སྣར། པེ།༽ ཚུལ་ཁྲིམས་ཀྱིམདོ་
[^161]: བདག་གི་ ༼སྣར། པེ།༽ བདག་གིས་
[^162]: དཔག་ ༼སྣར། པེ།༽ དཔགས་
[^163]: ལུས་ཀྱི་ལས་ཀྱི་ལམ་ ༼སྣར། པེ།༽ ལུས་ཀྱིལམ་
[^164]: གཏོགས་པ་དང་ ༼སྣར། པེ།༽ གཏོགས་པ་
[^165]: འདོགས་ ༼སྣར།༽ འདོག་
[^166]: བརྟེན་པོར་ ༼སྣར། པེ།༽ བརྟན་པོར་
[^167]: འཐོབ་པའི་ ༼སྣར། པེ།༽ ཐོབ་པའི་
[^168]: ཉེས་པ་ ༼སྣར། པེ།༽ ཉེས་པའི་
[^169]: སྨོན་པས་ ༼སྣར། པེ།༽ སྨིན་པས་
[^170]: བདག་གིས་ ༼སྣར། པེ།༽ བདག་གི་
[^171]: བ་ ༼སྣར། པེ།༽ བཱ་
