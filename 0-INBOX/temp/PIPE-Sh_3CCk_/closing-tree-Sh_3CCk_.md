## དཀར་ཆག / Table of Contents
* I. ཀླད་ཀྱི་དོན། [[༄། སློབ་དཔོན་བྷུ་སུ་ཀུའི་མཛད་པ་བཞུགས་སོ།།]]
* 1. ལོ་རྒྱུས [[བདེ་མཆོག་འཁོར་ལོའི་བསྒྲུབ་ཐབས་འདི་ལ། དོན་གཉིས་ཏེ། ལོ་རྒྱུས་དང་གཞུང་ངོ་། །]]
   * 1.1 བསྡུས་པ [[དང་པོ་ནི། སློབ་དཔོན་འདིའི་རིགས་རྒྱལ་པོ་ཡིན། གྲུབ་པ་འཕགས་པ་འཇམ་དཔལ་ལས་]]
   * 1.2 རྒྱས་པ [[རྒྱས་པ་ཞལ་ལས་ཤེས་སོ། །]]
* 2. གཞུང [[གཉིས་པ་གཞུང་ལ་གསུམ་སྟེ། ཕྱི་ལྟར་བསྐྱེད་པའི་རིམ་པ་དང་། ནང་ལྟར་རྫོགས་པའི་རིམ་པ་དང་།]]
   * 2.1 ཕྱི་ལྟར་བསྐྱེད་པའི་རིམ་པ [[དེ་ལ་དང་པོ་ཕྱི་ལྟར་བསྐྱེད་པའི་རིམ་པའི་སྒྲུབ་ཐབས། གཞན་དུ་གསལ་བས་འདིར་མ་བཤད་དོ། །]]
   * 2.2 ནང་ལྟར་རྫོགས་པའི་རིམ་པ [[གཉིས་པ་ནང་ལྟར་ལ་གཉིས་ཏེ། ངག་འདོན་དང་། གཞུང་དོན།]]
      * 2.2.1 ངག་འདོན [[དེ་ལས་དང་པོ་ནི། བདེ་བའི་སྟན་ལ་འདུག་པར་བྱ། །དཀྱིལ་ཀྲུང་བཅའ་]]
      * 2.2.2 གཞུང་དོན [[གཉིས་པ་གཞུང་ནི། རི་རབ་དབུས་སུ་སྣ་ཚོགས་པདྨས་མཛེས་ཅེས་པ་ནི།]]
   * 2.3 གསང་བ་ལྟར་སྤྱོད་པ [[གསུམ་པ་གསང་བ་ལྟར་སྤྱོད་པ་ནི། སྐྱེད་པའི་རིམ་པའི་སྒོ་ནས།]]
* b. མཇུག་བྱང། [[སློབ་དཔོན་བྷུ་སུ་ཀུས་མཛད་པའི་བདེ་མཆོག་འཁོར་ལོའི་ཊ་ཀི༌[^4]རྫོགས་སོ།། །།]]
   * b.1 མཛད་བྱང། [[སློབ་དཔོན་བྷུ་སུ་ཀུས་མཛད་པའི་བདེ་མཆོག་འཁོར་ལོའི་ཊ་ཀི༌[^4]རྫོགས་སོ།། །།]]
