## དཀར་ཆག / Table of Contents

* 1. བསམས་པ་ལས་བྱུང་བའི་སའི་རྣམ་པར་གཏན་ལ་དབབ་པ [[༄༅༅། །བམ་པོ་ཉི་ཤུ་རྩ་གསུམ་པ། དེ་ལ་ཆོས་ཟག་པ་དང་བཅས་]]
* 2. བསྒོམས་པ་ལས་བྱུང་བའི་སའི་རྣམ་པར་གཏན་ལ་དབབ་པ [[བམ་པོ་ཉི་ཤུ་རྩ་ལྔ་པ། བསྒོམས་པ་ལས་བྱུང་བའི་སའི་རྣམ་པར་གཏན་]]
* 3. ཉན་ཐོས་ཀྱི་སའི་རྣམ་པར་གཏན་ལ་དབབ་པ [[ཉན་ཐོས་ཀྱི་སའི་རྣམ་པར་གཏན་ལ་དབབ་པ་ནི་སའི་དངོས་གཞིར་གང་ཟག་]]
* 4. རང་སངས་རྒྱས་ཀྱི་སའི་རྣམ་པར་གཏན་ལ་དབབ་པ [[རང་སངས་རྒྱས་ཀྱི་སའི་རྣམ་པར་གཏན་ལ་དབབ་པའི་གཞུང་ནི་མི་སྣང་ངོ་། །]]
* 5. བྱང་ཆུབ་སེམས་དཔའི་སའི་རྣམ་པར་གཏན་ལ་དབབ་པ [[བྱང་ཆུབ་སེམས་དཔའི་སའི་རྣམ་པར་གཏན་ལ་དབབ་པ་ཉན་ཐོས་ཀྱི་རིགས་སྒྲུབ་]]
* 6. ཕུང་པོ་དང་བཅས་པ་དང་ཕུང་པོ་མེད་པའི་སའི་རྣམ་པར་གཏན་ལ་དབབ་པ [[ཕུང་པོ་དང་བཅས་པ་དང་ཕུང་པོ་མེད་པའི་སའི་རྣམ་པར་གཏན་ལ་དབབ་]]
