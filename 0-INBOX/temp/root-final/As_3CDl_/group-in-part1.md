# ༄༅། །རྣལ་འབྱོར་སྤྱོད་པའི་ས་ལས་དངོས་གཞིའི་ས་མང་པོ།༼སྨད་ཆ།༽ ^0

## རྟོག་པ་དང་བཅས་དཔྱོད་པ་དང་བཅས་པ་དང་རྟོག་པ་མེད་ལ་དཔྱོད་པ་ཙམ་དང་རྟོག་པ་ཡང་མེད་དཔྱོད་པ་ཡང་མེད་པའི་ས། ^1-0
S1  ༄༅༅། །བམ་པོ་བརྒྱད་པ། ཉོན་མོངས་པ་ཆེ་བའི་མཚན་ཉིད་དང་། དྲག་པའི་མཚན་ཉིད་དང་། ལྕི་བའི་མཚན་ཉིད་ཇི་ལྟར་རིག་པར་བྱ་ཞེ་ན།
S2  མདོར་བསྡུ་ན་རྣམ་པ་དྲུག་གིས་ཏེ། ལྟུང་བ་དང་། སྐྱེ་བ་དང་། རྒྱུད་དང་། གཞི་དང་། ལས་ཀུན་ནས་སློང་བ་དང་། མཐར་གྱུར་པས་སོ། །
S3  དེ་ལ་ལྟུང་བ་ནི་ཉོན་མོངས་པའི་ཀུན་ནས་དཀྲིས་པ་གང་གིས་ལྟུང་བ་མ་ལུས་པ་འབྱུང་བར་འགྱུར་རོ། །
S4  དེ་ལ་སྐྱེ་བ་ནི་འདོད་པ་ན་སྤྱོད་པའམ། ངན་སོང་དུ་འགྱུར་བ་གང་ཡིན་པའོ། །
S5  དེ་ལ་རྒྱུད་ནི་ལང་ཚོ་ལ་བབ་ཅིང་དབང་པོ་ཡོངས་སུ་སྨིན་ལ། འདོད་ཆགས་ལ་སོགས་པ་སྤྱོད་པ་རྣམས་དང་། ཡོངས་སུ་མྱ་ངན་ལས་འདའ་བའི་ཆོས་ཅན་མ་ཡིན་པ་རྣམས་ཀྱི་གང་ཡིན་པའོ། །
S6  དེ་ལས་གཞི་ནི་བླ་མའི་གནས་ལ་དམིགས་པ་དང་། ཡོན་ཏན་གྱི་གནས་ལ་དམིགས་པ་དང་། འཇུག་པར་བྱ་བ་མ་ཡིན་པའི་གནས་ལ་དམིགས་པའོ། །
S7  དེ་ལ་ལས་ཀུན་ནས་སློང་བ་ནི། ཉོན་མོངས་པའི་ཀུན་ནས་དཀྲིས་པ་གང་གིས་ཟིལ་གྱིས་ནོན་ཅིང་སེམས་ཡོངས༌[^1]སུ་ཟིན་ནས། ལུས་དང་ངག་གི་ལས་ཀུན་ནས་སློང་བའོ། །

S9  ཕྱིན་ཅི་ལོག་ནི་རྣམ་པ༌[^2]བདུན་པོ་འདི་དག་ཡིན་ཏེ། འདི་ལྟ་སྟེ། འདུ་ཤེས་ཕྱིན་ཅི་ལོག་དང་། ལྟ་བ་ཕྱིན་ཅི་ལོག་དང་། སེམས་ཕྱིན་ཅི་ལོག་དང་། མི་རྟག་པ་ལ་རྟག་གོ་སྙམ་པའི་ཕྱིན་ཅི་ལོག་དང་། སྡུག་བསྔལ་ལ་བདེའོ་སྙམ་པའི་ཕྱིན་ཅི་ལོག་དང་། མི་གཙང་བ་ལ་གཙང་ངོ་སྙམ་པའི་ཕྱིན་ཅི་ལོག་དང་། བདག་མེད་པ་ལ་བདག་གོ་སྙམ་པའི་ཕྱིན་ཅི་ལོག་གོ། །
S10  འདུ་ཤེས་ཕྱིན་ཅི་ལོག་གང་ཞེ་ན།
S11  མི་རྟག་པ་ལ་རྟག་གོ་སྙམ་པ་དང་། སྡུག་བསྔལ་བ་ལ་བདེའོ་སྙམ་པ་དང་། མི་གཙང་བ་ལ་གཙང་ངོ་སྙམ་པ་དང་། བདག་མེད་པ་ལ་བདག་གོ་སྙམ་པའི་འདུ་ཤེས་ཀྱི་ཡོངས་སུ་རྟོག་པ༌[^3]གང་ཡིན་པའོ། །

S21  དེ་ལ་འཇིག་ཚོགས་ལ་ལྟ་བ་ནི། བདག་མེད་པ་ལ་བདག་གོ་སྙམ་དུ་ཕྱིན་ཅི་ལོག་པའོ། །
S22  མཐར་འཛིན་པར་ལྟ་བའི་ཕྱོགས་གཅིག་ནི། མི་རྟག་པ་ལ་རྟག་གོ་སྙམ་དུ་ཕྱིན་ཅི་ལོག་པའོ། །
