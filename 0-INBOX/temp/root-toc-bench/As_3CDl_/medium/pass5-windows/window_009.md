* 12. བསྒོམས་པ་ལས་བྱུང་བའི་ས [[བསྒོམས་པ༌[^1961]ལས་བྱུང་བའི་ས་གང་ཞེ་ན། མདོར་བསྡུ་ན། བསྒོམས་པ་ལས་བྱུང་བའི་ས་ནི་]]
   * 12.1 མངོན་པར་འགྲུབ་པ་ཕུན་སུམ་ཚོགས་པ [[དེ་ལ་མངོན་པར་འགྲུབ་པ་ཕུན་སུམ་ཚོགས་པ་གང་ཞེ་ན། དེ་ནི་མདོར་བསྡུ་ན།]]
      * 12.1.1 ནང་ལ་བརྟེན་ཏེ་མངོན་པར་འགྲུབ་པ་ཕུན་སུམ་ཚོགས་པ [[ནང་ལ༌[^1964]བརྟེན་ཏེ་མངོན་པར་འགྲུབ་པ་ཕུན་སུམ་ཚོགས་པ་རྣམ་པ་ལྔ་པོ་གང་ཞེ་ན།]]
      * 12.1.2 ཕྱི་རོལ་ལ་བརྟེན་ཏེ་མངོན་པར་འགྲུབ་པ་ཕུན་སུམ་ཚོགས་པ [[ཕྱི་རོལ་ལ༌[^1971]བརྟེན་ཏེ། མངོན་པར་འགྲུབ་པ་ཕུན་སུམ་ཚོགས་པ་རྣམ་པ་ལྔ་པོ༌[^1972]གང་ཞེ་ན།]]
   * 12.2 དམ་པའི་ཆོས་ཉན་པ་ཕུན་སུམ་ཚོགས་པ [[དམ་པའི་ཆོས་ཉན་པ་ཕུན་སུམ་ཚོགས་པ་གང་ཞེ་ན། ཡང་དག་པར་བསྟན་པ་གང་ཡིན་པ་དང་།]]
      * 12.2.1 ཡང་དག་པར་བསྟན་པ [[ཡང་དག་པར་བསྟན་པ་ཡང་མདོར་བསྡུ་ན་རྣམ་པ་གཉིས་ཏེ། མཐུན་པ་དང་།]]
      * 12.2.2 ཡང་དག་པར་ཉན་པ [[ཡང་དག་པར་ཉན་པ་ཡང་རྣམ་པ་བཞི་སྟེ། འདི་ལྟ་སྟེ། ཁེངས་པ་མེད་པ་དང་།]]
   * 12.3 མྱ་ངན་ལས་འདས་པ་གཙོ་བོར་བྱེད་པ [[མྱ་ངན་ལས་འདས་པའི་གཙོ་བོར་བྱེད་པ་གང་ཞེ་ན། འདི་ལྟར་དེ་བཞིན་གཤེགས་པའི་ཉན་ཐོས་དེ་]]
   * 12.4 རྣམ་པར་གྲོལ་བ་ཡོངས་སུ་སྨིན་པར་བྱེད་པའི་ཤེས་རབ་ཡོངས་སུ་སྨིན་པ [[རྣམ་པར་གྲོལ་བ་ཡོངས་སུ་སྨིན་པར་བྱེད་པའི་ཤེས་རབ་ཡོངས་སུ་སྨིན་པ་གང་ཞེ་ན། ལྷག་མཐོང་གི་ཡན་ལག་]]
   * 12.5 གཉེན་པོ་བསྒོམ་པ [[གཉེན་པོ་བསྒོམ་པ་གང་ཞེ་ན། མདོར་བསྡུ་ན་གནས་སྐབས་གསུམ་ལ་རྣལ་འབྱོར་བསྒོམ་པའི་]]
   * 12.6 རྣམ་པ་ཐམས་ཅད་དུ་འཇིག་རྟེན་པ་རྣམ་པར་དག་པ [[རྣམ་པ་ཐམས་ཅད་དུ་འཇིག་རྟེན་པ་རྣམ་པར་དག་པ་གང་ཞེ་ན། དེ་ནི་མདོར་བསྡུ་ན་རྣམ་པ་གསུམ་དུ་]]
      * 12.6.1 ཏིང་ངེ་འཛིན་ཐོབ་པ [[དེ་ལ་ཐོག་མ་ཁོ་ནར་ཏིང་ངེ་འཛིན་གྱི་མི་མཐུན་པའི་ཕྱོགས་སུ་གྱུར་པའི་ཆོས་རྣམ་པ་]]
      * 12.6.2 ཏིང་ངེ་འཛིན་ཡོངས་སུ་རྫོགས་པ [[དེས་དེ་ལྟར་ཏིང་ངེ་འཛིན་ཐོབ་ནས་བྱེ་བྲག་ཆུང་ངུ་ངན་ངོན་ཙམ་གྱིས་ཆོག་པར་མི་འཛིན་ཏེ།]]
