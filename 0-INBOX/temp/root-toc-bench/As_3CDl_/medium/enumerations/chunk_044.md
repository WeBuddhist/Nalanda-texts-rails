Enumeration Block 1:
དེ་ནི་རྣམ་པ་བཞིར་རིག་པར་བྱ་སྟེ། དབང་པོ་ཡོངས་སུ་མ་ཉམས་ཤིང་། ཡིད་ལ་བྱེད་པ་མངོན་དུ་གནས་པ་ན་མཐུན་པར་སྐྱེ་བ་དང་། ཡང་དག་པར་འདས་ནས་སྐྱེ་བ་དང་། སྒྲིབ་པ་མེད་པ་དང་། ཐག་རིང་བ་མ་ཡིན་པའོ། །

Enumeration Block 2:
དེ་ཡང་རྣམ་པ་བཞིར་རིག་པར་བྱ་སྟེ། སྒྲིབ་གཡོགས་ཀྱི༌[^1098]སྒྲིབ་པ་དང་། མི་སྣང་བར་བྱེད་པ་དང་། ཟིལ་གྱིས་གནོན་པ་དང་། རྨོངས་པའི་སྒྲིབ་པས་མ་བསྒྲིབས་པ་གང་ཡིན་པ་དེ་ནི་མ་བསྒྲིབས་པ་ཞེས་བྱའོ། །

Enumeration Block 3:
དེ་ནི་རྣམ་པ་ལྔའམ། རྣམ་པ་བདུན་དུ་བལྟ་བར་བྱ་སྟེ།

Enumeration Block 4:
མདོར་བསྡུ་ན་བཞི་སྟེ། དབང་པོ་གཟུགས་ཅན་གྱི་མངོན་སུམ་དང་། ཡིད་ཀྱིས་མྱོང་བའི་མངོན་སུམ་དང་། འཇིག་རྟེན་གྱི་མངོན༌[^1110]སུམ་དང་། དག་པའི་མངོན་སུམ་མོ། །
