Enumeration Block 1:
འདོད་པ་རྣམས་ནི་ངོ་བོ་ཉིད་རྣམ་པ་གཉིས་ཏེ། དངོས་པོའི་འདོད་པ་རྣམས་དང་། ཉོན་མོངས་པའི་འདོད་པ་རྣམས་སོ། །

Enumeration Block 2:
བསྒོམས་པ་ལས་བྱུང་བའི་ས་ནི་གནས་བཞིས་བསྡུས་པར་རིག་པར་བྱ་སྟེ། གནས་བཞི་གང་ཞེ་ན།

མངོན་པར་འགྲུབ་པ་ཕུན་སུམ་ཚོགས་པ་དང་། དམ་པའི་ཆོས་ཉན་པ་ཕུན་སུམ་ཚོགས་པ་དང་། མྱ་ངན་ལས་འདས་པ་གཙོ་བོར་བྱེད་པ་དང་། རྣམ་པར་གྲོལ་བ་ཡོངས་སུ་སྨིན་པར་བྱེད་པའི་ཤེས་རབ་ཡོངས་སུ་སྨིན་པ་དང་། གཉེན་པོ་བསྒོམ་པ་དང་། རྣམ་པ་ཐམས་ཅད་དུ་འཇིག་རྟེན་པ་རྣམ་པར་དག་པ་དང་། རྣམ་པ་ཐམས་ཅད་དུ་འཇིག་རྟེན་ལས་འདས་པ་རྣམ་པར་དག་པ་སྟེ།

Enumeration Block 3:
དེ་ནི་མདོར་བསྡུ་ན། རྣམ་པ་བཅུར་བལྟ་བར་བྱ་སྟེ། ནང་ལ་བརྟེན་ཏེ་རྣམ་པ་ལྔ་དང་། ཕྱི་རོལ་ལ་བརྟེན་ཏེ་རྣམ་པ་ལྔ་སྟེ། ནང་དང་ཕྱི་རོལ་ལ་བརྟེན་ནས་རྣམ་པ་བཅུར་འགྱུར་རོ། །
