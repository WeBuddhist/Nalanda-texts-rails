Enumeration Block 1:
རྣམ་གྲངས་གཞན་ཡང་སེམས་ཀྱི་འཆིང་བ་ནི་བཞི་སྟེ། ཉེ་བར་ལེན་པའི་འཆིང་བ་དང་། མྱོང་བའི་འཆིང་བ་དང་། རྣམ་པར་རིག་པའི་འཆིང་བ་དང་། དེར་མངོན་པར་ཞེན་པའི་འཆིང་བའོ། །

Enumeration Block 2:
གཏོང་བ་རྣམ་པར་དག་པ་དང་། རྣམ་པར་མ་དག་པ་ནི་རྣམ་པ་བཞིར་རིག་པར་བྱའོ། །

Enumeration Block 3:
དེ་དང་དེ་དག་ཏུ་སེམས་ཅན་སྐྱེས་པ་རྣམས་ཀྱི་འཆི་བའི་དུས་བྱེད་པ་ནི་རྣམ་པ་བཞི་སྟེ།

Enumeration Block 4:
གཞན་ཡང་རྣམ་པར་དག་པའི་ལམ་བཞི་སྟེ། ཉེས་པར་བཤད་པའི་ཆོས་འདུལ་བ་ལ་མི་ཕྱོགས་པ་དང་། ལེགས་པར་བཤད་པའི་ཆོས་འདུལ་བ་ལ་མངོན་དུ་ཕྱོགས་པ་དང་། ཚོགས་ཀྱི་ལམ་དང་། རྣམ་པར་དག་པའི་ལམ་མོ། །

Enumeration Block 5:
ལས་གཉིས་ནི་རྣམ་པ་བཞིར་རིག་པར་བྱ་སྟེ། འཇུག་པར་གཏོགས་པའི་ལས་རྣམ་པ་གསུམ་དང་། ལྡོག་པར་གཏོགས་པའི༌[^944]ལས་སོ། །
