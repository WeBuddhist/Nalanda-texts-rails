Enumeration Block 1:
བར་ཆད་བྱེད་པ་དེའི་གཉེན་པོར་སེམས་ཀྱི་དམིགས་པ་ལ་ལེགས་པར་འཇུག་པ་ཡང་རྣམ་པ་གཉིས་ཁོ་ནར་རིག་པར་བྱ་སྟེ།

Enumeration Block 2:
མདོར་བསྡུ་ན། བར་དུ་གཅོད་པ་རྣམ་པ་གཉིས་སུ་རིག་པར་བྱ་སྟེ། རྒྱུ་བ་དང་གནས་པའོ། །

Enumeration Block 3:
དེ་ལ་ཞི་གནས་དང་ལྷག་མཐོང་ལ་བརྩམས་ནས། བར་དུ་གཅོད་པ་རྣམ་པ་བཞི་ཡོད་པར་རིག་པར་བྱ་སྟེ། ལྷག་མཐོང་གི་ཡན་ལག་དང་མི་མཐུན་པ་དང་། ཞི་གནས་ཀྱི་ཡན་ལག་དང་མི་མཐུན་པ་དང་། དེ་གཉི་གའི་ཕྱོགས་ཀྱི་དྲན་པ་དང་མི་མཐུན་པ་དང་། གནས་དང་མི་མཐུན་པའོ། །

Enumeration Block 4:
བར་དུ་གཅོད་པ་རྣམ་པ་འདི་གཉིས་ཀྱང་མདོར་བསྡུ་ན། རྒྱུ་རྣམ་བ་གཉིས་ཀྱིས་ཡོངས་སུ་སྤོང་བར་རིག་པར་བྱ་སྟེ། ཏིང་ངེ་འཛིན་ལ་དགའ་བ་མང་དུ་བྱེད་པ་དང་། སོ་སོར་བརྟགས་པ༌[^2158]མང་དུ་བྱེད་པའོ། །

Enumeration Block 5:
དེ་ལ་ཏིང་ངེ་འཛིན་ལ་དགའ་བ་མང་དུ་བྱེད་པ་ནི་མདོར་བསྡུ་ན་རྣམ་པ་དྲུག་ཏུ་རིག་པར་བྱ་སྟེ།

Enumeration Block 6:
རང་སངས་རྒྱས་ཀྱི་ས་གང་ཞེ་ན། དེ་ནི་རྣམ་པ་ལྔར་རིག་པར་བྱའོ། །
