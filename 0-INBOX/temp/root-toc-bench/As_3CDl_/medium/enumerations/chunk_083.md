Enumeration Block 1:
རང་སངས་རྒྱས་ཀྱི་ས་གང་ཞེ་ན།
དེ་ནི་རྣམ་པ་ལྔར་རིག་པར་བྱའོ། །
རིགས༌[^2194]དང་། ལམ་དང་། ཡང་དག་པར་འགྲུབ་པ་དང་། གནས་པ་དང་། རྒྱུ་བའོ། །

Enumeration Block 2:
རང་སངས་རྒྱས་ཀྱི་རིགས་གང་ཞེ་ན།
དེ་ནི་མཚན་ཉིད་གསུམ་དུ་རིག་པར་བྱ་སྟེ།

Enumeration Block 3:
དེ་ལྟར༌[^2197]རང་སངས་རྒྱས་ཀྱི་ལམ་ཡང་མཚན་ཉིད་གསུམ་དུ་རིག་པར་བྱ་སྟེ།

Enumeration Block 4:
ཕུང་པོ་དང་བཅས་པའི་ས་གང་ཞེ་ན།
དེ་ནི་རྣམ་པ་གསུམ་དུ་བལྟ་བར༌[^2215]བྱ་སྟེ། སར་གདགས་པ་རྣམ་པར་གཞག་པ་དང་། ཉེ་བར་ཞི་བར་གདགས་པ་རྣམ༌[^2216]པར་གཞག་པ་དང་། ཕུང་པོར་གདགས་པ་རྣམ་པར་གཞག་པའོ། །

Enumeration Block 5:
ཉེ་བར་ཞི་བར་གདགས་པ་རྣམ་པར་གཞག་པ་གང་ཞེ་ན།
ཕུང་པོ་དང་བཅས་པའི་ས་ནི་ཉེ་བར་ཞི་བ་རྣམ་པ་བཞིས་རྣམ་པར་གཞག་སྟེ། སྡུག་བསྔལ་ཉེ་བར་ཞི་བ་དང་། ཉོན་མོངས་པ་ཉེ་བར་ཞི་བ་དང་། སེམས་ཅན་རྣམས་ལ་རྣམ་པར་འཚེ་བ་ཉེ་བར་ཞི་བ་དང་། བཏང་སྙོམས་ཉེ་བར་ཞི་བའོ། །

Enumeration Block 6:
ཕུང་པོ༌[^2231]གདགས་པ་རྣམ་པར་གཞག་པ་གང་ཞེ་ན།
ཕུང་པོ་ནི་བརྒྱད་པོ་འདི་དག་ཡིན་ཏེ། གདགས་པའི་ཕུང་པོ་དང་། ཡོངས་སུ་གཟུང་བའི་ཕུང་པོ་དང་། གནས་པའི་ཕུང་པོ་དང་། འཇུག་པའི་ཕུང་པོ་དང་། བར་དུ་གཅོད་པའི་ཕུང་པོ་དང་། སྡུག་བསྔལ་གྱི་ཕུང་པོ་དང་། དགའ་བའི་ཕུང་པོ་དང་། ཐ་མའི་ཕུང་པོའོ། །

Enumeration Block 7:
ཕུང་པོ་མེད་པའི་ས་གང་ཞེ་ན།
དེ་ཡང་རྣམ་པ་གསུམ་དུ་བལྟ་བར་བྱ་སྟེ། སར་གདགས་པ་རྣམ་པར་གཞག་པ་དང་། མྱ་ངན་ལས་འདས་པར་གདགས་པ་རྣམ་པར་གཞག་པ་དང་། མྱ་ངན་ལས་འདས་པའི་རྣམ་གྲངས་སུ་གདགས་པ་རྣམ་པར་གཞག་པའོ། །

Enumeration Block 8:
མྱ་ངན་ལས་འདས་པར་གདགས་པ༌[^2249]རྣམ་པར་གཞག་པ་གང་ཞེ་ན།
ཕུང་པོ་མེད་པའི་ས་ནི་མྱ་ངན་ལས་འདས་པ་རྣམ་པ་གཉིས་པོ་ཉེ་བར་ཞི་བའི་མྱ་ངན་ལས་འདས་པ་དང་། གནོད་པ་མེད་པའི་མྱ་ངན་ལས་འདས་པས་རྣམ་པར་གཞག་སྟེ།
