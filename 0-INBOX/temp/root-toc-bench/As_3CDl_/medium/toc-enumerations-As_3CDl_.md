དེ་ནི་རྣམ་པ་བཞིར་བལྟ་བར་བྱ་སྟེ། འདི་ལྟ་སྟེ། ནད་ལ་མཁས་པ་དང་། ནད་ཅི་ལས་གྱུར་པ་ལ་མཁས་པ་དང་། ནད་བྱུང་བ་བསྩལ་བ༌[^1046]ལ་མཁས་པ་དང་། ནད་བསལ་ནས་ཕྱིས་མི་འབྱུང་བར་བྱ་བ་ལ་མཁས་པའོ། །
Enumeration Block 2:
སྨྲ་བ་གང་ཞེ་ན།
དེ་ཡང་རྣམ་པ་དྲུག་ཏུ་བལྟ་བར་བྱ་སྟེ། སྨྲ་བ་དང་། རྨད་ཁྱེར་བ་སྨྲ་བ་དང་། རྩོད་པ་སྨྲ་བ་དང་། ཚིག་ངན༌[^1049]སྨྲ་བ་དང་། མཐུན་པ༌[^1050]སྨྲ་བ་དང་། གདམས་པར་སྨྲ་བའོ། །
Enumeration Block 3:
སྨྲ་བའི་ཞལ་ཅེ་པ༌[^1081]གང་ཞེ་ན།
དེ་ཡང་རྣམ་པ་དྲུག་ཏུ་བལྟ་བར་བྱ་སྟེ། འདི་ལྟ་སྟེ། རྒྱལ་པོ་བཞུགས་པའི་ས་དང་། བསྐོས་པ་འདུ་བའི་ས་དང་། འཁོར་དང་། འདུ་བ་དང་། ཆོས་དང་དོན་ལ་མཁས་པའི་དགེ་སྦྱོང་དང་བྲམ་ཟེ་རྣམས་དང་། ཆོས་དང་དོན་འདོད་པའི་སེམས་ཅན་རྣམས་སོ། །
Enumeration Block 4:
སྨྲ་བའི་གཞི་གང་ཞེ་ན།
དེ་ནི་རྣམ་པ་བཅུར་བལྟ་བར་བྱ་སྟེ། བསྒྲུབ་པར་བྱ་བའི་དོན་རྣམ་པ་གཉིས་དང་། བསྒྲུབ༌[^1082]པ་རྣམ་པ་བརྒྱད་དོ། །
བསྒྲུབ་པར་བྱ་བའི་དོན་རྣམ་པ་གཉིས་གང་ཞེ་ན།
ངོ་བོ་ཉིད་དང་། བྱེ་བྲག་གོ། །
Enumeration Block 5:
བསྒྲུབ་པ་རྣམ་པ་བརྒྱད་གང་ཞེ་ན།
དམ་བཅའ་བ༌[^1085]དང་། གཏན་ཚིགས་དང་། དཔེར་བརྗོད་པ་དང་། མཐུན་པ་དང་། མི་མཐུན་པ་དང་། མངོན་སུམ་དང་། རྗེས་སུ་དཔག་པ་དང་། ཡིད་ཆེས་པའི་ལུང་ངོ་། །
Enumeration Block 6:
དེ་ཡང་རྣམ་པ་ལྔར་བལྟ་བར་བྱ་སྟེ། རྟགས་འདྲ་བ་དང་། ངོ་བོ་ཉིད་འདྲ་བ༌[^1093]དང་། ཆོས་འདྲ་བ་དང་། རྒྱུ་དང་འབྲས་བུ་འདྲ་བའོ། །

Enumeration Block 1:
དེ་ནི་རྣམ་པ་བཞིར་རིག་པར་བྱ་སྟེ། དབང་པོ་ཡོངས་སུ་མ་ཉམས་ཤིང་། ཡིད་ལ་བྱེད་པ་མངོན་དུ་གནས་པ་ན་མཐུན་པར་སྐྱེ་བ་དང་། ཡང་དག་པར་འདས་ནས་སྐྱེ་བ་དང་། སྒྲིབ་པ་མེད་པ་དང་། ཐག་རིང་བ་མ་ཡིན་པའོ། །

Enumeration Block 2:
དེ་ཡང་རྣམ་པ་བཞིར་རིག་པར་བྱ་སྟེ། སྒྲིབ་གཡོགས་ཀྱི༌[^1098]སྒྲིབ་པ་དང་། མི་སྣང་བར་བྱེད་པ་དང་། ཟིལ་གྱིས་གནོན་པ་དང་། རྨོངས་པའི་སྒྲིབ་པས་མ་བསྒྲིབས་པ་གང་ཡིན་པ་དེ་ནི་མ་བསྒྲིབས་པ་ཞེས་བྱའོ། །

Enumeration Block 3:
དེ་ནི་རྣམ་པ་ལྔའམ། རྣམ་པ་བདུན་དུ་བལྟ་བར་བྱ་སྟེ།

Enumeration Block 4:
མདོར་བསྡུ་ན་བཞི་སྟེ། དབང་པོ་གཟུགས་ཅན་གྱི་མངོན་སུམ་དང་། ཡིད་ཀྱིས་མྱོང་བའི་མངོན་སུམ་དང་། འཇིག་རྟེན་གྱི་མངོན༌[^1110]སུམ་དང་། དག་པའི་མངོན་སུམ་མོ། །

Enumeration Block 1:
མདོར་བསྡུ་ན་བཞི་སྟེ། དབང་པོ་གཟུགས་ཅན་གྱི་མངོན་སུམ་དང་། ཡིད་ཀྱིས་མྱོང་བའི་མངོན་སུམ་དང་། འཇིག་རྟེན་གྱི་མངོན༌[^1110]སུམ་དང་། དག་པའི་མངོན་སུམ་མོ། །

Enumeration Block 2:
དེ་ཡང་རྣམ་པ་ལྔར་བལྟ་བར་བྱ་སྟེ། རྟགས་དང་། ངོ་བོ་ཉིད་དང་། ལས་དང་། ཆོས་དང་། རྒྱུ་དང་འབྲས་བུའོ། །

Enumeration Block 3:
དེ་ཡང་རྣམ་པ་གསུམ་དུ་བལྟ་བར་བྱ་སྟེ། གསུང་རབ་སྡུད་པ་དང་། ཀུན་ནས་ཉོན་མོངས་པའི་གཉེན་པོ་དང་། མཚན་ཉིད་དང་མི་འགལ་བའོ། །

Enumeration Block 4:
དེ་ནི་རྣམ་པ་ལྔར་བལྟ་བར་བྱ་སྟེ། འདི་ལྟ་སྟེ། བདག་དང་ཕ་རོལ་གྱི་ལུགས་ཤེས་པ་དང་། ཚིག་གི་སྦྱོར་བ་ཕུན་སུམ་ཚོགས་པ་དང་། མི་འཇིགས་པ་དང་། བརྟེན་པ་དང་། ངོ་མི་བཟློག་པའོ། །

Enumeration Block 5:
དེ་ནི་ཡོན་ཏན་རྣམ་པ་ལྔ་དང་ལྡན་པར་རིག་པར་བྱ་སྟེ། གྲོང་མིའི་སྐད་མ་ཡིན་པ་དང་། ཡང་བ་དང་། བརྗིད་པ་དང་། འབྲེལ་པ་དང་། དོན་བཟང་པོ་ཡིན་ནོ། །

དེ་ནི་རྣམ་པ་ལྔར་བལྟ་བར་བྱ་སྟེ། འདི་ལྟ་སྟེ། བདག་དང་ཕ་རོལ་གྱི་ལུགས་ཤེས་པ་དང་། ཚིག་གི་སྦྱོར་བ་ཕུན་སུམ་ཚོགས་པ་དང་། མི་འཇིགས་པ་དང་། བརྟེན་པ་དང་། ངོ་མི་བཟློག་པའོ། །

Enumeration Block 2:
དེ་ནི་ཡོན་ཏན་རྣམ་པ་ལྔ་དང་ལྡན་པར་རིག་པར་བྱ་སྟེ། གྲོང་མིའི་སྐད་མ་ཡིན་པ་དང་། ཡང་བ་དང་། བརྗིད་པ་དང་། འབྲེལ་པ་དང་། དོན་བཟང་པོ་ཡིན་ནོ། །

Enumeration Block 3:
དེ་ནི་རྣམ་པ་གསུམ་དུ་བལྟ་བར་བྱ་སྟེ། བརྗོད་པ་གཏོང་བ་དང་། བརྗོད་པ་སྨ་དབབ་པ་དང་། བརྗོད་པའི་ཉེས་པའོ། །

Enumeration Block 1:
ཉེས་པ་དགུ་གང་ཞེ་ན། འདི་ལྟ་སྟེ། ཚིག་འཆལ་པ་དང་། ཉེས་པ་རྩོམ་པ་དང་། བརྡ་མ༌[^1182]ཕྲད་པ་དང་། རན་པ་མ་ཡིན་པ་དང་། དོན་དང་ལྡན་པ་མ་ཡིན་པ་དང་། དུས་མ་ཡིན་པ་དང་། མི་བརྟན་པ་དང་། མི་གསལ་བ་དང་། ཚིག་རྒྱུན་ཆགས༌[^1183]མ་ཡིན་པའོ། །

Enumeration Block 3:
ཆོས་གསུམ་ནི་སྨྲ་བ་ལ་གཅེས་སྤྲས་བྱེད་པར་རིག་པར་བྱ་སྟེ། བདག་དང་ཕ་རོལ་གྱི་གཞུང་ལུགས་ཤེས་པ་དང་། མི་འཇིགས་པ་དང་། སྤོབས་པའོ། །

Enumeration Block 4:
དེ་ནི་རྣམ་པ་དྲུག་ཏུ་བལྟ་བར་བྱ་སྟེ། ཆོས་གདགས་པ་རྣམ་པར་གཞག་པ་དང་། དོན་གདགས་པ་རྣམ་པར་གཞག་པ་དང་། གང་ཟག་གདགས་པ་རྣམ་པར་གཞག་པ་དང་། དུས་གདགས་པ་རྣམ་པར་གཞག་པ་དང་། གྲངས་གདགས་པ་རྣམ་པར་གཞག་པ་དང་། གཞི་ཡན་ལག་དང་བཅས་པ་གདགས་པ་རྣམ་པར་གཞག་པའོ། །

Enumeration Block 5:
དེ་ལ་དོན་གདགས་པ་རྣམ་པར་གཞག་པ་ནི། རྣམ་པ་བཅུར་རིག་པར་བྱ་སྟེ། དབང་པོ་རྣམ་པར་གཞག་པ་དང་། འབྱུང་བ་ཆེན་པོ་རྣམ་པར་གཞག་པ་དག་ལས་རྣམ་པར་གཞག་པ་དང་། ཡོངས་སུ་ཚོལ་བ་རྣམ་པར་གཞག་པ་དང་། ཆོས་མ་ཡིན་པ་རྣམ་པར་གཞག་པ་དང་། ཆོས་རྣམ་པར་གཞག་པ་དང་། འབྱོར་པ་རྣམ་པར་གཞག་པ་དང་། རྒུད་པ་རྣམ་པར་གཞག་པ་དང་། ལོངས་སྤྱོད་རྣམ་པར་གཞག་པ་དང་། རྗེས་སུ་སྲུང་བ་རྣམ་པར་གཞག་པའོ། །

Enumeration Block 1:
དེ་ནི་རྣམ་པ་དྲུག་ཏུ་བལྟ་བར་བྱ་སྟེ། ཆོས་གདགས་པ་རྣམ་པར་གཞག་པ་དང་། དོན་གདགས་པ་རྣམ་པར་གཞག་པ་དང་། གང་ཟག་གདགས་པ་རྣམ་པར་གཞག་པ་དང་། དུས་གདགས་པ་རྣམ་པར་གཞག་པ་དང་། གྲངས་གདགས་པ་རྣམ་པར་གཞག་པ་དང་། གཞི་ཡན་ལག་དང་བཅས་པ་གདགས་པ་རྣམ་པར་གཞག་པའོ། །

Enumeration Block 2:
དེ་ལ་དོན་གདགས་པ་རྣམ་པར་གཞག་པ་ནི། རྣམ་པ་བཅུར་རིག་པར་བྱ་སྟེ། དབང་པོ་རྣམ་པར་གཞག་པ་དང་། འབྱུང་བ་ཆེན་པོ་རྣམ་པར་གཞག་པ་དག་ལས་རྣམ་པར་གཞག་པ་དང་། ཡོངས་སུ་ཚོལ་བ་རྣམ་པར་གཞག་པ་དང་། ཆོས་མ་ཡིན་པ་རྣམ་པར་གཞག་པ་དང་། ཆོས་རྣམ་པར་གཞག་པ་དང་། འབྱོར་པ་རྣམ་པར་གཞག་པ་དང་། རྒུད་པ་རྣམ་པར་གཞག་པ་དང་། ལོངས་སྤྱོད་རྣམ་པར་གཞག་པ་དང་། རྗེས་སུ་སྲུང་བ་རྣམ་པར་གཞག་པའོ། །

Enumeration Block 3:
ཡང་མདོར་བསྡུ་ན་དོན་རྣམ་པ་དྲུག་ཏུ་རིག་པར་བྱ་སྟེ། ངོ་བོ་ཉིད་ཀྱི་དོན་དང་། རྒྱུའི་དོན་དང་། འབྲས་བུའི་དོན་དང་། བྱ་བའི་དོན་དང་། ཁྱད་པར་དུ་སྦྱོར་བའི༌[^1199]དོན་དང་། འཇིགས་པའི༌[^1200]དོན་ཏོ། །

Enumeration Block 4:
དེ་ལ་དུས་གདགས་པ་རྣམ་པར་གཞག་པ་ནི། དུས་རྣམ་པ་གསུམ་སྟེ། འདས་པ་སྟེ་འདས་པའི་བྱེ་བྲག་དང་། མ་འོངས་པ་སྟེ་མ་འོངས་པའི་བྱེ་བྲག་དང་། ད་ལྟར་གྱི་སྟེ་ད་ལྟར་གྱི༌[^1202]བྱེ་བྲག་གོ། །

Enumeration Block 5:
དེ་ལ་གྲངས་གདགས་པ་རྣམ་པར་གཞག་པ་ནི། གྲངས་རྣམ་པ་གསུམ་སྟེ། གཅིག་གི་གྲངས་དང་། གཉིས་ཀྱི་གྲངས་དང་། མང་པོའི་གྲངས་སོ། །

Enumeration Block 6:
དེ་ལ་གཞི་རྣམ་པར་གཞག་པ་དང་། ཡན་ལག་རྣམ་པར་གཞག་པ་ལ་གཞི་ནི་ལྔ་སྟེ། སྦྱར་བ་དང་། མིང་དང་། བསྡུ་བ་དང་། དེ་ལ་ཕན་པ་དང་། སྙད་པའོ། །

Enumeration Block 7:
བཟོ་རྣམ་པ་བཅུ་གཉིས་གང་ཞེ་ན།
འདི་ལྟ་སྟེ། སྣམས་སུ༌[^1203]བྱ་བའི་བཟོ་དང་། ཉོ་ཚོང་གི་བཟོ་དང་། རྒྱལ་པོའི་ཞམ་འབྲིང་བྱ་བའི་བཟོ་དང་། ཡི་གེ་དང་། རྩིས་དང་། ཤོད་དགོད་པ་དང་། གྲངས་དང་། ལག་རྩིས་ཀྱི་བཟོ་དང་། ལྟས་སུ་བལྟ་བའི་བཟོ་དང་། བློ་གྲོས་ཀྱི་བཟོ་དང་། འབུར་གྱི་བཟོ་དང་། བསྐྱེད་པའི་བཟོ་དང་། སྣམས་སུ་བྱ་བའི་བཟོ་དང་། སྦྱོར་བའི་བཟོ་དང་། གཡོས་སུ་བྱ་བའི་བཟོ་དང་། རོལ་མོའི་བཟོའོ། །

Enumeration Block 8:
དེ་ནི་མདོར་བསྡུ་ན་རྣམ་པ་གསུམ་དུ་རིག་པར་བྱ་སྟེ། ངོ་བོ་ཉིད་རྣམ་པར་དག་པ་དང་། ཤེས་བྱ་རབ་ཏུ་རྣམ་པར་འབྱེད་པ་དང་། ཆོས་རབ་ཏུ་རྣམ་པར་འབྱེད་པའོ། །

Enumeration Block 9:
དེ་ནི་རྣམ་པ་ལྔར་བལྟ་བར་བྱ་སྟེ། རང་གི་མཚན་ཉིད་ཀྱིས་ཡོད་པ་དང་། སྤྱིའི་མཚན་ཉིད་ཀྱིས་ཡོད་པ་དང་། བརྡའི་མཚན་ཉིད་ཀྱིས་ཡོད་པ་དང་། རྒྱུའི་མཚན་ཉིད་ཀྱིས་ཡོད་པ་དང་། འབྲས་བུའི་མཚན་ཉིད་ཀྱིས་ཡོད་པའོ། །

Enumeration Block 10:
དེ་ནི་རྣམ་པ་གསུམ་དུ་བལྟ་བར་བྱ་སྟེ། དོན་དམ་པའི་མཚན་ཉིད་ཀྱིས་ཡོད་པ་དང་། མཚན་མའི་མཚན་ཉིད་ཀྱིས་ཡོད་པ་དང་། ད་ལྟར་གྱི་མཚན་ཉིད་ཀྱིས་ཡོད་པའོ། །

Enumeration Block 11:
དེ་ཡང་རྣམ་པ་ལྔར་བལྟ་བར་བྱ་སྟེ། སྐྱེ་བའི་སྤྱིའི་མཚན་ཉིད་དང་། བྱ་བ་བསྒྲུབ་པའི་སྤྱིའི་མཚན་ཉིད་དང་། འདུ་བྱེད་ཐམས་ཅད་ཀྱི་སྤྱིའི་མཚན་ཉིད་དང་། ཟག་པ་དང་བཅས་པ་ཐམས་ཅད་ཀྱི་སྤྱིའི་མཚན་ཉིད་དང་། ཆོས་ཐམས་ཅད་ཀྱི་སྤྱིའི་མཚན་ཉིད་དོ། །

Enumeration Block 12:
བརྗོད་པ་རྣམ་པ་དྲུག་གང་ཞེ་ན།
བདག་པོ་དང་འབྲེལ་པར་ལྡན་པའི་བརྗོད་པ་དང་། དེས་དེ་དང་གཞན་གྱིས་གཞན་སྤངས་པའི་བརྗོད་པ་དང་། བརྡ༌[^1213]ལས་བྱུང་བའི་བརྗོད་པ་དང་། མང་པོ་ལས་བྱུང་བའི་བརྗོད་པ་དང་། ཀུན་དུ་འགྲོ་བ་མ་ཡིན༌[^1214]པའི་བརྗོད་པ་དང་། མི་རྟག་པའི་བརྗོད་པའོ། །

Enumeration Block 1:
བརྗོད་པ་རྣམ་པ་དྲུག་གང་ཞེ་ན།
བདག་པོ་དང་འབྲེལ་པར་ལྡན་པའི་བརྗོད་པ་དང་། དེས་དེ་དང་གཞན་གྱིས་གཞན་སྤངས་པའི་བརྗོད་པ་དང་། བརྡ༌[^1213]ལས་བྱུང་བའི་བརྗོད་པ་དང་། མང་པོ་ལས་བྱུང་བའི་བརྗོད་པ་དང་། ཀུན་དུ་འགྲོ་བ་མ་ཡིན༌[^1214]པའི་བརྗོད་པ་དང་། མི་རྟག་པའི་བརྗོད་པའོ། །
Enumeration Block 2:
མཚན་མའི་མཚན་ཉིད་རྣམ་པ་དྲུག་པོ་གང་ཞེ་ན།
