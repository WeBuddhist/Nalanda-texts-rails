གཟུགས་ན་སྤྱོད་པ་རྣམ་པ་གསུམ་སྟེ། མི་དགེ་བ་མ་གཏོགས་པ་དང་། གཟུགས་མེད་པ་ན་སྤྱོད་པ་ཡང་དེ་དང་འདྲ་བ་དང་། འཇིག་རྟེན་ལས་འདས་པ་སློབ་པ༌[^421]དང་མི་སློབ་པའོ། །

Enumeration Block 8:
གཟུགས་ནི་རྣམ་པ་གཅིག་སྟེ། མིག་གི་སྤྱོད་ཡུལ་གྱི་དོན་གྱིས་སོ། །
རྣམ་པ་གཉིས་ཏེ། ནང་གི་དང་ཕྱི་རོལ་གྱིའོ། །
རྣམ་པ་གསུམ་སྟེ། ཁ་དོག་དང་། དབྱིབས་དང་རྣམ་པར་རིག་བྱེད་དོ། །
རྣམ་པ་བཞི་སྟེ། རང་གི་རྟེན་སྣང་བར་བྱེད་པ་དང་། རང་གི་རྟེན་སྣང་བར་བྱེད་པ་མ་ཡིན་པ་དང་། བདེ་བ་དང་། བདེ་བ་མ་ཡིན་པར་སྣང་བ་དང་། བསགས་པར་གནས་པའོ། །
རྣམ་པ་ལྔ་སྟེ། འགྲོ་བ་ལྔའི་བྱེ་བྲག་གིས་སོ། །
རྣམ་པ་དྲུག་སྟེ། གཞིར༌[^422]བསྡུས་པ་དང་། གནས་སུ་བསྡུས་པ་དང་། ཡུལ་དུ་བསྡུས་པ་དང་། སེམས་ཅན་དུ་བགྲང་བ་དང་། སེམས་ཅན་དུ་བགྲང་བ་མ་ཡིན་པ་དང་། བསྟན་དུ་ཡོད་ལ་ཐོགས་པ་དང་བཅས་པའོ། །
རྣམ་པ་བདུན་ཏེ། ཡོངས་སུ་གཟུང་བ༌[^423]རྣམ་པ་བདུན་པོ་དག་གི་བྱེ་བྲག་གིས་སོ། །

Enumeration Block 1:
རྣམ་པ་དགུ་སྟེ། སེམས་ཅན་གྱི་གནས་དགུ་པོ་རྣམས་སོ། །

Enumeration Block 2:
རྣམ་པ་བཅུ་གཅིག་སྟེ་སྔ་མ་བཞིན་ནོ། །

Enumeration Block 3:
རྣམ་པ་བཅུ་གཉིས་ནི་སེམས་བཅུ་གཉིས་ཏེ། འདོད་པ་ན་སྤྱོད་པ་དང་། དགེ་བ་དང་། མི་དགེ་བ་དང་། བསྒྲིབས་ལ་ལུང་དུ་མ་བསྟན་པ་དང་། མ་བསྒྲིབས་ལ་ལུང་དུ་མ་བསྟན་པའོ།[^420] །

Enumeration Block 4:
གཟུགས་ན་སྤྱོད་པ་རྣམ་པ་གསུམ་སྟེ། མི་དགེ་བ་མ་གཏོགས་པ་དང་། གཟུགས་མེད་པ་ན་སྤྱོད་པ་ཡང་དེ་དང་འདྲ་བ་དང་། འཇིག་རྟེན་ལས་འདས་པ་སློབ་པ༌[^421]དང་མི་སློབ་པའོ། །

Enumeration Block 5:
གཟུགས་ནི་རྣམ་པ་གཅིག་སྟེ། མིག་གི་སྤྱོད་ཡུལ་གྱི་དོན་གྱིས་སོ། །

Enumeration Block 6:
རྣམ་པ་གཉིས་ཏེ། ནང་གི་དང་ཕྱི་རོལ་གྱིའོ། །

Enumeration Block 7:
རྣམ་པ་གསུམ་སྟེ། ཁ་དོག་དང་། དབྱིབས་དང་རྣམ་པར་རིག་བྱེད་དོ། །

Enumeration Block 8:
རྣམ་པ་བཞི་སྟེ། རང་གི་རྟེན་སྣང་བར་བྱེད་པ་དང་། རང་གི་རྟེན་སྣང་བར་བྱེད་པ་མ་ཡིན་པ་དང་། བདེ་བ་དང་། བདེ་བ་མ་ཡིན་པར་སྣང་བ་དང་། བསགས་པར་གནས་པའོ། །

Enumeration Block 9:
རྣམ་པ་ལྔ་སྟེ། འགྲོ་བ་ལྔའི་བྱེ་བྲག་གིས་སོ། །

Enumeration Block 10:
རྣམ་པ་དྲུག་སྟེ། གཞིར༌[^422]བསྡུས་པ་དང་། གནས་སུ་བསྡུས་པ་དང་། ཡུལ་དུ་བསྡུས་པ་དང་། སེམས་ཅན་དུ་བགྲང་བ་དང་། སེམས་ཅན་དུ་བགྲང་བ་མ་ཡིན་པ་དང་། བསྟན་དུ་ཡོད་ལ་ཐོགས་པ་དང་བཅས་པའོ། །

Enumeration Block 11:
རྣམ་པ་བདུན་ཏེ། ཡོངས་སུ་གཟུང་བ༌[^423]རྣམ་པ་བདུན་པོ་དག་གི་བྱེ་བྲག་གིས་སོ། །

Enumeration Block 12:
རྣམ་པ་བརྒྱད་དེ། འཇིག་རྟེན་གྱི་སྣ་ཚོགས་བརྒྱད་དེ། དེ་དག་ཀྱང་ས་ཕྱོགས་སྣ་ཚོགས་དང་། རི་སྣ་ཚོགས་དང་། ཀུན་དགའ་ར་བ་དང་། ནགས་ཚལ་དང་། མཚོ་དང་། མཚེའུ་ལ་སོགས་པ་སྣ་ཚོགས་དང་། ཁང་ཁྱིམ་དང་གཞལ་མེད་ཁང་སྣ་ཚོགས་དང་། ལས་ཀྱི་གནས༌[^424]སྣ་ཚོགས་དང་། རི་མོ་བྲི་བ་སྣ་ཚོགས་དང་། བརྡུང་སྦྱར་གྱི་ལས་སྣ་ཚོགས་དང་། ཡོ་བྱད་སྣ་ཚོགས་སོ། །

Enumeration Block 13:
རྣམ་པ་དགུ་སྟེ། འདས་པ་དང་། མ་འོངས་པ་དང་། ད་ལྟར་བྱུང་བ་དང་། རགས་པ་དང་། ཆ་ཕྲ་བའམ། ངན་པའམ། བཟང་པོའམ། གང་རྒྱང་རིང་བའམ། གང་ཐག་ཉེ་བའོ། །

Enumeration Block 14:
རྣམ་པ་བཅུ་སྟེ། ཡོ་བྱད་བཅུ་པོ་རྣམས་སོ། །

Enumeration Block 15:
སྒྲ་ནི་རྣམ་པ་གཅིག་སྟེ། རྣ་བའི་སྤྱོད་ཡུལ་གྱི་དོན་གྱིས་སོ། །

Enumeration Block 16:
རྣམ་པ་གཉིས་ཏེ། གསལ་བའི་དོན་གྱི་སྒྲ་སྐད་དང་། གསལ་བ་མ་ཡིན་པའི་དོན་གྱི་སྒྲ་སྐད་དོ། །

Enumeration Block 17:
རྣམ་པ་གསུམ་སྟེ། ཟིན་པའི་འབྱུང་བ༌[^425]ཆེན་པོའི་རྒྱུ་ལས་བྱུང་བ་དང་། མ་ཟིན་པའི་འབྱུང་བ་ཆེན་པོའི་རྒྱུ་ལས་བྱུང་བ་དང་། དེ་གཉི་གའི་འབྱུང་བ་ཆེན་པོའི་རྒྱུ་ལས་བྱུང་བའོ། །

Enumeration Block 18:
རྣམ་པ་བཞི་སྟེ། དགེ་བ་དང་། མི་དགེ་བ་དང་། བསྒྲིབས་ལ་ལུང་དུ་མ་བསྟན་པ་དང་། མ་བསྒྲིབས་ལ་ལུང་དུ་མ་བསྟན་པའོ། །

Enumeration Block 19:
རྣམ་པ་ལྔ་སྟེ། འགྲོ་བ་ལྔའི་བྱེ་བྲག་གིས་སོ། །

Enumeration Block 20:
རྣམ་པ་དྲུག་སྟེ། ལུང་ནོད་པ་དང་། ཁ་ཐོན་བྱེད་པའི་སྒྲ་དང་། ཀུན་ཏུ་འདྲི་བ་དང་། ཡོངས་སུ་འདྲི་བའི་སྒྲ་དང་། ཆོས་འཆད་པའི་སྒྲ་དང་། འབེལ་བའི་གཏམ་དང་། རྣམ་པར་གཏན་ལ་འབེབས་པའི་སྒྲ་དང་། གཅིག་ལ་གཅིག་ཚིག་གིས་འདེབས་ཤིང་ཉེས་པ་ལས་འབྱིན་པའི་སྒྲ་དང་། འདྲེས་པ་ཅ་ཅོའི་སྒྲའོ། །

Enumeration Block 21:
རྣམ་པ་བདུན་ཏེ། བུད་མེད་ཀྱི་སྒྲ་དང་། སྐྱེས་པའི་སྒྲ་དང་། ཆུང་ངུ་དང་། འབྲིང་དང་། ཆེན་པོ་དང་། རི་དགས་དང་། བྱ་ལ་སོགས་པའི་སྒྲ་དང་། རླུང་དང་ཤིང་གི་སྒྲའོ། །

Enumeration Block 22:
རྣམ་པ་བརྒྱད་དེ། འཕགས་པའི་ཐ་སྙད་བཞི་པོའི་སྒྲ་རྣམས་དང་། འཕགས་པ་མ་ཡིན་པའི་ཐ་སྙད་བཞི་པོའི་སྒྲ་རྣམས་ཏེ། མ་མཐོང་བར་མཐོང་ངོ་ཞེས་སྨྲ༌[^426]བ་དང་། མཐོང་བ་ལ་མ་མཐོང་ངོ་ཞེས་སྨྲ་བ་འཕགས་པའི༌[^427]ཐ་སྙད་དང་། མ་ཐོས་པ་དང་། བྱེ་བྲག་མ་ཕྱེད་པ་དང་། རྣམ་པར་མ་ཤེས་པར་རྣམ་པར་ཤེས༌[^428]སོ་ཞེས་སྨྲ་བ་དང་། རྣམ་པར་ཤེས་པ་ལ་རྣམ་པར་མི༌[^429]ཤེས་སོ་ཞེས་སྨྲ་བ་འཕགས་པ་མ་ཡིན་པའི་ཐ་སྙད་དང་། མཐོང་བ་ལ་མཐོང་ཞེས་སྨྲ་བ་དང་། མ་མཐོང་བ་ལ་ཡང་མ་མཐོང་ཞེས་སྨྲ་བ་འཕགས་པའི་ཐ་སྙད་དང་། ཐོས་པ་དང་། བྱེ་བྲག་ཕྱེད་པ་དང་། རྣམ་པར་ཤེས་པ་ལ་རྣམ་པར་ཤེས་སོ་ཞེས་སྨྲ་བ་དང་། རྣམ་པར་མི༌[^430]ཤེས་པ་ལ་ཡང་རྣམ་པར་མ་ཤེས་སོ་ཞེས་སྨྲ་བ་འཕགས་པའི་ཐ་སྙད་དོ། །

Enumeration Block 23:
གཞན་ཡང་རྣམ་པ་བརྒྱད་དེ། ངག་གི༌[^431]ལས་ཀྱི་ལམ་དགེ་བ་བཞི་དང་། མི་དགེ་བ་བཞིའོ། །

Enumeration Block 24:
རྣམ་པ་དགུ་སྟེ། འདས་པ་དང་། མ་འོངས་པ་དང་། ད་ལྟར་བྱུང་བ་ནས།[^432] རྒྱང་རིང་བ་དང་། ཐག་ཉེ་བའི་བར་དག་གོ། །

Enumeration Block 25:
རྣམ་པ་བཅུ་སྟེ། སིལ་སྙན་གྱི་རྣམ་པ་ལྔར་བསྡུས་པ་སྟེ། དེ་ཡང་གར་དང་ལྡན་པ་དང་། གླུ་དང་ལྡན་པ་དང་རོལ་མོའི་སྒྲ་དང་ལྡན་པ་དང་། བུད་མེད་དང་ལྡན་པ་དང་། སྐྱེས་པ་དང་ལྡན་པ་དང་། དུང་གི་སྒྲ་དང་། རྔ་པ་ཊ་ཧའི་སྒྲ་དང་། རྔ་བོ་ཆེའི་སྒྲ་དང་། རྫ་རྔའི་སྒྲ་དང་། སྒྲ་བོ་ཆེའི་སྒྲའོ།[^433] །

Enumeration Block 26:
དྲི་ནི་རྣམ་པ་གཅིག་སྟེ། སྣའི་སྤྱོད་ཡུལ་གྱི་དོན་གྱིས་སོ། །

Enumeration Block 27:
རྣམ་པ་གཉིས་ཏེ། ནང་གི་དང་། ཕྱི་རོལ་གྱིའོ། །

Enumeration Block 28:
རྣམ་པ་གསུམ་སྟེ། ཡིད་དུ་འོང་བ་དང་། ཡིད་དུ་མི་འོང་བ་དང་། བཏང་སྙོམས་ཀྱི་གནས་སོ། །

Enumeration Block 29:
རྣམ་པ་བཞི་ནི་དྲི་ཆེན་པོ་རྣམ་པ་བཞི་སྟེ། ཨ་ཀ་རུའི་དྲི་དང་། དུ་རུ་སྐའི༌[^434]དྲི་དང་། ག་པུར་གྱི་དྲི་དང་། གླ་རྩིའི་དྲིའོ། །

Enumeration Block 30:
རྣམ་པ་ལྔ་སྟེ། རྩ་བའི་དྲི་དང་། སྙིང་པོའི་དྲི་དང་། ལོ་མའི་དྲི་དང་། མེ་ཏོག་གི་དྲི་དང་། འབྲས་བུའི་དྲིའོ། །

Enumeration Block 31:
རྣམ་པ་དྲུག་སྟེ། ཟས་ཀྱི་དྲི་དང་། སྐོམ་གྱི་དྲི་དང་། གོས་ཀྱི་དྲི་དང་། རྒྱན་གྱི་དྲི་དང་། བཞོན་པའི་དྲི་དང་། གནས་ཀྱི་དྲིའོ། །

Enumeration Block 32:
རྣམ་པ་བདུན་ཏེ། ཤིང་ཚའི༌[^435]དྲི་དང་། སྤོས་ལོའི་དྲི་དང་། སུག་སྨེལ་གྱི་དྲི་དང་། ཙན་དན་གྱི་དྲི་དང་། ཚ་བ་གསུམ་གྱི་དྲི་དང་། བདུག་པའི་དྲི་དང་། ཕྱེ་མའི་དྲིའོ། །

Enumeration Block 33:
རྣམ་པ་བརྒྱད་དེ། ལྷན་ཅིག་སྐྱེས་པ་དང་། ལྷན་ཅིག་སྐྱེས་པ་མ་ཡིན་པ་དང་། བརྟན་པ་དང་། བརྟན་པ་མ་ཡིན་པ་དང་། སྦྱར་བ་དང་། འབའ་ཞིག་པ་དང་། དྲི་ཆེ་བ་དང་། དྲི་ཆེ་བ་མ་ཡིན་པའོ། །

Enumeration Block 34:
རྣམ་པ་དགུ་སྟེ། འདས་པ་དང་། མ་འོངས་པ་དང་། ད་ལྟར་བྱུང་བ༌[^436]ནས། རྒྱང་རིང་བ་དང་། ཐག་ཉེ་བའི་བར་དག་གོ། །

Enumeration Block 35:
རྣམ་པ་བཅུ་སྟེ། སྐྱེས་པའི་དྲི་དང་། བུད་མེད་ཀྱི་དྲི་དང་། ཕྱི༌[^437]སའི་དྲི་དང་། གཅིན་གྱི་དྲི་དང་། ངར་སྣབས༌[^438]ཀྱི་དྲི་དང་། སྣབས་ཀྱི་དྲི་དང་། ཞག་དང་། ཆུ་སེར་གྱི་དྲི་དང་། རྣག་དང་། ཁྲག་གི་དྲི་དང་། ཤའི་དྲི་དང་། འདྲེས་པའི་དྲི་དང་། རུལ་པའི་དྲི་དང་། འདམ་རྫབ་ཀྱི་དྲིའོ། །

Enumeration Block 36:
རོ་ནི་རྣམ་པ་གཅིག་སྟེ། ལྕེའི་སྤྱོད་ཡུལ་གྱི་དོན་གྱིས་སོ། །

Enumeration Block 37:
རྣམ་པ་གཉིས་ཏེ། ནང་དང་། ཕྱི་རོལ༌[^439]གྱིའོ། །

Enumeration Block 38:
རྣམ་པ་གསུམ་སྟེ། ཡིད་དུ་འོང་བ་ནས་སྔ་མ་བཞིན་ནོ། །

Enumeration Block 39:
རྣམ་པ་བཞི་སྟེ། ནས་ཀྱི་རོ་དང་། སཱ་ལུའི་རོ་དང་། གྲོའི་རོ་དང་། འབྲུ་གཞན་གྱི་རོའོ། །

Enumeration Block 40:
རྣམ་པ་ལྔ་སྟེ། ཆང་གི་རོ་དང་། ཆང་མ་ཡིན་པའི་རོ་དང་། སྔོ་རྔད་ཀྱི་རོ་དང་། ནགས་ཚལ་གྱི་ཤིང་ཐོག་གི་རོ་དང་། ཁ་ཟས་ཀྱི་རོའོ། །

Enumeration Block 41:
རྣམ་པ་དྲུག་སྟེ། ཁ་བ་ལ་སོགས་པའོ། །

Enumeration Block 42:
རྣམ་པ་བདུན་ཏེ། མར་དང་། འབྲུ་མར་དང་། སྦྲང་རྩི་དང་། བུ་རམ་ཤིང་ལས་བྱུང་བའི་རོ་དང་། མངར་བའི་རོ་དང་། ལན་ཚྭའི་རོ་དང་། ཤའི་རོའོ།[^440] །

Enumeration Block 43:
རྣམ་པ་བརྒྱད་དེ། །དྲི་བཞིན་ནོ། །

Enumeration Block 44:
རྣམ་པ་དགུ་སྟེ། དྲི་ཁོ་ན་བཞིན་ནོ། །

Enumeration Block 45:
རྣམ་པ་བཅུ་སྟེ། བཅའ་བའི་རོ་དང་། བཟའ་བའི་རོ་དང་། མྱང་བའི་རོ་དང་། བཏུང་བའི་རོ་དང་། གཞིབ༌[^441]པའི་རོ་དང་། ཤ་འབྲི་བར་བྱེད་པ་དང་། ཤ་བརྟས་པར༌[^442]བྱེད་པ་དང་། ཞི་བར་བྱེད་པ་དང་། སྦྱོང་བར་བྱེད་པ་དང་། བརྟན་པར་བྱ་བའི་སྨན་གྱི་རོ་རྣམས་སོ། །

Enumeration Block 46:
རེག་བྱ་ནི་རྣམ་པ་གཅིག་སྟེ། ལུས་ཀྱི་སྤྱོད་ཡུལ་གྱི་དོན་གྱིས་སོ། །

Enumeration Block 47:
རྣམ་པ་གཉིས་ཏེ། དྲི་བཞིན་ནོ། །

Enumeration Block 48:
རྣམ་པ་གསུམ་སྟེ། ཡིད་དུ་འོང་བ་ལ་སོགས་པའོ། །

Enumeration Block 49:
རྣམ་པ་བཞི་སྟེ། རེག་པར་བྱ་བའི༌[^443]རེག་པར་བྱ་བ་དང་། བཙིར་བའི་རེག་པ་དང་། བསྣུན་པའི་རེག་པ་དང་། མཉེ་བའི་རེག་པའོ། །

Enumeration Block 50:
རྣམ་པ་ལྔ་སྟེ། འགྲོ་བ་ལྔའི་བྱེ་བྲག་གིས་སོ། །

Enumeration Block 51:
རྣམ་པ་དྲུག་སྟེ། བདེ་བ་དང་། སྡུག་བསྔལ་བ་དང་། སྡུག་བསྔལ་བ་ཡང་མ་ཡིན་བདེ་བ་ཡང་མ་ཡིན་པ་དང་། ལྷན་ཅིག་སྐྱེས་པ་དང་། མི་མཐུན་པའི་ཕྱོགས་སུ་བསྡུས་པ་དང་གཉེན་པོར་བསྡུས་པའོ། །

Enumeration Block 52:
རྣམ་པ་བདུན་ཏེ། སྲ་བ་དང་། གཤེར་བ་དང་། དྲོ་བ་དང་། གཡོ་བ་དང་། མཆོང་བ་དང་། ལྷུང་བའི་འདུས་ཏེ་རེག་པ་དང་། བྱུག་ནོམ་གྱི་འདུས་ཏེ་རེག་པ་དང་། ལུས་འགྱུར་གྱི་འདུས་ཏེ་རེག་པ་སྟེ། འདི་ལྟ་སྟེ། [^444]འཇམ་པ་ལ་སོགས་པ་རྣམས་ལའོ། །

Enumeration Block 53:
རྣམ་པ་བརྒྱད་དེ། །ལག་པའི་འདུས་ཏེ་རེག་པ་དང་། བོང་བའི་འདུས་ཏེ་རེག་པ་དང་། དབྱུག་པའི་འདུས་ཏེ་རེག་པ་དང་། མཚོན་ཆའི་འདུས་ཏེ་རེག་པ་དང་། གྲང་བའི་འདུས་ཏེ་རེག་པ་དང་། ཚ་བའི༌[^445]འདུས་ཏེ་རེག་པ་དང་། བཀྲེས་པའི༌[^446]འདུས་ཏེ་རེག་པ་དང་། སྐོམ་པའི༌[^447]འདུས་ཏེ་རེག་པའོ། །

Enumeration Block 54:
རྣམ་པ་དགུ་སྟེ། དྲི་བཞིན་ནོ། །

Enumeration Block 55:
རྣམ་པ་བཅུ་སྟེ། ཁ་ཟས་ཀྱི་འདུས་ཏེ་རེག་པ་དང་། སྐོམ་པའི་འདུས་ཏེ་རེག་པ་དང་། བཞོན་པའི་འདུས་ཏེ་རེག་པ་དང་། གོས་ཀྱི་འདུས་ཏེ་རེག་པ་དང་། རྒྱན་གྱི་འདུས་ཏེ་རེག་པ་དང་། ཁྲི་དང་ཁྲིའུའི་འདུས་ཏེ་རེག་པ་དང་། སྟན་ནང་ཚངས་ཅན་དང་། ལ་བའི་སྟན༌[^448]དང་། སྔས་ནང་ཚངས་ཅན་དང་། གོར་བུའི་འདུས་ཏེ་རེག་པ་དང་། བུད་མེད་ཀྱི་འདུས་ཏེ་རེག་པ་དང་། སྐྱེས་པའི་འདུས་ཏེ་རེག་པ་དང་། དེ་གཉིས་དགའ་མགུར་སྤྱོད་ཅིང་ཡོངས་སུ་སྤྱོད་པའི་འདུས་ཏེ་རེག་པའོ། །

Enumeration Block 56:
ཆོས་ཀྱི་ཁམས་དེ་ཡང་རྣམ་པ་གཅིག་སྟེ། ཡིད་ཀྱི་སྤྱོད་ཡུལ་གྱི་དོན་གྱིས་སོ། །

Enumeration Block 57:
རྣམ་པ་གཉིས་ཏེ། གདགས་པའི་ཆོས་སུ་བསྡུས་པ་དང་། གདགས་པ་མ་ཡིན་པའི་ཆོས་སུ་བསྡུས་པའོ། །

Enumeration Block 58:
རྣམ་པ་གསུམ་སྟེ། གཟུགས་ཅན་དང་། གཟུགས་ཅན་མ་ཡིན་པ་དང་། འདུས་བྱས་དང་། འདུས་མ་བྱས་སོ། །

Enumeration Block 59:
རྣམ་པ་བཞི་སྟེ། གཟུགས་ཅན་གདགས་པའི་ཆོས་སུ་བསྡུས་པ་དང་། གཟུགས་ཅན་མ་ཡིན་པ་སེམས་ལས་འབྱུང་བའི༌[^451]ཆོས་སུ་བསྡུས་པ་དང་། གཟུགས་ཅན་མ་ཡིན་པ་དང་ལྡན་ལྡན༌[^452]པ་མ་ཡིན་པ་གདགས་པའི་ཆོས་སུ་བསྡུས་པ་དང་། གཟུགས་ཅན་མ་ཡིན་པ་འདུས་མ་བྱས་པ༌[^453]གདགས་པའི་ཆོས་སུ་བསྡུས་པའོ། །

Enumeration Block 60:
རྣམ་པ་ལྔ་སྟེ། གཟུགས་དང་། སེམས་ལས་བྱུང་བའི་ཆོས་རྣམས་དང་། སེམས་དང་ལྡན་པ་མ་ཡིན་པ་རྣམས་དང་། འདུས་མ་བྱས་དགེ་བ་དང་། ལུང་དུ་མ་བསྟན་པའོ། །

Enumeration Block 61:
རྣམ་པ་དྲུག་སྟེ། ཚོར་བ་དང་། འདུ་ཤེས་དང་། འདུ་བྱེད་རྣམས་ལས་མཚུངས་པར་ལྡན་པ་རྣམས་དང་ལྡན་པ་མ་ཡིན་པ་རྣམས་དང་། གཟུགས་དང་། འདུས་མ་བྱས་སོ། །

Enumeration Block 62:
རྣམ་པ་བདུན་ཏེ། ཚོར་བ་དང་། འདུ་ཤེས་དང་། སེམས་པ་དང་། ཉོན་མོངས་པ་ཅན་དང་། ཉོན་མོངས་པ་ཅན་མ་ཡིན་པ་དང་། གཟུགས་དང་འདུས་མ་བྱས་སོ། །

Enumeration Block 63:
རྣམ་པ་བརྒྱད་དེ། དགེ་བ་དང་། མི་དགེ་བ་དང་། ལུང་དུ་མ་བསྟན་པ་དང་། ཚོར་བ་དང་། འདུ་ཤེས་དང་། འདུ་བྱེད་རྣམས་དང་། གཟུགས་དང་འདུས༌[^454]མ་བྱས་རྣམས་སོ། །

Enumeration Block 64:
རྣམ་པ་དགུ་སྟེ། འདས་པ་དང་། མ་འོངས་པ་ལ་སོགས་པའི་བྱེ་བྲག་གིས་སོ། །

Enumeration Block 65:
རྣམ་པ་བཅུ་ནི། རྣམ་པ་བཅུའི་ཕྱིར་ཏེ། རྗེས་སུ་འབྲེལ་པའི་སྐྱེ་བོའི་དོན་དང་། དམིགས་པ་མྱོང་བའི་དོན་དང་། དམིགས་པའི་མཚན་མར༌[^455]འཛིན་པའི་དོན་དང་། དམིགས་པ་མངོན་པར་འདུ་བྱེད་པའི་དོན་དང་། ཆོས་དེ་དག་ཉིད་དུས་ཐ་དད་པའི་དོན་དང་། སྒྲིབ་པ་མེད་པའི་དོན་དང་། མི་རྟག་པ་དང་བྲལ་བའི་དོན་དང་། མི་རྟག་པ་དང་མ་བྲལ་བའི་དོན་དང་། རྟག་པ་ཕྱིན་ཅི་མ་ལོག་པའི་དོན་དང་། བདེ་བ་དང་སྡུག་བསྔལ་དང་བྲལ༌[^456]བའི་དོན་དང་། ཚོར་བ་དང་བྲལ་བ་མ་ཡིན་པའི་དོན་དང་། ཚོར་བ་དང་བྲལ་བའི་དོན་དང་། ནང་དང་ཕྱིའི་སྐྱེ་མཆེད་རྣམས་ཀྱི་རབ་ཏུ་དབྱེ་བ་དེ༌[^457]དག་ནི། དྲུག་བརྒྱ་དྲུག་ཅུ་ཡོད་དོ། །

Enumeration Block 1:
ཆོས་ཀྱི་ཁམས་དེ་ཡང་རྣམ་པ་གཅིག་སྟེ། ཡིད་ཀྱི་སྤྱོད་ཡུལ་གྱི་དོན་གྱིས་སོ། །

Enumeration Block 2:
རྣམ་པ་གཉིས་ཏེ། གདགས་པའི་ཆོས་སུ་བསྡུས་པ་དང་། གདགས་པ་མ་ཡིན་པའི་ཆོས་སུ་བསྡུས་པའོ། །

Enumeration Block 3:
རྣམ་པ་གསུམ་སྟེ། གཟུགས་ཅན་དང་། གཟུགས་ཅན་མ་ཡིན་པ་དང་། འདུས་བྱས་དང་། འདུས་མ་བྱས་སོ། །

Enumeration Block 4:
རྣམ་པ་བཞི་སྟེ། གཟུགས་ཅན་གདགས་པའི་ཆོས་སུ་བསྡུས་པ་དང་། གཟུགས་ཅན་མ་ཡིན་པ་སེམས་ལས་འབྱུང་བའི༌[^451]ཆོས་སུ་བསྡུས་པ་དང་། གཟུགས་ཅན་མ་ཡིན་པ་དང་ལྡན་ལྡན༌[^452]པ་མ་ཡིན་པ་གདགས་པའི་ཆོས་སུ་བསྡུས་པ་དང་། གཟུགས་ཅན་མ་ཡིན་པ་འདུས་མ་བྱས་པ༌[^453]གདགས་པའི་ཆོས་སུ་བསྡུས་པའོ། །

Enumeration Block 5:
རྣམ་པ་ལྔ་སྟེ། གཟུགས་དང་། སེམས་ལས་བྱུང་བའི་ཆོས་རྣམས་དང་། སེམས་དང་ལྡན་པ་མ་ཡིན་པ་རྣམས་དང་། འདུས་མ་བྱས་དགེ་བ་དང་། ལུང་དུ་མ་བསྟན་པའོ། །

Enumeration Block 6:
རྣམ་པ་དྲུག་སྟེ། ཚོར་བ་དང་། འདུ་ཤེས་དང་། འདུ་བྱེད་རྣམས་ལས་མཚུངས་པར་ལྡན་པ་རྣམས་དང་ལྡན་པ་མ་ཡིན་པ་རྣམས་དང་། གཟུགས་དང་། འདུས་མ་བྱས་སོ། །

Enumeration Block 7:
རྣམ་པ་བདུན་ཏེ། ཚོར་བ་དང་། འདུ་ཤེས་དང་། སེམས་པ་དང་། ཉོན་མོངས་པ་ཅན་དང་། ཉོན་མོངས་པ་ཅན་མ་ཡིན་པ་དང་། གཟུགས་དང་འདུས་མ་བྱས་སོ། །

Enumeration Block 8:
རྣམ་པ་བརྒྱད་དེ། དགེ་བ་དང་། མི་དགེ་བ་དང་། ལུང་དུ་མ་བསྟན་པ་དང་། ཚོར་བ་དང་། འདུ་ཤེས་དང་། འདུ་བྱེད་རྣམས་དང་། གཟུགས་དང་འདུས༌[^454]མ་བྱས་རྣམས་སོ། །

Enumeration Block 9:
རྣམ་པ་དགུ་སྟེ། འདས་པ་དང་། མ་འོངས་པ་ལ་སོགས་པའི་བྱེ་བྲག་གིས་སོ། །

Enumeration Block 10:
རྣམ་པ་བཅུ་ནི། རྣམ་པ་བཅུའི་ཕྱིར་ཏེ། རྗེས་སུ་འབྲེལ་པའི་སྐྱེ་བོའི་དོན་དང་། དམིགས་པ་མྱོང་བའི་དོན་དང་། དམིགས་པའི་མཚན་མར༌[^455]འཛིན་པའི་དོན་དང་། དམིགས་པ་མངོན་པར་འདུ་བྱེད་པའི་དོན་དང་། ཆོས་དེ་དག་ཉིད་དུས་ཐ་དད་པའི་དོན་དང་། སྒྲིབ་པ་མེད་པའི་དོན་དང་། མི་རྟག་པ་དང་བྲལ་བའི་དོན་དང་། མི་རྟག་པ་དང་མ་བྲལ་བའི་དོན་དང་། རྟག་པ་ཕྱིན་ཅི་མ་ལོག་པའི་དོན་དང་། བདེ་བ་དང་སྡུག་བསྔལ་དང་བྲལ༌[^456]བའི་དོན་དང་། ཚོར་བ་དང་བྲལ་བ་མ་ཡིན་པའི་དོན་དང་། ཚོར་བ་དང་བྲལ་བའི་དོན་དང་། ནང་དང་ཕྱིའི་སྐྱེ་མཆེད་རྣམས་ཀྱི་རབ་ཏུ་དབྱེ་བ་དེ༌[^457]དག་ནི། དྲུག་བརྒྱ་དྲུག་ཅུ་ཡོད་དོ། །

Enumeration Block 11:
དངོས་པོ་དགུ་གང་ཞེ་ན། སེམས་ཅན་གྱི་དངོས་པོ་དང་། ལོངས་སྤྱོད་ཀྱི་དངོས་པོ་དང་། སྐྱེ་བའི་དངོས་པོ་དང་། གནས་པའི་དངོས་པོ་དང་། ཀུན་ནས་ཉོན་མོངས་པ་དང་། རྣམ་པར་བྱང་བའི་དངོས་པོ་དང་། སྣ་ཚོགས་ཀྱི་དངོས་པོ་དང་། སྟོན་པ་པོའི་དངོས་པོ་དང་། བསྟན་པར་བྱ་བའི་དངོས་པོ་དང་། འཁོར་གྱི་དངོས་པོའོ། །

Enumeration Block 12:
འཁོར་གྱི་དངོས་པོ་ནི་འཁོར༌[^469]བརྒྱད་དེ། རྒྱལ་རིགས་ཀྱི་འཁོར་དང་། བྲམ་ཟེའི་འཁོར་དང་། ཁྱིམ་བདག་གི་འཁོར་དང་། དགེ་སྦྱོང་གི་འཁོར་དང་། རྒྱལ་ཆེན་བཞིའི་རིས་ཀྱི་འཁོར་དང་། སུམ་ཅུ་རྩ་གསུམ་པའི་འཁོར་དང་། བདུད་ཀྱི༌[^470]རིས་ཀྱི་འཁོར་དང་། ཚངས་པའི་འཁོར་ཏོ། །

Enumeration Block 13:
ཁམས་གདགས་པ་རྣམ་པར་གདགས་པ་གང་ཞེ་ན། དེ་ནི་རྣམ་པ་བརྒྱད་དུ་རིག་པར་བྱ་སྟེ། གྲངས་རྣམ་པར་གཞག་པ་དང་། གནས་གཞན་རྣམ་པར་གཞག་པ་དང་། སེམས་ཅན་གྱི་ཚད་རྣམ་པར་གཞག་པ་དང་། སེམས་ཅན་དེ་དག་ཉིད་ཀྱི་ཚེའི་ཚད་རྣམ་པར་གཞག་པ་དང་། སེམས་ཅན་དེ་དག་ཉིད་ཀྱི་ལོངས་སྤྱོད་དང་། ཡོངས་སུ་སྤྱོད་པ་རྣམ་པར་གཞག་པ་དང་། སྐྱེ་བ་རྣམ་པར་གཞག་པ་དང་། ལུས་རྣམ་པར་གཞག་པ་དང་། རྒྱུ་དང་རྐྱེན་རྣམ་པར་གཞག་པའོ། །

Enumeration Block 14:
ཁམས་ནི་གསུམ་སྟེ། འདོད་པའི་ཁམས་དང་། གཟུགས་ཀྱི་ཁམས་དང་། གཟུགས་མེད་པའི་ཁམས་ཏེ།

Enumeration Block 15:
འདོད་པའི་ཁམས་ནི་གནས་གཞན་སུམ་ཅུ་རྩ་དྲུག་པོ་རྣམས་ཏེ། སེམས་ཅན་དམྱལ་བ་ཆེན་པོའི་གནས་བརྒྱད་ལ་འདི་ལྟ་སྟེ། ཡང་སོས་དང་། ཐིག་ནག་དང་། བསྡུས༌[^478]འཇོམས་དང་། ངུ་འབོད་དང་། ངུ་འབོད་ཆེན་པོ་དང་། ཚ་བ་དང་། རབ་ཏུ་ཚ་བ་དང་། མནར་མེད་པའོ། །

Enumeration Block 1:
འདོད་པའི་ཁམས་ནི་གནས་གཞན་སུམ་ཅུ་རྩ་དྲུག་པོ་རྣམས་ཏེ།

Enumeration Block 2:
སེམས་ཅན་དམྱལ་བ་ཆེན་པོའི་གནས་བརྒྱད་ལ་འདི་ལྟ་སྟེ། ཡང་སོས་དང་། ཐིག་ནག་དང་། བསྡུས་འཇོམས་དང་། ངུ་འབོད་དང་། ངུ་འབོད་ཆེན་པོ་དང་། ཚ་བ་དང་། རབ་ཏུ་ཚ་བ་དང་། མནར་མེད་པའོ། །

Enumeration Block 3:
གྲང་བའི་སེམས་ཅན་དམྱལ་བའི་གནས་བརྒྱད་ཡོད་པ་འདི་ལྟ་སྟེ། ཆུ་བུར་ཅན་དང་། ཆུ་བུར་རྡོལ་པ་དང་། སོ་ཐམས་ཐམས་པ་དང་། ཀྱི་ཧུད་ཟེར་བ་དང་། ཨ་ཅུ་ཟེར་བ་དང་། ཨུཏྤལ་ལྟར་གས་པ་དང་། པད་མ་ལྟར་གས་པ་དང་། པད་མ་ལྟར་གས་པ་ཆེན་པོའོ། །

Enumeration Block 4:
འདོད་པ་ན་སྤྱོད་པའི་ལྷ་རྣམ་པ་དྲུག་ལ། རྒྱལ་ཆེན་བཞིའི་རིས་དང་། སུམ་ཅུ་རྩ་གསུམ་དང་། འཐབ་བྲལ་དང་། དགའ་ལྡན་དང་། འཕྲུལ་དགའ་དང་། གཞན་འཕྲུལ་དབང་བྱེད་ཀྱི་ལྷ་རྣམས་སོ། །

Enumeration Block 5:
གཟུགས་ཀྱི་ཁམས་ནི་གནས་གཞན་བཅོ་བརྒྱད་དེ།

Enumeration Block 6:
གཟུགས་མེད་པའི་ཁམས་ནི༌གནས་གཞན་བཞི་པོ་རྣམས་སོ། །

Enumeration Block 1:
ཡི་དགས་རྣམས་ནི་མདོར་བསྡུ་ན་རྣམ་པ་གསུམ་སྟེ། ཟས་དང་སྐོམ་ལ་ཕྱི་རོལ་གྱི་སྒྲིབ་པ་ཡོད་པ་དང་། ཟས་དང༌[^580]སྐོམ་ལ་ནང་གི་སྒྲིབ་པ་ཡོད་པ་དང་། ཟས་དང་སྐོམ་ལ་སྒྲིབ་པ་ཡོད་པའོ། །

Enumeration Block 1:
དེའི་རིན་པོ་ཆེ་སྣ་བདུན་པོ་དེ་དག་ནི་འདི་ལྟ་བུ་ཡིན་ཏེ། འདི་ལྟ་སྟེ། འཁོར་ལོ་རིན་པོ་ཆེ་དང་། གླང་པོ་རིན་པོ་ཆེ་དང་། རྟ་རིན་པོ་ཆེ་དང་། ནོར་བུ་རིན་པོ་ཆེ་དང་། བུད་མེད་རིན་པོ་ཆེ་དང་། ཁྱིམ་བདག་རིན་པོ་ཆེ་དང་། བདུན་པ་བློན་པོ་རིན་པོ་ཆེའོ། །

Enumeration Block 2:
དེ་དག་གི་གཞལ་མེད་ཁང་ཡང་གསེར་ལས་གྲུབ་པ་དང་། དངུལ་ལས་གྲུབ་པ་དང་། ཤེལ་ལས་གྲུབ་པ་དང་། བཻ་ཌཱུརྱ་ལས་གྲུབ་པ་རྣམ་པ་བཞི་ཡོད་དོ། །

Enumeration Block 3:
དེ་དག་ལས་བདུད་རྩིའི་ཁ་ཟས་རྣམ་པ་བཞི་པོ་སྔོན་པོ་དང་། སེར་པོ་དང་། དམར་པོ་དང་། དཀར་པོ་དག་འབྱུང་བར་འགྱུར་རོ། །

Enumeration Block 4:

གནས་རྣམ་པ་དྲུག་སྟེ། འདི་ལྟ་སྟེ། ངེས་པའི་དུས་དང་། ལྡོག་པའི་དུས་དང་། ལས་ཀྱི་དུས་དང་། འཇིག་རྟེན་པའི་འདོད་ཆགས་དང་བྲལ་བའི་དུས་དང་། འཇིག་རྟེན་ལས་འདས་པའི་འདོད་ཆགས་དང་བྲལ་བའི་དུས་དང་། སེམས་ཅན་ལ་ཕན་འདོགས་པའི་དུས་སོ། །

Enumeration Block 7:
དངོས་པོ་བརྒྱད་དེ། སྦྱིན་པ་ལས་བྱུང་བའི་བསོད་ནམས་བྱ་བའི་དངོས་པོ་དང་། ཚུལ་ཁྲིམས་ལས་བྱུང་བ་དང་། བསྒོམས་པ་པ་ལས་བྱུང་བ་དང་། ཐོས་པ་ལས་བྱུང་བ་དང་། བསམས་པ་ལས་བྱུང་བ་དང་། དེ་ལས་གཞན་པའི་བསྒོམས་པ་ལས་བྱུང་བ་དང་། སོ་སོར་བརྟགས་པ་ལས་བྱུང་བ་དང་། སེམས་ཅན་ལ་ཕན་འདོགས་པ་ལས་བྱུང་བའོ། །

Enumeration Block 8:
ཡང་སྦྱིན་པ་དག་གི་མཚན་ཉིད་ནི་རྣམ་པ་བཞི་སྟེ། འདོད་པ་དང་། ཕྱོགས་མི་འཛིན་པ་དང་། ཕོངས་པ་སེལ་བ་དང་། ཡང་དག་པར་ཤེས་པའོ། །

Enumeration Block 9:
ཚུལ་ཁྲིམས་དང་ལྡན་པའི་མཚན་ཉིད་ནི། རྣམ་པ་བཞི་སྟེ། འདོད་པ་དང་ཆུ་ལོན་གྱིས་གློན་པ་དང་། ཀུན་ཏུ་མི་སྤྱོད་པ་དང་། ཡང་དག་པར་ཤེས་པའོ། །

Enumeration Block 10:
སྒོམ་པ་པོའི་མཚན་ཉིད་ནི་རྣམ་པ་བཞི་སྟེ། བསམ་པ་རྣམ་པར་དག་པ་དང་། ཉེ་བར་སྦྱོར་བ་རྣམ་པར་དག་པ་དང་། མོས་པས་སྙོམས་པར་འཇུག་པ་རྣམ་པར་དག་པ་དང་། ཤེས་པ་རྣམ་པར་དག་པའོ། །

Enumeration Block 11:
ཟས་སྦྱིན་པ་ནི་རྣམ་པ་དྲུག་སྟེ། ཡི་དམ་ཅན་ལ་སྦྱིན་པ་དང་། ཀུན་ཏུ་འཚོལ་ཟས་སྦྱིན་པ་དང་། གནོད་པ་ལ་ཟས་སྦྱིན་པ་དང་། རང་བཞིན་གྱིས་ཕོངས་པ་ལ་ཟས་སྦྱིན་པ་དང་། ཡུལ་དང་བྲལ་བར་གནས་པ་ལ་ཟས་སྦྱིན་པ་དང་། ཡོངས་སུ་ཞེན་པ་ལ་ཟས་སྦྱིན་པའོ། །

Enumeration Block 12:
གནོད་པ་ནི་རྣམ་པ་བརྒྱད་དེ། བཀྲེས་པས་གནོད་པ་དང་། སྐོམ་པས་གནོད་པ་དང་། ཁ་ཟས་ངན་པ་ཟ་བས་གནོད་པ་དང་། ཡོངས་སུ་ངལ་བས་གནོད་པ་དང་། གྲང་བས་གནོད་པ་དང་། ཚ་བས་གནོད་པ་དང་། སྐྱབས་མེད་པས་གནོད་པ་དང་། བསྒྲིབས་པས་གནོད་པའོ། །

Enumeration Block 13:
ཡང་གནོད་པ་ནི་རྣམ་པ་དྲུག་སྟེ། ལྷན་ཅིག་སྐྱེས་པ་དང་། འདོད་པས་ཕོངས་པ་ལས་བྱུང་བ་དང་། འགྲོ་བ་ལས་བྱུང་བ་དང་། དུས་ཚིགས་འགྱུར་བ་ལས་བྱུང་བ་དང་། འཛག་གནོད་བྱེད་པ་ལས་བྱུང་བ་དང་། ཐ་སྙད་ཆད་པ་ལས་བྱུང་བའོ། །

Enumeration Block 14:
ཕན་གདགས་པ་ནི་རྣམ་པ་དྲུག་སྟེ། ཉེ་བར་རྟོན་པས་ཕན་གདགས་པ་དང་། འགྲོ་བ་ལ་གནོད་པ་ལ་ཕན་གདགས་པ་དང་། གཡོགས་པས་ཕན་གདགས་པ་དང་། སྤོས་དང་མེ་ཏོག་ཕྲེང་དང་བྱུག་པས་ཕན་གདགས་པ་དང་། གནས་ཀྱིས་ཕན་གདགས་པ་དང་། འགྲོགས་པ་ལ་ཕན་གདགས་པའོ། །

Enumeration Block 15:
མི་མཛའ་བའི་མཚན་ཉིད་ནི་བཞི་སྟེ། འཁྲུག་པའི་བསམ་པ་མི་གཏོང་བ་དང་། སྡུག་པ་ལ་རྣམ་པར་བགེགས་བྱེད་པའི་གནས་དང་། མི་སྡུག་པ་བསྒྲུབ་པ་དང་། ཕན་པ་མ་ཡིན་པ་བསྒྲུབ་པའོ། །

Enumeration Block 16:
བསྒྲུབ་པ་ནི་རྣམ་པ་གསུམ་སྟེ། ཡོ་བྱད་ཀྱི་བདེ་བ་བསྒྲུབ་པ་དང་། དགའ་བ་དང་བཅས་པའི་བདེ་བ་བསྒྲུབ་པ་དང་། དགའ་བ་མེད་པའི་བདེ་བ་བསྒྲུབ་པའོ། །

Enumeration Block 17:
མཁས་པ་རྣམས་ཀྱི་མཁས་པའི་མཚན་ཉིད་ནི། གསུམ་པོ་འདི་དག་ཡིན་ཏེ། དགེ་བ་ཡང་དག་པར་ལེན་པ་དང་། དགེ་བ་ལ་གཅིག་ཏུ་ངེས་པ་དང་། དགེ་བ་ལ་བརྟེན་པའོ། །

Enumeration Block 18:
གཞན་ཡང་གསུམ་སྟེ། ལྷག་པའི་ཚུལ་ཁྲིམས་ཡང་དག་པར་ལེན་པ་དང་། ལྷག་པའི་སེམས་ཡང་དག་པར་ལེན་པ་དང་། ལྷག་པའི་ཤེས་རབ་ཡང་དག་པར་ལེན་པའོ།། །།

Enumeration Block 1:
དེ་དག་ཉིད་ལས་བཟློག་པ་ནི་མཛའ་བོའི་མཚན་ཉིད་རྣམ་པ་བཞིར་རིག་པར་བྱའོ། །

Enumeration Block 2:
བསྒྲུབ་པ་ནི་རྣམ་པ་གསུམ་སྟེ། ཡོ་བྱད་ཀྱི་བདེ་བ་བསྒྲུབ་པ་དང་། དགའ་བ་དང་བཅས་པའི་བདེ་བ་བསྒྲུབ་པ༌[^763]དང་། །དགའ་བ་མེད་པའི་བདེ་བ་བསྒྲུབ༌[^764]པའོ། །

Enumeration Block 3:
ཡང་མཐུན་པར་འཇུག་པར་ཁས་བླང་བ་ནི་བཞི་པོ་འདི་དག་ཡིན་ཏེ། འདི་ལྟ་སྟེ། འགྲོན་ལ་མཐུན་པར་འཇུག་པར་ཁས་བླང་བ་དང་། སྐྱེ་བོ་ཡོངས་ལ་མཐུན་པར་འཇུག་པར་ཁས་བླང་བ༌[^765]དང་། བླ་མ་རྣམས་དང་མཐུན་པར་འཇུག་པར་ཁས་བླང་བ་དང་། ཚོགས་པར་འདུ་འོས་ལ་མཐུན་པར་འཇུག་པར༌[^766]ཁས་བླང་བ་སྟེ། མཐུན་པར་འཇུག་པར་ཁས་བླང་བ་བཞི་པོ་འདི་དག་ལ། གནས་བཞི་བསྟེན་ནས་འབྲས་བུ་ལྔར་འགྱུར་བར་རིག་པར་བྱ་སྟེ། འདི་ལྟ་སྟེ་ཕན་གདགས་པ་དང་། རྣམ་པར་ཐོ་མི་འཚམས་པ༌[^767]དང་། མཆོད་པ་དང་། སྐལ་བ་མཉམ་པ་དང་། མཐུན་པར་འཇུག་པར་གནས་བཞི་པོ་འདི་དག་བསྟེན༌[^768]ནས། ལོངས་སྤྱོད་ཆེ་བ་དང་། ཕྱོགས་དང་ཕྱོགས་མཚམས་སུ་གྲགས་པ་དང་། ཡོངས་སུ་ཉོན་མོངས་པ་མེད་པ་དང་། མྱ་ངན་ལས་འདས་པ་འཐོབ་པ༌[^769]དང་། བདེ་འགྲོར་འགྲོ་བ་སྟེ། འབྲས་བུ་ལྔ་པོ་འདི་དག་འགྲུབ་པར་འགྱུར་རོ། །

Enumeration Block 4:
མཁས་པ་རྣམས་ཀྱི་མཁས་པའི་མཚན་ཉིད་ནི། གསུམ་པོ་འདི་དག་ཡིན་ཏེ། དགེ་བ་ཡང་དག་པར་ལེན་པ་དང་། དགེ་བ་ལ་གཅིག་ཏུ་ངེས་པ་དང་། དགེ་བ་ལ་བརྟེན་པའོ། །

Enumeration Block 5:

འདོད་པ་ན་སྤྱོད་པའི་སྡུག་བསྔལ་གྱི་བདེན་པ་དང་། ཀུན་འབྱུང་བའི་བདེན་པ་དང་། གཟུགས་ན་སྤྱོད་པའི་སྡུག་བསྔལ་གྱི་བདེན་པ་དང་། ཀུན་འབྱུང་གི༌[^1017]བདེན་པ་དང་། གཟུགས་མེད་པ་ན་སྤྱོད་པའི་སྡུག་བསྔལ་གྱི་བདེན་པ་དང་། ཀུན་འབྱུང་བའི་བདེན་པ་དང་། འདོད་པ་ན་སྤྱོད་པའི་དབང་གིས༌[^1018]དེ་ཡོངས་སུ་ཤེས་པའི་འབྲས་བུ་དང་། དེ་ཡོངས་སུ་ཤེས་པས་རབ་ཏུ་ཕྱེ་བའི་འགོག་པའི་བདེན་པ་དང་། ལམ་གྱི་བདེན་པ་དང་། གཟུགས་ན་སྤྱོད་པའི་དབང་གིས་དེ་ཡོངས་སུ་ཤེས་པའི་འབྲས་བུ་དང་། དེ་ཡོངས་སུ་ཤེས་པས་རབ་ཏུ་ཕྱེ་བའི་འགོག་པའི་བདེན་པ་དང་། ལམ་གྱི་བདེན་པ་དང་། གཟུགས་མེད་པ་ན་སྤྱོད་པའི་དབང་གིས་དེ་ཡོངས་སུ་ཤེས་པའི་འབྲས་བུ་དང་། དེ་ཡོངས་སུ་ཤེས་པས༌[^1019]རབ་ཏུ་ཕྱེ་བའི་འགོག་པའི་བདེན་པ་དང་། ལམ་གྱི་བདེན་པའོ། །

Enumeration Block 5:
རྒྱུ་ནི་རྣམ་པ་དྲུག་སྟེ། རྟེན་དང་། དམིགས་པ་དང་། འདུ་འཛི་དང་། བཤད་པ་དང་། གོམས་པ་དང་། ཡིད་ལ་བྱེད་པ་ལས་ཀྱང་ཉོན་མོངས་པ་སྐྱེའོ། །

Enumeration Block 6:
མདོར་བསྡུ་ན་རྣམ་པ་བདུན་ཏེ། བག་ལ་ཉལ་གྱི་གནས་སྐབས་དང་། ཀུན་ནས་དཀྲིས་པའི་གནས་སྐབས་དང་། ཀུན་ནས་བརྟགས་པའི་གནས་སྐབས་དང་། ལྷན་ཅིག་སྐྱེས་པའི་གནས་སྐབས་དང་། ཆུང་ངུའི་གནས་སྐབས་དང་། འབྲིང་གི་གནས་སྐབས་དང་། ཆེན་པོའི་གནས་སྐབས་སོ། །

Enumeration Block 7:
མདོར་བསྡུ་ན་ཀུན་ནས་དཀྲིས་པའི་སྒོ་དང་། བག་ལ་ཉལ་གྱི་སྒོ་སྟེ་སྒོ་རྣམ་པ་གཉིས་ཀྱིས་སོ། །

Enumeration Block 8:
རྣམ་པ་ལྔས་ཏེ། རབ་ཏུ་མ་ཞི་བར་གནས་པ་དང་། དགེ་བའི་བར་དུ་གཅོད་པ་དང་། ངན་སོང་གི་རྒྱུ་ཉེས་པར་སྤྱད་པ་ཀུན་ནས་སློང་བ་དང་། ཚེ་འདི་ཉིད་ལ་ཉམས་པར་འགྱུར་བ་ཡོངས་སུ་འཛིན་པ་དང་། སྐྱེ་བ་ལ་སོགས་པའི་སྡུག་བསྔལ་འགྲུབ་པས་སོ། །

Enumeration Block 9:
གཞན་ཡང་སྒོ་བདུན་གྱིས་ཉོན་མོངས་པ་ཐམས་ཅད་མཐོང་བ་དང་། བསྒོམ་པ་ལ་བགེགས་བྱེད་ཅིང་། སྒྲིབ༌[^1043]པར་བྱེད་པར་གྱུར་པར་རིག་པར་བྱའོ།[^1044] །

འདི་ལྟ་སྟེ། ལོག་པར་རྟོགས་པ་དང་། མ་རྟོགས་པ་དང་། རྟོགས་པ་ཡང་མ་ཡིན་མ་རྟོགས་པ་ཡང་མ་ཡིན་པ་དང་། ལོག་པར་རྟོགས་པས་ལོག་པར་སྒྲུབ་པ་དང་། དེའི་གཞིའི་གནས་རྟེན་དང་། དེ་འཇིགས་པ་བསྐྱེད་པ་དང་། རང་བཞིན་གྱིས་ཀུན་ཏུ་སྤྱོད་པའོ།། །།

Enumeration Block 1:
མདོར་བསྡུ་ན་རྣམ་པ་བདུན་ཏེ། བག་ལ་ཉལ་གྱི་གནས་སྐབས་དང་། ཀུན་ནས་དཀྲིས་པའི་གནས་སྐབས་དང་། ཀུན་ནས་བརྟགས་པའི་གནས་སྐབས་དང་། ལྷན་ཅིག་སྐྱེས་པའི་གནས་སྐབས་དང་། ཆུང་ངུའི་གནས་སྐབས་དང་། འབྲིང་གི་གནས་སྐབས་དང་། ཆེན་པོའི་གནས་སྐབས་སོ། །

Enumeration Block 2:
དེ་ལ་རྒྱུ་རྣམ་པ་གཉིས་ཀྱིས་ནི་ཉོན་མོངས་པའི་བག་ལ་ཉལ་ཕྲ་རྒྱས་སུ་འགྱུར་ཏེ། ས་བོན་གྱི་རྗེས་སུ་འབྲེལ་བ་དང་། དེའི་བདག་པོའི་དངོས་པོས་སོ། །

Enumeration Block 3:
མདོར་བསྡུ་ན་ཀུན་ནས་དཀྲིས་པའི་སྒོ་དང་། བག་ལ་ཉལ་གྱི་སྒོ་སྟེ་སྒོ་རྣམ་པ་གཉིས་ཀྱིས་སོ། །

Enumeration Block 4:
རྣམ་པ་ལྔས་ཏེ། རབ་ཏུ་མ་ཞི་བར་གནས་པ་དང་། དགེ་བའི་བར་དུ་གཅོད་པ་དང་། ངན་སོང་གི་རྒྱུ་ཉེས་པར་སྤྱད་པ་ཀུན་ནས་སློང་བ་དང་། ཚེ་འདི་ཉིད་ལ་ཉམས་པར་འགྱུར་བ་ཡོངས་སུ་འཛིན་པ་དང་། སྐྱེ་བ་ལ་སོགས་པའི་སྡུག་བསྔལ་འགྲུབ་པས་སོ། །

Enumeration Block 5:
འདི་ལྟ་སྟེ། ལོག་པར་རྟོགས་པ་དང་། མ་རྟོགས་པ་དང་། རྟོགས་པ་ཡང་མ་ཡིན་མ་རྟོགས་པ་ཡང་མ་ཡིན་པ་དང་། ལོག་པར་རྟོགས་པས་ལོག་པར་སྒྲུབ་པ་དང་། དེའི་གཞིའི་གནས་རྟེན་དང་། དེ་འཇིགས་པ་བསྐྱེད་པ་དང་། རང་བཞིན་གྱིས་ཀུན་ཏུ་སྤྱོད་པའོ།། །།
