Enumeration Block 1:
དེ་དག་ཀྱང་འཇིག་རྟེན་གྱི་ཁམས་རྣམ་པ་གསུམ་དུ་འགྱུར་རོ། །

Enumeration Block 2:
སྐྱེ་གནས་བཞི་པོ་སྒོ་ང་ལས་སྐྱེ་བ་དང་། མངལ་ནས༌[^294]སྐྱེ་བ་དང་། དྲོད་གཤེར་ལས་སྐྱེ་བ་དང་། རྫུས་ཏེ་སྐྱེ་བ་དང་། གཞི་དྲུག་དང་། དུས་རྣམ་པ་བཅུ་སྟེ།

Enumeration Block 3:
ཡོངས་སུ་གཟུང་བའི༌[^295]དངོས་པོ་བདུན་དང་། ལུས་ཀྱི་ཡོ་བྱད་བཅུ་དང་། འདོད་པ་ལ་ལོངས་སྤྱོད་པ་བཅུ་སྟེ།

Enumeration Block 4:
རྒྱུན་མི་འཆད་པར་རྗེས་སུ་སྤྱད་པ་རྣམ་པ་བརྒྱད་དང་། འཇིག་རྟེན་གྱི་ཆོས་བརྒྱད་དེ།

Enumeration Block 5:
ཕྱོགས་གསུམ་སྟེ།
