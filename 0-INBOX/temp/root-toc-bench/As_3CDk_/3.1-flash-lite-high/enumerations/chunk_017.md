Enumeration Block 1:
འདོད་པའི་ཁམས་ནི་གནས་གཞན་སུམ་ཅུ་རྩ་དྲུག་པོ་རྣམས་ཏེ།

Enumeration Block 2:
སེམས་ཅན་དམྱལ་བ་ཆེན་པོའི་གནས་བརྒྱད་ལ་འདི་ལྟ་སྟེ། ཡང་སོས་དང་། ཐིག་ནག་དང་། བསྡུས་འཇོམས་དང་། ངུ་འབོད་དང་། ངུ་འབོད་ཆེན་པོ་དང་། ཚ་བ་དང་། རབ་ཏུ་ཚ་བ་དང་། མནར་མེད་པའོ། །

Enumeration Block 3:
གྲང་བའི་སེམས་ཅན་དམྱལ་བའི་གནས་བརྒྱད་ཡོད་པ་འདི་ལྟ་སྟེ། ཆུ་བུར་ཅན་དང་། ཆུ་བུར་རྡོལ་པ་དང་། སོ་ཐམས་ཐམས་པ་དང་། ཀྱི་ཧུད་ཟེར་བ་དང་། ཨ་ཅུ་ཟེར་བ་དང་། ཨུཏྤལ་ལྟར་གས་པ་དང་། པད་མ་ལྟར་གས་པ་དང་། པད་མ་ལྟར་གས་པ་ཆེན་པོའོ། །

Enumeration Block 4:
འདོད་པ་ན་སྤྱོད་པའི་ལྷ་རྣམ་པ་དྲུག་ལ། རྒྱལ་ཆེན་བཞིའི་རིས་དང་། སུམ་ཅུ་རྩ་གསུམ་དང་། འཐབ་བྲལ་དང་། དགའ་ལྡན་དང་། འཕྲུལ་དགའ་དང་། གཞན་འཕྲུལ་དབང་བྱེད་ཀྱི་ལྷ་རྣམས་སོ། །

Enumeration Block 5:
གཟུགས་ཀྱི་ཁམས་ནི་གནས་གཞན་བཅོ་བརྒྱད་དེ།

Enumeration Block 6:
གཟུགས་མེད་པའི་ཁམས་ནི༌གནས་གཞན་བཞི་པོ་རྣམས་སོ། །
