Enumeration Block 1:
དེའི་རིན་པོ་ཆེ་སྣ་བདུན་པོ་དེ་དག་ནི་འདི་ལྟ་བུ་ཡིན་ཏེ། འདི་ལྟ་སྟེ། འཁོར་ལོ་རིན་པོ་ཆེ་དང་། གླང་པོ་རིན་པོ་ཆེ་དང་། རྟ་རིན་པོ་ཆེ་དང་། ནོར་བུ་རིན་པོ་ཆེ་དང་། བུད་མེད་རིན་པོ་ཆེ་དང་། ཁྱིམ་བདག་རིན་པོ་ཆེ་དང་། བདུན་པ་བློན་པོ་རིན་པོ་ཆེའོ། །

Enumeration Block 2:
དེ་དག་གི་གཞལ་མེད་ཁང་ཡང་གསེར་ལས་གྲུབ་པ་དང་། དངུལ་ལས་གྲུབ་པ་དང་། ཤེལ་ལས་གྲུབ་པ་དང་། བཻ་ཌཱུརྱ་ལས་གྲུབ་པ་རྣམ་པ་བཞི་ཡོད་དོ། །

Enumeration Block 3:
དེ་དག་ལས་བདུད་རྩིའི་ཁ་ཟས་རྣམ་པ་བཞི་པོ་སྔོན་པོ་དང་། སེར་པོ་དང་། དམར་པོ་དང་། དཀར་པོ་དག་འབྱུང་བར་འགྱུར་རོ། །

Enumeration Block 4:
ཡང་བྱེ་བྲག་རྣམ་པ་དྲུག་པོ་ཚད་ཀྱི་བྱེ་བྲག་དང་། ཤིན་ཏུ་གཞོན་ཤ་ཅན་གྱི་བྱེ་བྲག་དང་། རྐྱེན་གྱི་བྱེ་བྲག་དང་། དུས་ཀྱི་བྱེ་བྲག་དང་། སེམས་ཀྱི་བྱེ་བྲག་དང་། ལུས་ཀྱི་བྱེ་བྲག་གིས་སྡུག་བསྔལ་གྱི་བྱེ་བྲག་དང་། བདེ་བའི་བྱེ་བྲག་ཏུ་འགྱུར་བར་རིག་པར་བྱ་སྟེ།

Enumeration Block 5:
ཡང་བདེ་བ་ནི་རྣམ་པ་གཉིས་ཏེ། འཕགས་པ་མ་ཡིན་པའི་ནོར་ལས་བྱུང་བ་དང་། འཕགས་པའི་ནོར་ལས་བྱུང་བའོ། །

Enumeration Block 6:
དེ་ལ་འཕགས་པ་མ་ཡིན་པའི་ནོར་ལས་བྱུང་བའི་བདེ་བ་ནི། ཡོ་བྱད་རྣམ་པ་བཞི་པོ་དགའ་བའི་ཡོ་བྱད་དང་། ལྟ་བའི་ཡོ་བྱད་དང་། དག་པའི་ཡོ་བྱད་དང་། གནས་པའི་ཡོ་བྱད་ལ་བརྟེན་ནས་བྱུང་བའོ། །
