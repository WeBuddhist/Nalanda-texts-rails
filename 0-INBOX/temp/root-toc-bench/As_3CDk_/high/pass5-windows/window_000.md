* II. སྤྱི་སྡོམ། [[རྣལ་འབྱོར་སྤྱོད་པའི་ས་གང་ཞེ་ན། དེ་ནི་ས་བཅུ་བདུན་དུ་བལྟ་བར་བྱ་སྟེ།]]
* 1. རྣམ་པར་ཤེས་པའི་ཚོགས་ལྔ་དང་ལྡན་པའི་ས [[རྣམ་པར་ཤེས་པའི་ཚོགས་ལྔ་དང་ལྡན་པའི་ས་གང་ཞེ་ན། རྣམ་པར་ཤེས་པའི་ཚོགས་ལྔ་སྟེ།]]
* 1.1 མིག་གི་རྣམ་པར་ཤེས་པ [[མིག་གི་རྣམ་པར་ཤེས་པ་གང་ཞེ་ན། གང་མིག་ལ་བརྟེན་ནས་གཟུགས་སོ་སོར་རྣམ་པར་རིག་པའོ། །]]
* 1.2 རྣ་བའི་རྣམ་པར་ཤེས་པ [[རྣ་བའི་རྣམ་པར་ཤེས་པ་གང་ཞེ་ན། གང་རྣ་བ་ལ་བརྟེན་ནས་སྒྲ་སོ་སོར་རྣམ་པར་རིག་པའོ། །]]
* 1.3 སྣའི་རྣམ་པར་ཤེས་པ [[སྣའི་རྣམ་པར་ཤེས་པ་གང་ཞེ་ན། གང་སྣ་ལ་བརྟེན་ནས་དྲི་སོ་སོར་རྣམ་པར་རིག་པའོ། །]]
* 1.4 ལྕེའི་རྣམ་པར་ཤེས་པ [[ལྕེའི་རྣམ་པར་ཤེས་པ་གང་ཞེ་ན། གང་ལྕེ་ལ༌[^15]བརྟེན་ནས་སོ་སོར་རྣམ་པར་རིག་པའོ། །]]
* 1.5 ལུས་ཀྱི་རྣམ་པར་ཤེས་པ [[ལུས་ཀྱི་རྣམ་པར་ཤེས་པ་གང་ཞེ་ན། གང་ལུས་ལ་བརྟེན་ནས་རེག་བྱ་སོ་སོར་རྣམ་པར་རིག་པའོ། །]]
* 2. ཡིད་ཀྱི་ས [[ཡིད་ཀྱི་ས་གང་ཞེ་ན། དེ་ཡང་རྣམ་པ་ལྔ་ཁོ་ནར་བལྟ་བར་བྱ་སྟེ།]]
* 2.1 ངོ་བོ་ཉིད [[དེ་ལ་ངོ་བོ་ཉིད་གང་ཞེ་ན། སེམས་དང་ཡིད་དང་རྣམ་པར་ཤེས་པ་གང་ཡིན་པའོ། །]]
* 2.2 གནས [[གནས་གང་ཞེ་ན། ཡིད་དེ་མ་ཐག་པའི་གནས་དང་། སྔ་མ་བཞིན་དུ་]]
* 2.3 དམིགས་པ [[དམིགས་པ་གང་ཞེ་ན། ཆོས་ཐམས་ཅད་ནི་དམིགས་པ་སྟེ། འབའ་ཞིག་གི་ཚོར་བའི་ཕུང་པོ་དང་།]]
* 2.4 གྲོགས [[གྲོགས་གང་ཞེ་ན། འདི་ལྟ་སྟེ། ཡིད་ལ་བྱེད་པ་དང་། རེག་པ་དང་། ཚོར་བ་དང་།]]
* 2.5 ལས [[ལས་གང་ཞེ་ན། བདག་དང་གཞན་གྱི་ཡུལ་གྱི་དམིགས་པ་རྣམ་པར་རིག་པར་བྱེད་པ་ནི་ལས་དང་པོའོ། །]]
