Enumeration Block 1:
སྡོམ་ནི། ནུས་པ་ཡོད་པ་མ་ཡིན་དང་། ། ཁོངས་སུ་གཏོགས་ན་འགལ་བ་དང་། ། དགོས་པ་དང་ནི་དགོས་པ་མེད། ། རྒྱུ་ཡང་སྐྱོན་དང་ལྡན་ཕྱིར་རོ། །

Enumeration Block 2:
དེ་ལ་ལྷ་མི་སྤོང་བ་གཅིག་ནི་བློ་མ་བྱང་བ་ཁོ་ནའོ། ། གཉིས་པ་ནི་རྟོགས་པའི་མངོན་པའི་ང་རྒྱལ་ཅན་ནོ། ། གསུམ་པ་ནི་བློ་བྱང་བ་རྣམ་པར་ངེས་པ་མ་ཡིན་པའོ། ། བཞི་པ་ནི་ཤེས་པ་ཞན་ཅིང་ཤིན་ཏུ་རྨོངས་པ་ཁོ་ནའོ། །

Enumeration Block 3:
དེ་ཡང་བསམ་གཏན་ལ་བརྟེན་པ་དང་། རྟོག་གེ་ལ་བརྟེན་པའི་ཚུལ་གྱིས་རྣམ་པ་གཉིས་ཏེ།
