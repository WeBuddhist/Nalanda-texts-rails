Enumeration Block 1:
མཚན་ཉིད་རྣམ་པ་གསུམ་ཡོད་པས་ཀྱང་མི་རུང་སྟེ།
Enumeration Block 2:
དེ་ནི་ཀུན་ནས་ཉོན་མོངས་པ་གསུམ་དུ་རིག་པར་བྱའོ། །
Enumeration Block 3:
དེ་ཡང་གང་ཞེ་ན། ཉོན་མོངས་པའི་ཀུན་ནས་ཉོན་མོངས་པ་དང་། ལས་ཀྱི་ཀུན་ནས་ཉོན་མོངས་པ་དང་། སྐྱེ་བའི་ཀུན་ནས་ཉོན་མོངས་པའོ། །
Enumeration Block 4:
སྡོམ་ནི། ངོ་བོ་ཉིད་དང་རབ་དབྱེ་དང་། །རྒྱུ་དང་གནས་སྐབས་སྒོ་རྣམས་དང་། །ལྕི་བ་དང་ནི་ཕྱིན་ཅི་ལོག །རྣམ་གྲངས་དང་ནི་ཉེས་དམིགས་སོ། །
