Enumeration Block 1:
དེ་ལ་ཡང་རྣམ་པ་གཉིས་ཏེ། ཤིན་ཏུ་ཚབས་ཆེ་བ་དང་། ཤིན་ཏུ་ཚབས་ཆུང་བ་སྟེ།

Enumeration Block 2:
དག་ཅིང་གྲོལ་བ་རྣམས་ཀྱི་འཆི་བ་ནི་དུལ་བའི་འཆི་འཕོ་བ་ཞེས་བྱའོ། །དག་པ༌[^89]མ་ཡིན་པ་དང་། གྲོལ་བ་མ་ཡིན་པ་རྣམས་ཀྱི་འཆི་བ་ནི་དུལ་བ་མ་ཡིན་པའི་འཆི་འཕོ་བ་ཞེས་བྱའོ། །

Enumeration Block 3:
དེའི་རྣམ་གྲངས་ནི་འཆི་བའི་སྲིད་པ་དང༌[^100]སྐྱེ་བའི་སྲིད་པ་གཉིས་ཀྱི་བར་མ་དོར་འབྱུང་བས་ན་བར་མ་དོའི་སྲིད་པ་ཞེས་ཀྱང་བྱའོ། །དྲིའི་ཕྱིར་འགྲོ་བ་དང་། དྲིས་བརྟས་པར༌[^101]འགྱུར་བས་ན་དྲི་ཟ་ཞེས་ཀྱང་བྱའོ། །དེ་ལ་བརྟེན་ནས་ཡིད་སྐྱེ་བའི་གནས་སུ་འགྲོ་བས་ན་ཡིད་ལས་བྱུང་བ་ཞེས་ཀྱང་བྱ་སྟེ། ལུས་ཀྱི་འགྲོ་བས་འགྲོ་བའི་དམིགས་པའི་འགྲོ་བ་ནི་མ་ཡིན་ནོ། །སྐྱེ་བ་མངོན་དུ་འགྲུབ་པར་འགྱུར་བས་ན་མངོན་པར་འགྲུབ་པ་ཞེས་ཀྱང་བྱའོ། །

Enumeration Block 4:
གལ་ཏེ་བར་དུ་གཅོད་པ་རྣམ་པ་གསུམ་པོ་སྐྱེ་གནས་ཀྱི་ཉེས་པས་གྱུར་པ་དང་། ས་བོན་གྱི་ཉེས་པས་གྱུར་པ་དང་། ལས་ཀྱི་ཉེས་པས་གྱུར་པ་རྣམས་མེད་ན། མའི་མངལ་དུ་འཇུག་པར་འགྱུར་རོ། །

Enumeration Block 5:
དེ་ལ་སྐྱེ་གནས་ཀྱི་ཉེས་པ་གང་ཞེ་ན།

Enumeration Block 6:
ས་བོན་གྱི་ཉེས་པ་གང་ཞེ་ན།

Enumeration Block 7:
ལས་ཀྱི་ཉེས་པ་གང་ཞེ་ན།

Enumeration Block 8:
ཇི་ལྟར་འཇུག་པར་འགྱུར་ཞེ་ན།
