Enumeration Block 1:
དེ་ནི་རྣམ་པ་དྲུག་ཏུ་བལྟ་བར་བྱ་སྟེ། ཐོག་མ་ཁོ་ནར་དེ་རང་གི་ཡུལ་ལ་དམིགས་པ་རྣམ་པར་རིག་པའི་ཡུལ་ལས་དང་། ཡང་རང་གི་མཚན་ཉིད་རྣམ་པར་རིག་པ་དང་། ཡང་ད་ལྟར་གྱི་དུས་རྣམ་པར་རིག་པ་དང་། ཡང་སྐད་ཅིག་གཅིག་རྣམ་པར་རིག་པ་དང་། ཡང་རྣམ་པ་གཉིས་ཀྱིས་ཡིད་ཀྱི་རྣམ་པར་ཤེས་པའི་རྗེས་སུ་འཇུག་པ་སྟེ། དགེ་བ་ཉོན་མོངས་པ་ཅན་གྱི་རྗེས་སུ་འཇུག་པ་དང་། ལས་ཀུན་ལས་སློང་བའི་རྗེས་སུ་འཇུག་པ་དང་། ཡང་སྡུག་པ་དང་མི་སྡུག་པའི་འབྲས་བུ་ཡོངས་སུ་འཛིན་པ་སྟེ་ལས་དྲུག་པའོ། །

Enumeration Block 2:
དེ་ཡང་ཟིན་པའི་འབྱུང་བ་ཆེན་པོའི་རྒྱུ་ལས་བྱུང་བ་དང་། མ་ཟིན་པའི་འབྱུང་བ་ཆེན་པོའི་རྒྱུ་ལས་བྱུང་བ་དང་། ཟིན་པ་དང་མ་ཟིན་པའི་འབྱུང་བ་ཆེན་པོའི་རྒྱུ་ལས་བྱུང་བའོ། །

Enumeration Block 3:
དེ་ལ་མིག་གི་རྣམ་པར་ཤེས་པ་བྱུང་བ་ན། ཉེ་བར་གནས་པ་ལས་བྱུང་བ་དང་། ཚོལ་བ་དང་། ངེས་པའི་སེམས་རྣམ་པ་གསུམ་རིམ་བཞིན་དུ་དམིགས་པར་འགྱུར་ཏེ།
