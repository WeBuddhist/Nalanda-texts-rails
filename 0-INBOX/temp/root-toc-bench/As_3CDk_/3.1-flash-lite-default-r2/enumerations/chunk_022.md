Enumeration Block 1:
དེ་ལ་སྐྱེ་བར་འདོགས་པ་རྣམ་པར་གཞག་པ་ནི་འདི་ཡིན་ཏེ། འདི་ལྟ་སྟེ། འདོད་པ་སྐྱེ་བ་རྣམ་པ་གསུམ་པོ་རྣམས་ཏེ།

Enumeration Block 2:
བདེ་བ་སྐྱེ་བ་ནི་རྣམ་པ་གསུམ་པོ་འདི་དག་ཡིན་ཏེ།

Enumeration Block 3:
སྨྲས་པ་གསུམ་པོ་འདི་དག་ནི་ཚོལ་བ་ཡིན་ཏེ། འདོད་པ་ཚོལ་བ་དང་། སྲིད་པ་ཚོལ་བ་དང་། ཚངས་པར་སྤྱོད་པ་ཚོལ་བའོ། །

Enumeration Block 4:
དེ་ལ་ལུས་རྣམ་པར་གཞག་པ་ནི། འདི་ལྟ་སྟེ། ཁམས་གསུམ་ན་སེམས་ཅན་རྣམས་ཀྱི་ལུས་ཐོབ་པ་རྣམ་པ་བཞི་ཡོད་དེ།

Enumeration Block 5:
དེ་ལ་རྒྱུ་དང་རྐྱེན་དང་འབྲས་བུ་རྣམ་པར་གཞག་པ་ནི་རྣམ་པ་བཞིར་རིག་པར་བྱ་སྟེ། མཚན་ཉིད་དང་། གནས་དང་། རབ་ཏུ་དབྱེ་བ་དང་། རྣམ་པར་གཞག་པའོ། །

Enumeration Block 6:
རྒྱུ་དང་རྐྱེན་དང་འབྲས་བུའི་རབ་ཏུ་དབྱེ་བ་གང་ཞེ་ན། རྒྱུ་བཅུ་དང་། རྐྱེན་བཞི་དང་། འབྲས་བུ་ལྔའོ། །

Enumeration Block 7:
རྒྱུ་བཅུ་པོ་དག་གང་ཞེ་ན། རྗེས་སུ་ཐ་སྙད་འདོགས་པའི་རྒྱུ་དང་། ལྟོས་པའི་རྒྱུ་དང་། འཕེན་པའི་རྒྱུ་དང་། མངོན་པར་འགྲུབ་པའི་རྒྱུ་དང་། ཡོངས་སུ་འཛིན་པའི་རྒྱུ་དང་། འདྲེན་པའི་རྒྱུ་དང་། སོ་སོར་ངེས་པའི་རྒྱུ་དང་། ལྷན་ཅིག་བྱེད་པའི་རྒྱུ་དང་། མི་མཐུན་པའི་རྒྱུ་དང་། མི་མཐུན་པ་མེད་པའི་རྒྱུའོ། །

Enumeration Block 8:
རྐྱེན་བཞི་པོ་དག་གང་ཞེ་ན། རྒྱུའི་རྐྱེན་དང་། མཚུངས་པ་དེ་མ་ཐག་པའི་རྐྱེན་དང་། དམིགས་པའི་རྐྱེན་དང་། བདག་པོའི་རྐྱེན་ཏོ། །

Enumeration Block 9:
འབྲས་བུ་ལྔ་པོ་དག་གང་ཞེ་ན། རྣམ་པར་སྨིན་པའི་འབྲས་བུ་དང་། རྒྱུ་མཐུན་པའི་འབྲས་བུ་དང་། བྲལ་བའི་འབྲས་བུ་དང་། སྐྱེས་བུ་བྱེད་པའི་འབྲས་བུ་དང་། བདག་པོའི་འབྲས་བུའོ། །
