Enumeration Block 1:
དེ་ཡང་རྣམ་པ་གཉིས་ཏེ། འོག་གཞིར་གནས་པ་དང་། གློ་ན༌གནས་པ་སྟེ།

Enumeration Block 2:
ཀླུའི་རིགས་ནི་རྣམ་པ་བཞི་ཡོད་དེ༌ཀླུ་སྒོ་ང་ལས་སྐྱེ་བ་དང་། མངལ་ནས་སྐྱེ་བ་དང་། དྲོད་གཤེར་ལས་སྐྱེ་བ་དང་། རྫུས་ཏེ་སྐྱེ་བའོ། །

Enumeration Block 3:
ནམ་མཁའ་ལྡིང་ཡང་རྣམ་པ་བཞི་སྟེ། སྒོ་ང་ལས་སྐྱེ་བ་དང་། མངལ་ནས་སྐྱེ་བ་དང་། དྲོད་གཤེར་ལས་སྐྱེ་བ་དང་། རྫུས་ཏེ་སྐྱེ་བའོ། །

Enumeration Block 4:
རི་རབ་དེའི་དྲང༌ན་ཡང་བང་རིམ་བཞི་ཡོད་དེ།

Enumeration Block 5:
གླིང་བཞི་པོ་དེ་དག་ལས་གླིང་རེ་རེ་ལ་ཡང་གླིང་ཕྲན་གཉིས་གཉིས་ཡོད་དེ།
