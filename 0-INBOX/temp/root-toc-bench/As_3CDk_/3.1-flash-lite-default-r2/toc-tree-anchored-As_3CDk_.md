* 2. རྣམ་པར་ཤེས་པའི་ཚོགས་ལྔ་དང་ལྡན་པའི་ས་ [[རྣམ་པར་ཤེས་པའི་ཚོགས་ལྔ་དང་ལྡན་པའི་ས་གང་ཞེ་ན།]]

   * 2.2 དེ་དག་གི་གནས་ [[དེ་དག་གི་གནས་དང་། དེ་དག་གི་དམིགས་པ་དང་། དེ་དག་གི་གྲོགས་དང་།]]
   * 2.3 དེ་དག་གི་དམིགས་པ་ [[དེ་དག་གི་དམིགས་པ་དང་། དེ་དག་གི་གྲོགས་དང་། དེ་དག་གི་ལས་ནི་མདོར་ན་]]
   * 2.4 དེ་དག་གི་གྲོགས་ [[དེ་དག་གི་གྲོགས་དང་། དེ་དག་གི་ལས་ནི་མདོར་ན་རྣམ་པར་ཤེས་པའི་ཚོགས་ལྔ་]]
   * 2.5 དེ་དག་གི་ལས་ [[དེ་དག་གི་ལས་ནི་མདོར་ན་རྣམ་པར་ཤེས་པའི་ཚོགས་ལྔ་དང་ལྡན་པའི་སའོ། །]]
