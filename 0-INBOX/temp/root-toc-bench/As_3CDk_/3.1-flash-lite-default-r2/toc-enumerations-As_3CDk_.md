རྐྱེན་ནི་བཞི་སྟེ། རྒྱུའི་རྐྱེན་དང་། མཚུངས་པ་དེ་མ་ཐག་པའི་རྐྱེན་དང་། དམིགས་པའི་རྐྱེན་དང་། བདག་པོའི་རྐྱེན་དང་། དེ་ལ་ས་བོན་གྱི་རྒྱུའི་རྐྱེན་ཏེ། མཚུངས་པ་དེ་མ་ཐག་པའི་རྐྱེན་ནི། རྣམ་པར་ཤེས་པ་གང་གི་མཇུག་ཐོགས་སུ་རྣམ་པར་ཤེས་པ་གང་དག་འབྱུང་བར་ངེས་པ་དེ་ནི་དེ་དག་གི་མཚུངས་པ་དེ་མ་ཐག་པའི་རྐྱེན་ཏོ། །

Enumeration Block 2:
དགེ་བ་ནི་རྣམ་པ་གཅིག་སྟེ། ཁ་ན་མ་ཐོ་བ་མེད་པའི་དོན་གྱིས་སོ། །

Enumeration Block 3:
རྣམ་པ་གཉིས་ཏེ། སྐྱེས་ནས་ཐོབ་པ་དང་། སྦྱོར་བ་ལས་བྱུང་བའོ། །

Enumeration Block 4:
རྣམ་པ་གསུམ་སྟེ། ངོ་བོ་ཉིད་དང་ལྡན་པ་དང་། ཀུན་ནས་བསླང་བའོ། །

Enumeration Block 5:
རྣམ་པ་བཞི་སྟེ། བསོད་ནམས་ཀྱི་ཆ་དང་མཐུན་པ་དང་། ཐར་པའི་ཆ་དང་མཐུན་པ་དང་། ངེས་པར་འབྱེད་པའི་ཆ་དང་མཐུན་པ༌[^402]དང་། ཟག་པ་མེད་པའོ། །

Enumeration Block 6:
རྣམ་པ་ལྔ་སྟེ། སྦྱིན་པ་ལས་བྱུང་བ་དང་། ཚུལ་ཁྲིམས་ལས་བྱུང་བ་དང་། བསྒོམས་པ་ལས་བྱུང་བ་དང་། སྡུག་པའི་འབྲས་བུ་དང་། བྲལ་བའི་འབྲས་བུའོ། །

Enumeration Block 7:
དགེ་བའི༌[^403]རྣམ་པ་དྲུག་སྟེ། གཟུགས་དང་། ཚོར་བ་དང་། འདུ་ཤེས་དང་། འདུ་བྱེད་དང་། རྣམ་པར་ཤེས་པ་དང་། སོ་སོར་བརྟགས་པས་འགོག་པའོ། །

Enumeration Block 8:
རྣམ་པ་བདུན་ཏེ་དྲན་པ་ཉེ་བར་གཞག་པར་བསྡུས་པ་དང་། ཡང་དག་པའི་སྤོང་བ་དང་། རྫུ་འཕྲུལ་གྱི་རྐང་པ་དང་། དབང་པོ་དང་། སྟོབས་དང་། བྱང་ཆུབ་ཀྱི་ཡན་ལག་དང་། ལམ་གྱི་ཡན་ལག་ཏུ་བསྡུས་པའོ། །

Enumeration Block 9:
རྣམ་པ་བརྒྱད་དེ། མངོན་པར་སྨྲ་བ་དང་། ཕྱག་འཚལ་བ་དང་། ལྡང་བ་དང་། ཐལ་མོ་སྦྱར་བའི་ལས་སུ་བསྡུས་པ་དང་། ལེགས་པར་སྨྲས་པ་ལ་ལེགས་སོ་ཞེས་བྱ་བ་སྦྱིན་པ་དང་། བདེན་པའི་བསྔགས་པ་བརྗོད་པར་བསྡུས་པ་དང་། ནད་གཡོག་བྱ་བར་བསྡུས་པ་དང་། བླ་མ་རྣམས་ལ་གུས་པར་བསྙེན་བཀུར་བྱེད་པར་བསྡུས་པ་དང་། རྗེས་སུ་ཡི་རང་བར་བསྡུས་པ་དང་། གཞན་ཡང་དག་པར་འཛིན་དུ་འཇུག་པར་བསྡུས་པ་དང་། ཡོངས་སུ་བསྔོ་བར་བསྡུས་པ་དང་། ཚད་མེད་པར་བསྒོམ་པར་བསྡུས་པའོ། །

Enumeration Block 10:
རྣམ་པ་དགུ་སྟེ། སྦྱོར་བ་དང་། བར་ཆད་མེད་པ་དང་། རྣམ་པར་གྲོལ་བ་དང་། ཁྱད་པར་གྱི་ལམ་དུ་བསྡུས་པ་དང་། ཆུང་ངུ་དང་། འབྲིང་དང་། ཆེན་པོ་དང་། འཇིག་རྟེན་པ་དང་། འཇིག་རྟེན་ལས་འདས་པའི་ལམ་དུ་བསྡུས་པའོ། །

Enumeration Block 11:
རྣམ་པ་བཅུ་སྟེ། རྫས་ལས་བྱུང་བ་དང་། རྫས་ལས་བྱུང་བ་མ་ཡིན་པ་དང་། ཐོས་པ་ལས་བྱུང་བ་དང་། བསམས་པ༌[^404]ལས་བྱུང་བ་དང་། སྡོམ་པར་བསྡུས་པ་དང་། སྡོམ་པ་ཡང་མ་ཡིན། སྡོམ་པ་མ་ཡིན་པ་ཡང་མ་ཡིན་པར་བསྡུས་པ་དང་། དངོས་གཞི་དང་ཉེར་བསྡོགས༌[^405]སུ་བསྡུས་པ་དང་། ཉན་ཐོས་ཀྱི་ཐེག་པར་བསྡུས་པ་དང་། རང་སངས་རྒྱས་ཀྱི་ཐེག་པར་བསྡུས་པ་དང་། ཐེག་པ་ཆེན་པོར་བསྡུས་པའོ། །

Enumeration Block 12:
ཡང་རྣམ་པ་བཅུ་སྟེ། འདོད་པ་དང་ལྡན་པ་དང་། བསམ་གཏན་དང་པོ་དང་། གཉིས་པ་དང་། གསུམ་པ་དང་། བཞི་པ་དང་ལྡན་པ་དང་། ནམ་མཁའ་མཐའ་ཡས་སྐྱེ་མཆེད་དང་། རྣམ་ཤེས་མཐའ་ཡས་སྐྱེ་མཆེད་དང་། ཅི་ཡང་མེད་པའི་སྐྱེ་མཆེད་དང་། འདུ་ཤེས་མེད་འདུ་ཤེས་མེད་མིན་སྐྱེ་མཆེད་དང་ལྡན་པ་དང་། ཟག་པ་མེད་པར་བསྡུས་པའོ། །

Enumeration Block 13:
ཡང་རྣམ་པ་བཅུ་སྟེ། དགེ་བ་བཅུའི་ལས་ཀྱི་ལམ་རྣམས་སོ། །

Enumeration Block 14:
ཡང་རྣམ་པ་བཅུ་སྟེ། མི་སློབ་པའི་ཡང་དག་པའི་ལྟ་བ་ནས། [^406]ཡང་དག་པའི་རྣམ་པར་གྲོལ་བ་དང་། ཡང་དག་པའི་ཤེས་པའི་བར་རོ། །

Enumeration Block 15:
ཡང་རྣམ་པ་བཅུ་སྟེ། བསོད་ནམས་ལས་སྐྱེ་བ་བརྒྱད་དང་། འཁོར་ལོས་སྒྱུར་བའི༌[^407]རྒྱལ་པོར་འགྱུར་བ་དང་། མི་གཡོ་བར་ཉེ་བར་འགྲོ་བའི་དགེ་བ༌[^408]སྟེ། དེ་ལྟ་བུ་དང་མཐུན་པ་རྣམས་ནི་དགེ་བའི་རབ་ཏུ་དབྱེ་བ་ཡིན་ནོ། །

Enumeration Block 16:
མདོར་བསྡུ་ན་ནི་དགེ་བའི་དོན་རྣམ་པ་གཉིས་ཏེ། སྡུག་པའི་འབྲས་བུ་ཡོངས་སུ་འཛིན་པའི་དོན་དང་། དངོས་པོ་ཡོངས་སུ་ཤེས་པ་ལ་མཁས་པ་དེའི་འབྲས་བུའི་དོན་ཏོ། །

Enumeration Block 17:
ལུང་དུ་མ་བསྟན་པ་ནི་རྣམ་པ་བཞི་སྟེ། རྣམ་པར་སྨིན་པ་ལས་བྱུང་བ་དང་། དེ་ལ་སྤྱོད་ལམ་ལས་བྱུང་བ་ཁ་ཅིག་དང་། བཟོའི་གནས་ལས་བྱུང་བ་དང་། སྤྲུལ་པ་བྱེད་པ་ལས་བྱུང་བའོ། །

Enumeration Block 18:
མིག་ནི༌[^412]རྣམ་པ་གཅིག་སྟེ། གཟུགས་རྣམས་ལ་ལྟ་བའོ། །

Enumeration Block 19:
རྣམ་པ་གཉིས་ཏེ་རྒྱས་པ་ལས་བྱུང་བ་དང་། རྣམ་པར་སྨིན་པ་ལས་བྱུང་བའོ། །

Enumeration Block 20:
རྣམ་པ་གསུམ་སྟེ། ཤའི་མིག་དང་། ལྷའི་མིག་དང་། ཤེས་རབ་ཀྱི་མིག་གོ། །

Enumeration Block 21:
རྣམ་པ་བཞི་སྟེ། འཛུམས་པ་དང་། མི་འཛུམས་པ་དང་། བརྟན་པ༌[^413]དང་། བརྟན་པ་མ་ཡིན་པའོ། །

Enumeration Block 22:
རྣམ་པ་ལྔ་སྟེ། འགྲོ་བ་ལྔར་བསྡུས་པའོ། །

Enumeration Block 23:
རྣམ་པ་དྲུག་སྟེ། རང་གི་རྒྱུད་ལ་ཡོད་པ་དང་། གཞན་གྱི་རྒྱུད་ལ་ཡོད་པ་དང་། སྡུག་པ་དང་། མི་སྡུག་པ་དང་། དྲི་མ་ཅན་དང་། དྲི་མ་མེད་པའོ། །

Enumeration Block 24:
རྣམ་པ་བདུན་ཏེ། རྣམ་པར་ཤེས་པ་དང་བཅས་པ་དང་། རྣམ་པར་ཤེས་པ་མེད་པ་དང་། མཐུ་དང་ལྡན་པ་དང་། མཐུ་ཆུང་བ་དང་། དགེ་བའི་རྣམ་པར་ཤེས་པའི་རྟེན་དང་། མི་དགེ་བའི་རྣམ་པར་ཤེས་པའི་རྟེན་དང་། ལུང་དུ་མ་བསྟན་པའི་རྣམ་པར་ཤེས་པའི་རྟེན་ཏོ། །

Enumeration Block 25:
རྣམ་པ་བརྒྱད་དེ་གནས་ཀྱི་མིག་དང་། སྤྲུལ་པའི་མིག་དང་། དགེ་བའི་ལས་ཀྱི་རྣམ་པར་སྨིན་པ་ལས་བྱུང་བ་དང་། མི་དགེ་བའི་ལས་ཀྱི་རྣམ་པར་སྨིན་པ་ལས་བྱུང་བ་དང་། ཁ་ཟས་ཀྱིས་རྒྱས་པར་བྱས་པ་དང་། གཉིད་ལོག་པས་རྒྱས་པར་བྱས་པ་དང་། ཚངས་པར་སྤྱད་པས་རྒྱས་པར་བྱས་པ་དང་། སྙོམས་པར་འཇུག་པས་རྒྱས་པར་བྱས་པའོ། །

Enumeration Block 26:
རྣམ་པ་དགུ་སྟེ། ཐོབ་པ་དང་། མ་ཐོབ་པ་དང་། སྔོན་ཐོབ་པ་དང་། སྔོན་མ་ཐོབ་པ་དང་། ཐོབ་པ་ལས་ཉམས་པ་དང་། སྤང་བར་བྱ་བ་དང་། སྤང་བར་བྱ་བ་མ་ཡིན་པ་དང་། སྤངས་པ་དང་། མ་སྤངས་པའོ། །

Enumeration Block 27:
རྣམ་པ་བཅུ་གཅིག་སྟེ། འདས་པ་དང་། མ་འོངས་པ་དང་། ད་ལྟར་བྱུང་བ་དང་། ནང་གི་དང༌[^414]ཕྱི་རོལ་གྱི་དང་། རགས་པ་དང་། ཆ་ཕྲ་བ་དང་། ངན་པ་དང་། བཟང་པོ་དང་། རིང་པོ་དང་། ཉེ་བའོ། །

Enumeration Block 28:
རྣ་བ་རྣམ་པ་གསུམ་ནི། ཤ་ལས༌[^415]གྲུབ་པ་དང་། ལྷའི་དང་། རྣ་སླགས༌[^416]པའོ། །

Enumeration Block 29:
རྣམ་པ་བཞི་ནི་བརྟན་པ་དང་། བརྟན་པ་མ་ཡིན་པ་དང་། སྐད་བསྐྱེད་ན་ཐོས་པ་དང་། སྐད་མ་བསྐྱེད་པར་ཐོས་པའོ། །

Enumeration Block 30:
སྣ༌[^417]དང་ལྕེ་རྣམ་པ་གསུམ་ནི། གསལ་བ་དང་མི་གསལ་བ་དང་། ཉམས་པའོ། །

Enumeration Block 31:
སྣ་དང་ལྕེ་རྣམ་པ་བཞི་ནི་བརྟན་པ་དང་། བརྟན་པ་མ་ཡིན་པ་དང་། རྣམ་པར་ཤེས་པ་དང་བཅས་པ་དང་། རྣམ་པར་ཤེས་པ་མེད་པའོ། །

Enumeration Block 32:
ལུས་རྣམ་པ་གསུམ་ནི་རོ་ཡོད་པ་དང་། རོ་མེད་པ་དང་། དབང་པོ་ཐམས་ཅད་ཀྱི་རྗེས་སུ་འཇུག་པའི་ཕྱིར་ཀུན་ཏུ་འགྲོ་བའོ། །

Enumeration Block 33:
རྣམ་པ་བཞི་ནི་བརྟེན་པ་དང་། བརྟན་པ་མ་ཡིན་པ་དང་། རང་གི་ལུས་ལས་འོད་འབྱུང་བ་དང་། རང་གི་ལུས་ལས་འོད་འབྱུང་བ་མ་ཡིན་པའོ། །

Enumeration Block 34:
ཡིད་ནི་རྣམ་པ་གཅིག་སྟེ། ཆོས་རྣམ་པར་ཤེས་པའི་དོན་གྱིས་སོ། །

Enumeration Block 35:
རྣམ་པ་གཉིས་ཏེ། གདགས་པར་གཏོགས་པ་དང་། གདགས་པར་གཏོགས་པ་མ་ཡིན་པས་ཏེ། དེ་ལ་དང་པོ་ནི་ཤེད་བྱེད་པའི་ཐ་སྙད་ཅན་རྣམས་ཀྱིའོ། །

Enumeration Block 36:
རྣམ་པ་གསུམ་སྟེ། སེམས་དང་། ཡིད་དང་། རྣམ་པར་ཤེས་པའོ། །

Enumeration Block 37:
རྣམ་པ་བཞི་སྟེ། དགེ་བ་དང་མི་དགེ་བ་དང་། བསྒྲིབས་ལ་ལུང་དུ་མ་བསྟན་པ་དང་། མ་བསྒྲིབས་ལ་ལུང་དུ་མ་བསྟན་པའོ། །

Enumeration Block 38:
རྣམ་པ་ལྔ་ནི། དུས་ལྔའི་བྱེ་བྲག་ལས་ནི་གྱུར་ཏེ། རྒྱུའི་དུས་དང་། འབྲས་བུའི་དུས་དང་། བདེ་བའི་དུས་དང་། སྡུག་བསྔལ་བའི་དུས་དང་། སྡུག་བསྔལ་བ་ཡང་མ་ཡིན་བདེ་བ་ཡང་མ་ཡིན་པའི་དུས་སོ། །

Enumeration Block 39:
རྣམ་པ་དྲུག་སྟེ། རྣམ་པར་ཤེས་པའི་ཚོགས་དྲུག་པོ་རྣམས་སོ། །

Enumeration Block 40:
རྣམ་པ་བདུན་ཏེ། རྣམ་པར་ཤེས་པ་གནས་པ་བདུན་པོ་རྣམས་སོ། །

Enumeration Block 41:
རྣམ་པ་བརྒྱད་དེ། ཚིག་བླ་དགས་ཀྱི་འདུས་ཏེ་རེག་པ་དང་ལྡན་པ་དང་། ཐོགས༌[^419]པའི་འདུས་ཏེ་རེག་པ་དང་ལྡན་པ་དང་། ཞེན་པ་ལ་བརྟེན་པ་དང་། མངོན་པར་འབྱུང་བ་ལ་བརྟེན་པ་དང་། ཟང་ཟིང་དང་བཅས་པ་དང་། ཟང་ཟིང་མེད་པ་དང་། འཇིག་རྟེན་པ་དང་། འཇིག་རྟེན་ལས་འདས་པའོ། །

Enumeration Block 42:
རྣམ་པ་དགུ་སྟེ། སེམས་ཅན་གྱི་གནས་དགུ་པོ་རྣམས་སོ། །

Enumeration Block 43:
རྣམ་པ་བཅུ་གཅིག་སྟེ་སྔ་མ་བཞིན་ནོ། །

Enumeration Block 44:
རྣམ་པ་བཅུ་གཉིས་ནི་སེམས་བཅུ་གཉིས་ཏེ། འདོད་པ་ན་སྤྱོད་པ་དང་། དགེ་བ་དང་། མི་དགེ་བ་དང་། བསྒྲིབས་ལ་ལུང་དུ་མ་བསྟན་པ་དང་། མ་བསྒྲིབས་ལ་ལུང་དུ་མ་བསྟན་པའོ།[^420] །

Enumeration Block 45:
གཟུགས་ན་སྤྱོད་པ་རྣམ་པ་གསུམ་སྟེ། མི་དགེ་བ་མ་གཏོགས་པ་དང་། གཟུགས་མེད་པ་ན་སྤྱོད་པ་ཡང་དེ་དང་འདྲ་བ་དང་། འཇིག་རྟེན་ལས་འདས་པ་སློབ་པ༌[^421]དང་མི་སློབ་པའོ། །

Enumeration Block 46:
གཟུགས་ནི་རྣམ་པ་གཅིག་སྟེ། མིག་གི་སྤྱོད་ཡུལ་གྱི་དོན་གྱིས་སོ། །

Enumeration Block 47:
རྣམ་པ་གཉིས་ཏེ། ནང་གི་དང་ཕྱི་རོལ་གྱིའོ། །

Enumeration Block 48:
རྣམ་པ་གསུམ་སྟེ། ཁ་དོག་དང་། དབྱིབས་དང་རྣམ་པར་རིག་བྱེད་དོ། །

Enumeration Block 49:
རྣམ་པ་བཞི་སྟེ། རང་གི་རྟེན་སྣང་བར་བྱེད་པ་དང་། རང་གི་རྟེན་སྣང་བར་བྱེད་པ་མ་ཡིན་པ་དང་། བདེ་བ་དང་། བདེ་བ་མ་ཡིན་པར་སྣང་བ་དང་། བསགས་པར་གནས་པའོ། །

Enumeration Block 50:
རྣམ་པ་ལྔ་སྟེ། འགྲོ་བ་ལྔའི་བྱེ་བྲག་གིས་སོ། །

Enumeration Block 51:
རྣམ་པ་དྲུག་སྟེ། གཞིར༌[^422]བསྡུས་པ་དང་། གནས་སུ་བསྡུས་པ་དང་། ཡུལ་དུ་བསྡུས་པ་དང་། སེམས་ཅན་དུ་བགྲང་བ་དང་། སེམས་ཅན་དུ་བགྲང་བ་མ་ཡིན་པ་དང་། བསྟན་དུ་ཡོད་ལ་ཐོགས་པ་དང་བཅས་པའོ། །

Enumeration Block 52:
རྣམ་པ་བདུན་ཏེ། ཡོངས་སུ་གཟུང་བ༌[^423]རྣམ་པ་བདུན་པོ་དག་གི་བྱེ་བྲག་གིས་སོ། །

Enumeration Block 1:
རྣམ་པ་དགུ་སྟེ། སེམས་ཅན་གྱི་གནས་དགུ་པོ་རྣམས་སོ། །

Enumeration Block 2:
རྣམ་པ་བཅུ་གཅིག་སྟེ་སྔ་མ་བཞིན་ནོ། །

Enumeration Block 3:
རྣམ་པ་བཅུ་གཉིས་ནི་སེམས་བཅུ་གཉིས་ཏེ། འདོད་པ་ན་སྤྱོད་པ་དང་། དགེ་བ་དང་། མི་དགེ་བ་དང་། བསྒྲིབས་ལ་ལུང་དུ་མ་བསྟན་པ་དང་། མ་བསྒྲིབས་ལ་ལུང་དུ་མ་བསྟན་པའོ། །

Enumeration Block 4:
གཟུགས་ན་སྤྱོད་པ་རྣམ་པ་གསུམ་སྟེ། མི་དགེ་བ་མ་གཏོགས་པ་དང་། གཟུགས་མེད་པ་ན་སྤྱོད་པ་ཡང་དེ་དང་འདྲ་བ་དང་། འཇིག་རྟེན་ལས་འདས་པ་སློབ་པ༌དང་མི་སློབ་པའོ། །

Enumeration Block 5:
གཟུགས་ནི་རྣམ་པ་གཅིག་སྟེ། མིག་གི་སྤྱོད་ཡུལ་གྱི་དོན་གྱིས་སོ། །

Enumeration Block 6:
རྣམ་པ་གཉིས་ཏེ། ནང་གི་དང་ཕྱི་རོལ་གྱིའོ། །

Enumeration Block 7:
རྣམ་པ་གསུམ་སྟེ། ཁ་དོག་དང་། དབྱིབས་དང་རྣམ་པར་རིག་བྱེད་དོ། །

Enumeration Block 8:
རྣམ་པ་བཞི་སྟེ། རང་གི་རྟེན་སྣང་བར་བྱེད་པ་དང་། རང་གི་རྟེན་སྣང་བར་བྱེད་པ་མ་ཡིན་པ་དང་། བདེ་བ་དང་། བདེ་བ་མ་ཡིན་པར་སྣང་བ་དང་། བསགས་པར་གནས་པའོ། །

Enumeration Block 9:
རྣམ་པ་ལྔ་སྟེ། འགྲོ་བ་ལྔའི་བྱེ་བྲག་གིས་སོ། །

Enumeration Block 10:
རྣམ་པ་དྲུག་སྟེ། གཞིར༌བསྡུས་པ་དང་། གནས་སུ་བསྡུས་པ་དང་། ཡུལ་དུ་བསྡུས་པ་དང་། སེམས་ཅན་དུ་བགྲང་བ་དང་། སེམས་ཅན་དུ་བགྲང་བ་མ་ཡིན་པ་དང་། བསྟན་དུ་ཡོད་ལ་ཐོགས་པ་དང་བཅས་པའོ། །

Enumeration Block 11:
རྣམ་པ་བདུན་ཏེ། ཡོངས་སུ་གཟུང་བ༌རྣམ་པ་བདུན་པོ་དག་གི་བྱེ་བྲག་གིས་སོ། །

Enumeration Block 12:
རྣམ་པ་བརྒྱད་དེ། འཇིག་རྟེན་གྱི་སྣ་ཚོགས་བརྒྱད་དེ། དེ་དག་ཀྱང་ས་ཕྱོགས་སྣ་ཚོགས་དང་། རི་སྣ་ཚོགས་དང་། ཀུན་དགའ་ར་བ་དང་། ནགས་ཚལ་དང་། མཚོ་དང་། མཚེའུ་ལ་སོགས་པ་སྣ་ཚོགས་དང་། ཁང་ཁྱིམ་དང་གཞལ་མེད་ཁང་སྣ་ཚོགས་དང་། ལས་ཀྱི་གནས༌སྣ་ཚོགས་དང་། རི་མོ་བྲི་བ་སྣ་ཚོགས་དང་། བརྡུང་སྦྱར་གྱི་ལས་སྣ་ཚོགས་དང་། ཡོ་བྱད་སྣ་ཚོགས་སོ། །

Enumeration Block 13:
རྣམ་པ་དགུ་སྟེ། འདས་པ་དང་། མ་འོངས་པ་དང་། ད་ལྟར་བྱུང་བ་དང་། རགས་པ་དང་། ཆ་ཕྲ་བའམ། ངན་པའམ། བཟང་པོའམ། གང་རྒྱང་རིང་བའམ། གང་ཐག་ཉེ་བའོ། །

Enumeration Block 14:
རྣམ་པ་བཅུ་སྟེ། ཡོ་བྱད་བཅུ་པོ་རྣམས་སོ། །

Enumeration Block 15:
སྒྲ་ནི་རྣམ་པ་གཅིག་སྟེ། རྣ་བའི་སྤྱོད་ཡུལ་གྱི་དོན་གྱིས་སོ། །

Enumeration Block 16:
རྣམ་པ་གཉིས་ཏེ། གསལ་བའི་དོན་གྱི་སྒྲ་སྐད་དང་། གསལ་བ་མ་ཡིན་པའི་དོན་གྱི་སྒྲ་སྐད་དོ། །

Enumeration Block 17:
རྣམ་པ་གསུམ་སྟེ། ཟིན་པའི་འབྱུང་བ༌ཆེན་པོའི་རྒྱུ་ལས་བྱུང་བ་དང་། མ་ཟིན་པའི་འབྱུང་བ་ཆེན་པོའི་རྒྱུ་ལས་བྱུང་བ་དང་། དེ་གཉི་གའི་འབྱུང་བ་ཆེན་པོའི་རྒྱུ་ལས་བྱུང་བའོ། །

Enumeration Block 18:
རྣམ་པ་བཞི་སྟེ། དགེ་བ་དང་། མི་དགེ་བ་དང་། བསྒྲིབས་ལ་ལུང་དུ་མ་བསྟན་པ་དང་། མ་བསྒྲིབས་ལ་ལུང་དུ་མ་བསྟན་པའོ། །

Enumeration Block 19:
རྣམ་པ་ལྔ་སྟེ། འགྲོ་བ་ལྔའི་བྱེ་བྲག་གིས་སོ། །

Enumeration Block 20:
རྣམ་པ་དྲུག་སྟེ། ལུང་ནོད་པ་དང་། ཁ་ཐོན་བྱེད་པའི་སྒྲ་དང་། ཀུན་དགུ་འདྲི་བ་དང་། ཡོངས་སུ་འདྲི་བའི་སྒྲ་དང་། ཆོས་འཆད་པའི་སྒྲ་དང་། འབེལ་བའི་གཏམ་དང་། རྣམ་པར་གཏན་ལ་འབེབས་པའི་སྒྲ་དང་། གཅིག་ལ་གཅིག་ཚིག་གིས་འདེབས་ཤིང་ཉེས་པ་ལས་འབྱིན་པའི་སྒྲ་དང་། འདྲེས་པ་ཅ་ཅོའི་སྒྲའོ། །

Enumeration Block 21:
རྣམ་པ་བདུན་ཏེ། བུད་མེད་ཀྱི་སྒྲ་དང་། སྐྱེས་པའི་སྒྲ་དང་། ཆུང་ངུ་དང་། འབྲིང་དང་། ཆེན་པོ་དང་། རི་དགས་དང་། བྱ་ལ་སོགས་པའི་སྒྲ་དང་། རླུང་དང་ཤིང་གི་སྒྲའོ། །

Enumeration Block 22:
རྣམ་པ་བརྒྱད་དེ། འཕགས་པའི་ཐ་སྙད་བཞི་པོའི་སྒྲ་རྣམས་དང་། འཕགས་པ་མ་ཡིན་པའི་ཐ་སྙད་བཞི་པོའི་སྒྲ་རྣམས་ཏེ། མ་མཐོང་བར་མཐོང་ངོ་ཞེས་སྨྲ༌བ་དང་། མཐོང་བ་ལ་མ་མཐོང་ངོ་ཞེས་སྨྲ་བ་འཕགས་པའི༌ཐ་སྙད་དང་། མ་ཐོས་པ་དང་། བྱེ་བྲག་མ་ཕྱེད་པ་དང་། རྣམ་པར་མ་ཤེས་པར་རྣམ་པར་ཤེས༌སོ་ཞེས་སྨྲ་བ་དང་། རྣམ་པར་ཤེས་པ་ལ་རྣམ་པར་མི༌ཤེས་སོ་ཞེས་སྨྲ་བ་འཕགས་པ་མ་ཡིན་པའི་ཐ་སྙད་དང་། མཐོང་བ་ལ་མཐོང་ཞེས་སྨྲ་བ་དང་། མ་མཐོང་བ་ལ་ཡང་མ་མཐོང་ཞེས་སྨྲ་བ་འཕགས་པའི་ཐ་སྙད་དང་། ཐོས་པ་དང་། བྱེ་བྲག་ཕྱེད་པ་དང་། རྣམ་པར་ཤེས་པ་ལ་རྣམ་པར་ཤེས་སོ་ཞེས་སྨྲ་བ་དང་། རྣམ་པར་མི༌ཤེས་པ་ལ་ཡང་རྣམ་པར་མ་ཤེས་སོ་ཞེས་སྨྲ་བ་འཕགས་པའི་ཐ་སྙད་དོ། །

Enumeration Block 23:
གཞན་ཡང་རྣམ་པ་བརྒྱད་དེ། ངག་གི༌ལས་ཀྱི་ལམ་དགེ་བ་བཞི་དང་། མི་དགེ་བ་བཞིའོ། །

Enumeration Block 24:
རྣམ་པ་དགུ་སྟེ། འདས་པ་དང་། མ་འོངས་པ་དང་། ད་ལྟར་བྱུང་བ་ནས། རྒྱང་རིང་བ་དང་། ཐག་ཉེ་བའི་བར་དག་གོ། །

Enumeration Block 25:
རྣམ་པ་བཅུ་སྟེ། སིལ་སྙན་གྱི་རྣམ་པ་ལྔར་བསྡུས་པ་སྟེ། དེ་ཡང་གར་དང་ལྡན་པ་དང་། གླུ་དང་ལྡན་པ་དང་རོལ་མོའི་སྒྲ་དང་ལྡན་པ་དང་། བུད་མེད་དང་ལྡན་པ་དང་། སྐྱེས་པ་དང་ལྡན་པ་དང་། དུང་གི་སྒྲ་དང་། རྔ་པ་ཊ་ཧའི་སྒྲ་དང་། རྔ་བོ་ཆེའི་སྒྲ་དང་། རྫ་རྔའི་སྒྲ་དང་། སྒྲ་བོ་ཆེའི་སྒྲའོ། །

Enumeration Block 26:
དྲི་ནི་རྣམ་པ་གཅིག་སྟེ། སྣའི་སྤྱོད་ཡུལ་གྱི་དོན་གྱིས་སོ། །

Enumeration Block 27:
རྣམ་པ་གཉིས་ཏེ། ནང་གི་དང་། ཕྱི་རོལ་གྱིའོ། །

Enumeration Block 28:
རྣམ་པ་གསུམ་སྟེ། ཡིད་དུ་འོང་བ་དང་། ཡིད་དུ་མི་འོང་བ་དང་། བཏང་སྙོམས་ཀྱི་གནས་སོ། །

Enumeration Block 29:
རྣམ་པ་བཞི་ནི་དྲི་ཆེན་པོ་རྣམ་པ་བཞི་སྟེ། ཨ་ཀ་རུའི་དྲི་དང་། དུ་རུ་སྐའི༌དྲི་དང་། ག་པུར་གྱི་དྲི་དང་། གླ་རྩིའི་དྲིའོ། །

Enumeration Block 30:
རྣམ་པ་ལྔ་སྟེ། རྩ་བའི་དྲི་དང་། སྙིང་པོའི་དྲི་དང་། ལོ་མའི་དྲི་དང་། མེ་ཏོག་གི་དྲི་དང་། འབྲས་བུའི་དྲིའོ། །

Enumeration Block 31:
རྣམ་པ་དྲུག་སྟེ། ཟས་ཀྱི་དྲི་དང་། སྐོམ་གྱི་དྲི་དང་། གོས་ཀྱི་དྲི་དང་། རྒྱན་གྱི་དྲི་དང་། བཞོན་པའི་དྲི་དང་། གནས་ཀྱི་དྲིའོ། །

Enumeration Block 32:
རྣམ་པ་བདུན་ཏེ། ཤིང་ཚའི༌དྲི་དང་། སྤོས་ལོའི་དྲི་དང་། སུག་སྨེལ་གྱི་དྲི་དང་། ཙན་དན་གྱི་དྲི་དང་། ཚ་བ་གསུམ་གྱི་དྲི་དང་། བདུག་པའི་དྲི་དང་། ཕྱེ་མའི་དྲིའོ། །

Enumeration Block 33:
རྣམ་པ་བརྒྱད་དེ། ལྷན་ཅིག་སྐྱེས་པ་དང་། ལྷན་ཅིག་སྐྱེས་པ་མ་ཡིན་པ་དང་། བརྟན་པ་དང་། བརྟན་པ་མ་ཡིན་པ་དང་། སྦྱར་བ་དང་། འབའ་ཞིག་པ་དང་། དྲི་ཆེ་བ་དང་། དྲི་ཆེ་བ་མ་ཡིན་པའོ། །

Enumeration Block 34:
རྣམ་པ་དགུ་སྟེ། འདས་པ་དང་། མ་འོངས་པ་དང་། ད་ལྟར་བྱུང་བ༌ནས། རྒྱང་རིང་བ་དང་། ཐག་ཉེ་བའི་བར་དག་གོ། །

Enumeration Block 35:
རྣམ་པ་བཅུ་སྟེ། སྐྱེས་པའི་དྲི་དང་། བུད་མེད་ཀྱི་དྲི་དང་། ཕྱི༌སའི་དྲི་དང་། གཅིན་གྱི་དྲི་དང་། ངར་སྣབས༌ཀྱི་དྲི་དང་། སྣབས་ཀྱི་དྲི་དང་། ཞག་དང་། ཆུ་སེར་གྱི་དྲི་དང་། རྣག་དང་། ཁྲག་གི་དྲི་དང་། ཤའི་དྲི་དང་། འདྲེས་པའི་དྲི་དང་། རུལ་པའི་དྲི་དང་། འདམ་རྫབ་ཀྱི་དྲིའོ། །

Enumeration Block 36:
རོ་ནི་རྣམ་པ་གཅིག་སྟེ། ལྕེའི་སྤྱོད་ཡུལ་གྱི་དོན་གྱིས་སོ། །

Enumeration Block 37:
རྣམ་པ་གཉིས་ཏེ། ནང་དང་། ཕྱི་རོལ༌གྱིའོ། །

Enumeration Block 38:
རྣམ་པ་གསུམ་སྟེ། ཡིད་དུ་འོང་བ་ནས་སྔ་མ་བཞིན་ནོ། །

Enumeration Block 39:
རྣམ་པ་བཞི་སྟེ། ནས་ཀྱི་རོ་དང་། སཱ་ལུའི་རོ་དང་། གྲོའི་རོ་དང་། འབྲུ་གཞན་གྱི་རོའོ། །

Enumeration Block 40:
རྣམ་པ་ལྔ་སྟེ། ཆང་གི་རོ་དང་། ཆང་མ་ཡིན་པའི་རོ་དང་། སྔོ་རྔད་ཀྱི་རོ་དང་། ནགས་ཚལ་གྱི་ཤིང་ཐོག་གི་རོ་དང་། ཁ་ཟས་ཀྱི་རོའོ། །

Enumeration Block 41:
རྣམ་པ་དྲུག་སྟེ། ཁ་བ་ལ་སོགས་པའོ། །

Enumeration Block 42:
རྣམ་པ་བདུན་ཏེ། མར་དང་། འབྲུ་མར་དང་། སྦྲང་རྩི་དང་། བུ་རམ་ཤིང་ལས་བྱུང་བའི་རོ་དང་། མངར་བའི་རོ་དང་། ལན་ཚྭའི་རོ་དང་། ཤའི་རོའོ། །

Enumeration Block 43:
རྣམ་པ་བརྒྱད་དེ། །དྲི་བཞིན་ནོ། །

Enumeration Block 44:
རྣམ་པ་དགུ་སྟེ། དྲི་ཁོ་ན་བཞིན་ནོ། །

Enumeration Block 45:
རྣམ་པ་བཅུ་སྟེ། བཅའ་བའི་རོ་དང་། བཟའ་བའི་རོ་དང་། མྱང་བའི་རོ་དང་། བཏུང་བའི་རོ་དང་། གཞིབ༌པའི་རོ་དང་། ཤ་འབྲི་བར་བྱེད་པ་དང་། ཤ་བརྟས་པར༌བྱེད་པ་དང་། ཞི་བར་བྱེད་པ་དང་། སྦྱོང་བར་བྱེད་པ་དང་། བརྟན་པར་བྱ་བའི་སྨན་གྱི་རོ་རྣམས་སོ། །

Enumeration Block 46:
རེག་བྱ་ནི་རྣམ་པ་གཅིག་སྟེ། ལུས་ཀྱི་སྤྱོད་ཡུལ་གྱི་དོན་གྱིས་སོ། །

Enumeration Block 47:
རྣམ་པ་གཉིས་ཏེ། དྲི་བཞིན་ནོ། །

Enumeration Block 48:
རྣམ་པ་གསུམ་སྟེ། ཡིད་དུ་འོང་བ་ལ་སོགས་པའོ། །

Enumeration Block 49:
རྣམ་པ་བཞི་སྟེ། རེག་པར་བྱ་བའི༌རེག་པར་བྱ་བ་དང་། བཙིར་བའི་རེག་པ་དང་། བསྣུན་པའི་རེག་པ་དང་། མཉེ་བའི་རེག་པའོ། །

Enumeration Block 50:
རྣམ་པ་ལྔ་སྟེ། འགྲོ་བ་ལྔའི་བྱེ་བྲག་གིས་སོ། །

Enumeration Block 51:
རྣམ་པ་དྲུག་སྟེ། བདེ་བ་དང་། སྡུག་བསྔལ་བ་དང་། སྡུག་བསྔལ་བ་ཡང་མ་ཡིན་བདེ་བ་ཡང་མ་ཡིན་པ་དང་། ལྷན་ཅིག་སྐྱེས་པ་དང་། མི་མཐུན་པའི་ཕྱོགས་སུ་བསྡུས་པ་དང་གཉེན་པོར་བསྡུས་པའོ། །

Enumeration Block 52:
རྣམ་པ་བདུན་ཏེ། སྲ་བ་དང་། གཤེར་བ་དང་། དྲོ་བ་དང་། གཡོ་བ་དང་། མཆོང་བ་དང་། ལྷུང་བའི་འདུས་ཏེ་རེག་པ་དང་། བྱུག་ནོམ་གྱི་འདུས་ཏེ་རེག་པ་དང་། ལུས་འགྱུར་གྱི་འདུས་ཏེ་རེག་པ་སྟེ། འདི་ལྟ་སྟེ། འཇམ་པ་ལ་སོགས་པ་རྣམས་ལའོ། །

Enumeration Block 53:
རྣམ་པ་བརྒྱད་དེ། །ལག་པའི་འདུས་ཏེ་རེག་པ་དང་། བོང་བའི་འདུས་ཏེ་རེག་པ་དང་། དབྱུག་པའི་འདུས་ཏེ་རེག་པ་དང་། མཚོན་ཆའི་འདུས་ཏེ་རེག་པ་དང་། གྲང་བའི་འདུས་ཏེ་རེག་པ་དང་། ཚ་བའི༌འདུས་ཏེ་རེག་པ་དང་། བཀྲེས་པའི༌འདུས་ཏེ་རེག་པ་དང་། སྐོམ་པའི༌འདུས་ཏེ་རེག་པའོ། །

Enumeration Block 54:
རྣམ་པ་དགུ་སྟེ། དྲི་བཞིན་ནོ། །

Enumeration Block 55:
རྣམ་པ་བཅུ་སྟེ། ཁ་ཟས་ཀྱི་འདུས་ཏེ་རེག་པ་དང་། སྐོམ་པའི་འདུས་ཏེ་རེག་པ་དང་། བཞོན་པའི་འདུས་ཏེ་རེག་པ་དང་། གོས་ཀྱི་འདུས་ཏེ་རེག་པ་དང་། རྒྱན་གྱི་འདུས་ཏེ་རེག་པ་དང་། ཁྲི་དང་ཁྲིའུའི་འདུས་ཏེ་རེག་པ་དང་། སྟན་ནང་ཚངས་ཅན་དང་། ལ་བའི་སྟན༌དང་། སྔས་ནང་ཚངས་ཅན་དང་། གོར་བུའི་འདུས་ཏེ་རེག་པ་དང་། བུད་མེད་ཀྱི་འདུས་ཏེ་རེག་པ་དང་། སྐྱེས་པའི་འདུས་ཏེ་རེག་པ་དང་། དེ་གཉིས་དགའ་མགུར་སྤྱོད་ཅིང་ཡོངས་སུ་སྤྱོད་པའི་འདུས་ཏེ་རེག་པའོ། །

Enumeration Block 56:
ཆོས་ཀྱི་ཁམས་དེ་ཡང་རྣམ་པ་གཅིག་སྟེ། ཡིད་ཀྱི་སྤྱོད་ཡུལ་གྱི་དོན་གྱིས་སོ། །

Enumeration Block 57:
རྣམ་པ་གཉིས་ཏེ། གདགས་པའི་ཆོས་སུ་བསྡུས་པ་དང་། གདགས་པ་མ་ཡིན་པའི་ཆོས་སུ་བསྡུས་པའོ། །

Enumeration Block 58:
རྣམ་པ་གསུམ་སྟེ། གཟུགས་ཅན་དང་། གཟུགས་ཅན་མ་ཡིན་པ་དང་། འདུས་བྱས་དང་། འདུས་མ་བྱས་སོ། །

Enumeration Block 59:

གཞན་ཡང་རྒྱུ་ནི་རྣམ་པ་བདུན་དུ་གཞག་པ་ཡིན་ཏེ། འདི་ལྟ་སྟེ། མི་རྟག་པ་ནི་རྒྱུ་ཡིན་ཏེ། རྟག་པའི་ཆོས་ནི་སྐྱེ་བའི་རྒྱུའམ། ཐོབ་པའི་རྒྱུའམ། གྲུབ་པར་འགྱུར་བའི་རྒྱུའམ། འགྲུབ་པའི་རྒྱུའམ། གནས་པའི་རྒྱུའམ། བྱེད་པའི་རྒྱུའམ། གང་གི་རྒྱུར་ཡང་མི་འགྱུར་རོ། །

Enumeration Block 5:
དེ་ནི་རྣམ་པ་བདུན་དུ་རིག་པར་བྱ་སྟེ། ལུས་དང་དམིགས་པ་དང་། རྣམ་པ་དང་། ཀུན་ནས་སློང་བ་དང་། རབ་ཏུ་དབྱེ་བ་དང་། རྣམ་པར་ངེས་པ་དང་། འཇུག་པའོ། །

Enumeration Block 1:
གཞན་ཡང་རྒྱུ་ནི་རྣམ་པ་ལྔར་གཞག་པ་ཡིན་ཏེ། འདི་ལྟ་སྟེ། སྡུག་པའི་རྒྱུ་དང་། མི་སྡུག་པའི་རྒྱུ་དང་། ལྟ་བའི་རྒྱུ་དང་། འཇུག་པའི་རྒྱུ་དང་། ལྡོག་པའི་རྒྱུའོ། །

Enumeration Block 2:
གཞན་ཡང་རྒྱུ་ནི་རྣམ་པ་བདུན་དུ་གཞག་པ་ཡིན་ཏེ། འདི་ལྟ་སྟེ། མི་རྟག་པ་ནི་རྒྱུ་ཡིན་ཏེ། རྟག་པའི་ཆོས་ནི་སྐྱེ་བའི་རྒྱུའམ། ཐོབ་པའི་རྒྱུའམ། གྲུབ་པར་འགྱུར་བའི་རྒྱུའམ། འགྲུབ་པའི་རྒྱུའམ། གནས་པའི་རྒྱུའམ། བྱེད་པའི་རྒྱུའམ། གང་གི་རྒྱུར་ཡང་མི་འགྱུར་རོ། །

Enumeration Block 3:
དེ་ནི་རྣམ་པ་བདུན་དུ་རིག་པར་བྱ་སྟེ། ལུས་དང་དམིགས་པ་དང་། རྣམ་པ་དང་། ཀུན་ནས་སློང་བ་དང་། རབ་ཏུ་དབྱེ་བ་དང་། རྣམ་པར་ངེས་པ་དང་། འཇུག་པའོ། །

Enumeration Block 4:
རབ་ཏུ་དབྱེ་བ་རྣམ་པ་བདུན་ཏེ། མཚན་མ་ཅན་དང་། མཚན་མ་ཅན་མ་ཡིན་པ་ནས། ཉོན་མོངས་པ་ཅན་མ་ཡིན་པའི་བར་དུ་སྔ་མ་བཞིན་ནོ། །

Enumeration Block 5:
དེ་ནི་རྣམ་པ་བརྒྱད་དུ་རིག་པར་བྱ་སྟེ། གནས་དང་དངོས་པོ་དང་། ཚོལ་བ་དང་། ལོངས་སྤྱོད་པ་དང་། ཡང་དག་པར་འགྲུབ་པ་དང་། ཉན་ཐོས་ཀྱི་ཐེག་པའི་ཚོགས་ལ་སྦྱོར་བ་དང་། རང་སངས་རྒྱས་ཀྱི་ཐེག་པའི་ཚོགས་ལ་སྦྱོར་བ་དང་། ཕ་རོལ་ཏུ་ཕྱིན་པ་བསྒྲུབ་པ་ལ་སྦྱོར་བའོ། །

Enumeration Block 6:
གནས་རྣམ་པ་དྲུག་སྟེ། འདི་ལྟ་སྟེ། ངེས་པའི་དུས་དང་། ལྡོག་པའི་དུས་དང་། ལས་ཀྱི་དུས་དང་། འཇིག་རྟེན་པའི་འདོད་ཆགས་དང་བྲལ་བའི་དུས་དང་། འཇིག་རྟེན་ལས་འདས་པའི་འདོད་ཆགས་དང་བྲལ་བའི་དུས་དང་། སེམས་ཅན་ལ་ཕན་འདོགས་པའི་དུས་སོ། །

Enumeration Block 7:
དངོས་པོ་བརྒྱད་དེ། སྦྱིན་པ་ལས་བྱུང་བའི་བསོད་ནམས་བྱ་བའི་དངོས་པོ་དང་། ཚུལ་ཁྲིམས་ལས་བྱུང་བ་དང་། བསྒོམས་པ་པ་ལས་བྱུང་བ་དང་། ཐོས་པ་ལས་བྱུང་བ་དང་། བསམས་པ་ལས་བྱུང་བ་དང་། དེ་ལས་གཞན་པའི་བསྒོམས་པ་ལས་བྱུང་བ་དང་། སོ་སོར་བརྟགས་པ་ལས་བྱུང་བ་དང་། སེམས་ཅན་ལ་ཕན་འདོགས་པ་ལས་བྱུང་བའོ། །

Enumeration Block 8:
ཡང་སྦྱིན་པ་དག་གི་མཚན་ཉིད་ནི་རྣམ་པ་བཞི་སྟེ། འདོད་པ་དང་། ཕྱོགས་མི་འཛིན་པ་དང་། ཕོངས་པ་སེལ་བ་དང་། ཡང་དག་པར་ཤེས་པའོ། །

Enumeration Block 9:
ཚུལ་ཁྲིམས་དང་ལྡན་པའི་མཚན་ཉིད་ནི། རྣམ་པ་བཞི་སྟེ། འདོད་པ་དང་ཆུ་ལོན་གྱིས་གློན་པ་དང་། ཀུན་ཏུ་མི་སྤྱོད་པ་དང་། ཡང་དག་པར་ཤེས་པའོ། །

Enumeration Block 10:
སྒོམ་པ་པོའི་མཚན་ཉིད་ནི་རྣམ་པ་བཞི་སྟེ། བསམ་པ་རྣམ་པར་དག་པ་དང་། ཉེ་བར་སྦྱོར་བ་རྣམ་པར་དག་པ་དང་། མོས་པས་སྙོམས་པར་འཇུག་པ་རྣམ་པར་དག་པ་དང་། ཤེས་པ་རྣམ་པར་དག་པའོ། །

Enumeration Block 11:
ཟས་སྦྱིན་པ་ནི་རྣམ་པ་དྲུག་སྟེ། ཡི་དམ་ཅན་ལ་སྦྱིན་པ་དང་། ཀུན་ཏུ་འཚོལ་ཟས་སྦྱིན་པ་དང་། གནོད་པ་ལ་ཟས་སྦྱིན་པ་དང་། རང་བཞིན་གྱིས་ཕོངས་པ་ལ་ཟས་སྦྱིན་པ་དང་། ཡུལ་དང་བྲལ་བར་གནས་པ་ལ་ཟས་སྦྱིན་པ་དང་། ཡོངས་སུ་ཞེན་པ་ལ་ཟས་སྦྱིན་པའོ། །

Enumeration Block 12:
གནོད་པ་ནི་རྣམ་པ་བརྒྱད་དེ། བཀྲེས་པས་གནོད་པ་དང་། སྐོམ་པས་གནོད་པ་དང་། ཁ་ཟས་ངན་པ་ཟ་བས་གནོད་པ་དང་། ཡོངས་སུ་ངལ་བས་གནོད་པ་དང་། གྲང་བས་གནོད་པ་དང་། ཚ་བས་གནོད་པ་དང་། སྐྱབས་མེད་པས་གནོད་པ་དང་། བསྒྲིབས་པས་གནོད་པའོ། །

Enumeration Block 13:
ཡང་གནོད་པ་ནི་རྣམ་པ་དྲུག་སྟེ། ལྷན་ཅིག་སྐྱེས་པ་དང་། འདོད་པས་ཕོངས་པ་ལས་བྱུང་བ་དང་། འགྲོ་བ་ལས་བྱུང་བ་དང་། དུས་ཚིགས་འགྱུར་བ་ལས་བྱུང་བ་དང་། འཛག་གནོད་བྱེད་པ་ལས་བྱུང་བ་དང་། ཐ་སྙད་ཆད་པ་ལས་བྱུང་བའོ། །

Enumeration Block 14:
ཕན་གདགས་པ་ནི་རྣམ་པ་དྲུག་སྟེ། ཉེ་བར་རྟོན་པས་ཕན་གདགས་པ་དང་། འགྲོ་བ་སྒནོད་པ་ལ་ཕན་གདགས་པ་དང་། གཡོགས་པས་ཕན་གདགས་པ་དང་། སྤོས་དང་མེ་ཏོག་ཕྲེང་དང་བྱུག་པས་ཕན་གདགས་པ་དང་། གནས་ཀྱིས་ཕན་གདགས་པ་དང་། འགྲོགས་པ་ལ་ཕན་གདགས་པའོ། །

Enumeration Block 15:
མི་མཛའ་བའི་མཚན་ཉིད་ནི་བཞི་སྟེ། འཁྲུག་པའི་བསམ་པ་མི་གཏོང་བ་དང་། སྡུག་པ་ལ་རྣམ་པར་བགེགས་བྱེད་པའི་གནས་དང་། མི་སྡུག་པ་བསྒྲུབ་པ་དང་། ཕན་པ་མ་ཡིན་པ་བསྒྲུབ་པའོ། །

Enumeration Block 16:
བསྒྲུབ་པ་ནི་རྣམ་པ་གསུམ་སྟེ། ཡོ་བྱད་ཀྱི་བདེ་བ་བསྒྲུབ་པ་དང་། དགའ་བ་དང་བཅས་པའི་བདེ་བ་བསྒྲུབ་པ་དང་། དགའ་བ་མེད་པའི་བདེ་བ་བསྒྲུབ་པའོ། །

Enumeration Block 17:
མཐུན་པར་འཇུག་པར་ཁས་བླང་བ་ནི་བཞི་པོ་འདི་དག་ཡིན་ཏེ། འདི་ལྟ་སྟེ། འགྲོན་ལ་མཐུན་པར་འཇུག་པར་ཁས་བླང་བ་དང་། སྐྱེ་བོ་ཡོངས་ལ་མཐུན་པར་འཇུག་པར་ཁས་བླང་བ་དང་། བླ་མ་རྣམས་དང་མཐུན་པར་འཇུག་པར་ཁས་བླང་བ་དང་། ཚོགས་པར་འདུ་འོས་ལ་མཐུན་པར་འཇུག་པར་ཁས་བླང་བ་སྟེ།

Enumeration Block 18:
གནས་བཞི་བསྟེན་ནས་འབྲས་བུ་ལྔར་འགྱུར་བར་རིག་པར་བྱ་སྟེ། འདི་ལྟ་སྟེ་ཕན་གདགས་པ་དང་། རྣམ་པར་ཐོ་མི་འཚམས་པ་དང་། མཆོད་པ་དང་། སྐལ་བ་མཉམ་པ་དང་། མཐུན་པར་འཇུག་པར་གནས་བཞི་པོ་འདི་དག་བསྟེན་ནས། ལོངས་སྤྱོད་ཆེ་བ་དང་། ཕྱོགས་དང་ཕྱོགས་མཚམས་སུ་གྲགས་པ་དང་། ཡོངས་སུ་ཉོན་མོངས་པ་མེད་པ་དང་། མྱ་ངན་ལས་འདས་པ་འཐོབ་པ་དང་། བདེ་འགྲོར་འགྲོ་བ་སྟེ། འབྲས་བུ་ལྔ་པོ་འདི་དག་འགྲུབ་པར་འགྱུར་རོ། །

Enumeration Block 19:
མཁས་པ་རྣམས་ཀྱི་མཁས་པའི་མཚན་ཉིད་ནི། གསུམ་པོ་འདི་དག་ཡིན་ཏེ། དགེ་བ་ཡང་དག་པར་ལེན་པ་དང་། དགེ་བ་ལ་གཅིག་ཏུ་ངེས་པ་དང་། དགེ་བ་ལ་བརྟེན་པའོ། །

Enumeration Block 20:
གཞན་ཡང་གསུམ་སྟེ། ལྷག་པའི་ཚུལ་ཁྲིམས་ཡང་དག་པར་ལེན་པ་དང་། ལྷག་པའི་སེམས་ཡང་དག་པར་ལེན་པ་དང་། ལྷག་པའི་ཤེས་རབ་ཡང་དག་པར་ལེན་པའོ།། །།

Enumeration Block 1:
མཛའ་བོའི་མཚན་ཉིད་རྣམ་པ་བཞིར་རིག་པར་བྱའོ། །

Enumeration Block 2:
བསྒྲུབ་པ་ནི་རྣམ་པ་གསུམ་སྟེ། ཡོ་བྱད་ཀྱི་བདེ་བ་བསྒྲུབ་པ་དང་། དགའ་བ་དང་བཅས་པའི་བདེ་བ་བསྒྲུབ་པ༌དང་། །དགའ་བ་མེད་པའི་བདེ་བ་བསྒྲུབ༌པའོ། །

Enumeration Block 3:
མཐུན་པར་འཇུག་པར་ཁས་བླང་བ་ནི་བཞི་པོ་འདི་དག་ཡིན་ཏེ། འདི་ལྟ་སྟེ། འགྲོན་ལ་མཐུན་པར་འཇུག་པར་ཁས་བླང་བ་དང་། སྐྱེ་བོ་ཡོངས་ལ་མཐུན་པར་འཇུག་པར་ཁས་བླང་བ༌དང་། བླ་མ་རྣམས་དང་མཐུན་པར་འཇུག་པར་ཁས་བླང་བ་དང་། ཚོགས་པར་འདུ་འོས་ལ་མཐུན་པར་འཇུག་པར༌ཁས་བླང་བ་སྟེ།

Enumeration Block 4:
མཐུན་པར་འཇུག་པར་ཁས་བླང་བ་བཞི་པོ་འདི་དག་ལ། གནས་བཞི་བསྟེན་ནས་འབྲས་བུ་ལྔར་འགྱུར་བར་རིག་པར་བྱ་སྟེ། འདི་ལྟ་སྟེ་ཕན་གདགས་པ་དང་། རྣམ་པར་ཐོ་མི་འཚམས་པ༌དང་། མཆོད་པ་དང་། སྐལ་བ་མཉམ་པ་དང་། མཐུན་པར་འཇུག་པར་གནས་བཞི་པོ་འདི་དག་བསྟེན༌ནས། ལོངས་སྤྱོད་ཆེ་བ་དང་། ཕྱོགས་དང་ཕྱོགས་མཚམས་སུ་གྲགས་པ་དང་། ཡོངས་སུ་ཉོན་མོངས་པ་མེད་པ་དང་། མྱ་ངན་ལས་འདས་པ་འཐོབ་པ༌དང་། བདེ་འགྲོར་འགྲོ་བ་སྟེ། འབྲས་བུ་ལྔ་པོ་འདི་དག་འགྲུབ་པར་འགྱུར་རོ། །

Enumeration Block 5:
མཁས་པ་རྣམས་ཀྱི་མཁས་པའི་མཚན་ཉིད་ནི། གསུམ་པོ་འདི་དག་ཡིན་ཏེ། དགེ་བ་ཡང་དག་པར་ལེན་པ་དང་། དགེ་བ་ལ་གཅིག་ཏུ་ངེས་པ་དང་། དགེ་བ་ལ་བརྟེན་པའོ། །

Enumeration Block 6:
གཞན་ཡང་གསུམ་སྟེ། ལྷག་པའི་ཚུལ་ཁྲིམས་ཡང་དག་པར་ལེན་པ་དང་། ལྷག་པའི་སེམས་ཡང་དག་པར་ལེན་པ་དང་། ལྷག་པའི་ཤེས་རབ་ཡང་དག་པར་ལེན་པའོ།། །།

Enumeration Block 7:
ཕ་རོལ་སྨྲ་བ་ནི་བཅུ་དྲུག་པོ་འདི་དག་ཡིན་ཏེ། འདི་ལྟ་སྟེ། རྒྱུ་ལ་འབྲས་བུ་ཡོད་པར་སྨྲ་བ་དང་། མངོན་པར་གསལ་བར་སྨྲ་བ་དང་། འདས་པ༌དང་མ་འོངས་པ་རྫས་སུ་ཡོད་པར་སྨྲ་བ་དང་། བདག་ཏུ་སྨྲ་བ་དང་། རྟག་པར་སྨྲ་བ་དང་། སྔོན་བྱས་པ་རྒྱུར་སྨྲ་བ་དང་། དབང་ཕྱུག་ལ་སོགས་པ་བྱེད་པ་པོར་སྨྲ་བ་དང་། རྣམ་པར་འཚེ་བའི་ཆོས་སུ་སྨྲ་བ་དང་། མཐའ་དང་མཐའ་མེད་པར་སྨྲ་བ་དང་། མཐའ་མི་སྤོང་བར༌སྨྲ་བ་དང་། རྒྱུ་མེད་པར་སྨྲ་བ་དང་། ཆད་པར༌སྨྲ་བ་དང་། མེད་པར་སྨྲ་བ་དང་། མཆོག་ཏུ་སྨྲ་བ་དང་། དག་པར་སྨྲ་བ་དང་། དགེ་མཚན་དང་བཀྲ་ཤིས་སུ་སྨྲ་བའོ། །

Enumeration Block 1:
འདུ་བྱེད་ཀྱི་མཚན་ཉིད་རྣམ་པ་གསུམ་མོ། །

Enumeration Block 2:
མ་འོངས་པའི་མཚན་ཉིད་རྣམ་པ་བཅུ་གཉིས་ཡོད་པར་རིག་པར་བྱ་སྟེ། རྒྱུར་རབ་ཏུ་ཕྱེ་བ་དང་། ལུས་མ་སྐྱེས་པ་དང་། རྐྱེན་ལ་ལྟོས་པ་དང་། སྐྱེས་པ་དང་འདྲ་བ་དང་། སྐྱེ་བའི་ཆོས་ཅན་དང་། མི་སྐྱེ་བའི༌ཆོས་ཅན་དང་། ཀུན་ནས་ཉོན་མོངས་པ་མ་སྐྱེས་པ་དང་། རྣམ་པར་བྱང་བ་མ་སྐྱེས་པ་དང་། འདོད་པར་བྱ་བ་དང་། འདོད་པར་བྱ་བ་མ་ཡིན་པ་དང་། བརྟག་ཏུ་རུང་བ་དང་བརྟག་ཏུ་རུང་བ་མ་ཡིན་པའོ། །

Enumeration Block 3:
ད་ལྟར་བྱུང་བ་ལ༌ཡང་མཚན་ཉིད་རྣམ་པ་བཅུ་གཉིས་ཡོད་དེ། འབྲས་བུ་རབ་ཏུ་ཕྱེ་བ་དང་། ལུས་སྐྱེས་པ་དང་། རྐྱེན་དང་ལྡན་པ་དང་། སྐྱེས་པ་དང་འདྲ་བ་དང་། སྐད་ཅིག་པ་དང་། མི་སྐྱེ་བའི་ཆོས་ཅན་དང་། ཀུན་ནས་ཉོན་མོངས་པ་དང་ལྡན་པ་དང་། རྣམ་པར་བྱང་བ་དང་ལྡན་པ་དང་། ཡིད་དུ་འོང་བ་དང་། ཡིད་དུ་མི་འོང་བ་དང་། བརྟག་ཏུ་རུང་བ་དང་། བརྟག་ཏུ་རུང་བ་མ་ཡིན་པའོ། །

Enumeration Block 4:
འདས་པ་ལ་ཡང་མཚན་ཉིད་རྣམ་པ་བཅུ་གཉིས་ཡོད་པར་རིག་པར་བྱ་སྟེ། རྒྱུ་འདས་པ་དང་། རྐྱེན་འདས་པ་དང་། འབྲས་བུ་འདས་པ་དང་། ལུས་ཞིག་པ་དང་། འགགས་པའི་རང་བཞིན་ཅན་དང་། མི་སྐྱེ་བའི་ཆོས་ཅན་དང་། ཀུན་ནས་ཉོན་མོངས་པ་རྣམ་པར་ཞི་བ་དང་། རྣམ་པར་བྱང་བ་རྣམ་པར་ཞི་བ་དང་། ལྟས་པའི༌གནས་ལྟ༌བུ་དང་། ལྟོས་པ་མ་ཡིན་པའི་གནས་ལྟ་བུ་དང་། བརྟག་ཏུ་རུང་བ་དང་། བརྟག་ཏུ་རུང་བ་མ་ཡིན་པའོ། །

Enumeration Block 1:
ཅི་ཆོས་ཀྱི་རང་གི་ངོ་བོ་ཉིད་ལས་སེམས་ཅན་གྱི་བློ་འབྱུང་བའམ་འོན་ཏེ་གཞན་གྱི་ངོ་བོ་ཉིད་ལས་བྱུང་བར་འདོད།

Enumeration Block 2:
ཅི་སེམས་ཅན་དུ་བགྲང་བས་མ་ཡིན་པ་ལ་སེམས་ཅན་དུ་བགྲང་བའི་བློ་འམ། སེམས་ཅན་དུ་བགྲང་བ་ལ་སེམས་ཅན་དུ་བགྲང་བ་མ་ཡིན་པའི་བློ་འམ། དེ་ལས་གཞན་པའི་སེམས་ཅན་དུ་བགྲང་བ་ལ་དེ་ལས་གཞན་པའི་སེམས་ཅན་དུ་བགྲང་བའི་བློ་འབྱུང་བར་འདོད༌དམ་མི་འདོད།

Enumeration Block 3:
ཅི་སེམས་ཅན་གྱི་བློ་གང་ཡིན་པ་དེ་མངོན་སུམ་གྱི་དོན་འཛིན་པའམ། འོན་ཏེ་རྗེས་སུ་དཔག་པའི་དོན་འཛིན་པར་འདོད།

Enumeration Block 4:
ཅི་སྤྱོད་པ་བློའི་རྒྱུ་ལས་བྱུང་བའམ། འོན་ཏེ་སེམས་ཅན་གྱི་རྒྱུ་ལས་བྱུང་བར་འདོད།

Enumeration Block 5:
ཅི་སྤྱོད་པའི་རྒྱུ་མི་རྟག་པའམ། འོན་ཏེ་རྟག་པར་འདོད།

Enumeration Block 6:
ཅི་སེམས་ཅན་རྩོལ་བའི་བདག་ཉིད་ཅན་ཞིག་སྤྱོད་པར་འགྱུར་བའམ། འོན་ཏེ་མི་རྩོལ་བའི་བདག་ཉིད་ཅན་ཞིག་སྤྱོད་པར་འདོད།

Enumeration Block 7:
ཅི་རྒྱུ་ཡོད་པས་སེམས་ཅན་སྤྱོད་པའམ། འོན་ཏེ་རྒྱུ་མེད་པར་སྤྱོད་པར་འདོད།

Enumeration Block 8:
ཅི་སེམས་ཅན་རང་དབང་གིས་སྤྱོད་པའམ། འོན་ཏེ་གཞན་གྱི་དབང་གིས་སྤྱོད་པར་འདོད།

Enumeration Block 9:
ཅི་ཕུང་པོ་ཙམ་སེམས་ཅན་དུ་འདོགས་པའམ། འོན་ཏེ་ཕུང་པོ་ལ་ཡོད་པའམ། ཕུང་པོ་རྣམས་དང་ཐ་དད་པའམ། ཕུང་པོ་མེད་པ་ཞིག་ཏུ་འདོད།

Enumeration Block 10:
ཅི་ལྟ་བ་པོ་ལ་སོགས་པའི་མཚན་ཉིད་གཅིག་ཡིན་ནམ། འོན་ཏེ་དེ་དང་ཐ་དད་པའི་མཚན་ཉིད་གཅིག་ཡིན་པར་འདོད།

Enumeration Block 11:
ཅི་གང་ཀུན་ནས་ཉོན་མོངས་པ་དང་། རྣམ་པར་བྱང་བའི་མཚན་ཉིད་དང་ལྡན་པ་དེ། ཀུན་ནས་ཉོན་མོངས་པའམ། རྣམ་པར་བྱང་བར་འགྱུར་རམ། འོན་ཏེ་དེའི་མཚན་ཉིད་དང་མི་ལྡན་པ་དེ་ལྟར་འགྱུར་བར་འདོད།

Enumeration Block 12:
ཅི་གང་འཇུག་པའི་མཚན་ཉིད་དང་ལྡན་པ་དེ་འཇུག་ཀྱང་འཇུག་ལ་ལྡོག་ཀྱང་ལྡོག་པར་འགྱུར་རམ། འོན་ཏེ་དེའི་མཚན་ཉིད་དང་མི་ལྡན་པ་དེ་ལྟར་འགྱུར་བར་འདོད།

Enumeration Block 13:
ཅི་ཡུལ་གྱིས་བསྐྱེད་པའི་བདེ་བ་དང་སྡུག་བསྔལ་བར་འགྱུར་བ་གང་ཡིན་པ་དང་། སེམས་ཀྱིས་འགྱུར་བ་གང་ཡིན་པ་དང་། ཉོན་མོངས་པ་དང་། ཉེ་བའི་ཉོན་མོངས་པ་རྣམས་ཀྱིས་འགྱུར་བ་གང་ཡིན་པ་དེ་ནི་ཟ་བ་པོའམ། བྱེད་པ་པོའམ། གྲོལ་པ་པོར་འདོད་དམ། འོན་ཏེ་མི་འགྱུར་བ་གང་ཡིན་པ་དེ་དེ་ལྟར་འདོད།

Enumeration Block 14:
ཅི་བདག་ཉིད་ལ་བྱེད་པ་པོར་འདོགས་པའམ། འོན་ཏེ་བདག་ལས་གཞན་པ་ལ་ཡང་འདོགས་པར་འདོད།

Enumeration Block 15:
ཅི་བདག་ཉིད་ལ་བདག་ཏུ་འདོགས་པའམ། འོན་ཏེ་གཞན་ལ་ཡང་འདོགས་པར་འདོད།

Enumeration Block 16:
ཅི་བདག་ཏུ་ལྟ་བ་གང་ཡིན་པ་འདི་དགེ་བའམ་མི་དགེ་བར་འདོད།

Enumeration Block 17:
ཅི་བདག་མེད་པར་ལྟ་བ་དགེ་བའམ་མི་དགེ་བ་ཡིན་པར་འདོད།

Enumeration Block 18:
ཅི་བདག་ཉིད་ལ་བདག་ཡོད་དོ་སྙམ་དུ་སེམས་སམ༌འོན་ཏེ་བདག་ཏུ་ལྟ་བ་ཡིན་པར་འདོད།

Enumeration Block 19:
ཅི་སྔོན་གྱི་གནས་རྗེས་སུ་དྲན་པ། ཕུང་པོ་འཛིན་པ་ཡིན་ནམ། བདག་འཛིན་པ་ཡིན་པར་འདོད།

Enumeration Block 20:
ཅི་གཟུགས་ལ་དམིགས་ཏེ་མིག་གི་རྣམ་པར་ཤེས་པ་མངོན་སུམ་དུ་གྱུར་ལ། ཡུལ་གཟུགས་ཁོ་ན་དང་ཕྲད་ན། དེ་ལས་གཞན་པའི་ཡུལ་བཀོད་པར་གྱུར་པ་རྣམས་ལ་དེ་ལས་གཞན་པའི་རྣམ་པར་ཤེས་པ་རྣམས་འགགས་པའམ། འཇུག་པར་འདོད།

Enumeration Block 1:
བདག་དང་འཇིག་རྟེན་ནི་རྟག་པ་སྟེ། བྱས་པ་མ་ཡིན་པ་དང་། བྱས་པས་བྱས་པ་མ་ཡིན་པ་དང་། སྤྲུལ་པ་མ་ཡིན་པ་དང་། སྤྲུལ་པས་བྱས་པ་མ་ཡིན་པ་དང་། གསད༌དུ་མེད་པ་དང་། ཐེར་ཟུག་ཏུ་གནས་པ་དང་། སྲོག་ཤིང་ལྟར་བརྟན་པར་གནས་པའོ་སྙམ་དུ་འཛིན་ཏོ། །

Enumeration Block 2:
འདི་ལྟ་སྟེ། རྟག་པར་སྨྲ་བ་དང་། ཁ་ཅིག་རྟག་པར་འཛིན་པ་སྔོན་གྱི་མཐའ་ལ་རྟོག་པ་རྣམས་དང་། ཕྱི་མའི་མཐའ༌ལ་རྟོག་པ་འདུ་ཤེས་ཅན་དུ་སྨྲ་བ་རྣམས་དང་། འདུ་ཤེས་ཅན་མ་ཡིན་པར་སྨྲ་བ་རྣམས་དང་། འདུ་ཤེས་ཡོད་པ་ཡང་མ་ཡིན་འདུ་ཤེས་མེད་པ༌ཡང་མ་ཡིན་པར་སྨྲ་བ་རྣམས་སོ། །

Enumeration Block 3:
དུས་ཐམས་ཅད་དུ་མི་འགྱུར་བའི་མཚན་ཉིད་དང་། རྣམ་པ་ཐམས་ཅད་དུ་མི་འགྱུར་བའི་མཚན་ཉིད་དང་། བདག་ཉིད་མི་འགྱུར་བའི་མཚན་ཉིད་དང་། གཞན་གྱིས་མི་འགྱུར་བའི་མཚན་ཉིད་དང་། སྐྱེ་བ་ཅན་མ་ཡིན་པ་གང་ཡིན་པ་དེ་ནི་རྟག་པའི་མཚན་ཉིད་ཡིན་པར་རིག་པར་བྱའོ། །

Enumeration Block 4:

Enumeration Block 1:

Enumeration Block 2:
ཉོན་མོངས་པ་རྣམ་པ་གཅིག་ཀྱང་ཡོད་དེ་ཀུན་ནས་ཉོན་མོངས་པའི་དོན་ཏོ། །

Enumeration Block 3:
རྣམ་པ་གཉིས་ཀྱང་ཡོད་དེ་མཐོང་བས་སྤང་བར་བྱ་བ་དང་། བསྒོམ་པས་སྤང་བར་བྱའོ། །

Enumeration Block 4:
རྣམ་པ་གསུམ་ཡང་ཡོད་དེ། འདོད་པ་དང་ལྡན་པ་དང་། གཟུགས་དང་ལྡན་པ་དང་། གཟུགས་མེད་པ་དང་ལྡན་པའོ། །

Enumeration Block 5:
རྣམ་པ་བཞི་ཡང་ཡོད་དེ། འདོད་པ་དང་ལྡན་པའི་ལུང་དུ་བསྟན་པ་དང་། ལུང་དུ་མ་བསྟན་པ་དང་། གཟུགས་དང་ལྡན་པའི་ལུང་དུ་མ་བསྟན་པ་དང་། གཟུགས་མེད་པ་དང་ལྡན་པའི་ལུང་དུ་མ་བསྟན་པའོ། །

རྣམ་པ་ལྔ་ཡང་ཡོད་དོ། །

Enumeration Block 7:
རྣམ་པ་དྲུག་ནི་འདོད་ཆགས་དང་། ཁོང་ཁྲོ་བ་དང་། ང་རྒྱལ་དང་། མ་རིག་པ་དང་། ལྟ་བ་དང་། ཐེ་ཚོམ་མོ། །

Enumeration Block 8:
རྣམ་པ་བདུན་ནི། བག་ལ་ཉལ་བདུན་ཏེ། འདོད་པའི་འདོད་ཆགས་ཀྱི་བག་ལ་ཉལ་བ་དང་། ཁོང་ཁྲོ་བའི་བག་ལ་ཉལ་བ་དང་། སྲིད་པའི་འདོད་ཆགས་ཀྱི༌བག་ལ་ཉལ་བ་དང་། ང་རྒྱལ་གྱི༌བག་ལ་ཉལ་བ་དང་། མ་རིག་པའི་བག་ལ་ཉལ་བ་དང་། ལྟ་བའི་བག་ལ་ཉལ་བ་དང་། ཐེ་ཚོམ་གྱི་བག་ལ་ཉལ་བའོ། །

Enumeration Block 9:
རྣམ་པ་བརྒྱད་ནི། འདོད་ཆགས་དང་། ཁོང་ཁྲོ་བ་དང་། ང་རྒྱལ་དང་། མ་རིག་པ་དང་། ཐེ་ཚོམ་དང་། ལྟ་བ་དང་། མཆོག་ཏུ་འཛིན་པ་གཉིས་སོ། །

Enumeration Block 10:
རྣམ་པ་དགུ་ནི། ཀུན་ཏུ་སྦྱོར་བ་དགུ་སྟེ། རྗེས་སུ་ཆགས་པའི་ཀུན་ཏུ་སྦྱོར་བ་དང་། ཁོང་ཁྲོ་བའི་ཀུན་ཏུ་སྦྱོར་བ་དང་། ང་རྒྱལ་གྱི་ཀུན་ཏུ་སྦྱོར་བ་དང་། མ་རིག་པའི་ཀུན་ཏུ་སྦྱོར་བ་དང་། ལྟ་བའི་ཀུན་ཏུ་སྦྱོར་བ་དང་། མཆོག་ཏུ་འཛིན་པའི་ཀུན་ཏུ་སྦྱོར་བ་དང་། ཐེ་ཚོམ་གྱི་ཀུན་ཏུ་སྦྱོར་བ་དང་། ཕྲག་དོག་གི་ཀུན་ཏུ་སྦྱོར་བ་དང་། སེར་སྣའི་ཀུན་ཏུ་སྦྱོར་བའོ། །

Enumeration Block 11:
རྣམ་པ་བཅུ་ནི་འཇིག་ཚོགས་ལ་ལྟ་བ་དང་། མཐར་འཛིན་པར་ལྟ་བ་དང་། ལོག་པར་ལྟ་བ་དང་། ལྟ་བ་མཆོག་ཏུ་འཛིན་པ་དང་། ཚུལ་ཁྲིམས་དང་། བརྟུལ་ཞུགས་མཆོག་ཏུ་འཛིན་པ་དང་། འདོད་ཆགས་དང་། ཁོང་ཁྲོ་བ་དང་། ང་རྒྱལ་དང་། མ་རིག་པ་དང་། ཐེ་ཚོམ་མོ། །

Enumeration Block 12:
བདེན་པ་རྣམ་པ་བཅུ་གཉིས་གང་ཞེ་ན།

Enumeration Block 13:
རྒྱུ་ནི་རྣམ་པ་དྲུག་སྟེ། རྟེན་དང་། དམིགས་པ་དང་། འདུ་འཛི་དང་། བཤད་པ་དང་། གོམས་པ་དང་། ཡིད་ལ་བྱེད་པ་ལས་ཀྱང་ཉོན་མོངས་པ་སྐྱེའོ། །

Enumeration Block 14:
མདོར་བསྡུ་ན་རྣམ་པ་བདུན་ཏེ། བག་ལ་ཉལ་གྱི་གནས་སྐབས་དང་། ཀུན་ནས་དཀྲིས་པའི་གནས་སྐབས་དང་། ཀུན་ནས་བརྟགས་པའི་གནས་སྐབས་དང་། ལྷན་ཅིག་སྐྱེས་པའི་གནས་སྐབས་དང་། ཆུང་ངུའི་གནས་སྐབས་དང་། འབྲིང་གི་གནས་སྐབས་དང་། ཆེན་པོའི་གནས་སྐབས་སོ། །

Enumeration Block 15:
དེ་ལ་རྒྱུ་རྣམ་པ་གཉིས་ཀྱིས་ནི་ཉོན་མོངས་པའི་བག་ལ་ཉལ་ཕྲ་རྒྱས་སུ་འགྱུར་ཏེ། ས་བོན་གྱི་རྗེས་སུ་འབྲེལ་བ་དང་། དེའི་བདག་པོའི་དངོས་པོས་སོ། །

Enumeration Block 16:
མདོར་བསྡུ་ན་ཀུན་ནས་དཀྲིས་པའི་སྒོ་དང་། བག་ལ་ཉལ་གྱི་སྒོ་སྟེ་སྒོ་རམ་པ་གཉིས་ཀྱིས་སོ། །

Enumeration Block 17:
