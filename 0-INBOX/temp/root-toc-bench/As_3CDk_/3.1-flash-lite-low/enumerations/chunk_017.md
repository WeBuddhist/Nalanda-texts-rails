Enumeration Block 1:
འདོད་པའི་ཁམས་ནི་གནས་གཞན་སུམ་ཅུ་རྩ་དྲུག་པོ་རྣམས་ཏེ། སེམས་ཅན་དམྱལ་བ་ཆེན་པོའི་གནས་བརྒྱད་ལ་འདི་ལྟ་སྟེ།

Enumeration Block 2:
གྲང་བའི་སེམས་ཅན་དམྱལ་བའི་གནས་བརྒྱད་ཡོད་པ་འདི་ལྟ་སྟེ།

Enumeration Block 3:
འདོད་པ་ན་སྤྱོད་པའི་ལྷ་རྣམ་པ་དྲུག་ལ།

Enumeration Block 4:
གཟུགས་ཀྱི་ཁམས་ནི་གནས་གཞན་བཅོ་བརྒྱད་དེ།

Enumeration Block 5:
གཟུགས་མེད་པའི་ཁམས་ནི་གནས་གཞན་བཞི་པོ་རྣམས་སོ། །
