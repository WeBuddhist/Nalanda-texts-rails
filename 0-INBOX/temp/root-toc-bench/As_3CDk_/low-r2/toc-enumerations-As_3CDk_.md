ཡང་འཕགས་པ་ཤེས་རབ་ཀྱིས་འཚོ་བ་རྣམས་ཀྱི་ཆོས་ཀྱི༌[^658]ལོངས་སྤྱོད་ནི་ཕྱི་རོལ་གྱི་འདོད་པ་ཅན་རྣམས་ཀྱི་འདོད་པའི་ལོངས་སྤྱོད་ལས་རྣམ་པ་ལྔས་ཁྱད་པར་དུ་འཕགས་ཏེ།

Enumeration Block 5:
དེ་ལ་སྐྱེ་བར་འདོགས་པ་རྣམ་པར་གཞག་པ་ནི་འདི་ཡིན་ཏེ། འདི་ལྟ་སྟེ། འདོད་པ་སྐྱེ་བ་རྣམ་པ་གསུམ་པོ་རྣམས་ཏེ།

Enumeration Block 1:
དེ་ལ་སྐྱེ་བར་འདོགས་པ་རྣམ་པར་གཞག་པ་ནི་འདི་ཡིན་ཏེ། འདི་ལྟ་སྟེ། འདོད་པ་སྐྱེ་བ་རྣམ་པ་གསུམ་པོ་རྣམས་ཏེ།

Enumeration Block 2:
བདེ་བ་སྐྱེ་བ་ནི་རྣམ་པ་གསུམ་པོ་འདི་དག་ཡིན་ཏེ།

Enumeration Block 3:
གསུམ་པོ་འདི་དག་ནི༌[^692]ཚོལ་བ་ཡིན་ཏེ། འདོད་པ་ཚོལ་བ་དང་། སྲིད་པ་ཚོལ་བ་དང་། ཚངས་པར་སྤྱོད་པ་ཚོལ་བའོ། །

Enumeration Block 4:
དེ་ལ་ལུས་རྣམ་པར་གཞག་པ་ནི། འདི་ལྟ་སྟེ། ཁམས་གསུམ་ན་སེམས་ཅན་རྣམས་ཀྱི་ལུས་ཐོབ་པ་རྣམ་པ་བཞི་ཡོད་དེ།

Enumeration Block 5:
དེ་ལ་རྒྱུ་དང་རྐྱེན་དང་འབྲས་བུ་རྣམ་པར་གཞག་པ་ནི་རྣམ་པ་བཞིར་རིག་པར་བྱ་སྟེ། མཚན་ཉིད་དང་། གནས་དང་། རབ་ཏུ་དབྱེ་བ་དང་། རྣམ་པར་གཞག་པའོ། །

Enumeration Block 6:
བཅོ་ལྔ་པོ་འདི་དག་ནི་རྒྱུའི་གནས་ཡིན་ཏེ། འདི་ལྟ་སྟེ་ཚིག་དང་མྱོང་བ་དང་། བག་ཆགས་དང་རླན་དང་བཅས་པའི་ས་བོན་དང་ཕྲད་ནས་འགག་པ་དང་། ཡུལ་དང་། དབང་པོ་དང་། བྱེད་པ་དང་། སྐྱེས་བུའི་བྱེད་པ་དང་། དེ་ཁོ་ན་ལ་ལྟ་བ་དང་། མཐུན་པ་དང་། མཐུ་སྣ་ཚོགས་དང་། ཚོགས་པ༌[^710]དང་བར་དུ་གཅོད་པ་དང་། བར་དུ་གཅོད་པ་མ་ཡིན་པའོ། །

Enumeration Block 7:
རྒྱུ་དང་རྐྱེན་དང་འབྲས་བུའི་རབ་ཏུ་དབྱེ་བ་གང་ཞེ་ན།

རྒྱུ་བཅུ་དང་། རྐྱེན་བཞི་དང་། འབྲས་བུ་ལྔའོ། །
རྒྱུ་བཅུ་པོ་དག་གང་ཞེ་ན།

རྗེས་སུ་ཐ་སྙད་འདོགས་པའི་རྒྱུ་དང་། ལྟོས་པའི་རྒྱུ་དང་། འཕེན་པའི་རྒྱུ་དང་། མངོན་པར་འགྲུབ་པའི༌[^711]རྒྱུ་དང་། ཡོངས་སུ་འཛིན་པའི་རྒྱུ་དང་། འདྲེན་པའི་རྒྱུ་དང་། སོ་སོར་ངེས་པའི་རྒྱུ་དང་། ལྷན་ཅིག་བྱེད་པའི་རྒྱུ་དང་། མི་མཐུན་པའི་རྒྱུ་དང་། མི་མཐུན་པ་མེད་པའི་རྒྱུའོ། །
རྐྱེན་བཞི་པོ་དག་གང་ཞེ་ན།

རྒྱུའི་རྐྱེན་དང་། མཚུངས་པ་དེ་མ་ཐག་པའི་རྐྱེན་དང་། དམིགས་པའི་རྐྱེན་དང་། བདག་པོའི་རྐྱེན་ཏོ། །
འབྲས་བུ་ལྔ་པོ་དག་གང་ཞེ་ན།

རྣམ་པར་སྨིན་པའི་འབྲས་བུ་དང་། རྒྱུ་མཐུན་པའི་འབྲས་བུ་དང་། བྲལ་བའི་འབྲས་བུ་དང་། སྐྱེས་བུ་བྱེད་པའི་འབྲས་བུ་དང་། བདག་པོའི་འབྲས་བུའོ། །

Enumeration Block 1:
ཡང་རྒྱུ་ནི་རྣམ་པ་ལྔར་གཞག་པ་ཡིན་ཏེ། འདི་ལྟ་སྟེ། སྐྱེད་པའི་རྒྱུ་དང་། ཐབས་ཀྱི་རྒྱུ་དང་། ལྷན་ཅིག་བྱུང་བའི་རྒྱུ་དང་། འགགས་མ་ཐག་པ་དང་། འགགས་ནས་རིང་དུ་ལོན་པའོ། །

Enumeration Block 2:
གཞན་ཡང་རྒྱུ་ནི་རྣམ་པ་ལྔར་གཞག་པ་ཡིན་ཏེ། འདི་ལྟ་སྟེ། སྡུག་པའི་རྒྱུ་དང་། མི་སྡུག་པའི་རྒྱུ་དང་། ལྟ་བའི་རྒྱུ་དང་། འཇུག་པའི་རྒྱུ་དང་། ལྡོག་པའི་རྒྱུའོ། །

Enumeration Block 3:
གཞན་ཡང་རྒྱུ་ནི་རྣམ་པ་བདུན་དུ་གཞག་པ་ཡིན་ཏེ།

Enumeration Block 4:
དེ་ལ་མཚན་ཉིད་གདགས་པ་རྣམ་པར་གཞག་པ་གང་ཞེ་ན། དེ་ནི་རྣམ་པ་བདུན་དུ་རིག་པར་བྱ་སྟེ། ལུས་དང་དམིགས་པ་དང་། རྣམ་པ་དང་། ཀུན་ནས་སློང་བ་དང་། རབ་ཏུ་དབྱེ་བ་དང་། རྣམ་པར་ངེས་པ་དང་། འཇུག་པའོ། །

Enumeration Block 1:
གཞན་ཡང་རྒྱུ་ནི་རྣམ་པ་ལྔར་གཞག་པ་ཡིན་ཏེ། འདི་ལྟ་སྟེ། སྡུག་པའི་རྒྱུ་དང་། མི་སྡུག་པའི་རྒྱུ་དང་། ལྟ་བའི་རྒྱུ་དང་། འཇུག་པའི་རྒྱུ་དང་། ལྡོག་པའི་རྒྱུའོ། །

Enumeration Block 2:
དེ་ལ་མཚན་ཉིད་གདགས་པ་རྣམ་པར་གཞག་པ་གང་ཞེ་ན། དེ་ནི་རྣམ་པ་བདུན་དུ་རིག་པར་བྱ་སྟེ། ལུས་དང་དམིགས་པ་དང་། རྣམ་པ་དང་། ཀུན་ནས་སློང་བ་དང་། རབ་ཏུ་དབྱེ་བ་དང་། རྣམ་པར་ངེས་པ་དང་། འཇུག་པའོ། །

Enumeration Block 3:
རྟོག་པ་དང་དཔྱོད་པ་རྣམས་ཀྱི༌[^736]རབ་ཏུ་དབྱེ་བ་གང་ཞེ་ན། རབ་ཏུ་དབྱེ་བ་རྣམ་པ་བདུན་ཏེ། མཚན་མ་ཅན་དང་། མཚན་མ་ཅན་མ་ཡིན་པ་ནས། ཉོན་མོངས་པ་ཅན་མ་ཡིན་པའི་བར་དུ༌[^737]སྔ་མ་བཞིན་ནོ། །

Enumeration Block 4:
དེ་ལ་ཚུལ་བཞིན་ཡིད་ལ་བྱེད་པ་གདགས་པ་རྣམ་པར་གཞག་པ་གང་ཞེ་ན། དེ་ནི་རྣམ་པ་བརྒྱད་དུ་རིག་པར་བྱ་སྟེ། གནས་དང་དངོས་པོ་དང་། ཚོལ་བ་དང་། ལོངས་སྤྱོད་པ་དང་། ཡང་དག་པར་འགྲུབ་པ་དང་། ཉན་ཐོས་ཀྱི་ཐེག་པའི་ཚོགས་ལ་སྦྱོར་བ་དང་། རང་སངས་རྒྱས་ཀྱི་ཐེག་པའི་ཚོགས་ལ་སྦྱོར་བ་དང་། ཕ་རོལ་ཏུ་ཕྱིན་པ་བསྒྲུབ་པ་ལ་སྦྱོར་བའོ། །

Enumeration Block 5:
ཚུལ་བཞིན་ཡིད་ལ་བྱེད་པ་དང་ལྡན་པའི་རྟོག་པ་དང་དཔྱོད་པ་རྣམས་ཀྱི་གནས་གང་ཞེ་ན། གནས་རྣམ་པ་དྲུག་སྟེ། འདི་ལྟ་སྟེ། ངེས་པའི་དུས་དང་། ལྡོག་པའི་དུས་དང་། ལས་ཀྱི་དུས་དང་། འཇིག་རྟེན་པའི་འདོད་ཆགས་དང་བྲལ་བའི་དུས་དང་། འཇིག་རྟེན་ལས་འདས་པའི་འདོད་ཆགས་དང་བྲལ་བའི་དུས་དང་། སེམས་ཅན་ལ་ཕན་འདོགས་པའི་དུས་སོ། །

Enumeration Block 6:
ཚུལ་བཞིན་ཡིད་ལ་བྱེད་པ་དང་ལྡན་པའི་རྟོག་པ་དང་དཔྱོད་པ་རྣམས་ཀྱི་དངོས་པོ་གང་ཞེ་ན། དངོས་པོ་བརྒྱད་དེ། སྦྱིན་པ་ལས་བྱུང་བའི་བསོད་ནམས་བྱ་བའི་དངོས་པོ་དང་། ཚུལ་ཁྲིམས་ལས་བྱུང་བ་དང་། བསྒོམས་པ་པ༌[^753]ལས་བྱུང་བ་དང་། ཐོས་པ་ལས་བྱུང་བ་དང་། བསམས་པ་ལས་བྱུང་བ་དང་། དེ་ལས་གཞན་པའི་བསྒོམས་པ༌[^754]ལས་བྱུང་བ་དང་། སོ་སོར་བརྟགས་པ་ལས་བྱུང་བ་དང་། སེམས་ཅན་ལ་ཕན་འདོགས་པ་ལས་བྱུང་བའོ། །

Enumeration Block 7:
ཡང་སྦྱིན་པ་དག་གི་མཚན་ཉིད་ནི་རྣམ་པ་བཞི་སྟེ། འདོད་པ་དང་། ཕྱོགས་མི་འཛིན་པ་དང་། ཕོངས་པ་སེལ་བ་དང་། ཡང་དག་པར་ཤེས་པའོ། །

Enumeration Block 8:
ཚུལ་ཁྲིམས་དང་ལྡན་པའི་མཚན་ཉིད་ནི། རྣམ་པ་བཞི་སྟེ། འདོད་པ་དང་ཆུ་ལོན་གྱིས་གློན་པ་དང་། ཀུན་ཏུ་མི་སྤྱོད་པ་དང་། ཡང་དག་པར་ཤེས་པའོ། །

Enumeration Block 9:
སྒོམ་པ་པོའི་མཚན་ཉིད་ནི་རྣམ་པ་བཞི་སྟེ། བསམ་པ་རྣམ་པར་དག་པ་དང་། ཉེ་བར་སྦྱོར་བ་རྣམ་པར་དག་པ་དང་། མོས་པས་སྙོམས་པར་འཇུག་པ་རྣམ་པར་དག་པ་དང་། ཤེས་པ་རྣམ་པར་དག་པའོ། །

Enumeration Block 10:
ཟས་སྦྱིན་པ་ནི་རྣམ་པ་དྲུག་སྟེ། ཡི་དམ་ཅན་ལ་སྦྱིན་པ་དང་། ཀུན་ཏུ་འཚོལ་ཟས་སྦྱིན་པ་དང་། གནོད་པ་ལ་ཟས་སྦྱིན་པ་དང་། རང་བཞིན་གྱིས་ཕོངས་པ་ལ་ཟས་སྦྱིན་པ་དང་། ཡུལ་དང་བྲལ་བར་གནས་པ་ལ་ཟས་སྦྱིན་པ་དང་། ཡོངས་སུ་ཞེན་པ་ལ་ཟས་སྦྱིན་པའོ། །

Enumeration Block 11:
གནོད་པ་ནི་རྣམ་པ་བརྒྱད་དེ། བཀྲེས་པས་གནོད་པ་དང་། སྐོམ་པས་གནོད་པ་དང་། ཁ་ཟས་ངན་པ་ཟ་བས་གནོད་པ་དང་། ཡོངས་སུ་ངལ་བས་གནོད་པ་དང་། གྲང་བས་གནོད་པ་དང་། ཚ་བས་གནོད་པ་དང་། སྐྱབས་མེད་པས་གནོད་པ་དང་། བསྒྲིབས་པས་གནོད་པའོ། །

Enumeration Block 12:
ཡང་གནོད་པ་ནི་རྣམ་པ་དྲུག་སྟེ། ལྷན་ཅིག་སྐྱེས་པ་དང་། འདོད་པས་ཕོངས་པ་ལས་བྱུང་བ་དང་། འགྲོ་བ་ལས་བྱུང་བ་དང་། དུས་ཚིགས་འགྱུར་བ་ལས་བྱུང་བ་དང་། འཛག་གནོད་བྱེད་པ་ལས་བྱུང་བ་དང་། ཐ་སྙད་ཆད་པ་ལས་བྱུང་བའོ། །

Enumeration Block 13:
ཕན་གདགས་པ་ནི་རྣམ་པ་དྲུག་སྟེ། ཉེ་བར་རྟོན་པས་ཕན་གདགས་པ་དང་། འགྲོ་བས༌[^761]གནོད་པ་ལ་ཕན་གདགས་པ་དང་། གཡོགས་པས་ཕན་གདགས་པ་དང་། སྤོས་དང་མེ་ཏོག་ཕྲེང་དང་བྱུག་པས་ཕན་གདགས་པ་དང་། གནས་ཀྱིས་ཕན་གདགས་པ་དང་། འགྲོགས་པ་ལ་ཕན་གདགས་པའོ། །

Enumeration Block 14:
མི་མཛའ་བའི་མཚན་ཉིད་ནི་བཞི་སྟེ། འཁྲུག་པའི༌[^762]བསམ་པ་མི་གཏོང་བ་དང་། སྡུག་པ་ལ་རྣམ་པར་བགེགས་བྱེད་པའི་གནས་དང་། མི་སྡུག་པ་བསྒྲུབ་པ་དང་། ཕན་པ་མ་ཡིན་པ་བསྒྲུབ་པའོ། །

Enumeration Block 15:
བསྒྲུབ་པ་ནི་རྣམ་པ་གསུམ་སྟེ། ཡོ་བྱད་ཀྱི་བདེ་བ་བསྒྲུབ་པ་དང་། དགའ་བ་དང་བཅས་པའི་བདེ་བ་བསྒྲུབ་པ༌[^763]དང་། །དགའ་བ་མེད་པའི་བདེ་བ་བསྒྲུབ༌[^764]པའོ། །

Enumeration Block 16:
མཁས་པ་རྣམས་ཀྱི་མཁས་པའི་མཚན་ཉིད་ནི། གསུམ་པོ་འདི་དག་ཡིན་ཏེ། དགེ་བ་ཡང་དག་པར་ལེན་པ་དང་། དགེ་བ་ལ་གཅིག་ཏུ་ངེས་པ་དང་། དགེ་བ་ལ་བརྟེན་པའོ། །གཞན་ཡང་གསུམ་སྟེ། ལྷག་པའི་ཚུལ་ཁྲིམས་ཡང་དག་པར་ལེན་པ་དང་། ལྷག་པའི་སེམས་ཡང་དག་པར་ལེན་པ་དང་། ལྷག་པའི་ཤེས་རབ་ཡང་དག་པར་ལེན་པའོ།།

Enumeration Block 1:
བསྒྲུབ་པ་ནི་རྣམ་པ་གསུམ་སྟེ། ཡོ་བྱད་ཀྱི་བདེ་བ་བསྒྲུབ་པ་དང་། དགའ་བ་དང་བཅས་པའི་བདེ་བ་བསྒྲུབ་པ༌[^763]དང་། །དགའ་བ་མེད་པའི་བདེ་བ་བསྒྲུབ༌[^764]པའོ། །

Enumeration Block 2:
ཡང་མཐུན་པར་འཇུག་པར་ཁས་བླང་བ་ནི་བཞི་པོ་འདི་དག་ཡིན་ཏེ། འདི་ལྟ་སྟེ། འགྲོན་ལ་མཐུན་པར་འཇུག་པར་ཁས་བླང་བ་དང་། སྐྱེ་བོ་ཡོངས་ལ་མཐུན་པར་འཇུག་པར་ཁས་བླང་བ༌[^765]དང་། བླ་མ་རྣམས་དང་མཐུན་པར་འཇུག་པར་ཁས་བླང་བ་དང་། ཚོགས་པར་འདུ་འོས་ལ་མཐུན་པར་འཇུག་པར༌[^766]ཁས་བླང་བ་སྟེ།

Enumeration Block 3:
མཁས་པ་རྣམས་ཀྱི་མཁས་པའི་མཚན་ཉིད་ནི། གསུམ་པོ་འདི་དག་ཡིན་ཏེ། དགེ་བ་ཡང་དག་པར་ལེན་པ་དང་། དགེ་བ་ལ་གཅིག་ཏུ་ངེས་པ་དང་། དགེ་བ་ལ་བརྟེན་པའོ། །

Enumeration Block 4:
གཞན་ཡང་གསུམ་སྟེ། ལྷག་པའི་ཚུལ་ཁྲིམས་ཡང་དག་པར་ལེན་པ་དང་། ལྷག་པའི་སེམས་ཡང་དག་པར་ལེན་པ་དང་། ལྷག་པའི་ཤེས་རབ་ཡང་དག་པར་ལེན་པའོ།།

Enumeration Block 5:

གཞན་ཡང་སྒོ་བདུན་གྱིས་ཉོན་མོངས་པ་ཐམས་ཅད་མཐོང་བ་དང་། བསྒོམ་པ་ལ་བགེགས་བྱེད་ཅིང་། སྒྲིབ༌པར་བྱེད་པར་གྱུར་པར་རིག་པར་བྱའོ། །འདི་ལྟ་སྟེ། ལོག་པར་རྟོགས་པ་དང་། མ་རྟོགས་པ་དང་། རྟོགས་པ་ཡང་མ་ཡིན་མ་རྟོགས་པ་ཡང་མ་ཡིན་པ་དང་། ལོག་པར་རྟོགས་པས་ལོག་པར་སྒྲུབ་པ་དང་། དེའི་གཞིའི་གནས་རྟེན་དང་། དེ་འཇིགས་པ་བསྐྱེད་པ་དང་། རང་བཞིན་གྱིས་ཀུན་ཏུ་སྤྱོད་པའོ།།

Enumeration Block 2:

Enumeration Block 3:

Enumeration Block 4:
