Enumeration Block 1:
རྣམ་པ་དགུ་སྟེ། སེམས་ཅན་གྱི་གནས་དགུ་པོ་རྣམས་སོ། །
Enumeration Block 2:
རྣམ་པ་བཅུ་གཅིག་སྟེ་སྔ་མ་བཞིན་ནོ། །
Enumeration Block 3:
རྣམ་པ་བཅུ་གཉིས་ནི་སེམས་བཅུ་གཉིས་ཏེ། འདོད་པ་ན་སྤྱོད་པ་དང་། དགེ་བ་དང་། མི་དགེ་བ་དང་། བསྒྲིབས་ལ་ལུང་དུ་མ་བསྟན་པ་དང་། མ་བསྒྲིབས་ལ་ལུང་དུ་མ་བསྟན་པའོ། །
Enumeration Block 4:
གཟུགས་ན་སྤྱོད་པ་རྣམ་པ་གསུམ་སྟེ། མི་དགེ་བ་མ་གཏོགས་པ་དང་། གཟུགས་མེད་པ་ན་སྤྱོད་པ་ཡང་དེ་དང་འདྲ་བ་དང་། འཇིག་རྟེན་ལས་འདས་པ་སློབ་པ༌དང་མི་སློབ་པའོ། །
Enumeration Block 5:
གཟུགས་ནི་རྣམ་པ་གཅིག་སྟེ། མིག་གི་སྤྱོད་ཡུལ་གྱི་དོན་གྱིས་སོ། །
Enumeration Block 6:
རྣམ་པ་གཉིས་ཏེ། ནང་གི་དང་ཕྱི་རོལ་གྱིའོ། །
Enumeration Block 7:
རྣམ་པ་གསུམ་སྟེ། ཁ་དོག་དང་། དབྱིབས་དང་རྣམ་པར་རིག་བྱེད་དོ། །
Enumeration Block 8:
རྣམ་པ་བཞི་སྟེ། རང་གི་རྟེན་སྣང་བར་བྱེད་པ་དང་། རང་གི་རྟེན་སྣང་བར་བྱེད་པ་མ་ཡིན་པ་དང་། བདེ་བ་དང་། བདེ་བ་མ་ཡིན་པར་སྣང་བ་དང་། བསགས་པར་གནས་པའོ། །
Enumeration Block 9:
རྣམ་པ་ལྔ་སྟེ། འགྲོ་བ་ལྔའི་བྱེ་བྲག་གིས་སོ། །
Enumeration Block 10:
རྣམ་པ་དྲུག་སྟེ། གཞིར༌བསྡུས་པ་དང་། གནས་སུ་བསྡུས་པ་དང་། ཡུལ་དུ་བསྡུས་པ་དང་། སེམས་ཅན་དུ་བགྲང་བ་དང་། སེམས་ཅན་དུ་བགྲང་བ་མ་ཡིན་པ་དང་། བསྟན་དུ་ཡོད་ལ་ཐོགས་པ་དང་བཅས་པའོ། །
Enumeration Block 11:
རྣམ་པ་བདུན་ཏེ། ཡོངས་སུ་གཟུང་བ༌རྣམ་པ་བདུན་པོ་དག་གི་བྱེ་བྲག་གིས་སོ། །
Enumeration Block 12:
རྣམ་པ་བརྒྱད་དེ། འཇིག་རྟེན་གྱི་སྣ་ཚོགས་བརྒྱད་དེ། དེ་དག་ཀྱང་ས་ཕྱོགས་སྣ་ཚོགས་དང་། རི་སྣ་ཚོགས་དང་། ཀུན་དགའ་ར་བ་དང་། ནགས་ཚལ་དང་། མཚོ་དང་། མཚེའུ་ལ་སོགས་པ་སྣ་ཚོགས་དང་། ཁང་ཁྱིམ་དང་གཞལ་མེད་ཁང་སྣ་ཚོགས་དང་། ལས་ཀྱི་གནས༌སྣ་ཚོགས་དང་། རི་མོ་བྲི་བ་སྣ་ཚོགས་དང་། བརྡུང་སྦྱར་གྱི་ལས་སྣ་ཚོགས་དང་། ཡོ་བྱད་སྣ་ཚོགས་སོ། །
Enumeration Block 13:
རྣམ་པ་དགུ་སྟེ། འདས་པ་དང་། མ་འོངས་པ་དང་། ད་ལྟར་བྱུང་བ་དང་། རགས་པ་དང་། ཆ་ཕྲ་བའམ། ངན་པའམ། བཟང་པོའམ། གང་རྒྱང་རིང་བའམ། གང་ཐག་ཉེ་བའོ། །
Enumeration Block 14:
རྣམ་པ་བཅུ་སྟེ། ཡོ་བྱད་བཅུ་པོ་རྣམས་སོ། །
Enumeration Block 15:
སྒྲ་ནི་རྣམ་པ་གཅིག་སྟེ། རྣ་བའི་སྤྱོད་ཡུལ་གྱི་དོན་གྱིས་སོ། །
Enumeration Block 16:
རྣམ་པ་གཉིས་ཏེ། གསལ་བའི་དོན་གྱི་སྒྲ་སྐད་དང་། གསལ་བ་མ་ཡིན་པའི་དོན་གྱི་སྒྲ་སྐད་དོ། །
Enumeration Block 17:
རྣམ་པ་གསུམ་སྟེ། ཟིན་པའི་འབྱུང་བ༌ཆེན་པོའི་རྒྱུ་ལས་བྱུང་བ་དང་། མ་ཟིན་པའི་འབྱུང་བ་ཆེན་པོའི་རྒྱུ་ལས་བྱུང་བ་དང་། དེ་གཉི་གའི་འབྱུང་བ་ཆེན་པོའི་རྒྱུ་ལས་བྱུང་བའོ། །
Enumeration Block 18:
རྣམ་པ་བཞི་སྟེ། དགེ་བ་དང་། མི་དགེ་བ་དང་། བསྒྲིབས་ལ་ལུང་དུ་མ་བསྟན་པ་དང་། མ་བསྒྲིབས་ལ་ལུང་དུ་མ་བསྟན་པའོ། །
Enumeration Block 19:
རྣམ་པ་ལྔ་སྟེ། འགྲོ་བ་ལྔའི་བྱེ་བྲག་གིས་སོ། །
Enumeration Block 20:
རྣམ་པ་དྲུག་སྟེ། ལུང་ནོད་པ་དང་། ཁ་ཐོན་བྱེད་པའི་སྒྲ་དང་། ཀུན་དུ་འདྲི་བ་དང་། ཡོངས་སུ་འདྲི་བའི་སྒྲ་དང་། ཆོས་འཆད་པའི་སྒྲ་དང་། འབེལ་བའི་གཏམ་དང་། རྣམ་པར་གཏན་ལ་འབེབས་པའི་སྒྲ་དང་། གཅིག་ལ་གཅིག་ཚིག་གིས་འདེབས་ཤིང་ཉེས་པ་ལས་འབྱིན་པའི་སྒྲ་དང་། འདྲེས་པ་ཅ་ཅོའི་སྒྲའོ། །
Enumeration Block 21:
རྣམ་པ་བདུན་ཏེ། བུད་མེད་ཀྱི་སྒྲ་དང་། སྐྱེས་པའི་སྒྲ་དང་། ཆུང་ངུ་དང་། འབྲིང་དང་། ཆེན་པོ་དང་། རི་དགས་དང་། བྱ་ལ་སོགས་པའི་སྒྲ་དང་། རླུང་དང་ཤིང་གི་སྒྲའོ། །
Enumeration Block 22:
རྣམ་པ་བརྒྱད་དེ། འཕགས་པའི་ཐ་སྙད་བཞི་པོའི་སྒྲ་རྣམས་དང་། འཕགས་པ་མ་ཡིན་པའི་ཐ་སྙད་བཞི་པོའི་སྒྲ་རྣམས་ཏེ། མ་མཐོང་བར་མཐོང་ངོ་ཞེས་སྨྲ༌བ་དང་། མཐོང་བ་ལ་མ་མཐོང་ངོ་ཞེས་སྨྲ་བ་འཕགས་པའི༌ཐ་སྙད་དང་། མ་ཐོས་པ་དང་། བྱེ་བྲག་མ་ཕྱེད་པ་དང་། རྣམ་པར་མ་ཤེས་པར་རྣམ་པར་ཤེས༌སོ་ཞེས་སྨྲ་བ་དང་། རྣམ་པར་ཤེས་པ་ལ་རྣམ་པར་མི༌ཤེས་སོ་ཞེས་སྨྲ་བ་འཕགས་པ་མ་ཡིན་པའི་ཐ་སྙད་དང་། མཐོང་བ་ལ་མཐོང་ཞེས་སྨྲ་བ་དང་། མ་མཐོང་བ་ལ་ཡང་མ་མཐོང་ཞེས་སྨྲ་བ་འཕགས་པའི་ཐ་སྙད་དང་། ཐོས་པ་དང་། བྱེ་བྲག་ཕྱེད་པ་དང་། རྣམ་པར་ཤེས་པ་ལ་རྣམ་པར་ཤེས་སོ་ཞེས་སྨྲ་བ་དང་། རྣམ་པར་མི༌ཤེས་པ་ལ་ཡང་རྣམ་པར་མ་ཤེས་སོ་ཞེས་སྨྲ་བ་འཕགས་པའི་ཐ་སྙད་དོ། །
Enumeration Block 23:
གཞན་ཡང་རྣམ་པ་བརྒྱད་དེ། ངག་གི༌ལས་ཀྱི་ལམ་དགེ་བ་བཞི་དང་། མི་དགེ་བ་བཞིའོ། །
Enumeration Block 24:
རྣམ་པ་དགུ་སྟེ། འདས་པ་དང་། མ་འོངས་པ་དང་། ད་ལྟར་བྱུང་བ་ནས། རྒྱང་རིང་བ་དང་། ཐག་ཉེ་བའི་བར་དག་གོ། །
Enumeration Block 25:
རྣམ་པ་བཅུ་སྟེ། སིལ་སྙན་གྱི་རྣམ་པ་ལྔར་བསྡུས་པ་སྟེ། དེ་ཡང་གར་དང་ལྡན་པ་དང་། གླུ་དང་ལྡན་པ་དང་རོལ་མོའི་སྒྲ་དང་ལྡན་པ་དང་། བུད་མེད་དང་ལྡན་པ་དང་། སྐྱེས་པ་དང་ལྡན་པ་དང་། དུང་གི་སྒྲ་དང་། རྔ་པ་ཊ་ཧའི་སྒྲ་དང་། རྔ་བོ་ཆེའི་སྒྲ་དང་། རྫ་རྔའི་སྒྲ་དང་། སྒྲ་བོ་ཆེའི་སྒྲའོ། །
Enumeration Block 26:
དྲི་ནི་རྣམ་པ་གཅིག་སྟེ། སྣའི་སྤྱོད་ཡུལ་གྱི་དོན་གྱིས་སོ། །
Enumeration Block 27:
རྣམ་པ་གཉིས་ཏེ། ནང་གི་དང་། ཕྱི་རོལ་གྱིའོ། །
Enumeration Block 28:
རྣམ་པ་གསུམ་སྟེ། ཡིད་དུ་འོང་བ་དང་། ཡིད་དུ་མི་འོང་བ་དང་། བཏང་སྙོམས་ཀྱི་གནས་སོ། །
Enumeration Block 29:
རྣམ་པ་བཞི་ནི་དྲི་ཆེན་པོ་རྣམ་པ་བཞི་སྟེ། ཨ་ཀ་རུའི་དྲི་དང་། དུ་རུ་སྐའི༌དྲི་དང་། ག་པུར་གྱི་དྲི་དང་། གླ་རྩིའི་དྲིའོ། །
Enumeration Block 30:
རྣམ་པ་ལྔ་སྟེ། རྩ་བའི་དྲི་དང་། སྙིང་པོའི་དྲི་དང་། ལོ་མའི་དྲི་དང་། མེ་ཏོག་གི་དྲི་དང་། འབྲས་བུའི་དྲིའོ། །
Enumeration Block 31:
རྣམ་པ་དྲུག་སྟེ། ཟས་ཀྱི་དྲི་དང་། སྐོམ་གྱི་དྲི་དང་། གོས་ཀྱི་དྲི་དང་། རྒྱན་གྱི་དྲི་དང་། བཞོན་པའི་དྲི་དང་། གནས་ཀྱི་དྲིའོ། །
Enumeration Block 32:
རྣམ་པ་བདུན་ཏེ། ཤིང་ཚའི༌དྲི་དང་། སྤོས་ལོའི་དྲི་དང་། སུག་སྨེལ་གྱི་དྲི་དང་། ཙན་དན་གྱི་དྲི་དང་། ཚ་བ་གསུམ་གྱི་དྲི་དང་། བདུག་པའི་དྲི་དང་། ཕྱེ་མའི་དྲིའོ། །
Enumeration Block 33:
རྣམ་པ་བརྒྱད་དེ། ལྷན་ཅིག་སྐྱེས་པ་དང་། ལྷན་ཅིག་སྐྱེས་པ་མ་ཡིན་པ་དང་། བརྟན་པ་དང་། བརྟན་པ་མ་ཡིན་པ་དང་། སྦྱར་བ་དང་། འབའ་ཞིག་པ་དང་། དྲི་ཆེ་བ་དང་། དྲི་ཆེ་བ་མ་ཡིན་པའོ། །
Enumeration Block 34:
རྣམ་པ་དགུ་སྟེ། འདས་པ་དང་། མ་འོངས་པ་དང་། ད་ལྟར་བྱུང་བ༌ནས། རྒྱང་རིང་བ་དང་། ཐག་ཉེ་བའི་བར་དག་གོ། །
Enumeration Block 35:
རྣམ་པ་བཅུ་སྟེ། སྐྱེས་པའི་དྲི་དང་། བུད་མེད་ཀྱི་དྲི་དང་། ཕྱི༌སའི་དྲི་དང་། གཅིན་གྱི་དྲི་དང་། ངར་སྣབས༌ཀྱི་དྲི་དང་། སྣབས་ཀྱི་དྲི་དང་། ཞག་དང་། ཆུ་སེར་གྱི་དྲི་དང་། རྣག་དང་། ཁྲག་གི་དྲི་དང་། ཤའི་དྲི་དང་། འདྲེས་པའི་དྲི་དང་། རུལ་པའི་དྲི་དང་། འདམ་རྫབ་ཀྱི་དྲིའོ། །
Enumeration Block 36:
རོ་ནི་རྣམ་པ་གཅིག་སྟེ། ལྕེའི་སྤྱོད་ཡུལ་གྱི་དོན་གྱིས་སོ། །
Enumeration Block 37:
རྣམ་པ་གཉིས་ཏེ། ནང་དང་། ཕྱི་རོལ༌གྱིའོ། །
Enumeration Block 38:
རྣམ་པ་གསུམ་སྟེ། ཡིད་དུ་འོང་བ་ནས་སྔ་མ་བཞིན་ནོ། །
Enumeration Block 39:
རྣམ་པ་བཞི་སྟེ། ནས་ཀྱི་རོ་དང་། སཱ་ལུའི་རོ་དང་། གྲོའི་རོ་དང་། འབྲུ་གཞན་གྱི་རོའོ། །
Enumeration Block 40:
རྣམ་པ་ལྔ་སྟེ། ཆང་གི་རོ་དང་། ཆང་མ་ཡིན་པའི་རོ་དང་། སྔོ་རྔད་ཀྱི་རོ་དང་། ནགས་ཚལ་གྱི་ཤིང་ཐོག་གི་རོ་དང་། ཁ་ཟས་ཀྱི་རོའོ། །
Enumeration Block 41:
རྣམ་པ་དྲུག་སྟེ། ཁ་བ་ལ་སོགས་པའོ། །
Enumeration Block 42:
རྣམ་པ་བདུན་ཏེ། མར་དང་། འབྲུ་མར་དང་། སྦྲང་རྩི་དང་། བུ་རམ་ཤིང་ལས་བྱུང་བའི་རོ་དང་། མངར་བའི་རོ་དང་། ལན་ཚྭའི་རོ་དང་། ཤའི་རོའོ། །
Enumeration Block 43:
རྣམ་པ་བརྒྱད་དེ། །དྲི་བཞིན་ནོ། །
Enumeration Block 44:
རྣམ་པ་དགུ་སྟེ། དྲི་ཁོ་ན་བཞིན་ནོ། །
Enumeration Block 45:
རྣམ་པ་བཅུ་སྟེ། བཅའ་བའི་རོ་དང་། བཟའ་བའི་རོ་དང་། མྱང་བའི་རོ་དང་། བཏུང་བའི་རོ་དང་། གཞིབ༌པའི་རོ་དང་། ཤ་འབྲི་བར་བྱེད་པ་དང་། ཤ་བརྟས་པར༌བྱེད་པ་དང་། ཞི་བར་བྱེད་པ་དང་། སྦྱོང་བར་བྱེད་པ་དང་། བརྟན་པར་བྱ་བའི་སྨན་གྱི་རོ་རྣམས་སོ། །
Enumeration Block 46:
རེག་བྱ་ནི་རྣམ་པ་གཅིག་སྟེ། ལུས་ཀྱི་སྤྱོད་ཡུལ་གྱི་དོན་གྱིས་སོ། །
Enumeration Block 47:
རྣམ་པ་གཉིས་ཏེ། དྲི་བཞིན་ནོ། །
Enumeration Block 48:
རྣམ་པ་གསུམ་སྟེ། ཡིད་དུ་འོང་བ་ལ་སོགས་པའོ། །
Enumeration Block 49:
རྣམ་པ་བཞི་སྟེ། རེག་པར་བྱ་བའི༌རེག་པར་བྱ་བ་དང་། བཙིར་བའི་རེག་པ་དང་། བསྣུན་པའི་རེག་པ་དང་། མཉེ་བའི་རེག་པའོ། །
Enumeration Block 50:
རྣམ་པ་ལྔ་སྟེ། འགྲོ་བ་ལྔའི་བྱེ་བྲག་གིས་སོ། །
Enumeration Block 51:
རྣམ་པ་དྲུག་སྟེ། བདེ་བ་དང་། སྡུག་བསྔལ་བ་དང་། སྡུག་བསྔལ་བ་ཡང་མ་ཡིན་བདེ་བ་ཡང་མ་ཡིན་པ་དང་། ལྷན་ཅིག་སྐྱེས་པ་དང་། མི་མཐུན་པའི་ཕྱོགས་སུ་བསྡུས་པ་དང་གཉེན་པོར་བསྡུས་པའོ། །
Enumeration Block 52:
རྣམ་པ་བདུན་ཏེ། སྲ་བ་དང་། གཤེར་བ་དང་། དྲོ་བ་དང་། གཡོ་བ་དང་། མཆོང་བ་དང་། ལྷུང་བའི་འདུས་ཏེ་རེག་པ་དང་། བྱུག་ནོམ་གྱི་འདུས་ཏེ་རེག་པ་དང་། ལུས་འགྱུར་གྱི་འདུས་ཏེ་རེག་པ་སྟེ། འདི་ལྟ་སྟེ། འཇམ་པ་ལ་སོགས་པ་རྣམས་ལའོ། །
Enumeration Block 53:
རྣམ་པ་བརྒྱད་དེ། །ལག་པའི་འདུས་ཏེ་རེག་པ་དང་། བོང་བའི་འདུས་ཏེ་རེག་པ་དང་། དབྱུག་པའི་འདུས་ཏེ་རེག་པ་དང་། མཚོན་ཆའི་འདུས་ཏེ་རེག་པ་དང་། གྲང་བའི་འདུས་ཏེ་རེག་པ་དང་། ཚ་བའི༌འདུས་ཏེ་རེག་པ་དང་། བཀྲེས་པའི༌འདུས་ཏེ་རེག་པ་དང་། སྐོམ་པའི༌འདུས་ཏེ་རེག་པའོ། །
Enumeration Block 54:
རྣམ་པ་དགུ་སྟེ། དྲི་བཞིན་ནོ། །
Enumeration Block 55:
རྣམ་པ་བཅུ་སྟེ། ཁ་ཟས་ཀྱི་འདུས་ཏེ་རེག་པ་དང་། སྐོམ་པའི་འདུས་ཏེ་རེག་པ་དང་། བཞོན་པའི་འདུས་ཏེ་རེག་པ་དང་། གོས་ཀྱི་འདུས་ཏེ་རེག་པ་དང་། རྒྱན་གྱི་འདུས་ཏེ་རེག་པ་དང་། ཁྲི་དང་ཁྲིའུའི་འདུས་ཏེ་རེག་པ་དང་། སྟན་ནང་ཚངས་ཅན་དང་། ལ་བའི་སྟན༌དང་། སྔས་ནང་ཚངས་ཅན་དང་། གོར་བུའི་འདུས་ཏེ་རེག་པ་དང་། བུད་མེད་ཀྱི་འདུས་ཏེ་རེག་པ་དང་། སྐྱེས་པའི་འདུས་ཏེ་རེག་པ་དང་། དེ་གཉིས་དགའ་མགུར་སྤྱོད་ཅིང་ཡོངས་སུ་སྤྱོད་པའི་འདུས་ཏེ་རེག་པའོ། །
Enumeration Block 56:
ཆོས་ཀྱི་ཁམས་ནི་མདོར་བསྡུ་ན། གདགས་པའི་ཆོས་རྣམས་དང་བཅས་པར་ཆོས་བརྒྱད་ཅུ་རྩ་བདུན་ཡོད་དེ། 
Enumeration Block 57:
ཆོས་ཀྱི་ཁམས་དེ་ཡང་རྣམ་པ་གཅིག་སྟེ། ཡིད་ཀྱི་སྤྱོད་ཡུལ་གྱི་དོན་གྱིས་སོ། །
Enumeration Block 58:
རྣམ་པ་གཉིས་ཏེ། གདགས་པའི་ཆོས་སུ་བསྡུས་པ་དང་། གདགས་པ་མ་ཡིན་པའི་ཆོས་སུ་བསྡུས་པའོ། །
Enumeration Block 59:
རྣམ་པ་གསུམ་སྟེ། གཟུགས་ཅན་དང་། གཟུགས་ཅན་མ་ཡིན་པ་དང་། འདུས་བྱས་དང་། འདུས་མ་བྱས་སོ། །
Enumeration Block 60:
རྣམ་པ་བཞི་སྟེ། གཟུགས་ཅན་གདགས་པའི་ཆོས་སུ་བསྡུས་པ་དང་། གཟུགས་ཅན་མ་ཡིན་པ་སེམས་ལས་འབྱུང་བའི༌ཆོས་སུ་བསྡུས་པ་དང་། གཟུགས་ཅན་མ་ཡིན་པ་དང་ལྡན་ལྡན༌པ་མ་ཡིན་པ་གདགས་པའི་ཆོས་སུ་བསྡུས་པ་དང་། གཟུགས་ཅན་མ་ཡིན་པ་འདུས་མ་བྱས་པ༌གདགས་པའི་ཆོས་སུ་བསྡུས་པའོ། །
Enumeration Block 61:
རྣམ་པ་ལྔ་སྟེ། གཟུགས་དང་། སེམས་ལས་བྱུང་བའི་ཆོས་རྣམས་དང་། སེམས་དང་ལྡན་པ་མ་ཡིན་པ་རྣམས་དང་། འདུས་མ་བྱས་དགེ་བ་དང་། ལུང་དུ་མ་བསྟན་པའོ། །
Enumeration Block 62:
རྣམ་པ་དྲུག་སྟེ། ཚོར་བ་དང་། འདུ་ཤེས་དང་། འདུ་བྱེད་རྣམས་ལས་མཚུངས་པར་ལྡན་པ་རྣམས་དང་ལྡན་པ་མ་ཡིན་པ་རྣམས་དང་། གཟུགས་དང་། འདུས་མ་བྱས་སོ། །
Enumeration Block 63:
རྣམ་པ་བདུན་ཏེ། ཚོར་བ་དང་། འདུ་ཤེས་དང་། སེམས་པ་དང་། ཉོན་མོངས་པ་ཅན་དང་། ཉོན་མོངས་པ་ཅན་མ་ཡིན་པ་དང་། གཟུགས་དང་འདུས་མ་བྱས་སོ། །
Enumeration Block 64:
རྣམ་པ་བརྒྱད་དེ། དགེ་བ་དང་། མི་དགེ་བ་དང་། ལུང་དུ་མ་བསྟན་པ་དང་། ཚོར་བ་དང་། འདུ་ཤེས་དང་། འདུ་བྱེད་རྣམས་དང་། གཟུགས་དང་འདུས༌མ་བྱས་རྣམས་སོ། །
Enumeration Block 65:
རྣམ་པ་དགུ་སྟེ། འདས་པ་དང་། མ་འོངས་པ་ལ་སོགས་པའི་བྱེ་བྲག་གིས་སོ། །
