Enumeration Block 1:
དེ་ནི་ས་བཅུ་བདུན་དུ་བལྟ་བར་བྱ་སྟེ། བཅུ་བདུན་གང་ཞེ་ན།

Enumeration Block 2:
རྣམ་པར་ཤེས་པའི་ཚོགས་ལྔ་སྟེ། ངོ་བོ་ཉིད་དང་། དེ་དག་གི་གནས་དང་། དེ་དག་གི་དམིགས་པ་དང་། དེ་དག་གི་གྲོགས་དང་། དེ་དག་གི་ལས་ནི་མདོར་ན་རྣམ་པར་ཤེས་པའི་ཚོགས་ལྔ་དང་ལྡན་པའི་སའོ། །

Enumeration Block 3:
རྣམ་པར་ཤེས་པའི་ཚོགས་ལྔ་གང་ཞེ་ན། མིག་གི་རྣམ་པར་ཤེས་པ་དང་། རྣ་བ་དང་། སྣ་དང་། ལྕེ་དང་། ལུས་དང་། ཡིད་ཀྱི་རྣམ་པར་ཤེས་པའོ། །

Enumeration Block 4:
དེ་ཡང་མདོར་བསྡུ་ན་གནས་རྣམ་པ་གཉིས་སུ་འགྱུར་རོ། །

Enumeration Block 5:
དེ་ཡང་རྣམ་པ་དུ་མ་ཡོད་དོ། །

Enumeration Block 6:
མདོར་ན་ཁ་དོག་དང་དབྱིབས་དང་རྣམ་པར་རིག་བྱེད་དོ། །

Enumeration Block 7:
ལས་གང་ཞེ་ན། དེ་ནི་རྣམ་པ་དྲུག་ཏུ་བལྟ་བར་བྱ་སྟེ། ཐོག་མ་ཁོ་ནར་དེ་རང་གི་ཡུལ་ལ་དམིགས་པ་རྣམ་པར་རིག་པའི་ཡུལ་ལས་དང་། ཡང་རང་གི་མཚན་ཉིད་རྣམ་པར་རིག་པ་དང་། ཡང་ད་ལྟར་གྱི་དུས་རྣམ་པར་རིག་པ་དང་། ཡང་སྐད་ཅིག་གཅིག་རྣམ་པར་རིག་པ་དང་། ཡང་རྣམ་པ་གཉིས་ཀྱིས་ཡིད་ཀྱི་རྣམ་པར་ཤེས་པའི་རྗེས་སུ་འཇུག་པ་སྟེ། དགེ་བ་ཉོན་མོངས་པ་ཅན་གྱི་རྗེས་སུ་འཇུག་པ་དང་། ལས་ཀུན་ལས་སློང་བའི་རྗེས་སུ་འཇུག་པ་དང་། ཡང་སྡུག་པ་དང་མི་སྡུག་པའི་འབྲས་བུ་ཡོངས་སུ་འཛིན་པ་སྟེ་ལས་དྲུག་པའོ། །
