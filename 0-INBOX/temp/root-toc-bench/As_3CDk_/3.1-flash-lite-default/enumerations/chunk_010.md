Enumeration Block 1:
གཞི་དྲུག་གང་ཞེ་ན།

Enumeration Block 2:
ཡོངས་སུ་གཟུང་བའི་དངོས་པོ་བདུན་གང་ཞེ་ན།

Enumeration Block 3:
ཡོ་བྱད་བཅུ་གང་ཞེ་ན།

Enumeration Block 4:
རྒྱུན་མི་འཆད་པར་རྗེས་སུ་སྤྱད་པ་བརྒྱད་གང་ཞེ་ན།

Enumeration Block 5:
འཇིག་རྟེན་གྱི་སྤྱོད་པ་རྣམ་པ་གསུམ་གང་ཞེ་ན།

Enumeration Block 6:
གཏམ་རྣམ་པ་གསུམ་གང་ཞེ་ན།

Enumeration Block 7:
ཉེས་རྩོམ་རྣམ་པ་ཉི་ཤུ་རྩ་གཉིས་གང་ཞེ་ན།

Enumeration Block 8:
སེམས་ཅན་གྱི་རིས་དྲུག་ཅུ་རྩ་བཞི་གང་ཞེ་ན།

Enumeration Block 9:
དུས་བརྒྱད་གང་ཞེ་ན།

Enumeration Block 10:
མངལ་དུ་འཇུག་པ་བཞི་གང་ཞེ་ན།

Enumeration Block 11:
འཚོ་བ་རྣམ་པ་དྲུག་གང་ཞེ་ན།

Enumeration Block 12:
ཀུན་ནས་སྲུང་བ་རྣམ་པ་དྲུག་གང་ཞེ་ན།

Enumeration Block 13:
སྡུག་བསྔལ་རྣམ་པ་བདུན་གང་ཞེ་ན།

Enumeration Block 14:
ང་རྒྱལ་རྣམ་པ་བདུན་གང་ཞེ་ན།

Enumeration Block 15:
རྒྱགས་པ་རྣམ་པ་བདུན་གང་ཞེ་ན།

Enumeration Block 16:
ཐ་སྙད་བཞི་གང་ཞེ་ན།

Enumeration Block 17:
ཐ་སྙད་ཀྱི་གཞི་མང་པོ་དག་གང་ཞེ་ན།
