Enumeration Block 1:
ཅི་ཆོས་ཀྱི་རང་གི་ངོ་བོ་ཉིད་ལས་སེམས་ཅན་གྱི་བློ་འབྱུང་བའམ་འོན་ཏེ་གཞན་གྱི་ངོ་བོ་ཉིད་ལས་བྱུང་བར་འདོད།
Enumeration Block 2:
ཅི་སེམས་ཅན་དུ་བགྲང་བས་མ་ཡིན་པ་ལ་སེམས་ཅན་དུ་བགྲང་བའི་བློ་འམ། སེམས་ཅན་དུ་བགྲང་བ་ལ་སེམས་ཅན་དུ་བགྲང་བ་མ་ཡིན་པའི་བློ་འམ། དེ་ལས་གཞན་པའི་སེམས་ཅན་དུ་བགྲང་བ་ལ་དེ་ལས་གཞན་པའི་སེམས་ཅན་དུ་བགྲང་བའི་བློ་འབྱུང་བར་འདོད།
Enumeration Block 3:
ཅི་སེམས་ཅན་གྱི་བློ་གང་ཡིན་པ་དེ་མངོན་སུམ་གྱི་དོན་འཛིན་པའམ། འོན་ཏེ་རྗེས་སུ་དཔག་པའི་དོན་འཛིན་པར་འདོད།
Enumeration Block 4:
ཅི་སྤྱོད་པ་བློའི་རྒྱུ་ལས་བྱུང་བའམ། འོན་ཏེ་སེམས་ཅན་གྱི་རྒྱུ་ལས་བྱུང་བར་འདོད།
Enumeration Block 5:
ཅི་སྤྱོད་པའི་རྒྱུ་མི་རྟག་པའམ། འོན་ཏེ་རྟག་པར་འདོད།
Enumeration Block 6:
ཅི་སེམས་ཅན་རྩོལ་བའི་བདག་ཉིད་ཅན་ཞིག་སྤྱོད་པར་འགྱུར་བའམ། འོན་ཏེ་མི་རྩོལ་བའི་བདག་ཉིད་ཅན་ཞིག་སྤྱོད་པར་འདོད།
Enumeration Block 7:
ཅི་རྒྱུ་ཡོད་པས་སེམས་ཅན་སྤྱོད་པའམ། འོན་ཏེ་རྒྱུ་མེད་པར་སྤྱོད་པར་འདོད།
Enumeration Block 8:
ཅི་སེམས་ཅན་རང་དབང་གིས་སྤྱོད་པའམ། འོན་ཏེ་གཞན་གྱི་དབང་གིས་སྤྱོད་པར་འདོད།
Enumeration Block 9:
ཅི་ཕུང་པོ་ཙམ་སེམས་ཅན་དུ་འདོགས་པའམ། འོན་ཏེ་ཕུང་པོ་ལ་ཡོད་པའམ། ཕུང་པོ་རྣམས་དང་ཐ་དད་པའམ། ཕུང་པོ་མེད་པ་ཞིག་ཏུ་འདོད།
Enumeration Block 10:
ཅི་ལྟ་བ་པོ་ལ་སོགས་པའི་མཚན་ཉིད་གཅིག་ཡིན་ནམ། འོན་ཏེ་དེ་དང་ཐ་དད་པའི་མཚན་ཉིད་གཅིག་ཡིན་པར་འདོད།
Enumeration Block 11:
ཅི་གང་ཀུན་ནས་ཉོན་མོངས་པ་དང་། རྣམ་པར་བྱང་བའི་མཚན་ཉིད་དང་ལྡན་པ་དེ། ཀུན་ནས་ཉོན་མོངས་པའམ། རྣམ་པར་བྱང་བར་འགྱུར་རམ། འོན་ཏེ་དེའི་མཚན་ཉིད་དང་མི་ལྡན་པ་དེ་ལྟར་འགྱུར་བར་འདོད།
Enumeration Block 12:
ཅི་གང་འཇུག་པའི་མཚན་ཉིད་དང་ལྡན་པ་དེ་འཇུག་ཀྱང་འཇུག་ལ་ལྡོག་ཀྱང་ལྡོག་པར་འགྱུར་རམ། འོན་ཏེ་དེའི་མཚན་ཉིད་དང་མི་ལྡན་པ་དེ་ལྟར་འགྱུར་བར་འདོད།
Enumeration Block 13:
ཅི་ཡུལ་གྱིས་བསྐྱེད་པའི་བདེ་བ་དང་སྡུག་བསྔལ་བར་འགྱུར་བ་གང་ཡིན་པ་དང་། སེམས་ཀྱིས་འགྱུར་བ་གང་ཡིན་པ་དང་། ཉོན་མོངས་པ་དང་། ཉེ་བའི་ཉོན་མོངས་པ་རྣམས་ཀྱིས་འགྱུར་བ་གང་ཡིན་པ་དེ་ནི་ཟ་བ་པོའམ། བྱེད་པ་པོའམ། གྲོལ་པ་པོར་འདོད་དམ། འོན་ཏེ་མི་འགྱུར་བ་གང་ཡིན་པ་དེ་དེ་ལྟར་འདོད།
Enumeration Block 14:
ཅི་བདག་ཉིད་ལ་བྱེད་པ་པོར་འདོགས་པའམ། འོན་ཏེ་བདག་ལས་གཞན་པ་ལ་ཡང་འདོགས་པར་འདོད།
Enumeration Block 15:
ཅི་བདག་ཉིད་ལ་བདག་ཏུ་འདོགས་པའམ། འོན་ཏེ་གཞན་ལ་ཡང་འདོགས་པར་འདོད།
Enumeration Block 16:
ཅི་བདག་ཏུ་ལྟ་བ་གང་ཡིན་པ་འདི་དགེ་བའམ་མི་དགེ་བར་འདོད།
Enumeration Block 17:
ཅི་བདག་མེད་པར་ལྟ་བ་དགེ་བའམ་མི་དགེ་བ་ཡིན་པར་འདོད།
Enumeration Block 18:
ཅི་བདག་ཉིད་ལ་བདག་ཡོད་དོ་སྙམ་དུ་སེམས་སམ། འོན་ཏེ་བདག་ཏུ་ལྟ་བ་ཡིན་པར་འདོད།
Enumeration Block 19:
ཅི་སྔོན་གྱི་གནས་རྗེས་སུ་དྲན་པ། ཕུང་པོ་འཛིན་པ་ཡིན་ནམ། བདག་འཛིན་པ་ཡིན་པར་འདོད།
Enumeration Block 20:
ཅི་གཟུགས་ལ་དམིགས་ཏེ་མིག་གི་རྣམ་པར་ཤེས་པ་མངོན་སུམ་དུ་གྱུར་ལ། ཡུལ་གཟུགས་ཁོ་ན་དང་ཕྲད་ན། དེ་ལས་གཞན་པའི་ཡུལ་བཀོད་པར་གྱུར་པ་རྣམས་ལ་དེ་ལས་གཞན་པའི་རྣམ་པར་ཤེས་པ་རྣམས་འགགས་པའམ། འཇུག་པར་འདོད།
