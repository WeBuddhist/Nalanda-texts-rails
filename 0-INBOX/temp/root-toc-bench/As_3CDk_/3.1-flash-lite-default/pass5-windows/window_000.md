* 1.1 རྣམ་པར་ཤེས་པའི་ཚོགས་ལྔ་དང་ལྡན་པའི་ས་ [[རྣམ་པར་ཤེས་པའི་ཚོགས་ལྔ་དང་ལྡན་པའི་ས་གང་ཞེ་ན།]]
* 1.1.1 རྣམ་པར་ཤེས་པའི་ཚོགས་ལྔ་ [[རྣམ་པར་ཤེས་པའི་ཚོགས་ལྔ་གང་ཞེ་ན།]]
* 1.1.2 མིག་གི་རྣམ་པར་ཤེས་པ་ [[མིག་གི་རྣམ་པར་ཤེས་པ་གང་ཞེ་ན།]]
* 1.1.2.1 མིག་གི་རྣམ་པར་ཤེས་པའི་གནས་ [[མིག་གི་རྣམ་པར་ཤེས་པའི་གནས་གང་ཞེ་ན།]]
* 1.1.2.2 མིག་གི་རྣམ་པར་ཤེས་པའི་དམིགས་པ་ [[མིག་གི་རྣམ་པར་ཤེས་པའི་དམིགས་པ་གང་ཞེ་ན།]]
* 1.1.2.3 ལས་ [[ལས་གང་ཞེ་ན།]]

* 1.1.4 རྣམ་པ་གསུམ་ [[དེ་ཡང་ཟིན་པའི་འབྱུང་བ་ཆེན་པོའི་རྒྱུ་ལས་བྱུང་བ་དང་།]]
* 1.1.5 རྣལ་འབྱོར་སྤྱོད་པའི་ས་ལས་རྣམ་པར་ཤེས་པའི་ཚོགས་ལྔ་དང་ལྡན་པའི་ས་སྟེ་དང་པོ་ [[རྣལ་འབྱོར་སྤྱོད་པའི་ས་ལས་རྣམ་པར་ཤེས་པའི་ཚོགས་ལྔ་དང་ལྡན་པའི་ས་སྟེ་དང་པོའོ།། །།]]
* 1.2 ཡིད་ཀྱི་ས་ [[ཡིད་ཀྱི་ས་གང་ཞེ་ན།]]

* 1.2.2 དམིགས་པ་ལ་ཇི་ལྟར་ཉེ་བར་སེམས་ [[དམིགས་པ་ལ་ཇི་ལྟར་ཉེ་བར་སེམས་ཤེ་ན།]]
* 1.2.3 རིགས་པས་བསྐྱེད་པ་ [[རིགས་པས་བསྐྱེད་པ་ཇི་ལྟ་བུ་ཞེ་ན།]]
