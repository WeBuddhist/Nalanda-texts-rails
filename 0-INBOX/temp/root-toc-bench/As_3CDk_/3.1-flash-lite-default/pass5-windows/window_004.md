* 1.12.349 དེ་ལ་དག་པའི་ཡོ་བྱད་ [[དེ་ལ་དག་པའི་ཡོ་བྱད་གང་ཞེ་ན། གང་དག་དག་པའི་བསམ་པས་བསྒྲུབས་པ་]]
* 1.12.350 དེ་ལ་གནས་པའི་ཡོ་བྱད་ [[དེ་ལ་གནས་པའི་ཡོ་བྱད་གང་ཞེ་ན། གང་དག་རང་བཞིན་གྱིས་གནས་པ་]]
* 1.12.351 འཕགས་པའི་ནོར་བདུན་པོ་ [[འཕགས་པའི་ནོར་བདུན་པོ་གང་ཞེ་ན། དད་པའི་ནོར་དང་། ཚུལ་ཁྲིམས་ཀྱི་ནོར་]]
* 1.12.352 བཅོ་ལྔ་པོ་ [[བཅོ་ལྔ་པོ་གང་ཞེ་ན། འཇིག་རྟེན་པའི་བདེ་བ་རྣམ་པ་ལྔ་དང་། འཇིག་རྟེན་ལས་]]

* 1.12.354 ལུས་དེ་ལ་སྡུག་བསྔལ་གྱི་ཚོར་བ་འབྱུང་བ་ [[ལུས་དེ་ལ་སྡུག་བསྔལ་གྱི་ཚོར་བ་འབྱུང་བ་གང་ཞེ་ན། གང་དག་ལུས་ཀྱི་སྡུག་བསྔལ་]]
* 1.12.355 ལུས་དེ་ལ་སྡུག་བསྔལ་ཡང་མ་ཡིན་བདེ་བ་ཡང་མ་ཡིན་པའི་ཚོར་བ་འབྱུང་བ་ [[ལུས་དེ་ལ་སྡུག་བསྔལ་ཡང་མ་ཡིན་བདེ་བ་ཡང་མ་ཡིན་པའི་ཚོར་བ་འབྱུང་བ་གང་ཞེ་ན།]]
* 1.12.356 དེ་ལ་འཁྲིག་པའི་ལོངས་སྤྱོད་ [[དེ་ལ་འཁྲིག་པའི་ལོངས་སྤྱོད་གང་ཞེ་ན། འདོད་པ་ན་སྤྱོད་པའི་ལྷ་རྣམས་ཀྱི་]]
* 1.12.357 དེ་ལ་སྐྱེ་བར་འདོགས་པ་རྣམ་པར་གཞག་པ་ [[དེ་ལ་སྐྱེ་བར་འདོགས་པ་རྣམ་པར་གཞག་པ་གང་ཞེ་ན། འདོད་པ་སྐྱེ་བ་དང་། བདེ་བ་]]
* 1.12.358 འདོད་པ་སྐྱེ་བ་རྣམ་པ་གསུམ་ [[འདོད་པ་སྐྱེ་བ་རྣམ་པ་གསུམ་གང་ཞེ་ན། འདོད་པ་ན་སྤྱོད་པ་དང་། གཟུགས་ན་སྤྱོད་པ་]]
* 1.12.359 བདེ་བ་སྐྱེ་བ་རྣམ་པ་གསུམ་ [[བདེ་བ་སྐྱེ་བ་རྣམ་པ་གསུམ་གང་ཞེ་ན། འདོད་པ་ན་སྤྱོད་པ་དང་། གཟུགས་ན་སྤྱོད་པ་]]
* 1.12.360 ལུས་ཐོབ་པ་རྣམ་པ་བཞི་ [[ལུས་ཐོབ་པ་རྣམ་པ་བཞི་གང་ཞེ་ན། མངལ་ནས་སྐྱེ་བ་དང་། སྒོང་སྐྱེ་དང་།]]
* 1.12.361 རྒྱུ་དང་རྐྱེན་དང་འབྲས་བུ་རྣམ་པར་གཞག་པ་རྣམ་པ་བཞི་ [[རྒྱུ་དང་རྐྱེན་དང་འབྲས་བུ་རྣམ་པར་གཞག་པ་རྣམ་པ་བཞི་གང་ཞེ་ན། རྒྱུའི་གནས་དང་།]]
* 1.12.362 རྒྱུ་དང་རྐྱེན་དང་འབྲས་བུའི་རབ་ཏུ་དབྱེ་བ་ [[རྒྱུ་དང་རྐྱེན་དང་འབྲས་བུའི་རབ་ཏུ་དབྱེ་བ་གང་ཞེ་ན། དེ་ལ་རྒྱུའི་གནས་དང་།]]
* 1.12.363 དེ་ལ་རྒྱུའི་གནས་ཚིག་ལ་བརྟེན་ནས [[དེ་ལ་རྒྱུའི་གནས་ཚིག་ལ་བརྟེན་ནས་སྐྱེ་བ་གང་ཞེ་ན། སེམས་ཅན་རྣམས་ཀྱི་རྒྱུ་]]

* 1.12.365 དེ་ལ་རྒྱུའི་གནས་བག་ཆགས་ལ་བརྟེན་ནས [[དེ་ལ་རྒྱུའི་གནས་བག་ཆགས་ལ་བརྟེན་ནས་སྐྱེ་བ་གང་ཞེ་ན། གང་དག་ལས་ཀྱི་ས་]]
* 1.12.366 དེ་ལ་རྒྱུའི་གནས་རླན་དང་བཅས་པའི་ས་བོན་ལ་བརྟེན་ནས [[དེ་ལ་རྒྱུའི་གནས་རླན་དང་བཅས་པའི་ས་བོན་ལ་བརྟེན་ནས་སྐྱེ་བ་གང་ཞེ་ན། གང་དག་]]
* 1.12.367 དེ་ལ་རྒྱུའི་གནས་ཕྲད་ནས་འགགས་པ་ལ་ཡང་བརྟེན་ལ [[དེ་ལ་རྒྱུའི་གནས་ཕྲད་ནས་འགགས་པ་ལ་ཡང་བརྟེན་ལ་སྐྱེ་བ་གང་ཞེ་ན། གང་དག་]]
* 1.12.368 དེ་ལ་རྒྱུའི་གནས་མཐུན་པ་ལ་བརྟེན་ནས [[དེ་ལ་རྒྱུའི་གནས་མཐུན་པ་ལ་བརྟེན་ནས་སྐྱེ་བ་གང་ཞེ་ན། གང་དག་ལུས་ཀྱི་དང་། ངག་]]
