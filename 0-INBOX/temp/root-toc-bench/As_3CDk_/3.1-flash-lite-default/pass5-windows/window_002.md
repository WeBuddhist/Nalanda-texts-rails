* 1.12.213 ཉོན་མོངས་པ་རྣམས་ཀྱི་གནས་སྐབས་ [[འོག་ཏུ་ཡང་འགྲོ་སྟེ་བསྐོལ༌[^566]ཞིང་འཚེད་པ་ནི་དཔེར་ན་ཟངས་ཆུས་བཀང་ལ་མེ་ཆེན་པོ་ཤིན་ཏུ་སྦར་བའི་ནང་དུ་མོན་སྲན་སྡེའུ་དང་།]]
