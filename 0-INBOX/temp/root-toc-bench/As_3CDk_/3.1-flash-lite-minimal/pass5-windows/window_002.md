* 201.1 ལུས་ཐོབ་པ་གང་བདག་ཉིད་ཀྱི་སེམས་ཀྱིས་འཕོ་བར་འགྱུར་ལ། གཞན་གྱི་སེམས་ཀྱིས་མ་ཡིན་པ་ [[འདི་ལྟ་སྟེ། འདོད་པའི་ཁམས་ན་ལྷ་རྩེད་མོས་མྱོས་པ་ཞེས་བྱ་བ་དག་ཡོད་དེ། དེ་དག་གང་གི་ཚེ་ཧ་ཅང་རྩེ་བ་དང་། དགའ་བ་དང་། བརྒྱན་པའི་གནས་ཀྱི་སྦྱོར་བ་དང་ལྡན་པར་གནས་པ་ན།]]
* 201.2 ལུས་འཐོབ་པ་གང་གཞན་གྱི་སེམས་ཀྱིས་འཕོ་བར་འགྱུར་ལ། བདག་གི་སེམས་ཀྱིས་མ་ཡིན་པ་ [[འདི་ལྟ་སྟེ། སེམས་ཅན་མའི་མངལ་ན་གནས་པ་མེར་མེར་པོར་གྱུར་པ་རྣམས་དང་། ནུར་ནུར་པོར་གྱུར་པ་རྣམས་དང་། མཁྲང་གྱུར་པ་རྣམས་དང་། ལྟར་ལྟར་པོར་གྱུར་པ་རྣམས་སོ། །]]
* 201.3 ལུས་ཐོབ་པ་གང་བདག་ཉིད་ཀྱི་སེམས་ཀྱིས་ཀྱང་འཕོ་བར་འགྱུར་ལ། གཞན་གྱི་སེམས་ཀྱིས་ཀྱང་འཕོ་བར་འགྱུར་བ་ [[འདི་ལྟ་སྟེ། དེ་དག་ཉིད་སྐྱེས་པ་དང་། དབང་པོ་ཡོངས་སུ་རྫོགས་པ་དང་། དབང་པོ་ཡོངས་སུ་སྨིན་པ་རྣམས་སོ། །]]
* 201.4 ལུས་འཐོབ་པ་གང་བདག་ཉིད་ཀྱི་སེམས་ཀྱིས་ཀྱང་འཕོ་བར་མི་འགྱུར་ལ། གཞན་གྱི་སེམས་ཀྱིས་ཀྱང་འཕོ་བར་མི་འགྱུར་བ་ [[འདི་ལྟ་སྟེ། གཟུགས་དང་གཟུགས་མེད་པ་ན་སྤྱོད་པའི་ལྷ་རྣམས་དང་། སེམས་ཅན་དམྱལ་བ་ཐམས་ཅད་དང་།]]
