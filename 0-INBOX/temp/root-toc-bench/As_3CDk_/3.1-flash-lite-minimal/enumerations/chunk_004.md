Enumeration Block 1:
དེ་ལ་ཡང་རྣམ་པ་གཉིས་ཏེ། ཤིན་ཏུ་ཚབས་ཆེ་བ་དང་། ཤིན་ཏུ་ཚབས་ཆུང་བ་སྟེ། 

Enumeration Block 2:
དེ་ལ་བརྟེན་ནས་ཡིད་སྐྱེ་བའི་གནས་སུ་འགྲོ་བས་ན་ཡིད་ལས་བྱུང་བ་ཞེས་ཀྱང་བྱ་སྟེ། 

Enumeration Block 3:
གལ་ཏེ་བར་དུ་གཅོད་པ་རྣམ་པ་གསུམ་པོ་སྐྱེ་གནས་ཀྱི་ཉེས་པས་གྱུར་པ་དང་། ས་བོན་གྱི་ཉེས་པས་གྱུར་པ་དང་། ལས་ཀྱི་ཉེས་པས་གྱུར་པ་རྣམས་མེད་ན། 

Enumeration Block 4:
དེ་ལ་སྐྱེ་གནས་ཀྱི་ཉེས་པ་གང་ཞེ་ན།

Enumeration Block 5:
ས་བོན་གྱི་ཉེས་པ་གང་ཞེ་ན།

Enumeration Block 6:
ལས་ཀྱི་ཉེས་པ་གང་ཞེ་ན།

Enumeration Block 7:
ཇི་ལྟར་འཇུག་པར་འགྱུར་ཞེ་ན།
