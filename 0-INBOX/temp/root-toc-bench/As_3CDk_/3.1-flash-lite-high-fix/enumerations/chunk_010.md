Enumeration Block 1:
གཞི་དྲུག་གང་ཞེ་ན།

Enumeration Block 2:
དེ་དག་ཀྱང་ཟས་རྣམ་པ་བཞི་སྟེ། ཁམ་གྱི་ཟས་དང་། རེག་པ་དང་། ཡིད་ལ་སེམས་པ་དང་། རྣམ་པར་ཤེས་པའི་ཟས་ཏེ།

Enumeration Block 3:
ཡོངས་སུ་གཟུང་བའི་དངོས་པོ་བདུན་གང་ཞེ་ན།

Enumeration Block 4:
ཡོ་བྱད་བཅུ་གང་ཞེ་ན།

Enumeration Block 5:
རྒྱུན་མི་འཆད་པར་རྗེས་སུ་སྤྱད་པ་བརྒྱད་གང་ཞེ་ན།

Enumeration Block 6:
འཇིག་རྟེན་གྱི་སྤྱོད་པ་རྣམ་པ་གསུམ་གང་ཞེ་ན།

Enumeration Block 7:
གཏམ་རྣམ་པ་གསུམ་གང་ཞེ་ན།

Enumeration Block 8:
ཉེས་རྩོམ་རྣམ་པ་ཉི་ཤུ་རྩ་གཉིས་གང་ཞེ་ན།

Enumeration Block 9:
སེམས་ཅན་གྱི་རིས་དྲུག་ཅུ་རྩ་བཞི་གང་ཞེ་ན།

Enumeration Block 10:
འཁོར་ལོས་སྒྱུར་བ་དེ་དག་ཀྱང་། གླིང་གཅིག་ལ་དབང་བ་རྣམས་དང་། གླིང་གཉིས་ལ་དབང་བ་རྣམས་དང་། གླིང་གསུམ་ལ་དབང་བ་རྣམས་དང་། གླིང་བཞི་ལ་དབང་བ་རྣམས་ཏེ།

Enumeration Block 11:
དུས་བརྒྱད་གང་ཞེ་ན།

Enumeration Block 12:
མངལ་དུ་འཇུག་པ་བཞི་གང་ཞེ་ན།

Enumeration Block 13:
འཚོ་བ་རྣམ་པ་དྲུག་གང་ཞེ་ན།

Enumeration Block 14:
ཀུན་ནས་སྲུང་བ་རྣམ་པ་དྲུག་གང་ཞེ་ན།

Enumeration Block 15:
སྡུག་བསྔལ་རྣམ་པ་བདུན་གང་ཞེ་ན།

Enumeration Block 16:
ང་རྒྱལ་རྣམ་པ་བདུན་གང་ཞེ་ན།

Enumeration Block 17:
རྒྱགས་པ་རྣམ་པ་བདུན་གང་ཞེ་ན།

Enumeration Block 18:
ཐ་སྙད་བཞི་གང་ཞེ་ན།

Enumeration Block 19:
མཐོང་བའི་ཐ་སྙད་གང་ཞེ་ན།

Enumeration Block 20:
ཐོས་པའི་ཐ་སྙད་གང་ཞེ་ན།

Enumeration Block 21:
བྱེ་བྲག་ཕྱེད་པའི་ཐ་སྙད་གང་ཞེ་ན།

Enumeration Block 22:
རྣམ་པར་ཤེས་པའི་ཐ་སྙད་གང་ཞེ་ན།

Enumeration Block 23:
ཐ་སྙད་ཀྱི་གཞི་མང་པོ་དག་གང་ཞེ་ན།
