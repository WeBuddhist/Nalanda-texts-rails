རྣམ་པ་བཞི་སྟེ། གཟུགས་ཅན་གདགས་པའི་ཆོས་སུ་བསྡུས་པ་དང་། གཟུགས་ཅན་མ་ཡིན་པ་སེམས་ལས་འབྱུང་བའི༌[^451]ཆོས་སུ་བསྡུས་པ་དང་། གཟུགས་ཅན་མ་ཡིན་པ་དང་ལྡན་ལྡན༌[^452]པ་མ་ཡིན་པ་གདགས་པའི་ཆོས་སུ་བསྡུས་པ་དང་། གཟུགས་ཅན་མ་ཡིན་པ་འདུས་མ་བྱས་པ༌[^453]གདགས་པའི་ཆོས་སུ་བསྡུས་པའོ། །

Enumeration Block 5:
རྣམ་པ་ལྔ་སྟེ། གཟུགས་དང་། སེམས་ལས་བྱུང་བའི་ཆོས་རྣམས་དང་། སེམས་དང་ལྡན་པ་མ་ཡིན་པ་རྣམས་དང་། འདུས་མ་བྱས་དགེ་བ་དང་། ལུང་དུ་མ་བསྟན་པའོ། །

Enumeration Block 6:
རྣམ་པ་དྲུག་སྟེ། ཚོར་བ་དང་། འདུ་ཤེས་དང་། འདུ་བྱེད་རྣམས་ལས་མཚུངས་པར་ལྡན་པ་རྣམས་དང་ལྡན་པ་མ་ཡིན་པ་རྣམས་དང་། གཟུགས་དང་། འདུས་མ་བྱས་སོ། །

Enumeration Block 7:
རྣམ་པ་བདུན་ཏེ། ཚོར་བ་དང་། འདུ་ཤེས་དང་། སེམས་པ་དང་། ཉོན་མོངས་པ་ཅན་དང་། ཉོན་མོངས་པ་ཅན་མ་ཡིན་པ་དང་། གཟུགས་དང་འདུས་མ་བྱས་སོ། །

Enumeration Block 8:
རྣམ་པ་བརྒྱད་དེ། དགེ་བ་དང་། མི་དགེ་བ་དང་། ལུང་དུ་མ་བསྟན་པ་དང་། ཚོར་བ་དང་། འདུ་ཤེས་དང་། འདུ་བྱེད་རྣམས་དང་། གཟུགས་དང་འདུས༌[^454]མ་བྱས་རྣམས་སོ། །

Enumeration Block 9:
རྣམ་པ་དགུ་སྟེ། འདས་པ་དང་། མ་འོངས་པ་ལ་སོགས་པའི་བྱེ་བྲག་གིས་སོ། །

Enumeration Block 10:
དངོས་པོ་དགུ་གང་ཞེ་ན། སེམས་ཅན་གྱི་དངོས་པོ་དང་། ལོངས་སྤྱོད་ཀྱི་དངོས་པོ་དང་། སྐྱེ་བའི་དངོས་པོ་དང་། གནས་པའི་དངོས་པོ་དང་། ཀུན་ནས་ཉོན་མོངས་པ་དང་། རྣམ་པར་བྱང་བའི་དངོས་པོ་དང་། སྣ་ཚོགས་ཀྱི་དངོས་པོ་དང་། སྟོན་པ་པོའི་དངོས་པོ་དང་། བསྟན་པར་བྱ་བའི་དངོས་པོ་དང་། འཁོར་གྱི་དངོས་པོའོ། །

Enumeration Block 11:
འཁོར་གྱི་དངོས་པོ་ནི་འཁོར༌[^469]བརྒྱད་དེ། རྒྱལ་རིགས་ཀྱི་འཁོར་དང་། བྲམ་ཟེའི་འཁོར་དང་། ཁྱིམ་བདག་གི་འཁོར་དང་། དགེ་སྦྱོང་གི་འཁོར་དང་། རྒྱལ་ཆེན་བཞིའི་རིས་ཀྱི་འཁོར་དང་། སུམ་ཅུ་རྩ་གསུམ་པའི་འཁོར་དང་། བདུད་ཀྱི༌[^470]རིས་ཀྱི་འཁོར་དང་། ཚངས་པའི་འཁོར་ཏོ། །

Enumeration Block 12:
ས་གསུམ་པོ་འདི་དག་ནི། ཁམས་གདགས་པ་རྣམ་པར་གཞག་པ་དང་། མཚན་ཉིད་གདགས་པ་རྣམ་པར་གཞག་པ་དང་། ཚུལ་བཞིན་ཡིད་ལ་བྱེད་པ་གདགས་པ་རྣམ་པར་གཞག་པ་དང་། ཚུལ་བཞིན་མ་ཡིན་པ་ཡིད་ལ་བྱེད་པ་གདགས་པ་རྣམ་པར་གཞག་པ་དང་། ཀུན་ནས་ཉོན་མོངས་པ་གདགས་པ་རྣམ་པར་གཞག་པས་རྣམ་པར་གཞག་པར་རིག་པར་བྱའོ། །

Enumeration Block 13:
ཁམས་གདགས་པ་རྣམ་པར་གདགས་པ་གང་ཞེ་ན། དེ་ནི་རྣམ་པ་བརྒྱད་དུ་རིག་པར་བྱ་སྟེ། གྲངས་རྣམ་པར་གཞག་པ་དང་། གནས་གཞན་རྣམ་པར་གཞག་པ་དང་། སེམས་ཅན་གྱི་ཚད་རྣམ་པར་གཞག་པ་དང་། སེམས་ཅན་དེ་དག་ཉིད་ཀྱི་ཚེའི་ཚད་རྣམ་པར་གཞག་པ་དང་། སེམས་ཅན་དེ་དག་ཉིད་ཀྱི་ལོངས་སྤྱོད་དང་། ཡོངས་སུ་སྤྱོད་པ་རྣམ་པར་གཞག་པ་དང་། སྐྱེ་བ་རྣམ་པར་གཞག་པ་དང་། ལུས་རྣམ་པར་གཞག་པ་དང་། རྒྱུ་དང་རྐྱེན་རྣམ་པར་གཞག་པའོ། །

Enumeration Block 14:
ཁམས་ནི་གསུམ་སྟེ། འདོད་པའི་ཁམས་དང་། གཟུགས་ཀྱི་ཁམས་དང་། གཟུགས་མེད་པའི་ཁམས་ཏེ།

Enumeration Block 15:
སེམས་ཅན་དམྱལ་བ་ཆེན་པོའི་གནས་བརྒྱད་ལ་འདི་ལྟ་སྟེ། ཡང་སོས་དང་། ཐིག་ནག་དང་། བསྡུས༌[^478]འཇོམས་དང་། ངུ་འབོད་དང་། ངུ་འབོད་ཆེན་པོ་དང་། ཚ་བ་དང་། རབ་ཏུ་ཚ་བ་དང་། མནར་མེད་པའོ། །

Enumeration Block 16:
གྲང་བའི་སེམས་ཅན་དམྱལ་བའི་གནས་བརྒྱད་ཡོད་པ༌[^480]འདི་ལྟ་སྟེ། ཆུ་བུར་ཅན་དང་། ཆུ་བུར་རྡོལ་པ་དང་། སོ་ཐམས་ཐམས་པ་དང་། ཀྱི་ཧུད་ཟེར་བ་དང་། ཨ་ཅུ་ཟེར་བ་དང་། ཨུཏྤལ་ལྟར་གས་པ་དང་། པད་མ་ལྟར་གས་པ་དང་། པད་མ་ལྟར་གས་པ་ཆེན་པོའོ། །

Enumeration Block 17:
འདོད་པ་ན་སྤྱོད་པའི་ལྷ་རྣམ་པ་དྲུག་ལ། རྒྱལ་ཆེན་བཞིའི་རིས༌[^482]དང་། སུམ་ཅུ་རྩ་གསུམ་དང་། འཐབ་བྲལ་དང་། དགའ་ལྡན་དང་། འཕྲུལ་དགའ་དང་། གཞན་འཕྲུལ་དབང་བྱེད་ཀྱི་ལྷ་རྣམས་སོ། །

Enumeration Block 1:
ཡི་དགས་རྣམས་ནི་མདོར་བསྡུ་ན་རྣམ་པ་གསུམ་སྟེ། ཟས་དང་སྐོམ་ལ་ཕྱི་རོལ་གྱི་སྒྲིབ་པ་ཡོད་པ་དང་། ཟས་དང༌[^580]སྐོམ་ལ་ནང་གི་སྒྲིབ་པ་ཡོད་པ་དང་། ཟས་དང་སྐོམ་ལ་སྒྲིབ་པ་ཡོད་པའོ། །

Enumeration Block 1:
ཡང་བདེ་བ་ནི་རྣམ་པ་གཉིས་ཏེ། འཕགས་པ་མ་ཡིན་པའི་ནོར་ལས་བྱུང་བ་དང་། འཕགས་པའི་ནོར་ལས་བྱུང་བའོ། །

Enumeration Block 1:
ཡང་བདེ་བ་ནི་རྣམ་པ་གཉིས་ཏེ། འཕགས་པ་མ་ཡིན་པའི་ནོར་ལས་བྱུང་བ་དང་། འཕགས་པའི་ནོར་ལས་བྱུང་བའོ། །

Enumeration Block 2:
དེ་ལ་འཕགས་པ་མ་ཡིན་པའི་ནོར་ལས་བྱུང་བའི་བདེ་བ་ནི། ཡོ་བྱད་རྣམ་པ་བཞི་པོ་དགའ་བའི་ཡོ་བྱད་དང་། ལྟ་བའི་ཡོ་བྱད་དང་། དག་པའི་ཡོ་བྱད་དང་། གནས་པའི་ཡོ་བྱད་ལ་བརྟེན་ནས་བྱུང་བའོ། །

Enumeration Block 3:
དེ་ལ་འཕགས་པའི་ནོར་ལས་བྱུང་བའི་བདེ་བ་ནི། འཕགས་པའི་ནོར་བདུན་པོ་དད་པའི་ནོར་དང་། ཚུལ་ཁྲིམས་ཀྱི་ནོར་དང་། ངོ་ཚ་ཤེས་པའི་ནོར་དང་། ཁྲེལ་ཡོད་པའི་ནོར་དང་། ཐོས་པའི་ནོར་དང་། གཏོང་བའི་ནོར་དང་། ཤེས་རབ་ཀྱི་ནོར་ལ༌[^648]བརྟེན་ནས་བྱུང༌[^649]བའོ། །

Enumeration Block 4:
དེ་ལ་འཕགས་པའི་ནོར་ལས་བྱུང་བའི་བདེ་བ་ནི། འཕགས་པ་མ་ཡིན་པའི་ནོར་ལས་བྱུང་བའི་བདེ་བ་ལས་རྣམ་པ་བཅོ་ལྔས་ཁྱད་པར་དུ་འཕགས་ཏེ། བཅོ་ལྔ་པོ་གང་ཞེ་ན།

Enumeration Block 5:
ཡང་འཕགས་པ་ཤེས་རབ་ཀྱིས་འཚོ་བ་རྣམས་ཀྱི་ཆོས་ཀྱི༌[^658]ལོངས་སྤྱོད་ནི་ཕྱི་རོལ་གྱི་འདོད་པ་ཅན་རྣམས་ཀྱི་འདོད་པའི་ལོངས་སྤྱོད་ལས་རྣམ་པ་ལྔས་ཁྱད་པར་དུ་འཕགས་ཏེ། དེས་ན་འཕགས་པ་ཤེས་རབ་ཀྱིས་འཚོ་བ་རྣམས་ལ་བླ་ན་མེད་པའི་ཤེས་རབ་ཀྱིས་འཚོ་བས་འཚོ་བ་ཞེས་བྱ་སྟེ། ཆོས་ཀྱི་ལོངས་སྤྱོད་ཀུན་ནས་ཉོན་མོངས་པ་མ་ཡིན་པ་དང་། ཆོས་ཀྱི་ལོངས་སྤྱོད་གཏན་དུ་ངེས་པ་དང་། ཆོས་ཀྱི་ལོངས་སྤྱོད་གཅིག་ཏུ་ངེས་པ༌[^659]དང་། ཆོས་ཀྱི་ལོངས་སྤྱོད་ཤེས་རབ་ཀྱིས་འཚོ་བ་དང་། དེ་ལས་གཞན་པའི་ཤེས་རབ་ཀྱིས་འཚོ་བ་རྣམས་དང་། ཐུན་མོང་མ་ཡིན་པ་དང་། ཆོས་ཀྱི་ལོངས་སྤྱོད་བདེ་བ་ཡོངས་སུ་རྫོགས་པ་བདུད་དང་ཕྱིར་རྒོལ་བ་ངེས་པར་བཅོམ་པའི་ཕྱིར་རོ། །

Enumeration Block 6:
དེ་ལ་སྐྱེ་བར་འདོགས་པ་རྣམ་པར་གཞག་པ་ནི་འདི་ཡིན་ཏེ། འདི་ལྟ་སྟེ། འདོད་པ་སྐྱེ་བ་རྣམ་པ་གསུམ་པོ་རྣམས་ཏེ། སེམས་ཅན་གང་དག་འདོད་པ་ཉེ་བར་གནས་པར་གྱུར་ལ། འདོད་པ་ཉེ་བར་གནས་པར་གྱུར་པ་དག་གིས། དབང་ཕྱུག་ལ་དབང་བྱེད་པ་དག་ཀྱང་ཡོད་དོ། ། དེ་དག་ཀྱང་གང་ཞེ་ན།

Enumeration Block 1:
དེ་ལ་རྒྱུ་དང་རྐྱེན་དང་འབྲས་བུ་རྣམ་པར་གཞག་པ་ནི་རྣམ་པ་བཞིར་རིག་པར་བྱ་སྟེ། མཚན་ཉིད་དང་། གནས་དང་། རབ་ཏུ་དབྱེ་བ་དང་། རྣམ་པར་གཞག་པའོ། །

Enumeration Block 2:
རྒྱུ་དང་རྐྱེན་དང་འབྲས་བུའི་རབ་ཏུ་དབྱེ་བ་གང་ཞེ་ན། རྒྱུ་བཅུ་དང་། རྐྱེན་བཞི་དང་། འབྲས་བུ་ལྔའོ། །རྒྱུ་བཅུ་པོ་དག་གང་ཞེ་ན། རྗེས་སུ་ཐ་སྙད་འདོགས་པའི་རྒྱུ་དང་། ལྟོས་པའི་རྒྱུ་དང་། འཕེན་པའི་རྒྱུ་དང་། མངོན་པར་འགྲུབ་པའི༌[^711]རྒྱུ་དང་། ཡོངས་སུ་འཛིན་པའི་རྒྱུ་དང་། འདྲེན་པའི་རྒྱུ་དང་། སོ་སོར་ངེས་པའི་རྒྱུ་དང་། ལྷན་ཅིག་བྱེད་པའི་རྒྱུ་དང་། མི་མཐུན་པའི་རྒྱུ་དང་། མི་མཐུན་པ་མེད་པའི་རྒྱུའོ། །རྐྱེན་བཞི་པོ་དག་གང་ཞེ་ན། རྒྱུའི་རྐྱེན་དང་། མཚུངས་པ་དེ་མ་ཐག་པའི་རྐྱེན་དང་། དམིགས་པའི་རྐྱེན་དང་། བདག་པོའི་རྐྱེན་ཏོ། །འབྲས་བུ་ལྔ་པོ་དག་གང་ཞེ་ན། རྣམ་པར་སྨིན་པའི་འབྲས་བུ་དང་། རྒྱུ་མཐུན་པའི་འབྲས་བུ་དང་། བྲལ་བའི་འབྲས་བུ་དང་། སྐྱེས་བུ་བྱེད་པའི་འབྲས་བུ་དང་། བདག་པོའི་འབྲས་བུའོ། །

Enumeration Block 1:
ཡང་རྒྱུ་ནི་རྣམ་པ་ལྔར་གཞག་པ་ཡིན་ཏེ། འདི་ལྟ་སྟེ། སྐྱེད་པའི་རྒྱུ་དང་། ཐབས་ཀྱི་རྒྱུ་དང་། ལྷན་ཅིག་བྱུང་བའི་རྒྱུ་དང་། འགགས་མ་ཐག་པ་དང་། འགགས་ནས་རིང་དུ་ལོན་པའོ། །

Enumeration Block 2:
གཞན་ཡང་རྒྱུ་ནི་རྣམ་པ་ལྔར་གཞག་པ་ཡིན་ཏེ། འདི་ལྟ་སྟེ། སྡུག་པའི་རྒྱུ་དང་། མི་སྡུག་པའི་རྒྱུ་དང་། ལྟ་བའི་རྒྱུ་དང་། འཇུག་པའི་རྒྱུ་དང་། ལྡོག་པའི་རྒྱུའོ། །

Enumeration Block 3:
གཞན་ཡང་རྒྱུ་ནི་རྣམ་པ་བདུན་དུ་གཞག་པ་ཡིན་ཏེ།

Enumeration Block 4:
དེ་ལ་མཚན་ཉིད་གདགས་པ་རྣམ་པར་གཞག་པ་གང་ཞེ་ན། དེ་ནི་རྣམ་པ་བདུན་དུ་རིག་པར་བྱ་སྟེ། ལུས་དང་དམིགས་པ་དང་། རྣམ་པ་དང་། ཀུན་ནས་སློང་བ་དང་། རབ་ཏུ་དབྱེ་བ་དང་། རྣམ་པར་ངེས་པ་དང་། འཇུག་པའོ། །

Enumeration Block 1:
གཞན་ཡང་རྒྱུ་ནི་རྣམ་པ་ལྔར་གཞག་པ་ཡིན་ཏེ། འདི་ལྟ་སྟེ། སྡུག་པའི་རྒྱུ་དང་། མི་སྡུག་པའི་རྒྱུ་དང་། ལྟ་བའི་རྒྱུ་དང་། འཇུག་པའི་རྒྱུ་དང་། ལྡོག་པའི་རྒྱུའོ། །

Enumeration Block 2:
དེ་ལ་མཚན་ཉིད་གདགས་པ་རྣམ་པར་གཞག་པ་གང་ཞེ་ན། དེ་ནི་རྣམ་པ་བདུན་དུ་རིག་པར་བྱ་སྟེ། ལུས་དང་དམིགས་པ་དང་། རྣམ་པ་དང་། ཀུན་ནས་སློང་བ་དང་། རབ་ཏུ་དབྱེ་བ་དང་། རྣམ་པར་ངེས་པ་དང་། འཇུག་པའོ། །

Enumeration Block 3:
རབ་ཏུ་དབྱེ་བ་རྣམ་པ་བདུན་ཏེ། མཚན་མ་ཅན་དང་། མཚན་མ་ཅན་མ་ཡིན་པ་ནས། ཉོན་མོངས་པ་ཅན་མ་ཡིན་པའི་བར་དུ༌[^737]སྔ་མ་བཞིན་ནོ། །

Enumeration Block 4:
དེ་ལ་ཚུལ་བཞིན་ཡིད་ལ་བྱེད་པ་གདགས་པ་རྣམ་པར་གཞག་པ་གང་ཞེ་ན། དེ་ནི་རྣམ་པ་བརྒྱད་དུ་རིག་པར་བྱ་སྟེ། གནས་དང་དངོས་པོ་དང་། ཚོལ་བ་དང་། ལོངས་སྤྱོད་པ་དང་། ཡང་དག་པར་འགྲུབ་པ་དང་། ཉན་ཐོས་ཀྱི་ཐེག་པའི་ཚོགས་ལ་སྦྱོར་བ་དང་། རང་སངས་རྒྱས་ཀྱི་ཐེག་པའི་ཚོགས་ལ་སྦྱོར་བ་དང་། ཕ་རོལ་ཏུ་ཕྱིན་པ་བསྒྲུབ་པ་ལ་སྦྱོར་བའོ། །

Enumeration Block 5:
གནས་རྣམ་པ་དྲུག་སྟེ། འདི་ལྟ་སྟེ། ངེས་པའི་དུས་དང་། ལྡོག་པའི་དུས་དང་། ལས་ཀྱི་དུས་དང་། འཇིག་རྟེན་པའི་འདོད་ཆགས་དང་བྲལ་བའི་དུས་དང་། འཇིག་རྟེན་ལས་འདས་པའི་འདོད་ཆགས་དང་བྲལ་བའི་དུས་དང་། སེམས་ཅན་ལ་ཕན་འདོགས་པའི་དུས་སོ། །

Enumeration Block 6:
དངོས་པོ་བརྒྱད་དེ། སྦྱིན་པ་ལས་བྱུང་བའི་བསོད་ནམས་བྱ་བའི་དངོས་པོ་དང་། ཚུལ་ཁྲིམས་ལས་བྱུང་བ་དང་། བསྒོམས་པ་པ༌[^753]ལས་བྱུང་བ་དང་། ཐོས་པ་ལས་བྱུང་བ་དང་། བསམས་པ་ལས་བྱུང་བ་དང་། དེ་ལས་གཞན་པའི་བསྒོམས་པ༌[^754]ལས་བྱུང་བ་དང་། སོ་སོར་བརྟགས་པ་ལས་བྱུང་བ་དང་། སེམས་ཅན་ལ་ཕན་འདོགས་པ་ལས་བྱུང་བའོ། །

Enumeration Block 7:

དེ་ནི་ཀུན་ནས་ཉོན་མོངས་པ་གསུམ་དུ་རིག་པར༌[^1009]བྱའོ། །དེ་ཡང་གང་ཞེ་ན། ཉོན་མོངས་པའི་ཀུན་ནས་ཉོན་མོངས་པ་དང་། ལས་ཀྱི་ཀུན་ནས་ཉོན་མོངས་པ་དང་། སྐྱེ་བའི་ཀུན་ནས་ཉོན་མོངས་པའོ། །

Enumeration Block 2:
ཉོན་མོངས་པ་རྣམ་པ༌[^1012]གཅིག་ཀྱང་ཡོད་དེ་ཀུན་ནས་ཉོན་མོངས་པའི་དོན་ཏོ། །རྣམ་པ་གཉིས་ཀྱང་ཡོད་དེ་མཐོང་བས་སྤང་བར་བྱ་བ་དང་། བསྒོམ་པས་སྤང་བར་བྱའོ།[^1013] །རྣམ་པ་གསུམ་ཡང་ཡོད་དེ། འདོད་པ་དང་ལྡན་པ་དང་། གཟུགས་དང་ལྡན་པ་དང་། གཟུགས་མེད་པ་དང་ལྡན་པའོ། །རྣམ་པ་བཞི་ཡང་ཡོད་དེ། འདོད་པ་དང་ལྡན་པའི་ལུང་དུ་བསྟན་པ་དང་། ལུང་དུ་མ་བསྟན་པ་དང་། གཟུགས་དང་ལྡན་པའི་ལུང་དུ་མ་བསྟན་པ་དང་། གཟུགས་མེད་པ་དང་ལྡན་པའི་ལུང་དུ་མ་བསྟན་པའོ། །རྣམ་པ་ལྔ་ཡང་ཡོད་དོ། །སྡུག་བསྔལ་མཐོང་བས་སྤང་བར་བྱ་བ་དང་། ཀུན་འབྱུང་བ་མཐོང་བས་སྤང་བར་བྱ་བ་དང་། འགོག་པ་མཐོང་བས་སྤང་བར་བྱ་བ་དང་། ལམ་མཐོང་བས་སྤང་བར་བྱ་བ་དང་། བསྒོམ་པས་སྤང་བར་བྱ་བའོ།[^1014] །རྣམ་པ་དྲུག་ནི་འདོད་ཆགས་དང་། ཁོང་ཁྲོ་བ་དང་། ང་རྒྱལ་དང་། མ་རིག་པ་དང་། ལྟ་བ་དང་། ཐེ་ཚོམ་མོ། །རྣམ་པ་བདུན་ནི། བག་ལ་ཉལ་བདུན་ཏེ། འདོད་པའི་འདོད་ཆགས་ཀྱི་བག་ལ་ཉལ་བ་དང་། ཁོང་ཁྲོ་བའི་བག་ལ་ཉལ་བ་དང་། སྲིད་པའི་འདོད་ཆགས་ཀྱི༌[^1015]བག་ལ་ཉལ་བ་དང་། ང་རྒྱལ་གྱི༌[^1016]བག་ལ་ཉལ་བ་དང་། མ་རིག་པའི་བག་ལ་ཉལ་བ་དང་། ལྟ་བའི་བག་ལ་ཉལ་བ་དང་། ཐེ་ཚོམ་གྱི་བག་ལ་ཉལ་བའོ། །རྣམ་པ་བརྒྱད་ནི། འདོད་ཆགས་དང་། ཁོང་ཁྲོ་བ་དང་། ང་རྒྱལ་དང་། མ་རིག་པ་དང་། ཐེ་ཚོམ་དང་། ལྟ་བ་དང་། མཆོག་ཏུ་འཛིན་པ་གཉིས་སོ། །རྣམ་པ་དགུ་ནི། ཀུན་ཏུ་སྦྱོར་བ་དགུ་སྟེ། རྗེས་སུ་ཆགས་པའི་ཀུན་ཏུ་སྦྱོར་བ་དང་། ཁོང་ཁྲོ་བའི་ཀུན་ཏུ་སྦྱོར་བ་དང་། ང་རྒྱལ་གྱི་ཀུན་ཏུ་སྦྱོར་བ་དང་། མ་རིག་པའི་ཀུན་ཏུ་སྦྱོར་བ་དང་། ལྟ་བའི་ཀུན་ཏུ་སྦྱོར་བ་དང་། མཆོག་ཏུ་འཛིན་པའི་ཀུན་ཏུ་སྦྱོར་བ་དང་། ཐེ་ཚོམ་གྱི་ཀུན་ཏུ་སྦྱོར་བ་དང་། ཕྲག་དོག་གི་ཀུན་ཏུ་སྦྱོར་བ་དང་། སེར་སྣའི་ཀུན་ཏུ་སྦྱོར་བའོ། །རྣམ་པ་བཅུ་ནི་འཇིག་ཚོགས་ལ་ལྟ་བ་དང་། མཐར་འཛིན་པར་ལྟ་བ་དང་། ལོག་པར་ལྟ་བ་དང་། ལྟ་བ་མཆོག་ཏུ་འཛིན་པ་དང་། ཚུལ་ཁྲིམས་དང་། བརྟུལ་ཞུགས་མཆོག་ཏུ་འཛིན་པ་དང་། འདོད་ཆགས་དང་། ཁོང་ཁྲོ་བ་དང་། ང་རྒྱལ་དང་། མ་རིག་པ་དང་། ཐེ་ཚོམ་མོ། །

Enumeration Block 3:
རྒྱུ་ནི་རྣམ་པ་དྲུག་སྟེ། རྟེན་དང་། དམིགས་པ་དང་། འདུ་འཛི་དང་། བཤད་པ་དང་། གོམས་པ་དང་། ཡིད་ལ་བྱེད་པ་ལས་ཀྱང་ཉོན་མོངས་པ་སྐྱེའོ། །

Enumeration Block 4:
མདོར་བསྡུ་ན་རྣམ་པ་བདུན་ཏེ། བག་ལ་ཉལ་གྱི་གནས་སྐབས་དང་། ཀུན་ནས་དཀྲིས་པའི་གནས་སྐབས་དང་། ཀུན་ནས་བརྟགས་པའི་གནས་སྐབས་དང་། ལྷན་ཅིག་སྐྱེས་པའི་གནས་སྐབས་དང་། ཆུང་ངུའི་གནས་སྐབས་དང་། འབྲིང་གི་གནས་སྐབས་དང་། ཆེན་པོའི་གནས་སྐབས་སོ། །

Enumeration Block 5:
རྒྱུ་རྣམ་པ་གཉིས་ཀྱིས་ནི་ཉོན་མོངས་པའི་བག་ལ་ཉལ་ཕྲ་རྒྱས་སུ་འགྱུར་ཏེ། ས་བོན་གྱི་རྗེས་སུ་འབྲེལ་བ་དང་། དེའི་བདག་པོའི་དངོས་པོས་སོ། །

Enumeration Block 6:
མདོར་བསྡུ་ན་ཀུན་ནས་དཀྲིས་པའི་སྒོ་དང་། བག་ལ་ཉལ་གྱི་སྒོ་སྟེ་སྒོ་རྣམ་པ་གཉིས་ཀྱིས་སོ། །

Enumeration Block 7:
རྣམ་པ་ལྔས་ཏེ། རབ་ཏུ་མ་ཞི་བར་གནས་པ་དང་། དགེ་བའི་བར་དུ་གཅོད་པ་དང་། ངན་སོང་གི་རྒྱུ་ཉེས་པར་སྤྱད་པ་ཀུན་ནས་སློང་བ་དང་། ཚེ་འདི་ཉིད་ལ་ཉམས་པར་འགྱུར་བ་ཡོངས་སུ་འཛིན་པ་དང་། སྐྱེ་བ་ལ་སོགས་པའི་སྡུག་བསྔལ་འགྲུབ་པས་སོ། །

Enumeration Block 8:
སྒོ་བདུན་གྱིས་ཉོན་མོངས་པ་ཐམས་ཅད་མཐོང་བ་དང་། བསྒོམ་པ་ལ་བགེགས་བྱེད་ཅིང་། སྒྲིབ༌[^1043]པར་བྱེད་པར་གྱུར་པར་རིག་པར་བྱའོ།[^1044] །འདི་ལྟ་སྟེ། ལོག་པར་རྟོགས་པ་དང་། མ་རྟོགས་པ་དང་། རྟོགས་པ་ཡང་མ་ཡིན་མ་རྟོགས་པ་ཡང་མ་ཡིན་པ་དང་། ལོག་པར་རྟོགས་པས་ལོག་པར་སྒྲུབ་པ་དང་། དེའི་གཞིའི་གནས་རྟེན་དང་། དེ་འཇིགས་པ་བསྐྱེད་པ་དང་། རང་བཞིན་གྱིས་ཀུན་ཏུ་སྤྱོད་པའོ།། །།

Enumeration Block 1:
མདོར་བསྡུ་ན་རྣམ་པ་བདུན་ཏེ། བག་ལ་ཉལ་གྱི་གནས་སྐབས་དང་། ཀུན་ནས་དཀྲིས་པའི་གནས་སྐབས་དང་། ཀུན་ནས་བརྟགས་པའི་གནས་སྐབས་དང་། ལྷན་ཅིག་སྐྱེས་པའི་གནས་སྐབས་དང་། ཆུང་ངུའི་གནས་སྐབས་དང་། འབྲིང་གི་གནས་སྐབས་དང་། ཆེན་པོའི་གནས་སྐབས་སོ། །

Enumeration Block 2:
དེ་ལ་རྒྱུ་རྣམ་པ་གཉིས་ཀྱིས་ནི་ཉོན་མོངས་པའི་བག་ལ་ཉལ་ཕྲ་རྒྱས་སུ་འགྱུར་ཏེ། ས་བོན་གྱི་རྗེས་སུ་འབྲེལ་བ་དང་། དེའི་བདག་པོའི་དངོས་པོས་སོ། །

Enumeration Block 3:
མདོར་བསྡུ་ན་ཀུན་ནས་དཀྲིས་པའི་སྒོ་དང་། བག་ལ་ཉལ་གྱི་སྒོ་སྟེ་སྒོ་རྣམ་པ་གཉིས་ཀྱིས་སོ། །

Enumeration Block 4:
