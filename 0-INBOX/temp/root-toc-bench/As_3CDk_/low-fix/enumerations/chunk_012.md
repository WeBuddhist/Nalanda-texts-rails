Enumeration Block 1:
གཟུགས་འདུས་པ་དེ་ཡང་རྒྱུ་རྣམ་པ་གསུམ་གྱིས་འཇུག་པར་འགྱུར་ཏེ། རྒྱས་པ་ལས་བྱུང་བ་དང་། རྒྱུ་མཐུན་པ་ལས་བྱུང་བ་དང་། རྣམ་པར་སྨིན་པ་ལས་བྱུང་བའོ། །

Enumeration Block 2:
དེ་ལ་རྒྱས་པ་ལས་བྱུང་བ་ནི་རྣམ་པ་གཉིས་ཏེ། ཡུལ་ལ་ཁྱབ་པའི་རྒྱས་པ་ལས་བྱུང་བ་དང་། མཚན་ཉིད་བརྟས་པར༌[^363]བྱེད་པའི་རྒྱས་པ་ལས་བྱུང་བའོ། །

Enumeration Block 3:
རྒྱུ་མཐུན་པ༌[^364]ལས་བྱུང་བ་ནི་རྣམ་པ་བཞི་སྟེ། རྒྱས་པའི་རྒྱུ་མཐུན་པ་ལས་བྱུང་བ་དང་། རྣམ་པར་སྨིན་པའི་རྒྱུ་མཐུན་པ༌[^365]ལས་བྱུང་བ་དང་། གྱུར་པའི༌[^366]རྒྱུ་མཐུན་པ་ལས་བྱུང་བ་དང་། རང་བཞིན་གྱི་རྒྱུ་མཐུན་པ་ལས་བྱུང་བའོ། །

Enumeration Block 4:
རྣམ་པར་སྨིན་པ་ལས་བྱུང་བ་ནི་རྣམ་པ་གཉིས་ཏེ། རྣམ་པར་སྨིན་པར་སྐྱེས་པ། རྣམ་པར་སྨིན་པར་བྱུང་བ་དང་། རྣམ་པར་སྨིན་པ་ལས་སྐྱེས་པ། རྣམ་པར་སྨིན་པ་ལས་བྱུང་པའོ། །

Enumeration Block 5:
གཟུགས་འདུས་པ་དེ་ཡང་མདོར་བསྡུ་ན། གནས་དྲུག་ལ༌[^367]བརྟེན་ནས་འཇུག་སྟེ། གཞིའི་གནས་དང་། རྟེན་གྱི་གནས་དང་། ཡོ་བྱད་ཀྱི་གནས་དང་། དབང་པོའི་རྟེན་གྱི་གནས་དང་། དབང་བོའི་གནས་དང་། ཏིང་ངེ་འཛིན་གྱི་སྤྱོད་ཡུལ་ཀྱི་གནས་སོ། །

Enumeration Block 6:
དེ་དང་འབྱུང་བ་ཡིན༌[^374]ལ་བྱེད་པ་ཇི་ལྟར་འབྱུང་བར་འགྱུར་ཞེ་ན། རྣམ་པ་བཞིས་འགྱུར་ཏེ་འདུན་པའི་སྟོབས་དང་། དྲན་པའི་སྟོབས་དང་། ཡུལ་གྱི་སྟོབས་དང་། གོམས་པའི་སྟོབས་ཀྱིས་འབྱུང་བར་འགྱུར་རོ། །
