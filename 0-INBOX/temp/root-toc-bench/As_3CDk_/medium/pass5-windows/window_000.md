* II. སྤྱི་སྡོམ། [[རྣལ་འབྱོར་སྤྱོད་པའི་ས་གང་ཞེ་ན། དེ་ནི་ས་བཅུ་བདུན་དུ་བལྟ་བར་བྱ་སྟེ། བཅུ་བདུན་གང་ཞེ་ན།]]
* 1. རྣམ་པར་ཤེས་པའི་ཚོགས་ལྔ་དང་ལྡན་པའི་ས [[རྣམ་པར་ཤེས་པའི་ཚོགས་ལྔ་དང་ལྡན་པའི་ས་གང་ཞེ་ན། རྣམ་པར་ཤེས་པའི་ཚོགས་ལྔ་སྟེ། ངོ་བོ་ཉིད་དང་།]]
   * 1.1 མིག་གི་རྣམ་པར་ཤེས་པ [[མིག་གི་རྣམ་པར་ཤེས་པ་གང་ཞེ་ན། གང་མིག་ལ་བརྟེན་ནས་གཟུགས་སོ་སོར་རྣམ་པར་རིག་པའོ། །]]
   * 1.2 རྣ་བའི་རྣམ་པར་ཤེས་པ [[རྣ་བའི་རྣམ་པར་ཤེས་པ་གང་ཞེ་ན། གང་རྣ་བ་ལ་བརྟེན་ནས་སྒྲ་སོ་སོར་རྣམ་པར་རིག་པའོ། །]]
   * 1.3 སྣའི་རྣམ་པར་ཤེས་པ [[སྣའི་རྣམ་པར་ཤེས་པ་གང་ཞེ་ན། གང་སྣ་ལ་བརྟེན་ནས་དྲི་སོ་སོར་རྣམ་པར་རིག་པའོ། །]]
   * 1.4 ལྕེའི་རྣམ་པར་ཤེས་པ [[ལྕེའི་རྣམ་པར་ཤེས་པ་གང་ཞེ་ན། གང་ལྕེ་ལ༌[^15]བརྟེན་ནས་སོ་སོར་རྣམ་པར་རིག་པའོ། །]]
   * 1.5 ལུས་ཀྱི་རྣམ་པར་ཤེས་པ [[ལུས་ཀྱི་རྣམ་པར་ཤེས་པ་གང་ཞེ་ན། གང་ལུས་ལ་བརྟེན་ནས་རེག་བྱ་སོ་སོར་རྣམ་པར་རིག་པའོ། །]]
* 2. ཡིད་ཀྱི་ས [[ཡིད་ཀྱི་ས་གང་ཞེ་ན། དེ་ཡང་རྣམ་པ་ལྔ་ཁོ་ནར་བལྟ་བར་བྱ་སྟེ། ངོ་བོ་ཉིད་དང་།]]
   * 2.1 ངོ་བོ་ཉིད [[དེ་ལ་ངོ་བོ་ཉིད་གང་ཞེ་ན། སེམས་དང་ཡིད་དང་རྣམ་པར་ཤེས་པ་གང་ཡིན་པའོ། །]]
      * 2.1.1 སེམས [[སེམས་གང་ཞེ་ན། ས་བོན་ཐམས་ཅད་དང་ལྡན་པ་དང་། གནས་ཀྱི་དངོས་པོར་གྱུར་པ་དང་།]]
      * 2.1.2 ཡིད [[ཡིད་གང་ཞེ་ན། རྣམ་པར་ཤེས་པའི་ཚོགས་དྲུག་པོ་དག་འགགས་མ་ཐག་པ་གང་ཡིན་པ་དང་།]]
      * 2.1.3 རྣམ་པར་ཤེས་པ [[རྣམ་པར་ཤེས་པ་གང་ཞེ་ན། དམིགས་པ་རྣམ་པར་རིག་པར་བྱེད་པས་ཉེ་བར་གནས་པ་གང་ཡིན་པའོ། །]]
   * 2.2 གནས [[གནས་གང་ཞེ་ན། ཡིད་དེ་མ་ཐག་པའི་གནས་དང་། སྔ་མ་བཞིན་དུ་ས་བོན་ཐམས་ཅད་པ་ཀུན་གཞི་རྣམ་པར་ཤེས་པས་ས༌[^25]བོན་གྱི་གནས་སོ། །]]
   * 2.3 དམིགས་པ [[དམིགས་པ་གང་ཞེ་ན། ཆོས་ཐམས་ཅད་ནི་དམིགས་པ་སྟེ། འབའ་ཞིག་གི་ཚོར་བའི་ཕུང་པོ་དང་།]]
   * 2.4 གྲོགས [[གྲོགས་གང་ཞེ་ན། འདི་ལྟ་སྟེ། ཡིད་ལ་བྱེད་པ་དང་། རེག་པ་དང་། ཚོར་བ་དང་། འདུ་ཤེས་དང་།]]
   * 2.5 ལས [[ལས་གང་ཞེ་ན། བདག་དང་གཞན་གྱི་ཡུལ་གྱི་དམིགས་པ་རྣམ་པར་རིག་པར་བྱེད་པ་ནི་ལས་དང་པོའོ། །]]
