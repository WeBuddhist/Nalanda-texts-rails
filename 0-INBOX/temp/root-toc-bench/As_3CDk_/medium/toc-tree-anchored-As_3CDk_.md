## དཀར་ཆག / Table of Contents
* II. སྤྱི་སྡོམ། [[རྣལ་འབྱོར་སྤྱོད་པའི་ས་གང་ཞེ་ན། དེ་ནི་ས་བཅུ་བདུན་དུ་བལྟ་བར་བྱ་སྟེ། བཅུ་བདུན་གང་ཞེ་ན།]]

* 1. རྣམ་པར་ཤེས་པའི་ཚོགས་ལྔ་དང་ལྡན་པའི་ས [[རྣམ་པར་ཤེས་པའི་ཚོགས་ལྔ་དང་ལྡན་པའི་ས་གང་ཞེ་ན། རྣམ་པར་ཤེས་པའི་ཚོགས་ལྔ་སྟེ། ངོ་བོ་ཉིད་དང་།]]
   * 1.1 མིག་གི་རྣམ་པར་ཤེས་པ [[མིག་གི་རྣམ་པར་ཤེས་པ་གང་ཞེ་ན། གང་མིག་ལ་བརྟེན་ནས་གཟུགས་སོ་སོར་རྣམ་པར་རིག་པའོ། །]]
   * 1.2 རྣ་བའི་རྣམ་པར་ཤེས་པ [[རྣ་བའི་རྣམ་པར་ཤེས་པ་གང་ཞེ་ན། གང་རྣ་བ་ལ་བརྟེན་ནས་སྒྲ་སོ་སོར་རྣམ་པར་རིག་པའོ། །]]
   * 1.3 སྣའི་རྣམ་པར་ཤེས་པ [[སྣའི་རྣམ་པར་ཤེས་པ་གང་ཞེ་ན། གང་སྣ་ལ་བརྟེན་ནས་དྲི་སོ་སོར་རྣམ་པར་རིག་པའོ། །]]
   * 1.4 ལྕེའི་རྣམ་པར་ཤེས་པ [[ལྕེའི་རྣམ་པར་ཤེས་པ་གང་ཞེ་ན། གང་ལྕེ་ལ༌[^15]བརྟེན་ནས་སོ་སོར་རྣམ་པར་རིག་པའོ། །]]
   * 1.5 ལུས་ཀྱི་རྣམ་པར་ཤེས་པ [[ལུས་ཀྱི་རྣམ་པར་ཤེས་པ་གང་ཞེ་ན། གང་ལུས་ལ་བརྟེན་ནས་རེག་བྱ་སོ་སོར་རྣམ་པར་རིག་པའོ། །]]
* 2. ཡིད་ཀྱི་ས [[ཡིད་ཀྱི་ས་གང་ཞེ་ན། དེ་ཡང་རྣམ་པ་ལྔ་ཁོ་ནར་བལྟ་བར་བྱ་སྟེ། ངོ་བོ་ཉིད་དང་།]]
   * 2.1 ངོ་བོ་ཉིད [[དེ་ལ་ངོ་བོ་ཉིད་གང་ཞེ་ན། སེམས་དང་ཡིད་དང་རྣམ་པར་ཤེས་པ་གང་ཡིན་པའོ། །]]
      * 2.1.1 སེམས [[སེམས་གང་ཞེ་ན། ས་བོན་ཐམས་ཅད་དང་ལྡན་པ་དང་། གནས་ཀྱི་དངོས་པོར་གྱུར་པ་དང་།]]
      * 2.1.2 ཡིད [[ཡིད་གང་ཞེ་ན། རྣམ་པར་ཤེས་པའི་ཚོགས་དྲུག་པོ་དག་འགགས་མ་ཐག་པ་གང་ཡིན་པ་དང་།]]
      * 2.1.3 རྣམ་པར་ཤེས་པ [[རྣམ་པར་ཤེས་པ་གང་ཞེ་ན། དམིགས་པ་རྣམ་པར་རིག་པར་བྱེད་པས་ཉེ་བར་གནས་པ་གང་ཡིན་པའོ། །]]
   * 2.2 གནས [[གནས་གང་ཞེ་ན། ཡིད་དེ་མ་ཐག་པའི་གནས་དང་། སྔ་མ་བཞིན་དུ་ས་བོན་ཐམས་ཅད་པ་ཀུན་གཞི་རྣམ་པར་ཤེས་པས་ས༌[^25]བོན་གྱི་གནས་སོ། །]]
   * 2.3 དམིགས་པ [[དམིགས་པ་གང་ཞེ་ན། ཆོས་ཐམས་ཅད་ནི་དམིགས་པ་སྟེ། འབའ་ཞིག་གི་ཚོར་བའི་ཕུང་པོ་དང་།]]
   * 2.4 གྲོགས [[གྲོགས་གང་ཞེ་ན། འདི་ལྟ་སྟེ། ཡིད་ལ་བྱེད་པ་དང་། རེག་པ་དང་། ཚོར་བ་དང་། འདུ་ཤེས་དང་།]]
   * 2.5 ལས [[ལས་གང་ཞེ་ན། བདག་དང་གཞན་གྱི་ཡུལ་གྱི་དམིགས་པ་རྣམ་པར་རིག་པར་བྱེད་པ་ནི་ལས་དང་པོའོ། །]]
* 3. ས་གསུམ་པོ་འདི་དག [[ས་གསུམ་པོ་འདི་དག་ནི། ཁམས་གདགས་པ་རྣམ་པར་གཞག་པ་དང་། མཚན་ཉིད་གདགས་པ་རྣམ་པར་]]
   * 3.1 ཁམས་གདགས་པ་རྣམ་པར་གདགས་པ [[ཁམས་གདགས་པ་རྣམ་པར་གདགས་པ་གང་ཞེ་ན། དེ་ནི་རྣམ་པ་བརྒྱད་དུ་རིག་པར་བྱ་སྟེ།]]
      * 3.1.1 གྲངས་རྣམ་པར་གཞག་པ [[དེ་ལ་གྲངས་རྣམ་པར་གཞག་པ་ནི་འདི་ཡིན་ནོ། །ཁམས་ནི་གསུམ་སྟེ། འདོད་པའི་ཁམས་དང་།]]
      * 3.1.2 གནས་གཞན་རྣམ་པར་གཞག་པ [[དེ་ལ་གནས་གཞན་རྣམ་པར་གཞག་པ་ནི་འདི་ཡིན་ནོ། །འདོད་པའི་ཁམས་ནི་གནས་གཞན་སུམ་ཅུ་]]
      * 3.1.3 སེམས་ཅན་གྱི་ཚད་རྣམ་པར་གཞག་པ [[དེ་ལ་སེམས་ཅན་གྱི་ཚད་རྣམ་པར་གཞག་པ་ནི་འདི་ཡིན་ཏེ། འཛམ་བུའི་གླིང་གི་མི་རྣམས་ཀྱི]]
      * 3.1.4 སེམས་ཅན་དེ་དག་ཉིད་ཀྱི་ཚེའི་ཚད་རྣམ་པར་གཞག་པ [[དེ་ལ་ཚེའི་ཚད་རྣམ་པར་གཞག་པ་ནི་འདི་ཡིན་ཏེ། འཛམ༌[^498]བུའི་གླིང་གི་མི་རྣམས་ཀྱི་ནི]]
      * 3.1.5 སེམས་ཅན་དེ་དག་ཉིད་ཀྱི་ལོངས་སྤྱོད་དང་ཡོངས་སུ་སྤྱོད་པ་རྣམ་པར་གཞག་པ [[དེ་ལ་ལོངས་སྤྱོད་དང་ཡོངས་སུ་སྤྱོད་པ་རྣམ་པར་གཞག་པ་ནི་འདི་ཡིན་ཏེ། འདི་ལྟ་སྟེ། བདེ་བ་དང་སྡུག་བསྔལ]]
      * 3.1.6 སྐྱེ་བ་རྣམ་པར་གཞག་པ [[དེ་ལ་སྐྱེ་བར་འདོགས་པ་རྣམ་པར་གཞག་པ་ནི་འདི་ཡིན་ཏེ། འདི་ལྟ་སྟེ། འདོད་པ་སྐྱེ་བ་རྣམ་པ་གསུམ]]
      * 3.1.7 ལུས་རྣམ་པར་གཞག་པ [[དེ་ལ་ལུས་རྣམ་པར་གཞག་པ་ནི། འདི་ལྟ་སྟེ། ཁམས་གསུམ་ན་སེམས་ཅན་རྣམས་ཀྱི་ལུས་ཐོབ་པ]]
      * 3.1.8 རྒྱུ་དང་རྐྱེན་དང་འབྲས་བུ་རྣམ་པར་གཞག་པ [[དེ་ལ་རྒྱུ་དང་རྐྱེན་དང་འབྲས་བུ་རྣམ་པར་གཞག་པ་ནི་རྣམ་པ་བཞིར་རིག་པར་བྱ་སྟེ། མཚན་ཉིད་དང་།]]
         * 3.1.8.1 རྒྱུའི་མཚན་ཉིད [[དེ་ལ་རྒྱུའི་མཚན་ཉིད་གང་ཞེ་ན། སྔ་ན་ཡོད་པ་གང་ཡིན་པ་གང་ལ་བརྟེན༌[^699]ནས།]]
         * 3.1.8.2 རྒྱུ་དང་རྐྱེན་དང་འབྲས་བུའི་གནས [[རྒྱུ་དང་རྐྱེན་དང་འབྲས་བུའི་གནས་གང་ཞེ་ན། བཅོ་ལྔ་པོ་འདི་དག་ནི་རྒྱུའི་གནས་ཡིན་ཏེ།]]
         * 3.1.8.3 རྒྱུ་དང་རྐྱེན་དང་འབྲས་བུའི་རབ་ཏུ་དབྱེ་བ [[རྒྱུ་དང་རྐྱེན་དང་འབྲས་བུའི་རབ་ཏུ་དབྱེ་བ་གང་ཞེ་ན། རྒྱུ་བཅུ་དང་། རྐྱེན་བཞི་དང་། འབྲས་བུ་ལྔའོ། །]]
            * 3.1.8.3.1 རྒྱུ་བཅུ [[རྒྱུ་བཅུ་པོ་དག་གང་ཞེ་ན། རྗེས་སུ་ཐ་སྙད་འདོགས་པའི་རྒྱུ་དང་།]]
            * 3.1.8.3.2 རྐྱེན་བཞི [[རྐྱེན་བཞི་པོ་དག་གང་ཞེ་ན། རྒྱུའི་རྐྱེན་དང་། མཚུངས་པ་དེ་མ་ཐག་པའི་རྐྱེན་དང་།]]
            * 3.1.8.3.3 འབྲས་བུ་ལྔ [[འབྲས་བུ་ལྔ་པོ་དག་གང་ཞེ་ན། རྣམ་པར་སྨིན་པའི་འབྲས་བུ་དང་། རྒྱུ་མཐུན་པའི་འབྲས་བུ་དང་།]]
