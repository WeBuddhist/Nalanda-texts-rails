དེ་ནི་རྣམ་པ་བདུན་དུ་རིག་པར་བྱ་སྟེ། ལུས་དང་དམིགས་པ་དང་། རྣམ་པ་དང་། ཀུན་ནས་སློང་བ་དང་། རབ་ཏུ་དབྱེ་བ་དང་། རྣམ་པར་ངེས་པ་དང་། འཇུག་པའོ། །

Enumeration Block 1:
གཞན་ཡང་རྒྱུ་ནི་རྣམ་པ་ལྔར་གཞག་པ་ཡིན་ཏེ། འདི་ལྟ་སྟེ། སྡུག་པའི་རྒྱུ་དང་། མི་སྡུག་པའི་རྒྱུ་དང་། ལྟ་བའི་རྒྱུ་དང་། འཇུག་པའི་རྒྱུ་དང་། ལྡོག་པའི་རྒྱུའོ། །

Enumeration Block 2:
དེ་ལ་མཚན་ཉིད་གདགས་པ་རྣམ་པར་གཞག་པ་གང་ཞེ་ན། དེ་ནི་རྣམ་པ་བདུན་དུ་རིག་པར་བྱ་སྟེ། ལུས་དང་དམིགས་པ་དང་། རྣམ་པ་དང་། ཀུན་ནས་སློང་བ་དང་། རབ་ཏུ་དབྱེ་བ་དང་། རྣམ་པར་ངེས་པ་དང་། འཇུག་པའོ། །

Enumeration Block 3:
རབ་ཏུ་དབྱེ་བ་རྣམ་པ་བདུན་ཏེ། མཚན་མ་ཅན་དང་། མཚན་མ་ཅན་མ་ཡིན་པ་ནས། ཉོན་མོངས་པ་ཅན་མ་ཡིན་པའི་བར་དུ༌[^737]སྔ་མ་བཞིན་ནོ། །

Enumeration Block 4:
དེ་ལ་ཚུལ་བཞིན་ཡིད་ལ་བྱེད་པ་གདགས་པ་རྣམ་པར་གཞག་པ་གང་ཞེ་ན། དེ་ནི་རྣམ་པ་བརྒྱད་དུ་རིག་པར་བྱ་སྟེ། གནས་དང་དངོས་པོ་དང་། ཚོལ་བ་དང་། ལོངས་སྤྱོད་པ་དང་། ཡང་དག་པར་འགྲུབ་པ་དང་། ཉན་ཐོས་ཀྱི་ཐེག་པའི་ཚོགས་ལ་སྦྱོར་བ་དང་། རང་སངས་རྒྱས་ཀྱི་ཐེག་པའི་ཚོགས་ལ་སྦྱོར་བ་དང་། ཕ་རོལ་ཏུ་ཕྱིན་པ་བསྒྲུབ་པ་ལ་སྦྱོར་བའོ། །

Enumeration Block 5:
གནས་རྣམ་པ་དྲུག་སྟེ། འདི་ལྟ་སྟེ། ངེས་པའི་དུས་དང་། ལྡོག་པའི་དུས་དང་། ལས་ཀྱི་དུས་དང་། འཇིག་རྟེན་པའི་འདོད་ཆགས་དང་བྲལ་བའི་དུས་དང་། འཇིག་རྟེན་ལས་འདས་པའི་འདོད་ཆགས་དང་བྲལ་བའི་དུས་དང་། སེམས་ཅན་ལ་ཕན་འདོགས་པའི་དུས་སོ། །

Enumeration Block 6:
དངོས་པོ་བརྒྱད་དེ། སྦྱིན་པ་ལས་བྱུང་བའི་བསོད་ནམས་བྱ་བའི་དངོས་པོ་དང་། ཚུལ་ཁྲིམས་ལས་བྱུང་བ་དང་། བསྒོམས་པ་པ༌[^753]ལས་བྱུང་བ་དང་། ཐོས་པ་ལས་བྱུང་བ་དང་། བསམས་པ་ལས་བྱུང་བ་དང་། དེ་ལས་གཞན་པའི་བསྒོམས་པ༌[^754]ལས་བྱུང་བ་དང་། སོ་སོར་བརྟགས་པ་ལས་བྱུང་བ་དང་། སེམས་ཅན་ལ་ཕན་འདོགས་པ་ལས་བྱུང་བའོ། །

Enumeration Block 7:
ཡང་སྦྱིན་པ་དག་གི་མཚན་ཉིད་ནི་རྣམ་པ་བཞི་སྟེ། འདོད་པ་དང་། ཕྱོགས་མི་འཛིན་པ་དང་། ཕོངས་པ་སེལ་བ་དང་། ཡང་དག་པར་ཤེས་པའོ། །

Enumeration Block 8:
ཚུལ་ཁྲིམས་དང་ལྡན་པའི་མཚན་ཉིད་ནི། རྣམ་པ་བཞི་སྟེ། འདོད་པ་དང་ཆུ་ལོན་གྱིས་གློན་པ་དང་། ཀུན་ཏུ་མི་སྤྱོད་པ་དང་། ཡང་དག་པར་ཤེས་པའོ། །

Enumeration Block 9:
སྒོམ་པ་པོའི་མཚན་ཉིད་ནི་རྣམ་པ་བཞི་སྟེ། བསམ་པ་རྣམ་པར་དག་པ་དང་། ཉེ་བར་སྦྱོར་བ་རྣམ་པར་དག་པ་དང་། མོས་པས་སྙོམས་པར་འཇུག་པ་རྣམ་པར་དག་པ་དང་། ཤེས་པ་རྣམ་པར་དག་པའོ། །

Enumeration Block 10:
ཟས་སྦྱིན་པ་ནི་རྣམ་པ་དྲུག་སྟེ། ཡི་དམ་ཅན་ལ་སྦྱིན་པ་དང་། ཀུན་ཏུ་འཚོལ་ཟས་སྦྱིན་པ་དང་། གནོད་པ་ལ་ཟས་སྦྱིན་པ་དང་། རང་བཞིན་གྱིས་ཕོངས་པ་ལ་ཟས་སྦྱིན་པ་དང་། ཡུལ་དང་བྲལ་བར་གནས་པ་ལ་ཟས་སྦྱིན་པ་དང་། ཡོངས་སུ་ཞེན་པ་ལ་ཟས་སྦྱིན་པའོ། །

Enumeration Block 11:
གནོད་པ་ནི་རྣམ་པ་བརྒྱད་དེ། བཀྲེས་པས་གནོད་པ་དང་། སྐོམ་པས་གནོད་པ་དང་། ཁ་ཟས་ངན་པ་ཟ་བས་གནོད་པ་དང་། ཡོངས་སུ་ངལ་བས་གནོད་པ་དང་། གྲང་བས་གནོད་པ་དང་། ཚ་བས་གནོད་པ་དང་། སྐྱབས་མེད་པས་གནོད་པ་དང་། བསྒྲིབས་པས་གནོད་པའོ། །

Enumeration Block 12:
ཡང་གནོད་པ་ནི་རྣམ་པ་དྲུག་སྟེ། ལྷན་ཅིག་སྐྱེས་པ་དང་། འདོད་པས་ཕོངས་པ་ལས་བྱུང་བ་དང་། འགྲོ་བ་ལས་བྱུང་བ་དང་། དུས་ཚིགས་འགྱུར་བ་ལས་བྱུང་བ་དང་། འཛག་གནོད་བྱེད་པ་ལས་བྱུང་བ་དང་། ཐ་སྙད་ཆད་པ་ལས་བྱུང་བའོ། །

Enumeration Block 13:
ཕན་གདགས་པ་ནི་རྣམ་པ་དྲུག་སྟེ། ཉེ་བར་རྟོན་པས་ཕན་གདགས་པ་དང་། འགྲོ་བས༌[^761]གནོད་པ་ལ་ཕན་གདགས་པ་དང་། གཡོགས་པས་ཕན་གདགས་པ་དང་། སྤོས་དང་མེ་ཏོག་ཕྲེང་དང་བྱུག་པས་ཕན་གདགས་པ་དང་། གནས་ཀྱིས་ཕན་གདགས་པ་དང་། འགྲོགས་པ་ལ་ཕན་གདགས་པའོ། །

Enumeration Block 14:
མི་མཛའ་བའི་མཚན་ཉིད་ནི་བཞི་སྟེ། འཁྲུག་པའི༌[^762]བསམ་པ་མི་གཏོང་བ་དང་། སྡུག་པ་ལ་རྣམ་པར་བགེགས་བྱེད་པའི་གནས་དང་། མི་སྡུག་པ་བསྒྲུབ་པ་དང་། ཕན་པ་མ་ཡིན་པ་བསྒྲུབ་པའོ། །

Enumeration Block 15:
བསྒྲུབ་པ་ནི་རྣམ་པ་གསུམ་སྟེ། ཡོ་བྱད་ཀྱི་བདེ་བ་བསྒྲུབ་པ་དང་། དགའ་བ་དང་བཅས་པའི་བདེ་བ་བསྒྲུབ་པ༌[^763]དང་། །དགའ་བ་མེད་པའི་བདེ་བ་བསྒྲུབ༌[^764]པའོ། །

Enumeration Block 16:
མཁས་པ་རྣམས་ཀྱི་མཁས་པའི་མཚན་ཉིད་ནི། གསུམ་པོ་འདི་དག་ཡིན་ཏེ། དགེ་བ་ཡང་དག་པར་ལེན་པ་དང་། དགེ་བ་ལ་གཅིག་ཏུ་ངེས་པ་དང་། དགེ་བ་ལ་བརྟེན་པའོ། །
གཞན་ཡང་གསུམ་སྟེ། ལྷག་པའི་ཚུལ་ཁྲིམས་ཡང་དག་པར་ལེན་པ་དང་། ལྷག་པའི་སེམས་ཡང་དག་པར་ལེན་པ་དང་། ལྷག་པའི་ཤེས་རབ་ཡང་དག་པར་ལེན་པའོ།།

Enumeration Block 1:
བསྒྲུབ་པ་ནི་རྣམ་པ་གསུམ་སྟེ། ཡོ་བྱད་ཀྱི་བདེ་བ་བསྒྲུབ་པ་དང་། དགའ་བ་དང་བཅས་པའི་བདེ་བ་བསྒྲུབ་པ༌[^763]དང་། །དགའ་བ་མེད་པའི་བདེ་བ་བསྒྲུབ༌[^764]པའོ། །

Enumeration Block 2:
མཁས་པ་རྣམས་ཀྱི་མཁས་པའི་མཚན་ཉིད་ནི། གསུམ་པོ་འདི་དག་ཡིན་ཏེ། དགེ་བ་ཡང་དག་པར་ལེན་པ་དང་། དགེ་བ་ལ་གཅིག་ཏུ་ངེས་པ་དང་། དགེ་བ་ལ་བརྟེན་པའོ། །

Enumeration Block 3:

ཉོན་མོངས་པ་རྣམ་པ༌གཅིག་ཀྱང་ཡོད་དེ་ཀུན་ནས་ཉོན་མོངས་པའི་དོན་ཏོ། །རྣམ་པ་གཉིས་ཀྱང་ཡོད་དེ་མཐོང་བས་སྤང་བར་བྱ་བ་དང་། བསྒོམ་པས་སྤང་བར་བྱའོ། །རྣམ་པ་གསུམ་ཡང་ཡོད་དེ། འདོད་པ་དང་ལྡན་པ་དང་། གཟུགས་དང་ལྡན་པ་དང་། གཟུགས་མེད་པ་དང་ལྡན་པའོ། །རྣམ་པ་བཞི་ཡང་ཡོད་དེ། འདོད་པ་དང་ལྡན་པའི་ལུང་དུ་བསྟན་པ་དང་། ལུང་དུ་མ་བསྟན་པ་དང་། གཟུགས་དང་ལྡན་པའི་ལུང་དུ་མ་བསྟན་པ་དང་། གཟུགས་མེད་པ་དང་ལྡན་པའི་ལུང་དུ་མ་བསྟན་པའོ། །རྣམ་པ་ལྔ་ཡང་ཡོད་དོ། །སྡུག་བསྔལ་མཐོང་བས་སྤང་བར་བྱ་བ་དང་། ཀུན་འབྱུང་བ་མཐོང་བས་སྤང་བར་བྱ་བ་དང་། འགོག་པ་མཐོང་བས་སྤང་བར་བྱ་བ་དང་། ལམ་མཐོང་བས་སྤང་བར་བྱ་བ་དང་། བསྒོམ་པས་སྤང་བར་བྱའོ། །རྣམ་པ་དྲུག་ནི་འདོད་ཆགས་དང་། ཁོང་ཁྲོ་བ་དང་། ང་རྒྱལ་དང་། མ་རིག་པ་དང་། ལྟ་བ་དང་། ཐེ་ཚོམ་མོ། །རྣམ་པ་བདུན་ནི། བག་ལ་ཉལ་བདུན་ཏེ། འདོད་པའི་འདོད་ཆགས་ཀྱི་བག་ལ་ཉལ་བ་དང་། ཁོང་ཁྲོ་བའི་བག་ལ་ཉལ་བ་དང་། སྲིད་པའི་འདོད་ཆགས་ཀྱི༌བག་ལ་ཉལ་བ་དང་། ང་རྒྱལ་གྱི༌བག་ལ་ཉལ་བ་དང་། མ་རིག་པའི་བག་ལ་ཉལ་བ་དང་། ལྟ་བའི་བག་ལ་ཉལ་བ་དང་། ཐེ་ཚོམ་གྱི་བག་ལ་ཉལ་བའོ། །རྣམ་པ་བརྒྱད་ནི། འདོད་ཆགས་དང་། ཁོང་ཁྲོ་བ་དང་། ང་རྒྱལ་དང་། མ་རིག་པ་དང་། ཐེ་ཚོམ་དང་། ལྟ་བ་དང་། མཆོག་ཏུ་འཛིན་པ་གཉིས་སོ། །རྣམ་པ་དགུ་ནི། ཀུན་ཏུ་སྦྱོར་བ་དགུ་སྟེ། རྗེས་སུ་ཆགས་པའི་ཀུན་ཏུ་སྦྱོར་བ་དང་། ཁོང་ཁྲོ་བའི་ཀུན་ཏུ་སྦྱོར་བ་དང་། ང་རྒྱལ་གྱི་ཀུན་ཏུ་སྦྱོར་བ་དང་། མ་རིག་པའི་ཀུན་ཏུ་སྦྱོར་བ་དང་། ལྟ་བའི་ཀུན་ཏུ་སྦྱོར་བ་དང་། མཆོག་ཏུ་འཛིན་པའི་ཀུན་ཏུ་སྦྱོར་བ་དང་། ཐེ་ཚོམ་གྱི་ཀུན་ཏུ་སྦྱོར་བ་དང་། ཕྲག་དོག་གི་ཀུན་ཏུ་སྦྱོར་བ་དང་། སེར་སྣའི་ཀུན་ཏུ་སྦྱོར་བའོ། །རྣམ་པ་བཅུ་ནི་འཇིག་ཚོགས་ལ་ལྟ་བ་དང་། མཐར་འཛིན་པར་ལྟ་བ་དང་། ལོག་པར་ལྟ་བ་དང་། ལྟ་བ་མཆོག་ཏུ་འཛིན་པ་དང་། ཚུལ་ཁྲིམས་དང་། བརྟུལ་ཞུགས་མཆོག་ཏུ་འཛིན་པ་དང་། འདོད་ཆགས་དང་། ཁོང་ཁྲོ་བ་དང་། ང་རྒྱལ་དང་། མ་རིག་པ་དང་། ཐེ་ཚོམ་མོ། །

Enumeration Block 3:
རྒྱུ་ནི་རྣམ་པ་དྲུག་སྟེ། རྟེན་དང་། དམིགས་པ་དང་། འདུ་འཛི་དང་། བཤད་པ་དང་། གོམས་པ་དང་། ཡིད་ལ་བྱེད་པ་ལས་ཀྱང་ཉོན་མོངས་པ་སྐྱེའོ། །

Enumeration Block 4:
མདོར་བསྡུ་ན་རྣམ་པ་བདུན་ཏེ། བག་ལ་ཉལ་གྱི་གནས་སྐབས་དང་། ཀུན་ནས་དཀྲིས་པའི་གནས་སྐབས་དང་། ཀུན་ནས་བརྟགས་པའི་གནས་སྐབས་དང་། ལྷན་ཅིག་སྐྱེས་པའི་གནས་སྐབས་དང་། ཆུང་ངུའི་གནས་སྐབས་དང་། འབྲིང་གི་གནས་སྐབས་དང་། ཆེན་པོའི་གནས་སྐབས་སོ། །

Enumeration Block 5:
རྒྱུ་རྣམ་པ་གཉིས་ཀྱིས་ནི་ཉོན་མོངས་པའི་བག་ལ་ཉལ་ཕྲ་རྒྱས་སུ་འགྱུར་ཏེ། ས་བོན་གྱི་རྗེས་སུ་འབྲེལ་བ་དང་། དེའི་བདག་པོའི་དངོས་པོས་སོ། །

Enumeration Block 6:
མདོར་བསྡུ་ན་ཀུན་ནས་དཀྲིས་པའི་སྒོ་དང་། བག་ལ་ཉལ་གྱི་སྒོ་སྟེ་སྒོ་རྣམ་པ་གཉིས་ཀྱིས་སོ། །

Enumeration Block 7:
རྣམ་པ་ལྔས་ཏེ། རབ་ཏུ་མ་ཞི་བར་གནས་པ་དང་། དགེ་བའི་བར་དུ་གཅོད་པ་དང་། ངན་སོང་གི་རྒྱུ་ཉེས་པར་སྤྱད་པ་ཀུན་ནས་སློང་བ་དང་། ཚེ་འདི་ཉིད་ལ་ཉམས་པར་འགྱུར་བ་ཡོངས་སུ་འཛིན་པ་དང་། སྐྱེ་བ་ལ་སོགས་པའི་སྡུག་བསྔལ་འགྲུབ་པས་སོ། །

Enumeration Block 8:
སྒོ་བདུན་གྱིས་ཉོན་མོངས་པ་ཐམས་ཅད་མཐོང་བ་དང་། བསྒོམ་པ་ལ་བགེགས་བྱེད་ཅིང་། སྒྲིབ༌པར་བྱེད་པར་གྱུར་པར་རིག་པར་བྱའོ། །འདི་ལྟ་སྟེ། ལོག་པར་རྟོགས་པ་དང་། མ་རྟོགས་པ་དང་། རྟོགས་པ་ཡང་མ་ཡིན་མ་རྟོགས་པ་ཡང་མ་ཡིན་པ་དང་། ལོག་པར་རྟོགས་པས་ལོག་པར་སྒྲུབ་པ་དང་། དེའི་གཞིའི་གནས་རྟེན་དང་། དེ་འཇིགས་པ་བསྐྱེད་པ་དང་། རང་བཞིན་གྱིས་ཀུན་ཏུ་སྤྱོད་པའོ།།
