* 1. ས་བཅུ་བདུན་ [[རྣལ་འབྱོར་སྤྱོད་པའི་ས་གང་ཞེ་ན། དེ་ནི་ས་བཅུ་བདུན་དུ་བལྟ་བར་བྱ་སྟེ།]]
   * 1.1 དང་པོ་རྣམ་པར་ཤེས་པའི་ཚོགས་ལྔ་དང་ལྡན་པའི་ས་ [[རྣམ་པར་ཤེས་པའི་ཚོགས་ལྔ་དང་ལྡན་པའི་ས་གང་ཞེ་ན། རྣམ་པར་ཤེས་པའི་ཚོགས་ལྔ་སྟེ།]]
      * 1.1.1 དང་པོ་ངོ་བོ་ཉིད་ [[རྣམ་པར་ཤེས་པའི་ཚོགས་ལྔ་གང་ཞེ་ན། མིག་གི་རྣམ་པར་ཤེས་པ་དང་།]]
         * 1.1.1.1 དང་པོ་མིག་གི་རྣམ་པར་ཤེས་པ་ [[མིག་གི་རྣམ་པར་ཤེས་པ་གང་ཞེ་ན། གང་མིག་ལ་བརྟེན་ནས་གཟུགས་སོ་སོར་རྣམ་པར་རིག་པའོ། །]]
         * 1.1.1.2 གཉིས་པ་རྣ་བའི་རྣམ་པར་ཤེས་པ་ [[རྣ་བའི་རྣམ་པར་ཤེས་པ་གང་ཞེ་ན། གང་རྣ་བ་ལ་བརྟེན་ནས་སྒྲ་སོ་སོར་རྣམ་པར་རིག་པའོ། །]]
         * 1.1.1.3 གསུམ་པ་སྣའི་རྣམ་པར་ཤེས་པ་ [[སྣའི་རྣམ་པར་ཤེས་པ་གང་ཞེ་ན། གང་སྣ་ལ་བརྟེན་ནས་དྲི་སོ་སོར་རྣམ་པར་རིག་པའོ། །]]
         * 1.1.1.4 བཞི་པ་ལྕེའི་རྣམ་པར་ཤེས་པ་ [[ལྕེའི་རྣམ་པར་ཤེས་པ་གང་ཞེ་ན། གང་ལྕེ་ལ༌[^15]བརྟེན་ནས་སོ་སོར་རྣམ་པར་རིག་པའོ། །]]
         * 1.1.1.5 ལྔ་པ་ལུས་ཀྱི་རྣམ་པར་ཤེས་པ་ [[ལུས་ཀྱི་རྣམ་པར་ཤེས་པ་གང་ཞེ་ན། གང་ལུས་ལ་བརྟེན་ནས་རེག་བྱ་སོ་སོར་རྣམ་པར་རིག་པའོ། །]]
      * 1.1.2 གཉིས་པ་དེ་དག་གི་གནས་ [[དེ་ལ་གནས་ནི་ཡུལ་གཞན་དུ་འགྲོ་བའི་བཞོན་པ་བཞིན་དུ་བལྟ་བར་བྱའོ། །]]
      * 1.1.3 གསུམ་པ་དེ་དག་གི་དམིགས་པ་ [[དམིགས་པ་ནི་བྱ་བའི་དོན་ལྟ་བུའོ། །]]
      * 1.1.4 བཞི་པ་དེ་དག་གི་གྲོགས་ [[རྣམ་པར་ཤེས་པའི་ཚོགས་ལྔ་པོ་དག་ནི་གྲོགས་རྣམས་ནི་འགྲོན་པོ་འགྲོགས་པ་ལྟ་བུའོ། །]]
      * 1.1.5 ལྔ་པ་དེ་དག་གི་ལས་ [[ལས་ནི་རང་གི་ནུས་པ་ལྟ་བུའོ། །]]
   * 1.2 གཉིས་པ་ཡིད་ཀྱི་ས་ [[ཡིད་ཀྱི་ས་གང་ཞེ་ན། དེ་ཡང་རྣམ་པ་ལྔ་ཁོ་ནར་བལྟ་བར་བྱ་སྟེ།]]
      * 1.2.1 དང་པོ་ངོ་བོ་ཉིད་ [[དེ་ལ་ངོ་བོ་ཉིད་གང་ཞེ་ན། སེམས་དང་ཡིད་དང་རྣམ་པར་ཤེས་པ་གང་ཡིན་པའོ། །]]
         * 1.2.1.1 དང་པོ་སེམས་ [[སེམས་གང་ཞེ་ན། ས་བོན་ཐམས་ཅད་དང་ལྡན་པ་དང་།]]
         * 1.2.1.2 གཉིས་པ་ཡིད་ [[ཡིད་གང་ཞེ་ན། རྣམ་པར་ཤེས་པའི་ཚོགས་དྲུག་པོ་དག་འགགས་མ་ཐག་པ་གང་ཡིན་པ་དང་།]]
         * 1.2.1.3 གསུམ་པ་རྣམ་པར་ཤེས་པ་ [[རྣམ་པར་ཤེས་པ་གང་ཞེ་ན། དམིགས་པ་རྣམ་པར་རིག་པར་བྱེད་པས་ཉེ་བར་གནས་པ་གང་ཡིན་པའོ། །]]
      * 1.2.2 གཉིས་པ་གནས་ [[གནས་གང་ཞེ་ན། ཡིད་དེ་མ་ཐག་པའི་གནས་དང་།]]
      * 1.2.3 གསུམ་པ་དམིགས་པ་ [[དམིགས་པ་གང་ཞེ་ན། ཆོས་ཐམས་ཅད་ནི་དམིགས་པ་སྟེ།]]
      * 1.2.4 བཞི་པ་གྲོགས་ [[གྲོགས་གང་ཞེ་ན། འདི་ལྟ་སྟེ། ཡིད་ལ་བྱེད་པ་དང་།]]
      * 1.2.5 ལྔ་པ་ལས་ [[ལས་གང་ཞེ་ན། བདག་དང་གཞན་གྱི་ཡུལ་གྱི་དམིགས་པ་རྣམ་པར་རིག་པར་བྱེད་པ་ནི་ལས་དང་པོའོ། །]]
         * 1.2.5.1 དམིགས་པ་ལ་ཇི་ལྟར་རྣམ་པར་རྟོག་པ་ [[དམིགས་པ་ལ་ཇི་ལྟར་རྣམ་པར་རྟོག་ཅེ་ན། རྣམ་པར་རྟོག་པ་བདུན་གྱིས་རྣམ་པར་རྟོག་སྟེ།]]
         * 1.2.5.2 དམིགས་པ་ལ་ཇི་ལྟར་ཉེ་བར་སེམས་པ་ [[དམིགས་པ་ལ་ཇི་ལྟར་ཉེ་བར་སེམས་ཤེ་ན། རིགས་པས་བསྐྱེད་པ་དང་།]]
         * 1.2.5.3 དེ་ལ་གནད་འཆད་པ་ [[དེ་ལ་གནད་འཆད་པ་ནི། སེམས་ཅན་དམྱལ་བའི་འགྲོ་བ་དང་།]]
            * 1.2.5.3.1 དང་པོ་ཤིན་ཏུ་ཚབས་ཆེ་བ་ [[དེ་ལ་ཡང་རྣམ་པ་གཉིས་ཏེ། ཤིན་ཏུ་ཚབས་ཆེ་བ་དང་། ཤིན་ཏུ་ཚབས་ཆུང་བ་སྟེ།]]
            * 1.2.5.3.2 གཉིས་པ་ཤིན་ཏུ་ཚབས་ཆུང་བ་ [[ལས་ལེགས་པ་བྱེད་བྱེད༌[^88]པ་རྣམས་ཀྱི་ནི་ཤིན་ཏུ་ཚབས་ཆུང་བ་ཡིན་ནོ། །]]
         * 1.2.5.4 བར་དུ་གཅོད་པ་རྣམ་པ་གསུམ་ [[དེ་ལ་མ་ཉམས་བདེ་ཞིང་ཟླ་མཚན༌[^112]ལྡན་པ་དང་། ཕ་མ༌[^113]ཆགས་པར་གྱུར་ཅིང་ཕྲད་པ་དང་།]]
            * 1.2.5.4.1 དང་པོ་སྐྱེ་གནས་ཀྱི་ཉེས་པས་གྱུར་པ་ [[དེ་ལ་སྐྱེ་གནས་ཀྱི་ཉེས་པ་གང་ཞེ་ན། གལ་ཏེ་རླུང་གིས༌[^114]མ་རུང་བར༌[^115]བྱས་པའམ།]]
            * 1.2.5.4.2 གཉིས་པ་ས་བོན་གྱི་ཉེས་པས་གྱུར་པ་ [[ས་བོན་གྱི་ཉེས་པ་གང་ཞེ་ན། གལ་ཏེ་ཕའི་ཁུ་བ་བྱུང་ལ།]]
            * 1.2.5.4.3 གསུམ་པ་ལས་ཀྱི་ཉེས་པས་གྱུར་པ་ [[ལས་ཀྱི་ཉེས་པ་གང་ཞེ་ན། གལ་ཏེ་ཕའམ་མའམ།]]
         * 1.2.5.5 མངལ་ན་གནས་པ་དེ་ལ་ཡང་དུས་རྣམ་པ་བརྒྱད་ [[མངལ་ན་གནས་པ་དེ་ལ་ཡང་དུས་རྣམ་པ་བརྒྱད་ཡོད་དེ། དུས་རྣམ་པ་བརྒྱད༌[^167]པོ་གང་ཞེ་ན།]]
         * 1.2.5.6 བར་གྱི་བསྐལ་པ་དེ་ཡང་མུ་གེ་དང་ནད་དང་མཚོན་རྣམ་པ་གསུམ་ [[བར་གྱི་བསྐལ་པ་དེ་ཡང་མུ་གེ་དང་ནད་དང་མཚོན་རྣམ་པ་གསུམ་གྱིས༌[^212]ཐལ་བར་འགྱུར་རོ། །]]
         * 1.2.5.7 མཆོག་ཏུ་རྒུད་པ་རྣམ་པ་གསུམ་ [[སེམས་ཅན་དེ་དག་ལ་དེའི་ཚེ་མཆོག་ཏུ་རྒུད་པ་རྣམ་པ་གསུམ་འབྱུང་བར་འགྱུར་ཏེ།]]
            * 1.2.5.7.1 དང་པོ་ཚེ་རྒུད་པ་ [[དེ་ལ་ཚེ་རྒུད་པ་ནི་ཚེའི་ཚད་རེ་ལྟར་རིང་ན་རེ་ལྟར༌[^219]ལོ་བཅུ་ཐུབ་པ་ཡིན་ནོ། །]]
            * 1.2.5.7.2 གཉིས་པ་ལུས་རྒུད་པ་ [[དེ་ལ་ལུས་རྒུད་པ་ནི། ལུས་ཀྱི་ཚད་རེ་ལྟར་རིང་ན་མཐོ་གང་དང་།]]
            * 1.2.5.7.3 གསུམ་པ་ཡོ་བྱད་རྒུད་པ་ [[དེ་ལ་ཡོ་བྱད་རྒུད་པ་ནི། ཁ་ཟས་ཀྱི་མཆོག་ནི༌[^220]ཁྲེ་རྒོད་ཡིན་ནོ། །]]
         * 1.2.5.8 འཆགས་པ་ [[འཆགས་པ་གང་ཞེ་ན། བར་གྱི་བསྐལ་པ་ཉི་ཤུ་པོ་དེ་དག་འདས་ནས༌[^238]ཡང་སེམས་ཅན་རྣམས་ཀྱི་འཆགས་པར་འགྱུར་བའི་ལས་ཀྱི་དབང་གིས།]]
