Enumeration Block 2:
དེ་ལ་བསྙེན་གནས་པའི་སྡོམ་པ་ནི་མདོར་བསྡུ་ན་ཡན་ལག་ལྔས་བསྡུས་པ་ཡིན་ཏེ། ཡན་ལག་ལྔ་གང་ཞེ་ན། གཞན་ལ་གནོད་པ་སྤོང་བ་ཡང་དག་པར་ལེན་པའི་ཡན་ལག་དང་། བདག་དང་གཞན་ལ་གནོད་པ་སྤོང་བ་ཡང་དག་པར་ལེན་པའི་ཡན་ལག་དང་། ཡང་དག་པར་བླངས་པ་ལས་ཉམས་པ་ཕྱིར་གསོ་བའི་ཡན་ལག་དང་། ཡང་དག་པར་བླངས་པ་ལས་མི་ཉམས་པར་བྱ་བའི་ཕྱིར་དྲན་པ་ཉེ་བར་འཇོག་པའི་ཡན་ལག་དང་། དྲན་པ་རྨོངས་པར་མི་འགྱུར་བའི་ཡན་ལག་གོ། །

Enumeration Block 3:
དེ་ལ་རྒྱུ་དུས་ན་དགེ་སློང་གི་སྡོམ་པ་ལེན་པར་མི་འགྱུར་ཞིང་། དགེ་སློང་གི་སྡོམ་པ་འདོད་ཀྱང་འཐོབ་པར་མི་འགྱུར་ཞེ་ན། མདོར་བསྡུ༌[^509]ན་རྒྱུ་དྲུག་གིས་ཏེ། བསམ་པ་ཉམས་པ་དང་། ལུས་ཉམས་པ་དང་། སྐྱེས་པ་ཉིད་ཉམས་པ་དང་། དགེ་བའི་ཆོས་ཉམས་པ་དང་། གཞན་གྱི་དབང་དུ་གྱུར་པ་དང་། གཞན་རྗེས་སུ་སྲུང་བས༌[^510]སོ། །

Enumeration Block 4:
མ་ནིང་ནི་མདོར་བསྡུ་ན་རྣམ་པ་གསུམ་དུ་རིག་པར་བྱ་སྟེ། ཡོངས༌[^523]མ་ནིང་དང་། ཕྱོགས་གཅིག་གི་མ་ནིང་དང་། ཉམས་པའི་མ་ནིང་ངོ་། །

Enumeration Block 5:
རྒྱུ་དུས་ནི་དགེ་བསྙེན་གྱི་སྡོམ་པ་ལེན་པར་མི་འགྱུར་ཞེ་ན། མདོར་བསྡུ་ན་རྒྱུ་གཉིས་ཀྱིས་ཏེ། བསམ་པ་ཉམས་པ་དང་། སྐྱེས་པ་ཉིད་ཉམས་པས་སོ། །

Enumeration Block 6:
དེ་ལ་རྒྱུ་དུས་ན་དགེ་སློང་གི་སྡོམ་པ་བླངས་ཀྱང་གཏོང་བར་འགྱུར་ཞེ་ན། མདོར་བསྡུ་ན་རྒྱུ་ལྔས་ཏེ་བསླབ་པའི་གཞི་འབུལ་བ་དང་། ལྟུང་བའི་རྩ་བ་ལྷག་པར་སྤྱོད་པ་དང་། མཚན་ནུབ་ཅིང་མཚན་གཉིས་སྐྱེས་པ་དང་། དགེ་བའི་རྩ་བ་ཆད་པ་དང་། རིགས་མཐུན་པ་སྤངས་པས་ཀྱང་དགེ་སློང་གི་སྡོམ་པ་བླངས་བ་གཏོང་བར་འགྱུར་རོ། །

Enumeration Block 1:
གཞན་ཡང་དབྱེ་བ་རྣམ་པ་གསུམ་ཡོད་པར་བལྟ་བར༌[^586]བྱ་སྟེ། མྱོང་བའི་དབྱེ་བ་དང་དམིགས་པ་ལ༌[^587]མཚན་མར་འཛིན་པའི་དབྱེ་བ་དང་། གནས་སྐབས་ཀྱི་དབྱེ་བའོ། །
Enumeration Block 2:
དེ་ལ་གཟུགས་ཀྱི་ཕུང་པོའི་རབ་ཏུ་དབྱེ་བ་གང་ཞེ་ན། དེ་ནི་རྣམ་པ་དྲུག་ཏུ་བལྟ་བར་བྱ་སྟེ། དངོས་པོ་དང་མཚན་ཉིད་དང་། རྣམ་པར་ཤེས་པ་གནས་པ་དང་མི་གནས་པ་དང་། རྣམ་པར་ཤེས་པ་ལས་དབེན་པ་དང་མི་དབེན་པ་དང་། འདུ་ཤེས་ཀྱི་སྤྱོད་ཡུལ་དང་མཐའོ། །
Enumeration Block 3:
དེ་ལ་ཚོར་བའི་ཕུང་པོ༌[^602]རབ་ཏུ་དབྱེ་བ་གང་ཞེ་ན། དེ་ནི་རྣམ་པ་ལྔར༌[^603]བལྟ་བར་བྱ་སྟེ། དངོས་པོ་དང་། མཚན་ཉིད་དང་། རབ་ཏུ་སྐྱེ་བ་དང་ཉེ་བར་བརྟགས་པ༌[^604]དང་། ངེས་པར་འབྱུང་བའོ། །
Enumeration Block 4:
དེ་ལ་འདུ་ཤེས་ཀྱི་ཕུང་པོའི་རབ་ཏུ་དབྱེ་བ་གང་ཞེ་ན། དེ་ཡང་རྣམ་པ་ལྔར་བལྟ་བར་བྱ་སྟེ། དངོས་པོ་དང་། མཚན་ཉིད་དང་། ཕྱིན་ཅི་ལོག་དང་། ཕྱིན་ཅི་མ་ལོག་པ་དང་། ཡོངས་སུ་སྤྱོད་པའོ། །
Enumeration Block 5:
དེ་ལ་ཡོངས་སུ་གཅོད་པའི༌[^637]རབ་ཏུ་དབྱེ་བ་ནི་ལྔ་པོ་འདི་དག་ནི་འདུ་ཤེས་ཀྱི་ཡོངས་སུ་གཅོད་པ་ཡིན་ཏེ། ཡུལ་ཡོངས་སུ་གཅོད་པ༌[^638]དང་། མྱོང་བ་ཡོངས་སུ་གཅོད་པ༌[^639]དང་། བརྡ་ཡོངས་སུ་གཅོད་པ༌[^640]དང་། ལོག་པར་ཡོངས་སུ་གཅོད་པ༌[^641]དང་། བདེན་པའི་དོན་ཡོངས་སུ་གཅོད༌[^642]པའོ། །

Enumeration Block 1:
དེ་ལ་རང་གི་མཚན་ཉིད་ནི་སྔ་མ་བཞིན་དུ་རྣམ་པ་དྲུག་ཏུ་བལྟ་བར་བྱའོ། །

Enumeration Block 2:
དེ་ལ་ཡོངས་སུ་གཅོད་པའི༌[^637]རབ་ཏུ་དབྱེ་བ་ནི་ལྔ་པོ་འདི་དག་ནི་འདུ་ཤེས་ཀྱི་ཡོངས་སུ་གཅོད་པ་ཡིན་ཏེ། ཡུལ་ཡོངས་སུ་གཅོད་པ༌[^638]དང་། མྱོང་བ་ཡོངས་སུ་གཅོད་པ༌[^639]དང་། བརྡ་ཡོངས་སུ་གཅོད་པ༌[^640]དང་། ལོག་པར་ཡོངས་སུ་གཅོད་པ༌[^641]དང་། བདེན་པའི་དོན་ཡོངས་སུ་གཅོད༌[^642]པའོ། །

Enumeration Block 3:
དེ་ལ་འདུ་བྱེད་ཀྱི་ཕུང་པོའི་རབ་ཏུ་དབྱེ་བ་གང་ཞེ་ན།

དེ་ཡང་རྣམ་པ་ལྔར་བལྟ་བར་བྱ་སྟེ། ཡུལ་དང་། གནས་སྐབས་དང་། ཀུན་ནས་ཉོན་མོངས་པ་དང་། རྣམ་པར་བྱང་བ་དང་། མངོན་པར་འདུ་བྱེད་པའོ། །

Enumeration Block 4:
དེ་ལ་རྣམ་པར་ཤེས་པའི་ཕུང་པོའི་རབ་ཏུ་དབྱེ་བ་གང་ཞེ་ན།

དེ་ཡང་རྣམ་པ་ལྔར་བལྟ་བར་བྱ་སྟེ། ཀུན་ཏུ་ཞེན་པ་དང་། ཀུན་ནས་ཉོན་མོངས་པ་དང་། གནས་དང་། གནས་པ་དང་། རྣམ་པ་སྣ་ཚོགས་སོ། །

Enumeration Block 1:
དེ་ལ་སེམས་རྣམ་པ་སྣ་ཚོགས་ཀྱི་རབ་ཏུ་དབྱེ་བ་དང་པོའི་རབ་ཏུ་དབྱེ་བ་བཤད་པར་བྱ་སྟེ། ཕྱོགས་ནི་གསུམ་པོ་འདི་དག་ཡིན་ཏེ་འདི་ལྟ་སྟེ། ཏིང་ངེ་འཛིན་གྱི་ཕྱིར་མ་བསྐྱོད་པ་རྣམས་དང་། བསྐྱོད་པ་ཏིང་ངེ་འཛིན་མ་ཐོབ་པ༌[^687]རྣམས་དང་། ཏིང་ངེ་འཛིན་ཐོབ་པ་རྣམས་སོ། །

Enumeration Block 2:
དེ་ལ་ཕུང་པོ་རྣམས་ཀྱི་གོ་རིམས་བསྟན་པའི་རྣམ་པ་གང་ཞེ་ན། དེ་ནི་རྣམ་པ་ལྔར་བལྟ་བར་བྱ་སྟེ། སྐྱེ་བ་ལས་གྱུར་པ་དང་། གཉེན་པོ་ལས་གྱུར་པ་དང་། འཇུག་པ་ལས་གྱུར་པ་དང་། གནས་པ་ལས་གྱུར་པ་དང་། རྣམ་པར་གཞག་པ་ལས་གྱུར་པའོ། །

Enumeration Block 1:
ཆོས་ཀྱི་སྐྱེ་མཆེད་དུ་གཏོགས་པའི་གཟུགས་ནི་རྣམ་པ་གཉིས་ཏེ། རྫས་སུ་ཡོད་པ་དང་བརྟགས་པའི༌[^749]ཡོད་པའོ། །

Enumeration Block 2:

Enumeration Block 1:

Enumeration Block 2:

དེ་ལ་གནས་ངན་ལེན་ནི་མདོར་བསྡུ་ན་རྣམ་པ་གཉིས་ཏེ། ཟག་པའི་གནས་ངན་ལེན་དང་ཟག་པ་དང་བཅས་པའི་གནས་ངན་ལེན་ཏོ། །

Enumeration Block 1:

ཆོས་མངོན་པ་དང་འདུལ་བ་མངོན་པ་ལ་མཁས་པའི་དགེ་སློང་ངམ། དགེ་བསྙེན་ཀུན་ཤེས་པ་ལས་བརྩམས་ཏེ། དྲི་བ་འདྲི་བར༌[^2671]འདོད་པས་ནི་རྣམ་པ་བརྒྱད་ཀྱིས་དྲི་བར་བྱ་སྟེ། རྣམ་པ་བརྒྱད་གང་ཞེ་ན། འདི་ལྟ་སྟེ། ཀུན་ཤེས་པའི་གཞི་དང་། ཀུན་ཤེས་པའི་མི་མཐུན་པའི་ཕྱོགས་དང་། ཀུན་ཤེས་པའི་འབྲས་བུ་དང་ཀུན་ཤེས་པའི་ངོ་བོ་ཉིད་དང་། ཀུན་ཤེས་པའི་འབྲས་བུའི་ཁྱད་པར་དང་། ཀུན་ཤེས་པའི་གནས་དང་། ཀུན་ཤེས་པའི་ཕན་ཡོན་དང་། ཀུན་ཤེས་པ་ཡང་དག་པར་འགྲུབ་པས་སོ། །

Enumeration Block 1:
ཏིང་ངེ་འཛིན་སྒོམ་པ༌[^2766]ནི་རྣམ་པ་བཞི་སྟེ། ཚེ་འདི་ལ་བདེ་བར་གནས་པ་ཐོབ་པར་བྱ་བའི་ཕྱིར་དང་། ཡེ་ཤེས་དང་མཐོང་བ་ཐོབ་པར་བྱ་བའི་ཕྱིར་དང་། ཤེས་རབ་ཀྱི་རབ་ཏུ་དབྱེ་བ་ཐོབ་པར་བྱ་བའི་ཕྱིར་དང་། ཟག་པ་ཟད་པ་ཐོབ་པར་བྱ་བའི་ཕྱིར་རོ། །

Enumeration Block 2:
དེ་ལ་འདོད་ཆགས་དང་བྲལ་བ་ནི་རྣམ་པ་དྲུག་ཏུ་རིག་པར་བྱ་སྟེ། འདི་ལྟ་སྟེ། རང་བཞིན་གྱིས་འདོད་ཆགས་དང་བྲལ་བ་དང་། གནོད་པས་འདོད་ཆགས་དང་བྲལ་བ་དང་། སྟོན་པས་འདོད་ཆགས་དང་བྲལ་བ་དང་། ཡང་དག་ཕུལ་གྱིས་འདོད་ཆགས་དང་བྲལ་བ་དང་། ཀུན་དུ་རྨོངས་པས་འདོད་ཆགས་དང་བྲལ་བ་དང་། གཉེན་པོས་འདོད་ཆགས་དང་བྲལ་བའོ། །

Enumeration Block 3:
དེ་ལ་འདོད་ཆགས་དང་བྲལ་བའི་ཡོངས་སུ་ཉམས་པ་ནི་རྣམ་པ་བཅུར་རིག་པར་བྱ་སྟེ།

Enumeration Block 4:
སེམས་ཀྱི་འཇུག་པ་ནི་མདོར་བསྡུ་ན་རྣམ་པ་ལྔར༌[^2807]རིག་པར་བྱ་སྟེ། ཀུན་རྫོབ་ཀྱི་ཚུལ་རྣམ་པར་གཞག་པ་དང་། དོན་དམ་པའི་ཚུལ་རྣམ་པར་གཞག་པ་དང་། གནས་དང་གནས་པ་རྣམ་པར་གཞག་པ་དང་། ལྷན་ཅིག་དངོས་པོར་རྣམ་པར་གཞག་པ་དང་། ཀུན་ནས་ཉོན་མོངས་པ་དང་། རྣམ་པར་བྱང་བ་རྣམ་པར་གཞག་པས་སོ། །

Enumeration Block 1:
སེམས་ཀྱི་འཇུག་པ་ནི་མདོར་བསྡུ་ན་རྣམ་པ་ལྔར༌[^2807]རིག་པར་བྱ་སྟེ། ཀུན་རྫོབ་ཀྱི་ཚུལ་རྣམ་པར་གཞག་པ་དང་། དོན་དམ་པའི་ཚུལ་རྣམ་པར་གཞག་པ་དང་། གནས་དང་གནས་པ་རྣམ་པར་གཞག་པ་དང་། ལྷན་ཅིག་དངོས་པོར་རྣམ་པར་གཞག་པ་དང་། ཀུན་ནས་ཉོན་མོངས་པ་དང་། རྣམ་པར་བྱང་བ་རྣམ་པར་གཞག་པས་སོ། །
Enumeration Block 2:
མདོར་བསྡུ་ན་རྣམ་པར་ཤེས་པ་ནི་རྣམ་པ་གཉིས་ཏེ། ཀུན་གཞི་རྣམ་པར་ཤེས་པ་དང་། འཇུག་པའི་རྣམ་པར་ཤེས་པའོ། །
Enumeration Block 3:
མདོར་བསྡུ་ན་བདུན་པོ་འདི་དག་ནི་སེམས་མི་སྐྱེ་བའི་རྒྱུ་ཡིན་ཏེ། དེ་དག་གིས༌[^2830]སེམས་སྐྱེ་བར་མི་འགྱུར་རོ། ། བདུན་གང་ཞེ་ན་རྐྱེན་མེད་པ་ལས་ཀྱང་། སེམས་མི་སྐྱེ་བ་དང་། ཡིད་ལ་བྱེད་པ་མེད་པ༌[^2831]དང་། མ་ཐོབ་པ་དང་། མི་མཐུན་པ་དང་། སྤངས་པ་དང་། འགགས་པ༌[^2832]དང་། སྐྱེས་པ་ལས་ཀྱང་སེམས་མི་སྐྱེའོ། །

Enumeration Block 1:
སངས་རྒྱས་དང་ཆོས་དང་དགེ་འདུན་དཀོན་མཆོག་རྣམས་ཀྱི་ཁྱད་པར་ནི་རྣམ་པ་དྲུག་གིས་རིག་པར་བྱ་སྟེ། མཚན་ཉིད་དང་། ཕྲིན་ལས་དང་། མོས་པ་དང་། སྒྲུབ་པ༌[^2868]དང་། རྗེས་སུ་དྲན་པ་དང་། བསོད་ནམས་འཕེལ་བས་སོ། །

Enumeration Block 2:
བྲམ་ཟེའི་ཆོས་ལས་དགེ་སྦྱོང་གི་ཆོས་རྣམ་པ་ལྔས་ཁྱད་པར་དུ་འཕགས་ཏེ། ཆོས་རྣམ་པ་ལྔ་གང་ཞེ་ན། འདི་ལྟ་སྟེ། ཐོས་པའི་ཆོས་དང་། ཚུལ་ཁྲིམས་ཀྱི་ཆོས་དང་། ཡོངས་སུ་གཟུང་བའི༌[^2877]ཆོས་དང་། ལོངས་སྤྱོད་ཀྱི་ཆོས་དང་། རྟོགས་པའི་ཆོས་ཀྱིས་སོ། །

Enumeration Block 3:
སངས་རྒྱས་ཀྱི་བཀའ་དེ་ཡང་མདོར་བསྡུ་ན་ཚུལ་དྲུག་གིས་ཁོང་དུ་ཆུད་པར་བྱ་སྟེ། འདི་ལྟ་སྟེ། དེ་ཁོ་ནའི་དོན་གྱི༌[^2906]ཚུལ་དང་འཐོབ་པའི་ཚུལ་དང་། བཤད་པའི་ཚུལ་དང་། མཐའ་གཉིས་རྣམ་པར་སྤངས་པའི་ཚུལ་དང་། བསམ་གྱིས་མི་ཁྱབ་པའི་ཚུལ་དང་། དགོངས་པའི་ཚུལ་གྱིས་སོ། །

Enumeration Block 4:
དེ་ལ་དེ་ཁོ་ནའི་དོན་ནི་མདོར་བསྡུ་ན་རྣམ་པ་དྲུག་ཏུ་རིག་པར་བྱ་སྟེ། འཇིག་རྟེན་གྱི་གྲགས་པ༌[^2907]དང་། རིགས་པའི༌[^2908]གྲགས་པ་དང་ཉོན་མོངས་པའི་སྒྲིབ་པ་རྣམ་པར་དག་པའི་ཡེ་ཤེས་ཀྱི་སྤྱོད་ཡུལ་དང་། ཤེས་བྱའི་སྒྲིབ་པ་རྣམ་པར་དག་པའི་ཡེ་ཤེས་ཀྱི་སྤྱོད་ཡུལ་དང་། རྣམ་པར་བཞག་པ་དང་། རྣམ་པར་མ་བཞག་པའོ། །

Enumeration Block 5:
ཀུན་རྫོབ་རྣམ་པ་གསུམ་གྱིས་རྣམ་པར་འཇོག་པར་བྱེད་པའི་ཕྱིར་ཏེ། འཇིག་རྟེན་གྱི་ཀུན་རྫོབ་དང་། རིགས་པའི་ཀུན་རྫོབ་དང་། རྟོགས་པའི་ཀུན་རྫོབ་ཀྱིས་སོ། །

Enumeration Block 1:
དེ་ནི་ཀུན་རྫོབ་རྣམ་པ་གསུམ་གྱིས་རྣམ་པར་འཇོག་པར་བྱེད་པའི་ཕྱིར་ཏེ། འཇིག་རྟེན་གྱི་ཀུན་རྫོབ་དང་། རིགས་པའི་ཀུན་རྫོབ་དང་། རྟོགས་པའི་ཀུན་རྫོབ་ཀྱིས་སོ། །

Enumeration Block 2:
འཐོབ་པ་ནི་མདོར་བསྡུ་ན་རྣམ་པ་བཞི་སྟེ། སེམས་ཅན་རྣམས་ཀྱི་ལས་ཀྱི་རྣམ་པར་སྨིན་པ་འཐོབ་པ་དང་། ཉན་ཐོས་ཀྱི་ཐེག་པ་འཐོབ་པ་དང་། རང་སངས་རྒྱས་ཀྱི་ཐེག་པ་འཐོབ་པ་དང་། ཐེག་པ་ཆེན་པོ་འཐོབ་པའོ། །

Enumeration Block 3:
དེ་ལ་ཉན་ཐོས་ཀྱི་ཐེག་པ་འཐོབ་པ་ནི་སྐྱབས་སུ་འགྲོ་བ་ལ་སོགས་པ་ནས། དགེ་སྦྱོང་གི་རྒྱན་གྱི་བར་ལ་བརྟེན༌[^2919]ནས་རྣམ་པ་ལྔ་འཐོབ་པ་གང་ཡིན་པ་སྟེ། ས་འཐོབ་པ་དང་། ཤེས་པ་འཐོབ་པ་དང་། དད་པ་འཐོབ་པ་དང་། འབྲས་བུ་འཐོབ་པ་དང་། ཡོན་ཏན་འཐོབ་པའོ། །

Enumeration Block 4:
དེ་ལ་ས་འཐོབ་པ་ནི་ས་གསུམ་སྟེ། མཐོང་བའི་ས་དང་། བསྒོམ་པའི་ས་དང་། མཐར་ཐུག་པའི་སའོ། །

Enumeration Block 5:
དེ་ལ་ཤེས་པ་འཐོབ་པ་ནི། ཤེས་པ་དགུ་སྟེ། འདི་ལྟ་སྟེ། ཆོས་ཤེས་པ་དང་། རྗེས་སུ་རྟོགས་པ༌[^2920]ཤེས་པ་དང་། སྡུག་བསྔལ་ཤེས་པ་དང་། ཀུན་འབྱུང་བ་ཤེས་པ་དང་། འགོག་པ་ཤེས་པ་དང་། ལམ༌[^2921]ཤེས་པ་དང་། དེ་དག་གི༌[^2922]རྗེས་ལས་ཐོབ་པ༌[^2923]ཀུན་རྫོབ་ཤེས་པ་དང་། ཟད་པ་ཤེས་པ་དང་། མི་སྐྱེ་བ་ཤེས་པའོ། །

Enumeration Block 6:
དེ་ལ་རང་སངས་རྒྱས་ཀྱི་ཐེག་པ་འཐོབ་པ་ནི་མདོར་བསྡུ་ན་རྣམ་པ༌[^2926]གསུམ་སྟེ། ངེས་པར་འབྱེད་པའི་ཆ་དང་མཐུན་པ་འཐོབ་པ་སྔོན་དུ་བཏང་བ་དང་། རྟོགས་པ་སྔོན་དུ་བཏང་བ་དང་། སྔོན་དུ་མ་བཏང་བའོ། །

Enumeration Block 7:
དེ་ལ་ཐེག་པ་ཆེན་པོ་འཐོབ་པ་ནི་རྣམ་པ་བརྒྱད་དེ། སེམས་བསྐྱེད་པ་འཐོབ་པ་དང་། སྙིང་རྗེ་འཐོབ་པ་དང་། ཕ་རོལ་ཏུ་ཕྱིན་པ་འཐོབ་པ་དང་། བསྡུ་བའི་དངོས་པོ་འཐོབ་པ་དང་། ས་འཐོབ་པ་དང་། དཔག་ཏུ་མེད་པ་ལྔ་ལ་དེ་བཞིན་ཉིད་ཁོང་དུ་ཆུད་པ་འཐོབ་པ་དང་། མཐུ་བསམ་གྱིས་མི་ཁྱབ་པ་འཐོབ་པ་དང་། སངས་རྒྱས་ཀྱི་ཆོས་མ་འདྲེས་པ་འཐོབ་པ་གང་ཡིན་པ་སྟེ།

Enumeration Block 8:
དེ་ལ་བཤད་པ་ནི་མདོར་བསྡུ་ན་གནས་གསུམ་གྱིས་བསྡུ་བ༌[^2927]ཡིན་ཏེ། སྡེ་སྣོད་བསྡུ་བ་དང་། མ་མོ་བསྡུ་བ་དང་། དེ་གཉི་ག་བསྡུ་བས་སོ། །

Enumeration Block 9:
དེ་ལ་དེ༌[^2928]གཉི་ག་བསྡུ་བ་ནི། མདོར་བསྡུ་ན་རྣམ་པ་བཅུ་སྟེ། འདི་ལྟ་སྟེ། བདེན་པའི་མཚན་ཉིད་བཤད་པ་དང་། ཡོངས་སུ་ཤེས་པ་བཤད་པ་དང་། སྤང་བ་བཤད་པ་དང་། མངོན་དུ་བྱ་བ་བཤད་པ་དང་། བསྒོམ་པ༌[^2929]བཤད་པ་དང་། དེ་དག་ཉིད་ཀྱི་རྣམ་པ་རབ་ཏུ་དབྱེ་བ་བཤད་པ་དང་། དེ་དག་ཉིད་ཀྱི་གནས་དང་གནས་པའི་འབྲེལ་པ་བཤད་པ་དང་། ཡོངས་སུ་ཤེས་པ་ལ་སོགས་པའི་བར་དུ་གཅོད་པའི་ཆོས་བཤད་པ་དང་། ཡོངས་སུ་ཤེས་པ་ལ་སོགས་པའི་རྗེས་སུ་མཐུན་པའི་ཆོས་བཤད་པ་དང་། ཡོངས་སུ་མི་ཤེས་པ་ལ་སོགས་པ་དང་། ཡོངས་སུ༌[^2930]ཤེས་པ་ལ་སོགས་པའི་ཉེས་དམིགས་དང་ཕན་ཡོན་བཤད་པ་སྟེ།

Enumeration Block 10:
ཡང་མདོར་བསྡུ་ན་བཤད་པ་རྣམ་པ་བཅུ་གཉིས་ཡོད་དོ།[^2931] །
འདི་ལྟ་སྟེ། དངོས་པོ་བཤད་པ་དང་། མིང་གི་རྣམ་གྲངས་བཤད་པ་དང་། རང་གི་གཞུང་ལུགས་བརྟག་པ་བཤད་པ་དང་། གཞན་གྱི་གཞུང་ལུགས་བརྟག་པ་བཤད་པ་དང་། དྲང་བའི་དོན་བཤད་པ་དང་། ངེས་པའི་དོན་བཤད་པ་དང་། ཀུན་རྫོབ་ཀྱི་བདེན་པ་བཤད་པ་དང་། དོན་དམ་པའི་བདེན་པ་བཤད་པ་དང་། གསང་བ་བཤད་པ་དང་། རྣམ་པར་ཕྱེ་བ་བཤད་པ་དང་། ལན་གདབ་པའི་དངོས་པོ་བཤད་པ་དང་། ལན་མི་གདབ་པའི་དངོས་པོ་བཤད་པའོ། །

Enumeration Block 11:
དེ་ནི་མདོར་བསྡུ་ན་རྣམ་པ་དྲུག་ཏུ་བལྟ་བར༌[^2952]བྱ་སྟེ། ཡོད་པ་མ་ཡིན་པ་ལ་སྒྲོ་འདོགས་པའི་མཐའ་རྣམ་པར་སྤང་བ་དང་། ཡོད་པ་ལ་སྐུར་པ་འདེབས་པའི་མཐའ་རྣམ་པར་སྤང་བ་དང་། རྟག་པར་འཛིན་པའི་མཐའ་རྣམ་པར་སྤང་བ་དང་། ཆད་པར་འཛིན་པའི་མཐའ་རྣམ་པར་སྤང་བ་དང་། འདོད་པའི་བསོད་ཉམས་ལ་སྦྱོར་བའི་མཐའ་རྣམ་པར་སྤང་བ་དང་། བདག་ཉིད་ངལ་བར་སྦྱོར་བའི་མཐའ་རྣམ་པར་སྤང་པའོ། །

Enumeration Block 12:
མདོར་བསྡུ་ན་བསམ་གྱིས་མི་ཁྱབ་པ་དྲུག་སྟེ། བདག་ལ་སེམས་པ་དང་། སེམས་ཅན་ལ་སེམས་པ་དང་། འཇིག་རྟེན་ལ་སེམས་པ་དང་། སེམས་ཅན་རྣམས་ཀྱི་ལས་ཀྱི་རྣམ་པར་སྨིན་པ་ལ་སེམས་པ་དང་། བསམ་གཏན་པ་རྣམས་ཀྱི་བསམ་གཏན་པའི་ཡུལ་དང་། སངས་རྒྱས་རྣམས་ཀྱི་སངས་རྒྱས་ཀྱི་ཡུལ་ལོ། །

Enumeration Block 13:
མདོར་བསྡུ་ན་རྣམ་པ་བཅུ་དྲུག་སྟེ། ཡང་དག་པར་སྟོན་པའི་དགོངས་པ་དང་། འདུན་པ་བཟློག་པའི༌[^2960]དགོངས་པ་དང་། ཡང་དག་པར་འཛིན་དུ་འཇུག་པའི་དགོངས་པ་དང་། ཡང་དག་པར་གཟེངས་བསྟོད་པའི་དགོངས་པ་དང་། ཡང་དག་པར་རབ་ཏུ་དགའ་བར་མཛད་པའི་དགོངས་པ་དང་། གཟུད་པའི་དགོངས་པ་དང་། ཐེ་ཚོམ་གཅད་པའི༌[^2961]དགོངས་པ་དང་། ཡོངས་སུ་སྨིན་པར་བྱ་བའི་དགོངས་པ་དང་། ཏིང་ངེ་འཛིན་དུ་བྱ་བའི་དགོངས་པ་དང་། རྣམ་པར་གྲོལ་བར་བྱ་བའི་དགོངས་པ་དང་། དོན་གཞན་དང་འབྲེལ་པའི་དགོངས་པ་དང་། རྟོགས་པར༌[^2962]བྱེད་པ་རྣམས་ལ་ཁ་ན་མ་ཐོ་བ་མེད་པའི་དགའ་བ་དང་མཆོག་ཏུ་དགའ་བ་སྐྱེད་པའི༌[^2963]དགོངས་པ་དང་། སྨྲ་བ་པོ་ལ་ཉན་པ་རྣམས་རི་མོ་ཆེར་བསྐྱེད་པར་བྱ་བའི་དགོངས་པ་དང་། ཆོས་ཀྱི་ཚུལ་འཇུག་པར་བྱ་བའི་དགོངས་པ་དང་། དགེ་བ་མང་བར་བྱ་བའི་དགོངས་པ་དང་། མཚན་མ་ཐམས་ཅད་ཟིལ་གྱིས་མནན་པའི་དགོངས་པའོ། །

Enumeration Block 1:
ཆོས་རྣམས་ཀྱི་རབ་ཏུ་དབྱེ་བའི་ཚུལ་ཡང་མདོར༌[^3027]བསྡུ་ན་རྣམ་པ་ལྔར་རིག་པར་བྱ་སྟེ། འདི་ལྟ་སྟེ་རྟགས་དང་། ངོ་བོ་ཉིད་དང་། ལས་དང་། ཆོས་དང་། རྒྱུ་དང་འབྲས་བུའོ། །
Enumeration Block 2:
