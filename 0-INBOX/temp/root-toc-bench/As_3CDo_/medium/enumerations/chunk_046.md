Enumeration Block 1:
དེ་ལ་ཉོན་མོངས་པའི་ཀུན་ནས་ཉོན་མོངས་པའི་རབ་ཏུ་དབྱེ་བ་ནི་རྣམ་པ་ལྔས་རྣམ་པར་གཞག་སྟེ། ལྔ་གང་ཞེ་ན།
ངོ་བོ་ཉིད་དང་། ངོ་བོ་ཉིད་ཀྱི་རབ་ཏུ་དབྱེ་བ་དང་། ཀུན་ནས་ཉོན་མོངས་པའི་རབ་ཏུ་དབྱེ་བ་དང་། སྤོང་བའི་རབ་ཏུ་དབྱེ་བ༌[^1616]དང་། གཉེན་པོའི་རབ་ཏུ་དབྱེ་བས་སོ། །

Enumeration Block 2:
མདོར་བསྡུ་ན་ངོ་བོ་ཉིད་ནི་རྣམ་པ་གཉིས་ཏེ། ཉོན་མོངས་པ་རྣམས་ནི་ལྟ་བའི་ངོ་བོ་ཉིད་དང་། ལྟ་བ་མ་ཡིན་པའི་ངོ་བོ་ཉིད་དོ། །

Enumeration Block 3:
མདོར་བསྡུ་ན་རྣམ་པ་བཅུར་བལྟ་བར་བྱ་སྟེ། ལྟ་བའི་ངོ་བོ་ཉིད་ཀྱི་ཉོན་མོངས་པ་རྣམས་ཀྱི་རབ་ཏུ་དབྱེ་བ་རྣམ་པ་ལྔ་དང་ལྟ་བ་མ་ཡིན་པའི་ངོ་བོ་ཉིད་རྣམས་ཀྱི་རབ་ཏུ་དབྱེ་བ་རྣམ་པ་ལྔ་སྟེ། དེ་དག་བསྡུས་ནས༌[^1618]ཉོན་མོངས་པའི༌[^1619]རབ་ཏུ་དབྱེ་བ་རྣམ་པ་བཅུར་འགྱུར་ཏེ། འདི་ལྟ་སྟེ། འཇིག་ཚོགས་ལ་ལྟ་བ་དང་མཐར་འཛིན་པར་ལྟ་བ་དང་ལོག་པར་ལྟ་བ་དང་ལྟ་བ་མཆོག་ཏུ་འཛིན་པ་དང་ཚུལ་ཁྲིམས་དང་བརྟུལ་ཞུགས་མཆོག་ཏུ་འཛིན་པ་དང་། འདོད་ཆགས་དང་ཁོང་ཁྲོ་བ་དང་། ང་རྒྱལ་དང་མ་རིག་པ་དང་ཐེ་ཚོམ་མོ། །

Enumeration Block 4:
དེའང་རྣམ་པ་གཉིས་སུ་རིག་པར་བྱ་སྟེ། ལྷན་ཅིག་སྐྱེས་པ་དང་ཀུན་བརྟགས་པའོ། །

Enumeration Block 5:
དེའང་མདོར་བསྡུ༌[^1624]ན་རྣམ་པ་གཉིས་སུ་བལྟ་བར་བྱ་སྟེ། སྒྲོ་འདོགས་པར་བྱེད་པ་དང་སྐུར་པ་འདེབས་པར་བྱེད་པའོ། །
