Enumeration Block 1:
དེ་ལ་གནས་ངན་ལེན་ནི་མདོར་བསྡུ་ན་རྣམ་པ་གཉིས་ཏེ། ཟག་པའི་གནས་ངན་ལེན་དང་ཟག་པ་དང་བཅས་པའི་གནས་ངན་ལེན་ཏོ། །

Enumeration Block 2:
དེའི་ཁྱབ་པར་འཇུག་པ་ཉིད་ཀྱང་རྣམ་པ་གསུམ་དུ་རིག་པར་བྱ་སྟེ།

Enumeration Block 3:
རྣམ་གྲངས་གཞན་ཡང་ཤེས་བྱ་རབ་ཏུ་རྟོགས་པར༌[^1842]བྱ་བ་དང་སྤོང་བ་མངོན་དུ་བྱ་བ་ལ་གེགས་སུ་གྱུར་པའི་ཆོས་ནི་གཉིས་ཏེ། ལོག་པར་བསྒྲུབ་པའི་རྒྱུ་དང་སྡུག་བསྔལ་སྐྱེ་བའི་རྒྱུའོ། །

Enumeration Block 4:
ཆོས་དེ་གཉིས་ཀྱི་རྒྱུ་ཡང་རྣམ་པ་གཉིས་ཏེ།

Enumeration Block 5:
གཞན་ཡང་མངོན་པར་ཞེན་པ་ནི་གཉིས་ཡོད་དེ། དབང་པོ་དང་ཡུལ་ལ་མངོན་པར་ཞེན་པ་དང་། སེམས་ཅན་གཅིག་ལ་གཅིག་མངོན་པར་ཞེན་པའོ། །
