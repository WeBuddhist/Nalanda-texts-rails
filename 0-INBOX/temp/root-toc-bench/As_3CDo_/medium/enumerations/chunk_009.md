Enumeration Block 1:
དེ་ལ་དགེ་བསྙེན་གྱི་སྡོམ་པ་ནི་ཡན་ལག་གསུམ་གྱིས་བསྡུས་པ་ཡིན་ཏེ། ཡན་ལག་གསུམ་གང་ཞེ་ན། གཞན་ལ་གནོད་པའི་དངོས་པོ་ཆེན་པོ༌[^474]སྤོང་བ་ཡང་དག་པར་བླང་བའི་ཡན་ལག་དང་། ཡང་དག་པར་བླངས་པ་ལས་ཉམས་པ་ཕྱིར་གསོ་བའི་ཡན་ལག་དང་། ཡང་དག་པར་བླངས་པ་ལས་མི་ཉམས་པའི་ཡན་ལག་གོ། །

Enumeration Block 2:
དེ་ལ་བསྙེན་གནས་པའི་སྡོམ་པ་ནི་མདོར་བསྡུ་ན་ཡན་ལག་ལྔས་བསྡུས་པ་ཡིན་ཏེ། ཡན་ལག་ལྔ་གང་ཞེ་ན། གཞན་ལ་གནོད་པ་སྤོང་བ་ཡང་དག་པར་ལེན་པའི་ཡན་ལག་དང་། བདག་དང་གཞན་ལ་གནོད་པ་སྤོང་བ་ཡང་དག་པར་ལེན་པའི་ཡན་ལག་དང་། ཡང་དག་པར་བླངས་པ་ལས་ཉམས་པ་ཕྱིར་གསོ་བའི་ཡན་ལག་དང་། ཡང་དག་པར་བླངས་པ་ལས་མི་ཉམས་པར་བྱ་བའི་ཕྱིར་དྲན་པ་ཉེ་བར་འཇོག་པའི་ཡན་ལག་དང་། དྲན་པ་རྨོངས་པར་མི་འགྱུར་བའི་ཡན་ལག་གོ། །

Enumeration Block 3:
དེ་ལ་རྒྱུ་དུས་ན་དགེ་སློང་གི་སྡོམ་པ་ལེན་པར་མི་འགྱུར་ཞིང་། དགེ་སློང་གི་སྡོམ་པ་འདོད་ཀྱང་འཐོབ་པར་མི་འགྱུར་ཞེ་ན། མདོར་བསྡུ༌[^509]ན་རྒྱུ་དྲུག་གིས་ཏེ། བསམ་པ་ཉམས་པ་དང་། ལུས་ཉམས་པ་དང་། སྐྱེས་པ་ཉིད་ཉམས་པ་དང་། དགེ་བའི་ཆོས་ཉམས་པ་དང་། གཞན་གྱི་དབང་དུ་གྱུར་པ་དང་། གཞན་རྗེས་སུ་སྲུང་བས༌[^510]སོ། །

Enumeration Block 4:
མ་ནིང་ནི་མདོར་བསྡུ་ན་རྣམ་པ་གསུམ་དུ་རིག་པར་བྱ་སྟེ། ཡོངས༌[^523]མ་ནིང་དང་། ཕྱོགས་གཅིག་གི་མ་ནིང་དང་། ཉམས་པའི་མ་ནིང་ངོ་། །

Enumeration Block 5:
རྒྱུ་དུས་ནི་དགེ་བསྙེན་གྱི་སྡོམ་པ་ལེན་པར་མི་འགྱུར་ཞེ་ན། མདོར་བསྡུ་ན་རྒྱུ་གཉིས་ཀྱིས་ཏེ། བསམ་པ་ཉམས་པ་དང་། སྐྱེས་པ་ཉིད་ཉམས་པས་སོ། །

Enumeration Block 6:
དེ་ལ་རྒྱུ་དུས་ན་དགེ་སློང་གི་སྡོམ་པ་བླངས་ཀྱང་གཏོང་བར་འགྱུར་ཞེ་ན། མདོར་བསྡུ་ན་རྒྱུ་ལྔས་ཏེ་བསླབ་པའི་གཞི་འབུལ་བ་དང་། ལྟུང་བའི་རྩ་བ་ལྷག་པར་སྤྱོད་པ་དང་། མཚན་ནུབ་ཅིང་མཚན་གཉིས་སྐྱེས་པ་དང་། དགེ་བའི་རྩ་བ་ཆད་པ་དང་། རིགས་མཐུན་པ་སྤངས་པས་ཀྱང་དགེ་སློང་གི་སྡོམ་པ་བླངས་བ་གཏོང་བར་འགྱུར་རོ། །
