Enumeration Block 1:
དེ་ནི་ཀུན་རྫོབ་རྣམ་པ་གསུམ་གྱིས་རྣམ་པར་འཇོག་པར་བྱེད་པའི་ཕྱིར་ཏེ། འཇིག་རྟེན་གྱི་ཀུན་རྫོབ་དང་། རིགས་པའི་ཀུན་རྫོབ་དང་། རྟོགས་པའི་ཀུན་རྫོབ་ཀྱིས་སོ། །

Enumeration Block 2:
འཐོབ་པ་ནི་མདོར་བསྡུ་ན་རྣམ་པ་བཞི་སྟེ། སེམས་ཅན་རྣམས་ཀྱི་ལས་ཀྱི་རྣམ་པར་སྨིན་པ་འཐོབ་པ་དང་། ཉན་ཐོས་ཀྱི་ཐེག་པ་འཐོབ་པ་དང་། རང་སངས་རྒྱས་ཀྱི་ཐེག་པ་འཐོབ་པ་དང་། ཐེག་པ་ཆེན་པོ་འཐོབ་པའོ། །

Enumeration Block 3:
དེ་ལ་ཉན་ཐོས་ཀྱི་ཐེག་པ་འཐོབ་པ་ནི་སྐྱབས་སུ་འགྲོ་བ་ལ་སོགས་པ་ནས། དགེ་སྦྱོང་གི་རྒྱན་གྱི་བར་ལ་བརྟེན༌[^2919]ནས་རྣམ་པ་ལྔ་འཐོབ་པ་གང་ཡིན་པ་སྟེ། ས་འཐོབ་པ་དང་། ཤེས་པ་འཐོབ་པ་དང་། དད་པ་འཐོབ་པ་དང་། འབྲས་བུ་འཐོབ་པ་དང་། ཡོན་ཏན་འཐོབ་པའོ། །

Enumeration Block 4:
དེ་ལ་ས་འཐོབ་པ་ནི་ས་གསུམ་སྟེ། མཐོང་བའི་ས་དང་། བསྒོམ་པའི་ས་དང་། མཐར་ཐུག་པའི་སའོ། །

Enumeration Block 5:
དེ་ལ་ཤེས་པ་འཐོབ་པ་ནི། ཤེས་པ་དགུ་སྟེ། འདི་ལྟ་སྟེ། ཆོས་ཤེས་པ་དང་། རྗེས་སུ་རྟོགས་པ༌[^2920]ཤེས་པ་དང་། སྡུག་བསྔལ་ཤེས་པ་དང་། ཀུན་འབྱུང་བ་ཤེས་པ་དང་། འགོག་པ་ཤེས་པ་དང་། ལམ༌[^2921]ཤེས་པ་དང་། དེ་དག་གི༌[^2922]རྗེས་ལས་ཐོབ་པ༌[^2923]ཀུན་རྫོབ་ཤེས་པ་དང་། ཟད་པ་ཤེས་པ་དང་། མི་སྐྱེ་བ་ཤེས་པའོ། །

Enumeration Block 6:
དེ་ལ་རང་སངས་རྒྱས་ཀྱི་ཐེག་པ་འཐོབ་པ་ནི་མདོར་བསྡུ་ན་རྣམ་པ༌[^2926]གསུམ་སྟེ། ངེས་པར་འབྱེད་པའི་ཆ་དང་མཐུན་པ་འཐོབ་པ་སྔོན་དུ་བཏང་བ་དང་། རྟོགས་པ་སྔོན་དུ་བཏང་བ་དང་། སྔོན་དུ་མ་བཏང་བའོ། །

Enumeration Block 7:
དེ་ལ་ཐེག་པ་ཆེན་པོ་འཐོབ་པ་ནི་རྣམ་པ་བརྒྱད་དེ། སེམས་བསྐྱེད་པ་འཐོབ་པ་དང་། སྙིང་རྗེ་འཐོབ་པ་དང་། ཕ་རོལ་ཏུ་ཕྱིན་པ་འཐོབ་པ་དང་། བསྡུ་བའི་དངོས་པོ་འཐོབ་པ་དང་། ས་འཐོབ་པ་དང་། དཔག་ཏུ་མེད་པ་ལྔ་ལ་དེ་བཞིན་ཉིད་ཁོང་དུ་ཆུད་པ་འཐོབ་པ་དང་། མཐུ་བསམ་གྱིས་མི་ཁྱབ་པ་འཐོབ་པ་དང་། སངས་རྒྱས་ཀྱི་ཆོས་མ་འདྲེས་པ་འཐོབ་པ་གང་ཡིན་པ་སྟེ།

Enumeration Block 8:
དེ་ལ་བཤད་པ་ནི་མདོར་བསྡུ་ན་གནས་གསུམ་གྱིས་བསྡུ་བ༌[^2927]ཡིན་ཏེ། སྡེ་སྣོད་བསྡུ་བ་དང་། མ་མོ་བསྡུ་བ་དང་། དེ་གཉི་ག་བསྡུ་བས་སོ། །

Enumeration Block 9:
དེ་ལ་དེ༌[^2928]གཉི་ག་བསྡུ་བ་ནི། མདོར་བསྡུ་ན་རྣམ་པ་བཅུ་སྟེ། འདི་ལྟ་སྟེ། བདེན་པའི་མཚན་ཉིད་བཤད་པ་དང་། ཡོངས་སུ་ཤེས་པ་བཤད་པ་དང་། སྤང་བ་བཤད་པ་དང་། མངོན་དུ་བྱ་བ་བཤད་པ་དང་། བསྒོམ་པ༌[^2929]བཤད་པ་དང་། དེ་དག་ཉིད་ཀྱི་རྣམ་པ་རབ་ཏུ་དབྱེ་བ་བཤད་པ་དང་། དེ་དག་ཉིད་ཀྱི་གནས་དང་གནས་པའི་འབྲེལ་པ་བཤད་པ་དང་། ཡོངས་སུ་ཤེས་པ་ལ་སོགས་པའི་བར་དུ་གཅོད་པའི་ཆོས་བཤད་པ་དང་། ཡོངས་སུ་ཤེས་པ་ལ་སོགས་པའི་རྗེས་སུ་མཐུན་པའི་ཆོས་བཤད་པ་དང་། ཡོངས་སུ་མི་ཤེས་པ་ལ་སོགས་པ་དང་། ཡོངས་སུ༌[^2930]ཤེས་པ་ལ་སོགས་པའི་ཉེས་དམིགས་དང་ཕན་ཡོན་བཤད་པ་སྟེ།

Enumeration Block 10:
ཡང་མདོར་བསྡུ་ན་བཤད་པ་རྣམ་པ་བཅུ་གཉིས་ཡོད་དོ།[^2931] །
འདི་ལྟ་སྟེ། དངོས་པོ་བཤད་པ་དང་། མིང་གི་རྣམ་གྲངས་བཤད་པ་དང་། རང་གི་གཞུང་ལུགས་བརྟག་པ་བཤད་པ་དང་། གཞན་གྱི་གཞུང་ལུགས་བརྟག་པ་བཤད་པ་དང་། དྲང་བའི་དོན་བཤད་པ་དང་། ངེས་པའི་དོན་བཤད་པ་དང་། ཀུན་རྫོབ་ཀྱི་བདེན་པ་བཤད་པ་དང་། དོན་དམ་པའི་བདེན་པ་བཤད་པ་དང་། གསང་བ་བཤད་པ་དང་། རྣམ་པར་ཕྱེ་བ་བཤད་པ་དང་། ལན་གདབ་པའི་དངོས་པོ་བཤད་པ་དང་། ལན་མི་གདབ་པའི་དངོས་པོ་བཤད་པའོ། །

Enumeration Block 11:
དེ་ནི་མདོར་བསྡུ་ན་རྣམ་པ་དྲུག་ཏུ་བལྟ་བར༌[^2952]བྱ་སྟེ། ཡོད་པ་མ་ཡིན་པ་ལ་སྒྲོ་འདོགས་པའི་མཐའ་རྣམ་པར་སྤང་བ་དང་། ཡོད་པ་ལ་སྐུར་པ་འདེབས་པའི་མཐའ་རྣམ་པར་སྤང་བ་དང་། རྟག་པར་འཛིན་པའི་མཐའ་རྣམ་པར་སྤང་བ་དང་། ཆད་པར་འཛིན་པའི་མཐའ་རྣམ་པར་སྤང་བ་དང་། འདོད་པའི་བསོད་ཉམས་ལ་སྦྱོར་བའི་མཐའ་རྣམ་པར་སྤང་བ་དང་། བདག་ཉིད་ངལ་བར་སྦྱོར་བའི་མཐའ་རྣམ་པར་སྤང་པའོ། །

Enumeration Block 12:
མདོར་བསྡུ་ན་བསམ་གྱིས་མི་ཁྱབ་པ་དྲུག་སྟེ། བདག་ལ་སེམས་པ་དང་། སེམས་ཅན་ལ་སེམས་པ་དང་། འཇིག་རྟེན་ལ་སེམས་པ་དང་། སེམས་ཅན་རྣམས་ཀྱི་ལས་ཀྱི་རྣམ་པར་སྨིན་པ་ལ་སེམས་པ་དང་། བསམ་གཏན་པ་རྣམས་ཀྱི་བསམ་གཏན་པའི་ཡུལ་དང་། སངས་རྒྱས་རྣམས་ཀྱི་སངས་རྒྱས་ཀྱི་ཡུལ་ལོ། །

Enumeration Block 13:
མདོར་བསྡུ་ན་རྣམ་པ་བཅུ་དྲུག་སྟེ། ཡང་དག་པར་སྟོན་པའི་དགོངས་པ་དང་། འདུན་པ་བཟློག་པའི༌[^2960]དགོངས་པ་དང་། ཡང་དག་པར་འཛིན་དུ་འཇུག་པའི་དགོངས་པ་དང་། ཡང་དག་པར་གཟེངས་བསྟོད་པའི་དགོངས་པ་དང་། ཡང་དག་པར་རབ་ཏུ་དགའ་བར་མཛད་པའི་དགོངས་པ་དང་། གཟུད་པའི་དགོངས་པ་དང་། ཐེ་ཚོམ་གཅད་པའི༌[^2961]དགོངས་པ་དང་། ཡོངས་སུ་སྨིན་པར་བྱ་བའི་དགོངས་པ་དང་། ཏིང་ངེ་འཛིན་དུ་བྱ་བའི་དགོངས་པ་དང་། རྣམ་པར་གྲོལ་བར་བྱ་བའི་དགོངས་པ་དང་། དོན་གཞན་དང་འབྲེལ་པའི་དགོངས་པ་དང་། རྟོགས་པར༌[^2962]བྱེད་པ་རྣམས་ལ་ཁ་ན་མ་ཐོ་བ་མེད་པའི་དགའ་བ་དང་མཆོག་ཏུ་དགའ་བ་སྐྱེད་པའི༌[^2963]དགོངས་པ་དང་། སྨྲ་བ་པོ་ལ་ཉན་པ་རྣམས་རི་མོ་ཆེར་བསྐྱེད་པར་བྱ་བའི་དགོངས་པ་དང་། ཆོས་ཀྱི་ཚུལ་འཇུག་པར་བྱ་བའི་དགོངས་པ་དང་། དགེ་བ་མང་བར་བྱ་བའི་དགོངས་པ་དང་། མཚན་མ་ཐམས་ཅད་ཟིལ་གྱིས་མནན་པའི་དགོངས་པའོ། །
