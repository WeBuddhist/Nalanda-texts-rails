Enumeration Block 1:
སངས་རྒྱས་དང་ཆོས་དང་དགེ་འདུན་དཀོན་མཆོག་རྣམས་ཀྱི་ཁྱད་པར་ནི་རྣམ་པ་དྲུག་གིས་རིག་པར་བྱ་སྟེ། མཚན་ཉིད་དང་། ཕྲིན་ལས་དང་། མོས་པ་དང་། སྒྲུབ་པ༌[^2868]དང་། རྗེས་སུ་དྲན་པ་དང་། བསོད་ནམས་འཕེལ་བས་སོ། །

Enumeration Block 2:
བྲམ་ཟེའི་ཆོས་ལས་དགེ་སྦྱོང་གི་ཆོས་རྣམ་པ་ལྔས་ཁྱད་པར་དུ་འཕགས་ཏེ། ཆོས་རྣམ་པ་ལྔ་གང་ཞེ་ན། འདི་ལྟ་སྟེ། ཐོས་པའི་ཆོས་དང་། ཚུལ་ཁྲིམས་ཀྱི་ཆོས་དང་། ཡོངས་སུ་གཟུང་བའི༌[^2877]ཆོས་དང་། ལོངས་སྤྱོད་ཀྱི་ཆོས་དང་། རྟོགས་པའི་ཆོས་ཀྱིས་སོ། །

Enumeration Block 3:
སངས་རྒྱས་ཀྱི་བཀའ་དེ་ཡང་མདོར་བསྡུ་ན་ཚུལ་དྲུག་གིས་ཁོང་དུ་ཆུད་པར་བྱ་སྟེ། འདི་ལྟ་སྟེ། དེ་ཁོ་ནའི་དོན་གྱི༌[^2906]ཚུལ་དང་འཐོབ་པའི་ཚུལ་དང་། བཤད་པའི་ཚུལ་དང་། མཐའ་གཉིས་རྣམ་པར་སྤངས་པའི་ཚུལ་དང་། བསམ་གྱིས་མི་ཁྱབ་པའི་ཚུལ་དང་། དགོངས་པའི་ཚུལ་གྱིས་སོ། །

Enumeration Block 4:
དེ་ལ་དེ་ཁོ་ནའི་དོན་ནི་མདོར་བསྡུ་ན་རྣམ་པ་དྲུག་ཏུ་རིག་པར་བྱ་སྟེ། འཇིག་རྟེན་གྱི་གྲགས་པ༌[^2907]དང་། རིགས་པའི༌[^2908]གྲགས་པ་དང་ཉོན་མོངས་པའི་སྒྲིབ་པ་རྣམ་པར་དག་པའི་ཡེ་ཤེས་ཀྱི་སྤྱོད་ཡུལ་དང་། ཤེས་བྱའི་སྒྲིབ་པ་རྣམ་པར་དག་པའི་ཡེ་ཤེས་ཀྱི་སྤྱོད་ཡུལ་དང་། རྣམ་པར་བཞག་པ་དང་། རྣམ་པར་མ་བཞག་པའོ། །

Enumeration Block 5:
ཀུན་རྫོབ་རྣམ་པ་གསུམ་གྱིས་རྣམ་པར་འཇོག་པར་བྱེད་པའི་ཕྱིར་ཏེ། འཇིག་རྟེན་གྱི་ཀུན་རྫོབ་དང་། རིགས་པའི་ཀུན་རྫོབ་དང་། རྟོགས་པའི་ཀུན་རྫོབ་ཀྱིས་སོ། །
