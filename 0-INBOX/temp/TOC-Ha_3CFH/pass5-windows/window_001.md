* 2. བསྟོད་པ [[བརྒྱ་བྱིན་གྱིས་གསོལ་པ། བཅོམ་ལྡན་འདས་ཤེས་རབ་ཀྱི་ཕ་རོལ་ཏུ་ཕྱིན་པ་འདི་ནི་ཡོན་ཏན་ཐམས་ཅད༌[^218]ཡོངས་སུ་རྫོགས་པར་བགྱི་བའི་སླད་དུ]]
   * 2.1 བསྟོད་པ་ཙམ་དང་པོ [[བརྒྱ་བྱིན་གྱིས་གསོལ་པ། བཅོམ་ལྡན་འདས་ཤེས་རབ་ཀྱི་ཕ་རོལ་ཏུ་ཕྱིན་པ་འདི་ནི་ཡོན་ཏན་ཐམས་ཅད༌[^218]ཡོངས་སུ་རྫོགས་པར་བགྱི་བའི་སླད་དུ]]
   * 2.2 བསྟོད་པ་ཙམ་གཉིས་པ [[ཀཽ་ཤི་ཀ་གཞན་ཡང་རིགས་ཀྱི་བུའམ། རིགས་ཀྱི་བུ་མོ་གང་ལ་ལས་ཤེས་རབ་ཀྱི་ཕ་རོལ་ཏུ་ཕྱིན་པ་འདི་ཇི་སྐད་དུ་བསྟན་པ་འདི]]
   * 2.3 བསྟོད་པ་ཙམ་གསུམ་པ [[ཀཽ་ཤི་ཀ་སེམས་ཅན་གཅིག་ཅིག་རྒྱུན་དུ་ཞུགས་པའི་འབྲས་བུ་ལ་བཞག་ན་དེའི་བསོད་ནམས་མང་དུ་འཕེལ་གྱི།]]
   * 2.4 བསྟོད་པ་ཙམ་བཞི་པ [[དེ་བཞིན་དུ་ལན་ཅིག་ཕྱིར་འོང་བའི་འབྲས་བུ་ལ་སེམས་ཅན་གཅིག་ཅིག་བཞག་ན་དེའི་བསོད་ནམས་མང་དུ་འཕེལ་གྱི།]]
   * 2.5 བསྟོད་པ་ཙམ་ལྔ་པ [[དེ་བཞིན་དུ་ཕྱིར་མི་འོང་བའི་འབྲས་བུ་ལ་སེམས་ཅན་གཅིག་ཅིག་བཞག་ན་དེའི་བསོད་ནམས་མང་དུ་འཕེལ་གྱི།]]
   * 2.6 བསྟོད་པ་ཙམ་དྲུག་པ [[དེ་བཞིན་དུ་སེམས་ཅན་གཅིག་ཅིག་དགྲ་བཅོམ་པ་ཉིད་ལ་བཞག་ན་དེའི་བསོད་ནམས་མང་དུ་འཕེལ་གྱི།]]
   * 2.7 བསྟོད་པ་ཙམ་བདུན་པ [[དེ་བཞིན་དུ་སེམས་ཅན་གཅིག་ཅིག་རང་བྱང་ཆུབ་ལ་བཞག་ན་དེའི་བསོད་ནམས་མང་དུ་འཕེལ་གྱི།]]
   * 2.8 བསྟོད་པ་ཙམ་བརྒྱད་པ [[རིགས་ཀྱི་བུའམ། རིགས་ཀྱི་བུ་མོ་ལ་ལ་ཞིག་གིས་འཛམ་བུའི་གླིང་གི་སེམས་ཅན་རྣམས་རྒྱུན་དུ་ཞུགས་པའི་འབྲས་བུ་ལ་བཀོད་པ་བས།]]
   * 2.9 བསྟོད་པ་ཙམ་དགུ་པ [[དེ་བཞིན་དུ་ལ་ལ་ཞིག་གིས་འཛམ་བུའི་གླིང་གི༌[^255]སེམས་ཅན་ཐམས་ཅད་ལན་ཅིག་ཕྱིར་འོང་པའི་འབྲས་བུ་ལ་བཀོད་པ་བས།]]
* 3. བཀུར་བ [[དེ་བཞིན་དུ་ལ་ལ་ཞིག་གིས་འཛམ་བུའི་གླིང་གི་སེམས་ཅན་ཐམས་ཅད་ཕྱིར་མི་འོང་བའི་འབྲས་བུ་ལ་བཀོད་པ་བས།]]
   * 3.1 བཀུར་བ་ཙམ་དང་པོ [[དེ་བཞིན་དུ་ལ་ལ་ཞིག་གིས་འཛམ་བུའི་གླིང་གི་སེམས་ཅན་ཐམས་ཅད་ཕྱིར་མི་འོང་བའི་འབྲས་བུ་ལ་བཀོད་པ་བས།]]
   * 3.2 བཀུར་བ་ཙམ་གཉིས་པ [[དེ་བཞིན་དུ་ལ་ལ་ཞིག་གིས་འཛམ་བུའི་གླིང་གི་སེམས་ཅན་ཐམས་ཅད་དགྲ་བཅོམ་པ་ཉིད་ལ་རབ་ཏུ་བཀོད་པ་བས།]]
   * 3.3 བཀུར་བ་ཙམ་གསུམ་པ [[དེ་བཞིན་དུ་རིགས་ཀྱི་བུའམ། རིགས་ཀྱི་བུ་མོ་གཞན་ལ་ལ་ཞིག་གིས་འཛམ་བུའི་གླིང་གི་སེམས་ཅན་ཐམས་ཅད་རང་བྱང་ཆུབ་ལ་བཀོད་པ་བས།]]
   * 3.4 བཀུར་པ་ཙམ་བཞི་པ [[ཀཽ་ཤི་ཀ་གཞན་ཡང་རིགས་ཀྱི་བུའམ། རིགས་ཀྱི་བུ་མོ་ལ་ལ་ཞིག་གིས་འཛམ་བུའི་གླིང་གི་སེམས་ཅན་རྣམས་དགེ་བ་བཅུའི་ལས་ཀྱི་ལམ་ནས།]]
   * 3.5 བཀུར་བ་ཙམ་ལྔ་པ [[ཀཽ་ཤི་ཀ་གཞན་ཡང་རིགས་ཀྱི་བུའམ། རིགས་ཀྱི་བུ་མོ་ལ་ལ་ཞིག་གིས་ཤེས་རབ་ཀྱི་ཕ་རོལ་ཏུ་ཕྱིན་པའི་དོན་གཞན་ལ་རྣམ་གྲངས་དུ་མས་རྒྱ་ཆེར་སྟོན་པར་བྱེད།]]
   * 3.6 བཀུར་བ་ཙམ་དྲུག་པ [[ཀཽ་ཤི་ཀ་གཞན་ཡང་རིགས་ཀྱི་བུའམ། རིགས་ཀྱི་བུ་མོ་ལ་ལ་ཞིག་བདག་ཉིད་ཀྱང་ཤེས་རབ་ཀྱི་ཕ་རོལ་ཏུ་ཕྱིན་པ་འདི་འཛིན་པར་འགྱུར།]]
   * 3.7 བཀུར་བ་ཙམ་བདུན་པ [[ཀཽ་ཤི་ཀ་གལ་ཏེ་རིགས་ཀྱི་བུའམ། རིགས་ཀྱི་བུ་མོ་ཕྱོགས་བཅུའི་ཕྱོགས་རེ་རེ་ཞིང་འཇིག་རྟེན་གྱི་ཁམས་ཚད་མེད་པ་རྣམས་ཀྱི]]
   * 3.8 བཀུར་བ་ཙམ་བརྒྱད་པ [[ཀཽ་ཤི་ཀ་གཞན་ཡང་རིགས་ཀྱི་བུའམ། རིགས་ཀྱི་བུ་མོ་གང་ལ་ལས་བསྐལ་པ་གྲངས་མེད་གཞལ་དུ་མེད་པར་སྦྱིན་པའི་ཕ་རོལ་ཏུ་ཕྱིན་པ་དང་།]]
   * 3.9 བཀུར་བ་ཙམ་དགུ་པ [[ཀཽ་ཤི་ཀ་གཞན་ཡང་འཛམ་བུའི་གླིང་གི་སེམས་ཅན་ཇི་སྙེད་པ་དེ་དག་རིགས་ཀྱི་བུའམ། རིགས་ཀྱི་བུ་མོ་ལ་ལ་ཞིག་གིས་རྒྱུན་དུ་ཞུགས་པའི་འབྲས་བུ་ལ་བཀོད་ན།]]
* 4. བསྔགས་པ [[ཀཽ་ཤི་ཀ་གཞན་ཡང་འཛམ་བུའི་གླིང་གི་སེམས་ཅན་ཇི་སྙེད་པ་དེ་དག་རིགས་ཀྱི་བུའམ་རིགས་ཀྱི་བུ་མོ་ལ་ལ་ཞིག་གིས་ལན་ཅིག་ཕྱིར་འོང་བའི་འབྲས་བུ་ལ་བཀོད་ཞེས༌[^316]བྱ་བ་ནི]]
   * 4.1 བསྔགས་པ་ཙམ་དང་པོ [[ཀཽ་ཤི་ཀ་གཞན་ཡང་འཛམ་བུའི་གླིང་གི་སེམས་ཅན་ཇི་སྙེད་པ་དེ་དག་རིགས་ཀྱི་བུའམ་རིགས་ཀྱི་བུ་མོ་ལ་ལ་ཞིག་གིས་ལན་ཅིག་ཕྱིར་འོང་བའི་འབྲས་བུ་ལ་བཀོད་ཞེས༌[^316]བྱ་བ་ནི]]
   * 4.2 བསྔགས་པ་ཙམ་གཉིས་པ [[ཇི་སྙེད་པ་ཕྱིར་མི་འོང་བའི་འབྲས་བུ་ལ་བཀོད་ཅེས་བྱ་བ་ནི་བསྔགས་པ་ཙམ་གཉིས་པ་ཡིན་ནོ། །]]
   * 4.3 བསྔགས་པ་ཙམ་གསུམ་པ [[ཇི་སྙེད་པ་དགྲ་བཅོམ་པ་ཉིད་ལ་རབ་ཏུ་བཀོད་ན། ཀཽ་ཤི་ཀ་དེ་ཇི་སྙམ་དུ་སེམས། རིགས་ཀྱི་བུའམ། རིགས་ཀྱི་བུ་མོ་དེའི་བསོད་ནམས་དེའི་རྒྱུས་མང་དུ་འཕེལ་ལམ།]]
   * 4.4 བསྔགས་པ་ཙམ་བཞི་པ [[ཀཽ་ཤི་ཀ་གཞན་ཡང་ཕྱོགས་བཅུའི་ཕྱོགས་རེ་རེ་ཞིང་སངས་རྒྱས་ཀྱི་ཞིང་གང་གཱའི་ཀླུང་གི་བྱེ་མ་སྙེད་ཀྱི]]
   * 4.5 བསྔགས་པ་ཙམ་ལྔ་པ [[ཀཽ་ཤི་ཀ་གཞན་ཡང་འཛམ་བུའི་གླིང་གི་སེམས་ཅན་ཇི་སྙེད་པ་དེ་དག་རིགས་ཀྱི་བུའམ། རིགས་ཀྱི་བུ་མོ་ལ་ལ་ཞིག་གིས]]
