━━━ ISSUE TYPES ━━━

CONNECTOR_ENDING
  The block ends with a connector particle (དང་། / ཞིང་། / ཅིང་། / ནས། / ལས། /
  སྟེ། / ཏེ།) that grammatically requires continuation. Real issue if the next
  block is the grammatical continuation. False positive if this is a closing verse
  pāda or a deliberate short citation frame.

OBJECTION_REPLY_FUSED
  The block contains both an objection marker (ཅེ་ན། / ཞེ་ན། / སྙམ་ན།) and a reply
  opener (འོ་ན།). These should always be two separate blocks. Almost always a
  real issue.

OVER_LENGTH
  The block exceeds the syllable threshold. Usually NOT wrong: a whole explanation
  unit is legitimately long. Split only if a new node opener (ordinal + title +
  ནི། / ལ་ N།) or the treatment of a new verse is buried mid-block.

SHORT_FRAGMENT
  The block is suspiciously short — may be a stray split artifact that should be
  merged with an adjacent block.

Rules:

  block into 3+ units, set "after" to a LIST of substrings in document order.
- Each block number appears in AT MOST ONE operation.
- Heading blocks (lines starting with #) and [VERSE] blocks are NEVER touched.
- If no corrections are needed, output: []
- Output ONLY the JSON array. No commentary, no code fences.

ལྷ་ཉིད་ཀྱི་སྐུ་འོ་བརྒྱལ་བར༌[^1610]མཛད་པ་བཏང་དུ་གསོལ། བདག་ཅག་ཀྱང་ཚིམ་པར་བགྱིས་ལགས་ཀྱིས་ཞེས་བྱ་བས༌[^1611]སོ། །སྐྱོབ་པ༌[^1612]མ་ཡིན་ཏེ། གང་དེ་ལས་གཞན་ཡོངས་སུ་བསྐྱབ་པར༌[^1613]བྱ་བ་མེད་པའི་ཕྱིར་རོ། །དེ་ལྟར་རེ་ཞིག་ནང་གི་སྦྱིན་པ་རྣམ་པ་བཞིའི་དབྱེ་བ་ཡིན་ཏེ། དེ་བས་ན་དེ་ལྟར་སྐྱེས་པའི་རབས་རྒྱུ༌[^1614]རྣམ་པ་བཞི་བཀོད་པ་ཡིན་ནོ། །བཞི་པོ་དེའི་ནང་དུ་དེའི་རང་བཞིན་གཞན་ཡང་ཆུད་པ་ཡིན་ཏེ། དེའི་རིགས་དེས་སྐྱེས་པའི་རབས་གཞན་ཡང་རབ་ཏུ་འགྲུབ་བོ། །དེ་གོ་བར་འདོད་པ་རྣམས་ལ་མཐའ་དག་གི་ཐབས་བསྟན་པ་ཡིན་ནོ། །ད་ནི་ཕྱི་རོལ་གྱི་དངོས་པོའི་སྦྱིན་པའི་དབང་དུ་བྱས་ནས་སྐྱེས་པའི་རབས་ཅིག་ཤོས་བཞི་བསྟན་པ་ཡིན་ཏེ། ཇི་ལྟར་ཕྱི་རོལ་གྱི་སྦྱིན་པ་ཡིན་ཞེ་ན། རྣམ་པ་གསུམ་དུ་བརྩམས་པ་ཡིན་ཏེ། སྦྱིན་པ་པོ་ཕུན་སུམ་ཚོགས་པ་དང་། ལེན་པ་པོ་ཕུན་སུམ་ཚོགས་པ་དང་། སྦྱིན་པའི་དངོས་པོ་ཕུན་སུམ་ཚོགས་པའོ། །ཕུན་སུམ་ཚོགས་པ་འདི་གསུམ་གྱི་དབང་དུ་བྱས་ན་ཚོང་དཔོན་གྱི་སྐྱེས་པའི་རབས་སུ་ལེན་པ་པོ་ཕུན་སུམ་ཚོགས་པ་ནི་དེ་ཉིད་དུ་རང་སངས་རྒྱས་ཉོན་མོངས་པའི་བུད་ཤིང་ཐམས་ཅད་བསྲེགས་པ་དེའི་བསོད་ནམས་ཀྱི་ཚོགས་རྣམ་པར་འཕེལ་བར་འདོད་པ་ཞིག་དེའི་ཁྱིམ་དུ་བསོད་སྙོམས་ཀྱི་ཕྱིར་འོངས་སོ་ཞེས་པས་སོ། །སྦྱིན་པའི་དངོས་པོ་ཕུན་སུམ་ཚོགས་པ་ཡང་དེ་ཉིད་དུ་བསྟན་ཏེ། དེས་དེའི་ལྟར༌[^1615]མཉན་ཏེ་དེ་བཞིན་དུ་བགྱིའོ་ཞེས་སྨྲས་ནས་བཟའ་བ་དང་བཅའ་བ་བཟང་པོ་ཁྱེར་ཏེ་ཞེས་བྱ་བའི་ཚིག་གིས་སོ། །སྦྱིན་པ་པོ་ཕུན་སུམ་ཚོགས་པ་ཡང་དེ་ཉིད་དུ་བསྟན་ཏེ། བྱང་ཆུབ་སེམས་དཔའ་དག༌[^1616]གི་སྐལ་པ་དང་བསོད་ནམས་ཀྱི་མཐུ་ལ་བརྟེན་ནས་སྦྱིན་པ་ལ་ཉེས་དམིགས་མེད་པར་ཡང་ཤེས་ཏེ། བུ་སྨད་དང་གཡོག་འཁོར་འགྲོར་མི་སྟེར་བར་འཐེན་པ་རྣམས་བོར་ནས་བློ་ལ་ཚམ་ཚོམ་མེད་ཅིང་སྦྱིན་པ་བྱེད་པར་འདོད་པ་སྐྱེས་ཏེ་དམྱལ་བའི་ནང་ནས༌[^1617]སོང་ངོ་ཞེས་བྱ་བའི་ཚིག་གིས་སོ། །ད་ནི་ཀོ་ས་ལའི་བདག་པོའི་སྐྱེས་པའི་རབས་ལ་ནི་ཕུན་སུམ་ཚོགས་པ་གཉིས་ཡོད་དེ་སྦྱིན་པ་པོ་ཕུན་སུམ་ཚོགས་པ་དང་། ལེན་པ་པོ་ཕུན་སུམ་ཚོགས་པ་དང༌[^1618]ཀོ་ས་ལའི་བདག་པོ་ལ་ནི་སྦྱིན་པའི་དངོས་པོ་ཕུན་སུམ་ཚོགས་པ་མེད་དོ། །དེ་ལ་སྦྱིན་པ་པོའི་ཕུན་སུམ་ཚོགས་པ་ཡང་དེ་ཉིད་དུ་བསྟན་ཏེ། ཚུལ་དང་ལྡན་ཡང་ནོར་ཙམ་གྱིས་ནི་མཐོ་བ་ལ། །ལས་ཀྱིས༌[^1619]མགུ་བར་བྱས་ནས་སྨན༌[^1620]ཚིས་འཚོ་བའི་ཞེས་བྱ་བ་དང་། གཞན་ཡང་དང༌[^1621]ཞིང་འཇམ་པའི་ཡིད་ཀྱིས་དེ་ལ་ཕྱག་འཚལ་ནས། །ཞེས་པའི་ཚིག་གིས་སོ། །ལེན་པ་པོ་ཕུན་སུམ་ཚོགས་པ་ཡང་དེ་ཉིད་དུ་བཤད་དེ།

ཞེས་བྱ་བ་ཡིན་ཏེ། བཞི་སྨྲོས་པ་ནི་སྦྱིན་པའི་གནས་དགེ་འདུན་དུ་བསྟན་པའི་ཕྱིར་ཏེ། དེ་བས་ན་ལེན་པ་པོ་ཕུན་སུམ་ཚོགས་པར་བསྟན་ཏོ། །སྦྱིན་པའི་དངོས་པོ་ཕུན་སུམ་ཚོགས་པ་ནི་མེད་དེ། དེ་ཡང་དེ་ཉིད་དུ་བསྟན་པ། ཟན་དྲོན་ཁེངས་པ་རྩུབ་པོ་ལེན་ཚ༌[^1623]མེད་པའི་འབྲས་བུ་འབྱོར་པ་ཆེན་པོ་འདི་ལྟར་འགྱུར་ལ་ལྟོས།[^1624] །ཞེས་བྱ་བ་དང་། སྐྱེས་པའི་རབས་དེ་ཉིད་དུ་གཅིག་གི་བར་དུ་བྱས་པ་སྟེ། གང་གི་ཚེ་ལེན་པ་པོ་ཕུན་སུམ་ཚོགས་པ་ཉི་ཚེ༌[^1625]བསྟན་པ་ཡིན་ཏེ། ཐུབ་པ་ཟག་པ་ཟད་ལ་གུས་པར་ཕུལ་བ་ཡིས། །ཞེས་བྱ་བའི་ཚིག་གིས་སོ། །སྦྱིན་པར་བྱ་བའི་དངོས་པོ་ཕུན་སུམ་ཚོགས་པ་ནི་མེད་དེ། ཟས་ལས་བགོ་སྐལ་བགོས་པའོ། །སྦྱིན་པ་པོ་ཕུན་སུམ་ཚོགས་པ་ཡང་མེད་དེ། བྲན་མོ་བགྱིད་པའི་ཚེ་ན་ཞེས་པའི་ཚིག་གིས་སོ། །གུས་པར་ཕུལ་བ་ནི་དུས་ཚོད་དེ་ཙམ་ན་གུས་པ་ཡོད་པའོ། །དེའི་ཕྱིར་འབྲས་བུ་ཆུང་བ་སྟེ་བུད་མེད་དུ་གྱུར་པའོ། །ད་ནི་སྦྱིན་པའི་དངོས་པོ་ཕུན་སུམ་ཚོགས་པ་དང་། སྦྱིན་པ་པོ་ཕུན་སུམ་ཚོགས་པ་ནི་ཐམས་ཅད་སྒྲོལ་གྱི་སྐྱེས་པའི་རབས་ཡིན་ཏེ། སྦྱིན་པའི་དངོས་པོ་ཕུན་སུམ་ཚོགས་པ་ནི་ཕྱི་རོལ་གྱི་དངོས་པོ་སེམས་ཅན་དང་སེམས་ཅན་མ་ཡིན་པའི་གྲངས་སུ་འགྲོ་བའི་རྣམ་པ་ཐམས་ཅད་དེ། ཕྱི་རོལ་གྱི་སྦྱིན་པའི་དངོས་པོའོ། །སེམས་ཅན་གྱི་གྲངས་སུ་འགྲོ་བའི་ཕྱི་རོལ་གྱི་སྦྱིན་པ་ནི་གླང་པོ་རིན་པོ་ཆེ་དང་། རྟ་ཆས་དང་བཅས་པ་ལ་སོགས་པ་མཐའ་དག་སྦྱིན་པའོ། །སེམས་ཅན་མ་ཡིན་པ་ནི་བུ༌[^1626]སྨད་དང་བཅས་པ་ཡིན་ཡང་དེ་ལ་མ་ལྟོས་པར༌[^1627]ཤིང་རྟ་སྦྱིན་པའོ། །བུ་སྦྱིན་པ་དང་། ཆུང་མ་སྦྱིན་པ་ནི་བདག་ཉིད་གྱི་ཕྱི་རོལ་གྱི་སྦྱིན་པའི་དངོས་པོ་ཁྱད་པར་དུ་གྱུར་པའོ། །སྦྱིན་པ་པོ་ཕུན་སུམ་ཚོགས་པའི་ཁྱད་པར་དུ་གྱུར་པ་དེ་ཉིད་དུ་བསྟན་ཏེ།

ཅེས་བྱ་བ་དང་། ཅི་ནས་ཀྱང་མིག་དེ་དེའི༌[^1607]མིག་ཏུ་གནས་པར་གྱུར་པ་དང་། དེ་ནས་མིག་ཡ་གཅིག་ཕྱེ་སྟེ་ཞེས་བྱ་བའི་ཚིག་གིས་སོ། །དབང་པོས་ནི་ལོངས་སྤྱོད་ཅིང་ཟ་བར་བྱེད་པ་མ་ཡིན་གྱི། དབང་པོ་དེ་ལ་བརྟེན་ནས་ཡོངས་སུ་ལོངས་སྤྱོད་པ་ཡིན་ཏེ། གཞན་དུ་ན་ལོངས་སྤྱོད་པར་མི་ནུས་ཏེ་དེས་ན་ཡུལ་དམིགས་པ་དེ་ཉིད་ཀྱིས་ལོངས་སྤྱོད་པའོ། །བྱམས་པའི་སྟོབས་བསྐྱེད་པ་ལ་ཡང་ནང་གི་སྦྱིན་པ་དབང་པོའི་དབྱེ་བ་ཤ་དང་ཁྲག་གི་སྦྱིན་པ་ཡིན་ཏེ། སྲོག་གི་སྦྱིན་པ་ནི་མ་ཡིན་པར་དེ་ཉིད་ལས་བསྟན་པ་སྟེ།[^1608] ལྷ་དང་མིའི་སྨན་གྱི་ཁྱད་པར་རྨ་སར་པ་སོས༌[^1609]པར་བྱེད་ནུས་པ་རྣམས་ཀྱིས་དེའི་ལུས་སྔོན་བཞིན་དུ་སྡུག་བསྔལ་མེད་པར་བྱས་ཞེས་པའི་ཚིག་གིས་སོ། །ཡོངས་སུ་ལོངས་སྤྱོད་པ་ཉིད་དུ་བཤད་པའི་ཕྱིར། ལྷ་ཉིད་ཀྱི་སྐུ་འོ་བརྒྱལ་བར༌[^1610]མཛད་པ་བཏང་དུ་གསོལ། བདག་ཅག་ཀྱང་ཚིམ་པར་བགྱིས་ལགས་ཀྱིས་ཞེས་བྱ་བས༌[^1611]སོ། །སྐྱོབ་པ༌[^1612]མ་ཡིན་ཏེ། གང་དེ་ལས་གཞན་ཡོངས་སུ་བསྐྱབ་པར༌[^1613]བྱ་བ་མེད་པའི་ཕྱིར་རོ། །དེ་ལྟར་རེ་ཞིག་ནང་གི་སྦྱིན་པ་རྣམ་པ་བཞིའི་དབྱེ་བ་ཡིན་ཏེ། དེ་བས་ན་དེ་ལྟར་སྐྱེས་པའི་རབས་རྒྱུ༌[^1614]རྣམ་པ་བཞི་བཀོད་པ་ཡིན་ནོ། །བཞི་པོ་དེའི་ནང་དུ་དེའི་རང་བཞིན་གཞན་ཡང་ཆུད་པ་ཡིན་ཏེ། དེའི་རིགས་དེས་སྐྱེས་པའི་རབས་གཞན་ཡང་རབ་ཏུ་འགྲུབ་བོ། །དེ་གོ་བར་འདོད་པ་རྣམས་ལ་མཐའ་དག་གི་ཐབས་བསྟན་པ་ཡིན་ནོ། །ད་ནི་ཕྱི་རོལ་གྱི་དངོས་པོའི་སྦྱིན་པའི་དབང་དུ་བྱས་ནས་སྐྱེས་པའི་རབས་ཅིག་ཤོས་བཞི་བསྟན་པ་ཡིན་ཏེ། ཇི་ལྟར་ཕྱི་རོལ་གྱི་སྦྱིན་པ་ཡིན་ཞེ་ན། རྣམ་པ་གསུམ་དུ་བརྩམས་པ་ཡིན་ཏེ། སྦྱིན་པ་པོ་ཕུན་སུམ་ཚོགས་པ་དང་། ལེན་པ་པོ་ཕུན་སུམ་ཚོགས་པ་དང་། སྦྱིན་པའི་དངོས་པོ་ཕུན་སུམ་ཚོགས་པའོ། །ཕུན་སུམ་ཚོགས་པ་འདི་གསུམ་གྱི་དབང་དུ་བྱས་ན་ཚོང་དཔོན་གྱི་སྐྱེས་པའི་རབས་སུ་ལེན་པ་པོ་ཕུན་སུམ་ཚོགས་པ་ནི་དེ་ཉིད་དུ་རང་སངས་རྒྱས་ཉོན་མོངས་པའི་བུད་ཤིང་ཐམས་ཅད་བསྲེགས་པ་དེའི་བསོད་ནམས་ཀྱི་ཚོགས་རྣམ་པར་འཕེལ་བར་འདོད་པ་ཞིག་དེའི་ཁྱིམ་དུ་བསོད་སྙོམས་ཀྱི་ཕྱིར་འོངས་སོ་ཞེས་པས་སོ། །སྦྱིན་པའི་དངོས་པོ་ཕུན་སུམ་ཚོགས་པ་ཡང་དེ་ཉིད་དུ་བསྟན་ཏེ། དེས་དེའི་ལྟར༌[^1615]མཉན་ཏེ་དེ་བཞིན་དུ་བགྱིའོ་ཞེས་སྨྲས་ནས་བཟའ་བ་དང་བཅའ་བ་བཟང་པོ་ཁྱེར་ཏེ་ཞེས་བྱ་བའི་ཚིག་གིས་སོ། །སྦྱིན་པ་པོ་ཕུན་སུམ་ཚོགས་པ་ཡང་དེ་ཉིད་དུ་བསྟན་ཏེ། བྱང་ཆུབ་སེམས་དཔའ་དག༌[^1616]གི་སྐལ་པ་དང་བསོད་ནམས་ཀྱི་མཐུ་ལ་བརྟེན་ནས་སྦྱིན་པ་ལ་ཉེས་དམིགས་མེད་པར་ཡང་ཤེས་ཏེ། བུ་སྨད་དང་གཡོག་འཁོར་འགྲོར་མི་སྟེར་བར་འཐེན་པ་རྣམས་བོར་ནས་བློ་ལ་ཚམ་ཚོམ་མེད་ཅིང་སྦྱིན་པ་བྱེད་པར་འདོད་པ་སྐྱེས་ཏེ་དམྱལ་བའི་ནང་ནས༌[^1617]སོང་ངོ་ཞེས་བྱ་བའི་ཚིག་གིས་སོ། ## བརྒྱ་བྱིན་གྱི་སྐྱེས་པའི་རབས། ^12-0

[Block 1328 — CONNECTOR_ENDING]
དབང་ཕྱུག་ཕུན་སུམ་ཚོགས་པ་ཞེས་བྱ་བ་ནི་མཐུ་དང་ནུས་པ་ཕུན་སུམ་ཚོགས་པ་ཞེས་བྱ་བ་ཡིན་ཏེ། མཐོ་བར་གྱུར་པ་དེས་གཞན་དག་ལ་སྙིང་བརྩེ་བ་ལྷོད་པར་མི་འགྱུར་བ༌[^1646]སྟེ་བདག་ཉིད་ཆེན་པོ་དེའོ། །ཡུན་རིང་མོ་ནས་བསོད་ནམས་སྤྱོད་པ་ལ་རབ་ཏུ་གོམས་ཞིང༌[^1647]ཞེས་བྱ་བ་ནི་ཡུན་རིང་མོ་ནས་བསོད་ནམས་ལ་རབ་ཏུ་གོམས་པ་སྟེ། བདག་དང་གཞན་ལ་ཕན་པ་སྒྲུབ་པའི་མཚན་ཉིད་ཀྱི་ལས་གང་ཡིན་པ་དེ་ནི་བསོད་ནམས་ཏེ། ཡུན་རིང་མོ་ནས་བསོད་ནམས་སྤྱོད་པ་ལ་རབ་ཏུ་གོམས་པའོ། །འདིས་ནི་འདས་པའི་དུས་ཀྱི་བསོད་ནམས་ཀྱི་ཚོགས་བསྟན་ཏོ། །སྦྱིན་པ་དང་། དུལ་བ་དང་། སྡོམ་པ་དང་། སྙིང་རྗེ་ལ་འདྲིས་པ་གང་ཡིན་པ་དེ་ནི་སྦྱིན་པ་དང་། དུལ་བ་དང་། སྡོམ་པ་དང་སྙིང་རྗེ་ལ་འདྲིས་པར་གྱུར་པ་སྟེ། འདིས་ནི་ད་ལྟར་བྱུང་བའི་དུས་སུ་བདག་དང་གཞན་ལ་ཕན་པ་སྒྲུབ་པའི་མཚན་ཉིད་བསྟན་ཏོ། །གཞན་ལ་ཕན་པར་སྤྱོད་པ་ཁྱད་པར་ཅན་ལ་ངེས་པར་བྱེད་པ་གང་ཡིན་པ་དེ་ནི་གཞན་ལ་ཕན་པར་སྤྱོད་པ་ཁྱད་པར་ཅན་ལ་ངེས་པར་སྤྱོད་པའོ། །འདིས་ནི་རྟག་ཏུ་གུས་པ་དང་སྦྱོར་བ་གཉིས་ཀྱིས་གཞན་ལ་ཕན་པ་སྒྲུབ་པ་བསྟན་ཏོ། །དེ་ལ་རྟེན༌[^1648]བཅས་པ་ཞེས་བྱ་བ་ནི་མཚོན་པ་སྟེ། བདག་དང་གཞན་གྱི་སྒྲུབ་པ་ཁྱད་པར་ཅན་ཡང་དག་པར་བརྟེན་པའོ། །ཡང་ཏོག་རྡོ་ཐལ་གསར་དུ་བསྐུས་པ་ཞེས་བྱ་བ་ལྟ་བུ་ནི་སྔར་བཤད་པའི་བྱང་ཆུབ་སེམས་དཔའོ། །ད་ནི་གང་གོང་དུ་བསྟན་པའི་དབང་ཕྱུག་ཕུན་སུམ་ཚོགས་པ་དང་རྗེས་སུ་མཐུན་པ་ཡིན་ཡང་སྙིང་རྗེ་ལྷོད་པར་མི་འགྱུར་རོ་ཞེས་བྱ་བ་དེ་ཉིད་སྒྲུབ་པའི་ཕྱིར། རོལ་པའི་བགེགས་གྱུར་འགྲོ་བ་འཇིགས་པར་འགྱུར་བ་སྟེ། ལྷའི་འགྲོ་བའོ། །དེས་ན་རྒྱ་མཚོའི་འགྲམ་ལ་ཐུག་པར་སྔོན་སུ་བར་བྱེད་པ་ཡིན་ནོ། །འདུག་བཞིན་དུ་ཞེས་བྱ་བ་སྟེ་མཚོན་རྡེག་པར་བྱེད་དོ། །ང་ནི་འདི་ན་ཞེས་སྨྲས་ནས་ཀྱང་རབ་ཏུ་རྡེག་པར་བྱེད་དོ། །མཐོང་བཞིན་ཞེས་བྱས༌[^1664]ནས་ཀྱང་གཞན་དག་ལ་རྡེག་པར་བྱེད་དོ། །ད་ནི་ཐར་པར་ག་ལ་འགྱུར་ཞེས་བྱས་ཤིང་ཡང་གཞན་དག༌[^1665]ལ་རབ་ཏུ་སྣུན་པར༌[^1666]བྱེད་དོ། །དེ་ལྟར་སྨྲས་ནས་གཞན་དག་ལ་ཐོབ་ཅིག་ཅེས་སྨྲས་ཏེ་ཕྱིར་ལོག་པ་དང་། དེ་དག༌[^1667]ལས་གཞན་དག་གིས་ཀྱང་མཚོན་འདེབས་པར་བྱེད་ཅིང་། ད་ནི་མེད་ཟིན་གྱིས་ཞེས་སྨྲས་ཏེ་མཚོན་འདེབས་པར་བྱེད་དོ། །མཚོན་ཆ་འཁྲུགས་པ༌[^1668]ནི་གཡུལ་དུའོ། །གློག་བཞིན་དུ་འགྱུ་བའི༌[^1669]བ་དན་ཅན་གང་དག་ནི་ཤིང་རྟ་སྟེ། དེ་ནི་གློག་ལྟར་འགྱུ་བའི་བ་དན་ཅན་ནོ། །གདུགས་དང་། རྒྱལ་མཚན་དང་། གོ་ཆ་དང་། མཚོན་ཆ་དང་། ཅོད་པན་རྣམས་ཏེ། [^1670]དེ་དག་ལྷུང་བར་གྱུར་པ་ནི་འགྱེལ་བར་གྱུར་པའོ། །ཕོག་པར་གྱུར་པ་ནི་ལམ་དུ་སྟེ་ཕོག་པར་གྱུར་པའི་སྟེང་དུའོ། །དེར་བབ་པ་ནི་ཕོག་པར་གྱུར་པའི་སྟེང་དུ་བབ་པའོ། །ཁ་ལོ་པ་ནི་ཁ་ལོ་སྒྱུར་བའོ། །ཕྲུ་གུ་མ་ཚར་བ་ཞེས་བྱ་བ་ནི་གཤོག་པ་མ་སྐྱེས་པའོ། །མ་ཚར་བ་ཉིད་བྱ༌[^1671]ཡིན་པས་བྱའི་ཕྲུ་གུ་སྟེ། བྱ་ཕྲུག་མ་ཚར་བ་དེའི་ཚང༌[^1672]བཅས་པའོ། །ལྷ་མ་ཡིན་འདི་དག་ང་ཅུང་སླར་མི་ལྡོག་གོ་ཞེས་བྱ་བ་དང་། ཅི་ཞེས་བྱ་བ་ནི་སྐྱོན་ཅི་ཡོད་ཅེས་བྱ་བའི་དོན་ཏོ། །ཤིང་རྟ་མ་བཟློག་པར་ནམ་མཁའ་ལྡིང་གི་ཚང་ལས་བཟུར་བར་མི་ནུས་པའི་ཕྱིར་རོ། །ཤིང་རྟ་བཟློག་པ༌[^1673]དེ་ལས་ཉེས༌[^1674]པ་མེད། །ཅེས་པ༌[^1675]དེའི་དབང་དུ་བྱས་ནས་ཤིང་རྟ་འདི་ནི་སླད་དུ་བཟློག༌[^1676]ན་གདོད་ཅེས་བྱ་བའི་ཚིགས་བཅད་བརྩམས་པ་ཡིན་ཏེ། ནམ་མཁའ་ལྡིང་གི་ཚང་འདི་ལས་ཟུར་ཅིག་ཅེས་བྱ་བའི་ལས༌[^1677]ནི། ཤིང་རྟ་འདི་ནི་སླད་དུ་བཟློག་ན་གདོད་ཅེས་བྱ་བའི་ཚིགས་བཅད་ཕྱེད་ཡིན་ནོ། །

[Block 1334]
འོ་ན་ཅི་ཞེས་བྱ་བའི་ལན་ནི་ལྷ་རྣམས་ལ་ནི་ཞེས་བྱ་བ་སྟེ། ཚིགས་བཅད་ཀྱི་ཕྱེད་འོག་མའོ། །དེ་བས་ན༌[^1678]ཞེས་བྱ་བ་ནི་ཤིང་རྟ་བཟློག་པ་ལ་ནི་ཉེས་པ་ཡོད་དོ་ཞེས་གོང་དུ་མ་ཏ་ལིས་སྨྲས་པའི་ཚིག་གོ། །ལྷ་རྣམས་ལ་ནི་གནས་ནས་སྐབས་རྙེད་པ་ཞེས་བྱ་བ་འདིའི་ལན་ནི་མཚོན་གྱིས་ཕོག་སྟེ་ཤི་བ་བླས༌[^1679]ཞེས་བྱ་བ་ཡིན་ཏེ། རང་གི་ལྷག་པའི་བསམ་པ་ཁྱད་པར་ཅན་བསྟན་པའི་ཕྱིར་སྨྲས་པའོ། །ཤི་ཡང་བླས༌[^1680]ཞེས་བྱ་བ་ལ་སོགས་པ་ནི་སྙིང་རྗེའི་དབང་གིས་སྨྲས་པ་སྟེ།[^1681] དེ་ལྟར་སྤྱོད་པའི་སེམས་ཅན་འཇིགས་པས་ཉེན་པ་འདིའི་ཆེད་དུའོ། །འཇིགས་པས་བརྟབས་ཤིང་རབ་ཏུ་མགྱོགས་པར་གྱུར་པ་གང་ཡིན་པ་དེ་ནི་སྐྲག་ནས་བརྟབས་ཤིང་རབ་ཏུ་མགྱོགས་པར་བྱེད་པའོ། །ཇི་ལྟ་བུར༌[^1682]ཞེ་ན། ཆར་སྤྲིན་ནག་པོ་རླུང་གིས༌[^1683]གཏོར་བ་བཞིན། །བདག་གི་དམག་ཚོགས་ཕམ་ཡང་ཞེས་བྱ་བའི་ཚིགས་བཅད་ཡིན་ནོ། །དགའ་བ་དང་ངོ་ཚ་བ་ནི་དགའ་ཞིང་ངོ་ཚ་བའོ། །དགའ་བ་དང་ངོ་ཚ་བ་དང་བཅས་པ་ནི་དགའ་ཞིང་ངོ་ཚ་བཞིན་དུའོ། །ཕོངས་ན་ཞེས་བྱ་བའི་སྒྲ་ནི་ངན་པ་དང་བློ་འབྲིང་པོ་གཉི་ག་ལ་སྦྱར་བར་བྱའོ། །ངན་པ་དང་བློ་འབྲིང་པོ་ནི་སྡིག་པ་སྤྱོད་པའི་ཚེ་ན་མི་མཉམ་པ་སྟེ། སྙིང་རྗེ་དང་བཅས་པས་སོ། །སྐྱེ་བོ་དམ་པ་རྣམས་ཀྱི་ཁྱད་པར་ནི་འདི་ཡིན་ཏེ། རྣམ་པ་ཐམས་ཅད་དུ་སྡིག་པ་མི་བྱེད་དེ། སྙིང་རྗེ་དང་བཅས་པར་གྲུབ་པ་ཡིན་པས་ཡང་མི་བརྗོད་དོ། །[^1684]སློབ་དཔོན་དཔའ་བོས་མཛད་པའི་སྐྱེས་པའི་རབས་རྒྱ་ཆེར་བཤད་པ་ལས་བརྒྱ་བྱིན་གྱི་སྐྱེས་པའི་རབས་སོ།། །།

## བྲམ་ཟེའི་སྐྱེས་པའི་རབས། ^13-0

──────────────────────────────────────────────────

[Block 1332]
ཡང་ན་ཟླ་མེད་པའི་གོས་བཟང་པོ་གང་ལ་ཡོད་པ་དེ་ནི་གོས་བཟང་པོ་འོས་པའོ། །བསྒྲེང་བ་ཡང་ཡིན་ལ་གོས་བཟང་པོ་ཕྱར་བ་ཡང་ཡིན་པས་བསྒྲེང་བའི་གོས་བཟང་པོ་འོས་པར༌[^1661]ཕྱར་བའོ། །བ་དན་ཡང་ཡིན་ལ་མཛེས་པ་ཡང་ཡིན་པས་བ་དན་མཛེས་པའོ། །གོས་བཟང་པོ་འོས་པས་བ་དན་མཛེས་པར་ཕྱར་བའི་ཕྱིར༌[^1662]རྒྱལ་མཚན་བསྒྲེང་བ་གང་ཡིན་པ་དེ་ནི་གོས་བཟང་པོ་འོས་པས་བ་དན་མཛེས་པར་ཕྱར་བའི་རྒྱལ་མཚན་བསྒྲེང་བའོ། །རིན་པོ་ཆེ་སྣ་ཚོགས་པ་ཉིད་ནི་རིན་པོ་ཆེའི་རྣམ་པ་སྣ་ཚོགས་པའོ། །

ཡང་ན་ནོར་བུ་དང་འདྲ་བའི་རིན་པོ་ཆེ་ནི་ནོར་བུ་རིན་པོ་ཆེའོ། །རིན་པོ་ཆེ་སྣ་ཚོགས་པ་ནི་རིན་པོ་ཆེ་སྣ་ཚོགས་པ་སྟེ། དེ་རྣམས་ཀྱི་འོད་ནི་ནོར་བུ་རིན་པོ་ཆེ་སྣ་ཚོགས་ཀྱི་འོད་དོ། །དེས་གསལ་བར༌[^1663]གྱུར་པ་ནི་གསལ་བར་སྣང་བའོ། །རྒྱན་གདགས་པའི་གོ་རིམས་སུ་གྱུར་པ་ནི་རྒྱན་གདགས་པའི་གོ་རིམས་སོམོ། །རྒྱན་གདགས་པའི་གོ་རིམས་དང་། ངེས་པར་བྱས་པ་དང་། ངོས་གཉིས་མཚོན་ཆ་རྣོན་པོ་རྣམ་པ་སྣ་ཚོགས་འབར་བས་མཛེས་པ་གང་ཡིན་པ་དེ་ནི་ལྷའི་གོས་དཀར་པོ་ཅན་ནོ། །ཡོངས་སུ་བསྐོར་བ་ནི་ཤིང་རྟ་གོས་དཀར་པོ་ཅན་ཏེ། རྒྱ་མཚོའི་འགྲམ་དུ་ཐུག་པར་ཞེས་བྱ་བ་དེ་ནི་གང་གི་ཕྱིར་དེ་རྣམས་ཀྱི་རྒྱ་མཚོའི་འགྲམ་ན་གནས་ཏེ། དེས་ན་འགྲམ་དུ་ཡོད་པ་ཡིན་ནོ། །ལྷ་མ་ཡིན་རྣམས་ཀྱི་སྔ་མ་ལྟར་འོང་བ་དེ་ཤེས་པ་སྟེ། རོལ་པའི་བགེགས་གྱུར་འགྲོ་བ་འཇིགས་པར་འགྱུར་བ་སྟེ། ལྷའི་འགྲོ་བའོ། །དེས་ན་རྒྱ་མཚོའི་འགྲམ་ལ་ཐུག་པར་སྔོན་སུ་བར་བྱེད་པ་ཡིན་ནོ། །འདུག་བཞིན་དུ་ཞེས་བྱ་བ་སྟེ་མཚོན་རྡེག་པར་བྱེད་དོ། །ང་ནི་འདི་ན་ཞེས་སྨྲས་ནས་ཀྱང་རབ་ཏུ་རྡེག་པར་བྱེད་དོ། །མཐོང་བཞིན་ཞེས་བྱས༌[^1664]ནས་ཀྱང་གཞན་དག་ལ་རྡེག་པར་བྱེད་དོ། །ད་ནི་ཐར་པར་ག་ལ་འགྱུར་ཞེས་བྱས་ཤིང་ཡང་གཞན་དག༌[^1665]ལ་རབ་ཏུ་སྣུན་པར༌[^1666]བྱེད་དོ། །དེ་ལྟར་སྨྲས་ནས་གཞན་དག་ལ་ཐོབ་ཅིག་ཅེས་སྨྲས་ཏེ་ཕྱིར་ལོག་པ་དང་། དེ་དག༌[^1667]ལས་གཞན་དག་གིས་ཀྱང་མཚོན་འདེབས་པར་བྱེད་ཅིང་། ད་ནི་མེད་ཟིན་གྱིས་ཞེས་སྨྲས་ཏེ་མཚོན་འདེབས་པར་བྱེད་དོ། །མཚོན་ཆ་འཁྲུགས་པ༌[^1668]ནི་གཡུལ་དུའོ། །གློག་བཞིན་དུ་འགྱུ་བའི༌[^1669]བ་དན་ཅན་གང་དག་ནི་ཤིང་རྟ་སྟེ། དེ་ནི་གློག་ལྟར་འགྱུ་བའི་བ་དན་ཅན་ནོ། །གདུགས་དང་། རྒྱལ་མཚན་དང་། གོ་ཆ་དང་། མཚོན་ཆ་དང་། ཅོད་པན་རྣམས་ཏེ། [^1670]དེ་དག་ལྷུང་བར་གྱུར་པ་ནི་འགྱེལ་བར་གྱུར་པའོ། །ཕོག་པར་གྱུར་པ་ནི་ལམ་དུ་སྟེ་ཕོག་པར་གྱུར་པའི་སྟེང་དུའོ། །དེར་བབ་པ་ནི་ཕོག་པར་གྱུར་པའི་སྟེང་དུ་བབ་པའོ། །ཁ་ལོ་པ་ནི་ཁ་ལོ་སྒྱུར་བའོ། །ཕྲུ་གུ་མ་ཚར་བ་ཞེས་བྱ་བ་ནི་གཤོག་པ་མ་སྐྱེས་པའོ། །མ་ཚར་བ་ཉིད་བྱ༌[^1671]ཡིན་པས་བྱའི་ཕྲུ་གུ་སྟེ། བྱ་ཕྲུག་མ་ཚར་བ་དེའི་ཚང༌[^1672]བཅས་པའོ། །ལྷ་མ་ཡིན་འདི་དག་ང་ཅུང་སླར་མི་ལྡོག་གོ་ཞེས་བྱ་བ་དང་། ཅི་ཞེས་བྱ་བ་ནི་སྐྱོན་ཅི་ཡོད་ཅེས་བྱ་བའི་དོན་ཏོ། །ཤིང་རྟ་མ་བཟློག་པར་ནམ་མཁའ་ལྡིང་གི་ཚང་ལས་བཟུར་བར་མི་ནུས་པའི་ཕྱིར་རོ། །ཤིང་རྟ་བཟློག་པ༌[^1673]དེ་ལས་ཉེས༌[^1674]པ་མེད། །ཅེས་པ༌[^1675]དེའི་དབང་དུ་བྱས་ནས་ཤིང་རྟ་འདི་ནི་སླད་དུ་བཟློག༌[^1676]ན་གདོད་ཅེས་བྱ་བའི་ཚིགས་བཅད་བརྩམས་པ་ཡིན་ཏེ། ནམ་མཁའ་ལྡིང་གི་ཚང་འདི་ལས་ཟུར་ཅིག་ཅེས་བྱ་བའི་ལས༌[^1677]ནི། ཤིང་རྟ་འདི་ནི་སླད་དུ་བཟློག་ན་གདོད་ཅེས་བྱ་བའི་ཚིགས་བཅད་ཕྱེད་ཡིན་ནོ། །

འོ་ན་ཅི་ཞེས་བྱ་བའི་ལན་ནི་ལྷ་རྣམས་ལ་ནི་ཞེས་བྱ་བ་སྟེ། ཚིགས་བཅད་ཀྱི་ཕྱེད་འོག་མའོ། །དེ་བས་ན༌[^1678]ཞེས་བྱ་བ་ནི་ཤིང་རྟ་བཟློག་པ་ལ་ནི་ཉེས་པ་ཡོད་དོ་ཞེས་གོང་དུ་མ་ཏ་ལིས་སྨྲས་པའི་ཚིག་གོ། །ལྷ་རྣམས་ལ་ནི་གནས་ནས་སྐབས་རྙེད་པ་ཞེས་བྱ་བ་འདིའི་ལན་ནི་མཚོན་གྱིས་ཕོག་སྟེ་ཤི་བ་བླས༌[^1679]ཞེས་བྱ་བ་ཡིན་ཏེ། རང་གི་ལྷག་པའི་བསམ་པ་ཁྱད་པར་ཅན་བསྟན་པའི་ཕྱིར་སྨྲས་པའོ། །ཤི་ཡང་བླས༌[^1680]ཞེས་བྱ་བ་ལ་སོགས་པ་ནི་སྙིང་རྗེའི་དབང་གིས་སྨྲས་པ་སྟེ།[^1681] དེ་ལྟར་སྤྱོད་པའི་སེམས་ཅན་འཇིགས་པས་ཉེན་པ་འདིའི་ཆེད་དུའོ། །འཇིགས་པས་བརྟབས་ཤིང་རབ་ཏུ་མགྱོགས་པར་གྱུར་པ་གང་ཡིན་པ་དེ་ནི་སྐྲག་ནས་བརྟབས་ཤིང་རབ་ཏུ་མགྱོགས་པར་བྱེད་པའོ། །ཇི་ལྟ་བུར༌[^1682]ཞེ་ན། ཆར་སྤྲིན་ནག་པོ་རླུང་གིས༌[^1683]གཏོར་བ་བཞིན། །བདག་གི་དམག་ཚོགས་ཕམ་ཡང་ཞེས་བྱ་བའི་ཚིགས་བཅད་ཡིན་ནོ། །དགའ་བ་དང་ངོ་ཚ་བ་ནི་དགའ་ཞིང་ངོ་ཚ་བའོ། །དགའ་བ་དང་ངོ་ཚ་བ་དང་བཅས་པ་ནི་དགའ་ཞིང་ངོ་ཚ་བཞིན་དུའོ། །ཕོངས་ན་ཞེས་བྱ་བའི་སྒྲ་ནི་ངན་པ་དང་བློ་འབྲིང་པོ་གཉི་ག་ལ་སྦྱར་བར་བྱའོ། །ངན་པ་དང་བློ་འབྲིང་པོ་ནི་སྡིག་པ་སྤྱོད་པའི་ཚེ་ན་མི་མཉམ་པ་སྟེ། སྙིང་རྗེ་དང་བཅས་པས་སོ། །སྐྱེ་བོ་དམ་པ་རྣམས་ཀྱི་ཁྱད་པར་ནི་འདི་ཡིན་ཏེ། རྣམ་པ་ཐམས་ཅད་དུ་སྡིག་པ་མི་བྱེད་དེ། སྙིང་རྗེ་དང་བཅས་པར་གྲུབ་པ་ཡིན་པས་ཡང་མི་བརྗོད་དོ། །[^1684]སློབ་དཔོན་དཔའ་བོས་མཛད་པའི་སྐྱེས་པའི་རབས་རྒྱ་ཆེར་བཤད་པ་ལས་བརྒྱ་བྱིན་གྱི་སྐྱེས་པའི་རབས་སོ།། །།

## བྲམ་ཟེའི་སྐྱེས་པའི་རབས། ^13-0

[Block 1336]
བདག་ངོ་ཚ་བ་ཉིད་ཀྱིས་ཞེས་བྱ་བ་ནི་ངོ་ཚ་བ་ཉིད་ཁྲེལ་ཡོད་པ་ཞེས་བྱ་བའི་དོན་ཏོ། །བདག་དང་ཆོས་ཀྱི་དབང་དུ་བྱས་ཏེ་ཁ་ན་མ་ཐོ་བ་ཞེས་བྱ་བའི་ཚིག་གིས་སོ། །སྤྱོད་ཡུལ་གྱི་དུས་ཞེས་བྱ་བ་ནི་ཚུལ་དང་སྤྱོད་པ་སྟེ་གང་བྱ་བའོ། །རང་གི་ཆོས་ཞེས་བྱ་བ་ནི་འདོན་པ་དང་། འདོན་དུ་འཇུག་པ་དང་། མཆོད་སྦྱིན་བྱེད་པ་དང་། བྱེད་དུ་འཇུག་པ་དང་། སྦྱིན་པ་དང་། ལེན་པ་སྟེ། དེ་དག་ནི༌[^1685]རང་གི་ཆོས་སོ། །རང་གི་ཆོས་དེ་དག་གི་རྗེས་སུ་སྤྱོད་པའི་གྲགས་པ་གང་ཡིན་པ་དེ་ནི་རང་གི་ཆོས་ལ་སྤྱོད་པའི་གྲགས་པའོ།[^1686] །འདུལ་བ་ནི་བྱ་བ་མ་ཡིན་པའི་ལས་ལ་སོགས་པ༌[^1687]ལས་ལྡོག་པ་སྟེ། ཇི་ལྟར་རིགས་པའི་སྒྲུབ་པའོ། །བཙས་པའི་ཆོ་ག་བྱ་བ་ལ་སོགས་པས་ཞེས་སྨོས་པས་ནི་ལྷག་མཆོ་ག་བཅུ་གཉིས་ཀྱང་གཟུང་ངོ་། །ལྡོག་པ༌[^1688]དང་། འཛིན་པ་ནི་ལྡོག་པ༌[^1689]དང་འཛིན་པ་དག་སྟེ། ཐོབ་པ༌[^1690]ལྡོབ་ཅིང་འཛིན་པ་དེ་གཉིས་ལ་གང༌[^1691]གསལ་བར་གྱུར་པ་ནི་ཐོབ་པ༌[^1692]ལྡོབ་ཅིང་འཛིན་པ་གསལ་བའོ། །འདི་དག་ནི་བྱ་བ་ཤེས་པ་དང་། སློབ་པའི་ཡན་ལག་ཡིན་ནོ། །རྒྱུད་ཉིད་གུས་པ་ཡིན་པས་རྒྱུད་གུས་ཏེ། གུས་པའི་རྒྱུད་ཅེས་བྱ་བའི་དོན་ཏོ། །དུལ་བ་ནི་བྱ་བ་རྣམས་ལ་བླ་མའི་རྗེས་སུ་འཇུག་པ་ཡིན་ཏེ། འདིས་ནི་བསླབ་པའི་ཡན་ལག་དང་ལྡན་པ་བསྟན་ཏོ། །ཞི་ཞིང་ཆོས་བཟང་པོ་གང་ལ་ཡོད་པ་དེ་ནི་ཞི་ཞིང་ཆོས་བཟང་པོའོ།[^1693] །འདིས་ཀྱང་ཚུལ་ཁྲིམས་ཀྱི་ཡན་ལག་བསྟན་ཏོ། །བྱམས་པ་ནི་ཆགས་པའོ། །དགའ་བ་ནི་དད་པ་འམ་དང་བའོ། །བྱམས་ཤིང༌[^1694]དགའ་བ་གཉིས་སུ་གྱུར་པ་ནི་དེ་གཉིས་ཀྱིས་ཡིན་ཏེ། བྱམས་པར་གྱུར་པ་ནི་ཞི་བས་སོ། །ཆོས་བཟང་བར་གྱུར་པ༌[^1695]ནི་བླ་མ་དགའ་བར་གྱུར་པའོ། །དབང་དུ་བྱེད་པ་ནི་སྔགས་ཀྱི་དོན་གྱིས་སོ། །ཡོན་ཏན་དབང་དུ་བྱེད་པའི་སྔགས་རྟག་ཏུ་ཞེས་བྱ་བ་ལ། སྔགས་ཡོན་ཏན་དབང་དུ་བྱེད་པ་ལས་གཞན་དག་ལས་ཡོན་ཏན་གྱི་མཚན་ཉིད་ཀྱིས་དབང་དུ་བྱེད་པའི་སྔགས་འདི་ནི་ཁྱད་པར་དུ་བསྟན་པ་ཡིན་ཏེ། ཡོན་ཏན་ནི་རྟག་ཏུ་ཡོད་པ་ཡིན་པས་སྔགས་གཞན་ལྟར་མི་རྟག་ཅིང་ཉམས་པ་ནི་མ་ཡིན་ཏེ། ཡོན་ཏན་དབང་དུ་བྱེད་པའི་སྔགས་འདི་ལས་གཞན་པའི་དབང་དུ་བྱེད་པའི་སྔགས་ནི། ཞེ་སྡང་གིས་འཁྲུགས་པ་སྟེ། དབང་དུ་བྱེད་པའི་ནུས་པ་མེད་དོ། །སྔགས་འདིས་ནི་དེ་ལྟ་བུའང་དབང་དུ་བྱེད་པ་ཡིན་ནོ། །སྔགས་ཐ་མལ་པས་ནི༌[^1696]བདག་ཉིད་ཀྱི་སེམས་དབང་དུ་བྱེད་པ་ཡིན་ནོ། །གཞན་དག་ནི་མ་ཡིན་ནོ། །གསང་དུས་དག་ཏུ་ཞེས་བྱ་བ་ནི་མི་འདོད་པའི་དུས་རྟག༌[^1697]ཏུའོ། །དབུལ་བ་འབྲས་བུ་རེ་བ་མེད། །ཅེས་བྱ་བའི་ཚིགས་བཅད་ཀྱི་དོན་ནི་འདི་ཡིན་ཏེ། བདག་དང་གཞན་གྱི་ཕན་པ་དང་། འཇིག་རྟེན་འདི་དང༌[^1698]ཕ་རོལ་ཏུ་ཕན་པ་མེད་པ་སྟེ། བདག་གིས༌[^1699]མི་ལའང་སྨྲར་མེད་ཅིང་། །ཅེས་བྱ་བ་འདིས་ནི་གཞན་ལ་ཕན་པ་མི་ནུས་པ་ཉིད་དོ། །དགའ་སྟོན་ཚེ་ན་འད་དགའ་མི་མྱོང་། །ཞེས་བྱ་བ་འདིས་ནི་བདག་གི་དོན་མི་ནུས་པ་ཉིད་དོ། །ཀྱི་ཧུད་སྦྱིན་པའི་གཏམ་ཡང་གཞན། །ཞེས་བྱ་བ་འདིས་ནི་འཇིག་རྟེན་ཕ་རོལ་གྱི་ཕན་པ་མི་ནུས་པ་ཉིད་དེ། གང་གི་ཕྱིར་སྦྱིན་པ་ཡོད་ན་ནི་འཇིག་རྟེན་ཕ་རོལ་ཏུ་མངོན་པར་མཐོ་བ་ཐོབ་པར་འགྱུར་རོ། །དབུལ་བ་འབྲས་བུ་རེ་བ་མེད། །ཅེས་བྱ་བ་འདིས་ནི་འཇིག་རྟེན་འདི་ལ་ཕན་པའི་བྱ་བ་མི་ནུས་པ་ཉིད་དོ། །རེ་བ་ནི་མངོན་པར་འདོད་པ་སྟེ། འདི་དང་འདི་བྱའོ་ཞེས་བྱ་བ་དེ་དང་དེའི་འབྲས་བུ་མེད་པ་ཡིན་ཏེ། འབྱོར་པ་མ་ཡིན་པར་ནི་བསམ་པ་འབྲས་བུ་དང་བཅས་པར་མི་འགྱུར་རོ། །སྨ་འབབ་གནས་གྱུར་ཞེས་བྱ་བའི་ཚིགས་བཅད་ཀྱི་དོན་ནི་འདི་ཡིན་ཏེ། བདག་དང་གཞན་གྱི་སྒྲུབ་པའི་རྒྱུ་མེད་པ་དང་། བདག་ཉིད་ཀྱི་སྡུག་བསྔལ་གྱི་རྒྱུ་དང་། བདེ་བ་མི་ཐོབ་པའི་རྒྱུ་དང་། གཞན་ལ་ཡང་དག་པར་སྒྲུབ་པ་མི་འཐོབ་པའི༌[^1700]རྒྱུ་དང་བཞི་པོ་འདི་དག༌[^1701]གོ་རིམས་བཞིན་དུ༌[^1702]སྦྱར་བར་བྱའོ། །ཉམས་ཉེས༌[^1703]བཞིན་དུ་རྟག་ཏུ་མྱ་ངན་བྱེད། །ཅེས་བྱ་བ་ནི་བཞི་པོ་དེ་དག་གི་རྒྱུས་སོ། །བཀྲེས་སྐོམ་ཟན་དང་ཞེས་བྱ་བ་འདིའི་ལུས་ནི་རྣམ་པ་གསུམ་སྟེ། སྡུག་བསྔལ་རྣམ་པ་གསུམ་གྱི༌[^1704]གསོ་བར་བསྟན་པ་ཡིན་ཏེ། བཀྲེས་པ་ལ་ནི་ཟན་ནོ། །སྐོམ་པ་ལ་ནི་ཆུའོ། །འདི་གཉིས་ནི་ལྷན་ཅིག་སྐྱེས་པའི་སྡུག་བསྔལ་གྱི་གསོ་བར་བསྟན་ཏོ། །སྨན་བཅས་སྔགས་ཀྱིས་ནད་སོས་འགྱུར། །ཞེས་བྱ་བ་འདིས་ནི་གློ་བུར་གྱི་སྡུག་བསྔལ་གསོ་བར་བསྟན་ཏོ། །རྒྱུན་གནས་ནོར་གྱིས༌[^1705]དབུལ་པོར་འགྱུར། །ཞེས་བྱ་བ་འདིས་ནི་སྔོན་བྱས་པའི་རྒྱུའི་དབུལ་བའི་སྡུག་བསྔལ་ལས་གསོ་བར་བསྟན་ཏེ། གང་གི་ཕྱིར་དབུལ་པོ་ནི་སྐྱེ་བ་སྔ་མ་ལ་རང་གི་སེར་སྣ་བྱས་པའི་རྒྱུ༌[^1706]ཡིན་ཏེ། ད༌[^1707]གསོ་བ་ནི་ནོར་རོ། །བླང་བའི་ཐབས་རབ་ཏུ་ཆུང་བ་གང་ཡིན་པ་དེ་ནི་བླང་བའི་ཐབས་རབ་ཏུ་ཆུང་བའོ། །བྲམ་ཟེ་རྒུད་ཚེ་རྐུ་བ་ཆོས་སུ་བཤད། ## བྲམ་ཟེའི་སྐྱེས་པའི་རབས། ^13-0

[Block 1336 — OVER_LENGTH (913 syllables)]
བདག་ངོ་ཚ་བ་ཉིད་ཀྱིས་ཞེས་བྱ་བ་ནི་ངོ་ཚ་བ་ཉིད་ཁྲེལ་ཡོད་པ་ཞེས་བྱ་བའི་དོན་ཏོ། །བདག་དང་ཆོས་ཀྱི་དབང་དུ་བྱས་ཏེ་ཁ་ན་མ་ཐོ་བ་ཞེས་བྱ་བའི་ཚིག་གིས་སོ། །སྤྱོད་ཡུལ་གྱི་དུས་ཞེས་བྱ་བ་ནི་ཚུལ་དང་སྤྱོད་པ་སྟེ་གང་བྱ་བའོ། །རང་གི་ཆོས་ཞེས་བྱ་བ་ནི་འདོན་པ་དང་། འདོན་དུ་འཇུག་པ་དང་། མཆོད་སྦྱིན་བྱེད་པ་དང་། བྱེད་དུ་འཇུག་པ་དང་། སྦྱིན་པ་དང་། ལེན་པ་སྟེ། དེ་དག་ནི༌[^1685]རང་གི་ཆོས་སོ། །རང་གི་ཆོས་དེ་དག་གི་རྗེས་སུ་སྤྱོད་པའི་གྲགས་པ་གང་ཡིན་པ་དེ་ནི་རང་གི་ཆོས་ལ་སྤྱོད་པའི་གྲགས་པའོ།[^1686] །འདུལ་བ་ནི་བྱ་བ་མ་ཡིན་པའི་ལས་ལ་སོགས་པ༌[^1687]ལས་ལྡོག་པ་སྟེ། ཇི་ལྟར་རིགས་པའི་སྒྲུབ་པའོ། །བཙས་པའི་ཆོ་ག་བྱ་བ་ལ་སོགས་པས་ཞེས་སྨོས་པས་ནི་ལྷག་མཆོ་ག་བཅུ་གཉིས་ཀྱང་གཟུང་ངོ་། །ལྡོག་པ༌[^1688]དང་། འཛིན་པ་ནི་ལྡོག་པ༌[^1689]དང་འཛིན་པ་དག་སྟེ། ཐོབ་པ༌[^1690]ལྡོབ་ཅིང་འཛིན་པ་དེ་གཉིས་ལ་གང༌[^1691]གསལ་བར་གྱུར་པ་ནི་ཐོབ་པ༌[^1692]ལྡོབ་ཅིང་འཛིན་པ་གསལ་བའོ། །འདི་དག་ནི་བྱ་བ་ཤེས་པ་དང་། སློབ་པའི་ཡན་ལག་ཡིན་ནོ། །རྒྱུད་ཉིད་གུས་པ་ཡིན་པས་རྒྱུད་གུས་ཏེ། གུས་པའི་རྒྱུད་ཅེས་བྱ་བའི་དོན་ཏོ། །དུལ་བ་ནི་བྱ་བ་རྣམས་ལ་བླ་མའི་རྗེས་སུ་འཇུག་པ་ཡིན་ཏེ། འདིས་ནི་བསླབ་པའི་ཡན་ལག་དང་ལྡན་པ་བསྟན་ཏོ། །ཞི་ཞིང་ཆོས་བཟང་པོ་གང་ལ་ཡོད་པ་དེ་ནི་ཞི་ཞིང་ཆོས་བཟང་པོའོ།[^1693] །འདིས་ཀྱང་ཚུལ་ཁྲིམས་ཀྱི་ཡན་ལག་བསྟན་ཏོ། །བྱམས་པ་ནི་ཆགས་པའོ། །དགའ་བ་ནི་དད་པ་འམ་དང་བའོ། །བྱམས་ཤིང༌[^1694]དགའ་བ་གཉིས་སུ་གྱུར་པ་ནི་དེ་གཉིས་ཀྱིས་ཡིན་ཏེ། བྱམས་པར་གྱུར་པ་ནི་ཞི་བས་སོ། །ཆོས་བཟང་བར་གྱུར་པ༌[^1695]ནི་བླ་མ་དགའ་བར་གྱུར་པའོ། །དབང་དུ་བྱེད་པ་ནི་སྔགས་ཀྱི་དོན་གྱིས་སོ། །ཡོན་ཏན་དབང་དུ་བྱེད་པའི་སྔགས་རྟག་ཏུ་ཞེས་བྱ་བ་ལ། སྔགས་ཡོན་ཏན་དབང་དུ་བྱེད་པ་ལས་གཞན་དག་ལས་ཡོན་ཏན་གྱི་མཚན་ཉིད་ཀྱིས་དབང་དུ་བྱེད་པའི་སྔགས་འདི་ནི་ཁྱད་པར་དུ་བསྟན་པ་ཡིན་ཏེ། ཡོན་ཏན་ནི་རྟག་ཏུ་ཡོད་པ་ཡིན་པས་སྔགས་གཞན་ལྟར་མི་རྟག་ཅིང་ཉམས་པ་ནི་མ་ཡིན་ཏེ། ཡོན་ཏན་དབང་དུ་བྱེད་པའི་སྔགས་འདི་ལས་གཞན་པའི་དབང་དུ་བྱེད་པའི་སྔགས་ནི། ཞེ་སྡང་གིས་འཁྲུགས་པ་སྟེ། དབང་དུ་བྱེད་པའི་ནུས་པ་མེད་དོ། །སྔགས་འདིས་ནི་དེ་ལྟ་བུའང་དབང་དུ་བྱེད་པ་ཡིན་ནོ། །སྔགས་ཐ་མལ་པས་ནི༌[^1696]བདག་ཉིད་ཀྱི་སེམས་དབང་དུ་བྱེད་པ་ཡིན་ནོ། །གཞན་དག་ནི་མ་ཡིན་ནོ། །གསང་དུས་དག་ཏུ་ཞེས་བྱ་བ་ནི་མི་འདོད་པའི་དུས་རྟག༌[^1697]ཏུའོ། །དབུལ་བ་འབྲས་བུ་རེ་བ་མེད། །ཅེས་བྱ་བའི་ཚིགས་བཅད་ཀྱི་དོན་ནི་འདི་ཡིན་ཏེ། བདག་དང་གཞན་གྱི་ཕན་པ་དང་། འཇིག་རྟེན་འདི་དང༌[^1698]ཕ་རོལ་ཏུ་ཕན་པ་མེད་པ་སྟེ། བདག་གིས༌[^1699]མི་ལའང་སྨྲར་མེད་ཅིང་། །ཅེས་བྱ་བ་འདིས་ནི་གཞན་ལ་ཕན་པ་མི་ནུས་པ་ཉིད་དོ། །དགའ་སྟོན་ཚེ་ན་འད་དགའ་མི་མྱོང་། །ཞེས་བྱ་བ་འདིས་ནི་བདག་གི་དོན་མི་ནུས་པ་ཉིད་དོ། །ཀྱི་ཧུད་སྦྱིན་པའི་གཏམ་ཡང་གཞན། །ཞེས་བྱ་བ་འདིས་ནི་འཇིག་རྟེན་ཕ་རོལ་གྱི་ཕན་པ་མི་ནུས་པ་ཉིད་དེ། གང་གི་ཕྱིར་སྦྱིན་པ་ཡོད་ན་ནི་འཇིག་རྟེན་ཕ་རོལ་ཏུ་མངོན་པར་མཐོ་བ་ཐོབ་པར་འགྱུར་རོ། །དབུལ་བ་འབྲས་བུ་རེ་བ་མེད། །ཅེས་བྱ་བ་འདིས་ནི་འཇིག་རྟེན་འདི་ལ་ཕན་པའི་བྱ་བ་མི་ནུས་པ་ཉིད་དོ། །རེ་བ་ནི་མངོན་པར་འདོད་པ་སྟེ། འདི་དང་འདི་བྱའོ་ཞེས་བྱ་བ་དེ་དང་དེའི་འབྲས་བུ་མེད་པ་ཡིན་ཏེ། འབྱོར་པ་མ་ཡིན་པར་ནི་བསམ་པ་འབྲས་བུ་དང་བཅས་པར་མི་འགྱུར་རོ། །སྨ་འབབ་གནས་གྱུར་ཞེས་བྱ་བའི་ཚིགས་བཅད་ཀྱི་དོན་ནི་འདི་ཡིན་ཏེ། བདག་དང་གཞན་གྱི་སྒྲུབ་པའི་རྒྱུ་མེད་པ་དང་། བདག་ཉིད་ཀྱི་སྡུག་བསྔལ་གྱི་རྒྱུ་དང་། བདེ་བ་མི་ཐོབ་པའི་རྒྱུ་དང་། གཞན་ལ་ཡང་དག་པར་སྒྲུབ་པ་མི་འཐོབ་པའི༌[^1700]རྒྱུ་དང་བཞི་པོ་འདི་དག༌[^1701]གོ་རིམས་བཞིན་དུ༌[^1702]སྦྱར་བར་བྱའོ། །ཉམས་ཉེས༌[^1703]བཞིན་དུ་རྟག་ཏུ་མྱ་ངན་བྱེད། །ཅེས་བྱ་བ་ནི་བཞི་པོ་དེ་དག་གི་རྒྱུས་སོ། །བཀྲེས་སྐོམ་ཟན་དང་ཞེས་བྱ་བ་འདིའི་ལུས་ནི་རྣམ་པ་གསུམ་སྟེ། སྡུག་བསྔལ་རྣམ་པ་གསུམ་གྱི༌[^1704]གསོ་བར་བསྟན་པ་ཡིན་ཏེ། བཀྲེས་པ་ལ་ནི་ཟན་ནོ། །སྐོམ་པ་ལ་ནི་ཆུའོ། །འདི་གཉིས་ནི་ལྷན་ཅིག་སྐྱེས་པའི་སྡུག་བསྔལ་གྱི་གསོ་བར་བསྟན་ཏོ། །སྨན་བཅས་སྔགས་ཀྱིས་ནད་སོས་འགྱུར། །ཞེས་བྱ་བ་འདིས་ནི་གློ་བུར་གྱི་སྡུག་བསྔལ་གསོ་བར་བསྟན་ཏོ། །རྒྱུན་གནས་ནོར་གྱིས༌[^1705]དབུལ་པོར་འགྱུར། །ཞེས་བྱ་བ་འདིས་ནི་སྔོན་བྱས་པའི་རྒྱུའི་དབུལ་བའི་སྡུག་བསྔལ་ལས་གསོ་བར་བསྟན་ཏེ། གང་གི་ཕྱིར་དབུལ་པོ་ནི་སྐྱེ་བ་སྔ་མ་ལ་རང་གི་སེར་སྣ་བྱས་པའི་རྒྱུ༌[^1706]ཡིན་ཏེ། ད༌[^1707]གསོ་བ་ནི་ནོར་རོ། །བླང་བའི་ཐབས་རབ་ཏུ་ཆུང་བ་གང་ཡིན་པ་དེ་ནི་བླང་བའི་ཐབས་རབ་ཏུ་ཆུང་བའོ། །བྲམ་ཟེ་རྒུད་ཚེ་རྐུ་བ་ཆོས་སུ་བཤད། །ཅེས་བྱ་བའི་ཚིགས་སུ་བཅད་པ་འདིས་ནི་བྲམ་ཟེ་རྒུད་པར་གྱུར་པའི་ཚེ་ན་ནི་བྲམ་ཟེ་རྒུད་པ་ཉིད་ལ་ཉེས་པ་མེད་པ་ཉིད་དུ་བསྟན་ཏོ། །གལ་ཏེ་བྲམ་ཟེ་རྣམས་ཀྱི་རང་ཉིད་ཀྱི་ནོར་ཡིན་ན་ཅིའི་ཕྱིར་མ་མཐོང་བར་བླང་ཞེ་ན། དེའི་ལན་བསྟན་པའི་ཕྱིར། ངོ་མཐོན་དུ་ནི་ནོར་འཕྲོག༌[^1708]ནུས་གྱུར་ཀྱང་། །ཞེས་བྱ་བའི་ཚིགས་བཅད་བརྩམས་བ་ཡིན་ནོ། །
