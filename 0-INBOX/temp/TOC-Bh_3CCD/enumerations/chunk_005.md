Enumeration Block 1:
ཟུང་དུ་འཇུག་པའི་རིམ་པ་བསྟན་པར་བྱ་སྟེ། དེ་ཡང་གཉིས་སོ། །
རྒྱུའི་ཟུང་དུ་འཇུག་པ་དང་། འབྲས་བུའི་ཟུང་དུ་འཇུག་པའོ། །
རྒྱུའི་ཟུང་དུ་འཇུག་པ་ལ་རྣམ་པ་བཞི་སྟེ། ཉན་ཐོས་དང་། རང་སངས་རྒྱས་དང་། དབུ་མ་དང་། སྔགས་ཀྱི་ལྟ་བའི་བྱེ་བྲག་གིས་སོ། །
Enumeration Block 2:
སངས་རྒྱས་བཅོམ་ལྡན་འདས་རྣམས༌[^606]ཀྱི་སྤྱོད་ལམ་རྣམ་པ་བཞི་སྟེ། སྤྱོད་ལམ་གྱི་བཞུགས་པ་དང་། བསྟན་པའི་བཞུགས་པ་དང་། ཏིང་ངེ་འཛིན་གྱི་བཞུགས་པ་དང་། སོ་སོར་ཡང་དག་པའི་འཇུག་པའི་བཞུགས་པའོ། །
Enumeration Block 3:
དེ་བརྩམ་པ༌[^620]ལ་དང་པོ་རྣམ་པ་གསུམ་ཡིན་ཏེ། བྱ་བ་དང་བྱ་བའི་འབྲས་བུ་དང་། བྱ་བའི་འབྲས་བུའི་འབྲས་བུའོ། །
Enumeration Block 4:
བརྗོད་པ་ལ་སོགས་པ་རྣམ་པ་ལྔ་པོ་ཉན་པ་པོ་འཇུག་པར་བྱ་བའི་ཕྱིར་སྨྲ་བར་བྱ་སྟེ། རྗོད་པ་དང་བརྗོད་པར་བྱ་བ་དང་། འབྲེལ་པ་དང་། དགོས་པ་དང་། དགོས་པའི་དགོས་པའོ། །
Enumeration Block 5:
འབྲེལ་པ་ཞེས་བྱ་བ་ནི་རྣམ་པ་གཉིས་ཏེ། དེའི་བདག་ཉིད་དང་། དེ་ལས་བྱུང་བའོ། །
Enumeration Block 6:
འབྲེལ་པ་དེ་ཡང་རྣམ་པ་དྲུག་ཏུ་འགྱུར༌[^656]ཏེ། དེ་བཞིན་གཤེགས་པ་དང་ལྷ་མོ་དང་བྱང་ཆུབ་སེམས་དཔའ་དང་། ལྷ་དང་། མིའམ་ཅི་དང་། མི་རྣམས་ཀྱིའོ།[^657] །
Enumeration Block 7:
འབྲེལ་པ་དྲུག་པོ་རྒྱས་པ་དེ་མདོར་བསྡུས་པས་རྣམ་པ་གཉིས་སུ་འགྱུར་ཏེ། སྒྲ་དང་དོན་གྱི་འབྲེལ་པ་དང་། [^678]སྟོན་པ་དང་འཁོར་གྱི་འབྲེལ་པའོ། །
Enumeration Block 8:
གང་ཟག་ལྔ་བརྟག་པར༌[^700]བྱ་སྟེ།
Enumeration Block 9:
གང་ཟག་བཞི་ཡོད་དེ། མི་ཤེས་པ་དང་། ཐེ་ཚོམ་ཟ་བ་དང་། ཕྱིན་ཅི་ལོག་པའི་བློ་དང་། ངེས་པ་ཅན་གྱི་བློ་ཅན་ནོ། །
དེ་ལ་མི་ཤེས་པ་ནི་རྣམ་པ་གཉིས་ཏེ། ཚད་མའི་རྗེས་སུ་འབྲང་བ་དང་། ཚད་མ་མ་ཡིན་པའི་རྗེས་སུ་འབྲང་བའོ། །
Enumeration Block 10:
ཐེ་ཚོམ་ཟ་བ་ལ་ཡང་རྣམ་པ་གཉིས་ཏེ་སྔ་མ་བཞིན་ཏེ།
Enumeration Block 11:
ཕྱིན་ཅི་ལོག་པའི་བློ་ཅན་ནི་རྣམ་པ་གསུམ་སྟེ། ཐེ་ཚོམ་ཟ་བ་ལ་ཕྱིན་ཅི་ལོག་པ་དང་། མི་ཤེས་པ་ལ་ཕྱིན་ཅི་ལོག་པ་དང་། ཤེས་པ་ལ་ཕྱིན་ཅི་ལོག་པའོ། །
Enumeration Block 12:
ཤེས་པ་ལ་ཕྱིན་ཅི་ལོག་པ་ལ་ཡང་གཉིས་ཏེ། ཚད་མའི་རྗེས་སུ་འབྲང་བ་དང་། ཚད་མའི་རྗེས་སུ་འབྲང་བ་མ་ཡིན་པའོ། །
Enumeration Block 13:
ཤེས་པ་ལ་ཚད་མའི་རྗེས་སུ་འབྲང་བ་ཕྱིན་ཅི་ལོག་པའི་བློ་ཅན་ལ༌[^718]རྣམ་པ་དྲུག་སྟེ། གྲངས་ཅན་པ་དང་། རིགས་པ་པ་དང་། འཇིག་རྟེན་རྒྱང་པན་པ་དང་། མཆོད་འོས་པ་དང་། ཞི་བ་པ་དང་། དཔྱོད་པ༌[^719]པའོ། །
