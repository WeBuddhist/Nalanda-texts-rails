Enumeration Block 1:
ཤིན་ཏུ་དགོད་དང་སྤྱོད་པའི་གནས། །
དེ་བཞིན་དུ་ནི་རིགས་ཀྱི་རི། །
རྒྱལ་བ་དང་ནི་ཉེ་རྒྱལ་དང་། །
དེ་བཞིན་རབ་མཆོག་ཆུ་ཡི་གནས། །
ཆར་པའི་རྩེ་དང་དེ་བརྒྱད་དང་། །
དེ་དག་ཞིང་ཞེས་བྱ་བར་གྲགས། །

Enumeration Block 2:
འདབ་མ་བརྒྱད་ཀྱིས་རྣམ་པར་བརྒྱན། །
དེ་ལྟ་བས་ན་བརྒྱད་དུ་ཤེས། །

Enumeration Block 3:
སྣ་ཚོགས་མཆོད་པ་དྲུག་ཆོ་གས། །

Enumeration Block 4:
ན་དི༌[^44]བཅུ་པོའང་དེ་བཞིན་ནོ། །

Enumeration Block 5:
རབ་དགའ་ལ་སོགས་ས་བརྒྱད་དང་། །
ལགས་པའི་བློ་གྲོས་དང་བཅས་དགུ། །
ཞིང་བརྒྱད་ཁྱད་པར་དུ་བརྗོད་པ། །
ཞིང་དགུའི་བདག་པོར་ཤེས་པར་བྱ། །

Enumeration Block 6:
ས་ལ་སོགས་པ་དེ་བཞིན་དྲུག །
འདོད་པ་ཡི་ནི་གཟུགས་སུ་གནས། །
གཞན་དུ་བདུད་རྩི་ལྔ་ཡང་བརྗོད། །

Enumeration Block 7:
དབང་ཕྱུག་དང་སོགས་དངོས་གྲུབ་བརྒྱད། །

Enumeration Block 8:
ལྔ་པོ་ལྔ་པོའི་བདག་ཉིད་ཀྱིས།[^49] །

Enumeration Block 9:
རིམ་པ་བརྒྱད་པ༌[^50]ཤེས་པར་བྱ། །

Enumeration Block 10:
དེ་ཉིད་གསུམ་པོ་ལམ་གསུམ་བཞི། །
མགོ་ཞེས་བྱ་བར༌[^55]སྒྲ་ཆེན་པོ། །
བཅུ་གཉིས་ཀྱི་ནི་མཚམས་སུ་གནས། །
