དེ་ལ་བཤད་པ་ནི་རྣམ་པ་བརྒྱད་དེ། བརྗིད་པ་དང་། རྣམ་པར་འགྲེལ་བ་དང་ལྡན་པ་དང་། རྒོལ་བའི་ལན་དང་ལྡན་པ་དང་། རབ་ཏུ་དབྱེ་བ་དང་ལྡན་པ་དང་། དེ་དང་འབྲེལ་པ་དང་། དེ་ལས་གཞན་པ་ལས་དྲངས་པ་དང་། སྤོབས་པ་ལས་བྱུང་བ་དང་། གྲུབ་པའི་མཐའི་རྗེས་སུ་འབྲང་བའོ། །

Enumeration Block 5:
དེ་ལ་འཁོར་ནི་རྣམ་པ་ལྔ་སྟེ། ཁྱིམ་ན་གནས་པའི་འཁོར་དང་། རབ་ཏུ་བྱུང་བའི་འཁོར་དང་། དད་པ་དང་ལྡན་པའི་འཁོར་དང་། ཞེ་འགྲས་པའི་འཁོར་དང་། ཐ་མལ་པར་གནས་པའི་འཁོར་ཏོ། །

Enumeration Block 6:
དེ་ལ་བརྗིད་པའི་གཏམ་ནི་རྣམ་པ་ལྔར་རིག་པར་བྱ་སྟེ། གཏན་ཚིགས་དང་ལྡན་པ་དང་། དཔེ་དང་ལྡན་པ་དང་ཚིག་གི་བྱ་བ་དང་ལྡན་པ་དང་། ཚིག༌[^135]དང་། ཡིག་འབྲུ་སྣ་ཚོགས་པ་དང་། གོ་སླ་བའོ། །

Enumeration Block 7:
དེ་ཡང་བསྡུས་པ་དང་། རྒྱས་པ་སྟེ། དེ་ལ་བསྡུས་པ་ནི་རྣམ་པ་ལྔས་རིག་པར་བྱ་སྟེ། གཟུགས་བཟང་བ་དང་། ཉེ་བར་ཞི་བ་དང་། མཁྱེན་པ་དང་། སྒྲུབ་པ་དང་། མཐུས་སོ། །

Enumeration Block 8:

Enumeration Block 1:
དེ༌[^178]ཡང་བཅོམ་ལྡན་འདས་ཀྱི༌[^179]བསྔགས་པ་བསྡུས་ཏེ་བརྗོད་པ་ནི་རྣམ་པ་དྲུག་གིས་རིག་པར་བྱ་སྟེ།

Enumeration Block 2:
དེ་ལྟར་མཁས་པར་འགྱུར་བ་ལ་ནི་ཕན་ཡོན་རྣམ་པ་ལྔ་ཡོད་དེ། ཚེགས་ཆུང་ངུས་སངས་རྒྱས་ཀྱི་བཀའི་དོན་རྟོགས་པར་འགྱུར་བ་དང་། རྣམ་པ་ཐམས་ཅད་ཡོངས་སུ་རྫོགས་པའི་གཏམ་དག་ལ་འཇུག་པར་འགྱུར་བ་དང་། བདག་དང་གཞན་གྱི་རྒྱུད་དག༌[^222]ལ་དགའ་བ་དང་། མཆོག་ཏུ་དགའ་བ་དགེ་བ་དང་ངེས་པར་འབྱུང་བ་དང་ལྡན་པ་རྒྱ་ཆེན་པོ་སྐྱེད་པར་འགྱུར་བ་དང་། ལྷ་དང་མི་རྣམས་ཀྱི་བར་དག་ལ་སྙན་པ་དང་གྲགས་པ་དགེ་བ་ངེས་པར་འབྱུང་བ་དང་ལྡན་པ་རྒྱས་པར༌[^223]འགྱུར་བ་དང་། བསོད་ནམས་ཚད་མེད་པ་སྐྱེ་བར་འགྱུར་བའོ། །

Enumeration Block 3:
དེའི་ལུས་ནི་ཚིག་འབྲུ་དང་དོན་ཏོ། །

Enumeration Block 1:
དྲན་པ་དེ་ཡང་མདོར་བསྡུ་ན་རྣམ་པ་གསུམ་དུ་བལྟ་བར་བྱ་སྟེ། ཆོས་བསྟན་པ་ལ་བརྟེན་པ་དང་། གདམས་ངག་ལ་བརྟེན་པ་དང་། བྱས་པ་དང་མ་བྱས་པ་ལ་སོ་སོར་རྟོག་པ་ལ་བརྟེན་པའོ། །

Enumeration Block 2:
གཞན་ཡང་མདོ་སྡེ་རྣམ་པར་བཤད་པ་ནི་རྣམ་པ་དྲུག་པོ་འདི་དག་གིས་སྦྱར་བར་བྱ་སྟེ། དངོས་པོ་ཡོངས་སུ་ཤེས་པ་དང་། ཉེས་པར༌[^334]སྤྱད་པ་དང་། ཉོན་མོངས་པ་དང་། ཉེ་བའི་ཉོན་མོངས་པ་སྤང་བ༌[^335]དང་། ལེགས་པར་སྤྱད་པ་ཡང་དག་པར་བླང་བ་དང་། ནད་ལ་སོགས་པའི་རྣམ་པ་དག་གིས་ཤེས་པ་དང་། ཡོངས་སུ་ཤེས་པ་རབ་ཏུ་རྟོགས་པ༌[^336]དང་། དེའི་འབྲས་བུ་དང་། བདག་ཉིད་དང་། གཞན་དག་གིས་དེའི་འབྲས་བུ་རྟོགས་པ་སྟེ།
