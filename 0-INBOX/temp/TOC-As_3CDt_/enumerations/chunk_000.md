Enumeration Block 1:
མདོ་སྡེའི་ལུས་ནི་མདོར་བསྡུ་ན་རྣམ་པ་གཉིས་ཏེ། ཚིག་འབྲུ་དང་དོན་ཏོ། །

Enumeration Block 2:
རྣམ་པར་བཤད་པ་གང་ཞེ་ན། མདོར་བསྡུ་ན་རྣམ་པ་ལྔར་བལྟ་བར་བྱ་སྟེ། ཆོས་དང་། ཀུན་ནས་སློང་བ་དང་། དོན་དང་། རྒོལ་བའི་ལན་དང་། མཚམས་སྦྱར་བའོ། །

Enumeration Block 3:
དེ་ལ་ཚིག་འབྲུ་ནི་རྣམ་པ་དྲུག་སྟེ། མིང་གི་ཚོགས་རྣམས༌དང་། ཚིག་གི་ཚོགས་རྣམས༌དང་། ཡི་གེའི་ཚོགས་རྣམས༌དང་། ངག་དང་། རྣམ་པ་དང་། བསྟན་པའོ། །

Enumeration Block 4:
དེ་ཡང་རྣམ་པ་བཅུ་གཉིས་ཏེ། ཉེ་བར་བཏགས་པ་ལས་བྱུང་བ་དང་། ཡང་དག་པའི་དངོས་པོ་དང་། རིགས་པ༌དང་འབྲེལ་བ་དང་། སོ་སོ་དང་འབྲེལ་བ་དང་། ཡོན་ཏན་ལས་བྱུང་བ་དང་། ཐ་སྙད་ལས་བྱུང་བ་དང་། གྲགས་པ་དང་། མ་གྲགས་པ་དང་། གསལ་བ་དང་། མི་གསལ་བ་དང་། བསྡུས་པ་དང་། རྒྱས་པའོ། །

Enumeration Block 5:
དེ་ཡང་རྣམ་པ་དྲུག་སྟེ། ཡོངས་སུ་མ་རྫོགས་པའི་ཚིག་དང་། ཡོངས་སུ་རྫོགས་པའི་ཚིག་དང་། བསྒྲུབ༌པའི་ཚིག་དང་། སྒྲུབ་པའི༌ཚིག་དང་། བསྟན་པའི་ཚིག་དང་། བཤད་པའི་ཚིག་གོ། །

Enumeration Block 6:
མིང་གི་ཚོགས་ལ་སོགས་པ་དེ་དག་གི་རྟེན་ནི་མདོར་བསྡུ་ན་རྣམ་པ་དྲུག་སྟེ། འདི་ལྟ་སྟེ། ཆོས་དང་། དོན་དང་། གང་ཟག་དང་། དུས་དང་། གྲངས་དང་སྐབས་སོ། །

Enumeration Block 7:
དེ་ལ་ངག་ནི༌མདོར་བསྡུ་ན་གྲོང་ཁྱེར་བ་དང་སྙན་ཅིང་འཇེབས་པ་ལ་སོགས་པ་ཡན་ལག་བརྒྱད་དང་ལྡན་པ་ཡིན་པར་རིག་པར་བྱ་སྟེ།

Enumeration Block 8:
ངག་རྣམ་པ་བརྒྱད་པོ་དེ་དག་གི་ཡོན་ཏན་ཡང་མདོར་བསྡུ་ན་རྣམ་པ་གསུམ་དུ་རིག་པར་བྱ་སྟེ།
