* 1. སྤྱན་དྲངས་པའི་རྗེས་ལ། འཕགས་པ་གདན་འཛོམ་པ་ལ་སྤྱིར་ཕྱག་འཚལ་ཞིང་གསོལ་བ་གདབ་པ [[སྤྱན་དྲངས་པའི་རྗེས་ལ། འཕགས་པ་གདན་འཛོམ་པ་ལ་སྤྱིར་ཕྱག་འཚལ་ཞིང་གསོལ་བ་གདབ་པ། དེ་ནས་མཆོད་པའི་ཚོགས་ཀྱིས་]]
* 2. དེའི་འོག་ཏུ་འཕགས་པ་རྣམས་ལ་རེ་རེ་ཞིང་མཆོད་པ་འབུལ་ཞིང་སྨོན་ལམ་གདབ་པ [[དེའི་འོག་ཏུ་འཕགས་པ་རྣམས་ལ་རེ་རེ་ཞིང་མཆོད་པ་འབུལ་ཞིང་སྨོན་ལམ་གདབ་པར་བགྱིའོ། །]]
* 2.1 དེ་བཞིན་གཤེགས་པ་མཚན་ལེགས་པར་ཡོངས་བསྒྲགས་དཔལ་གྱི་རྒྱལ་པོའི་མཚན་ནས་བརྗོད་དེ་མཆོད་ནས་སྨོན་ལམ་དུ་གསོལ་བ [[དེ་བཞིན་གཤེགས་པ་མཚན་ལེགས་པར་ཡོངས་བསྒྲགས་དཔལ་གྱི་རྒྱལ་པོའི་མཚན་ནས་བརྗོད་དེ་མཆོད་ནས། སྨོན་ལམ་དུ་གསོལ་བ། བཅོམ་ལྡན་འདས་]]
* 2.2 དེ་བཞིན་གཤེགས་པ་རིན་པོ་ཆེ་དང་ཟླ་བ་དང་པདྨས་རབ་ཏུ་བརྒྱན་པ་མཁས་པ་གཟི་བརྗིད་སྒྲ་དབྱངས་ཀྱི་རྒྱལ་པོའི་མཚན་ནས་བརྗོད་དེ་མཆོད་ནས་སྨོན་ལམ་དུ་གསོལ་བ [[དེ་བཞིན་གཤེགས་པ་རིན་པོ་ཆེ་དང་ཟླ་བ་དང་པདྨས་རབ་ཏུ་བརྒྱན་པ། མཁས་པ་གཟི་བརྗིད་སྒྲ་དབྱངས་ཀྱི་རྒྱལ་པོའི་མཚན་ནས་བརྗོད་དེ་མཆོད་ནས། སྨོན་ལམ་དུ་གསོལ་བ།]]
* 2.3 དེ་བཞིན་གཤེགས་པ་གསེར་བཟང་དྲི་མེད་རིན་ཆེན་སྣང་བརྟུལ་ཞུགས་གྲུབ་པའི་མཚན་ནས་བརྗོད་དེ་མཆོད་ནས་སྨོན་ལམ་དུ་གསོལ་པ [[དེ་བཞིན་གཤེགས་པ་གསེར་བཟང་དྲི་མེད་རིན་ཆེན་སྣང་བརྟུལ་ཞུགས་གྲུབ་པའི་མཚན་ནས་བརྗོད་དེ། མཆོད་ནས་སྨོན་ལམ་དུ་གསོལ་པ།]]
* 2.4 དེ་བཞིན་གཤེགས་པ་མྱ་ངན་མེད་མཆོག་གི་མཚན་ནས་བརྗོད་དེ་མཆོད་ནས་སྨོན་ལམ་དུ་གསོལ་པ [[དེ་བཞིན་གཤེགས་པ་མྱ་ངན་མེད་མཆོག་གི་མཚན་ནས་བརྗོད་དེ། མཆོད་ནས་སྨོན་ལམ་དུ་གསོལ་པ། བཅོམ་ལྡན་འདས་]]
* 2.5 དེ་བཞིན་གཤེགས་པ་ཆོས་བསྒྲགས་རྒྱ་མཚོའི་དབྱངས་ཀྱི་མཚན་ནས་བརྗོད་དེ་མཆོད་ནས་སྨོན་ལམ་དུ་གསོལ་པ [[དེ་བཞིན་གཤེགས་པ་ཆོས་བསྒྲགས་རྒྱ་མཚོའི་དབྱངས་ཀྱི་མཚན་ནས་བརྗོད་དེ། མཆོད་ནས་སྨོན་ལམ་དུ་གསོལ་པ། བཅོམ་ལྡན་འདས་]]
* 2.6 དེ་བཞིན་གཤེགས་པ་ཆོས་རྒྱ་མཚོའི་མཆོག་གི་བློས་རྣམ་པར་རོལ་པས་མངོན་པར་མཁྱེན་པའི་མཚན་ནས་བརྗོད་དེ་མཆོད་ནས་སྨོན་ལམ་དུ་གསོལ་པ [[དེ་བཞིན་གཤེགས་པ་ཆོས་རྒྱ་མཚོའི་མཆོག་གི་བློས་རྣམ་པར་རོལ་པས་མངོན་པར་མཁྱེན་པའི་མཚན་ནས་བརྗོད་དེ། མཆོད་ནས་སྨོན་ལམ་དུ་གསོལ་པ།]]
* 2.7 དེ་བཞིན་གཤེགས་པ་སྨན་གྱི་བླ་བཻ་ཌཱུརྱ་འོད་ཀྱི་མཚན་ནས་བརྗོད་དེ་མཆོད་ནས་སྨོན་ལམ་དུ་གསོལ་བ [[དེ་བཞིན་གཤེགས་པ་སྨན་གྱི་བླ་བཻ་ཌཱུརྱ་འོད་ཀྱི་མཚན་ནས་བརྗོད་དེ། མཆོད་ནས་སྨོན་ལམ་དུ་གསོལ་བ། བཅོམ་ལྡན་འདས་]]
* 2.8 སྟོན་པ་བཅོམ་ལྡན་འདས་ཤཱཀྱ་ཐུབ་པའི་མཚན་ནས་བརྗོད་དེ་མཆོད་ནས་སྨོན་ལམ་དུ་གསོལ་བ [[སྟོན་པ་བཅོམ་ལྡན་འདས་ཤཱཀྱ་ཐུབ་པའི་མཚན་ནས་བརྗོད་དེ། མཆོད་ནས་སྨོན་ལམ་དུ་གསོལ་བ། སྟོན་པ་བཅོམ་ལྡན་འདས་]]
