## དཀར་ཆག / Table of Contents

* 1. དང་པོ་མངོན་སུམ་གྱི་ལེའུ་ [[ཡང་དག་པའི་ཤེས་པ་ནི། སྐྱེས་བུའི་དོན་ཐམས་ཅད་འགྲུབ་པའི་སྔོན་དུ་འགྲོ་བ་ཅན་ཡིན་པས་ན་དེ་བསྟན་ཏོ། །]]
   * 1.1 དབང་པོའི་ཤེས་པ་ [[དེ་ནི་རྣམ་པ་བཞི་སྟེ། དབང་པོའི་ཤེས་པ་དང་།]]
   * 1.2 ཡིད་ཀྱི་རྣམ་པར་ཤེས་པ་ [[དབང་པོའི་ཤེས་པ་མཚུངས་པ་དེ་མ་ཐག་པའི་རྐྱེན་གྱིས་བསྐྱེད་པའི་ཡིད་ཀྱི་རྣམ་པར་ཤེས་པ་དང་།]]
   * 1.3 སེམས་དང་སེམས་ལས་བྱུང་བ་ཐམས་ཅད་ཀྱི་རང་རིག་པ་ [[སེམས་དང་སེམས་ལས་བྱུང་བ་ཐམས་ཅད་ཀྱི་རང་རིག་པ་དང་།]]
   * 1.4 རྣལ་འབྱོར་པའི་ཤེས་པ་ [[ཡང་དག་པའི་དོན་བསྒོམ་པའི༌[^3]རབ་ཀྱི་མཐའ་ལས་བྱུང་བ༌[^4]རྣལ་འབྱོར་པའི་ཤེས་པའོ། །]]
* 2. གཉིས་པ་བདག་གི་དོན་རྗེས་སུ་དཔག་པའི་ལེའུ་ [[རྗེས་སུ་དཔག་པ་ནི་རྣམ་པ་གཉིས་ཏེ། རང་གི་དོན་དང་གཞན་གྱི་དོན་ནོ། །]]
   * 2.1 མི་དམིགས་པ་ [[དེ་ལ་མི་དམིགས་པ་ནི་དཔེར་ན་ཕྱོགས་ཀྱི་བྱེ་བྲག་འགའ་ཞིག་ན་བུམ་པ་མེད་དེ།]]
      * 2.1.1 རང་བཞིན་མི་དམིགས་པ་ [[དེ་ནི་སྦྱོར་བའི་བྱེ་བྲག་གིས་རྣམ་པ་བཅུ་གཅིག་སྟེ། རང་བཞིན་མི་དམིགས་པ་ནི་དཔེར་ན་འདི་ན་དུ་བ་མེད་དེ༌[^19]དམིགས་པའི་རིག་བྱར་གྱུར་པ་ལས་མི་དམིགས་པའི་ཕྱིར་རོ། །]]
      * 2.1.2 འབྲས་བུ་མི་དམིགས་པ་ [[འབྲས་བུ་མི་དམིགས་པ་ནི། དཔེར་ན་འདི་ན་དུ་བའི་རྒྱུ་ནུས་པ་ཐོགས་པ་མེད་པ་དག་མེད་དེ།]]
      * 2.1.3 ཁྱབ་པར་བྱེད་པ་མི་དམིགས་པ་ [[ཁྱབ་པར་བྱེད་པ་མི༌[^20]དམིགས་པ་ནི། དཔེར་ན་འདི་ན་ཤིང་མེད་པའི་ཕྱིར་ཤིང་ཤ་པ་མེད་དོ། །]]
      * 2.1.4 རང་བཞིན་འགལ་བ་དམིགས་པ་ [[རང་བཞིན་འགལ་བ་དམིགས་པ་ནི་དཔེར་ན་འདི་ན་མེ་ཡོད་པའི་ཕྱིར་གྲང་བའི་རེག་པ་མེད་དོ་ཞེས་པ་ལྟ་བུའོ། །]]
      * 2.1.5 འགལ་བའི་འབྲས་བུ་དམིགས་པ་ [[འགལ་བའི་འབྲས་བུ་དམིགས་པ་ནི་དཔེར་ན་འདི་ན་དུ་བ་ཡོད་པའི་ཕྱིར། གྲང་བའི་རེག་པ་མེད་དོ་ཞེས་བྱ་བ་ལྟ་བུའོ། །]]
      * 2.1.6 འགལ་བ་ཁྱབ་པ་དམིགས་པ་ [[འགལ་བ༌[^21]ཁྱབ་པ་དམིགས་པ་ནི་དཔེར་ན་དངོས་པོ་བྱུང་བ༌[^22]ཡང་འཇིག་པར་ངེས་པར་འགྱུར་བ༌[^23]མེད་དེ།]]
      * 2.1.7 འབྲས་བུ་འགལ་བ་དམིགས་པ་ [[འབྲས་བུ་འགལ་བ་དམིགས་པ་ནི་དཔེར་ན་འདི་ན་མེ་ཡོད་པའི་ཕྱིར་གྲང་བའི་རྒྱུའི༌[^24]ནུས་པ་ཐོགས་པ་མེད་པ་དག་མེད་དོ་ཞེས་བྱ་བ་ལྟ་བུའོ། །]]
      * 2.1.8 ཁྱབ་པར་བྱེད་པ་འགལ་བ་དམིགས་པ་ [[ཁྱབ་པར་བྱེད་པ་འགལ་བ་དམིགས་པ་ནི་དཔེར་ན་འདི་ན་མེ་ཡོད་པའི་ཕྱིར་བ་མོའི་རེག་པ་མེད་དོ་ཞེས་བྱ་བ་ལྟ་བུའོ། །]]
      * 2.1.9 རྒྱུ་མི་དམིགས་པ་ [[རྒྱུ་མི་དམིགས་པ་ནི་དཔེར་ན་འདི་ན་མེ་མེད་པའི་ཕྱིར་དུ་བ་མེད་དོ་ཞེས་བྱ་བ་ལྟ་བུའོ། །]]
      * 2.1.10 རྒྱུ་འགལ་བ་དམིགས་པ་ [[རྒྱུ་འགལ་བ་དམིགས་པ་ནི་དཔེར་ན་འདི་ན་སྤུ་ལོང་ཞེས་བྱ་བ་ལ་སོགས་པའི་བྱེ་བྲག༌[^25]མེད་དེ།]]
      * 2.1.11 རྒྱུ་འགལ་བའི་འབྲས་བུ་དམིགས་པ་ [[རྒྱུ་འགལ་བའི་འབྲས་བུ་དམིགས་པ་ནི་དཔེར་ན་ཕྱོགས་འདི་ན་དུ་བ་ཡོད་པའི་ཕྱིར། སྤུ་ལོང་ཞེས་བྱེད་པ་ལ་སོགས་པའི་བྱེ་བྲག་དང་ལྡན་པའི་མི་དང་ལྡན་པ་མ་ཡིན་ནོ་ཞེས་བྱ་བ་ལྟ་བུའོ། །]]
   * 2.2 རང་བཞིན་ [[རང་བཞིན་ནི་རང་ཡོད་པ་ཙམ་དུ་གྱུར་པ། བསྒྲུབ་པར་བྱ་བའི་ཆོས་ཀྱི༌[^8]གཏན་ཚིགས་ཏེ།]]
   * 2.3 འབྲས་བུ་ [[འབྲས་བུ་ནི་དཔེར་ན་དུ་བ་ཡོད་པའི་ཕྱིར། དེ་ན་མེ་ཡོད་དོ་ཞེས་བྱ་བ༌[^9]ལྟ་བུའོ། །]]
* 3. གསུམ་པ་གཞན་གྱི་དོན་གྱི་རྗེས་སུ་དཔག་པའི་ལེའུ་ [[གཞན་གྱི་དོན་གྱི་རྗེས་སུ་དཔག་པ་ནི་ཚུལ་གསུམ་པའི་རྟགས་བརྗོད་པ་སྟེ། རྒྱུ་ལ་འབྲས་བུ་བཏགས་པའི་ཕྱིར་རོ། །]]
   * 3.1 ཆོས་མཐུན་པ་ཉིད་ཅན་ [[དེ་ལ་ཆོས་མཐུན་པ་ཉིད་ཅན་ནི་དམིགས་པའི་རིག་བྱར་གྱུར་པ༌[^34]གང་མ་དམིགས་པ་དེ་ནི་མེད་པའི་ཐ་སྙད་ཀྱི་ཡུལ་དུ་གྲུབ་སྟེ།]]
   * 3.2 ཆོས་མི་མཐུན་པ་ཉིད་ཅན་ [[ཆོས་མི་མཐུན་པ་ཉིད་ཅན་གྱི་སྦྱོར་བ་ནི་གང་ཡོད་ལ་དམིགས་པའི་རིག་བྱར་གྱུར་པ་དེ་ནི་དམིགས་པ༌[^48]ཁོ་ནར་འགྱུར་ཏེ།]]
