Enumeration Block 1:
ཡང་དག་པའི་ཤེས་པ་ནི་རྣམ་པ་གཉིས་ཏེ། མངོན་སུམ་དང་རྗེས་སུ་དཔག་པའོ། །

Enumeration Block 2:
དེ་ནི་རྣམ་པ་བཞི་སྟེ། དབང་པོའི་ཤེས་པ་དང་། རང་གི་ཡུལ་གྱི་དེ་མ་ཐག་པ་ཡུལ་ལྷན་ཅིག་བྱེད་པ་ཅན། དབང་པོའི་ཤེས་པ་མཚུངས་པ་དེ་མ་ཐག་པའི་རྐྱེན་གྱིས་བསྐྱེད་པའི་ཡིད་ཀྱི་རྣམ་པར་ཤེས་པ་དང་། སེམས་དང་སེམས་ལས་བྱུང་བ་ཐམས་ཅད་ཀྱི་རང་རིག་པ་དང་། ཡང་དག་པའི་དོན་བསྒོམ་པའི༌[^3]རབ་ཀྱི་མཐའ་ལས་བྱུང་བ༌[^4]རྣལ་འབྱོར་པའི་ཤེས་པའོ། །

Enumeration Block 3:
རྗེས་སུ་དཔག་པ་ནི་རྣམ་པ་གཉིས་ཏེ། རང་གི་དོན་དང་གཞན་གྱི་དོན་ནོ། །

Enumeration Block 4:
ཚུལ་གསུམ་པོ་དག་ནི་རྟགས་གསུམ༌[^7]ཁོ་ན་དང་ལྡན་པ་སྟེ། མི་དམིགས་པ་དང་། རང་བཞིན་དང་། འབྲས་བུའོ། །

Enumeration Block 5:
དེ་ནི་སྦྱོར་བའི་བྱེ་བྲག་གིས་རྣམ་པ་བཅུ་གཅིག་སྟེ།

Enumeration Block 6:
སྦྱོར་བའི་བྱེ་བྲག་གིས་དེ་ནི་རྣམ་པ་གཉིས་ཏེ། ཆོས་མཐུན་པ་ཉིད་ཅན་དང་། ཆོས་མི་མཐུན་པ་ཉིད་ཅན་ནོ། །
