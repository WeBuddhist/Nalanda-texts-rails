Enumeration Block 1:
ཡང་གནས་མའི་བུ་ཡང་རྣམ་པ་གཉིས་ཏེ། རི་ཆེན་པོ་དང་། མང་པོས་བཀུར་བ་པའོ། །

Enumeration Block 2:
ཡང་རི་ཆེན་པོ་པ་ཡང་རྣམ་པ་གཉིས་ཏེ། ཆོས་མཆོག་པ་དང་། ལམ་བཟངས་བ་ཞེས་བྱ་བའོ། །

Enumeration Block 3:
ཐམས་ཅད་ཡོད་པར་སྨྲ་བ་རྣམས་ཀྱི་འདོད་གཞུང་གི་བྱེ་བྲག་ཀྱང་དབྱེ་བ་རྣམ་པ་བཞི་སྟེ་དངོས་པོ་དང་། མཚན་ཉིད་དང་། གནས་སྐབས་དང་། གཞན་གཞན་དུ་འགྱུར་བ་ཉིད་ཀྱི་བྱེ་བྲག་གིས་སོ། །

Enumeration Block 4:
དེ་བཞིན་དུ་ཁ་ཅིག་རྐྱེན་བདུན་ཏེ། རྒྱུ་དང་། དམིགས་པ་དང་། དེ་མ་ཐག་པ་དང་། བདག་པོ་དང་། ལས་དང་། ཟས་དང་། རྟེན་ཞེས་བྱའོ། །

Enumeration Block 5:
དེ་བཞིན་དུ་ལ་ལ་ནི་རྟོགས་པའི་སེམས་བཞི་སྟེ། བདེན་པ་སོ་སོ་པའོ།[^105] །
