## དཀར་ཆག / Table of Contents
* I. ཀླད་ཀྱི་དོན། [[༄༅༅། །རྒྱ་གར་སྐད་དུ། ཨཱརྱ་སཱ་ལི་སྟམྦ་སྱ་ཊཱི་ཀཱ། བོད་སྐད་དུ། འཕགས་པ་སཱ་ལུ་ལྗང་པ་ར]]

* 1. མདོ་སྡེ་འདིའི་བསྡུས་པའི་དོན [[དེ་ལ་མདོ་སྡེ་འདིའི་བསྡུས་པའི་དོན་ནི། རྣམ་པ་བདུན་ཏེ། གླེང་གཞི་དང་།]]
   * 1.1 གླེང་གཞི [[དེ་ལ་གླེང་གཞི་ནི་མདོ་སྡེ་འབྱུང་བའི་རྒྱུ་སྟེ། དེ་ཡང་ཡང་དག་པར་སྡུད་པར་བྱེད་པས།]]
   * 1.2 གླེང་བསླང་བ [[གླེང་བསླང་བ་ནི་མདོ་སྡེ་བཤད་པའི་ཕྱིར་སྐབས་དང་སྦྱར་བ་སྟེ། སྐབས་སུ་མ་བབ་པར་སྨྲས་ན།]]
   * 1.3 ཡོངས་སུ་ཤེས་པར་བྱ་བའི་དངོས་པོ [[ཡོངས་སུ་ཤེས་པར་བྱ་བའི་དངོས་པོ་གང་ཞེ་ན། རྟེན་ཅིང་འབྲེལ་བར་འབྱུང་བ་ལུགས་སུ་]]
   * 1.4 ཡོངས་སུ་ཤེས་པ [[ལམ་འདི་ཉིད་ཀྱིས་དེ་ཁོ་ན་ཡོངས་སུ་ཤེས་པས་ལམ་གྱི་རང་བཞིན་གྱི་ཆོས་ནི་ཡོངས་སུ]]
   * 1.5 ཡོངས་སུ་ཤེས་པའི་འབྲས་བུ [[ཡོངས་སུ༌[^1]ཤེས་པའི་འབྲས་བུ་ནི་རྣམ་པ་གཉིས་ཏེ། བླ་ན་ཡོད་པ༌[^2]དང་། བླ་ན་མེད་པའོ། །]]
      * 1.5.1 བླ་ན་ཡོད་པ [[དེ་ལ་བླ་ན་ཡོད་པ་ནི་ཉན་ཐོས་རྣམས་ཀྱི་དགེ་སྦྱོང་གི༌[^3]འབྲས་བུ་བཞི་དང་།]]
      * 1.5.2 བླ་ན་མེད་པ [[བླ་ན་མེད་པ་ནི་སངས་རྒྱས་ཉིད་དེ། དེ་གཉིས་ཀྱིས་ནི་བླང་བར་བྱ་བའི་ཡན་ལག་]]
   * 1.6 དེ་ཇི་ལྟར་ཡོངས་སུ་ཤེས་པར་བྱ་བ [[ཇི་ལྟར་དེ་ཡོངས་སུ་ཤེས་པར་བྱ་ཞེ་ན། དོན་དམ་པ་དང་ཀུན་རྫོབ་ཏུ་སྟེ།]]
   * 1.7 མདོ་སྡེའི་དགོས་པ [[དགོས་པ་ནི་སྒྲིབ་པ་སྤང་བ་དང་། མི་གནས་པའི་མྱ་ངན་ལས་འདས་པའི་ལམ་དུ]]
* 2. མཚན་ཉིད་རྣམ་པ་ལྔ་ [[དེ་ལྟ་མོད་ཀྱི་ཀུན་རྫོབ་ཏུ་ཇི་ལྟར་མུ་སྟེགས་ཅན་རྣམས་ཀྱིས་འདི་རྒྱུ་མེད་པ་དང་།]]
   * 2.1 རྒྱུ་དང་བཅས་པ་ལས་བྱུང་བའི་མཚན་ཉིད [[དེ་ལ་རྒྱུ་དང་བཅས་རྐྱེན་དང་བཅས་ཞེས་བྱ་བ་འདིས༌[^107]ནི། མཚན་ཉིད་དང་པོ་བསྟན་ཏེ།]]
   * 2.2 མི་རྟག་པ་དུ་མའི་རྒྱུ་ལས་བྱུང་བའི་མཚན་ཉིད [[གཉིས་ཀྱི་ཕྱིར་ཞེས་བྱ་བ་ལ་སོགས་པས་ནི་མཚན་ཉིད་གཉིས་པ་སྟོན་ཏོ། །]]
   * 2.3 བདག་མེད་པར་འབྱུང་བའི་མཚན་ཉིད [[མཚན་ཉིད་གསུམ་པ་བསྟན་པའི་ཕྱིར། དེ་ཡང་ཕྱིའི་དང་ནང་གི་རྣམ་པ་གཉིས་སུ་བལྟའོ་ཞེས་བྱ་བ]]
   * 2.4 ནུས་པའི་རྐྱེན་ལས་བྱུང་བའི་མཚན་ཉིད [[འདི་ལྟ་སྟེ། ས་བོན་ལས་མྱུ་གུ་ཞེས་བྱ་བ་ལ་སོགས་པས་ནི་ཕྱི་རོལ་གྱི་རྟེན་ཅིང་འབྲེལ]]
   * 2.5 བྱེད་པ་མེད་པའི་རྐྱེན་ལས་བྱུང་བའི་མཚན་ཉིད [[དེ་ལ་ས་བོན་ནི་འདི་སྙམ་དུ་བདག་གིས་མྱུ་གུ་མངོན་པར་བསྒྲུབ་པོ༌[^118]སྙམ་དུ་མི་སེམས་སོ]]
* 3. མཚན་ཉིད་ [[འདིར་ཡང་མཚན་ཉིད་རྣམ་པ་ལྔར་གསུངས་ཏེ། རང་གི་མཚན་ཉིད་དང་། ངེས་པའི་ཚིག་གི་མཚན་ཉིད]]
   * 3.1 རང་གི་མཚན་ཉིད [[གང་ཁམས་དྲུག་པོ་ཐ་དད་པ་ལ་ཐ་དད་པ་མ་ཡིན་པར་འདུ་ཤེས་པ་དེ་ནི་གཅིག་པུར་འདུ་ཤེས་པའོ]]
   * 3.2 ངེས་པའི་ཚིག་གི་མཚན་ཉིད [[དེ་ལ་མུན་པ་ཆེན་པོའི་ཕྱིར་མ་རིག་པའོ་ཞེས་བྱ་བ་ལ་སོགས་པས་ནི་ངེས་པའི་ཚིག]]
   * 3.3 ཡན་ལག་གི་མཚམས་སྦྱོར་བའི་མཚན་ཉིད [[ད་ནི་བདག་མེད་པ་གཉི་ག་ལོག་པར་ཁོང་དུ་ཆུད་པ་ལ་ཡན་ལག་གི་མཚམས་སྦྱོར་བའི]]
   * 3.4 མཐའ་གཉིས་དང་བྲལ་བའི་མཚན་ཉིད [[དེ་ལྟར་ཞེས་བྱ་བ་ནི་མཇུག་སྡུད་པ་སྟེ། མཐའ་གཉིས་དང་བྲལ་བའི་མཚན་ཉིད་སྟོན་ཏོ། །]]
   * 3.5 རྒྱུ་བསྡུ་བའི་མཚན་ཉིད [[གལ་ཏེ་རྒྱུན་མི་འཆད་པར་འཇུག་པ་ཡིན་ན། དེའི་ཚེ་རྒྱུ་གང་སྤངས་པས་མྱ་ངན་ལས་འདས་]]
* b. མཇུག་བྱང། [[འཕགས་པ་སཱ་ལུ་ལྗང་པའི་མདོ་སྡེ༌[^211]རྒྱ་ཆེར་འགྲེལ་པ་སློབ་དཔོན་ཀ༌[^212]མ་ལ་ཤཱི་ལས་]]
