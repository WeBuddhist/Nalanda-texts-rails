Enumeration Block 1:
ཡང་རྣམ་པ་གསུམ་དུ་གནས་ཏེ་སེམས་ཅན་མ་ཡིན་པར་བརྗོད་པ་འབྱུང་བ་དང་འབྱུང་བ་ལས་གྱུར་པ༌[^392]འདུས་ནས་གནས་པ་དང་། སེམས་ཅན་དུ་བརྗོད་པ་འདུས་ནས་གནས་པ་དང་། འབྱུང་བ་དང་འབྱུང་བ་ལས་གྱུར་པའི་ངོ་བོ་ཐ་དད་དུ་གནས་པ་ཞེས་བྱ་བ་འདི་དག་གོ། །

Enumeration Block 2:
ངག་གི་སྤྲུལ་པའི་བསྡུས་པའི་དོན་ནི། མཚན་ཉིད་གང་ཡིན་པ་དང་། རྟེན་གང་ཡིན་པ་དང་། གང་གི་དོན་དུ་ཡིན་པའོ། །

Enumeration Block 3:
སྔོན་གྱི་གནས་རྗེས་སུ་དྲན་པའི་བསྡུས་པའི་དོན་ནི། གང་གིས་དྲན་པ་དང་གང་དྲན་པ་དང་། རྣམ་པ་གང་གིས་དྲན་པའོ། །

Enumeration Block 4:
དེ་དག་རྣམས་ཀྱི་བསྡུས་པའི་དོན་ནི། གང་བཞེད་པ་དང་། ཇི་ལྟར་བཞེད་པ་དང་། ཇི་ཙམ་བཞེད་པ་ཞེས་བྱ་བ་སྟེ།

Enumeration Block 5:
ལྷའི་རྣ་བའི་མཁྱེན་པའི་བསྡུས་པའི་དོན་ནི། གང་གི་སྒྲ་དང་། ཆོས་གང་གི་རྣམ་པ་དང་། གང་གི་དོན་དུ་ཞེས་བྱ་བ་སྟེ།

Enumeration Block 6:
ལྷའི་མིག་གི༌[^432]བསྡུས་པའི་དོན་ནི། འཆི་འཕོ་བ་དང་། སྐྱེ་བ་དང་། སྐྱེས་པ་དང་། ལུས་ཀྱི་ལས་སྣ་ཚོགས་ལ་གནས་པར་མངོན་པ་དང་། གཟུགས་ཕྲ་བ་དང་། ཐམས་ཅད་དུ་ཞེས་བྱ་བའོ། །

Enumeration Block 7:
སྦྱིན་པ་ལ་སོགས་པའི་ཆོས་འདི་རྣམས་ཀྱི་མཐུའི་དོན་གྱི༌[^446]བསྡུས་པའི་དོན་ནི་རྣམ་པ་བཞི་སྟེ། འབྲས་བུ་ལས་བསྟན་པར་འགྱུར་རོ། །ཇི་ལྟར་གང་ཞེ་ན། མི་མཐུན་པའི་ཕྱོགས་སྤངས་པ༌[^447]བྲལ་བའི་འབྲས་བུ་དང་། ཚོགས་ཡོངས་སུ་སྨིན་པའི་སྐྱེས་བུའི་བྱེད་པའི་འབྲས་བུ་དང་། བདག་དང་གཞན་རྗེས་སུ་འཛིན་པའི་བདག་པོའི་འབྲས་བུ་དང་། འདི་ལྟར་མ་འོངས་པ་ནི༌[^448]འབྲས་བུ་སྦྱིན་པའི་འབྲས་བུ་རྣམ་པ་གཉིས་པོ་རྣམ་པར་སྨིན་པའི་འབྲས་བུ་དང་། རྒྱུ་མཐུན་པའི་འབྲས་བུའོ། །
