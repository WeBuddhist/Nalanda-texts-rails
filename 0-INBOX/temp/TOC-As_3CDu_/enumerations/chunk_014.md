Enumeration Block 1:
རྣམ་པ་བཞིས་བལྟ་སྟེ།

Enumeration Block 2:
རྣམ་པ་ལྔས་སྒོམ་སྟེ། ལྔ་གང་ཞེ་ན། འདི་ལྟ་སྟེ། འདྲེས་པར་སྒོམ་པ་དང་། མཚན་མ་མེད་པར་སྒོམ་པ་དང་། ལྷུན་གྱིས་གྲུབ་པར་སྒོམ་པ་དང་། འབར་བར་སྒོམ་པ་དང་། ཆོག་པར་མི་འཛིན་པར་སྒོམ་པས་སོ། །

Enumeration Block 3:
གཙོར་ན་ས་བཅུ་དག་ཏུ་ཕ་རོལ་ཏུ་ཕྱིན་པ་བཅུ་སྒོམ་པར་འགྱུར་ཏེ། དྲུག་ཏུ་ནི་དྲུག་ཇི་སྐད་དུ༌[^530]བསྟན་པ་རྣམས་སོ། །ཕྱི་མ་བཞིར་ནི་བཞི་སྟེ།

Enumeration Block 4:
གང་ཟག་ལྔ་ནི་བསྐལ་པ་གྲངས་མེད་པ་གསུམ་གྱིས་རྫོགས་པར་འགྱུར་ཏེ།

Enumeration Block 5:
མདོར་བསྡུ་ན་ཁྱད་པར་བཞིས་ཁྱད་པར་དུ་བལྟ་སྟེ། རབ་ཏུ་དབྱེ་བའི་ཁྱད་པར་དང་། བསླབ་པ་ཐུན་མོང་དང་། ཐུན་མོང་མ་ཡིན་པའི་ཁྱད་པར་དང་། རྒྱ་ཆེ་བ་ཉིད་ཀྱི༌[^540]ཁྱད་པར་དང་། ཟབ་པ་ཉིད་ཀྱི་ཁྱད་པར་གྱིས་ཁྱད་པར་དུ་བལྟའོ། །

Enumeration Block 6:
མདོར་བསྡུ་ན་རབ་ཏུ་དབྱེ་བ་དྲུག་གིས་བལྟ་བར༌[^552]བྱ་སྟེ། དམིགས་པས་རབ་ཏུ་དབྱེ་བ་དང་། སྣ་ཚོགས་ཉིད་ཀྱིས་རབ་ཏུ་དབྱེ་བ་དང་། གཉེན་པོས་རབ་ཏུ་དབྱེ་བ་དང་། ལས༌[^553]སུ་རུང་བ་ཉིད་ཀྱིས་རབ་ཏུ་དབྱེ་བ་དང་། མངོན་པར་སྒྲུབ་པས་རབ་ཏུ་དབྱེ་བ་དང་། ལས་ཀྱིས༌[^554]རབ་ཏུ་དབྱེ་བ་སྟེ།

Enumeration Block 7:
དཀའ་བ་སྤྱོད་པ་རྣམ་པ་བཅུ་ནི་འདི་ལྟ་སྟེ།
