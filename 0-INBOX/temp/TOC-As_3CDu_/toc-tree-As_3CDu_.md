## དཀར་ཆག / Table of Contents

* 1. གནས་ཀྱི་ཁྱད་པར་
   * 1.1 ཀུན་གཞི་རྣམ་པར་ཤེས་པའི་རྣམ་གྲངས་རྣམ་པར་གཞག་པ་
      * 1.1.1 རྣམ་པར་ཤེས་པ་འགགས་མ་ཐག་པའི་ཡིད་
      * 1.1.2 གཉིས་པ་ཉོན་མོངས་པ་ཅན་གྱི་ཡིད་
   * 1.2 མཚན་ཉིད་རྣམ་པར་གཞག་པ་
      * 1.2.1 དང་པོ་ཀུན་གཞི་རྣམ་པར་ཤེས་པའི་རང་གི་མཚན་ཉིད་
      * 1.2.2 གཉིས་པ་རྒྱུ་ཉིད་ཀྱི་མཚན་ཉིད་
      * 1.2.3 གསུམ་པ་འབྲས་བུ་ཉིད་དུ་རྣམ་པར་གཞག་པ་ཉིད་
   * 1.3 རྟེན་ཅིང་འབྲེལ་པར་འབྱུང་བ་
      * 1.3.1 དང་པོ་ངོ་བོ་ཉིད་རྣམ་པར་འབྱེད་པ་ཅན་
      * 1.3.2 གཉིས་པ་སྡུག་པ་དང་མི་སྡུག་པ་རྣམ་པར་འབྱེད་པ་ཅན་
   * 1.4 ཀུན་ནས་ཉོན་མོངས་པ་དང་རྣམ་པར་བྱང་བ་
      * 1.4.1 དང་པོ་ཉོན་མོངས་པའི་ཀུན་ནས་ཉོན་མོངས་པ་
      * 1.4.2 གཉིས་པ་ལས་ཀྱི་ཀུན་ནས་ཉོན་མོངས་པ་
      * 1.4.3 གསུམ་པ་སྐྱེ་བའི་ཀུན་ནས་ཉོན་མོངས་པ་
      * 1.4.4 བཞི་པ་འཇིག་རྟེན་པའི་རྣམ་པར་བྱང་བ་
      * 1.4.5 ལྔ་པ་འཇིག་རྟེན་ལས་འདས་པའི་རྣམ་པར་བྱང་བ་
   * 1.5 ཀུན་གཞི་རྣམ་པར་ཤེས་པ་འདིའི་རབ་ཏུ་དབྱེ་བ་
      * 1.5.1 དང་པོ་བག་ཆགས་རྣམ་པ་གསུམ་གྱི་བྱེ་བྲག་གིས་རྣམ་པ་གསུམ་
      * 1.5.2 གཉིས་པ་རྣམ་པ་བཞི་
         * 1.5.2.1 དང་པོ་འཕེན་པས་རབ་ཏུ་དབྱེ་བ་
         * 1.5.2.2 གཉིས་པ་རྣམ་པར་སྨིན་པས་རབ་ཏུ་དབྱེ་བ་
         * 1.5.2.3 གསུམ་པ་རྒྱུ་ཉིད་དུ་རབ་ཏུ་དབྱེ་བ་
         * 1.5.2.4 བཞི་པ་མཚན་ཉིད་ཀྱིས་རབ་ཏུ་དབྱེ་བ་
* 2. མཚན་ཉིད་ཀྱི་ཁྱད་པར་
   * 2.1 དང་པོ་གཞན་གྱི་དབང་གི་མཚན་ཉིད་
   * 2.2 གཉིས་པ་ཀུན་བརྟགས་པའི་མཚན་ཉིད་
   * 2.3 གསུམ་པ་ཡོངས་སུ་གྲུབ་པའི་མཚན་ཉིད་
* 3. ཤེས་བྱའི་མཚན་ཉིད་དེ་ལ་འཇུག་པའི་ཁྱད་པར་
   * 3.1 ཐེག་པ་ཆེན་པོའི་ཆོས་འཆད་པར་འདོད་པས་མདོར་བསྡུ་ན་རྣམ་པ་གསུམ་
      * 3.1.1 དང་པོ་རྟེན་ཅིང་འབྲེལ་པར་འབྱུང་བ་བསྟན་པ་
      * 3.1.2 གཉིས་པ་རྟེན་ཅིང་འབྲེལ་པར་འབྱུང་བའི་ཆོས་རྣམས་ཀྱི་མཚན་ཉིད་བསྟན་པ་
      * 3.1.3 གསུམ་པ་བཤད་ཟིན་པ་དོན་བཤད་པ་
         * 3.1.3.1 དང་པོ་ཡོན་ཏན་གྱི་དབང་དུ་བྱ་བ་
         * 3.1.3.2 གཉིས་པ་དོན་གྱི་དབང་དུ་བྱ་བ་
            * 3.1.3.2.1 དང་པོ་སེམས་སྦྱོང་བ་དང་པོ་
            * 3.1.3.2.2 གཉིས་པ་སྦྱོང་བ་གཉིས་པ་
            * 3.1.3.2.3 གསུམ་པ་སྦྱོང་བ་གསུམ་པ་
   * 3.2 བྱང་ཆུབ་སེམས་དཔའི་མངོན་པར་རྟོགས་པའི་ཁྱད་པར་བཅུ་
* 4. དེ་ལ་འཇུག་པ་དེའི་རྒྱུ་དང་འབྲས་བུའི་ཁྱད་པར་
   * 4.1 དང་པོ་གྲངས་
   * 4.2 གཉིས་པ་མཚན་ཉིད་
   * 4.3 གསུམ་པ་གོ་རིམས་
   * 4.4 བཞི་པ་ངེས་པའི་ཚིག་
   * 4.5 ལྔ་པ་སྒོམ་པ་
   * 4.6 དྲུག་པ་རབ་ཏུ་དབྱེ་བ་
   * 4.7 བདུན་པ་བསྡུས་པ་
   * 4.8 བརྒྱད་པ་མི་མཐུན་པའི་ཕྱོགས་
   * 4.9 དགུ་པ་ཕན་ཡོན་
* 5. དེའི་རྒྱུ་དང་འབྲས་བུ་བསྒོམ་པ་རབ་ཏུ་དབྱེ་བའི་ཁྱད་པར་
   * 5.1 དང་པོ་ས་བཅུ་
   * 5.2 གཉིས་པ་ས་འདི་དག་ཐོབ་པ་
   * 5.3 གསུམ་པ་ས་འདི་དག་གི་སྒོམ་པ་
* 6. བསྒོམ་པ་རབ་ཏུ་དབྱེ་བ་དེ་ཉིད་ལ་ལྷག་པའི་ཚུལ་ཁྲིམས་ཀྱི་ཁྱད་པར་
   * 6.1 དང་པོ་རབ་ཏུ་དབྱེ་བའི་ཁྱད་པར་
   * 6.2 གཉིས་པ་བསླབ་པ་ཐུན་མོང་དང་ཐུན་མོང་མ་ཡིན་པའི་ཁྱད་པར་
   * 6.3 གསུམ་པ་རྒྱ་ཆེ་བ་ཉིད་ཀྱི་ཁྱད་པར་
   * 6.4 བཞི་པ་ཟབ་པ་ཉིད་ཀྱི་ཁྱད་པར་
* 7. ལྷག་པའི་སེམས་ཀྱི་ཁྱད་པར་
   * 7.1 དང་པོ་དམིགས་པས་རབ་ཏུ་དབྱེ་བ་
   * 7.2 གཉིས་པ་སྣ་ཚོགས་ཉིད་ཀྱིས་རབ་ཏུ་དབྱེ་བ་
   * 7.3 གསུམ་པ་གཉེན་པོས་རབ་ཏུ་དབྱེ་བ་
   * 7.4 བཞི་པ་ལས་སུ་རུང་བ་ཉིད་ཀྱིས་རབ་ཏུ་དབྱེ་བ་
   * 7.5 ལྔ་པ་མངོན་པར་སྒྲུབ་པས་རབ་ཏུ་དབྱེ་བ་
   * 7.6 དྲུག་པ་ལས་ཀྱིས་རབ་ཏུ་དབྱེ་བ་
* 8. ལྷག་པའི་ཤེས་རབ་ཀྱི་ཁྱད་པར་
   * 8.1 དང་པོ་རྣམ་པར་མི་རྟོག་པའི་ཡེ་ཤེས་ཀྱི་ངོ་བོ་ཉིད་
   * 8.2 གཉིས་པ་རྣམ་པར་རྟོག་པ་མེད་པའི་གནས་
   * 8.3 གསུམ་པ་རྣམ་པར་རྟོག་པ་མེད་པའི་གཞི་
   * 8.4 བཞི་པ་རྣམ་རྟོག་མེད་པའི་དམིགས་པ་
   * 8.5 ལྔ་པ་རྣམ་པར་མི་རྟོག་རྣམ་པ་
   * 8.6 དྲུག་པ་རྣམ་པར་རྟོག་པ་མེད་པའི་གྲོགས་
   * 8.7 བདུན་པ་རྣམ་རྟོག་མེད་པའི་རྣམ་སྨིན་
   * 8.8 བརྒྱད་པ་རྣམ་རྟོག་མེད་པའི་རྒྱུ་མཐུན་
   * 8.9 དགུ་པ་རྣམ་རྟོག་མེད་པའི་འབྱུང་བ་
   * 8.10 བཅུ་པ་རྣམ་རྟོག་མེད་པའི་མཐར་ཐུག་པ་
   * 8.11 བཅུ་གཅིག་པ་རྣམ་པར་མི་རྟོག་པ་ལ་སྦྱོར་བ་ལས་བྱུང་བའི་ཡེ་ཤེས་
   * 8.12 བཅུ་གཉིས་པ་རྣམ་པར་མི་རྟོག་པའི་ཡེ་ཤེས་
   * 8.13 བཅུ་གསུམ་པ་དེའི་རྗེས་ལས་ཐོབ་པ་
   * 8.14 བཅུ་བཞི་པ་གནས་རྣམ་པ་ལྔ་ཡོངས་སུ་སྤོང་བ་
   * 8.15 བཅོ་ལྔ་པ་ཉན་ཐོས་དང་བྱང་ཆུབ་སེམས་དཔའི་ཡེ་ཤེས་ལ་ཁྱད་པར་རྣམ་པ་ལྔ་
* 9. དེའི་འབྲས་བུ་སྤངས་པའི་ཁྱད་པར་
