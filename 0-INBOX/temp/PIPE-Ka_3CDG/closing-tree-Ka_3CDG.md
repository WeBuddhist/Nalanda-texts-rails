## དཀར་ཆག / Table of Contents
* I. ཀླད་ཀྱི་དོན། [[༄༅༅། །རྒྱ་གར་སྐད་དུ། ཨཱརྱ་སཔྟ་ཤ་ཏི་ཀཱ་པྲཛྙཱ་པཱ་ར་མི་ཏ་ཊཱི་ཀཱ། བོད་སྐད་དུ། འཕགས་པ་ཤེས་རབ་ཀྱ]]
* 1. བམ་པོ་དང་པོ [[དེ་བཞིན་གཤེགས་པའི་རང་གི་ངོ་བོ་དང་། ལམ་ལ་ལོག་པར་ཞུགས་པ་རྣམས་ཀྱི་ཆེད་དུ་འདི་བརྩམས་ཏེ། དེའི་ར]]
* 2. བམ་པོ་གཉིས་པ [[འཕགས་པ་ཤེས་རབ་ཀྱི་ཕ་རོལ་ཏུ་ཕྱིན་པ་བདུན་བརྒྱ་པ་རྒྱ་ཆེར་བཤད་པ། [^135]བམ་པོ་གཉིས་པ། འགའ་ཞིག་ཡ]]
* 3. བམ་པོ་གསུམ་པ [[འཕགས་པ་ཤེས་རབ་ཀྱི་ཕ་རོལ་ཏུ་ཕྱིན་པ་བདུན་བརྒྱ་པ་རྒྱ་ཆེར་བཤད་པ། [^236]བམ་པོ་གསུམ་པ། ཁ་ཅིག་ཆོས]]
* 4. བམ་པོ་བཞི་པ [[འཕགས་པ་ཤེས་རབ་ཀྱི་ཕ་རོལ་ཏུ་ཕྱིན་པ་བདུན་བརྒྱ་པ་རྒྱ་ཆེར་བཤད་པ།[^375] བམ་པོ་བཞི་པ། ཁ་ཅིག་གི་བ]]
* 5. བམ་པོ་ལྔ་པ [[འཕགས་པ་ཤེས་རབ་ཀྱི་ཕ་རོལ་ཏུ་ཕྱིན་པ་བདུན་བརྒྱ་པ་རྒྱ་ཆེར་བཤད་པ༌[^516]བམ་པོ་ལྔ་པ། ཇི་སྐད་དུ་མི]]
* 6. བམ་པོ་དྲུག་པ [[འཕགས་པ་ཤེས་རབ་ཀྱི་ཕ་རོལ་ཏུ་ཕྱིན་པ་བདུན་བརྒྱ་པ་རྒྱ་ཆེར་བཤད་པ༌[^685]བམ་པོ་དྲུག་པའོ།[^686] །བ]]
* b. མཇུག་བྱང། [[འཕགས་པ་ཤེས་རབ་ཀྱི་ཕ་རོལ་ཏུ་ཕྱིན་པ་བདུན་བརྒྱ་པ་རྒྱ་ཆེར་བཤད༌[^870]པ། སློབ་དཔོན་ཀ་མ་ལ་ཤཱི་ལས་]]
