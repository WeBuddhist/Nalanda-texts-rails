## དཀར་ཆག / Table of Contents
* I. ཀླད་ཀྱི་དོན། [[༄༅༅། །རྒྱ་གར་སྐད་དུ། ན་ཡ་བིནྡུ་པཱུརྦ་པཀྵེ་སཾ་ཀྵིཔྟ། བོད་སྐད་དུ། རིགས་པའི་ཐིགས་པའི་ཕྱོགས་]]
* 1. མངོན་སུམ་ལ་ལོག་པར་རྟོགས་པ [[ལོག་པར་རྟོགས་པ༌[^1]ནི་རྣམ་པ་བཞི་སྟེ། གྲངས་ལ་ལོག་པར་རྟོགས་པ༌[^2]དང་། རང་གི་ངོ་]]
   * 1.1 གྲངས་ལ་ལོག་པར་རྟོགས་པ [[དེ་ལ་གྲངས་ལ་ལོག་པར་རྟོགས་པ༌[^6]ནི། འདི་ལྟ་སྟེ། ཕུར་བུ་བ་རྣམས་ནི་མངོན་སུམ་]]
   * 1.2 རང་གི་ངོ་བོ་ལ་ལོག་པར་རྟོགས་པ [[དེ་ལ་རང་གི་ངོ་བོ་ལ་ལོག་པར་རྟོགས་པ༌[^9]ནི། འདི་ལྟ་སྟེ། རིགས་པ་ཅན་རྣམས་]]
   * 1.3 ཡུལ་ལ་ལོག་པར་རྟོགས་པ [[དེ་ལ་ཡུལ་ལ་ལོག་པར་རྟོགས་པས༌[^16]ནི་འདི་ལྟ་སྟེ། རིགས་པ་ཅན་ལ་སོགས་པ་]]
   * 1.4 འབྲས་བུ་ལ་ལོག་པར་རྟོགས་པ [[དེ་ལ་འབྲས་བུ་ལ་ལོག་པར་རྟོགས་པ༌[^21]ནི་འདི་ལྟ་སྟེ། རྒྱལ་དཔོག་པ་ལ་སོགས་]]
* 2. བཅོམ་ལྡན་འདས་ཀྱང་བཞེད་པ [[འདི་ནི་བཅོམ་ལྡན་འདས་ཀྱང་བཞེད་པ་ཁོ་ན་ཡིན་ཏེ། ཇི་སྐད་དུ།]]
* 3. རྗེས་སུ་དཔག་པ་ལ་ལོག་པར་རྟོགས་པ [[རྗེས་སུ་དཔག་པ་ལ་ཡང་ལོག་པར་རྟོགས་པ་སྣང་སྟེ། འདི་ལྟ་སྟེ། བརྡ་སྤྲོད་པ་]]
   * 3.1 ཚུལ་གསུམ་པ [[སྣོད་ཀྱི་རྗེས་ན་རེ་ནི་གཞན་དུ་མི་འཐད་པའི་ངོ་བོ་གཅིག་པུ་ཁོ་]]
   * 3.2 རྟགས་ཀྱི་རབ་ཏུ་ཕྱེ་བ [[ཁ་ཅིག་རྗེས་སུ་དཔག་པའི་རབ་ཏུ་དབྱེ་བ་དང་། རང་གི་ངོ་བོ་གཞན་]]
   * 3.3 མི་དམིགས་པ་བྱེ་བྲག་ཏུ་བཤད་པ [[རྒྱལ་དཔོག་པ་ལ་སོགས་པ་ནི་ཐམས་ཅད་མཁྱེན་པ་ལ་སོགས་པ་དམིགས་པའི་]]
   * 3.4 རང་བཞིན་གྱི་གཏན་ཚིགས་ཀྱི་ཡུལ [[གནས་མའི་བུའི་སྡེ་པ་ལ་སོགས་པ་ནི་མི་རྟག་པ་ལ་སོགས་པ་ཕྱིས་]]
   * 3.5 འབྲས་བུའི་གཏན་ཚིགས [[བརྡ་སྤྲོད་པ་ལ་སོགས་པ་མེ་མ་ཡིན་པ་བརྒྱ་བྱིན་གྱི་སྤྱི་བོ་ལ་]]
   * 3.6 དངོས་པོ་རྣམས་ཀྱི་འབྲེལ་པ [[གྲངས་ཅན་པ་རྣམས་ནི་དངོས་པོ་རྣམས་ཀྱི་འབྲེལ་པ་རྣམ་པ་བདུན་བརྗོད་དོ། །]]
   * 3.7 མི་དམིགས་པའི་རབ་ཏུ་དབྱེ་བ [[སྤྱོད་པ་པ་རྣམས་ནི་ད་ལྟར་ཐམས་ཅད་མཁྱེན་པ་ལ་སོགས་པ་མི་དམིགས་]]
* 4. རྗེས་སུ་དཔག་པའི་མཚན་ཉིད་བཅོམ་ལྡན་འདས་ཀྱིས་གསུངས་པ [[རྗེས་སུ་དཔག་པ་འདིའི་མཚན་ཉིད་ནི། བཅོམ་ལྡན་འདས་རྗེས་སུ་དཔག་པའི་རྟེན་གྱི་]]
   * 4.1 རང་བཞིན་ཞེས་བྱ་བའི་གཏན་ཚིགས [[རྟགས་དེ་ཡང་རང་བཞིན་དང་། འབྲས་བུ་དང་། མི་དམིགས་པའི་བདག་ཉིད་རྣམ་པ་]]
   * 4.2 འབྲས་བུ [[འབྲས་བུ་ཞེས་བྱ་བ་ཡང་།]]
   * 4.3 མི་དམིགས་པའི་ཁྱད་པར [[མི་དམིགས་པ་ཙམ་ཚད་མ་ཉིད་ཡིན་པ་སྤང༌[^92]བར་མཛད་པས། མི་དམིགས་པའི་ཁྱད་པར་]]
* 5. གཞན་གྱི་དོན་གྱི་རྗེས་སུ་དཔག་པ [[རིགས་པ་ཅན་ལ་སོགས་པ་ནི་གཞན་གྱི་དོན་གྱི་རྗེས་སུ་དཔག་པ་ཚིག་]]
   * 5.1 རང་གི་ངོ་བོ [[ཡན་ལག་ལྔ་ནི། དམ་བཅས༌[^95]པ་དང་། གཏན་ཚིགས་དང་། དཔེ་དང་། ཉེ་བར་སྦྱར་བ་དང་]]
   * 5.2 རབ་ཏུ་དབྱེ་བ [[རྟོག་གེ་པ་གཞན་ཐམས་ཅད་ནི། འདི༌[^98]རེ་ཞིག་ཆོས་མཐུན་པ་དང་། ཆོས་མི་མཐུན་པ་]]
   * 5.3 ཕྱོགས་ཀྱི་མཚན་ཉིད [[རང་གི་སྡེ་པ་གང་དག་ཉེ་བར་སྦྱར་བ་དང་། མཇུག་བསྡུ་བ་དག་ནི་]]
   * 5.4 འགལ་བ [[རྒྱལ་དཔོག་པ་རྣམས་ནི་རང་རིག་པའི་མངོན་སུམ་དུ་རབ་ཏུ་གྲུབ་པ་བློ་]]
   * 5.5 གཏན་ཚིགས་ལྟར་སྣང་བ [[རིགས་པ་ཅན་རྣམས་ནི་གཏན་ཚིགས་ལྟར་སྣང་བ་རྣམས་ཀྱི་མཚན་ཉིད་ནི། འཁྲུལ་པ་]]
   * 5.6 དཔེ་ལྟར་སྣང་བ [[རིགས་པ་ཅན་ལ་སོགས་པ་ནི་མཚན་ཉིད་གསུམ་པའི་གཏན་ཚིགས་ལས་མ་གཏོགས་]]
   * 5.7 ལྟག་ཆོད [[དེ་ལ་ལྟག་ཆོད༌[^165]རྣམས་ཀྱི་དཔེར་བརྗོད་པ༌[^166]ཕྱོགས་ཙམ་ཞིག་བརྗོད་པར་བྱ་སྟེ། དཔེར་ན་མི་]]
* b. མཇུག་བྱང། [[རིགས་པའི་ཐིགས་པའི་ཕྱོགས་སྔ་མ་མདོར་བསྡུས་པ། སློབ་དཔོན་མང་དུ་ཐོས་པ་ཀ་]]
   * b.1 མཛད་བྱང། [[རིགས་པའི་ཐིགས་པའི་ཕྱོགས་སྔ་མ་མདོར་བསྡུས་པ། སློབ་དཔོན་མང་དུ་ཐོས་པ་ཀ་]]
   * b.2 འགྱུར་བྱང། [[རྒྱ་གར་གྱི་མཁན་པོ༌[^176]ཤུདྡྷ་སིཾ་ཧ་དང་། ཞུ་ཆེན་གྱི་ལོ་ཙཱ་བ་དགེ་སློང་]]
