* 2.12 རྟགས་བཅུ་གཉིས་པ [[གསོལ་པ། བཅོམ་ལྡན་འདས་བྱང་ཆུབ་སེམས་དཔའ་སེམས་དཔའ་ཆེན་པོ་དེ་ལྟར་སྤྱོད་པ་ནི་གཟུགས་ལ་མི་སྤྱོད།]]
* 3. རྣམ་པར་འཕེལ་བ [[བཅོམ་ལྡན་འདས་ཀྱིས་བཀའ་སྩལ་པ། རབ་འབྱོར་གལ་ཏེ་འཛམ་བུའི་གླིང་གི༌[^647]སེམས་ཅན་ཇི་སྙེད་པ་དེ་དག་ཐམས་ཅད་]]
   * 3.1 རྣམ་པར་འཕེལ་བ་དང་པོ [[བཅོམ་ལྡན་འདས་ཀྱིས་བཀའ་སྩལ་པ། རབ་འབྱོར་གལ་ཏེ་འཛམ་བུའི་གླིང་གི༌[^647]སེམས་ཅན་ཇི་སྙེད་པ་དེ་དག་ཐམས་ཅད་]]
   * 3.2 རྣམ་པར་འཕེལ་བ་གཉིས་པ [[དེས་ཤེས་རབ་ཀྱི་ཕ་རོལ་ཏུ་ཕྱིན་པ་དང་ལྡན་པའི་གཏམ་བརྗོད་ནས་ཤེས་རབ་ཀྱི་ཕ་རོལ་ཏུ་ཕྱིན་པ་དང་ལྡན་པའི་ཡིད་ལ་བྱེད་པ་ཉིད་]]
   * 3.3 རྣམ་པར་འཕེལ་བ་གསུམ་པ [[གསོལ་པ། བཅོམ་ལྡན་འདས་གལ་ཏེ་ཤེས་རབ་ཀྱི་ཕ་རོལ་ཏུ་ཕྱིན་པ་རང་བཞིན་གྱིས་དབེན་ཞིང་རང་བཞིན་གྱིས་སྟོང་པ་ལགས་ན།]]
   * 3.4 རྣམ་པར་འཕེལ་བ་བཞི་པ [[རབ་འབྱོར་གྱིས་གསོལ་པ། བཅོམ་ལྡན་འདས་ཅི་ལགས། ཆོས་ཐམས་ཅད་མི་སྐྱེ་བའི་སླད་དུ་བྱང་ཆུབ་སེམས་དཔའ་སེམས་དཔའ་ཆེན་པོ༌[^690]བླ་ན་མེད་པ་]]
   * 3.5 རྣམ་པར་འཕེལ་བ་ལྔ་པ [[དེ་ནས་ལྷའི་དབང་པོ་བརྒྱ་བྱིན་གྱིས་བཅོམ་ལྡན་འདས་ལ་འདི་སྐད་ཅེས་གསོལ་ཏོ། །བཅོམ་ལྡན་འདས་ཤེས་རབ་ཀྱི་ཕ་རོལ་ཏུ་ཕྱིན་པ་ནི་]]
   * 3.6 རྣམ་པར་འཕེལ་བ་དྲུག་པ [[དེ་ལྟར་སློབ་པའི་བྱང་ཆུབ་སེམས་དཔའ་སེམས་དཔའ་ཆེན་པོའི་དྲུང་དུ་རྒྱལ་པོ་ཆེན་པོ་བཞིས༌[^711]ཀྱང་འགྲོ་བར་བྱ་བར་སེམས་ཏེ།]]
   * 3.7 རྣམ་པར་འཕེལ་བ་བདུན་པ [[དེ་ནས་ཚེ་དང་ལྡན་པ་ཀུན་དགའ་བོ་འདི་སྙམ་དུ་གྱུར༌[^720]ཏེ། ལྷའི་དབང་པོ་བརྒྱ་བྱིན་འདི་རང་གི་སྤོབས་པས་ཤེས་རབ་ཀྱི་ཕ་རོལ་ཏུ་ཕྱིན་པ་འདི་]]
   * 3.8 རྣམ་པར་འཕེལ་བ་བརྒྱད་པ [[བམ་པོ་ལྔ་བཅུ་བཞི་པ། ཀུན་དགའ་བོས་གསོལ་པ། བཅོམ་ལྡན་འདས་ཇི་ལྟར་བྱང་ཆུབ་སེམས་དཔའ་སེམས་དཔའ་ཆེན་པོས་གང་ཟག་]]
   * 3.9 རྣམ་པར་འཕེལ་བ་དགུ་པ [[གསོལ་པ། བཅོམ་ལྡན་འདས་ཅི་ལགས། བྱང་ཆུབ་སེམས་དཔའ་སེམས་དཔའ་ཆེན་པོ་གཟུགས་བས་པར་བགྱི་བའི་སླད་དུ་སློབ་ན་]]
   * 3.10 རྣམ་པར་འཕེལ་བ་བཅུ་པ [[རབ་འབྱོར་འདི་ལྟ་སྟེ་དཔེར་ན། ས་ཆེན་པོའི་ཕྱོགས་གང་ན་འཛམ་བུའི་ཆུ་ཀླུང་གི་གསེར་གྱི་ས་ལེ་སྦྲམ་འབྱུང་བ་]]
   * 3.11 རྣམ་པར་འཕེལ་བ་བཅུ་གཅིག་པ [[རབ་འབྱོར་འདི་ལྟ་སྟེ་དཔེར་ན། སེམས་ཅན་གང་འཁོར་ལོས་སྒྱུར་བའི༌[^778]རྒྱལ་པོར་འགྱུར་བའི་ལས་ཡང་དག་པར་བླངས་ཏེ་]]
   * 3.12 རྣམ་པར་འཕེལ་བ་བཅུ་གཉིས་པ [[རབ་འབྱོར་གཞན་ཡང་བྱང་ཆུབ་སེམས་དཔའ་སེམས་དཔའ་ཆེན་པོ་ཤེས་རབ་ཀྱི་ཕ་རོལ་ཏུ་ཕྱིན་པ་ལ་སྤྱོད་པའི་ཚེ། སེར་སྣ་དང་ལྡན་པའི་]]
   * 3.13 རྣམ་པར་འཕེལ་བ་བཅུ་གསུམ་པ [[གཟུགས་དང་ལྡན་པའི་སེམས་མི་སྐྱེའོ། །ཚོར་བ་དང་། འདུ་ཤེས་དང་། འདུ་བྱེད་རྣམས་དང་། རྣམ་པར་ཤེས་པ་དང་ལྡན་པའི་]]
   * 3.14 རྣམ་པར་འཕེལ་བ་བཅུ་བཞི་པ [[རབ་འབྱོར་འདི་ལྟ་སྟེ་དཔེར་ན། འཇིག་ཚོགས་སུ་ལྟ་བར་ལྟ་བའི་རྣམ་པ་དྲུག་ཅུ་རྩ་གཉིས་པོ་ཐམས་ཅད་ཀྱང་འདུས་པ་ཡིན་ཏེ།]]
   * 3.15 རྣམ་པར་འཕེལ་བ་བཅོ་ལྔ་པ [[རབ་འབྱོར་ཤེས་རབ་ཀྱི་ཕ་རོལ་ཏུ་ཕྱིན་པ་ཟབ་མོ་འདི་ལ་སློབ་པའི་བྱང་ཆུབ་སེམས་དཔའ་སེམས་དཔའ་ཆེན་པོ་ནི་སེམས་ཅན་ཐམས་ཅད་ཀྱི་]]
