## དཀར་ཆག / Table of Contents

* II. རྣལ་འབྱོར་སྤྱོད་པའི་ས་བཅུ་བདུན་མདོར་བསྟན་པ [[རྣལ་འབྱོར་སྤྱོད་པའི་ས་གང་ཞེ་ན། དེ་ནི་ས་བཅུ་བདུན་དུ་བལྟ་བར་]]
* 1. རྣམ་པར་ཤེས་པའི་ཚོགས་ལྔ་དང་ལྡན་པའི་ས [[རྣམ་པར་ཤེས་པའི་ཚོགས་ལྔ་དང་ལྡན་པའི་ས་གང་ཞེ་ན།]]
   * 1.1 མིག་གི་རྣམ་པར་ཤེས་པ [[མིག་གི་རྣམ་པར་ཤེས་པ་གང་ཞེ་ན།]]
      * 1.1.1 ངོ་བོ་ཉིད [[མིག་གི་རྣམ་པར་ཤེས་པ་གང་ཞེ་ན།]]
      * 1.1.2 མིག་གི་རྣམ་པར་ཤེས་པའི་གནས [[མིག་གི་རྣམ་པར་ཤེས་པའི་གནས་གང་ཞེ་ན།]]
      * 1.1.3 མིག་གི་རྣམ་པར་ཤེས་པའི་དམིགས་པ [[མིག་གི་རྣམ་པར་ཤེས་པའི་དམིགས་པ་གང་ཞེ་ན།]]
      * 1.1.4 གྲོགས [[གྲོགས་གང་ཞེ་ན། དེ་དང་ལྷན་ཅིག་འབྱུང་ཞིང་མཚུངས་པར་ལྡན་པ་སེམས་ལས་]]
      * 1.1.5 ལས [[ལས་གང་ཞེ་ན། དེ་ནི་རྣམ་པ་དྲུག་ཏུ་བལྟ་བར་བྱ་སྟེ། ཐོག་མ་ཁོ་]]
   * 1.2 རྣ་བའི་རྣམ་པར་ཤེས་པ [[རྣ་བའི་རྣམ་པར་ཤེས་པ་གང་ཞེ་ན།]]
      * 1.2.1 ངོ་བོ་ཉིད [[རྣ་བའི་རྣམ་པར་ཤེས་པ་གང་ཞེ་ན།]]
      * 1.2.2 གནས [[གནས་གང་ཞེ་ན། རྣ་བ་ནི་ལྷན་ཅིག་འབྱུང་བའི་གནས་སོ། །]]
      * 1.2.3 དམིགས་པ [[དམིགས་པ་གང་ཞེ་ན། སྒྲ་རྣམ་པ་དུ་མ་བསྟན་དུ་མེད་ལ་ཐོགས་པ་]]
      * 1.2.4 གྲོགས [[གྲོགས་དང་ལས་ནི་མིག་གི་རྣམ་པར་ཤེས་པའི་རང་བཞིན་དུ་རིག་པར་]]
      * 1.2.5 ལས [[གྲོགས་དང་ལས་ནི་མིག་གི་རྣམ་པར་ཤེས་པའི་རང་བཞིན་དུ་རིག་པར་]]
   * 1.3 སྣའི་རྣམ་པར་ཤེས་པ [[སྣའི་རྣམ་པར་ཤེས་པ་གང་ཞེ་ན། གང་སྣ་ལ་བརྟེན་ནས་དྲི་སོ་སོར་]]
      * 1.3.1 ངོ་བོ་ཉིད [[སྣའི་རྣམ་པར་ཤེས་པ་གང་ཞེ་ན། གང་སྣ་ལ་བརྟེན་ནས་དྲི་སོ་སོར་]]
      * 1.3.2 གནས [[གནས་གང་ཞེ་ན། སྣ་ནི་ལྷན་ཅིག་འབྱུང་བའི་གནས་སོ། །]]
      * 1.3.3 དམིགས་པ [[དམིགས་པ་གང་ཞེ་ན། དྲི་རྣམ་པ་དུ་མ་བསྟན་དུ་མེད་ལ་ཐོགས་པ་]]
      * 1.3.4 གྲོགས [[གྲོགས་དང་ལས་ནི་སྔ་མ་བཞིན་དུ་རིག་པར་བྱའོ། །]]
      * 1.3.5 ལས [[གྲོགས་དང་ལས་ནི་སྔ་མ་བཞིན་དུ་རིག་པར་བྱའོ། །]]
   * 1.4 ལྕེའི་རྣམ་པར་ཤེས་པ [[ལྕེའི་རྣམ་པར་ཤེས་པ་གང་ཞེ་ན། གང་ལྕེ་ལ༌[^15]བརྟེན་ནས་སོ་སོར་རྣམ་]]
      * 1.4.1 ངོ་བོ་ཉིད [[ལྕེའི་རྣམ་པར་ཤེས་པ་གང་ཞེ་ན། གང་ལྕེ་ལ༌[^15]བརྟེན་ནས་སོ་སོར་རྣམ་]]
      * 1.4.2 གནས [[གནས་གང་ཞེ་ན། ལྕེ་ནི་ལྷན་ཅིག་འབྱུང་བའི་གནས་སོ། །]]
      * 1.4.3 དམིགས་པ [[དམིགས་པ་གང་ཞེ་ན། རོ་རྣམ་པ་དུ་མ་བསྟན་དུ་མེད་ལ་ཐོགས་པ་]]
      * 1.4.4 གྲོགས [[གྲོགས་དང་ལས་ནི་སྔ་མ་བཞིན་དུ་རིག་པར་བྱའོ། །]]
      * 1.4.5 ལས [[གྲོགས་དང་ལས་ནི་སྔ་མ་བཞིན་དུ་རིག་པར་བྱའོ། །]]
   * 1.5 ལུས་ཀྱི་རྣམ་པར་ཤེས་པ [[ལུས་ཀྱི་རྣམ་པར་ཤེས་པ་གང་ཞེ་ན།]]
      * 1.5.1 ངོ་བོ་ཉིད [[ལུས་ཀྱི་རྣམ་པར་ཤེས་པ་གང་ཞེ་ན།]]
      * 1.5.2 གནས [[གནས་གང་ཞེ་ན། ལུས་ནི་ལྷན་ཅིག་འབྱུང་བའི་གནས་སོ། །]]
      * 1.5.3 དམིགས་པ [[དམིགས་པ་གང་ཞེ་ན། རེག་བྱ་རྣམ་པ་བསྟན་དུ་མེད་ལ་ཐོགས་པ་དང་]]
      * 1.5.4 གྲོགས [[གྲོགས་དང་ལས་ནི་སྔ་མ་བཞིན་དུ་རིག་པར་བྱའོ། །]]
      * 1.5.5 ལས [[གྲོགས་དང་ལས་ནི་སྔ་མ་བཞིན་དུ་རིག་པར་བྱའོ། །]]
* 2. ཡིད་ཀྱི་ས [[ཡིད་ཀྱི་ས་གང་ཞེ་ན། དེ་ཡང་རྣམ་པ་ལྔ་ཁོ་ནར་བལྟ་བར་བྱ་]]
   * 2.1 ངོ་བོ་ཉིད [[དེ་ལ་ངོ་བོ་ཉིད་གང་ཞེ་ན། སེམས་དང་ཡིད་དང་རྣམ་པར་ཤེས་པ་]]
      * 2.1.1 སེམས [[སེམས་གང་ཞེ་ན། ས་བོན་ཐམས་ཅད་དང་ལྡན་པ་དང་། གནས་ཀྱི་དངོས་པོར་]]
      * 2.1.2 ཡིད [[ཡིད་གང་ཞེ་ན། རྣམ་པར་ཤེས་པའི་ཚོགས་དྲུག་པོ་དག་འགགས་མ་ཐག་པ་]]
      * 2.1.3 རྣམ་པར་ཤེས་པ [[རྣམ་པར་ཤེས་པ་གང་ཞེ་ན། དམིགས་པ་རྣམ་པར་རིག་པར་བྱེད་པས་ཉེ་]]
   * 2.2 གནས [[གནས་གང་ཞེ་ན། ཡིད་དེ་མ་ཐག་པའི་གནས་དང་། སྔ་མ་བཞིན་དུ་ས་]]
   * 2.3 དམིགས་པ [[དམིགས་པ་གང་ཞེ་ན། ཆོས་ཐམས་ཅད་ནི་དམིགས་པ་སྟེ། འབའ་ཞིག་གི་ཚོར་བའི་]]
   * 2.4 གྲོགས [[གྲོགས་གང་ཞེ་ན། འདི་ལྟ་སྟེ། ཡིད་ལ་བྱེད་པ་དང་། རེག་པ་དང་། ཚོར་བ་]]
   * 2.5 ལས [[ལས་གང་ཞེ་ན། བདག་དང་གཞན་གྱི་ཡུལ་གྱི་དམིགས་པ་རྣམ་པར་རིག་པར་]]
      * 2.5.1 དམིགས་པ་ལ་ཇི་ལྟར་རྣམ་པར་རྟོག [[དམིགས་པ་ལ་ཇི་ལྟར་རྣམ་པར་རྟོག་ཅེ་ན།]]
      * 2.5.2 དམིགས་པ་ལ་ཇི་ལྟར་ཉེ་བར་སེམས [[དམིགས་པ་ལ་ཇི་ལྟར་ཉེ་བར་སེམས་ཤེ་ན།]]
      * 2.5.3 ཇི་ལྟར་ར་རོ་བར་བྱེད [[ཇི་ལྟར་ར་རོ་བར༌[^43]བྱེད་ཅེ་ན། རང་གཞན་གྱིས༌[^44]ལུས་ཉམ་ཆུང་བ་དང་།]]
      * 2.5.4 ཇི་ལྟར་སྨྱོ་བར་བྱེད [[ཇི་ལྟར་སྨྱོ་བར་བྱེད་ཅེ་ན། སྔོན་གྱི་ལས་ཀྱིས༌[^46]འཕངས་པ་དང་། ཁམས་མི་]]
      * 2.5.5 ཇི་ལྟར་གཉིད་ལོག་པར་བྱེད [[ཇི་ལྟར་གཉིད་ལོག་པར་བྱེད་ཅེ་ན། རང་བཞིན་གྱིས་ལུས་ཉམ་ཆུང་བ་དང་།]]
      * 2.5.6 ཇི་ལྟར་སངས་པར་བྱེད [[ཇི་ལྟར་སངས་པར་བྱེད་ཅེ་ན། གཉིད་ཀྱིས་བརྟས༌[^50]ནས་དེའི་ཀུན་ནས་དཀྲིས་པ་]]
      * 2.5.7 ཇི་ལྟར་བརྒྱལ་བར་བྱེད [[ཇི་ལྟར་བརྒྱལ་བར་བྱེད་ཅེ་ན། རླུང་དང༌[^53]མཁྲིས་པས་དཀྲུགས་པ་དང་། སྣད་པ་]]
      * 2.5.8 ཇི་ལྟར་བརྒྱལ་བ་ལས་སངས་པར་བྱེད [[ཇི་ལྟར་བརྒྱལ་བ་ལས་སངས་པར་བྱེད་ཅེ་ན།]]
      * 2.5.9 ཇི་ལྟར་ལུས་དང་ངག་གི་ལས་འཇུག་པར་བྱེད [[ཇི་ལྟར་ལུས་དང་ངག་གི་ལས་འཇུག་པར་བྱེད་ཅེ་ན།]]
