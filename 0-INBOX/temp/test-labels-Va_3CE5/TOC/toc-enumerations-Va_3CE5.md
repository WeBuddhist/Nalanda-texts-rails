Enumeration Block 1:
བཞིན་དུ་ཚིག་དགུས་བགེགས་བཅོམ་པ་དང་། སྟོན་པ་ཉིད་ཕུན་སུམ་ཚོགས་པ་གསུང་བ་ཉིད་དང་། སྒྲུབ་པ་ཉིད་ཀྱི་མཚན་ཉིད་དང་། རྒྱུ་གང་ཡིན་པ་དང་། ཇི་ལྟར་གཤེགས་པ་དང་། སེམས་ཅན་སྐལ་བ་དང་ལྡན་པ་དང་། མི་ལྡན་པ་ལ་གཟིགས་པ་དང་། སྐལ་བ་དང་ལྡན་པ་འདུལ་བར་མཛད་པ་དང་། སྟོན་པ་ཉིད་དེ་གང་དག་ལ་གནས་པ་དང་། གང་དག་གི་དོན་ཡིན་པ་མངོན་པར་བརྗོད་པའི་སྒོ་ནས་ཡོན་ཏན་ཆེ་བའི་བདག་ཉིད་མངོན་པར་བརྗོད་པ་ཡིན་ཏེ།
Enumeration Block 2:
སྟོན་པ་ཉིད་ཕུན་སུམ་ཚོགས་པ་དེ་ཡང་རྣམ་པ་གཉིས་ཏེ། གསུང་བ་ཉིད་ཀྱི་རྒྱུ་མཚན་ཉིད་དང་། སྒྲུབ་པ་ཉིད་ཀྱི་མཚན་ཉིད་དོ། །
Enumeration Block 3:
སྟོན་པ་ཉིད་ཀྱི་ཕྲིན་ལས༌[^13]དེ་ཡང་རྣམ་པ་གཉིས་ཏེ། འཇིག་རྟེན་སྐལ་བ་དང་ལྡན་པ་དང་། སྐལ་བ་དང་མི༌[^14]ལྡན་པ་ལ་གཟིགས་པ་དང་། སྐལ་བ་དང་ལྡན་པ་འདུལ་བར་མཛད་པའོ། །
Enumeration Block 4:
བཅོམ་ལྡན་འདས་དེ་སེམས་ཅན་གྱི་དོན་རྒྱུ་གང་གིས་གཏན་དུ་དང་། སྐུ་གང་ཡིན་པ་དང་། གང་ལ་བརྟེན་པ་དང་། བྱ་བ་གང་ཡིན་པ་དང་། ཐབས་གང་ཡིན་པ་དང་། གང་ན་གནས་ཤིང་དེ་ལ་མ་ཆགས་པར་དོན་མཛད་པ་དང་། དངོས་པོ་གང་ལ་ཆགས་པ་དང་། སྤང་བ༌[^34]གང་ཡིན་པ་དང་། ཡེ་ཤེས་གང་ཡིན་པ་དང་། སྐུ་གང་དག་ལ་བཞུགས་ནས་གཏན་དུ་སེམས་ཅན་གྱི་དོན་མཛད་པའི་དོན་དེ་དག་གི་བཞིན་དུ་ཚིག་གཉིས་དང་། དྲུག་དང་། གསུམ་དང་། བཞི་དང་། ཡང་དྲུག་དང་། གསུམ་དང་། གསུམ་དང་། བཞི་དང་། བཞིས་བསྟན་ཏོ། །
Enumeration Block 5:
གཟུགས་ཀྱི་སྐུ་དེའི་ཕུན་སུམ་ཚོགས་པ་ལ་ཡང་རྣམ་པ་ལྔས་སྟོན་ཏེ། རྩ་བའི་རྒྱུ་ཕུན་སུམ་ཚོགས་པ་དང་། རབ་ཏུ་དབྱེ་བའི་རྒྱུ་ཕུན་སུམ་ཚོགས་པ་དང་། ངོ་བོ་ཉིད་ཕུན་སུམ་ཚོགས་པ་དང་། གནས་སྐབས་ཕུན་སུམ་ཚོགས་པ་དང་། མཛད་པ་ཕུན་སུམ་ཚོགས་པའོ། །
Enumeration Block 6:
སེམས་ཅན་དེ་དག་ཀྱང་དད་པའི་བསམ་པའམ། ཟིལ་གྱིས་མནན་པའི་བསམ་པ་སྟེ། བསམ་པ་གཉིས་ཀྱིས་དེ་བཞིན་གཤེགས་པའི་དྲུང་དུ་འོང་ངོ་། །དད་པའི་བསམ་པ་ཡང་རྣམ་པ་གཉིས་ཏེ། ཅི་འདྲ་བ་སྙམ་པའི་བསམ་པའམ། རབ་ཏུ་དགའ་བའི༌[^52]བསམ་པའོ། །
Enumeration Block 7:

Enumeration Block 8:
བྱ་བ་དེའི་གནས་སྐབས་ཀྱི་བྱེ་བྲག་ནི་རྣམ་པ་གཉིས་ཏེ། ཞུགས་པའི་གནས་སྐབས་ཀྱི་བྱེ་བྲག་དང་། འཇུག་པའི་གནས་སྐབས་ཀྱི་བྱེ་བྲག་གོ། ། ཞུགས་པའི་གནས་སྐབས་ཀྱི་བྱེ་བྲག་ཀྱང་སངས་རྒྱས་འབྱུང་བ་དང་ཉེ་བར་བསྒྲུབ་པར༌[^65]བྱ་བའི་ཕྱིར་སངས་རྒྱས་དང་ཉན་ཐོས་ཀྱི་རིགས་ཀྱི་བྱེ་བྲག་ནི་རྣམ་པ་གཉིས་སོ། །
Enumeration Block 9:
ཐབས་དེ་ཡང་དེ་ལས་གསུམ་ཡིན་ནོ། །
Enumeration Block 10:
སྤོབས་པའི་ཁྱད་པར་ཡང་རྣམ་པ་གཉིས་ཏེ། ཡི་གེ་ལ་བརྟེན་པ་དང་། དོན་ལ་བརྟེན་པའོ། །
Enumeration Block 11:
ཉོན་མོངས་པ་རྣམས་ནི་མདོར་བསྡུ་ན། ཡུལ་དང་མ་ཕྲད་པ་དང་། ཕྲད་པའི་བྱེ་བྲག་གིས་རྣམ་པ་གཉིས་ཏེ། མདུད་པའི་མཚན་ཉིད་རྣམས་དང་། ཡོངས་སུ་གདུང་བའི་མཚན་ཉིད་རྣམས་སོ། ། དེ་དག་གི་སྒོ་ཡང་རྣམ་པ་གཉིས་ཏེ། སྲེད་པའི་སྒོ་རྣམས་དང་། ཆུ་བོའི་སྒོ་རྣམས་སོ། །
Enumeration Block 12:
