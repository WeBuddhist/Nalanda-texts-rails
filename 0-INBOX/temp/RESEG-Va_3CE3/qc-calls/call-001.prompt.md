━━━ ISSUE TYPES ━━━

CONNECTOR_ENDING
  The block ends with a connector particle (དང་། / ཞིང་། / ཅིང་། / ནས། / ལས། /
  སྟེ། / ཏེ།) that grammatically requires continuation. Real issue if the next
  block is the grammatical continuation. False positive if this is a closing verse
  pāda or a deliberate short citation frame.

OBJECTION_REPLY_FUSED
  The block contains both an objection marker (ཅེ་ན། / ཞེ་ན། / སྙམ་ན།) and a reply
  opener (འོ་ན།). These should always be two separate blocks. Almost always a
  real issue.

OVER_LENGTH
  The block exceeds the syllable threshold. Usually NOT wrong: a whole explanation
  unit is legitimately long. Split only if a new node opener (ordinal + title +
  ནི། / ལ་ N།) or the treatment of a new verse is buried mid-block.

SHORT_FRAGMENT
  The block is suspiciously short — may be a stray split artifact that should be
  merged with an adjacent block.

དེ་ནས་ཡང་འཕགས་པ་བྱམས་པས། ཀུན་བརྟགས་པའི་གཟུགས་ནི་གང་ལགས་ཞེས་བྱ་བ་ལ་སོགས་པ༌[^2215]ཞུས་པ་དང་། བཅོམ་ལྡན་འདས་ཀྱིས། བྱམས་པ་གང་འདུ་བྱེད་ཀྱི་མཚན་མའི་དངོས་པོ་དེ་ལ་གཟུགས་ཞེས་བྱ་བའི་མིང་དང་། འདུ་ཤེས་དང་། བཏགས་པ་དང་། ཐ་སྙད་ལ་བརྟེན་ནས་གཟུགས་ཀྱི་ངོ་བོ་ཉིད་དུ་ཡོངས་སུ་རྟོགས་པ་འདི་ནི་ཀུན་བརྟགས་པའི་གཟུགས་སོ་ཞེས་བྱ་བ་ལ་སོགས་པ་གསུངས་ཏེ།[^2216] ཐ་སྙད་ལ་བརྟེན་ནས། ཐ་སྙད་ཀྱི་རྒྱུ་འདུ་བྱེད་ཀྱི་དངོས་པོ་ལ་གཟུགས་ཀྱི་ངོ་བོ་ཉིད་དུ་བརྟགས་པ་ལ་གཟུགས་ཞེས་བྱ་བའི་འདུ་ཤེས་དང་བརྟགས་པ་དེ་ནི་ཀུན་བརྟགས་པའི་གཟུགས་ཡིན་ནོ་ཞེས་བྱ་བའི་ཐ་ཚིག་གོ། །ཆོས་རྣམས་ཀྱི་ངོ་བོ་ཉིད་ནི་གསུམ་སྟེ། ཀུན་བརྟགས་པའི་ངོ་བོ་ཉིད་དང་། གཞན་གྱི་དབང་གི་ངོ་བོ་ཉིད་དང་། ཡོངས་སུ་གྲུབ་པའི་ངོ་བོ་ཉིད་དེ།[^2217] དེ་ལ་གཟུགས་ལ་སོགས་པ༌[^2218]ཆོས་རྣམས་ལ་གཟུགས་ཞེས་བྱ་བ་ལ་སོགས་པར་མངོན་པར༌[^2219]བརྗོད་པའི་རྣམ་པ་གང་ཡིན་པ་དེ་ནི་ཀུན་བརྟགས་པའི་ངོ་བོ་ཉིད་དོ། །མ་རིག་པ་ལ་སོགས་པའི་དབང་གིས་རྣམ་པར་ཤེས་པ་ལ༌[^2220]ཆོས་རྣམས་སུ་ཕྱིན་ཅི་ལོག་ཏུ་སྣང་བའི་རྣམ་པ་གང་ཡིན་པ་དེ་ནི་གཞན་གྱི་དབང་གི༌[^2221]ངོ་བོ་ཉིད་དོ། །གང་མིང་དེ་དང་། ཕྱིན་ཅི་ལོག་ཏུ་སྣང་བའི་རྣམ་པ་དེ་དང་བྲལ་བ་བརྗོད་དུ་མེད་པ། མཚན་མ་མེད་པའི་རྣམ་པ་གང་ཡིན་པ༌[^2222]དེ་ནི་དོན་དམ་པ་ཡོངས་སུ་གྲུབ་པའི་ངོ་བོ་ཉིད་དེ། འདི་རྒྱས་པར་ནི་རབ་ཏུ་བྱེད་པ་ལས་གཟུང་བར་བྱའོ། །ངོ་བོ་ཉིད་གསུམ་པོ་དེ་དག་དང་། འདིར་ཀུན་བརྟགས་པའི་གཟུགས་དང་། རྣམ་པར་བརྟགས་པའི་གཟུགས་དང་། ཆོས་ཉིད་ཀྱི་གཟུགས་ཞེས་བྱ་བ་དེ་དག༌[^2223]གོ་རིམས་བཞིན༌[^2224]དུ་བསྟན་པར་བྱ་སྟེ། དེ་ལ་གཟུགས་དང་། ཚོར་བ་དང་། འདུ་ཤེས་ཞེས་བྱ་བ་ལ་སོགས་པའི་མིང་གི་ཀུན་བརྟགས་པའི་གཟུགས་དང་། ཀུན་བརྟགས་པའི་ཚོར་བ་དང་། ཀུན་བརྟགས་པའི་འདུ་ཤེས་ཞེས་བྱ་བ་ལ་སོགས་པར་བརྗོད་དེ། འདུ་བྱེད་ཀྱི་མཚན་མའི་དངོས་པོ་དེ་དང་དེ་ལ་གཟུགས་སོ་ཞེས་བྱ་བའི་མིང་དང་། འདུ་ཤེས་དང་། བཏགས་པ་ཞེས་བྱ་བ་ལ་སོགས་པས་སྟོན་ཏོ། །

#### རྣམ་པར་བརྟགས་པའི་གཟུགས། ^2-2-2-0

[Block 2094]
དེའི་འོག་ཏུ་རྣམ་པ་གཉིས་ནི་འདུ་བྱེད་ཀྱི་མཚན་མའི་དངོས་པོ་དེ་རྣམ་པར་རྟོག་པ་ཙམ་གྱི་ཆོས་ཉིད་ལ་གནས་པའི་རྣམ་པར་རྟོག༌[^2225]པ་ལ་བརྟེན་ནས་མངོན་པར་བརྗོད་དེ་ཞེས་བྱ་བ་ལ་སོགས་པས་སྟོན་ཏེ། བྱིས་པ་སོ་སོའི་སྐྱེ་བོ་རྣམས་ཀྱི་སེམས་ཉོན་མོངས་པ་དང་། ལས་དང༌[^2226]རྣམ་པར་སྨིན་པ་ལ་སོགས་པའི་རྒྱུ་དང་རྐྱེན་གྱིས་ཕྱིན་ཅི་ལོག་ཏུ་གྱུར་པ་རྣམས་ལ་དངོས་པོའི་རྣམ་པར་བློ་སྐྱེ་ཞིང་སྣང་བ་ནི༌[^2227]རྣམ་པར་བརྟགས་པའི་གཟུགས་ཞེས་བྱའོ། །འདུ་བྱེད་ཀྱི་མཚན་མའི་དངོས་པོ་དེ་ཞེས་བྱ་བ་ལ་སོགས་པས་དེ་སྟོན་ཏེ། རྣམ་པར་རྟོག་པ་ཙམ་གྱི་ཆོས་ཉིད༌[^2228]ལ་གནས་པ་ཞེས་བྱ་བ་ནི་བློས༌[^2229]རྣམ་པར་བརྟགས་པའི་རྣམ་པ་མ་གཏོགས༌[^2230]པར་ངོ་བོ་ཉིད་གཞན་མེད་དེ། དེ་བས་ན་དངོས་པོ་དེ་རྣམ་པར་བརྟགས་པ་ཙམ་གྱི་ངོ་བོ་ཉིད་ལ་གནས་ཏེ། དེ་ལ་གནས་པ་དེ་ཉིད་ལ་རྣམ་པར་རྟོག་པ་ཞེས་བྱའོ། །དེ་ལྟར་བློས་རྣམ་པར་བརྟགས་པའི་རྣམ་པ་ཙམ་གྱི་ངོ་བོ་ཉིད་ལ་གནས་པ་རྣམ་པར་རྟོག་པ་དེ་ཉིད་ལ་བརྟེན་ཏེ་ཉེ་བར་བཟུང་ནས། གང་མངོན་པར་བརྗོད་པ་དང་འབྲེལ་པ་དངོས་པོའི་བདག་ཉིད་དུ་ཀུན་ཏུ་གཡེངས་པའི་རྣམ་པ་ལ་མངོན་པར་བརྗོད་པ་ཞེས་བྱ་སྟེ། དེ་ལྟར་བློས་རྣམ་པར་བརྟགས་པའི་རྣམ་པའི་ངོ་བོ་ཉིད་དུ་གནས་པ་ཞེས་བྱ་བའི་རྣམ་པ་ལ་བརྟེན་ནས་བློ་ལ་དངོས་པོའི་བདག་ཉིད་དུ་སྣང་བ་ནི་རྣམ་པར་བརྟགས་པའི་གཟུགས་ཞེས་བྱ་བའི་ཐ་ཚིག་གོ། །དེ་བཞིན་དུ་ཚོར་བ་ལ་སོགས་པ་ལ་ཡང་སྦྱར་བར་བྱའོ། །

དེ་ནས་ཡང་འཕགས་པ་བྱམས་པས། ཀུན་བརྟགས་པའི་གཟུགས་ནི་གང་ལགས་ཞེས་བྱ་བ་ལ་སོགས་པ༌[^2215]ཞུས་པ་དང་། བཅོམ་ལྡན་འདས་ཀྱིས། བྱམས་པ་གང་འདུ་བྱེད་ཀྱི་མཚན་མའི་དངོས་པོ་དེ་ལ་གཟུགས་ཞེས་བྱ་བའི་མིང་དང་། འདུ་ཤེས་དང་། བཏགས་པ་དང་། ཐ་སྙད་ལ་བརྟེན་ནས་གཟུགས་ཀྱི་ངོ་བོ་ཉིད་དུ་ཡོངས་སུ་རྟོགས་པ་འདི་ནི་ཀུན་བརྟགས་པའི་གཟུགས་སོ་ཞེས་བྱ་བ་ལ་སོགས་པ་གསུངས་ཏེ།[^2216] ཐ་སྙད་ལ་བརྟེན་ནས། ཐ་སྙད་ཀྱི་རྒྱུ་འདུ་བྱེད་ཀྱི་དངོས་པོ་ལ་གཟུགས་ཀྱི་ངོ་བོ་ཉིད་དུ་བརྟགས་པ་ལ་གཟུགས་ཞེས་བྱ་བའི་འདུ་ཤེས་དང་བརྟགས་པ་དེ་ནི་ཀུན་བརྟགས་པའི་གཟུགས་ཡིན་ནོ་ཞེས་བྱ་བའི་ཐ་ཚིག་གོ། །ཆོས་རྣམས་ཀྱི་ངོ་བོ་ཉིད་ནི་གསུམ་སྟེ། ཀུན་བརྟགས་པའི་ངོ་བོ་ཉིད་དང་། གཞན་གྱི་དབང་གི་ངོ་བོ་ཉིད་དང་། ཡོངས་སུ་གྲུབ་པའི་ངོ་བོ་ཉིད་དེ།[^2217] དེ་ལ་གཟུགས་ལ་སོགས་པ༌[^2218]ཆོས་རྣམས་ལ་གཟུགས་ཞེས་བྱ་བ་ལ་སོགས་པར་མངོན་པར༌[^2219]བརྗོད་པའི་རྣམ་པ་གང་ཡིན་པ་དེ་ནི་ཀུན་བརྟགས་པའི་ངོ་བོ་ཉིད་དོ། །མ་རིག་པ་ལ་སོགས་པའི་དབང་གིས་རྣམ་པར་ཤེས་པ་ལ༌[^2220]ཆོས་རྣམས་སུ་ཕྱིན་ཅི་ལོག་ཏུ་སྣང་བའི་རྣམ་པ་གང་ཡིན་པ་དེ་ནི་གཞན་གྱི་དབང་གི༌[^2221]ངོ་བོ་ཉིད་དོ། །གང་མིང་དེ་དང་། ཕྱིན་ཅི་ལོག་ཏུ་སྣང་བའི་རྣམ་པ་དེ་དང་བྲལ་བ་བརྗོད་དུ་མེད་པ། མཚན་མ་མེད་པའི་རྣམ་པ་གང་ཡིན་པ༌[^2222]དེ་ནི་དོན་དམ་པ་ཡོངས་སུ་གྲུབ་པའི་ངོ་བོ་ཉིད་དེ། འདི་རྒྱས་པར་ནི་རབ་ཏུ་བྱེད་པ་ལས་གཟུང་བར་བྱའོ། །ངོ་བོ་ཉིད་གསུམ་པོ་དེ་དག་དང་། འདིར་ཀུན་བརྟགས་པའི་གཟུགས་དང་། རྣམ་པར་བརྟགས་པའི་གཟུགས་དང་། ཆོས་ཉིད་ཀྱི་གཟུགས་ཞེས་བྱ་བ་དེ་དག༌[^2223]གོ་རིམས་བཞིན༌[^2224]དུ་བསྟན་པར་བྱ་སྟེ། དེ་ལ་གཟུགས་དང་། ཚོར་བ་དང་། འདུ་ཤེས་ཞེས་བྱ་བ་ལ་སོགས་པའི་མིང་གི་ཀུན་བརྟགས་པའི་གཟུགས་དང་། ཀུན་བརྟགས་པའི་ཚོར་བ་དང་། ཀུན་བརྟགས་པའི་འདུ་ཤེས་ཞེས་བྱ་བ་ལ་སོགས་པར་བརྗོད་དེ། འདུ་བྱེད་ཀྱི་མཚན་མའི་དངོས་པོ་དེ་དང་དེ་ལ་གཟུགས་སོ་ཞེས་བྱ་བའི་མིང་དང་། འདུ་ཤེས་དང་། བཏགས་པ་ཞེས་བྱ་བ་ལ་སོགས་པས་སྟོན་ཏོ། །

དེའི་འོག་ཏུ་རྣམ་པ་གཉིས་ནི་འདུ་བྱེད་ཀྱི་མཚན་མའི་དངོས་པོ་དེ་རྣམ་པར་རྟོག་པ་ཙམ་གྱི་ཆོས་ཉིད་ལ་གནས་པའི་རྣམ་པར་རྟོག༌[^2225]པ་ལ་བརྟེན་ནས་མངོན་པར་བརྗོད་དེ་ཞེས་བྱ་བ་ལ་སོགས་པས་སྟོན་ཏེ། བྱིས་པ་སོ་སོའི་སྐྱེ་བོ་རྣམས་ཀྱི་སེམས་ཉོན་མོངས་པ་དང་། ལས་དང༌[^2226]རྣམ་པར་སྨིན་པ་ལ་སོགས་པའི་རྒྱུ་དང་རྐྱེན་གྱིས་ཕྱིན་ཅི་ལོག་ཏུ་གྱུར་པ་རྣམས་ལ་དངོས་པོའི་རྣམ་པར་བློ་སྐྱེ་ཞིང་སྣང་བ་ནི༌[^2227]རྣམ་པར་བརྟགས་པའི་གཟུགས་ཞེས་བྱའོ། །འདུ་བྱེད་ཀྱི་མཚན་མའི་དངོས་པོ་དེ་ཞེས་བྱ་བ་ལ་སོགས་པས་དེ་སྟོན་ཏེ། རྣམ་པར་རྟོག་པ་ཙམ་གྱི་ཆོས་ཉིད༌[^2228]ལ་གནས་པ་ཞེས་བྱ་བ་ནི་བློས༌[^2229]རྣམ་པར་བརྟགས་པའི་རྣམ་པ་མ་གཏོགས༌[^2230]པར་ངོ་བོ་ཉིད་གཞན་མེད་དེ། དེ་བས་ན་དངོས་པོ་དེ་རྣམ་པར་བརྟགས་པ་ཙམ་གྱི་ངོ་བོ་ཉིད་ལ་གནས་ཏེ། དེ་ལ་གནས་པ་དེ་ཉིད་ལ་རྣམ་པར་རྟོག་པ་ཞེས་བྱའོ། །དེ་ལྟར་བློས་རྣམ་པར་བརྟགས་པའི་རྣམ་པ་ཙམ་གྱི་ངོ་བོ་ཉིད་ལ་གནས་པ་རྣམ་པར་རྟོག་པ་དེ་ཉིད་ལ་བརྟེན་ཏེ་ཉེ་བར་བཟུང་ནས། གང་མངོན་པར་བརྗོད་པ་དང་འབྲེལ་པ་དངོས་པོའི་བདག་ཉིད་དུ་ཀུན་ཏུ་གཡེངས་པའི་རྣམ་པ་ལ་མངོན་པར་བརྗོད་པ་ཞེས་བྱ་སྟེ། དེ་ལྟར་བློས་རྣམ་པར་བརྟགས་པའི་རྣམ་པའི་ངོ་བོ་ཉིད་དུ་གནས་པ་ཞེས་བྱ་བའི་རྣམ་པ་ལ་བརྟེན་ནས་བློ་ལ་དངོས་པོའི་བདག་ཉིད་དུ་སྣང་བ་ནི་རྣམ་པར་བརྟགས་པའི་གཟུགས་ཞེས་བྱ་བའི་ཐ་ཚིག་གོ། །དེ་བཞིན་དུ་ཚོར་བ་ལ་སོགས་པ་ལ་ཡང་སྦྱར་བར་བྱའོ། །

དེའི་འོག་ཏུ་ཆོས་ཉིད་ཀྱི་གཟུགས་ནི་དེ་བཞིན་གཤེགས་པ་རྣམས་བྱུང་ཡང་རུང་མ་བྱུང་ཡང་རུང་ཞེས་བྱ་བ་ལ་སོགས་པ་གསུངས་ཏེ། དེ་བཞིན་གཤེགས་པ་རྣམས༌[^2231]བྱུང་ཡང་རུང་ཞེས་བྱ་བ༌[^2232]འདིས་ཆོས་ཉིད་དེ་ངོ་བོ་ཉིད་ཡིན་གྱི་མི་རྟག་པ་ནི་མ་ཡིན་ནོ་ཞེས་བསྟན་པ་དེ།[^2233] གང་ཀུན་བརྟགས་པའི་གཟུགས་དེས་རྣམ་པར་བརྟགས་པའི་གཟུགས་དེ༌[^2234]རྟག་པ་རྟག་པའི་དུས་དང་། ཐེར་ཟུག་ཐེར་ཟུག་གི་དུས་སུ་ངོ་བོ་ཉིད་མེད་པ་ཁོ་ན་ཞེས་བྱ་བ་དེ་ལ། ཆོས་ཉིད་ཀྱི་གཟུགས་ཞེས་བྱ་བ་ནི་གང་གི་ཚེ་རྣམ་པར་མི་རྟོག་པའི༌[^2235]བློ་ལ་སྣང་བའི་རྣམ་པ་དེ་ཉིད་སྔར་སྨོས་པའི་ཀུན་བརྟགས་པ་བརྗོད་པར་བྱ་བ་དང་། བརྗོད་པར༌[^2236]བྱེད་པའི་རྣམ་པས་འདུ་ཤེས་དང་། གདགས་པར་འོས་པའི་བདག་ཉིད་དང་བྲལ་བར་གྱུར་པ་དེའི་ཚེ། བདག་ཉིད་ཀྱི༌[^2237]བརྗོད་དུ་མེད་པ་རྣམ་པར་མི་རྟོག་པའི་བདག་ཉིད་དུ་གནས་པའི་རྣམ་པ་དེ་ལ་ཆོས་ཉིད་ཀྱི་གཟུགས་ཞེས་བྱའོ། །ངོ་བོ་ཉིད་མེད་པ་ཞེས་བྱ་བ་ནི་ཀུན་བརྟགས་པའི་ངོ་བོ་ཉིད་མེད་པའི་ཕྱིར་རོ། །ཆོས་ལ་བདག་མེད་པ་ཞེས་བྱ་བ་ནི་ཆོས་ཀྱི་བདག་ཉིད་ཀྱི་རྣམ་པ་མེད་པའོ། །དེ་བཞིན་ཉིད་ཅེས་བྱ་བ་ནི་ཕྱིན་ཅི་མ་ལོག་པའི་རྣམ་པའོ། །ཡང་དག་པའི་མཐའ་ཞེས་བྱ་བ་ནི་རྣམ་པ་དེ་ལྟ་བུའི་མཐར་ཐུག་པའོ། །དེ་བཞིན་དུ་ཚོར་བ་ལ་སོགས་པ་ལ་ཡང༌[^2238]སྦྱར་བར་བྱའོ། །

དེའི་འོག་ཏུ་རྣམ་པ་གཉིས་ནི་འདུ་བྱེད་ཀྱི་མཚན་མའི་དངོས་པོ་དེ་རྣམ་པར་རྟོག་པ་ཙམ་གྱི་ཆོས་ཉིད་ལ་གནས་པའི་རྣམ་པར་རྟོག༌[^2225]པ་ལ་བརྟེན་ནས་མངོན་པར་བརྗོད་དེ་ཞེས་བྱ་བ་ལ་སོགས་པས་སྟོན་ཏེ། བྱིས་པ་སོ་སོའི་སྐྱེ་བོ་རྣམས་ཀྱི་སེམས་ཉོན་མོངས་པ་དང་། ལས་དང༌[^2226]རྣམ་པར་སྨིན་པ་ལ་སོགས་པའི་རྒྱུ་དང་རྐྱེན་གྱིས་ཕྱིན་ཅི་ལོག་ཏུ་གྱུར་པ་རྣམས་ལ་དངོས་པོའི་རྣམ་པར་བློ་སྐྱེ་ཞིང་སྣང་བ་ནི༌[^2227]རྣམ་པར་བརྟགས་པའི་གཟུགས་ཞེས་བྱའོ། །འདུ་བྱེད་ཀྱི་མཚན་མའི་དངོས་པོ་དེ་ཞེས་བྱ་བ་ལ་སོགས་པས་དེ་སྟོན་ཏེ། རྣམ་པར་རྟོག་པ་ཙམ་གྱི་ཆོས་ཉིད༌[^2228]ལ་གནས་པ་ཞེས་བྱ་བ་ནི་བློས༌[^2229]རྣམ་པར་བརྟགས་པའི་རྣམ་པ་མ་གཏོགས༌[^2230]པར་ངོ་བོ་ཉིད་གཞན་མེད་དེ། དེ་བས་ན་དངོས་པོ་དེ་རྣམ་པར་བརྟགས་པ་ཙམ་གྱི་ངོ་བོ་ཉིད་ལ་གནས་ཏེ། དེ་ལ་གནས་པ་དེ་ཉིད་ལ་རྣམ་པར་རྟོག་པ་ཞེས་བྱའོ། །དེ་ལྟར་བློས་རྣམ་པར་བརྟགས་པའི་རྣམ་པ་ཙམ་གྱི་ངོ་བོ་ཉིད་ལ་གནས་པ་རྣམ་པར་རྟོག་པ་དེ་ཉིད་ལ་བརྟེན་ཏེ་ཉེ་བར་བཟུང་ནས། གང་མངོན་པར་བརྗོད་པ་དང་འབྲེལ་པ་དངོས་པོའི་བདག་ཉིད་དུ་ཀུན་ཏུ་གཡེངས་པའི་རྣམ་པ་ལ་མངོན་པར་བརྗོད་པ་ཞེས་བྱ་སྟེ། དེ་ལྟར་བློས་རྣམ་པར་བརྟགས་པའི་རྣམ་པའི་ངོ་བོ་ཉིད་དུ་གནས་པ་ཞེས་བྱ་བའི་རྣམ་པ་ལ་བརྟེན་ནས་བློ་ལ་དངོས་པོའི་བདག་ཉིད་དུ་སྣང་བ་ནི་རྣམ་པར་བརྟགས་པའི་གཟུགས་ཞེས་བྱ་བའི་ཐ་ཚིག་གོ། །དེ་བཞིན་དུ་ཚོར་བ་ལ་སོགས་པ་ལ་ཡང་སྦྱར་བར་བྱའོ། །

#### ཆོས་ཉིད་ཀྱི་གཟུགས། ^2-2-3-0

[Block 2096 — OVER_LENGTH (251 syllables)]

#### བསམ་གྱིས་མི་ཁྱབ་པའི་སྐྱེ་བ། ^2-6-1-0

[Block 2129 — OVER_LENGTH (335 syllables)]
དེ་ལ་གང་ཉན་ཐོས་ཀྱི་རིགས་མ་ངེས་པ་དེ་དག་ནི། གལ་ཏེ་དེ་བཞིན་གཤེགས་པ་དང་ཉེ་བར་གྱུར་ན། དེའི་ཚེ་དེ་བཞིན་གཤེགས་པས་དེ་དག་གི་རིགས་ཀྱི་ཁྱད་པར་ལ་གཟིགས་ནས། ཇི་ལྟར་དེ༌[^2304]བླ་ན་མེད་པ་ཡང་དག་པར་རྫོགས་པའི་བྱང་ཆུབ་ལ་འདོད་པ་བསྐྱེད་པ༌[^2305]དེ་ལྟ་བུའི་ཆོས་བཤད་པ་མཛད་ནས། དེ་ལྟ་བུའི་ལམ་ལ་སྦྱོར་ཏེ།[^2306] འདོད་པ་དེ་ཡོངས་སུ་མ་བཏང་བར་ཡང་དག་པའི་མཐའ་མངོན་སུམ་དུ་བྱས་ནས།[^2307] རྒྱུན་དུ་ཞུགས་པའི་འབྲས་བུ་ལ་སོགས་པ་ཐོབ་པར་བྱེད་དོ། །དེ་ལྟར་སངས་རྒྱས་རྣམས་ཐབས་མཁས་པའི་ཕྱིར་ཤེས་རབ་ཀྱི་ཕ་རོལ་ཏུ་ཕྱིན་པའི་ཚུལ་གྱིས་དེ་དག་ཐམས་ཅད་མཁྱེན་པ་ཉིད་ཀྱི་ལམ་ལ་བཀོད་ནས། སློབ་པའམ་མི་སློབ་པར་གྱུར་པ༌[^2308]ལ། བླ་ན་མེད་པ་ཡང་དག་པར་རྫོགས་པའི་བྱང་ཆུབ་ལ་འདོད་པ་མ་བཏང་བས་མྱ་ངན་ལས་འདས་པ་མངོན་དུ་བྱེད་ཀྱང་ངེས་པའི་ཉན་ཐོས་ལྟར། དེ་ལ་ཤིན་ཏུ་དྲག་པོའི་མོས་པ་མི་སྐྱེད༌[^2309]དེ། དཔེར་ན་ལ་ལ་ཞིག་གྲོང་ངམ་གྲོང་ཁྱེར་ལ་ལྟ་བ་ན། དེ་ཉིད་དུ་གནས་པར་བྱའོ་སྙམ་དུ་བསམས་ཏེ་བལྟས་ན་ནི། དེར་མོས་པར༌[^2310]མོས་པ་གཞན་དུ་འགྱུར་རོ། །གཞན་དུ་འགྲོའོ་སྙམ་དུ་བསམས་ཏེ། བལྟས་ན་ནི་བློ་གཞན་དུ་འགྱུར་རོ། །དེ་བཞིན་དུ་འདིར་ཡང་ཡང་དག་པར་རྫོགས་པའི་བྱང་ཆུབ་འདོད་ན༌[^2311]ནི། མྱ་ངན་ལས་འདས་པ་ལ་འདོད་པ་རྣམ་པ་གཞན་དུ་འགྱུར་ལ། ངེས་པའི་ཉན་ཐོས་རྣམས་ཀྱང་རྣམ་པ་གཞན་དུ་འགྱུར་རོ། །དེ་བས་ན་ཉོན་མོངས་པ་སྤངས་ཀྱང་ལ་ལ་བག་ཆགས་ལ་སོགས་པའི་དབང་གིས་ཁྱད་པར་དུ་འགྱུར་ཏེ། སྙིང་རྗེའི་བསམ་པའི་དབང་གིས་ཀྱང་། དེ་དག་འཁོར་བས་ཤིན་ཏུ་སྐྱོ་བར་མི་འགྱུར་ལ། སེམས་ཅན་ལ་ཕན་པ་བྱེད་པར་འདོད་པ་རྣམས་ནི་བུ་གཞོན་ནུ་མི་གཙང་བའི་དོང་དུ་ལྟུང་བ་འབྱིན་པར་འདོད་པས་མི་གཙང་བའི་དོང་ལ་བལྟ༌[^2312]ཡང་། དེས་སྐྱོ་བར་མི་འགྱུར་བ་བཞིན་ནོ། །

སློབ་པའམ་མི་སློབ་པ་དེ་ལྟ་བུར་གྱུར་པ་དེ་དག་ནི་དེ་བཞིན་གཤེགས་པའི་མན་ངག་གིས་འཇིག་རྟེན་ལས་འདས་པ་ཟག་པ་མེད་པ། འཕགས་པའི་ལམ་ལ་སོགས་པའི་དགེ་བའི་རྩ་བ་རྣམས་འདི་ལྟར་ཡོངས་སུ་སྔོ་བར༌[^2313]བྱེད་དེ། གང་བདག༌[^2314]གི་དགེ་བའི་རྩ་བ་འཇིག་རྟེན་ལས་འདས་པ་ཟག་པ་མེད་པ་དེ་དག་ཐམས་ཅད་སེམས་ཅན་ལ་ཕན་པའི་ཕྱིར་འཁོར་བར་སྐྱེ་བ་ལ་མངོན་དུ་ཕྱོགས་པར་གྱུར་ཅིག་ཅེས་ཡོངས་སུ་བསྔོའོ། །དེ་དག་དེ་ལྟར་ཡོངས་སུ་བསྔོས་པའི་དབང་གིས་ལམ་ལ་སོགས་པ་ཟག་པ་མེད་པའི་དགེ་བ་རྣམས་ཀྱིས་འཁོར་བར་སྐྱེ་བར་བྱེད་དེ། དེ་དག་ལ་ཡང་ལྷན་ཅིག་བྱེད་པའི་རྐྱེན་དུ་གྱུར་པ་ཉོན་མོངས་པ་དང་འདྲ་བའི་དགེ་བའི་ཆོས་རྣམས་ཡོད་དེ། འདི་ལྟར་མདོ་སྡེ་གཞན་དག་ལས་བློ་གྲོས་རྒྱ་མཚོ་འཁོར་བའི་རྒྱུན་བྱེད་ལ། དགེ་བའི་རྩ་བ་དང་མཚུངས་པར་ལྡན་པའི་ཉོན་མོངས་པ་དེ་དག་གང་ཞེ་ན། འདི་ལྟ་སྟེ་བསོད་ནམས་ཀྱི་ཚོགས་བཙལ་བས་ཡོངས་སུ་མི་ངོམས་པ་དང་། བསམས་བཞིན་དུ་སྲིད་པར་སྐྱེ་བ་ཡོངས་སུ་འཛིན་པ་དང་། སངས་རྒྱས་དང་ཕྲད་པར་སྨོན་པ་དང་། སེམས་ཅན་ཡོངས་སུ་སྨིན་པར་བྱ་བ་ལ་ཡོངས་སུ་མི་སྐྱོ་བ་དང་། དམ་པའི་ཆོས་ཡོངས་སུ་འཛིན་པ་ལ་བརྩོན་པ་དང་། སེམས་ཅན་གྱི་བྱ་བ་ཅི་ཡོད་སྙམ་པ་ལ་སྤྲོ་བ་དང་། ཆོས་འདོད་པའི་བག་ལ་ཉལ་མི་འདོར་བ་དང་། ཕ་རོལ་ཏུ་ཕྱིན་པ་ལ་སྦྱོར་བ་རྣམས་ཡོངས་སུ་མི་གཏོང་བའོ། །བློ་གྲོས་རྒྱ་མཚོ་དེ་དག་ནི་དགེ་བའི་རྩ་བ་དང་མཚུངས་པར་ལྡན་པའི་ཉོན་མོངས་པ་རྣམས་ཏེ། བྱང་ཆུབ་སེམས་དཔའ་དེ་དག་གིས་འདྲེ༌[^2315]ཡང་། ཉོན་མོངས་པའི་སྐྱོན་རྣམས་ཀྱིས༌[^2316]མི་གོས་སོ། །གསོལ་པ་བཅོམ་ལྡན་འདས་དགེ་བའི་རྩ་བ་ལགས་ན་ཅིའི་སླད་དུ་ཉོན་མོངས་པ་རྣམས་ཞེས་བགྱི། བཀའ་སྩལ་པ། བློ་གྲོས་རྒྱ་མཚོ་འདི་ལྟར་ཉོན་མོངས་པ་དེ་ལྟ་བུ༌[^2317]དག་གིས་བྱང་ཆུབ་སེམས་དཔའ་ཁམས་གསུམ་དང་འདྲེ་ཞིང་། ཁམས་གསུམ་པ་ནི་ཉོན་མོངས་པ་ལས་བྱུང་བ་ཡིན་པས་དེ་ལ་བྱང་ཆུབ་སེམས་དཔའ་ནི་ཐབས་མཁས་པ་དང་། དགེ་བའི་རྩ་བའི་སྟོབས་བསྐྱེད་པས༌[^2318]བསམས་བཞིན་དུ་ཁམས་གསུམ་དུ་འདྲེའོ།[^2319] །དེའི་ཕྱིར་དགེ་བའི་རྩ་བ་དང་མཚུངས་པར་ལྡན་པའི་ཉོན་མོངས་པ་ཞེས་བྱ་སྟེ། ཁམས་གསུམ་དུ་འདྲེས་པས༌[^2320]དེ་སྐད་བྱའི༌[^2321]སེམས་ཉེ་བར་ཉོན་མོངས་པས་ནི་མ་ཡིན་ནོ་ཞེས་གསུངས་པ་ལྟ་བུའོ། །དེ་བས་ན་དེ་ལྟར་ཡོངས་སུ་བསྔོས་པའི་མཐུས་ཟག་པ་མེད་པའི་དགེ་བའི༌[^2322]རྩ་བ་རྣམས་ཀྱིས་སྲིད་པར་སྐྱེའོ་ཞེས་བྱའོ། །

དེ་ལ་གང་ཉན་ཐོས་ཀྱི་རིགས་མ་ངེས་པ་དེ་དག་ནི། གལ་ཏེ་དེ་བཞིན་གཤེགས་པ་དང་ཉེ་བར་གྱུར་ན། དེའི་ཚེ་དེ་བཞིན་གཤེགས་པས་དེ་དག་གི་རིགས་ཀྱི་ཁྱད་པར་ལ་གཟིགས་ནས། ཇི་ལྟར་དེ༌[^2304]བླ་ན་མེད་པ་ཡང་དག་པར་རྫོགས་པའི་བྱང་ཆུབ་ལ་འདོད་པ་བསྐྱེད་པ༌[^2305]དེ་ལྟ་བུའི་ཆོས་བཤད་པ་མཛད་ནས། དེ་ལྟ་བུའི་ལམ་ལ་སྦྱོར་ཏེ།[^2306] འདོད་པ་དེ་ཡོངས་སུ་མ་བཏང་བར་ཡང་དག་པའི་མཐའ་མངོན་སུམ་དུ་བྱས་ནས།[^2307] རྒྱུན་དུ་ཞུགས་པའི་འབྲས་བུ་ལ་སོགས་པ་ཐོབ་པར་བྱེད་དོ། །དེ་ལྟར་སངས་རྒྱས་རྣམས་ཐབས་མཁས་པའི་ཕྱིར་ཤེས་རབ་ཀྱི་ཕ་རོལ་ཏུ་ཕྱིན་པའི་ཚུལ་གྱིས་དེ་དག་ཐམས་ཅད་མཁྱེན་པ་ཉིད་ཀྱི་ལམ་ལ་བཀོད་ནས། སློབ་པའམ་མི་སློབ་པར་གྱུར་པ༌[^2308]ལ། བླ་ན་མེད་པ་ཡང་དག་པར་རྫོགས་པའི་བྱང་ཆུབ་ལ་འདོད་པ་མ་བཏང་བས་མྱ་ངན་ལས་འདས་པ་མངོན་དུ་བྱེད་ཀྱང་ངེས་པའི་ཉན་ཐོས་ལྟར། དེ་ལ་ཤིན་ཏུ་དྲག་པོའི་མོས་པ་མི་སྐྱེད༌[^2309]དེ། དཔེར་ན་ལ་ལ་ཞིག་གྲོང་ངམ་གྲོང་ཁྱེར་ལ་ལྟ་བ་ན། དེ་ཉིད་དུ་གནས་པར་བྱའོ་སྙམ་དུ་བསམས་ཏེ་བལྟས་ན་ནི། དེར་མོས་པར༌[^2310]མོས་པ་གཞན་དུ་འགྱུར་རོ། །གཞན་དུ་འགྲོའོ་སྙམ་དུ་བསམས་ཏེ། བལྟས་ན་ནི་བློ་གཞན་དུ་འགྱུར་རོ། །དེ་བཞིན་དུ་འདིར་ཡང་ཡང་དག་པར་རྫོགས་པའི་བྱང་ཆུབ་འདོད་ན༌[^2311]ནི། མྱ་ངན་ལས་འདས་པ་ལ་འདོད་པ་རྣམ་པ་གཞན་དུ་འགྱུར་ལ། ངེས་པའི་ཉན་ཐོས་རྣམས་ཀྱང་རྣམ་པ་གཞན་དུ་འགྱུར་རོ། །དེ་བས་ན་ཉོན་མོངས་པ་སྤངས་ཀྱང་ལ་ལ་བག་ཆགས་ལ་སོགས་པའི་དབང་གིས་ཁྱད་པར་དུ་འགྱུར་ཏེ། སྙིང་རྗེའི་བསམ་པའི་དབང་གིས་ཀྱང་། དེ་དག་འཁོར་བས་ཤིན་ཏུ་སྐྱོ་བར་མི་འགྱུར་ལ། སེམས་ཅན་ལ་ཕན་པ་བྱེད་པར་འདོད་པ་རྣམས་ནི་བུ་གཞོན་ནུ་མི་གཙང་བའི་དོང་དུ་ལྟུང་བ་འབྱིན་པར་འདོད་པས་མི་གཙང་བའི་དོང་ལ་བལྟ༌[^2312]ཡང་། དེས་སྐྱོ་བར་མི་འགྱུར་བ་བཞིན་ནོ། །

ལ་ལ་ནི་དགེ་བའི་བཤེས་གཉེན་ལ་བརྟེན་པའི་མཐུས། དེ་ལྟ་བུའི་སྨོན་ལམ་གྱི་ཁྱད་པར་དག་ཐོག་མ་ནས་བསྩགས་པར་གྱུར་ཏེ། དེ་དག་གི་སྨོན་ལམ་དེ་དག་རྣམ་པར་སྨིན་པའི་བདག་ཉིད་དུ་གྱུར་ནས་ཡོངས་སུ་བསྔོས་པའི་སྐྱེ་བ་དག་སྒྲུབ་པར་བྱེད་དེ། དེ་ནི་ཡོངས་སུ་བསྔོས་པའི་སྐྱེ་བ་ཞེས་བྱའོ། །

འོ་ན་དེ་དག་ཅིའི་ཕྱིར་རྒྱུན་དུ་ཞུགས་པའི་འབྲས་བུ་ལ་སོགས་པ་མ་ཐོབ་པར། བྱང་ཆུབ་ཀྱི་ཕྱོགས༌[^2323]ཡོངས་སུ་རྫོགས་པར་མི་བྱེད་ཅེ་ན། [^2324]མེད་པའི་ཕྱིར་ཏེ། འདི་ལྟར་དེ་དག་ནི་ཉོན་མོངས་པ་ཤས་ཆེ་ལ་དབང་པོ་རྟུལ༌[^2325]ཏེ། དབང་པོ་སྦྱང་བར་བྱ་བ་དང་། ཉོན་མོངས་པ་སྤངས་པ་མེད་པར་བྱང་ཆུབ་ཀྱི་ཚོགས་ཡོངས་སུ་རྫོགས་པར་བྱེད་མི་ནུས་ཏེ། དེ་བས་ན་དེ་བཞིན་གཤེགས་པ་ཐབས་མཁས་པས་དེ་དག་ལ་དེ་ལྟ་བུའི་མཐུ་མཆོག་དང་ལྡན་པར་མཛད་དོ། །

[Block 2136]
ཇི་སྐད་དུ་མདོ་སྡེ་གཞན་དག་ལས། བཅོམ་ལྡན་འདས་དེ་བཞིན་གཤེགས་པས་ཉན་ཐོས་རྣམས་བླ་ན་མེད་པ་ཡང་དག་པར་རྫོགས་པའི་བྱང་ཆུབ་ཏུ་ལུང་བསྟན་པ་དེ་དག་ཇི་ལྟར་བལྟ་བར་བགྱི། བཅོམ་ལྡན་འདས་ཀྱིས་བཀའ་སྩལ་པ། རིགས་ཀྱི་བུ་ངས་ཉན་ཐོས་རྣམས་བླ་ན་མེད་པ་ཡང་དག་པར་རྫོགས་པའི་བྱང་ཆུབ་ཏུ་ལུང་བསྟན་པ་གང་ཡིན་པ་དེ་དག་ནི། རིགས་ལ་བལྟས་ཏེ་ལུང་བསྟན་པའོ། །གསོལ་པ་བཅོམ་ལྡན་འདས། ཉན་ཐོས་ཟག་པ་མ་མཆིས་པ་སྲིད་པར་ཀུན་དུ་སྦྱོར་བ་རྒྱུན་བཅད་པ་རྣམས་རིགས་མཆིས་སུ་ལགས་ཀྱང་ཇི་ལྟར་བླ་ན་མེད་པ་ཡང་དག་པར་རྫོགས་པའི་བྱང་ཆུབ་མངོན་པར་རྫོགས་པར་འཚང་རྒྱ་བར་འགྱུར། བཅོམ་ལྡན་འདས་ཀྱིས་བཀའ་སྩལ་པ། རིགས་ཀྱི་བུ་དེ་བས་དཔེ་བསྟན་གྱི༌[^2326]ཉོན་ཅིག །རིགས་ཀྱི་བུ་འདི་ལྟ་སྟེ་དཔེར་ན་རྒྱལ་པོ་རྒྱལ་རིགས་སྤྱི་བོ་ནས་དབང་བསྐུར་བ་ལ་བུ་ཞིག་ཡོད་དེ། དེ་ཡང་བཟོའི༌[^2327]གནས་ཐམས་ཅད་ལ་སློབ་པ་ལས། དེ༌[^2328]དབང་པོ་རྟུལ༌[^2329]ཞིང་དབང་པོ་རྣོ་བ་མ་ཡིན་པས། ཕྱིས་བསླབ་པར་བྱ་བ་གང་ཡིན་པ་དེ་ནི་སྔར་སློབ། སྔར་བསླབ་པར་བྱ་བ་གང་ཡིན་པ་དེ་ནི་ཕྱིས་སློབ་པར་བྱེད་ན། རིགས་ཀྱི་བུ་དེ་ཇི་སྙམ་དུ་སེམས། ཅིའི་རྒྱུ་དེས་རྒྱལ་པོའི་བུ་མ་ཡིན་ཞེས་བྱ་བའམ། གསོལ་པ་བཅོམ་ལྡན་འདས་དེ་ནི་མ་ལགས་སོ། །བདེ་བར་གཤེགས་པ་དེ་ནི་མ་ལགས་ཏེ། བཅོམ་ལྡན་འདས་དེ་རྒྱལ་པོའི་བུ་ཉིད་ལགས་སོ་ཞེས་བགྱིའོ། །རིགས་ཀྱི་བུ་དེ་དེ༌[^2330]བཞིན་དུ་བྱང་ཆུབ་སེམས་དཔའ་དབང་པོ་རྟུལ་པོ༌[^2331]རིགས་དང་ལྡན་པ་རྣམ་པ་བསྒོམ༌[^2332]པའི་ལམ་གྱིས་སྔར་ཉོན་མོངས་པ་རྣམས་ཟད་པར་བྱས་ནས། ཕྱིས་བླ་ན་མེད་པ་ཡང་དག་པར་རྫོགས་པའི་བྱང་ཆུབ་མངོན་པར་རྫོགས་པར༌[^2333]འཚང་རྒྱ་བར་བྱེད་ན། རིགས་ཀྱི་བུ་དེ་ཇི་སྙམ་དུ་སེམས་རྒྱུ་དེས་མངོན་པར་རྫོགས་པར་སངས་མ་རྒྱས་ཞེས་བྱ་བའམ། གསོལ་པ་བཅོམ་ལྡན་འདས་དེ་ནི་མ་ལགས་སོ། །བདེ་བར་གཤེགས་པ་དེ་ནི་མ་ལགས་སོ་ཞེས་བྱ་བ་ལ་སོགས་པ་གསུངས་པ་ལྟ་བུའོ། །དེ་བས་ན་དེ་ལྟར་སྐྱེ་བ་རྣམ་པ་གསུམ་གྱི་དབང་གིས་སྐྱེས་ནས་བྱང་ཆུབ་ཀྱི་ཚོགས་ཡོངས་སུ་རྫོགས་པར་བྱེད་དོ། །

## མཇུག་བྱང། ^b-0

──────────────────────────────────────────────────

[Block 2134]
ལ་ལ་ནི་དགེ་བའི་བཤེས་གཉེན་ལ་བརྟེན་པའི་མཐུས། དེ་ལྟ་བུའི་སྨོན་ལམ་གྱི་ཁྱད་པར་དག་ཐོག་མ་ནས་བསྩགས་པར་གྱུར་ཏེ། དེ་དག་གི་སྨོན་ལམ་དེ་དག་རྣམ་པར་སྨིན་པའི་བདག་ཉིད་དུ་གྱུར་ནས་ཡོངས་སུ་བསྔོས་པའི་སྐྱེ་བ་དག་སྒྲུབ་པར་བྱེད་དེ། དེ་ནི་ཡོངས་སུ་བསྔོས་པའི་སྐྱེ་བ་ཞེས་བྱའོ། །

[Block 2135]
འོ་ན་དེ་དག་ཅིའི་ཕྱིར་རྒྱུན་དུ་ཞུགས་པའི་འབྲས་བུ་ལ་སོགས་པ་མ་ཐོབ་པར། བྱང་ཆུབ་ཀྱི་ཕྱོགས༌[^2323]ཡོངས་སུ་རྫོགས་པར་མི་བྱེད་ཅེ་ན། [^2324]མེད་པའི་ཕྱིར་ཏེ། འདི་ལྟར་དེ་དག་ནི་ཉོན་མོངས་པ་ཤས་ཆེ་ལ་དབང་པོ་རྟུལ༌[^2325]ཏེ། དབང་པོ་སྦྱང་བར་བྱ་བ་དང་། ཉོན་མོངས་པ་སྤངས་པ་མེད་པར་བྱང་ཆུབ་ཀྱི་ཚོགས་ཡོངས་སུ་རྫོགས་པར་བྱེད་མི་ནུས་ཏེ། དེ་བས་ན་དེ་བཞིན་གཤེགས་པ་ཐབས་མཁས་པས་དེ་དག་ལ་དེ་ལྟ་བུའི་མཐུ་མཆོག་དང་ལྡན་པར་མཛད་དོ། །
