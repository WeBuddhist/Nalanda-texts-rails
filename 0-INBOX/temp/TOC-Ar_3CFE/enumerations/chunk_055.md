Enumeration Block 1:
མངོན་པར་ཤེས་པ་དྲུག་གང་ཞེ་ན། རྫུ་འཕྲུལ་གྱི་མངོན་པར་ཤེས་པ་དང་། ལྷའི་མིག་དང་། ལྷའི་རྣ་བ་དང་། ཕ་རོལ་གྱི་སེམས་ཤེས་པ་དང་། སྔོན་གྱི་གནས་རྗེས་སུ་དྲན་པ་དང་། ཟག་པ་ཟད་པ་ཤེས་པ་མངོན་སུམ་དུ་བྱེད་པའི་མངོན་པར་ཤེས་པའོ། །

Enumeration Block 2:
སོ་སོ་ཡང་དག་པར་རིག་པ་བཞི་ལ།

Enumeration Block 3:
རྣམ་པ་ཐམས་ཅད་དུ་ཡོངས་སུ་དག་པ་བཞི་གང་ཞེ་ན།

Enumeration Block 4:
དབང་བཅུ་གང་ཞེ་ན།

Enumeration Block 5:
སྟོབས་བཅུ་ནི་འདི་ལྟ་སྟེ། གནས་དང་གནས་མ་ཡིན་པ་མཁྱེན་པའི་སྟོབས་དང་། ལས་ཀྱི་རྣམ་པར་སྨིན་པ་མཁྱེན་པའི་སྟོབས་དང་། བསམ་གཏན་དང་། ཏིང་ངེ་འཛིན་དང་སྙོམས་པར་འཇུག་པ་མཁྱེན་པའི་སྟོབས་དང་། དབང་པོ་མཆོག་དང་མཆོག་མ་ཡིན་པ༌[^2449]མཁྱེན་པའི་སྟོབས་དང་། མོས་པ་སྣ་ཚོགས་མཁྱེན་པའི་སྟོབས་དང་། ཁམས་སྣ་ཚོགས་མཁྱེན་པའི་སྟོབས་དང་། ཐམས་ཅད་དུ་འགྲོ་བའི་ལམ་མཁྱེན་པའི་སྟོབས་དང་། འཆི་འཕོ་བ༌[^2450]དང་སྐྱེ་བ་མཁྱེན་པའི་སྟོབས་དང་། སྔོན་གྱི་གནས་རྗེས་སུ་དྲན་པ་མཁྱེན་པའི་སྟོབས་དང་། ཟག་པ་ཟད་པ་མཁྱེན་པའི་སྟོབས་སོ། །

Enumeration Block 6:
མི་འཇིགས་པ་བཞི་ནི།

Enumeration Block 7:
བསྲུང་བ་མེད་པ་གསུམ་ནི་འདི་ལྟ་སྟེ།

Enumeration Block 8:
དྲན་པ་ཉེ་བར་གཞག་པ་གསུམ་ནི་འདི་ལྟ་སྟེ།

Enumeration Block 9:
སངས་རྒྱས་ཀྱི་ཆོས་མ་འདྲེས་པ་བཅོ་བརྒྱད་ནི་དེ་བཞིན་གཤེགས་པ་ལ་འཁྲུལ་པ་མི་མངའོ། །

ཅ་ཅོ་མི་མངའོ། །

དགོངས་པ་ཉམས་པ་མི་མངའོ། །

ཐུགས་མཉམ་པར་མ་བཞག་པ༌[^2469]མི་མངའོ། །

འདུ་ཤེས་སྣ་ཚོགས་པ་མི་མངའོ། །

སོ་སོར་མ་བརྟགས་པའི༌[^2470]བཏང་སྙོམས་མི་མངའོ། །

འདུན་པ་ཉམས་པ་མི་མངའོ། །

བརྩོན་འགྲུས་ཉམས་པ་མི་མངའོ། །

དྲན་པ་ཉམས་པ་མི་མངའོ། །

ཏིང་ངེ་འཛིན་ཉམས་པ་མི་མངའོ། །ཤེས་རབ་ཉམས་པ་མི་མངའོ། །

རྣམ་པར་གྲོལ་བ་ཉམས་པ་མི་མངའོ། །

འདས་པ་ལ་མ་ཆགས༌[^2471]མ་ཐོགས་པའི་ཡེ་ཤེས་འཇུག་གོ། །

ད་ལྟར་དང་། མ་འོངས་པ་ལ་མ་ཆགས་མ་ཐོགས༌[^2472]པའི་ཡེ་ཤེས་འཇུག་གོ། །

སྐུའི་ཕྲིན་ལས༌[^2473]ཐམས་ཅད་ཡེ་ཤེས་སྔོན་དུ་འགྲོ་ཞིང་ཡེ་ཤེས་ཀྱི་རྗེས་སུ་འབྲང་ངོ་། །གསུང་གི་ཕྲིན་ལས་ཐམས་ཅད་ཡེ་ཤེས་སྔོན་དུ་འགྲོ་ཞིང་ཡེ་ཤེས་ཀྱི་རྗེས་སུ་འབྲང་ངོ་། །ཐུགས་ཀྱི་ཕྲིན་ལས་ཐམས་ཅད་ཡེ་ཤེས་སྔོན་དུ་འགྲོ་ཞིང་ཡེ་ཤེས་ཀྱི་རྗེས་སུ་འབྲང་བ་སྟེ།
