Enumeration Block 1:
ད་ནི་མཐོང་བའི་ལམ་གྱི་མི་མཐུན་པའི་ཕྱོགས་གཟུང་བ་དང་འཛིན་པའི་རྣམ་པར་རྟོག་པ་རྣམ་པ་བཞི་པོ་གཉེན་པོ་དང་བཅས་པ་བརྗོད་པར་བྱ་བ་ཡིན་པ་དེས་ན།

Enumeration Block 2:
དེ་ལ་གཟུང་བའི་རྣམ་པར་རྟོག་པ་རྣམ་པ་གཉིས་ལས།

Enumeration Block 3:
འཛིན་པའི་རྣམ་པར་རྟོག་པ་ཡང་རྣམ་པ་གཉིས་ཡིན་པ་དེས་ན།

Enumeration Block 4:
དེ་ལྟར་ན་རྣམ་པར་རྟོག་པ་འདི་བཞི་ཆར་ཡང་རེ་རེ་ཞིང་རྣམ་པ༌[^1999]དགུར་ཤེས་པར་བྱའོ། །
དེ་ལ་གཟུང་བའི་རྣམ་པར་རྟོག་པ་དང་པོ་རྣམ་པ་དགུ་པོ་གང་ཡིན་ཞེ་ན།

Enumeration Block 5:
དེ་ལ་གཟུང་བའི་རྣམ་པར་རྟོག་པ་གཉིས་པ་ཇི་ལྟར་རྣམ་པ་དགུ་ཡིན་ཞེ་ན།

Enumeration Block 6:
ད་ནི་འཛིན་པའི་རྣམ་པར་རྟོག་པ་རྣམ་པ༌[^2018]གཉིས་པོ་རེ་རེ་ཞིང༌[^2019]དབྱེ་བ་རྣམ་པ་དགུར་འགྱུར་བ་བརྗོད་པར་བྱའོ། །
