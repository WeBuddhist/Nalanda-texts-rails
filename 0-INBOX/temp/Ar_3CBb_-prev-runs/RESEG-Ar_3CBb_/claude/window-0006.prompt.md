=== SYSTEM PROMPT ===
You are an expert in classical Tibetan Buddhist commentary (འགྲེལ་པ་) structure.

You are given a numbered list of blocks from a Tibetan verse commentary. A
rule-based segmenter has already cut them; most cuts are right. Your job is to
output the few merge/split operations that bring the blocks to the layout the
human editors of this vault use.

━━━ TARGET LAYOUT — one block per FUNCTIONAL UNIT ━━━

OPENER       A node's division announcement together with the first-child opener
             that follows it is ONE block:
               "<topic> ལ་གསུམ། A། B། C་འོ། །དང་པོ་ནི།"
             A sibling opener "གཉིས་པ་ <title> ནི།" is its own block.
ROOT QUOTE   A quoted root stanza is its own block. These blocks are tagged
             [VERSE]; they are protected — never include them in any operation.
EXPLANATION  The gloss that follows a quote ("ཞེས་པ་སྟེ། …", "ཞེས་པ་ནི། …", or a
             running explanation) is ONE block up to the next opener, quote or
             heading — even when it is long (100–250 syllables) and contains several
             sentence ends, a question and answer ("…ལོ། །གང་ལ་ན། …"), a side remark
             on a variant reading ("…ཞེས་འགྱུར་བཅོས་…"), a cross-reference
             ("འདི་དང་འོག་གི་ས་བཅད་…"), or a mantra cited in passing.
SECOND LEVEL A passage that re-reads the same stanza on another level — opening
             "སྦས་དོན་ནི།", "ངེས་དོན་ནི།", "ངེས་པའི་དོན་དུ།", "ཟབ་དོན་ནི།",
             "དེའི་ནང་གི་དོན་ལ།", "མཐར་ཐུག་གི་དོན་ནི།" or the like after the literal
             gloss — is its OWN block, never merged into the literal gloss before it
             (the editors keep the two readings apart). Within that passage, M1 applies.
FRAME        The namo line alone; each of the author's own verses one block;
             "སྨྲས་པ།" alone; the colophon ("ཅེས་ … སྦྱར་བའོ། །" + closing wishes) one block.

━━━ MERGE — adjacent blocks that are one unit ━━━

M1  CONTINUED EXPLANATION
    A block that goes on explaining the same quote/topic as the block before it —
    no new opener, no new quote, no new verse being treated — belongs to that block.
    This is the most common fix. Do NOT keep a cut just because a sentence ends.
    Exception: a SECOND LEVEL opener (see above) always starts a new block.
M2  INCOMPLETE SENTENCE
    A block ending in a connector (དང་། / ཞིང་། / ཅིང་། / ནས། / སྟེ། / ཏེ།) that
    the next block completes.
M3  OPENER CHAIN
    An enumeration block followed by "དང་པོ་ནི།" / "དང་པོ་ལ་ N།" (and further
    nested first-child enumerations) — merge them into one opener block.
M4  COLOPHON
    The parts of the closing colophon and its final wishes form one block.

━━━ SPLIT — one block that holds two units ━━━

S1  A new node opener (ordinal + title + "ནི།" or "ལ་ N།") buried mid-block:
    split before it.
S2  The treatment of a new verse/topic starts mid-block (e.g. "ཡང་ཕྱག་གང་ལ་འཚལ་ན"
    starting the next homage): split before it.
S3  An introductory opener "… ནི།" fused to the explanation of the PREVIOUS
    quote: split so the opener starts the next unit.

Never split a block only because it is long.

━━━ HEADING / VERSE BLOCKS — always KEEP ━━━

Blocks tagged [HEADING] or [VERSE] are NEVER part of any operation.

━━━ OUTPUT FORMAT ━━━

A JSON array of operations. Blocks not mentioned are kept as-is.

[
  {"op": "merge", "blocks": [N, M]},
  {"op": "merge", "blocks": [N, M, P]},
  {"op": "split", "block": N, "after": "<verbatim unique substring ending at split point>"},
  {"op": "split", "block": N, "after": ["<sub1>", "<sub2>", "<sub3>"]}
]

Rules for the output:
- Block numbers are CONTINUOUS and INCLUDE heading and verse blocks. You may only
  merge blocks with consecutive numbers (N and N+1). Never merge across a heading
  or a verse block, and never propose a merge whose numbers skip over one.
- Each block number appears in AT MOST ONE operation.
- For each "after" substring: copy a verbatim slice from the block that ends exactly
  at the split point and is UNIQUE within that block (10–20 characters is usually enough).
- If nothing needs to change in this window, output: []
- Output ONLY the JSON array. No explanation, no commentary, no code fences.

དེ་ལྟ་ཡིན་ན་ནི་རྒྱས་པ་དང་བསྡུས་པ་ཡང་མི་རིགས་སོ། །དེ་ཅིའི་ཕྱིར་ཞེ་ན། དོན་གྱི་རྣམ་པ་གཅིག་ལ་རྒྱ་ཆེ་བ་དང་ཆུང་བའི་བྱེ་བྲག་གིས་བསྡུས་པ་དང་རྒྱས་པར་འགྱུར་གྱི། དོན་ཐ་དད་པ་ལ་ནི་ནམ་ཡང་བསྡུས་པ་དང་རྒྱས་པ་མི་རིགས་སོ། །

[Block 699]
ཇི་སྟེ་གལ་ཏེ་ཡིན་ནོ་ཞེ་ན་ནི་ཧ་ཅང་ཡང་ཐལ་བར་འགྱུར་རོ། །

[Block 700]
མི་རྟོགས་པར་བྱ་བའི་ཕྱིར་ཡིན་ནོ་ཞེ་ན་ནི། འདི་ཅིའི་དབང་པོ་རྣོ་བའི་དབང་དུ་འམ། གདུག་སེམས་ཀྱིས་སྨྲས་ཞེས་རྟོག་གྲང་ན་རེ་ཞིག་དང་པོ་ལྟར་ན༌[^338]ནི་མ་ཡིན་ཏེ། ཚོགས་ཀྱི་གང་ཟག་ལ་སོགས་པ་གཟུང་བའི་ཕྱིར་རོ། །

[Block 701]
གཞན་ཡང་འདི་ཉིད་ལས།

[Block 702]
ཐུབ་པ་ཆེན་པོས་ཆོས་ཕུང་པོ། །ཞེས་བྱ་བ་ལ་སོགས་པ་གསུངས་པའི་ཕྱིར་རོ། །

[Block 703]
ཅི་སྟེ་ཕྱི་མ་ལྟར་ན་ཡང་མ་ཡིན་ཏེ། དེ་བཞིན་གཤེགས་པ་རྣམས་ནི་ཐུགས་རྗེ་ཆེན་པོའི་སྟོབས་ཀྱིས་འཇུག་པའི་ཕྱིར་རོ། །

[Block 704]
གདུག་སེམས་དང་སྙིང་རྗེ་ནི་གཅིག་གིས་གཅིག་སྤངས་པ་ཡིན་པའི་ཕྱིར་འགལ་བ་ཡིན་ནོ། །

[Block 705]
ཅི་སྟེ་དེ་ལྟ་ན་ཡང་ཡིན་ནོ་ཞེ་ན་ནི་ཧ་ཅང་ཡང་ཐལ་བར་འགྱུར་རོ་ཞེས་བྱ་བ་འདི་ཡང་བརྗོད་པར་བྱ་སྟེ། རེ་ཞིག་སྒྲ་དངོས་ཀྱི་ནུས་པའམ། དགོངས་ནས་བཤད་པའི་ནུས་པ་ཞེས་རྟོག་གྲང་ན། སྒྲ༌[^339]དངོས་ཀྱི་ནུས་པ་ལྟར་ན༌[^340]ནི་བདེན་ཏེ། དེ་ནི་མ་ཡིན་ནོ། །

[Block 706]
འདི་ནི་དེ་བཞིན་གཤེགས་པ་རྣམས་ཀྱིས་དགོངས་ནས་སྨྲས་པ་སྟེ་འདི་ཅི་ལ་དགོངས་ཤེ་ན། བཅོམ་ལྡན་འདས་ཉིད་ཀྱིས་ཀྱང་དང་པོ་བཤད་པ་བཞི་ལ་དགོངས་ནས་གསུངས་སོ། །

[Block 707]
དེས་དེ་ལྟར་འགྱུར་བ་ཡང་མ་ཡིན་ཏེ། ཐུགས་རྗེ་ཆེན་པོའི་དོན་དང་ལྡན་པའི་ཕྱིར་རོ། །

[Block 708]
དེ་ལྟ་ན་ནི་ཡང་ཡིན་ནོ་ཞེ་ན་མ་ཡིན་ཏེ། གསང་བ་འདི་ནི་སེམས་ཅན་ཐམས་ཅད་ཀྱི་ཐུན་མོང་དུ་མ་གྱུར་པའི་ཕྱིར་རོ། །

[Block 709]
ཡང་ན་འདི་ནི་ཕྱི་རབས་པའི་གང་ཟག་སློབ་དཔོན་དང་སློབ་མར་འབྲེལ་པར་བྱ་བའི་ཕྱིར་ཏེ། འོག་ནས་བཤད་པའི་ཕྱིར་རོ། །

[Block 710]
བླ་མ་ལ་རག་ལས་པ་ཉིད་ཅིའི་ཕྱིར་ཞེ་ན། རྩོད་པའི་དུས་ན་སེམས་ཅན་ཐམས་ཅད་འདོད་རྒྱལ་གྱི་ཞགས་པས་ཟིན་ཏེ་གཟུ་ལུམ༌[^341]ལ་མཆོག་ཏུ་གཞོལ་བར་འགྱུར་རོ། །

[Block 711]
གང་གི་ཚེ་གཟུ་ལུམ༌[^342]ལ་མཆོག་ཏུ་གཞོལ་བ་དེ་ནི་དེ་བཞིན་གཤེགས་པའི་བཀའ་ཡང་དག་པར་མྱུར་དུ་འཇུག་པར་འགྱུར་རོ། །

[Block 712]
གང་ཞིག་གང་མྱུར་དུ་ཞུགས་པ་དེས་ནི་དེ་མ་ཐག་ཏུ་དེ་ལ་སྐྱོ་བར་འགྱུར་རོ། །

[Block 713]
གང་ཞིག་གང་ལ་མྱུར་དུ་སྐྱོ་བ་སྐྱེ་བར་འགྱུར་བ་དེ་ནི་དེའི་བཀའ་མྱུར་དུ་སྤོང་བར་འགྱུར་རོ། །

[Block 714]
གང་གིས་གང་ཞིག་མྱུར་དུ་སྤངས་པར་གྱུར་པ་དེ་ནི་བསྟན་པ་ཡུན་རིང་དུ་གནས་པར་མི་བྱེད་དེ་ཡུན་ཐུང་བར་བྱེད་ཅེས་བྱ་བའི་དོན་ཏོ། །

[Block 715]
དེ་བས་ན་དེ་བཞིན་གཤེགས་པ་རྣམས་ནི་སློབ་དཔོན་དང་སློབ་མར་འབྲེལ་པར་བྱ་བ་དང་། བསྟན་པ་ཡུན་རིང་དུ་གནས་པར་བྱ་བ་དང་བསྟན་པ་བརྟན་པ་དང་། གང་ཟག་རྣམས་ཀྱི་བློ་ཟབ་ཅིང་རྒྱ་ཆེ་བར་བྱ་བའི་ཕྱིར་བཤད་པ་བཞི་ལ་དགོངས་ནས་གསུངས་པ་ཡིན་ནོ། །

[Block 716]
འདི་ཉིད་ནི་དེ་བཞིན་གཤེགས་པ་ཐམས་ཅད་ཀྱི་གསང་བ་མངོན་པར་གྲུབ་པ་ཞེས་བྱ་བའི་རྒྱུད་ལས་ཀྱང་།

[Block 717 [VERSE]]
དེ་བཞིན་གཤེགས་པ་ཐམས་ཅད་ཀྱི། །
གསང་བ་དེ་ཉིད་མངོན་གྲུབ་འདི། །
བདེ་གཤེགས་རྣམས་ཀྱིས་བསྟན་པ་རྣམས། །
ཡུན་རིང་གནས་པར་བྱ་བའི་ཕྱིར། །

[Block 718]
བཤད་པའི་མཆོག་ནི་རབ་སྦས་ཏེ། །བླ་མ་ལས་ནི་རྟོགས་པར་བྱ། །ཞེས་འབྱུང་བ་དང་། སློབ་དཔོན་གྱིས་ཀྱང་།

[Block 719]
བླ་མ་ལ་བརྙས་སྒྱུ་ཅན་དད་པ་མེད། །ཅེས་བྱ་བ་ལ་སོགས་པ་གསུངས་པའི་ཕྱིར་རོ། །

[Block 720]
གཞན་ཡང་གསང་བ་ཆེན་པོ་ཞེས་བྱ་བ་རྣལ་འབྱོར་ཆེན་པོའི་རྒྱུད་ལས་ཀྱང་། སེམས་དཔའ་ཆེན་པོ་འཇིག་རྟེན་གྱི་ཁམས་འདིར་རྩོད་པ་རྒྱས་པའི་དུས་འདིར༌[^343]སེམས་ཅན་གཟུ་ལུམ༌[^344]མཁན་བླ་མ་ལ་སྡང་བ་དང་། ཆོག་པར་འཛིན་པ་དང་། དེ་བཞིན་གཤེགས་པའི་བཀའ་ཟབ་མོ་ལ༌[^345]རང་འདོད་དུ་སྤྱོད་པ་འབྱུང་གི་དེ་ཡིས༌[^346]དེ་བཞིན་གཤེགས་པའི་བཀའ་ཟབ་ཅིང་རྒྱ་ཆེ་བ་རྟོགས་པར་མི་ནུས་སོ། །

[Block 721]
དེ་བས་ན་དེ་བཞིན་གཤེགས་པ་ཐམས་ཅད་ཀྱི་གསང་བ་ཆེན་པོ་འདི་ནི་ཐེག་པ་ཆེན་པོའི་རིགས་ཅན་གྱི་གང་ཟག་རྨད་དུ་བྱུང་བའི་ཡུལ་ཡིན་པར་འགྱུར་རོ། །

[Block 722]
དེ་ཡང་གང་ལས་ཤེས་ཤེ་ན་དེ་བཞིན་གཤེགས་པ་ཐམས་ཅད་ཀྱི་གསང་བའི་ལུང་ལས་ཤེས་པར་འགྱུར་ཏེ། ཇི་སྐད་དུ།

[Block 723 [VERSE]]
དེ་བཞིན་གཤེགས་པ་ཐམས་ཅད་ཀྱི། །
གསང་བ་ཆེན་པོའི་བདག་ཉིད་མཆོག །
རབ་ཏུ་གསང་བ་ཡིན་པའི་ཕྱིར། །
ཐམས་ཅད་ཀུན་གྱིས༌[^347]གསལ་མ་བྱས། །

[Block 724 [VERSE]]
གང་ཡང་དུས་གསུམ་སངས་རྒྱས་དང་། །
རྣལ་འབྱོར་རྣལ་འབྱོར་མ་རྣམས་ཀྱིས། །
གང་ཚེ་གསང་བའི་དོན་གསུངས་པ། །
ཕྱི་དང་ཤིན་ཏུ་ནང་དག་དང་། །

[Block 725 [VERSE]]
དེ་བཞིན་བླ་མེད་ལ་དགོངས་ནས། །
གསང་བའི་དོན་རྣམས་གསུངས་པ་ཡིན། །
དེ་ལས་གཞན་དུ་གསུངས་གྱུར་ན། །
ཇི་བཞིན་དོན་དུ་བཟུང་བ་སྟེ། །
དེས་ན་ལམ་ངན་དག་ཏུ་ལྟུང་། །
ཞེས་པ་ལ་སོགས་པ་འབྱུང་བ་ལྟ་བུའོ། །

[Block 726]
དེས་ན་དེ་བཞིན་གཤེགས་པའི་གསང་བ་ཆེན་པོ་འདི་ནི་རྣལ་འབྱོར་གྱི་རྒྱུད་རྣམས་ཀྱིས་ཤིན་ཏུ་རྒྱས་བཏབ་པ་ཡིན་ནོ་ཞེས་བསྟན་པར་བྱའོ། །

[Block 727]
གཞན་ཡང་གཞན་དུ་ཤེས་པར་བྱའོ། །

[Block 728]
དེ་ལྟར་ན༌[^348]བཤད་པ་བསྡུས་པ་དང་། དོན་བསྡུས་པ་བཤད་ནས། ད་ནི་དེ་ཉིད་ཀྱི་དོན་བསྡུས་པ་རྒྱས་པར་བཤད་པར་བྱ་སྟེ། དེའི་ཕྱིར་རིམ་པ་འདི་ཉིད་ཀྱིས་ན་བཞུགས་པའི་ཚིག་ནས་བརྩམས་ཏེ་ཞེས་བྱ་བ་སྨོས་ཏེ་འདིས་ནི་ཕྱག་རྒྱས་བཏབ་པ་ཡིན་ལ་ཞེས་སྦྱར་རོ། །གང་གིས་རྒྱས་བཏབ་ཅེ་ན། རིམ་པ་འདི་ཉིད་ཀྱིས་རྒྱས་བཏབ་ཅེས་སྨོས་སོ། །

[Block 729]
ཡང་ན་རིམ་པ་འདི་ཉིད་ཀྱིས་བཤད་པའི་ཕྱིར་རྒྱས་བཏབ་ཅེས་སྦྱར་རོ། །

[Block 730]
གང་རྒྱས་བཏབ་ཅེ་ན་བཞུགས་པའི་ཚིག་ནས་བརྩམས་ཏེ་རྗེས་སུ་ཡི་རང་བའི་བར་དུའོ། །

[Block 731]
མཐའ་རྣམ་པ་དྲུག་ཏུ་བཤད་པ་དང་ཞེས་བྱ་བ་ལ་སོགས་པ་ནི་བཤད་ཟིན་ཏོ། །

[Block 732]
དེ་ཉིད་ཀྱིས༌[^349]གསང་བ་འདུས་པའི་དོན་ཕྱག་རྒྱས་བཏབ་ཅེས་སྨོས་པས་ན་སྒྲ་ཕྱག་རྒྱས་བཏབ་པ་ནི་མ་ཡིན་ཏེ། དོན་གསལ་བར་མ༌[^350]བྱས་ཞེས་བྱ་བའི་དོན་ཏོ། །

[Block 733]
འདི་དག་ལ་མ་རྟོགས་པར་ཅིར་འགྱུར་ཞེ་ན། དེ་མ་རྟོགས་པར་ཞེས་བྱ་བ་ལ་སོགས་པ་སྨོས་ཏེ། དེ་ལ་མ་རྟོགས་པ་ནི་གོང་མ་ཉིད་མ་རྟོགས་པའོ། །

[Block 734]
འོ་ན་གང་ཞིག་ལ་བརྟེན་ཞེ་ན་སྒྲ་ཇི་བཞིན་པའི་བཤད་པའི་སྒྲའི་དོན་ཙམ་ལ་བརྟེན་ཏེ་ཞེས་སྨོས་སོ། །

[Block 735]
སྒྲ་ཇི་བཞིན་པར་བཤད་པ་ནི་སྒྲ་ཇི་བཞིན་པ་ཉིད་དེ་དེ་བཤད་པའི་དོན་གང་ཡིན་པ་དེ་ལ་དེ་སྐད་ཅེས་བྱའོ། །

[Block 736]
དེ་ལྟ་བུ་ལ་རྟོག་པའི༌[^351]སེམས་ཅན་གང་ཞིག་ཡིན་ཞེ་ན། ཡུལ་རྣམས་ལ་ཆགས་པའི་སེམས་ཅན་རྣམས་འགལ་བ་དང་། ཤིན་ཏུ་རྨད་དུ་བྱུང་བའི་བྱ་བ་བྱེད་པས་ལས་ཀྱི་དབང་དུ་འགྱུར་རོ་ཞེས་པ་ནི་ཡུལ་རྣམས་ལ་ཆགས་པ་ནི་ཡུལ་རྣམས་ལ་ཆགས་པ་སྟེ། ཡུལ་ལ་ཞེན་པར་གྱུར་པའི་ཐ་ཚིག་གོ། །

[Block 737]
ཡུལ་ལ་ཆགས་པ་ཡང་ཡིན་ལ་སེམས་ཅན་ཡང་ཡིན་པས་ཡུལ་རྣམས་ལ་ཆགས་པའི་སེམས་ཅན་དེ༌[^352]དེ་ལྟ་བུའི་གང་ཟག་གིས་དེ་ལ་དེ་ལྟར་རྟོག་ཅེས༌[^353]པའི་ཐ་ཚིག་གོ། །

[Block 738]
བརྟགས་པས་ཅི་བྱེད་ཅེ་ན་འགལ་བ་དང་ཤིན་ཏུ་རྨད་དུ་བྱུང་བའི་བྱ་བ་བྱེད་དེ། འདི་ལྟར་མ་བྱིན་པར་ལེན་པ་ལ་སོགས་པའི་བྱ་བ་ལ་འཇུག་པར་འགྱུར་རོ། །

[Block 739]
དེ་ཅིར་འགྱུར་ཞེ་ན། ལས་ཀྱི་དབང་དུ་འགྱུར་ཏེ། ལས་དེའི་སྟོབས་ཀྱིས་འབྲས་བུ་རྩུབ་མོ་ཉམས་སུ་མྱོང་བར་འགྱུར་རོ་ཞེས་བྱ་བའི་ཐ་ཚིག་གོ། །

[Block 740]
འདི་དག་གིས་ནི་འདི་སྐད་དུ་སྟོན་པར་འགྱུར་ཏེ་དེ་བཞིན་གཤེགས་པ་ཐམས་ཅད་ཀྱི་བཀའ་དགོངས་པ་དང་བཅས་ཏེ་བཤད་པར་མ་གྱུར་པ་དེའི་ཚེ་སྒྲ་ཇི་བཞིན་པར་ངེས་པར་འཛིན་པར་འགྱུར་རོ། །

[Block 741]
གང་གི་ཚེ་སྒྲ་ཇི་བཞིན་པར་ངེས་པར་བཟུང་བར་འགྱུར་བ༌[^354]དེའི་ཚེ་ཡུལ་ལ་ཆགས་པའི་སེམས་ཅན་འཇུག་པར་འགྱུར་རོ། །

[Block 742]
གང་གི་ཚེ་ཡུལ་ལ་ཆགས་པའི་སེམས་ཅན་ཞུགས་པར་གྱུར་པ་དེའི་ཚེ། དེ་བཞིན་གཤེགས་པའི་གདམས་ངག་དང་དུ་མི་ལེན་པར་འགྱུར་རོ། །

[Block 743]
གང་གི་ཚེ་དེ་བཞིན་གཤེགས་པའི་གདམས་ངག་དང་དུ་མི་ལེན་པར་གྱུར་པ་དེའི་ཚེ་དེ་བཞིན་གཤེགས་པའི་བཀའ་དགོངས་པ་ཅན་གཞན་ལ་ཡང་སྒྲ་ཇི་བཞིན་པར་འཛིན་པར་འགྱུར་རོ། །

[Block 744]
གང་གི་ཚེ་སྒྲ་ཇི་བཞིན་པར་བཟུང་བ་དེའི་ཚེ་འགལ་བ་དང་རྨད་དུ་བྱུང་བའི་བྱ་བ་བྱེད་པར་འགྱུར་རོ། །

[Block 745]
ཤིན་ཏུ་རྨད་དུ་བྱུང་བའི་བྱ་བ་བྱེད་པ་དེའི་ཚེ་སེམས་ཅན་ཐམས་ཅད་ལོག་པའི་ལམ་ལ་གནས་པར་འགྱུར་རོ། །

[Block 746]
སེམས་ཅན་ཐམས་ཅད་ལོག་པའི་ལམ་ལ་གནས་པར་གྱུར་པ་དེའི་ཚེ་རྨད་དུ་བྱུང་བའི་བྱ་བ་བྱེད་པའི་ལས་ཀྱི་འབྲས་བུ་སྨིན་པར་འགྱུར་རོ་ཞེས་བྱ་བའི་དོན་ཏོ། །དེ་ཡང་གང་ལས་ཤེས་ཤེ་ན། བཅོམ་ལྡན་འདས་ཀྱིས་དགོངས་པ་ལུང་བསྟན་པ་ཞེས་བྱ་བའི་རྒྱུད་ལས་གསུངས་ཏེ་ཞེས་བྱ་བ་ལ་སོགས་པ་གསུངས་ཏེ།

[Block 747]
གསང་བའི་བདག་པོ་ཞེས་བྱ་བ་ནི་བོད་པའོ། །དོན་རྒྱས་པ་ཡི་ཚུལ་ཆེན་འདི་ནི་རྙེད་གྱུར་ནས། །ཞེས་པ་དོན་རྒྱས་པའི་ཚུལ་ཆེན་པོ་ནི་དེ་བཞིན་གཤེགས་པའི་གསང་བ་འདུས་པ་ཉིད་དོ། །

[Block 748]
ཇི་བཞིན་དོན་ནི་རྙེད་བཟུང་བས། །ཞེས་པ་ནི་སྒྲ་ཇི་བཞིན་པའི་དོན་རྙེད་པའོ། །

[Block 749]
དེས་ཇི་ལྟར་གཟུང་བ༌[^355]ཞེ་ན། གསང་བ་འདུས་པའི་དགོངས་པ་ཅན་ཐམས་ཅད་ཀྱང་སྒྲ་ཇི་བཞིན་པར་བཟུང་ཞེས་བྱ་བའི་དོན་ཏོ། །

[Block 750]
དེས་ཅིར་འགྱུར་ཞེ་ན། དེས་ན་ལམ་ངན་ངག་ཏུ་ལྟུང་། །ཞེས་པ་ནི་གང་བཟོད་པར་དཀའ་བའི༌[^356]སྡུག་བསྔལ་དང་ལྡན་པ་དེ་ནི་ལམ་ངན་པ་སྟེ་གང་ཞིག་གང་དུ་ལྟུང་བ་དེ་ལ་དེ་སྐད་ཅེས་བྱའོ། །

[Block 751]
དེ་ལྟ་བུར་འཛིན་པར་བྱེད་པའི་གང་ཟག་ཀྱང་ཇི་ལྟ་བུ་ཡིན་ཞེ་ན། མངོན་པའི་ང་རྒྱལ་རྟག་དགའ་བས། །ཞེས་བྱ་བ་ནི་མངོན་པའི་ང་རྒྱལ་གཏོང་བར་མི་བྱེད་པ་སྟེ་གང་ཞིག་གང་ལ་འཕངས་པར༌[^357]འཛིན་པ་དེ་ལ་དེ་སྐད་ཅེས་བྱའོ། །

[Block 752]
རྣལ་འབྱོར་པ་ནི་བདག་ཅེས་སྨྲ། །ཞེས་པ་ནི་རྣལ་འབྱོར་གྱི་དོན་དང་མི་ལྡན་པར་བདག་ཉིད་རྣལ་འབྱོར་པ་ཡིན་ཞེས་ཟེར་བ༌[^358]ལྟ་བུའོ། །

[Block 753]
ཆོས་ནི་གཡོ་ཡིས་བྱེད་པར་འགྱུར། །ཞེས་པ་ནི་མ་བྱིན་པར་ལེན་པ་དང་སྲོག་གཅོད་པ་དང་བརྫུན་དང་ཚིག་འཁྱལ་བ་དང་། ངག་རྩུབ་མོ་ལ་སོགས་པས་ཆོས་ཡོངས་སུ་ཚོལ་བར་བྱེད་པ་དེ་ལ་དེ་སྐད་ཅེས་བྱའོ། །

[Block 754]
དེས་ནི་འདུས་པ་མི་ཤེས་པར། །ཞེས་པ་ནི་དེ་བཞིན་གཤེགས་པའི་གསང་བ་འདུས་པའི་དགོངས་པ་ལ་སོགས་པ་ལེགས་པར་མི་ཤེས་པའོ། །

[Block 755]
དམ་ཚིག་ལ་སོགས་སྤྱོད་བྱེད་ལ། །ཞེས་པ་ནི་དམ་ཚིག་དང་སྒྲུབ་པ༌[^359]ལ་སོགས་པ་ཉེ་བར་སྤྱོད༌[^360]པའོ། །

[Block 756]
གསང་བ་སྲུང་བར༌[^361]མི་བྱེད་ཅིང་། །ཞེས་པ་ནི།

[Block 757 [VERSE]]
ཐམས་ཅད་དུ་ནི་རབ་ཏུ་སྟོན། །
ཞེས་བྱ་བ་དེ་ཉིད་ཀྱིས་བཤད་དོ། །
མངོན་སུམ་སངས་རྒྱས་འདྲ་བ་ཡི། །
སློབ་དཔོན་སྨོད་ཅིང་བཀུར༌[^362]མི་བྱེད། །

[Block 758]
ཞེས་པ་ནི་བླ་མའི་བསྲུང་བར་བྱ་བའི་སྡོམ་པ་ལ་ཕྱལ་བར་གཏོང་བའོ། །

[Block 759]
སྐད་ཅིག་གིས་ནི་ཁོང་ཁྲོ་ཞིང་། །ཞེས་པ་ནི་ཉེས་པ་མཐོང་ན་སྐད་ཅིག་ཙམ་གྱིས་ཁྲོ་བར་བྱེད་པའོ། །

[Block 760]
དེ་བཞིན་སྐད་ཅིག་གིས་རྗེས་ཆགས། །ཞེས་པ་ནི་བདག་ཉིད་དང་རྗེས་སུ་མཐུན་པའི་ལས་བྱུང་ན་ཆགས་པར་བྱེད་པའོ། །

[Block 761]
འདི་དག་གིས་ནི་བློ་མི་བརྟན་པ་བསྟན་ཏོ།[^363] །དེ་ནས་འདོད་པས་ལོག་པར་གཡེམ་པ་ལ་སོགས་པའི་ཉེས་པ་བསྟན་པའི་ཕྱིར། མ་དང་སྲིང་མོ་བུ་མོ་སྟེ། །ཞེས་པ་ནི་བདག་ཉིད་བསྐྱེད་པ་དང་། བདག་ཉིད་དང་ལྷན་ཅིག་ཏུ་བསྐྱེད་པ་དང་བདག་གིས་བསྐྱེད་པའོ། །

[Block 762]
དེ་དག་གིས་ནི་བགྲོད་པ་མ་ཡིན་ཏེ་དེ་བཞིན་གཤེགས་པ་རྣམས་ཀྱིས་རྨད་པ་ཡིན་པའི་ཕྱིར་རོ། །

[Block 763]
དེ་ལ་བགྲོད་པར་བྱེད་པ་གང་ཡིན་པ་དེ་ནི་ཉེས་པ་མཆོག་དང་ལྡན་པ་ཡིན་ཞེས་སྦྱར་རོ། །

[Block 764]
ཉེས་པ་གཞན་ཡང་ཡོད་པའི་ཕྱིར། །ཕ་མ་གསོད་ཅིང་ཞེས་བྱ་བ་ལ་སོགས་པ་གསུངས་ཏེ་ཕ་མ་གསོད་པ་ནི་ཕ་མ་གསོད་པས་ཏེ། ཕ་མ་ལ་ངན་སེམས་ཀྱིས་ཚོན་རྡེག་པ་གང་ཡིན་པ་དེ་ལ་དེ་སྐད་ཅེས་བྱའོ། །

[Block 765]
སྲོག་ཆགས་གཞན་ཡང་གསོད་པར་བྱེད། ཅེས་པ་ནི་འཇིག་རྟེན་གྱི་སྲོག་ཆགས་རགས་པ་དང་ཕྲ་བ་ལ་སོགས་པ་གསོད་པ་གང་ཡིན་པ་དེ་ལ་དེ་སྐད་ཅེས་བྱའོ། །

[Block 766]
དེ་བཞིན་བརྫུན་གྱི་ཚིག་སྨྲ་ཞིང་། །ཞེས་པ་ནི་གང་ཞིག་བདེན་པར་སྨྲ་བ་སྤངས་པའོ། །

[Block 767]
ཁྱད་པར་དུ་ཡང་རྐུ་བར་བྱེད། །ཅེས་པ་ནི་གང་གིས་མ་བྱིན་པར་ལེན་པར་བྱེད་པ་དེ་ལ་དེ་སྐད་ཅེས་བྱའོ། །

[Block 768]
གཞན་གྱི་ཆུང་མའི་ཐད་འགྲོ་ཞིང་། །ཞེས་པ་ནི་གཞན་གྱི་ཆུང་མ་ལ་ཉེ་བར་སྦྱོར་བའོ། །

[Block 769]
སྨད་པ་གཞན་ཡང་བྱེད་པར་འགྱུར། །ཞེས་པ་ནི་བསྟན་བཅོས་ལས་སྨད་པའི་བྱ་བ་གཞན་ཐམས་ཅད་ལྷུར་ལེན་པར་འགྱུར་ཞེས་པའི་དོན་ཏོ། །

[Block 770 [VERSE]]
དེ་ཉིད་ཡེ་ཤེས་འབྱུང་བ་ཡི། །
དམ་ཚིག་རྣམས་ནི་དེས་མི་ཤེས། །

[Block 771]
ཞེས་པ་ནི་གསང་བ་ཆེན་པོ་མཆོག་གི་དམ་ཚིག་རྒྱས་པ་དེ་ཉིད་ཀྱིས་མི་ཤེས་ཞེས་པའི་དོན་ཏོ། །

[Block 772 [VERSE]]
ཉེས་པ་ཅུང་ཟད་ཙམ་ལ་ཡང་། །
མངོན་སྤྱོད་དག་ནི་བྱེད་པར་འགྱུར། །

[Block 773]
ཞེས་པ་ནི་ཉེས་པ་ཕྲ་མོ་ཙམ་ལ་ཡང་དྲག་པོའི་ལས་རྩོམ་ཞེས་པའི་དོན་ཏོ། །

[Block 774]
རྟག་ཏུ་ཕྱི་རོལ་བསྟན་བཅོས་དགའ། །ཞེས་པ་ནི་གཞུང་འདི་པ་མ་ཡིན་པའི་བསྟན་བཅོས་ལ་གཞོལ་བ་གང་ཡིན་པ་དེ་ལ་དེ་སྐད་ཅེས་བྱའོ། །

[Block 775]
རང་གི་དམ་ཚིག་ཡོངས་སྤངས་ཏེ། །ཞེས་པ་ནི་རང་གི་དམ་ཚིག་མི་བསྲུང་བའོ། །

[Block 776 [VERSE]]
ལྕགས་ཀྱུ་མེད་པ་བཞིན་དུ་སྤྱོད། །
ཅེས་པ་ནི་ཐབས་དང་བྲལ་བ་ཉིད་དོ། །

[Block 777]
སྔགས་དང་ཕྱག་རྒྱའི་སྦྱོར་བ་ཡི།[^364] །འཚོ་བ་དག་ནི་ངེས༌[^365]སྒྲུབ་བྱེད། །ཅེས་པ་ནི་སྔགས་དང་ཕྱག་རྒྱས་རང་གི་འཚོ་བ་ཡོངས་སུ་ཚོལ་བ་དེ་ལ་དེ་སྐད་ཅེས་བྱའོ། །

[Block 778 [VERSE]]
གང་དུ་རྙེད་པ་ཐོབ་འགྱུར༌[^366]བར། །
དམ་པའི་ཆོས་ནི་འཆང་བར་འགྱུར། །

[Block 779]
ཞེས་པ་ནི་ཡུལ་དུ༌[^367]ཤེས་པ་དང་མི་ལྡན་ཞིང་རྙེད་པ་ཉེ་བར་ཐོབ་པར་འགྱུར་བར་དམ་པའི་ཆོས་འཆད་པར་འགྱུར་ཞེས་བྱ་བའི་དོན་ཏོ། །

[Block 780]
དེས་ཅིར་འགྱུར་ཞེ་ན། སྔགས་པ་རྣམས་ནི་འགྲུབ་མི་འགྱུར། །ཞེས་སྨོས་ཏེ་དེ་ལྟ་བུའི་གང་ཟག་གིས་སྔགས་དང་ཕྱག་རྒྱའི་དངོས་གྲུབ་འགྲུབ་པ་མེད་ཀྱི་མནར་མེད་པའི་སྡུག་བསྔལ་ཆེན་པོ་སྐྱེད་ཅེས་པའི་དོན་ཏོ། །དེ་ཅིའི་ཕྱིར་ཞེ་ན། རྣལ་འབྱོར་རབ་སྦྱོར་དམན་པའི་ཕྱིར། །ཞེས་སྨོས་ཏེ། རབ་ཏུ་སྦྱོར་བ་དམན་པ་ནི་རབ་ཏུ་སྦྱོར་བ་ཞན་པ་ཞེས་པའི་དོན་ཏོ། །

[Block 781]
དེ་རྣམས་གཟུང་བར་བྱ་བའི་ཕྱིར། །ཞེས་པ་ནི་དེ་རྣམས་ཀྱི་ངན་འགྲོའི་སྲིད་པ་དགག་པའི་ཕྱིར༌[^368]ཞེས་པའི་དོན་ཏོ། །

[Block 782 [VERSE]]
གསང་བ་དགོངས་པས་བཤད་པ་ཡིན། །
ཞེས་བྱ་བ་ནི་བཤད་ཟིན་ཏོ། །

[Block 783]
འདིས་ནི་བསྡུས་པའི་དོན་བསྟན་ཏོ་ཞེས་པ་ནི་འདི་ཉིད་ཀྱིས་བསྡུས་པའི་དོན་ཡིན་གྱི་རྒྱས་པར་བཤད་པ་ནི་མ་ཡིན་ནོ། །

[Block 784]
གང་ཞིག་གང་དུ་གང་གི་ཕྱིར་བསྟན་པ་ཡིན་ཞེ་ན། དེ་བཞིན་གཤེགས་པའི་གསང་བ་འདུས་པའི་དོན་མཐའ་དག་དང་། དེ་བཞིན་གཤེགས་པའི་གསང་བ་འདུས་པའི་བཤད་པ་མཐའ་དག་བསྡུས་པའི་དོན་འདི་ཉིད་ཀྱིས་བསྡུས་པའི་ཕྱིར་དེ་ལ་དེ་སྐད་ཅེས་བྱའོ། །

[Block 785]
འདིས་ཀྱང་བསྡུས་པ་ལ་དགའ་བ་རྣམས་འདི་ཙམ་གྱིས་ཚིམ་པར་འགྱུར༌[^369]ཞེས་བྱ་བའི་དོན་ཏོ། །

[Block 786]
དེ་ལྟར་བསྡུས་པའི་དོན་བསྟན་ནས་ཞེས་པ་ནི་རྒྱས་པར་བསྟན་པར་བཤད་པར་འདོད་པས་དེ་སྐད་ཅེས་བྱའོ། །

[Block 787]
ད་ནི་ཞེས་བྱ་བ་ནི་སྐབས་ལ་བབ་པའི་ཚིག་གོ། །

[Block 788]
ཡན་ལག་གི་དོན་རྣམ་པར་དབྱེ་བའི་ཕྱིར་ཞེས་པ་ནི་རྩ་བའི་དོན་མ་ཡིན་པའི་ཕྱིར་དེ་སྐད་ཅེས་བྱའོ། །

[Block 789]
རྒྱུད་ལ་འཇུག་པར་བྱ་སྟེ་ཞེས་པ་ནི་རྒྱུད་ཉིད་བཤད་པར་བྱ་ཞེས་བྱ་བའི་དོན་ཏོ། །

[Block 790]
འདི་སྐད་བདག་གིས་ཐོས་པ་ཞེས་བྱ་བ་འདི་ཡང་གང་གིས་གང་ལ་བསྟན་ཞེ་ན། འདིར་སྡུད་པར་བྱེད་པ་ཞེས་བྱ་བ་ལ་སོགས་པ་སྨོས་ཏེ་སྡུད་པར་བྱེད་པ་ནི་སྡུད་པར་བྱེད་པ་སྟེ་དེ་བཞིན་གཤེགས་པའི་རྒྱུད་ཐོབ་པར་བྱེད་ཅེས་པའི་དོན་ཏོ། །

[Block 791]
ཐོས་པར༌[^370]བྱེད་པ་པོ་གང་ཡིན་ཞེ་ན། འཕགས་པ་ཕྱག་ན་རྡོ་རྗེ༌[^371]ཞེས་པ་སྟེ་དགོངས་པ༌[^372]ཐམས་ཅད་འབྱུང་བར་བྱེད་པའི་རྡོ་རྗེ་ཐོགས་པ་གང་ཡིན་པ་དེ་ལ་དེ་སྐད་ཅེས་བྱའོ། །

[Block 792]
