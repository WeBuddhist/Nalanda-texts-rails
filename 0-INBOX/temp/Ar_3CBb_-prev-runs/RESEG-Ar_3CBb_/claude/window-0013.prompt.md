=== SYSTEM PROMPT ===
You are an expert in classical Tibetan Buddhist commentary (འགྲེལ་པ་) structure.

You are given a numbered list of blocks from a Tibetan verse commentary. A
rule-based segmenter has already cut them; most cuts are right. Your job is to
output the few merge/split operations that bring the blocks to the layout the
human editors of this vault use.

━━━ TARGET LAYOUT — one block per FUNCTIONAL UNIT ━━━

OPENER       A node's division announcement together with the first-child opener
             that follows it is ONE block:
               "<topic> ལ་གསུམ། A། B། C་འོ། །དང་པོ་ནི།"
             A sibling opener "གཉིས་པ་ <title> ནི།" is its own block.
ROOT QUOTE   A quoted root stanza is its own block. These blocks are tagged
             [VERSE]; they are protected — never include them in any operation.
EXPLANATION  The gloss that follows a quote ("ཞེས་པ་སྟེ། …", "ཞེས་པ་ནི། …", or a
             running explanation) is ONE block up to the next opener, quote or
             heading — even when it is long (100–250 syllables) and contains several
             sentence ends, a question and answer ("…ལོ། །གང་ལ་ན། …"), a side remark
             on a variant reading ("…ཞེས་འགྱུར་བཅོས་…"), a cross-reference
             ("འདི་དང་འོག་གི་ས་བཅད་…"), or a mantra cited in passing.
SECOND LEVEL A passage that re-reads the same stanza on another level — opening
             "སྦས་དོན་ནི།", "ངེས་དོན་ནི།", "ངེས་པའི་དོན་དུ།", "ཟབ་དོན་ནི།",
             "དེའི་ནང་གི་དོན་ལ།", "མཐར་ཐུག་གི་དོན་ནི།" or the like after the literal
             gloss — is its OWN block, never merged into the literal gloss before it
             (the editors keep the two readings apart). Within that passage, M1 applies.
FRAME        The namo line alone; each of the author's own verses one block;
             "སྨྲས་པ།" alone; the colophon ("ཅེས་ … སྦྱར་བའོ། །" + closing wishes) one block.

━━━ MERGE — adjacent blocks that are one unit ━━━

M1  CONTINUED EXPLANATION
    A block that goes on explaining the same quote/topic as the block before it —
    no new opener, no new quote, no new verse being treated — belongs to that block.
    This is the most common fix. Do NOT keep a cut just because a sentence ends.
    Exception: a SECOND LEVEL opener (see above) always starts a new block.
M2  INCOMPLETE SENTENCE
    A block ending in a connector (དང་། / ཞིང་། / ཅིང་། / ནས། / སྟེ། / ཏེ།) that
    the next block completes.
M3  OPENER CHAIN
    An enumeration block followed by "དང་པོ་ནི།" / "དང་པོ་ལ་ N།" (and further
    nested first-child enumerations) — merge them into one opener block.
M4  COLOPHON
    The parts of the closing colophon and its final wishes form one block.

━━━ SPLIT — one block that holds two units ━━━

S1  A new node opener (ordinal + title + "ནི།" or "ལ་ N།") buried mid-block:
    split before it.
S2  The treatment of a new verse/topic starts mid-block (e.g. "ཡང་ཕྱག་གང་ལ་འཚལ་ན"
    starting the next homage): split before it.
S3  An introductory opener "… ནི།" fused to the explanation of the PREVIOUS
    quote: split so the opener starts the next unit.

Never split a block only because it is long.

━━━ HEADING / VERSE BLOCKS — always KEEP ━━━

Blocks tagged [HEADING] or [VERSE] are NEVER part of any operation.

━━━ OUTPUT FORMAT ━━━

A JSON array of operations. Blocks not mentioned are kept as-is.

[
  {"op": "merge", "blocks": [N, M]},
  {"op": "merge", "blocks": [N, M, P]},
  {"op": "split", "block": N, "after": "<verbatim unique substring ending at split point>"},
  {"op": "split", "block": N, "after": ["<sub1>", "<sub2>", "<sub3>"]}
]

Rules for the output:
- Block numbers are CONTINUOUS and INCLUDE heading and verse blocks. You may only
  merge blocks with consecutive numbers (N and N+1). Never merge across a heading
  or a verse block, and never propose a merge whose numbers skip over one.
- Each block number appears in AT MOST ONE operation.
- For each "after" substring: copy a verbatim slice from the block that ends exactly
  at the split point and is UNIQUE within that block (10–20 characters is usually enough).
- If nothing needs to change in this window, output: []
- Output ONLY the JSON array. No explanation, no commentary, no code fences.

ཕྲག་དོག་ནི་གཞན་གྱི་ཡོན་ཏན་ལ་སེམས་ཁོང་ནས་འཁྲུགས་པ་སྟེ། གང་གིས༌[^804]དེ་དང་ལྡན་པའི་སེམས་ཅན་འདུལ་བར༌[^805]བྱེད་པ་དེའི་ཕྱིར་དེ་ལ་དེ་སྐད་ཅེས་བྱའོ། །

[Block 1492]
ཁམས་ཕྲ་བ་ནི་ལྟེ་བ་ལ་གནས་པའི་རླུང་སྟེ། དེས་ཐབས༌[^806]ཀྱི་ཡེ་ཤེས་བྱང་ཆུབ་ཀྱི་སེམས་བཀུག་ནས་མཆོག་ཏུ་དགའ་བ་སྐྱེད་པ་སྟེ་དེ་ལས་བྱུང་བའི་ཕྱིར་རོ། །

[Block 1493]
རབ་ཏུ་རྣམ་པར་འབྱེད་པ་ནི་རྟོག་པ་དང་དཔྱོད་པ་དང་། ངེས་པར་འབྱེད་པ་སྟེ།

[Block 1494 [VERSE]]
རྒྱུ་དེ་ལས་བྱུང་བའི་ཕྱིར་རོ། །
འཛིན་པ་ནི་དེ་དང་ལྡན་པའོ། །
ཟླ་བ་ནི་བྱང་ཆུབ་ཀྱི་སེམས་སོ། །
རླུང་གིས་འཛིན་པ་ནི་དེ་མི་གཏོང་བའོ། །

[Block 1495]
གདུལ་བྱ༌[^807]ནི་ཁམས་གསུམ་གྱི་སེམས་ཅན་ནོ། །

[Block 1496]
དེའི་མངོན་པར་འདོད་པ་ནི་དེའི་བླང་བར་བྱ་བའོ། །

[Block 1497]
ཟག་པ་མེད་པའི་བདེ་བ་ཆེན་པོ་ནི་ཆོས་ཀྱི་སྐུའོ། །

[Block 1498]
རིགས་འདི་རྣམས་ཞེས་པ་ནི་འོག་ནས་སྟོན་ཏོ། །

[Block 1499]
ཕུང་པོ་འདི་དག༌[^808]ནི་གཟུགས་ལ་སོགས་པ་སྟེ་དེ་ཉིད་དོན་དམ་པར་སངས་རྒྱས་དང་ངོ་བོ་གཅིག་པའི་ཚུལ་གྱིས་སོ། །

[Block 1500]
དེ་ལྟ་བུའི་དབུས༌[^809]སུ་མ་ཡིན་ནམ་སྙམ་པ་ལ། རྫོགས་པའི་བྱང་ཆུབ་རྐྱེན་དུ་བྱུང་། །ཞེས་པ་ནི་འདི་ལ་བརྟེན་ནས་བླ་ན་མེད་པའི་བྱང་ཆུབ་སྒྲུབ་པ་ཉིད་དོ། །

[Block 1501]
དེའི་ཕྱིར་ནི་ཐ་དད་དོ༌[^810]ཞེ་ན། དེ་བཞིན་ཉིད་དུ་གཉིས་མེད་པ། །ཞེས་དོན་དམ་པར་གཉིས་སུ་མེད་ཅིང་དབྱེར་མེད་པའོ། །

[Block 1502]
ཡང་རྣམ་པར་སྣང་མཛད་ཅེས་བྱ་བ་ལ་སོགས་པའི་དོན་ནི། །

[Block 1503]
རྫོགས་སངས་རྒྱས་ནི་ཆགས་པ་བྲལ། །འདོད་ཆགས་ཅན་ལ་དེ་ཉིད་དོ། །ཞེས་པ་ལྟ་བུའོ། །

[Block 1504 [VERSE]]
མཱ་མ་ཀཱི་ནི་འཁྲིག་པ་ཡི། །
རེག་བྱས་མཉེས་པར་བྱེད་པའི་ཕྱིར། །
འདའ་བར་བྱ་བ་མ་ཡིན་ནོ། །

[Block 1505]
ཞེས་བསྟན་པར་འགྱུར་རོ། །

[Block 1506]
ཞེ་སྡང་ནི་མི་བསྐྱོད་པ་སྟེ་ཞེ་སྡང་ཅན་གྱིས༌[^811]འགྲོ་བ་འདུལ་བར་བྱེད་པའི་ཕྱིར་རོ། །

[Block 1507]
དེ༌[^812]དགའ་བ་ནི་དེ་མཉེས་པར་བྱེད་པའི་ཚུལ་གྱིས་སོ། །

[Block 1508]
ཞེ་སྡང་རྣམ་པར་དག་པ་ནི་དེ་བཞིན་ཉིད་དེ་རྒྱུ་དང་ངོ་བོ་ལ་སོགས་པ་མ་གྲུབ་པའི་ཕྱིར་རོ། །

[Block 1509]
དེ་ལ་དགའ་བ་ནི་དེ་དང་དབྱེར་མེད་པའི་ཚུལ་གྱིས་ཏེ་ཡང་དག་པའི༌[^813]ཡེ་ཤེས་སོ། །

[Block 1510]
བཅོམ་ལྡན་འདས་རྡོ་རྗེ་འཆང་ཆེན་པོ་དེ་ཉིད་ཅེས་བྱ་བ་ལ་སོགས་པའི་དོན་ནི་དེ་དག་ཀྱང་རྡོ་རྗེ་འཆང་གིས་སེམས་ཅན་གྱི་དོན་དུ་དེ་ལྟར་བསྟན་གྱི་དོན་དམ་པར་ནི་མ་ཡིན་ནོ་ཞེའོ། །

[Block 1511]
གཞན་ལ་ཡང་དེ་ལྟར་ཤེས་པར་བྱའོ། །

[Block 1512]
སྐུ་དང་གསུང་དང་ཐུགས་མི་རྟག་པ༌[^814]ནི་སྐད་ཅིག་གཉིས་པ་ལ་སོགས་པར་མི་གནས་པའོ། །

[Block 1513]
སླུ་བ༌[^815]ནི་རྟག་པར་སེམས་པ་ལའོ། །

[Block 1514]
ཆོས་ཐམས་ཅད་སྟོང་པ་ནི་ཇི་ལྟར་བརྟག་པ༌[^816]དང་བྲལ་བའོ། །

[Block 1515]
སླུ་བ་ནི་ཡོད་པར་འཛིན་པའི་གང་ཟག་ལའོ། །

[Block 1516]
སྣང་བ་གསུམ་ནི་བཤད་ཟིན་ཏོ། །

[Block 1517]
སླར་ཡང་དངོས་པོ་མེད་པར་བྱས་པ་ནི་འོད་གསལ་བའི་ངང་དུ་སྟེ་དེ་ཉིད་ཡོད་པར་འཛིན་པ་ནི་གང་ཟག་ལའོ། །

[Block 1518]
ཕུང་པོ་ལ་སོགས་པ་ནི་སྦྱང་བར་བྱའོ།[^817] །རིལ་པོར་འཛིན་པ་ལ་སོགས་པ་ནི་སྦྱོར་བའི་ཐབས་སོ། །

[Block 1519]
དེ་ཐམས་ཅད་དབྱེ་བ༌[^818]མེད་པར་གྱུར་པ༌[^819]ནི་དེའི་འབྲས་བུའོ། །འདི་ནི་ཐམས་ཅད་རང་གིས་བརྟགས་པས་སླུ༌[^820]བ་སྟེ།

[Block 1520]
བདེན་པར་གྱུར་པའི་དོན་མཐོང་བས། །དམན་ལ་བདེན་པར་གྱུར་པ་སླུ། །ཞེས་འབྱུང་བ་ལྟ་བུའོ། །

[Block 1521]
གཞན་ནི་སྔ་མ་བཞིན་ནོ། །

[Block 1522]
གཤིན་རྗེ་ནི་དམྱལ་བའི་སྲུང་མ་དང་བཅས་པ་སྟེ་དེ་ན་དབང་ཆེ་བར་སྣང་བའི་ཕྱིར་རོ། །

[Block 1523]
ཁྲོ་བོ་ཆེན་པོ་ནི་དེ་དག་འཇིགས་པར་སྣང་བའོ། །

[Block 1524]
མཐར་ཐུག༌[^821]མཛད་ཅིང་འཇིགས་པ་ནི་གཏུམ་པོའི་ལས་ཀྱི༌[^822]དོན་ཆེན་པོ་དང་ལྡན་པར་བྱེད་པའོ། །

[Block 1525]
རྨོངས་པའི་མུན་པ་ཉིད་མ་རིག་པ༌[^823]སྟེ་དམན་པར་གྱུར་པའི་ཕྱིར་སྡུག་བསྔལ་སྣ་ཚོགས་ཉམས་སུ་མྱོང་བར་བྱེད་པས་གཤིན་རྗེའོ། །

[Block 1526]
དོན་དམ་པའི་བདེན་པས་མཐར་ཐུག༌[^824]པར་མཛད་པ་ནི་རང་བཞིན་གྱིས་བག་ཆགས་དང་བཅས་ཏེ་རྩད་ནས་གདོན་པའི་ཕྱིར་རོ། །

[Block 1527]
དེ་བཞིན་གཤེགས་པ་ཐམས་ཅད་ཀྱི་མངོན་པར་བྱང་ཆུབ་པ་ཡང་གང་ཞེ་ན་རིན་ཆེན་འབྱུང་ལྡན་ནོ། །

[Block 1528]
འོད་གསལ་བ་ནི་མངོན་པར་བྱང་ཆུབ་པ་ལས་བྱུང་བ་དང་།

[Block 1529]
དེའི་ངོ་བོ་ཉིད་ཀྱི་ཕྱིར་རོ། །དེ་ཉིད་ནི་མི་ཕྱེད་པས་རྡོ་རྗེའོ། །

[Block 1530]
རྣམ་པར་རྟོག་པའི༌[^825]བདག་ཉིད་ཅན་ནི་ཡིད་ཀྱི་རྣམ་པར་ཤེས་པ་དང་མཚུངས་པར༌[^826]ལྡན་པའོ། །

[Block 1531]
དེ་འོད་གསལ་བར་འཇུག་པ་ནི་སྟོང་པ་ཉིད་དུ་བྱས་པའོ། །

[Block 1532]
རྡོ་རྗེའི་དམ་ཚིག་ནི་གང་ཞིག་དེས་གང་བསྙེངས་པར་བྱ་ཞེ་ན་རྡོ་རྗེ་ནི་དེ་བཞིན་གཤེགས་པའི་ཁྲོ་བོའི་ཚུལ་ཅན་ཏེ་དེས་གདུག་པ་ཅན་སློབ་དཔོན་ལ་སྡང་བ་ལ་སོགས་པ་བསྲེགས་པ་ནི་དོན་ཆེན་པོ་དང་ལྡན་པར་བྱ་བའི་ཕྱིར་རོ། །

[Block 1533]
ཡང་བྱེ་བྲག་བསྡུ་བ་སྟེ། རྡོ་རྗེ་དམ་ཚིག་ཉིད་སྲེག༌[^827]པའོ། །

[Block 1534]
འོད་དཔག་ཏུ་མེད་པ་ནི་ཆོས་རིན་པོ་ཆེ་སྟེ་ཆོས་ཐམས་ཅད་ཀྱི་འབྱུང་གནས་སུ་གྱུར་པའི་ཕྱིར་རོ། །

[Block 1535]
རྟ་མགྲིན་ཡང་འོད་དཔག་ཏུ་མེད་པ་སྟེ་དེའི་རིགས་སུ་གྱུར་པའི་ཕྱིར་རོ། །

[Block 1536]
འོད་གསལ་བ་ནི་ཆོས་རིན་པོ་ཆེ་སྟེ་ཆོས་ཐམས་ཅད་ཀྱི་དེ་བཞིན་ཉིད་ཀྱི་ཕྱིར་རོ། །

[Block 1537]
རྟ་མགྲིན་ཡང་དེ་ལས་བྱུང་བའི་ཕྱིར་དེ་སྐད་ཅེས་བྱའོ། །

[Block 1538]
ཉོན་མོངས་པ་རྣམས་ཀྱིས་མ་གོས་པ་ནི་དེའི་རང་བཞིན༌[^828]ཡིན་པའི་ཕྱིར་རོ། །

[Block 1539]
དེ་ཉིད་འཇིགས་པར༌[^829]མཛད་པ་ནི་དེ་དང་ལྷན་ཅིག་པར་འགལ་བའི་ཕྱིར་རོ། །

[Block 1540]
པདྨ་ནི་སྐྱེ་གནས་སོ་ཞེས་པ་ལ་སོགས་པའི་དོན་ནི་རྡོ་རྗེ་པདྨ་སྙོམས་པར་ཞུགས་པས་བྱང་ཆུབ་སེམས་ཕབ་སྟེ་དེས་བདེ་བ་དང་བདེ་བ་དམ་པ་སྐྱེ་བར་འགྱུར་རོ་ཞེས་པའི་དོན་ཏོ། །

[Block 1541]
རྣམ་པར་དག་པའི་གནས་ནི་རྣམ་པར་དག་པར་བྱེད་པའི་རྟེན་ཏེ་གང་ཡིན་ཞེ་ན་འོད་གསལ་བའོ། །

[Block 1542]
བགེགས་ནི་བི་ནཱ་ཡ་ག་ལ་སོགས་པ་སྟེ་དེ་མཐར་བྱེད་པ་ནི་ཐབས་གང༌[^830]གི་སྒོ་ནས་དོན་ཆེན་པོ་ལྡན་པར་བྱེད་པའི་ཕྱིར་དེ་ལ་དེ་སྐད་ཅེས་བྱའོ། །

[Block 1543]
དེས་པའི་དོན་དུ་བགེགས་ཞེས་བྱ་བ་གང་ཞིག་ཅེ་ན། བགེགས་ནི་ཁམས་བཞི་པོ་སྟེ། ས་དང་ཆུ་དང་མེ་དང་རླུང་རང་གི་ལུས་ཀྱིས་བསྡུས་པའོ། །

[Block 1544]
དེ་ལ་ཡང་ཅིའི་ཕྱིར་ཞེ་ན། དེ་དག་འཕེལ་བ་དང་འགྲིབ་པས་ལུས་གཟིར་བར་བྱེད་པའི་ཕྱིར་རོ། །

[Block 1545]
ཐབས་ཀྱི༌[^831]ཡེ་ཤེས་ཤར་བས་རྣམ་པར་འཇིག་པ་ནི་གང་གིས་ལུས་ཀྱི་རྒྱུན་ལས་བྱང་ཆུབ་སེམས་ཕབ་སྟེ་དེའི་ཉེས་པ་དང་བྲལ་བར་བྱས་པ་ཉིད་དོ། །

[Block 1546]
འདི་ལ་ཁ་ཅིག་གིས༌[^832]འདི་སྐད་ཅེས་དེ་བཞིན་གཤེགས་པའི་གཙོ་བོ་དང་འཁོར་གྱི་རྣམ་པར་སྣང་བ་འདི༌[^833]ཐ་དད་པའམ་གཅིག་པའམ་དེ་ལས་གཞན་དུ་འགྱུར་ཞེས་རྟོག་དྲང༌[^834]ན། རེ་ཞིག་དང་པོར་ཐ་དད་པ་ནི་མ་ཡིན་ཏེ་སོ་སོར་མ་འདྲེས་པར་རྣམ་པར་སྣང་བའི་ཕྱིར་དང་གང་གིས་རག་ལས་དེའི་དབང་གིས་འགྱུར་རོ་ཞེས་བྱ་བར་ཡང་མི་ནུས་ཏེ། དུང་དང་དཀར་པོ་ལྟ་བུའོ། །

[Block 1547]
རང་གི་བློ་དང༌[^835]འགྱུར་བ་ཡང་མ་ཡིན་ཏེ་བརྟགས་པ་མ་ཡིན་པའི་ཕྱིར་རོ། །

[Block 1548]
གལ་ཏེ་ཡིན་ནོ་ཞེ་ན་ཡང་བླང་བར་བྱ་བ་མ་ཡིན་པ་ཉིད་དོ། །

[Block 1549]
ཕྱོགས་ངེས་པར༌[^836]འགྲུབ་པར་མི་འགྱུར་ཏེ་དེ་ཉིད་ཀྱི་ཕྱིར་ཐ་དད་པ་ནི་མ་ཡིན་ནོ། །

[Block 1550]
གལ་ཏེ་གཅིག་པ་ཉིད་དོ་ཞེ་ན་ཡང་ཤིན་ཏུ་རིགས་པ་མ་ཡིན་ཏེ། ཁ་དོག་དང་གནས་ལ་སོགས་པ་ཐ་དད་པའི་ཕྱིར་རོ། །

[Block 1551]
གལ་ཏེ་གནས་གཅིག་པས་གཅིག་པ་ཉིད་དོ་ཞེ་ན་ཡང་རིགས་པ་མ་ཡིན་ཏེ། ཐམས་ཅད་སའི་དཀྱིལ་འཁོར་གཅིག་ལ་བརྟེན་པ་ཉིད་ཀྱི་ཕྱིར་རོ། །

[Block 1552]
གལ་ཏེ་ལུས་འདྲ་བས་གཅིག་པ་ཉིད་དོ༌[^837]ཞེ་ན་ཡང་མ་ཡིན་ཏེ་གང་གིས་མི་རྣམས་ཀྱི༌[^838]ལུས་འདྲ་བས་གཅིག་པ་མ་གྲུབ་པ་བཞིན་ནོ། །

[Block 1553]
གལ་ཏེ་ཡེ་ཤེས་གཅིག་པ་ཉིད་ཀྱིས་གཅིག་པ་ཉིད་དོ་ཞེ་ན་ཡང་མ་ཡིན་ཏེ་མི་རྟག་པ་དང་མི་རྟག་པ་ཅན་ཡང་ཤིན་ཏུ་གཅིག་པར་འགྱུར་རོ། །

[Block 1554]
གལ་ཏེ་རིག་པ་ཙམ་དུ་འདོད་པའོ་ཞེ་ན་ཡང་མ་ཡིན་ཏེ་སངས་རྒྱས་དང་བྱང་ཆུབ་སེམས་དཔའ་དང་སོ་སོའི་སྐྱེ་བོའི་བར་ལ་སོགས་པ་ཟག་པ་མེད་པའི་ས་བོན་དང་བཅས་པས་བསྡུས་པའི་ཕྱིར་ཐམས་ཅད་ཀྱང་ངོ་། །གལ་ཏེ་ཤེས་པ་ཐ་དད་དུ་གྱུར་པས་ཡིན་ནོ་ཞེ་ན་སོ་སོ་རང་གི་རིག་པས་བརྟགས་ན་དབྱེར་མེད་པའི་ཕྱིར་རོ། །

[Block 1555]
[^839]ཡང་སྔ་མའི་ས༌[^840]ན་འདུག་པ་ཉིད་དོ་ཞེ་ན་ཡང་མ་ཡིན་ཏེ། རང་གི་གདུལ་བྱའི་དབང་གིས་སྣ་ཚོགས་པར་སྣང་བའི་ཕྱིར་རོ། །

[Block 1556]
དེ་བས་ན་འདིར་ཡང་སངས་རྒྱས་ཐམས་ཅད་དབྱེར་མེད་ཀྱང་རང་གི་གདུལ་བྱའི་དབང་གིས༌[^841]སྣ་ཚོགས་པར་སྣང་བའི་ཕྱིར་རོ། །

[Block 1557]
གལ་ཏེ་དེ་ལྟ་ན། གཅིག་པར་འགྱུར་རོ་ཞེ་ན་དེ་ནི་འདོད་པ་སྟེ། དེའི་རང་བཞིན་གྱི་ཕྱིར་དུས་ཐམས་ཅད་དུ་གཅིག་པ་ཉིད་ཀྱི་ཕྱིར་རོ། །

[Block 1558]
དེ་ལྟར་ན་སེམས་ཅན་གྱི་འདོད་པས་བྱུང་བའི་ཕྱིར་དུས་ཐམས་ཅད་དུ་འདོད་པས་ཇི་ལྟ་བ་བཞིན་དུ་འབྱུང་བར་འགྱུར་རོ། །

[Block 1559]
གལ་ཏེ༌[^842]ནི་རང་གི་རྣམ་པར་རྟོག་པས༌[^843]བསྒྲིབས་པའི་ཕྱིར་མི་སྣང་ངོ་། །འདོད་པ་ལ་རག་ལས་པའི་དངོས་པོ་ནི་མི་སྣང་བར་མི་འགྱུར་ཏེ་གང་གི་ཕྱིར་རང་གི་འདོད་པ་ཙམ༌[^844]གཙོ་བོར་བྱེད་པའི་ཕྱིར་རོ། །

[Block 1560]
གལ་ཏེ་རང་གི་འདོད་པ་གཙོ་བོར་མི་བྱེད་ན་ནི་ཐ་དད་པས་སྣང་བར་མི་འགྱུར་ཏེ་བཀབ༌[^845]པའི་ཕྱིར་རོ། །

[Block 1561]
གལ་ཏེ་སྒྲིབ༌[^846]པས༌[^847]མི་སྣང་ན་སྒྲིབ་པ༌[^848]དང་བྲལ་བའི་དུས་ན་ཐ་དད་པ་མི་སྣང་སྟེ་དེ་ནི་མེད་པའི་ཕྱིར་རོ། །

[Block 1562]
གང་གི་ཕྱིར༌[^849]སེམས་ཅན་གྱི་མོས་པ་འབའ་ཞིག་ལས་མ་ཡིན་ཏེ་སྨོན་ལམ་ཆེན་པོའི་འཕེན་པས་ཀྱང་སྣང་ངོ་། །

[Block 1563]
དེ་བས་ན་གཉིས་ཚོགས་ན་འགྱུར་གྱི་གཞན་དུ་ནི་མ་ཡིན་ནོ། །

[Block 1564]
ཡང་ཅི་ཐ་དད་པར་འགྱུར་བའི་སྨོན་ལམ་འགྲུབ་པ་ཅིའི་ཕྱིར་ཞེ་ན། ཐ་དད་པའི༌[^850]སེམས་ཅན་ཡོངས་སུ་སྨིན་པར་བྱ་བའི་ཕྱིར་ཏེ་འདི་ལྟར་ཐ་དད་པའི་སེམས་ཅན་རྣམས་ལ་མཐུན་པ་དང་མི་མཐུན་པ་གཅིག་གིས༌[^851]དོན་བྱེད་པ་ནི་འགལ་བའི་ཕྱིར་རོ། །

[Block 1565]
གལ་ཏེ་དེ་ལྟ་ན་རྒྱུ་གཉིས་ལས་གྲུབ་པའི་ཕྱིར་གཅིག་ལས་སྣ་ཚོགས་སུ་ནི༌[^852]སྣང་ན། གང་གི༌[^853]ཕྱིར་ཤེས་པ་སྣ་ཚོགས་པར་གྱུར་པ་ཉིད་དེ་གལ་ཏེ་དེ་ལྟར༌[^854]མ་གྱུར་ན་ཐམས་ཅད་མཁྱེན་པ་གྲུབ་པར་མི་འགྱུར་རོ་ཞེ་ན་མ་ཡིན་ཏེ། གང་གི་ཕྱིར་དེའི་རྒྱུ་ཚོགས་པ་དེ་ཙམ་གྱིས་ཤེས༌[^855]བྱ་ཐམས་ཅད་མཁྱེན་པའི་ཚུལ་དུ་སྣང་གི་དོན་དམ་པར་ནི་མ་ཡིན་ཏེ་སྒྱུ་མའི་རྟ་ལ་སོགས་པ་བཞིན་ནོ། །

[Block 1566]
གལ་ཏེ་དེ་ལྟ་ན༌[^856]ནི་ང་ནི་ཟག་པ་ཟད་དོ། །

[Block 1567]
ད་ནི་ཆོས་ཐམས་ཅད་ཀྱི་དོན་ཡོངས་སུ་ཤེས་པའོ་ཞེས་བྱ་བ་ལ་སོགས་པ་འདི་ལེགས་པར་གནས་པར་མི་འགྱུར་རོ་ཞེ་ན། དེ་ནི་དགོངས་པ་སྟེ། འདིར་ཆོས་ཐམས་ཅད་ཀྱི་དེ་ཁོ་ན་ཉིད་ཀྱི་དོན་ཇི་ལྟ་བ་བཞིན་ལ་དགོངས་པའོ། །

[Block 1568]
གལ་ཏེ་མཚན་མ་ཐམས་ཅད་མཁྱེན་ན་ཅིར་འགྱུར་ཞེ་ན། མཚན་མ་ནི་ཐོག་མ་མེད་པའི་ལས་ཀྱིས་བསྒྲུབས་པས་འཁྲུལ་པའི་ཕྱིར་ལ། འཁྲུལ་པའི་ཡུལ་ལ་དམིགས་པའི་ཕྱིར་འཁྲུལ་པའི་ཡུལ་ཅན་གྱི་ཤེས་པར་འགྱུར་གྱི་ཡེ་ཤེས༌[^857]ནི་མ་ཡིན་ནོ། །

[Block 1569]
གལ་ཏེ་དེ་ཉིད་ཡེ་ཤེས་སོ་ཞེ་ན་གང་གི་ཕྱིར་ཇི་ལྟར་གནས་པའི་དོན་ཤེས་པས་ཡེ་ཤེས་ཞེས་བྱ་བ་ནི།[^858] དེ་གང་གིས་འགྲུབ་པར་འགྱུར་རོ།[^859] །དེ་ནི་སོ་སོར་རྟོག་པའི་ཡེ་ཤེས་སོ་ཞེ་ན། དེ་ནི་ལོངས་སྤྱོད་རྫོགས་པའི་སྐུའི་ཤེས་པ་ཉིད་སྤྲུལ་པ་ཞེས་བྱ་བར་ཡང་མི་འགྱུར་ཏེ༌[^860]མེ་ལོང་ལྟ་བུའི་ཡེ་ཤེས་དང་བྲལ་བའི་ཕྱིར་རོ། །

[Block 1570]
དེ་ནི་དེ་ལ་ཡང་མཚུངས་སོ། །

[Block 1571]
[^861]དེ་བས་ན༌[^862]འདིར་འཁོར་གྱི་སྣང་བ་མ་གཏོགས་པ་གཞན་མ་ཡིན་ནོ། །

[Block 1572]
གལ་ཏེ་ལོངས་སྤྱོད་རྫོགས་པའི་སྐུ་སྒྲུབ་པ་ཉིད་དེ། སྤྲུལ་པའི་ལས་བྱེ་བྲག་ཏུ་བྱ་བའི་ཕྱིར་རོ་ཞེ་ན་མ་ཡིན་ཏེ་སྔ་མའི་སྐྱོན་ཉིད་དོ། །

[Block 1573]
གལ་ཏེ་འཁྲུལ་པ་ནི་འཁྲུལ་པར་མ་འཁྲུལ་པ་ནི་མ་འཁྲུལ་པར་མཁྱེན་ན་ཇི་ལྟར་འཁྲུལ། མཚན་མ་ལ་དམིགས་པའམ་མཚན་མར་སྣང་བ་དེ་མི་འཁྲུལ་པ་མ་ཡིན་པ་དེ་བརྗོད༌[^863]དགོས་སོ། །

[Block 1574]
གལ་ཏེ་གཟུགས་དང་སེམས་སོ་ཞེ་ན། གཟུགས་ལྟར་སྣང་བའི་ས་བོན་ལས་བྱུང་བའི་ཕྱིར་ལེགས་པར་བཤད་པར་འགྱུར་རོ། །

[Block 1575]
འདི་ལྟར་ཆོས་འདི་དག་ལས་ཀྱི་འཁྲུལ༌[^864]འཁོར་གྱིས་བྱུང་བ་སྟེ་དེ་ཉིད་ལས༌[^865]སྣ་ཚོགས་པར་སྣང་པའི་ཕྱིར་རོ། །

[Block 1576]
གལ་ཏེ་སྣ་ཚོགས་པ་དེ་གཅིག་པའི་རང་བཞིན་ཡིན་ནོ་ཞེ་ན། དེ་ལྟར་སྣང་བར་གྱུར་པའི་ཤེས་པ༌[^866]སྣང་བ་ཉིད་ལས་མངོན་སུམ་དང་ལྡན་པའི་སྐྱེས་བུ་ས་བོན་སྣ་ཚོགས་པ་ཉིད་དོ། །
