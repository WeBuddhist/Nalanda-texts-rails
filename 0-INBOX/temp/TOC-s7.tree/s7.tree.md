* 2. ཆོས་རྣམས་ཀྱི་ངོ་བོ་ཉིད་མེད་པའི་མཚན་ཉིད་བསྟན་པ [[དེ་ཡང་རྣམ་པར་དབྱེ་ན་རྣམ་པ་གཉིས་ཏེ། ཡོངས་སུ་ཞུས་པ་དང་། རྒྱ་ཆེར་བསྟན་པའོ། །]]

   * 2.2 དེའི་འོག་ཏུ་རྒྱ་ཆེར་བསྟན་པ [[དེའི་འོག་ཏུ་རྒྱ་ཆེར་བསྟན་པའི་ཚིག་གི་དོན་ལ་སོགས་པ་བཤད་པར་བྱ་སྟེ།]]
      * 2.2.1 ངོ་བོ་ཉིད་མེད་པ་ཉིད་ཀྱི་ལྡེམ་པོར་དགོངས་པ་བསྟན་པ [[དེ་ལ་དང་པོར་ངོ་བོ་ཉིད་མེད་པ་ཉིད་ཀྱི་ལྡེམ་པོར་དགོངས་པ་བསྟན་པའི་ཚིག་གི་དོན]]
      * 2.2.2 དེ་ལ་སྤྱོད་པའི་གང་ཟག་གི་བྱེ་བྲག [[དེའི་འོག་ཏུ་དེ་ལ་སྤྱོད་པའི་གང་ཟག་གི་བྱེ་བྲག་བསྟན་པའི་ཚིག་གི་དོན་ལ་སོགས་པ]]

               * 2.2.2.1.2.1 གཞི་གསུམ་དང་ལྡན་པ [[དེ་ཡང་གཞི་གསུམ་དང་ལྡན་པ་ཡིན་ཏེ། གཞི་གསུམ་དང་ལྡན་པ་ནི་བསྟན་པའི་གཞི་དང་ལྡན་པ]]
                  * 2.2.2.1.2.1.1 དང་པོར་བསྟན་པའི་གཞི་དང་ལྡན་པའི་སྒྲུབ་པའི་བྱེ་བྲག་བསྟན་པ [[དེ་ལ་དང་པོར༌[^1656]བསྟན་པའི་གཞི་དང་ལྡན་པའི་སྒྲུབ་པའི༌[^1657]བྱེ་བྲག་བསྟན་པའི་ཚིག་གི་དོན་ལ་སོགས་པ]]
                  * 2.2.2.1.2.1.2 རིགས་པའི་གཞི་དང་ལྡན་པ [[དེའི་འོག་ཏུ་རིགས་ཀྱི་གཞི་དང་ལྡན་པའི་སྒྲུབ་པའི་བྱེ་བྲག་བསྟན་པའི་ཚིག་གི་དོན་ལ་སོགས]]
                  * 2.2.2.1.2.1.3 རྐྱེན་གྱི་གཞི་དང་ལྡན་པ [[དེའི་འོག་ཏུ་རྐྱེན་གྱི་གཞི་དང་ལྡན་པའི་བསྒྲུབ་པའི༌[^1817]བྱེ་བྲག་བསྟན་པའི་ཚིག་གི་དོན་ལ་སོགས་པ]]

               * 2.2.2.2.2.1 དང་པོ་མོས་པའི་བྱེ་བྲག་རྒྱས་པར་བཤད་པ [[དེ་ལ་དང་པོར་མོས་པའི་བྱེ་བྲག་རྒྱས་པར་བཤད་པ་དང་པོའི་ཚིག་གི་དོན་ལ་སོགས་པ༌[^1839]བཤད]]
