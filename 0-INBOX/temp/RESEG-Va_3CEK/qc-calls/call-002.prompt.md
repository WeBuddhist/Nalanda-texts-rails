━━━ ISSUE TYPES ━━━

CONNECTOR_ENDING
  The block ends with a connector particle (དང་། / ཞིང་། / ཅིང་། / ནས། / ལས། /
  སྟེ། / ཏེ།) that grammatically requires continuation. Real issue if the next
  block is the grammatical continuation. False positive if this is a closing verse
  pāda or a deliberate short citation frame.

OBJECTION_REPLY_FUSED
  The block contains both an objection marker (ཅེ་ན། / ཞེ་ན། / སྙམ་ན།) and a reply
  opener (འོ་ན།). These should always be two separate blocks. Almost always a
  real issue.

OVER_LENGTH
  The block exceeds the syllable threshold. Usually NOT wrong: a whole explanation
  unit is legitimately long. Split only if a new node opener (ordinal + title +
  ནི། / ལ་ N།) or the treatment of a new verse is buried mid-block.

SHORT_FRAGMENT
  The block is suspiciously short — may be a stray split artifact that should be
  merged with an adjacent block.

ཡང༌[^1128]སྐལ་བ་མཉམ་པའི་ཁམས་ཀུན་དུ་འགྲོ་བ་དག་ཏུ་ཕྲ་རྒྱས་བཅུ་གཅིག་བཤད་པ་གང་དག་ཡིན་པ་དེ་དག་ལས་དགུ་གང༌[^1129]དུ་དམིགས། ལྟ་བ་གཉིས་པོ་མ་གཏོགས་སོ། །འཇིག་ཚོགས་ལ་ལྟ་བ་དང་། མཐར་འཛིན་པར་ལྟ་བ་ལས༌[^1130]མ་གཏོགས་པ་ཕྲ་རྒྱས་གཞན་དགུ་ནི་སྐལ་བ་མི་མཉམ་པའི་ཁམས་ཀུན་དུ་འགྲོ་བ་དག་ཡིན་ནོ། །རེས་འགའ་ནི་སྐལ་བ་མི་མཉམ་པའི་ཁམས་གཅིག་ལ་དམིགས་སོ། །རེས་འགའ་ནི་གཉིས་ལ་དམིགས་ཏེ། འདོད་པ་དང་ལྡན་པ་གཟུགས་དང་ལྡན་པ་ལ་དམིགས་པ་རྣམས་ལ།[^1131] གཟུགས་མེད་པ་དང་ལྡན་པ་ལ་དམིགས་པ་རྣམས་དང་། འདོད་པ་དང་ལྡན་པ་གཟུགས༌[^1132]མེད་པ་དང་ལྡན་པ་ལ་དམིགས་པའི་ཕྲ་རྒྱས་གང་དག་ཡིན་པ་ཞེས་འབྱུང་བའི་ཕྱིར་རོ། །གང་གི་ཚེ་འདོད་པའི་ཁམས་ན་གནས་པ་ཚངས་པ་ལ་སེམས་ཅན་དུ་ལྟ་བ་དང་། རྟག་པར་ལྟ་བ་སྐྱེད་པར་བྱེད་པ་དེའི་ཚེ་ཇི་ལྟར་འཇིག་ཚོགས་དང་། མཐར་འཛིན་པར་ལྟ་བ་སྐལ་བ་མི་མཉམ་པའི་ཁམས་ལ་དམིགས་པ་དག་མ་ཡིན་ཞེ་ན། བདག་དང་བདག་གིར་མི་འཛིན་པའི་ཕྱིར་དང་། མཐར་འཛིན་པར་ལྟ་བ་ཡང་དེས་ཀུན་ནས་བསླང་བའི་ཕྱིར་རོ། །
