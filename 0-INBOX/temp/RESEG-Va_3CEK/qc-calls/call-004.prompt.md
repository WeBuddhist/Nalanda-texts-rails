━━━ ISSUE TYPES ━━━

CONNECTOR_ENDING
  The block ends with a connector particle (དང་། / ཞིང་། / ཅིང་། / ནས། / ལས། /
  སྟེ། / ཏེ།) that grammatically requires continuation. Real issue if the next
  block is the grammatical continuation. False positive if this is a closing verse
  pāda or a deliberate short citation frame.

OBJECTION_REPLY_FUSED
  The block contains both an objection marker (ཅེ་ན། / ཞེ་ན། / སྙམ་ན།) and a reply
  opener (འོ་ན།). These should always be two separate blocks. Almost always a
  real issue.

OVER_LENGTH
  The block exceeds the syllable threshold. Usually NOT wrong: a whole explanation
  unit is legitimately long. Split only if a new node opener (ordinal + title +
  ནི། / ལ་ N།) or the treatment of a new verse is buried mid-block.

SHORT_FRAGMENT
  The block is suspiciously short — may be a stray split artifact that should be
  merged with an adjacent block.

Rules:
- Only output corrections for REAL issues. Skip false positives entirely.
- Block numbers are CONTINUOUS and include heading blocks. Only merge blocks with
  consecutive numbers (N and N+1); never merge across a heading or skip a number.
- "after" must be verbatim from the block and unique within it. To break one long
  block into 3+ units, set "after" to a LIST of substrings in document order.
- Each block number appears in AT MOST ONE operation.
- Heading blocks (lines starting with #) and [VERSE] blocks are NEVER touched.
- If no corrections are needed, output: []
- Output ONLY the JSON array. No commentary, no code fences.

མདོ་ལས། མཆོག་ཏུ་ཐོགས་ན་ལན་བདུན་པ་ཞེས་འབྱུང་བ་ནི་དེ༌[^1914]མཆོག་ཏུ་ཐོགས་ན་སྐྱེ་བ་ལན་བདུན་པ༌[^1915]ཞེས་བྱ་བའི་ཐ་ཚིག་སྟེ། མཆོག་ཅེས་བྱ་བའི་སྒྲ་ནི་རབ་ཏུའོ། །མྱ་ངན་ལས་འདས་པའི་རྒྱུན་ནི་ལམ་སྟེ། དེས་ན་དེར་འགྲོ་བའི་ཕྱིར་རོ། །འདི་ནི་དེར་ཞུགས་ཤིང་ཕྱིན་ལ་སོན་པས་ན་རྒྱུན་དུ་ཞུགས་པ་ཡིན་ནོ། །ཇི་ལྟར་ན་ཞུགས་པ་ཡིན། གལ་ཏེ་ལམ་དང་པོ་ཐོབ་པའི་ཕྱིར་རོ་ཞེ་ན་ནི་བརྒྱད་པ་ཡང་ཡིན་པར་འགྱུར་རོ། །གལ་ཏེ་འབྲས་བུ་དང་པོ་ཐོབ་པའི་ཕྱིར་རོ་ཞེ་ན་ནི་ཕལ་ཆེར་ལས་འདོད་ཆགས་དང་བྲལ་བ་ཡང་ཡིན་པར་འགྱུར་ལ། འདོད་པ་ལས་འདོད་ཆགས་དང་བྲལ་བ་ཡང་ཡིན་པར་འགྱུར་རོ། །འབྲས་བུ་ཐམས་ཅད་ཐོབ༌[^1916]པའི་དབང་དུ་བྱས་ནས་འབྲས་བུ་དང་པོ་ཐོབ་པའི་ཕྱིར་རོ། །[^1917]ཅིའི་ཕྱིར་དེ་ཁོ་ན་ཡིན་ལ་བརྒྱད་པ་ནི་མ་ཡིན་ཞེ་ན། ལམ་ལ་རྗེས་སུ་ཤེས་པ་ལ་ནི་ཞུགས་པ་དང་འབྲས་བུའི་ལམ་ཐོབ་པའི་ཕྱིར་དང་། མཐོང་བ་དང་བསྒོམ་པའི་ལམ་ཐོབ་པའི་ཕྱིར་དང་། རྒྱུན་ཐམས་ཅད་མངོན་པར་རྟོགས་པའི་ཕྱིར་རོ། །

འདི་ལ་ཤེས་པར་བྱེད་པ་མདོའམ་རིགས་པ་ཅི་ཞིག་ཡོད། ལྷ་དང་མི་དག་གི་ནང་ནས༌[^1921]སོར་ལན་བདུན་སྐྱེའི་གཉི་གའི་ནང་དུ་ལན་བདུན་མ་ཡིན་པ་ཉིད་དོ་ཞེས་བྱ་བ་འདི་ལ་ཡང་ཤེས་པར་བྱེད་པ་ཅི་ཞིག་ཡོད་དེ། འདི་སྐད་དུ་ལྷ་རྣམས་དང་མི་རྣམས་ཀྱི་ནང་དུ༌[^1922]ལན་བདུན་ཞེས་འབྱུང་ངོ་ཞེ་ན། འོད་སྲུངས་པ་རྣམས་ལྷ་རྣམས་སུ་ལན་བདུན། མི་རྣམས་སུ་ལན་བདུན་ཞེས་སོ་སོར་ཡང་འདོན་པས་འདི་ལ་མངོན་པར་ཞེན་པར་མི་བྱའོ། །གང་ཞིག་མི་དག་གི་ནང་དུ་རྒྱུན་དུ་ཞུགས་པར་གྱུར་པ་དེ་ནི་དེ་ཁོ་ནར་འོངས་ནས་ཡོངས་སུ་མྱ་ངན་ལས་འདས༌[^1923]ལ། གང་ཞིག་ལྷ་དག་གི་ནང་དུ་རྒྱུན་དུ་ཞུགས་པར་གྱུར་པ་དེ་ནི་དེ་ཁོ་ནར་འོངས་ནས་ཡོངས་སུ་མྱ་ངན་ལས་འདའོ། །ཅིའི་ཕྱིར་སྲིད་པ་བརྒྱད་པ་མངོན་པར་མི་འགྲུབ་ཅེ་ན། དུས་དེ་སྲིད་ཀྱིས་གདོན་མི་ཟ་བར་རྒྱུད་ཡོངས་སུ་སྨིན་པའི་ཕྱིར་རོ། །ལམ་དེ་ནི་དེ་འདྲ་སྟེ། སྦྲུལ་གོམ་པ་བདུན་པས་ཟིན་པ་ལྟ་བུ་དང་། རིམས་ཉིན་བཞི་པ་བཞིན་ནོ། །ཀུན་ཏུ་སྦྱོར་བ་བདུན་པོ་ཐ་མའི་ཆ་དང་མཐུན་པ་གཉིས་དང་། གོང་མའི་ཆ་དང་མཐུན་པ་ལྔ་ལུས་པའི་ཡང་ཕྱིར་རོ། །བར་སྐབས་སུ་ཡང་འཕགས་པའི་ལམ་མངོན་དུ་བྱེད་ཅིང་ཡོངས་སུ་མྱ་ངན་ལས་མི་འདའ་སྟེ། དེ་སྲིད་དུ་སྲིད་པ་མྱོང་བར་འགྱུར་བའི་ལས་ཀྱི་སྟོབས་བསྐྱེད་པའི་ཕྱིར་རོ། །སངས་རྒྱས་འབྱུང་བ་མེད་ན་ཁྱིམ་པ་ཁོ་ནར་དགྲ་བཅོམ་པ་ཉིད་འཐོབ་ན༌[^1924]ཁྱིམ་ན་ནི་མི་གནས་སོ། །ཆོས་ཉིད་ཀྱིས་འཐོབ་པའི་དགེ་སློང་གི་མཚན་མ་ཡང་འཐོབ་བོ། །

དེ་ནི་རྡོ་རྗེ་ལྟ་བུ་ཡིན། །བར་ཆད་མེད་པའི་ལམ་དེ་ནི་ཕྲ་རྒྱས་ཐམས་ཅད་འཇོམས་པར་བྱེད༌[^2046]པ་ཡིན་པའི་ཕྱིར་རྡོ་རྗེ་ལྟ་བུའི་ཏིང་ངེ་འཛིན་ཞེས་བྱའོ། །བཅོམ་ཟིན་པའི་ཕྱིར་འདིས་ཐམས་ཅད་འཇོམས་པ་ནི་མ་ཡིན་གྱི། བར་ཆད་མེད་པའི་ལམ་ཐམས་ཅད་ཀྱི་ནང་ནས༌[^2047]ཤིན་ཏུ་ཆེ་བ་ཡིན་པའི་ཕྱིར་ཐམས་ཅད༌[^2048]འཇོམས་པར་ནུས་པ་ཡིན་ནོ། །རྡོ་རྗེ་ལྟ་བུ་རྣམས་ཀྱི་བྱེ་བྲག་ནི་རྣམ་པ་མང་པོ་ཞིག་ཏུ་བརྗོད་དེ། མི་ལྕོགས་པ༌[^2049]མེད་པས་བསྡུས་པ་སྲིད་པའི་རྩེ་མོའི་སྡུག་བསྔལ་དང་ཀུན་འབྱུང་ལ་དམིགས་པས༌[^2050]སྡུག་བསྔལ་དང་ཀུན་འབྱུང་ལ་རྗེས་སུ་ཤེས་པའི་རྣམ་པ་དག་དང་མཚུངས་པར་ལྡན་པ་བརྒྱད་དང་། འགོག་པ་དང་ལམ་ལ་ཆོས་ཤེས་པའི་རྣམ་པ་དག་དང་མཚུངས་པ༌[^2051]ལྡན་པ་བརྒྱད་དང་། འགོག་པ་ལ་རྗེས་སུ་ཤེས་པའི་རྣམ་པ་དག་དང་མཚུངས་པར་ལྡན་པ་བསམ་གཏན་དང་པོའི་འགོག་པ་ལ་དམིགས་པ་བཞི་ནས་དེ་བཞིན་དུ་སྲིད་པའི་རྩེ་མོའི་འགོག་པ་ལ་དམིགས་པའི་བར་དུ་བཞི་དང་། ལམ་ལ་རྗེས་སུ་ཤེས་པའི་རྣམ་པ་དག་དང་མཚུངས་པར་ལྡན་པ་བཞི་སྟེ། རྗེས་སུ་ཤེས་པའི་ཕྱོགས་དང་མཐུན་པ་ཟད་པར༌[^2052]ལ་དམིགས་པའི་ཕྱིར་རོ། །དེ་དག་ནི་ཤེས་པའི་དམིགས་པ་དང་རྣམ་པའི་བྱེ་བྲག་གིས་ཐ་དད་པའི་ཕྱིར་རྡོ་རྗེ་ལྟ་བུ་ལྔ་བཅུ་རྩ་གཉིས་ཡིན་ནོ། །མི་ལྕོགས་པ༌[^2053]མེད་པས་བསྡུས་པ་ཇི་ལྟ་བར་བསམ་གཏན་བཞི་པས་བསྡུས་པའི་བར་དག་ཀྱང་དེ་དང་འདྲའོ། །ནམ་མཁའ་དང་རྣམ་ཤེས་མཐའ་ཡས་དང་ཅི་ཡང་མེད་པའི་སྐྱེ་མཆེད་ཀྱིས༌[^2054]བསྡུས་པ་རྣམས་ནི་གྲངས་བཞིན་དུ་ཉི་ཤུ་རྩ་བརྒྱད་དང་ཉི་ཤུ་རྩ་བཞི་དང་ཉི་ཤུ་ཡིན་ཏེ། དེ་དག་ནི༌[^2055]ཆོས་ཤེས་པ་དང་རྗེས་སུ་ཤེས་པས་ས༌[^2056]འོག་མའི་འགོག་པ་ལ་དམིགས་པ་མེད་པའི་ཕྱིར་རོ། །ས་འོག་མིའི༌[^2057]གཉེན་པོ་ལ་དམིགས་པ་ནི་ཡོད་དེ།[^2058] དེ་ནི་ཕན་ཚུན་དུ་རྒྱུ་བའི་ཕྱིར་རོ། །གང་དག་ལམ་ལ་རྗེས་སུ་ཤེས་པ་ཡང་ས་རེ་རེའི་གཉེན་པོ་ལ་དམིགས་པ་ཡིན་པར་འདོད་པ་དེ་དག་གི་ལྟར་ན་ཉི་ཤུ་རྩ་བརྒྱད་ལྷག་པར་བསྣན་ནས་མི་ལྕོགས་པ་མེད་པས་བསྡུས་པ་རྡོ་རྗེ་ལྟ་བུ་ནི་བརྒྱད་ཅུ་ཡིན་ཏེ། བསམ་གཏན་བཞི་པས་བསྡུས་པའི་བར་དུ་ཡང་དེ་དང་འདྲའོ། །ནམ་མཁའ་མཐའ་ཡས་སྐྱེ་མཆེད་ལ་སོགས་པ་དག་ནི་གོ་རིམས་བཞིན་དུ་བཞི་བཅུ་དང་། སུམ་ཅུ་རྩ་གཉིས་དང་། ཉི་ཤུ་རྩ་བཞི་ཡིན་ནོ། །ཡང་རིགས་དང་དབང་པོའི་བྱེ་བྲག་གིས་ནི་ཆེས་མང་བ་ཡིན་ནོ། །

གལ་ཏེ་ཡང་དགྲ་བཅོམ་པ་ཉིད་ལས་ཡོངས་སུ་ཉམས་པ་སྲིད་པ་ཞིག་ཏུ་གྱུར་ན། ཅིའི་ཕྱིར་བཅོམ་ལྡན་འདས་ཀྱིས་མཐོང་བའི་ཆོས་ལ་བདེ་བར་གནས་པར༌[^2188]ལྷག་པའི་སེམས་ལས་བྱུང་བ་དག་ཁོ་ན་ལས་ཡོངས་སུ་ཉམས་པར་འགྱུར་བར་གསུངས་པར་གྱུར༌[^2189]ཏེ། དེའི་ཕྱིར་དགྲ་བཅོམ་པ་ཐམས་ཅད་ཀྱི་རྣམ་པར་གྲོལ་བ་ནི་མི་གཡོ་བ་ཡིན་པར་ཁོང་དུ་ཆུད་དོ། །མཐོང་བའི་ཆོས་ལ་བདེ་བར་གནས་པ་དག་ལས་ནི་ལ་ལ་ནི༌[^2190]རྙེད་པ་དང་བཀུར་སྟིས་གཡེན་སྤྱོ་བའི་ཉེས་པས་དབང་ཉམས་པའི་ཕྱིར་ཡོངས་སུ་ཉམས་པར་འགྱུར་ཏེ། དབང་པོ་རྟུལ་པོ་གང་ཡིན་པའོ། །ལ་ལ་ཡོངས་སུ་ཉམས་པར་མི་འགྱུར་ཏེ། དབང་པོ་རྣོན་པོ་གང་ཡིན་པའོ། །དེ་ལ་གང་ཞིག་ཡོངས་སུ་ཉམས་པར་འགྱུར་བ་དེ་ནི་ཡོངས་སུ་ཉམས་པའི་ཆོས་ཅན་ཡིན་ལ། གང་ཞིག་ཡོངས་སུ་ཉམས་པར་མི༌[^2191]འགྱུར་བ་དེ་ནི་ཡོངས་སུ་ཉམས་པར་མི་འགྱུར་བའི་ཆོས་ཅན་ཡིན་ཏེ། དེ་བཞིན་དུ་འཆི་བར་སེམས་པའི་ཆོས་ཅན་ལ་སོགས་པ་ལ་ཡང་སྦྱར་བར་བྱའོ། །ཡོངས་སུ་མི་ཉམས་པའི་ཆོས་ཅན་དང་། གནས་པ་ལས་མི་བསྐྱོད་པ་དང་། མི་གཡོ་བའི་ཆོས་ཅན་རྣམས་ལ༌[^2192]ཁྱད་པར་ཅི་ཡོད་ཅེ་ན། ཡོངས་སུ་མི་ཉམས་པའི་ཆོས་ཅན་ནི་སྦྱངས་པ་ལས་གྱུར་པ་ནི༌[^2193]མ་ཡིན་ལ། མི་གཡོ་བའི་ཆོས་ཅན་ནི་སྦྱངས་པ་ལས་གྱུར་པ་ཡིན་ཏེ། དེ་གཉིས་ནི་ཏིང་ངེ་འཛིན་གྱི་ཁྱད་པར་གང་ཁོ་ན་སྐྱེད་པར་བྱེད་པ་དེ་ལས་ཡོངས་སུ་ཉམས་པར་མི་འགྱུར་རོ། །གནས་པ་ལས་མི་བསྐྱོད༌[^2194]པ་ནི་ཡོན་ཏན་གང་ཁོ་ན་ལ༌[^2195]གནས་པ་དེ་ལས་ཡོངས་སུ་ཉམས་པར་མི་འགྱུར་བ་འབའ་ཞིག་ཏུ་ཟད་ཀྱི། གཞན་ཡང་སྐྱེད་པར་མི་བྱེད་པའམ། སྐྱེད་པར་བྱེད་ན་ཡང་དེ་ལས་གཡོ་བར་འགྱུར་བ་ཡིན་པས་འདི་ནི་ཁྱད་པར་ཡིན་པར་མངོན་ནོ། །ཚེ་དང་ལྡན་པ་གནག་ཚོགས་ཅན་སློབ་པར་གྱུར་པ་ཧ་ཅང་རོ་མྱང་བའི་ཕྱིར་དང་། དབང་པོ་རྟུལ་པོ་ཡིན་པའི་ཕྱིར་སེམས་རྣམ་པར་གྲོལ་བ་དུས་དང་སྦྱོར་བ་པ་ལས་ཡང་དང་ཡང་དུ་ཡོངས་སུ་ཉམས་པ་དང་། ཡི་ཆད་ནས་ལུས་དང་སྲོག་ལ་མི་ལྟ་བར་མཚོན་གྱིས་འདེབས་པར་བྱེད་ལ། འཆི་བའི་དུས་ཁོ་ནར་དགྲ་བཅོམ་པ་ཉིད་ཐོབ་ཅིང་ཡོངས་སུ་མྱ་ངན་ལས་འདས་པར་ཡང་གྱུར་ཏེ། དེ་ལྟ་བས་ན་དེ་ཡང་དགྲ་བཅོམ་པ་ཉིད་ལས་ཡོངས་སུ་ཉམས་པ༌[^2196]མ་ཡིན་ནོ། །

#### ཡིད་འབྱུང་བ་དང་འདོད་ཆགས་དང་བྲལ་བ། ^3-2-22-0

[Block 1865 — OVER_LENGTH (297 syllables)]
དངོས་པོ་གང་གིས་ཡིད་འབྱུང་བར་འགྱུར་བའི་དངོས་པོ་དེས་འདོད་ཆགས་དང་བྲལ་བར་ཡང་འགྱུར་རམ་ཞེ་ན། མུ་བཞིའོ། །ཇི་ལྟར་བྱས་པས་ཤེ་ན། སྡུག་བསྔལ་རྒྱུ་བཟོད་ཤེས་རྣམས་ཀྱིས། །ཡིད་འབྱུང་སྡུག་བསྔལ་དང་ཀུན་འབྱུང་ལ་བཟོད་པ་དང་ཤེས་པ་རྣམས་ཁོ་ནས་ཡིད་འབྱུང་བར་འགྱུར་གྱི༌[^2386]གཞན་དག་གིས་ནི་མ་ཡིན་ནོ། །གང་གིས་སྤོང་འགྱུར་བ། ཀུན་གྱིས་འདོད་ཆགས་བྲལ་བར་འགྱུར། །སྡུག་བསྔལ་དང༌[^2387]ཀུན་འབྱུང་བ་དང་འགོག་པ་དང་ལམ་ལ་བཟོད་པ་དང་ཤེས་པ་གང་དག་གིས་ཉོན་མོངས་པ་སྤོང་བར་འགྱུར་བ་ཐམས་ཅད་ཀྱིས་ཀྱང་འདོད་ཆགས་དང་བྲལ་བར་འགྱུར་རོ། །དེ་ལྟ་ན༌[^2388]ནི་མུ་བཞི་སྲིད། དེ་ལྟ་ན་མུ་བཞིར་གྲུབ༌[^2389]སྟེ། སྡུག་བསྔལ་དང་ཀུན་འབྱུང་ལ་བཟོད་པ་དང་ཤེས་པ་རྣམས་ཀྱིས་ཉོན་མོངས་པ་དག༌[^2390]མི་སྤོང་ན་ཡིད་འབྱུང་བ་ཁོ་ན་ཡིན་ཏེ། ཡིད་འབྱུང་བའི་དངོས་པོ་ཁོ་ན་ལ་དམིགས་པའི་ཕྱིར་རོ། །འགོག་པ་དང་ལམ་ལ་བཟོད་པ་དང་ཤེས་པ་རྣམས་ཀྱིས་ཉོན་མོངས་པ་དག་སྤོང་ན་འདོད་ཆགས་དང་བྲལ་བ་ཁོ་ན་ཡིན་ཏེ། མཆོག་ཏུ་དགའ་བའི་དངོས་པོ་ལ་དམིགས་པའི་ཕྱིར་རོ། །སྔ་མ་རྣམས་ཀྱིས་ཉོན་མོངས་པ་དག་སྤོང༌[^2391]ན་གཉི་ག་ཡིན་ནོ། །ཕྱི་མ་རྣམས་ཀྱིས་ཉོན་མོངས་པ་དག་མི་སྤོང་ན་གཉི་ག་མ་ཡིན་ནོ། །དེ་ལ་འདོད་ཆགས་དང་བྲལ་བ་ཞིག་བདེན་པ་རྣམས་ལ་ལྟ་ན་ཆོས་ཤེས་པ་དང་བཟོད་པ་རྣམས་ཀྱིས་ཉོན་མོངས་པ་དག་མི་སྤོང་ངོ་། །ཤེས་པ་རྣམས་ཀྱིས་ནི་སྦྱོར་བ་དང་རྣམ་པར་གྲོལ་བ་དང་ཁྱད་པར་ཅན་གྱི་ལམ་གྱིས༌[^2392]བསྡུས་པ་རྣམས་ཀྱིས་མི་སྤོང་ངོ་། །[^2393]ཆོས་མངོན་པ་མཛོད་ཀྱི༌[^2394]བཤད་པ་ལས་ལམ་དང་གང་ཟག་བསྟན་པ་ཞེས་བྱ་བ་མཛོད་ཀྱི་གནས་དྲུག་པའོ།། །།

གཞན་ཉི་འོག་པ་རྣམས་ན་རེ་ཡོད་དོ་ཞེས་ཟེར་རོ། །ཇི་ལྟར་ན༌[^2530]ཁོང་དུ་ཆུད་ཅེ་ན། བསྟན་བཅོས་ལས་ཞེས་བྱ་བ་སྨོས་ཏེ། བསྟན་བཅོས་ལས་འདི་སྐད་དུ་མི་ལྡན་པའི་སེམས་ཀྱིས༌[^2531]འདོད་པ་དང་ལྡན་པའི་ཆོས་རྣམས་ཤེས་པར་འགྱུར་བ་ཡོད་དམ་ཞེ་ན། ཤེས་པར་འགྱུར་ཏེ། རིགས་པས་བསྐྱེད་པའི་སྒོ་ནས་མི་རྟག་པ་དང་། སྡུག་བསྔལ་བ༌[^2532]དང་། སྟོང་པ་དང་། བདག་མེད་པ་དང་། རྒྱུ་དང་། ཀུན་འབྱུང་བ་དང་། རབ་ཏུ་སྐྱེ་བ་དང་། རྐྱེན་དང་། འདི་ནི་གནས་ཡོད་དོ། །འདི་ནི་གཞི་ཡོད་དོ་ཞེས་བྱ་བར་ཤེས་པར་འགྱུར་རོ་ཞེས་འབྱུང་ངོ་། །གལ་ཏེ་གང་ལས་འདི་ནི་གནས་ཡོད་དོ། །འདི་ནི་གཞི་ཡོད་དོ་ཞེས་དེ་སྙམ་དུ་ཤེས་པར་འགྱུར་རོ་ཞེས་བྱ་བ་འདིའི་དོན་ནི་འདི་མ་ཡིན་ཏེ། འོན་ཀྱང་མི་རྟག་པ་ལ་སོགས་པ༌[^2533]ཤེས་པར་འགྱུར་བ་གང་ཡིན་པ་འདི་ནི་གནས་ཡོད་དོ། །འདི་ནི་གཞི་ཡོད་དོ་ཞེས་བྱ་བ་ཡིན་ནོ། །ཞེ་ན། མ་ཡིན་ཏེ། གཞན་ནས་མི་འབྱུང་བའི་ཕྱིར་རོ། །གལ་ཏེ་འདི་བསྟན་བཅོས་ཀྱི་དོན་ཡིན་པར་འགྱུར་ན། འདི་སྐད་དུ་མཐོང་བས་སྤང་བར་བྱ་བའི་སེམས་ཀྱིས༌[^2534]འདོད་པ་དང་ལྡན་པའི་ཆོས་རྣམས་ཤེས་པར་འགྱུར་བ་ཡོད་དམ་ཞེ་ན། ཤེས་པར་འགྱུར་ཏེ། རིགས་པ་མ་ཡིན་པས་བསྐྱེད་པའི་སྒོ་ནས་བདག་དང་། བདག་གི་དང་། རྟག་པ་དང་། ཆད་པ་དང་། རྒྱུ་མེད་པ་དང་། བྱེད་པ་མེད་པ་དང་། སྐུར་བ་འདེབས་པ་དང་། མཆོག་དང་། གཙོ་བོ་དང་། ཁྱད་པར་དུ་འཕགས་པ་དང་། དམ་པ་དང་། དག་པ་དང་། གྲོལ་བ་དང་། ངེས་པར་འཛིན་པར་བྱེད་པ་དང་། ནེམ་ནུར་དང་། ཡིད་གཉིས་དང་། ཐེ་ཚོམ་དུ་ཤེས་པར་འགྱུར་ཞིང་། ཆགས་པ་དང་། སྡང་བ་དང་། རློམ་པ་དང་། རྨོངས་པར་འགྱུར་རོ་ཞེས་གང་གསུངས་པ་དེར་ཡང་འདི་སྐད་དུ་འདི་ནི་གནས་ཡོད་དོ། །འདི་ནི༌[^2535]གཞི་ཡོད་དོ་ཞེས་འབྱུང་བར་འགྱུར་བ༌[^2536]ཞིག་ན། དེ་སྐད་ཀྱང་མི་འབྱུང་སྟེ། དེ་ལྟ་བས་ན་འདི་ནི་དེའི་དོན་མ་ཡིན་ནོ། །
