## དཀར་ཆག / Table of Contents
* I. ཀླད་ཀྱི་དོན། [[༄༅༅། །རྒྱ་གར་སྐད་དུ། ཨཱརྱ་བྷ་དྲ་ཙརྱ་པྲ་ཎི་དྷ་ན་མ༌[^1]ཧཱ་]]
* 1. ཕྱག་འཚལ་བ [[བཟང་པོ་སྤྱོད་པའི་སྨོན་ལམ་གྱི་རྒྱལ་པོ་ཆེན་པོ་ལ་དོན་]]
   * 1.1 ལུས་དང་ངག་དང་ཡིད་རྣམ་པར་མ་ཕྱེ་བར་ཕྱག་འཚལ་བ [[དེ་ལ་ཕྱོགས་བཅུ་ཀུན་གྱི་ཞིང་ལ་སོགས་པ༌[^3]ན་བཞུགས་]]
   * 1.2 ལུས་ལ་སོགས་པ་སོ་སོ་རྣམ་པར་ཕྱེ་བས་ཕྱག་འཚལ་བ [[ད་ནི་ལུས་ལ་སོགས་པ་སོ་སོ་རྣམ་པར་ཕྱེ་བས་ཕྱག་འཚལ་བ་]]
      * 1.2.1 ལུས་ཀྱིས་ཕྱག་འཚལ་བ [[དེ་ལ་རེ་ཞིག་ལུས་ཀྱིས་ཕྱག་འཚལ་བ་ནི། ཞིང་གི་རྡུལ་སྙེད་]]
      * 1.2.2 ཡིད་ཀྱིས་ཕྱག་འཚལ་བ [[དེ་བཞིན་དུ་ཡིད་ཀྱིས་ཕྱག་འཚལ་བ་ནི། རྡུལ་གཅིག་སྟེང་]]
      * 1.2.3 ངག་གིས་ཕྱག་འཚལ་བ [[ད་ནི། དེ་དག་བསྔགས་པ་རྒྱ་མཚོ་མི་ཟད་རྣམས། །ཞེས་བྱ་བ་]]
* 2. མཆོད་པ [[ད་ནི་སངས་རྒྱས་བཅོམ་ལྡན་འདས་དེ་དག་ཉིད་ལ་བླ་ན་ཡོད་]]
   * 2.1 བླ་ན་ཡོད་པའི་མཆོད་པ [[མེ་ཏོག་དམ་པ་ཞེས་བྱ་བ་ལ་སོགས་པའི་ཚིགས་སུ་བཅད་པ་གཉིས་]]
   * 2.2 བླ་ན་མེད་པའི་མཆོད་པ [[མཆོད་པ་གང་རྣམས་བླ་མེད་རྒྱ་ཆེ་བ། །ཞེས་བྱ་བ་ལ་སོགས་]]
* 3. སྡིག་པ་བཤགས་པ [[ཀུན་ནས་སློང་བ་དང་། གནས༌[^37]དང་། ངོ་བོ་ཉིད་རྣམ་པ་གསུམ་]]
   * 3.1 ཀུན་ནས་སློང་བ [[དེ་ལ་སྡིག་པ་ཀུན་ནས་སློང་བའི་རྒྱུ་གང་ཞིག་ཡིན་ཞེ་ན།]]
   * 3.2 གནས [[གནས་གང་ཡིན་ཞེ་ན། གནས་ནི་ལུས་དང་ངག་དང་ཡིད་ཡིན་ནོ། །]]
   * 3.3 ངོ་བོ་ཉིད [[ངོ་བོ་ཉིད་ནི། སྡིག་པ་བདག་གིས་བགྱིས་པ་ཅི་མཆིས་པ། །ཞེས་]]
* 4. བསོད་ནམས་ལ་རྗེས་སུ་ཡི་རང་བ [[ད༌[^40]ནི་ཕྱོགས་བཅུའི་འགྲོ་བ་ཀུན་དང་ཞེས་བྱ་བ་ལ་སོགས་]]
* 5. ཆོས་ཀྱི་འཁོར་ལོ་བསྐོར་བར་བསྐུལ་བ [[ད་ནི་ཆོས་ཀྱི་འཁོར་ལོ་བསྐོར་བར་བསྐུལ་བ་ནི། ཕྱོགས་བཅུའི་]]
* 6. དེ་བཞིན་གཤེགས་པ་རྣམས་བཞུགས་པར་གསོལ་བ [[ད་ནི། མྱ་ངན་འདས༌[^56]སྟོན་གང་བཞེད་དེ་དག་ལ། །ཞེས་བྱ་]]
* 7. དགེ་བའི་རྩ་བ་ཡོངས་སུ་བསྔོ་བ [[ད་ནི་ཇི་སྐད་བརྗོད་པའི་ཕྱག་འཚལ་བ་ལ་སོགས་པས་བསྐྱེད་]]
* 8. ཡན་ལག་སོ་སོའི་རབ་ཏུ་དབྱེ་བ [[ད་ནི་བརྒྱད་པ་དེའི་རབ་ཏུ་དབྱེ་བ་སྟེ། ཀུན་དུ་བཟང་པོའི་]]
   * 8.1 བསམ་པ [[དེ་ལ་བསམ་པའི་སྒོ་ནས་ནི་རྣམ་པ་དང་པོའོ། །]]
      * 8.1.1 དེ་བཞིན་གཤེགས་པ་ལ་མཆོད་པ་དང་དགོངས་པ་ཡོངས་སུ་རྫོགས་པའི་བསམ་པ [[དེ་བཞིན་གཤེགས་པ་ལ་མཆོད་པ་དང་དགོངས་པ་ཡོངས་སུ་རྫོགས་]]
      * 8.1.2 སངས་རྒྱས་ཀྱི་ཞིང་ཡོངས་སུ་སྦྱོང་བའི་བསམ་པ [[སངས་རྒྱས་ཀྱི་ཞིང་ཡོངས་སུ་སྦྱོང་བའི་བསམ་པ་ནི། ཕྱོགས་]]
      * 8.1.3 སེམས་ཅན་ཐམས་ཅད་བདེ་བའི་ལྷག་པའི་བསམ་པ [[སེམས་ཅན་ཐམས་ཅད་བདེ་བའི་ལྷག་པའི་བསམ་པ་ནི་ཕྱོགས་བཅུའི་]]
   * 8.2 བྱང་ཆུབ་ཀྱི་སེམས་མི་བརྗེད་པ [[ད་ནི་མི་མཐུན་པའི་ཕྱོགས་སྤང་བ༌[^77]ཉེ་བར་སྟོན་པའི་]]
   * 8.3 མ་གོས་པའི་སྦྱོར་བ [[དེ་ནི་རྣམ་པ་གསུམ་མ་གོས་པའི་སྦྱོར་བ་རྒྱུ་རྣམ་པ་གསུམ་]]
   * 8.4 སེམས་ཅན་ལ་ཕན་པ [[རྣམ་པ་བཞི་པ་འདི་དང་ཕ་རོལ་ཏུ་སེམས་བསྐྱེད་མ་ལུས་པ་]]
   * 8.5 གོ་ཆ [[རྣམ་པ་ལྔ་པ་ནི་གོ་ཆའོ། །]]
      * 8.5.1 སངས་རྒྱས་ཀྱི་ཆོས་ཡོངས་སུ་རྫོགས་པར་བྱེད་པ [[བྱང་ཆུབ་སྤྱོད་པ་ཡོངས་སུ་རྫོགས་བྱེད་ཅིང་། །ཞེས་བྱ་བ་ལ། བྱང་ཆུབ་ཀྱི་]]
      * 8.5.2 སེམས་ཅན་གྱི་སྤྱོད་པ་དང་མཐུན་པར་འདུག་པ [[སྐྱེ་བ་དང་སྐྱེ་བར་སེམས་ཅན་རྣམས་ཀྱི་སེམས་ཀྱི་སྤྱོད་]]
      * 8.5.3 དམ་པའི་ཆོས་རབ་ཏུ་སྦྱིན་པ [[བཟང་པོ་སྤྱོད་པ་དག་ནི་རབ་སྟོན་ཅིང་། །ཞེས་བྱ་བ་ལ་འདིར་]]
   * 8.6 སྐལ་བ་མཉམ་པའི་བྱང་ཆུབ་སེམས་དཔའ་དང་འགྲོགས་པ [[རྣམ་པ་དྲུག་པ་ལུས་དང་ངག་དང་ཡིད་ཀྱི་སྤྱོད་པ་དང་སྨོན་]]
   * 8.7 དགེ་བའི་བཤེས་གཉེན་མཉེས་པར་བྱེད་པ [[རྣམ་པ་བདུན་པ་ཕན་པའི་བསམ་པས་ཉེ་བར་བསྟན་པ་སྒྲུབ་པ༌[^122]དག་]]
   * 8.8 དེ་བཞིན་གཤེགས་པ་མངོན་དུ་གྱུར་པ [[རྣམ་པ་བརྒྱད་པ་དུས་རིང་པར་མཆོད་པའི་བྱ་བས་མི་སྐྱོ་]]
   * 8.9 དམ་པའི་ཆོས་ཡོངས་སུ་འཛིན་པ [[རྣམ་པ་དགུ་པ་འཛིན་པ་དང་སྟོན་པར་བྱེད་པའི་བྱ་བ་དག་གིས་]]
   * 8.10 མི་ཟད་པའི་མཛོད་ཐོབ་པ [[རྣམ་པ་བཅུ་པ་བསོད་ནམས་དང་ཡེ་ཤེས་ལ་སོགས་པ་རྙེད་པས་]]
   * 8.11 འཇུག་པ [[རྣམ་པ་བཅུ་གཅིག་པ་ནི་འཇུག་པའོ། །]]
      * 8.11.1 སངས་རྒྱས་ཀྱི་ཞིང་བལྟ་བ་ལ་འཇུག་པ [[དེ་ལ་སངས་རྒྱས་ཀྱི་ཞིང་བལྟ་བ་ལ་འཇུག་པ་རྣམ་པ་གཉིས་]]
      * 8.11.2 སངས་རྒྱས་ཀྱི་གསུང་ལ་འཇུག་པ [[སངས་རྒྱས་ཀྱི་གསུང་ལ་འཇུག་པ་ནི། གསུང་གཅིག་ཡན་ལག་རྒྱ་]]
      * 8.11.3 ཆོས་ཀྱི་འཁོར་ལོ་བསྐོར་བ་ལ་འཇུག་པ [[ཆོས་ཀྱི་འཁོར་ལོ་བསྐོར་བ་ལ་འཇུག་པ་ནི། དུས་གསུམ་གཤེགས་]]
      * 8.11.4 བསྐལ་པའི་འཇུག་པ་ལ་འཇུག་པ [[བསྐལ་པའི་འཇུག་པ་ལ་འཇུག་པ་ནི། མ་འོངས་བསྐལ་པ་ཀུན་གྱི་]]
      * 8.11.5 དེ་བཞིན་གཤེགས་པ་བལྟ་བ་དང་དེའི་སྤྱོད་ཡུལ་ལ་འཇུག་པ [[དེ་བཞིན་གཤེགས་པ་བལྟ་བ་དང་དེའི་སྤྱོད་ཡུལ་ལ་འཇུག་པ་]]
      * 8.11.6 སངས་རྒྱས་ཀྱི་ཞིང་མངོན་པར་བསྒྲུབ་པ་ལ་འཇུག་པ [[སངས་རྒྱས་ཀྱི་ཞིང་མངོན་པར་བསྒྲུབ་པ་ལ་འཇུག་པ་ནི། གང་]]
      * 8.11.7 དེ་བཞིན་གཤེགས་པ་རྣམས་ཀྱི་དྲུང་དུ་འགྲོ་བ་ལ་འཇུག་པ [[དེ་བཞིན་གཤེགས་པ་རྣམས་ཀྱི་དྲུང་དུ་འགྲོ་བ་ལ་འཇུག་པ་]]
   * 8.12 སྟོབས [[རྣམ་པ་བཅུ་གཉིས་པ་ནི་སྟོབས་སོ། །]]
