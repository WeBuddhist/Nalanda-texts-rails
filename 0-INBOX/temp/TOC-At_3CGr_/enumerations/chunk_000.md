Enumeration Block 1:
ཆོས་ཀྱི་འཁོར་ལོ་གཉིས་པའི་དོན་ཐམས་ཅད་བསྡུ་ན་གཉིས་ཏེ། མངོན་པར་རྟོགས་པའི་དོན་དང་། སྙིང་པོའི་དོན་ནོ། །
Enumeration Block 2:
མདོའི་དོན་གཞན་དུ་ཡང་བཤད་པ་ཡོད་དེ། མདོ་འབྱུང་བའི་རྒྱུ༌[^4]དང་། མདོ་དངོས་སོ། །
དང་པོ་ལ་གཉིས་ཏེ། [^5]གླེང་སློང་བ༌[^6]དང་གླེང་གཞིའོ། །
Enumeration Block 3:
གླེང་གཞི་ལ་གཉིས་ཏེ། ཐུན་མོང་དང་ཁྱད་པར་གྱི་གླེང་གཞིའོ། །
Enumeration Block 4:
ཐུན་མོང་ལ་བཞི་སྟེ། དུས་དང་སྟོན་པ་དང་། གནས་དང་འཁོར་རོ། །
ཁྱད་པར་གྱི༌[^7]གླེང་གཞི་ལ་གཉིས་ཏེ། གཙོ་བོ་དང་འཁོར་ཏིང་ངེ་འཛིན་ལ་ཞུགས་པའོ། །
Enumeration Block 5:
དང་པོ་སུན་འབྱིན་ཏེ། དེ་ལ༌[^11]སྐྱོན་གཉིས་ཏེ། མི་ནུས་པ་དང་དཔང་པོར་མི་འགྱུར་བའོ། །
Enumeration Block 6:
ལན་ནི་ལམ་རྣམ་པ་ལྔ་ལ་རྣམ་པར་ཕྱེ་ནས་བསྟན་པས་བཅུ་གཅིག་ཏུ་འགྱུར་རོ། །
དེ་ལ་ཡང་གཉིས་ཏེ། དབང་པོ་རྟུལ་པོའི་དབང་དུ་བྱས་པ་དང་། རྣོན་པོའི་དབང་དུ་བྱས་པའོ། །
Enumeration Block 7:
དབང་པོ་རྟུལ་པོའི་དབང་དུ་བྱས་པའི་ལན་བཅུ་ཡང་འཕགས་པ་དགོངས་པ་ངེས་པར་འགྲེལ་པ་ལས་དམིགས་པ་རྣམ་པ་བཞི་བཤད་པ་དེས་དོན་གྱི་ཁོག་དབུབ༌[^26]པར་བྱ་སྟེ། རྣམ་པར་རྟོག་པ་དང་བཅས་པའི་གཟུགས་བརྙན་ལྷག་མཐོང་གི་དམིགས་པ་དང་། རྣམ་པར་མི་རྟོགས་པའི༌[^27]གཟུགས་བརྙན་ཞི་གནས་ཀྱི་དམིགས་པ་དང་། དངོས་པོ་མཐའི་དམིགས་པ་དང་། དགོས་པ་ཡོངས་སུ་གྲུབ་པའི་དམིགས་པའོ། །
Enumeration Block 8:
དེ་ལ་ཡང་གསུམ་ཏེ། དམིགས་པ་དང་། དམིགས་པ་དེ་ལ་འཇུག་པའི་རྣམ་པ་དང་། རྣམ་པ་དེས་རྣམ་པར་བལྟས་པའི་འབྲས་བུའོ། །
Enumeration Block 9:
འདི་ལ་ཡང་གསུམ་སྟེ། རྣམ་པ་སོ་སོའི་མཚན་ཉིད་དང་། གྲངས་ངེས་པ་དང་། གོ་རིམས་ངེས་པའོ། །
Enumeration Block 10:
བླ་ན་མེད་པ་ཞེས་བྱ་བ་ལ་སོགས་པ་ལ། དེ་ལ་གཉིས་ཏེ། ཇི་སྙེད་ཡོད་པ་མཁྱེན་པ་དང་ཇི་ལྟར༌[^45]མཁྱེན་པ་སྟེ།
