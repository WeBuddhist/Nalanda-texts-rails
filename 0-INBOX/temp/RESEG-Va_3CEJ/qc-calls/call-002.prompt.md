━━━ ISSUE TYPES ━━━

CONNECTOR_ENDING
  The block ends with a connector particle (དང་། / ཞིང་། / ཅིང་། / ནས། / ལས། /
  སྟེ། / ཏེ།) that grammatically requires continuation. Real issue if the next
  block is the grammatical continuation. False positive if this is a closing verse
  pāda or a deliberate short citation frame.

OBJECTION_REPLY_FUSED
  The block contains both an objection marker (ཅེ་ན། / ཞེ་ན། / སྙམ་ན།) and a reply
  opener (འོ་ན།). These should always be two separate blocks. Almost always a
  real issue.

OVER_LENGTH
  The block exceeds the syllable threshold. Usually NOT wrong: a whole explanation
  unit is legitimately long. Split only if a new node opener (ordinal + title +
  ནི། / ལ་ N།) or the treatment of a new verse is buried mid-block.

SHORT_FRAGMENT
  The block is suspiciously short — may be a stray split artifact that should be
  merged with an adjacent block.

Rules:
- Only output corrections for REAL issues. Skip false positives entirely.
- Block numbers are CONTINUOUS and include heading blocks. Only merge blocks with
  consecutive numbers (N and N+1); never merge across a heading or skip a number.
- "after" must be verbatim from the block and unique within it. To break one long
  block into 3+ units, set "after" to a LIST of substrings in document order.
- Each block number appears in AT MOST ONE operation.
- Heading blocks (lines starting with #) and [VERSE] blocks are NEVER touched.
- If no corrections are needed, output: []
- Output ONLY the JSON array. No commentary, no code fences.

དེ་ལྟ་ན་ཡང་མི་རུང་བ་ཅི་ཞིག་ཡོད། མི་རུང་བ་འདི་དག༌[^625]ཡོད་དེ། གང་གི་ཕྱིར་གཟུགས་དང་སྒྲ་ལ་སོགས་པ་ལྟར་རམ། འདོད་ཆགས་དང་ཞེ་སྡང་ལ་སོགས་པ་ལྟར་འདིའི་རང་གི་ངོ་བོ་ཡང་མི་སྣང་ལ། མིག་དང་རྣ་བ་ལ་སོགས་པ་ལྟར་བྱ་བ་ཡང་མི་སྣང་བ་དེའི་ཕྱིར་རྫས་ཀྱི་ཆོས་མི་སྲིད་པས་མི་རུང་ངོ་། །[^626]གལ་ཏེ་ཆོས་རྣམས་སྐྱེ་བའི་རྒྱུ་ལ་ཐོབ་པའོ༌[^627]ཞེས་བྱའོ་ཞེ་ན། འདུས་མ་བྱས་ཀྱི་མ་ཡིན་པར་འགྱུར་རོ། །ཆོས་གང་དག་མ་ཐོབ་པ་རྣམས་དང་། གང་དག་ས་འཕོས་པ་དང་འདོད་ཆགས་དང་བྲལ་བས་བཏང་སྙོམས་པ༌[^628]དེ་དག་ཀྱང་ཇི་ལྟར་སྐྱེ་བར་འགྱུར་རོ།[^629] །འོན་ཏེ་ལྷན་ཅིག་སྐྱེས་པའི་ཐོབ་པའི་རྒྱུ་རྐྱེན༌[^630]ཡིན་ནོ་ཞེ་ན། དེའི་ཚེ་སྐྱེ་བའམ། སྐྱེ་བའི་སྐྱེ་བ་ཅི་ཞིག་བྱེད་པར་འགྱུར། འཆིང་བ་མཐའ་དག་དང་ལྡན་པ་རྣམས་ཀྱི་ཉོན་མོངས་པ་ཆུང་ངུ་དང་འབྲིང་དང་ཆེན་པོ་སྐྱེ་བའི་ཁྱད་པར་དུ་ཡང་མི་འགྱུར་ཏེ། ཐོབ་པ་བྱེ་བྲག་མེད་པའི་ཕྱིར་རོ། །འོན་ཏེ་དེ་ལས་དེ་དག་གི་བྱེ་བྲག་ཏུ་འགྱུར་ན་ནི་དེ་ཁོ་ན་ལས་དེ་དག་སྐྱེ་བ་ཡིན་ནོ། །དེ་ལྟ་བས་ན་ཐོབ་པ་སྐྱེ་བའི་རྒྱུ་མ་ཡིན་ནོ། །

ཐོབ་པ་སྐྱེ་བའི་རྒྱུ་ཡིན་ནོ་ཞེས་དེ་སྐད་དུ་སུ༌[^631]ཟེར། འོ་ན་ཅི་ཞེ་ན། རྣམ་པར་གཞག་པའི་རྒྱུ་ཡིན་ཏེ། ཐོབ་པ་མེད་ན་འཇིག་རྟེན་པའི་ཡིད་དང་ལྡན་པའི་འཕགས་པ་དང་། སོ་སོའི་སྐྱེ་བོ་རྣམས་ལ་འདི་དག་ནི་འཕགས་པའོ། །འདི་དག་ནི་སོ་སོའི༌[^632]སྐྱེ་བོའོ་ཞེས་རྣམ་པར་གཞག་པར་མི་འགྱུར་རོ། །དེ་ནི་ཉོན་མོངས་པ་སྤངས་པ་དང་མ་སྤངས་པ་ཉིད་ཀྱི་བྱེ་བྲག་ལས་འགྱུར་བར་འོས་སོ། །འདི་དག་ནི་ཉོན་མོངས་པ་སྤངས་པའོ། །འདི་དག་ནི་ཉོན་མོངས་པ་མ་སྤངས་པའོ་ཞེས་བྱ་བ་འདི་ཉིད་དུ་ཡང་ཇི་ལྟར་འགྱུར། ཐོབ་པ་ཡོད་ན་ནི་དེ་དང་བྲལ་མ་བྲལ་ལས་འདི་ཡང་འགྲུབ་བོ། །འདི་ནི་རྟེན་གྱི་བྱེ་བྲག་ལས་འགྲུབ་པར་འགྱུར་ཏེ། འཕགས་པ་རྣམས་ཀྱི་གནས་དེ་ནི་མཐོང་བ་དང་བསྒོམ་པའི་ལམ་གྱི་མཐུས་ཇི་ལྟར་དེ་དག་གིས་སྤང་བར་བྱ་བའི་ཉོན་མོངས་པ་རྣམས་ཡང་འབྱུང་བར་མི་ནུས་པ་དེ་ལྟར་གྱུར་པ་ཡིན་ཏེ། དེའི་ཕྱིར་རྟེན་འབྲུ་མེས་ཚིག་པ་བཞིན་དུ་ཉོན་མོངས་པ་རྣམས་ཀྱི་ས་བོན་དུ་མ་གྱུར་པའམ། འཇིག་རྟེན་པའི་ལམ་གྱི་ས་བོན་གྱི་དངོས་པོ་ཉམས་པར་བྱས་ན་ཉོན་མོངས་པ་སྤངས་པ་ཞེས་བྱ་ལ། བཟློག་པ་ནི་མ་སྤངས་པ་མ༌[^633]ཡིན་པས་གང་མ་སྤངས་པ་དེ་དང་མི་ལྡན།[^634] གང་སྤངས་པ་དེ་དང་ནི་མི་ལྡན་ནོ་ཞེས་གདགས་སོ། །

དེ་ལྟར་ན་སྙོམས་པར་འཇུག་པ་འདི་གཉིས་ནི་ས་ལས་ཀྱང་ཁྱད་པར་ཡོད་དེ། བསམ་གཏན་བཞི་པ་དང་སྲིད་པའི་རྩེ་མོའི་ས་པ་ཡིན་པའི་ཕྱིར་རོ། །སྦྱོར་བ་ལས་ཀྱང་ངེས་པར་འབྱུང་བ་དང་གནས་པའི་འདུ་ཤེས་སྔོན་དུ་བཏང་བའི་ཡིད་ལ་བྱེད་པས་སྦྱོར་བའི་ཕྱིར་རོ། །རྒྱུད་ལས་ཀྱང་སོ་སོའི་སྐྱེ་བོ་དང་འཕགས་པའི་རྒྱུད་ལ་སྐྱེ་བའི་ཕྱིར་རོ། །འབྲས་བུ་ལས་ཀྱང་འདུ་ཤེས་མེད་པ་པ་དང་སྲིད་པའི་རྩེ་མོའི་འབྲས་བུ་ཡིན་པའི་ཕྱིར་རོ། །མྱོང་བར་འགྱུར་བ་ལས་ཀྱང་མྱོང་བར་འགྱུར་བར་ངེས་པ་དང་གཉི་ག་ཡིན་པའི་ཕྱིར་རོ། །དང་པོ་སྐྱེད་པ་ལས་ཀྱང་ཁམས་གཉིས་དང་མིའི་ནང་དུ་སྐྱེད་པའི༌[^732]ཕྱིར་རོ། །

གང་ཡང་ཡེ་ཤེས་ལ་འཇུག་པ་ལས། སེམས་གཅིག་ལ་འབྱུང་བ་གང་ཞེ་ན། སྨྲས་པ། སྐྱེ་བའོ། །འཇིག་པ་གང་ཞེ་ན། འཆི་བའོ། །གནས་པ་གཞན་དུ་འགྱུར་བ་ཉིད༌[^811]གང་ཞེ་ན། རྒ་བའོ་ཞེས་གསུངས་པ་དེར་ཡང་རིས་མཐུན་པའི་སེམས་ལ་རུང་བར་འགྱུར་རོ། །སྐད་ཅིག་མ་རེ་རེ་ལ་ཡང་རྫས་གཞན་དུ་རྟོགས་པ༌[^812]མེད་པ༌[^813]བཞིན་དུ་འདུས་བྱས་ཀྱི་དེ་དག་རུང་སྟེ། ཇི་ལྟ་ཞེ་ན། སྐད་ཅིག་མ་རེ་རེ་ལ་མ་བྱུང་བ་ལས་བྱུང་བ་ནི་སྐྱེ་བའོ། །བྱུང་ནས་མེད་པ་ནི་འཇིག་པའོ། །སྔ་མ་སྔ་མ་དང་ཕྱི་མ་ཕྱི་མའི་སྐད་ཅིག་མ་རྗེས་སུ་འབྲེལ་བ་ནི་གནས་པའོ། །དེའི་མི་འདྲ་བ་ཉིད་ནི་གནས་པ་གཞན་དུ་འགྱུར་བ་ཉིད་དོ། །

འོ་ན་གང་གི་ཚེ་འདྲ་བར་ཡང་སྐྱེའོ་ཞེ་ན། དེ་དག་ཁྱད་པར་མེད་པ་མ་ཡིན་ནོ། །འདི་ཇི་ལྟར་ཤེས་ཤེ་ན། རྡོ་རྗེ་ལ་སོགས་པ་འཕངས་པ་དང་མ་འཕངས་པ་དང་། སྟོབས་ཆེན་པོ་དང་། སྟོབས་ཆུང་ངུས་འཕངས་པ་བུལ་བ་དང་མྱུར་བ་དང་། ཆེས་དལ་བ་དང་། ཆེས་མྱུར་བར་ལྟུང་བའི་དུས་ཀྱི་བྱེ་བྲག་ལས་དེའི་འབྱུང་བ་རྣམས་ཡོངས་སུ་གྱུར་པའི་བྱེ་བྲག་འགྲུབ་པའི་ཕྱིར་རོ། །འདུས་བྱས་རྣམས་ནི་བྱེ་བྲག་གི་ཁྱད་པར་ཆེན་པོ་མཚར་ཅིག་མེད་པས་གཞན་དུ་འགྱུར་བ་ཉིད་ཡོད༌[^814]དུ་ཟིན་ཀྱང་འདྲ་བ་བཞིན་དུ་སྣང་ངོ་། །འོ་ན་ནི་སྒྲ་དང་མེ་ལྕེའི་སྐད་ཅིག་མ་ཐ་མ་དང་། ཡོངས་སུ་མྱ་ངན་ལས་འདའ་བའི་ཚེའི་སྐྱེ་མཆེད་དྲུག་ལ་སྐད་ཅིག་མ་ཕྱི་མ་མེད་པའི་ཕྱིར་གནས་པ་གཞན་དུ་འགྱུར་བ༌[^815]མེད་པས་མཚན་ཉིད་རྣམ་པར་གཞག་པ་མ་ཁྱབ་པ་ཅན་དུ་འགྱུར་རོ། །འདུས་བྱས་ཀྱི་མཚན་ཉིད་ནི་གནས་པ་ཁོ་ན་ཡང་མ་ཡིན་གྱི་གནས་པ་གཞན་དུ་འགྱུར་བ་ཉིད་ཀྱང་ཡིན་ནོ། །དེའི་ཕྱིར་གང་ལ་གནས་པ་ཡོད་པ་དེ་ལ་གདོན་མི་ཟ་བར་གཞན་དུ་འགྱུར་བ་ཉིད་ཀྱང་ཡོད་པས་རྣམ་པར་གཞག་པ་ཉམས་པ་མེད་དོ། །མདོར་ན་བཅོམ་ལྡན་འདས་ཀྱིས་ནི་མདོ་འདི་ལས༌[^816]འདུས་བྱས་ཞེས་བྱ་བ་ནི། གང་མ་བྱུང་བ་ལས་འབྱུང་བ་དང་། བྱུང་ནས་ཀྱང་མི་འབྱུང་བ་འདི་འདུས་བྱས་ཀྱི་མཚན་ཉིད་ཡིན་པར་གསུངས་ལ། འདིའི་གནས་པ་ཞེས་བྱ་བ་རྒྱུན་གང་ཡིན་པ་དེ་ཡང་གཞན་དང་གཞན་དུ་འགྱུར་བ་ཡིན་ན། འདིར་སྐྱེ་བ་ལ་སོགས་པ་རྫས་གཞན་དག་གིས་ཅི་ཞིག་བྱ། ད་ནི་ཇི་ལྟར་ན་མཚན་ཉིད་ཀྱི་གཞིའི་ཆོས་དེ༌[^817]ཉིད་ཀྱི་མཚན་ཉིད་དུ་རུང་བར་འགྱུར་ཞེ་ན། རེ་ཞིག་ཇི་ལྟར་ན་སྐྱེས་བུ་ཆེན་པོའི་མཚན་རྣམས་སྐྱེས་བུ་ཆེན་པོ༌[^818]ལས་མི་གཞན་པ་ཡིན། བ་ལང་ཉིད་ཀྱི་མཚན་ཉིད་ལྐོག་ཤལ་དང་། མཇུག་མ་དང་། ནོག་དང་། རྨིག་པ་དང་། རྭ་རྣམས་ཀྱང་བ་ལང་ལས་མི་གཞན་པ་ཡིན། སའི་ཁམས་ལ་སོགས་པའི་མཚན་ཉིད་སྲ་བ་ཉིད་ལ་སོགས་པ་རྣམས་ཀྱང་དེ་དག་ལས་མི་གཞན་པ་ཡིན། གཞན་ཡང་ཇི་ལྟར་གྱེན་དུ་འགྲོ་བ་ལས་ནི༌[^819]ཐག་རིང་པོ་ནས་དུ་བ་ལ་དུ་བ་ཉིད་དུ་ཤེས་མོད་ཀྱི། དེ་ནི་དེ་ལས་ཀྱང་མི་གཞན་པ་ལྟར་འདིར་ཡང་ཚུལ་དེ་ཉིད་ཡིན་ནོ། །འདུས་བྱས་གཟུགས་ལ་སོགས་པ་རང་གི་ངོ་བོ་བཟུང་ཡང་ཇི་སྲིད་དུ་སྔ་ན་མེད་པ་དང་ཕྱིས་མེད་པ་དང་རྒྱུན་གྱི་བྱེ་བྲག་མི་ཤེས་པ་དེ་སྲིད་དུ་འདུས་བྱས་ཉིད་དུ་མི་ཤེས་ཏེ། དེ་ལྟ་བས་ན་དེ་ཉིད་ཀྱིས་དེ་མཚོན་པ་ཡང་མ་ཡིན་ལ། དེ་དག་ལས་སྐྱེ་བ་ལ་སོགས་པ་རྫས་གཞན་ཉིད་དུ་ཡོད་པ་ཡང་མ་ཡིན་ནོ། །

འོན་ཏེ་སྐྱེ་བ་ལ་སོགས་པ་རྫས་གཞན་ཞིག་ཏུ་གྱུར་ན་ཡང་ཅི་ལྟར༌[^820]འགྱུར་ཞེ་ན། དེ་དག་ནི་ལྷན་ཅིག་འབྱུང་བའི་ཕྱིར་ཆོས་གཅིག་དུས་གཅིག་ཏུ་སྐྱེས་པ༌[^821]དང་གནས་པ་དང་རྒས་པ་དང་ཞིག་པར་འགྱུར་རོ། །མ་ཡིན་ཏེ། བྱ་བའི་དུས་ཐ་དད་པའི་ཕྱིར་རོ། །སྐྱེ་བ་མ་འོངས་པ༌[^822]ནི་བྱ་བ་བྱེད་དེ། འདི་ལྟར་མ་སྐྱེས་པ་སྐྱེད་དོ། །བསྐྱེད་ཟིན་པའི་ཆོས་ལ་ནི་ད་ལྟར་གནས་པ་ལ་སོགས་པ་བྱ་བ་བྱེད་པས་གང་གི་ཚེ་སྐྱེ་བ་དེ༌[^823]ཚེ་གནས་པའམ། རྒ་བ་འམ། འཇིག་པར་མི་འགྱུར་རོ། །རེ་ཞིག་འདིར་ཅི་མ་འོངས་པ་རྫས་སུ་ཡོད་དམ་མེད་ཅེས་བྱ་བ་འདི་དཔྱད་དགོས་པར་འགྱུར་ཏེ། ཕྱིས་ནི་སྐྱེད་པར་བྱེད་དམ་འོན་ཏེ་མ་ཡིན་ཞེས་བྱ་བ་འགྲུབ་པར་འགྱུར་རོ། །དེ་ཡོད་དུ་ཆུག༌[^824]ན་ཡང་སྐྱེ་བ་བྱ་བ་བྱེད་ན་ཇི་ལྟར་མ་འོངས་པར༌[^825]འགྲུབ་པར་འགྱུར། དེ་ལྟ་བས་ན་མ་འོངས་པའི་མཚན་ཉིད་ཀྱང་བརྗོད་པར་བྱའོ། །བྱུང་བ་ཡང་བྱ་བ་ཞིག་པ་ཡིན་ན་ཇི་ལྟར་ན་ད་ལྟར་འགྲུབ་པར་འགྱུར། དེ་ལྟ་བས་ན་ད་ལྟའི་མཚན་ཉིད་ཀྱང་བརྗོད་པར་བྱའོ། །གནས་པ་ལ་སོགས་པ་ཡང་ཅིག་ཅར་བྱ་བ་ལ་འཇུག་པ་ཡིན་ན་ནི་སྐད་ཅིག་མ་གཅིག་ཁོ་ན་ལ་ཆོས་གནས་པ་དང་རྒ་བ་དང་འཇིག་པར༌[^826]ཐལ་བར་འགྱུར་ཏེ། འདི་གང་གི་ཚེ་གནས་པས་གནས་པར་བྱེད་པ་དེ་ཉིད་ཀྱི་ཚེ་རྒ་བས་རྒ་བར་བྱེད་ཅིང་མི་རྟག་པ་ཉིད་ཀྱིས་འཇིག་པར་བྱེད་པའི་ཕྱིར་འདི་ཅི་དུས་དེར་གནས་སམ། འོན་ཏེ་རྒ་བའམ། [^827]འོན་ཏེ་འཇིག་པར་འགྱུར། གང་ཡང་སྐྱེ་བ་ལ་སོགས་པ་རྣམས་ཀྱང་བྱ་བ་རིམ་གྱིས་བྱེད་དོ་ཞེས་ཟེར་བ་དེའི་ལྟར་ན་སྐད་ཅིག་མ་གཅིག་ལ་གནོད་པར་འགྱུར་རོ། །

འོ་ན་གང་གི་ཚེ་འདྲ་བར་ཡང་སྐྱེའོ་ཞེ་ན། དེ་དག་ཁྱད་པར་མེད་པ་མ་ཡིན་ནོ། །འདི་ཇི་ལྟར་ཤེས་ཤེ་ན། རྡོ་རྗེ་ལ་སོགས་པ་འཕངས་པ་དང་མ་འཕངས་པ་དང་། སྟོབས་ཆེན་པོ་དང་། སྟོབས་ཆུང་ངུས་འཕངས་པ་བུལ་བ་དང་མྱུར་བ་དང་། ཆེས་དལ་བ་དང་། ཆེས་མྱུར་བར་ལྟུང་བའི་དུས་ཀྱི་བྱེ་བྲག་ལས་དེའི་འབྱུང་བ་རྣམས་ཡོངས་སུ་གྱུར་པའི་བྱེ་བྲག་འགྲུབ་པའི་ཕྱིར་རོ། །འདུས་བྱས་རྣམས་ནི་བྱེ་བྲག་གི་ཁྱད་པར་ཆེན་པོ་མཚར་ཅིག་མེད་པས་གཞན་དུ་འགྱུར་བ་ཉིད་ཡོད༌[^814]དུ་ཟིན་ཀྱང་འདྲ་བ་བཞིན་དུ་སྣང་ངོ་། །འོ་ན་ནི་སྒྲ་དང་མེ་ལྕེའི་སྐད་ཅིག་མ་ཐ་མ་དང་། ཡོངས་སུ་མྱ་ངན་ལས་འདའ་བའི་ཚེའི་སྐྱེ་མཆེད་དྲུག་ལ་སྐད་ཅིག་མ་ཕྱི་མ་མེད་པའི་ཕྱིར་གནས་པ་གཞན་དུ་འགྱུར་བ༌[^815]མེད་པས་མཚན་ཉིད་རྣམ་པར་གཞག་པ་མ་ཁྱབ་པ་ཅན་དུ་འགྱུར་རོ། །འདུས་བྱས་ཀྱི་མཚན་ཉིད་ནི་གནས་པ་ཁོ་ན་ཡང་མ་ཡིན་གྱི་གནས་པ་གཞན་དུ་འགྱུར་བ་ཉིད་ཀྱང་ཡིན་ནོ། །དེའི་ཕྱིར་གང་ལ་གནས་པ་ཡོད་པ་དེ་ལ་གདོན་མི་ཟ་བར་གཞན་དུ་འགྱུར་བ་ཉིད་ཀྱང་ཡོད་པས་རྣམ་པར་གཞག་པ་ཉམས་པ་མེད་དོ། །མདོར་ན་བཅོམ་ལྡན་འདས་ཀྱིས་ནི་མདོ་འདི་ལས༌[^816]འདུས་བྱས་ཞེས་བྱ་བ་ནི། གང་མ་བྱུང་བ་ལས་འབྱུང་བ་དང་། བྱུང་ནས་ཀྱང་མི་འབྱུང་བ་འདི་འདུས་བྱས་ཀྱི་མཚན་ཉིད་ཡིན་པར་གསུངས་ལ། འདིའི་གནས་པ་ཞེས་བྱ་བ་རྒྱུན་གང་ཡིན་པ་དེ་ཡང་གཞན་དང་གཞན་དུ་འགྱུར་བ་ཡིན་ན། འདིར་སྐྱེ་བ་ལ་སོགས་པ་རྫས་གཞན་དག་གིས་ཅི་ཞིག་བྱ། ད་ནི་ཇི་ལྟར་ན་མཚན་ཉིད་ཀྱི་གཞིའི་ཆོས་དེ༌[^817]ཉིད་ཀྱི་མཚན་ཉིད་དུ་རུང་བར་འགྱུར་ཞེ་ན། རེ་ཞིག་ཇི་ལྟར་ན་སྐྱེས་བུ་ཆེན་པོའི་མཚན་རྣམས་སྐྱེས་བུ་ཆེན་པོ༌[^818]ལས་མི་གཞན་པ་ཡིན། བ་ལང་ཉིད་ཀྱི་མཚན་ཉིད་ལྐོག་ཤལ་དང་། མཇུག་མ་དང་། ནོག་དང་། རྨིག་པ་དང་། རྭ་རྣམས་ཀྱང་བ་ལང་ལས་མི་གཞན་པ་ཡིན། སའི་ཁམས་ལ་སོགས་པའི་མཚན་ཉིད་སྲ་བ་ཉིད་ལ་སོགས་པ་རྣམས་ཀྱང་དེ་དག་ལས་མི་གཞན་པ་ཡིན། གཞན་ཡང་ཇི་ལྟར་གྱེན་དུ་འགྲོ་བ་ལས་ནི༌[^819]ཐག་རིང་པོ་ནས་དུ་བ་ལ་དུ་བ་ཉིད་དུ་ཤེས་མོད་ཀྱི། དེ་ནི་དེ་ལས་ཀྱང་མི་གཞན་པ་ལྟར་འདིར་ཡང་ཚུལ་དེ་ཉིད་ཡིན་ནོ། །འདུས་བྱས་གཟུགས་ལ་སོགས་པ་རང་གི་ངོ་བོ་བཟུང་ཡང་ཇི་སྲིད་དུ་སྔ་ན་མེད་པ་དང་ཕྱིས་མེད་པ་དང་རྒྱུན་གྱི་བྱེ་བྲག་མི་ཤེས་པ་དེ་སྲིད་དུ་འདུས་བྱས་ཉིད་དུ་མི་ཤེས་ཏེ། དེ་ལྟ་བས་ན་དེ་ཉིད་ཀྱིས་དེ་མཚོན་པ་ཡང་མ་ཡིན་ལ། དེ་དག་ལས་སྐྱེ་བ་ལ་སོགས་པ་རྫས་གཞན་ཉིད་དུ་ཡོད་པ་ཡང་མ་ཡིན་ནོ། །

འོན་ཏེ་སྐྱེ་བ་ལ་སོགས་པ་རྫས་གཞན་ཞིག་ཏུ་གྱུར་ན་ཡང་ཅི་ལྟར༌[^820]འགྱུར་ཞེ་ན། དེ་དག་ནི་ལྷན་ཅིག་འབྱུང་བའི་ཕྱིར་ཆོས་གཅིག་དུས་གཅིག་ཏུ་སྐྱེས་པ༌[^821]དང་གནས་པ་དང་རྒས་པ་དང་ཞིག་པར་འགྱུར་རོ། །མ་ཡིན་ཏེ། བྱ་བའི་དུས་ཐ་དད་པའི་ཕྱིར་རོ། །སྐྱེ་བ་མ་འོངས་པ༌[^822]ནི་བྱ་བ་བྱེད་དེ། འདི་ལྟར་མ་སྐྱེས་པ་སྐྱེད་དོ། །བསྐྱེད་ཟིན་པའི་ཆོས་ལ་ནི་ད་ལྟར་གནས་པ་ལ་སོགས་པ་བྱ་བ་བྱེད་པས་གང་གི་ཚེ་སྐྱེ་བ་དེ༌[^823]ཚེ་གནས་པའམ། རྒ་བ་འམ། འཇིག་པར་མི་འགྱུར་རོ། །རེ་ཞིག་འདིར་ཅི་མ་འོངས་པ་རྫས་སུ་ཡོད་དམ་མེད་ཅེས་བྱ་བ་འདི་དཔྱད་དགོས་པར་འགྱུར་ཏེ། ཕྱིས་ནི་སྐྱེད་པར་བྱེད་དམ་འོན་ཏེ་མ་ཡིན་ཞེས་བྱ་བ་འགྲུབ་པར་འགྱུར་རོ། །དེ་ཡོད་དུ་ཆུག༌[^824]ན་ཡང་སྐྱེ་བ་བྱ་བ་བྱེད་ན་ཇི་ལྟར་མ་འོངས་པར༌[^825]འགྲུབ་པར་འགྱུར། དེ་ལྟ་བས་ན་མ་འོངས་པའི་མཚན་ཉིད་ཀྱང་བརྗོད་པར་བྱའོ། །བྱུང་བ་ཡང་བྱ་བ་ཞིག་པ་ཡིན་ན་ཇི་ལྟར་ན་ད་ལྟར་འགྲུབ་པར་འགྱུར། དེ་ལྟ་བས་ན་ད་ལྟའི་མཚན་ཉིད་ཀྱང་བརྗོད་པར་བྱའོ། །གནས་པ་ལ་སོགས་པ་ཡང་ཅིག་ཅར་བྱ་བ་ལ་འཇུག་པ་ཡིན་ན་ནི་སྐད་ཅིག་མ་གཅིག་ཁོ་ན་ལ་ཆོས་གནས་པ་དང་རྒ་བ་དང་འཇིག་པར༌[^826]ཐལ་བར་འགྱུར་ཏེ། འདི་གང་གི་ཚེ་གནས་པས་གནས་པར་བྱེད་པ་དེ་ཉིད་ཀྱི་ཚེ་རྒ་བས་རྒ་བར་བྱེད་ཅིང་མི་རྟག་པ་ཉིད་ཀྱིས་འཇིག་པར་བྱེད་པའི་ཕྱིར་འདི་ཅི་དུས་དེར་གནས་སམ། འོན་ཏེ་རྒ་བའམ། [^827]འོན་ཏེ་འཇིག་པར་འགྱུར། གང་ཡང་སྐྱེ་བ་ལ་སོགས་པ་རྣམས་ཀྱང་བྱ་བ་རིམ་གྱིས་བྱེད་དོ་ཞེས་ཟེར་བ་དེའི་ལྟར་ན་སྐད་ཅིག་མ་གཅིག་ལ་གནོད་པར་འགྱུར་རོ། །

དེ་ལ་རང་ལས་གཞན་པ་བྱེད་རྒྱུའི་རྒྱུ། །རང་གི་ངོ་བོ་མ་གཏོགས་པ་ཆོས་ཐམས་ཅད་ནི་ཆོས་འདུས་བྱས་ཀྱི་བྱེད་རྒྱུའི་རྒྱུ་ཡིན་ཏེ། སྐྱེ་བ་ལ་བགེགས༌[^894]མི་བྱེད་པའི་ངོ་བོར་གནས་པའི་ཕྱིར་རོ། །ཟག་པ་གང་དག་མི་ཤེས་པ་དེ་ལ་སྐྱེ་བ་དེ་དག་ཤེས་པ་དེ་ལ་མི་སྐྱེའོ་ཞེས་གསུངས་པས་དེ་དག་སྐྱེ་བ་ལ་ཡང་ཤེས་པ་གེགས་བྱེད་ལ། སྐར་མ་རྣམས་མཐོང་བ་ལ་ཡང་ཉི་མའི་འོད་བགེགས་བྱེད༌[^895]པ་མ་ཡིན་ན༌[^896]ནམ། ཇི་ལྟར་ན་རང་གི་ངོ་བོ་མ་གཏོགས་པ་ཆོས་ཐམས་ཅད་ཆོས་འདུས་བྱས་ཀྱི་བྱེད་རྒྱུ་ཡིན་ཞེ་ན། སྐྱེ་བ་ལ་བགེགས་མི༌[^897]བྱེད་པའི་ངོ་བོར༌[^898]གནས་པའི་ཕྱིར་ཤེས་པར་བྱའོ། །རེ་ཞིག་སྐྱེ་བ་ལ་བགེགས་བྱེད༌[^899]ནུས་པ་རྣམས་ནི་བགེགས༌[^900]མི་བྱེད་པའི་ཕྱིར་རྒྱུ་ཉིད་དུ་ཡང་འགྱུར་ཏེ། དཔེར་ན་སྤྱོད་པར་བྱེད་པའི༌[^901]མི་འཚེ་བའི་དབང་དུ་བྱས་ནས༌[^902]གྲོང་མི་རྣམས་བདག་ཅག་ནི་རྗེ་བོས་བདེ་བར་བྱས་སོ་ཞེས་འཛེར་བ་ལྟ་བུ་ཡིན་ན།[^903] གང་ཞིག་བགེགས༌[^904]བྱེད་པར་མི་ནུས་པ་དཔེར་ན་ཆོས་ཐམས་ཅད་སྐྱེ་བ་ལ་མྱ་ངན་ལས་འདས་པ་དང་། མི་སྐྱེ་བའི་ཆོས་ཅན་རྣམས་ལྟ་བུ་དང་། གཟུགས་མེད་པའི་སེམས་ཅན་གྱི་ཕུང་པོ་སྐྱེ་བ་ལ་དམྱལ་བ༌[^905]ལ་སོགས་པ་དག་ལྟ་བུ་དེ་གོ་ཇི་ལྟར་ན་རྒྱུའི་དངོས་པོ་ཡིན། དེ་དག་མེད་དུ་ཟིན་ཀྱང་དེ་ཁོ་ན་བཞིན་དུ་བགེགས༌[^906]བྱེད་མི་ནུས་པར་འགྱུར་ཏེ། སྤྱོད་པར་བྱེད་པར་མི་ནུས་བཞིན་དུ་ཡང་དེ་སྐད་དུ་འཛེར་བ་ཡོད་པས་འདིར་དཔེ་ནི་དེ་ཉིད་ཡིན་ནོ། །འདི་ནི་སྤྱིར་བསྟན་པ་ཡིན་གྱི། བྱེད་རྒྱུའི་རྒྱུ་གཙོ་བོ་གང་ཡིན་པ་འདི་ནི་བསྐྱེད་པར་བྱ་བ་ལ་ཡང་ནུས་པ་ཡོད་དེ༌[^907]དཔེར་ན་མིག་གི་རྣམ་པར་ཤེས་པ་ལ་མིག་དང་གཟུགས་དག་དང་། ལུས་ལ་ཟས་དང་། མྱུ་གུ་ལ་སོགས་པ་ལ་ས་བོན་ལ་སོགས་པ་བཞིན་ནོ། །གང་ཞིག་འདི་སྐད་དུ་གལ་ཏེ་མི་སྒྲིབ་པའི་ངོ་བོས་ཆོས་ཐམས་ཅད་རྒྱུ་དག་ཡིན་ནོ། །[^908]ཅིའི་ཕྱིར་ཆོས་ཐམས་ཅད་ཅིག་ཅར་སྐྱེ་བར་མི་འགྱུར་རོ། །[^909]སྲོག་གཅོད་པ་ལ་སོགས་པ༌[^910]ལ་ཡང་གཤེད་མ་པ་བཞིན་དུ་ཐམས་ཅད་དེ་བསྟེན་པར༌[^911]མི་འགྱུར་ཞེས་རྒོལ་བར་བྱེད་པ་དེའི་དེ་ནི་ཀླན་ཀར་མི་རུང་སྟེ། འདི་ལྟར་མི་སྒྲིབ་པའི་ངོ་བོས་ཆོས་ཐམས་ཅད་རྒྱུ་ཡིན་པར་དམ་འཆའི། བྱེད་པ་པོའི་ངོ་བོ་ནི་མ་ཡིན་པའི་ཕྱིར་རོ། །

མ་འོངས་པ་ཁོ་ན་སྐལ་བ་མཉམ་པའི་རྒྱུ་མ་ཡིན་ནོ་ཞེས་བྱ་བ་འདི་དག་ལས་སྨྲས་པ། བསྟན་བཅོས་ལས་ཏེ། སྐལ་བ་མཉམ་པའི་རྒྱུ་གང་ཞེ་ན། དགེ་བའི་རྩ་བ་སྔར་བྱུང་བ་རྣམས་ནི་རང་གི་ཁམས་ན་དགེ་བའི་རྩ་བ་ཕྱིས་འབྱུང་བ་རྣམས་དང་། དེ་དག་དང་མཚུངས་པར་ལྡན་པའི་ཆོས་རྣམས་ཀྱི་སྐལ་བ་མཉམ་པའི་རྒྱུས་རྒྱུ་ཡིན་ནོ། །དེ་ལྟར་ན་འདས་པ༌[^948]དང་། ད་ལྟར་བྱུང་བ་རྣམས་ཀྱི་ཡིན་ནོ། །འདས་པ་དང་ད་ལྟར་བྱུང་བ་རྣམས་ནི་མ་འོངས་པ་རྣམས་ཀྱི་ཡིན་ནོ་ཞེས་བརྗོད་པར་བྱའོ་ཞེས་འབྱུང་ངོ་། །ཆོས་གང་ཆོས་གང་གི་རྒྱུའི་ཡིན་པའི་ཆོས་དེ་རེས་འགའ་ཞིག་ཆོས་དེའི་རྒྱུ་མ་ཡིན་པ་ཡིན་ནམ་ཞེ་ན་སྨྲས་པ། ནམ་ཡང་མ་ཡིན་ནོ་ཞེས་འབྱུང་བ་འདི་ཡང་བསྟན་བཅོས་ཡིན་ནོ། །ལྷན་ཅིག་འབྱུང་བ་དང་མཚུངས་པར་ལྡན་པ་དང་རྣམ་པར་སྨིན་པའི་རྒྱུ་ལས་དགོངས་ནས་གསུངས་པའི་ཕྱིར་དེ་ནི་ཉེས་པ་མེད་དོ། །གང་ཞིག་ཆོས་མ་འོངས་པ་དེ་ཡང་སྐྱེ་བའི་ཚེའི་གནས་སྐབས་ན་སྐལ་བ་མཉམ་པའི་རྒྱུ་ཉིད་དུ་ངེས་པར་འགྱུར་བ་ཡིན་ནོ། །དེའི་ཕྱིར་ཐ་མའི་གནས་སྐབས་དེ་ལས༌[^949]དགོངས་ནས་ནམ་ཡང་རྒྱུ་མ་ཡིན་པ་མ་ཡིན་ནོ་ཞེས་གསུངས་སོ་སྙམ་དུ་སེམས་པ་དེ་ནི་དེའི་ལན་དུ་མི་རུང་སྟེ། འདི་ལྟར་ཆོས་དེ་སྐྱེ་བའི་གནས་སྐབས་ཀྱི་སྔོན་རོལ་ནས༌[^950]སྐལ་བ་མཉམ་པའི་རྒྱུ་མ་ཡིན་པ་ལས་ཕྱིས་ཡིན་པས་སོ། །ཆོས་གང་ཞིག་ཆོས་གང་གི༌[^951]མཚུངས་པ༌[^952]དེ་མ་ཐག་པ་ཡིན་པའི་ཆོས་དེ་རེས་འགའ་ཞིག་ཆོས་དེའི་མཚུངས་པ་དེ་མ་ཐག་པ་མ་ཡིན༌[^953]ནམ་ཞེས་བྱ་བ་འདྲི་བ་འདི་ཡང་ཡོངས་སུ་རྟོགས་པ་འདིས་རེས་འགའ་ཡང༌[^954]མ་ཡིན༌[^955]ནོ་ཞེས་བརྗོད་པར་ནུས་ན་ཅིའི་ཕྱིར་འདི་སྐད་དུ་གལ་ཏེ་ཆོས་དེ་མ་སྐྱེས་པར་གྱུར་ནའོ་ཞེས་གསུངས། དེར་ཇི་ལྟ་བ་དེ་བཞིན་འདིར་ཡང་བརྗོད་པར་བྱ་ལ། འདིར་ཇི་ལྟ་བ་དེ་བཞིན་དེར་ཡང་བརྗོད་པར་བྱའོ་ཞེས་སྒོ་གཉིས་སུ་བསྟན་པར་བྱ་བའི་བར་རོ། །དེ་ལྟ་ཡིན་ན་ཡོན་ཏན་ཅི་ཞིག་འཐོབ་པར་འགྱུར་ཏེ། དེ་ལྟ་ན་འདིར༌[^956]བསྟན་བཅོས་བྱེད་པ་མི༌[^957]མཁས་པ་ཁོ་ནར་ཡིད་ཆེས་པར་འགྱུར་རོ། །དེ་ལྟ་བས་ན་འདིར་ལན་སྔ་མ་ཁོ་ན་ལེགས་པ་ཡིན་ནོ། །

དེ་ལྟ༌[^961]ན་སྐལ་བ་མཉམ་པའི་རྒྱུ་མ་ཡིན་པ་ལས་རྒྱུ་ཡིན་པར་འགྱུར་བ་མ་ཡིན་ནམ། གནས་སྐབས་ནི་འདོད་པ་ཁོ་ན་ཡིན་གྱི་རྫས་ལ་ནི་མ་ཡིན་ཏེ། ཚོགས་པ་ནི་གནས་སྐབས་ཀྱི་འབྲས་བུ་ཅན་ཡིན་གྱི། རྫས་ཀྱི་འབྲས་བུ་ཅན་ནི་མ་ཡིན་ནོ། །གལ་ཏེ་རྣམ་པར་སྨིན་པའི་རྒྱུ་བཞིན་དུ་སྐལ་བ་མཉམ་པའི་རྒྱུ་ཡང་མ་འོངས་པ་ཡིན་ན་ཅིར་འགྱུར་ཞེ་ན། བསྟན་བཅོས་ལས་དེ་སྨོས་པར་འགྱུར་རོ། །འབྲས་བུ་འབྱིན་པ༌[^962]དང་འཛིན་པར་བྱེད་ནུས་པ་གང་ཡིན་པ་དེ་ཁོ་ན་སྨོས་པའི་ཕྱིར་ཉེས་པ་མེད་དོ་ཞེ་ན། དེ་ནི་མ་ཡིན་ཏེ། སྐལ་བ་མཉམ་པའི་རྒྱུ་ནི་རྒྱུ་མཐུན་པའི་འབྲས་བུས་འབྲས་བུ་དང་བཅས་པ་ཡིན་ན་དེ་ཡང་མ་འོངས་པ་ལ་རིགས་པ་མ་ཡིན་ཏེ། སྔ་ཕྱི་མེད་པའི་ཕྱིར་རོ། །བྱུང་ཟིན་པ་ཡང་མ་འོངས་པའི་རྒྱུ་མཐུན་པར་མི་རུང་སྟེ། དཔེར་ན་ད་ལྟའི་འདས་པ་བཞིན་ནོ། །རྒྱུ་བས་འབྲས་བུ་སྔ་ན་མི་རུང་བས་སྐལ་བ་མཉམ་པའི་རྒྱུ་མ་འོངས་པ་ནི་མེད་དོ། །དེ་ལྟ་ན་རྣམ་པར་སྨིན་པའི་རྒྱུ་ཡང་མ་འོངས་པ་ཡིན་པར་མི་འགྱུར་ཏེ། རྣམ་པར་སྨིན་པའི་འབྲས་བུ་སྔ་བ་དང་ལྷན་ཅིག་པ་མི་རུང་བའི་ཕྱིར་ལ། མ་འོངས་པའི་དུས་ལ་ཡང་སྔ་ཕྱི་མེད་པའི་ཕྱིར་རོ་ཞེ་ན། དེ་ནི་མ་ཡིན་ཏེ། སྐལ་བ་མཉམ་པའི་རྒྱུ་ནི་སྔ་ཕྱི་མེད་པར་འདྲ་བའི་སྐལ་བ་མཉམ་པའི་རྒྱུ་འདྲ་བ་ཡིན་པས་ཕན་ཚུན་དུ་རྒྱུར་གྱུར་པའི་ཕྱིར་ཕན་ཚུན་རྒྱུ༌[^963]མཐུན་པ་ཉིད་དུ་ཐལ་བར་འགྱུར་ཏེ། ཕན་ཚུན་རྒྱུ་མཐུན་པ་ཉིད་དུ་ནི༌[^964]རིགས་པ་དང་ལྡན་པ་མ་ཡིན་ནོ། །རྣམ་པར་སྨིན་པའི་རྒྱུ་ནི་སྔ་ཕྱི་མེད་བཞིན་དུ་ཡང་དེ་ལྟར་ཕན་ཚུན་འབྲས་བུ་ཉིད་དུ་ཐལ་བར་མི་འགྱུར་ཏེ། རྒྱུ་དང་འབྲས་བུ་དག་མཚན་ཉིད་ཐ་དད་པའི་ཕྱིར་རོ། །དེ་ལྟ་བས་ན་སྐལ་བ་མཉམ་པའི་རྒྱུ་ནི་གནས་སྐབས་ལས་རྣམ་པར་གནས་པ་ཁོ་ན་ཡིན་ལ། རྣམ་པར་སྨིན་པའི་རྒྱུ་ནི་མཚན་ཉིད་ལས་རྣམ་པར་གནས་པ་ཡིན་པས་མ་འོངས་པ་ཡང་མི་བཟློག་གོ། །

འདི་ལྟ་སྟེ། སྡུག་བསྔལ་ལ་ཆོས་ཤེས་པའི་བཟོད་པ་ནི་དེ་ཉིད་མ་འོངས་པ་དང་མི་སྐྱེ་བ་ཤེས་པའི་ཁྱད་པར་ཅན་གྱི་རྒྱུ་ཡང་ཡིན་ནོ། །མི་སྐྱེ་བ་ཤེས་པ་ནི་ཁྱད་པར་ཅན་གཞན་མེད་པའི་ཕྱིར་མི་སྐྱེ་བ་ཤེས་པ་ཁོ་ནའི་ཡིན་ནོ། །མཐོང་བ་དང་བསྒོམ་པ་དང་མི་སློབ་པའི་ལམ་རྣམས་ནི་གསུམ་དང་གཉིས་དང་གཅིག་དག་གི་ཡིན་ནོ། །དེ་ལ་ཡང་དབང་པོ་རྟུལ་པོའི་ལམ་ནི་དབང་པོ་རྟུལ་པོ་དང༌[^968]རྣོན་པོའི་ལམ་གྱི་རྒྱུ་ཡིན་ལ། དབང་པོ་རྣོན་པོའི་ལམ་ནི་དབང་པོ་རྣོན་པོའི་ལམ་ཁོ་ན༌[^969]ཡིན་ཏེ། འདི་ལྟ་སྟེ་དད་པས་རྗེས་སུ་འབྲང་བ་དང་དད་པས་མོས་པ་དང་དུས་ཀྱིས་རྣམ་པར་གྲོལ་བའི་ལམ་རྣམས་ནི་དྲུག་དང་བཞི་དང་གཉིས་དག་གི་ཡིན་ནོ། །ཆོས་ཀྱིས༌[^970]རྗེས་སུ་འབྲང་བ་དང་མཐོང་བས་ཐོབ་པ་དང་། དུས་དང་མི་སྦྱོར་བར་རྣམ་པར་གྲོལ་བའི་ལམ་རྣམས་ནི་གསུམ་དང་གཉིས་དང་གཅིག་གི་ཡིན་ནོ། །ཡང་ཇི་ལྟར་ས༌[^971]གོང་མ་པས༌[^972]འོག་མ་པའི་ལམ་དང་མཉམ་བའམ་ཁྱད་པར་ཅན་ཡིན་ཞེ་ན། དབང་པོ་དང་རྒྱུས་རྒྱས་པར་བྱས་པའི་སྒོ་ནས་ཏེ། དེ་ལ་རྒྱུས་ཤིན་ཏུ་རྒྱས་པར་བྱས་པ་ནི་མཐོང་བའི་ལམ་ལ་སོགས་པ་དང་། ཆུང་ངུའི་ཆུང་ངུ་ལ་སོགས་པ་གོང་ནས་གོང་དུའོ། །རྒྱུད་གཅིག་ལ་དད་པས་རྗེས་སུ་འབྲང་བ་དང་། ཆོས་ཀྱིས༌[^973]རྗེས་སུ་འབྲང་བའི་ལམ་དག་མི་སྲིད་མོད་ཀྱི་འབྱུང་བ་ནི་མ་འོངས་པའི་རྒྱུ་ཡིན་ནོ། །ཅི་ལམ་ཁོ་ན་མཉམ་པ་དང་ཁྱད་པར་ཅན་དག་གི་སྐལ་བ་མཉམ་པའི་རྒྱུ་ཡིན་ནམ་ཞེ་ན་སྨྲས་པ་མ་ཡིན་ཏེ། འཇིག་རྟེན་པ་དག་ཀྱང་། སྦྱོར་བྱུང་དེ་གཉིས༌[^974]ཁོ་ནའི་ཡིན། །མཉམ་པ་དང་ཁྱད་པར་ཅན་དག་གི་སྐལ་བ་མཉམ་པའི་རྒྱུ་ཡིན་གྱི་དམན་པའི་ནི་མ་ཡིན་ནོ། །
