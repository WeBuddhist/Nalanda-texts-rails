━━━ ISSUE TYPES ━━━

CONNECTOR_ENDING
  The block ends with a connector particle (དང་། / ཞིང་། / ཅིང་། / ནས། / ལས། /
  སྟེ། / ཏེ།) that grammatically requires continuation. Real issue if the next
  block is the grammatical continuation. False positive if this is a closing verse
  pāda or a deliberate short citation frame.

OBJECTION_REPLY_FUSED
  The block contains both an objection marker (ཅེ་ན། / ཞེ་ན། / སྙམ་ན།) and a reply
  opener (འོ་ན།). These should always be two separate blocks. Almost always a
  real issue.

OVER_LENGTH
  The block exceeds the syllable threshold. Usually NOT wrong: a whole explanation
  unit is legitimately long. Split only if a new node opener (ordinal + title +
  ནི། / ལ་ N།) or the treatment of a new verse is buried mid-block.

SHORT_FRAGMENT
  The block is suspiciously short — may be a stray split artifact that should be
  merged with an adjacent block.

━━━ CORRECTION OPERATIONS ━━━

[
  {"op": "merge", "blocks": [N, M]},
  {"op": "merge", "blocks": [N, M, P]},
  {"op": "split", "block": N, "after": "<verbatim unique substring ending at split point>"},
  {"op": "split", "block": N, "after": ["<sub1>", "<sub2>"]}
]

Rules:
- Only output corrections for REAL issues. Skip false positives entirely.
- Block numbers are CONTINUOUS and include heading blocks. Only merge blocks with
  consecutive numbers (N and N+1); never merge across a heading or skip a number.
- "after" must be verbatim from the block and unique within it. To break one long
  block into 3+ units, set "after" to a LIST of substrings in document order.
- Each block number appears in AT MOST ONE operation.
- Heading blocks (lines starting with #) and [VERSE] blocks are NEVER touched.
- If no corrections are needed, output: []
- Output ONLY the JSON array. No commentary, no code fences.

མདོ་སྡེ་པ་རྣམས་ན་རེ་དབྱིབས་ནི་རྫས་སུ་མེད་དེ། ཕྱོགས་གཅིག་གི་སྒོར་ཁ་དོག་ཕལ་ཆེར་བྱུང་བ་ལ་གཟུགས་རིང་པོར༌[^2435]ཞེས་འདོགས་པར་བྱེད། དེ་ཉིད་ལ་ལྟོས་ནས་ཉུང་ངུར་བྱུང་བ་ལ་ཐུང་ངུ་ཞེས་འདོགས་པར་བྱེད། ཕྱོགས་བཞིར་མང་པོར་བྱུང་བ་ལ་གྲུ་བཞི་ཞེས་འདོགས་པར་བྱེད། ཐམས་ཅད་དུ་མཉམ་པ༌[^2436]ན་ལྷམ་པ་ཞེས་འདོགས་པར་བྱེད་དེ། ཐམས་ཅད་ཀྱང་དེ་དང་འདྲའོ། །དཔེར་ན་མགལ་མེ་ཕྱོགས་གཞན་གཅིག་ཏུ་མྱུར་དུ་འདབ་ཆགས་པར་སྣང་བ་ནི་རིང་པོའོ་སྙམ་དུ་ཤེས་ལ། ཐམས་ཅད་དུ་སྣང་ན་ཟླུམ་པོའོ་སྙམ་དུ་ཤེས་ཀྱི་དབྱིབས་རྫས་སུ༌[^2437]གཞན་ཡོད་པ་ནི་མ་ཡིན་པ་བཞིན་ནོ། །གལ་ཏེ་ཡོད་ན་ནི། གཉིས་གཟུང་འགྱུར། མིག་གིས་མཐོང་ན་ཡང་རིང་པོའོ་སྙམ་དུ་ཤེས་པར་འགྱུར་ལ། ལུས་ཀྱི་དབང་པོ༌[^2438]རེག་ན་ཡང་ཤེས་པར་འགྱུར་བས་འདི་དབང་པོ་གཉིས་ཀྱི༌[^2439]གཟུང་བར་འགྱུར་བ་ཞིག་ན། གཟུགས་ཀྱི་སྐྱེ་མཆེད་ལ་ནི་གཉིས་ཀྱིས་འཛིན་པ་མེད་དོ་ཞེས་ཟེར་རོ། །

མདོ་སྡེ་པ་རྣམས་ན་རེ་དབྱིབས་ནི་རྫས་སུ་མེད་དེ། ཕྱོགས་གཅིག་གི་སྒོར་ཁ་དོག་ཕལ་ཆེར་བྱུང་བ་ལ་གཟུགས་རིང་པོར༌[^2435]ཞེས་འདོགས་པར་བྱེད། དེ་ཉིད་ལ་ལྟོས་ནས་ཉུང་ངུར་བྱུང་བ་ལ་ཐུང་ངུ་ཞེས་འདོགས་པར་བྱེད། ཕྱོགས་བཞིར་མང་པོར་བྱུང་བ་ལ་གྲུ་བཞི་ཞེས་འདོགས་པར་བྱེད། ཐམས་ཅད་དུ་མཉམ་པ༌[^2436]ན་ལྷམ་པ་ཞེས་འདོགས་པར་བྱེད་དེ། ཐམས་ཅད་ཀྱང་དེ་དང་འདྲའོ། །དཔེར་ན་མགལ་མེ་ཕྱོགས་གཞན་གཅིག་ཏུ་མྱུར་དུ་འདབ་ཆགས་པར་སྣང་བ་ནི་རིང་པོའོ་སྙམ་དུ་ཤེས་ལ། ཐམས་ཅད་དུ་སྣང་ན་ཟླུམ་པོའོ་སྙམ་དུ་ཤེས་ཀྱི་དབྱིབས་རྫས་སུ༌[^2437]གཞན་ཡོད་པ་ནི་མ་ཡིན་པ་བཞིན་ནོ། །གལ་ཏེ་ཡོད་ན་ནི། གཉིས་གཟུང་འགྱུར། མིག་གིས་མཐོང་ན་ཡང་རིང་པོའོ་སྙམ་དུ་ཤེས་པར་འགྱུར་ལ། ལུས་ཀྱི་དབང་པོ༌[^2438]རེག་ན་ཡང་ཤེས་པར་འགྱུར་བས་འདི་དབང་པོ་གཉིས་ཀྱི༌[^2439]གཟུང་བར་འགྱུར་བ་ཞིག་ན། གཟུགས་ཀྱི་སྐྱེ་མཆེད་ལ་ནི་གཉིས་ཀྱིས་འཛིན་པ་མེད་དོ་ཞེས་ཟེར་རོ། །

མདོ་སྡེ་པ་རྣམས་ན་རེ་དབྱིབས་ནི་རྫས་སུ་མེད་དེ། ཕྱོགས་གཅིག་གི་སྒོར་ཁ་དོག་ཕལ་ཆེར་བྱུང་བ་ལ་གཟུགས་རིང་པོར༌[^2435]ཞེས་འདོགས་པར་བྱེད། དེ་ཉིད་ལ་ལྟོས་ནས་ཉུང་ངུར་བྱུང་བ་ལ་ཐུང་ངུ་ཞེས་འདོགས་པར་བྱེད། ཕྱོགས་བཞིར་མང་པོར་བྱུང་བ་ལ་གྲུ་བཞི་ཞེས་འདོགས་པར་བྱེད། ཐམས་ཅད་དུ་མཉམ་པ༌[^2436]ན་ལྷམ་པ་ཞེས་འདོགས་པར་བྱེད་དེ། ཐམས་ཅད་ཀྱང་དེ་དང་འདྲའོ། །དཔེར་ན་མགལ་མེ་ཕྱོགས་གཞན་གཅིག་ཏུ་མྱུར་དུ་འདབ་ཆགས་པར་སྣང་བ་ནི་རིང་པོའོ་སྙམ་དུ་ཤེས་ལ། ཐམས་ཅད་དུ་སྣང་ན་ཟླུམ་པོའོ་སྙམ་དུ་ཤེས་ཀྱི་དབྱིབས་རྫས་སུ༌[^2437]གཞན་ཡོད་པ་ནི་མ་ཡིན་པ་བཞིན་ནོ། །གལ་ཏེ་ཡོད་ན་ནི། གཉིས་གཟུང་འགྱུར། མིག་གིས་མཐོང་ན་ཡང་རིང་པོའོ་སྙམ་དུ་ཤེས་པར་འགྱུར་ལ། ལུས་ཀྱི་དབང་པོ༌[^2438]རེག་ན་ཡང་ཤེས་པར་འགྱུར་བས་འདི་དབང་པོ་གཉིས་ཀྱི༌[^2439]གཟུང་བར་འགྱུར་བ་ཞིག་ན། གཟུགས་ཀྱི་སྐྱེ་མཆེད་ལ་ནི་གཉིས་ཀྱིས་འཛིན་པ་མེད་དོ་ཞེས་ཟེར་རོ། །

ཡང་ན༌[^2440]ཇི་ལྟར་རེག་བྱ་ལ་རིང་པོ་ལ་སོགས་པར་འཛིན་པ་ལྟར་ཁ་དོག་ལ་ཡང་དེ་བཞིན་དུ་ཡིད་ཆེས་པར་བྱའོ། །དེ་ལ་ནི་རེག་བྱ་དང་ལྷན་ཅིག་སྤྱོད་པའི་ཕྱིར་དྲན་པ་ཙམ་ཡིན་གྱི་མངོན་སུམ་དུ་འཛིན་པ་ནི་མ་ཡིན་གྱི།[^2441] དཔེར་ན་མེའི་གཟུགས་མཐོང་ནས་དེའི་ཚ་བའི་དྲན་པ་འབྱུང་བ་དང་། མེ་ཏོག་གི་དྲི་བསྣམས་ནས་དེའི་ཁ་དོག་གི་དྲན་པ་འབྱུང་བ༌[^2442]བཞིན་ནོ་ཞེ་ན།[^2443] འདི་ལ་ནི་འཁྲུལ་པ་མེད་པའི་ཕྱིར་གཞན་གྱིས་གཞན་དྲན་པར་རིགས་ཀྱི་གང་ལས་འདི་ངེས་པར་དྲན་པར་འགྱུར་བ་རེག་བྱ་ལས༌[^2444]ནི་ཅུང་ཟད་ཀྱང་དབྱིབས་གང་ལ་ཡང་ངེས་པར་མེད་དོ། །འོན་ཏེ་ལྷན་ཅིག་སྤྱོད་པར་ངེས་པ་མེད་ཀྱང་ངེས་པར་དབྱིབས་དྲན་པར་འགྱུར་ན་ནི་ཁ་དོག་ཀྱང་འགྱུར་རོ། །ཡང་ན་ནི་ཁ་དོག་བཞིན་དུ་དབྱིབས་ཀྱང་ངེས་པར་མི་འགྱུར་བ་ཞིག་ན་དེ་ལྟ་ཡང་མ་ཡིན་པར༌[^2445]རེག་བྱ་ལས་འདི་དྲན་པར་ནི་རིགས་པ་མ་ཡིན་ནོ། །རི་མོས༌[^2446]བཀྲམ་པ་ལ༌[^2447]དབྱིབས་དུ༌[^2448]མ་སྣང་བའི་ཕྱིར་མང་པོ་ཡང་ཕྱོགས་གཅིག་པར་འགྱུར་བ་ཞིག་ན་དེ་ཡང་རིགས་པ་མ་ཡིན་ཏེ། ཁ་དོག་བཞིན་ནོ། །དེ་ལྟ་བས་ན་དབྱིབས་ནི་རྫས་སུ་མེད་དོ། །

གང་ཡང་ཐོགས་པ་དང་བཅས་པའི་གཟུགས་ཅུང་ཟད་ཡོད་པ་དེ་ནི་གདོན་མི་ཟ་བར་རྡུལ་ཕྲ་རབ་ལ་ཡོད་པ་ཡིན་ན་དེ་རྡུལ་ལ་མེད་དེ། [^2449]རིང་པོ་ལ་སོགས་པའི་དབྱིབས་ནི་རྡུལ་ཕྲ་རབ་ལ་མེད་དོ། །དེ་ལྟ་བས་ན་དབྱིབས་ནི༌[^2450]མང་པོ་དེ་ལྟར་གནས་པ་དག་ཁོ་ན་ལ་རིང་པོ་ལ་སོགས་པ་འདོགས་པར་ཟད་དོ། །འོན་ཏེ་དབྱིབས་ཀྱི་རྡུལ་ཕྲ་རབ་དག་ཁོ་ན་དེ་ལྟར་གནས་པ་ལ་རིང་པོ་ལ་སོགས་པའི༌[^2451]མིང་འདོགས་པར་འདོད་ན་ནི་དེ་དག་མ་གྲུབ་པའི་ཕྱིར་དེ་ནི་ཕྱོགས་འཛིན་པ་འབའ་ཞིག་ཏུ་ཟད་དོ། །རང་གི་མཚན་ཉིད་རྣམས་གྲུབ་ན་ནི་དེ་དག་བསགས་པ་རུང་བར་འགྱུར་ན་དབྱིབས་ཀྱི་ཡན་ལག་རྣམས་ནི་ཁ་དོག་ལ་སོགས་པ་དེ༌[^2452]བཞིན་དུ་རང་གི་ངོ་བོར༌[^2453]གྲུབ་པ་ཡང་མེད་ན་དེ་དག་བསགས་པ་ལྟ་ཞིག་ག་ལ་ཡོད། འོ་ན་གང་ཁམ་པའི་སྣོད་རྣམས་ཁ་དོག་ཀྱང་ཐ་མི་དད་པ་ལ་དབྱིབས་ཀྱང་ཐ་དད་པར་སྣང་ངོ་ཞེ་ན། ཇི་ལྟར་གནས་པར་གྱུར་པའི་ཁ་དོག་ལ་རིང་པོ་ལ་སོགས་པར་མིང་འདོགས་པར་ཟད་དོ་ཞེས་མ་བཤད་དམ། དཔེར་ན་གྲོག༌[^2454]མ་ལ་སོགས་པ་ཐ་མི་དད་བཞིན་དུ་འཁོར་ལོ་ལ་སོགས་པ་ཐ་དད་པར་འདོགས་པ་ལྟར་དབྱིབས་ཀྱང་དེ་དང་འདྲའོ། །འོ་ན་གང་མུན་ཁུང་དང་ཐག་རིང་པོ་ནས་སྡོང་དུམ་ལ་སོགས་པའི་ཁ་དོག་མ་མཐོང་བར་རིང་པོ་ལ་སོགས་པ་མཐོང་བར་འགྱུར་རོ༌[^2455]ཞེ་ན། དེ་དག་གི༌[^2456]དེ་ཁ་དོག་མི་གསལ་བ༌[^2457]ཁོ་ན་མཐོང་ནས་རིང་པོ་ལ་སོགས་པར་ཡོངས་སུ་རྟོག་པར་བྱེད་དེ། ཕྲེང་བ་དང་དམག་ལ་སོགས་པ༌[^2458]ལ་ཡོངས་སུ་རྟོག་པ་བཞིན་ནོ། །དེ་ནི་གདོན་མི་ཟ་བར་དེ་ལྟར་ཤེས་པར་བྱ་སྟེ། གང་རེས་འགའ་ཡོངས་སུ་ཆད་པ་ངེས་པར་མི་ཟིན་པ་ནི་ཚོགས་པ་ཙམ་དང་མི་གསལ་བ་སྣང་བ་ཡིན་ནོ། །

འོ་ན་གང་སེམས་པ་དང་། བསམ་པའི༌[^2463]ལས་སོ་ཞེས་གསུངས་སོ་ཞེ་ན། འདི་དང་འདི་ལྟ་བུ་ཞིག་བྱའོ༌[^2464]སྙམ་པའི་ཀུན་དུ་རྟོག་པ་ནི་སྔར་འབྱུང་ལ། དེ་ལྟར་བསམས་ནས་དེའི་འོག་ཏུ་གང་གིས་ལུས༌[^2465]འཇུག་པར་བྱེད་པར་བྱ་བའི་སེམས་པ་སྐྱེ་བར་འགྱུར་ཏེ། དེ་ནི་བསམ་པའི༌[^2466]ལས་ཞེས་བྱའོ། །དེ་ལྟ་ན་ནི་འོ་ན་རྣམ་པར་རིག་བྱེད་མེད་པའི་ཕྱིར་འདོད་པ་ན་སྤྱོད་པའི་རྣམ་པར་རིག་བྱེད་མ་ཡིན་པ་ཡང་མེད་པས་ཉེས་པ་ཆེན་པོར་ཐལ་བར་འགྱུར་རོ། །ཐལ་བ་རྣམས་ལ་ཡང་ཐལ་བའི་གཉེན་པོ་དག་ཡོད་དེ། གལ་ཏེ་ལུས་ཀྱི་ལས་ཞེས་བྱ་བའི༌[^2467]སེམས་པའི༌[^2468]ཁྱད་པར་དེ་ཉིད་ལས་རྣམ་པར་རིག་བྱེད་མ་ཡིན་པ་འབྱུང་བར་འགྱུར༌[^2469]ན་ཡང་ཅིར་འགྱུར་མཉམ་པར་གཞག་པའི་རྣམ་པར་རིག་བྱེད་མ་ཡིན་པ་བཞིན་དུ་སེམས་ཀྱི་རྗེས་སུ༌[^2470]འབྲང་བ་ཡིན་པར་འགྱུར་རོ། །དེ་ལྟར་མི་འགྱུར་ཏེ། སེམས་པའི་ཁྱད་པར་གྱིས་དེའི་འཕེན་པ་ཁྱད་པར་ཡོད་པའི་ཕྱིར་རོ། །རྣམ་པར་རིག་བྱེད་དེ་ཡོད་ན་ཡང་དེ་འཕང་བར་བྱ་བ་ནི་སེམས་པའི་སྟོབས་ལ་རག་ལས་པ་ཡིན་ཏེ་དེ་བླུན་པའི་ཕྱིར་རོ། །

གང་ཡང་ཐོགས་པ་དང་བཅས་པའི་གཟུགས་ཅུང་ཟད་ཡོད་པ་དེ་ནི་གདོན་མི་ཟ་བར་རྡུལ་ཕྲ་རབ་ལ་ཡོད་པ་ཡིན་ན་དེ་རྡུལ་ལ་མེད་དེ། [^2449]རིང་པོ་ལ་སོགས་པའི་དབྱིབས་ནི་རྡུལ་ཕྲ་རབ་ལ་མེད་དོ། །དེ་ལྟ་བས་ན་དབྱིབས་ནི༌[^2450]མང་པོ་དེ་ལྟར་གནས་པ་དག་ཁོ་ན་ལ་རིང་པོ་ལ་སོགས་པ་འདོགས་པར་ཟད་དོ། །འོན་ཏེ་དབྱིབས་ཀྱི་རྡུལ་ཕྲ་རབ་དག་ཁོ་ན་དེ་ལྟར་གནས་པ་ལ་རིང་པོ་ལ་སོགས་པའི༌[^2451]མིང་འདོགས་པར་འདོད་ན་ནི་དེ་དག་མ་གྲུབ་པའི་ཕྱིར་དེ་ནི་ཕྱོགས་འཛིན་པ་འབའ་ཞིག་ཏུ་ཟད་དོ། །རང་གི་མཚན་ཉིད་རྣམས་གྲུབ་ན་ནི་དེ་དག་བསགས་པ་རུང་བར་འགྱུར་ན་དབྱིབས་ཀྱི་ཡན་ལག་རྣམས་ནི་ཁ་དོག་ལ་སོགས་པ་དེ༌[^2452]བཞིན་དུ་རང་གི་ངོ་བོར༌[^2453]གྲུབ་པ་ཡང་མེད་ན་དེ་དག་བསགས་པ་ལྟ་ཞིག་ག་ལ་ཡོད། འོ་ན་གང་ཁམ་པའི་སྣོད་རྣམས་ཁ་དོག་ཀྱང་ཐ་མི་དད་པ་ལ་དབྱིབས་ཀྱང་ཐ་དད་པར་སྣང་ངོ་ཞེ་ན། ཇི་ལྟར་གནས་པར་གྱུར་པའི་ཁ་དོག་ལ་རིང་པོ་ལ་སོགས་པར་མིང་འདོགས་པར་ཟད་དོ་ཞེས་མ་བཤད་དམ། དཔེར་ན་གྲོག༌[^2454]མ་ལ་སོགས་པ་ཐ་མི་དད་བཞིན་དུ་འཁོར་ལོ་ལ་སོགས་པ་ཐ་དད་པར་འདོགས་པ་ལྟར་དབྱིབས་ཀྱང་དེ་དང་འདྲའོ། །འོ་ན་གང་མུན་ཁུང་དང་ཐག་རིང་པོ་ནས་སྡོང་དུམ་ལ་སོགས་པའི་ཁ་དོག་མ་མཐོང་བར་རིང་པོ་ལ་སོགས་པ་མཐོང་བར་འགྱུར་རོ༌[^2455]ཞེ་ན། དེ་དག་གི༌[^2456]དེ་ཁ་དོག་མི་གསལ་བ༌[^2457]ཁོ་ན་མཐོང་ནས་རིང་པོ་ལ་སོགས་པར་ཡོངས་སུ་རྟོག་པར་བྱེད་དེ། ཕྲེང་བ་དང་དམག་ལ་སོགས་པ༌[^2458]ལ་ཡོངས་སུ་རྟོག་པ་བཞིན་ནོ། །དེ་ནི་གདོན་མི་ཟ་བར་དེ་ལྟར་ཤེས་པར་བྱ་སྟེ། གང་རེས་འགའ་ཡོངས་སུ་ཆད་པ་ངེས་པར་མི་ཟིན་པ་ནི་ཚོགས་པ་ཙམ་དང་མི་གསལ་བ་སྣང་བ་ཡིན་ནོ། །

འོ་ན་འདི་སྐད་དུ་དེ་ལྟར་ཤེས་ཤིང་དེ་ལྟར་མཐོང་བ་དེའི་ཡང་དག་པའི་ལྟ་བ་དང་། [^2486]ཡང་དག་པའི་རྟོག་པ་དང་། ཡང་དག་པའི༌[^2487]རྩོལ་བ་དང་། ཡང་དག་པའི་དྲན་པ་དང་། ཡང་དག་པའི་ཏིང་ངེ་འཛིན་བསྒོམ་པ་ཡོངས་སུ་རྫོགས་པར་འགྱུར་རོ། །འདིའི་ངག་དང་། ལས་ཀྱི་མཐའ་དང་། འཚོ་བ་རྣམས་ནི་སྔོན་ཡོངས་སུ་དག་ཅིང་ཡོངས་སུ་བྱང་བ་ཡིན་ནོ་ཞེས་གང་གསུངས་སོ་ཞེ་ན། འདི་ནི་སྔོན་འཇིག་རྟེན་པའི་ལམ་གྱིས་འདོད་ཆགས་དང་བྲལ་བར་བྱས་པ་ལ་དགོངས་ཏེ་གསུངས་པ་ཡིན་ནོ། །

མདོ་ལས། གནས་གསུམ་གྱི་གཟུགས་ཀྱིས༌[^2476]གཟུགས་བསྡུས་པ་ཡིན་ཏེ། བསྟན་དུ་ཡོད་ལ་ཐོགས་པ་དང་བཅས་པའི་གཟུགས་ཀྱང་ཡོད། བསྟན་དུ་མེད་ལ་ཐོགས་པ་དང་བཅས་པའི་གཟུགས་ཀྱང་ཡོད། བསྟན་དུ་ཡང་མེད་ལ་ཐོགས་པ་ཡང་མེད་པའི་གཟུགས་ཀྱང་ཡོད་དོ་ཞེས་གཟུགས་རྣམ་པ་གསུམ་གསུངས་སོ། །ཟག་པ་མེད་པའི་ཆོས་རྣམས་ཀྱང༌[^2477]གང་ཞེ་ན། གཟུགས་འདས་པ་དང་མ་འོངས་པ་དང་ད་ལྟར་བྱུང་བ་གང་དང་རྣམ་པར་ཤེས་པའི་བར་གང་ལ་རྗེས་སུ་ཆགས་པའམ་ཁོང་ཁྲོ་བ་མི་སྐྱེ་བ་འདི་དག་ནི་ཟག་པ་མེད་པའི་ཆོས་རྣམས་ཞེས་བྱའོ་ཞེས་གཟུགས་ཟག་པ་མེད་པ་ཡང་གསུངས་ཏེ། རྣམ་པར་རིག་བྱེད་མ་ཡིན་པ་མ་གཏོགས་པར་ནི་བསྟན་དུ་ཡང་མེད་ལ་ཐོགས་པ་ཡང་མེད་པའི་གཟུགས་ཀྱང་མེད་ལ་ཟག་པ་མེད་པ་ཡང་མེད་དོ། །རྫས་ལས་བྱུང་བའི་བསོད་ནམས་བྱ་བའི་དངོས་པོ་བདུན་པོ་འདི་དག་དང་ལྡན་པའི་དད་པའི་རིགས་ཀྱི་བུའམ་རིགས་ཀྱི་བུ་མོ་ནི་རྒྱུ་ཡང་རུང་འདུག་ཀྱང་རུང༌[^2478]ཉལ་ཡང་རུང་མི་ཉལ་ཡང་རུང་སྟེ། རྟག་ཏུ་རྒྱུན་མི་ཆད་པར༌[^2479]བསོད་ནམས་མངོན་པར་འཕེལ་བ་ཁོ་ནར་འགྱུར་ཞིང་བསོད་ནམས་ཉེ་བར་སྐྱེ་བ་ཁོ་ནར་འགྱུར་ཏེ། རྫས་ལས་བྱུང་བ་མ་ཡིན་པ༌[^2480]དང་ལྡན་པ་ཡང་དེ་དང་འདྲའོ་ཞེས་འཕེལ་བར༌[^2481]ཡང་གསུངས་ཏེ། རྣམ་པར་རིག་བྱེད་མ་ཡིན་པ་མ་གཏོགས་པར་ནི་ཡིད་གཞན་དང་ལྡན་པའི་བསོད་ནམས་ཀྱང་མངོན་པར་འཕེལ་བར་མི་རུང་ངོ་། །རྣམ་པར་རིག་བྱེད་མ་ཡིན་པ་མེད་ན་བདག་ཉིད་ཀྱིས་མ་བྱས་ལ། གཞན་དག་བྱེད་དུ་བཅུག་པའི་ལས་ཀྱི་ལམ་དག་འགྲུབ་པར་མི་འགྱུར་ཏེ། ལུང་དུ་བསྒོ༌[^2482]བ་ཙམ་གྱིས༌[^2483]ལས་ཀྱི་ལམ་དུ་མི་རུང་སྟེ། ལས་དེ་མ་བྱས་པའི་ཕྱིར་རོ། །བྱས༌[^2484]སུ་ཟིན་ཀྱང་དེའི་རང་གི་ངོ་བོ་ལ་ཁྱད་པར་མེད་པའི་ཕྱིར་རོ། །

བཅོམ་ལྡན་འདས་ཀྱིས་ཀྱང་དགེ་སློང་ཆོས་ནི་ཕྱིའི་སྐྱེ་མཆེད་ཡིན་ཏེ། སྐྱེ་མཆེད་བཅུ་གཅིག་གིས་མ་བསྡུས་པ་བསྟན་དུ་མེད་པ་ཐོགས་པ་མེད་པའོ་ཞེས་གསུངས་ཀྱི། གཟུགས་ཅན་མ་ཡིན་པའོ་ཞེས་ནི་མ་གསུངས་ཏེ། དེར་གལ་ཏེ་ཆོས་ཀྱི་སྐྱེ་མཆེད་ཀྱི་ཁོངས་སུ་མ༌[^2485]གཏོགས་པ་རྣམ་པར་རིག་བྱེད་མ་ཡིན་པའི་གཟུགས་ཤིག་མ་གཟིགས་ན་དགོས་པ་ཅི་ཞིག་ཡོད་པར་འགྱུར་རོ། །རྣམ་པར་རིག་བྱེད་མ་ཡིན་པའི་གཟུགས་མེད་ན་ལམ་ཡན་ལག་བརྒྱད་པར་ཡང་མི་འགྱུར་ཏེ། སྙོམས་པར་འཇུག་པ་ལ་ངག་དང་། ལས་ཀྱི་མཐའ་དང་། འཚོ་བ་རྣམས་མི་རུང་བའི་ཕྱིར་རོ། །

འདི་ལ་མདོ་སྡེ་པ་རྣམས་ན་རེ་འདི་ནི་མང་པོ་ཡང༌[^2491]ཡིན་ལ། འདི་ནི་སྣ་ཚོགས་པ་ཡང་ཡིན་མོད་ཀྱི་འདི་དེ་ལྟར༌[^2492]ཡང་མ་ཡིན་ནོ་ཞེས་ཟེར་མོད། [^2493]ཅིའི་ཕྱིར་ཞེ་ན། རེ་ཞིག་གང་གཟུགས་རྣམ་པ་གསུམ་གསུངས་པའི་ཕྱིར་རོ་ཞེས་སྨྲས་པ། དེ་ལ་རྣལ་འབྱོར་སྤྱོད་པ་དག་ན་རེ་བསམ་གཏན་པ་རྣམས་ཀྱི་ཏིང་ངེ་འཛིན་གྱི་མཐུས་ཏིང་ངེ་འཛིན་གྱི་ཡུལ་གྱི་གཟུགས་སྐྱེ་སྟེ། དེ་ཡང་དབང་པོའི་ཡུལ་མ་ཡིན་པའི་ཕྱིར་ནི་བསྟན་དུ་མེད་པ་ཡིན་ལ། ཡུལ་ལ་མི་སྒྲིབ་པའི་ཕྱིར་ནི་ཐོགས་པ་མེད་པ་ཡིན་ནོ་ཞེས་སྟོན་པར༌[^2494]བྱེད་དོ། །ད་ནི་དེ་ཇི་ལྟར་གཟུགས་ཡིན་སྙམ་དུ་སེམས་ན་དེ་ནི་རྣམ་པར་རིག་བྱེད་མ་ཡིན་པ་ལ་ཡང་མཚུངས་སོ། །གང་ཡང་གཟུགས་ཟག་པ་མེད་པ་གསུངས་པའི་ཕྱིར་རོ་ཞེས་སྨྲས་པ་ནི་རྣལ་འབྱོར་སྤྱོད་པ་རྣམས་ན་རེ་ཏིང་ངེ་འཛིན་གྱི་མཐུ་ལས༌[^2495]སྐྱེས་པའི་གཟུགས་དེ་ཉིད་ཟག་པ་མེད་པའི་ཏིང་ངེ་འཛིན་ལ་ཟག་པ་མེད་པ་ཡིན་ནོ་ཞེས་བརྗོད་དོ། །
