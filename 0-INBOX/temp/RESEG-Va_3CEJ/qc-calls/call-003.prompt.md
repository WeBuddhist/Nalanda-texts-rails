━━━ ISSUE TYPES ━━━

CONNECTOR_ENDING
  The block ends with a connector particle (དང་། / ཞིང་། / ཅིང་། / ནས། / ལས། /
  སྟེ། / ཏེ།) that grammatically requires continuation. Real issue if the next
  block is the grammatical continuation. False positive if this is a closing verse
  pāda or a deliberate short citation frame.

OBJECTION_REPLY_FUSED
  The block contains both an objection marker (ཅེ་ན། / ཞེ་ན། / སྙམ་ན།) and a reply
  opener (འོ་ན།). These should always be two separate blocks. Almost always a
  real issue.

OVER_LENGTH
  The block exceeds the syllable threshold. Usually NOT wrong: a whole explanation
  unit is legitimately long. Split only if a new node opener (ordinal + title +
  ནི། / ལ་ N།) or the treatment of a new verse is buried mid-block.

SHORT_FRAGMENT
  The block is suspiciously short — may be a stray split artifact that should be
  merged with an adjacent block.

]

Rules:
- Only output corrections for REAL issues. Skip false positives entirely.
- Block numbers are CONTINUOUS and include heading blocks. Only merge blocks with
  consecutive numbers (N and N+1); never merge across a heading or skip a number.
- "after" must be verbatim from the block and unique within it. To break one long
  block into 3+ units, set "after" to a LIST of substrings in document order.
- Each block number appears in AT MOST ONE operation.
- Heading blocks (lines starting with #) and [VERSE] blocks are NEVER touched.
- If no corrections are needed, output: []
- Output ONLY the JSON array. No commentary, no code fences.

འདི་ལྟ་སྟེ། སྡུག་བསྔལ་ལ་ཆོས་ཤེས་པའི་བཟོད་པ་ནི་དེ་ཉིད་མ་འོངས་པ་དང་མི་སྐྱེ་བ་ཤེས་པའི་ཁྱད་པར་ཅན་གྱི་རྒྱུ་ཡང་ཡིན་ནོ། །མི་སྐྱེ་བ་ཤེས་པ་ནི་ཁྱད་པར་ཅན་གཞན་མེད་པའི་ཕྱིར་མི་སྐྱེ་བ་ཤེས་པ་ཁོ་ནའི་ཡིན་ནོ། །མཐོང་བ་དང་བསྒོམ་པ་དང་མི་སློབ་པའི་ལམ་རྣམས་ནི་གསུམ་དང་གཉིས་དང་གཅིག་དག་གི་ཡིན་ནོ། །དེ་ལ་ཡང་དབང་པོ་རྟུལ་པོའི་ལམ་ནི་དབང་པོ་རྟུལ་པོ་དང༌[^968]རྣོན་པོའི་ལམ་གྱི་རྒྱུ་ཡིན་ལ། དབང་པོ་རྣོན་པོའི་ལམ་ནི་དབང་པོ་རྣོན་པོའི་ལམ་ཁོ་ན༌[^969]ཡིན་ཏེ། འདི་ལྟ་སྟེ་དད་པས་རྗེས་སུ་འབྲང་བ་དང་དད་པས་མོས་པ་དང་དུས་ཀྱིས་རྣམ་པར་གྲོལ་བའི་ལམ་རྣམས་ནི་དྲུག་དང་བཞི་དང་གཉིས་དག་གི་ཡིན་ནོ། །ཆོས་ཀྱིས༌[^970]རྗེས་སུ་འབྲང་བ་དང་མཐོང་བས་ཐོབ་པ་དང་། དུས་དང་མི་སྦྱོར་བར་རྣམ་པར་གྲོལ་བའི་ལམ་རྣམས་ནི་གསུམ་དང་གཉིས་དང་གཅིག་གི་ཡིན་ནོ། །ཡང་ཇི་ལྟར་ས༌[^971]གོང་མ་པས༌[^972]འོག་མ་པའི་ལམ་དང་མཉམ་བའམ་ཁྱད་པར་ཅན་ཡིན་ཞེ་ན། དབང་པོ་དང་རྒྱུས་རྒྱས་པར་བྱས་པའི་སྒོ་ནས་ཏེ། དེ་ལ་རྒྱུས་ཤིན་ཏུ་རྒྱས་པར་བྱས་པ་ནི་མཐོང་བའི་ལམ་ལ་སོགས་པ་དང་། ཆུང་ངུའི་ཆུང་ངུ་ལ་སོགས་པ་གོང་ནས་གོང་དུའོ། །རྒྱུད་གཅིག་ལ་དད་པས་རྗེས་སུ་འབྲང་བ་དང་། ཆོས་ཀྱིས༌[^973]རྗེས་སུ་འབྲང་བའི་ལམ་དག་མི་སྲིད་མོད་ཀྱི་འབྱུང་བ་ནི་མ་འོངས་པའི་རྒྱུ་ཡིན་ནོ། །ཅི་ལམ་ཁོ་ན་མཉམ་པ་དང་ཁྱད་པར་ཅན་དག་གི་སྐལ་བ་མཉམ་པའི་རྒྱུ་ཡིན་ནམ་ཞེ་ན་སྨྲས་པ་མ་ཡིན་ཏེ། འཇིག་རྟེན་པ་དག་ཀྱང་། སྦྱོར་བྱུང་དེ་གཉིས༌[^974]ཁོ་ནའི་ཡིན། །མཉམ་པ་དང་ཁྱད་པར་ཅན་དག་གི་སྐལ་བ་མཉམ་པའི་རྒྱུ་ཡིན་གྱི་དམན་པའི་ནི་མ་ཡིན་ནོ། །

དཔེར༌[^975]ཇི་ལྟ་བུ་ཞེ་ན་སྨྲས་པ། ཐོས་དང་བསམས༌[^976]བྱུང་ལ་སོགས་པའང་།[^977] །ཐོས་པ་དང་བསམས་པ༌[^978]དང་བསྒོམས་པ་ལས་བྱུང་བ་སྦྱོར་བ་ལས་འབྱུང་བའི༌[^979]ཡོན་ཏན་དེ་དག་ཀྱང་ཉམས་པ་དང་ཁྱད་པར་ཅན་དག་ཁོ་ནའི་རྒྱུ་ཡིན་གྱི་དམན་པ་རྣམས་ཀྱི་ནི་མ་ཡིན་ཏེ། འདི་ལྟ་སྟེ། འདོད་པ་ན་སྤྱོད་པའི་ཐོས་པ་ལས་བྱུང་བ་རྣམས་ནི་ཐོས་པ་ལས་བྱུང་བ་དང་བསམས་པ་ལས་བྱུང་བ་རྣམས་ཀྱི་ཡིན་ནོ། །བསམ་པ༌[^980]ལས་བྱུང་བ་རྣམས་ནི་བསམས་པ་ལས་བྱུང་བ་རྣམས་ཀྱི་ཡིན་ཏེ། བསྒོམས་པ་ལས་བྱུང་བ་ནི་མེད་པའི་ཕྱིར་རོ། །གཟུགས་ན་སྤྱོད་པའི་ཐོས་པ་ལས་བྱུང་བ་རྣམས་ནི་ཐོས་པ་ལས་བྱུང་བ་དང་བསྒོམས་པ་ལས་བྱུང་བ་རྣམས་ཀྱི་ཡིན་ཏེ། བསམས་པ་ལས་བྱུང་བ་ནི་མེད་པའི་ཕྱིར་རོ། །བསྒོམས་པ༌[^981]ལས་བྱུང་བ་རྣམས༌[^982]ནི་བསྒོམས་པ་ལས་བྱུང་བ་རྣམས་ཁོ་ནའི་ཡིན་ནོ། །དེ་དག་ཀྱང་རྣམ་པ་དགུ་ཐ་དད་པའི་ཕྱིར་ཆུང་ངུའི་ཆུང་ངུ་དག་ནི་ཐམས་ཅད་ཀྱི་ཡིན་ལ། ཆུང་ངུའི་འབྲིང་པོ་དག་ནི་བརྒྱད་ཀྱི་ཡིན་ཏེ། ལུགས་ནི་དེ་ལྟ་བུའོ།[^983] །སྐྱེས་ནས་ཐོབ་པ་ཅན་གྱི་དགེ་བའི་ཆོས་རྣམས་ནི༌[^984]རྣམ་པ་དགུ་པོ་ཐམས་ཅད་ཕན་ཚུན་དུ་སྐལ་བ་མཉམ་པའི་རྒྱུ་ཡིན་ཏེ། ཉོན་མོངས་པ་ཅན་རྣམས་ཀྱང་དེ་དང་འདྲའོ། །མ་བསྒྲིབས་ལ་ལུང་དུ་མ་བསྟན་པ་རྣམས་ནི་རྣམ་པ་བཞི་སྟེ། རྣམ་པར་སྨིན་པ་ལས་སྐྱེས་པ་དང་། སྤྱོད་ལམ་པ་འམ།[^985] བཟོའི་གནས་པ་དང་། སྤྲུལ་པའི་སེམས་ལྷན་ཅིག་སྐྱེས་པ་རྣམས་ཏེ། དེ་དག་ནི་གོ་རིམས་བཞིན་དུ་བཞི་དང་། གསུམ་དང་། གཉིས་དང་། གཅིག་དག་གི་སྐལ་བ་མཉམ་པའི་རྒྱུ་ཡིན་ནོ། །སྤྲུལ་པའི་སེམས་བསམ་གཏན་བཞིའི་འབྲས་བུ་འདོད་པ་ན་སྤྱོད་པ༌[^986]ཡང་ཡིན་ཏེ། དེ་ལ་བསམ་གཏན་གོང་མའི་འབྲས་བུ་ནི་བསམ་གཏན་འོག་མའི་འབྲས་བུ་ནི་མ༌[^987]ཡིན་ནོ། །འབད་པ༌[^988]འབྲས་བུ་མེད་པར་འགྱུར་དུ་འོང་བའི་ཕྱིར་སྐལ་བ་མཉམ་པའི་རྒྱུ་མངོན་པར་འདུ་བྱེད་པ་ཅན་གྱི་འབྲས་བུ་ནི་དམན་པ་མ་ཡིན་ཏེ། དཔེར་ན་སཱ་ལུ་དང་ནས་ལ་སོགས་པའི་ལྟ་བུའོ། །དེ་ཉིད་ཀྱི་ཕྱིར་ཟག་པ་མེད་པ་སྐྱེས་པ་ཟག་པ་མེད་པ་མ་སྐྱེས་པའི་རྒྱུ་མ་ཡིན་པ་ཡོད་དམ་ཞེ་ན་ཡོད་དེ། དཔེར་ན་སྡུག་བསྔལ་ལ་ཆོས་ཤེས་པའི༌[^989]བཟོད་པ་མ་སྐྱེས་པ་རྣམས་ཀྱི་ལྟ་བུ་དང་། ཁྱད་པར་ཅན་ཐམས་ཅད་དམན་པའི་ལྟ་བུའོ། །རྒྱུད་གཅིག་ལ་ངེས་པའི་ཟག་པ་མེད་པའི་ཆོས་སྔོན་ཐོབ་པ་ཕྱིས་སྐྱེས་པའི་རྒྱུ་མ་ཡིན་པ་ཡོད་དམ་ཞེ་ན། ཡོད་དེ་སྡུག་བསྔལ་ལ་ཆོས་ཤེས་པའི་བཟོད་པ་མ་འོངས་པ་དག་སྡུག་བསྔལ་ལ་ཆོས་ཤེས་པའི་ལྟ་བུའོ། །[^990]འདི་ལྟར་འབྲས་བུ་སྔ་མའམ།[^991] སྐལ་བ་མཉམ་པའི་རྒྱུ་མ་འོངས་པ་ནི་མེད་དོ། །ཟག་པ་མེད་པའི་ཆོས་སྔར་སྐྱེས་པ་རྣམས་ཟག་པ་མེད་པའི་ཆོས་ཕྱིས་སྐྱེ་བའི་རྒྱུ་མ་ཡིན་པ་ཡོད་དམ་ཞེ་ན་ཡོད་དེ། ཆེན་པོ་ཆུང་ངུའི་ལྟ་བུ་སྟེ། འདི་ལྟ་སྟེ། འབྲས་བུ་གོང་མ་ལས་ཡོངས་སུ་ཉམས་པ་འབྲས་བུ་འོག་མ་མངོན་དུ་བྱེད་པའི་ཚེ་དང་སྡུག་བསྔལ་ལ་ཆོས་ཤེས་པའི་ཐོབ་པ༌[^992]སྐད་ཅིག་མ་ཕྱི་མ་དང་ལྷན་ཅིག་སྐྱེས་པ་སྡུག་བསྔལ་ལ་ཆོས་ཤེས་པའི་བཟོད་པའི་ཐོབ་པ་རྣམས་ཀྱི་ལྟ་བུ་སྟེ། །ཐོས་པ་དང་བསམས་པ༌[^978]དང་བསྒོམས་པ་ལས་བྱུང་བ་སྦྱོར་བ་ལས་འབྱུང་བའི༌[^979]ཡོན་ཏན་དེ་དག་ཀྱང་ཉམས་པ་དང་ཁྱད་པར་ཅན་དག་ཁོ་ནའི་རྒྱུ་ཡིན་གྱི་དམན་པ་རྣམས་ཀྱི་ནི་མ་ཡིན་ཏེ། འདི་ལྟ་སྟེ། འདོད་པ་ན་སྤྱོད་པའི་ཐོས་པ་ལས་བྱུང་བ་རྣམས་ནི་ཐོས་པ་ལས་བྱུང་བ་དང་བསམས་པ་ལས་བྱུང་བ་རྣམས་ཀྱི་ཡིན་ནོ། །བསམ་པ༌[^980]ལས་བྱུང་བ་རྣམས་ནི་བསམས་པ་ལས་བྱུང་བ་རྣམས་ཀྱི་ཡིན་ཏེ། བསྒོམས་པ་ལས་བྱུང་བ་ནི་མེད་པའི་ཕྱིར་རོ། །གཟུགས་ན་སྤྱོད་པའི་ཐོས་པ་ལས་བྱུང་བ་རྣམས་ནི་ཐོས་པ་ལས་བྱུང་བ་དང་བསྒོམས་པ་ལས་བྱུང་བ་རྣམས་ཀྱི་ཡིན་ཏེ། བསམས་པ་ལས་བྱུང་བ་ནི་མེད་པའི་ཕྱིར་རོ། །བསྒོམས་པ༌[^981]ལས་བྱུང་བ་རྣམས༌[^982]ནི་བསྒོམས་པ་ལས་བྱུང་བ་རྣམས་ཁོ་ནའི་ཡིན་ནོ། །དེ་དག་ཀྱང་རྣམ་པ་དགུ་ཐ་དད་པའི་ཕྱིར་ཆུང་ངུའི་ཆུང་ངུ་དག་ནི་ཐམས་ཅད་ཀྱི་ཡིན་ལ། ཆུང་ངུའི་འབྲིང་པོ་དག་ནི་བརྒྱད་ཀྱི་ཡིན་ཏེ། ལུགས་ནི་དེ་ལྟ་བུའོ།[^983] །སྐྱེས་ནས་ཐོབ་པ་ཅན་གྱི་དགེ་བའི་ཆོས་རྣམས་ནི༌[^984]རྣམ་པ་དགུ་པོ་ཐམས་ཅད་ཕན་ཚུན་དུ་སྐལ་བ་མཉམ་པའི་རྒྱུ་ཡིན་ཏེ། ཉོན་མོངས་པ་ཅན་རྣམས་ཀྱང་དེ་དང་འདྲའོ། །མ་བསྒྲིབས་ལ་ལུང་དུ་མ་བསྟན་པ་རྣམས་ནི་རྣམ་པ་བཞི་སྟེ། རྣམ་པར་སྨིན་པ་ལས་སྐྱེས་པ་དང་། སྤྱོད་ལམ་པ་འམ།[^985] བཟོའི་གནས་པ་དང་། སྤྲུལ་པའི་སེམས་ལྷན་ཅིག་སྐྱེས་པ་རྣམས་ཏེ། དེ་དག་ནི་གོ་རིམས་བཞིན་དུ་བཞི་དང་། གསུམ་དང་། གཉིས་དང་། གཅིག་དག་གི་སྐལ་བ་མཉམ་པའི་རྒྱུ་ཡིན་ནོ། །སྤྲུལ་པའི་སེམས་བསམ་གཏན་བཞིའི་འབྲས་བུ་འདོད་པ་ན་སྤྱོད་པ༌[^986]ཡང་ཡིན་ཏེ། དེ་ལ་བསམ་གཏན་གོང་མའི་འབྲས་བུ་ནི་བསམ་གཏན་འོག་མའི་འབྲས་བུ་ནི་མ༌[^987]ཡིན་ནོ། །འབད་པ༌[^988]འབྲས་བུ་མེད་པར་འགྱུར་དུ་འོང་བའི་ཕྱིར་སྐལ་བ་མཉམ་པའི་རྒྱུ་མངོན་པར་འདུ་བྱེད་པ་ཅན་གྱི་འབྲས་བུ་ནི་དམན་པ་མ་ཡིན་ཏེ། མདོ་སྡེ་པ་རྣམས་ན་རེ། བཅོམ་ལྡན་འདས་ཀྱིས་གང་ལས་ཀྱང་འདུས་མ་བྱས་རྒྱུ་ཡིན་ནོ་ཞེས་མ་གསུངས་ཀྱི། རྒྱུ་མ་ཡིན་ནོ་ཞེས༌[^1028]རྣམ་གྲངས་ཀྱིས་གསུངས་སོ།[^1029] །ཇི་ལྟར་གསུངས་ཤེ་ན། གཟུགས་སྐྱེད་པའི༌[^1030]རྒྱུ་གང་དག་ཡིན་པ་དང་། རྐྱེན་གང་དག་ཡིན་པ་དེ་དག་ཀྱང་མི་རྟག་པ་ཡིན་ན་རྒྱུ་དང་རྐྱེན་མི་རྟག་པ་དག་ལ་བརྟེན་ནས་བྱུང་བའི་གཟུགས་ལྟ་རྟག་པར་ག་ལ་འགྱུར། རྣམ་པར་ཤེས་པའི་བར་དུ་ཡང་དེ་དང་འདྲའོ་ཞེས་གསུངས་སོ་ཞེས་ཟེར་རོ། །དེ་ལྟ་ན་འོ་ན་ནི་འདུས་མ་བྱས་རྣམ་པར་ཤེས་པའི་དམིགས་པའི་རྐྱེན་དུ་ཡང་མི་འགྱུར་རོ། །སྐྱེས་པའི༌[^1031]ཞེས་དཀར་བའི༌[^1032]ཕྱིར་འགྱུར་ཏེ། རྣམ་པར་ཤེས་པ་སྐྱེད་པའི༌[^1033]རྒྱུ་གང་དག་ཡིན་པ་དང་རྐྱེན་གང་དག་ཡིན་པ༌[^1034]དེ་དག་ཀྱང་མི་རྟག་ན་ཞེས་གསུངས་ཀྱི་རྣམ་པར་ཤེས་པའི་རྐྱེན་གང་དག་ཡིན་པ༌[^1035]དེ་དག་ཀྱང་མི་རྟག་ན་ཞེས་ནི་མི་གསུངས༌[^1036]སོ། །རྒྱུ་རྣམས་ཀྱང་གང་དག་སྐྱེད་པའི་རྒྱུ་དེ་དག་ཁོ་ན་མི་རྟག་གོ་ཞེས་འབྱུང་བའི་ཕྱིར༌[^1037]འདུས་མ་བྱས་ཀྱང་མི་སྒྲིབ་པའི་དངོས་པོ་ཙམ་གྱིས་བྱེད་རྒྱུའི་རྒྱུ་ཉིད་དུ་མི་དགག་པ༌[^1038]ཡིན་ནམ། མདོ་ལས་དམིགས་པའི་རྐྱེན་ཡིན་པར་གསུངས་ཀྱི་མི་སྒྲིབ་པའི་རྒྱུ་ཡིན་པར་ནི་མ་གསུངས་པས། མདོ་ལས་འདུས་མ་བྱས་རྒྱུའི་དངོས་པོ༌[^1039]མི་འགྲུབ་བོ། །མ་གསུངས་མོད་ཀྱི་བཀག་པ་ནི་མེད་དོ། །

ཡང་སེམས་ཉི་ཤུ་པོ་འདི་དག་ལས་གང་གི་མཇུག་ཐོགས་སུ་གང་ཞིག་འབྱུང་ཞེ་ན། རེ་ཞིག་འདོད་པ་ན་སྤྱོད་པའི་བརྒྱད་ལས་སྦྱོར་བ་ལས་བྱུང་བའི་མཇུག་ཐོགས་སུ༌[^1240]ནི་སེམས་བཅུ་འབྱུང་སྟེ། མངོན་པར་ཤེས་པའི་འབྲས་བུ་མ་གཏོགས་པ་རང་གི་ས་པ་བདུན་དང་། གཟུགས་ན་སྤྱོད་པའི་སྦྱོར་བ་ལས་བྱུང་བ་དང་། སློབ་པ་དང་། མི་སློབ་པའོ། །དེ་ནི་བརྒྱད་ཀྱི་མཇུག་ཐོགས་སུ་འབྱུང་སྟེ། རང་གི་དགེ་བ་དང་། ཉོན་མོངས་པ་ཅན་དག་དང་། གཟུགས་ན་སྤྱོད་པའི་སྦྱོར་བ་ལས་བྱུང་བ་དང་། ཉོན་མོངས་པ༌[^1241]ཅན་དག་དང་། སློབ་པ་དང་། མི་སློབ་པ་དག་ལས་སོ། །སྐྱེས་ནས་ཐོབ་པའི་མཇུག་ཐོགས་སུ་ནི་དགུ་སྟེ། མངོན་པར་ཤེས་པའི་འབྲས་བུ་མ་གཏོགས་པ་རང་གི་ས་པ་བདུན་དང་། གཟུགས་དང་གཟུགས་མེད་པ་ན་སྤྱོད་པའི་ཉོན་མོངས་པ་ཅན་དག་གོ། །དེ་ནི་བཅུ་གཅིག་གི་མཇུག་ཐོགས་སུ་འབྱུང་སྟེ། སྔ་མ་བཞིན་དུ་རང་གི་བདུན་དང་། གཟུགས་ན་སྤྱོད་པའི་སྦྱོར་བ་ལས་བྱུང་བ་དང་། ཉོན་མོངས་པ་ཅན་དག་དང་། སློབ་པ་དང་། མི་སློབ་པ་དག་ལས་སོ། །མི་དགེ་བ་དང་། བསྒྲིབས་ལ་ལུང་དུ་མ་བསྟན་པའི་མཇུག་ཐོགས་སུ་ནི་བདུན་ཏེ། སྔ་མ་བཞིན་དུ་རང་གི་དག་ཁོ་ནའོ། །དེ་དག་ནི་སེམས་བཅུ་བཞིའི་མཇུག་ཐོགས་སུ་འབྱུང་སྟེ། རང་གི་བདུན་དང་། སྦྱོར་བ་ལས་བྱུང་བ་དང་། མངོན་པར་ཤེས་པའི་འབྲས་བུ་དག་མ་གཏོགས་པ་གཟུགས་ན་སྤྱོད་པ་བཞི་དང་། སྦྱོར་བ་ལས་བྱུང་བ་མ་གཏོགས་པ་གཟུགས་མེད་པ་ན་སྤྱོད་པ་གསུམ་ལས་སོ། །སྤྱོད་ལམ་པ་དང་། རྣམ་པར་སྨིན་པ་ལས་སྐྱེས་པའི་མཇུག་ཐོགས་སུ་ནི་བརྒྱད་དེ། སྦྱོར་བ་ལས་བྱུང་བ་དང་། མངོན་པར་ཤེས་པའི་འབྲས་བུ་དག་མ་གཏོགས་པ་རང་གི་ས་པ་དྲུག་དང་། གཟུགས་དང་གཟུགས་མེད་པ་ན་སྤྱོད་པའི་ཉོན་མོངས་པ་ཅན་དག་གོ། །དེ་དག་ནི་སེམས་བདུན་གྱི་མཇུག་ཐོགས་སུ་འབྱུང་སྟེ། སྔ་མ་བཞིན་དུ་རང་གི་བདུན་ཁོ་ན་ལས་སོ། །བཟོའི་གནས་པའི་མཇུག་ཐོགས་སུ་ནི་དྲུག་སྟེ། སྦྱོར་བ་ལས་བྱུང་བ་དང་། མངོན་པར་ཤེས་པའི་འབྲས་བུ་དག་མ་གཏོགས་པ་རང་གི་རྣམས་ཁོ་ནའོ། །དེ་ནི་བདུན་གྱི་མཇུག་ཐོགས་སུ་འབྱུང་སྟེ། མངོན་པར་ཤེས་པའི་འབྲས་བུ་མ་གཏོགས་པ་རང་གི་དག་ཁོ་ན་ལས་སོ། །མངོན་པར་ཤེས་པའི་འབྲས་བུའི་མཇུག་ཐོགས་སུ་ནི་གཉིས་ཏེ། མངོན་པར་ཤེས་པའི་འབྲས་བུ་དང་རང་གི་དྲུག༌[^1242]དང་། གཟུགས་ན་སྤྱོད་པའི་སྦྱོར་བ་ལས་བྱུང་བའོ། །དེ་ཡང་དེ་གཉིས་ཁོ་ན་ལས་སོ། །

###### **གཟུགས་ན་སྤྱོད་པའི་དྲུག།** ^2-5-6-2-1-2-0

[Block 1093]
ད་ནི་གཟུགས་ན་སྤྱོད་པའི་དྲུག་གི་བརྗོད་པར་བྱ་སྟེ། སྦྱོར་བ་ལས་བྱུང་བའི་མཇུག་ཐོགས་སུ་ནི་བཅུ་གཉིས་ཏེ། འདོད་པ་ན་སྤྱོད་པའི་དགེ་བ་དག༌[^1243]དང་། མངོན་པར་ཤེས་པའི་འབྲས་བུ་དང་། རང་གི་དྲུག་དང་། གཟུགས་མེད་པ་ན་སྤྱོད་པའི་སྦྱོར་བ་ལས་བྱུང་བ་དང་། སློབ་པ་དང་། མི་སློབ་པའོ། །དེ་ན་སེམས་བཅུའི་མཇུག་ཐོགས་སུ་འབྱུང་སྟེ། འདོད་པ་ན་སྤྱོད་པའི་སྦྱོར་བ་ལས་བྱུང་བ་དང་། མངོན་པར་ཤེས་པའི་འབྲས་བུ་དག་དང་། སྤྱོད་ལམ་པ་དང་། རྣམ་པར་སྨིན་པ་ལས་སྐྱེས་པའི་དག་མ་གཏོགས་པ་རང་གི་བཞི་དང་། གཟུགས་མེད་པ་ན་སྤྱོད་པ༌[^1244]སྦྱོར་བ་ལས་བྱུང་བ་དང་། ཉོན་མོངས་པ་ཅན་དག་དང་། སློབ་པ་དང་། མི་སློབ་པ་དག་ལས་སོ། །སྐྱེས་ནས་ཐོབ་པའི་མཇུག་ཐོགས་སུ་ནི་བརྒྱད་དེ། འདོད་པ་ན་སྤྱོད་པའི་ཉོན་མོངས་པ་ཅན་དག་དང་། མངོན་པར་ཤེས་པའི་འབྲས་བུ་མ་གཏོགས་པ་རང་གི་ལྔ་དང་། གཟུགས་མེད་པ་ན་སྤྱོད་པའི་ཉོན་མོངས་པ་ཅན་ནོ། །དེ་ནི་ལྔ་ལས་ཏེ། མངོན་པར་ཤེས་པའི་འབྲས་བུ་མ་གཏོགས་པ་རང་གི་དག་ཁོ་ན་ལས་སོ། །ཉོན་མོངས་པ་ཅན་གྱི་མཇུག་ཐོགས་སུ་ནི་དགུ་སྟེ། འདོད་པ་ན་སྤྱོད་པའི་དགེ་བ་དག་དང་། ཉོན་མོངས་པ་ཅན་དག་སྟེ༌[^1245]བཞི་དང་། མངོན་པར་ཤེས་པའི་འབྲས་བུ་མ་གཏོགས་པ་རང་གི་ལྔའོ། །དེ་ནི་སེམས་བཅུ་གཅིག་གི་མཇུག་ཐོགས་སུ་འབྱུང་སྟེ། འདོད་པ་ན་སྤྱོད་པའི་སྐྱེས་ནས་ཐོབ་པ་དང་། སྤྱོད་ལམ་པ་དང་། རྣམ་པར་སྨིན་པ་ལས་སྐྱེས་པ་དག་དང་། མངོན་པར་ཤེས་པའི་འབྲས་བུ་མ་གཏོགས་པ་རང་གི་ལྔ་དང་། སྦྱོར་བ་ལས་བྱུང་བ་མ་གཏོགས་པ་གཟུགས་མེད་པ་ན་སྤྱོད་པ་གསུམ་ལས་སོ། །སྤྱོད་ལམ་པའི་མཇུག་ཐོགས་སུ་ནི་བདུན་ཏེ། འདོད་པ་ན་སྤྱོད་པའི་ཉོན་མོངས་པ་ཅན་དག་དང་། སྦྱོར་བ་ལས་བྱུང་བ་དང་། མངོན་པར་ཤེས་པའི་འབྲས་བུ་མ་གཏོགས་པ་རང་གི་བཞི་དང་། གཟུགས་མེད་པ་ན་སྤྱོད་པའི་ཉོན་མོངས་པ་ཅན་ནོ། །དེ་ནི་ལྔའི་མཇུག་ཐོགས་སུ་འབྱུང་སྟེ། མངོན་པར་ཤེས་པའི་འབྲས་བུ་མ་གཏོགས་པ་རང་གི་དག་ཁོ་ན་ལས་སོ། །རྣམ་པར་སྨིན་པ་ལས་སྐྱེས་པ་ཡང་དེ་དང་འདྲ་བར་བརྗོད་པར་བྱའོ། །མངོན་པར་ཤེས་པའི་འབྲས་བུའི་མཇུག་ཐོགས་སུ་ནི་གཉིས་ཏེ། རང་གི་སྦྱོར་བ་ལས་བྱུང་བ་དང་། མངོན་པར་ཤེས་པའི་འབྲས་བུ་དག་ཁོ་ནའོ། །དེ་ཡང་དེ་དག་ཁོ་ན་ལས་སོ། །

མདོ་སྡེ་པ་རྣམས་ནི་མདོ་ལས་འོད་གསལ་བའི་ལྷའི་རིས་དེ་ན་སེམས་ཅན་གང་དག་སྐྱེས་ནས་རིང་པོ་མ་ལོན་པ་འཇིག་རྟེན་འདི་འཇིག་པ་ལ་མི་མཁས་ཤིང་འཆགས་པ་ལ་མི་མཁས་པ་དེ་དག་མེ་ལྕེ་དེ་མཐོང་ནས༌[^1344]མེ་ལྕེ་དེ༌[^1345]ཚངས་པའི་གཞལ་མེད་ཁང་སྟོང་པ་བསྲེགས་ནས༌[^1346]འདིར་འོང་བར་འགྱུར་ན་མི་རུང་ངོ་ཞེས་སྐྲག་ནས་ཡི་ཆད་ཅིང་སྐྱོ་བར་འགྱུར་རོ། །འོད་གསལ་བའི་ལྷའི་རིས་དེ་ན་སེམས་ཅན་གང་དག་སྐྱེས་ནས་རིང་དུ་ལོན་པ་འཇིག་རྟེན་འདི་འཇིག་པ་ལ་མཁས་ཤིང་འཆགས་པ་ལ་མཁས་པ་ལ༌[^1347]དེ་དག་སེམས་ཅན་སྐྲག་པ་དེ་དག་ལ་གྲོགས་པོ་དག་མ་འཇིགས་ཤིག །གྲོགས་པོ་དག་མ་འཇིགས་ཤིག །མེ་ལྕེ་འདི་ནི་སྔོན་ཡང་ཚངས་པའི་གཞལ་མེད་ཁང་སྟོང་པ་བསྲེགས་ནས་དེ་ཉིད་དུ་མེད་པར་གྱུར་ཏོ༌[^1348]ཞེས་དབུགས་འབྱིན་པར་བྱེད་དོ་ཞེས་དེ་དག་ཇི་ལྟར་འདུ་ཤེས་ཐ་དད་པ་དག་ཡིན་པར་བཤད་དེ། དེ་ལྟ་བས་ན་དེ་དག་མེ་ལྕེ་འོང་བ་དང་མེད་པར་འདུ་ཤེས་པའི་ཕྱིར་དང་། སྐྲག་པ་དང་མི་སྐྲག་པར་འདུ་ཤེས་པའི་ཕྱིར་འདུ་ཤེས༌[^1349]ཐ་དད་པ་དག་ཡིན་གྱི་བདེ་བ་དང་སྡུག་བསྔལ་དང་། [^1350]བདེ་བ་ཡང་མ་ཡིན་སྡུག་བསྔལ་ཡང་མ་ཡིན་པར་འདུ་ཤེས་པའི་ཕྱིར་ནི་མ་ཡིན་ནོ་ཞེས་འཆད་དོ། །
