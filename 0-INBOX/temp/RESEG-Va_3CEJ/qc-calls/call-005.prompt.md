━━━ ISSUE TYPES ━━━

CONNECTOR_ENDING
  The block ends with a connector particle (དང་། / ཞིང་། / ཅིང་། / ནས། / ལས། /
  སྟེ། / ཏེ།) that grammatically requires continuation. Real issue if the next
  block is the grammatical continuation. False positive if this is a closing verse
  pāda or a deliberate short citation frame.

OBJECTION_REPLY_FUSED
  The block contains both an objection marker (ཅེ་ན། / ཞེ་ན། / སྙམ་ན།) and a reply
  opener (འོ་ན།). These should always be two separate blocks. Almost always a
  real issue.

OVER_LENGTH
  The block exceeds the syllable threshold. Usually NOT wrong: a whole explanation
  unit is legitimately long. Split only if a new node opener (ordinal + title +
  ནི། / ལ་ N།) or the treatment of a new verse is buried mid-block.

SHORT_FRAGMENT
  The block is suspiciously short — may be a stray split artifact that should be
  merged with an adjacent block.

- Each block number appears in AT MOST ONE operation.

གང་འཇིག་རྟེན༌[^2201]འདི་ཆགས་ནས་བར་གྱི་བསྐལ་པ་ཉི་ཤུར་འདུག་པ་དེ་ལས་ནི་ངེས་པར་འབྱུང་བ་ཞེས་བརྗོད་པར་བྱ་ལ། གང་བར་གྱི་བསྐལ་པ་ཉི་ཤུར་འཇིག་པར་འགྱུར་བ་དེ་ལ་ནི་ཞུགས་པ་ཞེས་བརྗོད་པར་བྱ་སྟེ། །དེའི་ཚེ་གང་ལ་ངེས་པར་དམྱལ་བ་མྱོང་བར་འགྱུར་བའི་ལས་ཡོད་པ་དེ་ནི་འཇིག་རྟེན་གྱི་ཁམས་གཞན་དག་ཏུ་འཕེན་པར་འགྱུར་ཏེ། དུད་འགྲོ་མྱོང་བར་འགྱུར་བ་དང་། ཡི་དགས་མྱོང་བར་འགྱུར་བ་ཡང་དེ་བཞིན་དུ་བརྗོད་པར་བྱའོ། །རྒྱ་མཚོ་ཆེན་པོ་ན་འཁོད་པའི་དུད་འགྲོ་རྣམས་ནི་སྔར་འཇིག་གོ། །མི་དང་ལྷན་ཅིག་རྒྱུ་བ༌[^2203]རྣམས་ནི་དེ་དག་མི་དང་ལྷན་ཅིག་ཏུའོ། །གང་མི་རྣམས་དག་གི་ནང་ན་སེམས་ཅན་གང་ཡང་རུང་བ་བདག་ཉིད་ཀྱིས་སློབ་དཔོན་མེད་པར༌[^2204]ཆོས་ཉིད་ཀྱིས་ཐོབ་པའི་བསམ་གཏན་དང་པོ་ལ་སྙོམས་པར་འཇུག་པ་དེ་ལྟ་བུའི་དུས་ཀྱང་ཡོད་དེ། དེ་དེ་ལས་ལངས་ནས་ཚིག་ཏུ་ཀྱེ་མ་དབེན་པ་ལས་སྐྱེས་པའི་དགའ་བ་དང་བདེ་བ་ནི་བདེ་བ་ཡིན་ནོ། །དབེན་པ་ལས་སྐྱེས་པའི་དགའ་བ་དང་བདེ་བ་ནི་ཞི་བ་ཡིན་ནོ་ཞེས་ཀྱང་སྨྲ་ལ། སྒྲ་དེ་ཐོས་ནས་སེམས་ཅན་དེ་དག༌[^2205]ཀྱང་སྙོམས་པར་འཇུག་ཅིང་། ཤི་ནས་ཚངས་པའི་འཇིག་རྟེན་དུ་སྐྱེ་བར་འགྱུར་ཏེ། གང་གི་ཚེ་འཛམ་བུའི་གླིང་ན་སེམས་ཅན་འགའ་ཡང་མ་ལུས་པར་གྱུར་ན་དེ་ཙམ་གྱིས་འདི་ལྟ་སྟེ། འཛམ་བུའི་གླིང་འཇིག་པས་འཇིག་རྟེན་འདི་ཞིག་པ་ཡིན་ནོ། །ཤར་གྱི་ལུས་འཕགས་དང་། ནུབ་ཀྱི་བ་ལང་སྤྱོད་དང་། བྱང་གི་སྒྲ་མི་སྙན་འཇིག་པ་དག་ཀྱང་དེ་བཞིན་དུ་བརྗོད་པར་བྱ་སྟེ། གང་གི་ཚེ་མི་དག་གི་ནང་ན་སེམས་ཅན་འགའ་ཡང་མ་ལུས་པར་གྱུར་པ་དེ་ཙམ་གྱིས་ན་འདི་ལྟ་སྟེ། མི་འཇིག་པས་འཇིག་རྟེན་འདི་ཞིག་པ་ཡིན་ནོ། །བྱང་གི་སྒྲ་མི་སྙན་པ་རྣམས་ནི་འདོད་པ་ན་སྤྱོད་པའི་ལྷ་དག་གི་ནང་དུ་སྐྱེ་བར་འགྱུར་ཏེ། དེ་ན་འདོད་ཆགས་དང་བྲལ་བ་མེད་པའི་ཕྱིར་རོ། །དེ་བཞིན་དུ་རྒྱལ་ཆེན་བཞིའི་རིས་ཀྱི་ལྷ་དག་ན། ཡང་བསམ་གཏན་དང་པོ་བསྐྱེད་པ་ནས་ཚངས་པའི་འཇིག་རྟེན་དུ་སྐྱེ་བར་འགྱུར་ཏེ། གང་གི་ཚེ་དེ་ན་སེམས་ཅན་འགའ་ཡང་མ་ལུས་པར་གྱུར་ན་དེ་ཙམ་གྱིས་འདི་ལྟ་སྟེ། རྒྱལ་ཆེན་བཞིའི་རིས་འཇིག་པས་འཇིག་རྟེན་འདི་ཞིག་པ་ཡིན་ནོ། །གཞན་འཕྲུལ་དབང་བྱེད་འཇིག་པའི་བར་དུ་ཡང་དེ་བཞིན་དུ་བརྗོད་པར་བྱ་སྟེ། གང་གི་ཚེ་འདོད་པ་ན་སྤྱོད་པའི་ལྷ་དག་གི་ནང་ན་སེམས་ཅན་འགའ་ཡང་མ་ལུས་པར་གྱུར་པ་དེ་ཙམ་གྱིས་ན་འདི་ལྟ་སྟེ་འདོད་པའི་ཁམས་འཇིག་པས་འཇིག་རྟེན་འདི༌[^2206]ཞིག་པ་ཡིན་ནོ། །ཚངས་པའི་འཇིག་རྟེན་ན་ཡང་སེམས་ཅན་གང་ཡང་རུང་བ་ཞིག་ཆོས་ཉིད་ཀྱིས་ཐོབ་པའི་བསམ་གཏན་གཉིས་པ་ལ་སྙོམས་པར་ཞུགས་ཏེ། ལངས་ནས་ཚིག་ཏུ་ཀྱེ་མ་ཏིང་ངེ་འཛིན་ལས་སྐྱེས་པའི་དགའ་བ་དང་བདེ་བ་ནི་བདེ་བ་ཡིན་ནོ། །དེད་འདྲེན་ཕྲག་བཅུ་ལ་ནི་དེད་འདྲེན་ཆེན་པོའོ། །དེད་འདྲེན་ཆེན་པོ་ཕྲག་བཅུ་ལ་ནི་མཐའ་སྣང་ངོ་། །མཐའ་སྣང་ཕྲག་བཅུ་ལ་ནི་མཐའ་སྣང་ཆེན་པོའོ། །མཐའ་སྣང་ཆེན་པོ་ཕྲག་བཅུ་ལ་ནི་རྒྱུ་རིག་གོ། །རྒྱུ་རིག༌[^2233]ཕྲག་བཅུ་ལ་ནི་རྒྱུ་རིག་ཆེན་པོའོ། །རྒྱུ་རིག་ཆེན་པོ་ཕྲག་བཅུ་ལ་ནི་འོད་མཛེས་སོ། །འོད་མཛེས་ཕྲག་བཅུ་ལ་ནི་འོད་མཛེས་ཆེན་པོའོ། །འོད་མཛེས་ཆེན་པོ་ཕྲག་བཅུ་ལ་ནི་དབང་པོའོ། འོ་ན་ཡང༌[^2236]བྱང་ཆུབ་སེམས་དཔའ་སྨོན་ལམ་བཏབ་པ་རྣམས་དུས་རིང་པོ་ཁོ་ནས་མངོན་པར་རྫོགས་པར་འཚང་རྒྱ་བར་འགྱུར་རམ་ཞེ་ན། ཅི་དེ་དེ༌[^2237]ལྟར་འགྱུར་རམ། བྱང་ཆུབ་སེམས་དཔའ་རྣམས༌[^2238]ནི་བསྐལ་པ་གྲངས་མེད་པ་གསུམ་དུ་དཀའ་བ་བརྒྱ་སྟོང་གིས་བསོད་ནམས་དང་ཡེ་ཤེས་ཀྱི་ཚོགས་ཆེན་པོ་ཕ་རོལ་ཏུ་ཕྱིན་པ་དྲུག་གིས་མངོན་པར་རྫོགས་པར་འཚང་རྒྱ་བར་འགྱུར་རོ། །གལ་ཏེ་ཐར་པའི་གོ་སྐབས་གཞན་དེ་ལྟ་མ་ཡིན་པ་ཡང་ཡོད་ན་གོ། དེ་དག་ཅིའི་ཕྱིར་འབད་པ་འདི་སྙེད་ཅིག་རྩོམ་པར་བྱེད་ཅེ་ན། དེ་དག་ནི་ཇི་ལྟར་ན་གཞན་དག་ཀྱང་སྡུག་བསྔལ་གྱི་ཆུ་བོ་ཆེན་པོ་ལས་ཡོངས་སུ་བསྐྱབ་པར་ནུས་པར་འགྱུར་སྙམ་དུ་གཞན་གྱི་དོན་དུ་འབད་པ་རྩོམ་པར་བྱེད་དོ། །འདི་དག་གི་གཞན་གྱི་དོན་གྱིས་བདག་གི་དོན་དུ་འགྱུར་བ་གང་ཡིན༌[^2239]ཞེ་ན། དེ་དག་གི་གཞན་གྱི་དོན་གང༌[^2240]ཡིན་པ་དེ་ཉིད་བདག་གི་དོན་ཏེ། [^2241]དེ་འདོད་པའི་ཕྱིར་རོ། །ད་ནི་སུ་ཞིག་འདི་ལ་དད་པར་འགྱུར་ཞེ་ན། བདག་གསོ་བར་བྱེད་པའི་སྙིང་རྗེ་མེད་པ་རྣམས་ཀྱིས་འདི་ལ་དད་པར་དཀའ་བ་ནི་བདེན་ནོ། །སྙིང་རྗེ་ཅན༌[^2242]རྣམས་ཀྱིས་དད་པར་བྱས་ཟིན་པ་ཡིན་ཏེ། དཔེར་ན་འདི་ན་སྙིང་རྗེ་མེད་པ་ལ་གོམས་པ་ཁ་ཅིག་རང་གི་དོན་མེད་བཞིན་དུ་ཡང་གཞན་ཉོན་མོངས་པ་ལ་མངོན་པར་དགའ་བ་དམིགས་པ་དེ་བཞིན་དུ་སྙིང་རྗེ་ལ་གོམས་པ་དག་རང་གི་དོན་མེད་བཞིན་དུ་ཡང་གཞན་ལ་ཕན་པར་བྱ་བ་ལ་མངོན་པར་དགའ་བ་ཡོད་དོ་སྙམ་དུ་ཡིད་ཆེས་པར་བྱའོ། །ཡང་དཔེར་ན་འདུས་བྱས་ཀྱི་མཚན་ཉིད་མངོན་པར་མི་ཤེས་པ་དག་གོམས་པའི་དབང་གིས་འདུས་བྱས་བདག་མེད་པར་གྱུར་པ་དག་ལ་བདག་ཏུ་ཆགས་པ་བསྐྱེད་ནས་རྒྱུ་དེས་སྡུག་བསྔལ་དག་ཉམས་སུ་མྱོང་བར་འགྱུར་བ་དེ་བཞིན་དུ་གོམས་པའི་དབང་གིས་དེ་དག་ལས་བདག་ཏུ་ཆགས་པ་བཟློག་ནས། གཞན་དག་ལ་ལྟ་བ་བསྐྱེད་དེ། རྒྱུ་དེས་སྡུག་བསྔལ་དག་མྱོང་བར་འགྱུར་རོ་སྙམ་དུ་ཡིད་ཆེས་པར་བྱའོ། །གང་གཞན་དག་གི་སྡུག་བསྔལ་གྱིས་སྡུག་བསྔལ་བར་འགྱུར་ཞིང་། གཞན་དག་གི་བདེ་བས་བདེ་བར་འགྱུར་གྱི། བདག་ཉིད་ཀྱི་ནི་མ་ཡིན་པ་དེ་ལྟ་བུའི་རིགས་གཞན་ཁོ་ན་ཡང་འགྲུབ་སྟེ། དེ་ལྟ་ནི་རང་གི་དོན་དུ་མི་བལྟའོ། །

།བརྒྱ་ཕྲག་བཅུ་ལ་ནི་སྟོང་ངོ་། །སྟོང་ཕྲག་བཅུ་ལ་ནི་ཁྲིའོ། །ཁྲི་ཕྲག་བཅུ་ལ་ནི་འབུམ་མོ། །འབུམ་ཕྲག་བཅུ་ལ་ནི་ས་ཡའོ། །ས་ཡ་ཕྲག་བཅུ་ལ་ནི་བྱེ་བའོ། །བྱེ་བ་ཕྲག་བཅུ་ལ་ནི་དུང་ཕྱུར་རོ། །དུང་ཕྱུར་ཕྲག་བཅུ་ལ་ནི་ཐེར་འབུམ་མོ། །ཐེར་འབུམ་ཕྲག་བཅུ་ལ་ནི་ཐེར་འབུམ་ཆེན་པོའོ། །ཐེར་འབུམ་ཆེན་པོ་ཕྲག་བཅུ་ལ་ནི་ཁྲག་ཁྲིག་གོ། །ཁྲག་ཁྲིག་ཕྲག་བཅུ་ལ་ནི་ཁྲག་ཁྲིག་ཆེན་པོའོ། །ཁྲག་ཁྲིག་ཆེན་པོ་ཕྲག་བཅུ་ལ་ནི་རབ་བཀྲམ་མོ། །རབ་བཀྲམ་ཕྲག་བཅུ་ལ་ནི་རབ་བཀྲམ་ཆེན་པོའོ། །རབ་བཀྲམ་ཆེན་པོ་ཕྲག་བཅུ་ལ་ནི་གཏམས་སོ། །གཏམས་ཕྲག་བཅུ་ལ་ནི་གཏམས་ཆེན་ནོ། །གཏམས་ཆེན་ཕྲག་བཅུ་ལ་ནི་དཀྲིགས་སོ། །དཀྲིགས་ཕྲག་བཅུ་ལ་ནི་དཀྲིགས་ཆེན་ནོ།[^2232] །དཀྲིགས་ཆེན་ཕྲག་བཅུ་ལ་ནི་མི་འཁྲུགས་པའོ། །མི་འཁྲུགས་པ་ཕྲག་བཅུ་ལ་ནི་མི་འཁྲུགས་པ་ཆེན་པོའོ། །མི་འཁྲུགས་པ་ཆེན་པོ་ཕྲག་བཅུ་ལ་ནི་ཁྱད་ཕྱིན་ནོ། ཡང་མི་ཚེ་ལོ་བཅུ་པ་རྣམས་ལ་ཉེས་པ༌[^2330]དག་ཉིད་ཀྱིས༌[^2331]ལྷས་ཆར་པ་མི་འབེབས་ཏེ། དེས་ན་མུ་གེ་གབ་ཙེ༌[^2332]ཞེས་བྱ་བ་དང་། རུས་གོང་དཀར་པོ་ཞེས་བྱ་བ་དང་། ཐུར་མས་འཚོ་བ་ཞེས་བྱ་བའི་མུ་གེ་འབྱུང་བར་འགྱུར་རོ། །ཇི་ལྟར་གབ་ཙེ་ཡིན་ཞེ་ན། རྒྱུ་གཉིས་ཀྱིས་ཡིན་ཏེ། དེང་སང་འདུ་བ་གང་ཡིན་པ་དེ་ནི་དེའི་ཚེ་གབ་ཙེ་ཞེས་བྱ་བ། གབ་ཙེ་ལ་ཡང་གབ་ཙེ་ཞེས་བྱ་སྟེ། བཀྲེས་པ་དང་། ཉམ་ཆུང་བས་བཀྲེས་པའི་མི༌[^2333]དག་འདུ་ཞིང་འདུས་ནས་འཆི་བར་འགྱུར་བ་དང་། མ་འོངས་པའི་སྐྱེ་བོ་རྣམས་ལ་ཕན་གདགས་པའི་ཕྱིར་གབ་ཙེ་དག་གི་ནང་དུ་ས་བོན་དག་འཇོག་པར་བྱེད་དེ། དེའི་ཕྱིར་མུ་གེ་དེ་ནི་གབ་ཙེ་ཞེས་བྱའོ། །ཇི་ལྟར་ན༌[^2334]རུས་གོང་དཀར་པོ་ཡིན་ཞེ་ན། རྒྱུ་གཉིས་ཀྱིས་ཡིན་ཏེ། ལུས་སྐམས་ཤིང་རྩུབ་པོ་དེ་དག་ཤི་བ་དང་མྱུར་བ་ཁོ་ན༌[^2335]རུས་པ་དཀར་པོར་གྱུར་པ༌[^2336]དང་། བཀྲེས་པས་ཉེན་པ་དེ༌[^2337]རྣམས་ཀྱི་རུས་གོང་དཀར་པོ་དེ་དག་བསྡུས་ཏེ་བསྐོལ་ནས་འཐུང་བར་བྱེད་པའོ། ། ཇི་ལྟར་ན་ཐུར་མས་འཚོ་བ་ཡིན་ཞེ་ན། རྒྱུ་གཉིས་ཀྱིས་ཡིན་ཏེ། སེམས་ཅན་དེ་དག་ཐུར་མས་བསྒོ་བས་ཁྱིམ་དག་ཏུ་དེ་རིང་ནི་ཁྱིམ་བདག་ཟ་བའི་རེས་ལ་བབ་བོ། །སང་ནི་ཁྱིམ་བདག་མོ་ཞེས་བྱ༌[^2338]དེ་ལྟ་བུ་ལ་སོགས་པས་ཟས་འགྱེད་པར་བྱེད་པ་དང་། འབྲུའི་གནས་ཀྱི་གསེབ་དག་ནས་འབྲུ་དག་ཐུར་མས་བྲུས་ཏེ། ཆུ་མང་པོར་བསྐོལ་ནས་བསྐོལ་བ་དེ་འཐུང་བར་བྱེད་དོ། །འདི་སྐད་དུ་གང་གིས་ཉི་མ་འགའ་ཞིག་སྲོག་གཅོད་པ་སྤངས་པ་ལེགས་པར་བསྲུངས་པ༌[^2339]དང་། དགེ་འདུན་ལ་ཨ་རུ་ར་འགའ་དང་། བསོད་སྙོམས་འགའ་ཞིག་གུས་པར་བྱས་ཏེ། ཕུལ་བ་དེ་ནི་མཚོན་དང་། ནད་དང་། མུ་གེ་དང་། བར་གྱི་བསྐལ་པ་དེ་དག་ཏུ་སྐྱེ་བར་མི་འགྱུར་རོ་ཞེས་བརྗོད་དོ། །

འདི་ནི་རིགས་པ་མ་ཡིན་ནོ། །འདི་ལ་མི་རིགས་པ་གང་ཞིག་ཡིན་ཞེ་ན། གང་མ་གྲུབ་པ་བསྒྲུབ་པའི་ཕྱིར་དཔེར༌[^2359]བརྗོད་པ་མ་གྲུབ་པ་ཡིན་ནོ། །ཇི་ལྟར༌[^2360]འདི་ལ་ཅི་ཞིག་མ་གྲུབ་ཅེ་ན། འཇག་མ་དག་ལས་རེ་ལྡེ་གཞན་པ་དང་། སྐུད་པ་དག་ལས་རས་ཡུག་གཞན་ཞེས་བྱ་བ་མ་ཡིན་ཏེ། དེ་དག་དང་དེ་དག་ཁོ་ན་དེ་ལྟར་གནས་པ༌[^2361]ལ་དེ་དང་དེའི་མིང་ཐོབ་སྟེ། གྲོག་མའི་ཕྲེང་བ་བཞིན་ནོ། །ཇི་ལྟར་ཁོང་དུ་ཆུད་ཅེ་ན། སྐུད་པ་གཅིག་དང་ལྡན་ན་རས་ཡུག་མི་དམིགས་པའི་ཕྱིར་ཏེ། དེའི་ཚེ་རས་ཡུག་ཡོད་ན་ནི་དམིགས་པར་བྱ་བ་ལ་སུ་ཞིག་བགེགས༌[^2362]བྱེད། ཟད་པར་ཡོད་པ་མ་ཡིན་ན་ནི་དེ་ལ༌[^2363]རས་ཡུག་གི་ཆ་ཡོད་ཀྱི་རས་ཡུག་ནི་མ་ཡིན་པས་འདུས་པ་ཙམ་རས་ཡུག་ཡིན་ནོ། །སྐུད་པ་དག་ལས་གཞན་ལ༌[^2364]རས་ཡུག་གི་ཆ་ཡང་གང་ཞིག་ཡོད། རྟེན་དུ་མ་ཞིག་དང་ལྡན་པ་ལ་ལྟོས་ན་ནི་ཁ་ཚར་མཐོང་བ་ཙམ་དང་ལྡན་ན་རས་ཡུག་དམིགས་པར་འགྱུར་རོ། །

འོ་ན་ཇི་ལྟ་བུ་ཞེ་ན། སེམས་ཅན་རྣམས་ཀྱི། ལས་ལས་འཇིག་རྟེན་སྣ་ཚོགས་སྐྱེས། །གལ་ཏེ་ལས་ལས་སྐྱེས་ནས༌[^2395]ཅིའི་ཕྱིར་སེམས་ཅན་རྣམས་ཀྱི་ལས་དག་གིས་གུར་གུམ་དང་། ཙན་དན་ལ་སོགས་པ་ཆེས་དགའ་དགའ་ལྟ་བུར་སྐྱེས་པར༌[^2396]འགྱུར་ལ་དེ་དག་གི་ལུས་ནི་མ་ཡིན་ཞེ་ན། སེམས་ཅན་འདྲེན་མར་བྱེད་པ་རྣམས་ཀྱི་ལས་དེ་ལྟ་བུ་དག་ཁོ་ན༌[^2397]གང་རྨ་ལྟ་བུར་གྱུར་པའི་ལུས་དག་དང་། དེའི་ཚེ༌[^2398]གཉེན་པོར་གྱུར་པ་ལོངས་སྤྱོད་དགའ་དགའ་ལྟ་བུ་དག་ཀྱང༌[^2399]སྐྱེའི། ལྷ་འདྲེན་མར་བྱེད་པ་མ་ཡིན་པ་རྣམས་ཀྱི་ནི་གཉི་ག་ཡང་དགའ་དགའ་ལྟ་བུ་དག་ཡིན་ནོ། །

[Block 1974]

[Block 1975]
ལས་གཉིས་པོ་དེ་དག་ནི་གསུམ་ཡིན་ཏེ། ལུས་དང་ངག་དང་ཡིད་ཀྱི་ལས་རྣམས་སོ། །ལས་འདི་དག་ཇི་ལྟར་རྣམ་པར་གཞག་ཅི་རྟེན་ལས་སམ། འོན་ཏེ་ངོ་བོ་ཉིད་ལས་སམ། འོན་ཏེ་ཀུན་ནས་སློང་བ་ལས་གལ་ཏེ་རྟེན་ལས་ཡིན་ན་ནི་ཐམས་ཅད་ལུས་ལ་བརྟེན་པའི་ཕྱིར་ལུས་ཀྱི་ལས་གཅིག་པུར་འགྱུར་རོ། །གལ་ཏེ་ངོ་བོ་ཉིད་ལས་ཡིན་ན་ནི་དེ་དག་གི་ལས་གཅིག་པུར་འགྱུར་རོ། །གལ་ཏེ་ཀུན་ནས་སློང་བ་ལས་ཡིན་ན་ནི་ཐམས་ཅད་ཀྱང་ཡིད་ཀྱི༌[^2403]ཀུན་ནས་བསླང་བའི་ཕྱིར་ཡིད་ཀྱི་ལས་གཅིག་པུར་འགྱུར་རོ་ཞེ་ན། བྱེ་བྲག་ཏུ་སྨྲ་བ་རྣམས་ན་རེ་རྒྱུ་གསུམ་གྱིས་གོ་རིམས་བཞིན་དུ་གསུམ་རྣམ་པར་གཞག་གོ་ཞེས་ཟེར་རོ། །

དངོས་པོ་རྣམས་འཇིག་པ་ནི་རྒྱུ་མེད་པ་ལས་བྱུང་བ་ཡིན་ནོ། །ཅིའི་ཕྱིར་ཞེ་ན། བྱ་བའི་རྒྱུ་ཡིན་ན་འཇིག་པ་ཡང་མེད་པ་ཡིན་པས་མེད་པ་གང་ཡིན་པ་དེ་ལ་ནི་ཅི་ཞིག་བྱར་ཡོད། རྒྱུ་མེད་པ་ལས་བྱུང་བའི་འཇིག་པ་དེ་ནི་དངོས་པོ་སྐྱེད་པ༌[^2412]ཙམ་ལ་མ་ཡིན་ན་ཕྱིས་ཀྱང་མི་འབྱུང་སྟེ།[^2413] དངོས་པོ་མཚུངས་པའི་ཕྱིར་རོ། །འོན་ཏེ་གཞན་དུ་གྱུར་པ་ཡིན་ནོ་ཞེ་ན། དེ་ཉིད་གཞན་དུ་གྱུར་པ༌[^2414]ནི་རིགས་པ་མ་ཡིན་ཏེ། དེ་ཉིད་དེ་དང་མཚན་ཉིད་མི་མཐུན་པར་ནི་མི་རུང་ངོ་། །ཤིང་ལ་སོགས་པ་དག་མེ་དང་འབྲེལ་པ་ལས་འཇིག་པར་ཡང་མཐོང་ལ་མཐོང་བ་ལས་བརླིང་བའི་ཚད་མ་ཡང་མེད་པས་ཐམས་ཅད་ཀྱི་འཇིག་པ་ནི་རྒྱུ་མེད་པ་ལས་བྱུང་བ་མ་ཡིན་ནོ་ཞེ་ན། རེ་ཞིག་ཁྱོད་ཤིང་ལ༌[^2415]སོགས་པ་དག་མེ་དང་འབྲེལ་པ་ལས་འཇིག་པར་བལྟ་བར་བྱའོ༌[^2416]ཞེས་བྱ་བ་ཇི་ལྟ་བུར་སེམས། དེ་ཡོད་ན་དེ་དག་ལ༌[^2417]ཡང་མི་སྣང་བའི་ཕྱིར་རོ། །རེ་ཞིག་འདི་དཔྱད་པར་བྱ་སྟེ། ཅི་མེ་དང་འབྲེལ་པ་ལས་ཤིང་ལ་སོགས་པ་ཞིག་སྟེ། དེའི་ཕྱིར་མི་སྣང་བ་ཞིག་ཡིན་ནམ། འོན་ཏེ་རང་ཉིད་ཞིག་ལ༌[^2418]གཞན་དག་ཀྱང་མ་སྐྱེས་པས་དེའི་ཕྱིར་མི་སྣང་སྟེ་དཔེར་ན་རླུང་དང་ཕྲད་པ་ལས་མར་མེ་དང་ལག་པ་དང་ཕྲད་པ་ལས་དྲིལ་བུའི་སྒྲ་ལྟ་བུ་ཞིག་ཡིན། དེ་ལྟ་བས་ན་དོན་འདི་ནི་རྗེས་སུ་དཔག་པས་བསྒྲུབ་པར་བྱ་བ་ཡིན་ནོ། །འདི་ལ་རྗེས་སུ་དཔག་པ་གང་ཞེ་ན། རེ་ཞིག་མེད་པ་ནི་བྱ་བ་མ་ཡིན་པའི་ཕྱིར་ཞེས་ནི་བཤད་ཟིན་ཏོ། །
