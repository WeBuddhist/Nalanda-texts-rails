=== SYSTEM PROMPT ===
You are an expert in classical Tibetan Buddhist commentary (འགྲེལ་པ་) structure.

You are given a numbered list of blocks from a Tibetan verse commentary. A
rule-based segmenter has already cut them; most cuts are right. Your job is to
output the few merge/split operations that bring the blocks to the layout the
human editors of this vault use.

━━━ TARGET LAYOUT — one block per FUNCTIONAL UNIT ━━━

OPENER       A node's division announcement together with the first-child opener
             that follows it is ONE block:
               "<topic> ལ་གསུམ། A། B། C་འོ། །དང་པོ་ནི།"
             A sibling opener "གཉིས་པ་ <title> ནི།" is its own block.
ROOT QUOTE   A quoted root stanza is its own block. These blocks are tagged
             [VERSE]; they are protected — never include them in any operation.
EXPLANATION  The gloss that follows a quote ("ཞེས་པ་སྟེ། …", "ཞེས་པ་ནི། …", or a
             running explanation) is ONE block up to the next opener, quote or
             heading — even when it is long (100–250 syllables) and contains several
             sentence ends, a question and answer ("…ལོ། །གང་ལ་ན། …"), a side remark
             on a variant reading ("…ཞེས་འགྱུར་བཅོས་…"), a cross-reference
             ("འདི་དང་འོག་གི་ས་བཅད་…"), or a mantra cited in passing.
SECOND LEVEL A passage that re-reads the same stanza on another level — opening
             "སྦས་དོན་ནི།", "ངེས་དོན་ནི།", "ངེས་པའི་དོན་དུ།", "ཟབ་དོན་ནི།",
             "དེའི་ནང་གི་དོན་ལ།", "མཐར་ཐུག་གི་དོན་ནི།" or the like after the literal
             gloss — is its OWN block, never merged into the literal gloss before it
             (the editors keep the two readings apart). Within that passage, M1 applies.
FRAME        The namo line alone; each of the author's own verses one block;
             "སྨྲས་པ།" alone; the colophon ("ཅེས་ … སྦྱར་བའོ། །" + closing wishes) one block.

━━━ MERGE — adjacent blocks that are one unit ━━━

M1  CONTINUED EXPLANATION
    A block that goes on explaining the same quote/topic as the block before it —
    no new opener, no new quote, no new verse being treated — belongs to that block.
    This is the most common fix. Do NOT keep a cut just because a sentence ends.
    Exception: a SECOND LEVEL opener (see above) always starts a new block.
M2  INCOMPLETE SENTENCE
    A block ending in a connector (དང་། / ཞིང་། / ཅིང་། / ནས། / སྟེ། / ཏེ།) that
    the next block completes.
M3  OPENER CHAIN
    An enumeration block followed by "དང་པོ་ནི།" / "དང་པོ་ལ་ N།" (and further
    nested first-child enumerations) — merge them into one opener block.
M4  COLOPHON
    The parts of the closing colophon and its final wishes form one block.

━━━ SPLIT — one block that holds two units ━━━

S1  A new node opener (ordinal + title + "ནི།" or "ལ་ N།") buried mid-block:
    split before it.
S2  The treatment of a new verse/topic starts mid-block (e.g. "ཡང་ཕྱག་གང་ལ་འཚལ་ན"
    starting the next homage): split before it.
S3  An introductory opener "… ནི།" fused to the explanation of the PREVIOUS
    quote: split so the opener starts the next unit.

Never split a block only because it is long.

━━━ TOPIC SHIFT vs CONTINUATION (from the editors' corrections) ━━━

The editors' blocks are large (median ≈ 55 syllables; whole explanations of
100–250 syllables are normal). A sentence end is NOT a boundary. Inside one
explanation they cut only where the commentary turns to something new:
  START a new block at   "ཡང་ན་ …" (an alternative explanation)
                         "ཁ་ཅིག་ …", "གཞན་དག་ …" (another party's view)
                         "འོ་ན་ …" (the reply to an objection)
                         "དེ་སྐད་དུ་ …", "ཇི་སྐད་དུ་ …" (introducing a supporting quotation)
                         "དེ་ནས་ …" when it opens the next step of a procedure
                         "དཔེ་ …" / "དཔེར་ན་ …" when an example section begins
KEEP WITH the block before (merge into it):
                         "ད་ནི་ …" — a transitional "now …" line is not a new unit
                         (no heading or verse between them)
                         "ལེའུ་ … པའོ། །" — a chapter-closing line stays with the
                         explanation it closes
                         "ཞེས་ / ཅེས་ …" — the quotative closing the words just before it

━━━ HEADING / VERSE BLOCKS — always KEEP ━━━

Blocks tagged [HEADING] or [VERSE] are NEVER part of any operation.

━━━ OUTPUT FORMAT ━━━

A JSON array of operations. Blocks not mentioned are kept as-is.

[
  {"op": "merge", "blocks": [N, M]},
  {"op": "merge", "blocks": [N, M, P]},
  {"op": "split", "block": N, "after": "<verbatim unique substring ending at split point>"},
  {"op": "split", "block": N, "after": ["<sub1>", "<sub2>", "<sub3>"]}
]

Rules for the output:
- Block numbers are CONTINUOUS and INCLUDE heading and verse blocks. You may only
  merge blocks with consecutive numbers (N and N+1). Never merge across a heading
  or a verse block, and never propose a merge whose numbers skip over one.
- Each block number appears in AT MOST ONE operation.
- For each "after" substring: copy a verbatim slice from the block that ends exactly
  at the split point and is UNIQUE within that block (10–20 characters is usually enough).
- If nothing needs to change in this window, output: []
- Output ONLY the JSON array. No explanation, no commentary, no code fences.

[Block 4247]
བསད་དོ་སྙམ་དུ་སེམས་པ་ན་དུས་གསུམ་པའི་སེམས་པས་སྲོག་གཅོད་པའི་ཁ་ན་མ་ཐོ་བས་རེག་པར་འགྱུར་རོ་ཞེས་ཟེར་ན།[^2520] མ་ལ་སོགས་པ་མ་བསད་པར་བསད་དོ་སྙམ་པའི༌[^2521]ང་རྒྱལ་ཅན་རྣམས་ལ། མཚམས་མེད་པའི་ལས་ཀྱི་ལམ་དུ་འགྱུར་དུ་འོངས་པས༌[^2522]དེ་ཙམ་གྱིས༌[^2523]ལས་ཀྱི་ལམ་ཡོངས་སུ་རྫོགས་པ་ནི་མ་ཡིན་གྱི་འདི་ལ་བསམ་པ་ནི་བདག་ཉིད་ཀྱིས་གསོད་པ་ལ་སེམས་པ་དེ་སྙེད་ཅིག་ཀུན་དུ་འབྱུང་ངོ་ཞེས་བྱ་བ་འདི་ཡིན་པར་རིགས་པའི་ངོ་བོ་ཡིན་ནོ། །

[Block 4248]
ད་ནི༌[^2524]རྣམ་པར་རིག་བྱེད་མ་ཡིན་པ་ནི་སྤོང་བར་བྱེད་ཅིང་དེ་ཁོ་ན་དང་འདྲ་བར་མི་མངོན་པར་རྒྱུད་ཡོངས་སུ་འགྱུར་བའི་བྱེ་བྲག་ཁས་ལེན་པར་བྱེད་པའི་རབ་ཏུ་སྣང་བ༌[^2525]དེ་གང་ཞེ་ན། རབ་ཏུ་སྣང་བ༌[^2526]ནི་ཅི་ཡང་མེད་མོད་ཀྱི་འོན་ཀྱང་སེམས་ཀྱི་རྒྱུ་ལས་བྱུང་བའི་ལུས༌[^2527]ཀྱི་སྦྱོར་བས་བྱ༌[^2528]བ་ཡོངས་སུ་རྫོགས་ན་སྦྱོར་བ་པོ་ལ༌[^2529]དེ་དག་དང་ཐ་དད་པར་གྱུར་པའི་ཆོས་གཞན་ཞིག་ན༌[^2530]སྐྱེའོ་ཞེས་བྱ་བ་ནི་ཡོངས་སུ་དགའ་བ་མི་སྐྱེའོ། །

[Block 4252]
གང་ཡང་འཕགས་པའི་ལམ་ཡན་ལག་བརྒྱད་པར༌[^2534]འགྱུར་རོ་ཞེས་སྨྲས་པ་ནི་རེ་ཞིག་ཇི་ལྟར་ན་ལམ་ལ་སྙོམས་པར་ཞུགས་པ་ལ་ཡང་དག་པའི་ངག་དང་། ལས་ཀྱི་མཐའ་དང་། འཚོ་བ་དག་ཡོད་པ་ཁྱོད་སྨྲོས་ཤིག །ཅི་འདི་ཚིག་ཏུ་སྨྲ་འམ། འོན་ཏེ་བྱ་བ་བྱེད་དམ། འོན་ཏེ་ཆོས་གོས་ལ་སོགས་པ་དག་འཆོལ༌[^2535]བར་བྱེད། སྨྲས་པ། མ་ཡིན་ནོ། །

[Block 4253]
འོ་ན་ཇི་ལྟ་བུ་ཞེ་ན། གང་ཞིག་ཐོབ་པའི་ཕྱིར་ལངས་ན་ཡང་ལོག་པའི་ངག་ལ་སོགས་པ་དག་ལ་ནི་མི་འཇུག་ལ། ཡང་དག་པའི་ངག་ལ་སོགས་པ་དག་ལ་ནི་འཇུག་པར་འགྱུར་བ་དེ་ལྟ་བུའི་རྣམ་པར་རིག་བྱེད་མ་ཡིན་པ་ཟག་པ་མེད་པ་འཐོབ་སྟེ། དེའི་ཕྱིར་རྒྱུ་མཚན་ལ་རྒྱུ་མཚན༌[^2536]ཅན་བཏགས་པ༌[^2537]ནས་རྣམ་པར་རིག་བྱེད་མ་ཡིན་པ་ལ་དེར་བཤད་དོ། །

[Block 4254]
གལ་ཏེ་དེ་ལྟ་ན་གོ་འདི་ལ་ཡང་དེ་བཞིན་དུ་ལམ་ལ་སྙོམས་པར་ཞུགས་པས་རྣམ་པར་རིག་བྱེད་མ་ཡིན་པ་མེད་བཞིན་དུ་གང་ཞིག་ཐོབ་པའི་ཕྱིར་ལངས་ན་ཡང་ལོག་པའི་ངག་ལ་སོགས་པ་དག་ལ་ནི་མི་འཇུག༌[^2538]ལ། ཡང་དག་པའི་ངག་ལ་སོགས་པ་དག་ལ་ནི་འཇུག་པར་འགྱུར་བ་དེ་ལྟ་བུའི་བསམ་པ་དང་ལུས་ཐོབ་པར་འགྱུར་ཏེ། དེའི་ཕྱིར་རྒྱུ་མཚན་ལ་རྒྱུ་མཚན་ཅན་ཉེ་བར་བཏགས་པ་བྱས་ནས་ལམ་གྱི་ཡན་ལག་བརྒྱད་རྣམ་པར་གཞག་གོ་ཞེས་བྱ་བར་ཅིའི་ཕྱིར་མི་གཟུང་གཞན་དག་ན་རེ་དེ་དག་མི་བྱེད་པ་ཙམ་འདིར་ཡན་ལག་ཏུ་གསུངས་པ་ཡིན་ཏེ། འདིས་འཕགས་པའི་ལམ་གྱི་མཐུས་ངེས་པར་མི་བྱེད་པར༌[^2539]འཐོབ་པ་གང་ཡིན་པ་དེ་ཡང་ཟག་པ་མེད་པའི་ལམ་ལ་བརྟེན་ནས་འཐོབ་པའི་ཕྱིར་ཟག་པ་མེད་པ་ཡིན་ནོ། །

[Block 4255]

[Block 4256]
སོ་སོར་ཐར་པའི་སྡོམ་པར་ཡང་འགྱུར་ཏེ། སེམས་པ་གང་གིས་ཆོ་ག་སྔོན་དུ་བཏང་བའི་ཁས་བླངས་ཏེ་ལས་བཀག་ནས༌[^2541]ལུས་དང་ངག་དག་སྡོམ་པར་བྱེད་དོ། །

[Block 4257]
གལ་ཏེ་སེམས་གཞན་དང་ལྡན་ན་མ་བསྡམས་པར་འགྱུར་རོ་ཞེ་ན། མ་ཡིན་ཏེ། དེ་ལ་གོམས་པར་བྱས་པའི་དུས་སུ་དྲན་པ་ཉེ་བར་གནས་པའི་ཕྱིར་རོ། །

[Block 4258]
ཆུ་ལོན་གྱི་ངོ་བོར་ཡང་འགྱུར་ཏེ། ངོ་ཚ་ཤེས་པས་མི་བྱ་བར་དམ་བཅས་པ༌[^2542]ཡང་དག་པར་དྲན་ཞིང་ཡང་དག་པར་དྲན་ནས་འཆལ་པའི་ཚུལ་ཁྲིམས་མི་བྱེད་པའི་ཕྱིར་ཏེ། དེ་ལྟ་བུ་ཁོ་ནའི་དོན་དུ་དེ་ཡང་དག་པར་ལེན་པ་ཡང༌[^2543]ཡིན་ནོ། །

[Block 4259]
གལ་ཏེ་རྣམ་པར་རིག་བྱེད་མ་ཡིན་པ་ཁོ་ན་འཆལ་བའི་ཚུལ་ཁྲིམས་ཀྱི་བགེགས་བྱེད༌[^2544]པ་ཡིན་པར་གྱུར་ན་ནི་བརྗེད་ངས་པ་འགགས༌[^2545]ཀྱང་ཚུལ་ཁྲིམས་འདྲལ་བར༌[^2546]མི་འགྱུར་རོ། །

[Block 4260]
རྒྱས་པར་ནི་མི་དགོས་སོ། །

[Block 4261]
བྱེ་བྲག་ཏུ་སྨྲ་བ་རྣམས་ན་རེ་རྣམ་པར་རིག་བྱེད་མ་ཡིན་པའི་གཟུགས་རྫས་གཞན་ཁོ་ནར་ཡོད་དོ་ཞེས་ཟེར་རོ། །

[Block 4262]
གལ་ཏེ་ཡོད་ལ་དེ་ཡང་འབྱུང་བ་ཆེན་པོ་དག་རྒྱུར་བྱས་པ་ཡིན་ནོ་ཞེས་བཤད་ན་དེ་ཅི་རྣམ་པར་རིག་བྱེད་ཀྱི་འབྱུང་བ་དག་ཁོ་ན་རྒྱུར་བྱས་ནས་རྣམ་པར་རིག་བྱེད་མ་ཡིན་པ་སྐྱེ་བའམ། [^2547]འོན་ཏེ་གཞན་དག་ཀྱང་ཡིན་ཞེ་ན། སྨྲས་བ། མ་ཡིན་ནོ། །

[Block 4263]
དེ་ནི་འབྱུང་བ་ཆེན་པོ་གཞན་དང་གཞན་དག་ཁོ་ན་རྒྱུར་བྱས་ནས་སྐྱེ་བར་འགྱུར་ཏེ། ཚོགས་པ་དེ་ཉིད་འབྲས་བུ་ཕྲ་མོ་ཅན་ཡང་ཡིན་ལ། འབྲས་བུ་རགས་པ་ཅན་ཡང་ཡིན་པར་ནི་མི་རུང་ངོ་། །ཡང་ཅི་དེ་གང་གི་ཚེ་རྣམ་པར་རིག་བྱེད་མ་ཡིན་པ་ཡོད་པ་དེའི་ཚེ་ཡོད་པའི་འབྱུང་བ་ཆེན་པོ་དག་ཁོ་ན་རྒྱུར་བྱས་ནས་འབྱུང་ངམ་ཞེ་ན། རྒྱུར་བྱས་པའི་གཟུགས་ཕལ་ཆེར་ཐམས་ཅད་ནི་དེ་ལྟ་བུ་ཡིན་ནོ། །

[Block 4264]
ད་ལྟར་དང་མ་འོངས་པ་ཅུང་ཟད་ཅིག་ནི་འདས་པའི་འབྱུང་བ་ཆེན་པོ་དག་རྒྱུར་བྱས་ནས་འབྱུང་ངོ་། །དེ་ཡང་གང་ཞེ་ན།

[Block 4265 [VERSE]]
འདོད་གཏོགས་རྣམ་རིག་མིན་སྐད་ཅིག །
ཕྱིན་ཆད་འདས་པའི་འབྱུང་ལས་སྐྱེ། །

[Block 4266]
འདོད་པ་ན༌[^2548]སྤྱོད་པའི་རྣམ་པར་རིག་བྱེད་མ་ཡིན་པ་ནི་སྐད་ཅིག་མ༌[^2549]

[Block 4267]
དང་པོ་ཕྱིན་ཅད་འདས་པའི་འབྱུང་བ་ཆེན་པོ་དག་རྒྱུར་བྱས་ནས་སྐྱེའོ། །

[Block 4268]
དེ་དག་ནི་འདིའི་གཞིའི༌[^2550]དོན་དུ་འགྱུར་ལ་ལུས་ཀྱི་འབྱུང་བ་ཆེན་པོ་དེ་ལྟར་འབྱུང་བ༌[^2551]རྣམས་ནི་རྟེན་གྱི་དོན་དུ་འགྱུར་ཏེ། འཇུག་པ་དང་རྗེས་སུ་འཇུག་པའི་རྒྱུ་ཡིན་པའི་ཕྱིར་གོ་རིམས་བཞིན་ཏེ། འཁོར་ལོ་ས་ལ་འདྲིལ་བ་ལ་ལག་པས་འཕུལ་བ༌[^2552]དང་སའི་ཕྱོགས་བཞིན་ནོ། །

[Block 4269]
ཡང་གང་ན་ཡོད་པའི་ལུས་དང་ངག་གི་ལས་གང་ན་ཡོད་པའི་འབྱུང་བ་ཆེན་པོ་དག་རྒྱུར་བྱས་པ་ཡིན་ཞེ་ན།

[Block 4270 [VERSE]]
ཟག་བཅས་ལུས་དང་ངག་གི་ལས། །
རང་གི་འབྱུང་བ་དག་རྒྱུར་བྱས། །

[Block 4271]
འདོད་པ་ན་སྤྱོད་པའི་ལུས་དང་ངག་གི་ལས་ནི་འདོད་པ་ན་སྤྱོད་པའི་འབྱུང་བ་དག་ཁོ་ན་རྒྱུར་བྱས་པ་ཡིན་ལ། དེ་བཞིན་དུ་བསམ་གཏན་བཞི་པའི་ས་པའི་བར་དུ་ཡང་དེའི་ས་པའི་འབྱུང་བ་དག་ཁོ་ན་རྒྱུར་བྱས་པ་ཡིན་ནོ། །

[Block 4272]
ཟག་མེད་གང་དུ་སྐྱེས་པ་ཡིན། །ཟག་པ་མེད་པའི་ལུས་དང་ངག་གི་ལས་དེ་ནི་ས་གང་དུ་སྐྱེས་ཏེ༌[^2553]སྐྱེད་པར་བྱེད་པ་དེའི་ས་པའི་འབྱུང་བ་ཆེན་པོ་དག་རྒྱུར་བྱས་པ་ཡིན་ཏེ། ཁམས་གསུམ༌[^2554]མ་གཏོགས་པའི་ཕྱིར་དང་། ཟག་པ་མེད་པ་རྣམས་ལས་འབྱུང་བ་དག་མེད་པའི་ཕྱིར་དང་། དེའི་སྟོབས་ལས་སྐྱེ་བའི་ཕྱིར་རོ། །

[Block 4273]
རྣམ་པར་རིག་བྱེད་དང་། རྣམ་པར་རིག་བྱེད་མ་ཡིན་པའི་ལས་དེ་ལས་ཀྱང་།

[Block 4274 [VERSE]]
རྣམ་རིག་བྱེད་མིན་མ་ཟིན་དང་། །
རྒྱུ་མཐུན་ལས་བྱུང་སེམས་ཅན་སྟོན། །

[Block 4275]
གཞན་ཡང་། རྒྱུ་མཐུན་ཟིན་པའི་འབྱུང་ལས་སྐྱེ།[^2555] །རྣམ་པར་རིག་བྱེད་མ་ཡིན་པ་ནི་རྒྱུ་མཐུན་པ་དང་ཟིན་པའི་འབྱུང་བ་དག་ཁོ་ན་རྒྱུར་བྱས་ནས་སྐྱེ་སྟེ། འདི་ནི་མཉམ་པར་གཞག་པ་མ་ཡིན་པའི་ས་པའི་རྣམ་པ་ཡིན་ནོ། །
