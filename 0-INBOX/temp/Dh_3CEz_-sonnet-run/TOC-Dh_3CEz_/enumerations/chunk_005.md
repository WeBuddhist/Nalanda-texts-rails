Enumeration Block 1:
བསྐྱེད་པའི་རྒྱུ་ནི་གཉིས་ཏེ་བསྐྱེད་པའི་རིམ་པ་དང་རྫོགས་པའི་རིམ་པའོ། །
Enumeration Block 2:
དེ་ལ་དང་པོ་ལ་གསུམ་སྟེ། ཀུན་བརྟགས་ཀྱི་ཀུན་བརྟགས་ས་བོན་དང་མཚན་མས་བསྐྱེད་པའི་རང་རྒྱུད་དུ་རྟོགས་པ་དང་། གཞན་དབང་ཡེ་ཤེས་ཀྱི་སྣང་བར་བྱས་པ་དང་། ཡོངས་གྲུབ་བདེ་བ་ཆེན་པོས་བྱིན་གྱིས་བརླབས་པའོ། །
Enumeration Block 3:
ལམ་གཉིས་ཏེ་བསྐྱེད་རིམ་མང་བར་བྱ་སྟེ་རྫོགས་རིམ་ཉུང་ལྡན་སྒྲུབ་ཐབས་བཞིན་སྒོམ་པ་དང་རྫོགས་པའི་རིམ་པ་མང་ལྡན་བསྐྱེད་རིམ་ཉུང་ལྡན་ཏེ་མོས་པའི་རྣལ་འབྱོར་ལ་སོགས་པའམ་ཡན་ལག་བཞི་བསྒོམ་པའོ། །
Enumeration Block 4:
རྫོགས་པའི་རིམ་པ་ལ་བཞི་སྟེ། ངོ་བོ་ཡེ་ཤེས་ཆེན་པོ་བསྟན་པ་དང་རྟེན་རྡོ་རྗེའི་ལུས་ལམ་དུ་བྱེད་པ་དང་། ལྡན་པའི་ཆོས་སྡོམ་པའི་དབྱེ་བ་དང་། ཉམས་སུ་ལེན་པ་རླུང་ལ་བསླབ་པ་དང་གཏུམ་མོ་སྦར་བའོ། །
Enumeration Block 5:
བསླབ་པ་ཤེས་པར་བྱ་བ་ལ་གཉིས་ཏེ། དེ་ཁོ་ན་ཉིད་བཤད་པ་དང་།
རྣམ་པར་གཞག་པའི་ཆ་དབྱེ་བའོ། །
དེ་ཁོ་ན་ཉིད་ལ་གཉིས་ཏེ།
ཡེ་ཤེས་དང་ཆོས་ཉིད་དོ། །
ཡེ་ཤེས་ལ་ཡང་གཉིས་ཏེ།
Enumeration Block 6:
ཆོས་ཉིད་ལ་གཉིས་ཏེ། དངོས་པོ་ཀུན་ལ་ཁྱབ་ཅེས་པས་རྟེན་བསྟན་པ་དང་། རྟོག་པ་ཐམས་ཅད་ཡང་དག་སྤངས། །ཞེས་པ་ཚུལ་ལམ་མཚན་ཉིད་འདུས་མ་བྱས་ཏེ་དེ་བཞིན་ཉིད་བསྟན་པའོ། །
Enumeration Block 7:
རྣམ་པར་གཞག་པའི་ཆ་དབྱེ་བ་ལ་བཞི་སྟེ། ཚིག་དང་པོས་རྟེན་བསྟན་པ་དང་། རྟོག་པ་གཉིས༌[^141]པས་མཚན་ཉིད་དང་། གསུམ་པས་ཡོན་ཏན་དང་། བཞི་པས་དེ་ཁོ་ན་ཉིད་ཀྱི་རང་བཞིན་སྐྱེ་མེད་དུ་བསྟན་པའོ། །
Enumeration Block 8:
བསྒོམ་པ་ཉམས་སུ་ལེན་པ་ལ་གཉིས་ཏེ། མངོན་རྟོགས་ལམ་དུ་བྱས་པ་དང་། འབྲས་བུ་ལམ་དུ་བྱས་པའོ། །
མངོན་རྟོགས་ལམ་དུ་བྱས་པ་ལ་གསུམ་སྟེ།
ཆགས་ཅན་དང་ཆགས་བྲལ་དང་ཕྱག་རྒྱ་ཆེན་པོའོ། །
Enumeration Block 9:
ཕྱག་རྒྱ་ཆེན་པོ་ལ་གཉིས་ཏེ་ཆགས་བྲལ་ལྟ་བུ་དང་། ཆགས་ཅན་ལྟ་བུའོ། །
Enumeration Block 10:
འབྲས་བུ༌[^153]ལམ་དུ་བྱས་པ་ནི་སྐུ་བཞི་སྟེ། ཚིག་དང་པོ་ལོངས་སྐུའོ། །
ཚིག་གཉིས་པ་ནི་ཆོས་སྐུའོ། །
གསུམ་པ་སྤྲུལ་སྐུའོ། །
