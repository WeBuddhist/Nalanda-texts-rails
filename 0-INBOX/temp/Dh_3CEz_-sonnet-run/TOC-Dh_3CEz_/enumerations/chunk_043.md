Enumeration Block 1:
དེ་ཡང་བཞི་སྟེ། སྙོམས་པར་འཇུག་པའི་སྦྱོར་བ་དང་ལྡན་པ་དང་། ཡོན་ཏན་སྤོང་བའི་ཁྱད་པར་དང༌[^1152]ལྡན་པའི་སྦྱོར་བ་དང་། ཡོན་ཏན་ཐོབ་པའི་ཁྱད་པར་དང་ལྡན་པའོ། །
Enumeration Block 2:
གཉིས་མེད་ཕྱག་རྒྱ་ཆེན་པོ་ལ་དྲུག་སྟེ། ལྟ་བ་དང་སྤྱོད་པ་དང་སྒོམ་པ་དང་དབང་པོ་རང་སྣང་དང་སྤྱོད་ལམ་དང་བསྲེ་བ་དང་། འབྲས་བུ་ལ་སོགས་པའོ། །
Enumeration Block 3:
སྤྱོད་པ་ལ་གཉིས་ཏེ་སྤྱོད་པ་དང་སྤྱོད་པའི་རྒྱུ་མཚན་ནོ། །
Enumeration Block 4:
