Enumeration Block 1:
སྒྲའི་ཚུལ་ལ་ཡང་གསུམ་སྟེ། སྒྲའི་བྱེད་པའི་གནས་དང་སྦྱར་བ་དང་། ནུས་པའི་རྩལ་དང་མིང་ཁྱད་པར་དུ་བཏགས་པའི་ཡོན་ཏན་ཏོ། །
Enumeration Block 2:
དུས་གཅིག་གིས་ནི་ཡོན་ཏན་གསུམ་འདྲེན་པར་བྱེད་དེ།
Enumeration Block 3:
བྷ་ག་ཝཱན་གྱིས་ནི་ཡོན་ཏན་གཉིས་འདྲེན་ཏེ།
Enumeration Block 4:
དོན་བཞིན་དུ་བཤད་པ་ནི་གཉིས་ཏེ། །
