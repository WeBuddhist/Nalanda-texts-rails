Enumeration Block 1:
སྭཱ་ཧཱ་ཐ་མར་གཞག་པ་ནི་གདུལ་བྱ་རྣམ་པ་གསུམ་དུ་ངེས་ཏེ།
Enumeration Block 2:
དེ་ལ་གཉིས་ཏེ། རིམ་དང་ཅིག་ཅར་བའི༌[^222]བཟླས་པའོ། །
Enumeration Block 3:
གནས་སྐབས་རྣམ་པ་གསུམ་དུ་འགྱུར་ཏེ། བསྙེན་པའི་ས་བསྲུང་བ་དང་། རྣལ་འབྱོར་གྱི་ས་བསྲུང་བ་དང་། སྒྲུབ་པའི་ས་བསྲུང་བའོ། །
Enumeration Block 4:
ལྷ་དགས་པ་ལ་གཉིས་ཏེ་ཕྱི་དང་ནང་ངོ་། །
