Enumeration Block 1:
ཚོགས་ཀྱི་འཁོར་ལོ་ནི་བཞི་སྟེ། ཕན་ཡོན་དང་། གནས་དང་། ཟླ་བ་དུས་དང་། འཇུག་པའོ། །
Enumeration Block 2:
འཇུག་པ་ལ་གཉིས་ཏེ། ཐུན་མོང་དང་ཁྱད་པར་རོ། །
Enumeration Block 3:
ཐུན་མོང་ལ་གསུམ་སྟེ།
Enumeration Block 4:
རྒྱན་དགྲམ་པ་ལ་ཡང་གསུམ་སྟེ་ཐལ་ཆེན་གྱིས་བྱུག་པ་དང་། ཞིང་དང་སྟག་གི་པགས་པ་དང་། །རུས་པའི་རྒྱན་ནོ། །
Enumeration Block 5:
དཔའ་བོའི་སྟོན་མོ་ལ་བཞི་སྟེ།
Enumeration Block 6:
སྡེར་ལ་གསུམ་སྟེ་རབ༌[^1323]ཞིང་གི་པགས་པ། འབྲིང་དུར་ཁྲོད་ཀྱི་རས། ཐ་མ་ཤིང་ལོའི་སྡེར་རོ། །
Enumeration Block 7:
ཚོགས་ལ་གཉིས་ཏེ་ལས་དང་པོ་པས་ཡོན་ཏན་དང་ལྡན་པའི་ཕྱག་རྒྱས༌[^1324]གཡས་སུ་འདུག་སྟེ་བསྒོམ་པ་དང་། ལས་སྨིན་བས་བགྲོད་དང་བགྲོད་མིན་དུ་མཆོད་པས་འབྲས་བུ་དང་བཅས་པའོ། །
