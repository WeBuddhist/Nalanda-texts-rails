Enumeration Block 1:

Enumeration Block 2:
དབྱེ་བ་ལ་མཚོན་བྱ་དང་མཚོན་བྱེད་ཀྱིས་དབྱེ་བ་དང་། ངོ་བོ་ཉིད་ཀྱི་སྒོ་ནས་དབྱེ་བ་དང་། རྟེན་གྱི་སྒོ་ནས་དབྱེ་བ་དང་། རྣམ་པར་གཞག་པའི་སྒོ་ནས་དབྱེ་བའོ། །

Enumeration Block 3:
