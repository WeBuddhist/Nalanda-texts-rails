Enumeration Block 1:
འབྲས་བུ༌[^153]ལམ་དུ་བྱས་པ་ནི་སྐུ་བཞི་སྟེ།
Enumeration Block 2:
དེ་ལ་རྣམ་པར་གཞག་པའི་ནི་གྲངས་དང་ལས་དང་སོ་སོའི་མཚན་ཉིད་དང་གནས་དང་། གཙོ་བོ་དང་། ཕལ་བར་དབྱེ་བའོ། །
Enumeration Block 3:
དེ་ཡང་བསྐྱེད་པའི་རིམ་པ་དང་། རྫོགས་པའི་རིམ་པའོ། །
Enumeration Block 4:
དེ་ལ་རྫོགས་པའི་རིམ་པ་ཡང་གཞན་ལུས་ཤེས་རབ་ལ་བརྟེན་པ་དང་། རང་ལུས་ཐབས་དང་ལྡན་པ་དང་དབྱེར་མེད་ཕྱག་རྒྱ་ཆེན་པོའོ། །
Enumeration Block 5:
གཉིས་མེད་ཕྱག་རྒྱ་ཆེན་པོ་ལ་གཉིས་ཏེ། བརྟེན་པ་ཆོས་ལ་འཇུག་པ་དང་། རྟེན་ནང་ནས་འཇུག་པའོ། །
Enumeration Block 6:
དེ་རྣམས་ཀྱི་རྟགས་ནི་གསུམ་སྟེ།
