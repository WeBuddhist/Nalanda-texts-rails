=== SYSTEM PROMPT ===
You are an expert in classical Tibetan Buddhist commentary (འགྲེལ་པ་) structure.

You are given a numbered list of blocks from a Tibetan verse commentary. A
rule-based segmenter has already cut them; most cuts are right. Your job is to
output the few merge/split operations that bring the blocks to the layout the
human editors of this vault use.

━━━ TARGET LAYOUT — one block per FUNCTIONAL UNIT ━━━

OPENER       A node's division announcement together with the first-child opener
             that follows it is ONE block:
               "<topic> ལ་གསུམ། A། B། C་འོ། །དང་པོ་ནི།"
             A sibling opener "གཉིས་པ་ <title> ནི།" is its own block.
ROOT QUOTE   A quoted root stanza is its own block. These blocks are tagged
             [VERSE]; they are protected — never include them in any operation.
EXPLANATION  The gloss that follows a quote ("ཞེས་པ་སྟེ། …", "ཞེས་པ་ནི། …", or a
             running explanation) is ONE block up to the next opener, quote or
             heading — even when it is long (100–250 syllables) and contains several
             sentence ends, a question and answer ("…ལོ། །གང་ལ་ན། …"), a side remark
             on a variant reading ("…ཞེས་འགྱུར་བཅོས་…"), a cross-reference
             ("འདི་དང་འོག་གི་ས་བཅད་…"), or a mantra cited in passing.
SECOND LEVEL A passage that re-reads the same stanza on another level — opening
             "སྦས་དོན་ནི།", "ངེས་དོན་ནི།", "ངེས་པའི་དོན་དུ།", "ཟབ་དོན་ནི།",
             "དེའི་ནང་གི་དོན་ལ།", "མཐར་ཐུག་གི་དོན་ནི།" or the like after the literal
             gloss — is its OWN block, never merged into the literal gloss before it
             (the editors keep the two readings apart). Within that passage, M1 applies.
FRAME        The namo line alone; each of the author's own verses one block;
             "སྨྲས་པ།" alone; the colophon ("ཅེས་ … སྦྱར་བའོ། །" + closing wishes) one block.

━━━ MERGE — adjacent blocks that are one unit ━━━

M1  CONTINUED EXPLANATION
    A block that goes on explaining the same quote/topic as the block before it —
    no new opener, no new quote, no new verse being treated — belongs to that block.
    This is the most common fix. Do NOT keep a cut just because a sentence ends.
    Exception: a SECOND LEVEL opener (see above) always starts a new block.
M2  INCOMPLETE SENTENCE
    A block ending in a connector (དང་། / ཞིང་། / ཅིང་། / ནས། / སྟེ། / ཏེ།) that
    the next block completes.
M3  OPENER CHAIN
    An enumeration block followed by "དང་པོ་ནི།" / "དང་པོ་ལ་ N།" (and further
    nested first-child enumerations) — merge them into one opener block.
M4  COLOPHON
    The parts of the closing colophon and its final wishes form one block.

━━━ SPLIT — one block that holds two units ━━━

S1  A new node opener (ordinal + title + "ནི།" or "ལ་ N།") buried mid-block:
    split before it.
S2  The treatment of a new verse/topic starts mid-block (e.g. "ཡང་ཕྱག་གང་ལ་འཚལ་ན"
    starting the next homage): split before it.
S3  An introductory opener "… ནི།" fused to the explanation of the PREVIOUS
    quote: split so the opener starts the next unit.

Never split a block only because it is long.

━━━ HEADING / VERSE BLOCKS — always KEEP ━━━

Blocks tagged [HEADING] or [VERSE] are NEVER part of any operation.

━━━ OUTPUT FORMAT ━━━

A JSON array of operations. Blocks not mentioned are kept as-is.

[
  {"op": "merge", "blocks": [N, M]},
  {"op": "merge", "blocks": [N, M, P]},
  {"op": "split", "block": N, "after": "<verbatim unique substring ending at split point>"},
  {"op": "split", "block": N, "after": ["<sub1>", "<sub2>", "<sub3>"]}
]

Rules for the output:
- Block numbers are CONTINUOUS and INCLUDE heading and verse blocks. You may only
  merge blocks with consecutive numbers (N and N+1). Never merge across a heading
  or a verse block, and never propose a merge whose numbers skip over one.
- Each block number appears in AT MOST ONE operation.
- For each "after" substring: copy a verbatim slice from the block that ends exactly
  at the split point and is UNIQUE within that block (10–20 characters is usually enough).
- If nothing needs to change in this window, output: []
- Output ONLY the JSON array. No explanation, no commentary, no code fences.

གཞན་གྱིས་བརྩམས་པ་དོན་མེད་འགྱུར། །

[Block 23]
དེ་བཞིན་གཤེགས་པ་ཐམས་ཅད་ཀྱི་སྐུ་དང་གསུང་དང་ཐུགས་ཀྱི་གསང་བ་བསྡུས་པ་འདི་ཅིའི་ཕྱིར་གསུངས་ཤེ་ན། འདི་ལྟར་རིགས་ཐམས་ཅད་གཟུང་བར་བྱ་བ་དང་། རིགས་མཆོག་ཏུ་གྱུར་པ་གཟུང་བར་བྱ་བའི་ཕྱིར་ཏེ། དེ་བཞིན་གཤེགས་པ་ཐམས་ཅད་ཀྱི་གསང་བ་འདུས་པའི་དཀྱིལ་འཁོར་འདིར་མཚམས་མེད་པ་ལྔ་ལ་སོགས་པ་བྱས་པ་ཡང་བླ་ན་མེད་པའི་མཆོག་ཐོབ་པར་འགྱུར་རོ༌[^12]ཞེས་གསུངས་པའི་ཕྱིར་དང་། གསང་བའི་དོན་འདི་ནི་ཐམས་ཅད་ཀྱི་ཐུན་མོང་མ་ཡིན་ནོ་ཞེས་འབྱུང་བའི་ཕྱིར་རོ། །

[Block 24]
གལ༌[^13]ཏེ། རིགས་ཐམས་ཅད་ཅེས་བྱ་བ་ནི་རིགས་ཆད་པ་ལ་སོགས་པ་ཡང་སྨོས་པ་ཡིན་ནམ། གལ་ཏེ་དེ་ལྟ་ཡིན་ན་ནི་བཅོམ་ལྡན་འདས་ཀྱིས་བདེན་པ་བཞི་དང་། ཕ་རོལ་ཏུ་ཕྱིན་པ་ལ་སོགས་པ་གསུངས་པ་དོན་མེད་པར་འགྱུར་རོ་ཞེ་ན་མ་ཡིན་ཏེ། རིགས་མཆོག་ཏུ་འགྱུར་བའི༌[^14]ཕྱིར་རོ། །

[Block 25]
དེ་ལྟ༌[^15]ན་ནི་རིགས་མཆོག་ཏུ་གྱུར་པ་འདུལ་བ་དང་། རིགས་ཐམས་ཅད་པ་འདུལ་བ་གཅིག་གིས་གཅིག་སྤངས་པ་མ་ཡིན་ནམ་ཞེ་ན། མ་ཡིན་ཏེ། ཆོས་ཀྱི་ཕུང་པོ་བརྒྱད་ཁྲི་བཞི་སྟོང་གི་སྣོད་ཡིན་པའི་ཕྱིར་རོ་ཞེའོ། །

[Block 26]
དེ་ལྟ་ན་ནི་ཐེག་པ་མཆོག་ཏུ་མི་འགྱུར་གྱི་ཐེག་པ་ཐམས་ཅད་པར་འགྱུར་རོ་ཞེ་ན་མ་ཡིན་ཏེ། ཐེག་པ་ནི་གཉིས་དང་གསུམ་དུ་ཡོད་པ་མ་ཡིན་ནོ། །དེ་ཅིའི་ཕྱིར་ཞེ་ན། དེ་བཞིན་གཤེགས་པ་ཐམས་ཅད་ཀྱི་སྐུ་དང་གསུང་དང་ཐུགས་གསང་བ་ལས་མི་འདའ་ལ་སེམས་ཅན་ཐམས་ཅད་ཀྱང་དེའི་རང་བཞིན་ཅན་ཡིན་པའི་ཕྱིར་རོ། །

[Block 27]
དེ་ལྟ་ན་ནི་བཅོམ་ལྡན་འདས་ཀྱིས་བདེན་པ་བཞིའི་ཆོས་ཀྱི་འཁོར་ལོ་ལ་སོགས་པ་གསུངས་པ་དོན་ཡོད༌[^16]པར་འགྱུར་ཏེ་སྔ་མ་བཞིན་ནོ་ཞེ་ན། མ་ཡིན་ཏེ། སེམས་ཅན་ཐམས་ཅད་ཀྱང་རང་རང་གི་རིགས་ལ་གནས་པའི་ཕྱིར་རོ། །

[Block 28]
རིགས་ཞེས་བྱ་བ་འདི་ཡང་རྐྱེན་ལས་བྱུང་བའམ། ཆོས་ཉིད་ཀྱིས་ཡིན་ཞེས་རྟོག་གྲང་ན། རྐྱེན་ལས་བྱུང་བ་ནི་མ་ཡིན་ཏེ། རྐྱེན་ཐམས་ཅད་དང་ལྡན་པའི་ཕྱིར་རོ། །

[Block 29]
དེ་ལྟ་ན་ནི་རིགས་ངེས་པར་མི་འགྱུར་གྱི། རིགས་མ་ངེས་པར་ནི་འགྱུར་རོ་ཞེ་ན། རང་གི་རིགས་ཀྱི༌[^17]བསྐྱེད་པའི་ཕྱིར་རོ། །

[Block 30]
རང་གི་ཆོས་ཀྱིས༌[^18]བསྐྱེད་པ་ཞེས་བྱ་བ་འདི་ཡང་ས་བོན་ཐམས་ཅད་ཀྱིས་གཅིག་བསྐྱེད་དམ། ས་བོན་གཅིག་གིས་ཐམས་ཅད་བསྐྱེད་ཅེ་ན། ས་བོན་ཐམས་ཅད་གཅིག་གིས་བསྐྱེད་པ་ནི་མ་ཡིན་ཏེ། རྐྱེན་མ་ངེས་པར་འགྱུར་བ་ཉིད་དང་། ཐམས་ཅད་ལས་ཐམས་ཅད་སྐྱེ་བར་འགྱུར་བ་དང་། རྐྱེན་ཅན་དོན་མེད་པ་ཉིད་དུ་ཡང་འགྱུར་རོ་ཞེ་ན། མ་ཡིན་ཏེ། འདིར་ནི་ས་བོན་ཐམས་ཅད་རྐྱེན་ཐམས་ཅད་ཀྱིས་གསོས་འདེབས་པ་ཉིད་ཀྱི་ཕྱིར་རོ། །

[Block 31]
གསོས་འདེབས་པ་ཞེས་བྱ་བ་འདི་ཡང་ས་བོན་ཉིད་རྐྱེན་གཞན་གྱི་དབང་དུ་འགྱུར་བ་ནི་མ་ཡིན་ཏེ། གོང་མའི་སྐྱོན་ཉིད༌[^19]དུ་འགྱུར་རོ། །

[Block 32]
ལུང་ལས་དེ་བཞིན་གཤེགས་པ་གསང་བ་མཆོག་གི་ཕྱིར། ས་བོན་རྣམས་ནི་གཅིག་ཏུ་འགྱུར། །ཞེས་འབྱུང་བའི་ཕྱིར་ཆོས་ཉིད་ཀྱིས་ཐམས་ཅད་ཡོད་པ་མ་ཡིན་ནོ་ཞེ་ན། འདི་ལས་དང་པོ་པ་འམ། ས་ལ་གནས་པ་ཡིན། ས་ལ་གནས་པའི་དབང་དུ་ནི་འདོད་པ་ཡིན་ཏེ། གནོད་པ་ཅུང་ཟད་ཀྱང་མེད་དོ། །

[Block 33]
ཕྱོགས་ཕྱི་མ་ལྟར་ན་ནི་འཇུག་པར་ཡང་མི་འགྱུར་ན། རིགས་གཅིག་པ་ལྟར་གྱུར་པ་ལྟ་སྨོས་ཀྱང་ཅི་དགོས། འོན་ཀྱང༌[^20]ས་ལ་གནས་པ་ཐམས་ཅད་ཀྱང་གསད་པའི་མཆོག་ལ་གནས་པའམ། སོ་སོ་རང་རང་གི་ལམ་ལ་གནས་ཤེ་ན།

[Block 34]
དང་པོ་ལྟར་ནི་མ་ཡིན་ཏེ། དུས་ཀྱིས་གནོད་པའི་ཕྱིར་རོ། །

[Block 35]
ཕྱོགས་ཕྱི་མ་ལྟར་ན་ནི་རང་གི་ཚིག་གིས་གནོད་པའི་ཕྱིར་རོ། །དེ་ཅིའི་ཕྱིར་ཞེ་ན། ཚིག་གི་བླང་དོར་མེད་པའི་བྱང་ཆུབ་སྒྲུབ་པའམ། བསྐལ་པ་གྲངས་མེད་པ་གསུམ་གྱིས་འགྲུབ་པ་ཉིད་ཀྱི་ཕྱིར་རོ། །

[Block 36]
ཐམས་ཅད་གསང་བ་མཆོག་ལ་གནས། །ཞེས་བྱ་བ༌[^21]དང་། རང་གི་ལམ་ལ་གནས་ཞེས་པ་ཡང་གཅིག་གིས་གཅིག་སྤངས་པའི་ཕྱིར་རོ། །

[Block 37]
དེ་བས་ན་འདི་ནི་བླང་བར་བྱ་བ་ཉིད་དོ་ཞེ་ན་མ་ཡིན་ཏེ། ས་ལ་གནས་པ་རྣམས་ནི་ཐམས་ཅད་ཀྱང་བསྐྱེད་པའི་རིམ་པ་ཉམས་སུ་ལེན་པའི་ཕྱིར་དང་དེ་བཞིན་གཤེགས་པ་ཐམས་ཅད་ཀྱི་གསང་བ་ཆེན་པོར་ལུང་བསྟན་པའི་ཕྱིར་རོ། །

[Block 38]
དེ་ལྟ་ན་ནི་ཐེག་པའི་བྱེ་བྲག་མེད་པར་འགྱུར་རོ་ཞེ་ན་མ་ཡིན་ཏེ་གཉིས་པ༌[^22]ཡོད་པའི་ཕྱིར་རོ། །

[Block 39]
གཉིས་ཞེས་བྱ་བ་འདི་ཡང་གསུམ་དང་གཉིས་ཀྱི་བྱེ་བྲག་གིས་ཡིན་ནོ། །

[Block 40]
ཐེག་པ་ཆེན་པོ་མདོ་སྡེའི་རྗེས་སུ་ཞུགས་པ་རྣམས་ནི་དོན་དམ་པ་ཆོས་ཉིད་མངོན་དུ་གྱུར་ནས་སྣང་བ་སྒྱུ་མ་ཙམ་དང་། རྩོལ་བ་དང་བཅས་པ་ལྷ་དང་ལྷ་མོའི་དཀྱིལ་འཁོར་དུ་བསལ༌[^23]བའོ། །

[Block 41]
གསང་བ་འདུས་པའི་དཀྱིལ་འཁོར་ལ་གནས་པ་རྣམས་ནི་དོན་དམ་པའི་བདེན་པ་དང་། ཡང་དག་པའི་ཀུན་རྫོབ་འབའ་ཞིག་ལ་ཉེ་བར་ལོངས་སྤྱོད་པའི་ཕྱིར་རོ། །

[Block 42]
དངོས་པོར་སྣང་བ་སྒྱུ་མ་ཙམ་འདི་ཅི་ཡང་དག་པའི་ཀུན་རྫོབ་པ་འམ། ལོག་པའི་ཀུན་རྫོབ་ཅེས་རྟོག་གྲང་ན། རེ་ཞིག་ཡང་དག་པའི་ཀུན་རྫོབ་ནི་མ་ཡིན་ཏེ། ཟླས་གསལ་བའི་ཕྱིར་རོ། །

[Block 43]
ལོག་པའི་ཀུན་རྫོབ་པ་ནི་མ་ཡིན་ཏེ། ཐམས་ཅད་ལས་མཐུན་པར་སྣང་བའི་ཕྱིར་རོ། །

[Block 44]
དངོས་པོ་ལྷའི་དཀྱིལ་འཁོར་དུ་སྣང་བ་ཞེས་བྱ་བ་འདི་ཡང་ལོག་པའི་ཀུན་རྫོབ་ནི་མ་ཡིན་ཏེ་ཁས་མ་བླངས་པའི་ཕྱིར་རོ། །

[Block 45]
ཡང་དག་པའི་ཀུན་རྫོབ་ཀྱང་མ་ཡིན་ཏེ། ཐམས་ཅད་ལ་མཐུན་པར་སྣང་བ་མ་ཡིན་པའི་ཕྱིར་རོ། །

[Block 46]
དེ་བས་འདི༌[^24]བླང་བར་བྱ་བ་མ༌[^25]ཡིན་ནོ་ཞེ་ན་མ་ཡིན་ཏེ། དངོས་པོར་སྣང་བ་སྒྱུ་མ་ཙམ་འདི༌[^26]དམན་པ་ལ་ཡང་དག་པའི་ཀུན་རྫོབ་ཏུ་སྣང་ན་ནི་མི་འདོད་པ་མེད་དོ་ཐམས་ཅད་ལ་ཡང་དག་པའི་ཀུན་རྫོབ་ཏུ་སྣང་ཞེས་བྱ་བའི་ངེས་པ་ཅི་ཞིག་ཡོད། ལོག་པའི་ཀུན་རྫོབ་ཅེས་བྱ་བ་ནི་འཁྲུལ་པ་ཉིད་དོ། །

[Block 47]
འདི་ལྟར་འཁྲུལ་པ་ཞེས་བྱ་བ་ཡང་། རྟོག་པ་དང་དབང་པོ་མེད་པ་ནི་ཡང་དག་པར་ཡང་སྣང་ངོ་། །དངོས་པོ་ལྷའི་སར༌[^27]སྣང་བ་ནི་དེ་ལྟ་མ་ཡིན་ཏེ། མ་འཁྲུལ་པའི་དངོས་པོ༌[^28]ཡོད་པའི་ཕྱིར་དང་། རྟོག་པའི༌[^29]དུས་ན་དེར་སྣང་བ་ཉིད་ཀྱི་ཕྱིར་རོ། །

[Block 48]
གང་གིས་གང་ལ་གནས་པ་དེ་ཉིད་དོན་ལ་མི་སླུ་བར༌[^30]བྱེད་པ་ནི་ཡང་དག་པའི་ཀུན་རྫོབ་སྟེ། དཔེར་ན་དུ་བ་ལས་མེ་དཔོག་པ་བཞིན་ནོ། །

[Block 49]
ལོག་པའི་ཀུན་རྫོབ་ནི་རྟོག་པའི༌[^31]དུས་ན་མི་གནས་པའི་ཕྱིར་དོན་ལ་སླུ་བར༌[^32]བྱེད་པ་སྟེ་ཐག་པ་ལ་སྦྲུལ་བཞིན་ནོ། །

[Block 50]
བསྐྱེད་པའི་རིམ་པ་འདི་ཡང་ཕྲད་པར་བྱེད་པའི་ཕྱིར་དང་། མི་སླུ་བར༌[^33]བྱེད་པའི་ཕྱིར་ཡང་དག་པའི་ཀུན་རྫོབ་ཏུ་འགྱུར་རོ་འཁྲུལ་པའི་ཤེས་པ་དང་། མ་འཁྲུལ་པའི་ཤེས་པ་ནི་སླུ་བར་བྱེད་པ་དང་མི་བྱེད་པས་གཅིག་གིས་གཅིག་སྤངས་པའི་ཕྱིར་འགལ་བར་གནས་པའོ། །

[Block 51]
དེ་བས་ན་མདོ་སྡེའི་རྗེས་སུ་ཞུགས་པའི་བྱང་ཆུབ་སེམས་དཔའ་རྣམས་ནི་དོན་དམ་པའི་བདེན་པ་དང་། ཡང་དག་པའི་ཀུན་རྫོབ་དང་ལོག་པའི་ཀུན་རྫོབ་གསུམ་ལ་ཉེ་བར་གནས་པའོ། །

[Block 52]
སྔགས་ཀྱི་སྒོར་ཞུགས་པའི་བྱང་ཆུབ་སེམས་དཔའ་རྣམས་ནི། དོན་དམ་པའི་བདེན་པ་དང་། ཡང་དག་པའི་ཀུན་རྫོབ་འབའ་ཞིག་ལ་ཉེ་བར་སྤྱོད་པའི་ཕྱིར། དེ་བས་ན་ཐེག་པ་གཉིས་སུ་ཡང་འགྱུར་རོ།[^34] །དུས་ཀྱིས་གསལ་བ་ཡང་མ་ཡིན་ཏེ།

[Block 53]
སློབ་པ་དང་མི་སློབ་པའི་བྱེ་བྲག་གིས་ཡིན་ནོ། །རང་གི༌[^35]ཚིག་གིས་གསལ་བ་ཡང་མ་ཡིན་ཏེ།

[Block 54]
གཉིས་ཉིད་ཡོད་པའི་ཕྱིར་རོ། །

[Block 55]
དེ་བས་ན་འདི་ནི་བླང་བར་བྱ་བ་ཉིད་དོ། །

[Block 56]
དགོས་པ་མེད་པ་ཡང་མ་ཡིན་ཏེ། སེམས་ཅན་འདོད་ཆགས་ཅན་ལ་སོགས་པ་འདུལ་བར་བྱེད་པ་ཉིད་ཀྱི་ཕྱིར་རོ། །

[Block 57]
སེམས་ཅན་འདོད་ཆགས་ཅན་རྣམས་ནི་འདོད་ཆགས་ཆེན་པོའི་ཆོས་ཀྱི་རྗེས་སུ་འཇུག་པའི་ཕྱིར་དེ་བཞིན་གཤེགས་པ་རྣམས་ཀྱིས་འདོད་ཆགས་ཀྱི་སྒོ་ནས་ཆོས་སྟོན་ཏོ། །

[Block 58]
སེམས་ཅན་ཞེ་སྡང་ཅན་རྣམས་ནི་ཞེ་སྡང་ཆེན་པོའི་ཆོས་ཀྱི་རྗེས་སུ་འཇུག་པའི་ཕྱིར་དེ་བཞིན་གཤེགས་པ་རྣམས་ཀྱིས་ཞེ་སྡང་གི་སྒོ་ནས་ཆོས་སྟོན་ཏོ། །

[Block 59]
སེམས་ཅན་གཏི་མུག་ཅན་རྣམས་ནི་གཏི་མུག་ཆེན་པོའི་ཆོས་ཀྱི་རྗེས་སུ་འཇུག་པའི་ཕྱིར་དེ་བཞིན་གཤེགས་པ་རྣམས་ཀྱིས་གཏི་མུག་ཆེན་པོའི་སྒོ་ནས་ཆོས་སྟོན་ཏོ། །

[Block 60]
སེམས་ཅན་ང་རྒྱལ་ཅན་རྣམས་ནི་ང་རྒྱལ་ཆེན་པོའི་ཆོས་ཀྱི་རྗེས་སུ་འཇུག་པའི་ཕྱིར་དེ་བཞིན་གཤེགས་པ་རྣམས་ཀྱིས༌[^36]ང་རྒྱལ་གྱི་སྒོ་ནས་ཆོས་སྟོན་ཏོ། །

[Block 61]
སེམས་ཅན་ཕྲག་དོག་ཅན་རྣམས་ནི་ཕྲག་དོག་ཆེན་པོའི་ཆོས་ཀྱི་རྗེས་སུ་འཇུག་པའི་ཕྱིར་དེ་བཞིན་གཤེགས་པ་རྣམས་ཀྱིས་ཕྲག་དོག་གི་སྒོ་ནས་ཆོས་སྟོན་ཏོ། །

[Block 62]
དེ་ལ་སོགས་པ་རྨད་དུ་བྱུང་བའི་སྤྱོད་པ་ཆེན་པོས་སེམས་ཅན་ཐམས་ཅད་ཀྱི་དོན་བྱེད་པའི་ཕྱིར་དགོས་པ་ཆེན་པོ་དང་ལྡན་པས་རྒྱུད་ཆེན་པོའོ། །

[Block 63]
དེ་ལྟ་བུའི་རྨད་དུ་བྱུང་བའི་རྒྱུད་འདི་ནི་སྤྱོད་པ་ཆེན་པོ་དང་། དུས་ཆེན་པོ་ལ་སོགས་པ་དང་ལྡན་པའི་ཕྱིར་རྒྱུད་ཆེན་པོ་ཞེས་བྱའོ། །

[Block 64]
འདིའི་བརྗོད་པར་བྱ་བ་ནི་གང་དགོས་པ་ནི་གང༌[^37]དགོས་པའི་དགོས་པ་ནི་གང་། འབྲེལ་པ་ནི་གང་ཞེ་ན། དེ་བཞིན་གཤེགས་པ་ཐམས་ཅད་ཀྱི་གསང་བ་འདུས་པ་ལམ་འབྲས་བུ་དང་བཅས་པ་ནི་འདི་ནི་བརྗོད་པར་བྱ་བའོ། །

[Block 65]
ལམ་འབྲས་བུ་དང་བཅས་པ་ཇི་ལྟ་བུའི་འབྲས་བུ་རྣམ་པར་རྟོག་པ༌[^38]ནི་དགོས་པའོ། །

[Block 66]
རྗོད་པར༌[^39]བྱེད་པ་དང་དགོས་པ་ནི་གང་ལ་གང་ཞིག་རག་ལས་པར་འགྱུར་བ་དེའི་ཕྱིར་རག་ལས་པའི་འབྲེལ་པར་འགྱུར་རོ། །

[Block 67]
བདག་གི་དོན་དང་གཞན་གྱི་དོན་ཕུན་སུམ་ཚོགས་པར་བྱེད་པ་ནི་དགོས་པའི་དགོས་པའོ། །

[Block 68]
ཡང་ན་ལམ་ལ་གནས་པར༌[^40]བྱེད་པ་ནི་དགོས་པ་ཡིན་ལ། དེས་འབྲས་བུ་ཐོབ་པ་ནི་དགོས་པའི་ཕྱིར་ན༌[^41]དགོས་པའོ། །

[Block 69]

[Block 73]
རྒྱུད་དེ་ཉིད་རྒྱལ་པོ་སྟེ་རྣལ་འབྱོར་རྒྱུད་ཀྱི༌[^45]ཤིན་ཏུ་གསལ་བར་རྣམ་ཕྱེ་ཞེས་བཤད་པའི་ཕྱིར་རོ། །

[Block 74]

[Block 78]
དེས་ཅིར་འགྱུར་ཞེ་ན། རྒྱལ་པོར་མ་གྱུར་ཞེས་པ་ནི་དམན་པར་གྱུར་ཞེས་པའོ། །

[Block 79]

[Block 80]

[Block 81]

[Block 82]
གང་རྨད་དུ་བྱུང་བའི་སྤྱོད་ཡུལ་མ་ཡིན་པ་དེ་ནི་དེའི་འབྲས་བུ་ཅན་མ་ཡིན་ནོ། །

[Block 83]
གང་དེའི་འབྲས་བུ་ཅན་མ་ཡིན་པ་དེ་ནི་ལོག་པའི་འབྲས་བུ་དང་ལྡན་པར་འགྱུར་རོ། །

[Block 87]

[Block 92]

[Block 93]
སེམས་ཅན་འདི་དག་ནི་དེ་བཞིན་གཤེགས་པའི་དངོས་གྲུབ་ཐམས་ཅད་སྤངས་པའོ་ཞེས་འབྱུང་བའི་ཕྱིར་རོ། །

[Block 94]
མཐའ་དྲུག་གི༌[^52]འཆིང་བས་བཅིངས་པའི་ཕྱིར་ཐམས་ཅད་ཀྱི་སྤྱོད་ཡུལ་མ་ཡིན་ནམ་ཞེ་ན། མ་ཡིན་ཏེ། དེའི་ཕྱིར་རྒྱལ་སྲས་ཡུལ་གྱུར་ཞེས་བྱ་བ་སྨོས་ཏེ། རྒྱལ་བ་ནི་སངས་རྒྱས་ཏེ་རྡོ་རྗེ་འཆང་ཆེན་པོ་ལ་སོགས་པའོ། །

[Block 95]

[Block 96]

[Block 97]

[Block 98]
དེ་ཉིད་སེམས་ཅན་ཐམས་ཅད་ཀྱི་ཡུལ་དུ་མ་གྱུར་པ་ཅིའི་ཕྱིར་ཞེ་ན། སངས་རྒྱས་ཀུན་གྱིས་རྒྱས་བཏབ་ཅེས་སྨོས༌[^55]ཏེ། སངས་རྒྱས་ཀུན་ནི་རྡོ་རྗེ་འཆང་ཆེན་པོ་ལ་སོགས་པས་སོ། །

[Block 99]
དེས་རྒྱས་བཏབ་ཅེས་པ་ནི་ཐམས་ཅད་ལ་སྦས་པ་ཞེས་པའོ། །

[Block 100]
དེ་དག་གི་དོན་ཡང་དོན༌[^56]འདི་སྐད་དུ་སྟོན་པར་འགྱུར་ཏེ། དེ་བཞིན་གཤེགས་པ་རྣམས་ཀྱི་སྤྱོད་པ་རྨད་དུ་བྱུང་བ་གཉིས་སུ་མེད་པའི་ཐབས་ཀྱི་སྦྱོར་བ་འདི་ནི་ཉན་ཐོས་དང་རང་སངས་རྒྱས་ལ་སོགས་པ་རྣམས་ཀྱི་ཐུན་མོང་མ་ཡིན་པ་ཤིན་ཏུ་གསང་བར་དགོངས་སོ། །

[Block 101]
གལ་ཏེ་གསང་བ་ཞིག་ཡིན་ན། ཐམས་ཅད་ནས་ཐམས་ཅད་དུ་རྟོག་པ༌[^57]མེད་པར་འགྱུར་རོ་ཞེ་ན། མ་ཡིན་པའི་ཕྱིར་ཀླུ་སྒྲུབ་ལས་རྙེད་པ་ཞེས་སྨོས་ཏེ། ལེགས་པར་ལུང་བསྟན་པའི་བྱང་ཆུབ་སེམས་དཔའ་ཀླུ་སྒྲུབ་ལས་རྙེད་པ་བཤད་ཅེས་སྦྱར་རོ། །

[Block 102]
ཡང་ན་དཔལ་ལྡན་རྒྱུད་རྒྱལ་གྱི་དཔལ་ནི་སྐུ་རྣམ་པ་གསུམ་མོ། །

[Block 103]
དཔལ་དེ་ཐོབ་པའི་ཐབས་གང་ལ་ཡོད་པ་དེ་ནི་དཔལ་ལྡན་ཏེ། བསྐྱེད་པའི་རིམ་པ་དང་རྫོགས་པའི་རིམ་པའོ། །

[Block 104]
རིམ་པ་རྣམ་པ་གཉིས་གཙོ་བོར་སྟོན་པའི་རྒྱུད་ནི་རྒྱུད་རྒྱལ་ཏེ།

[Block 105]
དེ་བཞིན་གཤེགས་པ་ཐམས་ཅད་ཀྱི་གསང་བ་འདུས་པའོ། །ཡང་ན་དཔལ་ལྡན་ནི་དེ་བཞིན་གཤེགས་པ་རྣམས་སོ། །

[Block 106]
དེ་དང་གང་ལྡན་པ་ནི་དཔལ་ལྡན་ཏེ་རྡོ་རྗེ་འཆང་ཆེན་པོའོ། །

[Block 107]
དེ་ཉིད་ཀྱིས་གསུངས་པ་འདི་ཉིད་ནི་རྒྱུད་ཀྱི་རྒྱལ་པོ་ཡིན་ཞེས་སྦྱར་རོ། །

[Block 108]
ཡང་ན་དཔལ་ལྡན་ཡང་ཡིན་རྒྱུད་ཀྱང་ཡིན་པས་ན་དཔལ་ལྡན་རྒྱུད་རྒྱལ་ཏེ། གང་ལ་བསོད་ནམས་དང་ཡེ་ཤེས་ཀྱི་ཚོགས་ཐོབ་པར་བྱེད་པའི་ཐབས་ཡོད་པ་དེ་ལ་དེ་སྐད་ཅེས་བྱའོ། །

[Block 109]
དེ་ཉིད་ནི་རྣལ་འབྱོར་གྱི་རྒྱུད་ཀྱིས་ཤིན་ཏུ་གསལ་བར་རྣམ་ཕྱེ་སྟེ། གང་ལ་ཏིང་ངེ་འཛིན་གཙོ་བོར༌[^58]སྟོན་པར་བྱེད་པའི་རྒྱུད་ནི་རྣལ་འབྱོར་གྱི་རྒྱུད་དོ། །གང་ཞེ་ན། དེ་བཞིན་གཤེགས་པ་ལ་བྱམས་པ་ལ་སོགས་པས་ཞུས་པའི་རྒྱུད་ཡེ་ཤེས་རྡོ་རྗེ་ཀུན་ལས་བཏུས་པ་ལ་སོགས་པའོ། །

[Block 110]
དེས་གསལ་བར་བྱེད་པ་ནི་དེས་གསལ་བར་བཤད་པ་སྟེ། སྒྲ་དང་དོན་ཐམས་ཅད་རྒྱས་པར་བྱས་ཤེའོ།[^59] །དེ་བཞིན་གཤེགས་པ་ཐམས་ཅད་ཀྱི་གསང་བ་འདུས་པ་ལ་རྣལ་འབྱོར་གྱི་རྒྱུད་ཀྱིས་རྒྱས་པར་བྱེད་པ་ཅིའི་ཕྱིར་ཞེ་ན། མཐའ་དྲུག་གི་ནི་འཆིང་བས་བཅིངས། །ཞེས་བྱ་བ་སྨོས་ཏེ། གང་ལ་མཐའ་དྲུག་གི་འཆིང་བ་ཡོད་པ་དེ་ལ་དེ་སྐད་ཅེས་བྱའོ། །

[Block 111]
གལ་ཏེ་མཐའ་དྲུག་གི་འཆིང་བས་བཅིངས་ཀྱང་ཉེ་བར་གདགས་པ་མི་བྱའོ་ཞེ་ན། བློ་དམན་པ་རྣམས་ཀྱིས་རྟོགས་པར་བྱེད་པར་འགྱུར་ཏེ། དེའི་ཕྱིར་རྒྱལ་སྲས་ཡུལ་གྱུར་ཞེས་བྱ་བ་སྨོས་སོ། །

[Block 112]
རྒྱལ་བའི་ཡུལ་དུ་གྱུར་ཞེས་པས་ནི་རྡོ་རྗེ་འཆང་ཆེན་པོ་ལ་སོགས་པས་རྟོགས་པར་བྱ་བ་ཡིན་པར་བསྟན་ཏོ། །

[Block 113]
རྒྱལ་བའི་སྲས་ཀྱི་ཡུལ་དུ་གྱུར། །ཞེས་པས་ནི་བྱམས་པ་ལ་སོགས་པ་བྱང་ཆུབ་སེམས་དཔའ་རྣམས་ཀྱིས་རྟོགས་པར་བྱ་བ་ཡིན་པར་བསྟན་ཏོ། །

[Block 114]
རྒྱས་སྲས༌[^60]ཡུལ་གྱུར་ཞེས་བྱ་བ་འདི་ནི་རྒྱལ་སྲས་གྱི་ཡུལ་དུ་གྱུར་པ་ཁོ་ནའོ་ཞེས་བྱ་བ་ནི་མ་ཡིན་གྱི།

[Block 115]
རྒྱལ་བའི་སྲས་ཁོ་ནའི་ཡུལ་དུ་གྱུར་ཞེས་པའོ། །འདིས་ནི་གཞན་དང་ལྡན་པ་རྣམ་པར་བཅད་པའོ། །

[Block 116]
མཐའ་དྲུག་གི་ནི་འཆིང་བས་བཅིངས། །ཞེས་བྱ་བ་འདི་ནི་ཉེ་བར་མཚོན་པའི་ཚིག་སྟེ། བཤད་པ་བཞི་ཡི་འཆིང་བས་བཅིངས། །ཞེས་བྱ་བ་ལ་སོགས་པ་ཡང་ཤེས་པར་བྱའོ། །

[Block 117]
དེ་དག་གིས་བཅིངས་པ་ཡང་གང་ཡིན༌[^61]ཞེ་ན། རྒྱལ་བའི་འདུས་གང་ཡིན་ཞེས་བྱ་བ་སྨོས་ཏེ། དེ་བཞིན་གཤེགས་པ་ཐམས་ཅད་ཀྱི་གསང་བ་འདུས་པ་མཐའ་དྲུག་གི་འཆིང་བས་བཅིངས་ཞེས་སྦྱར་རོ། །

[Block 118]
རྒྱལ་བའི་འདུས་པ་ཡང་སྒྲའི་རྣམ་པ་བཅིངས་སམ། དོན་གྱི་རྣམ་པ་བཅིངས་ཞེས་རྟོག༌[^62]གྲང་ན། སྒྲའི་རྣམ་པ་མ་ཡིན་པའི་ཕྱིར། རིམ་གཉིས་གནས་ཀྱིས་རྒྱས་བཏབ་དེ་ནི་ཞེས་བྱ་བ་སྨོས་ཏེ། བསྐྱེད་པའི་རིམ་པ་དང་། རྫོགས་པའི་རིམ་པ་གཉིས་ཀྱིས་རྒྱས་བཏབ་ཅེའོ། །

[Block 119]
དེ་བཞིན་གཤེགས་པ་རྣམས་ཀྱིས་རྒྱས་བཏབ་ཅེས་པ་ཡང་མི་གདུག༌[^63]སེམས་དང་བཅས་པ་འམ། སྙོམ༌[^64]ལས་དང་བཅས་པ༌[^65]ཡིན་ཞེས་རྟོག་གྲང་ན། ཕྱོགས་གཉི་ག་ནི་བླང་བར་བྱ་བ་མ་ཡིན་པའི་ཕྱིར་རེ་ཞིག་བསལ་ལོ། །

[Block 120]
དེ་ཉིད་ཐམས་ཅད་ཀྱིས་རྟོགས་པ་མ་ཡིན་ནོ་ཞེ་ན། ཀླུ་སྒྲུབ་ལས་རྙེད་པ་ཞེས་སྨོས་ཏེ། དེ་བཞིན་གཤེགས་པ་ཐམས་ཅད་ཀྱི་གསང་བ་འདུས་པ་གང་ཡིན་པ་དེ་སུས་ཀྱང་རྙེད་པར༌[^66]མ་གྱུར་པ་སློབ་དཔོན་ཀླུ་སྒྲུབ་ལས་རྙེད་ཅེས་སྦྱར་རོ། །
