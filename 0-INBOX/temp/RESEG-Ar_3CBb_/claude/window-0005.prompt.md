=== SYSTEM PROMPT ===
You are an expert in classical Tibetan Buddhist commentary (འགྲེལ་པ་) structure.

You are given a numbered list of blocks from a Tibetan verse commentary. A
rule-based segmenter has already cut them; most cuts are right. Your job is to
output the few merge/split operations that bring the blocks to the layout the
human editors of this vault use.

━━━ TARGET LAYOUT — one block per FUNCTIONAL UNIT ━━━

OPENER       A node's division announcement together with the first-child opener
             that follows it is ONE block:
               "<topic> ལ་གསུམ། A། B། C་འོ། །དང་པོ་ནི།"
             A sibling opener "གཉིས་པ་ <title> ནི།" is its own block.
ROOT QUOTE   A quoted root stanza is its own block. These blocks are tagged
             [VERSE]; they are protected — never include them in any operation.
EXPLANATION  The gloss that follows a quote ("ཞེས་པ་སྟེ། …", "ཞེས་པ་ནི། …", or a
             running explanation) is ONE block up to the next opener, quote or
             heading — even when it is long (100–250 syllables) and contains several
             sentence ends, a question and answer ("…ལོ། །གང་ལ་ན། …"), a side remark
             on a variant reading ("…ཞེས་འགྱུར་བཅོས་…"), a cross-reference
             ("འདི་དང་འོག་གི་ས་བཅད་…"), or a mantra cited in passing.
SECOND LEVEL A passage that re-reads the same stanza on another level — opening
             "སྦས་དོན་ནི།", "ངེས་དོན་ནི།", "ངེས་པའི་དོན་དུ།", "ཟབ་དོན་ནི།",
             "དེའི་ནང་གི་དོན་ལ།", "མཐར་ཐུག་གི་དོན་ནི།" or the like after the literal
             gloss — is its OWN block, never merged into the literal gloss before it
             (the editors keep the two readings apart). Within that passage, M1 applies.
FRAME        The namo line alone; each of the author's own verses one block;
             "སྨྲས་པ།" alone; the colophon ("ཅེས་ … སྦྱར་བའོ། །" + closing wishes) one block.

━━━ MERGE — adjacent blocks that are one unit ━━━

M1  CONTINUED EXPLANATION
    A block that goes on explaining the same quote/topic as the block before it —
    no new opener, no new quote, no new verse being treated — belongs to that block.
    This is the most common fix. Do NOT keep a cut just because a sentence ends.
    Exception: a SECOND LEVEL opener (see above) always starts a new block.
M2  INCOMPLETE SENTENCE
    A block ending in a connector (དང་། / ཞིང་། / ཅིང་། / ནས། / སྟེ། / ཏེ།) that
    the next block completes.
M3  OPENER CHAIN
    An enumeration block followed by "དང་པོ་ནི།" / "དང་པོ་ལ་ N།" (and further
    nested first-child enumerations) — merge them into one opener block.
M4  COLOPHON
    The parts of the closing colophon and its final wishes form one block.

━━━ SPLIT — one block that holds two units ━━━

S1  A new node opener (ordinal + title + "ནི།" or "ལ་ N།") buried mid-block:
    split before it.
S2  The treatment of a new verse/topic starts mid-block (e.g. "ཡང་ཕྱག་གང་ལ་འཚལ་ན"
    starting the next homage): split before it.
S3  An introductory opener "… ནི།" fused to the explanation of the PREVIOUS
    quote: split so the opener starts the next unit.

Never split a block only because it is long.

━━━ HEADING / VERSE BLOCKS — always KEEP ━━━

Blocks tagged [HEADING] or [VERSE] are NEVER part of any operation.

━━━ OUTPUT FORMAT ━━━

A JSON array of operations. Blocks not mentioned are kept as-is.

[
  {"op": "merge", "blocks": [N, M]},
  {"op": "merge", "blocks": [N, M, P]},
  {"op": "split", "block": N, "after": "<verbatim unique substring ending at split point>"},
  {"op": "split", "block": N, "after": ["<sub1>", "<sub2>", "<sub3>"]}
]

Rules for the output:
- Block numbers are CONTINUOUS and INCLUDE heading and verse blocks. You may only
  merge blocks with consecutive numbers (N and N+1). Never merge across a heading
  or a verse block, and never propose a merge whose numbers skip over one.
- Each block number appears in AT MOST ONE operation.
- For each "after" substring: copy a verbatim slice from the block that ends exactly
  at the split point and is UNIQUE within that block (10–20 characters is usually enough).
- If nothing needs to change in this window, output: []
- Output ONLY the JSON array. No explanation, no commentary, no code fences.

དེའི་དོན་གཞན་དག་ཀྱང་རྙེད་པ་ནི་རྫོགས་པའི་རིམ་པ་དང་ཕྲ་མོའི་ཏིང་ངེ་འཛིན་ལ་སོགས་པ་ཡང་འདིར་རྙེད་ཅེས་སྦྱར་རོ། །

[Block 584]
དེ་ལ་ཡང་འདི་ལས་གཞན་པ་ཞིག་ཡིན་ནམ་ཞེ་ན་མ་ཡིན་པའི་ཕྱིར། ལྷའི་རྣལ་འབྱོར་རྣམ་པ་གཉིས་པོ་ཉིད་ལ་འཇུག་ཅིང་ཞེས་པ་སྨོས་ཏེ། ལྷའི་རྣལ་འབྱོར་གཉིས་ནི་བསྐྱེད་པའི་རིམ་པ་དང་རྫོགས་པའི་རིམ་པ་གཉིས་སོ། །

[Block 585]
འདི་ལ་གང་གིས༌[^295]ཏིང་ངེ་འཛིན་གྱི་ཡུལ་དུ་བྱེད་པ་དེ་ནི་རྣལ་འབྱོར་པའོ། །

[Block 586]
རྣལ་འབྱོར་རྣམ་པ་གཉིས་པོ་འདི་ཉིད་ཀྱང་གང་ལ་ཤེས་ཤིང་བཤད་ཅེ་ན། གསང་བ་འདུས་པའི་རྒྱུད་ཕྱི་མ་ལས་གསུངས་སོ་ཞེས་སྦྱར་རོ། །

[Block 587]
གསང་བ་འདུས་པའི་དོན་དེ་ཉིད་གཞན་ཡིན་ནོ་ཞེ་ན་མ་ཡིན་པའི་ཕྱིར་དོན་འདི་ཉིད་ཅེས་སྨོས་ཏེ། འདི་ཉིད་ཉེ་བར་སྟོན་ཏེ་གཞན་ནི་མ་ཡིན་ཞེས་ཤུགས་ཀྱིས་བསྟན་ཏོ། །ཇི་སྐད་བསྟན་ཞེ་ན། སངས་རྒྱས་རྣམས་ཀྱིས་ཆོས་བསྟན་པ། །ཞེས་པ་ནི་དེ་བཞིན་གཤེགས་པ་རྡོ་རྗེ་འཆང་ཆེན་པོ་ལ་སོགས་པ་རྣམས་ཀྱིས་གསུངས་པའི་གཞུང་གི་ཚོགས་རྣམས་སོ། །

[Block 588]
རིམ་པ་གཉིས་ལ་ཡང་དག་གནས། །ཞེས་པ་ནི་དེ་ཐམས་ཅད་ཀྱང་རིམ་པ་གཉིས་སུ་འདུས་ཞེས་པའི་དོན་ཏོ། །

[Block 589]
རིམ་པ་གཉིས་ཉིད་གང་ཡིན་ཞེ་ན། བསྐྱེད་པ་ཡི་ནི་རིམ་པ་དང་། ཞེས་སྨོས་ཏེ་བསྐྱེད་པའི་རིམ་པ་ནི་བསྐྱེད་པའི་རིམ་པ་སྟེ། གང་གིས༌[^296]བློས་བསྐྱེད་པ་དེ་ལ་དེ་སྐད་ཅེས་བྱའོ། །

[Block 590]
བསྐྱེད་པའི་རིམ་པ་ཞེས་བྱ་བ༌[^297]ནི་དེ་ལས་སྐྱེས་པའི་སྐུའོ། །

[Block 591]
ཡང་ན་བསྐྱེད་པའི་རིམ་པ་ནི་ལྷའི་རྣལ་འབྱོར་འབའ་ཞིག་པའོ། །

[Block 592]
རྫོགས་པའི་རིམ་པ་ནི་ཕྲ་མོའི་རྣལ་འབྱོར་འབའ་ཞིག་པའོ། །

[Block 593]
འདི་ཡང་དེ་བཞིན་གཤེགས་པ་ཐམས་ཅད་ཀྱི་གསང་བའི་མཛོད་ཅེས་བྱ་བ་ལས་གསུངས་ཏེ་བཅོམ་ལྡན་འདས་བསྐྱེད་པའི་རིམ་པ་ཞེས་བྱ་བ་དེ་གང་ལགས། བཅོམ་ལྡན་འདས་ཀྱིས་བཀའ་སྩལ་པ། སེམས་དཔའ་ཆེན་པོ་དེ་བཞིན་གཤེགས་པ་ཐམས་ཅད་ཀྱི་བསྐྱེད་པའི་རིམ་པ་ནི་རྟེན་དུ་གྱུར་པ་ཉིད་དོ། །

[Block 594]
བཅོམ་ལྡན་འདས་རྟེན་དུ་གྱུར་པ༌[^298]ཞེས་བྱ་བ་དེ༌[^299]གང་ལགས། སེམས་དཔའ་ཆེན་པོ་དེ་བཞིན་གཤེགས་པ་ཐམས་ཅད་ཀྱི་གསང་བ་ཆེན་པོའི་རྟེན་དུ་གྱུར་པའོ། །

[Block 595]
བཅོམ་ལྡན་འདས་གསང་བ་ཆེན་པོ་ཞེས་བྱ་བ་དེ་གང་ལགས། དེའི་རྟེན་ཞེས་བྱ་བ་དེ་གང་ལགས། སེམས་དཔའ་ཆེན་པོ་དེ་བཞིན་གཤེགས་པ་ཐམས་ཅད་ཀྱི་གསང་བ་ཆེན་པོ་ཞེས་བྱ་བ་དེ༌[^300]ནི་ཉན་ཐོས་དང་རང་སངས་རྒྱས་ལ་སོགས་པ་རྣམས་ཀྱི་ཡུལ་མ་ཡིན་པ་ཚོགས་ཀྱི་གང་ཟག་གི་ཡང་ཡུལ་མ་ཡིན་པ་ཤིན་ཏུ་རྨད་དུ་བྱུང་བ་ཐེག་པ་ཆེན་པོའི་རིགས་ཅན་གྱི་སྤྱོད་ཡུལ་དུ་གྱུར་པའོ། །

[Block 596]
སེམས་དཔའ་ཆེན་པོ་དེའི་རྟེན་ནི་དེ་བཞིན་གཤེགས་པ་ཐམས་ཅད་ཀྱི་སྤྲུལ་པའི་སྐུ་ཤིན་ཏུ་རྨད་དུ་བྱུང་བའོ། །

[Block 597]
བཅོམ་ལྡན་འདས་དེ་བཞིན་གཤེགས་པ་ཐམས་ཅད་ཀྱི༌[^301]བསྐྱེད་པའི་རིམ་པ་ཞེས་བྱ་བ་དེ་གང་ལགས། སེམས་དཔའ་ཆེན་པོ་དེ་བཞིན་གཤེགས་པ་ཐམས་ཅད་ཀྱི་བསྐྱེད་པའི་རིམ་པ་ཞེས་བྱ་བ་ནི་གསང་བའི་ཡང་ཤིན་ཏུ་གསང་བ་ཕྲ་མོའི་ཏིང་ངེ་འཛིན་ཏོ་ཞེས་འབྱུང་བ་ལྟ་བུའོ། །

[Block 598]
ཉིད་ཅེས་བྱ་བ་ནི་ཁོ་ན་ཞེས་པ་སྟེ། འདིར་གཞན་དང་ལྡན་པ་རྣམ་པར་གཅོད་པའི་དབང་དུ་བྱས་པའོ། །

[Block 599]
རྒོལ་ཏེ་འོག་ནས་འཆད་པ་ཞེས་བྱ་བ་ཡང་འདི་ཉིད་དམ་འདི་ལས༌[^302]གཞན་ཞིག་རྟོག་གྲང་ན། འདི་ཉིད་ནི་མ་ཡིན་ཏེ་གྲུབ་པ་ལ་སྒྲུབ་པ་ཉིད་ཀྱི་ཕྱིར་དོན་མེད་པར་འགྱུར་རོ། །

[Block 600]
མདོར་བསྟན་པ་ཡང་མ་ཡིན་ཏེ་མིང་ཉིད་ཀྱིས༌[^303]ཐམས་ཅད་མདོར་བསྟན་པའི་ཕྱིར་རོ། །

[Block 601]
རྒྱས་པར་བཤད་པ་ཡང་མ་ཡིན་ཏེ། །མིང་ཉིད་དང་འགལ་བའི་ཕྱིར་དང་། གཞུང་རྒྱས་པས་འཇིགས་པའི་ཕྱིར་རོ། །

[Block 602]
འོག་མ་དང་ཐ་དད་པ་ཡང༌[^304]མ་ཡིན་ཏེ། ཐ་དད་པ་དང་ཐ་དད་པ་མ་ཡིན་པ་ནི་གཅིག་གིས་གཅིག་སྤངས་པའི་འགལ་བ་ཡིན་པའི་ཕྱིར་རོ།[^305] །དེ་ལྟ་ན་ཡང་འགྱུར་རོ་ཞེ་ན། ཧ་ཅང་ཡང་ཐལ་བར་འགྱུར་རོ། །

[Block 603]
འོན་ཏེ་ཐ་མི་དད་ན་ནི་སྔ་མའི་སྐྱོན་དུ་འགྱུར་རོ། །

[Block 604]
རྒྱུ་ཐ་མི་དད་པ་གཅིག་ཡིན་ནོ་ཞེ་ན་ནི་འབྲས་བུ་ཡང་དེ་ལྟར་འགྱུར་རོ། །

[Block 605]
ཐ་མི་དད་པས་ཐ་དད་པ་སྐྱེད༌[^306]ན་ནི་ཧ་ཅང་ཡང་ཐལ་བར་འགྱུར་རོ། །

[Block 606]
ཐམས་ཅད་ཐ་མི་དད་ཀྱང་ཡིན་ནོ་ཞེ་ན་ནི་གོང་མའི་སྐྱོན་དེ་ཉིད་དུ་འགྱུར་རོ། །

[Block 607]
གཞན་ཡང་རྒྱུ་ཐ་མི་དད་པས་འབྲས་བུ་ཐ་དད་པ་སྐྱེད་ན་ནི་རྫོགས་པའི་རིམ་པ་ཡང་དོན་མེད་པར་འགྱུར་རོ། །

[Block 608]
ཅི་སྟེ་གལ་ཏེ༌[^307]ཉེ་བའི་ཕྱིར་ཡིན་ནོ་ཞེ་ན༌[^308]དེ་ལྟ་ན་ནི་བསྐྱེད་པའི་རིམ་པ་ཡང་བླང་བྱ་མ་ཡིན་པར་འགྱུར་རོ། །

[Block 609]
འདི་ལྟར་རིང་བར་འགྱུར་བ་ཉིད་དང་ཕན་མི་འདོགས་པ་ཉིད་དང་། གནོད་པ་སྒྲུབ་པ་ཉིད་ནི་སྦྲུལ་ནག་པོ་བཞིན་དུ་དོར་བར་བྱ་བ་ཡིན་གྱི་ནོར་བུ་བཞིན་བླང་བར་བྱ་བ་མ་ཡིན་ནོ་ཞེ་ན་དེ་ནི་མ༌[^309]ཡིན་ཏེ། འདི་ལྟར་དེ་བཞིན་གཤེགས་པ་ཐམས་ཅད་ཀྱི་སྐུ་དང་གསུང་དང་ཐུགས་གསང་བ་ཆེན་པོ་འདི་ནི་མདོར་བསྟན་པ་དང་རྒྱས་པར་བསྟན་པ་གཉིས་ལ་འཇུག་སྟེ། དེ་བཞིན་གཤེགས་པ་ཐམས་ཅད་ཀྱི་གསང་བ་འདུས་པའི་ལེའུ་དང་པོ་ལས་ནི་མདོར་བསྟན་པ་འབའ་ཞིག་ཉེ་བར་བསྟན་ཏེ། དེ་ཅིའི་ཕྱིར་ཞེ་ན། དེ་བཞིན་གཤེགས་པ་ཐམས་ཅད་ནི་སེམས་ཅན་གྱི་དོན་ཆེན་པོ་ལ་རབ་ཏུ་འཇུག་པའི་ཕྱིར་རོ། །

[Block 610]
བསྡུས་པ་འདི་ཉིད་ཀྱིས་སེམས་ཅན་གྱི་དོན་དུ་ཇི་ལྟར་འགྱུར་ཞེ་ན། འདི་ནི་སེམས་ཅན་མདོར་བསྡུས་པ་ལ་དགའ་བའི་ཕྱིར་རོ། །

[Block 611]
ལྷག་མ་ནི་རྒྱས་པར་བསྟན་པ་ལ་དགའ་བའི་ཕྱིར་རོ། །

[Block 612]
དེ་བས་ན་འདི་ནི་དགོས་པ་ཆེན་པོ་དང་ལྡན་པའི་ཕྱིར་བླང་བར་བྱ་བ་ཉིད་དོ་ཞེའོ། །

[Block 613]
ལེའུ་དང་པོ་བསྡུས་པ་བཤད་པའོ།། །།

[Block 614 [HEADING]]
### ལེའུ་གཉིས་པ། ^2-2-0

[Block 615]
ལེའུ་གཉིས་པ་ལས་ནི་རྫོགས་པའི་རིམ་པ་འབའ་ཞིག་ཉེ་བར་སྟོན་ཏོ་ཞེས་པ་ནི་དང་པོ་ནི་བཤད་ཟིན་ལ་དེ་ལས་གཞན་ནི་མ་བྱུང་བས་དེ་ཉིད་ཀྱི་སྐབས་སུ་བབ་སྟེ། དེ་ལ་དེ་སྐད་ཅེས་བྱའོ། །

[Block 616]
རྫོགས་པའི་རིམ་པ་ནི་རྫོགས་པའི་རིམ་པ་སྟེ། རྫོགས་པ་ཆེན་པོ་དང་ཤིན་ཏུ་ཉེ་བའི་རྒྱུར་གྱུར་པའི་ཕྱིར་དེ་ལ་དེ་སྐད་ཅེས་བྱའོ། །

[Block 617]
ཡང་ན་རྫོགས་པ་ནི་རྫོགས་པ་ཆེན་པོ་སྟེ་དེ་ཁོ་ན་ཉིད་ཆོས་ཀྱི་སྐུའོ། །

[Block 618]
དེའི་རིམ་པ་ནི་རྫོགས་པ་ཐོབ་པའི་ཐབས་ཀྱི་རིམ་པ་སྟེ་ཕྲ་མོའི་ཏིང་ངེ་འཛིན་ཏོ། །

[Block 619]
འབའ་ཞིག་ཅེས་བྱ་བ་ནི་ལྷག༌[^310]མེད་ཅེས་བྱ་བའི་དོན་ཏེ་རྫོགས་པའི་རིམ་པ་འབའ་ཞིག་ཉེ་བར་སྟོན་གྱི་གཞན་མི་སྟོན་ཞེས་བྱ་བའི་ཐ་ཚིག་གོ། །

[Block 620]
འདིར་ཡང་རྫོགས་པའི་རིམ་པ་འབའ་ཞིག་སྟོན་གྱི་གཞན་མི་སྟོན་པ་ཅིའི་ཕྱིར་ཞེ་ན། འདི་ནི་དེ་བཞིན་གཤེགས་པ་ཐམས་ཅད་ཀྱིས་ཚོགས་ཀྱི་གང་ཟག་གི་དབང་དུ་བྱས་པ་མ་ཡིན་གྱི་སློབ་མ་འབའ་ཞིག་གི་དབང་དུ་བྱས་པའོ། །

[Block 621]
དེ་ལྟར་ཡང་ཅི་མངོན་ཞེ་ན། གསང་བ་ལུང་བསྟན་པ་ཞེས་བྱ་བ་ལས་ཀྱང་། བཅོམ་ལྡན་འདས་དེ་བཞིན་གཤེགས་པ་ཐམས་ཅད་ཀྱི་སྐུ་དང་། གསུང་དང་ཐུགས་གསང་བའི་ཡང་ཤིན་ཏུ་གསང་བ་མཆོག་ཏུ་གྱུར་པའི་དངོས་ཀྱི་ལམ་དུ་གྱུར་པ་འདི་ནི་ཉན་ཐོས་ཀྱི་ཡུལ་མ་ཡིན་རང་སངས་རྒྱས་ཀྱི་ཡུལ་མ་ཡིན་བྱང་ཆུབ་སེམས་དཔའི་ཡུལ་མ་ཡིན་ནོ། །

[Block 622]
དེའི༌[^311]ཕྱིར་དེ་བཞིན་གཤེགས་པ་ཐམས་ཅད་ཀྱི་གསང་བ་ཆེན་པོ་འདི་ནི་འདས་པའི་དུས་སུ་ཡང་མ་གསུངས་སོ། །

[Block 623]
མ་འོངས་པའི་དུས་སུ་ཡང་གསུང་བར་མི་འགྱུར་རོ། །དེ་ཅིའི་ཕྱིར་ཞེ་ན། དེ་ནི་གསང་བ་ཆེན་པོ༌[^312]དེའི་སྣོད་དུ་མ་གྱུར་པའི་ཕྱིར་རོ། །

[Block 624]
དེ་བས་ན་དེ་ལ་དེ་སྐད་ཅེས་བྱའོ།། །།

[Block 625 [HEADING]]
### ལེའུ་གསུམ་པ། ^2-3-0

[Block 626]
ལེའུ་གཉིས་པ་བརྗོད་ཟིན་ནས་གསུམ་པ་བརྗོད་པར་རིགས་པས་དེའི་ཕྱིར་ལེའུ་གསུམ་པ་ལས་ནི་ཞེས་བྱ་བ་ལ་སོགས་པ་སྨོས་ཏེ། ལེའུ་གསུམ་པ་ནི་འདིར་གྲངས་ཀྱིས༌[^313]

[Block 627]
གསུམ་པ་ཉིད་དོ། །

[Block 628]
ལས་ཞེས་པ་འདིར་འབྱུང་ཁུངས་ཀྱི་དོན་ཏེ༌[^314]ལེའུ་གསུམ་པ་ལས་ཡོངས་སུ་གྱུར་པ་དག་པའི་ལྷའི་རྣལ་འབྱོར་གསལ་བར་བྱེད་དོ་ཞེས་བྱ་བ་ནི་ཡོངས་སུ་དག་པའི་ལྷའི་རྣལ་འབྱོར་གྱི་རྟོག་པ་རྙེད་དོ་ཞེས་བྱ་བའི་དོན་ཏོ། །

[Block 629]
ལེའུ་གསུམ་པ་ལས་ལྷའི་རྣལ་འབྱོར་དེ་ཉིད་ཀྱང་རྙེད་པ་ཅིའི་ཕྱིར་ཞེ་ན། དེ་བཞིན་གཤེགས་པ་ཐམས་ཅད་ཀྱི་གསང་བ་ཆེན་པོ་ནི་འདི༌[^315]ལ་བསམས་ནས་གསུངས་པའི་ཕྱིར་རོ། །

[Block 630]
ཡོངས་སུ་དག་པའི་ལྷའི་རྣལ་འབྱོར་ཡང་གང་ཞིག་ཡིན། དེ་ཉིད་མི་ཤེས་སོ་ཞེ་ན་གང་གིས་མ་དག་པ༌[^316]རྣམ་པར་བཅད་ནས་གང་ཞིག་དག་པར་གྱུར་པ་ཡོངས་སུ་གཅོད་པ་དེ་ལ་དེ་སྐད་ཅེས་བྱའོ། །

[Block 631]
ཡོངས་སུ་དག་པ་ཡང་ཡིན་ལ་ལྷའི་རྣལ་འབྱོར་ཡང་ཡིན་པའི་ཕྱིར་ཡོངས་སུ་དག་པ་ལྷའི་རྣལ་འབྱོར་ཏེ་རྣམ་པར་རྟོག་པ་དང་བྲལ་བའི་ལྷ་ལ་དམིགས་པའི་ཏིང་ངེ་འཛིན་ཞེས་བྱའོ། །

[Block 632]
ཡོངས་སུ་དག་པ་ལ་སོགས་པ་འདི་ཡང་གང་ཞིག་ཡིན་ཏེ། དེ་ཉིད་མི་ཤེས་སོ་ཞེ་ན་སྤང་བྱས་ཡོངས་སུ་དག་པ་སྟེ། བསྐྱེད་པའི་རིམ་པའི་ལྷའི་རྣལ་འབྱོར་གྱི༌[^317]ཏིང་ངེ་འཛིན་དང་ལྡན་པ་དེ་ལ་དེ་སྐད་ཅེས་བྱའོ། །

[Block 633]
ཡང་ན་བྲལ་བའི་དོན་གྱིས༌[^318]ཡོངས་སུ་དག་པའི་ལྷའི་རྣལ་འབྱོར་ཏེ་ཞེས་བྱ་བ༌[^319]སྟེ། རྣམ་པར་རྟོག་པ་རགས་པ་དང་བྲལ་བ་སྒྱུ་མ་ལྟ་བུའི་སྐུ་ལ་དེ་སྐད་ཅེས་བྱའོ། །

[Block 634 [HEADING]]
### ལེའུ་བཞི་པ། ^2-4-0

[Block 635]
ཡང་ན་ཉེ་བར་ལོངས་སྤྱོད་པའི་དོན་གྱིས་ཡོངས་སུ་དག་པ་ལྷའི་རྣལ་འབྱོར་ཞེས་བྱ་སྟེ་ལོངས་སྤྱོད་རྫོགས་པའི་སྐུ་དེ་ལ་དེ་སྐད་ཅེས་བྱའོ། །

[Block 636]

[Block 637]
ལེའུ་བཞི་པ་ལས་ནི་དབང་བསྐུར་བའི་དཀྱིལ་འཁོར་སྟོན་ཏོ་ཞེས་བྱ་བ་ནི་སློབ་མ་དབང་བསྐུར་བའི་དཀྱིལ་འཁོར་ཆེན་པོ་ཞེས་བྱ་བའི་དོན་ཏོ། །

### ལེའུ་ལྔ་པ། ^2-5-0

[Block 639]

[Block 640]

[Block 641]

[Block 642]
རྣལ་འབྱོར་གྱི་སྤྱོད་པ་ཡང་བསྡུས་པ་དང་རྒྱས་པ་ཞེས་རྟོག་གྲང་ན། རྒྱས་པ་འོག་ནས་སྟོན་པའི་ཕྱིར་འདི་ནི་བསྡུས་པ་ཞེས་བྱའོ། །

[Block 643]
དེ་གང་ལ་སྟོན་པའི་ལེའུ་ནི་རྣལ་འབྱོར་གྱི་སྤྱོད་པའོ། །

[Block 644 [HEADING]]
### ལེའུ་དྲུག་པ་དང་བདུན་པ། ^2-6-0

[Block 645]
ལེའུ་དྲུག་པ་ལས་ནི་ཞེས་བྱ་བ་ལ་སོགས་པ་ནི་སྐུ་དང་གསུང་དང་ཐུགས་བྱིན་གྱིས་རློབ་པའི་ལེའུ་ནི་སྐུ་དང་གསུང་དང་ཐུགས་བྱིན་གྱིས་རློབ་པའི་ལེའུའོ། །

[Block 646]
དེ་གང་གིས་གསུངས་པ་དེ་ལ་དེ་སྐད་ཅེས་བྱའོ། །

[Block 647]
སྐུ་བྱིན་གྱིས་རློབ་པ་ནི་རྣམ་པ་གཉིས་ཏེ་བླངས་པས༌[^321]བྱིན་གྱིས་རློབ་པ་དང་ཐོབ་པས་བྱིན་གྱིས་རློབ་པའོ། །

[Block 648]
གསུང་དང་ཐུགས་ལ་ཡང་དེ་བཞིན་དུ་སྦྱར་བར་བྱའོ། །

[Block 649]
ལེའུ་བདུན་པ་ལས་ནི་ལེའུ་ལྔ་པའི༌[^322]བཤད་པ༌[^323]སྤྱོད་པ་སྤྲོས་ནས་སྟོན་ཏོ་ཞེས་བྱ་བ༌[^324]ནི་ལེའུ་ལྔ་པ་ལས་བཤད་པའི་སྤྱོད་པ་ཉིད་སྤྲོས་ནས་སྟོན་གྱི་དེ་ལས་གཞན་དུ་བཤད་པའི་སྤྱོད་པ་ནི་མ་ཡིན་ནོ། །དེ་ཅིའི་ཕྱིར་ཞེ་ན། དེ་བཞིན་གཤེགས་པ་ཐམས་ཅད་ཀྱི་མཆོག་གི་སྤྱོད་པ་ནི་ལེའུ་ལྔ་པ་ལས་བཤད་པ་ལས་ནམ་ཡང་གཞན་ནས༌[^325]འབྱུང་བར་མི༌[^326]འགྱུར་བའི་ཕྱིར་རོ། །

[Block 650 [HEADING]]
### ལེའུ་བརྒྱད་པ་ནས་བཅུ་གཅིག་པའི་བར། ^2-7-0

[Block 651]
ལེའུ་བརྒྱད་པ་ལས་ནི་གསང་བའི་དབང་བསྐུར་བ་གསུངས་སོ་ཞེས་པ་ནི། གང་ལ་བྱང་ཆུབ་སེམས་ཀྱི་དབང་བསྐུར་བར་ཡོད་པ་དེ་ལ་དེ་སྐད་ཅེས་བྱའོ། །

[Block 652]
ལེའུ་དགུ་པ་ལས་ནི་རྨད་དུ་བྱུང་བའི་ལུང་བསྟན་པ་གསུངས་སོ་ཞེས་པ་ནི་མཆོག་ཏུ་གྱུར་པའི་ལུང་སྟོན་པ་དེ་ལ་དེ་སྐད་ཅེས་བྱའོ། །

[Block 653]
ལེའུ་བཅུ་པ་ལས་ནི་མངོན་པར་འདོད་པའི་དངོས་གྲུབ་མངོན་དུ་བྱ་བའི་ཕྱིར་ཕྱི་དང་ནང་གི་བདག་ཉིད་ཅན་གྱི་ལྷའི་སྙིང་པོ་བསྐུལ་བ་གསུངས་སོ་ཞེས་པ་ནི་མངོན་པར་འདོད་པའི་དངོས་གྲུབ་ནི་བླང་བར་བྱ་བའི་དངོས་གྲུབ་སྟེ་ཐུན་མོང་དང་མཆོག་གི་དངོས་གྲུབ་རྣམ་པ་གཉིས་སོ། །

[Block 654]
དེ་ཐོབ་པར་བྱེད་པའི་ཐབས་ནི་ལྷའི་སྙིང་པོ་ཡིན་པས་དེ་ལ་དེ་སྐད་ཅེས་བྱའོ། །

[Block 655]
ལེའུ་བཅུ་གཅིག་པ་ལས་ནི་སྔགས་ཀྱི་སྐུ་བསྐྱེད་པ་དང་ཡེ་ཤེས་ཀྱི་སྐུ་བསྐྱེད་པ་སྟོན་ཏོ་ཞེས་པ་ནི་སྔགས་ཀྱི་སྐུ་བསྐྱེད་པ་ནི་འདིས་བསྐྱེད་པའི་དབང་དུ་གསུངས་སོ། །

[Block 656]
ཡེ་ཤེས་ཀྱི་སྐུ་བསྐྱེད་པ་ནི་ལོངས་སྤྱོད་རྫོགས་པའི་སྐུའི་དབང་དུ་བྱས་པའོ། །

### ལེའུ་བཅུ་གཉིས་པ་ནས་བཅོ་ལྔ་པའི་བར། ^2-8-0

[Block 658]
ཡང་ན་སྔགས་ཀྱི་སྐུ་བསྐྱེད་པ་ནི་བསྐྱེད་པའི་རིམ་པའོ། །

[Block 659]
ཡེ་ཤེས་ཀྱི་སྐུ་བསྐྱེད་པ་ནི་སྒྱུ་མ་ལྟ་བུའི་སྐུའོ། །

[Block 660]
ལེའུ་གང་ལ་སྔགས་ཀྱི་སྐུ་བསྐྱེད་པ་དང་ཡེ་ཤེས་ཀྱི་སྐུ་བསྐྱེད་པ་ཡོད་པ་དེ་ལ་དེ་སྐད་ཅེས་བྱའོ། །

[Block 661]
ལེའུ་བཅུ་གཉིས་པ་ལས་ནི་ཕྱག་རྒྱ་ཆེན་པོ་ཡོངས་སུ་གྱུར་པ་ཞེས་པ་ནི་ཕྱག་རྒྱ་ཆེན་པོ་ནི་ཕྱག་རྒྱ་རྣམ་པ་བཞི་དང་ལྡན་པའི་སྐུའོ། །

[Block 662]
དེ་ཐོབ་པའི་ཐབས་གང་ལ་ཡོད་པ་དེ་ལ་དེ་སྐད་ཅེས་བྱའོ། །

[Block 663]
ལེའུ་བཅུ་གསུམ་པ་དང་བཅུ་བཞི་པ་ལས་ནི་ལས་ཀྱི་ཚོགས་རྣམས་གསུངས་སོ་ཞེས་པ་ནི་ལས་ཀྱི༌[^327]ཚོགས་མང་བ་གང་ཡིན་པ་དེ་ལ་དེ་སྐད་ཅེས་བྱའོ། །

[Block 664]
ལེའུ་བཅོ་ལྔ་པ་ལས་ནི་དངོས་གྲུབ་ཐམས་ཅད་ནི་དེ་ཁོ་ན་ཉིད་རྟོགས་པ་ཉིད་ཀྱིས་འགྲུབ་པར་འགྱུར་རོ་ཞེས་བསྟན་པའི་ཕྱིར་ཞེས་པས་ནི་དེ་ཉིད་ཀྱི་དགོངས་པ་སྟོན་ཏོ། །

[Block 665]
ཅིའི་ཕྱིར་ཞེ་ན་དེའི་ཕྱིར་ཞེས་པའི་དོན་ཏོ། །

[Block 668]

[Block 669]

[Block 670]
ལེའུ་བཅུ་དྲུག་པ་ལས་ནི་ལེའུ་བཞི་པ་ལས་གསུངས་པའི་རྡུལ་ཚོན་གྱི་དཀྱིལ་འཁོར་སྤྲོས་ནས་སྟོན་ཏོ་ཞེས་པ་ནི་ལེའུ་བཞི་པ་ལས་བཤད་པ་དེ་ཉིད་བཤད་ཀྱི་དེ་ལས་གཞན་པ་ནི་མ་ཡིན་ནོ་ཞེས་པའི་དོན་ཏོ། །

[Block 671]

### ལེའུ་བཅུ་བདུན་པ། ^2-10-0

[Block 675]

[Block 676]

[Block 677]
འདི་དག་གིས་ནི་དེ་བཞིན་གཤེགས་པ་ཐམས་ཅད་ཀྱི་གསང་བ་འདུས་པའི་དོན་མདོར་བསྡུས་པ་བསྟན་ཏོ། །

[Block 678]
དེ་ནས་དེ་བཞིན་གཤེགས་པ་ཐམས་ཅད་ཀྱི་བཤད་པ་མདོར་བསྡུས་པ་བསྟན་པའི་ཕྱིར། འདི་སྐད་བདག་གིས་ཐོས་པ་ཞེས་བྱ་བ་ནས་བྷ་ག་ལ་བཞུགས༌[^330]སོ་ཞེས་པའི་བར་དུ་ནི་བཤད་པའི་ཚུལ་རྣམ་པ་བཞི་དང་ལྡན་པར་བཤད་དོ་ཞེས་པ། ཡི་གེ་དང་། སྤྱི་དང་། སྦས་པ་དང་། མཐར་ཐུག་པ་རྣམ་པ་བཞིར་བསྟན་ཏོ། །

[Block 679]
