རྒྱུ་གསུམ་གྱིས་ན་ཡང་དག་པར༌[^2195]རབ་ཏུ་བརྩོན་པ་ཡང་རྩོམ་པ་འབྲས་བུ་མེད་པར་འགྱུར་ལ། དེ་ལས་བཟློག་པས་ནི་འབྲས་བུ༌[^2196]ཡོད་པར་འགྱུར་ལ།[^2197] འདི་ལྟ་སྟེ། དབང་པོ་ཡང་དག་པར་མི་འགྲུབ་པ་དང་། རྗེས་སུ་མཐུན་པའི་གདམས་ངག་མེད་པ་དང་། ཏིང་ངེ་འཛིན་མཐུ་ཆུང་བས་སོ། །
Enumeration Block 2:
གནས་བཞི་པོ་དག་རྒྱུ་རྣམ་པ་བཞི༌[^2221]ལེགས་པར་རྫས་སུ༌[^2222]བརྟག་པར་བྱ་སྟེ། སྨོན་ལམ་ལེགས་པར་རྗེས་སུ་བརྟག་པར་བྱ། རིགས་དང་། དབང་པོ་དང་། སྤྱད་པ་ལེགས་པར་རྗེས་སུ་བརྟག་པར་བྱའོ། །

Enumeration Block 1:
གནས་ལྔ་པོ་འདི་ལྟ་སྟེ། ཏིང་ངེ་འཛིན་གྱི་ཚོགས་བསྲུང་ཞིང་བསགས་པ་དང་། རབ་ཏུ་དབེན་པ་དང་། སེམས་རྩེ་གཅིག་པ་ཉིད་དང་། སྒྲིབ་པ་རྣམ་པར་སྦྱོང་བ་དང་། ཡིད་ལ་བྱེད་པ་བསྒོམ་པ་དག་ལ་ངེས་པར་སྦྱར་བར་བྱའོ།[^2251] །

Enumeration Block 3:

Enumeration Block 4:
དེ་ལ་སེམས་གནས་པ་རྣམ་པ་དགུ་གང་ཞེ་ན། འདི་ལ་དགེ་སློང་སེམས་ནང་ཁོ་ནར་འཇོག་པར་བྱེད་པ་དང་། ཡང་དག་པར་འཇོག་པར་བྱེད་པ་དང་། བསྡུས་ཏེ་འཇོག་པར་བྱེད་པ་དང་། ཉེ་བར་འཇོག་པར་བྱེད་པ་དང་། དུལ་བར་བྱེད་པ་དང་། ཞི་བར་བྱེད་པ་དང་། ཉེ་བར་ཞི་བར་བྱེད་པ་དང་། རྒྱུད་གཅིག་ཏུ་བྱེད་པ་དང་། ཏིང་ངེ་འཛིན་དུ་བྱེད་པའོ། །
Enumeration Block 5:
དེ་ལ་སྟོབས་རྣམ་པ་དྲུག་གིས་ནི་སེམས་གནས་པ་རྣམ་པ་དགུ་པོ་དག་འགྲུབ་སྟེ། འདི་ལྟ་སྟེ། ཐོས་པའི་སྟོབས་དང་། བསམ་པའི༌[^2319]སྟོབས་དང་། དྲན་པའི་སྟོབས་དང་། ཤེས་བཞིན་གྱི་སྟོབས་དང་། བརྩོན་འགྲུས་ཀྱི་སྟོབས་དང་། ཡོངས་སུ་འདྲིས་པའི་སྟོབས་ཀྱིས་སོ། །
Enumeration Block 6:
