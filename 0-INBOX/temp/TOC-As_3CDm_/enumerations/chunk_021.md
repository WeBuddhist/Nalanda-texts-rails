Enumeration Block 1:
ཁམས་དྲུག་པོ་དག་སྟེ། འདི་ལྟ་སྟེ། སའི་ཁམས་དང་། ཆུའི་ཁམས་དང་། མེའི་ཁམས་དང་། རླུང་གི་ཁམས་དང་། ནམ་མཁའི་ཁམས་དང་། རྣམ་པར་ཤེས་པའི་ཁམས་སོ། །
Enumeration Block 2:
སའི་ཁམས་ནི་རྣམ་པ་གཉིས་ཏེ། ནང་གི་དང་། ཕྱི་རོལ་གྱིའོ། །
Enumeration Block 3:
ཆུའི་ཁམས་ཀྱང་རྣམ་པ་གཉིས་ཏེ། ནང་གི་དང་། ཕྱི་རོལ་གྱིའོ། །
Enumeration Block 4:
མེའི་ཁམས་ཀྱང་རྣམ་པ་གཉིས་ཏེ། ནང་གི་དང་། ཕྱི་རོལ་གྱིའོ། །
Enumeration Block 5:
རླུང་གི་ཁམས་ཀྱང་རྣམ་པ་གཉིས་ཏེ། ནང་གི་དང་། ཕྱི་རོལ་གྱིའོ། །
Enumeration Block 6:
དབུགས་རྔུབ་པ་ཡང་རྣམ་པ་གཉིས་ཏེ། གཉིས་གང་ཞེ་ན། དབུགས་རྔུབ་པ་དང་། བར་དུ་དབུགས་རྔུབ་པའོ། ། དབུགས་འབྱུང་བ་ཡང་རྣམ་པ་གཉིས་ཏེ། གཉིས་གང་ཞེ་ན། དབུགས་འབྱུང་བ་དང་། བར་དུ་དབུགས་འབྱུང་བའོ། །
Enumeration Block 7:
དབུགས་རྔུབ་པ་དང་། དབུགས་འབྱུང་བ་དག་གི་རྒྱུ་ནི་རྣམ་པ་གཉིས་ཏེ། གཉིས་གང་ཞེ་ན།
