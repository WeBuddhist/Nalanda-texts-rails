Enumeration Block 1:
མངོན་པར་ཤེས་པ་ཐམས་ཅད་མངོན་པར་བསྒྲུབ་པའི༌[^3188]ཕྱིར་འདུ་ཤེས་རྣམ་པ་བཅུ་གཉིས་སྒོམ་པར༌[^3189]བྱེད་དེ། འདི་ལྟ་སྟེ། ཡང་བའི་འདུ་ཤེས་དང་། འཇམ་པའི་འདུ་ཤེས་དང་། ནམ་མཁའི་ཁམས་ཀྱི་འདུ་ཤེས་དང་། སེམས་དང་ལུས་ཕྲད་པའི་འདུ་ཤེས་དང་། མོས་པའི་འདུ་ཤེས་དང་། སྔོན་སྤྱད་པ་ཉམས་སུ་མྱོང་བའི་གོ་རིམས་རྗེས་སུ་དྲན་པའི་འདུ་ཤེས་དང་། རྣམ་པ་སྣ་ཚོགས་འདུས་པའི་སྒྲ་སྐད་ཀྱི་འདུ་ཤེས་དང་། སྣང་བའི་གཟུགས་ཀྱི་མཚན་མའི་འདུ་ཤེས་དང་། ཉོན་མོངས་པས་བྱས་པའི་གཟུགས་རྣམ་པར་འགྱུར་བའི་འདུ་ཤེས་དང་། རྣམ་པར་ཐར་པའི་འདུ་ཤེས་དང་། ཟིལ་གྱིས་གནོན་པའི་སྐྱེ་མཆེད་ཀྱི་འདུ་ཤེས་དང་། ཟད་པར་གྱི་སྐྱེ་མཆེད་ཀྱི་འདུ་ཤེས་སོ། །
Enumeration Block 2:
ཚངས་པའི་འཇིག་རྟེན་གྱི༌[^3218]བར་དུ་ལུས་ཀྱིས༌[^3219]དབང་སྒྱུར་བ༌[^3220]ནི་རྣམ་པ་གཉིས་ཏེ། འགྲོ་བས་དབང་སྒྱུར་བར༌[^3221]བྱེད་པ་དང་། ཚངས་པའི་འཇིག་རྟེན་མན་ཆད་ཀྱི་འབྱུང་བ་ཆེན་པོ་བཞི་དང་། རྒྱུར་བྱས་པའི་གཟུགས་རྣམས་པ༌[^3222]ཇི་ལྟར་འདོད་པ་བཞིན་དུ་མོས་པས་དབང་སྒྱུར་བར་བྱེད་པའོ། །
Enumeration Block 3:
རྣམ་པ་བཅུས་བདེན་པ་སྡུག་བསྔལ་ལ་ཡོངས་སུ་རྟོག་པར་བྱེད་པ་ན། རྣམ་པ་བཞི་པོ་དག་གིས༌[^3274]རྗེས་སུ་འཇུག་པར་འགྱུར་ཏེ། བཅུ་གང་ཞེ་ན།
འདི་ལྟ་སྟེ། འགྱུར་བའི་རྣམ་པ་དང་། འཇིག་པའི་རྣམ་པ་དང་། བྲལ་བའི་རྣམ་པ་དང་། ཆོས་ཉིད་ཀྱི་རྣམ་པ་དང་། ཉེ་བའི་རྣམ་པ་དང་། ཀུན་དུ་སྦྱོར་བ་དང་འཆིང་བའི་རྣམ་པ་དང་། མི་སྡུག་པའི་རྣམ་པ་དང་། གྲུབ་པ་དང་བདེ་བ་མེད་པའི་རྣམ་པ་དང་། དམིགས་སུ་མེད་པའི་རྣམ་པ་དང་། རང་དབང་མེད་པའི་རྣམ་པས་སོ། །
Enumeration Block 4:
འདུ་བྱེད་དེ་དག་ཀྱང་མདོར་བསྡུ་ན། རྣམ་པ་གཉིས་ཏེ། སེམས་ཅན་གྱི་འཇིག་རྟེན་དང་། སྣོད་ཀྱི་འཇིག་རྟེན་ནོ། །
Enumeration Block 5:
དངོས་པོ་གཉིས་རྣམ་པར་འཇོག་པར་བྱེད་དེ། གཉིས་གང་ཞེ་ན།
ནང་གི་དངོས་པོ་དང་། ཕྱི་རོལ་གྱི་དངོས་པོའོ། །
Enumeration Block 6:
ཕྱི་རོལ་གྱི་དངོས་པོ་ནི་དངོས་པོ༌[^3287]རྣམ་པ་བཅུ་དྲུག་སྟེ། བཅུ་དྲུག་གང་ཞེ་ན།
Enumeration Block 7:
ནང་གི་དངོས་པོའི་འགྱུར་བ་ནི༌[^3291]རྣམ་པ་བཅོ་ལྔ་དང་། འགྱུར་བའི་རྒྱུ་རྣམ་པ་བརྒྱད་ཡོད་དེ། དེ་ལ་ནང་གི་དངོས་པོའི་འགྱུར་བ་རྣམ་པ༌[^3292]བཅོ་ལྔ་གང་ཞེ་ན།
འདི་ལྟ་སྟེ། གནས་སྐབས་ལས་གྱུར་པ་དང་། ཁ་དོག་ལས་གྱུར་པ་དང་། དབྱིབས་ལས་གྱུར་པ་དང་། འབྱོར་པ་དང་རྒུད་པ་ལས་གྱུར་པ་དང་། ཡན་ལག་དང་ཉིང་ལག་ཚང་བ་དང་མ་ཚང་བ་ལས་གྱུར་པ་དང་། ཡོངས་སུ་ངལ་བ་ལས་གྱུར་པ་དང་། གཞན་གྱི་གནོད་པ་བྱས་པ་ལས་གྱུར་པ་དང་། གྲང་བ་དང་དྲོ་བ་ལས་གྱུར་པ་དང་། སྤྱོད་ལམ་ལས་གྱུར་པ་དང་། རེག་པ་ལས་གྱུར་པ་དང་། ཀུན་ནས་ཉོན་མོངས་པ་ལས་གྱུར་པ་དང་། ན་བ་ལས་གྱུར་པ་དང་། འཆི་བ་ལས་གྱུར་པ་དང་། རྣམ་པར་བསྔོས་པ་ལ་སོགས་པ་ལས་གྱུར་པ་དང་། རྣམ་པ་ཐམས་ཅད་ཀྱི་ཐམས་ཅད་དུ་མི་སྣང་ཞིང་ཡོངས་སུ་ཟད་པ་ལས་གྱུར་པའི་འགྱུར་བའོ། །
