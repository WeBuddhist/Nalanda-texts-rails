Enumeration Block 1:
བསླབ་པ་དང་རྗེས་སུ་མཐུན་པའི་ཆོས་བཅུ་ཡོད་པར་རིག་པར་བྱ་སྟེ། བཅུ་གང་ཞེ་ན།
འདི་ལྟ་སྟེ། སྔོན་གྱི་རྒྱུ་དང་། རྗེས་སུ་མཐུན་པའི་ལུང་དང་། ཚུལ་བཞིན་ལ་རབ་ཏུ་སྦྱོར་བ་དང་། རྟག་ཏུ་གུས་པར་བྱས་ཏེ་བྱེད་པ་དང་། འདུན་པ་དྲག་པོ་དང་། རྣལ་འབྱོར་གྱི་སྟོབས་སྐྱེད་པ༌[^1829]དང་། ལུས་དང་སེམས་ཀྱི་གནས་ངན་ལེན་ཤིན་ཏུ་སྦྱངས་པ་དང་། ཡང་དང་ཡང་དུ་སོ་སོར་རྟོག་པ་དང་། ཡོངས་སུ་གདུང་བ་མེད་པ་དང་། མངོན་པའི་ང་རྒྱལ་མེད་པའོ། །
Enumeration Block 2:
རྣལ་འབྱོར་ཉམས་པ་ནི་རྣམ་པ་བཞི་སྟེ། བཞི་གང་ཞེ་ན།
རྣལ་འབྱོར་ཉམས་པ་གཏན་དུ་བ་ཡང་ཡོད། རེ་ཞིག་པ་ཡང་ཡོད། ཐོབ་པ་ལས་ཡོངས་སུ་ཉམས་པ་ཡང་ཡོད། །ལོག་པར་སྒྲུབ་པས༌[^1848]བྱས་པ་ཡང་ཡོད་དོ། །
Enumeration Block 3:
རྣལ་འབྱོར་ནི་རྣམ་པ་བཞི་སྟེ། འདི་ལྟ་སྟེ། དད་པ་དང་། འདུན་པ་དང་། བརྩོན་འགྲུས་དང་། ཐབས་སོ། །
Enumeration Block 4:
འདུན་པ་ཡང་རྣམ་པ་བཞི་སྟེ།
Enumeration Block 5:
དེ་ལ་བརྩོན་འགྲུས་ཀྱང་རྣམ་པ་བཞི་སྟེ། འདི་ལྟ་སྟེ། མཉན་པའི་ཕྱིར་དང་། བསམ་པའི་ཕྱིར་དང་། བསྒོམ་པའི་ཕྱིར་དང་། སྒྲིབ་པ་ཡོངས་སུ་དག་པར་བྱ་བའི༌[^1866]ཕྱིར་བརྩོན་པའོ། །
Enumeration Block 6:
དེ་ལ་ཐབས་ཀྱང་རྣམ་པ་བཞི་སྟེ།
Enumeration Block 7:
ཡིད་ལ་བྱེད་པ་ནི་རྣམ་པ་བཞི་སྟེ། བཞི་གང་ཞེ་ན།
འདི་ལྟ་སྟེ་བསྒྲིམས་ཏེ་འཇུག་པ་དང་། སྐབས་སུ་འཆད་ཅིང་འཇུག་པ་དང་། སྐབས་སུ་འཆད་པ་མེད་པར་འཇུག་པ་དང་། རྩོལ་བ་མེད་པར་འཇུག་པའོ། །
Enumeration Block 8:
གཞན་ཡང་ཡིད་ལ་བྱེད་པ་ནི་རྣམ་པ་བཞི་སྟེ། འདི་ལྟ་སྟེ། མཐུན་པ་ལས་བྱུང་བ་དང་། གཉེན་པོ་ལས་བྱུང་བ་དང་། དད་པར་བྱ་བར་འོས་པ་དང་། སོ་སོར་བརྟག་པར༌[^1880]འོས་པའོ། །
Enumeration Block 9:
དེ་ལ་དམིགས་པ་ཡིད་ལ་བྱེད་པས། མཚན་མ་དུ་ཞིག་ཡིད་ལ་བྱ་བ་ཡིན་ཞེ་ན།
སྨྲས་པ། བཞི་སྟེ། བཞི་གང་ཞེ་ན།
འདི་ལྟ་སྟེ། དམིགས་པའི་མཚན་མ་དང་། གཞིའི་མཚན་མ་དང་། ཡོངས་སུ་སྤང་བར་བྱ་བའི་མཚན་མ་དང་། སོ་སོར་སྟོན་པར༌[^1883]བྱ་བའི་མཚན་མའོ། །
