Enumeration Block 1:
དེ་ལ་བྲམ་ཟེ་ནི་རྣམ་པ་གསུམ་སྟེ། འདི་ལྟ་སྟེ། རིགས་བྲམ་ཟེ་དང་། མིང་བྲམ་ཟེ་དང་། སྒྲུབ་པ་བྲམ་ཟེའོ། །
Enumeration Block 2:
དེ་ལ་ཚངས་པར་སྤྱོད་པ་ཡང་རྣམ་པ་གསུམ་སྟེ། འདི་ལྟ་སྟེ། སྤངས་ཤིང་ཡང་དག་པར་བླངས་པ་དང་། དེ་ལ་བར་ཆད་མེད་པས་སྤངས་པ་དང་། དེ་གཏན་སྤངས་པའོ། །
Enumeration Block 3:
དེ་ལ་སྡོམ་བརྩོན་པ་ནི་རྣམ་པ༌[^2157]གསུམ་སྟེ།
Enumeration Block 4:
དེ་ལ་རབ་ཏུ་བྱུང་བ་ནི་རྣམ་པ་གཉིས་ཏེ། ལེགས་པར་གསུངས་པའི་ཆོས་འདུལ་བ་དང་ལྡན་པ་དང་། ཉེས་པར་བཤད་པའི་ཆོས་འདུལ་བ་དང་ལྡན་པའོ། །
Enumeration Block 5:
དེ་ལ་གང་ཟག་བརྒྱད་གང་ཞེ་ན།
འདི་ལྟ་སྟེ། ནུས་པ་དང་། མི་ནུས་པ་དང་། ཐབས་ལ་མཁས་པ་དང་། ཐབས་ལ་མི་མཁས་པ་དང་། རྒྱུན་དུ་བྱེད་པ་དང་། རྒྱུན་དུ་མི་བྱེད་པ་དང༌[^2164]ཡོངས་སུ་སྦྱང་བ་བྱས་པ་དང་། ཡོངས་སུ་སྦྱང་བ་མ་བྱས་པའོ། །
དེ་ལ་གང་ཟག་རྣམ་པ་བཞི་རྣམ་པར་གཞག་པ་ནི་གང་ཟག་བརྒྱད་པོ་དེ་དག་ཉིད་རྣམ་པར་གཞག་པའི་རྒྱུ་ཡིན་ཏེ། རབ་ཏུ་དབྱེ་བ་རྣམ་པ་བཞིས་རྒྱུར་འགྱུར་རོ། །
Enumeration Block 6:
དེ་ལ་བདུད་བཞི་གང་ཞེ་ན།
ཕུང་པོའི་བདུད་དང་། ཉོན་མོངས་པའི་བདུད་དང་། འཆི་བའི་བདུད་དང་། ལྷའི་བུའི་བདུད་དོ། །
