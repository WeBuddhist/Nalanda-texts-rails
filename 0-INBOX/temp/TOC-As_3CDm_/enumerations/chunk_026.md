Enumeration Block 1:
བསླབ་པ་ནི་གསུམ་སྟེ། ལྷག་པའི་ཚུལ་ཁྲིམས་ཀྱི་བསླབ་པ་དང་། ལྷག་པའི་སེམས་ཀྱི་བསླབ་པ་དང་། ལྷག་པའི་ཤེས་རབ་ཀྱི་བསླབ་པའོ། །
Enumeration Block 2:
བདེན་པ་རྣམས་མངོན་པར་རྟོགས་པར་བྱེད་པའི་གང་ཟག་ནི་རྣམ་པ་གསུམ་སྟེ། གསུམ་གང་ཞེ་ན། འདི་ལྟ་སྟེ། འདོད་ཆགས་དང་མ་བྲལ་བ་དང་། འདོད་ཆགས་དང་ཤས་ཆེར་བྲལ་བ་དང་། འདོད་ཆགས་དང་བྲལ་བའོ། །
Enumeration Block 3:
དབང་པོ་ནི་གསུམ་སྟེ། མི་ཤེས་པ་ཀུན་ཤེས་པར་བྱེད་པའི་དབང་པོ་དང་། ཀུན་ཤེས་པའི་དབང་པོ་དང་། ཀུན་ཤེས་པ་དང་ལྡན་པའི་དབང་པོའོ། །
Enumeration Block 4:
རྣམ་པར་ཐར་པའི་སྒོ་ནི་གསུམ་སྟེ། འདི་ལྟ་སྟེ། སྟོང་པ་ཉིད་དང་། སྨོན་པ་མེད་པ་དང་། མཚན་མ་མེད་པའོ། །
Enumeration Block 5:
འདི་ནི་གཉིས་ཡིན་ཏེ། འདུས་བྱས་དང་། འདུས་མ་བྱས་སོ། །
Enumeration Block 6:
བསླབ་པ་དང་མི་མཐུན་པའི་ཆོས་བཅུ་ཡོད་དེ།
Enumeration Block 7:
བསླབ་པ་དང་མི་མཐུན་པ་དེ་དག་གི༌[^1826]གཉེན་པོ་བསླབ་པ་དང་རྗེས་སུ་མཐུན་པ་བཅུ་གང་ཞེ་ན། འདི་ལྟ་སྟེ། མི་སྡུག་པའི་འདུ་ཤེས་དང་། མི་རྟག་པའི་འདུ་ཤེས་དང་། མི་རྟག་པ་ལ་སྡུག་བསྔལ་བའི་འདུ་ཤེས་དང་། སྡུག་བསྔལ་བ་ལ་བདག་མེད་པའི་འདུ་ཤེས་དང་། ཟས་ལ་མི་མཐུན་པའི་འདུ་ཤེས་དང་། འཇིག་རྟེན་ཐམས་ཅད་ལ་མངོན་པར་མི་དགའ་བའི་འདུ་ཤེས་དང་། སྣང་བའི་འདུ་ཤེས་དང་། འདོད་ཆགས་དང་བྲལ་བའི་འདུ་ཤེས་དང་། འགོག་པའི་འདུ་ཤེས་དང་། འཆི་བའི་འདུ་ཤེས་ཏེ།[^1827]
Enumeration Block 8:
བསླབ་པ་དང་རྗེས་སུ་མཐུན་པའི་ཆོས་བཅུ་ཡོད་པར་རིག་པར་བྱ་སྟེ། བཅུ་གང་ཞེ་ན། འདི་ལྟ་སྟེ། སྔོན་གྱི་རྒྱུ་དང་། རྗེས་སུ་མཐུན་པའི་ལུང་དང་། ཚུལ་བཞིན་ལ་རབ་ཏུ་སྦྱོར་བ་དང་། རྟག་ཏུ་གུས་པར་བྱས་ཏེ་བྱེད་པ་དང་། འདུན་པ་དྲག་པོ་དང་། རྣལ་འབྱོར་གྱི་སྟོབས་སྐྱེད་པ༌[^1829]དང་། ལུས་དང་སེམས་ཀྱི་གནས་ངན་ལེན་ཤིན་ཏུ་སྦྱངས་པ་དང་། ཡང་དང་ཡང་དུ་སོ་སོར་རྟོག་པ་དང་། ཡོངས་སུ་གདུང་བ་མེད་པ་དང་། མངོན་པའི་ང་རྒྱལ་མེད་པའོ། །
