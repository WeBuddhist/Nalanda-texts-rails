## དཀར་ཆག / Table of Contents

* I. མཆོད་བརྗོད། [[དཀོན་མཆོག་གསུམ་ལ་ཕྱག་འཚལ་ལོ། །]]

* 2. སོང་བ་དང་མ་སོང་བ་དང་བགོམ་པ་བརྟག་པ། [[སྨྲས་པ། ཁྱེད་ཀྱིས་སྐྱེ་བ་མེད་པའི་རིགས་པ་འདི་རྗེས་སུ་རབ་ཏུ་བསྟན་པས་ཁོ་བོའི་ཡིད]]

* 4. ཕུང་པོ་བརྟག་པ། [[འདིར་སྨྲས་པ། འདི་ལ་གཟུགས་ལ་སོགས་པ་ཕུང་པོ་ལྔ་པོ་དག་བསྟན་ཏོ། །]]

* 12. སྡུག་བསྔལ་བརྟག་པ། [[དབུ་མའི་རྩ་བའི་འགྲེལ་པ་བུད་དྷ་པཱ་ལི་ཏ། བམ་པོ་ལྔ་པ། སྨྲས་པ། བདག་ནི་ཡོད་པ་ཁོ་ན་ཡིན་ཏེ།]]
* 13. དེ་ཁོ་ན་ཉིད་བརྟག་པ། [[སྨྲས་པ། སྡུག་བསྔལ་ཡང་ཡོད་ཕྱི་རོལ་གྱི་དངོས་པོ་རྣམས་ཀྱང་ཡོད་དེ།]]
* 14. ཕྲད་པ་བརྟག་པ། [[སྨྲས་པ། དངོས་པོ་རྣམས་ངོ་བོ་ཉིད་སྟོང་པ་ཉིད་མ་ཡིན་གྱི། དངོས་པོ་རྣམས་ངོ་བོ་ཉིད་ཡོད་པ་ཁོ་ན་ཡིན་ཏེ།]]

* a.2 འགྱུར་བྱང། [[རྒྱ་གར་གྱི་མཁན་པོ་ཛྙཱ་ན་གརྦྷ་དང་། །ཞུ་ཆེན་གྱི་ལོ་ཙཱ་བ་ཅོག་རོ་ཀླུའི་རྒྱལ་མཚན་གྱིས་བསྒྱུར]]
