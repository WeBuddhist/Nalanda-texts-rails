Enumeration Block 1:
དེ་ཡང་མདོར་བསྡུ་ན་སྤོང་བ་དང་། རྗེས་སུ་མཐུན་པ་རྣམ་པ་གཉིས་སུ་རིག་པར་བྱ་སྟེ། ཉེ་བར་སྟོན་པ་དང་རྗེས་སུ་མཐུན་པ་དང་། བརྩོན་འགྲུས་བརྩམས་པ་དང་རྗེས་སུ་མཐུན་པའོ། །
Enumeration Block 2:
དེ་ལ་དུས་ནི་གསུམ་སྟེ།
Enumeration Block 3:
དེ་ལ་རིགས་པ་ཡང༌[^978]རྣམ་པ་གསུམ་སྟེ། སློང་བ་ན་རུང་བ་སློང་བ་དང་། ཚོད་རན་པར་སློང་བ་དང་། གཏམ་ཟེར་བ་ན་ཆོས་ཀྱི་གཏམ་དོན་དང་ལྡན་པ་ཟེར་བའོ། །
Enumeration Block 4:
དེ་ལ་རན་པ༌[^979]ཡང་རྣམ་པ་གསུམ་གྱིས་རིག་པར༌[^980]བྱ་སྟེ། རྣམ་པར་འཁྲུགས་པ༌[^981]མ་ཡིན་པ་དང་། ཚིག་དང་ཡི་གེ་འདུས་པ་དག་གིས་རྣམ་པར་མ་འཕྲོས་པར་ཆོས་སྟོན་པ་དང་། ཟློས་བུ་མ་ཡིན་པར་སྨྲ་བ་སྟེ།
Enumeration Block 5:
དེ་ལ་ཞི་བ་ཡང་རྣམ་པ་གསུམ་སྟེ། སྤྱོད་ལམ་ཞི་བ་དང་། སྒྲ་ཞི་བ་དང་། སེམས་ཞི་བའོ། །
Enumeration Block 6:
དེ་ལ་ཚིག་གནམ་པ༌[^984]ཡང་རྣམ་པ་གསུམ་སྟེ། དུས་སུ་སྨྲ་བ་ནས་ཞི་བའི་བར་དུ་སྨྲ་བ་ན་སྔོན་གོམས་པའི་ཚུལ་གྱིས་སམ། ཚེ་འདི་ལ་གོམས་པའི་ཚུལ་གྱིས༌[^985]ཐ་མལ་པར་སྨྲ་བ་དང་། ཚིག་དེ་ལ་བསླབ་པར་འདོད་པས་སོ་སོར་རྟོགས་པའི༌[^986]སྟོབས་ཀྱིས་ཟིན་པ་དང་། དེའི་ཚིག་དེ་ལྐོག་གམ། མིག་སྔར་དེ་ཐམས་ཅད་དུ་མི་སླུ་བ་ཡིན་པའོ། །
