Enumeration Block 1:
ཉན་ཐོས་ཁྱིམ་རྣམས་སུ་འགྲོ་བར་འདོད་པས་ནི་ཉེ་བའི་ཉོན་མོངས་པ་གསུམ་སྤངས་པ་ཁྱིམ་རྣམས་སུ་འགྲོ་བར་བྱའོ། ། གསུམ་གང་ཞེ་ན། མཛའ་བཤེས་ཀྱི་ཁྱིམ་ཡོངས་སུ་འཛིན་པ་དང་། ཁྱིམ་ལ་སེར་སྣ་བྱེད་པ་དང་། ཟང་ཟིང་དང་བཅས་པའི་སེམས་ཀྱིས་ཆོས་སྦྱིན་པའོ། །
Enumeration Block 2:
ཉན་ཐོས་ཀུན་ནས་ཉོན་མོངས་པ་དང་། རྣམ་པར་བྱང་བ་ལ་བརྩོན་པས་ནི་མདོར་བསྡུ་ན་གནས་གསུམ་ཡོངས་སུ་ཤེས་པར་བྱ་སྟེ། ཀུན་ནས་ཉོན་མོངས་པ་དང་། རྣམ་པར་བྱང་བའི་གནས་ཀུན་ནས་ཉོན་མོངས་པ་དང་། རྣམ་པར་བྱང་བའི་གནས་ལས་ཡོངས་སུ་ཤེས་པར་བྱ་བ་དང་། ཀུན་ནས་ཉོན་མོངས་པ་ཀུན་ནས་ཉོན་མོངས་པ་ལས་ཡོངས་སུ་ཤེས་པར་བྱ་བ་དང་། རྣམ་པར་བྱང་བ་རྣམ་པར་བྱང་བ་ལས་ཡོངས་སུ་ཤེས་པར་བྱ་བའོ།[^299] །
Enumeration Block 3:
རྣམ་པར་བྱང་བ་དེ་ཡང་མདོར་བསྡུ་ན། རྒྱུ་ལྔས་རབ་ཏུ་དབྱེ་བ༌[^302]ཡིན་ཏེ། རྒྱུ་ལྔ་གང་ཞེ་ན། སྟོན་པ་དང་། སྒྲུབ་པ་པོ་དང་། སྒྲུབ་པ་དང་། ལྷག་པའི་སེམས་ཀྱི་མི་མཐུན་པའི་ཕྱོགས་ཀྱི་ཉེ་བའི་ཉོན་མོངས་པ་སྤོང་བ་དང་། ལྷག་པའི་ཤེས་རབ་ཀྱི་མི་མཐུན་པའི་ཕྱོགས་ཀྱི་ཉེ་བའི་ཉོན་མོངས་པ་སྤོང་བས་སོ། །
Enumeration Block 4:
ཉན་ཐོས་ཀྱི་ཀུན་ནས་ཉོན་མོངས་པ་དང་། རྣམ་པར་བྱང་བའི་གནས་དེ་ཡང་མདོར་བསྡུ་ན། རྒྱུ་གསུམ་གྱིས་ཡོངས་སུ་ཤེས་པར་བྱ་སྟེ། ངོ་བོ་ཉིད་དང་། རྒྱུ་དང་། ཉེས་དམིགས་ཀྱིས་སོ། །
Enumeration Block 5:
དེའི་རྒྱུ་ཡང་རྣམ་པ་གསུམ་སྟེ།
Enumeration Block 6:
མིའི་ལུས་དེའི་སོ་སོའི་རང་གི་མཚན་ཉིད་ཀྱི་རྒྱུ་ནི་རྣམ་པ་གཉིས་ཏེ།
Enumeration Block 7:
དེའི་ཉེས་དམིགས་ཀྱང་རྣམ་པ་གཉིས་ཏེ། སྡུག་བསྔལ་བ་ཉིད་དང་། མི་རྟག་པ་ཉིད་དོ། །
Enumeration Block 8:
གང་མི་རྟག་པ་དེ་ནི་སྡུག་བསྔལ་བའོ་ཞེས་བྱ་བ་ནི། རྒྱུ་ལྔས་རིག་པར་བྱ་སྟེ།
