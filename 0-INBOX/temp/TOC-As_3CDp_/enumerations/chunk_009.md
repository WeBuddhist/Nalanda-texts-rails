Enumeration Block 2:
སྲེད་པ་གསུམ་པོ་དེ་དག་ཀྱང་མདོར་བསྡུ་ན། རྣམ་པ་གཉིས་སུ་བལྟ་བར་བྱ་སྟེ། དང་པོ་ནི་སྲེད་པའི༌[^360]སྲེད་པའོ། །

Enumeration Block 3:
སྲེད་པ་དེ་དག་ཀྱང་ཁམས་ཀྱི་རབ་ཏུ་དབྱེ་བས་ནི་རྣམ་པ་གསུམ་དུ་འགྱུར་ཏེ་འདོད་པའི་སྲེད་པ་དང་། གཟུགས་ཀྱི་སྲེད་པ་དང་། གཟུགས་མེད་པའི་སྲིད༌[^362]པའོ། །
Enumeration Block 4:
མདོར་བསྡུ་ན་གཉིས་ཀྱིས་ཏེ། ཉོན་མོངས་པ་འགོག་པ་དང་། ཕུང་པོ་འགོག་པས་སོ། །
Enumeration Block 5:
ཉེས་པ་བཞི་རྣམ་པར་སྤངས་པས་འགོག་པའི་བདེན་པའི་ལན་འདེབས་པ་ནི་ཡང་དག་པར་ལན་འདེབས་པ་ཡིན་པར་རིག་པར་བྱ་སྟེ། སྒྲོ་འདོགས་པའི་ཉེས་པ་དང་། རང་གི་མཚན་ཉིད་ལོག་པར་ཡོངས་སུ་རྟོག་པའི་ཉེས་པ་དང་། མཚན་ཉིད་འདྲེས་པའི་ཉེས་པ་དང་། སྐུར་པ་འདེབས་པའི་ཉེས་པ་རྣམ་པར་སྤངས་པས་སོ། །
Enumeration Block 6:
ཡང་དག་པའི་ཆོས་ཀྱི་ལོངས་སྤྱོད་དང་། ཟང་ཟིང་གི་ལོངས་སྤྱོད་ཀྱི་དབང་དུ་བྱས་པའི་རྒྱུ་གཉིས་ཀྱིས་ཏེ།
Enumeration Block 7:
ཤེས་རབ་ཀྱི་ལས་ནི་མདོར་བསྡུ་ན་རྣམ་པ་གསུམ་ཡོད་ལ།
Enumeration Block 8:
རྣམ་པ་གཉིས་ཀྱིས་ཏེ། ངོ་བོ་ཉིད་དང་རྟེན་གྱིས་སོ། །
Enumeration Block 9:
དེ་ལ་ཡང་དག་པའི་ལྟ་བ་ནི་མདོར་བསྡུ་ན་རྣམ་པ་བཅུ་གཅིག་ཏུ་བལྟ་བར༌[^377]བྱ་སྟེ། ནང་དུ་ལྟ་བ་དང་། འབྲས་དང་། ཟུག་རྔུ་དང་། སྡིག་པ་དང་། མི་རྟག་པ་ཉིད་དང་། སྡུག་བསྔལ་བ་ཉིད་དང་། སྟོང་པ་ཉིད་དང་། བདག་མེད་པ་ཉིད་དང་། ཀུན་དུ་སྦྱོར་བར་བྱེད་པ་དང་། བྲལ་བ་དང་། འབྲལ་བར་བྱེད་པར་བལྟ་བའོ། །
Enumeration Block 10:
མི་རྟག་པ་ལ་སོགས་པར་ལྟ་བ་དེ་ཡང་། མདོར་བསྡུ་ན། རྣམ་པ་གཉིས་ཏེ།
Enumeration Block 11:
འདི་ལྟར་སྡུག་བསྔལ་གྱི་བདེན་པ་ནི་མཚན་ཉིད་གཉིས་ཀྱིས་ཡོངས་སུ་ཤེས་པར་བྱ་བ་ཡིན་ཏེ། རང་གི་མཚན་ཉིད་དང་། སྤྱིའི་མཚན་ཉིད་ཀྱིས་སོ། །
