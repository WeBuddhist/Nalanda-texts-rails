Enumeration Block 1:
ཀུན་རྫོབ་ཀྱི་མཚན་ཉིད་ནི་རྣམ་པ་གསུམ་སྟེ། གང་ཟག་བསྟན་པ་དང་། ཀུན་བརྟགས་པའི་ངོ་བོ་ཉིད་བསྟན་པ་དང་། ཆོས་རྣམས་ཀྱི་བྱེད་པ་དང་། གཡོ་བ་དང་ལས་བྱེད་པ་བསྟན་པས་བལྟ་བར་བྱའོ། །
Enumeration Block 2:
རྣམ་པའི་མཚན་ཉིད་ནི་བརྟགས་པ༌[^2354]རྣམ་པ་བརྒྱད་བསྟན་པས་བལྟ་བར་བྱ་སྟེ། བརྟགས༌[^2355]པ་རྣམ་པ༌[^2356]བརྒྱད་གང་ཞེ་ན། བདེན་པ་དང་། གནས་པ་དང་། སྐྱོན་དང་། ཡོན་ཏན་དང་། ཚུལ་དང་། འཇུག་པ་དང་། རིགས་པ༌[^2357]དང་། བསྡུ་བ་དང་། རྒྱས་པས་སོ། །
Enumeration Block 3:
ཚུལ་ནི་རྣམ་པ་དྲུག་ཏུ་རིག་པར་བྱ་སྟེ། དེ་ཁོ་ནའི་དོན་གྱི་ཚུལ་དང་། འཐོབ་པའི་ཚུལ་དང་། བཤད་པའི་ཚུལ་དང་། མཐའ་གཉིས་རྣམ་པར་སྤངས་པའི་ཚུལ་དང་། བསམ་གྱིས་མི་ཁྱབ་པའི་ཚུལ་དང་། དགོངས་པའི་ཚུལ་ལོ། །
Enumeration Block 4:
རིགས་པ་ནི་རྣམ་པ་བཞིར་རིག་པར་བྱ་སྟེ། ལྟོས་པའི་རིགས་པ་དང་། [^2360]བྱ་བ་བྱེད་པའི་རིགས་པ༌[^2361]དང་། འཐད་པས་བསྒྲུབ་པའི་རིགས་པ་དང་། ཆོས་ཉིད་ཀྱི་རིགས་པའོ། །
Enumeration Block 5:
དེ་ཡང་མདོར་བསྡུ་ན་རྣམ་པ་གཉིས་ཏེ། ཡོངས་སུ་དག་པ་དང་། ཡོངས་སུ་མ་དག་པའོ། ། དེ་ལ་ཡོངས་སུ་དག་པའི་མཚན་ཉིད་ནི་ལྔའོ། ། ཡོངས་སུ་མ་དག་པའི་མཚན་ཉིད་ནི་བདུན་ནོ། ། དེ་ལ་ཡོངས་སུ་དག་པའི་མཚན་ཉིད་ལྔ་པོ་དག་གང་ཞེ་ན། དེ་ལ༌[^2366]མངོན་སུམ་དུ་དམིགས་པའི་མཚན་ཉིད་དང་། དེ་ལ་གནས་པ་མངོན་སུམ་དུ་དམིགས་པའི་མཚན་ཉིད་དང་། རང་གི་ལས་ཀྱི་དཔེ་ཉེ་བར་སྦྱར་བའི་མཚན་ཉིད་དང་། ཡོངས་སུ་གྲགས་པའི་མཚན་ཉིད་དང་། ལུང་ཤིན་ཏུ་རྣམ་པར་དག་པ་གཏན་ལ་དབབ་པར༌[^2367]བསྟན་པའི་མཚན་ཉིད་དོ། །
Enumeration Block 6:
ཐམས་ཅད་མཁྱེན་པའི་མཚན་ཉིད་རྣམ་པ་དུས་རྟོགས་པར་བགྱི་ལགས། འཇམ་དཔལ་ལྔས་ཏེ།
Enumeration Block 7:
ཡོངས་སུ་མ་དག་པའི་མཚན་ཉིད་རྣམ་པ་བདུན་གང་ཞེ་ན། དེ་ལས་གཞན་པ༌[^2378]དང་མཐུན་པར་དམིགས་པའི་མཚན་ཉིད་དང་། དེ་ལས་གཞན་དང་མི་མཐུན་པར་དམིགས་པའི་མཚན་ཉིད་དང་། ཐམས་ཅད་མཐུན་པར་དམིགས་པའི་མཚན་ཉིད་དང་། ཐམས་ཅད་མི་མཐུན་པར་དམིགས་པའི་མཚན་ཉིད་དང་། གཞན་གྱི་རིགས་ཀྱི་དཔེ་ཉེ་བར་སྦྱར་བའི་མཚན་ཉིད་དང་། ཡོངས་སུ་མ་གྲགས་པའི་མཚན་ཉིད་དང་། ལུང་ཤིན་ཏུ་རྣམ་པར་མ་དག་པ་བསྟན་པའི་མཚན་ཉིད་དོ། །
