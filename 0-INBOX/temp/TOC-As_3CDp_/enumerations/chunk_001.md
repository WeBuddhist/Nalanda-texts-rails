Enumeration Block 1:
ཆོས་ངེས་པར་འབྱུང་བ་ལ་བརྟེན་པ་རྣམས་ཀྱི་རབ་ཏུ་དབྱེ་བ་ཡང་དེ་ལས་བཟློག་པ་རྣམ་པ་ལྔ་ཁོ་ནས་རྣམ་པར་གཞག་པར་རིག་པར་བྱ་སྟེ། སྔ་མ་བཞིན་ནོ། །
Enumeration Block 2:
དེ་ལ་ཆོས་འཇིག་རྟེན་པ་རྣམས་ཀྱི་རབ་ཏུ་དབྱེ་བ་ཡང་རྣམ་པ་ལྔ་ཁོ་ནས་རྣམ་པར་གཞག་སྟེ། ལྔ་གང་ཞེ་ན།
འཇིག་རྟེན་པའི་དང་བའི་གཟུགས་དང་། དང་བས་གཟུང་བའི་གཟུགས་ཐམས་ཅད་དང་འཇིག་རྟེན་པའི་སེམས་དང་སེམས་ལས་བྱུང་བའི་ཆོས་ཉོན་མོངས་པ་ཅན་ཐམས་ཅད་དང་། འཇིག་རྟེན་པའི་སེམས་དང་སེམས་ལས་བྱུང་བའི་ཆོས་ལུང་དུ་མ་བསྟན་པ་ཐམས་ཅད་དང་། འཇིག་རྟེན་པའི་སེམས་དང་སེམས་ལས་བྱུང་བའི་ཆོས་དགེ་བ་དང་སྤང་བར་བྱ་བ་དང་སྤངས་པ་ཐམས་ཅད་དང་། འཇིག་རྟེན་པའི་ཏིང་ངེ་འཛིན་གྱི་སྤྱོད་ཡུལ་འཇིག་རྟེན་པའི་གཟུགས་བསྟན་དུ་མེད་ལ་ཐོགས་པ་མེད་པ་ཐམས་ཅད་དོ། །
Enumeration Block 3:
ཆོས་འཇིག་རྟེན་ལས་འདས་པ་རྣམས་ཀྱི་རབ་ཏུ་དབྱེ་བ་ཡང་རྣམ་པ་ལྔ་ཁོ་ནས་རྣམ་པར་གཞག་སྟེ། ལྔ་གང་ཞེ་ན།
མཐོང་བས་སྤང་བར་བྱ་བའི་གཉེན་པོ་རྣམས་དང་། བསྒོམ་པས་སྤང་བར་བྱ་བའི་གཉེན་པོ་རྣམས་དང་། འདུ་ཤེས་རྣམ་པར་གྲོལ་བས་རྣམ་པར་གྲོལ་བ་འདི་ལྟ་སྟེ། ཉན་ཐོས་དང་རང་སངས་རྒྱས་དང་། བྱང་ཆུབ་སེམས་དཔའ་རྣམས་ཀྱི་སྤྲོས་པ་མེད་པའི་ཚུལ་ལ༌[^32]ཞུགས་པའི་ཤེས་རབ་དང་། དེ་དང་མཚུངས་པར་ལྡན་པའི་སེམས་དང་སེམས་ལས་བྱུང་བའི་ཆོས་རྣམས་དང་། དེའི་དམིགས་པ་བསྟན་དུ་མེད་ལ་ཐོགས་པ་མེད་པའི་གཟུགས་དང་། མི་མཐུན་པའི་ཕྱོགས་ཀྱི་ཕྱོགས་གཅིག་རྣམ་པར་གྲོལ་བས་རྣམ་པར་གྲོལ་བ་འདི་ལྟ་སྟེ། སློབ་པ་རྣམས་དང་། མི་མཐུན་པའི་ཕྱོགས་ཐམས་ཅད་རྣམ་པར་གྲོལ་བས་རྣམ་པར་གྲོལ་བ་འདི་ལྟ་སྟེ། མི་སློབ་པ་རྣམས་སོ། །
Enumeration Block 4:
དེ་ལ་ཆོས་འདུས་བྱས་རྣམས་ཀྱི་རབ་ཏུ་དབྱེ་བ་ཡང་རྣམ་པ་ལྔ་ཁོ་ནས་རྣམ་པར་གཞག་སྟེ། ཕྱི་མའི་མཐའ་ནས་མི་འབྱུང་བ་དང་། སྔོན་གྱི་མཐའ༌[^35]རྣམ་པར་ཞི་བ་དང་། དབུས་ཀྱི་མཐར་རང་གི་མཚན་ཉིད་ལ་གནས་པ་དང་། རྒྱུ་དང་རྐྱེན་གྱི་རྒྱུན་དང་། འབྲས་བུའི་རྒྱུན་གྱིས་སོ། །
Enumeration Block 5:
ཆོས་འདུས་མ་བྱས་རྣམས་ཀྱི་རབ་ཏུ་དབྱེ་བ་ཡང་རྣམ་པ་ལྔ་ཁོ་ནས་རྣམ་པར་གཞག་སྟེ། ལྔ་གང་ཞེ་ན།
Enumeration Block 6:
དེ་ལ་དམིགས་པའི་ཆོས་རྣམས་ཀྱི་རབ་ཏུ་དབྱེ་བ་ཡང་རྣམ་པ་ལྔས་རྣམ་པར་གཞག་སྟེ། ལྔ་གང་ཞེ་ན།
དགེ་བ་ཡིད་ལ་བྱེད་པའི་དམིགས་པའི་ཆོས་དག་ཀྱང་ཡོད། མི་དགེ་བ་ཡིད་ལ་བྱེད་པའི་དམིགས་པའི་ཆོས་དག་ཀྱང་ཡོད། ལུང་དུ་མ་བསྟན་པ་ཡིད་ལ་བྱེད་པའི་དམིགས་པའི་ཆོས་དག་ཀྱང་ཡོད། ཁམས་སུ་གཏོགས་པའི་ཡིད་ལ་བྱེད་པའི་དམིགས་པའི་ཆོས་དག་ཀྱང་ཡོད། རྣལ་འབྱོར་དང་ལྡན་པའི་ཡིད་ལ་བྱེད་པའི་དམིགས་པའི་ཆོས་དག་ཀྱང་ཡོད་དོ། །
Enumeration Block 7:
རྣལ་འབྱོར་དང་ལྡན་པའི་ཡིད་ལ་བྱེད་པའི་དམིགས་པ་ནི་མདོར་བསྡུ་ན་རྣམ་པ་བཞི་སྟེ། ཁྱབ་པའི་དམིགས་པ་དང་། སྤྱོད་པ༌[^49]རྣམ་པར་སྦྱོང་བའི་དམིགས་པ་དང་། མཁས་པའི་དམིགས་པ་དང་། ཉོན་མོངས་པ་རྣམ་པར་སྦྱོང་བའི་དམིགས་པའོ། །
Enumeration Block 8:
གནས་པ་སྒྲུབ་པའི༌[^70]ཆོས་རྣམས་ཀྱི་རབ་ཏུ་དབྱེ་བ་ཡང་རྣམ་པ་ལྔས་རྣམ་པར་གཞག་སྟེ། ལྔ་གང་ཞེ་ན།
ཁམ་གྱི་ཟས་དང་། རེག་པའི་ཟས་དང་། ཡིད་ལ་སེམས་པའི་ཟས་དང་། རྣམ་པར་ཤེས་པའི་ཟས་དང་། སྲོག་གི་དབང་པོ་ནི༌[^71]ལྔ་པ་ཡིན་ནོ། །
Enumeration Block 9:
གང་གི་ཚེ་རྒྱུ་བདུན་གྱིས་འདུ་བྱེད་རྣམས་གནས་པར་འགྱུར་ཏེ། བདུན་གང་ཞེ་ན།
