Enumeration Block 1:
འདོད་པ་སྤྱོད་པ་དང་། བསོད་ནམས་སྤྱོད་པ་དང་། ཕན་ཚུན་གནས་པའི་སྤྱོད་པ་ལས་བརྩམས་ནས། རྗེས་སུ་ཆགས་པ་དང་། ཁོང་ཁྲོ་བའི་ཀུན་ནས་ཉོན་མོངས་པ་རྣམ་པ་དྲུག་དང་། གཞི་བཞི་དང་། གཉེན་པོ་རྣམ་པ་ལྔ་ཡོད་པར་རིག་པར་བྱ་སྟེ།
Enumeration Block 2:
རྣམ་གྲངས་གཞན་ཡང་རྗེས་སུ་ཆགས་པ་དང་། ཁོང་ཁྲོ་བའི་ཀུན་ནས་ཉོན་མོངས་པ་རྣམ་པ་དྲུག་དང་། གཉེན་པོ་རྣམ་པ་ལྔ་ཡོད་པར་རིག་པར་བྱ༌[^814]སྟེ།
Enumeration Block 3:
གང་ཟག་བཞིའི་རབ་ཏུ་འབྱུང་བ་ལ་ཡོན་ཏན་ལྔ་ཡོད་པར་རིག་པར་བྱ་སྟེ། གང་ཟག་བཞི་གང་ཞེ་ན། རང་དབང་ཅན་དང་། གཞན་གྱི་དབང་དུ་གྱུར་པ་དང་། ཡོངས་སུ་སྨིན་པ་དང་། ཡོངས་སུ་མ་སྨིན་པའོ། །
Enumeration Block 4:
ཟག་པ་དང་བཅས་པའི་འདུ་བྱེད་ཐམས་ཅད་ནི་སྡུག་བསྔལ་ཉིད་རྣམ་པ་གསུམ་གྱི་རྣམ་པ་དགུ་དང་། རྗེས་སུ་འབྲེལ་པར་རིག་པར་བྱ་སྟེ། སྡུག་བསྔལ་ཉིད་རྣམ་པ་གསུམ་གང་ཞེ་ན། སྡུག་བསྔལ་གྱི་སྡུག་བསྔལ་ཉིད་དང་། འདུ་བྱེད་ཀྱི་སྡུག་བསྔལ་ཉིད་དང་། འགྱུར་བའི་སྡུག་བསྔལ་ཉིད་དོ། །
Enumeration Block 5:
དགེ་སློང་འཁོར་གྱི་ནང་དུ་རྒྱུ་བ་ནི་ཡན་ལག་བཞི་དང་ལྡན་ན། འཁོར་ལ་ཡང་དག་པར་རྗེས་སུ་སྟོན་པ་དང་། འཁོར་ཡོངས་སུ་སྡུད་པར་འོས་པ་དང་། བདག་ལ་ཕན་པ་དང་། གཞན་ལ་ཕན་པའི་ཕྱིར་ཞུགས་པ་ཡིན་ཏེ། བཞི་གང་ཞེ་ན། ཉེ་བའི་ཉོན་མོངས་པས༌[^820]དབེན་པ་དང་། ཤེས་པས་མི་དབེན་པ་དང་། དགེ་བའི་ཆོས་སྐྱེས་པ་རྣམས་གནས་པ་དང་མི་བརྗེད་པ་དང་། བསྒོམ་པ་ཡོངས་སུ་རྫོགས་པར་བྱ་བ་དང་། ཕྱིར་ཞིང་འཕེལ་བ་དང་། ཡངས་པར་བྱ་བའི་ཕྱིར་ཉེ་བར་རྟེན་པ༌[^821]ཉེ་བར་བསྒྲུབ་པ་དང་། དགེ་བའི་ཆོས་མ་སྐྱེས་པ་རྣམས་བསྐྱེད་པའི་ཕྱིར་ཉེ་བར་རྟེན༌[^822]པ་བསྒྲུབ་པའོ། །
Enumeration Block 6:
ཉེ་བའི་ཉོན་མོངས་པ་ནི་ལྔ་པོ་འདི་དག་ཡིན་ཏེ། ཁྱིམ་ན་འདུག་ན་ཆགས་པ་དང་། ཚུལ་ཁྲིམས་ཉམས་པ་དང་། སྔོན་ཉམས་སུ་མྱོང་བ་རྗེས་སུ་དྲན་པའི་ཀུན་དུ་རྟོག་པ་དང་ལྡན་པའི་ཚུལ་བཞིན་མ་ཡིན་པ་ཡིད་ལ་བྱེད་པ་དང་། མ་འོངས་པའི་ཡུལ་ལ་ཡོངས་སུ་འཆུམས་པའི་བརྣབ་སེམས་དང་། ཡིད་མི་བདེ་བ་དང་། ཆོས་ལ་སེར་སྣ་བྱེད་པའོ། །
Enumeration Block 7:
ཤེས་པ་ནི་བཞི་པོ་འདི་དག་ཡིན་ཏེ། བཞི་གང་ཞེ་ན། དང་པོར་ཉེ་བའི་ཉོན་མོངས་པ་ཅན་མ་ཡིན་པའི་སེམས་ཀྱི་རྒྱུད་ཀྱིས་འཕགས་པའི་ལམ་ཡན་ལག་བརྒྱད་པ་རྟོགས་པ་ལ༌[^843]བརྩམས་ནས་ཤེས་པ་དང་པོའོ། །འཕགས་པའི་ལམ་ཡན་ལག་བརྒྱད་པ་ཐོབ་པར་བྱ་ཞིང་གྲུབ་པར༌[^844]བྱ་བ་ལས་བརྩམས་ནས་ཤེས་པ་གཞན་གསུམ་མོ། །
