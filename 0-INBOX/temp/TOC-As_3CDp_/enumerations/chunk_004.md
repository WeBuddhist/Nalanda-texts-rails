Enumeration Block 1:
འབྱུང་བ་ཆེན་པོ་རྣམས་ནི་རྒྱུར་བྱས་པའི་གཟུགས་རྣམ་པ་གཉིས་སྐྱེད་པར་བྱེད་དེ། རང་གི་རིགས་ཀྱིས༌[^150]ཁྱད་པར་ཅན་དང་། གཞན་གྱི་རིགས་ཀྱིས་ཁྱད་པར་ཅན་ནོ། །
Enumeration Block 2:
བསྒོམ་པ་ནི་མདོར་བསྡུ་ན། རྣམ་པ་བཞིར་བལྟ་བར་བྱ་སྟེ། ཐོབ་པ༌[^158]བསྒོམ་པ་དང་། བསྟེན་པ་བསྒོམ་པ་དང་། སྤང་བ་བསྒོམ་པ་དང་། གཉེན་པོ་བསྒོམ་པའོ། །
Enumeration Block 3:
བསྒོམ་པ་རྣམ་པ་བཞི་པོ་དེ་དག་ཐམས་ཅད་བསྡུས་ནས་བསྒོམ་པ་རྣམ་པ་གཉིས་སུ་བལྟ་བར་བྱ་སྟེ། སྡོམ་པ་ཡང་དག་པར་བླང་བ་བསྒོམ་པ་དང་། ཡིད་ལ་བྱེད་པ་བསྒོམ་པའོ། །
Enumeration Block 4:
འདས་པའི་ཆོས་དེ་དག་གི་དངོས་པོ་རབ་ཏུ་དབྱེ་བ་ཡང་མདོར་བསྡུ་ན། རྣམ་པ་ལྔས་རྣམ་པར་གཞག་པར་བལྟ་བར་བྱ་སྟེ། ལྔ་གང་ཞེ་ན།
Enumeration Block 5:
དེ་དག་གི་རབ་ཏུ་དབྱེ་བ་ཡང་རྣམ་པ་ལྔས་རྣམ་པར་གཞག་པར་བལྟ་བར་བྱ་སྟེ། སྐད་ཅིག་མ་འོངས་པ་རྣམས་དང་། སྐྱེ་བ་མ་འོངས་པ་རྣམས་དང་། འཆགས་པ་མ་འོངས་པ་རྣམས་དང་། ཀུན་དུ་སྤྱོད་པ་མ་འོངས་པ་རྣམས་དང་། འཐོབ་པ༌[^175]མ་འོངས་པ་རྣམས་སོ།[^176] །
Enumeration Block 6:
དེ་དག་གི་རབ་ཏུ་དབྱེ་བ་ཡང་རྣམ་པ་ལྔས་རྣམ་པར་གཞག་པར་བལྟ་བར་བྱ་སྟེ། སྐད་ཅིག་ད་ལྟར་བྱུང་བ་རྣམས་དང་། སྐྱེ་བ༌[^177]ད་ལྟར་འབྱུང་བ༌[^178]རྣམས་དང་། འཆགས་པ་ད་ལྟར་འབྱུང་བ༌[^179]རྣམས་དང་། ཀུན་དུ་སྤྱོད་པ་ད་ལྟར་འབྱུང་བ༌[^180]རྣམས་དང་། ཐ་མ་ད་ལྟར་འབྱུང་བ༌[^181]རྣམས་ཏེ།
Enumeration Block 7:
དགེ་བ་དེའི་རབ་ཏུ་དབྱེ་བ་ཡང་རྣམ་པ་ལྔས་རྣམ་པར་གཞག་པར་རིག་པར་བྱ་སྟེ།
Enumeration Block 8:
མི་དགེ་བའི་ཆོས་རྣམས་ཀྱི་རབ་ཏུ་དབྱེ་བ་ཡང་དེ་ལས་བཟློག་པ་རྣམ་པ་ལྔ་ཁོ་ནས་རྣམ་པར་བཞག་པར་རིག་པར་བྱ་སྟེ། ཕྱི་མ་ལ་འབྲས་བུ་མི་འདོད་པ་དང་། ཀུན་ནས་ཉོན་མོངས་པའི་གཉེན་པོའི་མི་མཐུན་པའི༌[^191]ཕྱོགས་དང་། ཀུན་ནས་ཉོན་མོངས་པ་ཉེ་བར་མ་ཞི་བས་རབ་ཏུ་ཕྱེ་བ་དང་། ཉོན་མོངས་པ་ཅན་གྱི་གནས་པས་རབ་ཏུ་ཕྱེ་བ་དང་། གཞན་ལ་གནོད་པས་རབ་ཏུ་དབྱེ་བས་སོ། །
Enumeration Block 9:
དགེ་བའི་རྒྱུ་ལྔས་སྟོབས་དང་ལྡན་པ་ཡིན་ཏེ། ལྔ་གང་ཞེ་ན།
སྦྱོར་བ་དང་། སྔོན་གོམས་པ་དང་། ཡོན་ཏན་ཁྱད་པར་ཅན་ཡོངས་སུ་འཛིན་པ་དང་། ཞིང་དང་། དངོས་པོ་དང་། གནས་དང་། ངོ་བོ་ཉིད་ཀྱིས་སོ། །
Enumeration Block 10:
ཆོས་ལུང་དུ་མ་བསྟན་པ་རྣམས་ཀྱི་རབ་ཏུ་དབྱེ་བ་ཡང་རྣམ་པ་ལྔས་རྣམ་པར་གཞག་སྟེ། ལྔ་གང་ཞེ་ན།
རྣམ་པར་སྨིན་པ༌[^209]ལས་སྐྱེས་པ་དང་། སྤྱོད་ལམ་ལས་བྱུང་བ་དང་། བཟོའི་གནས་ལས་བྱུང་བ་དང་། སྤྲུལ་པ་ལས་བྱུང་བ་དང་། ངོ་བོ་ཉིད་ལས་བྱུང་བས་སོ། །
