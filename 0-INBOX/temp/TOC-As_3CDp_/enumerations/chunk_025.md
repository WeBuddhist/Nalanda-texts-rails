Enumeration Block 2:
དེ་ལ་ཞི་བ་ཡང་རྣམ་པ་གསུམ་སྟེ། སྤྱོད་ལམ་ཞི་བ་དང་། སྒྲ་ཞི་བ་དང་། སེམས་ཞི་བའོ། །
Enumeration Block 3:
དུས་ལྔར༌[^987]ཏེ།
Enumeration Block 4:
བདག་གི་དད་པ་ནས་རིགས་ཀྱི་བུ་ཉིད་ཇི་ཙམ་པ་ནི་རྒྱུ་གསུམ་གྱིས་རིག་པར་བྱ་སྟེ། གནས་དང་ངོ་བོ་ཉིད་དང་དུས་ཀྱིས་སོ། །
Enumeration Block 5:
སེམས་བསྐྱེད་པ༌[^1020]ནི་རྣམ་པ་བཅུ་སྟེ། འདི་ལྟ་སྟེ་ཡང་དག་པར་བླང་བ་བརྡ་ལས་བྱུང་བ་དང་། ཆོས་ཉིད་ཀྱིས་ཐོབ་པ་དང་། མ་ངེས་པ་དང་། ངེས་པ་དང་། ཡོངས་སུ་མ་དག་པ་དང་། ཡོངས་སུ་དག་པ་དང་། སྟོབས་ཆུང་བ་དང་། སྟོབས་དང་ལྡན་པ་དང་འབྲས་བུ་ཡོངས་སུ་མ་གྲུབ་པ་དང་། འབྲས་བུ་ཡོངས་སུ་གྲུབ་པའོ། །
Enumeration Block 6:
བྱང་ཆུབ་སེམས་དཔའ༌[^1038]བདག་གི་དོན་དང་གཞན་གྱི་དོན་ལས་བརྩམས་ནས་བསྒྲུབ་པ༌[^1039]ནི་དགུ་པོ་འདི་དག་ཡིན་ཏེ། འཁོར་བ་ལ༌[^1040]སྒྲུབ་པ་དང་། སེམས་ཅན་རྣམས་ལ་སྒྲུབ་པ་དང་། བདག་ཉིད་ལ་སྒྲུབ་པ་དང་། འདོད་པ་རྣམས་ལ་སྒྲུབ་པ༌[^1041]དང་། ལུས་དང་ངག་དང་ཡིད་ཀྱི་ལས་ལ་སྒྲུབ་པ༌[^1042]དང་། སེམས་ཅན་རྣམས༌[^1043]ལ་ཐོ་མི་འཚམས་པར༌[^1044]སྒྲུབ་པ༌[^1045]དང་། དགེ་བའི་ཆོས་རྣམས་རྟག་ཏུ་སྒོམ་པ༌[^1046]ལ་སྒྲུབ་པ་དང་། ནང༌[^1047]གི་སེམས་ཀྱི་ཞི་གནས་ལ་སྒྲུབ་པ༌[^1048]དང་། ལྷག་པའི་ཤེས་རབ་ཆོས་རྣམ་པར་མཐོང་བ་ལ་སྒྲུབ་པའོ། །
