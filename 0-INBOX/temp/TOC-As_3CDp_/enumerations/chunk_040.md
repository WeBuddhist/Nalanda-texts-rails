Enumeration Block 1:
བྱང་ཆུབ་ནི་རྣམ་པ་ལྔ་པོ་ངོ་བོ་ཉིད་དང་། མཐུ་དང་། ཐབས་དང་། འཇུག་པ་དང་། ལྡོག་པ་ལས་རིག་པར་བྱའོ
Enumeration Block 2:
དེ་ཡང་རྣམ་པ་བཞིས་རིག་པར་བྱ་སྟེ། འཇུག་པའི་གནས་དང་། མི་འཇུག་པའི་གནས་དང་། ཤེས་བྱ་ལེགས་པར་ཡོངས་སུ་བརྟགས་པའི་འབྲས་བུ་དང་། ཆོས་ཀྱི་དབྱིངས་རྣམ་པར་དག་པའི་མཚན་ཉིད་ཀྱིས་སོ། །
Enumeration Block 3:
བསམ་གྱིས་མི་ཁྱབ་པ་དེ་ཡང་རྣམ་པ་ལྔས་རིག་པར་བྱ་སྟེ། ངོ་བོ་ཉིད་དང་། ཡུལ་དང་། གནས་པ་དང་། གཅིག་པ་ཉིད་དང་། ཐ་དད་པ་ཉིད་དང་། བྱ་བ་བསྒྲུབ་པས་སོ། །
Enumeration Block 4:
དེ་ཡང་རྣམ་པ་གཉིས་སུ་བལྟ་བར་བྱ་སྟེ། དེའི་མོད་ལ་འཇུག་པ་དང་། དེ་གཏན་དུ་འཇུག་པའོ། །
Enumeration Block 5:
དེ་ཡང་རྣམ་པ་གཉིས་སུ་བལྟ་བར་བྱ་སྟེ། དེའི་མོད་ལ་ལྡོག་པ་དང་། དེ་གཏན་ལྡོག་པའོ། །
Enumeration Block 6:
དེ་བཞིན་གཤེགས་པའི་ཡོན་ཏན་ནི་རྣམ་པ་དྲུག་གིས་བསྡུས་པར་རིག་པར་བྱ་སྟེ། མཐའ་དག་དང་། དྲི་མ་མེད་པ་དག་དང་། མི་གཡོ་བ་དང་། མི་མཉམ་པ་དང་། སེམས་ཅན་གྱི་དོན་གྱི་ལས་ཅན་དང་། མཐུས་སོ། །
Enumeration Block 7:
དེ་བཞིན་གཤེགས་པ་རྣམས༌[^1477]ནི་སྐྱབས་ཀྱི་འོས་ཡིན་ལ། ལྷ་རྣམས་སྐྱབས་ཀྱི་འོས་མ་ཡིན་པ་ནི་རྒྱུ་ལྔས་རིག་པར་བྱ་བ༌[^1478]སྟེ། ལྔ་གང་ཞེ་ན། རྟགས་དང་། ངོ་བོ་ཉིད་དང་། ལས་དང་། ཆོས་དང་། རྒྱུ་དང་འབྲས་བུས་སོ། །
