Enumeration Block 1:
བྱང་ཆུབ་སེམས་དཔའི་དྲན་པ་བརྗེད་པར་འགྱུར་བའི་ཆོས་ཀྱང་བཞི་སྟེ། བཞི་གང་ཞེ་ན།
གང་ཟག་བཞི་ལ་གནས་བཞིས་རྣམ་པར་རྨོངས་པར་བྱེད་པ་སྟེ། གླེང་བ་པོ་རྣམས་དང་། ལུང་འབོགས་པ་རྣམས་དང་། ཕན་པར་འདོད་པ་རྣམས་དང་། ཡོན་ཏན་དང་ལྡན་པ་རྣམས་ལ་བདག་ཉིད་ཀྱི༌[^2494]འགལ་བར་རྣམ་པར་རྨོངས་པར་བྱེད་པ་དང་། ཚངས་པ་མཚུངས་པར་སྤྱོད་པ་བསླབ་པ་ལ་ལེགས་པར་གནས་པ་རྣམས་ལ་བསླབ་པ་ལ་བཞིས་རྣམ་པར་རྨོངས་པར་བྱེད་པ་དང་། ཐེག་པ་ཆེན་པོ་ལ་མོས་པར་འདོད་པ་དང་། སྒྲུབ་པར་འདོད་པ་རྣམས་ལ། མ་བརྗོད་པ་དང་། བརྗོད་པ་དང་། རྣམ་པར་བྱང་བའི༌[^2495]སྐྱོན་ཡོངས་སུ་སྟོན་པས་དེ་ལ་མོས་པ་དང་། སྒྲུབ་པ་རྣམ་པར་རྨོངས་པར་བྱེད་པ་དང་། ཆོས་སྨྲ་བའི་གང་ཟག་རྣམས་ལ་གསང་བའི་གནས་རྣམ་པར་དབྱེ་བའི་ཕྱིར་རྣམ་པར༌[^2496]རྨོངས་པར་བྱེད་པའོ། །
Enumeration Block 2:
བྱང་ཆུབ་སེམས་དཔའི་དཀར་པོའི་ཆོས་ཡོངས་སུ་གཏུགས་པར་འགྱུར་བའི་ཆོས་ཀྱང་བཞི་སྟེ། གཞན་ལ་སྟོན༌[^2497]པའི་དབང་དུ་བྱས་ནས། དཀར་པོའི་ཆོས་རྣམས་ཀྱི་གནས་མ་ཡིན་པ་ལ་སྦྱོར་བ་དང་། དཀར་པོའི་ཆོས་རྣམས་ཀྱི་གནས་མ་ཡིན་པ་ལ་སྦྱོར་བ་ལ་ལོག་པར་སྒྲུབ་པའི་ཉེས་པ་རྣམ་པ་གསུམ་སྟེ། ཟང་ཟིང་གི་ཉེས་པ་དང་། ལྟ་བའི་ཉེས་པ་དང་། སྟོན་པའི་ཉེས་པའོ། །
Enumeration Block 3:
བྱང་ཆུབ་སེམས་དཔའ༌[^2498]བྱང་ཆུབ་སེམས་དཔའི་ཆ་མ་ཡིན་པ༌[^2499]མི་མཐུན་པར་ཡིད་ཀྱིས་ཀུན་ཏུ་སྤྱོད་པ་ཡང་བཞི་པོ་འདི་དག་ཡིན་ཏེ། སྟོན་པ་ལ་ཡིད་མི་ཆེས་པར་གྱུར༌[^2500]ཅིང་། བསླབ་པ་ལ་གུས་པ་དང་མི་མཐུན་པ་དང་། ཚངས་པ་མཚུངས་པར་སྤྱོད་པ་གྲོགས་རྣམས་དང་། གླེང་བ་པོ་རྣམས་དང་། རྗེས་སུ་སྟོན་པ་རྣམས་ལ་བདག་ཉིད་ཇི་ལྟར་གྱུར་པ་བརྗོད་པ་དང་། མི་མཐུན་པ་དང་། ཤེས་པ་བསོད་ནམས་ཆེན་པོ་རྣམས་ལ་དགེ་བའི་བརྩོན་འགྲུས་རྩོམ་པ་དང་མི་མཐུན་པ་དང་ཟབ་ཅིང་རྒྱ་ཆེ་བ་ལ་མོས་པ་རྣམས་དང་། བདག་ཉིད་ཀྱི་སྒྲིབ་པ་རྣམ་པར་དག་པ་དང་མི་མཐུན་པའོ། །
Enumeration Block 4:
བྱང་ཆུབ་སེམས་དཔའི་གདུལ་དཀའ་བར་འགྱུར་བའི་ཆོས་ཀྱང་བཞི་སྟེ།[^2503] འདི་ལྟ་སྟེ་བསྒོམ་པའི་སྒྲིབ་པ་བཞི་པོ་དག་སྟེ། ཐོས་པ་ལྷུར་ལེན་པ་དང་། གདམས་ངག་ལ་ལོག་པར་འཛིན་པ་དང་། ཚུལ་ཁྲིམས་དག༌[^2504]ལ་གནས་པར་མི་བྱེད་པས་འགྱོད་པ་དང་། རང་གི་ལྟ་བ་མཆོག་ཏུ་འཛིན་ཅིང་གནས་པའོ། །
Enumeration Block 5:
བྱང་ཆུབ་སེམས་དཔའི་སེམས་ཅན་རྣམས་ལ་ལམ་ངན་པར་འགྲོ་བ་ཡང་བཞི་པོ་འདི་དག་ཡིན་ཏེ། སེམས་ཅན་དད་པས་ཞུགས་པ་མ་ཡིན་པ་རྣམས་ལ་སྟོན་པ་དང་། སེམས་ཅན་ཐེག་པ་དམན་པ་ཐེག་པ་ཆེན་པོ་འདོད་པ་རྣམས་ལ་མི་འཚམ་པ༌[^2506]སྟོན་པ་དང་། སེམས་ཅན་ཐེག་པ་ཆེན་པོ་ཐེག་པ༌[^2507]དམན་པ་འདོད་པ་རྣམས་ལ་མི་མཐུན་པ་སྟོན་པ་དང་། སེམས་ཅན་ཚུལ་ཁྲིམས་ལ་གནས་པ་དང་ཚུལ་ཁྲིམས་ལ་མི་གནས་པ་རྣམས་ལ་ཕྱོགས་ཀྱི་འདོད་ཆགས་ཀྱིས་མི་འདྲ་བར་སྟོན་པའོ། །
Enumeration Block 6:
བྱང་ཆུབ་སེམས་དཔའ་དམ་པ་མ་ཡིན་པ་དང་འགྲོགས་པ་ལ་བརྟེན་ན་རྣམ་པ་བཞི་ཡོངས་སུ་ཉམས་པར་འགྱུར་ཏེ། ཐེག་པ་ཡོངས་སུ་ཉམས་པ་དང་། སེམས་ཅན་གྱི་དོན་གྱི་སྦྱོར་བ་ཡོངས་སུ་ཉམས་པ་དང་། [^2511]བསྟན་པ་ཡོངས་སུ་ཉམས་པ་དང་། དགེ་བའི་ཆོས་རྣམས་ལ༌[^2512]རྟག་ཏུ་སྒོམ་པ་ཡོངས་སུ་ཉམས་པའོ། །
Enumeration Block 7:
ཡང་དག་པའི་སྒྲུབ་པ་ནི་དེ་ལས་བཟློག་པ་སྟེ། སྐྱོན་ཁྱད་པར་ཅན་ཡོངས་སུ་སྤངས་པ་དང་། གཉེན་པོ་བསྟན་པས་གོང་ནས་གོང་དུ་བསྒྲུབས་པས༌[^2519]རྣམ་པ་བརྒྱད་ཀྱིས་རིག་པར་བྱའོ། །
