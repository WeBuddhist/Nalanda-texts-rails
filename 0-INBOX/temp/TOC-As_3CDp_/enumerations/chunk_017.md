Enumeration Block 1:

Enumeration Block 3:

Enumeration Block 5:
མངོན་པར་འབྱུང་བའི་ས་ནི་མངོན་པར་འབྱུང་བ་རྣམ་པ་དྲུག་གི་དབང་དུ་བྱས་ནས། རྣམ་པར་གཞག་པར་རིག་པར་བྱའོ། །
མི་མཐུན་པ་ལས་མངོན་པར་འབྱུང་བ་དང་། མེད་པ་ལས་མངོན་པར་འབྱུང་བ་དང་། ཁྱིམ་ནས་མངོན་པར་འབྱུང་བ་དང་། མ་རྫོགས་པ་ལས༌[^711]མངོན་པར་འབྱུང་བ་དང་། ས་འོག་མ་པ་ལས་མངོན་པར་འབྱུང་བ་དང་། འཇིག་ཚོགས་ལས་མངོན་པར༌[^712]འབྱུང་བའོ། །

Enumeration Block 10:
ཏིང་ངེ་འཛིན་ཐོབ་པར་བྱ་བ་ལ་བརྩོན་པས་ཆོས་བདུན་རིག་པར་བྱ་སྟེ། ནང་གི་ཏིང་ངེ་འཛིན་ཉམས་པའི་རྒྱུ་དང་། ཕྱི་རོལ་གྱི་ཏིང་ངེ་འཛིན་ཉམས་པའི་རྒྱུ་དང་། ནང་གི་ཏིང་ངེ་འཛིན་ཉམས་པ་དང་། ཕྱི་རོལ་གྱི་ཏིང་ངེ་འཛིན་ཉམས་པ་དང་། ནང་གི་ཏིང་ངེ་འཛིན་རྒྱུ་དང་བཅས་པ་ཉམས་པའི་གཉེན་པོ་དང་། ཕྱི་རོལ་གྱི་ཏིང་ངེ་འཛིན་རྒྱུ་དང་བཅས་པ་ཉམས་པའི་གཉེན་པོ་དང་། དེ་གཉི་གའི༌[^744]གཉེན་པོའི་གཞིའོ།[^745] །
