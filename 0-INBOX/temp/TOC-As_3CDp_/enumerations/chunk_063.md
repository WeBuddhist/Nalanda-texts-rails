Enumeration Block 1:
རྣམ་པར་གནོན་པའི་གཉེན་པོ་དེ་ལ་གནས་གསུམ་ལ་མཁས་པ། རྟེན་ཅིང་འབྲེལ་པར་འབྱུང་བ་ལ་མཁས་པ་དང་། གང་ཟག་ལ་བདག་མེད་པར་མོས་པ་དང་། ཆོས་ལ་བདག་མེད་པར་མོས་པའི་ཀུན་ནས་ཉོན་མོངས་པ་མ་ལུས་པ་ལས་ཡང་དག་པར་འདའ་བར་བྱ་བའི་ཕྱིར་མི་ཤེས་པ་རྣམ་པ་བཞིའོ།[^2624] །
Enumeration Block 2:
དེ་ལ་སེམས་ཀྱི་སྤྱིའི་མཚན་ཉིད་ནི་རྣམ་པ་གསུམ་གྱིས་རིག་པར་བྱ་སྟེ། རྟེན་ཅིང་འབྲེལ་བར་འབྱུང་བ་ལྐོག་ན་གཡོ་བ་མེད་པ་ཉིད་དང་། དེ་ལྟར་གྱི་སྐད་ཅིག་པ་གཡོ་བ་མེད་པ་ཉིད་དང་། འདོད་ཆགས་ལ་སོགས་པ་རྐྱེན་ལས་བྱུང་བའི་སེམས་ཀྱིས་མ་བྱས་པ་ཉིད་ཀྱིས་སོ། །
སེམས་ཀྱི་རང་གི་མཚན་ཉིད་ཀྱང་རྣམ་པ་གསུམ་གྱིས་རིག་པར་བྱ་སྟེ། སྔ་མ་བཞིན་དུ་ཐ་སྙད་ལས་བྱུང་བའི་ངོ་བོ་ཉིད་ཀྱིས་མི་དམིགས་པ་དང་། སྔ་མ་བཞིན་དུ་རྣམ་པ་དྲུག་གིས་དེ་བཞིན་ཉིད་མི་དམིགས་པ་དང་། འཕགས་པ་ཐམས་ཅད་ཀྱི་བྱེ་བྲག་མེད་པའི་ཤེས་པ་མི༌[^2625]དམིགས་པས་སོ། །
Enumeration Block 3:
སེམས་ཀྱི་ཀུན་ནས་ཉོན་མོངས་པའི་མཚན་ཉིད་ཀྱང་རྣམ་པ་གསུམ་གྱིས་རིག་པར་བྱ་སྟེ། འགྲུབ་པ་དང་། འཇུག་པ་དང་། རྒྱུ་བས་ཏེ།
Enumeration Block 4:
སེམས་ཀྱི་རྣམ་པར་བྱང་བའི་མཚན་ཉིད་ཀྱང་རྣམ་པ་གསུམ་གྱིས་རིག་པར་བྱ་སྟེ། མི་རྟོགས་པ༌[^2635]དང་རྟོགས་པའི་མཚན་ཉིད་དང་། འདུས་མ་བྱས་ཀྱི་མཚན་ཉིད་དང་། རིགས་ཀྱི་མཚན་ཉིད་ཀྱིས་ཏེ།
Enumeration Block 5:
འདུས་མ་བྱས་ཀྱི་མཚན་ཉིད་དེ་ནི་རྣམ་པ་དགུས་བལྟ་བར་བྱ་སྟེ། དུས་རྣམས་སུ་རྒྱུ་བ་མེད་པ་དང་། ཇི་ལྟར་འགོག་པའི་སྙོམས་པར་འཇུག་པ་ལ་ཐ་སྙད་ལས་བྱུང་བའི་ངོ་བོ་ཉིད་ཀྱིས་དམིགས་སུ་མེད༌[^2636]ལ་དེ་བཞིན་ཉིད་ཀྱི་མཚན་ཉིད་ཀྱིས་དམིགས་སུ་ཡོད་པ་ལྟ་བུ་མ་ཡིན་པའི་ཕྱིར། གཉིས་སུ་མེད་པའི་མཚན་ཉིད་དང་། སྐྱེ་བ་མེད་པའི་མཚན་ཉིད་དང་། སྐྱེ་བའི་རྒྱུའི༌[^2637]ངོ་བོ་ཉིད་ལས་ཡང་དག་པར་འདས་པའི་མཚན་ཉིད་དང་། ཕྱི་མར་སྐྱེ་བ་ལས་ཡང་དག་པར་འདས་པ་དང་། འཆི་འཕོ་བ་ལས་ཡང་དག་པར་འདས་པ་དང་། སྐད་ཅིག་གཅིག་ནས་གཅིག་ཏུ་འབྲལ་བ་ལས་ཡང་དག་པར་འདས་པ་དང་། འགྲོ་བ་འགྱུར་བ་ལས་ཡང་དག་པར་འདས་པ་དང་། ལས་ཀྱིས༌[^2638]ཀུན་ནས་ཉོན་མོངས་པའི་འདུ་བྱེད་ལས་ཡང་དག་པར་འདས་པ་ཉིད་ཀྱིས་སོ། །
Enumeration Block 6:
རིགས་ཀྱི་མཚན་ཉིད་དེ་ཡང་གནས་སྐབས་བཞིར་རྣམ་པ་དགུར་རིག་པར་བྱ་སྟེ། རྣམ་པར་མ་དག་པའི་གནས་སྐབས་དང་། རྣམ་པར་དག་པའི་གནས་སྐབས་དང་། སོ་སོར་རྟོགས་པའི་གནས་སྐབས་དང་། ཡོངས་སུ་གཏུགས་པའི་གནས་སྐབས་སོ། །
Enumeration Block 7:
དེ་ལ་ལྟུང་བ་ཀུན་ནས་སློང་བར་བྱེད་པ་བརྣབ་སེམས་དང་ཡིད་མི་བདེ་བ་ནི་ཇི་ལྟར་སེལ་བར་མི་བྱེད་པ་དང་། ཇི་ལྟར་མ་བསྩལ་བ༌[^2645]དང་། ཇི་ལྟར་སེལ་བར་བྱེད་པ་དང་། ཇི་ལྟར་བསྩལ་བའི༌[^2646]རྣམ་པ་དེ་བཞིས་རིག་པར་བྱ་སྟེ།
Enumeration Block 8:
དེ་དག་ནི་རྣམ་པ་གསུམ་དུ་རིག་པར་བྱ་སྟེ། དགེ་སྦྱོང་གི་ཚུལ་ལ་མི་ལྟ་ཞིང་ཆ་ལུགས་དང་རྟགས་མཐུན་པ། ཆོ་ག་དང་། འཚོ་བ་དང་། ལོངས་སྤྱོད་དང་། བརྩོན་པ་དང་། ཚུལ་ཁྲིམས་དང་། ལྟ་བ་དང་། བསམ་པ་མི་མཐུན་པ་དང་། ཡོ་བྱད་ལ་ཡོངས་སུ་གཞོལ་བ་དང་། [^2652]ལྷག་པའི་ཚུལ་ཁྲིམས་དང་རྟགས་མཐུན་པ། [^2653]ལྷག་པའི་སེམས་དང་རྟགས་མཐུན་པ། [^2654]ལྷག་པའི་ཤེས་རབ་དང་རྟགས་མཐུན་པ༌[^2655]ལ། དེ་དག་བསྒྲུབ་པའི་བསམ་པ་དང་མི་མཐུན་པ་དང་། སྒྲ་ལ་ཡོངས་སུ་གཞོལ་བ། ཞི་གནས་ཀྱི་ཡན་ལག་དང་མཐུན། ལྷག་མཐོང་གི་ཡན་ལག་དང་མཐུན། དེ་གཉི་ག་བསྒོམ་པའི་ཡན་ལག་དང་མཐུན། དེ་གཉི་གའི་ཚོགས་ཀྱི་ཡན་ལག་དང་མཐུན། དེ་ལ༌[^2656]དེ་དག་གི་བསམ་པ་དང་མི་མཐུན་པའོ། །
Enumeration Block 9:
དེ་ནི་རྣམ་པ་བཞིར༌[^2657]རིག་པར་བྱ་སྟེ། སྦྱོར་བ་དང་། བསམ་པ་དང་། རྟོགས་པ་དང་། མཐར་ཐུག་པར་འགྲོ་བས་སོ། །
Enumeration Block 10:
དེ་ལ་ལེགས་པར་མ་བསླབས་པའི་དགེ་སྦྱོང་ནི་རྣམ་པ་གསུམ་གྱིས་ན་མིང་དོན་ཇི་ལྟ་བ་བཞིན་དུ༌[^2660]མ་ཡིན་པར་རིག་པར་བྱ་སྟེ། བསམ་པ་རྒུད་ལ་སྦྱོར་བ་ཕུན་སུམ་ཚོགས་པ་དང་། བསམ་པ་ཕུན་སུམ་ཚོགས་ལ་སྦྱོར་བ་རྒུད་པ་དང་། བསམ་པ་ཡང་རྒུད་ལ་སྦྱོར་བ་ཡང་རྒུད་པས་སོ། །
དེ་ལ་བསམ་པ་རྒུད་ལ་སྦྱོར་བ་ཕུན་སུམ་ཚོགས་པ་ནི་རྣམ་པ་གསུམ་སྟེ། ཉན་པ་དེ་ཙམ་གྱིས་ཆོག་པར་འཛིན་པ་དང་། སྨྲ་བ་དེ་ཙམ་གྱིས་ཆོག་པར་འཛིན་པ་དང་། འཇིག་རྟེན་པའི་ཏིང་ངེ་འཛིན་རྟོགས་པར་བྱེད་པ་དེ༌[^2661]རོ་མྱང་བ་ཙམ་གྱིས་ཆོག་པར་འཛིན་པའོ། །
Enumeration Block 11:
དེ་དག་ནི་རྣམ་པ་བཞིར་རིག་པར་བྱ་སྟེ། ཚུལ་ཁྲིམས་ཡན་ལག་དྲུག་དང་ལྡན་པའི་ཚུལ་ཁྲིམས་ཉམས་པ་གཉིས་པོ་འཇིག༌[^2663]ཚོགས་ལ་ལྟ་བས་ཀུན་ནས་དཀྲིས་པས་ལྟུང་བ་འབྱུང་བ་དང་། དེ་ལས་བསླབ་པ༌[^2664]ལ་མི་མཁས་པས་ཉམས་པ་དང་། ཉེས་པ་དེ༌[^2665]གཉི་ག་སྤངས་སུ་ཟིན་ཀྱང་འཇིག་རྟེན་པའི་རྣམ་པར་དག་པ་མ་ཐོབ་པའི་ཕྱིར་འཇིག་ཚོགས་ལ་ལྟ་བ་རྣམ་པར་བསྩལ་བ༌[^2666]དང་། འཇིག་རྟེན་པའི་རྣམ་པར་དག་པའི་སྡོམ་པ་ཐོབ་ཅིང་འཇིག་ཚོགས་ལ་ལྟ་བ་རྣམ་པར་བསྩལ༌[^2667]དུ་ཟིན་ཀྱང་ཡོ་བྱད་མ་བསྙུངས་ཤིང་ཆོས་བདག་མེད་པས་སྐྲག་པས་ཚུལ་ཁྲིམས་ཉམས་པ་དང་། སྐྱོན་གཞན་ཐམས་ཅད་སྤངས་སུ་ཟིན་ཀྱང་ཆོས་བདག་མེད་པ་ལ་ལོག་པར་མོས་པས་ཚུལ་ཁྲིམས་ཉམས་པའོ། །
