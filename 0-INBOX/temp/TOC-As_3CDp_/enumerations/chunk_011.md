Enumeration Block 1:
དེ་ལ༌[^434]ལྟུང་བ་ལས་བསླང་བ་ནི་རྣམ་པ་ལྔས་རིག་པར་བྱ་སྟེ། འདི་ལྟ་སྟེ། བདག་ལས་དང་། གཞན་ལས་དང་། བདག་དང་གཞན་ལས་དང་། ལུས་གྱུར་པ་ལས་དང་། ལུས་སྤངས་པ་ལས་སོ། །
Enumeration Block 2:
དགེ་སློང་འདུལ་བའི་བསླབ་པ་ལ་བརྩོན་པས་དུས་བཅུ་དག་ཏུ་བག་ཡོད་པར་བྱ་སྟེ། བཅུ་པོ་གང་དག་ཏུ་ཞེ་ན།
ལྟུང་བ་ལས་བརྩམས་པ་དང་། སྙོམས་པར་འཇུག་པ་ལས་བརྩམས་པ་དང་། སྐྱེ་བ་ལས་བརྩམས་པ་དང་། བསོད་སྙོམས་སྤྱོད་པ་ལས་བརྩམས་པ་དང་། འཕྲལ་གྱི་བྱ་བ་ལས་བརྩམས་པ་དང་། རྙེད་པ་དང་བཀུར་སྟིའི་ལོངས་སྤྱོད་ལས་བརྩམས་པ་དང་། ཐོས་པ་ཡོངས་སུ་ཚོལ་བ་ལས་བརྩམས་པ་དང་། དམ་པའི་ཆོས་བསམ་པ་ལས་བརྩམས་པ་དང་། རབ་ཏུ་དབེན་པ་ལས་བརྩམས་པ་དང་། རྟོགས་པའི་མཐའ་ལས་བརྩམས་པའི་དུས་སུའོ། །
Enumeration Block 3:
རབ་ཏུ་འབྱུང་བའི་སྒྲིབ་པ་ནི་བཞི་པོ་འདི་དག་ཡིན་པར་རིག་པར་བྱ་སྟེ། འདི་ལྟ་སྟེ། བསམ་པའི་སྒྲིབ་པ་དང་། ལུས་ཀྱི་སྒྲིབ་པ་དང་། ལས་ཀྱི་སྒྲིབ་པ་དང་། རང་དབང་མེད་པའི་སྒྲིབ་པའོ། །
Enumeration Block 4:
དེ་ལ་རབ་ཏུ་བྱུང་བས་འདུལ་བ་ལ་གནས་ལྔ་ངེས་པར་སློབ་ཏུ༌[^468]གཞུག་པར་བྱ་སྟེ། འདི་ལྟ་སྟེ། ལྟུང་བ་སློབ་ཏུ་གཞུག་པ་དང་། ལྟུང་བ་མེད་པ་དང་། ལྕི་བ་དང་། ཡང་བ་དང་། སོ་སོར་ཐར་པའི་མདོ་འདོན་པ་སློབ་ཏུ་གཞུག་པའོ། །
Enumeration Block 5:
དེ་ལ་ལྟུང་བ༌[^469]ལྕི་བ་ནི༌[^470]བྱེ་བྲག་དྲུག་གིས་འགྱུར་ཏེ།
Enumeration Block 6:
འདུལ་བ་འཛིན་པས་ལྟུང་བ་བྱུང་བ་ལ་རྣམ་པ་ལྔས་བརྟགས༌[^477]ནས། ལྟུང་བ་སྦྱིན་པར་བྱ་སྟེ། གཅིག་ཏུ་ཀུན་ནས་ཉོན་མོངས་པ་དང་། གཅིག་ཏུ་ལྷག་པར་མ་སྤྱད་པ་དང་། གཞི་ལས་བཅའ་བ་དང་། དེ་ལ་ཉེས་པ་བྱུང་བ་དང་མ་བྱུང་བ་བསྟན་པ་དང་། གཅིག་ཏུ་ཀུན་དུ་སྤྱོད་པ༌[^478]མ་ཡིན་པས་སོ། །
Enumeration Block 7:
དགེ་སློང་འདུལ་བའི་བསླབ་པ༌[^482]ལ་བརྩོན་པས་གནས་བདུན་ལ་བརྟེན་ནས། གནས་དྲུག་ལ་བརྩོན་པར་བྱ་སྟེ། གནས་བདུན་པོ་གང་དག་ལ་བརྟེན་ནས། གནས་དྲུག་པོ་གང་དག་ལ་བརྩོན་པར་བྱ་ཞེ་ན།
སྨྲས་པ། སྟོན་པ་ལ་བརྟེན་པ༌[^483]དང་། མཁན་པོ་དང་། སློབ་དཔོན་དང་། ཆོས་གོས་དང་། བསོད་སྙོམས་དང་། མལ་ཆ་དང་། སྟན་དང་། ན་བའི་གསོས་སྨན༌[^484]ཡོ་བྱད་ལ་བརྟེན་ནས། ཆོས་ལ་བརྩོན་པར་བྱ་བ་དང་། བསླབ་པ་དང་། གདམས་ཤིང་རྗེས་སུ་བསྟན་པ་དང་། ཏིང་ངེ་འཛིན་དང་། བགོ་བཤའ་དང་། བག་ཡོད་པ་ལ་བརྩོན་པར་བྱའོ། །
Enumeration Block 8:
འདུལ་བ་ལ་བླང་བ་ནི་ལྔ་པོ་འདི་དག་ཡིན་ཏེ། བདག་གིར་བྱ་བ་བླང་བ་དང་། བྱིན་ལེན་བླང་བ་དང་། གཏམས་པ༌[^486]བླང་བ་དང་དབུལ་བ་བླང་བ་དང་། གཞན་གྱི་ཕྱིར་བླང་བའོ། །
