Enumeration Block 1:
དེ་ལ་བག་ཡངས་བཅའ་བ་ཡང་གནས་ལྔས་ཟབ་པར་རིག་པར་བྱ་སྟེ། རྣམ་པར་དག་པ་དང་། དབྱེན་སྤང་བ་དང་། གང་ཟག་རླབས་པོ་ཆེ་དོན་ཆེན་པོ་དང་ལྡན་པ་གཞུག་པ་དང་། བསྟན་པ་འཕེལ་བར་བྱ་བ་དང་། དཀའ་བས་འཚོ་བ་སྤང་བས་སོ། །
Enumeration Block 2:
ལས་བཅའ་བ༌[^554]ནི་ལས་བཅུ་ལ་གང་ཟག༌[^555]ལྔས་ཟབ་པར་རིག་པར་བྱ་སྟེ། ལས་བཅུ་གང་ཞེ་ན།
བསྙེན་པར་རྫོགས་པའི་ལས་དང་། ས་ཚིགས་ཀྱི་ལས་དང་། གསོ་སྦྱོང་གི་ལས་དང་། གནང་བའི་ལས་དང་། གནས་པར་ཁས་བླང་བ༌[^556]དང་། དགག་དབྱེའི་ལས་དང་། ཆད་པའི་ལས་དང་། ཕན་གདགས་པའི་ལས་དང་། གསོལ་བ་དང་། གསོལ་བ་དང་གཉིས་ཀྱི་ལས་དང་། གསོལ་བ་དང་བཞིའི༌[^557]ལས་སོ། །
གང་ཟག་ལྔ་གང་ཞེ་ན།
གང་ཟག་ཅང་ཤེས་ལྟ་བུ་དང་། གང་ཟག་ནེ་ཙོ་ལྟ་བུ་དང་། གང་ཟག་སྐར་མདའ་ལྟ་བུ་དང་། གང་ཟག་གློག་ལྟ་བུ་དང་། གང་ཟག་རི་མོ་བྲི་བ་ལྟ་བུའོ། །
Enumeration Block 3:
འདུལ་བ་ལྷད་ཅན་གང་ཞེ་ན།
ལྷད་ཅན༌[^565]ནི་ལྔ་སྟེ། བསླབ་པའི་གཞི་བཅའ་བ་ལྷད་ཅན་དང་། ལྟུང་བ་བཅའ་བ་ལྷད་ཅན་དང་། ངེས་པར་འབྱུང་བ་བཅའ་བ་ལྷད་ཅན་དང་། བག་ཡངས་བཅའ་བ་ལྷད་ཅན་དང་། ལས་བཅའ་བ་ལྷད་ཅན་ནོ། །
Enumeration Block 4:
འདུལ་བ་ལ་ཆོས་དང་དོན་ཡོངས་སུ་བྱང་བར་བྱེད་པའི་དཔེའི་དངོས་པོ་ནི་ལྔ་པོ་འདི་དག་ཡིན་ཏེ། འདི་ལྟ་སྟེ། སྐྱེས་པའི་རབས་དང་། བྱུང་བ་དང་། འདྲ་བ་དང་། སྦྱར་བ་དང་། རྟོགས་པ་བརྗོད་པའོ། །
Enumeration Block 5:
ཤེས་བྱའི་ཆོས་རྣམས་ཀྱི་རབ་ཏུ་དབྱེ་བ་ནི་རྣམ་པ་ལྔས་རྣམ་པར་གཞག་སྟེ། ལྔ་གང་ཞེ་ན།
དངོས་པོ་དང་། རྣམ་པའི་ལས་ཀྱི༌[^581]རབ་ཏུ་དབྱེ་བ་དང་། ཤེས་པའི་རྟེན་དང་། ཤེས་པའི་རབ་ཏུ་དབྱེ་བ་དང་། དེ་ལས་གཞན་པའི་ཤེས་པ་བསྡུས་པས་སོ། །
Enumeration Block 6:
དེ་ཡང་རྣམ་པ་ལྔ་སྟེ། ཤེས་བྱ་རྣམ་པ་ལྔ་པོ་དེའི་ལས་ཀྱང་རྣམ་པ་ལྔར་བལྟ་བར་བྱའོ། །
ཤེས་བྱ་རྣམ་པ་ལྔ་གང་ཞེ་ན།
ཤེས་བྱ་ནི་བཏགས་པ་ལས་ཤེས་བྱ་ཡང་ཡོད་དོ། །
དོན་དམ་པ་ལས་ཤེས་བྱ་ཡང་ཡོད་དོ། །
བྱ་བའི་མཐའ་ལས་ཤེས་བྱ་ཡང་ཡོད་དོ། །
གཞན་དག་གི་སེམས་ཀྱི་རྒྱུ་བ༌[^582]དགེ་བ་དང་། མི་དགེ་བ་ལས་ཤེས་བྱ་ཡང་ཡོད་དོ། །
རྣམ་པ་ཐམས་ཅད་ལས་ཤེས་བྱ་ཡང་ཡོད་དོ། །
Enumeration Block 7:
དེ་ལ་ཤེས་པའི་རྟེན་ནི་རྣམ་པ་གཉིས་ཏེ། རང་ལ་ཕན་པ་བསྒྲུབ་པ་དང་། གཞན་ལ་ཕན་པ་བསྒྲུབ་པའོ། །
