Enumeration Block 1:
དགེ་སློང་འདུལ་བའི་བསླབ་པ༌[^482]ལ་བརྩོན་པས་གནས་བདུན་ལ་བརྟེན་ནས། གནས་དྲུག་ལ་བརྩོན་པར་བྱ་སྟེ། གནས་བདུན་པོ་གང་དག་ལ་བརྟེན་ནས། གནས་དྲུག་པོ་གང་དག་ལ་བརྩོན་པར་བྱ་ཞེ་ན།
སྨྲས་པ། སྟོན་པ་ལ་བརྟེན་པ༌[^483]དང་། མཁན་པོ་དང་། སློབ་དཔོན་དང་། ཆོས་གོས་དང་། བསོད་སྙོམས་དང་། མལ་ཆ་དང་། སྟན་དང་། ན་བའི་གསོས་སྨན༌[^484]ཡོ་བྱད་ལ་བརྟེན་ནས། ཆོས་ལ་བརྩོན་པར་བྱ་བ་དང་། བསླབ་པ་དང་། གདམས་ཤིང་རྗེས་སུ་བསྟན་པ་དང་། ཏིང་ངེ་འཛིན་དང་། བགོ་བཤའ་དང་། བག་ཡོད་པ་ལ་བརྩོན་པར་བྱའོ། །
Enumeration Block 2:
འདུལ་བ་ལ་བླང་བ་ནི་ལྔ་པོ་འདི་དག་ཡིན་ཏེ། བདག་གིར་བྱ་བ་བླང་བ་དང་། བྱིན་ལེན་བླང་བ་དང་། གཏམས་པ༌[^486]བླང་བ་དང་དབུལ་བ་བླང་བ་དང་། གཞན་གྱི་ཕྱིར་བླང་བའོ། །
Enumeration Block 3:
འདུལ་བ་ལ་དངོས་པོའི་ལོངས་སྤྱོད་ནི་རྒྱུ་ལྔས་རུང་བ་མ་ཡིན་ཏེ། རང་བཞིན་གྱིས༌[^493]ཁ་ན་མ་ཐོ་བ་དང་བཅས་པ་དང་། རྐྱེན་དུ་འབབ་པ་མ་ཡིན་པ་དང་། ལོངས་སྤྱོད་པར་འོས་པ་མ་ཡིན་པ་དང་། གཏོགས་པ་མ་ཡིན་པ་དང་། རུང་བ་མ་བྱས་པས་སོ། །
Enumeration Block 4:
འདུལ་བ་ནི་བཅའ་བ་ལྔས་ཟབ་པར་རིག་པར་བྱ་སྟེ། བཅའ་བ་ལྔ་གང་ཞེ་ན།
བསླབ་པ་བཅའ་བ་དང་། ལྟུང་བ་བཅའ་བ་དང་། ངེས་པར་འབྱུང་བ་བཅའ་བ་དང་། བག་ཡངས་བཅའ་བ་དང་། ལས་བཅའ་བས་སོ། །
དེ་ལ་བསླབ་པ་བཅའ་བ་ནི་གནས་ལྔས་ཟབ་པར་རིག་པར་བྱ་སྟེ། [^502]རང་དབང་ཡོད་པ་དང་། རང་དབང༌[^503]མེད་པ་དང་། ཚུལ་ཁྲིམས་ཉམས་པའི་ཉེས་པ་ཡང་དག་པར་བསྟན་པ་དང་། ལས་ངན་པ་ལ་མངོན་པར་དགའ་བའི་ཉེས་པ་ཡང་དག་པར་བསྟན་པ་དང་། དེ་གཉིས་ཀའི༌[^504]ཉེས་པ་ལྷག་པར་སྤྱད་པ་དང་ལྷག་པར་མ་སྤྱད་པས༌[^505]སོ། །
Enumeration Block 5:
དེ་ལ་ལྟུང་བ་བཅའ་བ་ཡང་གནས་ལྔས་ཟབ་པར་རིག་པར་བྱ་སྟེ།
Enumeration Block 6:
སྒྲིབ་པ་དེ་ཡང་རྣམ་པ་ལྔ་སྟེ། ལྷོད་པའི་སྒྲིབ་པ་དང་། ཁ་ན་མ་ཐོ་བའི་སྒྲིབ་པ་དང་། ཁྱད་དུ་གསོད་པའི་སྒྲིབ་པ་དང་། འགྱོད་པའི་སྒྲིབ་པ་དང་། ཤེས་བྱའི་སྒྲིབ་པའོ། །
Enumeration Block 7:
དེ་ལ་ངེས་པར་འབྱུང་བ་བཅས་པ་ཡང་གནས་ལྔས་ཟབ་པར་རིག་པར་བྱ་སྟེ། ཀུན་ནས་ཉོན་མོངས་པ་མེད་པས༌[^533]ངེས་པར་འབྱུང་བ་དང་། གནོད་པས་ངེས་པར་འབྱུང་བ་དང་། བར་ཆད་ཀྱིས་ངེས་པར་འབྱུང་བ་དང་། གཉེན་པོ་མེད་པས་ངེས་པར་འབྱུང་བ་དང་། བཤགས་པས་ངེས་པར་འབྱུང་བས་སོ། །
Enumeration Block 8:
དེ་ལ་བག་ཡངས་བཅའ་བ་ཡང་གནས་ལྔས་ཟབ་པར་རིག་པར་བྱ་སྟེ། རྣམ་པར་དག་པ་དང་། དབྱེན་སྤང་བ་དང་། གང་ཟག་རླབས་པོ་ཆེ་དོན་ཆེན་པོ་དང་ལྡན་པ་གཞུག་པ་དང་། བསྟན་པ་འཕེལ་བར་བྱ་བ་དང་། དཀའ་བས་འཚོ་བ་སྤང་བས་སོ། །
Enumeration Block 9:
