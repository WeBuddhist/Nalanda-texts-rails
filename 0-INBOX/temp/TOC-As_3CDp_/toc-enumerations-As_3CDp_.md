Enumeration Block 4:
དེ་ལ་ཤེས་པ་རྣམ་པར་དག་པ་རྣམ་པ༌[^1541]བཅུ་ནི་འདི་ལྟ་སྟེ། སྦྱིན་པ་ལ་བརྟེན་པའི་ཤེས་པ་རྣམ་པར་དག་པ་དང་། སློང༌[^1542]མོ་པ་ལ་བརྟེན་པའི་ཤེས་པ་རྣམ་པར་དག་པ་དང་། སྦྱིན་པར་བྱ་བའི་ཆོས་ལ་བརྟེན་པའི་ཤེས་པ་རྣམ་པར་དག་པ་དང་། སྦྱིན་པའི་སྦྱོར་བ་ལ་བརྟེན་པའི་ཤེས་པ་རྣམ་པར་དག་པ་དང་། སྦྱིན་པས་སེམས་ཅན་ཡོངས་སུ་སྨིན་པར་བྱ་བ་ལ་བརྟེན་པའི་ཤེས་པ་རྣམ་པར་དག་པ་དང་། ཐབས་ལ་མཁས་པ་ལ་བརྟེན་པའི་ཤེས་པ་རྣམ་པར་དག་པ་དང་། འདོད་པ་རྣམས་ཀྱི་ཉེས་དམིགས་ལ་བརྟེན་པའི་ཤེས་པ་རྣམ་པར་དག་པ་དང་། དྲི་མ་བསལ་བ་ལ་བརྟེན་པའི་ཤེས་པ་རྣམ་པར་དག་པ་དང་། སྡིག་པའི་གྲོགས་པོ་ཡོངས་སུ་སྤོང་བ་དང་དགེ་བའི་བཤེས་གཉེན་ཡོངས་སུ་གཟུང་བ༌[^1543]ལ་བརྟེན་པའི་ཤེས་པ་རྣམ་པར་དག་པ་དང་། ཕྱོགས་དྲུག་གིས་བཀབ་པ་ཉིད་ལ་བརྟེན་པའི་ཤེས་པ་རྣམ་པར་དག་པའོ། །

Enumeration Block 1:
འདུལ་བ་ནི་བསྡུ་ན་རྣམ་པ་གསུམ་དུ་རིག་པར་བྱ་སྟེ།
Enumeration Block 2:
དགེ་བའི་ཆོས་སྡུད་པའི་ཚུལ་ཁྲིམས་ལ་བརྩོན་པའི་བྱང་ཆུབ་སེམས་དཔས་མདོར་བསྡུ་ན་སེམས་དྲུག་ལ་སོ་སོར་བརྟག་པར་བྱ་སྟེ། དྲུག་གང་ཞེ་ན། ཁྱད་དུ་གསོད་པའི་སེམས་དང་། ལེ་ལོ་དང་ལྡན་པའི་སེམས་དང་། བསྒྲིབས་པའི་སེམས་དང་། བརྩལ་བ་ལས་ཡོངས་སུ་སྐྱོ་བའི་སེམས་དང་། གནོད་པ་དང་ལྡན་པའི་སེམས་དང་། བར་ཆད་དང་ལྡན་པའི་སེམས་སོ། །
Enumeration Block 3:
སེམས་ཅན་གྱི་དོན་བྱ་བའི་ཚུལ་ཁྲིམས་ལ་བརྩོན་པའི་བྱང་ཆུབ་སེམས་དཔའ༌[^1596]ནི་རྣམ་པར་རྟོག་པའི༌[^1597]གནས་དྲུག་ལ་སོ་སོར་བརྟག་པར་བྱ་སྟེ། བདག་དང་། གཞན་དང་། ཟང་ཟིང་གིས་ཕོངས་པ་དང་། ཟང་ཟིང་གིས་འབྱོར་པ་དང་། ཆོས་ཀྱིས་ཕོངས་པ་དང་། ཆོས་ཀྱིས་འབྱོར་པ་ནི་གནས་དྲུག་པ་ཡིན་ནོ། །

Enumeration Block 1:
དེ་ལ་བྱང་ཆུབ་སེམས་དཔའ་རྣམས་ཀྱི་སྦྱིན་པ་ནི་མདོར་བསྡུ་ན་ཡོན་ཏན་ལྔ་དང་ལྡན་ན་སྦྱིན་པའི་ཕ་རོལ་ཏུ་ཕྱིན་པ་ཞེས་བྱ་བའི་གྲངས་སུ་འགྲོ་སྟེ། ལྔ་གང་ཞེ་ན། འདི་ལྟ་སྟེ། ཆགས་པ་མེད་པ་ཉིད་དང་། མི་ལྟ་བ་ཉིད་དང་། ཁ་ན་མ་ཐོ་བ་མེད་པ་ཉིད༌[^1636]དང་། རྣམ་པར་རྟོག་པ་མེད་པ་ཉིད་དང་། ཡོངས་སུ་བསྔོ་བ་ཉིད་ཀྱིས་སོ། །
Enumeration Block 2:
སྟོང་པ་ཉིད་ལ་བརྟེན་ནས་དྲན་པ་ཉེ་བར་གཞག་པ་བསྒོམ་པ་ལ་བརྩོན་པའི་བྱང་ཆུབ་སེམས་དཔའ༌[^1674]ནི་མདོར་བསྡུ༌[^1675]ན་འདུ་ཤེས་ཀྱི་འཆིང་བ་རྣམ་པ་དྲུག་ལས་སེམས་རྣམ་པར་གྲོལ་བར་བྱ་སྟེ། འདུ་ཤེས་ཀྱི་འཆིང་བ་རྣམ་པ་དྲུག་གང་ཞེ་ན།
Enumeration Block 3:
དེ་ལ་ལྟ་བའི་གོང་ནས་གོང་དུ་འདུ་ཤེས་ཀྱི་འཆིང་བ་རྣམ་པ་བཅུ་གཅིག་ཡོད་པར་རིག་པར་བྱ་སྟེ། གོང་ནས་གོང་དུ་འདུ་ཤེས་ཀྱི་འཆིང་བ་རྣམ་པ་བཅུ་གཅིག་གང་ཞེ་ན།

Enumeration Block 1:
ལྟ་བའི་གོང་ནས་གོང་དུ་འདུ་ཤེས་ཀྱི་འཆིང་བ་རྣམ་པ་བཅུ་གཅིག་ཡོད་པར་རིག་པར་བྱ་སྟེ། གོང་ནས་གོང་དུ་འདུ་ཤེས་ཀྱི་འཆིང་བ་རྣམ་པ་བཅུ་གཅིག་གང་ཞེ་ན།
Enumeration Block 2:
ཐེག་པ་ཆེན་པོའི་མདོ་སྡེ༌[^1685]དོན་རབ་ཏུ་དབྱེ་བའི་རྒྱུ་བསྟན་པ་ནི་རྣམ་པ་ལྔས་རིག་པར་བྱ་སྟེ།
Enumeration Block 3:
རང་གི་མཚན་ཉིད་ཡོངས་སུ་བརྟགས་པ༌[^1686]དང་། སྤྱིའི་མཚན་ཉིད་ཡོངས་སུ་བརྟགས་པ༌[^1687]ལས་བརྩམས་ནས། སྐྱེ་མཆེད་བཅུ་གཉིས་པོ་དག་ལ། སངས་རྒྱས་ཀྱི་ཆོས་མ་འདྲེས་པ་ཐོབ་པར་བྱ་བའི་ཕྱིར་ཕྱིན་ཅི་མ་ལོག་པའི་ལམ་རྣམ་པ་བཅུ་ཡོད་པར་རིག་པར་བྱ་སྟེ། དེ་ལ་རྣམ་པ་དྲུག་གིས་ནི་སྐྱེ་མཆེད་བཅུ་གཉིས་པོ་དག་ལ་རང་གི་མཚན་ཉིད་ཡོངས་སུ་བརྟགས༌[^1688]པ་ཡིན་ལ། རྣམ་པ་བཞིས་ནི་སྤྱིའི་མཚན་ཉིད་ཡོངས་སུ་བརྟགས་པ༌[^1689]ཡིན་པར་རིག་པར་བྱ་སྟེ།
Enumeration Block 4:
ལས་རྣམ་པ་གཉིས་ལ་བརྟེན་ནས་རྣམ་པར་དག་པ་རྣམ་པ༌[^1695]གཉིས་སུ་རིག་པར་བྱ་སྟེ། མངོན་པར་གྲུབ་པའི་རྣམ་པར་དག་པ་དང་། ཉེ་བར་ཞི་བའི་རྣམ་པར་དག་པའོ། །
Enumeration Block 5:
གནས་པ་དང་ས་རྣམས་ཀྱི་གོང་ནས་གོང་མའི་ཁྱད་པར་ནི་ཁྱད་པར་རྣམ་པ་བརྒྱད་ཀྱིས་རིག་པར་བྱ་སྟེ། བསམ་པའི་ཁྱད་པར་དང་། སེམས་རྣམ་པར་དག་པའི་ཁྱད་པར་དང་། སྙིང་རྗེའི་ཁྱད་པར་དང་། ཕ་རོལ་ཏུ་ཕྱིན་པའི་ཁྱད་པར་དང་། སེམས་ཅན་ཡོངས་སུ་སྨིན་པའི་ཁྱད་པར་དང་། སངས་རྒྱས་སྣང་བར་འགྱུར་བ་དང་། མཆོད་པ་དང་བསྙེན་བཀུར་བྱེད་པའི་ཁྱད་པར་དང་། སྐྱེ་བའི་ཁྱད་པར་དང་། མཐུའི་ཁྱད་པར་གྱིས་སོ།། །།
Enumeration Block 6:

Enumeration Block 7:

Enumeration Block 2:
ཆོས་དེ་ནི་དབུ་མའི་ལམ་རྣམ་པ་བཅུ་གསུམ་སྨོས་པར་བྱེད་པ་ཡིན་པའི་ཕྱིར་ཏེ། གང་ཟག་སྟོང་པ་ཉིད་སྨོས་པར་བྱེད་པ་དང་། གང་ཟག་ལ་བདག་མེད་པ་དང་། ཆོས་སྟོང་པ་ཉིད་དང་། ཆོས་ལ་བདག་མེད་པ་དང་། སྒྲོ་འདོགས་པའི་མཐའ་དང་། སྐུར་པ་འདེབས་པའི་མཐའ་དང་། ཆོས་མངོན་པར་རྟོགས་པ་དང་། དེ་ཉིད་བྱང་ཆུབ་ཆེན་པོར་ཡོངས་སུ་བསྔོ་བ་ཉིད་དང་། ད་ལྟར༌[^2583]ཞུགས་པའི་སེམས་ཉོན་མོངས་པ་དང་སྡུག་བསྔལ་དག་གིས་ཡོངས་སུ་མ་གཏུགས་པ་ཉིད་དང་། བདག་མེད་པ་གཉིས་ལ་མོས་པའི་ཁྱད་པར་དང་། བདག་མེད་པ་སྔ་མ་ཤོས་ཕྱི་མའི་རྒྱུ་ཉིད་ཡིན་པ་དང་། མཐར་ཐུག་པའི་སྟོང་པ་ཉིད་དང་། དེ་ཉིད་ཀྱི་མཐུ་སྨོས་པར་བྱེད་དོ། །

Enumeration Block 1:
ཆོས་དེ་ནི་དབུ་མའི་ལམ་རྣམ་པ་བཅུ་གསུམ་སྨོས་པར་བྱེད་པ་ཡིན་པའི་ཕྱིར་ཏེ། གང་ཟག་སྟོང་པ་ཉིད་སྨོས་པར་བྱེད་པ་དང་། གང་ཟག་ལ་བདག་མེད་པ་དང་། ཆོས་སྟོང་པ་ཉིད་དང་། ཆོས་ལ་བདག་མེད་པ་དང་། སྒྲོ་འདོགས་པའི་མཐའ་དང་། སྐུར་པ་འདེབས་པའི་མཐའ་དང་། ཆོས་མངོན་པར་རྟོགས་པ་དང་། དེ་ཉིད་བྱང་ཆུབ་ཆེན་པོར་ཡོངས་སུ་བསྔོ་བ་ཉིད་དང་། ད་ལྟར༌[^2583]ཞུགས་པའི་སེམས་ཉོན་མོངས་པ་དང་སྡུག་བསྔལ་དག་གིས་ཡོངས་སུ་མ་གཏུགས་པ་ཉིད་དང་། བདག་མེད་པ་གཉིས་ལ་མོས་པའི་ཁྱད་པར་དང་། བདག་མེད་པ་སྔ་མ་ཤོས་ཕྱི་མའི་རྒྱུ་ཉིད་ཡིན་པ་དང་། མཐར་ཐུག་པའི་སྟོང་པ་ཉིད་དང་། དེ་ཉིད་ཀྱི་མཐུ་སྨོས་པར་བྱེད་དོ། །

Enumeration Block 4:
གོང་ནས་གོང་དུ་རྣམ་པ་བརྒྱད་དེ། དངོས་པོ་དེ་ཉིད་ལ་རྟག་པར་འཛིན་པས་སྒྲོ་འདོགས་པ་དང་། མི་རྟག་པར་འཛིན་པས་སྒྲོ་འདོགས་པ་དང་། [^2587]རྟག་པར་འཛིན་པས་སྒྲོ་འདོགས་པ་ལ་བརྟེན་ནས་བདག་ཏུ་འཛིན་པས་སྒྲོ་འདོགས་པ་དང་། མི་རྟག་པར་འཛིན་པས་སྒྲོ་འདོགས་པ་ལ་བརྟེན་ནས་བདག་མེད་པར་འཛིན་པས་སྒྲོ་འདོགས་པ་དང་། བདག་མེད་པར་འཛིན་པས་སྒྲོ་འདོགས་པ་ལ་བརྟེན་ནས་ཡང་དག་པའི་སེམས་སུ་འཛིན་པས་སྒྲོ་འདོགས་པ་དང་། བདག་ཏུ་འཛིན་པས་སྒྲོ་འདོགས་པ་ལ་བརྟེན་ནས་ཡང་དག་པ་མ་ཡིན་པའི་སེམས་སུ་འཛིན་པས་སྒྲོ་འདོགས་པ་དང་། དེ་ཡང་སེམས་མེད་པ་དང་ཚོལ་བ་པའོ། །
Enumeration Block 5:
རྣམ་པ་གསུམ་གྱིས་ཏེ། དངོས་པོ་དེ་ཉིད་དང་། བཞི་པ་སྐྱེ་བའི་དངོས་པོ་མི་མཐུན་པའི་ཕྱོགས་དང་གཉེན་པོ་དང་། འདུས་བྱས་དང་། འདུས་མ་བྱས་སུ་རྣམ་པར་གནས་པ་ལ་ངོ་བོ་ཉིད་མི་དམིགས་པ་ཡོངས་སུ་བསྟན་པ་དང་བྱེ་བྲག་མི་དམིགས་པ་ཡོངས་སུ་བསྟན་པ་དང་། དེ་གོམས་པར་བྱས་པས་ཤེས་པ་ཡང་དག་པ་ཇི་ལྟ་བ་བཞིན་རབ་ཏུ་རྟོགས་པ་ཡོངས་སུ་བསྟན་པས་སོ། །
Enumeration Block 6:
རྣམ་པ་བཞི་སྟེ། ལྟ་བའི་བྱེ་བྲག་ཡོངས་སུ་བསྟན་པ་དང་། དེ་ཉིད་ཁྱད་ཆེས་དམན་པའི་བྱེ་བྲག་ཡོངས་སུ་བསྟན་པ་དང་། སྤོང་བ་ལ་རྣམ་པར་འཁྲུལ་པའི་བྱེ་བྲག་ཡོངས་སུ་བསྟན་པ་དང་། སེམས་རྣམ་པར་འཁྲུལ་པའི་བྱེ་བྲག་ཡོངས་སུ་བསྟན་པ་ལས་སོ། །
Enumeration Block 7:
རྣམ་པ་གཉིས་ཀྱིས་ཏེ། འཛིན་པ་ལ་སོ་སོར་རྟོག་པ་ཡོངས་སུ་བསྟན་པ་དང་། དེ་ཡང་དག་པ་ཇི་ལྟ་བ་བཞིན་རབ་ཏུ་རྟོགས་པ་ཡོངས་སུ་བསྟན་པ་ལས་ཏེ།
Enumeration Block 8:
ཉན་ཐོས་ནི་རྣམ་པ་བཞིའོ། །
ཉན་ཐོས་ཀྱི་བསླབ་པ་དང་བྱང་ཆུབ་སེམས་དཔའི་བསླབ་པའི་བྱེ་བྲག་ནི་རྣམ་པ་བཅུ་གསུམ་གྱིས་རིག་པར་བྱའོ། །
སྤྲུལ་པའི་ཉན་ཐོས་དང་། མངོན་པའི་ང་རྒྱལ་ཅན་གྱི་ཉན་ཐོས་དང་། བྱང་ཆུབ་ཏུ་ཡོངས་སུ་གྱུར་པའི༌[^2604]ཉན་ཐོས་དང་། ཞི་བའི་བགྲོད་པ་གཅིག་པའི་ཉན་ཐོས་སོ། །

Enumeration Block 1:
རྣམ་པར་གནོན་པའི་གཉེན་པོ་དེ་ལ་གནས་གསུམ་ལ་མཁས་པ། རྟེན་ཅིང་འབྲེལ་པར་འབྱུང་བ་ལ་མཁས་པ་དང་། གང་ཟག་ལ་བདག་མེད་པར་མོས་པ་དང་། ཆོས་ལ་བདག་མེད་པར་མོས་པའི་ཀུན་ནས་ཉོན་མོངས་པ་མ་ལུས་པ་ལས་ཡང་དག་པར་འདའ་བར་བྱ་བའི་ཕྱིར་མི་ཤེས་པ་རྣམ་པ་བཞིའོ།[^2624] །
Enumeration Block 2:
དེ་ལ་སེམས་ཀྱི་སྤྱིའི་མཚན་ཉིད་ནི་རྣམ་པ་གསུམ་གྱིས་རིག་པར་བྱ་སྟེ། རྟེན་ཅིང་འབྲེལ་བར་འབྱུང་བ་ལྐོག་ན་གཡོ་བ་མེད་པ་ཉིད་དང་། དེ་ལྟར་གྱི་སྐད་ཅིག་པ་གཡོ་བ་མེད་པ་ཉིད་དང་། འདོད་ཆགས་ལ་སོགས་པ་རྐྱེན་ལས་བྱུང་བའི་སེམས་ཀྱིས་མ་བྱས་པ་ཉིད་ཀྱིས་སོ། །
སེམས་ཀྱི་རང་གི་མཚན་ཉིད་ཀྱང་རྣམ་པ་གསུམ་གྱིས་རིག་པར་བྱ་སྟེ། སྔ་མ་བཞིན་དུ་ཐ་སྙད་ལས་བྱུང་བའི་ངོ་བོ་ཉིད་ཀྱིས་མི་དམིགས་པ་དང་། སྔ་མ་བཞིན་དུ་རྣམ་པ་དྲུག་གིས་དེ་བཞིན་ཉིད་མི་དམིགས་པ་དང་། འཕགས་པ་ཐམས་ཅད་ཀྱི་བྱེ་བྲག་མེད་པའི་ཤེས་པ་མི༌[^2625]དམིགས་པས་སོ། །
Enumeration Block 3:
སེམས་ཀྱི་ཀུན་ནས་ཉོན་མོངས་པའི་མཚན་ཉིད་ཀྱང་རྣམ་པ་གསུམ་གྱིས་རིག་པར་བྱ་སྟེ། འགྲུབ་པ་དང་། འཇུག་པ་དང་། རྒྱུ་བས་ཏེ།
Enumeration Block 4:
སེམས་ཀྱི་རྣམ་པར་བྱང་བའི་མཚན་ཉིད་ཀྱང་རྣམ་པ་གསུམ་གྱིས་རིག་པར་བྱ་སྟེ། མི་རྟོགས་པ༌[^2635]དང་རྟོགས་པའི་མཚན་ཉིད་དང་། འདུས་མ་བྱས་ཀྱི་མཚན་ཉིད་དང་། རིགས་ཀྱི་མཚན་ཉིད་ཀྱིས་ཏེ།
Enumeration Block 5:
འདུས་མ་བྱས་ཀྱི་མཚན་ཉིད་དེ་ནི་རྣམ་པ་དགུས་བལྟ་བར་བྱ་སྟེ། དུས་རྣམས་སུ་རྒྱུ་བ་མེད་པ་དང་། ཇི་ལྟར་འགོག་པའི་སྙོམས་པར་འཇུག་པ་ལ་ཐ་སྙད་ལས་བྱུང་བའི་ངོ་བོ་ཉིད་ཀྱིས་དམིགས་སུ་མེད༌[^2636]ལ་དེ་བཞིན་ཉིད་ཀྱི་མཚན་ཉིད་ཀྱིས་དམིགས་སུ་ཡོད་པ་ལྟ་བུ་མ་ཡིན་པའི་ཕྱིར། གཉིས་སུ་མེད་པའི་མཚན་ཉིད་དང་། སྐྱེ་བ་མེད་པའི་མཚན་ཉིད་དང་། སྐྱེ་བའི་རྒྱུའི༌[^2637]ངོ་བོ་ཉིད་ལས་ཡང་དག་པར་འདས་པའི་མཚན་ཉིད་དང་། ཕྱི་མར་སྐྱེ་བ་ལས་ཡང་དག་པར་འདས་པ་དང་། འཆི་འཕོ་བ་ལས་ཡང་དག་པར་འདས་པ་དང་། སྐད་ཅིག་གཅིག་ནས་གཅིག་ཏུ་འབྲལ་བ་ལས་ཡང་དག་པར་འདས་པ་དང་། འགྲོ་བ་འགྱུར་བ་ལས་ཡང་དག་པར་འདས་པ་དང་། ལས་ཀྱིས༌[^2638]ཀུན་ནས་ཉོན་མོངས་པའི་འདུ་བྱེད་ལས་ཡང་དག་པར་འདས་པ་ཉིད་ཀྱིས་སོ། །
Enumeration Block 6:
རིགས་ཀྱི་མཚན་ཉིད་དེ་ཡང་གནས་སྐབས་བཞིར་རྣམ་པ་དགུར་རིག་པར་བྱ་སྟེ། རྣམ་པར་མ་དག་པའི་གནས་སྐབས་དང་། རྣམ་པར་དག་པའི་གནས་སྐབས་དང་། སོ་སོར་རྟོགས་པའི་གནས་སྐབས་དང་། ཡོངས་སུ་གཏུགས་པའི་གནས་སྐབས་སོ། །
Enumeration Block 7:
དེ་ལ་ལྟུང་བ་ཀུན་ནས་སློང་བར་བྱེད་པ་བརྣབ་སེམས་དང་ཡིད་མི་བདེ་བ་ནི་ཇི་ལྟར་སེལ་བར་མི་བྱེད་པ་དང་། ཇི་ལྟར་མ་བསྩལ་བ༌[^2645]དང་། ཇི་ལྟར་སེལ་བར་བྱེད་པ་དང་། ཇི་ལྟར་བསྩལ་བའི༌[^2646]རྣམ་པ་དེ་བཞིས་རིག་པར་བྱ་སྟེ།
Enumeration Block 8:
དེ་དག་ནི་རྣམ་པ་གསུམ་དུ་རིག་པར་བྱ་སྟེ། དགེ་སྦྱོང་གི་ཚུལ་ལ་མི་ལྟ་ཞིང་ཆ་ལུགས་དང་རྟགས་མཐུན་པ། ཆོ་ག་དང་། འཚོ་བ་དང་། ལོངས་སྤྱོད་དང་། བརྩོན་པ་དང་། ཚུལ་ཁྲིམས་དང་། ལྟ་བ་དང་། བསམ་པ་མི་མཐུན་པ་དང་། ཡོ་བྱད་ལ་ཡོངས་སུ་གཞོལ་བ་དང་། [^2652]ལྷག་པའི་ཚུལ་ཁྲིམས་དང་རྟགས་མཐུན་པ། [^2653]ལྷག་པའི་སེམས་དང་རྟགས་མཐུན་པ། [^2654]ལྷག་པའི་ཤེས་རབ་དང་རྟགས་མཐུན་པ༌[^2655]ལ། དེ་དག་བསྒྲུབ་པའི་བསམ་པ་དང་མི་མཐུན་པ་དང་། སྒྲ་ལ་ཡོངས་སུ་གཞོལ་བ། ཞི་གནས་ཀྱི་ཡན་ལག་དང་མཐུན། ལྷག་མཐོང་གི་ཡན་ལག་དང་མཐུན། དེ་གཉི་ག་བསྒོམ་པའི་ཡན་ལག་དང་མཐུན། དེ་གཉི་གའི་ཚོགས་ཀྱི་ཡན་ལག་དང་མཐུན། དེ་ལ༌[^2656]དེ་དག་གི་བསམ་པ་དང་མི་མཐུན་པའོ། །
Enumeration Block 9:
དེ་ནི་རྣམ་པ་བཞིར༌[^2657]རིག་པར་བྱ་སྟེ། སྦྱོར་བ་དང་། བསམ་པ་དང་། རྟོགས་པ་དང་། མཐར་ཐུག་པར་འགྲོ་བས་སོ། །
Enumeration Block 10:
དེ་ལ་ལེགས་པར་མ་བསླབས་པའི་དགེ་སྦྱོང་ནི་རྣམ་པ་གསུམ་གྱིས་ན་མིང་དོན་ཇི་ལྟ་བ་བཞིན་དུ༌[^2660]མ་ཡིན་པར་རིག་པར་བྱ་སྟེ། བསམ་པ་རྒུད་ལ་སྦྱོར་བ་ཕུན་སུམ་ཚོགས་པ་དང་། བསམ་པ་ཕུན་སུམ་ཚོགས་ལ་སྦྱོར་བ་རྒུད་པ་དང་། བསམ་པ་ཡང་རྒུད་ལ་སྦྱོར་བ་ཡང་རྒུད་པས་སོ། །

Enumeration Block 11:
དེ་དག་ནི་རྣམ་པ་བཞིར་རིག་པར་བྱ་སྟེ། ཚུལ་ཁྲིམས་ཡན་ལག་དྲུག་དང་ལྡན་པའི་ཚུལ་ཁྲིམས་ཉམས་པ་གཉིས་པོ་འཇིག༌[^2663]ཚོགས་ལ་ལྟ་བས་ཀུན་ནས་དཀྲིས་པས་ལྟུང་བ་འབྱུང་བ་དང་། དེ་ལས་བསླབ་པ༌[^2664]ལ་མི་མཁས་པས་ཉམས་པ་དང་། ཉེས་པ་དེ༌[^2665]གཉི་ག་སྤངས་སུ་ཟིན་ཀྱང་འཇིག་རྟེན་པའི་རྣམ་པར་དག་པ་མ་ཐོབ་པའི་ཕྱིར་འཇིག་ཚོགས་ལ་ལྟ་བ་རྣམ་པར་བསྩལ་བ༌[^2666]དང་། འཇིག་རྟེན་པའི་རྣམ་པར་དག་པའི་སྡོམ་པ་ཐོབ་ཅིང་འཇིག་ཚོགས་ལ་ལྟ་བ་རྣམ་པར་བསྩལ༌[^2667]དུ་ཟིན་ཀྱང་ཡོ་བྱད་མ་བསྙུངས་ཤིང་ཆོས་བདག་མེད་པས་སྐྲག་པས་ཚུལ་ཁྲིམས་ཉམས་པ་དང་། སྐྱོན་གཞན་ཐམས་ཅད་སྤངས་སུ་ཟིན་ཀྱང་ཆོས་བདག་མེད་པ་ལ་ལོག་པར་མོས་པས་ཚུལ་ཁྲིམས་ཉམས་པའོ། །

Enumeration Block 1:
དེ་ལ་ལེགས་པར་མ་བསླབས་པའི་དགེ་སྦྱོང་ནི་རྣམ་པ་གསུམ་གྱིས་ན་མིང་དོན་ཇི་ལྟ་བ་བཞིན་དུ༌[^2660]མ་ཡིན་པར་རིག་པར་བྱ་སྟེ། བསམ་པ་རྒུད་ལ་སྦྱོར་བ་ཕུན་སུམ་ཚོགས་པ་དང་། བསམ་པ་ཕུན་སུམ་ཚོགས་ལ་སྦྱོར་བ་རྒུད་པ་དང་། བསམ་པ་ཡང་རྒུད་ལ་སྦྱོར་བ་ཡང་རྒུད་པས་སོ། །
དེ་ལ་བསམ་པ་རྒུད་ལ་སྦྱོར་བ་ཕུན་སུམ་ཚོགས་པ་ནི་རྣམ་པ་གསུམ་སྟེ། ཉན་པ་དེ་ཙམ་གྱིས་ཆོག་པར་འཛིན་པ་དང་། སྨྲ་བ་དེ་ཙམ་གྱིས་ཆོག་པར་འཛིན་པ་དང་། འཇིག་རྟེན་པའི་ཏིང་ངེ་འཛིན་རྟོགས་པར་བྱེད་པ་དེ༌[^2661]རོ་མྱང་བ་ཙམ་གྱིས་ཆོག་པར་འཛིན་པའོ། །
Enumeration Block 2:
དེ་དག་ནི་རྣམ་པ་བཞིར་རིག་པར་བྱ་སྟེ། ཚུལ་ཁྲིམས་ཡན་ལག་དྲུག་དང་ལྡན་པའི་ཚུལ་ཁྲིམས་ཉམས་པ་གཉིས་པོ་འཇིག༌[^2663]ཚོགས་ལ་ལྟ་བས་ཀུན་ནས་དཀྲིས་པས་ལྟུང་བ་འབྱུང་བ་དང་། དེ་ལས་བསླབ་པ༌[^2664]ལ་མི་མཁས་པས་ཉམས་པ་དང་། ཉེས་པ་དེ༌[^2665]གཉི་ག་སྤངས་སུ་ཟིན་ཀྱང་འཇིག་རྟེན་པའི་རྣམ་པར་དག་པ་མ་ཐོབ་པའི་ཕྱིར་འཇིག་ཚོགས་ལ་ལྟ་བ་རྣམ་པར་བསྩལ་བ༌[^2666]དང་། འཇིག་རྟེན་པའི་རྣམ་པར་དག་པའི་སྡོམ་པ་ཐོབ་ཅིང་འཇིག་ཚོགས་ལ་ལྟ་བ་རྣམ་པར་བསྩལ༌[^2667]དུ་ཟིན་ཀྱང་ཡོ་བྱད་མ་བསྙུངས་ཤིང་ཆོས་བདག་མེད་པས་སྐྲག་པས་ཚུལ་ཁྲིམས་ཉམས་པ་དང་། སྐྱོན་གཞན་ཐམས་ཅད་སྤངས་སུ་ཟིན་ཀྱང་ཆོས་བདག་མེད་པ་ལ་ལོག་པར་མོས་པས་ཚུལ་ཁྲིམས་ཉམས་པའོ། །
Enumeration Block 3:

དེ་ནི་རྣམ་པ་ལྔས་རིག་པར་བྱ་སྟེ། ཞིང་བྱིན་གྱིས་རློབ་པའི་དུས་ན་དབང་ཕྱུག་གི་བདག་པོ་ཆེན༌[^2685]པོ་ཡང་དག་པར་གྲུབ་པའི༌[^2686]རྒྱུ་ཟིལ་གྱིས་གནོན་པ་དང་། ཡུལ༌[^2687]ཡོངས་སུ་གྲུབ་པ༌[^2688]དང་། དེའི་གནས་བསྟན༌[^2689]པའི་སྣོད་དུ་བྱེད་པ་དང་། སྟོན་པའི་སྣོད་དུ་བྱེད་པ་དང་། ལུས་སྤོང་བའི་དུས་ན་ལྟ་བ་དང་། ལས་རྣམ་པར་དག་པར་འགྱུར་བས་སོ། །
དེ་ལ་དབང་ཕྱུག་གི་བདག་པོ་ཆེན་པོ་ཡང་དག་པར་གྲུབ་པའི༌[^2690]རྒྱུ་ཟིལ་གྱིས་གནོན་པ་ནི་རྣམ་པ་ལྔས་རིག་པར་བྱ་སྟེ། འབྲས་བུ་དཔག་ཏུ་ཡོད་པ་དང་དཔག་ཏུ་མེད་པ་འཕེན་པ་དང་། རྒྱུ་ཟད་པ་དང་མི་ཟད་པའི་ཆོས་ཉིད་དང་། བདེ་བ་རྒྱ་ཆུང་ངུ༌[^2691]དང་རྒྱ་ཆེན་པོ༌[^2692]འགྲུབ་པ་དང་། དེ་ཡེ་ཤེས་ཀྱི་ཚོགས་ཀྱི་ངོ་བོ་ཉིད་ཡིན་པ་དང་། དེས་དེ་འདྲེན་པར་བྱེད་པས་སོ། །
