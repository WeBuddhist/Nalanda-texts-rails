Enumeration Block 1:
རྒྱལ་བའི་ཡོན་ཏན་མཐའ་མི་འཚལ་ཞེས་བྱ་བ་གླེང་བསླང་བའི་ཚིགས་སུ་བཅད་པ་འདིས་ནི་བསྡུས་པའི་དོན་བཞི་པོ་འདི་ལྟ་སྟེ། ཡོན་ཏན་ཡོངས་སུ་མི་ཤེས་པ་དང་། སྒྲོ་འདོགས་པ་མེད་པར་བྱ་བ་དང་། ང་རྒྱལ་མེད་པར་བྱ་བ་དང་། འདོད་པའི་དོན་བསྒྲུབ་པར་བྱ་བ་རྣམས་བསྟན་ཏོ། །

Enumeration Block 2:
དེ་ཡང་གནས་སྐབས་གསུམ་པོ་རྒྱུའི་གནས་སྐབས་དང་། འབྲས་བུའི་གནས་སྐབས་དང་། སེམས་ཅན་གྱི་དོན་བྱེད་པའི་གནས་སྐབས་རྣམས་དང་ལྡན་པ་ཡིན་ནོ། །

Enumeration Block 3:
དེ་ལ་རྒྱུའི་གནས་སྐབས་ནི་བསམ་པའི་གནས་སྐབས་དང་། སྦྱོར་བའི་གནས་སྐབས་དང་། དབང་མཛད་པའི་གནས་སྐབས་རྣམས་སོ། །

Enumeration Block 4:
དེའི་ཉེ་བར་བསྟན་པ་ཡང་བཞི་སྟེ། སྡུག་བསྔལ་བསྐྱེད་པ་ལ་སོ་སོར་རྟོག་པ་དང་། ཕན་བཏགས་པ་ལ་སོ་སོར་རྟོག་པ་དང་། གྲོགས་བྱས་པ་ལ་སོ་སོར་རྟོག་པ་དང་ཡང་དག་པར་ལོངས་སྤྱད་པ་ལ་སོ་སོར་རྟོག་པའོ། །
བྱང་ཆུབ་ཀྱི་སྨོན་ལམ་དེའི་རྒྱུ༌[^2]བཞི་སྟེ།

Enumeration Block 5:
དེ་ཡང་རྣམ་པ་གཉིས་ཏེ། མོས་པས་སྤྱོད་པ་རྣམས་ཀྱི་དང་། ས་ཐོབ་པ་རྣམས་ཀྱིའོ། །
དེ་ལ་རེ་ཞིག་མོས་པས་སྤྱོད་པ་རྣམས་ཀྱི་ཕ་རོལ་ཏུ་ཕྱིན་པ་ནི་བཅུ་སྟེ། འདི་ལྟར་སྦྱིན་པ་དང་། ཚུལ་ཁྲིམས་དང་། བཟོད་པ་དང་། བརྩོན་འགྲུས་དང་། བསམ་གཏན་དང་། ཤེས་རབ་དང་། ཐབས་དང་། སྨོན་ལམ་དང་། སྟོབས་དང་། ཡེ་ཤེས་ཀྱི་ཕ་རོལ་ཏུ་ཕྱིན་པ་དག་གོ། །

Enumeration Block 6:
ས་ཐོབ་པ་རྣམས་ཀྱི་སྦྱིན་པ་ནི་ཕུན་སུམ་ཚོགས་པ་རྫོགས་པ་བཞི་དང་ལྡན་པ་ཡིན་ཏེ། བསམ་པ་ཕུན་སུམ་ཚོགས་པ་དང་། སྦྱོར་བ་ཕུན་སུམ་ཚོགས་པ་དང་། ལེན་པ་པོ་ཕུན་སུམ་ཚོགས་པ་དང་། སྦྱིན་པར་བྱ་བ་ཕུན་སུམ་ཚོགས་པའོ། །

Enumeration Block 7:
དེ་ལ་མངའ་དབང་མཛད་པ་ནི་ལྔ་སྟེ། ཉོན་མོངས་པ་དང་། སྐྱེ་བ་དང་། ལས་དང་། ཐབས་དང་། སེམས་ཅན་ཡོངས་སུ་སྨིན་པར་མཛད་པ་དག་གོ། །
