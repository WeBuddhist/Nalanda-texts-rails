## དཀར་ཆག / Table of Contents

* 1. བདེན་པ་གཉིས་ [[བདེན་པ་གཉིས་རྣམ་པར་དབྱེ་བར་བྱའོ། །]]
   * 1.1 དང་པོར་ཀུན་རྫོབ་ཀྱི་བདེན་པ་རྣམ་པར་གཞག་པ [[དེ་ལ་དང་པོར་ཀུན་རྫོབ་ཀྱི་བདེན་པ་རྣམ་པར་གཞག་པ༌[^7]ནི།]]
   * 1.2 གཉིས་པ་དོན་དམ་པའི་བདེན་པ [[དོན་དམ་པའི་བདེན་པ་ཇི་ལྟ་བུ་ཞེ་ན།]]
* 2. བདེན་པ་གཉིས་ཀྱི་དོན་བཤད་པ [[ད་ནི་བདེན་པ༌[^27]གཉིས་ཀྱི་དོན་བཤད་པར་བྱ་སྟེ།]]
   * 2.1 སྤྱིར་བཤད་པ [[ཀུན་རྫོབ་བདེན་པ་ཇི་ལྟ་བུ། །]]
   * 2.2 བྱེ་བྲག་ཏུ་ལན་གདབ་པ [[ད་ནི་བྱེ་བྲག་ཏུ་ལན་གདབ་པར་བྱའོ། །]]
* 3. གང་ཟག་གསུམ་གྱི་རྟོགས་པ་དགག་པ [[འདིར་གང་ཟག་ནི་གསུམ་སྟེ། མ་རྟོགས་པ༌[^55]དང་།]]
   * 3.1 དང་པོ་ལོག་པར་རྟོགས་པའི་འཁྲུལ་པའི་ཀུན་རྫོབ་ཀྱི་ཤེས་རབ [[དེ་ལ་དང་པོར་ལོག་པར་རྟོགས་པའི༌[^57]འཁྲུལ་པའི་ཀུན་རྫོབ་ཀྱི་ཤེས་རབ་ནི།]]
   * 3.2 གཉིས་པ་དྲང་བའི་དོན་གྱི་ཡང་དག་པའི་ཀུན་རྫོབ་ཀྱི་ཤེས་རབ [[གསུང་གི་ཉི་མ་ཤར་མོད་ཀྱི། །]]
      * 3.2.1 ཉན་ཐོས་ཀྱི་ཤེས་རབ [[འདིར་ཉན་ཐོས་དག་ཕྱིར་ཟློག༌[^130]པར་བྱེད་དེ།]]
      * 3.2.2 སེམས་ཙམ་གྱི་རྣལ་འབྱོར་པའི་ཤེས་རབ [[ཐེག་ཆེན་རིགས་ཅན་ཡིན་མོད་ཀྱི། །]]
         * 3.2.2.1 དང་པོ་རྣམ་པ་དང་བཅས་པར་སྨྲ་བ [[དེ་ལ་རྣམ་པ་དང་བཅས་པར་སྨྲ་བ་དག་ནི་འདི་སྐད་དུ།]]
         * 3.2.2.2 གཉིས་པ་རྣམ་པ་མེད་པར་སྨྲ་བ [[འདི་ལྟར་རྣམ་པ་མེད་པར་སྨྲ་བ་དག་ལ་ཡང་དོན་དམ་པའི་ཤེས་པ་མེད་དེ།]]
   * 3.3 གསུམ་པ་ངེས་པའི་དོན་གྱི་ཡང་དག་པའི་ཀུན་རྫོབ [[འཕགས་པ་ཀླུ་སྒྲུབ་འཕགས་པའི་ལྷ། །]]
      * 3.3.1 བདེན་པ་གཉིས་ལ་འཇུག་པ [[བདེན་པ་གཉིས་ལ་འཇུག་པར་བྱ། །]]
         * 3.3.1.1 དང་པོར་ཀུན་རྫོབ་ཀྱི་བདེན་པ [[དེ་ལ་དང་པོར་ཀུན་རྫོབ་ཀྱི་བདེན་པ་སློབ་དཔོན་ཉིད་ཀྱིས་གསུངས་པ་བཞིན་དུ་ཤེས་པར་བྱའོ། །]]
         * 3.3.1.2 གཉིས་པ་དོན་དམ་པའི་བདེན་པ [[དེ་ལ་དོན་དམ་པའི་བདེན་པ༌[^201]ནི་ཡང་སློབ་དཔོན་གྱི་ཞལ་སྔ༌[^202]ནས།]]
      * 3.3.2 རྒོལ་བ་རྣམས་ཀྱི་སྐྱོན་སྤོང་བ [[འདིར་རང་གི་སྡེ་པ་དངོས་པོར་འཛིན་པ་ཤས་ཆེ་བ་དག་མ་བཟོད་ནས་ཤིན་ཏུ་རྔམས་ནས་རྒོལ་བར་བྱེད་དེ།]]
         * 3.3.2.1 དང་པོ་རྒོལ་བ་དང་པོ [[ཁྱེད་ཀྱི་རྒོལ་བ་དང་པོའི་སྐྱོན་གྱི་དྲི་མ་མེད་དེ།]]
         * 3.3.2.2 གཉིས་པ་རྒོལ་བ་གཉིས་པ [[རྒོལ་བ་གཉིས་པའི་སྐྱོན་གྱི་དྲི་མ་ཡོད་པ་མ་ཡིན་ཏེ།]]
         * 3.3.2.3 གསུམ་པ་རྒོལ་བ་གསུམ་པ [[རྒོལ་བ་གསུམ་པའི་སྐྱོན་གྱི་དྲི་མ་ཡང་མེད་དེ་ཕྱི་རོལ་པ་དག་ནི་འདི་སྐད་དུ།]]
            * 3.3.2.3.1 ཀུན་རྫོབ་ཀྱི་ཚུལ [[འདི་ལྟར་ཀུན་རྫོབ་ཀྱི་ཚུལ་གྱིས་ཀྱང་ཆད་པར་སྨྲ་བ་མ་ཡིན་ཏེ།]]
            * 3.3.2.3.2 དོན་དམ་པའི་ཚུལ [[དོན་དམ་པའི་ཚུལ་གྱིས་ཀྱང་ཆད་པར་སྨྲ་བ་མ་ཡིན་ཏེ།]]
         * 3.3.2.4 བཞི་པ་རྒོལ་བ་བཞི་པ [[རྒོལ་བ་བཞི་པའི་སྐྱོན་གྱིས་ཀྱང་གོས་པར་མི་འགྱུར་ཏེ།]]
         * 3.3.2.5 ལྔ་པ་རྒོལ་བ་ལྔ་པ [[རྒོལ་བ་ལྔ་པ་དང་དྲུག་པ་དང་། བདུན་པ་དང་། བརྒྱད་པའི་སྐྱོན་གྱི་དྲི་མས་ཀྱང་གོས་པར་མི་འགྱུར་ཏེ།]]
         * 3.3.2.6 དྲུག་པ་རྒོལ་བ་དྲུག་པ [[རྗེས་སུ་དཔག་པས་ཀྱང་གནོད་པ་མེད་དོ།[^266] །]]
         * 3.3.2.7 བདུན་པ་རྒོལ་བ་བདུན་པ [[གྲགས་པས་ཀྱང་གནོད་པ་མེད་དེ། གང་གི་ཕྱིར་འཇིག་རྟེན་ནི་མི་ཤེས་པའི་ལིང་ཐོག་གིས་མདོངས་པ༌[^268]ཡིན་པས་]]
         * 3.3.2.8 བརྒྱད་པ་རྒོལ་བ་བརྒྱད་པ [[བདེན་པ་གཉིས་ཀྱི་ཚུལ་ལ་གནས་པས་ཁས་བླངས་པའི་གནོད་པ་ཡང་མེད་དོ། །]]
* 4. དོན་དམ་པའི་ཤེས་རབ [[དེ་ལ་དོན་དམ་པའི་ཤེས་རབ་ཇི་ལྟ་བུ་ཞེ་ན།]]
* 5. ལམ་ལ་འཇུག་པའི་རིམ་པ [[དེ་ལྟ་བུའི་ཟབ་ཅིང་རྒྱ་ཆེ་བའི་ལམ་དུ་སུ་ཞིག་འཇུག་ཅེ་ན།]]
   * 5.1 དོན་དམ་བདེན་པ་དེ་ལ་བསྟན་པར་བྱ [[དཔག་མེད་སྐྱེ་བ་དེ་དང་དེར། ། སྦྱང་བ་བྱས་པའི་བདག་ཉིད་ཅན། །]]
   * 5.2 ཇི་ལྟར་འཇུག་པའི་ཚུལ [[འདིར་རྒྱུའི་སྟོབས་ཅན་དག་ཇི་ལྟར་འཇུག་པར་བྱ་ཞེ་ན་ཐོག་མར་སྐྱབས༌[^286]སུ་འགྲོ་བ་]]
      * 5.2.1 ལྟུང་བ་ལས་ལྡང་བ [[ལྟུང་བ་ལས་ལྡང་བ་ཡང་བློ་གྲོས་དམན་པ་ཁ་ཅིག་གིས་ནི་གཞུང་ལས་ཇི་ལྟར་]]
      * 5.2.2 ཞི་གནས་དང་ལྷག་མཐོང་གི་རྣལ་འབྱོར [[འདི་ལྟར་མོས་པ་སྤྱོད་པའི་ས་གསུམ་སྦྱངས་ནས། འཇིག་རྟེན་ལས་འདས་པའི་ལམ་སྐྱེ་བར་འགྱུར་ཏེ།]]
         * 5.2.2.1 རགས་པའི་རྣལ་འབྱོར [[འདི་ལྟར་རྩོད་པའི་རྩ་བར་གྱུར་ཅིང་། འཁྲུག་ལོང་དུ་བྱེད་པ་ནི་རྣམ་པར་]]
         * 5.2.2.2 ཕྲ་བའི་རྣལ་འབྱོར [[དེ་ལྟར་རགས་པའི༌[^323]རྣལ་འབྱོར་བསྟན་ནས། ད་ནི་ཕྲ་བའི་རྣལ་འབྱོར་]]
      * 5.2.3 མོས་པ་སྤྱོད་པའི་སའི་རིམ་པ [[འདི་ལྟར་མོས་པ་སྤྱོད་པའི་ས་རྣམ་པ་གསུམ་ནི༌[^352]དགུར་འགྱུར་ཏེ།]]
      * 5.2.4 བསྒོམ་པའི་རིམ་པ [[ད་ནི་བསྒོམ་པའི་རིམ་པ་ཉིད་ལ་འཇུག་པར་བྱའོ། ། དེ་ལ་བྱང་ཆུབ་སེམས་དཔའ་]]
* 6. སློབ་དཔོན་གྱི་ཞལ་སྔ་ནས་ཀྱི་ཆེ་བ་བརྗོད་པའི་སྐབས [[འདིར་སངས་རྒྱས་ཡོངས་སུ༌[^441]མྱ་ངན་ལས་འདས་ཤིང་། བྱང་ཆུབ་སེམས་དཔའ་རྣམས་ཀྱང་]]
