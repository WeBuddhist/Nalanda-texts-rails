━━━ ISSUE TYPES ━━━

CONNECTOR_ENDING
  The block ends with a connector particle (དང་། / ཞིང་། / ཅིང་། / ནས། / ལས། /
  སྟེ། / ཏེ།) that grammatically requires continuation. Real issue if the next
  block is the grammatical continuation. False positive if this is a closing verse
  pāda or a deliberate short citation frame.

OBJECTION_REPLY_FUSED
  The block contains both an objection marker (ཅེ་ན། / ཞེ་ན། / སྙམ་ན།) and a reply
  opener (འོ་ན།). These should always be two separate blocks. Almost always a
  real issue.

OVER_LENGTH
  The block exceeds the syllable threshold. Usually NOT wrong: a whole explanation
  unit is legitimately long. Split only if a new node opener (ordinal + title +
  ནི། / ལ་ N།) or the treatment of a new verse is buried mid-block.

SHORT_FRAGMENT
  The block is suspiciously short — may be a stray split artifact that should be
  merged with an adjacent block.

འཇིག་རྟེན་ལས་འདས་པའི་ལམ་གྱིས༌[^2109]ཉོན་མོངས་པ་རྣམ་པར་སྦྱོང་བའི་དམིགས་པ་ཡང་རྣམ་པ་གཉིས་ཏེ། རྣམ་པར་བཞག་པའི་བདེན་པ་ལ་དམིགས་པ་དང་། རྣམ་པར་མ་བཞག་པའི་བདེན་པ་ལ་དམིགས་པ་སྟེ། དེ་ལྟར་དམིགས་པ་རྣམ་པ༌[^2110]བཞི་པོ་དེ་དག་གང་ལ་དམིགས་ཏེ། རྣལ་འབྱོར་གྱིས༌[^2111]ཡོངས་སུ་བསྡུས་པའི་ཞི་གནས་དང་ལྷག་མཐོང་གི་ལམ་གྱི་ངོ་བོ་ཉིད་དེ་ལ་སྦྱར་བར་བྱ་ཞིང་དམིགས་པ་གང་ནི་ལམ་གང་གི་དམིགས་པ་ཡིན་སྙམ་དུ༌[^2112]སེམས་པ་རྣམས་ཀྱི་བསམ་པ་ལ་བརྟགས་ནས། མི་ཕམ་པ༌[^2113]ཉིད་ཀྱིས༌[^2114]ཁྱབ་པའི་དམིགས་པ་ནི་འཇིག་རྟེན་པ་དང་འཇིག་རྟེན་ལས་འདས་པའི་ལམ་ཐམས་ཅད་དུ་འགྲོ་ཞིང་། སྤྱད་པ་རྣམ་པར་སྦྱོང་བའི་དམིགས་པ་ལ་སོགས་པ་དམིགས་པ་ཐམས་ཅད་ཀྱི༌[^2115]རྗེས་སུ་སོང་བ་དང་། འདས་པ་དང་། མ་འོངས་པ་དང་། ད་ལྟར་བྱུང་བའི་ཡང་དག་པར་རྫོགས་པའི་སངས་རྒྱས་ཐམས་ཅད་ཀྱིས༌[^2116]བཤད་པ་ཡིན་པ་དང་། དེ་དག་ནི་ལྷག་མཐོང་གི་ཕྱོགས་དང་། དངོས་པོ་ཐམས་ཅད་དང་ལྡན་པ་དང་། ཡང་དག་པའི་དངོས་པོ་དང་ལྡན་པ་དང་། རྒྱུ་དང་འབྲས་བུའི་དངོས་པོ་དང་ལྡན་པའི་དམིགས་པ་ཡིན་ཏེ། དེ་ལ་རྣམ་པར་རྟོག་པ་དང་བཅས་པའི་གཟུགས་བརྙན་ནི་ལྷག་མཐོང་གི་ཕྱོགས་ཀྱི་དམིགས་པ་ཡིན་ལ། རྣམ་པར་མི་རྟོག་པའི་གཟུགས་བརྙན་ནི་ཞི་གནས་ཀྱི་ཕྱོགས་ཀྱི༌[^2117]དམིགས་པ་ཡིན་ནོ།[^2118] ། དངོས་པོའི་མཐའ་ནི་ཇི་སྙེད་ཡོད་པ་ཉིད་དང་། ཇི་ལྟ་བ་བཞིན་དུ་ཡོད་པ་ཉིད་ཀྱི༌[^2119]དངོས་པོ་ཐམས་ཅད་དང་ལྡན་པ་དང་། ཡང་དག་པའི་དངོས་པོ་དང་ལྡན་པའི་དམིགས་པ་ཡིན། དགོས་པ་ཡོངས་སུ་གྲུབ་པ་ནི་ཡིད་ལ་བྱེད་པ་ཡོངས་སུ་གྲུབ་པའི་རྒྱུས་འབྲས་བུ་གནས་ངན་ལེན་སྤངས་པ་དང་། གནས་གྱུར་པ་དང་། དངོས་གཞི་ཐོབ་པ་དང་། ཤེས་བྱ་ལ་ཤེས་པ་དང་། མཐོང་བ་འཇུག་པ་ཉིད་ཀྱིས་རྒྱུ་དང་འབྲས་བུའི་དངོས་པོ་དང་ལྡན་པའི་དམིགས་པ་ཡིན་པས། དེ་དག་ནི་ཁྱབ་པའི་དམིགས་པ་ཞེས་བྱ་སྟེ། དེ་ཉིད་མངོན༌[^2120]དུ་བྱ་བ་མཁྱེན་ནས། བཅོམ་ལྡན་འདས་ཀྱིས་ཞི་གནས་དང་། ལྷག་མཐོང་གི་དམིགས་པའི་དངོས་པོ་བཞི་པོ་འདི་ལྟ་སྟེ། རྣམ་པར་རྟོག་པ་དང་བཅས་པའི་གཟུགས་བརྙན་དང་། རྣམ་པར་མི་རྟོག་པའི༌[^2121]གཟུགས་བརྙན་དང་། དངོས་པོའི་མཐའ་དང་། དགོས་པ་ཡོངས་སུ་གྲུབ་པའོ་ཞེས་གང་དག་བསྟན་པ་དེ་ལ་ཞེས་བྱ་བ་ལ་སོགས་པས་དམིགས་པ་སྦྱོར་བའི་རྒྱུ་གང་ཡིན་པ་དང་། དམིགས་པ་གང་ནི་ལམ་གང་གི་དམིགས་པ་ཡིན་པར་སྦྱར་རོ། །

###### **སེམས་གནས་པ་དགུ།** ^4-2-4-2-2-1-2-1-0

[Block 1483 — OVER_LENGTH (687 syllables)]
སེམས་གནས་པ་དགུ་གང་ཞེ་ན། སེམས་འཇོག་པར་བྱེད་པ་དང་། ཡང་དག་པར་འཇོག་པར་བྱེད་པ་དང་། བསྡུས་ཏེ་འཇོག་པར་བྱེད་པ་དང་། ཉེ་བར་འཇོག་པར་བྱེད་པ་དང་། དུལ་བར་བྱེད་པ་དང་། ཞི་བར་བྱེད་པ་དང་། ཉེ་བར་ཞི་བར་བྱེད་པ་དང་། རྒྱུད་གཅིག་ཏུ་བྱེད་པ་དང་། ཏིང་ངེ་འཛིན་དུ་བྱེད་པའོ། །དེ་ལ་ཇི་ལྟར་ན་འཇོག་པར་བྱེད་པ་ཡིན་ཞེ་ན། ཕྱི་རོལ་གྱི་དམིགས་པ་ཐམས་ཅད་ལས་ཡང་དག་པར་བསྡུས་ཏེ། རྣམ་པར་མི་གཡེང་བར་བྱ་བའི་ཕྱིར་དང་པོ་ཉིད་དུ༌[^2159]ཉེ་བར་རྟོགས་པར༌[^2160]བྱེད་པ་གང་ཡིན་པ་དེ་ནི་འཇོག་པར་བྱེད་པ་ཡིན་ནོ། །ཇི་ལྟར་ཡང་དག་པར་འཇོག་པར་བྱེད་པ་ཡིན་ཞེ་ན། དང་པོར་ཉེ་བར་བརྟགས་པའི༌[^2161]སེམས་གང་ཡིན་པ་དེ་གཡོ་བ་དང་། རགས་པ་དང་། ཡང་དག་པར་མི་གནས་པ་དང་། ཡོངས་སུ་མི་གནས་པར་གྱུར་ན་དེ་དམིགས་པ་དེ་ཉིད་ལ་བརྟོད༌[^2162]པའི་ཚུལ་དང་། དང་བར་བྱ་བའི་ཚུལ་གྱིས་མངོན་པར་ཚར་བཅད་པ་དང་བཅས་པས་ཕྲ་བར་བྱེད་ཅིང་། མངོན་པར་གཡེང་བར་མི་བྱེད་པ་གང་ཡིན་པ་དེ་ནི་ཡང་དག་པར་འཇོག་པར་བྱེད་པ་ཡིན་ནོ། །ཇི་ལྟར་ན་བསྡུས་ཏེ་འཇོག་པར་བྱེད་པ་ཡིན་ཞེ་ན། དེ་ལྟར་དེའི་སེམས་གཞག་པ་དང་། ཡང་དག་པར་གཞག་པ་དེ་གལ་ཏེ་བརྗེད་ངས་པས་ཕྱི་རོལ་དུ་རྣམ་པར་གཡེང་བར་གྱུར་ན་དེ༌[^2163]ཡང་ཕྱིས་དེ་ཉིད་ལ་སྡུད༌[^2164]པར་བྱེད་དེ། དེ་ལྟར་ན་བསྡུས་ཏེ་འཇོག་པར་བྱེད་པ་ཡིན་ནོ། །ཇི་ལྟར་ན་ཉེ་བར་འཇོག་པར་བྱེད་པ་ཡིན་ཞེ་ན། དང་པོ་ཁོ་ནར་དེ་ལྟ་དེ་ལྟར་དྲན་པ་ཉེ་བར་གཞག་སྟེ་གནས་ཤིང་སེམས་དེ་ཡང་དག་པར་འཇོག་པར་བྱེད་པ་ན། ཅི་ནས་ཀྱང་དེའི་སེམས་དེ་ཕྱི་རོལ་དུ་མི་འཕྲོ་བར་བྱེད་དེ། དེ་ལྟར་ན་ཉེ་བར་འཇོག་པར་བྱེད་པ་ཡིན་ནོ། །ཇི་ལྟར་འདུལ་བར་བྱེད་པ་ཡིན་ཞེ་ན། གཟུགས་དང་། སྒྲ་དང་། དྲི་དང་། རོ་དང་། རེག་བྱའི་མཚན་མའམ།[^2165] འདོད་ཆགས་དང་། ཞེ་སྡང་དང་། གཏི་མུག་དང་། སྐྱེས་པ་དང་། བུད་མེད་ཀྱི་མཚན་མ་གང་གིས་དེའི་སེམས་རྣམ་པར་གཡེང་བར་འགྱུར་ན། དེ་ལ་དེས་དང་པོ་ཉིད་ནས་ཉེས་དམིགས་ཀྱི་འདུ་ཤེས་སུ་བཟུང་བ༌[^2166]དེ་ཉིད་ཀྱི་དབང་དུ་བྱས་ནས། མཚན་མ་དེ་དག་ལ་དེའི་སེམས་འཕྲོར་མི་སྟེར་བར་བྱེད་དེ། དེ་ལྟར་ན་དུལ་བར་བྱེད་པ་ཡིན་ནོ། །ཇི་ལྟར་ན་ཞི་བར་བྱེད་པ་ཡིན་ཞེ་ན། འདོད་པའི་རྣམ་པར་རྟོག་པ་ལ་སོགས་པ་རྣམ་པར་རྟོག་པ་གང་དག་དང་། འདོད་པ་ལ་འདུན་པ་ལ་སོགས་པ་ཉེ་བའི་ཉོན་མོངས་པ་གང་དག་གིས་དེའི་སེམས་ཀུན་ཏུ་འཁྲུགས་པར༌[^2167]གྱུར་ན། དེ་ལ་དེས་དང་པོ་ཉིད་ནས་ཉེས་དམིགས་ཀྱི་འདུ་ཤེས་སུ་བཟུང་བ་དེ་ཉིད་ཀྱི་དབང་དུ་བྱས་ནས་རྣམ་པར་རྟོག་པ་དང་ཉེ་བའི་ཉོན་མོངས་པ་དེ་དག་ལས༌[^2168]དེའི་སེམས་འཕྲོར་མི་སྟེར་བར་བྱེད་དེ། དེ་ལྟར་ན་ཞི་བར་བྱེད་པ་ཡིན་ནོ། །ཇི་ལྟར་ན་ཉེ་བར་ཞི་བར་བྱེད་པ་ཡིན་ཞེ་ན། དེ་བརྗེད་ངས་པའི་ཕྱིར་རྣམ་པར་རྟོག་པ་དང་ཉེ་བའི་ཉོན་མོངས་པ་དེ་གཉིས་ཀ་ཀུན་དུ་འབྱུང་བར་འགྱུར་ན། བྱུང་ངོ་ཅོག་དང་དུ་མི་ལེན་ཅིང་སྤོང་བར་བྱེད་དེ། དེ་ལྟར་ན་ཉེ་བར་ཞི་བར་བྱེད་པ་ཡིན་ནོ། །ཇི་ལྟར་ན་རྒྱུད་གཅིག༌[^2169]ཏུ་བྱེད་པ་ཡིན་ཞེ་ན། མངོན་པར་འདུ་བྱེད་པ་དང་བཅས་པས་བར་དུ་ཆད་པ་མེད་པ་དང་། རྒྱུན་ཆགས་པར༌[^2170]ཏིང་ངེ་འཛིན་གྱི་རྒྱུན་ལ་འཇོག་པར་བྱེད་དེ། དེ་ལྟར་ན་རྒྱུད་གཅིག༌[^2171]ཏུ་བྱེད་པ་ཡིན་ནོ། །ཇི་ལྟར་ན་ཏིང་ངེ་འཛིན་དུ་བྱེད་པ་ཡིན་ཞེ་ན། ཀུན་དུ་བརྟེན་ཅིང་གོམས་པར་བྱས་ལན་མང་དུ་བྱས་པའི་རྒྱུས༌[^2172]ལྷུན་གྱིས་གྲུབ་པའི་འཇུག་པ་དང་། རྣམ་པར་མི་རྟོག་པའི་ཞི་གནས་ཀྱི་རྣམ་པ་དེས་རབ་ཏུ་ཕྱེ་བ་ཤེས་བྱའི་དངོས་པོ་དང་ཆ་མཐུན་པ་སེམས་ཀྱི་གཟུགས་བརྙན་རང་རིག་པ་གང་ཡིན་པ་དེ་ནི་གཟུགས་བརྙན་ཞེས་བྱའོ་ཞེས་བྱ་བ་ལ། ཤེས་བྱའི་དངོས་པོ་དང་ཆ་མཐུན་པ་ཞེས་བྱ་བ་ནི་སྔ་མ་བཞིན་ཏེ། སྔར་རྣམ་པར་རྟོག་པ་དང་བཅས་པའི་ལྷག་མཐོང་གིས་མཉམ་པར་གཞག་པའི་ས་པའི་ཡིད་ལ་བྱེད་པ་ལ་བརྟེན་ནས། ཤེས་བྱའི་དངོས་པོའི་རྣམ་པ་རང་གི་བློ་ལ་སྣང་བར་བྱ་བའི་ཕྱིར་མོས་པ་ཡིད་ལ་བྱས་སམ་དེ་ཁོ་ན་ཉིད་ཡིད་ལ་བྱས་ཏེ། རྣམ་པར་རྟོག་པ་དང་བཅས་པའི་གཟུགས་བརྙན་གྱི་དམིགས་པ་ཐོབ་པ་དེ་ཉིད་དོ། །དེ་ལ་བྱེ་བྲག་ཏུ་ན་འདིར་ནི་གཟུགས་བརྙན་དེ་ཉིད་ལ་ལྷག་མཐོང་གི་རྣམ་པས་མོས་པར་མི་བྱེད་པར་ཞི་གནས་ཀྱི་རྣམ་པས་དེ་ཁོ་ན་ཉིད་ཡིད་ལ་བྱེད་པ་སེམས་ཀྱི་ངོ་བོ་ཉིད་དུ་ཡིད་ལ་བྱེད་ཅིང་། རྩེ་གཅིག་ཏུ་མཉམ་པར་བྱེད་དོ། །སེམས་ཀྱི་གཟུགས་བརྙན་རང་རིག་པ་ཞེས་བྱ་བ་ཡང་སྔ་མ་བཞིན་ཏེ། ཤེས་བྱའི་དངོས་པོ་དང་ཆ་མཐུན་པ་དེ་ཉིད་ཕྱི་རོལ་གྱི་ཤེས་བྱའི་དངོས་པོ་མ་ཡིན་གྱི། ནང་གི་ཞི་གནས་ཀྱི་སེམས་ཀྱི་རྣམ་པ་ཉིད་གཟུགས་བརྙན་རང་རིག་པ་དེ་ལྟ་བུར་སྣང་བའི་ཕྱིར་ཏེ། དེ་ནི་རྣམ་པར་མི་རྟོག་པའི་གཟུགས་བརྙན་ཞེས་བྱའོ། །

རྣམ་པར་མི་རྟོག་པའི་ཞི་གནས་ཀྱི་རྣམ་པ་དེས་རབ་ཏུ་ཕྱེ་བ་ཤེས་བྱའི་དངོས་པོ་དང་ཆ་མཐུན་པ་སེམས་ཀྱི་གཟུགས་བརྙན་རང་རིག་པ་གང་ཡིན་པ་དེ་ནི་གཟུགས་བརྙན་ཞེས་བྱའོ་ཞེས་བྱ་བ་ལ། ཤེས་བྱའི་དངོས་པོ་དང་ཆ་མཐུན་པ་ཞེས་བྱ་བ་ནི་སྔ་མ་བཞིན་ཏེ། སྔར་རྣམ་པར་རྟོག་པ་དང་བཅས་པའི་ལྷག་མཐོང་གིས་མཉམ་པར་གཞག་པའི་ས་པའི་ཡིད་ལ་བྱེད་པ་ལ་བརྟེན་ནས། ཤེས་བྱའི་དངོས་པོའི་རྣམ་པ་རང་གི་བློ་ལ་སྣང་བར་བྱ་བའི་ཕྱིར་མོས་པ་ཡིད་ལ་བྱས་སམ་དེ་ཁོ་ན་ཉིད་ཡིད་ལ་བྱས་ཏེ། རྣམ་པར་རྟོག་པ་དང་བཅས་པའི་གཟུགས་བརྙན་གྱི་དམིགས་པ་ཐོབ་པ་དེ་ཉིད་དོ། །དེ་ལ་བྱེ་བྲག་ཏུ་ན་འདིར་ནི་གཟུགས་བརྙན་དེ་ཉིད་ལ་ལྷག་མཐོང་གི་རྣམ་པས་མོས་པར་མི་བྱེད་པར་ཞི་གནས་ཀྱི་རྣམ་པས་དེ་ཁོ་ན་ཉིད་ཡིད་ལ་བྱེད་པ་སེམས་ཀྱི་ངོ་བོ་ཉིད་དུ་ཡིད་ལ་བྱེད་ཅིང་། རྩེ་གཅིག་ཏུ་མཉམ་པར་བྱེད་དོ། །སེམས་ཀྱི་གཟུགས་བརྙན་རང་རིག་པ་ཞེས་བྱ་བ་ཡང་སྔ་མ་བཞིན་ཏེ། ཤེས་བྱའི་དངོས་པོ་དང་ཆ་མཐུན་པ་དེ་ཉིད་ཕྱི་རོལ་གྱི་ཤེས་བྱའི་དངོས་པོ་མ་ཡིན་གྱི། ནང་གི་ཞི་གནས་ཀྱི་སེམས་ཀྱི་རྣམ་པ་ཉིད་གཟུགས་བརྙན་རང་རིག་པ་དེ་ལྟ་བུར་སྣང་བའི་ཕྱིར་ཏེ། དེ་ནི་རྣམ་པར་མི་རྟོག་པའི་གཟུགས་བརྙན་ཞེས་བྱའོ། །

ཅིའི་ཕྱིར་རྣམ་པར༌[^2183]མི་རྟོག་པའི་གཟུགས་བརྙན་ཞེས་བྱ་ཞེ་ན། རྣམ་པར་མི་རྟོག་པའི་ཞི་གནས་ཀྱི་རྣམ་པའི་སེམས་དེས། སེམས་ཀྱི་གཟུགས་བརྙན་རང་རིག༌[^2184]པ་དེ་ཉིད་ལ་ཁོ་ན་ཉིད་ཡིད་ལ་བྱེད་པས་སེམས་ཀྱི་ངོ་བོ་ཉིད་དུ་ཡིད་ལ་བྱེད་ཅིང་། རྩེ་གཅིག་ཏུ་མཉམ་པར་འཇོག་པ་ན་རྣམ་པར་མི་རྟོག་པའི་ཞི་གནས་ཀྱི་རྣམ་པའི་སེམས་དེ་ཉིད་གཟུགས་བརྙན་གྱི་རྣམ་པ་དེ་ལྟ་བུར་སྣང་བའི་ཕྱིར་ཏེ། དེ་བས་ན་དེ་ཉིད༌[^2185]ནི་ཞི་གནས་ཀྱི་རྣམ་པས་རབ་ཏུ་ཕྱེ་བ་ཞེས་བྱའོ། །གཟུགས་བརྙན་ཞེས་བྱ་བའི༌[^2186]སྒྲ་ཡང་སྔ་མ་བཞིན་ཏེ། འདིར་གཟུགས་བརྙན་ལྟ་བུར་ལྟ་བ་ནི་རྣམ་པར་མི་རྟོག་པའི་ཞི་གནས་ཀྱི་རྣམ་པའི་སེམས་ཉིད་ཡིན་ལ། གཟུགས་བརྙན་ལྟ་བུར་ལྟ་བ་ནི་སེམས་ཀྱི་གཟུགས་བརྙན་རང་རིག་པ་བློ་ལ་སྣང་བ་ཡིན་ཏེ། རྣམ་པར་མི་རྟོག་པའི་གཟུགས་བརྙན་གྱི་དམིགས་པ་ཐོབ་པ་དང་། ཞི་གནས་ཀྱི་ལམ་སྐྱེ་བ་ནི་འབྱུང་བའི་དུས་ཀྱང་གཅིག །[^2187]ངོ་བོ་ཉིད་དང་གཅིག་པ་ཉིད་ཀྱི༌[^2188]རྣམ་པར་མི་རྟོག་པའི་སེམས་ཀྱི་སྤྱོད་ཡུལ་ལྟ་བུར་བློ་ལ་སྣང་བས་ན་གཟུགས་བརྙན་ཞེས་བྱའོ། །

དངོས་པོའི་མཐའ་ཞེས་བྱ་བ་ནི་ཟུང་དུ་འབྲེལ་པས་རབ་ཏུ་ཕྱེ་བ་དམིགས་པ་དང་གནས་ཀྱི་དངོས་པོའི་མཐའ་གནས་གྱུར་པའི་ངོ་བོ་ཉིད་གང་ཡིན་པ་སྟེ། དེ་ལ་དངོས་པོ་ཞེས་བྱ་བ་ནི་ལྷག་མཐོང་དང་ཞི་གནས་ཀྱི་དམིགས་པ་རྣམ་པར་རྟོག་པ་དང་བཅས་པའི་གཟུགས་བརྙན་དང་། རྣམ་པར་མི་རྟོག་པའི་གཟུགས་བརྙན་གྱི་དངོས་པོ་ཀུན་གཞི་རྣམ་པར་ཤེས་པའོ། །མཐའ་ཞེས་བྱ་བ་ནི་དེའི་ཇི་སྙེད་ཡོད་པ་ཉིད་དང་། ཇི་ལྟ་བ་བཞིན་དུ་ཡོད་པ་ཉིད་ཀྱི་མཐར་གྱུར་པ་གནས་གྱུར་པའི་ངོ་བོ་ཉིད་དོ། །དེ་ཅིའི་ཕྱིར་དམིགས་པ་དེ་ཉིད་ལ་དངོས་པོ་ཞེས་བྱ་ཞེ་ན། དེ་གཉིས་ནི་ཞི་གནས་དང་ལྷག་མཐོང་གི་དངོས་པོའི་དམིགས་པ་དང་གནས་ཀྱི་དངོས་པོ་ཡིན་པའི་ཕྱིར་ཏེ། དེ་ལ་དམིགས་པའི་དངོས་པོའི་ཞེས་བྱ་བ་ནི་ཞི་གནས་དང་ལྷག་མཐོང་ནི་དམིགས་པ་གང་གིས༌[^2197]བསྐྱེད་པ་དེ་ཉིད་ལ་དམིགས་པ་ཡིན་པས་མཉམ་པར་གཞག་པའི་ས་པའི་མོས་པའི༌[^2198]ཡིད་ལ་བྱེད་པ་དང་། དེ་ཁོ་ན་ཉིད་ཡིད་ལ་བྱེད་པའི་མཐུས་རྣམ་པར་རྟོག་པ་དང་བཅས་པ་དང་། རྣམ་པར་མི་རྟོག་པའི་གཟུགས་བརྙན་གྱི་དམིགས་པ་ཐོབ་པར་གྱུར་པ་དེས་ཞི་གནས་དང་ལྷག་མཐོང་བསྐྱེད་ལ། ཞི་གནས་དང་ལྷག་མཐོང་ཡང་གཟུགས་བརྙན་གྱི་དམིགས་པ་དེ་ཉིད་ལ་དམིགས་པར་བྱེད་པའི་ཕྱིར་གཟུགས་བརྙན་གྱི་དམིགས་པ་ཀུན་གཞིའི་རྣམ་པར་ཤེས་པའི་ངོ་བོ་ཉིད་དེ་ནི་ཞི་གནས་དང་ལྷག་མཐོང་སེམས་ལས་བྱུང་བའི་ངོ་བོ་ཉིད་དེའི་དམིགས་པའི་དངོས་པོ་ཞེས་བྱའོ། །དེ་ལ་གནས་ཀྱི་དངོས་པོ་ཞེས་བྱ་བ་ནི་ཀུན་གཞི་རྣམ་པར་ཤེས་པ་སེམས་དང༌[^2199]སེམས་ལས་བྱུང་བའི་ཆོས་ཐམས་ཅད་ཀྱི་གནས་ཀྱི་དངོས་པོ་ཡིན་པས་མཉམ་པར་གཞག་པའི་ས་པའི་མོས་པའི་ཡིད་ལ་བྱེད་པ་དང་། དེ་ཁོ་ན་ཉིད་ཡིད་ལ་བྱེད་པའི་མཐུས་རྣམ་པར་རྟོག་པ་དང་བཅས་པ་དང་། རྣམ་པར་མི་རྟོག་པའི་གཟུགས་བརྙན་གྱི་དམིགས་པ་ཐོབ་པར་གྱུར་པ་དེ་ནི་ཀུན་གཞིའི་རྣམ་པར་ཤེས་པའི་ངོ་བོ་ཉིད་ཡིན་ལ། དམིགས་པ་དེ་ལ་བརྟེན་ཏེ་སྐྱེས་པའི་ཞི་གནས་དང་ལྷག་མཐོང་ནི་མཉམ་པར་གཞག་པའི་ས་པའི་སེམས་ལས་བྱུང་བའི་ཏིང་ངེ་འཛིན་དང་། ཤེས་རབ་ཀྱི་ངོ་བོ་ཉིད་ཡིན་པའི་ཕྱིར་གཟུགས་བརྙན་གྱི་དམིགས་པ་ཀུན་གཞིའི་རྣམ་པར་ཤེས་པའི་ངོ་བོ་ཉིད་དེ་ནི་ཞི་གནས་དང་ལྷག་མཐོང་དེ་ནི་སེམས་ལས་བྱུང་བའི་ངོ་བོ་ཉིད་དེའི་གནས་ཀྱི་དངོས་པོ་ཞེས་བྱ་སྟེ། དེའི་ཕྱིར་གཟུགས་བརྙན་དེ་ནི་དམིགས་པ་དང་གནས་ཀྱི་དངོས་པོ་ཞེས་བྱའོ། །

དེ་ལྟར་མཐོང་བའི་ཞི་གནས་ཀྱི་སེམས་དེ་ནི་ཡིད་ལ་བྱེད་པ་ཐོབ་པའི་ལམ་གྱིས་རབ་ཏུ་ཕྱེ་བའི་ཞི་གནས་ཀྱི་རྣམ་པ་སེམས་གནས་པ༌[^2189]དགུས་བསྡུས་པ་སྟོབས་དྲུག་དང་ལྡན་པའི་ཡིད་ལ་བྱེད་པ་བཞིས་འཇུག་པ་ཡིན་ལ། སྦྱོར་བ་མཐར་ཐུག་པའི་ལམ་གྱི་ཡིད་ལ་བྱེད་པའི་གནས་སྐབས་ཡིན་པས་དེའི་ཕྱིར་རྣམ་པར་མི་རྟོག་པ་ཞེས་བྱའོ། །ཡང་དེས་སེམས་ཀྱི༌[^2190]གཟུགས་བརྙན་རང་རིག་པ་དེ་ལ་ལྷག་མཐོང་གི་རྣམ་པས་རྣམ་པར་འབྱེད་པར་མི་བྱེད། རབ་ཏུ་རྣམ་པར་འབྱེད་པར་མི་བྱེད། ཡོངས་སུ་རྟོག་པར་མི་བྱེད། ཡོངས་སུ་དཔྱོད་པར་མི་བྱེད་པར་དམིགས་པའི་མཚན་མ་དེ་ཉིད་མི་གཏོང་བའི༌[^2191]ཞི་གནས་ཀྱི་རྣམ་པས་སེམས་ནང་ཁོ་ནར་འཇོག་པར་བྱེད། ཡང་དག་པར་འཇོག་པར་བྱེད། བསྡུས་ཏེ་འཇོག་པར་བྱེད། ཉེ་བར་འཇོག་པར་བྱེད། དུལ་བར་བྱེད། ཞི་བར་བྱེད། ཉེ་བར་ཞི་བར་བྱེད། རྒྱུད་གཅིག་ཏུ་བྱེད། ཏིང་ངེ་འཛིན་དུ་བྱེད་པས་ན་རྣམ་པར་མི་རྟོག་པ་ཞེས་བྱའོ། །སྔར་རྣམ་པར་རྟོག་པ་དང་བཅས་པའི་རྣམ་གྲངས་ཇི་སྐད་བསྟན་པ་དག་ལས༌[^2192]བཟློག་པའི་རྣམ་གྲངས་ཐམས་ཅད་ཀྱང་དེ་བཞིན་དུ་ཅི་རིགས་པར་སྦྱར་ཏེ། དེ་དག་ནི་རྣམ་པར་མི་རྟོག་པ་དེའི་མིང་གི་རྣམ་གྲངས་ཡིན་ནོ།[^2193] །གཟུགས་བརྙན་གྱི་མིང་གི་རྣམ་གྲངས་ནི་སྔ་མ་ཁོ་ན་བཞིན་ནོ། །བྱེ་བྲག་ཏུ་ན་སྔ་མ་ནི་ལྷག་མཐོང་གིས་རབ་ཏུ་ཕྱེ་བ་ཡིན་ལ་འདི་ནི་ཞི་གནས་ཀྱིས་རབ་ཏུ་ཕྱེ་བ་ཡིན་ཏེ། དེ་གཉིས་ཀ་ལ་ཡང་ལྷག་མཐོང་དང་ཞི་གནས་གཉིས་ཀའི་ཆ་ཡོད་མོད་ཀྱི་ཟུང་དུ་འབྲེལ་པའི་ལམ་མ་ཐོབ་པའི་གནས་སྐབས་ན། སྔ་མ་ནི་དམིགས་པ་མ༌[^2194]ཐོབ་པ་ཐོབ་པར་བྱེད་པ་ཡིན་པས་རྟོག་པའི་ཤས་ཆེ་བའི་ཕྱིར་ལྷག་མཐོང་གིས་རབ་ཏུ་ཕྱེ་བ་ཞེས་བྱ། འདི་ནི་དམིགས་པ་ཐོབ་པ་གོམས་པར་བྱེད་པ་ཡིན་པས་རྟོགས་པ༌[^2195]ཤས་ཆུང་བའི་ཕྱིར་ཞི་གནས་ཀྱིས༌[^2196]རབ་ཏུ་ཕྱེ་བ་ཞེས་བྱའོ། །

དངོས་པོའི་མཐའ་ཞེས་བྱ་བ་ནི་ཟུང་དུ་འབྲེལ་པས་རབ་ཏུ་ཕྱེ་བ་དམིགས་པ་དང་གནས་ཀྱི་དངོས་པོའི་མཐའ་གནས་གྱུར་པའི་ངོ་བོ་ཉིད་གང་ཡིན་པ་སྟེ། དེ་ལ་དངོས་པོ་ཞེས་བྱ་བ་ནི་ལྷག་མཐོང་དང་ཞི་གནས་ཀྱི་དམིགས་པ་རྣམ་པར་རྟོག་པ་དང་བཅས་པའི་གཟུགས་བརྙན་དང་། རྣམ་པར་མི་རྟོག་པའི་གཟུགས་བརྙན་གྱི་དངོས་པོ་ཀུན་གཞི་རྣམ་པར་ཤེས་པའོ། །མཐའ་ཞེས་བྱ་བ་ནི་དེའི་ཇི་སྙེད་ཡོད་པ་ཉིད་དང་། ཇི་ལྟ་བ་བཞིན་དུ་ཡོད་པ་ཉིད་ཀྱི་མཐར་གྱུར་པ་གནས་གྱུར་པའི་ངོ་བོ་ཉིད་དོ། །དེ་ཅིའི་ཕྱིར་དམིགས་པ་དེ་ཉིད་ལ་དངོས་པོ་ཞེས་བྱ་ཞེ་ན། དེ་གཉིས་ནི་ཞི་གནས་དང་ལྷག་མཐོང་གི་དངོས་པོའི་དམིགས་པ་དང་གནས་ཀྱི་དངོས་པོ་ཡིན་པའི་ཕྱིར་ཏེ། དེ་ལ་དམིགས་པའི་དངོས་པོའི་ཞེས་བྱ་བ་ནི་ཞི་གནས་དང་ལྷག་མཐོང་ནི་དམིགས་པ་གང་གིས༌[^2197]བསྐྱེད་པ་དེ་ཉིད་ལ་དམིགས་པ་ཡིན་པས་མཉམ་པར་གཞག་པའི་ས་པའི་མོས་པའི༌[^2198]ཡིད་ལ་བྱེད་པ་དང་། དེ་ཁོ་ན་ཉིད་ཡིད་ལ་བྱེད་པའི་མཐུས་རྣམ་པར་རྟོག་པ་དང་བཅས་པ་དང་། རྣམ་པར་མི་རྟོག་པའི་གཟུགས་བརྙན་གྱི་དམིགས་པ་ཐོབ་པར་གྱུར་པ་དེས་ཞི་གནས་དང་ལྷག་མཐོང་བསྐྱེད་ལ། ཞི་གནས་དང་ལྷག་མཐོང་ཡང་གཟུགས་བརྙན་གྱི་དམིགས་པ་དེ་ཉིད་ལ་དམིགས་པར་བྱེད་པའི་ཕྱིར་གཟུགས་བརྙན་གྱི་དམིགས་པ་ཀུན་གཞིའི་རྣམ་པར་ཤེས་པའི་ངོ་བོ་ཉིད་དེ་ནི་ཞི་གནས་དང་ལྷག་མཐོང་སེམས་ལས་བྱུང་བའི་ངོ་བོ་ཉིད་དེའི་དམིགས་པའི་དངོས་པོ་ཞེས་བྱའོ། །དེ་ལ་གནས་ཀྱི་དངོས་པོ་ཞེས་བྱ་བ་ནི་ཀུན་གཞི་རྣམ་པར་ཤེས་པ་སེམས་དང༌[^2199]སེམས་ལས་བྱུང་བའི་ཆོས་ཐམས་ཅད་ཀྱི་གནས་ཀྱི་དངོས་པོ་ཡིན་པས་མཉམ་པར་གཞག་པའི་ས་པའི་མོས་པའི་ཡིད་ལ་བྱེད་པ་དང་། དེ་ཁོ་ན་ཉིད་ཡིད་ལ་བྱེད་པའི་མཐུས་རྣམ་པར་རྟོག་པ་དང་བཅས་པ་དང་། རྣམ་པར་མི་རྟོག་པའི་གཟུགས་བརྙན་གྱི་དམིགས་པ་ཐོབ་པར་གྱུར་པ་དེ་ནི་ཀུན་གཞིའི་རྣམ་པར་ཤེས་པའི་ངོ་བོ་ཉིད་ཡིན་ལ། དམིགས་པ་དེ་ལ་བརྟེན་ཏེ་སྐྱེས་པའི་ཞི་གནས་དང་ལྷག་མཐོང་ནི་མཉམ་པར་གཞག་པའི་ས་པའི་སེམས་ལས་བྱུང་བའི་ཏིང་ངེ་འཛིན་དང་། ཤེས་རབ་ཀྱི་ངོ་བོ་ཉིད་ཡིན་པའི་ཕྱིར་གཟུགས་བརྙན་གྱི་དམིགས་པ་ཀུན་གཞིའི་རྣམ་པར་ཤེས་པའི་ངོ་བོ་ཉིད་དེ་ནི་ཞི་གནས་དང་ལྷག་མཐོང་དེ་ནི་སེམས་ལས་བྱུང་བའི་ངོ་བོ་ཉིད་དེའི་གནས་ཀྱི་དངོས་པོ་ཞེས་བྱ་སྟེ། དེའི་ཕྱིར་གཟུགས་བརྙན་དེ་ནི་དམིགས་པ་དང་གནས་ཀྱི་དངོས་པོ་ཞེས་བྱའོ། །

དེ་ལ་ཅིའི་ཕྱིར་དངོས་པོ་དེའི་ཇི་སྙེད་ཡོད་པ་ཉིད་དང་། ཇི་ལྟ་བ་བཞིན་དུ་ཡོད་པ་ཉིད་ལ་མཐའ་ཞེས་བྱ་ཞེ༌[^2200]ན། དེ་ཙམ་གྱིས་ནི་རྣམ་གྲངས་ཀྱི་མཐར་ཕྱིན་པ་དང་། མཚན་ཉིད་ཀྱི་མཐར་ཕྱིན་པར་གྱུར་པའི་ཕྱིར་ཏེ། དེ་ལ་ཇི་སྙེད་ཡོད་པ་ཉིད་ཅེས་བྱ་བ་ནི་རྣམ་གྲངས་ཏེ། དཔེར་ན་ཕུང་པོ་ནི་ལྔ་ཁོ་ནར་ཟད་དེ། དེ་དག་གིས་འདུས་བྱས་ཐམས་ཅད་བསྡུས་སོ། །ཁམས་ནི་བཅོ་བརྒྱད་ཁོ་ནའོ། །སྐྱེ་མཆེད་ནི་བཅུ་གཉིས་ཁོ་ན་སྟེ།[^2201] དེ་དག་གིས་ནི་འདུས་བྱས་དང་འདུས་མ་བྱས་ཀྱི་ཆོས་ཐམས་ཅད་བསྡུས་སོ། །འཕགས་པའི༌[^2202]བདེན་པ་ནི་བཞི༌[^2203]ཁོ་ན་སྟེ།[^2204] དེ་དག་གིས་ནི་ཤེས་བྱའི་དངོས་པོ་ཐམས་ཅད་བསྡུས་སོ་ཞེས་བྱ་བ་ནི་ཇི་སྙེད་ཡོད་པ་ཉིད་དོ། །ཇི་ལྟ་བ་བཞིན་དུ་ཡོད་པ་ཉིད་ནི་མཚན་ཉིད་དེ། དཔེར་ན་ཇི་སྙེད་ཡོད་པ་ཉིད་ཀྱི་རྣམ་པ་དེ་དག་གིས༌[^2205]ཡང་དག་པ་ཉིད་དང་། དེ་བཞིན་ཉིད་རིགས་པ་བཞི་དང་ལྡན་པ་ནི་ཇི་ལྟ་བ་བཞིན་དུ་ཡོད་པ་ཉིད་ཅེས་བྱའོ། །དེ་དང་འདྲ་བར་འདིར་ཡང་ཀུན་གཞིའི་རྣམ་པར་ཤེས་པའི་འཇུག་པ་རྣམ་པར་གཞག་པའི་རྣམ་གྲངས་ཇི་སྙེད་པ་ཐམས་ཅད་ནི་ཇི་སྙེད་པ་ཡོད་པ་ཉིད་དོ། །ལྡོག་པ་རྣམ་པར་གཞག་པའི་མཚན་ཉིད་ཅི་འདྲ་བ་ནི་ཇི་ལྟ་བ་བཞིན་དུ་ཡོད་པ་ཉིད་ཅེས་བྱ་སྟེ། དེ་ཙམ་གྱིས་ན་དངོས་པོ་དེའི་མཐར་ཕྱིན་པའི་ཕྱིར་ཇི་སྙེད་ཡོད་པ་ཉིད་དང་། ཇི་ལྟ་བ་བཞིན་དུ་ཡོད་པ་ཉིད་ནི་དངོས་པོ་དེའི་མཐའ་ཞེས་བྱའོ། །དེ་ཡང་གང་གི་དུས་ན་དངོས་པོ་དེའི་མཐར་གྱུར་པ་ཡིན་ཞེ་ན། གང་གི་ཚེ་ཀུན་གཞིའི་རྣམ་པར་ཤེས་པ་གནས་གྱུར་པ་དེའི་ཚེ་ན་དངོས་པོ་དེའི་རྣམ་གྲངས་དང་མཚན་ཉིད་ཀྱི་མཐར་གྱུར་པ་ཡིན་ནོ། །དེ་ལྟར་ན་དམིགས་པ་དང་གནས་ཀྱི་དངོས་པོའི་མཐའ་གནས་གྱུར་པའི་ངོ་བོ་ཉིད་ནི་དངོས་པོའི་མཐའ་ཞེས་བྱ་སྟེ། དེ་ནི་སྤངས་པ་ཕུན་སུམ་ཚོགས་པ་ཡིན་ནོ། །དེ་ཡང་གང་གིས་རབ་ཏུ་ཕྱེ་བ་ཡིན་ཞེ་ན། ཞི་གནས་དང་ལྷག་མཐོང་ཟུང་དུ་འབྲེལ་པས་རབ་ཏུ་ཕྱེ་བ་ཡིན་ཏེ། གང་གི་ཚེ་ཟུང་དུ་འབྲེལ་པའི་ལམ་སྐྱེས་པ་དེའི་ཚེ་ན་གནས་གྱུར་པ༌[^2206]ཐོབ་པ་ཡིན་ལ། གནས་གྱུར་པའི་དེ་བཞིན་ཉིད་དེ་ཡང་ཟུང་དུ་འབྲེལ་པའི་ལམ་གྱི་དམིགས་པ་ཡིན་པས་གནས་གྱུར་པའི་དམིགས་པ་འཐོབ་པ་དང་ཟུང་དུ་འབྲེལ་པའི་ལམ་སྐྱེ་བ་ནི་འབྱུང་བའི་དུས་ཀྱང་གཅིག་ངོ་བོ་ཉིད་དང་གཅིག་པས་ན་ཟུང་དུ་འབྲེལ་པས་རབ་ཏུ་ཕྱེ་བ་ཞེས་བྱ་སྟེ། དེ་ནི་དངོས་པོའི་མཐའ་ཡིན་ནོ། །

དངོས་པོའི་མཐའ་ཞེས་བྱ་བ་ནི་ཟུང་དུ་འབྲེལ་པས་རབ་ཏུ་ཕྱེ་བ་དམིགས་པ་དང་གནས་ཀྱི་དངོས་པོའི་མཐའ་གནས་གྱུར་པའི་ངོ་བོ་ཉིད་གང་ཡིན་པ་སྟེ། དེ་ལ་དངོས་པོ་ཞེས་བྱ་བ་ནི་ལྷག་མཐོང་དང་ཞི་གནས་ཀྱི་དམིགས་པ་རྣམ་པར་རྟོག་པ་དང་བཅས་པའི་གཟུགས་བརྙན་དང་། རྣམ་པར་མི་རྟོག་པའི་གཟུགས་བརྙན་གྱི་དངོས་པོ་ཀུན་གཞི་རྣམ་པར་ཤེས་པའོ། །མཐའ་ཞེས་བྱ་བ་ནི་དེའི་ཇི་སྙེད་ཡོད་པ་ཉིད་དང་། ཇི་ལྟ་བ་བཞིན་དུ་ཡོད་པ་ཉིད་ཀྱི་མཐར་གྱུར་པ་གནས་གྱུར་པའི་ངོ་བོ་ཉིད་དོ། །དེ་ཅིའི་ཕྱིར་དམིགས་པ་དེ་ཉིད་ལ་དངོས་པོ་ཞེས་བྱ་ཞེ་ན། དེ་གཉིས་ནི་ཞི་གནས་དང་ལྷག་མཐོང་གི་དངོས་པོའི་དམིགས་པ་དང་གནས་ཀྱི་དངོས་པོ་ཡིན་པའི་ཕྱིར་ཏེ། དེ་ལ་དམིགས་པའི་དངོས་པོའི་ཞེས་བྱ་བ་ནི་ཞི་གནས་དང་ལྷག་མཐོང་ནི་དམིགས་པ་གང་གིས༌[^2197]བསྐྱེད་པ་དེ་ཉིད་ལ་དམིགས་པ་ཡིན་པས་མཉམ་པར་གཞག་པའི་ས་པའི་མོས་པའི༌[^2198]ཡིད་ལ་བྱེད་པ་དང་། དེ་ཁོ་ན་ཉིད་ཡིད་ལ་བྱེད་པའི་མཐུས་རྣམ་པར་རྟོག་པ་དང་བཅས་པ་དང་། རྣམ་པར་མི་རྟོག་པའི་གཟུགས་བརྙན་གྱི་དམིགས་པ་ཐོབ་པར་གྱུར་པ་དེས་ཞི་གནས་དང་ལྷག་མཐོང་བསྐྱེད་ལ། ཞི་གནས་དང་ལྷག་མཐོང་ཡང་གཟུགས་བརྙན་གྱི་དམིགས་པ་དེ་ཉིད་ལ་དམིགས་པར་བྱེད་པའི་ཕྱིར་གཟུགས་བརྙན་གྱི་དམིགས་པ་ཀུན་གཞིའི་རྣམ་པར་ཤེས་པའི་ངོ་བོ་ཉིད་དེ་ནི་ཞི་གནས་དང་ལྷག་མཐོང་སེམས་ལས་བྱུང་བའི་ངོ་བོ་ཉིད་དེའི་དམིགས་པའི་དངོས་པོ་ཞེས་བྱའོ། །དེ་ལ་གནས་ཀྱི་དངོས་པོ་ཞེས་བྱ་བ་ནི་ཀུན་གཞི་རྣམ་པར་ཤེས་པ་སེམས་དང༌[^2199]སེམས་ལས་བྱུང་བའི་ཆོས་ཐམས་ཅད་ཀྱི་གནས་ཀྱི་དངོས་པོ་ཡིན་པས་མཉམ་པར་གཞག་པའི་ས་པའི་མོས་པའི་ཡིད་ལ་བྱེད་པ་དང་། དེ་ཁོ་ན་ཉིད་ཡིད་ལ་བྱེད་པའི་མཐུས་རྣམ་པར་རྟོག་པ་དང་བཅས་པ་དང་། རྣམ་པར་མི་རྟོག་པའི་གཟུགས་བརྙན་གྱི་དམིགས་པ་ཐོབ་པར་གྱུར་པ་དེ་ནི་ཀུན་གཞིའི་རྣམ་པར་ཤེས་པའི་ངོ་བོ་ཉིད་ཡིན་ལ། དམིགས་པ་དེ་ལ་བརྟེན་ཏེ་སྐྱེས་པའི་ཞི་གནས་དང་ལྷག་མཐོང་ནི་མཉམ་པར་གཞག་པའི་ས་པའི་སེམས་ལས་བྱུང་བའི་ཏིང་ངེ་འཛིན་དང་། ཤེས་རབ་ཀྱི་ངོ་བོ་ཉིད་ཡིན་པའི་ཕྱིར་གཟུགས་བརྙན་གྱི་དམིགས་པ་ཀུན་གཞིའི་རྣམ་པར་ཤེས་པའི་ངོ་བོ་ཉིད་དེ་ནི་ཞི་གནས་དང་ལྷག་མཐོང་དེ་ནི་སེམས་ལས་བྱུང་བའི་ངོ་བོ་ཉིད་དེའི་གནས་ཀྱི་དངོས་པོ་ཞེས་བྱ་སྟེ། དེའི་ཕྱིར་གཟུགས་བརྙན་དེ་ནི་དམིགས་པ་དང་གནས་ཀྱི་དངོས་པོ་ཞེས་བྱའོ། །

དེ་ལ་ཅིའི་ཕྱིར་དངོས་པོ་དེའི་ཇི་སྙེད་ཡོད་པ་ཉིད་དང་། ཇི་ལྟ་བ་བཞིན་དུ་ཡོད་པ་ཉིད་ལ་མཐའ་ཞེས་བྱ་ཞེ༌[^2200]ན། དེ་ཙམ་གྱིས་ནི་རྣམ་གྲངས་ཀྱི་མཐར་ཕྱིན་པ་དང་། མཚན་ཉིད་ཀྱི་མཐར་ཕྱིན་པར་གྱུར་པའི་ཕྱིར་ཏེ། དེ་ལ་ཇི་སྙེད་ཡོད་པ་ཉིད་ཅེས་བྱ་བ་ནི་རྣམ་གྲངས་ཏེ། དཔེར་ན་ཕུང་པོ་ནི་ལྔ་ཁོ་ནར་ཟད་དེ། དེ་དག་གིས་འདུས་བྱས་ཐམས་ཅད་བསྡུས་སོ། །ཁམས་ནི་བཅོ་བརྒྱད་ཁོ་ནའོ། །སྐྱེ་མཆེད་ནི་བཅུ་གཉིས་ཁོ་ན་སྟེ།[^2201] དེ་དག་གིས་ནི་འདུས་བྱས་དང་འདུས་མ་བྱས་ཀྱི་ཆོས་ཐམས་ཅད་བསྡུས་སོ། །འཕགས་པའི༌[^2202]བདེན་པ་ནི་བཞི༌[^2203]ཁོ་ན་སྟེ།[^2204] དེ་དག་གིས་ནི་ཤེས་བྱའི་དངོས་པོ་ཐམས་ཅད་བསྡུས་སོ་ཞེས་བྱ་བ་ནི་ཇི་སྙེད་ཡོད་པ་ཉིད་དོ། །ཇི་ལྟ་བ་བཞིན་དུ་ཡོད་པ་ཉིད་ནི་མཚན་ཉིད་དེ། དཔེར་ན་ཇི་སྙེད་ཡོད་པ་ཉིད་ཀྱི་རྣམ་པ་དེ་དག་གིས༌[^2205]ཡང་དག་པ་ཉིད་དང་། དེ་བཞིན་ཉིད་རིགས་པ་བཞི་དང་ལྡན་པ་ནི་ཇི་ལྟ་བ་བཞིན་དུ་ཡོད་པ་ཉིད་ཅེས་བྱའོ། །དེ་དང་འདྲ་བར་འདིར་ཡང་ཀུན་གཞིའི་རྣམ་པར་ཤེས་པའི་འཇུག་པ་རྣམ་པར་གཞག་པའི་རྣམ་གྲངས་ཇི་སྙེད་པ་ཐམས་ཅད་ནི་ཇི་སྙེད་པ་ཡོད་པ་ཉིད་དོ། །ལྡོག་པ་རྣམ་པར་གཞག་པའི་མཚན་ཉིད་ཅི་འདྲ་བ་ནི་ཇི་ལྟ་བ་བཞིན་དུ་ཡོད་པ་ཉིད་ཅེས་བྱ་སྟེ། དེ་ཙམ་གྱིས་ན་དངོས་པོ་དེའི་མཐར་ཕྱིན་པའི་ཕྱིར་ཇི་སྙེད་ཡོད་པ་ཉིད་དང་། ཇི་ལྟ་བ་བཞིན་དུ་ཡོད་པ་ཉིད་ནི་དངོས་པོ་དེའི་མཐའ་ཞེས་བྱའོ། །དེ་ཡང་གང་གི་དུས་ན་དངོས་པོ་དེའི་མཐར་གྱུར་པ་ཡིན་ཞེ་ན། གང་གི་ཚེ་ཀུན་གཞིའི་རྣམ་པར་ཤེས་པ་གནས་གྱུར་པ་དེའི་ཚེ་ན་དངོས་པོ་དེའི་རྣམ་གྲངས་དང་མཚན་ཉིད་ཀྱི་མཐར་གྱུར་པ་ཡིན་ནོ། །དེ་ལྟར་ན་དམིགས་པ་དང་གནས་ཀྱི་དངོས་པོའི་མཐའ་གནས་གྱུར་པའི་ངོ་བོ་ཉིད་ནི་དངོས་པོའི་མཐའ་ཞེས་བྱ་སྟེ། དེ་ནི་སྤངས་པ་ཕུན་སུམ་ཚོགས་པ་ཡིན་ནོ། །དེ་ཡང་གང་གིས་རབ་ཏུ་ཕྱེ་བ་ཡིན་ཞེ་ན། ཞི་གནས་དང་ལྷག་མཐོང་ཟུང་དུ་འབྲེལ་པས་རབ་ཏུ་ཕྱེ་བ་ཡིན་ཏེ། གང་གི་ཚེ་ཟུང་དུ་འབྲེལ་པའི་ལམ་སྐྱེས་པ་དེའི་ཚེ་ན་གནས་གྱུར་པ༌[^2206]ཐོབ་པ་ཡིན་ལ། གནས་གྱུར་པའི་དེ་བཞིན་ཉིད་དེ་ཡང་ཟུང་དུ་འབྲེལ་པའི་ལམ་གྱི་དམིགས་པ་ཡིན་པས་གནས་གྱུར་པའི་དམིགས་པ་འཐོབ་པ་དང་ཟུང་དུ་འབྲེལ་པའི་ལམ་སྐྱེ་བ་ནི་འབྱུང་བའི་དུས་ཀྱང་གཅིག་ངོ་བོ་ཉིད་དང་གཅིག་པས་ན་ཟུང་དུ་འབྲེལ་པས་རབ་ཏུ་ཕྱེ་བ་ཞེས་བྱ་སྟེ། དེ་ནི་དངོས་པོའི་མཐའ་ཡིན་ནོ། །

དགོས་པ་ཡོངས་སུ་གྲུབ་པ་ཞེས་བྱ་བ་ནི་ཟུང་དུ་འབྲེལ་པས་རབ་ཏུ་ཕྱེ་བ་སྦྱོར་བ་མཐར་ཐུག་པའི་འབྲས་བུའི་ཡིད་ལ་བྱེད་པ་ཡོངས་སུ་གྲུབ་པ་ཡང་དག་པའི་ཤེས་པའི་ངོ་བོ་ཉིད་ཡིན་པ་སྟེ། དེ་ལ་དགོས་པ་ཞེས་བྱ་བ་ནི་སྦྱོར་བ་མཐར་ཐུག་པའི་འབྲས་བུའི་ཡིད་ལ་བྱེད་པའོ། །ཡོངས་སུ་གྲུབ་པ་ཞེས་བྱ་བ་ནི་དེ་ཡོངས་སུ་གྲུབ་པའི་ཡང་དག་པའི་ཤེས་པའི་ངོ་བོ་ཉིད་དོ། །དེ་ལ་ཅིའི་ཕྱིར་སྦྱོར་བའི་མཐར་ཐུག་པའི་འབྲས་བུའི་ཡིད་ལ་བྱེད་པ་ལ་དགོས་པ་ཞེས་བྱ་ཞེ་ན། དགོས་པ་ཞེས་བྱ་བའི་དོན་ནི་འབྲས་བུ་དང་བྱ་བ་ཡིན་ལ། དགོས་པ་མཐར་ཐུག་པའི་འབྲས་བུ་ཡང་དངོས་གཞི༌[^2207]ཐོབ་པའི་འབྲས་བུ་ཡིན་པས་དེ་ཉིད་དགོས་པ་ཡིན་པའི་ཕྱིར་དང་དེའི་ཡིད་ལ་བྱེད་པ་ཡང་བྱ་བ་ཡིན་པས་དེ་ཡང་དགོས་པ་ཡིན་པའི་ཕྱིར་རོ། །དེ་ལ་ཅིའི་ཕྱིར་དེ་ཡོངས་སུ་གྲུབ་པ་ཡང་དག་པའི་ཤེས་པའི་ངོ་བོ་ཉིད་ལ་ཡོངས་སུ་གྲུབ་པ་ཞེས་བྱ་ཞེ་ན། དེ་ཡོངས་སུ་གྲུབ་པ་ཞེས་བྱ་བ་ནི་དངོས་གཞི་ཐོབ་པ་རྡོ་རྗེ་ལྟ་བུའི་ཏིང་ངེ་འཛིན་གྱིས༌[^2208]གནས་ངན་ལེན་ཕྲ་མོ་སྙིང་པོ་ལ་ཡོད་པ་ལྟ་བུ་མ་ལུས་པར་སྤངས་ཏེ་ཟད་པ་དང་མི་སྐྱེ་བ་ཤེས་པ་ཐོབ་པ་ན་སྦྱོར་བ་མཐར་ཐུག་པའི་འབྲས་བུའི་ཡིད་ལ་བྱེད་པ་དེ་ཡོངས་སུ་གྲུབ་པ་ཡིན་ལ། དེ་ཉིད་ཤེས་བྱ་ཐམས་ཅད་ལ་ཆགས་པ་མེད་པ་དང་། ཐོགས་པ་མེད་པའི་ཤེས་པ་དང་། མཐོང་བ་འཇུག་པ༌[^2209]འཇིག་རྟེན་ལས་འདས་པའི་ཡང་དག་པའི་ཤེས་པའི་ངོ་བོ་ཉིད་ཡིན་པའི་ཕྱིར་ཏེ། དེ་ལྟར་ན་སྦྱོར་བ་མཐར་ཐུག་པའི་འབྲས་བུའི་ཡིད་ལ་བྱེད་པ་ཡོངས་སུ་གྲུབ་པ་ཡང་དག་པའི་ཤེས་པའི་ངོ་བོ་ཉིད་ནི་དགོས་པ་ཡོངས་སུ་གྲུབ་པ་ཞེས་བྱ་སྟེ། དེ་ནི་ཡེ་ཤེས་ཕུན་སུམ་ཚོགས་པ་ཡིན་ནོ། །དེ་ཡང་གང་གིས་རབ་ཏུ་ཕྱེ་བ་ཡིན་ཞེ་ན། ཞི་གནས་དང་ལྷག་མཐོང་ཟུང་དུ་འབྲེལ་པས་རབ་ཏུ་ཕྱེ་བ་ཡིན་ཏེ། གང་གི་ཚེ་ཟུང་དུ་འབྲེལ་པའི་ལམ་སྐྱེས་པ་དེའི་ཚེ་ན་ཡང་དག་པའི་ཤེས་པ་ཐོབ་པ་ཡིན་ལ། ཡང་དག་པའི་ཤེས་པའི་དེ་བཞིན་ཉིད་ཀྱང་ཟུང་དུ་འབྲེལ་པའི་ལམ་གྱི་དམིགས་པ་ཡིན་པས་ཡང་དག་པའི་ཤེས་པའི་དམིགས་པ་འཐོབ་པ་དང་ཟུང་དུ་འབྲེལ་པའི་ལམ་སྐྱེ་བ་འདི༌[^2210]འབྱུང་བའི་དུས་ཀྱང་གཅིག་ངོ་བོ་ཉིད་ཀྱང་གཅིག༌[^2211]པས་ན་ཟུང་དུ་འབྲེལ་པས་རབ་ཏུ་ཕྱེ་བ་ཞེས་བྱ་སྟེ། དེ་ནི་དགོས་པ་ཡོངས་སུ་གྲུབ་པ་ཡིན་ནོ། །

དགོས་པ་ཡོངས་སུ་གྲུབ་པ་ཞེས་བྱ་བ་ནི་ཟུང་དུ་འབྲེལ་པས་རབ་ཏུ་ཕྱེ་བ་སྦྱོར་བ་མཐར་ཐུག་པའི་འབྲས་བུའི་ཡིད་ལ་བྱེད་པ་ཡོངས་སུ་གྲུབ་པ་ཡང་དག་པའི་ཤེས་པའི་ངོ་བོ་ཉིད་ཡིན་པ་སྟེ། དེ་ལ་དགོས་པ་ཞེས་བྱ་བ་ནི་སྦྱོར་བ་མཐར་ཐུག་པའི་འབྲས་བུའི་ཡིད་ལ་བྱེད་པའོ། །ཡོངས་སུ་གྲུབ་པ་ཞེས་བྱ་བ་ནི་དེ་ཡོངས་སུ་གྲུབ་པའི་ཡང་དག་པའི་ཤེས་པའི་ངོ་བོ་ཉིད་དོ། །དེ་ལ་ཅིའི་ཕྱིར་སྦྱོར་བའི་མཐར་ཐུག་པའི་འབྲས་བུའི་ཡིད་ལ་བྱེད་པ་ལ་དགོས་པ་ཞེས་བྱ་ཞེ་ན། དགོས་པ་ཞེས་བྱ་བའི་དོན་ནི་འབྲས་བུ་དང་བྱ་བ་ཡིན་ལ། དགོས་པ་མཐར་ཐུག་པའི་འབྲས་བུ་ཡང་དངོས་གཞི༌[^2207]ཐོབ་པའི་འབྲས་བུ་ཡིན་པས་དེ་ཉིད་དགོས་པ་ཡིན་པའི་ཕྱིར་དང་དེའི་ཡིད་ལ་བྱེད་པ་ཡང་བྱ་བ་ཡིན་པས་དེ་ཡང་དགོས་པ་ཡིན་པའི་ཕྱིར་རོ། །དེ་ལ་ཅིའི་ཕྱིར་དེ་ཡོངས་སུ་གྲུབ་པ་ཡང་དག་པའི་ཤེས་པའི་ངོ་བོ་ཉིད་ལ་ཡོངས་སུ་གྲུབ་པ་ཞེས་བྱ་ཞེ་ན། དེ་ཡོངས་སུ་གྲུབ་པ་ཞེས་བྱ་བ་ནི་དངོས་གཞི་ཐོབ་པ་རྡོ་རྗེ་ལྟ་བུའི་ཏིང་ངེ་འཛིན་གྱིས༌[^2208]གནས་ངན་ལེན་ཕྲ་མོ་སྙིང་པོ་ལ་ཡོད་པ་ལྟ་བུ་མ་ལུས་པར་སྤངས་ཏེ་ཟད་པ་དང་མི་སྐྱེ་བ་ཤེས་པ་ཐོབ་པ་ན་སྦྱོར་བ་མཐར་ཐུག་པའི་འབྲས་བུའི་ཡིད་ལ་བྱེད་པ་དེ་ཡོངས་སུ་གྲུབ་པ་ཡིན་ལ། དེ་ཉིད་ཤེས་བྱ་ཐམས་ཅད་ལ་ཆགས་པ་མེད་པ་དང་། ཐོགས་པ་མེད་པའི་ཤེས་པ་དང་། མཐོང་བ་འཇུག་པ༌[^2209]འཇིག་རྟེན་ལས་འདས་པའི་ཡང་དག་པའི་ཤེས་པའི་ངོ་བོ་ཉིད་ཡིན་པའི་ཕྱིར་ཏེ། དེ་ལྟར་ན་སྦྱོར་བ་མཐར་ཐུག་པའི་འབྲས་བུའི་ཡིད་ལ་བྱེད་པ་ཡོངས་སུ་གྲུབ་པ་ཡང་དག་པའི་ཤེས་པའི་ངོ་བོ་ཉིད་ནི་དགོས་པ་ཡོངས་སུ་གྲུབ་པ་ཞེས་བྱ་སྟེ། དེ་ནི་ཡེ་ཤེས་ཕུན་སུམ་ཚོགས་པ་ཡིན་ནོ། །དེ་ཡང་གང་གིས་རབ་ཏུ་ཕྱེ་བ་ཡིན་ཞེ་ན། ཞི་གནས་དང་ལྷག་མཐོང་ཟུང་དུ་འབྲེལ་པས་རབ་ཏུ་ཕྱེ་བ་ཡིན་ཏེ། གང་གི་ཚེ་ཟུང་དུ་འབྲེལ་པའི་ལམ་སྐྱེས་པ་དེའི་ཚེ་ན་ཡང་དག་པའི་ཤེས་པ་ཐོབ་པ་ཡིན་ལ། ཡང་དག་པའི་ཤེས་པའི་དེ་བཞིན་ཉིད་ཀྱང་ཟུང་དུ་འབྲེལ་པའི་ལམ་གྱི་དམིགས་པ་ཡིན་པས་ཡང་དག་པའི་ཤེས་པའི་དམིགས་པ་འཐོབ་པ་དང་ཟུང་དུ་འབྲེལ་པའི་ལམ་སྐྱེ་བ་འདི༌[^2210]འབྱུང་བའི་དུས་ཀྱང་གཅིག་ངོ་བོ་ཉིད་ཀྱང་གཅིག༌[^2211]པས་ན་ཟུང་དུ་འབྲེལ་པས་རབ་ཏུ་ཕྱེ་བ་ཞེས་བྱ་སྟེ། དེ་ནི་དགོས་པ་ཡོངས་སུ་གྲུབ་པ་ཡིན་ནོ། །
