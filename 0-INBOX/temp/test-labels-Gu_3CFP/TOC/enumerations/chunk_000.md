བྱང་ཆུབ་སེམས་དཔའི་སའི་སྡེ་འདིའི་བསྡུས་པའི་དོན་ནི། རྣལ་འབྱོར་གྱི་གཞིའི་གནས་དང་། རྣལ་འབྱོར་གྱི་གཞིའི་བདག་ཉིད་ཀྱི་གནས་དང་།

རྣལ་འབྱོར་གྱི་གཞིའི་མཐའ་ནི་ལེའུ་ལྔ་སྟེ།
Enumeration Block 2:
སྦྱིན་པའི་ཕ་རོལ་ཏུ་ཕྱིན་པའི་རིགས་ཀྱི་རྟགས་ནི་མདོར་བསྡུ་ན་རྣམ་པ་གསུམ་སྟེ། ཟང་ཟིང་གི་སྦྱིན་པ་དང་། ཆོས་ཀྱི་སྦྱིན་པ་དང་། མི་འཇིགས་པའི་སྦྱིན་པའོ། །
Enumeration Block 3:
གཞན་ལ་སྒྲུབ་པ་ལ་ཡང་རྣམ་པ་གཉིས་ཏེ། གཞན་སྦྱིན་པ་ལ་མ་ཞུགས་པ་ལ་སྒྲུབ་པ༌[^31]དང་། སྦྱིན་པ་ལ་ཞུགས་པ་ལ་སྒྲུབ་པའོ། །
སྦྱིན་པ་ལ་མ་ཞུགས་པ་ལ་ཡང་རྣམ་པ་གཉིས་ཏེ། སྦྱིན་པའི་ཕན་ཡོན་མི་ཤེས་པའི་སྐྱེ་བོ་རྨོངས་པ་དང་། བག་མེད་ཅིང་ཞུམ་པ་སྟེ།
Enumeration Block 4:
ཚུལ་ཁྲིམས་ཀྱི་ཕ་རོལ་ཏུ་ཕྱིན་པའི་རིགས་ཀྱི་རྟགས་བསྡུས་པའི་དོན་ནི། ཚུལ་ཁྲིམས་རྣམ་པ་གསུམ་གྱི་རྟགས་རྣམས་ཏེ། སྡོམ་པའི་ཚུལ་ཁྲིམས་དང་། དགེ་བ་ཆོས་སྡུད་པ་དང་།
སེམས་ཅན་གྱི་དོན་བྱ་བའི་ཚུལ་ཁྲིམས་ཀྱིའོ། །
Enumeration Block 5:
བརྩོན་འགྲུས་ཀྱི་ཕ་རོལ་ཏུ་ཕྱིན་པའི་རིགས་ཀྱི་རྟགས་རྣམས་ཀྱི་བསྡུས་པའི་དོན་ནི་རྣམ་པ་དྲུག་སྟེ། བྱང་ཆུབ་སེམས་དཔའ་བརྩོན་པ་གང་དང་ལྡན་པས། རྣམ་པ་ཐམས་ཅད་དུ་བརྩོན་འགྲུས་བརྩམས་པ་དང་། བརྟན་པ་དང་ལྡན་པ་དང་། བརྩོན་འགྲུས་དང་ལྡན་པ་དང་། སྤྲོ་བ་དང་། ཕ་རོལ་གནོད་པ་དང་། བླངས་པ་མི་འདོར་བ་ཞེས་བྱའོ། །
Enumeration Block 6:
བསམ་གཏན་གྱི་ཕ་རོལ་ཏུ་ཕྱིན་པའི་རིགས་ཀྱི་རྟགས་བསྡུས་པའི་དོན་ནི། ཏིང་ངེ་འཛིན་འདོད་པའི་སློབ་མ་གནས་ལྔ་ལ་ངེས་པར་སྦྱར་བར་བྱ་སྟེ། འདི་ལྟ་སྟེ། སེམས་རྩེ་གཅིག་པ་ཉིད་དང་། རབ་ཏུ་དབེན་པ་དང་། སྒྲིབ་པ་རྣམ་པར་སྦྱང་བ་དང་ཡིད་ལ་བྱེད་པ་གོམས་པར་བྱ་བ་དང་། སྡོམ་པ་སྲུང་ཞིང་སྤེལ་བར་བྱ་བ་སྟེ།
Enumeration Block 7:
དཀར་པོའི་ཆོས་དང་མི་མཐུན་པའི་ཉེ་བའི་ཉོན་མོངས་པ༌[^67]བཞི་པོའི་བསྡུས་པའི་དོན་ནི། རྒྱུ་ལས་གྱུར་པ་དང་། རྐྱེན་གྱི་མཚན་ཉིད་ཅེས་བྱ་བ་སྟེ།
རྒྱུ་ལས་གྱུར་པ་ནི་གཅིག་གོ། །
གསུམ་ནི་རྐྱེན་ལས་གྱུར་པའོ། །
རྐྱེན་ཡང་རྣམ་པ་གཉིས་ཏེ། ཕྱིའི་དང་། ནང་གིའོ། །
ཕྱི་ཡང་རྣམ་པ་གཉིས་ཏེ། བྱང་ཆུབ་འཐོབ་པ༌[^68]ལ་མི་ཕན་པ་དང་། དེ་འཐོབ་པ་ལ་བར་དུ་གཅོད་པའོ། །
Enumeration Block 8:
རྒྱུ་བཞིའི་བསྡུས་པའི་དོན་ནི། རྒྱུ་རྣམས་ལས་དང་པོ་གསུམ་ནི་རྐྱེན་ནོ། །
ཐ་མའི་བཞི་པ་ནི༌[^71]རྒྱུ་སྟེ།
Enumeration Block 9:
དེ་ཁྱད་པར་དུ་འཕགས་པའི་རྒྱུའི་ཁྱད་པར་ནི་རྣམ་པ་བཞི་སྟེ། རྣམ་པར་གྲོལ་བ་ལས་གྱུར་པ་དང་། ཐོག་མ་དང་བར་མ༌[^78]དང་ཐ་མ་ལས་གྱུར་པ་དང་། བདེ་འགྲོར་སྐྱེས་པ་དང་། ངན་འགྲོར་སྐྱེས་པའི་ཁྱད་པར་རོ། །
Enumeration Block 10:
ཐོག་མ་དང་། བར་མ་དང་ཐ་མ་ལས་གྱུར་པ་ནི་རྣམ་པ་བཞི་སྟེ། དབང་པོ་ལས་གྱུར་པ་དང་། བསྒྲུབ་པ༌[^79]ལས་གྱུར་པ་དང་། མཁས་པ་ལས་གྱུར་པ་དང་། འབྲས་བུ་ལས་གྱུར་པའོ། །
Enumeration Block 11:
ཉེ་བའི་ཉོན་མོངས་པ་བཅུའི་བསྡུས་པའི་དོན་ནི། འཇུག་པའི་བར་དུ་གཅོད་པ་དང་། འཇུག་པའི་ཤིན་ཏུ་བར་དུ་གཅོད་པ་དང་། སྒྲུབ་པའི་བར་དུ་གཅོད་པའོ། །
Enumeration Block 12:
སེམས་བསྐྱེད་པའི་རྐྱེན་བཞིའི་བསྡུས་པའི་དོན་ནི། བྱང་ཆུབ་སེམས་དཔའི་རིགས་ངེས་པ༌[^96]སེམས་བསྐྱེད་པའི་རྐྱེན་གཉིས་དང་། བྱང་ཆུབ་ཏུ་གྱུར་པའི་སེམས་བསྐྱེད་པའི་རྐྱེན་གཉིས་སོ། །
བྱང་ཆུབ་སེམས་དཔའི་རིགས༌[^97]ངེས་པ་རྣམ་པ་གཉིས་ནི་རྒྱ་ཆེ་བ་ལ་མོས་པ་དང་། ཟབ་པ་ལ་མོས་པའོ། །
བྱང་ཆུབ་ཏུ་འགྱུར་བ་རྣམ་པ་གཉིས་ནི། སློབ་པ༌[^98]དང་མི་སློབ་པ་ཞེས་བྱ་བའོ། །
Enumeration Block 13:
རྒྱུ་བཞིའི༌[^100]བསྡུས་པའི་དོན་ལ། རྒྱུ་གསུམ་ནི་ཆོས་ཉིད་ཀྱིས་ཐོབ་པ་དང་། ཕྱི་རོལ་གྱི་གཞན་གྱི་སྒྲའི་མཚན་མ་ལས༌[^101]དང་། ནང་གི་ཚུལ་བཞིན་ཡིད༌[^102]ལ་བྱེད་པས་བསྡུས་པའོ། །
དེ་ཡང་རྣམ་པ་གཉིས་ཏེ། གཞན་སྡུག་བསྔལ་ལས་བསྒྲལ་བར་འདོད་པ་དང་། བདག་གི་རྒྱུད་དུ་གཏོགས་པའི་སྡུག་བསྔལ་གྱིས་མི་འཇིགས་པ་ཉིད་དེ།
Enumeration Block 14:
བཤེས་གཉེན་ཕུན་སུམ་ཚོགས་པ་རྣམ་པ་བཞིའི་བསྡུས་པའི་དོན་ནི། ཤེས་རབ་ཕུན་སུམ་ཚོགས་པ་དང་། སྦྱོར་བ་ཕུན་སུམ་ཚོགས་པ་ཞེས་བསྟན་ཏོ། །
སྦྱོར་བ་ཕུན་སུམ་ཚོགས་པ་ཡང་རྣམ་པ་གསུམ་སྟེ། ཉོན་མོངས་པ་སྤྱོད་པ་ལས་ལྡོག་པར་སྦྱོར་བ་དང་། མི་དགེ་བའི་ལས་ཀྱི་ལམ་ལྡོག་པ་ལ་སྦྱོར་བ་དང་། དགེ་བའི་ལས་ལ་ནུས་པ་དང་ལྡན་པ་གོང་མ་གོང་མའི་ཁྱད་པ༌[^104]ལ་སྦྱོར་བ་སྟེ།
Enumeration Block 15:
རྒྱུ་བཞིས་བྱང་ཆུབ་སེམས་དཔའ་སྙིང་རྗེ་བའི་ཤས་ཆེ་བར་འགྱུར་ཏེ། རྒྱུ་བཞིའི་བསྡུས་པའི་དོན་ནི། གང་དུ་སྡུག་བསྔལ་བ་དང་། གང་གིས་སྡུག་བསྔལ་བ་དང་། གང་སྡུག་བསྔལ་གྱི་རྣམ་པ་ལ་ཉེ་བར་དམིགས་ནས་སྙིང་རྗེ་ཤས་ཆེ་བར་འགྱུར་བ་སྟེ།
Enumeration Block 16:

Enumeration Block 17:
