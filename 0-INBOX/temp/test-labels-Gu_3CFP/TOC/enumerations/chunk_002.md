Enumeration Block 1:
མདོར་བསྡུ༌[^390]ན་རྫུ་འཕྲུལ་ནི་རྣམ་པ་གཉིས་ཏེ། ཡོངས་སུ་བསྒྱུར་བ་དང་སྤྲུལ་པའོ། །
Enumeration Block 2:
ཡོངས་སུ་བསྒྱུར་བ་ཡང་རྣམ་པ་བཞི་སྟེ།
Enumeration Block 3:
སྦྱིན་པ་ལ་སོགས་པའི་ཆོས་འདི་རྣམས་ཀྱི་མཐུའི་དོན་གྱི༌[^446]བསྡུས་པའི་དོན་ནི་རྣམ་པ་བཞི་སྟེ།
Enumeration Block 4:
ཡོངས་སུ་སྨིན་པར་ནི་མདོར་བསྡུ་ན་རྣམ་པ་བཅུ༌[^462]དྲུག་ཅེས་བྱ་བའི་དོན་ནི། ཡོངས་སུ་སྨིན་པ་ནི་ཅི། གང་གིས།[^463] གང་དུ། ཅི་ཞིག་ཡོངས་སུ་སྨིན་པར་འགྱུར། གང་གི༌[^464]གང་ཞིག་གིས་ཡོངས་སུ་སྨིན་པར་བྱེད། ཡོངས་སུ་སྨིན་པའི་མཚན་ཉིད་ནི༌[^465]ཇི་ལྟ་བུར་འབྱུང་ཞེས་བྱ་བའོ། །
Enumeration Block 5:
ཡོངས་སུ་སྨིན་པའི་ཐབས་ཉི་ཤུ་རྩ་བདུན་པོ་རྣམས་ཀྱི་བསྡུས་པའི་དོན་ནི། བསྟན་པ་དང་། བཤད་པ་སྟེ།
Enumeration Block 6:
ཁམས་བརྟས་པའི༌[^488]བཤད་པ་ནི་དྲུག་གོ། །
ཁམས་བརྟས་པ༌[^489]དེ་ཡང་རྣམ་པ་གཉིས་ཏེ། ཆུང་ངུ་དང་ཆེན་པོའོ། །
Enumeration Block 7:
ད་ལྟར་གྱི་རྐྱེན་བཤད་པ་ནི། དེ་ལ་ད་ལྟར་གྱི་རྐྱེན་ཡང་རྣམ་པ་གསུམ་སྟེ[^502]། [^503]ཆོས་ལ་ཕྱིན་ཅི་མ་ལོག་པའི་ཆོས་འཆད་པ་དང་། དེ་ལ་ཕྱིན་ཅི་ལོག་པར་འཛིན་པ་ཉིད་དང་། ཆོས་དང་རྗེས་སུ་མཐུན་པའི་ཆོས་ལ་ཇི་ལྟ་བ་བཞིན་དུ་ནན་ཏན་བྱེད་པ་ཞེས་བྱ་བ་སྟེ།
Enumeration Block 8:
དམ་པ་བདུན་གྱི་བསྡུས་པའི་དོན་ནི། གང་ལ་བརྟེན་པ་དང་། གང་གི་དོན་དུ་བསྒྲུབ་པ་དང་། གང་ལ་གནས་པ་དང་། ཐབས་གང་གིས་དང་། འབྲས་བུ་གང་ཐོབ་པ་དང་། གནས་པ་གང་གིས་གནས་པ་ཞེས་བྱ་བའོ། །
Enumeration Block 9:
བསྡུས་པའི་དོན་སྟོན་པ་བདུན་པོ་འདི་དག་གི་བསྡུས་པའི་དོན་ནི། བདག་ཉིད་ཇི་ལྟར་སློབ་པ་དང་། གཞན་དག་ལ་ཡང་ཞེས་བྱ་བ་ནི་བསྡུས་པའི་དོན་ཏོ། །
དེ་ལ་བདག་ཉིད་སློབ་པར་བྱེད་པ་ནི། བྱང་ཆུབ་སེམས་དཔའ་ཆོས་ཀྱིས༌[^575]རྗེས་སུ་འབྲང་བ་དང་། དད་པས་རྗེས་སུ་འབྲང་བའོ། །
དེ་ལ་ཆོས་ཀྱིས༌[^576]རྗེས་སུ་འབྲང་བ་ནི་རྣམ་པ་གསུམ་དུ་སློབ་སྟེ། མོས་པ་མང་པོ༌[^577]ཉིད་ཀྱི་བསམ་པའི་རྒྱུན་ཉིད་དང་། སྦྱོར་བ་ཉིད་དང་།[^578] ཆོས་ཚོལ་བ་ལ་སྦྱོར་བ་ཉིད་ལའོ། །
དད་པས་རྗེས་སུ་འབྲང་བ་ནི་རྣམ་པ་བཞི་སྟེ།

གཞན་བསླབ་པ་ཡང་རྣམ་པ་གཉིས་ཏེ། གཞན་རྣམ་པ་གཉིས་ནི་ཞུགས་པ་དང་མ་ཞུགས་པ་ཞེས་བྱ་བའོ། །
