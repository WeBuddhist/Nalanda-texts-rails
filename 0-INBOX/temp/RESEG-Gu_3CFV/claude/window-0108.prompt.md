=== SYSTEM PROMPT ===
You are an expert in classical Tibetan Buddhist commentary (འགྲེལ་པ་) structure.

You are given a numbered list of blocks from a Tibetan verse commentary. A
rule-based segmenter has already cut them; most cuts are right. Your job is to
output the few merge/split operations that bring the blocks to the layout the
human editors of this vault use.

━━━ TARGET LAYOUT — one block per FUNCTIONAL UNIT ━━━

OPENER       A node's division announcement together with the first-child opener
             that follows it is ONE block:
               "<topic> ལ་གསུམ། A། B། C་འོ། །དང་པོ་ནི།"
             A sibling opener "གཉིས་པ་ <title> ནི།" is its own block.
ROOT QUOTE   A quoted root stanza is its own block. These blocks are tagged
             [VERSE]; they are protected — never include them in any operation.
EXPLANATION  The gloss that follows a quote ("ཞེས་པ་སྟེ། …", "ཞེས་པ་ནི། …", or a
             running explanation) is ONE block up to the next opener, quote or
             heading — even when it is long (100–250 syllables) and contains several
             sentence ends, a question and answer ("…ལོ། །གང་ལ་ན། …"), a side remark
             on a variant reading ("…ཞེས་འགྱུར་བཅོས་…"), a cross-reference
             ("འདི་དང་འོག་གི་ས་བཅད་…"), or a mantra cited in passing.
SECOND LEVEL A passage that re-reads the same stanza on another level — opening
             "སྦས་དོན་ནི།", "ངེས་དོན་ནི།", "ངེས་པའི་དོན་དུ།", "ཟབ་དོན་ནི།",
             "དེའི་ནང་གི་དོན་ལ།", "མཐར་ཐུག་གི་དོན་ནི།" or the like after the literal
             gloss — is its OWN block, never merged into the literal gloss before it
             (the editors keep the two readings apart). Within that passage, M1 applies.
FRAME        The namo line alone; each of the author's own verses one block;
             "སྨྲས་པ།" alone; the colophon ("ཅེས་ … སྦྱར་བའོ། །" + closing wishes) one block.

━━━ MERGE — adjacent blocks that are one unit ━━━

M1  CONTINUED EXPLANATION
    A block that goes on explaining the same quote/topic as the block before it —
    no new opener, no new quote, no new verse being treated — belongs to that block.
    This is the most common fix. Do NOT keep a cut just because a sentence ends.
    Exception: a SECOND LEVEL opener (see above) always starts a new block.
M2  INCOMPLETE SENTENCE
    A block ending in a connector (དང་། / ཞིང་། / ཅིང་། / ནས། / སྟེ། / ཏེ།) that
    the next block completes.
M3  OPENER CHAIN
    An enumeration block followed by "དང་པོ་ནི།" / "དང་པོ་ལ་ N།" (and further
    nested first-child enumerations) — merge them into one opener block.
M4  COLOPHON
    The parts of the closing colophon and its final wishes form one block.

━━━ SPLIT — one block that holds two units ━━━

S1  A new node opener (ordinal + title + "ནི།" or "ལ་ N།") buried mid-block:
    split before it.
S2  The treatment of a new verse/topic starts mid-block (e.g. "ཡང་ཕྱག་གང་ལ་འཚལ་ན"
    starting the next homage): split before it.
S3  An introductory opener "… ནི།" fused to the explanation of the PREVIOUS
    quote: split so the opener starts the next unit.

Never split a block only because it is long.

━━━ TOPIC SHIFT vs CONTINUATION (from the editors' corrections) ━━━

The editors' blocks are large (median ≈ 55 syllables; whole explanations of
100–250 syllables are normal). A sentence end is NOT a boundary. Inside one
explanation they cut only where the commentary turns to something new:
  START a new block at   "ཡང་ན་ …" (an alternative explanation)
                         "ཁ་ཅིག་ …", "གཞན་དག་ …" (another party's view)
                         "འོ་ན་ …" (the reply to an objection)
                         "དེ་སྐད་དུ་ …", "ཇི་སྐད་དུ་ …" (introducing a supporting quotation)
                         "དེ་ནས་ …" when it opens the next step of a procedure
                         "དཔེ་ …" / "དཔེར་ན་ …" when an example section begins
KEEP WITH the block before (merge into it):
                         "ད་ནི་ …" — a transitional "now …" line is not a new unit
                         (no heading or verse between them)
                         "ལེའུ་ … པའོ། །" — a chapter-closing line stays with the
                         explanation it closes
                         "ཞེས་ / ཅེས་ …" — the quotative closing the words just before it

━━━ HEADING / VERSE BLOCKS — always KEEP ━━━

Blocks tagged [HEADING] or [VERSE] are NEVER part of any operation.

━━━ OUTPUT FORMAT ━━━

A JSON array of operations. Blocks not mentioned are kept as-is.

[
  {"op": "merge", "blocks": [N, M]},
  {"op": "merge", "blocks": [N, M, P]},
  {"op": "split", "block": N, "after": "<verbatim unique substring ending at split point>"},
  {"op": "split", "block": N, "after": ["<sub1>", "<sub2>", "<sub3>"]}
]

Rules for the output:
- Block numbers are CONTINUOUS and INCLUDE heading and verse blocks. You may only
  merge blocks with consecutive numbers (N and N+1). Never merge across a heading
  or a verse block, and never propose a merge whose numbers skip over one.
- Each block number appears in AT MOST ONE operation.
- For each "after" substring: copy a verbatim slice from the block that ends exactly
  at the split point and is UNIQUE within that block (10–20 characters is usually enough).
- If nothing needs to change in this window, output: []
- Output ONLY the JSON array. No explanation, no commentary, no code fences.

དང་པོ་འཁྲུགས་པ་དང་། རྐུ་ཐབས་སུ་གནས་པ་དང་། མ་ནིང་དང་། དགེ་སློང་མ་སུན་ཕྱུང་བ་རྣམས་ལས་བྱིན་ཕྲོགས་བྱེད་པ་དང་། དེ་དག་གི་སྐྱོན་ནས་སྨྲ་བ་དང་། དེ་དག་ལས་ཕྲ་མ་བྱེད་པ་དང་། དེ་དག་གི་རྩོད་པ་ལ་སྐྱོ་སྔོགས་བྱེད་པ་དང་འདི་ལ་རང་གི་ཕྱོགས་ལ་བསྙེན་པར་རྫོགས་པ་ཉིད་ཡོད་པ་ལ་ཡང་དེའི་གནས་ངན་ལེན་པ་དང་། སྔོན་ལྟུང་བ་བྱུང་བ་དང་། དགེ་སློང་མ་སུན་ཕྱུང་བ་དག་གི་དྲུང་དུ་འདི་དང་ཕྱི་མའི་མིའི་ཆོས་བླ་མ་བརྗོད་པ་དང་། དགེ་འདུན་དེ་དང་འབྲེལ་པ་ཉིད་དང་། འདི་རྣམས་སྐུར་པ་ཐོབ་པར་བྱེད་པ་ཉིད་ཀྱིས༌[^2542]སྐུར་པ་འདེབས་པ་དང་། དེ་རྣམས་ལ་དེའི་བསླབ་པ་ལ་ཁྱད་དུ་གསོད་པ་དང་། དེ་དག་ལ་འཕྱ་བ་འམ་གཞོགས་འཕྱས་བྱེད་པ་དང་། དེ་དག་གི་རྩོད་པ་ལ་སྐྱོ་སྔོགས་བྱེད་པ་དང་། དེ་དག་གི་གཙུག་ལག་ཁང་དུ་གནས་མལ་མ་བརྟུལ༌[^2543]བར་འགྲོ་བ་དང་། བཏིང་བ་མ་དོར་བར་འགྲོ་བ་དང་། དེ་དག་གི་གཙུག་ལག་ཁང་དུ་དེ་དག་ལ་ཕྱིས་གནོད༌[^2544]པ་བྱེད་པ་དང་། དགེ་འདུན་གྱི་གཙུག་ལག་ཁང་ནས་དགེ་སློང་མ་ཉམས་པ་ལ་ཕྱིས་གནོད་པར༌[^2545]བྱེད་པ་དང་། དེ་དག་གི་གཙུག་ལག་ཁང་ནས་དགེ་སློང་མ་ཉམས་པ་སྐྲོད་པ་དང་། དེ་དག་གི་གཙུག་ལག་ཁང་ནས་ཁྲིའུ་རྩ་བ་འབྱུང་བ་ལ་འདུག་པ་ཡང་ཉེས་བྱས་སོ། །

[Block 3793]
སྔོན་ལྟུང་བ་བྱུང་བ་མོ་དང་།

[Block 3794]
དང་པོ་འཁྲུགས་པ་མོ་དང་། རྐུ་ཐབས་སུ་གནས་པ་མོ་དང་། དགེ་སློང་སུན་ཕྱུང་བ་མོ་དང་། འགྲོ་བ་གཞན་དུ་གཏོགས་པའི་དགེ་སློང་མ་ལ་མ་བསྐོས་པར་སྟོན་པ་དང་། ཟང་ཟིང་ཅུང་ཟད་ཙམ་གྱི་ཕྱིར་སྟོན་ཏོ་ཞེས་སྐུར་པ་འདེབས་པ་དང་། དགེ་སློང་མ་དང་། དགེ་ཚུལ་མ་དང་། སྔོན་ལྟུང་བ་བྱུང་བའི་དགེ་སློང་རྣམས་ལ་གོས་བྱིན་པ་དང་། དེ་དག་གི་གོས་བྱེད་པ་དང་། དེ་རྣམས་དང་ལྷན་ཅིག་ལམ་དུ༌[^2546]གྲུར་འགྲོ་བ་དང་། དབེན་པ་ན་འདུག་པ་དང་འགྲེང་བ་དང་། དེ་དག་གིས༌[^2547]སྦྱོར་དུ་བཅུག་པའི་ཟས་ཟ་བ་དང་། དེ་དག་ལ་བརྡེག་པ་དང་། གཟས་པ་དང་། གནས་ངན་ལེན་འཆབ་པ་དང་། ཟན་གཅོད་དུ་བཅུག་པ་དང་། དེ་རྣམས་ལས་འདུན་པ་ཕྱིར་བསྒྱུར་བ་དང་། འགྱོད་པ་བསྐྱེད་པ་དང་། ག་ག་ཚིལ་བྱེད་པ་དང་། སྔངས་པར༌[^2548]བྱེད་པ་ཡང་ཉེས་བྱས་སོ། །

[Block 3795]
ཡོ་བྱད་སྦེད་པ་ནི་ཆོས་འདི་པའི་རབ་ཏུ་བྱུང་བ་དང་། བསྙེན་པར་རྫོགས་པ་མ་གཏོགས་པའི་གཞན་ཐམས་ཅད་ཀྱི་སྦེད་པ་ལ་ཉེས་བྱས་སོ། །

[Block 3796]
ཆོས་འདི་པའི་སྦེད་པ་ལ་ནི་ལྟུང་བྱེད་དོ། །

[Block 3797]
དེ་དག་ལས་ནི༌[^2549]བྱིན་ཕྲོགས་བྱེད་པ་དང་། གཞི་མེད་པར་སྐུར་པ་འདེབས་པ་དང་། བསླབ་པ་ལ་ཉེ་བར་འཇོག་པ་སྤོང་བ་ལ་ཉེས་བྱས་སོ། །

[Block 3798]
དགེ་ཚུལ་དང་། དགེ་ཚུལ་མ་དང་། དགེ་སློང་མ་རྩོད་པའམ། དེ་དག་དང་དགེ་སློང་དག་རྩོད་པ་ལ་ཉན་རྣ་བྱེད་པ་ལ་ཡང་ཉེས་བྱས་སོ། །

[Block 3799]
མི་མ་ཡིན་པ་རབ་ཏུ་བྱུང་ཞིང་བསྙེན་པར་རྫོགས་པ་དང་། རྩོད་པ་ལ་ཉན་རྣ་བྱེད་པ་ལ་ཡང་ཉེས་བྱས་སོ། །

[Block 3800]
དགེ་ཚུལ་དང་། དགེ་ཚུལ་མ་དང་། མ་ནིང་མོ་དང་། རྐུ་ཐབས་སུ་གནས་པ་མོ་དང་དང་པོ་འཁྲུགས་པ་མོ་དང་དེའི་དོན་དུ་སྨྲ་བ་ནས་བླངས་ཏེ། འཆོས་སམ་ཟོས་ན་ཡང་ཉེས་བྱས་སོ། །

[Block 3801]
མཚན་དང་ཁས་བླངས་པ་དག་གིས་ནི་རང་གི་ཕྱོགས་ཉིད་ཀྱི་ཁོངས་སུ་གཏོགས་སོ་ཞེས་བྱ་བ་ནི། ཕོ་དང་མོའི་མཚན་དང་ལྟ་བ་མཉམ་པ༌[^2550]ཁས་བླངས་པ་དང་མ་བླངས་པ་དག་གི་རང་གི་ཕྱོགས་ཀྱི་ཁོངས་སུ་གཏོགས་པའི་བསྙེན་པར་རྫོགས་པ་གང་ཡིན་པ་ལ་བརྟེན་པའི༌[^2551]ཁ་ན་མ་ཐོ་བའི་བར་གྱུར་པར༌[^2552]རིག་པར་བྱའོ། །

[Block 3802]
ཇི་ལྟར་རང་གི་ཕྱོགས་ལས་ལོག་པར༌[^2553]བསྒྲུབ་པ་སྨད་པ་ཉིད་ཡིན་པ་དེ་ལྟར་གཞན་ལ་ལོག་པར་བསྒྲུབ་པ་ནི་སྨད་པར་བྱ་བ་ཉིད་མ་ཡིན་པའི་ཕྱིར་རྣམ་པ་དེ་ལས་འདི་ལྟར་ཤེས་སོ། །

[Block 3803]
དེ་ལྟར་དགེ་སློང་མ་རྣམས་ལ་ཡང་ཐམས་ཅད་རྣམ་པ་འདི་བཞིན་དུ་རིག་པར་བྱའོ། །

[Block 3804]
འདིར་དཔེ་རྣམས་བརྗོད་པར་བྱ་སྟེ། ཁས་བླངས་པས་ཁས་མ་བླངས་པ་ལ་གོས་བྱིན་ནས་ཕྲོགས་པ་དང་། ཁས་མ་བླངས་པས་ཁས་མ་བླངས་པ་ལ་གོས་བྱིན་ནས་ཕྲོགས་པ་དང་། དགེ་སློང་མ་དང་དགེ་སློབ་མ་དག་ལ་སྐྱོན་ནས་བརྗོད་པ་དང་། དེ་གཉིས་ལ་ཕྲ་མ་བྱས་པ་དང་། སྐྱོ་སྔོགས་བྱས་པ་དང་། སྨྲ་བ༌[^2554]དང་། དེ་དག་གི་གནས་ངན་ལེན་བརྗོད་པ་དང་། དགེ་སློང་མའི་དགེ་འདུན་དབང་བའི་རྙེད་པ་དགེ་སློང་མས་བཤེས་ངོར་བྱས་ཏེ་གཞན་དུ་བསྒྱུར་རོ་ཞེས་སྐུར་པ་འདེབས་ན་ཉེས་བྱས་སོ། །

[Block 3805]
དེ་རྣམས་ཀྱི་བསླབ་པ་ལ་ཁྱད་དུ་གསོད་པ་དང་། དགེ་སློང་མའི་དགེ་འདུན་གྱི་གཙུག་ལག་ཁང་གི་གནས་མལ༌[^2555]མ་བརྟུལ་བར༌[^2556]འགྲོ་བ་དང་། དགེ་སློང་མའི་གཙུག་ལག་ཁང༌[^2557]དུ་ཕྱིས་གནོན་བྱེད་པ་དང་། དེ་ནས་སྐྲོད་པ་དང་། དེར་རྩ་བ་འབྱུང་བ་ལ་འདུག་པ་དང་། ཁས་བླངས་པས་ཁས་མ་བླངས་པའི་དགེ་སློང་མ་རྣམས་ལ་མ་བསྐོས་པར་སྟོན་པ་དང་། གོས་བྱིན་པ་དང་། གོས་བྱིན་པ་གཉིས་དང་། ཁས་མ་བླངས་པས་ཁས་བླངས་པའི་དགེ༌[^2558]སློང་མ་རྣམས་ལ་མ་བསྐོས་པར་སྟོན་པ་དང་། གོས་སྦྱིན་པ་དང་། གོས་བྱེད་པ་དག་པ༌[^2559]དང་། ཁས་མ་བླངས་པས་ཁས་བླངས་པ་ལ་ཟང་ཟིང་ཅུང་ཟད་ཙམ་གྱི་ཕྱིར་སྟོན་ཏོ་ཞེས་སྐུར་པ་འདེབས་པ་དང་། ཁས་མ༌[^2560]བླངས་པས་ཁས་མ་བླངས་པ་ལ༌[^2561]ཁས་བླངས་པ་མོ་དང་ལྷན་ཅིག་ལམ་དང་གྲུར་འགྲོ་བ་དང་། ཁས་བླངས་པས་ཁས་མ་བླངས་པ་མོ་དང་ཁས་བླངས་པ༌[^2562]མོས་སྦྱོར་དུ་བཅུག་པ་ཟ་བ་དང་། ཁས་མ་བླངས་པས་སྦྱོར་དུ་བཅུག་པ་ཟ་པ་དང་། ཁས་མ་བླངས་པས་ཁས༌[^2563]བླངས་པའི་ཁྱིམ་ནས་ལྷུང་བཟེད་དོ་གསུམ་ཙམ་ལས་ལྷག་པར་ལེན་པ་དང་། ཁས་བླངས་པས་ཁས་མ་བླངས་པའི་ཁྱིམ་ནས་ལྷུང་བཟེད་དོ་གསུམ་ཙམ་ལས་ལྷག་པར་ལེན་པ་དག་ནི་ཉེས་བྱས་སོ། །

[Block 3806]
བྱིན་ལེན་ནི་རྣམ་པ་ཐམས་ཅད་དུ་རང་གི་ཕྱོགས་ཀྱི་ཁོངས་སུ་གཏོགས་པ་མ་ཡིན་པས་བྱས་ན་མ་བྱས་པ་ཉིད་དོ། །

[Block 3807]
ཁས་མ་བླངས་པས་ཁས་བླངས་པའི་ཟས་བསོད་པ་བླངས་པ་ཟོས་པ་དང་། ཁས་མ་བླངས་པའི་ཟས་བསོད་པ་ཁས་བླངས་པས་ཟོས་པ་དང་། དགེ་སློང་མ་དང་། བསླབ་པ་བྱིན་པ་མོ་ལ༌[^2564]བརྡེག་པ་དང་། གཟས་པ་དག་དང་། དེ་གཉིས་ཀྱི་གནས་ངན་ལེན་བཅས་པ་དང་། ཁས་བླངས་པས་ཁས་མ་བླངས་པ་ལ་འདུན་པ་བྱིན་ནས་ཁས་བླངས་པས་ཁས༌[^2565]མ་བླངས་པ་ལ་ཕྱིར་བསྒྱུར་བ་དང་། ཁས་མ་བླངས་པས་ཁས་བླངས་པ་ལ་དགེ་སློང་མ་དང་བསླབ་པ་མོ་ལ་འགྱོད་པ་བསྐྱེད་པ་དང་སྔངས་པར་བྱེད་པ་དང་། སྐུར་པ་འདེབས་པ་དག་དང་། ཁས་བླངས་པས་ཁས་མ་བླངས་པའི་ཡོ་བྱད་སྦེད་པ་དང་། བྱིན་ཕྲོགས་བྱེད་པ་དང་། ཁས་མ་བླངས་པས་ཁས་བླངས་པའི་ཡོ་བྱད་སྦེད་པ་དང་། བྱིན་ཕྲོགས་བྱེད་པ་དང་། ཁས་བླངས་པས་ཁས་མ་བླངས་པའི་བསླབ་པ་ལ་ཉེ་བར་འཇོག་པ་སྤོང་བ་དང་། ཁས་མ་བླངས་པས་བླངས་པ་ལ་ཉེ་བར་འཇོག་པ་སྤོང་བ་དང་། དགེ་སློང་མ་དང་ལྷན་ཅིག་དགེ་སློང་རྩོད་པ་བྱེད་པ་དང་། དགེ་སློང་མ་རྣམས་ཀྱིས་ཐུན་མོང་མ་ཡིན་པ་སྟོན་པ་ལ་ཁོ་བོ་འདི་ལ་མི་སློབ་བོ་ཞེས་ཟེར་བ་དག་ཀྱང་ཉེས་བྱས་སོ། །

[Block 3808]
འདིར་གཏོགས་པ་ལ་ཁྱིམ་པ་ལ་ནི་རྟགས་ཅན་ཉིད་ཀྱིས་ན་སྨད་དོ་ཞེས་བྱ་བ་ནི། དགེ་སློང་དང་། དགེ་སློང་མ་ཉིད་ཀྱི་རྒྱུ་མཚན་གྱི་ཁ་ན་མ་ཐོ་བ་འདིར་གཏོགས་པ་ལ་ཁྱིམ་པ་རབ་ཏུ་མ༌[^2566]བྱུང་བའི་གང་ཟག་གི་རྟགས་ཅན་ནི༌[^2567]ན༌[^2568]སྨད་པར་ཡོངས་སུ་མ་རྫོགས་པ་ཉིད་དོ། །

[Block 3809]
ཇི་ལྟར་འདིར་ཕྱི་རོལ་པའི་རབ་ཏུ་བྱུང་བ་ལ་ན་སྨད་པ་བཞིན་དུ་ཕྱི་རོལ་པའི་རབ་ཏུ་བྱུང་བའི་རྒྱུ་མཚན་ལས༌[^2569]ན་སྨད་པ་དེ་བས་ཀྱང་ཁྱིམ་པ་ལ་ཆེས་ན་སྨད་པར་ཤེས་པར་བྱ་ཞེས་བྱ་བའི་དོན་ཏོ། །

[Block 3810]
གཞི་མེད་པ་དང་བག་ཙམ་དག་གིས་ནི་ཉེས་བྱས་ཕྲ་མོར་འགྱུར་རོ། །

[Block 3811]
ཁྱིམ་པར་གྱུར་པའི་སྐྱེས་པ་དང་བུད་མེད་ལ་སྐུར་བ་བཏབ་པ་མ་ཡིན་པ་ཞེས་བྱ་བ་འདིས་འཇུག་པ་ཀུན་ནས་ཐོབ་པའི་དོན་དུ་མདོ་འདི༌[^2570]བྱས་སོ། །

[Block 3812]
མི་མ་ཡིན་པ་རྟགས་ཅན་མ་ཡིན་པ་ལ་སྐྱོན་ནས་སྨྲས་པ་དང་ཕྲ་མ་བྱས་པ་ལ་ནི་ཉེས་བྱས་ཕྲ་མོའོ། །

[Block 3813]
མི་མ་ཡིན་པའི༌[^2571]ཁྱིམ་པ་རྣམས་ལ་འཕྱ་བ་དང་། ཁྱིམ་པའི་གནས་མལ་མ་བརྟུལ་བར༌[^2572]འགྲོ་བ་དང་། གང་ཟག་ལ་ནི་གང་ཞིག་ཉེས་བྱས་སུ་བྱས་པ་དེའི་བསོད་ནམས་མ་ཡིན་པར་རིག་པར་བྱའོ། །

[Block 3814]
མི་མ་ཡིན་པ་ཁྱིམ་པ་རྣམས་སྐྲོད་པ་དང་། དེ་རྣམས་ལ་བརྡེག་པ་དང་། གཟས་པ་དག་དང་། [^2573]ཁྱིམ་པ་གཞན་གཉིས་ཀ་ལ་ཡང་སྦྱོར་དུ་བཅུག་པ་ཟ་བ་དང་། དེ་དག་ལ་འགྱོད་པ་སྐྱེད་པ༌[^2574]དང་། ག་ག་ཚིལ་བྱེད་པ་དང་སྐུར་པ་འདེབས་པ་ཡང་ཉེས་བྱས་ཕྲ་མོའོ། །

[Block 3815]
འདིར་མི་མ་ཡིན་པ་དག་དང་ལྷན་ཅིག༌[^2575]པའི་དཔེ་དག་ལ་རྒྱུ་གཉིས་ཀྱིས་ན་སྨད་པར་ཤེས་པར་བྱ་སྟེ། ཁྱིམ་པ་ཉིད་ཡིན་པའི་ཕྱིར་དང་མི་མ་ཡིན་པ་ཉིད་ཡིན་པའི་ཕྱིར་རོ། །

[Block 3816]
རབ་ཏུ་བྱུང་བའི་རྫས་དག་ལ་ནི་རུང་བ་ཉིད་དང་ཚད་དང་ལྡན་པ་ལ་སོགས་པ་ཉིད་དོ་ཞེས་བྱ་བ་ནི། གཉིས་པོ་འདི་དག་ནི་དེ་རྣམས་ཀྱི་ཡན་ལག་གོ། །

[Block 3817]
སོགས་པའི་སྒྲས་ནི་མ་ཆོག་པ་ལ་ན་སྨད་པའི་བྱེད་པ་པོ་ཉིད་ཡིན་གྱི། ལྷག་པ༌[^2576]ལ་ནི་མ་ཡིན་ཞེས་བྱ་བའི་དོན་ཏོ། །

[Block 3818]
འདིར་ཚད་ལས་ལྷག་པ་ཡན་ལག་ཡིན་པའི་གཞུང་ནི། སྲིན་བལ་གྱི༌[^2577]སྟན་གྱི་སྐབས་ནས་བདེ་བར་གཤེགས་པའི་གདན་དང་ཚད་བགྱིད་ན་ལྟུང་བ་ཅིར་འགྱུར། སྤང་བའི་ལྟུང་བྱེད་དོ་ཞེས་གསུངས་པ་ཡིན་ནོ། །

[Block 3819]
