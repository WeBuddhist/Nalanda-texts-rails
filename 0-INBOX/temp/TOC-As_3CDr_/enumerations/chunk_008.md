```
Enumeration Block 1:
རྗེས་སུ་མཐུན་པའི་ཆོས་དེ་དག་དང་ལྡན་པ་དེའི་ཆོས་ལྔ་ནི་ཚུལ་ཁྲིམས་ཀྱི་ཕུང་པོ་སྲུང་བར་བྱེད་པ་ཡིན་ཏེ། ལེགས་པར་མངོན་པར་འབྱུང་བ་དང་། ཡོངས་སུ་འདྲི་བ་དང་། སོ་སོར་རྟོག་པ་དང་། གཉེན་པོ་སྒོམ་པ་དང་། དད་པའོ། །
```

```
Enumeration Block 2:
དགེ་སློང་འདུལ་བའི་བསླབ་པ་ལ་བརྩོན་པའི་ཆོས་ལྔ་ནི་ཉེ་བར་ཞི་བ་དང་། དུལ་བ་དང་། ཞི་བར་འགྱུར་བ་ཡིན་ཏེ། ལྔ་གང་ཞེ་ན། དེས་ཤིང་འགྲོགས་ན་བདེ་བ་ཉིད་དང་། སྤོང་བ་དང་། སྤོང་བའི་ཡན་ལག་དང་། བསྙེན་བཀུར་དང་། རྩོད་པ་ཉེ་བར་ཞི་བའོ། །
```

```
Enumeration Block 3:
དེ་ལས་བཟློག་པ་དཀར་པོའི་ཕྱོགས་ཀྱི་རྒྱུ་གསུམ་གྱིས་ནི་ཡང་དག་པར་མགུ་བར་འགྱུར་བའི་ཆོས་དྲུག་རྣམ་པར་གཞག་པར་རིག་པར་བྱ་སྟེ། དང་པོས༌[^190]ནི་གསུམ་རྣམ་པར་གཞག་གོ། །གཉིས་པས་ནི་བཞི་པའོ།[^191] །གསུམ་པས་ནི་ལྔ་པ་དང་དྲུག་པའོ། །
```

```
Enumeration Block 4:
རྒྱུ་གཉིས་ཀྱིས་ནི་དགའ་བ་ཉིད་དུ༌[^199]འགྱུར་ཏེ། ཡོན་ཏན་ལ་ཡིད་ཆེས་པས་བླ་མ་ཉིད་དང་། ཕན་འདོགས་པས་ཡིད་དུ་འོང་བ་ཉིད་ཀྱིས་སོ། །
```

```
Enumeration Block 5:
དགའ་བ་ཉིད་དེའི་འཕེལ་བ་ནི་རྣམ་པ་གཉིས་ཏེ། མ་སྐྱེས་པ༌[^200]སྐྱེད་པར་བྱེད་པ་དང་སྐྱེས་པ་ཕྱིར་འབྱུང་བ་འཕེལ་ཞིང་རྒྱས་པར་འགྱུར་བའོ། །
```
