Enumeration Block 1:
རྟེན་ཀྱང་ལྔ་སྟེ། ལྔ་གང་ཞེ་ན། གྲོང་སོགས་ལ་བརྟེན་པ་དང་། གནས་ལ་བརྟེན་པ་དང་། གང་ཟག་ལ་བརྟེན་པ་དང་། ཆོས་གོས་ལ་སོགས་པ་ཡོ་བྱད་ལ་བརྟེན་པ་དང་། སྤྱོད་ལམ་ལ་བརྟེན་པའོ། །

Enumeration Block 2:
ལོངས་སྤྱོད་མི་རུང་བ་ལྔ་དང་། རུང་བ་ལྔར་རིག་པར་བྱ་སྟེ།

Enumeration Block 3:
ལས་ནི་མདོར་བསྡུ་ན་བཞི་སྟེ། གསོལ་བའི་ལས་དང་། གསོལ་བ་དང་གཉིས་ཀྱི་ལས་དང་། གསོལ་བ་དང་བཞིའི་ལས་དང་། ལན་གསུམ་བརྗོད་པའི་ལས་སོ། །

Enumeration Block 4:
ལས་བཞིའི༌[^131]དེ་དག་ཀྱང་གཞི་གཉིས་ལ་བརྟེན་པ་ཡིན་ཏེ། སེམས་ཅན་དུ་བགྲང་བ་དང་། སེམས་ཅན་དུ་བགྲང་བ་མ་ཡིན་ནོ། །

Enumeration Block 5:
དགེ་སློང་འདུལ་བའི་བསླབ་པ་ལ་བརྩོན་པའི་བསླབ་པ་དང་མི་མཐུན་པའི་ཆོས་ནི་ལྔར་ཤེས་པར་བྱ་སྟེ།

Enumeration Block 6:
བསླབ་པ་དང་མཐུན་པ་ཡང་ལྔ་སྟེ།

Enumeration Block 7:
བསླབ་པ་དང་མི་མཐུན་པ་ལྔ་གང་ཞེ་ན། བར་དུ་གཅོད་པ་དང་། དམ་པའི་ཆོས་ལྟར་བཅོས་པ་དང་། སྡིག་པའི་གྲོགས་པོ་དང་། གླེན་ཞིང་ཉོན་མོངས་པ་མང་བ་དང་། སྔོན་གྱི་ཚོགས་སྟོབས་ཆུང་བ་ནི་ལྔ་པ་ཡིན་ནོ། །

Enumeration Block 8:
བར་དུ་གཅོད་པ་ལྔ་གང་ཞེ་ན། ལྷག་པའི་ཚུལ་ཁྲིམས་ཀྱི་བར་དུ་གཅོད་པ་དང་། ལྷག་པའི་སེམས་ཀྱི་བར་དུ་གཅོད་པ་དང་། ལྷག་པའི་ཤེས་རབ་ཀྱི་བར་དུ་གཅོད་པ་དང་། བདེ་འགྲོར་འགྲོ་བའི་བར་དུ་གཅོད་པ་དང་། རྙེད་པ་དང་སྲོག་དང་འཕྲལ་གྱི་བྱ་བའི་བར་དུ་གཅོད་པའོ། །

Enumeration Block 9:
དམ་པའི་ཆོས་ལྟར་བཅོས་པ་ནི་མདོར་བསྡུ་ན་རྣམ་པ་གཉིས་སུ་དགོངས་པར་རིག་པར་བྱ་སྟེ། བཤད་པ་དམ་པའི་ཆོས་ལྟར་ཐོས་པ་དང་། སྒྲུབ་པ་དམ་པའི་ཆོས་ལྟར་བཅོས་པའོ། །
