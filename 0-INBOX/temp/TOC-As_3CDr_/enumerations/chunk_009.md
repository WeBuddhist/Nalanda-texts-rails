Enumeration Block 1:
རྒྱུ་གཉིས་ཀྱིས་ནི་དགའ་བ་ཉིད་དུ༌[^199]འགྱུར་ཏེ། ཡོན་ཏན་ལ་ཡིད་ཆེས་པས་བླ་མ་ཉིད་དང་། ཕན་འདོགས་པས་ཡིད་དུ་འོང་བ་ཉིད་ཀྱིས་སོ། །
དགའ་བ་ཉིད་དེའི་འཕེལ་བ་ནི་རྣམ་པ་གཉིས་ཏེ། མ་སྐྱེས་པ༌[^200]སྐྱེད་པར་བྱེད་པ་དང་སྐྱེས་པ་ཕྱིར་འབྱུང་བ་འཕེལ་ཞིང་རྒྱས་པར་འགྱུར་བའོ། །

Enumeration Block 2:
སྔོན་བསོད་ནམས་བྱས་པའི་རྣམ་པར་སྨིན་པའི་འབྲས་བུ་འདོད་པ་རྣམ་པ་གཉིས་ལ་གནས་པ་ཡིན་ཏེ། ནང་གི་དང་ཕྱི་རོལ་གྱིའོ། །

Enumeration Block 3:
དེ་ལ་བསྙེན་བཀུར་ནི་རྣམ་པ་གསུམ་གྱིས་རིག་པར་བྱའོ། །
ཡོན་ཏན་དང་ཕན་ཡོན་ལ་ཡིད་ཆེས་པས་བླ་མར་བྱ་བ་དང་ཡིད་ཆེས་པ་དང་། རྗེས་སུ་མཐུན་པའི་ལུས་དང་ངག་དང་ཡིད་ཀྱིས་ཐུན་མོང་དུ་ལེགས་པར་བསྒྲུབས་པས་རི་མོར་བྱ་བ་དང་། གདུགས་དང་། རྒྱལ་མཚན་དང་བ་དན་དག་གིས་མཆོད་པར་བྱའོ། །

Enumeration Block 4:
དེ་དག་ཀྱང་མདོར་བསྡུ་ན་རྩོད་པ་རྣམ་པ་བཞི་དང་། དེ་ཉེ་བར་ཞི་བ་རྣམ་པ་བཞིར་འགྱུར་ཏེ། རྩོད་པ་རྣམ་བཞི༌[^250]གང་ཞེ་ན།
གཞན་གྱིས་གླེངས་པས་རྩོད་པ་དང་། ཕན་ཚུན་ཐེ་ཚོམ་ཟ་བས་རྩོད་པ་དང་། བདག་ཉིད་གླེངས་པས་རྩོད་པ་དང་། ཕན་ཚུན་གླེངས་པས་རྩོད་པས་སོ། །
ཉེ་བར་ཞི་བ་རྣམ་པ་བཞི་གང་ཞེ་ན།
བསམས་པའི༌[^251]ལྟུང་བ་དགེ་འདུན་ལ་སྟོན་པས་ཉེ་བར་ཞི་བ་དང་། ཡོངས་སུ་དག་པས༌[^252]སྦྱིན་པས༌[^253]ཉེ་བར་ཞི་བ་དང་། དེའི་ངོ་བོ་ཉིད་དང་གང་མང་བ་ཚོལ་བ་དང་ཡང་དག་པ་ཇི་ལྟ་བ་བཞིན་འགྲོ་བས་ཉེ་བར་ཞི་བ་དང་། བཤགས་པས་ཉེ་བར་ཞི་བའོ། །

Enumeration Block 5:
དགེ་སློང་འདུལ་བའི་བསླབ་པ་ལ་བརྩོན་པས་ཡོངས་སུ་ཤེས་པར་བྱ་བའི་གནས་ནི་ལྔ་སྟེ། ལྔ་གང་ཞེ་ན།
དངོས་པོ་ཡོངས་སུ་ཤེས་པར་བྱ་བ་དང་། ལྟུང་བ་ཡོངས་སུ་ཤེས་པར་བྱ་བ་དང་། གང་ཟག་ཡོངས་སུ་ཤེས་པར་བྱ་བ་དང་། རྫས་བླང་བ་ཡོངས་སུ་ཤེས་པར་བྱ་བ་དང་། གནོད་པ་ཡོངས་སུ་ཤེས་པར་བྱ་བའོ། །

Enumeration Block 6:
གཞན་ཡང་མདོར་བསྡུ་ན་དངོས་པོ་གཉིས་ཏེ། སེམས་ཅན་དུ་སྟོན་པ་དང་། སེམས་ཅན་དུ་མི་སྟོན་པའོ། །

Enumeration Block 7:
དགེ་སློང་འདུལ་བའི་བསླབ་པ་ལ་བརྩོན་པས་རྣམ་པ་ལྔས་ལྟུང་བ་ཡོངས་སུ་ཤེས་པར་བྱ་སྟེ། གཞི་དང་། ཀུན་ནས་སློང་བ་དང་། དངོས་པོ་དང་། སྦྱོར་བ་དང་། མཐའ་ཡས༌[^254]སོ། །

Enumeration Block 8:
དངོས་པོ་ལས་ནི་མདོར་བསྡུ་ན་དངོས་པོ་རྣམ་པ༌[^261]གཉིས་ཏེ། སེམས་ཅན་དུ་བགྲང་བ་དང་། སེམས་ཅན་དུ་བགྲང་བ་མ་ཡིན་པའོ། །
སྦྱོར་བ་ཡང་རྣམ་པ་གཉིས་ཏེ། བྱ་བ་མ་ཡིན་པ་བྱེད་པའི་སྦྱོར་བ་དང་། བྱ་བ་མི་བྱེད་པའི་སྦྱོར་བའོ། །
