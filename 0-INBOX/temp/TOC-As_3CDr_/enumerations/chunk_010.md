Enumeration Block 1:
དངོས་པོ་ལས་ནི་མདོར་བསྡུ་ན་དངོས་པོ་རྣམ་པ༌[^261]གཉིས་ཏེ། སེམས་ཅན་དུ་བགྲང་བ་དང་། སེམས་ཅན་དུ་བགྲང་བ་མ་ཡིན་པའོ། །

Enumeration Block 2:
སྦྱོར་བ་ཡང་རྣམ་པ་གཉིས་ཏེ། བྱ་བ་མ་ཡིན་པ་བྱེད་པའི་སྦྱོར་བ་དང་། བྱ་བ་མི་བྱེད་པའི་སྦྱོར་བའོ། །

Enumeration Block 3:
དེ་ལ་གང་ཟག་ཡོངས་སུ་ཤེས་པར་བྱ་བ་ནི་རྣམ་པ་ལྔས་རིག་པར་བྱ་སྟེ། དཔྱད་པའི་དབྱེ་བ་དང་། རིས་ཀྱི་དབྱེ་བ་དང་། མཐོ་དམན་གྱི་དབྱེ་བ་དང་། འཐོབ་པའི་དབྱེ་བ་དང་། བརྟག་པའི་དབྱེ་བས་སོ། །

Enumeration Block 4:
རྫས་བླང་བ་ནི་མདོར་བསྡུ༌[^279]ན་རྣམ་པ་གསུམ་དུ་རིག་པར་བྱ་སྟེ། བདག་ཉིད་དང་གཞན་དག་གི་རྙེད་པའི་རྫས་བླང་བ་དང་། ལྟུང་བ་ལས་བསླང་བའི༌[^280]རྫས་བླང་བ་དང་། དགེ་འདུན་བདེ་བར་བྱ་བའི་ཕྱིར་ཚུལ་ཁྲིམས་འཆལ་པ་བསྐྲད་པའི་རྫས་བླང་བའོ། །

Enumeration Block 5:
སེར་སྣའི་དྲི་མ་བརྒྱད་དེ། སྔོན་སེར་སྣ་ལ་གོམས་ཤིང་གཏོང་བ་ལ་མ་གོམས་པར༌[^288]སེར་སྣའི་དྲི་མ་དང་། ཚེ་འདི་ལ་ལུས་དང་སྲོག་ལ་ཤས་ཆེར་བལྟ་བ་དང་དེ་དང་སྐལ་བ་མཉམ་པའི་མཛའ་བཤེས་རྣམས་དང་འགྲོགས་ཤིང་རྗེས་སུ་འཇུག་པ་དང་། སེམས་ཅན་རྣམས་ལ་སྙིང་རྗེ་མ་གོམས་ཤིང་སྙིང་རྗེ་ཆུང་བ་དང་། ཞིང་མི་མཐུན་པ་ལ་སོགས་པར་སྒྲུབ་པ་ཀུན་ཏུ་སྟོན་པ་དང་། ཚེགས་ཆེན་པོས་ལོངས་སྤྱོད་འཐོབ་ཅིང་ཚེགས་ཆེན་པོས་འཐོབ་པར་གོམས་པའི་འདུ་ཤེས་དང་། དུས་གསུམ་དུ་ཡིད་མི་བདེ་ཞིང་འགྱོད་པ་དང་། གཅིག་ཏུ་ལོངས་སྤྱོད་རྣམས་ལ་ཡོན་ཏན་དུ་ལྟ༌[^289]ཞིང་ཉེས་དམིགས་སུ་མི་ལྟ་ལ། ལོག་པར་ལེན་ཅིང་ཡོངས་སུ་བསྔོ་སྟེ།

Enumeration Block 6:
དགེ་སློང་འདུལ་བའི་བསླབ་པ༌[^294]ལ་བརྩོན་པའི་ཆོས་ལྔ་ནི་མ་དད་པ་རྣམས་དད་པ་དང་དད་པ་རྣམས་ཕྱིར་ཞིང་འཕེལ་བར་འགྱུར་ཏེ། ལྔ་གང་ཞེ་ན། ཚུལ་ཁྲིམས་ཕུན་སུམ་ཚོགས་པ་དང་། ལྟ་བ་ཕུན་སུམ་ཚོགས་པ་དང་། ཆོ་ག་ཕུན་སུམ་ཚོགས་པ་དང་། འཚོ་བ་ཕུན་སུམ་ཚོགས་པ་དང་། ཕན་ཚུན་འཐབ་པ་དང་རྩོད་པ་མེད་པའོ། །

Enumeration Block 7:
དགེ་སློང་འདུལ་བའི་བསླབ་པ་ལ་བརྩོན་པའི༌[^313]སྟོབས་ལྔ་དང་ལྡན་པའི་ཡང་དག་པའི་སྦྱོར་བ་ནི་རྣམ་པ་ཐམས་ཅད་དུ་ཕུན་སུམ་ཚོགས་པ་ཡིན་པར་རིག་པར་བྱ་སྟེ། ལྔ་གང་ཞེ་ན། སྦྱོར་བའི་སྟོབས་དང་། བསམ་པའི་སྟོབས་དང་། རྟོགས་པའི་སྟོབས་དང་། ཤེས་པའི་སྟོབས་དང་། གནས་པའི་སྟོབས་སོ། །
