Enumeration Block 1:
ད་ནི་དེ་ཉིད་ཀྱི་བཤད་པ་བརྩམ་པར་བྱ་སྟེ།[^44] །སྡོམ་ནི། །
ཕན་ཡོན་སྡེ་ཚན་སྡུད་པ་དང་། །
རྗེས་སྤྱོད་མི་མཐུན་མཐུན་པ་དང་། །
ཉེར་ཞི་ཡོངས་ཤེས་རྣམ་ལྔ་དང་། །
དད་འགྱུར་འཕེལ་བར་འགྱུར་བ་དང་། །
སྟོབས་ལྔ་པོ་ནི་ཐ་མ་ཡིན། །
```

```
Enumeration Block 2:
དགེ་འདུན་བདེ་བར་གནས་པ༌[^48]བྱ་བ་ནི་རྣམ་པ་ལྔས་རིག་པར་བྱ་སྟེ། ཡོ་བྱད་རྐྱེན་དུ་འབབ་པ་དག་ཡོད་པ་དང་། ཆོས་མི་མཐུན་པའི་གང་ཟག་རྣམ་པར་བསྐྲད་པ་དང་། འགྱོད་པ་སྐྱེས་པ་སེལ་བ་དང་། ཉོན་མོངས་པའི་ཀུན་ནས་དཀྲིས་པ་རྣམ་པར་གནོན་པ་དང་། ཉོན་མོངས་པའི་བག་ལ་ཉལ་སྤོང་བས་སོ། །
```

```
Enumeration Block 3:
ལྟུང་བའི་སྡེ་ཚན་ནི་མདོར་བསྡུ་ན་རྣམ་པ་ལྔ་སྟེ། [^53]ལྔ་གང་ཞེ་ན།
ཕམ་པ་དང་། དགེ་འདུན་ལྷག་མ་དང་། ལྟུང་བྱེད་དང་། སོ་སོར་བཤགས་པར་བྱ་བ་དང་། ཉེས་བྱས་སོ། །
