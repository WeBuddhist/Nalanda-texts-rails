* 1. ཕན་ཡོན་ [[དེ་བཞིན་གཤེགས་པ་ནི་ཕན་ཡོན་བཅུ་ཡང་དག་པར་གཟིགས་ནས་]]
   * 1.1 དགེ་འདུན་བསྡུ་བ་ [[དེ་ལ་དགེ་འདུན་བསྡུ་བའི་ཕྱིར་ཞེས་བྱ་བ་ནི་]]
   * 1.2 དགེ་འདུན་ལེགས་པར་བྱ་བ་ [[དེ་ལྟར་རབ་ཏུ་བྱུང་བ་རྣམས་ལ་གཞི་དང་བཅས།]]
   * 1.3 དགེ་འདུན་བདེ་བར་གནས་པར་བྱ་བ་ [[དགེ་འདུན་བདེ་བར་གནས་པ༌[^48]བྱ་བ་ནི་རྣམ་པ་ལྔས་རིག་པར་བྱ་སྟེ།]]
      * 1.3.1 ཡོ་བྱད་རྐྱེན་དུ་འབབ་པ་དག་ཡོད་པ་ [[ཡོ་བྱད་རྐྱེན་དུ་འབབ་པ་དག་ཡོད་པ་དང་།]]
      * 1.3.2 ཆོས་མི་མཐུན་པའི་གང་ཟག་རྣམ་པར་བསྐྲད་པ་ [[ཆོས་མི་མཐུན་པའི་གང་ཟག་རྣམ་པར་བསྐྲད་པ་དང་།]]
      * 1.3.3 འགྱོད་པ་སྐྱེས་པ་སེལ་བ་ [[འགྱོད་པ་སྐྱེས་པ་སེལ་བ་དང་། ཉོན་མོངས་པའི་ཀུན་ནས་དཀྲིས་པ་རྣམ་པར་གནོན་པ་དང་།]]
      * 1.3.4 ཉོན་མོངས་པའི་ཀུན་ནས་དཀྲིས་པ་རྣམ་པར་གནོན་པ་ [[ཉོན་མོངས་པའི་ཀུན་ནས་དཀྲིས་པ་རྣམ་པར་གནོན་པ་དང་། ཉོན་མོངས་པའི་བག་ལ་ཉལ་སྤོང་བས་སོ།]]
      * 1.3.5 ཉོན་མོངས་པའི་བག་ལ་ཉལ་སྤོང་བ་ [[ཉོན་མོངས་པའི་བག་ལ་ཉལ་སྤོང་བས་སོ། །]]
   * 1.4 གནོང་མི་བཀུར་བའི་གང་ཟག་རྣམས་ཚར་གཅད་པ་ [[གཉིས་པའི་དབང་དུ་མཛད་ནས་ནི་གནོང་མི་བཀུར་བའི་གང་ཟག་རྣམས་ཚར་གཅད་པའི༌[^49]ཕྱིར་ཞེས་བྱའོ།]]
   * 1.5 ངོ་ཚ་ཤེས་པ་རྣམས་བདེ་བར་གནས་པ་ [[གསུམ་པའི་དབང་དུ་མཛད་ནས་ནི། ངོ་ཚ་ཤེས་པ་རྣམས་བདེ་བ་ལ་གནས་པར་བྱ་བའི་ཕྱིར་ཞེས་བྱའོ།]]
   * 1.6 མངོན་པར་མ་དད་པ་རྣམས་དད་པར་བྱ་བ་ [[དེ་ལ༌བདེ་བར་གནས་པར་བྱ་བ་དང་པོའི་དབང་དུ་མཛད་ནས་ནི། མངོན་པར་མ་དད་པ་རྣམས་མངོན་པར་དད་པར་བྱ་བའི་ཕྱིར་དང་།]]
   * 1.7 མངོན་པར་དད་པ་རྣམས་ཕྱིར་ཞིང་དད་པར་བྱ་བ་ [[མངོན་པར་དད་པ་རྣམས་ཕྱིར་ཞིང་དད་པར་བྱ་བའི་ཕྱིར་ཞེས་བྱ་བ་གསུངས་སོ།]]
   * 1.8 ཚེ་འདིའི་ཟག་པ་རྣམས་བསྡམ་པར་བྱ་བ་ [[བཞི་པའི་དབང་དུ་མཛད་ནས་ནི་ཚེ་འདིའི་ཟག་པ་རྣམས་བསྡམ་པའི་ཕྱིར་ཞེས་བྱའོ།]]
   * 1.9 ཚེ་རབས་ཕྱི་མའི་ཟག་པ་རྣམས་གཞོམ་པ་ [[ལྔ་པའི་དབང་དུ་མཛད་ནས་ནི་ཚེ་རབས་ཕྱི་མའི་ཟག་པ་རྣམས་གཞོམ་པའི་ཕྱིར་ཞེས་བྱའོ།]]
   * 1.10 ངའི་ཚངས་པར་སྤྱོད་པ་ཡུན་རིང་དུ་གནས་པར་འགྱུར་བ་ [[ཐོབ་པ་རྣམས་བདེ་བར་གནས་པར་འགྱུར་བ་དང་། མ་ཐོབ་པ་ལ་ཞུགས་པ་རྣམས་བདེ་བར་འཇུག་པར་འགྱུར་བའི་ཕྱིར་ངའི་ཚངས་པར་སྤྱོད་པ་]]
* 2. སྡེ་ཚན་ [[ལྟུང་བའི་སྡེ་ཚན་ནི་མདོར་བསྡུ་ན་རྣམ་པ་ལྔ་སྟེ།]]

   * 2.2 དགེ་འདུན་ལྷག་མ་ [[དགེ་འདུན་ལྷག་མ་དང་། ལྟུང་བྱེད་དང་།]]
   * 2.3 ལྟུང་བྱེད་ [[ལྟུང་བྱེད་དང་། སོ་སོར་བཤགས་པར་བྱ་བ་དང་།]]
   * 2.4 སོ་སོར་བཤགས་པར་བྱ་བ་ [[སོ་སོར་བཤགས་པར་བྱ་བ་དང་། ཉེས་བྱས་སོ།]]
   * 2.5 ཉེས་བྱས་ [[ཉེས་བྱས་སོ། །ཉེས་པ་སྦོམ་པོ༌[^54]གང་ཡིན་པ་དང་།]]
* 3. སྡུད་པ་ [[འདུལ་བ་སྡུད་པ་བྱེད་པའི་ཆོས་ནི་ལྔ་པོ་འདི་དག་ཡིན་ཏེ།]]

   * 3.2 བཅས་པའི་ཁ་ན་མ་ཐོ་བ་དང་བཅས་པ་ [[བཅས་པའི་ཁ་ན་མ་ཐོ་བ་དང་བཅས་པ་གང་ཞེ་ན།]]

   * 3.4 གནང་བ་ [[གནང་བ་ནི་དེ་ལས་བཟློག་པ་ཡིན་པར་རིག་པར་བྱའོ།]]
   * 3.5 སྒྲུབ་པ་ [[སྒྲུབ་པ་གང་ཞེ་ན།]]

         * 3.5.1.1 ལྟུང་བའི་རྒྱུ་རྣམ་པ་བཞི་ [[དེ་དག་ཀྱང་རྒྱུ་རྣམ་པ་བཞིས་འབྱུང་སྟེ།]]
         * 3.5.1.2 ལྟུང་བ་རྣམས་ཀྱི་ཆུང་ངུ་དང་འབྲིང་དང་ཆེན་པོ་ཉིད་ [[ལྟུང་བ་རྣམས་ཀྱི་ཆུང་ངུ་དང་། འབྲིང་དང་། ཆེན་པོ་ཉིད་ནི་རྣམ་པ་ལྔས་རིག་པར་བྱ་སྟེ།]]
      * 3.5.2 ལྟུང་བ་མེད་པ་ [[ལྟུང་བ་མེད་པ་གང་ཞེ་ན།]]
      * 3.5.3 ལྟུང་བ་ལས་བསླང་བ་ [[ལྟུང་བ་ལས་བསླང་བ་གང་ཞེ་ན།]]
* 4. རྗེས་སྤྱོད་མི་མཐུན་མཐུན་པ་ [[འདུལ་བའི་རྗེས་སུ་སྤྱོད་པའི་ཆོས་ནི་ལྔ་པོ་འདི་དག་ཡིན་པར་རིག་པར་བྱ་སྟེ།]]
   * 4.1 འདུལ་བའི་རྗེས་སུ་སྤྱོད་པའི་ཆོས་ [[གནས་པ་དང་། གནས་དང་། རྟེན་དང་། ལོངས་སྤྱོད་དང་། ལས་ནི་ལྔ་པ་ཡིན་ནོ།]]
      * 4.1.1 གནས་པ་ [[དེ་ལ་གནས་པ་གང་ཞེ་ན།]]
      * 4.1.2 གནས་ [[གནས་གང་ཞེ་ན།]]
      * 4.1.3 རྟེན་ [[རྟེན་གང་ཞེ་ན།]]
      * 4.1.4 ལོངས་སྤྱོད་ [[ལོངས་སྤྱོད་གང་ཞེ་ན།]]

   * 4.2 བསླབ་པ་དང་མི་མཐུན་པའི་ཆོས་ [[དགེ་སློང་འདུལ་བའི་བསླབ་པ་ལ་བརྩོན་པའི་བསླབ་པ་དང་མི་མཐུན་པའི་ཆོས་ནི་ལྔར་ཤེས་པར་བྱ་སྟེ།]]
      * 4.2.1 བར་དུ་གཅོད་པ་ [[བར་དུ་གཅོད་པ་ལྔ་གང་ཞེ་ན།]]
      * 4.2.2 དམ་པའི་ཆོས་ལྟར་བཅོས་པ་ [[དམ་པའི་ཆོས་ལྟར་བཅོས་པ་གང་ཞེ་ན།]]
      * 4.2.3 སྡིག་པའི་གྲོགས་པོ་ [[སྡིག་པའི་གྲོགས་པོ་ནི༌[^173]རྒྱ་ཆེར་འདི་ལྟ་སྟེ།]]
      * 4.2.4 གླེན་ཞིང་ཉོན་མོངས་པ་མང་བ་ [[དམན་ཞིང་རྨོངས་པའི་རང་བཞིན་ཅན་གྱི་ཉོན་མོངས་པ་ཤས་ཆེ་བ་གང་ཡིན་པ་དེ་ནི་གླེན་ཞིང་ཉོན་མོངས་པ་མང་བ་ཡིན་པར་རིག་པར་བྱའོ།]]

   * 4.3 བསླབ་པ་དང་མཐུན་པའི་ཆོས་ [[དེ་ལས་བཟློག་པའི་ཆོས་ལྔ་ནི་བསླབ་པ་དང་མཐུན་པ་ཡིན་པར་རིག་པར་བྱ་སྟེ།]]
      * 4.3.1 ལེགས་པར་མངོན་པར་འབྱུང་བ་ [[དེ་ལ་བུ་ལོན་གྱིས་ཉམ་ཐག་ནས་རབ་ཏུ་བྱུང་བ་མ་ཡིན་པ༌[^178]ཞེས་བྱ་བ་ནས།]]
      * 4.3.2 ཡོངས་སུ་འདྲི་བ་ [[དེ་དེ་ལྟར་མངོན་པར་བྱུང་ནས་ལྟུང་བ་དང་ལྟུང་བ་མེད་པ་དང་ལྟུང་བ་ལས་བསླངས་པ༌[^180]ལས་བརྩམས་ནས་]]
      * 4.3.3 སོ་སོར་རྟོག་པ་ [[དུས་གསུམ་དུ་བདག་ཉིད་ཀྱི་ཚུལ་ཁྲིམས་དག་ལས་སོ༌[^184]སོར་རྟོག་པར་བྱེད་ཅིང་]]
      * 4.3.4 གཉེན་པོ་སྒོམ་པ་ [[དེ་དུས་དུས་སུ་ནི༌[^185]ནམ་གྱི་ཆ་སྟོད་དང་། ནམ་གྱི་ཆ་སྨད་དག་ལ༌[^186]ཉིན་མོ་ཡང་རུང་སྟེ།]]
      * 4.3.5 དད་པ་ [[དེ་ལྟུང་བའི་འབྲས་བུ་ཕྱི་མ་ལ་མི་འདོད་པ་ཡིན་པར་ཡིད་ཆེས་པ་ནི་དད་པ་ཡིན་པར་རིག་པར་བྱའོ།]]
* 5. ཉེར་ཞི་ཡོངས་ཤེས་རྣམ་ལྔ་ [[དགེ་སློང་འདུལ་བའི་བསླབ་པ་ལ་བརྩོན་པའི་ཆོས་ལྔ་ནི་ཉེ་བར་ཞི་བ་དང་། དུལ་བ་དང་།]]
   * 5.1 འདུལ་བ་ཉེར་ཞིའི་ཆོས་ལྔ་ [[དེས་ཤིང་འགྲོགས་ན་བདེ་བ་ཉིད་དང་། སྤོང་བ་དང་། སྤོང་བའི་ཡན་ལག་དང་། བསྙེན་བཀུར་དང་། རྩོད་པ་ཉེ་བར་ཞི་བའོ།]]
      * 5.1.1 དེས་ཤིང་འགྲོགས་ན་བདེ་བ་ཉིད་ [[དེས་ཤིང་འགྲོགས་ན་བདེ་བ་ཉིད་གང་ཞེ་ན།]]
      * 5.1.2 སྤོང་བ་ [[སྤོང་བ་གང་ཞེ་ན། །ལྷ་དང་མི་རྣམས་ཀྱི་འཁོར་ལོ་བཞིའོ།]]
      * 5.1.3 སྤོང་བའི་ཡན་ལག་ [[སྤོང་བའི་ཡན་ལག་ནི་སྤོང་བའི་ཡན་ལག་ལྔའོ།]]
      * 5.1.4 བསྙེན་བཀུར་ [[བསྙེན་བཀུར་ནི་སྟོན་པ་ལ་བསྙེན་བཀུར་བྱེད་པ་ན་རྒྱས་པར་བག་ཡོད་པའི་བར་རོ།]]
      * 5.1.5 རྩོད་པ་ཉེ་བར་ཞི་བ་ [[རྩོད་པ་ཉེ་བར་ཞི་བར་བྱེད་པ་ནི་རྩོད་པ་ཉེ་བར་ཞི་བར་བྱེད་པའི་ཆོས་བདུན་ནོ།]]
         * 5.1.5.1 རྩོད་པ་རྣམ་པ་བཞི་ [[རྩོད་པ་རྣམ་བཞི༌[^250]གང་ཞེ་ན། །གཞན་གྱིས་གླེངས་པས་རྩོད་པ་དང་།]]
         * 5.1.5.2 ཉེ་བར་ཞི་བ་རྣམ་པ་བཞི་ [[ཉེ་བར་ཞི་བ་རྣམ་པ་བཞི་གང་ཞེ་ན། །བསམས་པའི༌[^251]ལྟུང་བ་དགེ་འདུན་ལ་སྟོན་པས་ཉེ་བར་ཞི་བ་དང་།]]
   * 5.2 ཡོངས་སུ་ཤེས་པར་བྱ་བའི་གནས་ལྔ་ [[དགེ་སློང་འདུལ་བའི་བསླབ་པ་ལ་བརྩོན་པས་ཡོངས་སུ་ཤེས་པར་བྱ་བའི་གནས་ནི་ལྔ་སྟེ།]]
      * 5.2.1 དངོས་པོ་ཡོངས་སུ་ཤེས་པར་བྱ་བ་ [[དེ་ལ་དངོས་པོ་ཡོངས་སུ་ཤེས་པར་བྱ་བ་གང་ཞེ་ན།]]
      * 5.2.2 ལྟུང་བ་ཡོངས་སུ་ཤེས་པར་བྱ་བ་ [[ལྟུང་བ་ཡོངས་སུ་ཤེས་པར་བྱ་བ་གང་ཞེ་ན།]]
      * 5.2.3 གང་ཟག་ཡོངས་སུ་ཤེས་པར་བྱ་བ་ [[དེ་ལ་གང་ཟག་ཡོངས་སུ་ཤེས་པར་བྱ་བ་ནི་རྣམ་པ་ལྔས་རིག་པར་བྱ་སྟེ།]]
         * 5.2.3.1 དང་པོ་དཔྱད་པའི་དབྱེ་བ་ [[དེ་ལ་དཔྱད་པའི་དབྱེ་བ་ནི། འདི་ལྟ་སྟེ། ཉན་ཐོས་ཀྱི་སར་བསྟན་པ་བཞིན་དུ་རིག་པར་བྱའོ།]]
         * 5.2.3.2 གཉིས་པ་རིས་ཀྱི་དབྱེ་བ་ [[རིས་ཀྱི་དབྱེ་བས༌[^271]ཡང་དགེ་སློང་དང་དགེ་སློང་མ་ལ་སོགས་པ་རིས་བདུན་གྱི་དབྱེ་བ་ཡིན་པར་རིག་པར་བྱའོ།]]
