Enumeration Block 1:
དགེ་འདུན་བདེ་བར་གནས་པ༌[^48]བྱ་བ་ནི་རྣམ་པ་ལྔས་རིག་པར་བྱ་སྟེ། ཡོ་བྱད་རྐྱེན་དུ་འབབ་པ་དག་ཡོད་པ་དང་། ཆོས་མི་མཐུན་པའི་གང་ཟག་རྣམ་པར་བསྐྲད་པ་དང་། འགྱོད་པ་སྐྱེས་པ་སེལ་བ་དང་། ཉོན་མོངས་པའི་ཀུན་ནས་དཀྲིས་པ་རྣམ་པར་གནོན་པ་དང་། ཉོན་མོངས་པའི་བག་ལ་ཉལ་སྤོང་བས་སོ། །

Enumeration Block 2:
ལྟུང་བའི་སྡེ་ཚན་ནི་མདོར་བསྡུ་ན་རྣམ་པ་ལྔ་སྟེ། [^53]ལྔ་གང་ཞེ་ན། ཕམ་པ་དང་། དགེ་འདུན་ལྷག་མ་དང་། ལྟུང་བྱེད་དང་། སོ་སོར་བཤགས་པར་བྱ་བ་དང་། ཉེས་བྱས་སོ། །

Enumeration Block 3:
ལྟུང་བ་ལས་བསླང་བའི་སྡེ་ཚན་ནི་རྣམ་པ་བཞི་སྟེ། བཞི་གང་ཞེ་ན། ཕམ་པ་མ་གཏོགས་པ་དེ་ལས་གཞན་པའི་ལྟུང་བ་བཞི་པོ་དག་ལས་བསླང་བ་དེ་དག་ནི་བསླང་བའི༌[^55]སྡེ་ཚན་བཞི་པོ་དག་ཡིན་ནོ། །

Enumeration Block 4:
དེ་ལ་ལྟུང་བའི་སྡེ་ཚན་ཐམས་ཅད་ལ་མདོར་བསྡུ་ན། ཉེས་པ་བཅོ་ལྔས་ལྟུང་བ་ཐམས་ཅད་རྣམ་པར་གཞག་པར་རིག་པར་བྱའོ།[^58] ། བཅོ་ལྔ་གང་ཞེ་ན། དངོས་པོ་ལྕི་བའི་ཉེས་པ་དང་མི་ལྡན་པ་དང་ཆོག་མི་ཤེས་པའི་ཉེས་པ་དང་། གཞན་དག་དང་གནས་སྐབས་བྱེད་པའི་ཉེས་པ་དང་། མ་དད་པ་དད་པར་མི་འགྱུར་ཞིང་དད་པ་གཞན་དུ་འགྱུར་བའི་ཉེས་པ་དང་། དོན་མང་ཞིང་བྱ་བ་མང་བའི་ཉེས་པ་དང་། ལྷག་པར་ཆགས་པའི་ཉེས་པ་དང་། གཞན་ལ་ཐོ་འཚམས༌[^59]པའི་ཉེས་པ་དང་། གནོད་པ་ཀུན་ནས་སློང་བའི་ཉེས་པ་དང་། བདེ་འགྲོར་འགྲོ་བའི་བར་དུ་གཅོད་པའི་ཉེས་པ་དང་། དགེ་སྦྱོང་གི་ཚུལ་གྱི་བར་དུ་གཅོད་པའི་ཉེས་པ་དང་། སྤང་བར་བྱ་བ་དང་། སྤང་བར་བྱ་བ་མ་ཡིན་པ་ལེགས་པར་མི་སྤོང་བ་དང་། སྤོང་བའི་ཉེས་པ་དང་། གནས་པར་བྱ་བ་མ་ཡིན་པ་དང་། གནས་པར་བྱ་བ་དང་གནས་པ་དང་མི་གནས་པར་བྱེད་པའི་ཉེས་པ་དང་། བསྙེན་བཀུར་བྱ་བ་དང་བསྙེན་བཀུར་མི་བྱ་བ་ལ་བསྙེན་བཀུར་མི་བྱེད༌[^60]པ་དང་། བསྙེན་བཀུར་བྱེད་པའི་ཉེས་པ་དང་། གསང་བར་བྱ་བ་དང་གསང་བར་མི་བྱ་བ་སྒྲོགས་པ་དང་འཆབ་པའི་ཉེས་པ་དང་། བསྟེན་པར་བྱ་བ་དང་བསྟེན་པར་མི་བྱ་བ་མི་བསྟེན་པ་དང་བསྟེན་པས་སོ། །

Enumeration Block 5:
འདུལ་བ་སྡུད་པ་བྱེད་པའི་ཆོས་ནི་ལྔ་པོ་འདི་དག་ཡིན་ཏེ། ལྔ་གང་ཞེ་ན། རང་བཞིན་གྱིས་ཁ་ན་མ་ཐོ་བ་དང་བཅས་པ་དང་། བཅས་པའི་ཁ་ན་མ་ཐོ་བ་དང་བཅས་པ་དང་། དགག་པ་དང་། གནང་བ་དང་། སྒྲུབ༌[^78]པའོ། །

Enumeration Block 6:
སྒྲུབ་པ་ནི་མདོར་བསྡུ་ན་རྣམ་པ་གསུམ་སྟེ། ལྟུང་བ་དང་ལྟུང་བ་མེད་པ་དང་། ལྟུང་བ་ལས་བསླང་བའོ། །དེ་དག་ཀྱང་མདོར་བསྡུ་ན་རྣམ་པ་གཉིས་ཏེ། ལོག་པར་སྒྲུབ་པ་དང་། ཡང་དག་པར་སྒྲུབ་པའོ། །

Enumeration Block 7:
དེ་དག་ཀྱང་རྒྱུ་རྣམ་པ་བཞིས་འབྱུང་སྟེ། མི་ཤེས་པ་དང་། བག་མེད་པ་དང་། ཉོན་མོངས་པ་མང་བ་དང་། མ་གུས་པ་ལས་སོ། །

Enumeration Block 8:
ལྟུང་བ་རྣམས་ཀྱི་ཆུང་ངུ་དང་། འབྲིང་དང་། ཆེན་པོ་ཉིད་ནི་རྣམ་པ་ལྔས་རིག་པར་བྱ་སྟེ། ལྔ་གང་ཞེ་ན། ངོ་བོ་ཉིད་དང་། བྱེད་པ་དང་། བསམ་པ་དང་། གཞི་དང་། ཚོགས་པའོ། །

Enumeration Block 1:
ལྟུང་བ་རྣམས་ཀྱི་ཆུང་ངུ་དང་། འབྲིང་དང་། ཆེན་པོ་ཉིད་ནི་རྣམ་པ་ལྔས་རིག་པར་བྱ་སྟེ། ལྔ་གང་ཞེ་ན། ངོ་བོ་ཉིད་དང་། བྱེད་པ་དང་། བསམ་པ་དང་། གཞི་དང་། ཚོགས་པའོ། །

Enumeration Block 2:
མདོར་བསྡུ་ན་བྱ་བ་ནི་རྣམ་པ་ལྔ་སྟེ། ཚོགས་ཀྱི་བྱ་བ་དང་། རྣམ་པར་དག་པའི་བྱ་བ་དང་། གྲོང་གི་བྱ་བ་དང་། དགེ་བའི་ཕྱོགས་ཀྱི་བྱ་བ་དང་། འཕྲལ་གྱི་བྱ་བའོ། །

Enumeration Block 3:
ལྟུང་བ་ལས་བསླང་བ་གང་ཞེ་ན། རྒྱུ་གསུམ་གྱིས་ལྡང་སྟེ། གསུམ་གང་ཞེ་ན། འགྱོད་པ་ལྔ་བསྐྱེད༌[^99]པ་དང་། ཡན་ལག་ལྔས་བསྡུས་པའི་བག་ཡོད་པ་དང་། རྣམ་པ་ལྔས་འགྱོད་པ་བསལ༌[^100]བའོ། །

Enumeration Block 4:
འདུལ་བའི་རྗེས་སུ་སྤྱོད་པའི་ཆོས་ནི་ལྔ་པོ་འདི་དག་ཡིན་པར་རིག་པར་བྱ་སྟེ། །དགེ་སློང་འདུལ་བ་ལ་བརྩོན་པ་ནི་དེ་དག་ལ་རྗེས་སུ་སྤྱོད་པར་བྱེད་དོ། །ལྔ་གང་ཞེ་ན། གནས་པ་དང་། གནས་དང་། རྟེན་དང་། ལོངས་སྤྱོད་དང་། ལས་ནི་ལྔ་པ་ཡིན་ནོ། །

Enumeration Block 5:
གནས་ལྔ་སྟེ། དགེ་སློང་གི་གནས་དང་། དགེ་སློང་མའི་གནས་དང་། མུ་སྟེགས་ཅན་གྱི་གནས་དང་། ཀུན་ནས་ཉོན་མོངས་པ་ཅན་གྱི་གནས་དང་། ཀུན་ནས་ཉོན་མོངས་པ་ཅན་མ་ཡིན་པའི་གནས་སོ། །

Enumeration Block 6:

Enumeration Block 6:
གཞན་ཡང་མདོར་བསྡུ་ན་དངོས་པོ་གཉིས་ཏེ། སེམས་ཅན་དུ་སྟོན་པ་དང་། སེམས་ཅན་དུ་མི་སྟོན་པའོ། །

Enumeration Block 7:
དགེ་སློང་འདུལ་བའི་བསླབ་པ་ལ་བརྩོན་པས་རྣམ་པ་ལྔས་ལྟུང་བ་ཡོངས་སུ་ཤེས་པར་བྱ་སྟེ། གཞི་དང་། ཀུན་ནས་སློང་བ་དང་། དངོས་པོ་དང་། སྦྱོར་བ་དང་། མཐའ་ཡས༌[^254]སོ། །

Enumeration Block 8:

Enumeration Block 1:

Enumeration Block 2:
སྦྱོར་བ་ཡང་རྣམ་པ་གཉིས་ཏེ། བྱ་བ་མ་ཡིན་པ་བྱེད་པའི་སྦྱོར་བ་དང་། བྱ་བ་མི་བྱེད་པའི་སྦྱོར་བའོ། །

Enumeration Block 3:
དེ་ལ་གང་ཟག་ཡོངས་སུ་ཤེས་པར་བྱ་བ་ནི་རྣམ་པ་ལྔས་རིག་པར་བྱ་སྟེ། དཔྱད་པའི་དབྱེ་བ་དང་། རིས་ཀྱི་དབྱེ་བ་དང་། མཐོ་དམན་གྱི་དབྱེ་བ་དང་། འཐོབ་པའི་དབྱེ་བ་དང་། བརྟག་པའི་དབྱེ་བས་སོ། །

Enumeration Block 4:

Enumeration Block 5:
སེར་སྣའི་དྲི་མ་བརྒྱད་དེ། སྔོན་སེར་སྣ་ལ་གོམས་ཤིང་གཏོང་བ་ལ་མ་གོམས་པར༌[^288]སེར་སྣའི་དྲི་མ་དང་། ཚེ་འདི་ལ་ལུས་དང་སྲོག་ལ་ཤས་ཆེར་བལྟ་བ་དང་དེ་དང་སྐལ་བ་མཉམ་པའི་མཛའ་བཤེས་རྣམས་དང་འགྲོགས་ཤིང་རྗེས་སུ་འཇུག་པ་དང་། སེམས་ཅན་རྣམས་ལ་སྙིང་རྗེ་མ་གོམས་ཤིང་སྙིང་རྗེ་ཆུང་བ་དང་། ཞིང་མི་མཐུན་པ་ལ་སོགས་པར་སྒྲུབ་པ་ཀུན་ཏུ་སྟོན་པ་དང་། ཚེགས་ཆེན་པོས་ལོངས་སྤྱོད་འཐོབ་ཅིང་ཚེགས་ཆེན་པོས་འཐོབ་པར་གོམས་པའི་འདུ་ཤེས་དང་། དུས་གསུམ་དུ་ཡིད་མི་བདེ་ཞིང་འགྱོད་པ་དང་། གཅིག་ཏུ་ལོངས་སྤྱོད་རྣམས་ལ་ཡོན་ཏན་དུ་ལྟ༌[^289]ཞིང་ཉེས་དམིགས་སུ་མི་ལྟ་ལ། ལོག་པར་ལེན་ཅིང་ཡོངས་སུ་བསྔོ་སྟེ།

Enumeration Block 6:

Enumeration Block 7:

Enumeration Block 1:

Enumeration Block 2:
