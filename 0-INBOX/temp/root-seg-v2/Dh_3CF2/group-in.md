# ༄༅། །ངན་སོང་ཐམས་ཅད་ཡོངས་སུ་སྦྱོང་བའི་རོའི་སྦྱིན་སྲེག་གི་དཀྱིལ་འཁོར་གྱི་ཆོ་ག། ^0

## ཀླད་ཀྱི་དོན། ^I-0
[frame] ༄༅༅། །རྒྱ་གར་སྐད་དུ། སརྦ་དུརྒ་ཏི་པ་རི་ཤོ་དྷ་ན་མ་ར་ཧོ་མ་མཎྜལོ་པ་ཡི་ཀ །
[frame] བོད་སྐད་དུ། ངན་སོང་ཐམས་ཅད་ཡོངས་སུ་སྦྱོང་བའི་རོའི་སྦྱིན་སྲེག་གི༌[^1]དཀྱིལ་འཁོར་གྱི་ཆོ་ག །
[frame] དེ་བཞིན་གཤེགས་པ་དགྲ་བཅོམ་པ་ཡང་དག་པར་རྫོགས་པའི་སངས་རྒྱས་ངན་སོང་ཐམས་ཅད་ཡོངས་སུ་སྦྱོང་བའི་རྒྱལ་པོ་ལ་ཕྱག་འཚལ་ལོ། །

## གཞུང་དངོས། ^1-0
S1  བདེར་གཤེགས་གཙོ་དང་སྲས་པོ་དང་པོ་དང་། །རྒྱལ་སྲས་ལྷག་མ་དང་ནི་རིགས་ཀྱི་ཡུམ་རྣམས་དང་། །ཕྱི་ནང་ལྷ་མོ་སྒོ་སྐྱོང་བཅས་པ་ལ། །དངོས་པོ་ཀུན་གྱི༌[^2]དང་བས་ཕྱག་འཚལ་འདུད། །
V2  རྩ་བའི་རྒྱུད་ལས་བཏུས་ནས་སུ། །
V3  ངན་སོང་ཐམས་ཅད་སྦྱོང་མཛད་པའི། །
V4  ཤི་བའི་དོན་དུ་རོ་སྲེག༌[^3]ཐབས། །
V5  སངས་རྒྱས་གསང་བའི་རིམ་པ་ལ། །
V6  བརྟེན་ཏེ་བདག་གིས་བཤད་པར་བྱ། །
S7  དང་པོར༌[^4]བླ་མ་རིན་པོ་ཆེ་མཉེས་པར་བྱས་ནས། དེས་དཀྱིལ་འཁོར་དུ་བཅུག་སྟེ་དབང་བསྐུར་བ་དང༌[^5]དམ་ཚིག་ཕོག་ནས། སྤྱི་དང་ཁྱད་པར་གྱི་དམ་ཚིག་ལ་གནས་པས་སྔར་རང་གི་སྒྲུབ་ཐབས་ཀྱི་རིམ་པས་བསྙེན་པ་བྱས་པ་དང་། བཟླས་བརྗོད་བྱས་པས་མཚན་མ་མཐོང་བས། བདག་དང་གཞན་འཁོར་བའི་རྒྱ་མཚོ་ལས་བསྒྲལ་བར་བྱ་བའི་ཕྱིར་དཀྱིལ་འཁོར་གྱི་བྱ་བ་ལ་འཇུག་པར་བྱའོ། །
S8  དཀྱིལ་འཁོར་ཡོ་བྱད་ཐམས་ཅད་བསྡུས་ནས་སུ། ཚེས་གྲངས་བཟང་དང་རྒྱུ་སྐར་ལ་སོགས༌[^6]བཟང་པོ་དང་།[^7] དཀྱིལ་འཁོར་ས་གཞི་མཚན་མ་བལྟ༌[^8]ཕྱིར་གྲོགས་དང་བཅས་པས་དེ་ཉིད་བརྟག་བྱ་སྟེ། །ལྷ་ཁང་ཚོང་དུས༌[^9]ཡུལ་དང་གྲོང་ཁྱེར་ཁྱམས་ཀྱི་ཤར་དང་བྱང་དུ་བརྩམ་པར་བྱ། །ཡང་ན་ས༌[^10]བཟང་སྣུམ་དང༌[^11]ཟུག་རྔུ་ལ་སོགས་ཉེས་མེད་ཤར་དང་བྱང་དུ་གཞོལ། མེ་ཏོག་ཆུར་ལྡན་རང་བཞིན་དག་པར་བྱའོ། །
S9  ཡང་ན་སྔགས་པ་ཡིད་གང་དུ་དགའ་བར་བྱའོ། །
S10  དེ་ནས་གཙོ་བོའི་ཏིང་ངེ་འཛིན་དུ་ཞུགས་ལ་ལྕི་བ་ས་ལ་མ་ལྷུང་བས་མཎྜལ་བྱའོ།[^12] །
S11  དཀོན་མཆོག་གསུམ་ལ་ཕྱི་ནང་མཆོད་པ་བྱ་ཞིང་འཇིག་རྟེན་སྐྱོང་བ་རྣམས་ལ་གཏོར་མ་སྦྱིན་དེ་ནས་ས་གཞི་གྲུ་བཞིར་བསམས༌[^13]ལ་ས་བདག་བསམས་ཏེ་བརྐོ། སྟོན་ཟླ་གསུམ་ལ་བྱང་དུ་བལྟས་ཏེ༌[^14]བརྐོ། །དགུན་ཟླ་གསུམ་ལ་ཤར་དུ་བལྟས་ལ་བརྐོ། །དཔྱིད་ཟླ་གསུམ་ལ་ལྷོ་རུ་བལྟས་ལ་བརྐོ། །དབྱར་ཟླ་གསུམ་ལ་ནུབ་ཏུ་བལྟས་ལ་བརྐོ་སྟེ་ལྟོ་བར་བསམས་ན། [^15]མགོ་དང་རྒྱབ་དང་འཕོང༌[^16]བོར་བའོ། །
S12  སའི་རོ་ལྔ་ལ་སོགས་པ་བསལ་ཞིང་ཡང་ངོ་། །
S13  དྲི་ཞིམ་པོ་དང་ས་བསྲེས་པའམ། དྲི་ཞིམ་པོ་དང་ཆུ་བསྲེས་པ་ལ་ཧཱུཾ་བཟླས་པས་བཀང་ལ་འཐས་པར་བཅགས་ལ། ལག་མཐིལ་ལྟར༌[^17]མཉམ་པའི་སྟེང་དུ་གཞལ་ཡས་ཁང་རྒྱན་དང་བཅས་པ་བསམ། མེ་ཏོག་ཕྲེང་བ་ལ་སོགས་པའི་རྒྱན་མང་པོ་དགོད། གཙོ་བོའི་བཟླས་པ་བྱས་པའི་སྨན་དང་འབྲུ་དང་རིན་པོ་ཆེ་དབུས་སུ་གཞག་གོ། །

S97  དེ་ནས་རྡོ་རྗེ་དྲིལ་བུ་བླངས་ལ། ཨོཾ་བཛྲ་ཨུཏྟིཥྛ། ཞེས་པས་ཇི་ལྟར་སྤྲུལ་པའི་ལྷའི་དཀྱིལ་འཁོར་ནམ་མཁའ་ལ་བཞུགས་སུ་གསོལ། ཡང་སྟང་སྟབས་གཡས་བརྐྱང་ལ་སོགས་པ་བྱའོ། །

S100  དེ་ནས་ཙནྡན་དམར་པོ་མེ་ཏོག་དམར་པོ་དར་དམར་པོའི་རྒྱན་དང་བཅས་པའི་ཕུར་པ་ལག་པ་གཡོན་པའི་ཁུ་ཚུར་གྱིས་བཟུང༌[^56]ལ་གཡས་པས༌[^57]ཐོ་བ་རྒྱན་དང་བཅས་པས་བརྡུང་ངོ་། །

S103  དེ་ནས་རྩེ་གསུམ་པའི་ཕྱག་རྒྱས་བགེགས་བསྐྲད། ཨོཾ་ཨཱཿཧཱུཾ། གསུམ་གྱིས་ཕྱི་རོལ་དུ་འཁོར་ལོ་དང་པདྨ་དང་རྡོ་རྗེ་ར་བ་དང་ས་གཞི་ཡང་རྡོ་རྗེར་བསམ། འབར་བའི་ཕྲེང་བ་འོད་དང་བཅས་པ་བསྒོམ་བགེགས་བསྐྲད་ཅིང་གཙོ་བོའི་སྔགས་དང་རྡོ་རྗེ་ཁུ་ཚུར་གྱིས་སྒོ་བཅད་པར་བསམ་མོ། །
S104  དེ་ནས་ཡི་གེ་ལཾ་ལས་བྱུང་བའི་སའི་ལྷ་མོ༌[^58]སྐུ་མདོག་སེར་མོ་བུམ་པ་ལག་ན་ཐོགས་པ་རྒྱན་ཐམས་ཅད་དང་ལྡན་པ། རྡོ་རྗེ་ལྕགས་ཀྱུ་ལ་སོགས་པས་དགུག་པ་ལ་སོགས་པ་བྱས་ནས། མཆོད་པ་བྱ་ཞིང་ཚིགས་སུ་བཅད་པ་འདིས་སྟ་གོན་དུ་བྱའོ། །
V105  སྐྱོབ་པ་སངས་རྒྱས་ཐམས་ཅད་ཀྱིས།[^59] །
V106  སྤྱོད་པའི་ཚུལ་དང་ཁྱད་པར་ནི། །

V108  ལྷ་མོ་ཁྱོད་ནི་དཔང་དུ་འགྱུར།[^60] །
V109  སྐྱོབ་པ་ཤཱཀྱ་སེང་གེ་ཡིས། །

S112  རྒྱལ་བར་བྱ་སྟེ༌[^61]དཀྱིལ་འཁོར་བྲི། སའི་ལྷ་མོ་དགའ་བའི་མདངས་ཀྱིས་དེ་བཞིན་དུ་གྱིས་ཤིག་ཟེར་ནས་འོག་ཏུ་ཐིམ་མོ། །
S113  དེ་ནས་རྡོ་རྗེ་བསྡམས་པ་དང་སྔགས་འདིས་གཟུང་བར་བྱའོ། །

S115  ཨོཾ་བཛྲ་དྷི་དེ་ཨུཏ་ཏིཥྛ། ཞེས་པས་བྱིན་གྱིས་བརླབ་པའི་ཆོ་གའོ། །
S116  དེ་ནས་དྲི་བཟང་པོ་ལ་སོགས་པས་བྱུགས་ལ། མེ་ཏོག་སྣ་ཚོགས་པ་ཆལ་པར་དགྲམ་མོ། །
S117  དཀྱིལ་འཁོར་དུ་ལྷ་རྣམས་ཇི་ལྟར་གནས་པའི་མིང་བརྗོད་དེ་མཎྜལ་རེ་རེ༌[^63]བྱའོ། །
S118  ར་བ་དང་དྲ་བ་ལ་སོགས་པས་མཚམས་བཅད་ནས། རྣམ་པར་སྣང་མཛད་འཁོར་དང་བཅས་པ་སྤྱན་དྲངས་ལ་ཞབས་བསིལ་དང་ཞལ་བསིལ་དང་ཡོན་ཆབ་དང་མཆོད་པ་བརྒྱད་དང་གཞན་གྱིས་ཀྱང་མཆོད་བསྟོད་པ་བྱ་སྟེ་ནམ་མཁའོ། །
S119  བདག་རང་དཀྱིལ་འཁོར་གྱི་དབུས་སུ་འདུག་ནས། སྒྲུབ་ཐབས་ནས༌[^64]འབྱུང་བ་བཞིན་དུ་བགེགས་བསལ་ནས་སེམས་དཔའི་སྐྱིལ་མོ་ཀྲུང་དུ་འདུག་ལ། རྣམ་པར་སྣང་མཛད་ཀྱི་རྣལ་འབྱོར་བྱས་ལ་ང་རྒྱལ་བསྐྱེད་དེ་སེམས་དག་པར་བྱ་ཞིང་འདི་བརྗོད་ལ།

V133  བདག་མིང་འདི་ཞེས་བགྱི་བ་ཡིས། །

V137  དངོས་གྲུབ་དེ་ནི་སྩལ་དུ་གསོལ།[^67] །
