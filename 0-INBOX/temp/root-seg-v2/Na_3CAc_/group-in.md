# ༄༅། །ཐམས་ཅད་གྲུབ་པ་དཔལ་འཕེལ་ལྷ་མོ་ལ་སློབ་དཔོན་ཀླུ་སྒྲུབ་ཀྱིས་བསྟོད་པ་བཞུགས་སོ། ། ^0

## གཞུང་དངོས། ^1-0
S1  ༄༅༅། ཨོཾ་ཐམས་ཅད་གྲུབ་པ་དཔལ་འཕེལ་ལྷ་མོ་ཁྱོད་ལགས་ཀྱེ། །རྣམ་ཐར་ཡོངས་རྫོགས་དྲི་མེད་ཤེས་རབ་ཕ་རོལ་ཕྱིན། །ཀུན་ལ་མངའ་མཛད་བསྡུ་བའི་ཏོག་ལྟར་མཛེས། །
V2  ཞབས་གཉིས་རོལ་པས་གཞན་དོན་མཛད་ལ་ཕྱག་འཚལ་བསྟོད། །
V3  ཚད་མེད་བཞིའི་བདུད་བཞིའི་དཔུང་རྣམས་བཅོམ་པ་ཀྱེ། །
V4  གང་གིས་འདོད་དོན་གསོལ་བ་དེ་དག་གྲུབ་པ་ཀྱེ། །
V5  སྐུ་དང་ཕྱག་ཞབས་རིན་ཆེན་དུ་མས༌[^1]བརྒྱན་ཀྱེ། །
V6  བསྡུ་བ་དངོས་པོ་བཞི་ལྡན་ཁྱོད་ལ་ཕྱག་འཚལ་བསྟོད། །
V7  དཔའ་མོ་རབ་བརྗིད་དུས་གསུམ་ས་ལེར་མཁྱེན་པ་ཀྱེ། །
V8  འཁོར་བའི་འདམ་ནས་འགྲོ་བ་མ་ལུས་འདྲེན་མཛད་མ། །
V9  ཧྲི་དང་ཧཱུཾ་ཕཊ་རབ་སྒྲོགས་དུས་གསུམ་དབང་ཕྱུག་མ། །
V10  བགེགས་ཀྱི་ཚོགས་རྣམས་མྱུར་སྒྲོལ་ཁྱོད་ལ་ཕྱག་འཚལ་བསྟོད། །
¶
V11  རྣམ་དག་སྤྱན་གྱིས་ཡུལ་ཀུན་དུས་ཀུན་གཟིགས་པ་ཀྱེ། །
S12  སྤྲུལ་པའི་ཚོགས་ཀྱིས་སྲིད་པའི་འཇིགས་ཆེན་འཇོམས། །ཐུགས་སྐྱོ་མི་མངའ་རིན་ཆེན་ནོར་འདྲ་མ་སྲིང་ཚུལ། །ཐུགས་རྗེའི་དབང་ཉིད་སྒྲོལ་མ་ཁྱོད་ལ་ཕྱག་འཚལ་ལོ། །
S13  མཁར་གནས་ཟླ་བ་ཉ་འདྲ་བསིལ་བའི་འོད་ལྡན་ཀྱེ། །རིམས་སྩོགས་ཉོན་མོངས་གདུང་བ་ཀུན་སེལ་ཅིང་། །
V14  གང་གིས་བསམ་པའི་དོན་འགྲུབ་ཐམས་ཅད་རྩོལ་མཛད་མ། །
V15  ཡིད་བཞིན་རིན་ཆེན་སྒྲོལ་མ་ཁྱོད་ལ་ཕྱག་འཚལ་བསྟོད། །
V16  ཐམས་ཅད་ཀུན་ལ་དབང་བསྒྱུར༌[^2]ཡེ་ཤེས་འོད་འབར་ཀྱེ། །
V17  སྲིད་གསུམ་སྐྱེ་འགྲོ་མ་ལུས་སྨིན་གྲོལ་མཛད་པ་ནི། །
V18  ཡིད་བཞིན་འཕྲིན་ལས་བཞིའི་ཡལ་བར་མི་འདོར་ཅིང་། །
V19  མཁྱེན་བརྩེ་མཐུ་ལྡན་མ་ཅིག་ཁྱོད་ལ་ཕྱག་འཚལ་བསྟོད། །
V20  ཕྱག་བཞི་མདའ་གཞུ་ལྕགས་ཀྱུ་ཨུཏྤལ་འཛིན་པ་ཀྱེ། །
V21  བདག་གི་ལས་སྒྲིབ་སྡུག་བསྔལ་ཞི་བར་མཛད་པ་དང་། །
V22  འདོད་དོན་གང་གསོལ་མྱུར་དུ་འགྲུབ་ཅིང་དཔལ་ལ་སོགས། །
V23  འཕེལ་བར་མཛད་ཅིང་ཞབས་ལ་གསོལ་འདེབས་ཕྱག་འཚལ་བསྟོད། །
V24  ནམ་མཁའ་ལྟ་བུ་རྒྱལ་ཡུམ་རིག་པ་འཛིན་མ་ཀྱེ། །
V25  འཕྲིན་ལས་བཞི་མཛད་ཁྱེད་ཞབས་ལྷ་དང་ལྷ་མིན་གྱིས། །
V26  ཚོགས་ཀྱིས་བཏུད་ཅིང་ཀུན་ལ་དབང་བསྐུར་མཁའ་འགྲོ་མ། །
V27  ས་གཞི་ལྟ་བུའི་མཐུ་མངའ་ཁྱོད་ལ་ཕྱག་འཚལ་བསྟོད། །
S28  སློབ་དཔོན་ཀླུ་གྲུབ་ཀྱིས་བསྟོད་པའོ།། །།
