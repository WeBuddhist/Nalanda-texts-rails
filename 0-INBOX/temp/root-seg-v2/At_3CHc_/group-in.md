# ༄༅། །གཟའ་ངན་པ་བཟློག་པའི་ཆོ་ག་རྒྱ་མཚོ་སྤྲིན་ཞེས་བྱ་བ། ^0

## གཞུང་དངོས། ^1-0
P1  ༄༅། །
P2  དཔལ་རྡོ་རྗེ་རྣམ་པར་འཇོམས་པ་ལ་ཕྱག་འཚལ་ལོ། །
P3  གང་ཟག་གཟའ་ངན་པའི་དུས་ལས་ཟློག་པར་འདོད་པའི་སྒྲུབ་པ་པོ་དམ་ཚིག་དང་ལྡན་པས།
P4  དཀྱིལ་འཁོར་སྔ་མ་བཞིན་དུ་བྲིས་ལ།
P5  དཀྱིལ་འཁོར་གྱི་དབུས་སུ་བུམ་པ་མཚན་ཉིད་དང་ལྡན་པ།
P6  ཁ་དོག་སྔོན་པོ་གཙོ་བོའི་མཚན་ཉིད་དང་ལྡན་པ་བཞག་ལ།
P7  དེ་ལ་གཙོ་བོའི་བསྙེན་པ་བརྒྱ་ཕུལ་ལ་གཞག་གོ། །
P8  དཀྱིལ་འཁོར་གྱི་ཕྱོགས་མཚམས་སུ་ཕུར་པ་བརྒྱད་ལ་དར་དམར་པོའི་ཅོད་པན་བཏགས་ལ་ཁྲོ་བོ་བརྒྱད་དུ་བསྐྱེད་ལ་གཞག་གོ། །
P9  མར་མེ་ལ་སོགས་པས་གཙོ་བོ་དང་གཟའ་བརྒྱད་མཆོད་དོ། །
P10  གཟའི་གཏོར་མ་གཙང་མ་བརྒྱད་ཕྱོགས་གཏོར་དང་བགེགས་གཏོར་ཡང་བཤམ་མོ། །
P11  དཀྱིལ་འཁོར་གྱི་ལྷའི་གནས་རྣམས་སུ་བག་ཟན་ལས༌[^1]གཟའི་གཟུགས་བྱས་ལ་ཚོན་གྱིས་བསྒྱུར་ལ་གཞག །
P12  དེ་དག་རེ་རེའི་མདུན་དུ་སྦྲང་རྩི་དང་།
P13  འོ་མ་ལ་སོགས་པ༌[^2]སྤྱན་གཟིགས་ཀྱིས་ཀྱང་འཁོར་བར་གཞག་གོ། །
P14  ཁྱམས་རྣམས་སུ་རྒྱུ་སྐར་གྱི་གཟུགས་བྱས་ལ་གཞག་གོ། །
P15  དེ་ནས་གཙོ་བོ་ལ་མཆོད་པ་དང་བསྟོད་པ་བྱས་ལ།
