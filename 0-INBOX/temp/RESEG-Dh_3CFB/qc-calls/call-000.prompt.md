━━━ ISSUE TYPES ━━━

CONNECTOR_ENDING
  The block ends with a connector particle (དང་། / ཞིང་། / ཅིང་། / ནས། / ལས། /
  སྟེ། / ཏེ།) that grammatically requires continuation. Real issue if the next
  block is the grammatical continuation. False positive if this is a closing verse
  pāda or a deliberate short citation frame.

OBJECTION_REPLY_FUSED
  The block contains both an objection marker (ཅེ་ན། / ཞེ་ན། / སྙམ་ན།) and a reply
  opener (འོ་ན།). These should always be two separate blocks. Almost always a
  real issue.

OVER_LENGTH
  The block exceeds the syllable threshold. Usually NOT wrong: a whole explanation
  unit is legitimately long. Split only if a new node opener (ordinal + title +
  ནི། / ལ་ N།) or the treatment of a new verse is buried mid-block.

SHORT_FRAGMENT
  The block is suspiciously short — may be a stray split artifact that should be
  merged with an adjacent block.

━━━ CORRECTION OPERATIONS ━━━

[
  {"op": "merge", "blocks": [N, M]},
  {"op": "merge", "blocks": [N, M, P]},
  {"op": "split", "block": N, "after": "<verbatim unique substring ending at split point>"},
  {"op": "split", "block": N, "after": ["<sub1>", "<sub2>"]}
]

Rules:
- Only output corrections for REAL issues. Skip false positives entirely.
- Block numbers are CONTINUOUS and include heading blocks. Only merge blocks with
  consecutive numbers (N and N+1); never merge across a heading or skip a number.
- "after" must be verbatim from the block and unique within it. To break one long
  block into 3+ units, set "after" to a LIST of substrings in document order.
- Each block number appears in AT MOST ONE operation.
- Heading blocks (lines starting with #) and [VERSE] blocks are NEVER touched.
- If no corrections are needed, output: []
- Output ONLY the JSON array. No commentary, no code fences.

ཚིག་ལ་ཁྱད་པར་མེད་པའི་ཕྱིར་རོ་ཞེས་བྱ་བ་ལྟ་བུའོ། །རྣམ་པ་ཐམས་ཅད་སྐྱེས་བུ་དག་གིས་བྱེད་པར་མཐོང་བའི་ཕྱིར་རོ། །ལེགས་པར་བྱ་བའི་བྱེ་བྲག་ལས་ཁྱད་པར་རྟོགས་པའི་ཕྱིར། ཡོན་ཏན་ཐམས་ཅད་ལ་ཁྱད་པར་མཐོང་བས་ན་གང་གིས་ན་ཚིག་ལ་སོགས་པ་ཅུང་ཟད་ཙམ་ཆོས་མཐུན་པས་རྣམ་པ་ཐམས་ཅད་དུ་མཐུན་པར་རྗེས་སུ་དཔག་པར་འགྱུར་བ་དེ་ལྟ་བུར་སྐྱེས་བུ་དག་ནི་རྒྱུའི་ཁྱད་པར་མེད་པ་ཅན་མ་ཡིན་པ་ཉིད་དོ། །དེ་བཞིན་དུ་གཞན་ལ་ཡང་སྲིད་པའི་ཕྱིར་རོ། །མི་སྲིད་པར་རྗེས་སུ་དཔག་པ༌[^133]ཡང་གནོད་པར་བྱེད་པའི་གཏན་ཚིགས་མེད་པའི་ཕྱིར་ཏེ། འདོད་ཆགས་དང་བྲལ་བ་མ་མཐོང་བའི་ཕྱིར་ལ། མ་མཐོང་བར༌[^134]ཡང༌[^135]གནོད་པར་བྱ་བ་དང་། གནོད་པར་བྱེད་པའི་དངོས་པོ་མི་འགྲུབ་པའི་ཕྱིར་རོ། །འདོད་ཆགས་ལ་སོགས་པའི་འབྲས་བུ་འཁྲུལ་པ་མེད་པ་ཅན་མེད་པའི་ཕྱིར་རོ། །སྲིད་ཀྱང་ཁྱད་པར་རྣམས་བལྟ་བར་མི་ནུས་པའི་ཕྱིར་རོ། །དེ་ལྟ་བུ་དག་ནི་སྤང་བར་འོས་པ་ཡང་མ་ཡིན་ནོ། །ཚིག་རྣམས་ནི༌[^136]དེ་ལྟ་བུ་མ་ཡིན་ཏེ། ཁྱད་པར་བལྟར་རུང་བའི་ཕྱིར་རོ། །བལྟར་མི་རུང་བ་ཞིག༌[^137]ཡིན་ན་ཡང་ཁྱད་པར་མ་མཐོང་བ་རྣམས་རིགས་མི་མཐུན་པ་ཉིད་དུ་ཁས་ལེན་པ་འགལ་བའི་ཕྱིར་རོ། །དེའི་ཁྱད་པར་རྣམས་ནི་གཞན་ལ་ཡང་བྱ་བར་ནུས་པའི་ཕྱིར་རོ། །སྒྲ་མངོན་སུམ་པ་རྣམས་ལ་མངོན་སུམ་མ་ཡིན་པའི་ངོ་བོ་ཉིད་མེད་པའི་ཡང་ཕྱིར་རོ། །འཁྲུལ་པའི་རྒྱུ་མཚན་མེད་པའི་ཕྱིར་ཏེ། གནོད་པར་བྱེད་པ་མེད་པས་འཁྲུལ་པ་མི་འགྲུབ་པའི་ཕྱིར་རོ། །སྐྱེས་བུ་དག་ནི་ཁྱད་པར་མཐོང་བ་གནོད་པར་བྱེད་པ་ཡིན་པའི་ཕྱིར་མཚུངས་པ་མ་ཡིན་ནོ། །ཚིག་གི་ཁྱད་པར་གཞན་གྱི་ངོ་བོར་གྱུར་པ་ནི་དེའི་ཁྱད་པར་མ་ཡིན་པའི་ཕྱིར་རོ། །དེའི་ཕྱིར༌[^138]ཁྱད་པར་མེད་པའི་རང་བཞིན་ཐམས་ཅད་སྐྱེས་བུས་བྱེད་དོ། །

[Block 105 — OVER_LENGTH (500 syllables)]
དེ་ལ་གཅིག་མཐོང་བས་གཞན་ན་དེ་ཡོད་པར་ངེས་པར་ནི་རིགས་པ་མ་ཡིན་ནོ། །གལ་ཏེ་ཇི་ཞིག་ལྟར་མི་མཐུན་པའི་ཕྱོགས་ལ༌[^130]མཐོང་བ་ཙམ་གྱིས་འབྲེལ་པ་མེད་པ་ཡང་དེ་འཁྲུལ་པ་མེད་དོ་ཞེ་ན། ཡུལ་འགའ་ཞིག་ན་རྫས་ཁ་ཅིག་ཅི་ཞིག་ལྟར་མཐོང་བ་གཞན་ན་གཞན་དུ་ཡང་སྣང་ངོ་། །དཔེར་ན་སྨན་ཁ་ཅིག་ཞིང་ཁྱད་པར་ཅན་ལས་རོ་དང་ནུས་པ་དང་ཁྱད་པར་དུ་སྨིན་པར་བྱེད་པ་ཁྱད་པར་ཅན་དུ་འགྱུར་ལ། གཞན་ལ༌[^131]ནི་མ་ཡིན་པ་ལྟ་བུ་སྟེ། དུས་དང་ལེགས་པར་བྱ་བའི་ཁྱད་པར་ལས་ཀྱང་དེ་དང་འདྲའོ། །ཡུལ་དེ་པ་རྣམས་ཀྱིས༌[^132]དེ་ལྟར་མཐོང་ཞེས་ཏེ། ཐམས་ཅད་དེ་ཉིད་དུ་དེ་ལྟ་བུ་ཡིན་པར་ནི་འགྲུབ་པར་མི་འགྱུར་ཏེ། ཡོན་ཏན་གྱི་ཁྱད་པར་རྣམས་ནི་རྒྱུའི་ཁྱད་པར་ལ་ལྟོས་པའི་ཕྱིར་རོ། །རྒྱུའི་ཁྱད་པར་མེད་ན་ནི་རྗེས་སུ་དཔག་ཏུ་རུང་སྟེ། བྱེད་པ་པོ་མ་མཐོང་བ་ཅན་གྱི་ཚིག་ཀྱང་སྐྱེས་བུའི་འདུ་བྱེད་པ་སྔོན་དུ་འགྲོ་བ་ཅན་ཡིན་ཏེ། ཚིག་ལ་ཁྱད་པར་མེད་པའི་ཕྱིར་རོ་ཞེས་བྱ་བ་ལྟ་བུའོ། །རྣམ་པ་ཐམས་ཅད་སྐྱེས་བུ་དག་གིས་བྱེད་པར་མཐོང་བའི་ཕྱིར་རོ། །ལེགས་པར་བྱ་བའི་བྱེ་བྲག་ལས་ཁྱད་པར་རྟོགས་པའི་ཕྱིར། ཡོན་ཏན་ཐམས་ཅད་ལ་ཁྱད་པར་མཐོང་བས་ན་གང་གིས་ན་ཚིག་ལ་སོགས་པ་ཅུང་ཟད་ཙམ་ཆོས་མཐུན་པས་རྣམ་པ་ཐམས་ཅད་དུ་མཐུན་པར་རྗེས་སུ་དཔག་པར་འགྱུར་བ་དེ་ལྟ་བུར་སྐྱེས་བུ་དག་ནི་རྒྱུའི་ཁྱད་པར་མེད་པ་ཅན་མ་ཡིན་པ་ཉིད་དོ། །དེ་བཞིན་དུ་གཞན་ལ་ཡང་སྲིད་པའི་ཕྱིར་རོ། །མི་སྲིད་པར་རྗེས་སུ་དཔག་པ༌[^133]ཡང་གནོད་པར་བྱེད་པའི་གཏན་ཚིགས་མེད་པའི་ཕྱིར་ཏེ། འདོད་ཆགས་དང་བྲལ་བ་མ་མཐོང་བའི་ཕྱིར་ལ། མ་མཐོང་བར༌[^134]ཡང༌[^135]གནོད་པར་བྱ་བ་དང་། གནོད་པར་བྱེད་པའི་དངོས་པོ་མི་འགྲུབ་པའི་ཕྱིར་རོ། །འདོད་ཆགས་ལ་སོགས་པའི་འབྲས་བུ་འཁྲུལ་པ་མེད་པ་ཅན་མེད་པའི་ཕྱིར་རོ། །སྲིད་ཀྱང་ཁྱད་པར་རྣམས་བལྟ་བར་མི་ནུས་པའི་ཕྱིར་རོ། །དེ་ལྟ་བུ་དག་ནི་སྤང་བར་འོས་པ་ཡང་མ་ཡིན་ནོ། །ཚིག་རྣམས་ནི༌[^136]དེ་ལྟ་བུ་མ་ཡིན་ཏེ། ཁྱད་པར་བལྟར་རུང་བའི་ཕྱིར་རོ། །བལྟར་མི་རུང་བ་ཞིག༌[^137]ཡིན་ན་ཡང་ཁྱད་པར་མ་མཐོང་བ་རྣམས་རིགས་མི་མཐུན་པ་ཉིད་དུ་ཁས་ལེན་པ་འགལ་བའི་ཕྱིར་རོ། །དེའི་ཁྱད་པར་རྣམས་ནི་གཞན་ལ་ཡང་བྱ་བར་ནུས་པའི་ཕྱིར་རོ། །སྒྲ་མངོན་སུམ་པ་རྣམས་ལ་མངོན་སུམ་མ་ཡིན་པའི་ངོ་བོ་ཉིད་མེད་པའི་ཡང་ཕྱིར་རོ། །འཁྲུལ་པའི་རྒྱུ་མཚན་མེད་པའི་ཕྱིར་ཏེ། ཡུལ་འགའ་ཞིག་ན་རྫས་ཁ་ཅིག་ཅི་ཞིག་ལྟར་མཐོང་བ་གཞན་ན་གཞན་དུ་ཡང་སྣང་ངོ་། །དཔེར་ན་སྨན་ཁ་ཅིག་ཞིང་ཁྱད་པར་ཅན་ལས་རོ་དང་ནུས་པ་དང་ཁྱད་པར་དུ་སྨིན་པར་བྱེད་པ་ཁྱད་པར་ཅན་དུ་འགྱུར་ལ། གཞན་ལ༌[^131]ནི་མ་ཡིན་པ་ལྟ་བུ་སྟེ། དུས་དང་ལེགས་པར་བྱ་བའི་ཁྱད་པར་ལས་ཀྱང་དེ་དང་འདྲའོ། །ཡུལ་དེ་པ་རྣམས་ཀྱིས༌[^132]དེ་ལྟར་མཐོང་ཞེས་ཏེ། ཐམས་ཅད་དེ་ཉིད་དུ་དེ་ལྟ་བུ་ཡིན་པར་ནི་འགྲུབ་པར་མི་འགྱུར་ཏེ། ཡོན་ཏན་གྱི་ཁྱད་པར་རྣམས་ནི་རྒྱུའི་ཁྱད་པར་ལ་ལྟོས་པའི་ཕྱིར་རོ། །རྒྱུའི་ཁྱད་པར་མེད་ན་ནི་རྗེས་སུ་དཔག་ཏུ་རུང་སྟེ། བྱེད་པ་པོ་མ་མཐོང་བ་ཅན་གྱི་ཚིག་ཀྱང་སྐྱེས་བུའི་འདུ་བྱེད་པ་སྔོན་དུ་འགྲོ་བ་ཅན་ཡིན་ཏེ། ཚིག་ལ་ཁྱད་པར་མེད་པའི་ཕྱིར་རོ་ཞེས་བྱ་བ་ལྟ་བུའོ། །རྣམ་པ་ཐམས་ཅད་སྐྱེས་བུ་དག་གིས་བྱེད་པར་མཐོང་བའི་ཕྱིར་རོ། །ལེགས་པར་བྱ་བའི་བྱེ་བྲག་ལས་ཁྱད་པར་རྟོགས་པའི་ཕྱིར། ཡོན་ཏན་ཐམས་ཅད་ལ་ཁྱད་པར་མཐོང་བས་ན་གང་གིས་ན་ཚིག་ལ་སོགས་པ་ཅུང་ཟད་ཙམ་ཆོས་མཐུན་པས་རྣམ་པ་ཐམས་ཅད་དུ་མཐུན་པར་རྗེས་སུ་དཔག་པར་འགྱུར་བ་དེ་ལྟ་བུར་སྐྱེས་བུ་དག་ནི་རྒྱུའི་ཁྱད་པར་མེད་པ་ཅན་མ་ཡིན་པ་ཉིད་དོ། །དེ་བཞིན་དུ་གཞན་ལ་ཡང་སྲིད་པའི་ཕྱིར་རོ། །མི་སྲིད་པར་རྗེས་སུ་དཔག་པ༌[^133]ཡང་གནོད་པར་བྱེད་པའི་གཏན་ཚིགས་མེད་པའི་ཕྱིར་ཏེ། འདོད་ཆགས་དང་བྲལ་བ་མ་མཐོང་བའི་ཕྱིར་ལ། མ་མཐོང་བར༌[^134]ཡང༌[^135]གནོད་པར་བྱ་བ་དང་། །ཚིག་རྣམས་ནི༌[^136]དེ་ལྟ་བུ་མ་ཡིན་ཏེ། ཁྱད་པར་བལྟར་རུང་བའི་ཕྱིར་རོ། །བལྟར་མི་རུང་བ་ཞིག༌[^137]ཡིན་ན་ཡང་ཁྱད་པར་མ་མཐོང་བ་རྣམས་རིགས་མི་མཐུན་པ་ཉིད་དུ་ཁས་ལེན་པ་འགལ་བའི་ཕྱིར་རོ། །དེའི་ཁྱད་པར་རྣམས་ནི་གཞན་ལ་ཡང་བྱ་བར་ནུས་པའི་ཕྱིར་རོ། །སྒྲ་མངོན་སུམ་པ་རྣམས་ལ་མངོན་སུམ་མ་ཡིན་པའི་ངོ་བོ་ཉིད་མེད་པའི་ཡང་ཕྱིར་རོ། །འཁྲུལ་པའི་རྒྱུ་མཚན་མེད་པའི་ཕྱིར་ཏེ། ཡང་ན་དོན་གྱིས་གོ་བས་གང་ཡང་རུང་བས་གཉི་ག་རབ་ཏུ་བསྟན་པའི་ཕྱིར་རོ་ཞེས་བཤད་པ་གང་ཡིན་པ་སྟེ། དེར་ཡང་དཔེས་དེའི་ངོ་བོ་དང་རྒྱུའི་དངོས་པོ་རབ་ཏུ་སྟོན་པར་དགོངས་ཏེ། དོན་གྱིས་གོ་བས་གཅིག་བརྗོད་པས་ཅིག་ཤོས་འགྲུབ་པར་བཤད་དོ། །འདི་ལྟར་གང་བྱས་པ་དེ་ནི་མི་རྟོག༌[^153]པའོ་ཞེས་སྨྲས་ན། དོན་ཐ་དད་པ་མེད་ན། གསལ་བར་འདི་ནི་འདིའི་ངོ་བོ་ཉིད་དེ་ཙམ་དང་འབྲེལ་པ་ཚད་མས་མཐོང་བ་ཡིན་ནོ་ཞེས་བྱ་བར་ངེས་པར་འགྱུར་ཏེ། དེ་ཡོད་པར་ངེས་པའི་ཕྱིར་རོ། །དེ་བས༌[^154]ན་དེའི་ངོ་བོར་ཤེས་པས་ནི་དོན་གྱིས༌[^155]གོ་བས་མི་རྟག་པ་ཉིད་མེད་ན་བྱས་པ་ཉིད་མེད་དོ། །ཞེས་བྱ་བར་འགྱུར་རོ། །རང་གི་ངོ་བོ་མེད་པར་ཡོད་པར་མི་འགྱུར་ཏེ། ཐ་དད་པ་མེད་པའི་ཕྱིར་རོ། །དེ་ལྟ༌[^156]མ་ཡིན་ན་དེ༌[^157]ཡོད་དོ་ཞེས་བྱ་བ་ཉིད་དུ་མི་འགྱུར་རོ། །དེ་བཞིན་དུ་དེ་མེད་ན་མེད་དོ་ཞེས་སྨྲས་ན།[^158] དེའི་ངོ་བོ་ཉིད་དུ་རིག་པ་ལས་འདི་ལྟར་འདི་ནི་འདིའི་ངོ་བོ་ཉིད་ཡིན་ཏེ། དེས་ནི༌[^159]དེ་མེད་ན་མེད་དོ། །དེ་ལྟ་མ་ཡིན་ན་མི་རུང་བའི་ཕྱིར་རོ། །དེའི་ཕྱིར་དེའི་ངོ་བོ་ཉིད་དུ་རྟོགས་པས་རྗེས་སུ་འགྲོ་བ་དྲན་པ༌[^160]འབྱུང་ངོ་། །དེ་བཞིན་དུ་གང་ན༌[^161]དུ་བ་ཡོད་པ་དེ་ན་མེ་ཡོད་དོ་ཞེས་སྨྲས་ན། དུ་བ་ནི་མེའི་འབྲས་བུ་ཡིན་ནོ། །དེས་ན་དུ་བ་ཡོད་ན་གདོན་མི་ཟ་བར་མེ་ཡོད་དོ། །དེ་ལྟ༌[^162]མ་ཡིན་ན་དོན་གཞན་དེ་དང་འབྲེལ་པར་ངེས་པ་མེད་པའི་ཕྱིར་ངོ་བོ་རང་དབང་ཅན་དུ་འགྱུར་རོ། །དེས་ན༌[^163]དེ་མེད་ཀྱང་རང་གི་ངོ་བོ་མ་ཚང་བ་མེད་པའི་ཕྱིར་མེད་པར་མི་འགྱུར་རོ། །འབྲས་བུ་ཡིན་ན་ནི་གདོན་མི་ཟ་བར་རྒྱུ་ཡོད་དོ། །རྒྱུ་རྒྱུ་ཉིད་ཡིན་པ་ནི་དེ་ཁོ་ན༌[^164]ཡིན་ཏེ། དོན་གཞན་ཡོད་ན་རང་གི་ངོ་བོ་ཉེ་བར་འཇོག་པ་གང་ཡིན་པའོ། །འབྲས་བུ་ཡང་དེ་ཡོད་པ་ཉིད་ན་ཡོད་པ་ཡིན་ནོ། །དེ་བཞིན་དུ་མེ་མེད་ན་དུ་བ་མེད་དོ་ཞེས་སྨྲས་ན། མེ་ལས་དུ་བ་གདོན་མི་ཟ་བར་འབྱུང་ངོ་ཞེས་ཤུགས་ཀྱིས་རྗེས་སུ་འགྲོ་བ་རྟོགས་སོ། །དེ་ལྟ་མ་ཡིན་ན་དེ་མེད་ན་ཅི་སྟེ་ཡོད་པར་མི་འགྱུར། དེ་གྲུབ་ན་མ་གྲུབ་པའམ་རྒྱུ་ཐ་དད་པ་ནི་དེའི་རང་བཞིན་དུ་རིགས་པ༌[^178]མ་ཡིན་ནོ། །དངོས་པོ་རྣམས་ཀྱི་ཐ་དད་པའམ། རྒྱུ་ཐ་དད་པ་ནི་འདི་ཁོ་ན་ཡིན་ཏེ། ཆོས་འགལ་བ་གནས་པའམ། རྒྱུ་ཐ་དད་པ་ཡིན་ནོ། །གལ་ཏེ་དེ་དག་ཀྱང་ཐ་དད་པར་བྱེད་པ༌[^179]ཡིན་ན་གང་ཡང་གང་ལས་ཀྱང་ཐ་དད་པར་བྱེད་པ་མེད་པས་རིལ་རྫས་གཅིག་ཏུ་འགྱུར་རོ། །དེས་ན་ལྷན་ཅིག་སྐྱེ་བ་དང་འཇིག་པ་དག་དང་ཐམས་ཅད་ལ་ཐམས་ཅད་ཉེ་བར་སྦྱར་བར་འགྱུར་རོ། །དེ་ལྟ་མ་ཡིན་ན་གཅིག་ཅེས་བྱ་བ་ཉིད་དུ་མི་འགྱུར་བའམ། མིང་ཐ་དད་པར་ཟད་དེ། དོན་ཁས་བླངས་ནས་དེ་སྐད་དུ་བརྗོད་པའི་ཕྱིར་རོ། །རྒྱུ་དོན་ཐ་དད་པ་ཉིད་མེད་ཀྱང་དངོས་པོའི་དུས་ན། མི་རྟག་པ༌[^180]ཉིད་མ་གྲུབ་པའི་ཕྱིར་དེའི་རང་བཞིན་མ་ཡིན་པར་མཚུངས་པ་མ་ཡིན་ནམ་ཞེ་ན། མི་རྟག་པ་ཉིད་ཅེས་བྱ་བ་གང་ཕྱིས༌[^181]འགྲུབ་པར་འགྱུར་པ་གཞན་ནི་འགའ་ཡང་མེད་པ་ཡིན་ཏེ། དངོས་པོ་སྐད་ཅིག་མར་གནས་པའི་ཆོས་ཁོ་ན༌[^182]མི་རྟག་པ་ཉིད་ཡིན་ནོ། །ཆོས་དང་ཆོས་ཅན་གྱི༌[^183]ཚིག་ཐ་དད་པ་ལ་ཡང་རྒྱུ་མཚན་བཤད་པར་བྱའོ། །རང་གི་རྒྱུ་ཁོ་ན་ལས་དེ་ལྟར་སྐྱེ་བའི་ཕྱིར་འདིའི་རང་བཞིན་སྐད་ཅིག་མར་གནས་པའི་ཆོས་ཉིད་དེ་ནི་མཐོང༌[^184]བཞིན་དུ་ཡང་བློ་གཞན་པ༌[^185]ཡོད་པ་དམིགས་པས་རྟག་ཏུ་དེ་ལྟར་ཡོད་པར་དགོས་པས་བསླུས་པའམ། འདྲ་གཞན་འབྱུང་བས་བསླུས་པས༌[^186]མི་རྟོགས་སོ། །སྐད་ཅིག་མ་ཐ་མ་མཐོང་བ་རྣམས་ལ་ངེས་པའི་ཕྱིར། ཕྱིས་འདི་མི་དམིགས་པས་མི་གནས་པར་རྟོགས་པའི་ཕྱིར་དེའི་ཚེ་ངེས་པའི་དུས་ཡིན་པས་མི་རྟག་པ་ཉིད་དུ་རྣམ་པར་གཞག་གོ། །འབྲས་བུ་བསྐྱེད་པའི་ནུས་པ་རྒྱུའི་དངོས་པོ་ཉིད་ཡིན་ཡང་འབྲས་བུ་མ་མཐོང་བ་རྒྱུ་མཐོང༌[^187]དུ་ཟིན་ཀྱང་དེའི་ངོ་བོ་མ་རྟོགས་པས་འབྲས་བུ་མཐོང་བས་རྟོགས་པ་བཞིན་ནོ། །དེ་ལྟ་མ་ཡིན་ན་གཞན་གྱི་རྒྱུ་མཚན་ཉིད་ཡིན་ནམ། རྒྱུ་མཚན་མེད་པ་ཅན་ཉིད་ཡིན་ཡང་རུང་སྟེ། མི་རྟག་པ༌[^188]ཉིད་དོན་གཞན་ཁོ་ནར་འགྱུར་རོ། །དེ་ལྟ་ན་ནི་དངོས་པོ་དེ༌[^189]དང་ལྡན་པར་མི་འགྱུར་ཏེ། དེ་ལ་མི་དགོས་པའི་ཕྱིར་རོ། །འོན་ཏེ་དགོས་ན་ནི་དེ་ཉིད་འདིའི་རང་གི་བདག་ཉིད་དུ་གྱུར་པའི་མི་རྟག་པ་ཉིད་ཡིན་པས་གཞན་གྱིས་ཅི་ཞིག་བྱ། རང་བཞིན་གྱིས་མི་གཡོ་བ་ནི་དོན་གཞན་དང་ལྡན་ཡང་དེའི་ངོ་བོར་མི་འཐད་པའི་ཕྱིར་རོ། །མི་རྟག་པ་ཉིད་དམ་ཆོས་གཞན་དེ་ཡང་དོན་གཞན་ལས་འབྱུང་བ་ན་རྒྱུ་ཡིན་པའམ། འབྲས་བུ་ཡིན་པ་ཞིག་ཏུ་འགྱུར་གྲང་ན། རྒྱུ་དང་འབྲས་བུ་མ་ཡིན་པ་ནི་འབྲེལ་པ་མེད་པའི་ཕྱིར། དེ་ལ་ཡོད་པར་རྗེས་སུ་དཔག་པར་མི་སྲིད་པའི་ཕྱིར་རོ། །

དེ་གྲུབ་ན་མ་གྲུབ་པའམ་རྒྱུ་ཐ་དད་པ་ནི་དེའི་རང་བཞིན་དུ་རིགས་པ༌[^178]མ་ཡིན་ནོ། །དངོས་པོ་རྣམས་ཀྱི་ཐ་དད་པའམ། རྒྱུ་ཐ་དད་པ་ནི་འདི་ཁོ་ན་ཡིན་ཏེ། ཆོས་འགལ་བ་གནས་པའམ། རྒྱུ་ཐ་དད་པ་ཡིན་ནོ། །གལ་ཏེ་དེ་དག་ཀྱང་ཐ་དད་པར་བྱེད་པ༌[^179]ཡིན་ན་གང་ཡང་གང་ལས་ཀྱང་ཐ་དད་པར་བྱེད་པ་མེད་པས་རིལ་རྫས་གཅིག་ཏུ་འགྱུར་རོ། །དེས་ན་ལྷན་ཅིག་སྐྱེ་བ་དང་འཇིག་པ་དག་དང་ཐམས་ཅད་ལ་ཐམས་ཅད་ཉེ་བར་སྦྱར་བར་འགྱུར་རོ། །དེ་ལྟ་མ་ཡིན་ན་གཅིག་ཅེས་བྱ་བ་ཉིད་དུ་མི་འགྱུར་བའམ། མིང་ཐ་དད་པར་ཟད་དེ། དོན་ཁས་བླངས་ནས་དེ་སྐད་དུ་བརྗོད་པའི་ཕྱིར་རོ། །རྒྱུ་དོན་ཐ་དད་པ་ཉིད་མེད་ཀྱང་དངོས་པོའི་དུས་ན། མི་རྟག་པ༌[^180]ཉིད་མ་གྲུབ་པའི་ཕྱིར་དེའི་རང་བཞིན་མ་ཡིན་པར་མཚུངས་པ་མ་ཡིན་ནམ་ཞེ་ན། མི་རྟག་པ་ཉིད་ཅེས་བྱ་བ་གང་ཕྱིས༌[^181]འགྲུབ་པར་འགྱུར་པ་གཞན་ནི་འགའ་ཡང་མེད་པ་ཡིན་ཏེ། དངོས་པོ་སྐད་ཅིག་མར་གནས་པའི་ཆོས་ཁོ་ན༌[^182]མི་རྟག་པ་ཉིད་ཡིན་ནོ། །ཆོས་དང་ཆོས་ཅན་གྱི༌[^183]ཚིག་ཐ་དད་པ་ལ་ཡང་རྒྱུ་མཚན་བཤད་པར་བྱའོ། །རང་གི་རྒྱུ་ཁོ་ན་ལས་དེ་ལྟར་སྐྱེ་བའི་ཕྱིར་འདིའི་རང་བཞིན་སྐད་ཅིག་མར་གནས་པའི་ཆོས་ཉིད་དེ་ནི་མཐོང༌[^184]བཞིན་དུ་ཡང་བློ་གཞན་པ༌[^185]ཡོད་པ་དམིགས་པས་རྟག་ཏུ་དེ་ལྟར་ཡོད་པར་དགོས་པས་བསླུས་པའམ། འདྲ་གཞན་འབྱུང་བས་བསླུས་པས༌[^186]མི་རྟོགས་སོ། །སྐད་ཅིག་མ་ཐ་མ་མཐོང་བ་རྣམས་ལ་ངེས་པའི་ཕྱིར། ཕྱིས་འདི་མི་དམིགས་པས་མི་གནས་པར་རྟོགས་པའི་ཕྱིར་དེའི་ཚེ་ངེས་པའི་དུས་ཡིན་པས་མི་རྟག་པ་ཉིད་དུ་རྣམ་པར་གཞག་གོ། །འབྲས་བུ་བསྐྱེད་པའི་ནུས་པ་རྒྱུའི་དངོས་པོ་ཉིད་ཡིན་ཡང་འབྲས་བུ་མ་མཐོང་བ་རྒྱུ་མཐོང༌[^187]དུ་ཟིན་ཀྱང་དེའི་ངོ་བོ་མ་རྟོགས་པས་འབྲས་བུ་མཐོང་བས་རྟོགས་པ་བཞིན་ནོ། །དེ་ལྟ་མ་ཡིན་ན་གཞན་གྱི་རྒྱུ་མཚན་ཉིད་ཡིན་ནམ། རྒྱུ་མཚན་མེད་པ་ཅན་ཉིད་ཡིན་ཡང་རུང་སྟེ། མི་རྟག་པ༌[^188]ཉིད་དོན་གཞན་ཁོ་ནར་འགྱུར་རོ། །དེ་ལྟ་ན་ནི་དངོས་པོ་དེ༌[^189]དང་ལྡན་པར་མི་འགྱུར་ཏེ། དེ་ལ་མི་དགོས་པའི་ཕྱིར་རོ། །འོན་ཏེ་དགོས་ན་ནི་དེ་ཉིད་འདིའི་རང་གི་བདག་ཉིད་དུ་གྱུར་པའི་མི་རྟག་པ་ཉིད་ཡིན་པས་གཞན་གྱིས་ཅི་ཞིག་བྱ། རང་བཞིན་གྱིས་མི་གཡོ་བ་ནི་དོན་གཞན་དང་ལྡན་ཡང་དེའི་ངོ་བོར་མི་འཐད་པའི་ཕྱིར་རོ། །མི་རྟག་པ་ཉིད་དམ་ཆོས་གཞན་དེ་ཡང་དོན་གཞན་ལས་འབྱུང་བ་ན་རྒྱུ་ཡིན་པའམ། འབྲས་བུ་ཡིན་པ་ཞིག་ཏུ་འགྱུར་གྲང་ན། རྒྱུ་དང་འབྲས་བུ་མ་ཡིན་པ་ནི་འབྲེལ་པ་མེད་པའི་ཕྱིར། དེ་ལ་ཡོད་པར་རྗེས་སུ་དཔག་པར་མི་སྲིད་པའི་ཕྱིར་རོ། །

ཁྱད་པར་ཐ་དད་པ་དག་ཁོ་ན་དོན་ལ་སྒྲ་དང་། ཤེས་པ་གཞན་དག་གི་རྒྱུ་མཚན་ཡིན་དུ་ཟིན་ཀྱང་དེ་དང་ལྡན་པ་གཅིག་པུ་ཉིད་དེ་ནི་དེ་དག་གིས་ཉེ་བར་ལེན་ཏོ། །ཁྱད་པར་སྣ་ཚོགས་པ་ལ་ཕན་པའི་རྟེན་ནུས་པའི་ངོ་བོ་ཉིད་དེ་ནི་བདག་ཉིད་ལ་ཐ་དད་པ་མེད་པའི་ཕྱིར། བདག་ཉིད་ཐམས་ཅད་དུ་གཟུང་ན་ཁྱད་པར་གྱི་བྱེ་བྲག་མ་ངེས་པ་གང་ཞིག་ཡོད་དེ། ཁྱད་པར་ཐམས་ཅད་ལ་ཕན་འདོགས་པར་བྱེད་པ་ཉིད་དུ་གཟུང་བའི་ཕྱིར་རོ། །རང་གི་ངོ་བོ་གཟུང་བ་དེའི་ཕན་པར་བྱེད་པ་ཉིད་མ་བཟུང་བ་གཞན་ན༌[^282]ནི་མེད་པ་ཁོ་ནའོ། །དེའི་ཕྱིར་འདིའི་རང་གི་ངོ་བོར་གཟུང་བ་གང་ཡིན་པ་དེ་ཉིད་ཕན་པར་བྱེད་པ་ཉིད་དུ་ཡང་ཡིན་ནོ། །དེ་དག་བདག་ཉིད་ལ་འབྲེལ་ཕྱིར།[^283] །གཅིག་ཤེས་ན་ནི་གཉི་ག་གཟུང་། །ཁྱད་པར༌[^284]དེ་དང་ལྡན་པ་ཕན་པར་བྱ་བ་དང་། ཕན་པར་བྱེད་པའི་ངོ་བོ་བདག་ཉིད་དུ་གྱུར་པ་གཟུང་བའི་ཕྱིར་གཅིག་ཤེས་ན༌[^285]གཉི་ག་གཟུང་བས༌[^286]དེ༌[^287]ཁྱད་པར༌[^288]དུ་བྱས་པ་གཟུང༌[^289]ན་ཡང་ཁྱད་པར༌[^290]ཐམས་ཅད་གཟུང་བ་ཡིན་ཏེ། ཁྱད་པར་དང་ལྡན་པ་འཛིན་པ་ནི་དེ་འཛིན་པ་མེད་ན་དེ༌[^291]མེད་པའི་ཕྱིར་རོ། །གཞན་དུ་ན་དེ་ལྟར་ཡང་འཛིན་པར་མི་འགྱུར་རོ། །གཞན་ལ་ཕན་པར་བྱེད་པ་གང་ཞིག་མ་བཟུང་བར་གྱུར་པ་གཞན་ནི་མེད་པ་ཉིད་དོ། །ཕན་པར་བྱེད་པ་དེ་ལྟར་གཟུང་ན༌[^292]ཕན་པར་བྱ་བ་མ་བཟུང་བ་ཡང་མེད་དེ། དེ་ལ་ཡང་མ་བཟུང་བར་ཐལ་བར་འགྱུར་བའི་ཕྱིར་རྗེ༌[^293]ཁོལ་བཞིན་ནོ། །དེའི་ཕྱིར་ཁྱད་པར་དོན་གཞན་ཡིན་པར་སྨྲ་བ་ལ་ཡང་ཐལ་བར་འགྱུར་བར་མཚུངས་སོ། །འོན་ཏེ་གང་དག་གིས་ཁྱད་པར་ལ་ཕན་འདོགས་པའི་ནུས་པ་དག་ནི་ཐ་དད་པ་ཁོ་ན་སྟེ། དེའི་ཕྱིར་ཐལ་བ་འདིར་མི་འགྱུར་རོ་སྙམ་དུ་སེམས་ན།

གལ་ཏེ་ཁྱད་པར་རེ་རེ་ལ་ཕན་པར་བྱེད་པ་ཉིད་དག་ཡིན་ན་ནི་དེའི་རང་གི་བདག་ཉིད་དུ་གྱུར་པ་དག་མ་ཡིན་པ་ཁོ་ན་སྟེ། དེ་ལས་ཕན་པ་ཉམས་སུ་མྱོང་བ་ཡང་མེད་ན་ཅི་སྟེ་དེའི་དེ་དག་ཡིན་ཞེས་བྱ། འོན་ཏེ་ཕན་ན༌[^295]འདི་གཅིག་པུས་རང་གི་བདག་ཉིད་དུ་གྱུར་པའི་ནུས་པ་དག་གིས་ནུས་པ་ལ་ཕན་པ་བྱེད་པ་ན་ཁྱད་པར་གཅིག་གིས་གཟུང་ན་ཡང་བདག་ཉིད་ཐམས་ཅད་དུ་གཟུང་བ་ཁོ་ན་ཡིན་ཏེ། འདི་ལྟར་ཁྱད་པར་གཟུང་ན་དེ་ལ་ཕན་འདོགས་པའི་ནུས་པ་བཟུང་བ་ཡིན་ནོ། །དེ་གཟུང་ན་དེ་ལ་ཕན་པར་བྱེད་པའི་དངོས་པོ་ནུས་པ་ལ་ཕན་པ་རང་གི་བདག་ཉིད་དུ་གྱུར་པ་མཐའ་དག་དང་ལྡན་པ་གཟུང་བས་ཐམས་ཅད་ཀྱི་ནུས་པ་འཛིན་པར་བྱེད་ལ། དེ་དག་གིས་ཀྱང་ཁྱད་པར་རྣམ་པར༌[^296]འཛིན་པར་བྱེད་པས་ཐལ་བར་འགྱུར་པ་སོ་ན་འདུག་པ་ཡིན་ནོ། །འོན་ཏེ་ནུས་པ་ལ་ཕན་འདོགས་པའི་ནུས་པ་དེ་དག་ཀྱང་དངོས་པོ་ལས་ཐ་དད་པ་ཁོ་ན་ཡིན་ན། དེ་ལྟར་ན་ཁྱད་པར་དང་དེའི་ནུས་པ་རྣམས་ནུས་པ་གཞན་དག་ཁོ་ན་ལ་མཐར་ཐུག་པ་མེད་པར་སྦྱོར་བའི་ཕྱིར། དེ་ལ་ཕན་པའི་བདག་ཉིད་དེ་གཅིག་པུ་ནམ་ཡང་དེ་དག་དང་མ་བཟུང་བས་དེ་དང་ལྡན་པ་ཉིད་དུ་འཛིན་པར་མི་འགྱུར་རོ། །ཡང་གལ་ཏེ་སྒྲ་དང་ཤེས་པ་རྣམས་ཀྱི༌[^297]ཁྱད་པར་བདག༌[^298]ཉི་ཚེ་ལ་ཉེ་བར་སྦྱོར་བར་འགྱུར་ལ། དེའི་ཚེ་དེ༌[^299]དང་མ་འབྲེལ་བའི་ཕྱིར་དེ་རྟོགས་པའི་སྒོ་ནས་ཐམས་ཅད་རྟོགས་པར་མི་འགྱུར་རོ་ཞེ་ན། དེའི་ཚེ་ཡང་སྒྲ་དག་གིས་དེ་མ་འཕངས་པའི་ཕྱིར། དེ་ལ་སྒྲ་མི་འཇུག་པས༌[^300]སྒྲ་སྦྱོར་བ་དེ་མེད༌[^301]པར་འགྱུར་ཏེ། སྒྲུབ་པ་དང་དགག་པ་དག་གིས་ཐ་སྙད་ཐམས་ཅད་ནི་དོན་བྱེད་པའི་རྟེན་ཅན་ཡིན་པས་སོ། །ཁྱད་པར་རྣམས་ཀྱིས༌[^302]ནི་དེར་མི་ནུས༌[^303]ལ་ནུས་པ་ནི་མི་བརྗོད་པས་སྒྲ་སྦྱོར་བ་དག་གིས་ཅི་ཞིག་བྱ། དེའི་ཕྱིར་ཁྱད་པར་རྣམས་ནི་ཁྱད་པར་ཡང་མ་ཡིན་པར་འགྱུར་ཏེ། འགའ་ཞིག་ལ་ཞུགས་ན་ནི་གཙོ་བོ་འགའི་ཡན་ལག་ཏུ་གྱུར་པའི་ཕྱིར། དེ་ལ་ལྟོས་ནས་དེ་སྐད་ཅེས་བརྗོད་དོ། །སྒྲ་དག་གིས་དེ་མི་འཕེན་ན་ནི་དེ་དག་གང་གི་ཡང་ཡན་ལག་ཏུ་གྱུར་པ་མ་ཡིན་པས་ཅི་སྟེ་ཁྱད་པར་དག་ཡིན། གལ་ཏེ་ཤེས་པར་བྱས་པས་མཚོན་པའི༌[^304]ཕྱིར་ཉེས་པ་མེད་དོ་ཞེ་ན། ཐལ་བར་འགྱུར་བར་མཚུངས་ཏེ། རེ་ཞིག་མེད་ན་མེད་པའི༌[^305]ཕྱིར་ཁྱད་པར་དེ་དག་གིས་དེ་ཉེ་བར་མཚོན་པ་ན་གཅིག་གིས་ཉེ་བར་མཚོན་ན་ཡང་བདག་ཉིད་ཐམས་ཅད་ཉེ་བར་མཚོན་པ་ཡིན་པས་ཐལ་བར་འགྱུར་བ་སོན་འདུག་པ་ཡིན་ནོ། །འདི་སྒྲས་ཉེ་བར་མཚོན་པར་བྱེད་ཀྱང་རུང་། དེས་ཉེ་བར་མཚོན་པའི་ཁྱད་པར་དག་གིས་ཉེ་བར་མཚོན་པར༌[^306]བྱེད་ཀྱང་རུང་སྟེ། འདི་ལ་ཁྱད་པར་ཅི་ཞིག་ཡོད། རེ་ཞིག་དེའི་ཚེ་དེ་ཐམས་ཅད་ལ་ཕན་པར་བྱེད་པ་པོ་ཡིན་ནོ་ཞེས་བྱ་བར་ངེས་པར༌[^307]བྱེད་པས་དེ་ནི་གྱི་ནའོ། ཐ་དད་པ་ལ་ནི་དྲུག་པའོ། །མང་པོ་ལ་ནི་བྱེད་པ་པོ་རྣམས་སོ། །ཞེས་བྱ་བ་ལ་སོགས་པ་དེ་ཡང་སྐྱེས་བུའི་འདོད་པ་ལ་མི་ལྟོས་པ་ཉིད་དུ་དངོས་པོ་ཉེ་བ་ཙམ་གྱིས་རང་ཉིད་ཞུགས་པ་ནི་མ་ཡིན་ཏེ། དེ་དག་ནི་དེ་ལ་དེ་ལྟར་སྦྱོར་བས་དེ་ལྟར༌[^358]གོ་བར་འགྱུར་རོ། །དེ་བཞིན་དུ་གཞན་ལ༌[^359]ལ་ཡང་དེ་དག་གིས་ཇི་ལྟར་ཡང་རུང་རབ་ཏུ་སྦྱར་བ་དེ་ཁོ་ན་བཞིན་དུ་གོ་བའི་རྒྱུ་དག་ཏུ་འགྱུར་རོ། །དེ་ལ་ནི་བརྗོད་པར་བྱ་བ་དག༌[^360]སྐྱེས་བུ་ལ་རག་ལས་ཏེ། འཇུག་པའི་སྒྲ་དངོས་པོ་ཡང་དག་པར་མི་སྟོན་པ་ཇི་ལྟར་གོམས་པ་བཞིན་རྣམ་པར་རྟོག་པ༌[^361]སད་པའི་རྒྱུར་གྱུར་པ་རྣམས་འཇུག་པ་སེམས་པ་དང་། དེའི་དབང་གིས་དངོས་པོ་རྣམ་པར་འཇོག་པ་ནི་བླུན་པར་སྟོན་པ་འབའ་ཞིག་ཏུ་ཟད་དོ། །ཆོས་དང་ཆོས་ཅན་ལ་སོགས་པ་ལ་སྒྲ་དག་དེ་ལྟར་རྣམ་པར་གཞག་པར་བྱས་ཀྱི། ལྡོག་པ་དང་དངོས་པོ་ཐ་དད་པའི་སྒོ་ནས་ནི་མ་ཡིན་ནོ་ཞེས་བྱ་བ་འདི་ག་ལས་ཤེ༌[^362]ན། དེ་ལྟར་ན༌[^363]ཐ་སྙད་མི་རུང་བའི་ཕྱིར་ཏེ། ཆོས་དང་ཆོས་ཅན་དག་ཐ་དད་པའམ། དེའི་ངོ་བོ་ཡིན་པའམ། སྒྲ་རྣམས་དངོས་པོ་ཇི་ལྟ་བ་བཞིན་དུ་འཇུག་པ་ཡིན་ནོ། །སྤྱི་དང་དེ་དག་གི་འབྲེལ་པ་དང་། གཞི་མཐུན་པ་ཉིད་དང་། ཁྱད་པར་དང་ཁྱད་པར་གྱི་གཞིའི་དངོས་པོ་དག༌[^364]མི་རུང་ངོ་ཞེས་འཆད་པར་འགྱུར་རོ། །གང་ཡང་སྒྲ་འཇུག་པའི་ཁྱད་པར་འདི་ནི་ཐམས་ཅད་དུ་དངོས་པོས་བྱས་པ་ཁོ་ནར་འདོད་པ་དེའི།

ཅེས་བྱ་བ་འདི་ལ་རྒྱུ་ཅི་ཡོད། གང་གི་ཚེ་བུད་མེད་གཅིག་ལ་ཡང་བཙུན་མོ་རྣམས་ཞེས་བྱ་བ་དང་། བྱེ་མ་གཅིག་ལ་ཡང་བྱེ་མ་རྣམས་ཞེས་ཐ་སྙད་འདོགས་པ་དེ་ལ་གང་གིས་ན་དེ་ལྟ་བུར་འགྱུར་བའི་མང་པོ་ཉིད་ཅི་ཞིག་ཡོད། གལ་ཏེ་ནུས་པ་ཐ་དད་པ་ཡིན་ནོ་ཞེ་ན། དེ་ནི༌[^367]ཐམས་ཅད་དུ་གཅིག་གིས༌[^368]ཚིག་ཉམས་པ་ཡིན་ཏེ། ནུས་པ་གཅིག་པ་མེད་པའི་ཕྱིར་རོ། །འབད་པ་ཡང་དོན་མེད་དོ། །གལ་ཏེ་དངོས་པོ་ཐ་མི༌[^369]དད་པའི་ཕྱིར་གཞན་ལ་གཅིག་གི་ཚིག་ཏུ་འགྱུར་རོ་ཞེ་ན། འདི་ལ་ཡང་འགྱུར་རོ། །དེའི་ཕྱིར་ངེས་པ་དངོས་པོ་མ་ཡིན་པ་འདི་བྱེད་པ་ན། སྒྲ་སྦྱོར་བ་ལ་འདོད་པ་རང་དབང་ཅན་དུ་སྟོན་པ་ཡིན་ནོ། །གྲོང་ཁྱེར་དྲུག་ཅེས་བྱ་བ་ཡང་ཇི་ལྟར་མང་པོ་དག་ལ་གཅིག་གི་ཚིག་ཏུ་འགྱུར། གྲོང་ཁྱེར་ཉིད་ཀྱང་ཅུང་ཟད་ཀྱང་མེད་ན། དེ་རྣམས་ལ་སྡུད་པ་ལྟ༌[^370]ག་ལ་ཡོད། ཁང་བཟངས་དང་སྐྱེས་བུ་ལ་སོགས་པ་རིགས་མི་མཐུན་པ་རྣམས་ཀྱིས་མི་རྩོམ་པའི་ཕྱིར། དེ་རྣམས་ཀྱི་སྤྱི་ལྟ་ཞིག་རྫས་གང་ལ༌[^371]ཡིན་ཏེ། ལྡན་པ་མེད་པའི་ཡང་ཕྱིར་རོ། །ལྡན་པ་ནི་མ་ཡིན་ཏེ། ཁང་བཟངས་རང་ཉིད་ལྡན་པའི་བདག་ཉིད་ཡིན་པ་གཞན་དང་མི་ལྡན་པའི་ཡང་ཕྱིར་རོ། །དེ་ཉིད་ཀྱི་ཕྱིར་གྲངས་ཀྱང་མེད་དེ། གལ་ཏེ་གྲོང་ཁྱེར་ནི་ལྡན་པ་དེ་དང་སྐྱེས་བུས་ཁྱད་པར་དུ་བྱས་པའི་ཡོད་པ་ཡིན་ནོ་ཞེ་ན། བོགས་དབྱུང་དུ་མེད་པ་འདི་ལ་ཁྱད་པར་ཅི་ཞིག་ཡོད། ཡོད་པ་ཡང་གཅིག་ཡིན་པའི་ཕྱིར། གྲོང་ཁྱེར་མང་པོ་ཉིད་ལ་ཡང་གྲོང་ཁྱེར་རྣམས་ཞེས་མང་པོའི་ཚིག་ཏུ་མི་འགྱུར་རོ།[^372] ། གལ་ཏེ་གཉིས་ཕན་ཚུན་གྲོགས་བྱེད་པ་ཉིད་ཡིན་ནོ་ཞེ་ན། ཕན་པར་བྱ་བ་དང་ཕན་པར་བྱེད་པ་པོ་མ་ཡིན་པ་དག་ལ་གྲོགས་བྱེད་པའི་དངོས་པོ་ཅི་ཞིག་ཡོད། སྐྱེས་བུ་དང་ལྡན་པ་དང་། ཡོད་པ་རྣམས་ཀྱང་མང་བའི་ཕྱིར། ཇི་ལྟར་གྲོང་ཁྱེར་ཞེས་གཅིག་གི་ཚིག་ཏུ་འགྱུར། གལ་ཏེ་དེ་ལྟ་བུ་རྣམས་དོན་འགའ་ཞིག་ལ་ནུས་པ་ཐ་མི་དད་པ་ཡོད་པས་དེ་རྒྱུ་མཚན་ཡིན་ནོ་ཞེ་ན། མ་ཡིན་ཏེ། ནུས་པ་ནི་དངོས་པོའི་ངོ་བོ་ལས་ཐ་མི་དད་པའི་ཕྱིར་རོ།། །།
