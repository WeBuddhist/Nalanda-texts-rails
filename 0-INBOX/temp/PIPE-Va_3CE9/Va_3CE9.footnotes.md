[^1]: མགོའི་ ༼སྣར། པེ།༽ གཽ་
[^2]: རྟོགས་པ་ ༼སྣར། པེ།༽ རྟོག་པ་
[^3]: བཟུང་བར་ ༼སྣར། པེ།༽ གཟུང་བར་
[^4]: བསྡུས་ ༼སྣར།༽ བསྡུད་
[^5]: བྱིན་པ་ ༼སྣར།༽ བྱིན་པར་
[^6]: རྫོགས་པས་སོ། ༼སྣར། པེ།༽ རྫོགས་པའོ།
[^7]: བརྟག་པར་ ༼སྣར། པེ།༽ བརྟགས་པར་
[^8]: འདས་ཀྱི་ ༼སྣར། པེ།༽ འདས་ཀྱིས་
[^9]: མོང་ ༼སྣར། པེ།༽ མོངས་
[^10]: དོན་འདི་ ༼སྣར། པེ།༽ དོན་
[^11]: ཡང་དག་པ་ ༼སྣར། པེ།༽ ཡང་དག་པར་
[^12]: རྡུ་བཏོན་ ༼སྣར། པེ།༽ རྡུ་སྟོན་
[^13]: པ་ ༼སྣར། པེ།༽ ལ་
[^14]: དང་སེམས་ཀྱི་ ༼སྣར། པེ།༽ དང་སེམས་ཀྱིས་
[^15]: བཏགས་པ་ ༼སྣར། པེ།༽ བརྟགས་པ་
[^16]: རིགས་པའི་ ༼སྣར། པེ།༽ རིག་པའི་
[^17]: རྣམ་པ་ ༼སྣར།༽ རྣམ་པར་
[^18]: སེམས་ཀྱི་ ༼སྣར། པེ།༽ སེམས་ཀྱིས་
[^19]: ཡིད་ཀྱི་ ༼སྣར། པེ།༽ ཡིད་ཀྱིས་
[^20]: བཏགས་པ་ ༼སྣར།༽ བརྟགས་པ་
[^21]: པ་ ༼སྣར། པེ།༽ པར་
[^22]: དང་བ་དང་། ༼སྣར། པེ།༽ དང་།
[^23]: འཛིན་གྱི་ ༼སྣར། པེ།༽ འཛིན་གྱིས་
[^24]: རྫོགས་པ་ ༼སྣར། པེ།༽ རྫོགས་
[^25]: དེས་ ༼སྣར། པེ།༽ དེ་
[^26]: དེས་ ༼སྣར། པེ།༽ དེ་
[^27]: དག་པ་ ༼སྣར། པེ།༽ དག་པར་
[^28]: མི་རྟག་པར་ ༼སྣར། པེ།༽ མི་རྟག་པ་
[^29]: ལ་ ༼སྣར། པེ།༽ ལས་
[^30]: བཟུང་བའི་ ༼སྣར། པེ།༽ གཟུང་བའི་
[^31]: རྟོག་པ་ ༼སྣར།༽ རྟོགས་པ་
[^32]: བསྟེན་པ་ ༼སྣར། པེ།༽ བརྟེན་པ་
[^33]: བཞིས་ ༼སྣར། པེ།༽ བཞི་
[^34]: ཆོས་ ༼སྣར། པེ།༽ ཆོས་ཀྱི་
[^35]: སྒྲུབ་པ་ ༼སྣར། པེ།༽ བསྒྲུབ་པ་
[^36]: ཐམས་ཅད་ལ་ ༼སྣར། པེ།༽ ཐམས་ཅད་
[^37]: འཇིག་རྟེན་པ་ ༼སྣར། པེ།༽ འཇིག་རྟེན་
[^38]: སེམས་ཅན་གྱི་ ༼སྣར། པེ།༽ སེམས་ཅན་གྱིས་
[^39]: བཞིན་ ༼སྣར།༽ གཞིན་
[^40]: རྟོགས་པའི་ ༼སྣར། པེ།༽ རྟོག་པའི་
[^41]: བསྒོམ་པའི་ ༼སྣར།༽ བསྒོས་པའི་
[^42]: རྟོགས་པ་ ༼སྣར། པེ།༽ རྟོག་པ་
[^43]: མཐུན་པ་བཞིན་དུ་ ༼སྣར། པེ།༽ མཐུན་པའི་
[^44]: བསླབ་པའི་ ༼སྣར།༽ བསླབས་པའི་
[^45]: བསྒོམས་པའི་ ༼སྣར། པེ།༽ བསྒོམ་པའི་
[^46]: དག་པ་ ༼སྣར།༽ དག་པས་
[^47]: དེ་དག་གི་ ༼སྣར།༽ དེ་དག་གིས་
[^48]: ཡང་དག་པ་ ༼སྣར། པེ།༽ ཡང་དག་པར་
[^49]: རྩ་བའི་ ༼སྣར། པེ།༽ རྩ་བ་
[^50]: ཉིད་ཀྱིས་ ༼སྣར། པེ།༽ ཉིད་ཀྱི་
[^51]: ཆུད་ ༼སྣར། པེ།༽ ཆུད་པ་མེད་
[^52]: གང་དུ་ ༼སྣར། པེ།༽ གང་
[^53]: དག་པས་ ༼སྣར། པེ།༽ དག་པ་ལས་
[^54]: ཡེ་ཤེས་ཀྱི་ ༼སྣར།༽ ཡེ་ཤེས་ཀྱིས་
[^55]: ཡང་དག་པ་ ༼སྣར། པེ།༽ ཡང་དག་པར་
[^56]: མཐུན་པར་ ༼སྣར། པེ།༽ མཐུན་པ་
[^57]: ཆུང་དུ་ ༼སྣར། པེ།༽ ཆུང་ངུས་
[^58]: སྣ་ཚོགས་ཀྱི་ ༼སྣར། པེ།༽ སྣ་ཚོགས་ཀྱིས་
[^59]: ཡིད་ཀྱིས་ ༼པེ།༽ ཡིད་ཀྱི་
[^60]: སྒྱུར་བ་ ༼སྣར། པེ།༽ བསྒྱུར་བ་
[^61]: འཇིགས་པ་ ༼སྣར།༽ འཇིག་པ་
[^62]: མངོན་ ༼སྣར། པེ།༽ མངོན་པས་མངོན་
[^63]: པ་ ༼སྣར། པེ།༽ པར་
[^64]: དང་རྣམ་པར་བྱང་བ་ཆུང་ ༼སྣར།༽ རྣམ་པར་བྱང་ཆུབ་
[^65]: རྟོག་པ་ ༼སྣར། པེ།༽ རྟོགས་པ་
[^66]: བརྩམས་པས་སོ། །ཡང་ ༼སྣར།༽ བརྩམས་པའོ། །
[^67]: བསླབ་པ་ ༼སྣར། པེ།༽ བསླབས་པ་
[^68]: ། བསྟན་པ་རྣམ་པར་དག་པ་དང་། ༼སྣར། པེ།༽ །
[^69]: ཞུ་ ༼སྣར། པེ།༽ ཞུས་
