Enumeration Block 1:
དེ་ལ་བསོད་སྙོམས་པ་ཉིད་ནི་རྣམ་པ་གསུམ་སྟེ། ཆུང་ངུ་དང་འབྲིང་དང་ཆེན་པོའོ། །

Enumeration Block 2:
དེ་ལ་ཕྱག་དར་ཁྲོད་པ་ནི་རྣམ་པ་གསུམ་སྟེ། ཆུང་ངུ་དང་འབྲིང་དང་ཆེན་པོའོ། །

Enumeration Block 3:
དེ་ལ་ཟས་ཕྱིས་མི་ལེན་པ་ནི་རྣམ་པ་གསུམ་སྟེ། ཆུང་ངུ་དང་འབྲིང་དང་ཆེན་པོའོ། །

Enumeration Block 4:
དེ་ལ་སྟན་གཅིག་པ་ནི་རྣམ་པ་གསུམ་སྟེ། ཆུང་ངུ་དང་འབྲིང་དང་ཆེན་པོའོ། །

Enumeration Block 5:
དེ་ལ་ལྷུང་བཟེད་ཀྱི་བསོད་སྙོམས་པ་ཉིད་ནི་རྣམ་པ་གསུམ་སྟེ། ཆུང་ངུ་དང་འབྲིང་དང་ཆེན་པོའོ། །

Enumeration Block 6:
དེ་ལ་མཐར་གྱིས་སློང་བའི་བསོད་སྙོམས་པ་ནི་རྣམ་པ་གསུམ་སྟེ། ཆུང་ངུ་དང་འབྲིང་དང་ཆེན་པོའོ། །

Enumeration Block 7:
