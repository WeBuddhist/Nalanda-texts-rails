Enumeration Block 1:
དེ་ལ་མཐར་གྱིས་སློང་བའི་བསོད་སྙོམས་པ་ནི་རྣམ་པ་གསུམ་སྟེ། ཆུང་ངུ་དང་འབྲིང་དང་ཆེན་པོའོ། །

Enumeration Block 2:
དེ་ལ་དུར་ཁྲོད་པ༌[^1842]རྣམ་པ་གསུམ་སྟེ། ཆུང་ངུ་དང་འབྲིང་དང་ཆེན་པོའོ། །

Enumeration Block 3:
དེ་ལ་བླ་གབ་མེད་པ་ནི༌[^1856]རྣམ་པ་གསུམ་སྟེ། ཆུང་ངུ་དང་འབྲིང་དང་ཆེན་པོའོ། །

Enumeration Block 4:
དེ་ལ་ཤིང་དྲུང་པ་ནི༌[^1860]རྣམ་པ་གསུམ་སྟེ། ཆུང་ངུ་དང་འབྲིང་དང་ཆེན་པོའོ། །

Enumeration Block 5:
དེ་ལ་ཅོག་པུ་པ་ཉིད་ནི་རྣམ་པ་གསུམ་སྟེ། ཆུང་ངུ་དང་འབྲིང་དང་ཆེན་པོའོ། །

Enumeration Block 6:
དེ་ལ་གཞི་ཇི་བཞིན་པ་ནི་རྣམ་པ་གསུམ་སྟེ། ཆུང་ངུ་དང་འབྲིང་དང་ཆེན་པོའོ། །

Enumeration Block 7:
དེ་ལ་ཆོས་གོས་གསུམ་པ་ནི་རྣམ་པ་གསུམ་སྟེ། ཆུང་ངུ་དང་འབྲིང་དང་ཆེན་པོའོ། །
