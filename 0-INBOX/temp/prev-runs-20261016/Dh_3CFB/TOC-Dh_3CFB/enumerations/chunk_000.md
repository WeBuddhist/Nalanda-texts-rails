Enumeration Block 1:
དེ་དག་ནི་འབྲས་བུ་དང་། རང་བཞིན་དང་། མི་དམིགས་པའི་མཚན་ཉིད་ཅན་གྱི་གཏན་ཚིགས་གསུམ་ཡིན་ཏེ།

Enumeration Block 2:
དེ་ལས་གཉིས་ནི་དངོས་པོ་སྒྲུབ་པ་ཡིན་ལ། གཅིག་ནི་དགག་པའི་གཏན་ཚིགས་ཡིན་ཏེ།

Enumeration Block 3:
དེ་ཡང་སྦྱོར་བའི་བྱེ་བྲག་གིས། །
འགལ་དང་འབྲས་བུ་དག་གྲུབ་དང་། །
རྒྱུ་དང་ངོ་བོར་བལྟར་རུང་བའི། །
བདག་ཉིད་དག་ནི་མ་གྲུབ་པའི། །
མེད་དོན་ཅན་མི་དམིགས་རྣམ་བཞི། །

Enumeration Block 4:
འདི་ལྟར་དེ་ནི་རྣམ་པ་གཉིས་ཀྱིས་བྱེད་དེ། འགའ་ཞིག་སྒྲུབ་པས༌[^27]སམ། དགག་པས་སོ། །

Enumeration Block 5:
དགག་པའི་ཡུལ་ཅན་གྱི་མི་དམིགས་པ་འདི་ནི་སྦྱོར་བའི་བྱེ་བྲག་གིས་རྣམ་པ་བཞི་ཡིན་ཏེ།
