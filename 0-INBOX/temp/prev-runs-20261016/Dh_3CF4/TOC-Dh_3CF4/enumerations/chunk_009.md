Enumeration Block 1:
སྐྱེ་བོ་མཛའ་བཤེས་བྱེས༌[^277]ནས་འོངས་པ་དག །ཅེས་བྱ་བའི་ཚིགས་བཅད་འདིའི་ལུས་ནི་སྦྱོར་བ་དང་། དངོས་དང་། མཇུག་སངས་རྒྱས་ཀྱི་བཀའ་དང༌[^278]མཐུན་པར་སྟོན་པ་ཡིན་ཏེ།
Enumeration Block 2:
སྦྱིན་པ་ལས་བྱུང་བ་ཞེས་བྱ་བ༌[^280]དང་། ཚིགས་བཅད་འདི་གཉིས་ཀྱིས་ནི་མཐོང་བའི་ཆོས་ཀྱིས་རྟོགས་པ་གཉིས་བསྟན་ཏེ། བདག་ཉིད་ལ་ལྟ་བ་དང་། གཞན་དག་ལ་ཡང་གྲགས་པར་བྱེད་པའོ། །
Enumeration Block 3:
ས་བདག་དམ་པ་ཁྱོད་ཀྱི་ཞེས་བྱ་བ་ལ་སོགས་པ་འདིའི་ལུས་ནི་གང་སློང་བ་དང་། ཇི་ལྟ་བུ་སློང་བ་དང་། གོང༌[^295]ནས་འོངས་ཏེ་སློང་བའོ། །
Enumeration Block 4:
གང་ཞིག་སྦྱིན་ཞེས་སྨྲས་ནས་ནི་ཞེས་བྱ་བ་ལ་སོགས་པའི་ཚིགས་བཅད་གསུམ་གྱིས་ནི་མིག༌[^331]སྦྱིན་པ་ཉིད་རིགས་པར༌[^332]ཕྱོགས་བླངས་ནས་སྨས་པ་སྟེ། བསམ་པ་ཉམས་པ་དང་། སྦྱོར་བ་ཉམས་པ་ལས་བརྩམས་ཏེ། གཉིས་ཀྱིས་ནི་བསམ་པ་ཉམས་པའོ། །
