Enumeration Block 1:
ཉེས་དམིགས་ཀྱང་རྣམ་པ་གཉིས་ཏེ། གྲགས་པ་མེད་པ་དང་། སྐྱེ་བོ་དམ་པས་སྨད་པ་སྟེ།

Enumeration Block 2:
དགྲ་དག་ལས་གྲུབ༌[^3122]པ་ཡང་རྣམ་པ་གཉིས་ཏེ། གསད་པ༌[^3123]དང་། གཞོམ་པར་བྱ་བའོ། །

Enumeration Block 3:
གྲོགས་པོ་ལ་ཡང་རྣམ་པ་གཉིས་ཏེ། སྒྲུབ་པ་དང་། [^3124]གཞག་པའོ། །

Enumeration Block 4:
རྒྱུ་འདི་གསུམ་གྱིས་ཏེ། དུས་སུ་སྦྱིན་པ་དང་། རིམ་གྲོ་བྱས་ཏེ། སྦྱིན་པ་དང་། རྒྱ་ཆེན་པོའི་སྦྱིན་པ་བསྟན་ཏོ། །

Enumeration Block 5:
བདག་གི་ཕུན་སུམ་ཚོགས་པ་ཡང་རྣམ་པ་གསུམ་སྟེ། གཟུགས་ཀྱི་ལུས་ཕུན་སུམ་ཚོགས་པ་དང་། མིང་གི་ལུས༌[^3150]ཕུན་སུམ་ཚོགས་པ་དང་། བྱ་བ་ཕུན་སུམ་ཚོགས་པའོ། །

Enumeration Block 6:
སྙིང་རྗེའི་ཞིང་ནི་གསུམ་སྟེ། ཕོངས་པ་དང་། སྡུག་བསྔལ་བ་ཉིད་དང་། རྗེས་སུ་འབྲང་བ་མེད་པའོ། །
