Enumeration Block 1:
རྣམ་པར་གྲོལ་བ་དེའི་སྔོན་དུ་འགྲོ་བའི་ཆོས་ནི་འདི་གཉིས་ཡིན་ཏེ། ལྟ་བའི་སྔོན་དུ་འགྲོ་བ་དང་། ལམ་གྱི་འབྲས་བུའི་སྔོན་དུ་འགྲོ་བའོ། །

Enumeration Block 2:
རྣམ་པར་གྲོལ་བ་དེ་མ་ཐོབ་པ་ཐོབ་པར་བྱ་བ་ལ་བརྟག་པའི་གཞི་རྣམ་པ་བརྒྱད་ཡོད་དེ། འདུ་བྱེད་རྣམས་ཀྱི་རོ་མྱང་བ་དང་། ཉེས་དམིགས་དང་། ངེས་པར་འབྱུང་བ་བརྟག་པ་དང་། ཐོས་པ་དང་། བསམས་པ༌[^36]དང་། སོ་སོར་བརྟག་པའི་སྟོབས་དང་། མཐོང་བ་དང་བསྒོམ་པའི་ལམ་བརྟག་པའོ། །

Enumeration Block 3:
འདུ་བྱེད་རྣམས་ཀྱི་ངེས་པ་ནི་བཞི་ཡོད་དེ། མི་རྟག་པར་ངེས་པ་དང་། སྡུག་བསྔལ་བར་ངེས་པ་དང་། སྟོང་པར་ངེས་པ་དང་། བདག་མེད་པར་ངེས་པའོ། །

Enumeration Block 4:
དེ་ལ་འདས་པ་དང་། མ་འོངས་པའི་འདུ་བྱེད་རྣམས་ཀྱང་རྣམ་པ་གསུམ་གྱིས་མི་རྟག་པར་རིག་པར་བྱ་ན། ད་ལྟར་བྱུང་བ་རྣམས་ལྟ་ཅི་སྨོས་ཏེ། གསུམ་གང་ཞེ་ན། མེད་པ་སྔོན་དུ་འགྲོ་བའི་ཡོད་པ་དང་། ཡོད་པ་སྔོན་དུ་འགྲོ་བའི་མེད་པ་དང་། སྐྱེ་བ་དང་འཇིག་པ་དང་ལྡན་པའོ། །

Enumeration Block 5:
དེ་ལ་སྟོང་པ་ཉིད་ནི་རྣམ་པ་གཉིས་སུ་རིག་པར་བྱ་སྟེ། གཏན་མེད་པའི་སྟོང་པ་ཉིད་དང་། ཕྱིས་བྲལ་བའི་སྟོང་པའོ། །

Enumeration Block 6:
ལྔ་པོ་འདི་དག་ནི་འབྲལ་བའི་ཕྱོགས་ཀྱི་ཁམས་ཏེ། འདི་ལྟ་སྟེ། སྤོང་བའི་ཁམས་དང་། འདོད་ཆགས་དང་བྲལ་བའི་ཁམས་དང་། འགོག་པའི་ཁམས་དང་། ཕུང་པོའི་ལྷག་མ་དང་བཅས་པའི་མྱ་ངན་ལས་འདས་པའི་ཁམས་དང་། ཕུང་པོ་ལྷག་མ་མེད་པའི་མྱ་ངན་ལས་འདས་པའི་ཁམས་སོ། །

Enumeration Block 7:
སེམས་རྣམ་པར་གྲོལ་བར་བྱ་བའི་ཕྱིར་བརྩོན་པ་ལ་གོ་རིམས་རྣམ་པ་གཉིས་ཡོད་དེ། ཤེས་པའི་གོ་རིམས་དང་། ཤེས་པའི་འབྲས་བུའི་གོ་རིམས་སོམོ། །
