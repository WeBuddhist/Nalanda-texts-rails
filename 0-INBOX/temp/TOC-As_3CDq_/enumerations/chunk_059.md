Enumeration Block 1:
མདོར་བསྡུ་ན་ཚོར་བ་རྣམ་པར་ཞི་བར་འགྱུར་བ་ནི་རྣམ་པ་གསུམ་དུ་རིག་པར་བྱ་སྟེ། གོང་མ་མཉམ་པར་གཞག་པའི་ས་ལ་བརྟེན་པས། ས་འོག་མའི་ཚོར་བ་རྣམ་པར་ཞི་བར་འགྱུར་བ་དང་། རེ་ཞིག་ཀུན་དུ་མི་སྤྱོད་པས་རྣམ་པར་ཞི་བ་དང་ཕྱི་མ་ལ་གཏན་དུ་མི་འཇུག་པས་རྣམ་པར་ཞི་བའོ། །

Enumeration Block 2:
ཚོར་བའི་རྣམ་པ་ཐམས་ཅད་ལ་ནི་རྣམ་པ་བདུན་གྱིས་ཚོར་བ༌[^2308]བརྟག་པར་རིག་པར་བྱ་སྟེ། རང་བཞིན་དང་། ད་ལྟར་འཇུག་པ་དང་ལྡོག་པའི་རྒྱུ་དང་། ཚེ་ཕྱི་མ་ལ་འཇུག་པའི་རྒྱུ་དང་། ཚེ་ཕྱི་མ་ལ་མི་འཇུག་པའི་རྒྱུ་དང་། ཀུན་ནས་ཉོན་མོངས་པ་འཇུག་པའི་རྒྱུ་དང་། རྣམ་པར་བྱང་བའི་རྒྱུ་དང་། རྣམ་པར་བྱང་བའི་སྒོ་ནས་ནི་བརྟག་པའོ། །

Enumeration Block 3:
དེ་ལ༌[^2317]ཁྱིམ་པ་དང་རབ་ཏུ་བྱུང་བ་འདོད་པ་རྣམས་ལས་འདོད་ཆགས་དང་མ་བྲལ་བའི་ཉོན་མོངས་པ་ཅན་གྱི་ཚོར་བ་ནི་རྒྱུ་གསུམ་གྱིས་སྐྱེ་བར་འགྱུར་ཏེ། ལྷག་པར་ཞེན་པའི་སྟོབས་དང་། ཡིད་ལ་བྱེད་པའི་སྟོབས་དང་། ཡུལ་གྱི་སྟོབས་སོ། །

Enumeration Block 4:
ཚོར་བ་རྣམས་ཀྱི་བྱེ་བྲག་ནི་རྣམ་པ་བཅུར་རིག་པར་བྱ་སྟེ། ཡང་དག་པའི་བྱེ་བྲག་དང་། འཇུག་པའི་རྟེན་གྱི་བྱེ་བྲག་དང་། རང་གི་མཚན་ཉིད་ཀྱི་བྱེ་བྲག་དང་། ཇི་སྙེད་ཡོད་པའི་བྱེ་བྲག་དང་། རང་གི་མཚན་ཉིད་ཀྱི་རྣམ་པའི་བྱེ་བྲག་དང་། འཇུག་པའི་སྒོའི་བྱེ་བྲག་དང་། ཀུན་ནས་ཉོན་མོངས་པའི་སྒོའི་བྱེ་བྲག་དང་། མི་མཐུན་པའི་ཕྱོགས་དང་གཉེན་པོའི་བྱེ་བྲག་དང་། དུས་ཀྱི་བྱེ་བྲག་དང་། སྐད་ཅིག་པ་གཅིག་ནས་གཅིག་ཏུ་བརྒྱུད་ཅིང་འཇུག་པའི་བྱེ་བྲག་གོ། །

Enumeration Block 5:
དེ་དག་ཐམས་ཅད་གཅིག་ཏུ་བསྡུས་ན་བདེ་བ་གསུམ་དུ་འགྱུར་ཏེ། ཡོངས་སུ་སྤང་བར་བྱ་བའི་བདེ་བ་དང་། བསྟེན་པར་བྱ་བའི༌[^2345]གནས་པའི་བདེ་བ་གོང་ན་ཡོད་པ་དང་གོང་ན་མེད་པ་དང་། གཏན་དུ་མཐར་ཐུག་པ་སྟེ་རྣམ་པར་གྲོལ་བའི་བདེ་བའོ། །
