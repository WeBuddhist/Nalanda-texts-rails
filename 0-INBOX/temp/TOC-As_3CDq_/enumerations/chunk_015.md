Enumeration Block 1:
ཆོས་འདི་པ་རྣམས་དང་། ཕྱི་རོལ་པ་རྣམས་ཀྱི་སྟོན་པ་རྣམས་དང་སློབ་མ་རྣམས་ནི་རྣམ་པ་ལྔས་མཐོ་བ་དང་དམའ་བར་རིག་པར་བྱ་སྟེ། འདི་ལྟ་སྟེ། གནས་པ་དང་། ཚོགས་ཡོངས་སུ་བསྐྱང་བ་དང་། འབེལ་བའི་གཏམ་རྣམ་པར་ངེས་པར་འབྱེད་པར་བྱེད་པ་དང་། ལམ་གདགས་པ་ཡང་དག་པར་བསྟན་པ་དང་། ནན་ཏན་དུ་སྒྲུབ་པའོ། །

Enumeration Block 2:
རྣམ་པ་བཞི་པོ་དེ་དག་ཀྱང་གཞི་གསུམ་གྱི་སྐབས་སུ་རིག་པར་བྱ་སྟེ། སྐྱེ་བའི་གནས་དང་། ཚོར་བ་དང་། དུས་སོ། །

Enumeration Block 3:
ཤེས་པ་ནི་གཉིས་ཏེ། ཡང་དག་པའི་ཤེས་པ་དང་། ལོག་པའི་ཤེས་པའོ། །

Enumeration Block 4:
མདོ་སྡེ་འདི༌[^563]གཉིས་ཡོད་དེ། ཆེད་དུ་བསྟན་པ་དང་། ཆེད་དུ་བསྟན་པ་མ་ཡིན་པའི་མདོ་སྡེའོ། །

Enumeration Block 5:
ཡན་ལག་གསུམ་གྱིས་ཡོངས་སུ་ཟིན་ན་མྱ་ངན་ལས་འདས་པ་ཡོངས་སུ་རྫོགས་པར་རིག་པར་བྱ་སྟེ། འདི་ལྟ་སྟེ། མཐུན་པའི་གདམས་ངག་དང་འདུ་བྱེད་ཐམས་ཅད་ཡང་དག་པར་བརྟགས་པ་དང་ཉོན་མོངས་པ་ཐམས་ཅད་སྤངས་པའོ། །
