Enumeration Block 1:
འདི་གཉིས་ནི་འདུས་བྱས་དང་། འདུས་མ་བྱས་པ་སྟེ། དེ་ལ་འདུས་བྱས་ཀྱི་མི་རྟག་པ་ནི་འདུས་བྱས་ཀྱི་མཚན་ཉིད་གསུམ་གྱིས་ཤེས་པར་འགྱུར་ཏེ། འདི་ལྟ་སྟེ། སྐྱེ་བ་དང་འཇིག་པ་དང་གནས་པ་ལས་གཞན་དུ་འགྱུར་བའོ། །

མཚན་ཉིད་གསུམ་པོ་དེ་དག་ཀྱང་འདུ་བྱེད་ཀྱི་རྒྱུན་གཉིས་ལ་བརྟེན་ནས་ཤེས་པར་འགྱུར་ཏེ། འདི་ལྟ་སྟེ། ཚེ་རབས་གཅིག་ནས་གཅིག་ཏུ་བརྒྱུད་པའི་རྒྱུན་དང་། སྐད་ཅིག་པ་གཅིག་ནས་གཅིག་ཏུ་བརྒྱུད་པའི་རྒྱུན་ནོ། །
Enumeration Block 2:
གཞན་དུ་འགྱུར་བ་ནི་གཉིས་ཏེ། ཐ་དད་པའི་གཞན་དུ་འགྱུར་བ་དང་། ཐ་དད་པར་འགྱུར་བའི་གཞན་དུ་འགྱུར་བའོ། །
Enumeration Block 3:
འདི་གཉིས་ནི་བདག་བསྟོད་པ་དང་། གཞན་སྨོད་པ་སྟེ། འདི་ལྟ་སྟེ། ཚིག་ཙམ་གྱིས་བྱེད་པ་དང་། སྟོན་ཅིང་ནན་ཏན་དུ་སྒྲུབ་པས༌[^642]བྱེད་པའོ། །
Enumeration Block 4:
བླ་ན་མེད་པ་ནི་གསུམ་སྟེ། འདི་ལྟ་སྟེ། ཤེས་པ་བླ་ན་མེད་པ་དང་། ལམ་བླ་ན་མེད་པ་དང་། རྣམ་པར་གྲོལ་བ་བླ་ན་མེད་པའོ། །
Enumeration Block 5:
བྱང་ཆུབ་ཀྱི་ཕྱོགས་དང་མཐུན་པ་ལ་བརྟེན་པ་འདུ་བྱེད་རྣམས་རབ་ཏུ་རྣམ་པར་འབྱེད་པ་ན་དུས་གཉིས་སུ་རྣམ་པ་བཞིས་འཇིག་ཚོགས་ལ་ལྟ་བ་ཡོངས་སུ་ཤེས་ན་དུས་གཉིས་ཀྱི་རྗེས་ཐོགས་སུ་ཟག་པ་ཟད་པ་ཐོབ་པར་འགྱུར་ཏེ། དུས་གཉིས་པོ༌[^653]གང་ཞེ་ན།

སོ་སོའི་སྐྱེ་བོའི་ས་དང་། མཐོང་བའི་སའོ། །

རྣམ་པ་བཞི་པོ་གང་ཞེ་ན།

འདི་ལྟ་སྟེ། རང་བཞིན་དང་། གནས་དང་། ཀུན་ནས་སློང་བ་དང་། འབྲས་བུའོ། །
