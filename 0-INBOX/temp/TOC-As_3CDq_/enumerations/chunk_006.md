Enumeration Block 1:
ཆོས་ཀྱི་མདོའི་དབང་གིས་བྱུང་བའི་འདུ་བྱེད་འདོད་པ་ནི་རྣམ་པ་གཉིས་སུ་རིག་པར་བྱ་སྟེ། མོས་པ་དང་ལྡན་པ་དང་། བསམ་པ་དང་ལྡན་པའོ། །

Enumeration Block 2:
དེ་ལྟར་ཤེས་པར་འདོད་པའི་སེམས་ཀྱིས་ཆོས་ཉན་པ་ན་རྣམ་པ་གསུམ་གྱི་སྒོ་ནས་ཡིད་བདེ་བ་སྐྱེ་བར་འགྱུར་ཏེ། འདི་ལྟ་སྟེ། གང་ཟག་གི་དབང་གིས་བྱུང་བ་དང་།[^201] ཆོས་ཀྱི་དབང་གིས་བྱུང་བ་དང་། བདག་གི་དབང་གིས་བྱུང་བའོ། །

Enumeration Block 3:
དེ་ལྟར་སེམས་ཉམས་བདེ་བར་འགྱུར་བ༌[^203]ལ་ནི་ལྟ་བ་གསུམ་ཡོད་དེ། གང་ལ་གནས་པ་དང་། དེས་ཡོངས་སུ་ཤེས་པར་བྱ་བ་གང་ཡིན་པ་དང་། འདི་ལྟ་སྟེ། བདེན་པ་མངོན་པར་མ་རྟོགས་པ་རྣམས་མངོན་པར་རྟོགས་པར་བྱ་བའི་ཕྱིར་མངོན་པར་སྒྲུབ་པ་གང་ཡིན་པའོ། །

Enumeration Block 4:
ཡོངས་སུ་གྲུབ་ཅིང་ཡོངས་སུ་མཐར་ཐུག་པའི་རྣམ་པར་གྲོལ་བ་མ་ཐོབ་པ་ཐོབ་པར་བྱ་བ་ལ་ཆོས་གསུམ་གྱིས་མངོན་པར་ཤེས་པ་མྱུར་བར་བྱེད་དེ། འདི་ལྟ་སྟེ། ཤེས་པའི་སྟོབས་དང་། བག་ཡོད་པའི་སྟོབས་དང་། གོམས་པའི་སྟོབས་སོ། །

Enumeration Block 5:
དེ་དེ་ལྟར་ཤེས་པ་དང་མཐོང་བ་ལ་བརྟེན་པས་བསྒོམ་པ་ལ་ཞུགས་པ་ནི་མཁས་པའི་གཞི་བཞིས་སྦྱོར་བར་བྱེད་དེ། འདི་ལྟ་སྟེ། ཉེ་བར་རྟོག་པའི་གཞི་དང་། གཏོང་བ་དང་ལེན་པའི་གཞི་དང་། ཚོར་བ་རྣམས་ལས་ངེས་པར་འབྱུང་བའི་གཞི་དང་། ཐབས་ཀྱི་གཞིས་སོ། །

Enumeration Block 6:
དེ་ལྟར་མཁས་པ་ལ་ཞུགས་པ་ལ་ནི་རྟེན་དང་། བརྟེན་པའི་དོན་བཞི་ཡོད་པར་རིག་པར་བྱ་སྟེ།
