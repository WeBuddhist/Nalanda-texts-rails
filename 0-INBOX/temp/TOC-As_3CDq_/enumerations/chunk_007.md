Enumeration Block 1:
དེ་དེ་ལྟར་ཤེས་པ་དང་མཐོང་བ་ལ་བརྟེན་པས་བསྒོམ་པ་ལ་ཞུགས་པ་ནི་མཁས་པའི་གཞི་བཞིས་སྦྱོར་བར་བྱེད་དེ། འདི་ལྟ་སྟེ། ཉེ་བར་རྟོག་པའི་གཞི་དང་། གཏོང་བ་དང་ལེན་པའི་གཞི་དང་། ཚོར་བ་རྣམས་ལས་ངེས་པར་འབྱུང་བའི་གཞི་དང་། ཐབས་ཀྱི་གཞིས་སོ། །

Enumeration Block 2:
དེ་ལྟར་མཁས་པ་ལ་ཞུགས་པ་ལ་ནི་རྟེན་དང་། བརྟེན་པའི་དོན་བཞི་ཡོད་པར་རིག་པར་བྱ་སྟེ།

Enumeration Block 3:
དེ་ལ་རྣམ་པར་དག་པའི་ལམ་ཡང་རྣམ་པ་བཞིར་རིག་པར་བྱ་སྟེ།

Enumeration Block 4:
ལུས་ཐམས་ཅད་ལ་ནི་རྒྱུ་རྣམ་པ་བཞིས་འདུ་བྱེད་ཐམས་ཅད་མི་རྟག་པར་རིག་པར་བྱ་སྟེ།

Enumeration Block 5:
རྣམ་པ་བཅོ་ལྔས་ནི་འདུ་བྱེད་རྟོགས་པས་འདུ་བྱེད་ཐམས་ཅད་ལ་རྨོངས་པ་སྤོང་བར་འགྱུར་ཏེ། བཅོ་ལྔ་གང་ཞེ་ན།

Enumeration Block 6:
འཇིག་རྟེན་གཉིས་ཀྱིས་ནི་འདུ་བྱེད་ཐམས་ཅད་བསྡུས་ཏེ། སེམས་ཅན་གྱི་འཇིག་རྟེན་དང་སྣོད་ཀྱི་འཇིག་རྟེན་ནོ། །

Enumeration Block 7:
སྐྱེ་བའི་འཁོར་བ་ནི་མི་འདྲ་བ་རྣམ་པ་ལྔས་སྣོད་ཀྱི་འཁོར་བ་དང་མི་འདྲ་བར་རིག་པར་བྱ་སྟེ།

Enumeration Block 8:
བྱིས་པ་རྣམས་ནི་རྣམ་པ་ལྔས་འཁོར་བ་དེར་འཁོར་བར་འགྱུར་ཏེ། [^240]འདི་ལྟ་སྟེ། སྲེད་པའི་རྒྱུ་དང་། སྲེད་པའི་འབྲས་བུ་དང་། སྲེད་པའི་རང་བཞིན་དང་། རྒྱུ་གཅིག་ནས་གཅིག་ཏུ་བརྒྱུད་པ་དང་། རྒྱུ་གཅིག་ནས་གཅིག་ཏུ་བརྒྱུད་པ་དེ་ཉིད་ཀྱང་སྔོན་གྱི་མཐའི་སྒོ་ནས་ཐོག་མ་མེད་པའོ། །

Enumeration Block 9:
དེ་ལ་སྲེད་པ༌[^244]རང་བཞིན་གྱི་སྒོ་ནས་ནི་དེའི་རང་བཞིན་མདོར་བསྡུ་ན་རྣམ་པ་གསུམ་ཡོད་དེ། ཡང་སྲིད་པ༌[^245]སྐྱེ་བར་བྱེད་པ་དང་། དགའ་བ་དང་འདོད་ཆགས་དང་ལྡན་པ་དང་། དེ་དང་དེར་མངོན་པར་དགའ་བ་སྟེ། དེ་དག་ཀྱང་མདོར་བསྡུ་ན། སྲིད་པའི་སྲེད་པ་དང་། ཡུལ་གྱི་སྲེད་པའོ། །

Enumeration Block 10:
རྣམ་པ་ལྔས་ནི་བྱིས་པའི་འཁོར་བའི་འཆིང་བ་རྣམ་པ་ལྔ་རི༌[^248]རིག་པར་བྱ་སྟེ། འདི་ལྟ་སྟེ། གང་དུ་བཅིངས་པ་དང་། ཅིས་བཅིངས་པ་དང་། གང་བཅིངས་པ་དང་། དེ་ལྟར་བཅིངས་པ་ཡང་རྟེན་གང་གིས་ཉམས་སུ་མྱོང་བ་དང་། གང་ཉམས་སུ་མྱོང་བའོ། །

Enumeration Block 11:
འདི་གཉིས་ནི་སྲེད་པ་སྤྱོད་པའི་ལམ་ལ་རྣམ་པར་སྤྱོད་པའི་འབྲས་བུ་སྣ་ཚོགས་ཡིན་ཏེ། འདི་ལྟ་སྟེ། སེམས་སྣ་ཚོགས་དང་ལུས་སྣ་ཚོགས་སོ། །
དེ་ལ་སེམས་སྣ་ཚོགས་ནི་རྣམ་པ་གཉིས་ཏེ། རྣམ་པ་སྣ་ཚོགས་དང་། ཀུན་ནས་ཉོན་མོངས་པ་སྣ་ཚོགས་སོ། །

Enumeration Block 12:
དེ་ལ་ལུས་སྣ་ཚོགས་ཀྱང་རྣམ་པ་གཉིས་ཏེ། ལུས་ཐ་དད་པ་སྣ་ཚོགས་དང་། ལུས་གཅིག་གི་སྣ་ཚོགས་སོ། །

Enumeration Block 13:
དེ་ལ་རྣམ་པ་བཞིས་ནི་རྒྱུ་སྣ་ཚོགས་ཀྱིས་འབྲས་བུ་སྣ་ཚོགས་སྒྲུབ་པར་བྱེད་དེ། གང་དུ་སྒྲུབ་པ་དང་། ཅིས་སྒྲུབ་པ་དང་། གང་སྒྲུབ་པ་དང་། ཇི་ལྟར་སྒྲུབ་པའོ། །
