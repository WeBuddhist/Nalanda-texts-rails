Enumeration Block 1:
ཐམས་ཅད་ནི་རྣམ་པ་གཉིས་ཏེ་ཕྱོགས་གཅིག་གི་ཐམས་ཅད་དང་ཐམས་ཅད་ཀྱི་ཐམས་ཅད་དོ། །

Enumeration Block 2:
བརྗེད་ངས་པ་ནི༌[^751]རྣམ་པ་གསུམ་དུ་རིག་པར་བྱ་སྟེ། རང་བཞིན་དང་རྒྱུ་དང་འབྲས་བུའོ། །

Enumeration Block 3:
བརྗེད་ངས་པ་མེད་པ་ཡང་རྣམ་པ་གསུམ་དུ་རིག་པར་བྱ་སྟེ། རང་བཞིན་དང་། བར་དུ་གཅོད་པ་དང་། སྒྲིབ་པའོ། །

Enumeration Block 4:
སངས་རྒྱས་རྣམས་དང་། སངས་རྒྱས་ཀྱི་ཉན་ཐོས་རྣམས་ནི་རྣམ་པ་གསུམ་གྱིས་སློབ་མ་རྣམས་ལ་ཡང་དག་པའི་གདམས་ངག་སྦྱིན་པར་རིག་པར་བྱ་སྟེ། འདི་ལྟ་སྟེ། བསྡུ་བའི་གདམས་ངག་དང་། དམིགས་པ་ལ་མཐུན་མཐུན་དུ་འཛུད་པ་དང་། རང་གི་དོན་ཐོབ་པར་བྱེད་པ་སྟེ།

Enumeration Block 5:
རྣམ་པར་གྲོལ་བ་ཡོངས་སུ་སྨིན་པར་བྱ་བའི་ཤེས་རབ་ནི་རྣམ་པ་གཉིས་ཀྱིས་ཡང་དག་པར་བཙལ་བར་བྱ་སྟེ། ཚུལ་བཞིན་དུ་ཐོས་པ་དང་བསམ་པ༌[^755]ཁྱད་པར་ཅན་གྱི་ཤེས་རབ་སློབ་པའི་རྣམ་པར་གྲོལ་བ་ཡོངས་སུ་སྨིན་པར་བྱེད་པ་གང་ཡིན་པ༌[^756]དང་། སློབ་པའི་ཁྱད་པར་ཅན་གྱི་ཤེས་རབ་མི་སློབ་པའི་རྣམ་པར་གྲོལ་བ་ཡོངས་སུ་སྨིན་པར་བྱེད་པ་གང་ཡིན་པའོ། །

Enumeration Block 6:
སེམས་རྣམ་པར་གྲོལ་བ་ཡོངས་སུ་སྨིན་པ་ནི་རྣམ་པ་གཉིས་ཏེ། སློབ་པ་དང་མི་སློབ་པའོ། །

Enumeration Block 7:
དགེ་སློང་སེམས་རྣམ་པར་གྲལ་བ་ལ་ཞུགས་པ་ལ་ནི་ཆོས་ལྔ་དབེན་པ་ཡིན་ཏེ། ལྔ་གང་ཞེ་ན།
ཡང་དག་པའི་གདམས་ངག་དང་། ཞི་གནས་ཀྱི་ཡན་ལག་དང་། ལྷག་མཐོང་གི་ཡན་ལག་དང་། རྟག་ཏུ་གུས་པར་བྱེད་པ་དང་། འཇིག་རྟེན་ལས་འདས་པའི་ཤེས་རབ་བོ། །

Enumeration Block 8:
དེ་ལ་ཡང་དག་པའི་གདམས་ངག་ནི་ཡང་དག་པའི་མཛའ་བཤེས་རྣམ་པ་གསུམ་གྱིས་ཕྱེ་བ་སྟེ། སྟོན་པ་དང་། སློབ་དཔོན་ནམ་བླ་མ་དང་འདྲ་བའི་ཚངས་བ་མཚུངས་པར་སྤྱོད་པ་དང་། ཁྱིམ་པ་མཁས་པ་ཆོས་འདི་པ་རྣམས་སོ། །

Enumeration Block 9:
དེ་ལ་ལྷག་མཐོང་གི་ཡན་ལག་ནི་གཏམ་རྣམ་པ་གསུམ་ཅི་འདོད་པ་ཐོབ་པ་གང་ཡིན་པ་སྟེ། འདི་ལྟ་སྟེ། འཕགས་པའི་དང་། ཡོ་བྱད་བསྙུངས་པའི་དང་། སེམས་སྒྲིབ་པ་མེད་པ་ལ་ཕན་པར་འགྱུར་བའིའོ། །

Enumeration Block 10:
དེ་ནི་སྒོ་གསུམ་དུ་རིག་པར་བྱ་སྟེ་ཉོན་མོངས་པའི་སྒྲིབ་པ་ཐམས་ཅད་ཀྱི་སྒྲིབ་པ་མེད་པ་ལ་ཕན་པར་འགྱུར་བ་དང་། སྒྲིབ་པ་ལྔའི་སྒྲིབ་པ་མེད་པ་ལ་ཕན་པར་འགྱུར་བ་དང་། མ་རིག་པའི་སྒྲིབ་པའི་སྒྲིབ་པ་མེད་པ་ལ་ཕན་པར་འགྱུར་བའོ། །

Enumeration Block 11:
བརྩོན་འགྲུས་བརྩམས་པ་དེ་ཡང་རྣམ་པ་ལྔར་རིག་པར་བྱ་སྟེ། འདི་ལྟ་སྟེ། གོ་ཆའི་བརྩོན་འགྲུས་དང་། སྦྱོར་བའི་བརྩོན་འགྲུས་དང་། ཞུམ་པ་མེད་པའི་བརྩོན་འགྲུས་དང་། མི་བསྐྱོད་པའི་བརྩོན་འགྲུས་དང་། ཆོག་མི་ཤེས་པའི་བརྩོན་འགྲུས་སོ། །
