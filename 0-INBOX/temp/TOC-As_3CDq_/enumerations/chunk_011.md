Enumeration Block 1:
གསུམ་པོ་འདི་དག་ནི་མངོན་པར་རྟོགས་པའི་མཐའ་ལས་བྱུང་བའི་ཤེས་པ་ཡིན་ཏེ། འདི་དག་གིས་མཐོང་བ་རྣམ་པར་དག་པ་རབ་ཏུ་ཕྱེ་སྟེ། འདི་ལྟ་སྟེ། ཟག་པ་མེད་པའི་ཤེས་པ་སྐྱེ་བ་དང་མཐུན་པ་དང་། ཟག་པ་མེད་པ་དང་། ཟག་པ་མེད་པའི་རྒྱུན་ལས་བྱུང་བའོ། །

Enumeration Block 2:
དེ་ལ་མ་ལུས་པར་སྤོང་བ་ནི་རྣམ་པ་གསུམ་དུ་རིག་པར་བྱ་སྟེ། ཀུན་དུ་མི་སྤྱོད་པ་དང་། ཁམས་དང་། དངོས་པོའོ། །

Enumeration Block 3:
དངོས་པོ་ནི་གཉིས་ཏེ། ཉོན་མོངས་པའི་དངོས་པོ་དང་། སྡུག་བསྔལ་གྱི་དངོས་པོའོ། །

Enumeration Block 4:
དེ་ལ་དགྲ་བཅོམ་པ་ཉིད་ཀྱི་རྣམ་པ་ནི་དོན་དང་འབྲལ་པ༌[^405]རྣམ་པ་བཞིར་རིག་པར་བྱ་སྟེ། རང་གི་དོན་མཐར་ཕྱིན་པས་གཞན་གྱི་དོན་བྱ་བར་འོས་པའི་དོན་དང་། བདག་ཉིད་རྫོགས་པ་དང་། རིགས་པའི་དོན་ཐོབ་པར་བྱ་བའི་དོན་དང་། མ་འོངས་པའི་འདུ་བྱེད་ཀྱི་རྒྱུ་ཡང་དག་པར་བཅོམ་སྟེ་ཚེ་འདི་ལ་བདེ་བར་གནས་པའི་དོན་དང་། སློབ་པའི་ས་ལས་ཡང་དག་པར་འདས་ནས་མི་སློབ་པའི་ས་ལ་འཇུག་པའི་དོན་ཏོ། །

Enumeration Block 5:
བདག་ཏུ་སྨྲ་བ་ནི་རྒྱུ་རྣམ་པ་གཉིས་ཀྱིས་ཀུན་ནས་ཉོན་མོངས་པར་བྱེད་པ་ཡིན་ཏེ། མངོན་པར་ཞེན་པ་དང་། བག་ལ་ཉལ་གྱི་སྒོ་ནས་སོ། །

Enumeration Block 6:
དེ་ལ་རྣམ་པ་བཞིས་དངོས་པོ་ལ་ལོག་པར་ཞེན་པའི་ཕྱིར་ནི་བདག་ཏུ་ལྟ་བ་ཀུན་ནས་ཉོན་མོངས་པར་འགྱུར་ཏེ། འདི་ལྟ་སྟེ། རྒྱུ་དང་། རང་བཞིན་དང་། འབྲས་བུ་དང་། རྒྱུ་མཐུན་པའོ། །དེ་ལ་རྒྱུ་ནི་རྨོངས་པ་རྣམ་པ་གཉིས་ལས་འགྱུར་ཏེ། དངོས་པོ་ལ་རྨོངས་པ་དང་། ལྟ་བ་ལ་རྨོངས་པའོ། །

Enumeration Block 7:
མ་རིག་པའི་གནས་སྐབས་ནི་གཉིས་ཏེ་སྔ་མ་དང་ཕྱི་མའོ། །
