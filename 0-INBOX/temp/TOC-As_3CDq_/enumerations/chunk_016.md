Enumeration Block 1:
ཡན་ལག་གསུམ་གྱིས་ཡོངས་སུ་ཟིན་ན་མྱ་ངན་ལས་འདས་པ་ཡོངས་སུ་རྫོགས་པར་རིག་པར་བྱ་སྟེ། འདི་ལྟ་སྟེ། མཐུན་པའི་གདམས་ངག་དང་འདུ་བྱེད་ཐམས་ཅད་ཡང་དག་པར་བརྟགས་པ་དང་ཉོན་མོངས་པ་ཐམས་ཅད་སྤངས་པའོ། །

Enumeration Block 2:
ཡན་ལག་དེས་མྱ་ངན་ལས་འདས་པ་ནི་རྒྱུ་གསུམ་དུ་རིག་པར་བྱའོ། །
རྣམ་པ་ལྔས་སྡུག་བསྔལ་ཡོངས་སུ་ཤེས་པ་དང་། སྡུག་བསྔལ་གྱི་གནས་འདུ་བྱེད་ཐམས་ཅད་ཀྱི་ཉེས་དམིགས་མཐོང་བ་དང་། མྱ་ངན་ལ་སོགས་པའི་སྡུག་བསྔལ་ཐམས་ཅད་ལས་འདས་པའོ། །

Enumeration Block 3:
དེ་བཞིན་གཤེགས་པ་ནི་རྣམ་པ་བཞིས་འཇིག་རྟེན༌[^584]སྡང་བའི་དགྲ་མ་ཡིན་མོད་ཀྱི་འོན་ཀྱང་འཇིག་རྟེན་ནི་དགྲ་ཡིན་ནོ་སྙམ་དུ་འཛིན་ཏེ། བཞི་གང་ཞེ་ན། རིགས་པའི་དོན་སྟོན་པ་དང་། ཡང་དག་པའི་དོན་སྟོན་པ་དང་། ཕན་པའི་དོན་སྟོན་པ་དང་། ལ་ལར་ཡིད་དང་སྦྱོར་བར་མཛད་པའོ། །

Enumeration Block 4:
ཀུན་ནས་ཉོན་མོངས་པ་ནི་གཉིས་ཏེ། ལྟ་བའི་ཀུན་ནས་ཉོན་མོངས་པ་དང་། དེ་མ་ཡིན་པའི་ཉོན་མོངས་པའི་ཀུན་ནས་ཉོན་མོངས་པའོ། །

Enumeration Block 5:
ལམ་གྱི་བགྲོད་པ་གཅིག་པ་ནི་རྣམ་པ་གསུམ་དུ་རིག་པར་བྱ་སྟེ།

Enumeration Block 6:
གནས་གཉིས་ལ་སྒྲིབ་པར་བྱེད་པའི་ཡོངས་སུ་ཡི་འཆད་པ་རྣམ་པ་བཞིར་རིག་པར་བྱ་སྟེ། བཞི་གང་ཞེ་ན།
གང་གི་གནས་སྐབས་སུ་སྐྱེ་བ་དང་། གང་ལ་བརྟེན་ཏེ་སྐྱེ་བ་དང་། ཇི་ལྟར་སྐྱེ་བ་དང་། རྣམ་པ་ཇི་ལྟ་བུ་སྐྱེ་བའོ། །
