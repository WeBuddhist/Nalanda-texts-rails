Enumeration Block 1:
འདུས་ཤིང་འཁོད་པ་རྣམས་ཀྱི་ཆོས་ཀྱི་གཏམ་ནི་རྣམ་པ་གཉིས་སུ་རིག་པར་བྱ་སྟེ། རྣམ་པར་གཏན་ལ་འབེབས་པའི་གཏམ་དང་། བསྟན་པའི་གཏམ་མོ། །
Enumeration Block 2:
གདམས་ངག་རྗེས་སུ་བསྟན་པ་ནི་རྣམ་པ་བཞིས་མཐུན་པར་བྱེད་པ་ཞེས་བྱ་སྟེ། སྐྱེ་མཆེད་ཀྱི་བྱེ་བྲག་གིས་འདུ་བྱེད་རྣམས་ལ་བདག་མེད་པར་ཤེས་པའི་ལྟ་བ་རྣམ་པར་དག་པ་དང་། གནས་དང་བཅས་པའི་ཚོར་བ་འགག་པ་ལ་མངོན་པའི་ང་རྒྱལ་མེད་ཅིང་ཞི་བ་ཉིད་དུ་ལྟ་བ་རྣམ་པར་དག་པ་དང་། མ་འོངས་པའི་སྡུག་བསྔལ་ལས་ཡང་དག་པར་འདའ་བར་བྱ་བའི་ལྟ་བ་རྣམ་པར་དག་པ་དང་། ད་ལྟར་བྱུང་བའི་སྡུག་བསྔལ་ལས་ཡང་དག་པར་འདའ་བར་བྱ་བའི་ལྟ་བ་རྣམ་པར་དག་པའོ། །
Enumeration Block 3:
རིག་པ་དང་རྣམ་པར་གྲོལ་བ་མ་ཐོབ་པ་དེ་ཐོབ་པར་བྱ་བའི་ཕྱིར་ནི་ལམ་རྣམ་པ་བཞི་བསྒོམ་པར་རིག་པར་བྱ་སྟེ། འདི་ལྟ་སྟེ། དབང་པོ་བསྒོམས་པས༌[^1356]ལུས་བསྒོམ་པ་དང་། ལུས་བསྒོམས་པས༌[^1357]དྲངས་པའི༌[^1358]ལེགས་པར་སྤྱོད་པ་སྟེ། ཚུལ་ཁྲིམས་བསྒོམ་པ་གང་ཡིན་པ་དང་། ཚུལ་ཁྲིམས་བསྒོམས་པས་དྲངས་པའི་དྲན་པ་ཉེ་བར་གཞག་པའི་བྱང་ཆུབ་ཀྱི་ཡན་ལག་བསྒོམས་པས༌[^1359]སེམས་དང་། ཤེས་རབ་བསྒོམ་པ་གང་ཡིན་པའོ། །
Enumeration Block 4:
དེ་ལ་དབང་པོ་བསྒོམ་པ་ནི་རྣམ་པ་གསུམ་སྟེ། འཇིག་རྟེན་པའི་དང་། སློབ་པའི་དང་། མི་སློབ་པའི་སྟེ།
Enumeration Block 5:
དེ་བཞིན་དུ་ཚུལ་ཁྲིམས་དང་སེམས་དང་ཤེས་རབ་བསྒོམ་པ་ཡང་རྣམ་པ་གསུམ་དུ་རིག་པར་བྱ་སྟེ།
