Enumeration Block 1:
གནས་གསུམ་གྱིས་གཞི༌[^2]བསྡུ་བར་འགྱུར་ཏེ། འདི་ལྟ་སྟེ། མདོ་སྡེའི་གཞི་དང་། འདུལ་བའི་གཞི་དང་། མ་མོའི་གཞིའོ། །
Enumeration Block 2:
གནས་ཉི་ཤུ་རྩ་བཞིས་མདོ་སྡེ་ཐམས་ཅད་བསྡུ་བར་འགྱུར་ཏེ། ཉི་ཤུ་རྩ་བཞི་པོ༌[^3]གང་ཞེ་ན། འདི་ལྟ་སྟེ། སོ་སོར་ཐར་པའི་མདོ་སྡེ་དང་། གཞིའི་མདོ་སྡེ་དང་། ཉན་ཐོས་དང་ལྡན་པའི་མདོ་སྡེ་དང་། ཐེག་པ་ཆེན་པོ་དང་ལྡན་པའི་མདོ་སྡེ་དང་། མ་རྟོགས་པའི་དོན་རྟོགས་པར་བྱེད་པ་དང་། རྟོགས་པའི་དོན་ཡོངས་སུ་བྱང་བར་བྱེད་པ་དང་། དུས་ཀྱི་དང་པོར༌[^4]བྱ་བ་དང་། ཁྱད་པར་དུ་འགྲོ་བར་བྱེད་པ་དང་། ནག་པོའི་ཕྱོགས་བརྗོད་པ་དང་། དཀར་པོའི་ཕྱོགས་བརྗོད་པ་དང་། བཀྲི་བའི་དོན་དང་། ངེས་པའི་དོན་དང་། དོན་མདོར་བསྡུས་ལ་ཚིག་དང་། ཡི་གེ་རྒྱས་པ་དང་། དོན་རྒྱས་ལ་ཚིག་དང་། ཡི་གེ་མདོར་བསྡུས་པ་དང་། དོན་ཡང་མདོར་བསྡུས་ལ། ཚིག་དང་ཡི་གེ་ཡང་མདོར་བསྡུས་པ་དང་། དོན་ཡང་རྒྱས་ལ་ཚིག་དང་ཡི་གེ་ཡང་རྒྱས་པ་དང་། དོན་ཟབ་ལ་ཚིག་དང་ཡི་གེ་གསལ་བ་དང་། དོན་གསལ་ལ་ཚིག་དང་ཡི་གེ་ཟབ་པ་དང་། དོན་ཡང་ཟབ་ལ་ཚིག་དང་ཡི་གེ་ཡང་ཟབ་པ་དང་། དོན༌[^5]ཡང་གསལ་ལ་ཚིག་དང་ཡི་གེ་ཡང་གསལ་བ་དང་། མ་འོངས་པའི་ཉེས་པ་བསལ་བ་དང་། ཉེ་བར་གནས་པའི་ཉེས་པ་བསལ་བ༌[^6]དང་། ཐེ་ཚོམ་སྐྱེས་པ་བསལ་བའི༌[^7]མདོ་སྡེ་དང་། དམ་པའི་ཆོས་ཡུན་རིང་དུ་གནས་པར་བྱེད་པའི་མདོ་སྡེའོ། །
Enumeration Block 3:
གཞིའི་མདོ་སྡེ་ནི་ལུང་རྣམ་པ་བཞི་སྟེ། འདི་ལྟ་སྟེ། ཡང་དག་པར་ལྡན་པ་དང་། བར་མ་དང་། རིང་པོ་དང་། གཅིག་ལས་འཕྲོས་པའོ། །
Enumeration Block 4:
དེ་ལ་ཡན་ལག་རྣམ་པ་གསུམ་ནི་ཡོངས་སུ་གྲུབ་པ་དང་། ཡོངས་སུ་མཐར་ཐུག་པའི་ཐམས་ཅད་ལས་རྣམ་པར་གྲོལ་བ་བསྟན་པ་དང་། དེ་ཉིད་ཀྱི་ཐབས་བསྟན་པ་དང་། དེ་ཉིད་ཀྱིས༌[^26]སོ་སོ་རང་རིག་པར་བྱའོ། །
Enumeration Block 5:
བྱ་བ་དང་བཅས་པ་དང་། བྱ་བ་མེད་པའི་ཕྱིར་རྣམ་པར་གྲོལ་བ་རྣམ་པ་གསུམ་ཡོད་དེ། འཇིག་རྟེན་པའི་དང་། སློབ་པའི་དང་། མི་སློབ་པའིའོ། །
Enumeration Block 6:
རྣམ་པར་གྲོལ་བ་དེའི་སྔོན་དུ་འགྲོ་བའི་ཆོས་ནི་འདི་གཉིས་ཡིན་ཏེ། ལྟ་བའི་སྔོན་དུ་འགྲོ་བ་དང་། ལམ་གྱི་འབྲས་བུའི་སྔོན་དུ་འགྲོ་བའོ། །
Enumeration Block 7:
རྣམ་པར་གྲོལ་བ་དེ་མ་ཐོབ་པ་ཐོབ་པར་བྱ་བ་ལ་བརྟག་པའི་གཞི་རྣམ་པ་བརྒྱད་ཡོད་དེ། འདུ་བྱེད་རྣམས་ཀྱི་རོ་མྱང་བ་དང་། ཉེས་དམིགས་དང་། ངེས་པར་འབྱུང་བ་བརྟག་པ་དང་། ཐོས་པ་དང་། བསམས་པ༌[^36]དང་། སོ་སོར་བརྟག་པའི་སྟོབས་དང་། མཐོང་བ་དང་བསྒོམ་པའི་ལམ་བརྟག་པའོ། །

Enumeration Block 1:
རྣམ་པར་གྲོལ་བ་དེའི་སྔོན་དུ་འགྲོ་བའི་ཆོས་ནི་འདི་གཉིས་ཡིན་ཏེ། ལྟ་བའི་སྔོན་དུ་འགྲོ་བ་དང་། ལམ་གྱི་འབྲས་བུའི་སྔོན་དུ་འགྲོ་བའོ། །

Enumeration Block 2:
རྣམ་པར་གྲོལ་བ་དེ་མ་ཐོབ་པ་ཐོབ་པར་བྱ་བ་ལ་བརྟག་པའི་གཞི་རྣམ་པ་བརྒྱད་ཡོད་དེ། འདུ་བྱེད་རྣམས་ཀྱི་རོ་མྱང་བ་དང་། ཉེས་དམིགས་དང་། ངེས་པར་འབྱུང་བ་བརྟག་པ་དང་། ཐོས་པ་དང་། བསམས་པ༌[^36]དང་། སོ་སོར་བརྟག་པའི་སྟོབས་དང་། མཐོང་བ་དང་བསྒོམ་པའི་ལམ་བརྟག་པའོ། །

Enumeration Block 3:
འདུ་བྱེད་རྣམས་ཀྱི་ངེས་པ་ནི་བཞི་ཡོད་དེ། མི་རྟག་པར་ངེས་པ་དང་། སྡུག་བསྔལ་བར་ངེས་པ་དང་། སྟོང་པར་ངེས་པ་དང་། བདག་མེད་པར་ངེས་པའོ། །

Enumeration Block 4:
དེ་ལ་འདས་པ་དང་། མ་འོངས་པའི་འདུ་བྱེད་རྣམས་ཀྱང་རྣམ་པ་གསུམ་གྱིས་མི་རྟག་པར་རིག་པར་བྱ་ན། ད་ལྟར་བྱུང་བ་རྣམས་ལྟ་ཅི་སྨོས་ཏེ། གསུམ་གང་ཞེ་ན། མེད་པ་སྔོན་དུ་འགྲོ་བའི་ཡོད་པ་དང་། ཡོད་པ་སྔོན་དུ་འགྲོ་བའི་མེད་པ་དང་། སྐྱེ་བ་དང་འཇིག་པ་དང་ལྡན་པའོ། །

Enumeration Block 5:
དེ་ལ་སྟོང་པ་ཉིད་ནི་རྣམ་པ་གཉིས་སུ་རིག་པར་བྱ་སྟེ། གཏན་མེད་པའི་སྟོང་པ་ཉིད་དང་། ཕྱིས་བྲལ་བའི་སྟོང་པའོ། །

Enumeration Block 6:
ལྔ་པོ་འདི་དག་ནི་འབྲལ་བའི་ཕྱོགས་ཀྱི་ཁམས་ཏེ། འདི་ལྟ་སྟེ། སྤོང་བའི་ཁམས་དང་། འདོད་ཆགས་དང་བྲལ་བའི་ཁམས་དང་། འགོག་པའི་ཁམས་དང་། ཕུང་པོའི་ལྷག་མ་དང་བཅས་པའི་མྱ་ངན་ལས་འདས་པའི་ཁམས་དང་། ཕུང་པོ་ལྷག་མ་མེད་པའི་མྱ་ངན་ལས་འདས་པའི་ཁམས་སོ། །

Enumeration Block 7:
སེམས་རྣམ་པར་གྲོལ་བར་བྱ་བའི་ཕྱིར་བརྩོན་པ་ལ་གོ་རིམས་རྣམ་པ་གཉིས་ཡོད་དེ། ཤེས་པའི་གོ་རིམས་དང་། ཤེས་པའི་འབྲས་བུའི་གོ་རིམས་སོམོ། །

Enumeration Block 1:
དྲུག་པོ་འདི་དག་ནི་འཆི་བ་ཡིན་ཏེ། འདི་ལྟ་སྟེ། འདས་པའི་འཆི་བ་དང་། ད་ལྟར་བྱུང་བའི་འཆི་བ་དང་། མ་དུལ་བའི་འཆི་བ་དང་། དུལ་བའི་འཆི་བ་དང་། འདྲ་བའི་འཆི་བ་དང་། མི་འདྲ་བའི་འཆི་བའོ། །

Enumeration Block 2:
འཆི་བ་རྣམ་པ་དྲུག་པོ་དེ་དག་ཀྱང་རྣམ་པ་གཉིས་སུ་རིག་པར་བྱ་སྟེ། འདུ་བྱེད་འཇུག་པའི་ཉེས་དམིགས་དང་། འདུ་བྱེད་ལྡོག་པའི་ཕན་ཡོན་ནོ། །

Enumeration Block 3:
འདུ་བྱེད་རྣམས་ལ་བདག་མེད་པར་ཡོངས་སུ་ཤེས་པ་དང་། སྤོང་བ་ནི་རྣམ་པ་གསུམ་དུ་རིག་པར་བྱ་སྟེ། འདི་ལྟ་སྟེ། ནང་ཡོངས་སུ་ཤེས་པ་དང་། ཕྱི་རོལ༌[^110]ཡོངས་སུ་ཤེས་པ་དང་། ནང་དང་ཕྱི་རོལ་ཡོངས་སུ་ཤེས་པ་སྟེ། སྤོང་བ་ཡང་དེ་དང་འདྲའོ། །

Enumeration Block 4:
གསུམ་པོ་འདི་དག་ནི་འཁོར་བར་འཇུག་པ་ན་འཆིང་བ་ཡིན་ཏེ། དེ་དག་ལས་སེམས་རྣམ་པར་གྲོལ་བར་དཀའོ། ། དེ་ཡང་ལེགས་པར་གསུངས་པའི་ཆོས་འདུལ་བ་ལས༌[^112]རྣམ་པར་གྲོལ་བར་འགྱུར་གྱི་ཉེས་པར་བཤད་པས་ནི་མ་ཡིན་ནོ། ། གསུམ་གང་ཞེ་ན། འདི་ལྟ་སྟེ་རྗེས་སུ་ཆགས་པའི་ཀུན་ཏུ་སྦྱོར་བ་མ་གཏོགས་པ་དེ་མ་ཡིན་པའི་ཀུན་ཏུ་སྦྱོར་བ་རྣམས་ཀྱིས་ཀུན་ཏུ་སྦྱོར་བར་བྱེད་པ་སྟེ། ཟག་པ་དང་བཅས་པའི་དངོས་པོ་གང་ཡིན་པ་དང་། རྗེས་སུ་ཆགས་པའི་ཀུན་ཏུ་སྦྱོར་བས་ཀུན་ཏུ་ཆགས་པར་བྱེད་པ་སྟེ། ཟག་པ་དང་བཅས་པའི་དངོས་པོ་གང་ཡིན་པ་དང་། ཕྱི་མ་ལ་ཡང་སྲིད་པ་འབྱུང༌[^113]བའི་འདུ་བྱེད་རྣམས་མངོན་པར་འགྲུབ་པའོ། ། འཆིང་བ་རྣམ་པ་གསུམ་པོ་འདི་དག་ལས་རྒྱུ་རྣམ་པ་གསུམ་གྱིས༌[^114]སེམས་རྣམ་པར་གྲོལ་བར་དཀའ་སྟེ།

Enumeration Block 5:
རྣམ་པ་ལྔས་ཡང་སྲིད་པར་འཆིང་བས་བཅིངས་པ་ནི་ངའོ་སྙམ་པའི་ང་རྒྱལ་རྣམ་པ་ལྔ་ཀུན་ཏུ་སྤྱོད་པར་རིག་པར་བྱ་སྟེ། འདི་ལྟ་སྟེ། རྟེན་དང་། དམིགས་པ་དང་། གྲོགས་དང་། ངོ་བོ་ཉིད་དང་། རྒྱུ་དང་འབྲས་བུའོ། །

Enumeration Block 6:
འདི་གཉིས་ནི་རྣམ་པ་ལྔ་དང་ལྡན་པའི་ཀུན་ནས་ཉོན་མོངས་པ་རྒྱུ་མཚན་རྣམ་པ་ལྔ་དང་བཅས་པ་སྟེ། དེ་གཉིས་ནི་སློབ་པས་ཡོངས་སུ་ཤེས༌[^120]ནས། སྤང་བར་བྱ་བ་ཡིན་ལ་མི་སློབ་པས་ནི་སྤང་བ༌[^121]ཡིན་ཏེ། འདི་ལྟ་སྟེ། ལྟ་བའི་ཀུན་ནས་ཉོན་མོངས་པ་དང་། ང་རྒྱལ་གྱི་ཀུན་ནས་ཉོན་མོངས་པའོ། ། དེ་གཉིས་ཀྱང་རྣམ་པ་དང་། ཀུན་ནས་དཀྲིས་པ་དང་། བག་ལ་ཉལ་གྱི་སྒོ་ནས་བྱེ་བྲག་རྣམ་པ་ལྔར་འགྱུར་ཏེ། འདི་ལྟ་སྟེ། བདག་ཏུ་འཛིན་པ་དང་། བདག་གིར་འཛིན་པ་དང་། ངའོ་སྙམ་པའི་ང་རྒྱལ་དང་། མངོན་པར་ཞེན་པ་དང་། བག་ལ་ཉལ་ལོ། །

Enumeration Block 7:
དེ་དག་ཀྱང་རྣམ་པར་ཤེས་པ་དང་བཅས་པའི་ལུས་འདི་དང་། ཕྱི་རོལ་ལ་བརྟེན་ནས་རྒྱུ་མཚན་རྣམ་པ་ལྔ་ཡོད་དེ། [^122]འདི་ལྟ་སྟེ། བདག་ཏུ་འཛིན་པའི་རྒྱུ་མཚན་ནས། བག་ལ་ཉལ་གྱི་རྒྱུ་མཚན་གྱི་བར་རྣམས་སོ། ། རྒྱུ་མཚན་དེ་ཡང་རྣམ་པ་གཉིས་ཏེ། དམིགས་པའི་རྒྱུ་མཚན་དང་། རྒྱུའི་རྒྱུ་མཚན་ནོ། །

Enumeration Block 8:
བཞི་པོ་འདི་དག་ནི་སེམས་ཅན་གྱི་རིགས༌[^124]ཡིན་ཏེ། དེ་དག་ལ་ཀུན་ནས་ཉོན་མོངས་པ་འདི་རྣམ་པར་གཞག་པར་རིག་པར་བྱའོ། ། བཞི་གང་ཞེ་ན། འདི་ལྟ་སྟེ། ཕྱི་རོལ༌[^125]གྱི་མུ་སྟེགས་ཅན་རྣམས་དང་། ཆོས་འདི་པའི་སོ་སོའི་སྐྱེ་བོ་རྣམས་དང་། སློབ་པ་རྣམས་དང་། མི་སློབ་པ་རྣམས་སོ། །

Enumeration Block 1:
བཞི་པོ་འདི་དག་ནི་སེམས་ཅན་གྱི་རིགས༌[^124]ཡིན་ཏེ། དེ་དག་ལ་ཀུན་ནས་ཉོན་མོངས་པ་འདི་རྣམ་པར་གཞག་པར་རིག་པར་བྱའོ། །

བཞི་གང་ཞེ་ན།

འདི་ལྟ་སྟེ། ཕྱི་རོལ༌[^125]གྱི་མུ་སྟེགས་ཅན་རྣམས་དང་། ཆོས་འདི་པའི་སོ་སོའི་སྐྱེ་བོ་རྣམས་དང་། སློབ་པ་རྣམས་དང་། མི་སློབ་པ་རྣམས་སོ། །

Enumeration Block 2:
གསུམ་པོ་འདི་དག་ནི་ལེགས་པར་གསུངས་པའི་ཆོས་འདུལ་བའི་ཕུན་སུམ་ཚོགས་པ་ཡིན་ཏེ། གསུམ་གང་ཞེ་ན།

ནན་ཏན་དུ་སྒྲུབ་པ་ཕུན་སུམ་ཚོགས་པ་དང་། འབྲས་བུ་ཕུན་སུམ་ཚོགས་པ་དང་། སྟོན་པ་ཕུན་སུམ་ཚོགས་པའོ། །

Enumeration Block 3:
ལྔ་པོ་འདི་དག་ནི་འདུ་བྱེད་རྣམས་ལ་མི་རྟག་པའི་འདུ་ཤེས་སྒོམ་པའི་རྣམ་པ་སྟེ། འདི་ལྟ་སྟེ། མི་རྟག་པ་དང་། མི་བརྟན་པ་དང་། ཐེར་ཟུག་མ་ཡིན་པ་དང་། ཡིད་བརྟན་དུ་མི་རུང་བ་དང་། འགྱུར་བའི་ཆོས་ཅན་ནོ། །

Enumeration Block 4:
གསུམ་པོ་འདི་དག་ནི་བྱིས་པ་རྣམས་ཀྱི་བྱིས་པའི་རྟགས་ཡིན་ནོ།[^146] །

གསུམ་གང་ཞེ་ན།

Enumeration Block 5:
འཕགས་པའི་ཤེས་རབ་ཀྱི་མིག་ནི་རྣམ་པ་གཉིས་ཀྱིས་རྣམ་པར་དག་པར་འགྱུར་བར་རིག་པར་བྱ་སྟེ།

Enumeration Block 6:
རྡུལ་མེད་ཅིང་དྲི་མ་དང་བྲལ་བ་དེས་ཆོས་རྣམས་ལ་ཆོས་ཀྱི་མིག་ཐོབ་པའི་མོད་ལ་ཕན་ཡོན་བཅུ་འབྱུང་བར་རིག་པར་བྱ་སྟེ། བཅུ་གང་ཞེ་ན།

Enumeration Block 7:
ཤེས་པ་དགུ་པོ་འདི་དག་ནི་འདུ་བྱེད་རྣམས་ཡོངས་སུ་ཤེས་པ་དང་། ཡང་དག་པར་འདའ་བར་འགྱུར་བ་སྟེ། འདི་ལྟ་སྟེ། འདུ་བྱེད་རྣམས་ཀྱི་འཇུག་པ་ཤེས་པ་དང་། ལྡོག་པ་ཤེས་པ་དང་། ཀུན་ནས་ཉོན་མོངས་པའི་རྒྱུ་ཤེས་པ་དང་། རྣམ་པར་བྱང་བའི་རྒྱུ་ཤེས་པ་དང་། རྣམ་པར་བྱང་བ་ཤེས་པ་དང་། སྡུག་བསྔལ་ཤེས་པ་དང་། ཀུན་འབྱུང་བ་དང་། འགོག་པ་དང་། ལམ་ཤེས་པའོ། །

Enumeration Block 8:
རྣལ་འབྱོར་པ་ནི་གནས་གསུམ་གྱིས་འདུ་བྱེད་ཐམས་ཅད་ལ་བརྗེད་ངས་པ་མེད་པར་གནས་ཏེ། གསུམ་གང་ཞེ་ན།

Enumeration Block 1:
ཤེས་པ་དགུ་པོ་འདི་དག་ནི་འདུ་བྱེད་རྣམས་ཡོངས་སུ་ཤེས་པ་དང་། ཡང་དག་པར་འདའ་བར་འགྱུར་བ་སྟེ། འདི་ལྟ་སྟེ། འདུ་བྱེད་རྣམས་ཀྱི་འཇུག་པ་ཤེས་པ་དང་། ལྡོག་པ་ཤེས་པ་དང་། ཀུན་ནས་ཉོན་མོངས་པའི་རྒྱུ་ཤེས་པ་དང་། རྣམ་པར་བྱང་བའི་རྒྱུ་ཤེས་པ་དང་། རྣམ་པར་བྱང་བ་ཤེས་པ་དང་། སྡུག་བསྔལ་ཤེས་པ་དང་། ཀུན་འབྱུང་བ་དང་། འགོག་པ་དང་། ལམ་ཤེས་པའོ། །
Enumeration Block 2:
གསུམ་པོ་འདི་དག་ནི་ཉོན་མོངས་པའི་རྣམ་གྲངས་ཡིན་ཏེ། དེ་དག་ནི་ཕལ་ཆེར་ཀུན་ནས་ཉོན་མོངས་པའི་ཕྱོགས་སུ་བསྟན་པར་འགྱུར་བ་སྟེ། འདི་ལྟ་སྟེ། འདོད་ཆགས་ཀྱི་རྣམ་གྲངས་དང་། ཞེ་སྡང་གི་རྣམ་གྲངས་དང་། གཏི་མུག་གི་རྣམ་གྲངས་སོ། །
Enumeration Block 3:
བཞི་པོ་འདི་དག་ནི་འདུ་བྱེད་རྣམས་ལ་ཚུལ་བཞིན་དུ་བརྩོན་པའི་ཁྱད་པར་དུ་འགྲོ་བ་ཡིན་ནོ། །ཁྱད་པར་དུ་འགྲོ་བའི་འདུ་ཤེས་ནི་གསུམ་སྟེ། འདི་ལྟ་སྟེ། མ་ཐོབ་པ་ཐོབ་པ་དང་། མ་རྟོགས་པ་རྟོགས་པ་དང་། མངོན་སུམ་དུ་མ་བྱས་པ་མངོན་སུམ་དུ་བྱེད་པ་དང་། ཚེ་འདི་ལ་བདེ་བར་གནས་པ་ནི་ཁྱད་པར་དུ༌[^172]འགྲོ་བ་བཞི་པའོ། །
Enumeration Block 4:
དེ་ལ་གསུམ་པོ་འདི་དག་ནི་ཁྱད་པར་དུ་འགྲོ་བའི་འདུ་ཤེས་ཡིན་ཏེ། འདི་ལྟ་སྟེ། འདུ་བྱེད་རྣམས་ལ་མི་མཐུན་པར་འདུ་ཤེས་པ་དང་། ཉེས་དམིགས་སུ་འདུ་ཤེས་པ་དང་། ཡང་དག་པའི་དོན་དུ་འདུ་ཤེས་པའོ། །མི་མཐུན་པའི་འདུ་ཤེས་ནི་རྣམ་པ་བཞི་སྟེ། འདུ་ཤེས༌[^177]རྣམས་ལ་ནད་དང་། འབྲས་དང་། ཟུག་རྔུ་དང་། སྡིག་པ་ཡིན་པར་ཡིད་ལ་བྱེད་པ་སྟེ།
Enumeration Block 5:
དེ་ལ་ཉེས་དམིགས་སུ་འདུ་ཤེས་པ་ནི་རྣམ་པ་གཉིས་ཏེ། འདི་ལྟ་སྟེ། འདུ་བྱེད་རྣམས་ལ་མི་རྟག་པའམ་སྡུག་བསྔལ་བར་ཡིད་ལ་བྱེད་པའོ། །དེ་ལ་ཡང་དག་པའི་དོན་དུ་འདུ་ཤེས་པ་ཡང་རྣམ་པ་གཉིས་ཁོ་ན་སྟེ། འདུ་བྱེད་རྣམས་ལ་སྟོང་པའམ་བདག་མེད་པར་ཡིད་ལ་བྱེད་པའོ། །
Enumeration Block 6:
རྣམ་པར་ཐར་པའི་སྒོ་གསུམ་གྱི་སྒོ་ནས་ཆོས་ཀྱི་མདོ་བཞི་རྣམ་པར་གཞག་པར་རིག་པར་བྱའོ། །འདི་ལྟ་སྟེ། སྟོང་པ་ཉིད་དང་། སྨོན་པ་མེད་པ་དང་། མཆན་མ་མེད་པའོ། །
Enumeration Block 7:
ཆོས་ཀྱི་མདོའི་དབང་གིས་བྱུང་བའི་འདུ་བྱེད་འདོད་པ་ནི་རྣམ་པ་གཉིས་སུ་རིག་པར་བྱ་སྟེ། མོས་པ་དང་ལྡན་པ་དང་། བསམ་པ་དང་ལྡན་པའོ། །

Enumeration Block 1:
ཆོས་ཀྱི་མདོའི་དབང་གིས་བྱུང་བའི་འདུ་བྱེད་འདོད་པ་ནི་རྣམ་པ་གཉིས་སུ་རིག་པར་བྱ་སྟེ། མོས་པ་དང་ལྡན་པ་དང་། བསམ་པ་དང་ལྡན་པའོ། །

Enumeration Block 2:
དེ་ལྟར་ཤེས་པར་འདོད་པའི་སེམས་ཀྱིས་ཆོས་ཉན་པ་ན་རྣམ་པ་གསུམ་གྱི་སྒོ་ནས་ཡིད་བདེ་བ་སྐྱེ་བར་འགྱུར་ཏེ། འདི་ལྟ་སྟེ། གང་ཟག་གི་དབང་གིས་བྱུང་བ་དང་།[^201] ཆོས་ཀྱི་དབང་གིས་བྱུང་བ་དང་། བདག་གི་དབང་གིས་བྱུང་བའོ། །

Enumeration Block 3:
དེ་ལྟར་སེམས་ཉམས་བདེ་བར་འགྱུར་བ༌[^203]ལ་ནི་ལྟ་བ་གསུམ་ཡོད་དེ། གང་ལ་གནས་པ་དང་། དེས་ཡོངས་སུ་ཤེས་པར་བྱ་བ་གང་ཡིན་པ་དང་། འདི་ལྟ་སྟེ། བདེན་པ་མངོན་པར་མ་རྟོགས་པ་རྣམས་མངོན་པར་རྟོགས་པར་བྱ་བའི་ཕྱིར་མངོན་པར་སྒྲུབ་པ་གང་ཡིན་པའོ། །

Enumeration Block 4:
ཡོངས་སུ་གྲུབ་ཅིང་ཡོངས་སུ་མཐར་ཐུག་པའི་རྣམ་པར་གྲོལ་བ་མ་ཐོབ་པ་ཐོབ་པར་བྱ་བ་ལ་ཆོས་གསུམ་གྱིས་མངོན་པར་ཤེས་པ་མྱུར་བར་བྱེད་དེ། འདི་ལྟ་སྟེ། ཤེས་པའི་སྟོབས་དང་། བག་ཡོད་པའི་སྟོབས་དང་། གོམས་པའི་སྟོབས་སོ། །

Enumeration Block 5:
དེ་དེ་ལྟར་ཤེས་པ་དང་མཐོང་བ་ལ་བརྟེན་པས་བསྒོམ་པ་ལ་ཞུགས་པ་ནི་མཁས་པའི་གཞི་བཞིས་སྦྱོར་བར་བྱེད་དེ། འདི་ལྟ་སྟེ། ཉེ་བར་རྟོག་པའི་གཞི་དང་། གཏོང་བ་དང་ལེན་པའི་གཞི་དང་། ཚོར་བ་རྣམས་ལས་ངེས་པར་འབྱུང་བའི་གཞི་དང་། ཐབས་ཀྱི་གཞིས་སོ། །

Enumeration Block 6:
དེ་ལྟར་མཁས་པ་ལ་ཞུགས་པ་ལ་ནི་རྟེན་དང་། བརྟེན་པའི་དོན་བཞི་ཡོད་པར་རིག་པར་བྱ་སྟེ།

Enumeration Block 1:
དེ་དེ་ལྟར་ཤེས་པ་དང་མཐོང་བ་ལ་བརྟེན་པས་བསྒོམ་པ་ལ་ཞུགས་པ་ནི་མཁས་པའི་གཞི་བཞིས་སྦྱོར་བར་བྱེད་དེ། འདི་ལྟ་སྟེ། ཉེ་བར་རྟོག་པའི་གཞི་དང་། གཏོང་བ་དང་ལེན་པའི་གཞི་དང་། ཚོར་བ་རྣམས་ལས་ངེས་པར་འབྱུང་བའི་གཞི་དང་། ཐབས་ཀྱི་གཞིས་སོ། །

Enumeration Block 2:
དེ་ལྟར་མཁས་པ་ལ་ཞུགས་པ་ལ་ནི་རྟེན་དང་། བརྟེན་པའི་དོན་བཞི་ཡོད་པར་རིག་པར་བྱ་སྟེ།

Enumeration Block 3:
དེ་ལ་རྣམ་པར་དག་པའི་ལམ་ཡང་རྣམ་པ་བཞིར་རིག་པར་བྱ་སྟེ།

Enumeration Block 4:
ལུས་ཐམས་ཅད་ལ་ནི་རྒྱུ་རྣམ་པ་བཞིས་འདུ་བྱེད་ཐམས་ཅད་མི་རྟག་པར་རིག་པར་བྱ་སྟེ།

Enumeration Block 5:
རྣམ་པ་བཅོ་ལྔས་ནི་འདུ་བྱེད་རྟོགས་པས་འདུ་བྱེད་ཐམས་ཅད་ལ་རྨོངས་པ་སྤོང་བར་འགྱུར་ཏེ། བཅོ་ལྔ་གང་ཞེ་ན།

Enumeration Block 6:
འཇིག་རྟེན་གཉིས་ཀྱིས་ནི་འདུ་བྱེད་ཐམས་ཅད་བསྡུས་ཏེ། སེམས་ཅན་གྱི་འཇིག་རྟེན་དང་སྣོད་ཀྱི་འཇིག་རྟེན་ནོ། །

Enumeration Block 7:
སྐྱེ་བའི་འཁོར་བ་ནི་མི་འདྲ་བ་རྣམ་པ་ལྔས་སྣོད་ཀྱི་འཁོར་བ་དང་མི་འདྲ་བར་རིག་པར་བྱ་སྟེ།

Enumeration Block 8:

Enumeration Block 13:

Enumeration Block 3:

Enumeration Block 4:
བྱིས་པ་འདུ་བྱེད་མི་རྟག་པར་མི་ཤེས་པ་འཇིག་ཚོགས་ལ་ལྟ་བ་ལ་བརྟེན་ནས་རྒྱུན་ཕྱོགས་སུ་ཞུགས་པ་ནི་རྣམ་པ་ལྔས་རྒྱུན་ཕྱོགས་སུ་ཁྱེར་བར་རིག་པར་བྱ་སྟེ། འདི་ལྟ་སྟེ། གང་དུ་ཁྱེར་བ་དང་། ཅིས་ཁྱེར་བ་དང་། གང་ལ་བརྟེན་ཏེ་ཁྱེར་བ་དང་། ཇི་ལྟར་ཁྱེར་བ་དང་། [^262]ཁྱེར་ན་ཅིར་འགྱུར་བའོ། །

Enumeration Block 6:
རྣམ་པ་ཐམས་ཅད་དུ་མི་རྟག་པའི་འདུ་ཤེས་བསྒོམ་པའི་བྱེ་བྲག་ནི་རྣམ་པ་བཞི་ཡོད་པར་རིག་པར་བྱ་སྟེ། བཞི་གང་ཞེ་ན། འབྲས་བུ་དང་། རང་བཞིན་དང་། རྣམ་པ་དང་། ཐབས་སོ། །

Enumeration Block 1:
འདི་གཉིས་ནི་རྣམ་པར་དག་པའི་ལྷ་ཡིན་ཏེ། ཤིན་ཏུ་རྣམ་པར་དག་པ་མ་ཡིན་པ་དང་ཤིན་ཏུ་རྣམ་པར་དག་པའོ། །

Enumeration Block 2:
རྣམ་པར་མི་གཡེང་བ་ནི་གཉིས་ཏེ། རྟོག་པ་དང་བཅས་མཚན་མ་དང་བཅས་པ་དང་མཚན་མ་མེད་པའོ། །

Enumeration Block 3:

Enumeration Block 4:

Enumeration Block 5:

Enumeration Block 6:

Enumeration Block 7:
དེ་ལ་མ་ལུས་པར་སྤོང་བ་ནི་རྣམ་པ་གསུམ་དུ་རིག་པར་བྱ་སྟེ། ཀུན་དུ་མི་སྤྱོད་པ་དང་། ཁམས་དང་། དངོས་པོའོ། །

Enumeration Block 1:

ཆོས་འདི་པ་རྣམས་དང་། ཕྱི་རོལ་པ་རྣམས་ཀྱི་སྟོན་པ་རྣམས་དང་སློབ་མ་རྣམས་ནི་རྣམ་པ་ལྔས་མཐོ་བ་དང་དམའ་བར་རིག་པར་བྱ་སྟེ། འདི་ལྟ་སྟེ། གནས་པ་དང་། ཚོགས་ཡོངས་སུ་བསྐྱང་བ་དང་། འབེལ་བའི་གཏམ་རྣམ་པར་ངེས་པར་འབྱེད་པར་བྱེད་པ་དང་། ལམ་གདགས་པ་ཡང་དག་པར་བསྟན་པ་དང་། ནན་ཏན་དུ་སྒྲུབ་པའོ། །

Enumeration Block 2:
རྣམ་པ་བཞི་པོ་དེ་དག་ཀྱང་གཞི་གསུམ་གྱི་སྐབས་སུ་རིག་པར་བྱ་སྟེ། སྐྱེ་བའི་གནས་དང་། ཚོར་བ་དང་། དུས་སོ། །

Enumeration Block 3:
ཤེས་པ་ནི་གཉིས་ཏེ། ཡང་དག་པའི་ཤེས་པ་དང་། ལོག་པའི་ཤེས་པའོ། །

Enumeration Block 4:
མདོ་སྡེ་འདི༌[^563]གཉིས་ཡོད་དེ། ཆེད་དུ་བསྟན་པ་དང་། ཆེད་དུ་བསྟན་པ་མ་ཡིན་པའི་མདོ་སྡེའོ། །

Enumeration Block 5:
ཡན་ལག་གསུམ་གྱིས་ཡོངས་སུ་ཟིན་ན་མྱ་ངན་ལས་འདས་པ་ཡོངས་སུ་རྫོགས་པར་རིག་པར་བྱ་སྟེ། འདི་ལྟ་སྟེ། མཐུན་པའི་གདམས་ངག་དང་འདུ་བྱེད་ཐམས་ཅད་ཡང་དག་པར་བརྟགས་པ་དང་ཉོན་མོངས་པ་ཐམས་ཅད་སྤངས་པའོ། །

Enumeration Block 1:
ཡན་ལག་གསུམ་གྱིས་ཡོངས་སུ་ཟིན་ན་མྱ་ངན་ལས་འདས་པ་ཡོངས་སུ་རྫོགས་པར་རིག་པར་བྱ་སྟེ། འདི་ལྟ་སྟེ། མཐུན་པའི་གདམས་ངག་དང་འདུ་བྱེད་ཐམས་ཅད་ཡང་དག་པར་བརྟགས་པ་དང་ཉོན་མོངས་པ་ཐམས་ཅད་སྤངས་པའོ། །

Enumeration Block 2:
ཡན་ལག་དེས་མྱ་ངན་ལས་འདས་པ་ནི་རྒྱུ་གསུམ་དུ་རིག་པར་བྱའོ། །
རྣམ་པ་ལྔས་སྡུག་བསྔལ་ཡོངས་སུ་ཤེས་པ་དང་། སྡུག་བསྔལ་གྱི་གནས་འདུ་བྱེད་ཐམས་ཅད་ཀྱི་ཉེས་དམིགས་མཐོང་བ་དང་། མྱ་ངན་ལ་སོགས་པའི་སྡུག་བསྔལ་ཐམས་ཅད་ལས་འདས་པའོ། །

Enumeration Block 3:
དེ་བཞིན་གཤེགས་པ་ནི་རྣམ་པ་བཞིས་འཇིག་རྟེན༌[^584]སྡང་བའི་དགྲ་མ་ཡིན་མོད་ཀྱི་འོན་ཀྱང་འཇིག་རྟེན་ནི་དགྲ་ཡིན་ནོ་སྙམ་དུ་འཛིན་ཏེ། བཞི་གང་ཞེ་ན། རིགས་པའི་དོན་སྟོན་པ་དང་། ཡང་དག་པའི་དོན་སྟོན་པ་དང་། ཕན་པའི་དོན་སྟོན་པ་དང་། ལ་ལར་ཡིད་དང་སྦྱོར་བར་མཛད་པའོ། །

Enumeration Block 4:
ཀུན་ནས་ཉོན་མོངས་པ་ནི་གཉིས་ཏེ། ལྟ་བའི་ཀུན་ནས་ཉོན་མོངས་པ་དང་། དེ་མ་ཡིན་པའི་ཉོན་མོངས་པའི་ཀུན་ནས་ཉོན་མོངས་པའོ། །

Enumeration Block 5:
ལམ་གྱི་བགྲོད་པ་གཅིག་པ་ནི་རྣམ་པ་གསུམ་དུ་རིག་པར་བྱ་སྟེ།

Enumeration Block 6:
གནས་གཉིས་ལ་སྒྲིབ་པར་བྱེད་པའི་ཡོངས་སུ་ཡི་འཆད་པ་རྣམ་པ་བཞིར་རིག་པར་བྱ་སྟེ། བཞི་གང་ཞེ་ན།
གང་གི་གནས་སྐབས་སུ་སྐྱེ་བ་དང་། གང་ལ་བརྟེན་ཏེ་སྐྱེ་བ་དང་། ཇི་ལྟར་སྐྱེ་བ་དང་། རྣམ་པ་ཇི་ལྟ་བུ་སྐྱེ་བའོ། །

Enumeration Block 1:
འདི་གཉིས་ནི་འདུས་བྱས་དང་། འདུས་མ་བྱས་པ་སྟེ། དེ་ལ་འདུས་བྱས་ཀྱི་མི་རྟག་པ་ནི་འདུས་བྱས་ཀྱི་མཚན་ཉིད་གསུམ་གྱིས་ཤེས་པར་འགྱུར་ཏེ། འདི་ལྟ་སྟེ། སྐྱེ་བ་དང་འཇིག་པ་དང་གནས་པ་ལས་གཞན་དུ་འགྱུར་བའོ། །

མཚན་ཉིད་གསུམ་པོ་དེ་དག་ཀྱང་འདུ་བྱེད་ཀྱི་རྒྱུན་གཉིས་ལ་བརྟེན་ནས་ཤེས་པར་འགྱུར་ཏེ། འདི་ལྟ་སྟེ། ཚེ་རབས་གཅིག་ནས་གཅིག་ཏུ་བརྒྱུད་པའི་རྒྱུན་དང་། སྐད་ཅིག་པ་གཅིག་ནས་གཅིག་ཏུ་བརྒྱུད་པའི་རྒྱུན་ནོ། །
Enumeration Block 2:
གཞན་དུ་འགྱུར་བ་ནི་གཉིས་ཏེ། ཐ་དད་པའི་གཞན་དུ་འགྱུར་བ་དང་། ཐ་དད་པར་འགྱུར་བའི་གཞན་དུ་འགྱུར་བའོ། །
Enumeration Block 3:
འདི་གཉིས་ནི་བདག་བསྟོད་པ་དང་། གཞན་སྨོད་པ་སྟེ། འདི་ལྟ་སྟེ། ཚིག་ཙམ་གྱིས་བྱེད་པ་དང་། སྟོན་ཅིང་ནན་ཏན་དུ་སྒྲུབ་པས༌[^642]བྱེད་པའོ། །
Enumeration Block 4:
བླ་ན་མེད་པ་ནི་གསུམ་སྟེ། འདི་ལྟ་སྟེ། ཤེས་པ་བླ་ན་མེད་པ་དང་། ལམ་བླ་ན་མེད་པ་དང་། རྣམ་པར་གྲོལ་བ་བླ་ན་མེད་པའོ། །
Enumeration Block 5:
བྱང་ཆུབ་ཀྱི་ཕྱོགས་དང་མཐུན་པ་ལ་བརྟེན་པ་འདུ་བྱེད་རྣམས་རབ་ཏུ་རྣམ་པར་འབྱེད་པ་ན་དུས་གཉིས་སུ་རྣམ་པ་བཞིས་འཇིག་ཚོགས་ལ་ལྟ་བ་ཡོངས་སུ་ཤེས་ན་དུས་གཉིས་ཀྱི་རྗེས་ཐོགས་སུ་ཟག་པ་ཟད་པ་ཐོབ་པར་འགྱུར་ཏེ། དུས་གཉིས་པོ༌[^653]གང་ཞེ་ན།

སོ་སོའི་སྐྱེ་བོའི་ས་དང་། མཐོང་བའི་སའོ། །

རྣམ་པ་བཞི་པོ་གང་ཞེ་ན།

འདི་ལྟ་སྟེ། རང་བཞིན་དང་། གནས་དང་། ཀུན་ནས་སློང་བ་དང་། འབྲས་བུའོ། །

Enumeration Block 1:
དུས་གཉིས་པོ༌[^653]གང་ཞེ་ན།
སོ་སོའི་སྐྱེ་བོའི་ས་དང་། མཐོང་བའི་སའོ། །
རྣམ་པ་བཞི་པོ་གང་ཞེ་ན།
འདི་ལྟ་སྟེ། རང་བཞིན་དང་། གནས་དང་། ཀུན་ནས་སློང་བ་དང་། འབྲས་བུའོ། །
Enumeration Block 2:
དེ་ལ་འབྲས་བུ་ནི་དུས་སྐབས་གསུམ་དུ་འཇིག་ཚོགས་ལ་ལྟ་བས་སྒྲིབ་པར༌[^654]བྱེད་པ་སྟེ། འདི་ལྟ་སྟེ། བདག་མེད་པ་ལས་བརྩམས་ནས་ཆོས་ལ་རྟོག་པའི་བཟོད་པའི་དུས་དང་། མངོན་པར་རྟོགས་པའི་དུས་དང་། དགྲ་བཅོམ་པ་ཉིད་འཐོབ་པའི༌[^655]དུས་ཀྱི་ཚེའོ། །
Enumeration Block 3:
འདུ་བྱེད་རྣམས་ལ་ནི་རྣམ་པ་ལྔས་ཚུལ་བཞིན་དུ་འདྲི་ཞིང་ལན་འདེབས་ཏེ། ལྔ་གང་ཞེ་ན།
རང་བཞིན་དང་། ལྡོག་པ་དང་འཇུག་པའི་རྩ་བ་དང་། [^660]ལྡོག་པ་དང་འཇུག་པ་དང་། ལྡོག་པ་དང་།[^661] འཇུག་པའི་ཐབས་སོ། །
Enumeration Block 4:

Enumeration Block 5:

Enumeration Block 1:
དེ་ལ་སེམས་ཅན་ནི་མདོར་བསྡུ་ན་རྣམ་པ་གཉིས་ཏེ། ཁྱིམ་པ་དང་རབ་ཏུ་བྱུང་བའོ། །

Enumeration Block 2:
འདི་གཉིས་ནི་ཁམས་རྣམས་ཀྱི་ཁམས་ཐ་དད་པ་ཡིན་ཏེ། གཉིས་གང་ཞེ་ན། གཞན་གྱི་རིགས་ཀྱིས་ཐ་དད་པ་དང་། རང་གི་རིགས་ཀྱིས་ཐ་དད་པའོ། །

Enumeration Block 3:
ཁམས་ཀྱི་སུམ་ཕྲུགས་གསུམ་དང་ངེས་པར་འབྱུང་བར་བྱེད་པའི་ཁམས་གཉིས་ནི་རྒྱུ་བཞིས་རྣམ་པར་གཞག་པར་རིག་པར་བྱ་སྟེ། བཞི་གང་ཞེ་ན། ཕྱི་རོལ་གྱི་ངེས་པར་འབྱུང་བ་མ་ཡིན་པ་དང་ངེས་པར་འབྱུང་བ་དང་། ནང་གི་ངེས་པར་འབྱུང་བ་མ་ཡིན་པ་དང་ངེས་པར་འབྱུང་བ་དང་། གཏན་དུ་ངེས་པར་འབྱུང་བ་མ་ཡིན་པ་དང་ངེས་པར་འབྱུང་བ་དང་། མངོན་པའི་ང་རྒྱལ་མེད་པའོ། །

Enumeration Block 4:
འདི་གཉིས་ནི་བྱིས་པ་རྣམས་ཀྱི་བྱིས༌[^2266]པའི་རྟགས་ཡིན་ཏེ། བདག་དང་གཞན་ལ་གནོད་པ་བྱེད་པར་ཞུགས་པ་དང་། གནས་བཞི་ལ་མི་མཁས་པའོ། །དེ་ལ་གནོད་པ་སྒྲུབ་པ་ནི་རྣམ་པ༌[^2267]བཞིར་རིག་པར་བྱ་སྟེ། བཞི་གང་ཞེ་ན། ཕ་རོལ་གྱི་བྱེ་བྲག་དང་། ནང་གི་བྱེ་བྲག་དང་། དུས་ཀྱི་བྱེ་བྲག་དང་། རྒྱུད་ཀྱི་བྱེ་བྲག་གིས་སྡུག་བསྔལ་རྣམ་པ་བཞི་སྐྱེད་པའི༌[^2268]ཕྱིར་རོ། །

Enumeration Block 1:
མདོར་བསྡུ་ན་ཚོར་བ་རྣམ་པར་ཞི་བར་འགྱུར་བ་ནི་རྣམ་པ་གསུམ་དུ་རིག་པར་བྱ་སྟེ། གོང་མ་མཉམ་པར་གཞག་པའི་ས་ལ་བརྟེན་པས། ས་འོག་མའི་ཚོར་བ་རྣམ་པར་ཞི་བར་འགྱུར་བ་དང་། རེ་ཞིག་ཀུན་དུ་མི་སྤྱོད་པས་རྣམ་པར་ཞི་བ་དང་ཕྱི་མ་ལ་གཏན་དུ་མི་འཇུག་པས་རྣམ་པར་ཞི་བའོ། །

Enumeration Block 2:
ཚོར་བའི་རྣམ་པ་ཐམས་ཅད་ལ་ནི་རྣམ་པ་བདུན་གྱིས་ཚོར་བ༌[^2308]བརྟག་པར་རིག་པར་བྱ་སྟེ། རང་བཞིན་དང་། ད་ལྟར་འཇུག་པ་དང་ལྡོག་པའི་རྒྱུ་དང་། ཚེ་ཕྱི་མ་ལ་འཇུག་པའི་རྒྱུ་དང་། ཚེ་ཕྱི་མ་ལ་མི་འཇུག་པའི་རྒྱུ་དང་། ཀུན་ནས་ཉོན་མོངས་པ་འཇུག་པའི་རྒྱུ་དང་། རྣམ་པར་བྱང་བའི་རྒྱུ་དང་། རྣམ་པར་བྱང་བའི་སྒོ་ནས་ནི་བརྟག་པའོ། །

Enumeration Block 3:
དེ་ལ༌[^2317]ཁྱིམ་པ་དང་རབ་ཏུ་བྱུང་བ་འདོད་པ་རྣམས་ལས་འདོད་ཆགས་དང་མ་བྲལ་བའི་ཉོན་མོངས་པ་ཅན་གྱི་ཚོར་བ་ནི་རྒྱུ་གསུམ་གྱིས་སྐྱེ་བར་འགྱུར་ཏེ། ལྷག་པར་ཞེན་པའི་སྟོབས་དང་། ཡིད་ལ་བྱེད་པའི་སྟོབས་དང་། ཡུལ་གྱི་སྟོབས་སོ། །

Enumeration Block 4:
ཚོར་བ་རྣམས་ཀྱི་བྱེ་བྲག་ནི་རྣམ་པ་བཅུར་རིག་པར་བྱ་སྟེ། ཡང་དག་པའི་བྱེ་བྲག་དང་། འཇུག་པའི་རྟེན་གྱི་བྱེ་བྲག་དང་། རང་གི་མཚན་ཉིད་ཀྱི་བྱེ་བྲག་དང་། ཇི་སྙེད་ཡོད་པའི་བྱེ་བྲག་དང་། རང་གི་མཚན་ཉིད་ཀྱི་རྣམ་པའི་བྱེ་བྲག་དང་། འཇུག་པའི་སྒོའི་བྱེ་བྲག་དང་། ཀུན་ནས་ཉོན་མོངས་པའི་སྒོའི་བྱེ་བྲག་དང་། མི་མཐུན་པའི་ཕྱོགས་དང་གཉེན་པོའི་བྱེ་བྲག་དང་། དུས་ཀྱི་བྱེ་བྲག་དང་། སྐད་ཅིག་པ་གཅིག་ནས་གཅིག་ཏུ་བརྒྱུད་ཅིང་འཇུག་པའི་བྱེ་བྲག་གོ། །
