## དཀར་ཆག / Table of Contents
* I. ཀླད་ཀྱི་དོན། [[༄༅༅། །རྒྱ་གར་སྐད་དུ། ཨཱརྱ་སཱ་ལི་སྟམྦ་སྱ་ཊཱི་ཀཱ། བོད་སྐད་དུ།]]
* 1. བསྡུས་པའི་དོན [[དེ་ལ་མདོ་སྡེ་འདིའི་བསྡུས་པའི་དོན་ནི། རྣམ་པ་བདུན་ཏེ། གླེང་གཞི་དང་]]
   * 1.1 གླེང་གཞི [[དེ་ལ་གླེང་གཞི་ནི་མདོ་སྡེ་འབྱུང་བའི་རྒྱུ་སྟེ། དེ་ཡང་ཡང་དག་པར་]]
   * 1.2 གླེང་བསླང་བ [[གླེང་བསླང་བ་ནི་མདོ་སྡེ་བཤད་པའི་ཕྱིར་སྐབས་དང་སྦྱར་བ་སྟེ། སྐབས་སུ་]]
   * 1.3 ཡོངས་སུ་ཤེས་པར་བྱ་བའི་དངོས་པོ [[ཡོངས་སུ་ཤེས་པར་བྱ་བའི་དངོས་པོ་གང་ཞེ་ན། རྟེན་ཅིང་འབྲེལ་བར་འབྱུང་]]
   * 1.4 ཡོངས་སུ་ཤེས་པ [[ལམ་འདི་ཉིད་ཀྱིས་དེ་ཁོ་ན་ཡོངས་སུ་ཤེས་པས་ལམ་གྱི་རང་བཞིན་གྱི་]]
   * 1.5 ཡོངས་སུ་ཤེས་པའི་འབྲས་བུ [[ཡོངས་སུ༌[^1]ཤེས་པའི་འབྲས་བུ་ནི་རྣམ་པ་གཉིས་ཏེ། བླ་ན་ཡོད་པ༌[^2]དང་]]
      * 1.5.1 བླ་ན་ཡོད་པ [[དེ་ལ་བླ་ན་ཡོད་པ་ནི་ཉན་ཐོས་རྣམས་ཀྱི་དགེ་སྦྱོང་གི༌[^3]འབྲས་བུ་]]
      * 1.5.2 བླ་ན་མེད་པ [[བླ་ན་མེད་པ་ནི་སངས་རྒྱས་ཉིད་དེ། དེ་གཉིས་ཀྱིས་ནི་བླང་བར་བྱ་]]
   * 1.6 དེ་ཇི་ལྟར་ཡོངས་སུ་ཤེས་པར་བྱ་བ [[ཇི་ལྟར་དེ་ཡོངས་སུ་ཤེས་པར་བྱ་ཞེ་ན། དོན་དམ་པ་དང་ཀུན་རྫོབ་]]
   * 1.7 མདོ་སྡེའི་དགོས་པ [[དགོས་པ་ནི་སྒྲིབ་པ་སྤང་བ་དང་། མི་གནས་པའི་མྱ་ངན་ལས་འདས་]]
      * 1.7.1 མི་གནས་པའི་མྱ་ངན་ལས་འདས་པའི་ལམ་དུ་འཇུག་པ [[མི་གནས་པའི་མྱ་ངན་ལས་འདས་པའི་ལམ་ནི། མདོར་ན་བྱང་ཆུབ་སེམས་དཔའ་]]
      * 1.7.2 སྒྲིབ་པ་སྤང་བ [[ལམ་དེས་ཀྱང་བྱང་ཆུབ་སེམས་དཔའ་རྣམས་ཀྱི་སྒྲིབ་པ་གཉིས་ཡང་དག་པར་བདེ་]]
* 2. དགོས་པ [[དགོས་པ༌[^6]བརྗོད་པ་དེ་ཡང་ཉན་པ༌[^7]དག་གུས་པར་ཉན་པ་དང་། ལེན་]]
* 3. ཚིག་གི་དོན་དང་མཚམས་སྦྱར་བ་དང་བརྒལ་བའི་ལན [[ཚིག་གི་དོན་དང་། མཚམས་སྦྱར་བ་དང་། བརྒལ་བའི་ལན་བརྗོད་པར་བྱ་]]
   * 3.1 གླེང་གཞི [[དེ་ལ་འདི་སྐད་ཅེས་བྱ་བ་འདིས་ནི།[^9] གསོལ་བ་བཏབ་ནས་ཡང་དག་པར་]]
   * 3.2 གླེང་བསླང་བ [[ད༌[^30]ནི་དེའི་ཚེ་ན་ཞེས་བྱ་བ་ལ་སོགས་པས་གླེང་བསླང་བ་བཤད་དོ།]]
   * 3.3 ཡོངས་སུ་ཤེས་པར་བྱ་བའི་དངོས་པོ [[ད་ནི་འཕགས་པ་བྱམས་པས་འདི་ལ་བཅོམ་ལྡན་འདས་ཞེས་བྱ་བ་ལ་སོགས་]]
   * 3.4 ཡོངས་སུ་ཤེས་པ་དང་དེའི་འབྲས་བུ་བླ་ན་ཡོད་པ [[ད་ནི་ཡོངས་སུ་ཤེས་པ་དང་། དེའི་འབྲས་བུ་བླ་ན་ཡོད་པ་བསྟན་]]
      * 3.4.1 འབྲས་བུའི་ཆོས [[འདུས་བྱས་དང་འདུས་མ་བྱས་ཀྱི་བྱེ་བྲག་གིས་འབྲས་བུའི༌[^58]ཆོས་ཀྱང་རྣམ་པ་]]
         * 3.4.1.1 འདུས་བྱས [[དེ་ལ་འདུས་བྱས་ནི་དགེ་སྦྱོང་གི་འབྲས་བུ་བཞི་སྟེ། རྣམ་པར་གྲོལ་བའི་]]
         * 3.4.1.2 འདུས་མ་བྱས [[འདུས་མ་བྱས་ནི་ཉོན་མོངས་པ་སྤངས་པའི་མཚན་ཉིད་མྱ་ངན་ལས་འདས་པའོ།]]
      * 3.4.2 སྒྲུབ་པའི་ཆོས [[དེ་ལ་དེ་ཁོ་ན་མ་ནོར་བའི་རང་བཞིན་དུ་རྟོག་པ་ནི་ཡང་དག་]]
   * 3.5 ཡོངས་སུ་ཤེས་པའི་འབྲས་བུ་བླ་ན་མེད་པ [[ད༌[^68]ནི་ཡོངས་སུ་ཤེས་པའི་འབྲས་བུ་བླ་ན་མེད་པ་སྟོན་ཏེ། སངས་རྒྱས་]]
   * 3.6 དེ་ཇི་ལྟར་ཡོངས་སུ་ཤེས་པར་བྱ་བ [[ད་ནི་བཅོམ་ལྡན་འདས་ཀྱིས་གང་ལ་དགོངས་ཏེ་གསུངས་པ་དེ་བསྟན་པ་དང་]]
      * 3.6.1 དོན་དམ་པའི་ཚུལ [[དེ་ལ་མ་རིག་པ་ལ་སོགས་པ་སྒྱུ་མ་དང་གཟུགས་བརྙན་ལ་སོགས་པ་]]
      * 3.6.2 ཀུན་རྫོབ་ཀྱི་ཚུལ [[གལ་ཏེ་རྟེན་ཅིང་འབྲེལ་བར་འབྱུང་བ་འདི་དོན་དམ་པར་རྒྱུ་དང་རྐྱེན་རྣམས་]]
         * 3.6.2.1 རྒྱུ་དང་བཅས་པ་ལས་བྱུང་བའི་མཚན་ཉིད [[དེ་ལ་རྒྱུ་དང་བཅས་རྐྱེན་དང་བཅས་ཞེས་བྱ་བ་འདིས༌[^107]ནི། མཚན་ཉིད་དང་]]
         * 3.6.2.2 མི་རྟག་པ་དུ་མའི་རྒྱུ་ལས་བྱུང་བའི་མཚན་ཉིད [[གཉིས་ཀྱི་ཕྱིར་ཞེས་བྱ་བ་ལ་སོགས་པས་ནི་མཚན་ཉིད་གཉིས་པ་སྟོན་ཏོ།]]
         * 3.6.2.3 བདག་མེད་པར་འབྱུང་བའི་མཚན་ཉིད [[མཚན་ཉིད་གསུམ་པ་བསྟན་པའི་ཕྱིར། དེ་ཡང་ཕྱིའི་དང་ནང་གི་རྣམ་པ་གཉིས་]]
            * 3.6.2.3.1 ཕྱི་རོལ་གྱི་རྟེན་ཅིང་འབྲེལ་བར་འབྱུང་བ [[འདི་ལྟ་སྟེ། ས་བོན་ལས་མྱུ་གུ་ཞེས་བྱ་བ་ལ་སོགས་པས་ནི་ཕྱི་]]
               * 3.6.2.3.1.1 རྒྱུ་དང་འབྲེལ་བ [[འདི་ལྟ་སྟེ། ས་བོན་ལས་མྱུ་གུ་ཞེས་བྱ་བ་ལ་སོགས་པས་ནི་ཕྱི་]]
                  * 3.6.2.3.1.1.1 ནུས་པའི་རྐྱེན་ལས་བྱུང་བའི་མཚན་ཉིད [[འདི་ལྟ་སྟེ། ས་བོན་ལས་མྱུ་གུ་ཞེས་བྱ་བ་ལ་སོགས་པས་ནི་ཕྱི་]]
                  * 3.6.2.3.1.1.2 བྱེད་པ་མེད་པའི་རྐྱེན་ལས་བྱུང་བའི་མཚན་ཉིད [[དེ་ལ་ས་བོན་ནི་འདི་སྙམ་དུ་བདག་གིས་མྱུ་གུ་མངོན་པར་བསྒྲུབ་པོ༌]]
               * 3.6.2.3.1.2 རྐྱེན་དང་འབྲེལ་བ [[དེ་ལ་སའི་ཁམས་ནི་ས་བོན་བརྟེན་པའི་བྱ་བ་བྱེད་དོ་ཞེས་བྱ་བ་]]
                  * 3.6.2.3.1.2.1 ནུས་པའི་རྐྱེན་ལས་བྱུང་བའི་མཚན་ཉིད [[དེ་ལ་སའི་ཁམས་ནི་ས་བོན་བརྟེན་པའི་བྱ་བ་བྱེད་དོ་ཞེས་བྱ་བ་]]
                  * 3.6.2.3.1.2.2 བྱེད་པ་མེད་པའི་རྐྱེན་ལས་བྱུང་བའི་མཚན་ཉིད [[སའི་ཁམས་ཀྱང་འདི་སྙམ་དུ་བདག་གིས་ས་བོན་བརྟེན་པའི་བྱ་བ་བྱའོ་སྙམ་]]
               * 3.6.2.3.1.3 ལྡོག་པའི་སྒོ་ནས་བསྩལ་བ [[དེ་ལྟར་མཚན་ཉིད་རྣམ་པ་ལྔ་བསྟན་པས་རྗེས་སུ་འགྲོ་བའི་སྒོ་ནས་མུ་]]
