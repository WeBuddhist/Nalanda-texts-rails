## དཀར་ཆག / Table of Contents

* I. ཀླད་ཀྱི་དོན། [[༄༅༅། །རྒྱ་གར་སྐད་དུ། ཨཱརྱ་སནྡྷི་ནིར་མོ་ཙ]]
* 1. དང་པོ་ [[དགོངས་པ་ངེས་པར་འགྲེལ་པ་ཐེག་པ་ཆེན་པོའི་མདོའི་ག]]
   * 1.1 དོན་དམ་པའི་མཚན་ཉིད་ལྔ [[དེ་ལ་བཅོམ་ལྡན་འདས་ཀྱིས་དོན་དམ་པའི་མཚན་ཉིད་ལྔ་བསྟན་ཏེ། དོན་དམ་པའི་མཚན་ཉིད་ལྔ་ནི།]]
   * 1.2 གཞལ་མེད་ཁང་གི་བསྔགས་པ [[དགོངས་པ་ངེས་པར་འགྲེལ་པའི་དོན་ལས་གཞལ་མེད་ཁང་གི་བསྔགས་པ་ནི་རྣམ་པ་བཅོ་བརྒྱད་དུ]]
   * 1.3 སངས་རྒྱས་ཀྱི་བསྔགས་པ [[སངས་རྒྱས་ཀྱི་བསྔགས་པ་ནི་བཅོམ་ལྡན་འདས་ཀྱི༌[^18]སྤངས་པ་དང་ཡེ་ཤེས་བླ་ན་མེད་པ་ཉིད་ཀྱིས]]
      * 1.3.1 ཡན་ལག་གཅིག་ལེགས་པར་ཐུགས་སུ་ཆུད་པའི་བློ་དང་ལྡན་པ [[ལེགས་པར་ཐུགས་སུ་ཆུད་པའི་བློ་དང་ལྡན་པ་ཞེས་བྱ་བ་ནི་ཡན་ལག་གཅིག་སྟེ། བློས་ཐུགས་སུ]]
      * 1.3.2 ཡན་ལག་གཉིས་པ་སྒྲིབ་པ་མེད་པའི་རྟོགས་པ་ཐུགས་སུ་ཆུད་པ [[སྒྲིབ་པ་མེད་པའི་རྟོགས་པ་ཐུགས་སུ་ཆུད་པ་ཞེས་བྱ་བ་ནི་ཡན་ལག་གཉིས་པ་སྟེ། རྟོགས་པར]]
      * 1.3.3 ཡན་ལག་གསུམ་པ་འཇིག་རྟེན་གྱི་ཁམས་ཐམས་ཅད་དུ་ཞུགས་པའི་སྐུ་དང་ལྡན་པ [[འཇིག་རྟེན་གྱི་ཁམས་ཐམས་ཅད་དུ་ཞུགས་པའི༌[^23]སྐུ་དང་ལྡན་པ་ཞེས་བྱ་བ་ནི་ཡན་ལག་གསུམ་པ]]
      * 1.3.4 ཡན་ལག་བཞི་པ་བྱང་ཆུབ་སེམས་དཔའ་ཐམས་ཅད་ཀྱི་ཡེ་ཤེས་ཡང་དག་པར་བླངས་པ [[བྱང་ཆུབ་སེམས་དཔའ་ཐམས་ཅད་ཀྱི་ཡེ་ཤེས་ཡང་དག་པར་བླངས་པ་ཞེས་བྱ་བ་ནི་ཡན་ལག]]
   * 1.4 དེ་བཞིན་གཤེགས་པའི་ཕུན་སུམ་ཚོགས་པ [[དངོས་པོ་བསྡུ་བའི་སྒོ་ནས་ཡང་རྣམ་གྲངས་གཞན་ཏེ། དེ་བཞིན་གཤེགས་པའི་ཕུན་སུམ་ཚོགས་པ༌[^28]]
   * 1.5 ཅང་ཤེས་ཕུན་སུམ་ཚོགས་པ [[ཅང་ཤེས་དེ་ཡང་ཕུན་སུམ་ཚོགས་པ་རྣམ་པ་བཅུ་གསུམ་གྱིས་བསྟན་ཏེ། གཉིས་སུ་མེད་པ་ཕུན་སུམ]]
* 2. གཉིས་པ་རྟོག་གེ་ལ་བརྟེན་ནས་དོན་རྣམ་པར་སྤྱོད་པ [[གཉིས་པ༌[^55]ནི་རྟོག་གེ་ལ་བརྟེན་ནས་དོན༌[^56]རྣམ་པར་སྤྱོད༌[^57]པ། གཞན་མུ་སྟེགས་ཅན་རྣམས་ལ་]]
* 3. གསུམ་པ [[གསུམ་པ་ལ་ནི་མོས་པས་སྤྱོད་པའི་ས་ལ་གནས་པའི་བྱང་ཆུབ་སེམས་དཔའ་ཤིན་ཏུ་རྨོངས་པ]]
   * 3.1 བཏགས་པ་ལ་ཤིན་ཏུ་རྨོངས་པ [[བཏགས་པ༌[^80]ལ་ཤིན་ཏུ་རྨོངས་པ་ནི་ངེས་པའི་དོན་གྱི་མདོ་སྡེ་ལས་ཕྱི་རོལ་དུ་]]
   * 3.2 རིགས་པ་ལ་ཤིན་ཏུ་རྨོངས་པ [[རིགས་པ་ལ་ཤིན་ཏུ་རྨོངས་པ་ནི་གཏན་ཚིགས༌[^81]ལ་སོགས་པ་ཡན་ལག་མངོན་པར་མི་ཤེས་པའི་ཕྱིར]]
* 4. བཞི་པ [[བཞི་པ་ལ་ནི་མངོན་པའི་ང་རྒྱལ་རྣམ་པ༌[^86]གསུམ་གྱི་གཉེན་པོར་ཐམས་ཅད་དུ་རོ་གཅིག་པའི་མཚན]]
   * 4.1 གཟུང་བའི་མངོན་པའི་ང་རྒྱལ [[དེ་ལ་གཟུང་བའི་མངོན་པའི་ང་རྒྱལ་གྱི་གཉེན་པོར་བསྟན་པ་ནི། དེ་ཅིའི་ཕྱིར་ཞེ་ན།]]
   * 4.2 འཛིན་པའི་མངོན་པའི་ང་རྒྱལ [[འཛིན་པའི་མངོན་པའི་ང་རྒྱལ་གྱི་གཉེན་པོར་བསྟན་པ་ནི། རབ་འབྱོར་གཞན་ཡང་དགེ་སློང་རྣལ་འབྱོར་]]
   * 4.3 མཚན་ཉིད་རབ་ཏུ་དབྱེ་བའི་མངོན་པའི་ང་རྒྱལ [[མཚན་ཉིད་རབ་ཏུ་དབྱེ་བའི་མངོན་པའི་ང་རྒྱལ་གྱི་གཉེན་པོར་བསྟན་པ་ནི། རབ་འབྱོར་གཞན་ཡང་]]
* 5. ལྔ་པ [[ལྔ་པ་ལ་ནི་སེམས་ཀྱི་གསང་བ་ལ་ཤིན་ཏུ་རྨོངས་པ་རྣམ་པ་གསུམ་སྟེ། ངོ་བོ་ཉིད་ལ]]
   * 5.1 ངོ་བོ་ཉིད་ལ་ཤིན་ཏུ་རྨོངས་པ [[དེ་ལ་ངོ་བོ་ཉིད་ལ་ཤིན་ཏུ་རྨོངས་པའི་གཉེན་པོར་བསྟན་པ་ནི། བློ་གྲོས་ཡངས་པ]]
   * 5.2 རབ་ཏུ་དབྱེ་བ་ལ་ཤིན་ཏུ་རྨོངས་པ [[རབ་ཏུ་དབྱེ་བ་ནི་རྣམ་པ་ལྔ་སྟེ། མཚན་ཉིད་རབ་ཏུ་དབྱེ་བ་ནི་ལེན་པའི་རྣམ་པར་ཤེས]]
   * 5.3 བརྒལ་བའི་ལན་ལ་ཤིན་ཏུ་རྨོངས་པ [[བརྒལ་བའི་ལན་གྱི་རབ་ཏུ་དབྱེ་བ་ནི་ས་བོན་བསྡུས་པས་གཞན་གཉིས་ཀྱང་བསྡུས་པའི་ཕྱིར།]]
* 6. དྲུག་པ [[དྲུག་པ་ལ་ནི་དགོས་པ་དྲུག་དང་ལྡན་པའི་ཆོས་ཀྱི་མཚན་ཉིད༌[^98]བསྟན་ཏེ། གཉེན་པོའི་དགོས་པ་དང་།]]
   * 6.1 གཉེན་པོའི་དགོས་པ [[དེ་ལ་གཉེན་པོའི་དགོས་པ་ནི། ཤིན་ཏུ་རྨོངས་པ་རྣམ་པ་བཞིའི་གཉེན་པོ་སྟེ། སྒྲོ་འདོགས་པའི་]]
   * 6.2 ཀུན་ཏུ་བསྟན་པའི་དགོས་པ [[དེ་ལ་ཀུན་ཏུ་བསྟན་པའི་དགོས་པ་ནི་རྣམ་པ་བཞི་སྟེ། དོན་ཀུན་ཏུ་བསྟན་པ་དང་། ཕྱི་ཀུན]]
   * 6.3 མངོན་པར་བསྒྲུབ་པའི་དགོས་པ [[དེ་ལ་མངོན་པར་བསྒྲུབ་པའི་དགོས་པ་ནི་རྣམ་པར་ཐར་པའི་སྒོ་གསུམ་མངོན་པར་བསྒྲུབ་པའི་ཕྱིར]]
   * 6.4 ཐབས་ཀྱི་དགོས་པ [[དེ་ལ་ཐབས་ཀྱི་དགོས་པ་ནི་གང་ལ་བརྟེན་ནས་མཚན་ཉིད་གསུམ་རབ་ཏུ་ཤེས་པའོ། །]]
   * 6.5 རྟོགས་པའི་དགོས་པ [[དེ༌[^103]ལ་རྟོགས་པའི་དགོས་པ་ནི་ཤེས་བྱའི་དངོས་པོའི་དོན་ཡོངས་སུ་ཤེས་པ་དང་། དེའི་འབྲས་བུ་]]
   * 6.6 ཕན་ཡོན་གྱི་དགོས་པ [[དེ་ལ་ཕན་ཡོན་གྱི་དགོས་པ་ནི་རྣམ་པ་ཐམས་ཅད་མཁྱེན་པ་ཉིད་ཐོབ་པ་སྟེ།]]
* 7. བདུན་པ [[བདུན་པ་ལ་ནི་དོན་ལ་ལོག་པར་རྟོག་པ་རྣམ་པ་བཞིའི་གཉེན་པོ་ངོ་བོ་ཉིད་མེད་པ]]
* 8. བརྒྱད་པ [[བརྒྱད་པ་ལ་ནི་རྣམ་པ་དྲུག་གིས་རྣལ་འབྱོར་གྱི་ལམ་བསྟན་ཏེ། ཡོངས་སུ་ཤེས་པ་དང་།]]
   * 8.1 ཡོངས་སུ་ཤེས་པ་དང་ཡོངས་སུ་མི་ཤེས་པ [[བརྒྱད་པ་ལ་ནི་རྣམ་པ་དྲུག་གིས་རྣལ་འབྱོར་གྱི་ལམ་བསྟན་ཏེ། ཡོངས་སུ་ཤེས་པ་དང་།]]
