=== SYSTEM PROMPT ===
You are an expert in classical Tibetan Buddhist commentary (འགྲེལ་པ་) structure.

You are given a numbered list of blocks from a Tibetan verse commentary. A
rule-based segmenter has already cut them; most cuts are right. Your job is to
output the few merge/split operations that bring the blocks to the layout the
human editors of this vault use.

━━━ TARGET LAYOUT — one block per FUNCTIONAL UNIT ━━━

OPENER       A node's division announcement together with the first-child opener
             that follows it is ONE block:
               "<topic> ལ་གསུམ། A། B། C་འོ། །དང་པོ་ནི།"
             A sibling opener "གཉིས་པ་ <title> ནི།" is its own block.
ROOT QUOTE   A quoted root stanza is its own block. These blocks are tagged
             [VERSE]; they are protected — never include them in any operation.
EXPLANATION  The gloss that follows a quote ("ཞེས་པ་སྟེ། …", "ཞེས་པ་ནི། …", or a
             running explanation) is ONE block up to the next opener, quote or
             heading — even when it is long (100–250 syllables) and contains several
             sentence ends, a question and answer ("…ལོ། །གང་ལ་ན། …"), a side remark
             on a variant reading ("…ཞེས་འགྱུར་བཅོས་…"), a cross-reference
             ("འདི་དང་འོག་གི་ས་བཅད་…"), or a mantra cited in passing.
SECOND LEVEL A passage that re-reads the same stanza on another level — opening
             "སྦས་དོན་ནི།", "ངེས་དོན་ནི།", "ངེས་པའི་དོན་དུ།", "ཟབ་དོན་ནི།",
             "དེའི་ནང་གི་དོན་ལ།", "མཐར་ཐུག་གི་དོན་ནི།" or the like after the literal
             gloss — is its OWN block, never merged into the literal gloss before it
             (the editors keep the two readings apart). Within that passage, M1 applies.
FRAME        The namo line alone; each of the author's own verses one block;
             "སྨྲས་པ།" alone; the colophon ("ཅེས་ … སྦྱར་བའོ། །" + closing wishes) one block.

━━━ MERGE — adjacent blocks that are one unit ━━━

M1  CONTINUED EXPLANATION
    A block that goes on explaining the same quote/topic as the block before it —
    no new opener, no new quote, no new verse being treated — belongs to that block.
    This is the most common fix. Do NOT keep a cut just because a sentence ends.
    Exception: a SECOND LEVEL opener (see above) always starts a new block.
M2  INCOMPLETE SENTENCE
    A block ending in a connector (དང་། / ཞིང་། / ཅིང་། / ནས། / སྟེ། / ཏེ།) that
    the next block completes.
M3  OPENER CHAIN
    An enumeration block followed by "དང་པོ་ནི།" / "དང་པོ་ལ་ N།" (and further
    nested first-child enumerations) — merge them into one opener block.
M4  COLOPHON
    The parts of the closing colophon and its final wishes form one block.

━━━ SPLIT — one block that holds two units ━━━

S1  A new node opener (ordinal + title + "ནི།" or "ལ་ N།") buried mid-block:
    split before it.
S2  The treatment of a new verse/topic starts mid-block (e.g. "ཡང་ཕྱག་གང་ལ་འཚལ་ན"
    starting the next homage): split before it.
S3  An introductory opener "… ནི།" fused to the explanation of the PREVIOUS
    quote: split so the opener starts the next unit.

Never split a block only because it is long.

━━━ TOPIC SHIFT vs CONTINUATION (from the editors' corrections) ━━━

The editors' blocks are large (median ≈ 55 syllables; whole explanations of
100–250 syllables are normal). A sentence end is NOT a boundary. Inside one
explanation they cut only where the commentary turns to something new:
  START a new block at   "ཡང་ན་ …" (an alternative explanation)
                         "ཁ་ཅིག་ …", "གཞན་དག་ …" (another party's view)
                         "འོ་ན་ …" (the reply to an objection)
                         "དེ་སྐད་དུ་ …", "ཇི་སྐད་དུ་ …" (introducing a supporting quotation)
                         "དེ་ནས་ …" when it opens the next step of a procedure
                         "དཔེ་ …" / "དཔེར་ན་ …" when an example section begins
KEEP WITH the block before (merge into it):
                         "ད་ནི་ …" — a transitional "now …" line is not a new unit
                         (no heading or verse between them)
                         "ལེའུ་ … པའོ། །" — a chapter-closing line stays with the
                         explanation it closes
                         "ཞེས་ / ཅེས་ …" — the quotative closing the words just before it

━━━ HEADING / VERSE BLOCKS — always KEEP ━━━

Blocks tagged [HEADING] or [VERSE] are NEVER part of any operation.

━━━ OUTPUT FORMAT ━━━

A JSON array of operations. Blocks not mentioned are kept as-is.

[
  {"op": "merge", "blocks": [N, M]},
  {"op": "merge", "blocks": [N, M, P]},
  {"op": "split", "block": N, "after": "<verbatim unique substring ending at split point>"},
  {"op": "split", "block": N, "after": ["<sub1>", "<sub2>", "<sub3>"]}
]

Rules for the output:
- Block numbers are CONTINUOUS and INCLUDE heading and verse blocks. You may only
  merge blocks with consecutive numbers (N and N+1). Never merge across a heading
  or a verse block, and never propose a merge whose numbers skip over one.
- Each block number appears in AT MOST ONE operation.
- For each "after" substring: copy a verbatim slice from the block that ends exactly
  at the split point and is UNIQUE within that block (10–20 characters is usually enough).
- If nothing needs to change in this window, output: []
- Output ONLY the JSON array. No explanation, no commentary, no code fences.

དེ་ལ་གཏམ་འདྲེ་བ་ལ་སོགས་པ་ཡང་བཟློག་པར་བྱའོ་ཞེས་བྱ་བ་ནི་མི་གདམས་པ་ཉིད་དུ་བྱས་པ་དེ་ལ་གདམས་ཤིང་རྗེས་སུ་བསྟན་པར་བྱ་བ་ཉིད་ཀྱིས་ཕན་གདགས་པ་བཟློག་པར་བྱ་བ་འབའ་ཞིག་ཏུ་མ་ཟད་ཀྱི་འོན་ཀྱང་གཏམ་འདྲེ་བ་དང་ཕེབས་པར་སྨྲ་བ་དང་། སོ་སོར་ཀུན་དགའ་བར་བྱ་བའི་ཐ་སྙད་ཀྱིས་ཚིག་སྦྱིན་པར༌[^2939]ཡང་མི་བྱའོ། །

[Block 3062]
དེ་ལྟར༌[^2940]ན་ཡང་གསོ་སྦྱོང་གཞག་གོ་ཞེས་བྱ་བ་ནི་དེ་ལྟར་ཡང་དུལ་བར་མི་འགྱུར་ཞིང་སྐབས་མི་འབྱེད་ན་དེའི་ཚེ༌[^2941]གསོ་སྦྱོང་གཞག་པར་བྱའོ། །

[Block 3063]
དེས་ཀྱང་ནི་དགག་དབྱེའོ་ཞེས་བྱ་བ་ནི་དེ་ལྟར་གཞག་པ༌[^2942]དེས་ཀྱང་དུལ་བར་མི་འགྱུར་ཞིང་སྐབས་མི་འབྱེད་ན་དེའི་ཚེ་དེའི་དགག་དབྱེ་གཞག་པར་བྱའོ། །

[Block 3064]
གསོ་སྦྱོང་དང་དགག་དབྱེ་གཞག་པར་ཞེས་བྱ་བ་ནི་གང་ཟག་འདི་འདུག་པ་དང་ལྷན་ཅིག་དགེ་སློང་རྣམས་ཀྱིས་གསོ་སྦྱོང་དང་དགག་དབྱེ་མི་བྱའོ་ཞེས་བྱ་བ་ཡིན་པར་རིག་པར་བྱའོ། །

[Block 3065]
འཇོག་པར་བྱེད་པ་དག་གིས་གཞག་པ་དང་ལྷན་ཅིག་ཏུ༌[^2943]བྱ་བ་ཡང་འདིར་བཟོད་པ་ཡིན་ནོ་ཞེས་བྱ་བ་ནི་གང་དག་གིས་གཞག་པ་གང་ཡིན་པ་དག་དང་ལྷན་ཅིག༌[^2944]གསོ་སྦྱོང་ལ་སོགས་པ་བྱ་བ་གང་ཡིན་པ་དེ་ཡང་སྐབས་འདིར་དེ་ལ་བཟོད་པ་བྱ་བ་ཡིན་གྱི་ཚིག་འབའ་ཞིག་གིས་བཟོད་པ་བྱ་ཞིང་བག་ཡངས་སུ་བྱ་བར་མ་ཟད་དོ་ཞེས་བྱ་བའི་དོན་ཏོ། །

[Block 3066]
འདིར་གཞུང་ནི་དྲུག་སྡེ་དག་གིས་འགྲན་དོར་གྱི༌[^2945]བསམ་པས༌[^2946]དགེ་སློང་གིས༌[^2947]གསོ་སྦྱོང་གཞག་པ་དང་། དགེ་སློང་རབ་ཏུ་གནས་པ་ཐམས་ཅད་ཀྱིས་ཀྱང་ཁྱེད་ཀྱི༌[^2948]གསོ་སྦྱོང་དྲུག་སྡེ་དག་གིས་གཞག་གོ་ཞེས་གསོ་སྦྱོང་ལས་ཟློག་པར་བྱེད་ན་ཡང་དྲུག་སྡེ་དག་གིས་གསོ་སྦྱོང་བྱའོ་ཞེས་སྨྲས་པ་ནས་བཅོམ་ལྡན་འདས་ཀྱིས་བཀའ་སྩལ་པ། གལ་ཏེ་དགེ་སློང་དག་གིས་གསོ་སྦྱོང་གཞག་པ་དེ་ཉིད་ཀྱིས་གསོ་སྦྱོང་བྱས་ནས་བཟོད་པར་བྱས་པར་བརྗོད་པར་བྱའོ་ཞེས་བྱ་བའི་བར་དུ་གསུངས་པ་ཡིན་ནོ། །

[Block 3067]
སྐབས་ཕྱེ་བ་ཉིད་ན་གལ་ཏེ་མཉན་པ༌[^2949]ཉིད་མ་ཡིན་ན་ཕུར་པ་དང་བཅས་པ་ཉིད༌[^2950]བྱའོ་ཞེས་བྱ་བ་ནི་སྐབས་ཕྱེ་བ་ཉིད་ན་གལ་ཏེ་དེ་མཉན་པ༌[^2951]ཉིད་དུ༌[^2952]མི་འགྱུར་ན་དེའི་ཚེ་དེ་ལ་ཕུར་པ་དང་བཅས་པ་ཉིད་ཅེས་བྱ་བ་སྟེ། ཕུར་པ་དང་བཅས་པའི་སྐབས་འདི་ནི་མ་མོ་ལས་འབྱུང༌[^2953]ངོ་། །ཇི་ལྟར་ཕུར་པ་དང་བཅས་པ་ཞེས་བྱ་ཞེ་ན། དེའི་ཕྱིར་གནས་འདིའམ་གཞན་དུའམ་གཞི་འདིའམ་གང་ཡང་རུང་བ་ལ་འདོད་པར་སྨྲ་བར་བྱའོ་ཞེས་བྱ་བ་དང་། ལྟུང་བ་བཀལ་ཞིང༌[^2954]ཉེས་པ་བསྟན་ཏེ་བཏང་བས་སོ་ཞེས་བྱ་བ་སྨོས་ཏེ་གང་ཡང་རུང་བ་ལ་འདོད་པར་བྱ་ཞེས་བྱ་བ༌[^2955]ནི་གནས་སམ་གཞི་ལའོ། །

[Block 3068]
ཉེས་པ་བསྟན་ཏེ་ཞེས་བྱ་བ་ནི་ལྟུང་བ་བཀལ་ཞིང༌[^2956]ཞེས་བྱ་བའི་རྣམ་གྲངས་གཞན་བསྟན་པའོ། །

[Block 3069]
རྟ་དམུ་རྒོད་ཕུར་པ་དང་བཅས་པ་དང་འདྲ་བར་དེ་དང་དྲི་མ་དང་བཅས་པར་བཏང་བ་ཡིན་པས་དེའི་ཕྱིར་ཕུར་པ་དང་བཅས་པ་ཞེས༌[^2957]བྱའོ། །

[Block 3070]
ཚུལ་ཁྲིམས་དང་ལྟ་བ་དང་ཆོ་ག་དང༌[^2958]འཚོ་བ་ཉམས་པས་གླེང་བ་ལ་སོགས་པ་དེ་དག་ཐམས་ཅད་བྱེད་ན་གཞི་དང་བཅས་པ་འཆགས་སོ་ཞེས་བྱ་བ་ནི་མཐོང་བ་དང་ཐོས་པ་དང་དོགས་པ་དག་གིས་གཞི་དང་བཅས་པར་ཚུལ་ཁྲིམས་དང་ལྟ་བ་དང་ཆོ་ག་དང་འཚོ་བ་ཉམས་པས་གླེང་བ་དང་དྲན་པར་བྱ་བ་དང་སྐབས་འབྱེད་དུ་གཞུག་པ་དང་བརྗོད་པ་དང་བཅས་པ་དང་། མི་གདམས་པ་ཉིད་དང་། གསོ་སྦྱོང་གཞག་པ་དང་། དགག་དབྱེ་གཞག་པ་ཕུར་པ་དང་བཅས་པས་བྱ་བ་དག་བྱེད་ན་འཆགས་པའོ། །

[Block 3071]
དེ་དག་བྱ་བ་ཡང་གཞི༌[^2959]ཡོད་ན་འཆགས་ཀྱི༌[^2960]གཞི་མེད་པར་ཚུལ་ཁྲིམས་ལ་སོགས་པ་ཉམས་པས་གླེང་བ་ལ་སོགས་པ་བྱེད་པ་ནི་མི་འཆགས་སོ། །

[Block 3072]
གཞི་ལེགས་པ་མ་ཡིན་པས་མི་བྱའོ་ཞེས་བྱ་བ་ནི༌[^2961]གླེང་བ་ལ་སོགས་པ་དེ་དག་ལེགས་པར་མ༌[^2962]མཐོང་བ་དང་། ལེགས་པར་མ་ཐོས་པ་དང་། ལེགས་པར་མི་དོགས་པར༌[^2963]མི་བྱ་བ་དང་། མི་གསལ་བར་ཐོས་པ་ནི་ལེགས་པར་མ་ཐོས་པའོ། །

[Block 3073]
སྙིང་ཐ་དད་ཅིང་དད་པ་ཞེན་པའི༌[^2964]ཡོངས་སུ་རྟོག་པ༌[^2965]ནི་ལེགས་པར་མི་དོགས༌[^2966]པའོ། །

[Block 3074]
འདིར་གཞི་དྲི་ངན་པ་ཡོད་དེ། དེ་བས་ན་འདིར་མི་འཆགས་པ༌[^2967]མ་ཡིན་པར་རིག་པར་བྱའོ། །

[Block 3075]
འདི་ནི་ཕྲན་ཚེགས་དག་ལས་འབྱུང་ངོ་། །འདི་ལ་དངོས་པོ་ལ་བདེན་པ་ཉིད་ནི་རྒྱུ་མ་ཡིན་ནོ་ཞེས་བྱ་བ་ནི་གཞི་འདི་ལ་དངོས་པོ་ལ་བདེན་པ་ཉིད་ནི་རྒྱུ་མ་ཡིན་གྱི་འདུ་ཤེས་ཀྱི་དབང་གིས་འདི་རྣམ་པར་གཞག་པ་སྟེ། དངོས་པོ་བདེན་པ་ཉིད་ཡིན་ན་ཡང་གལ་ཏེ་མཐོང་བ་ལ་སོགས་པའི་འདུ་ཤེས་མེད་པར་གླེང་བར་བྱེད་ན་གཞི་མེད་པ་ཁོ་ནས་གླེང་བ་ལ་སོགས་པ་ཁོ་ནར་འགྱུར་ལ། དངོས་པོ་མི་བདེན་པ་ཉིད་ཡིན་ཡང་གལ་ཏེ་མཐོང་བ་ལ་སོགས་པའི་འདུ་ཤེས་ཀྱིས་གླེང་བར་བྱེད་ན་གཞི་དང་བཅས་པ༌[^2968]ཁོ་ནས་གླེངས་པ༌[^2969]ལ་སོགས་པར་འགྱུར་རོ་ཞེས་བསྟན་པ་ཡིན་ནོ། །

[Block 3076]
ཐོས་པ་ནི་རྣམ་པ་གསུམ་སྟེ། བྱ་བའི་མཚན་མ་དང་། གཞན་ཕེབས་པར་སྨྲ་བ་དང་། རང་གི་རྗེས་སུ་ཐོས་པའོ་ཞེས་བྱ་བ་ལ། བྱ་བའི་མཚན་མ་ཞེས་བྱ་བ་སྨྲ་བ་གང་དག་གིས་འཇུག་པར་བྱེད་པའི་སྒྲ་དེ་དག་དེར་བྱ་བ༌[^2970]དེ་ལྷན་ཅིག་བྱུང་བའི་རང་བཞིན་གང་ཡིན་པ་དེ་ནི་བྱ་བའི་མཚན་མའོ། །

[Block 3077]
གཞན་དག་གིས་བྱས་པར་གྱུར་པ་ལ་དེའི་དོན་དུ་གཞན་ཕེབས་པར་སྨྲ་བ་ལ་གཞན་གྱིས་སྨྲས་པ་ཉིད་དོ། །

[Block 3078]
རང་གི་བདག་ཉིད་ཤེས་པ་པོ་ཉིད་ལ་གང་ཞིག་གཞན་གྱིས༌[^2971]ཐོས་སུ་བཅུག་པ་དེ་ནི་ཆེ་གེ་མོ་ཞིག་གིས་འདི་ལྟ་བུས་བྱས་སོ་ཞེས་གཞན་དག་ལོགས་ཤིག་ན་གཏམ་ཟེར་བ་རང་གིས༌[^2972]ལོགས་ཤིག་ནས་རྗེས་སུ་ཐོས་པ་གང་ཡིན་པའོ། །

[Block 3079]
འདིར་གཞུང་ནི་འདི་ལ་དགེ་སློང་དག་གིས་རྣམ་པ་གང་དག༌[^2973]དང་། རྟགས་གང་དག་དང་མཚན་མ་གང་དག་གིས་ཕམ་པར་འགྱུར་བའི་མཐའི་ལྟུང་བ་འབྱིན་པའི་རྣམ་པ་དེ་དག་དང་རྟགས་དེ་དག་དང་མཚན་མ་དེ་དག་གིས་ཕམ་པར་འགྱུར་བ་མཐའི་ལྟུང་བ་འབྱིན་པ་དེ་ཐོས་པ་དང་། གཏམ་དེ་ཡང་དེ་ལས་བྱུང༌[^2974]ཞིང་དེའི་རང་བཞིན་གྱིས་ཉེ་བར་གནས་པ་ཡིན་པ་དང་། དེ་བཞིན་དུ་དེས་དགེ་སློང་དེ་ཕམ་པར་འགྱུར་བའི་མཐའི་ལྟུང་བར་འབྱུང་ངོ་ཞེས་ཡིད་ཆེས་པའི་ཚིག་ལས་ཐོས་པར་གྱུར་ན་གཞི་དེས་གནས་པ༌[^2975]དེའམ་གཞན་དུ་དེའི་གསོ་སྦྱོང་འཇོག་པར་བྱེད་ན་ཆོས་བཞིན་དུ་གསོ་སྦྱོང་འཇོག་པ་ཡིན་ནོ་ཞེས་གསུངས་པ་ཡིན་ཏེ། དེར་ཇི་སྐད་གསུངས་པ་དེ་དག་གོ་རིམས་བཞིན་དུ་འདིར་བསྡུས་པ་ཡིན་ནོ་ཡིད༌[^2976]མ་ཆེས་པ་ནི་གཞི་ཉིད་མ་ཡིན་ནོ་ཞེས་བྱ་བ་ནི་ཐོས་ཀྱང་ཡིད་མ་ཆེས་པ་གང་ཡིན་པ་དེ་ནི་གཞི་མ་ཡིན་པར་རིག་པར་བྱའོ། །

[Block 3080]
འདིར་གཞུང་ནི་དེས༌[^2977]ཡིད་ཆེས་པའི་ཚིག་ལས་ཐོས་པ་མ་ཡིན་ནོ་ཞེས་གསུངས་པ་ཡིན་ནོ། །

[Block 3081]
ཡོངས་སུ་སྦྱོང་བའི་གཞིའོ།། །།

[Block 3082]
ཤེས་པ་དུ་མ་ཉིད་ཡིན༌[^2978]ན་གླེང་བ་ལ་སོགས་པ་ལ་འདོད་པས་སོ་ཞེས་བྱ་བ་ནི་ཤེས་པའི་དགེ་སློང༌[^2979]དུ་མ་ཉིད་ཡིན་ན་དེ་ལ་གླེང་བ་དང་དྲན་པར་བྱ་བ་དང་སྐབས་འབྱེད་དུ་གཞུག་པ་ལ་སོགས་པ༌[^2980]དེ་དག་རྒན་རིམ་གྱིས་འཇུག་པར་བྱ་བ་མ་ངེས་ཀྱིས་གླེང་བར་བྱ་བ༌[^2981]འདོད་པས་ཅི་དགར་འཇུག་པར་བྱའོ་ཞེས་བྱ་བའི་དོན་ཏོ། །

[Block 3083]
འདིར་གཞུང་ནི་བརྫུན་དུ་སྨྲ་བའི་ལྟུང་བྱེད་ཀྱི་ཞུ་བ་ལས།

[Block 3084]
བཙུན་པ་དགེ་སློང་གི་དགེ་འདུན་གྱི༌[^2982]དབུས་སུ་བསླབ་པ་ལས་འདའ་བར་བགྱིད་ན་སུས་གླེང་བར་བགྱི། གང་འདོད་པས་སོ་ཞེས་བྱ་བ་གསུངས་པ་ཡིན་ནོ། །

[Block 3085]
དགག་དབྱེ་མ་ཡིན་པར་དེ་གཞག་པར་མི་བྱའོ་ཞེས་བྱ་བ་ནི་དགག་དབྱེའི་ལས་ཀྱི་དུས་མ་ཡིན་པ༌[^2983]གཞན་དུ་དགག་དབྱེ་དེ་གཞག་པར་མི་བྱའོ། །
