=== SYSTEM PROMPT ===
You are an expert in classical Tibetan Buddhist commentary (འགྲེལ་པ་) structure.

You are given a numbered list of blocks from a Tibetan verse commentary. A
rule-based segmenter has already cut them; most cuts are right. Your job is to
output the few merge/split operations that bring the blocks to the layout the
human editors of this vault use.

━━━ TARGET LAYOUT — one block per FUNCTIONAL UNIT ━━━

OPENER       A node's division announcement together with the first-child opener
             that follows it is ONE block:
               "<topic> ལ་གསུམ། A། B། C་འོ། །དང་པོ་ནི།"
             A sibling opener "གཉིས་པ་ <title> ནི།" is its own block.
ROOT QUOTE   A quoted root stanza is its own block. These blocks are tagged
             [VERSE]; they are protected — never include them in any operation.
EXPLANATION  The gloss that follows a quote ("ཞེས་པ་སྟེ། …", "ཞེས་པ་ནི། …", or a
             running explanation) is ONE block up to the next opener, quote or
             heading — even when it is long (100–250 syllables) and contains several
             sentence ends, a question and answer ("…ལོ། །གང་ལ་ན། …"), a side remark
             on a variant reading ("…ཞེས་འགྱུར་བཅོས་…"), a cross-reference
             ("འདི་དང་འོག་གི་ས་བཅད་…"), or a mantra cited in passing.
SECOND LEVEL A passage that re-reads the same stanza on another level — opening
             "སྦས་དོན་ནི།", "ངེས་དོན་ནི།", "ངེས་པའི་དོན་དུ།", "ཟབ་དོན་ནི།",
             "དེའི་ནང་གི་དོན་ལ།", "མཐར་ཐུག་གི་དོན་ནི།" or the like after the literal
             gloss — is its OWN block, never merged into the literal gloss before it
             (the editors keep the two readings apart). Within that passage, M1 applies.
FRAME        The namo line alone; each of the author's own verses one block;
             "སྨྲས་པ།" alone; the colophon ("ཅེས་ … སྦྱར་བའོ། །" + closing wishes) one block.

━━━ MERGE — adjacent blocks that are one unit ━━━

M1  CONTINUED EXPLANATION
    A block that goes on explaining the same quote/topic as the block before it —
    no new opener, no new quote, no new verse being treated — belongs to that block.
    This is the most common fix. Do NOT keep a cut just because a sentence ends.
    Exception: a SECOND LEVEL opener (see above) always starts a new block.
M2  INCOMPLETE SENTENCE
    A block ending in a connector (དང་། / ཞིང་། / ཅིང་། / ནས། / སྟེ། / ཏེ།) that
    the next block completes.
M3  OPENER CHAIN
    An enumeration block followed by "དང་པོ་ནི།" / "དང་པོ་ལ་ N།" (and further
    nested first-child enumerations) — merge them into one opener block.
M4  COLOPHON
    The parts of the closing colophon and its final wishes form one block.

━━━ SPLIT — one block that holds two units ━━━

S1  A new node opener (ordinal + title + "ནི།" or "ལ་ N།") buried mid-block:
    split before it.
S2  The treatment of a new verse/topic starts mid-block (e.g. "ཡང་ཕྱག་གང་ལ་འཚལ་ན"
    starting the next homage): split before it.
S3  An introductory opener "… ནི།" fused to the explanation of the PREVIOUS
    quote: split so the opener starts the next unit.

Never split a block only because it is long.

━━━ TOPIC SHIFT vs CONTINUATION (from the editors' corrections) ━━━

The editors' blocks are large (median ≈ 55 syllables; whole explanations of
100–250 syllables are normal). A sentence end is NOT a boundary. Inside one
explanation they cut only where the commentary turns to something new:
  START a new block at   "ཡང་ན་ …" (an alternative explanation)
                         "ཁ་ཅིག་ …", "གཞན་དག་ …" (another party's view)
                         "འོ་ན་ …" (the reply to an objection)
                         "དེ་སྐད་དུ་ …", "ཇི་སྐད་དུ་ …" (introducing a supporting quotation)
                         "དེ་ནས་ …" when it opens the next step of a procedure
                         "དཔེ་ …" / "དཔེར་ན་ …" when an example section begins
KEEP WITH the block before (merge into it):
                         "ད་ནི་ …" — a transitional "now …" line is not a new unit
                         (no heading or verse between them)
                         "ལེའུ་ … པའོ། །" — a chapter-closing line stays with the
                         explanation it closes
                         "ཞེས་ / ཅེས་ …" — the quotative closing the words just before it

━━━ HEADING / VERSE BLOCKS — always KEEP ━━━

Blocks tagged [HEADING] or [VERSE] are NEVER part of any operation.

━━━ OUTPUT FORMAT ━━━

A JSON array of operations. Blocks not mentioned are kept as-is.

[
  {"op": "merge", "blocks": [N, M]},
  {"op": "merge", "blocks": [N, M, P]},
  {"op": "split", "block": N, "after": "<verbatim unique substring ending at split point>"},
  {"op": "split", "block": N, "after": ["<sub1>", "<sub2>", "<sub3>"]}
]

Rules for the output:
- Block numbers are CONTINUOUS and INCLUDE heading and verse blocks. You may only
  merge blocks with consecutive numbers (N and N+1). Never merge across a heading
  or a verse block, and never propose a merge whose numbers skip over one.
- Each block number appears in AT MOST ONE operation.
- For each "after" substring: copy a verbatim slice from the block that ends exactly
  at the split point and is UNIQUE within that block (10–20 characters is usually enough).
- If nothing needs to change in this window, output: []
- Output ONLY the JSON array. No explanation, no commentary, no code fences.

མི་གདམས་པའི༌[^3299]ཕྱིར་རྩོད་པ་ནི་རྒྱུད་གཅིག་ཏུ་བྱ་བ་དང་། དག་པ་སྦྱིན་པ་ཞེས་བྱ་བ་གཉིས་ཀྱིས༌[^3300]ཉེ་བར་ཞི་བར་བསྟན་པ་དེ་ལ་རྒྱུད་གཅིག་ཏུ་བྱ་བ་ནི་བསྟན༌[^3301]ཟིན་པས་དག་པ༌[^3302]སྦྱིན་པར་བརྗོད་པར་བྱ་སྟེ། དེའི་ཕྱིར་གླེང་བའི་ཁ་ན་མ་ཐོ་བ་མེད་པ་ལ་ནི་དག་པ་སྦྱིན་ནོ་ཞེས་བྱ་བ་སྨོས་ཏེ། གལ་ཏེ་དགེ་སློང་དེ་ལ་ལྟུང་བ་གང་གིས་གླེང་བར་བྱ་བའི་ལྟུང་བ་དེ་ནི་ཁ་ན་མ་ཐོ་བ་མེད་པར་གྱུར་ན་དེའི་ཕྱིར། དེ་ལ་དྲན་པས་འདུལ་བ་དང་། མ་སྨྱོས་པས་འདུལ་བའི༌[^3303]བདག་ཉིད་ཀྱིས་དག་པ་སྦྱིན་པར་བྱའོ། །

[Block 3305]
གླེང་བ་ནི་རྣམ་པ་བཞི་སྟེ། གཞི་མེད་པ་དང་གཞན་རྗེས་སུ་སྒྲུབ་པའི་དབང་གིས་དང་ཕྱིར་བཅོས་པ་ལ་མ༌[^3304]ལྟོས་པའི་ཕྱིར་དང་སྨྱོས་པས༌[^3305]བྱས་པས་སོ་ཞེས་བྱ་བ་ནི༌[^3306]གླེང་བའི་ཁ་ན་མ་ཐོ་བ་མེད་པ་ནི་རྣམ་པ་བཞི་སྟེ། གཞི་མེད་པ་ནི་ལྟུང་བ་མ་བྱུང་བ་ཉིད་ལ་གླེང་བ་གང་ཡིན་པའོ། །

[Block 3306]
གཞན་རྗེས་སུ་བསྒྲུབ་པའི་དབང་གིས་ནི་དེ་གཞན་རྗེས་སུ་བསྒྲུབས་ལ་གཞན་གྱིས་གླེང་བར་བྱེད་པ༌[^3307]སྟེ། ལྟུང་བྱེད་ལ་དགེ་འདུན་ལྷག་མ་ལ་སོགས་པས་གླེང་བས༌[^3308]སོ། །

[Block 3307]
ཕྱིར་བཅོས་པ་ལ་མི་ལྟོས་པའི༌[^3309]ཕྱིར་ནི་འདི་ལ་ལྟུང་བ་བྱུང་བར་གྱུར་ཏོ་ཞེས་བྱ་བ་དེ་དེས་ཆོས་བཞིན་དུ་ཕྱིར་བཅོས་པ་ཉིད་ན་ཕྱིར་བཅོས་པ་ཉིད་ལ་མ༌[^3310]ལྟོས་པར་གླེང་བའོ། །

[Block 3308]
སྨྱོས་པས༌[^3311]བྱ་བ་ནི་སྨྱོས་པའི༌[^3312]གནས་སྐབས་སུ་དེས་རུང་བ་མ་ཡིན་པ་ཀུན་དུ་སྤྱད་པ་དེས་གླེང་བར་བྱེད་པའོ། །

[Block 3309]
དང་པོ༌[^3313]གསུམ་ལ་ནི་དྲན་པས་འདུལ་བ་སྦྱིན་ནོ་ཞེས་བྱ་བ་ནི་གཞི་མེད་པ་དང་གཞན་རྗེས་སུ་བསྒྲུབ་པའི་དབང་གིས་དང་། ཕྱིར་བཅོས་པ་ལ་མི་ལྟོས་པའི་ཕྱིར་རོ་ཞེས་བྱ་བ་གསུམ་གྱིས་གླེང་བར་བྱ་བ་དེ་དག་ལ་ནི་དགེ་འདུན་གྱི་དྲན་པས་འདུལ་བ་སྦྱིན་པར་བྱ་སྟེ། དེ་བྱིན་པ་ན་དགེ་སློང་དེ་ལ་དགེ་སློང་དག་གིས་དྲན་པ་དང་ལྡན་པར༌[^3314]འཛིན་གྱི་ལྟུང་བ་དང་བཅས་པར་མི་འཛིན་ཏེ། དེ་ལྟར་ན་དེའི་རྩོད་པ་ཉེ་བར་ཞི་བ་བརྗོད་པར་བྱའོ། །

[Block 3310]
ཐ་མ་ལ་ནི་མ་སྨྱོས་པས་འདུལ་བ་སྦྱིན་པའོ་ཞེས་བྱ་བ་ནི་སྨྱོས་པས༌[^3315]བྱས་པ༌[^3316]གླེང་བ་ལ་ནི་དགེ་འདུན་གྱི༌[^3317]མ་སྨྱོས་པས་འདུལ་བ་སྦྱིན་པར་བྱ་བ་སྟེ། དེ་སྦྱིན་ན་དགེ་འདུན༌[^3318]དེ་ལ་དགེ་སློང་གིས༌[^3319]རང་བཞིན་དུ་གནས་པ་ཉིད་དུ་འཛིན་གྱི་ལྟུང་བ་དང་བཅས་པར་མི་འཛིན་ཏེ། མི་གདམས་པ་ལ་རྩོད་པ༌[^3320]ཉེ་བར་ཞི་བར་བྱ་བའི་ཕྱིར་ཆོ་ག་བཤད་ཟིན་ཏོ། །

[Block 3311]
ལྟུང་བའི་ཕྱིར༌[^3321]རྩོད་པ་ནི་ཕྱིར་བཅོས་པས༌[^3322]ཉེ་བར་ཞི་བར་བྱའོ་ཞེས་བསྟན་པ་དེའི་རབ་ཏུ་དབྱེ་བ་བསྟན་པའི་ཕྱིར་ལྟུང་བ་དང༌[^3323]བཅས་པ་ཉིད་ཀྱི་ཕྱིར༌[^3324]འཁྲུག་ལོང་རྣམ་པ་གསུམ་སྟེ། ཕྱིར་འཕྲོས་པ་མེད་པ་དང་ཕྱིར་འཕྲོས་པ༌[^3325]དང་བཅས་པས་རྣམ་པ་གཉིས་སོ། །

[Block 3312]
[^3326]ཉི་ཚེ་བ་དང་། དགེ་འདུན་མཐའ་དག་དང་འབྲེལ་པའོ་ཞེས་བྱ་བ་སྟེ། གལ་ཏེ་ལྟུང་བ་དང་བཅས་པ་ཉིད་ཀྱི༌[^3327]རྒྱུས་འཁྲུག་ལོང་གི་ཕྱིར་དགེ་འདུན་མཐའ་དག་ཕྱོགས་དང་གཞན་གྱི་ཕྱོགས་སུ༌[^3328]གནས་པར་གྱུར༌[^3329]ན་འདི་ནི་དགེ་འདུན་མཐའ་དག་གི༌[^3330]ཁོངས་སུ་གཏོགས་པ་ཁ་ཅིག་ལ་ཡང་འཁྲུག་ལོང་འབྱུང་བའོ། །

[Block 3313]
དང་པོ་ལས་ནི་ཁས་བླངས་པའི་བྱ་བ་ཕྱིར་བཅོས་སོ་ཞེས་བྱ་བ་ནི་ཕྱིར་འཕྲོས་པ༌[^3331]མེད་པར་འཁྲུག་ལོང་དུ་གྱུར་པའི་འོག་ཏུ་ལྟུང་བའི་ཕྱིར་རྩོད་པ་ནི་ཁས་བླངས་པའི་བྱ་བས་ཕྱིར་བཅོས་པར་བྱ་སྟེ། ཁས་བླངས་པ་ཙམ་གྱི་དབང་གིས་བྱེད་པ་ནི་བྱ་བ་སྟེ་དེའི་ཕྱིར་བཅོས་པའི་མིང་ངོ་། །

[Block 3314]
གཉིས་པ་ལས་ནི་མངོན་སུམ་གྱིས་འདུལ་བས་སོ་ཞེས་བྱ་བ་ནི་ཕྱིར་འཕྲོས་པ་དང་བཅས་པ་ཉི༌[^3332]ཚེ་བའི་འཁྲུག་ལོང་དུ་གྱུར་པ་གང་གི་འོག་ཏུ་ནི་མངོན་སུམ་གྱིས་འདུལ་བས༌[^3333]ཕྱིར་བཅོས་ཏེ། འདི་ལ་རྒོལ་བ་དང་ལན་གྱི་ཚིག་དག་མངོན་སུམ་དུ་བྱུང་གི༌[^3334]གླེང་བ་པོས་དམ་བཅས་པ་ཙམ་གྱིས་འདི་ལ་རྣམ་པར་ངེས་པར་སྦྱིན་པ་མ་ཡིན་པར་རིག་པར་བྱའོ། །

[Block 3315]
ཕྱིར་འཆོས་པར་བྱེད་པ་གང་ཡིན་པ་དེ་ནི་མངོན་སུམ་གྱིས༌[^3335]འདུལ་བར་བརྗོད་དོ། །

[Block 3316]
དེ་ལྟར་ཡང་གང་ཟག་ལ་གང་ཟག་གིས་གླེང་བར་བྱེད་ན་ཆོས་འདུལ་བས་མངོན་སུམ་དུ་སྲུང་བ༌[^3336]ཐོབ་པ་ཞེས་བྱ་བ་ལ་སོགས་པས་སོ། །

[Block 3317]
གསུམ་པ་ལ་ནི་རྩྭ་བཀྲམ་པ་ལྟ་བུས་སོ་ཞེས་བྱ་བ་ནི་དགེ་འདུན་དུ་གཏོགས་པ་ཐམས་ཅད་ཕྱོགས་སུ་རྣམ་པར་གནས་པའི་དགེ་འདུན་དུ་གྱུར་པའི་དགེ་སློང་ཐམས་ཅད་ཕྱིར་འཕྲོས་པ་དང་བཅས་པས་འཁྲུག་ལོང་གི་འོག་ཏུ་སྟེ། ཕྱིར་བཅོས་པ་ནི་རྩྭ་བཀྲམ་པའོ། །

[Block 3318]
རྩ་བཀྲམ་ན་རྩྭ་ཐམས་ཅད་ཕན་ཚུན་ནས་རྩེ་སྤྲོད་དུ་ཉལ་བ་དང་འདྲ་བས་འདིའི་མིང་དེ་ཡིན་ནོ། །

[Block 3319]
འདི་ལ་མང་པོ་དག་གི༌[^3337]དོན་དུ་དགེ་འདུན་མ་ཡིན་པ་ལ་བཤགས་པར་བྱ་བ་དག་ནི་གཅིག་གིས༌[^3338]ཕྱིར་བཅོས་པར་བྱའོ་ཞེས་བྱ་བ་ནི་ཉེས་པ་སྦོམ་པོ་དང་། དགེ་འདུན་ལྷག་མར་གཏོགས་པའི་ཉེས་པ་སྦོམ་པོར་དོར་ནས་དགེ་འདུན་ལ་བཤགས་པར་བྱ་བ་ཉིད་དོ། །

[Block 3320]
དེའི་ཕྱིར་ལྟུང་བ་གཞན་རྣམས་ལ་འདི་གང་ཟག་མང་པོ་དག་གི་དོན་གང་ཟག་གི༌[^3339]རྩྭ་བཀྲམ་པ་ལྟ་བུས་ཕྱིར་བཅོས་པར་བྱར་རུང་བ་ཞེས༌[^3340]བྱ་བའི་དོན་ཏོ། །

[Block 3321]
དུ་མ་དག་ཅིག་ཅར་དུ་ཡང༌[^3341]ཞེས་བྱ་བ་ནི་འདིར་མང་པོ་དག་གི་དོན་དུ་ལྟུང་བ་དུ་མ་དག་ཅིག་ཅར་དུ་ཕྱིར་འཆོས་སུ་ཡང་རུང་བའོ། །

[Block 3322]
གང་ཡིན་པ༌[^3342]ཞེས་སྨོས་པ་དང་ཤེས་པ་སྣང་བར་བྱས་པས་སོ་ཞེས་བྱ་བ་ནི་གཞི༌[^3343]འདི་ལས་ཁྱེད་ཅག་ལ་ལྟུང་བ་བྱུང་བ་གང་ཡིན་པ་དང་། ཁོ་བོ་ཅག་ལ་ལྟུང་བ་བྱུང་བ་གང་ཡིན་པ་དེ་དག་ལྟུང་བའི་མིང་དང་རིགས་སྨོས་པས་གཞན་ལ་ལྟུང་བའི་རིགས༌[^3344]ཤེས་པ་སྣང་བར་བྱ་ཞིང་གོ་བར་བྱས་པས་ཕྱིར་བཅོས་པར་བྱའོ་ཞེས་བྱ་བའི་དོན་ཏོ། །

[Block 3323]
ཕྱོགས་གཞན་གྱིས་ཀྱང་མཐུན་པ་དེ་དག་ལའོ་ཞེས་བྱ་བ་ནི་གཞན་གྱིས་ཀྱང་བློ་གཅིག་ཏུ་གྱུར་པ་དེ་དག་ལ་དེ་ཕྱིར་བཅོས་པར་བྱའི་གཞན་གང་ལ་ཡང་མ་ཡིན་ནོ། །

[Block 3324]
ཁས་མི་ལེན་པ་དང་དོན་མེད་པ་ལ་ནི་བཤགས་པའི༌[^3345]མི་འཆགས་སོ་ཞེས་བྱ་བ་ནི་ཁ་ན་མ་ཐོ་བ་ཁས་མི་ལེན་པ་དང་དོན་མེད་པར་ཁས་བླངས་པས་འཆགས་པ༌[^3346]གང་ཡིན་པ་དེ་ལ་ནི་བཤགས་པ་མི་འཆགས་ཏེ། གང་ཞིག་ལྟུང་བ་བྱུང་བ་དག་ལ་ལྟུང་བ་མ་བྱུང་ངོ་ཞེས་ཁས་མི་ལེན་པ་དང་། ལྟུང་བ་མ་བྱུང་བ་དག་ལ་ལྟུང་བ་བྱུང་ངོ་ཞེས་ཁས་ལེན་པར་བྱེད་པ་ནི་ཆོས་མ་ཡིན་པའོ་ཞེས༌[^3347]གསུངས་པ་དེ་འདིས་བསྡུས་པ་ཡིན་ནོ། །

[Block 3325]
ལྷན་ཅིག་གི་དངོས་པོས་གླེང་བ་ཉིད་དུ༌[^3348]རུང་ངོ་ཞེས་བྱ་བ་ནི་གང་ཟག་གིས་གང་ཟག་ལ་གླེང་བར་བྱེད་པ་དང་། གང་ཟག་གིས༌[^3349]གང་ཟག་གཉིས་ལ་དང་། གང་ཟག་གིས་གང་ཟག་མང་པོ་ལ་དང་། གང་ཟག་གིས་དགེ་འདུན་ལ་དང་། གང་ཟག་གཉིས་ཀྱིས་གང་ཟག་ལ་དང་། ཇི་སྲིད་དགེ་འདུན་གྱིས་གང་ཟག་མང་པོ་ལ་དང་། དགེ་འདུན་གྱིས་དགེ་འདུན་ལ་གླེང་བར་བྱེད་ན་ཞེས་བྱ་བའི་བར་དུ་གླེང༌[^3350]བར་བྱེད་པའི་སྐབས་ལྷན་ཅིག་གི་དངོས་པོར་བསྟན་པ་དེ་དག་བསྡུའོ། །

[Block 3326]
གླེང་བ་པོ་ཉིད་ཀྱང་དེ་བཞིན་ནོ། །

[Block 3327]
འདི་ལ་གྲངས་ཀྱི་བྱེ་བྲག་ནི་ངེས་པ་མེད་དོ་ཞེས་བྱ་བ་ནི་གླེང་བར་བྱ་བ་དང་གླེང་བ་པོ་གཉིས༌[^3351]ལ་གླེང་བར་བྱ་བ་ཇི་སྙེད་པ་དེ་སྙེད་པ་ཁོ་ནའི་གླེང་བ་པོ་དག་གིས་བྱ་བར་མ་ངེས་པའོ། །

[Block 3328]
གླེང་བ་པོ་ལུས་དང་ངག་དག་གིས་བསྡམས་པ་ཉིད་དང་། སྡེ་སྣོད་དག་ཤེས་པ་ཉིད་དང་། དགེ་འདུན་གྱི་ནང་དུ་བསམས་བཞིན༌[^3352]དུ་ཆོས་དང་འདུལ་བ་ལོག༌[^3353]པ་དང་། དེ་བཟློག་པ་དག་མི་སྟོན་པ་ཉིད་ཅེས་བྱ་བ་གསུམ་དང་ལྡན་པ་ལ་གུས་པར་བྱའོ་ཞེས་བྱ་བ་ལ། དེ་ལས་བཟློག་པར་ཞེས་བྱ་བ་ནི་ཆོས་དང་འདུལ་བ་མ་ཡིན་པ་ལས་ཏེ། ཆོས་ཀྱང་ཤེས་བྱ་རྣམ་པར་གཞག་པ་ལས་རིག་པར་བྱའོ། །

[Block 3329]
འདུལ་བ་ནི་ཚུལ་ཁྲིམས་རྣམ་པར་དག་པའི་ཆོ་གའོ། །

[Block 3330]
གླེང་བ་པོ་གང་ཞིག་ལུས་དང་ངག་དག་གིས་བསྡམས་པ་ཉིད་དང་། སྡེ་སྣོད་དག་ལ་མཁས་པ་ཉིད་དང་། དགེ་འདུན་གྱི་ནང་དུ་བསམས་བཞིན་དུ་ཆོས་དང༌[^3354]ཆོས་མ་ཡིན་པར་མི་སྟོན།[^3355] ཆོས་མ་ཡིན་པ་ཆོས་སུ་མི་སྟོན་པ་དང་། [^3356]འདུལ་བ་འདུལ་བ་མ་ཡིན་པར་མི་སྟོན་པ་དང་། འདུལ་བ་མ་ཡིན་པ་འདུལ་བར་མི་སྟོན་པའི་གླེང་བ་པོ་འདི་ལྟ་བུ་ལ་གུས་པར་བྱའོ། །
