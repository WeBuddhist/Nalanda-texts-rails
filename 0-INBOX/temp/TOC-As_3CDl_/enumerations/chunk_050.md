Enumeration Block 1:
དེ་ནི་མདོར་བསྡུ་ན་རྣམ་པ་ལྔར་བལྟ་བར་བྱ་སྟེ། སྡུག་པའི་རྒྱུ་དང་། མི་སྡུག་པའི་རྒྱུ་དང་། ལྟ་བའི་རྒྱུ་དང་། འབྱུང་བའི་རྒྱུ་དང་། ལྡོག་པའི་རྒྱུའོ། །
Enumeration Block 2:
དེ་ཡང་མཚན་ཉིད་རྣམ་པ་ལྔར་བལྟ་བར་བྱ་སྟེ། མ་སྐྱེས་པས་མེད་པ་དང་། འགགས་པས་མེད་པ་དང་། གཅིག་ལ་གཅིག་མེད་པ་དང་། དོན་དམ་པར་མེད་པ་དང་། གཏན་མེད་པའོ།[^1229] །
Enumeration Block 3:
གཞན་ཡང་ཆོས་རྣམ་པ་ལྔ་ནི་ཡོད་པ་ཉིད་དོ། ། རྣམ་པ་ལྔ་ནི་མེད་པ་ཉིད་དོ། ། དེ་ལ་རྣམ་པ་ལྔ་ཡོད་པ་ཉིད་གང་ཞེ་ན། ཡོངས་སུ་གྲུབ་པའི་མཚན་ཉིད་ཡོད་པ་ཉིད་དང་། གཞན་གྱི་དབང་གི་མཚན་ཉིད་ཡོད་པ་ཉིད་དང་། ཀུན་བརྟགས་པའི་མཚན་ཉིད་ཡོད་པ་ཉིད་དང་། བྱེ་བྲག་གི་མཚན་ཉིད་ཡོད་པ་ཉིད་དང་། བརྗོད་པར་བྱ་བ་མ་ཡིན་པའི་མཚན་ཉིད་ཡོད་པ་ཉིད་དོ། །
Enumeration Block 4:
དེའི་འོག་མ་ལྔ་པ་ནི་བརྗོད་པར་བྱ་བ་མ་ཡིན་པ་རྣམ་པ༌[^1233]བཞིས་བརྗོད་པར་བྱ་བ་མ་ཡིན་པའི་མཚན་ཉིད་དེ།
Enumeration Block 5:
རྣམ་པ་ལྔ་མེད་པ་ཉིད་གང་ཞེ་ན། དོན་དམ་པའི་མཚན་ཉིད་མེད་པ༌[^1240]དང་། གཞན་གྱི་དབང་གི༌[^1241]མཚན་ཉིད་མེད་པ་ཉིད་དང་། ཐམས་ཅད་ཀྱི་ཐམས་ཅད་དུ་རང་གི་མཚན་ཉིད་མེད་པ་ཉིད་དང་། བྱེ་བྲག་མེད་པའི་མཚན་ཉིད་མེད་པ་ཉིད་དང་། བརྗོད་པར་བྱ་བའི་མཚན་ཉིད་མེད་པ་ཉིད་དོ། །
Enumeration Block 6:
དེ་ནི་རྣམ་པ་གཉིས་སུ་བལྟ་བར༌[^1242]བྱ་སྟེ། མདོའི་དོན་རབ་ཏུ་རྣམ་པར་འབྱེད་པ་དང་། ཚིགས་སུ་བཅད་པའི་དོན་རབ་ཏུ་རྣམ་པར་འབྱེད་པའོ། །
Enumeration Block 7:
ཚིགས་སུ་བཅད་པའི་དོན་རབ་ཏུ་རྣམ་པར་འབྱེད་པ་ནི་རྣམ་པ་གསུམ་དུ་བལྟ་བར་བྱ་སྟེ། དོན་དམ་པའི་ཚིགས་སུ་བཅད་པ་རྣམ་པར་གཞག་པ་དང་། དགོངས་པའི་དོན་གྱི་ཚིགས་སུ་བཅད་པ་རྣམ་པར་གཞག་པ་དང་། འདུས་པའི་དོན་གྱི་ཚིགས་སུ་བཅད་པ་རྣམ་པར་གཞག་པའོ། །
