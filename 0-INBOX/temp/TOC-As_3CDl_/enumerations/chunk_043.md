Enumeration Block 1:
དེ་ནི་རྣམ་པ་བཞིར་བལྟ་བར་བྱ་སྟེ། འདི་ལྟ་སྟེ། ནད་ལ་མཁས་པ་དང་། ནད་ཅི་ལས་གྱུར་པ་ལ་མཁས་པ་དང་། ནད་བྱུང་བ་བསྩལ་བ༌[^1046]ལ་མཁས་པ་དང་། ནད་བསལ་ནས་ཕྱིས་མི་འབྱུང་བར་བྱ་བ་ལ་མཁས་པའོ། །
Enumeration Block 2:
དེ་ཡང་རྣམ་པ་དྲུག་ཏུ་བལྟ་བར་བྱ་སྟེ། སྨྲ་བ་དང་། རྨད་ཁྱེར་བ་སྨྲ་བ་དང་། རྩོད་པ་སྨྲ་བ་དང་། ཚིག་ངན༌[^1049]སྨྲ་བ་དང་། མཐུན་པ༌[^1050]སྨྲ་བ་དང་། གདམས་པར་སྨྲ་བའོ། །
Enumeration Block 3:
དེ་ཡང་རྣམ་པ་དྲུག་ཏུ་བལྟ་བར་བྱ་སྟེ། འདི་ལྟ་སྟེ། རྒྱལ་པོ་བཞུགས་པའི་ས་དང་། བསྐོས་པ་འདུ་བའི་ས་དང་། འཁོར་དང་། འདུ་བ་དང་། ཆོས་དང་དོན་ལ་མཁས་པའི་དགེ་སྦྱོང་དང་བྲམ་ཟེ་རྣམས་དང་། ཆོས་དང་དོན་འདོད་པའི་སེམས་ཅན་རྣམས་སོ། །
Enumeration Block 4:
དེ་ནི་རྣམ་པ་བཅུར་བལྟ་བར་བྱ་སྟེ། བསྒྲུབ་པར་བྱ་བའི་དོན་རྣམ་པ་གཉིས་དང་། བསྒྲུབ༌[^1082]པ་རྣམ་པ་བརྒྱད་དོ། །

Enumeration Block 5:
བསྒྲུབ་པ་རྣམ་པ་བརྒྱད་གང་ཞེ་ན།
