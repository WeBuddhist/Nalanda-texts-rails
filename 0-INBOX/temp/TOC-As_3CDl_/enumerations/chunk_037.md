Enumeration Block 1:
དེ་ནི་གཞི་གསུམ་པ་དང་། རྣམ་པ་བཞི་དང་། [^832]རབ་ཏུ་དབྱེ་བ་ལ་དམིགས་པ་དྲུག་ཏུ་བལྟ་བར༌[^833]བྱའོ། །
Enumeration Block 2:
སེམས་ཅན་གནས་པ་གསུམ་སྟེ། ཉིན་གཅིག་བཞིན་དུ་གནས་པ་དང་། ཚེའི་ཚད་ཇི་སྲིད་པའི་བར་དུ་གནས་པ་དང་། ཚེ་རབས་རྒྱུད་དུ་དགེ་བའི་ཆོས་རྣམས་ལ་གནས་པ་སྟེ།
Enumeration Block 3:
རྣལ་འབྱོར་པ་རྣམས་ཀྱི་རྣམ་པར་དག་པ་ནི་གཉིས་ཏེ། ཡིད་ལ་བྱེད་པ་རྣམ་པར་དག་པ་དང་། རྟེན་རྣམ་པར་དག་པ་སྟེ།
Enumeration Block 4:
སེམས་ཅན་རྣམས་ལ་སེམས་ཅན་རྣམས་ཀྱི་ལོག་པར་བསྒྲུབ་པ་ངན་འགྲོར་འགྲོ་བར་འགྱུར་བ་ནི་རྣམ་པ་བཅུ་དང་། སྒོ་གསུམ་དང་། རྣམ་པ་གསུམ་དང་། རྩ་བ་གསུམ་མོ། །
Enumeration Block 5:
ས་བོན་ཐམས་ཅད་ནི་མདོར་བསྡུ་ན། ས་བོན་བཞིར་འདུས་ཏེ། འཇིག་རྟེན་པ་དང་། འཇིག་རྟེན་ལས་འདས་པ་དང་། མ་དག་པའི་ས་བོན་དང་། དག་པའི་ས་བོན་ནོ། །
Enumeration Block 6:
དག་པའི་ས་བོན་ནི་རྣམ་པ་གཉིས་ཏེ། འཇིག་རྟེན་པའི་དག་པ་དང་། འཇིག་རྟེན་ལས་འདས་པའིའོ། །
