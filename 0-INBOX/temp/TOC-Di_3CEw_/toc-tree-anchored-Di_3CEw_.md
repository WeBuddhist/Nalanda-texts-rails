## དཀར་ཆག / Table of Contents

* 1. དཔེ་ཡང་གཉིས [[དཔེ་ཡང་གཉིས་སུ་ཡོད་དེ། དང་པོ་ཆོས་མཐུན་པའི་དཔེ་དང་།]]
   * 1.1 དང་པོ་ཆོས་མཐུན་པའི་དཔེ [[ཆོས་མཐུན་པའི་དཔེ་ནི་དོན་གང་ཡིན་པ་དེ་ལ་གཏན་ཚིགས་སུ་]]
   * 1.2 གཉིས་པ་ཆོས་མི་མཐུན་པའི་དཔེ [[ཆོས་མི་མཐུན་པའི་དཔེ་ནི་བསྒྲུབ་བྱའི་དོན་མེད་པ་གང་ཡིན་པ་དེ་ལ་]]
* 2. བསྒྲུབ་བྱ་ལྟར་སྣང [[བསྒྲུབ་པར༌[^9]བྱ་བར་འདོད་ཀྱང་མངོན་སུམ་ལ་སོགས་པ་བསལ་བའི་ཕྱིར་བསྒྲུབ་བྱ་ལྟར་སྣང་ངོ་། །]]
* 3. གཏན་ཚིགས་ལྟར་སྣང [[ད་ནི་གཏན་ཚིགས་ལྟར་སྣང་བཤད་པར་བྱའོ། །]]
   * 3.1 མ་གྲུབ་པ [[མ་གྲུབ་པའང་བཞི་ཡོད་དེ། གཉིས་ཀ་ལ་མ་གྲུབ་པ་དང་།]]
      * 3.1.1 གཉིས་ཀ་ལ་མ་གྲུབ་པ [[གཉིས་ཀ་ལ་མ་གྲུབ་པ་ནི་དཔེར་ན་སྒྲ་མི་རྟག་པར་སྒྲུབ་པ་ལ་]]
      * 3.1.2 གང་རུང་གཅིག་ལ་མ་གྲུབ་པ [[གང་རུང་གཅིག་ལ་མ་གྲུབ་པ་ནི་སྒྲ་མངོན་པར་གསལ་བར༌[^27]འདོད་པའི་]]
      * 3.1.3 ཐེ་ཚོམ་ཟ་ནས་མ་གྲུབ་པ [[ཐེ་ཚོམ་ཟ་ནས་མ་གྲུབ་པ་ནི་ཐེ་ཚོམ་ཟ་པའི་རླངས་པ་ལ་སོགས་པ་]]
      * 3.1.4 གཞི་མ་གྲུབ་པ [[གཞི་མ་གྲུབ་པ་ནི་ནམ་མཁའ་དངོས་པོར་ཡོད་དེ་ཡོན་ཏན་]]
   * 3.2 མ་ངེས་པ [[མ་ངེས་པ་ལ་དྲུག་ཡོད་དེ། ཐུན་མོང་བ་དང་། ཐུན་མོང་མ་ཡིན་པ་དང་།]]
      * 3.2.1 ཐུན་མོང་བ [[ད་ནི་ཐུན་མོང་བ་ནི་དཔེར་ན་སྒྲ་རྟག་པ་ཡིན་ཏེ་]]
      * 3.2.2 ཐུན་མོང་མ་ཡིན་པ [[ཐུན་མོང་མ་ཡིན་པར་བརྗོད་པ་ནི་དཔེར་ན་སྒྲ་རྟག་སྟེ་]]
      * 3.2.3 མཐུན་ཕྱོགས་ཀྱི་ཕྱོགས་གཅིག་ལ་འཇུག་ལ་མི་མཐུན་ཕྱོགས་ལ་ཁྱབ་པར་འཇུག་པ [[མཐུན་ཕྱོགས་ཀྱི་ཕྱོགས་གཅིག་ལ་འཇུག་ལ་མི་མཐུན་ཕྱོགས་ལ་ཁྱབ་པར་འཇུག་པ་ནི་]]
      * 3.2.4 མི་མཐུན་ཕྱོགས་ཀྱི་ཕྱོགས་གཅིག་ལ་འཇུག་ལ་མཐུན་ཕྱོགས་ལ་ཁྱབ་པར་འཇུག་པ [[མི་མཐུན་ཕྱོགས་ཀྱི་ཕྱོགས་གཅིག་ལ་འཇུག་ལ་མཐུན་ཕྱོགས་ལ་ཁྱབ་པར་འཇུག་པ་ནི་]]
      * 3.2.5 གཉིས་ཀའི་ཕྱོགས་རེ་ལ་འཇུག་པ [[གཉིས་ཀའི་ཕྱོགས་རེ༌[^36]ལ་འཇུག་པ་ནི་དཔེར་ན་]]
      * 3.2.6 འགལ་བ་ལ་མི་འཁྲུལ་བ [[འགལ་བ་ལ་མི་འཁྲུལ་བ་ནི་དཔེར་ན་སྒྲ་ནི་མི་རྟག་པ་ཡིན་ཏེ་]]
   * 3.3 འགལ་བ [[འགལ་བ་ལ་བཞི་སྟེ། ཆོས་ཀྱི་ངོ་བོ་དང་། འགལ་བའི་གཏན་ཚིགས་དང་།]]
      * 3.3.1 ཆོས་ཀྱི་ངོ་བོ་དང་འགལ་བའི་གཏན་ཚིགས [[འདིར་ཆོས་ཀྱི་ངོ་བོ་དང་འགལ་བའི་གཏན་ཚིགས་ནི་དཔེར་ན་]]
      * 3.3.2 ཆོས་ཀྱི་ཁྱད་པར་དང་འགལ་བའི་གཏན་ཚིགས [[ཆོས་ཀྱི་ཁྱད་པར་དང་འགལ་བའི་གཏན་ཚིགས་ནི་དཔེར་ན་མིག་ལ་སོགས་པ་]]
      * 3.3.3 ཆོས་ཅན་གྱི་ངོ་བོ་དང་འགལ་བའི་གཏན་ཚིགས [[ཆོས་ཅན་གྱི་ངོ་བོ་དང་འགལ་བའི་གཏན་ཚིགས་ནི་དཔེར་ན་ཡོད་པ་ཉིད་ནི་]]
      * 3.3.4 ཆོས་ཅན་གྱི་ཁྱད་པར་དང་འགལ་བའི་གཏན་ཚིགས [[ཆོས་ཅན་གྱི་ཁྱད་པར་དང་འགལ་བའི་གཏན་ཚིགས་ནི་དཔེར་ན་སྔར་གྱི་]]
* 4. དཔེ་ལྟར་སྣང [[ད༌[^45]ནི་དཔེ་ལྟར་སྣང་བརྗོད་པར་བྱ་སྟེ།[^46] ཆོས་མཐུན་པའི་དཔེ་ལྟར་སྣང༌[^47]ལའང་ལྔ་ཡོད་དེ།]]
   * 4.1 ཆོས་མཐུན་པའི་དཔེ་ལྟར་སྣང [[ཆོས་མཐུན་པའི་དཔེ་ལྟར་སྣང༌[^47]ལའང་ལྔ་ཡོད་དེ། སྒྲུབ་བྱེད་ཆོས་མ་གྲུབ་པ་དང་།]]
      * 4.1.1 སྒྲུབ་བྱེད་ཆོས་མ་གྲུབ་པ [[སྒྲུབ་བྱེད་ཆོས་མ་གྲུབ་པ་ནི་དཔེར་ན་སྒྲ་རྟག་སྟེ་]]
      * 4.1.2 བསྒྲུབ་བྱའི་ཆོས་མ་གྲུབ་པ [[བསྒྲུབ་བྱའི་ཆོས་མ་གྲུབ་པ་ནི་དཔེར་ན་ཚོར་བ་བཞིན་]]
      * 4.1.3 གཉིས་ཀ་མ་གྲུབ་པ [[གཉིས་ཀ་མ་གྲུབ་པ་ནི་དེ་ལའང་གཉིས་ཡོད་དེ། ཡོད་པ་དང་། མེད་པའོ། །]]
         * 4.1.3.1 ཡོད་པ [[གལ་ཏེ་བུམ་པ་བཞིན་ཞེས་བརྗོད་ན། ཡོད་པ་ལ་གཉིས་ཀ་མ་གྲུབ་པའོ། །]]
         * 4.1.3.2 མེད་པ [[གལ་ཏེ་ནམ་མཁའ་བཞིན་ཞེས་བརྗོད་ན། ནམ་མཁའ་མེད་པར་འདོད་པའི་]]
      * 4.1.4 མ་སྦྱར་བ [[མ་སྦྱར་བ་ནི་དོན་དེ་ལ་དཔེ་སྦྱོར་བ་གཏན་མེད་པས་]]
      * 4.1.5 ཕྱིན་ཅི་ལོག་ཏུ་སྦྱར་བ [[ཕྱིན་ཅི་ལོག་ཏུ་སྦྱར་བ་ནི་གང་བྱས་པ་ཐམས་ཅད་]]
   * 4.2 ཆོས་མི་མཐུན་པའི་དཔེ་ལྟར་སྣང [[ཆོས་མི་མཐུན་པའི་དཔེ་ལྟར་སྣང་ལ༌[^50]ཡང་ལྔ་ཡོད་དེ། བསྒྲུབ་པར་བྱ་བ་ལྡོག་པ་མེད་པ་དང་།]]
      * 4.2.1 བསྒྲུབ་པར་བྱ་བའི་ཆོས་ལྡོག་པ་མེད་པ [[ཆོས་མི་མཐུན་པའི༌[^55]དཔེ་ལྟར་སྣང་ནི་བསྒྲུབ་པར་བྱ་བའི་ཆོས༌[^56]ལྡོག་པ་མེད་པ་ཡིན་ཏེ།]]
      * 4.2.2 སྒྲུབ་པར་བྱེད་པ་ལྡོག་པ་མེད་པ [[དཔེར་ན་གཞན་གྱི་ལས་བཞིན་ཞེས་བསྒྲུབ་བྱ༌[^58]ལྡོག་པ་ལ༌[^59]སྒྲུབ་བྱེད་མི་ལྡོག་པ་སྟེ།]]
      * 4.2.3 གཉིས་ཀ་ལྡོག་པ་མེད་པ [[གཉིས་ཀ་ལྡོག་པ་མེད་པ༌[^61]ནི་ཡོད་པའི་བསྟན་བཅོས་ལ་ལྟོས་ནས་]]
      * 4.2.4 ལྡོག་པ་བསྟན་པ [[ལྡོག་པ་བསྟན་པ་ནི་དཔེར་ན་བུམ་པ་བཞིན་ཞེས་བརྗོད་ན།]]
      * 4.2.5 ལྡོག་པ་ཕྱིན་ཅི་ལོག་ཏུ་སྦྱར་བ [[ལྡོག་པ་ཕྱིན་ཅི་ལོག་ཏུ་སྦྱར་བ༌[^64]ནི་ཐོགས་བཅས་ཐམས་ཅད་མི་རྟག་པ་]]
* 5. རང་གིས་མངོན་པར་རིག་པར་བྱ་བ [[དེས་ན༌[^66]རང་གིས་མངོན་པར་རིག་པར་བྱ་སྟེ། མངོན་སུམ་དང་། རྗེས་སུ་དཔག་པའི་]]
   * 5.1 མངོན་སུམ་ཚད་མ [[འདིར་མངོན་སུམ་ཚད་མ་ནི་རྟོག་པ་དང་བྲལ་ཞིང་མ་འཁྲུལ་བ་སྟེ།]]
   * 5.2 རྗེས་སུ་དཔག་པའི་ཚད་མ [[རྗེས་སུ་དཔག་པའི་ཚད་མ་ནི་རྟགས་རྣམས་ལ་ལྟོས་ནས་]]
