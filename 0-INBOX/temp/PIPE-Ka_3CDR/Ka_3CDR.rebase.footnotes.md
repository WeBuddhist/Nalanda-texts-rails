[^1]: བསྒོམ་པ་ ༼སྣར། པེ།༽ སྒོམ་པ་
[^2]: བསྐྱེད་པ་ ༼པེ།༽ སྐྱེད་པ་
[^3]: བསྐྱེད་པ་ ༼སྣར། པེ།༽ སྐྱེད་པ་
[^4]: ལས་ ༼སྣར། པེ།༽ ལ་
[^5]: བསྒྲུབ་པར་ ༼སྣར། པེ།༽ སྒྲུབ་པར་
[^6]: སྐུ་ལུས་ཀྱིས། ༼སྣར། པེ།༽ སྐུ་ལུས་ཀྱི།
[^7]: བསྐྱེད་ ༼སྣར། པེ།༽ སྐྱེད་
[^8]: དང་སེམས་ཀྱི་ ༼སྣར། པེ།༽ དང་སེམས་ཀྱིས་
[^9]: མཐོང་བར་ ༼སྣར།༽ མཐོ་བར་
[^10]: འདོད་པས་ ༼སྣར། པེ།༽ འདོད་པ་
[^11]: བྱ་སྟེ། ༼སྣར།༽ བྱས་ཏེ།
[^12]: ལྷག་མཐོང་ནི་ ༼སྣར། པེ།༽ ལྷག་མཐོང་གི་
[^13]: བསམས་པས་ ༼སྣར། པེ།༽ བསམ་པས་
[^14]: བཅིངས་པས་དེ་ ༼སྣར། པེ།༽ བཅིངས་པ་དེས་
[^15]: ལམ་ཁ་བྲག་ ༼སྣར། པེ།༽ ལམ་ཁ་དབྲག་
[^16]: འགྲོན་པོ་ ༼སྣར། པེ།༽ འདྲོན་པོ་
[^17]: ངེས་པ་ ༼སྣར། པེ།༽ ངེས་པར་
[^18]: དེ་ནས་ ༼སྣར། པེ།༽ དེ་ནས་གནས་
[^19]: མཆིལ་ ༼སྣར། པེ།༽ འཆིལ་ལམ་
[^20]: དུས་གསུམ་གྱི་ ༼སྣར། པེ།༽ དང་དུས་སུམ་གྱིས་
[^21]: བྱ་སྟེ། ༼སྣར། པེ།༽ བྱས་ཏེ།
[^22]: ཀློད་ ༼སྣར། པེ།༽ གློད་
[^23]: སྒུ་བ་ ༼སྣར། པེ།༽ དགུ་པ་
[^24]: བཞུགས་ ༼སྣར། པེ།༽ ཞུགས་
[^25]: གང་གིས་ ༼སྣར། པེ།༽ གང་གི་
[^26]: བཞུགས་པ་ ༼པེ།༽ བཞུགས་པར་
[^27]: ལ་སོགས་པར་ ༼སྣར། པེ།༽ ལ་སོགས་པ་
[^28]: བརྟགས་པ་ ༼པེ།༽ བརྟག་པ་
[^29]: ངང་གིས་ ༼སྣར། པེ།༽ ངང་གི་
[^30]: དེས་ ༼སྣར། པེ།༽ དེ་
[^31]: གཡེང་བར་ ༼སྣར། པེ།༽ ཡེངས་པར་
[^32]: གཟུང་བ་ ༼སྣར། པེ།༽ བཟུང་བ་
[^33]: གཟུང་བའི་ ༼སྣར། པེ།༽ བཟུང་བའི་
[^34]: ཕྲ་རབ་ ༼སྣར། པེ།༽ ཕྲ་རབ་རབ་
[^35]: མེད་དོ། ༼སྣར། པེ།༽ མེད་དེ།
[^36]: སྣང་བའི་ ༼སྣར། པེ།༽ རྟོག་པའི་
[^37]: དེས་ ༼སྣར། པེ།༽ དེ་
[^38]: བྱ། གཡེང་བ་ ༼སྣར། པེ།༽ བྱའོ། །གཡེངས་པ་
[^39]: པར་ ༼སྣར། པེ།༽ པ་
[^40]: གཉིད་ཀྱིས་ ༼སྣར། པེ།༽ གཉིད་ཀྱི་
[^41]: བྱས་ལ་ ༼སྣར། པེ།༽ བྱས་
[^42]: མ་ ༼སྣར། པེ།༽ ལམ་
[^43]: བཏང་སྙོམས་སུ་ ༼སྣར། པེ།༽ བཏང་སྙོམས་
[^44]: དོན་དམ་པར་ ༼སྣར། པེ།༽ དོན་དམ་པ་
[^45]: བ་ཡང་ ༼སྣར། པེ།༽ བ་
[^46]: ཡོད་དོ་ ༼སྣར། པེ།༽ ཡོད་
[^47]: བསམས་ ༼སྣར། པེ།༽ བསམ་
[^48]: རྟག་ ༼སྣར། པེ།༽ བརྟག་
[^49]: དྲུག་དག་གིས་ ༼སྣར། པེ།༽ དྲུག་
[^50]: ཉམས་པར་ ༼སྣར། པེ།༽ མཉམ་པར་
[^51]: བལྟའོ། ༼སྣར། པེ།༽ ལྟའོ།
[^52]: བསྒྲུབས་ ༼སྣར། པེ།༽ བསྒྲུབ་
[^53]: བསྒོམ་པ་ ༼སྣར། པེ།༽ སྒོམ་པ་
[^54]: ཕབ་པ། ༼སྣར། པེ།༽ ཕབ་པོ།
