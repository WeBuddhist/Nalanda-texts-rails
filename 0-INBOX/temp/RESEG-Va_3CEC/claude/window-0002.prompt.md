=== SYSTEM PROMPT ===
You are an expert in classical Tibetan Buddhist commentary (འགྲེལ་པ་) structure.

You are given a numbered list of blocks from a Tibetan verse commentary. A
rule-based segmenter has already cut them; most cuts are right. Your job is to
output the few merge/split operations that bring the blocks to the layout the
human editors of this vault use.

━━━ TARGET LAYOUT — one block per FUNCTIONAL UNIT ━━━

OPENER       A node's division announcement together with the first-child opener
             that follows it is ONE block:
               "<topic> ལ་གསུམ། A། B། C་འོ། །དང་པོ་ནི།"
             A sibling opener "གཉིས་པ་ <title> ནི།" is its own block.
ROOT QUOTE   A quoted root stanza is its own block. These blocks are tagged
             [VERSE]; they are protected — never include them in any operation.
EXPLANATION  The gloss that follows a quote ("ཞེས་པ་སྟེ། …", "ཞེས་པ་ནི། …", or a
             running explanation) is ONE block up to the next opener, quote or
             heading — even when it is long (100–250 syllables) and contains several
             sentence ends, a question and answer ("…ལོ། །གང་ལ་ན། …"), a side remark
             on a variant reading ("…ཞེས་འགྱུར་བཅོས་…"), a cross-reference
             ("འདི་དང་འོག་གི་ས་བཅད་…"), or a mantra cited in passing.
SECOND LEVEL A passage that re-reads the same stanza on another level — opening
             "སྦས་དོན་ནི།", "ངེས་དོན་ནི།", "ངེས་པའི་དོན་དུ།", "ཟབ་དོན་ནི།",
             "དེའི་ནང་གི་དོན་ལ།", "མཐར་ཐུག་གི་དོན་ནི།" or the like after the literal
             gloss — is its OWN block, never merged into the literal gloss before it
             (the editors keep the two readings apart). Within that passage, M1 applies.
FRAME        The namo line alone; each of the author's own verses one block;
             "སྨྲས་པ།" alone; the colophon ("ཅེས་ … སྦྱར་བའོ། །" + closing wishes) one block.

━━━ MERGE — adjacent blocks that are one unit ━━━

M1  CONTINUED EXPLANATION
    A block that goes on explaining the same quote/topic as the block before it —
    no new opener, no new quote, no new verse being treated — belongs to that block.
    This is the most common fix. Do NOT keep a cut just because a sentence ends.
    Exception: a SECOND LEVEL opener (see above) always starts a new block.
M2  INCOMPLETE SENTENCE
    A block ending in a connector (དང་། / ཞིང་། / ཅིང་། / ནས། / སྟེ། / ཏེ།) that
    the next block completes.
M3  OPENER CHAIN
    An enumeration block followed by "དང་པོ་ནི།" / "དང་པོ་ལ་ N།" (and further
    nested first-child enumerations) — merge them into one opener block.
M4  COLOPHON
    The parts of the closing colophon and its final wishes form one block.

━━━ SPLIT — one block that holds two units ━━━

S1  A new node opener (ordinal + title + "ནི།" or "ལ་ N།") buried mid-block:
    split before it.
S2  The treatment of a new verse/topic starts mid-block (e.g. "ཡང་ཕྱག་གང་ལ་འཚལ་ན"
    starting the next homage): split before it.
S3  An introductory opener "… ནི།" fused to the explanation of the PREVIOUS
    quote: split so the opener starts the next unit.

Never split a block only because it is long.

━━━ TOPIC SHIFT vs CONTINUATION (from the editors' corrections) ━━━

The editors' blocks are large (median ≈ 55 syllables; whole explanations of
100–250 syllables are normal). A sentence end is NOT a boundary. Inside one
explanation they cut only where the commentary turns to something new:
  START a new block at   "ཡང་ན་ …" (an alternative explanation)
                         "ཁ་ཅིག་ …", "གཞན་དག་ …" (another party's view)
                         "འོ་ན་ …" (the reply to an objection)
                         "དེ་སྐད་དུ་ …", "ཇི་སྐད་དུ་ …" (introducing a supporting quotation)
                         "དེ་ནས་ …" when it opens the next step of a procedure
                         "དཔེ་ …" / "དཔེར་ན་ …" when an example section begins
KEEP WITH the block before (merge into it):
                         "ད་ནི་ …" — a transitional "now …" line is not a new unit
                         (no heading or verse between them)
                         "ལེའུ་ … པའོ། །" — a chapter-closing line stays with the
                         explanation it closes
                         "ཞེས་ / ཅེས་ …" — the quotative closing the words just before it

━━━ HEADING / VERSE BLOCKS — always KEEP ━━━

Blocks tagged [HEADING] or [VERSE] are NEVER part of any operation.

━━━ OUTPUT FORMAT ━━━

A JSON array of operations. Blocks not mentioned are kept as-is.

[
  {"op": "merge", "blocks": [N, M]},
  {"op": "merge", "blocks": [N, M, P]},
  {"op": "split", "block": N, "after": "<verbatim unique substring ending at split point>"},
  {"op": "split", "block": N, "after": ["<sub1>", "<sub2>", "<sub3>"]}
]

Rules for the output:
- Block numbers are CONTINUOUS and INCLUDE heading and verse blocks. You may only
  merge blocks with consecutive numbers (N and N+1). Never merge across a heading
  or a verse block, and never propose a merge whose numbers skip over one.
- Each block number appears in AT MOST ONE operation.
- For each "after" substring: copy a verbatim slice from the block that ends exactly
  at the split point and is UNIQUE within that block (10–20 characters is usually enough).
- If nothing needs to change in this window, output: []
- Output ONLY the JSON array. No explanation, no commentary, no code fences.

རྣམ་པ་ཐམས་ཅད་དུ་ཤེས་པ་ནི་དེ་དག་ཀྱང་མི་རྟག་པ་འམ། བདག་མེད་པའི་རྣམ་པར་ཤེས་པ་འམ། དུས་གསུམ་ཐམས་ཅད་དུ་ཤེས་པ་སྟེ། ནམས་ཀྱང༌[^61]ཤེས་པ་དེ་ལ་ཉམས་པ་མེད་པའོ། །

[Block 82]
འབད་པ་མེད་པར་ཤེས་པ་ནི་ཏིང་ངེ་འཛིན་ལ་སོགས་པའི་རྒྱུ་ལ་མི་ལྟོས༌[^62]ཤིང་བརྩལ་བ༌[^63]མེད་པར་ལྷུན་གྱིས༌[^64]གྲུབ་པར་ཤེས་པའོ། །

[Block 83]
མ་བསྟན་པར་ཤེས༌[^65]པ་ནི་མཁན་པོ་དང་སློབ་དཔོན་གྱི་མན་ངག་མེད་པར་རང་འབྱུང་གི་ཡེ་ཤེས་ཀྱི༌[^66]ཆོས་ཐམས་ཅད་རང་ཉིད་ཀྱིས་མངོན་པར་བྱང་ཆུབ་པའི་ཕྱིར་རོ། །

[Block 84]
སྤངས་པ་ཕུན་སུམ་ཚོགས་པ་ཡང་རྣམ་པ༌[^67]ལྔ་སྟེ། ཉོན་མོངས་པའི་སྒྲིབ་པ་སྤངས་པ་དང་། ཤེས་བྱའི་སྒྲིབ་པ་སྤངས་པ་དང་། ཤིན་ཏུ་སྤངས་པ་དང་། བག་ཆགས་དང་བཅས་པ་སྤངས་པ་དང་། སྙོམས་པར་འཇུག་པའི་སྒྲིབ་པ་ཐམས་ཅད་སྤངས་པའོ།[^68] །དེ་ལ་ཉོན་མོངས་པའི་སྒྲིབ་པ་སྤངས་པ་ནི་འདོད་ཆགས་ལ་སོགས་པ་མཐོང་བ་དང་། བསྒོམ་པའི་ལམ་གྱིས་སྤང་བར༌[^69]བྱ་བའི་ཉོན་མོངས་པ་རྣམས་སྤངས་པའོ། །ཤེས་བྱའི་སྒྲིབ་པ་སྤངས་པ་ནི་ཕུང་པོ་དང་ཁམས་དང་སྐྱེ་མཆེད་ལ་གཟུང་བ་དང་འཛིན་པའི་མངོན་པར་ཆགས་པའི་བག་ཆགས་ཉོན་མོངས་པ་ཅན་མ་ཡིན་པ་མི་ཤེས་པ་སྤངས་པའོ། །

[Block 85]
ཤིན་ཏུ་སྤངས་པ་ནི་སྒྲིབ་པ་དེ་གཉིས་ཕྱིས་སེམས་ཀྱི༌[^70]རྒྱུད་ལ་འབྱུང༌[^71]ཞིང་སྐྱེ་བ་མེད་པར་སྤངས་པའོ། །

[Block 86]
བག་ཆགས་དང་བཅས་པར་སྤངས་པ་ནི་སྒྲིབ་པ་དེ་གཉིས་ཀྱི་བག་ལ་ཉལ་རྩ༌[^72]ནས་བཏོན་པའོ། །

[Block 87]
སྙོམས་པར་འཇུག་པ་ཐམས་ཅད་ཀྱི་སྒྲིབ་པ་སྤངས་པ་ནི་མཐར་གྱིས་གནས་པའི༌[^73]སྙོམས་པར་འཇུག་པ་དགུ་དང་། ཟད་པར་གྱི་སྐྱེ་མཆེད་དང་། ཟིལ་གྱིས་གནོན་པའི་སྐྱེ་མཆེད་རྣམས་ཐོབ་པར་བྱ་བ་ལ་བར་དུ་གཅོད་པ་རྣམས་སྤངས་པའོ། །

[Block 88]
རྒྱུ་དང་རྐྱེན་གང་གིས་བླ་ན་མེད་པའི་བྱང་ཆུབ་ཐོབ་པར་འགྱུར་བའི་རྒྱུ་དང་རྐྱེན་དེ་རྣམས་ཉེ་བར་སྒྲུབ་པ༌[^74]ལ་བྱང་ཆུབ་ཀྱི་རྐྱེན་རྣམས་ཀྱང་ཉེ་བར་གཞོག་ལ་ཞེས་བྱ་སྟེ། རྒྱུ་དང་རྐྱེན་ཀྱང་བསོད་ནམས་དང་ཡེ་ཤེས་ཀྱི་ཚོགས་སོ། །

[Block 89]
རྐྱེན་དེ་དག་ཀྱང་ཟད་ཅིང་འགོག་པར་རྟོགས་ཏེ་ཞེས་བྱ་བ་ནི༌[^75]བྱང་ཆུབ་ཀྱི་རྒྱུ་དང་རྐྱེན་རྣམས་ངོ་བོ་ཉིད་མེད་པར་ཤེས་པ་འམ། མ་རིག་པའི༌[^76]རྐྱེན་གྱིས་འདུ་བྱེད་འབྱུང་བ་ལ་སོགས་པ་རྐྱེན་གོང་དུ་སྨོས་པ་རྣམས་ངོ་བོ་ཉིད་མེད་པར་ཤེས་པ་ཞེས་བྱ་བའི་དོན་ཏོ། །

[Block 90]
སེམས་ཅན་ལ་ལྟ་བའི་ཕྱིར་ཟད་ཅིང་འགོག་པའི་ཡེ་ཤེས་སུ་མི་འཇོག་ཅེས་བྱ་བ་ནི་དེ་ལྟར་དེ་བཞིན་མྱ་ངན་ལས་འདས་པ་སྟོང་པའི་མཚན་ཉིད་རྟོགས་ཀྱང་སེམས་ཅན་གྱི་དོན་དུ་མྱ་ངན་ལས་འདས་པ་འབའ་ཞིག་ལ་གནས་པར་མི་བྱེད་ཅེས་བྱ་བའི་དོན་ཏོ། །

[Block 91 [HEADING]]
#### དུས་གསུམ་ལ་མཁས་པ། ^1-1-2-0

[Block 92]
རྟེན་ཅིང་འབྲེལ་པར་འབྱུང་བ་བཤད་པའི་དོན་དུ༌[^77]དུས་གསུམ་ལ་མཁས་པ་བསྟན་པས་ཇི་ལྟར་བསྟན་པ་བཞིན་དུ་བཤད་པར་བཞེད་ནས། དེ་ལ༌[^78]བྱང་ཆུབ་སེམས་དཔའི་དུས་གསུམ་ལ་མཁས་པ་གང་ཞེ་ན་ཞེས་དྲིས་སོ། །

[Block 93]
དུས་གསུམ་པོ་དེ་ཡང་དུས་ཉིད་ལ་རྣམ་པ་གསུམ་ཡོད་པ་ནི་མ་ཡིན་གྱི། སེམས་དང་སེམས་ལས་བྱུང་བ་ལ་དུས་གསུམ་དུ་བཞག༌[^79]སྟེ། སེམས་དང་སེམས་ལས་བྱུང་བའི་དངོས་པོ་དེ་དག་ཉིད་རྒྱུ་དང་འབྲས་བུ་བཅས་པར་འདས་ཏེ། ཞིག་པ་ནི་འདས་པའི་དུས་ཞེས་བྱ།[^80] རྒྱུ་དང་འབྲས་བུ་ད་དུང་མ་སྐྱེས་པ་ལ་ནི་མ་འོངས་པའི་དུས་ཞེས་བྱ། རྒྱུ་དང་འབྲས་བུ་སྐྱེས་ནས་མ་ཞིག་གི་བར་དུ་ནི་ད་ལྟར་བྱུང་བའི་དུས་ཞེས་བྱ་སྟེ། དངོས་པོ་འདས་པ་དང་མ་འོངས་པ་དང་ད་ལྟར་བྱུང་བ་རྣམས་ཅི་འདྲ་བ་ལ་མཁས་པ་ནི་དུས་གསུམ་ལ་མཁས་པ་ཞེས་བྱའོ། །

[Block 94 [HEADING]]
##### འདས་པའི་དུས་ལ་མཁས་པ། ^1-1-2-1-0

[Block 95]
འདས་པའི་དུས་ལ་མཁས་པ་བསྟན་པའི་ཕྱིར། གང་བདག་དང་སེམས་ཅན་གཞན་གྱི་ཞེས་བྱ་བ་ལ་སོགས་པ་སྨོས་ཏེ། དགེ་བ་དང་མི་དགེ་བ་དང་འབྲེལ་པའི་སེམས་དང་སེམས་ལས་བྱུང་བ་གང་ཡིན་པ་ནི་སེམས་དང་སེམས་ལས་བྱུང་བ་དགེ་བ་དང་མི་དགེ་བ་རྣམས་ཞེས་བྱའོ། །

[Block 96]
བདག་དང་སེམས་ཅན་གཞན་གྱིས་འདས་པའི་དུས་ན་དགེ་བ་ནི་འདི་ལྟ་བུ་ཞིག་བྱས། མི་དགེ་བ་ནི་འདི་ལྟ་བུ་ཞིག་བྱས་ཞེས་བདག་དང༌[^81]གཞན་གྱིས་དགེ་བ་དང་མི་དགེ་བ༌[^82]བྱས་པ་མ་བརྗེད་པ་ནི་རྗེས་སུ་དྲན་པའོ། །

[Block 97]
དེ་ཙམ་གྱི༌[^83]འདས་པའི་དུས་ལ་མཁས་པ་ཡིན་ནམ་ཞེ་ན། མ་ཡིན་པར་བསྟན་པའི་ཕྱིར། མི་དགེ་བ༌[^84]སེམས་དང་སེམས་ལས་བྱུང་བའི་ཞེས་བྱ་བ་ལ་སོགས་པ་གསུངས་ཏེ། འདི་ཡང་བདག་དང་གཞན་གྱི༌[^85]མི་དགེ་བ་དང་འབྲེལ་པའི་སེམས་དང་སེམས་ལས་བྱུང་བ་དྲན་ནས་ཞེས་བྱ་བ་དང་སྦྱར་རོ། །

[Block 98]
བྱང་ཆུབ་ཏུ་བསྔོ་བ་ཞེས་བྱ་བ་ནི་དགེ་བ་བྱས་པ་རྣམས་བླ་ན་མེད་པའི་བྱང་ཆུབ་ཐོབ་པའི་རྒྱུར་གྱུར་ཞེས་སྨོན་པའོ། །

[Block 99 [HEADING]]
##### མ་འོངས་པའི་དུས་ལ་མཁས་པ། ^1-1-2-2-0

[Block 100]
མ་འོངས་པའི་དུས་ལ་མཁས་པ་བསྟན་པའི་ཕྱིར། གང་མ་འོངས་པའི་སེམས་དང་སེམས་ལས་བྱུང་བ་ཞེས་བྱ་བ་ལ་སོགས་པ་གསུངས་ཏེ། མ་འོངས་པ་ན་བདག་གི་བསོད་ནམས་དང་ཡེ་ཤེས་ཀྱི་ཚོགས་བླ་ན་མེད་པའི་བྱང་ཆུབ་ཐོབ་པའི་རྒྱུ་བདག་དང་གཞན་ལ་ཕན་པར་བྱེད་པའི་རྐྱེན་དུ་གྱུར་པའི༌[^86]དགེ་བའི་རྩ་བ་རྣམས་གདོན་མི་ཟ་བར་བྱའོ་ཞེས་སེམས་པ་ནི་དགེ་བའི་རྩ་བའི་ཚོགས་ལ་ངེས་པར་སེམས་པ་ཞེས་བྱའོ། །

[Block 101]
དོན་དེ་ཉིད་བསྟན་པའི་ཕྱིར། བྱང་ཆུབ་མངོན་དུ་གྱུར་པའི་ལས་སེམས་ཏེ་ཞེས་བྱ་བ་གསུངས་ཏེ། བྱང་ཆུབ་ཐོབ་པར་འགྱུར་བའི༌[^87]དགེ་བའི་ལས་བྱ་བར༌[^88]སེམས་པ་ནི་བྱང་ཆུབ་མངོན་དུ་འགྱུར་བའི༌[^89]ལས་སེམས་པ་ཞེས་བྱའོ། །

[Block 102]
དོན་དེ་ཉིད་ཇི་ལྟ་བུ་ཡིན་པ༌[^90]གསལ་བར་བསྟན་པའི་ཕྱིར། བདག་གི་དགེ་བའི་སེམས་བསྐྱེད་པ་གང་དག་ཅེས་བྱ་བ་ལ་སོགས་པ་གསུངས་ཏེ། དགེ་བ་དང་འབྲེལ་པའི་སེམས་ནི་དགེ་བའི་སེམས་སོ། །

[Block 103]
བསྐྱེད་པ་ནི་ད་ལྟར་གྱི༌[^91]དུས་ན་དགེ་བའི་སེམས་སྐྱེས་ཟིན་པའོ། །

[Block 104]
སྐྱེ་བར་འགྱུར་བ་ནི་མ་འོངས་པའི་དུས་ན་དགེ་བ་དང་འབྲེལ་པའི་སེམས་གདོན་མི་ཟ་བར་སྐྱེ་བར་འགྱུར་བའོ། །

[Block 105]
དེ་དག་ཅེས་བྱ་བ་ནི་དུས་གཉིས་ཀྱི་དགེ་བའི་སེམས་ཉིད་ལ་སྙེགས་ཏེ། ད་ལྟར་གྱི་དུས་ན་དགེ་བའི་སེམས་སྐྱེད༌[^92]པ་དང་། མ་འོངས་པའི་དུས་ན་སྐྱེ་བར་འགྱུར་བ་དེ་དག་ཅེས་བྱ་བའི་དོན་ཏོ། །

[Block 106]
ནི་ཞེས་བྱ་བས་དགེ་བ་དེ་དག་ཐེག་པ་གཉིས་དང་། ལྷ་དང་མིའི་བདེ་འགྲོར་མི་བསྔོ་ཞེས་བྱ་བར་སྟོན་ཏོ།[^93] །བྱང་ཆུབ་ཅེས་བྱ་བ་ནི་བྱང་ཆུབ་ཐོབ་པར་བྱ་བའི་ཕྱིར་ཞེས་བྱ་བའི་ཐ་ཚིག་གོ། །

[Block 107]
སྐབས༌[^94]མི་དབྱེ་ཞེས་བྱ་བ་ནི་མ་འོངས་པའི་མི་དགེ་བའི་སེམས་དང་སེམས་ལས་བྱུང་བ་སྐྱེ་བའི་སྐབས༌[^95]མི་དབྱེ་ཞེས་བྱ་བར་སྟོན་ཏོ། །

[Block 108]
གོང་དུ་བཤད་པའི་དོན་རྣམས་བསྡུས་ཏེ་བསྟན་པའི་ཕྱིར། གང་དེ་ལྟ་བུར་སེམས་ལ་བསྒོ༌[^96]བ་དེ་ནི་ཞེས་བྱ་བ་ལ་སོགས་པ་གསུངས་ཏེ། དེ་ལྟ་བུར་སེམས་ལ་བསྒོ་ཞེས་བྱ་བ་ནི་ཇི་ནས་ད་ལྟར་གྱི་དུས་ནས་དགེ་བའི་སེམས་བསྐྱེད་པ༌[^97]དང་། མ་འོངས་པའི་དུས་ན་དགེ་བའི་སེམས་སྐྱེ་བར་འགྱུར་བ་དེ་དག་ངེས་པར་བྱང་ཆུབ་ཏུ་བསྔོ་ལ། མ་འོངས་པའི་མི་དགེ་བའི་སེམས་དང་སེམས་ལས་བྱུང་བ་སྐྱེ་བའི་སྐབས་མི་དབྱེའོ་ཞེས་དེ་ལྟ་བུར་དེ་ནས་སེམས་ལ་བསྒོ་ཞིང་སེམས་ལ་འཇོག་པར་བྱེད་པ་དེ་ནི་ཞེས་བྱ་བའི་དོན་ཏོ། །

[Block 109 [HEADING]]
##### ད་ལྟར་བྱུང་བའི་དུས་ལ་མཁས་པ། ^1-1-2-3-0

[Block 110]
ད་ལྟར་བྱུང་བའི་དུས་ལ་མཁས་པ་བསྟན་པའི་ཕྱིར། ད་ལྟར་བྱུང་བ་ལ་མཁས་པ་གང་ཞེ་ན་ཞེས་བྱ་བ་ལ་སོགས་པ་གསུངས་ཏེ།[^98] འདོད་མ་ཆགས་པ་ལ་སོགས་པ་དགེ་བའི་རྩ་བ་བྱེད་ཅིང་། འདོད་ཆགས་ལ་སོགས་པ་མི་དགེ་བའི་རྩ་བ་རྣམས་ལ་མི་འཇུག་པ་ནི་ཚུལ་བཞིན་སྦྱོར་བ་ཞེས་བྱ་སྟེ། དོན་གཞན་ནི་སླ་བས་མ་བཤད་དོ། །ཤེས་རབ་དང་ཐབས་ཀྱི་ཡེ་ཤེས་ཀྱིས་དུས་གསུམ་ན་གནས་པའི་དངོས་པོ་རྣམས་ཇི་ལྟ་བ་བཞིན་དུ་ཕྱིན་ཅི་མ་ལོག་པར་ཁོང་དུ་ཆུད་པ་ནི་དུས་གསུམ་ལ་མཁས་པ་ཡིན་ནོ་ཞེས༌[^99]བསྟན་པར་བཞེད་ནས། གཞན་ཡང་གང་འདས་པའི་དུས་ཀྱི་ཆོས་རྣམས་སྟོང་པར་མོས་པ་ཞེས་བྱ་བ་ལ་སོགས་པ་གསུངས་ཏེ། གང་འདས་པའི་དུས་ཀྱི་ཆོས་ཕུང་པོ་དང་། སྐྱེ་མཆེད་ལ་སོགས་པ་གང་ཟག་དང་ཆོས་ཀྱི་དངོས་པོར་ཡོད་པ༌[^100]མ་ཡིན་པ་ཡིད་ཆེས་པ་ནི་འདས་པའི་དུས་ཀྱི་ཆོས་རྣམས་སྟོང་པར་མོས་པའོ། །
