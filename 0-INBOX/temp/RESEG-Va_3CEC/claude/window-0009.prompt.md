=== SYSTEM PROMPT ===
You are an expert in classical Tibetan Buddhist commentary (འགྲེལ་པ་) structure.

You are given a numbered list of blocks from a Tibetan verse commentary. A
rule-based segmenter has already cut them; most cuts are right. Your job is to
output the few merge/split operations that bring the blocks to the layout the
human editors of this vault use.

━━━ TARGET LAYOUT — one block per FUNCTIONAL UNIT ━━━

OPENER       A node's division announcement together with the first-child opener
             that follows it is ONE block:
               "<topic> ལ་གསུམ། A། B། C་འོ། །དང་པོ་ནི།"
             A sibling opener "གཉིས་པ་ <title> ནི།" is its own block.
ROOT QUOTE   A quoted root stanza is its own block. These blocks are tagged
             [VERSE]; they are protected — never include them in any operation.
EXPLANATION  The gloss that follows a quote ("ཞེས་པ་སྟེ། …", "ཞེས་པ་ནི། …", or a
             running explanation) is ONE block up to the next opener, quote or
             heading — even when it is long (100–250 syllables) and contains several
             sentence ends, a question and answer ("…ལོ། །གང་ལ་ན། …"), a side remark
             on a variant reading ("…ཞེས་འགྱུར་བཅོས་…"), a cross-reference
             ("འདི་དང་འོག་གི་ས་བཅད་…"), or a mantra cited in passing.
SECOND LEVEL A passage that re-reads the same stanza on another level — opening
             "སྦས་དོན་ནི།", "ངེས་དོན་ནི།", "ངེས་པའི་དོན་དུ།", "ཟབ་དོན་ནི།",
             "དེའི་ནང་གི་དོན་ལ།", "མཐར་ཐུག་གི་དོན་ནི།" or the like after the literal
             gloss — is its OWN block, never merged into the literal gloss before it
             (the editors keep the two readings apart). Within that passage, M1 applies.
FRAME        The namo line alone; each of the author's own verses one block;
             "སྨྲས་པ།" alone; the colophon ("ཅེས་ … སྦྱར་བའོ། །" + closing wishes) one block.

━━━ MERGE — adjacent blocks that are one unit ━━━

M1  CONTINUED EXPLANATION
    A block that goes on explaining the same quote/topic as the block before it —
    no new opener, no new quote, no new verse being treated — belongs to that block.
    This is the most common fix. Do NOT keep a cut just because a sentence ends.
    Exception: a SECOND LEVEL opener (see above) always starts a new block.
M2  INCOMPLETE SENTENCE
    A block ending in a connector (དང་། / ཞིང་། / ཅིང་། / ནས། / སྟེ། / ཏེ།) that
    the next block completes.
M3  OPENER CHAIN
    An enumeration block followed by "དང་པོ་ནི།" / "དང་པོ་ལ་ N།" (and further
    nested first-child enumerations) — merge them into one opener block.
M4  COLOPHON
    The parts of the closing colophon and its final wishes form one block.

━━━ SPLIT — one block that holds two units ━━━

S1  A new node opener (ordinal + title + "ནི།" or "ལ་ N།") buried mid-block:
    split before it.
S2  The treatment of a new verse/topic starts mid-block (e.g. "ཡང་ཕྱག་གང་ལ་འཚལ་ན"
    starting the next homage): split before it.
S3  An introductory opener "… ནི།" fused to the explanation of the PREVIOUS
    quote: split so the opener starts the next unit.

Never split a block only because it is long.

━━━ TOPIC SHIFT vs CONTINUATION (from the editors' corrections) ━━━

The editors' blocks are large (median ≈ 55 syllables; whole explanations of
100–250 syllables are normal). A sentence end is NOT a boundary. Inside one
explanation they cut only where the commentary turns to something new:
  START a new block at   "ཡང་ན་ …" (an alternative explanation)
                         "ཁ་ཅིག་ …", "གཞན་དག་ …" (another party's view)
                         "འོ་ན་ …" (the reply to an objection)
                         "དེ་སྐད་དུ་ …", "ཇི་སྐད་དུ་ …" (introducing a supporting quotation)
                         "དེ་ནས་ …" when it opens the next step of a procedure
                         "དཔེ་ …" / "དཔེར་ན་ …" when an example section begins
KEEP WITH the block before (merge into it):
                         "ད་ནི་ …" — a transitional "now …" line is not a new unit
                         (no heading or verse between them)
                         "ལེའུ་ … པའོ། །" — a chapter-closing line stays with the
                         explanation it closes
                         "ཞེས་ / ཅེས་ …" — the quotative closing the words just before it

━━━ HEADING / VERSE BLOCKS — always KEEP ━━━

Blocks tagged [HEADING] or [VERSE] are NEVER part of any operation.

━━━ OUTPUT FORMAT ━━━

A JSON array of operations. Blocks not mentioned are kept as-is.

[
  {"op": "merge", "blocks": [N, M]},
  {"op": "merge", "blocks": [N, M, P]},
  {"op": "split", "block": N, "after": "<verbatim unique substring ending at split point>"},
  {"op": "split", "block": N, "after": ["<sub1>", "<sub2>", "<sub3>"]}
]

Rules for the output:
- Block numbers are CONTINUOUS and INCLUDE heading and verse blocks. You may only
  merge blocks with consecutive numbers (N and N+1). Never merge across a heading
  or a verse block, and never propose a merge whose numbers skip over one.
- Each block number appears in AT MOST ONE operation.
- For each "after" substring: copy a verbatim slice from the block that ends exactly
  at the split point and is UNIQUE within that block (10–20 characters is usually enough).
- If nothing needs to change in this window, output: []
- Output ONLY the JSON array. No explanation, no commentary, no code fences.

སྡུག་པ་དང་བྲལ་བ་ནི་སེམས་ཅན་གྱི་གྲངས་སུ་གཏོགས་པ་འམ། སེམས་ཅན་གྱི་གྲངས་སུ་མ་གཏོགས་པ་ཡང་རུང་། ཡིད་དུ་འོང་བའི་དངོས་པོ་དང་བྲལ་བའོ། །

[Block 326]
ཅིའི་ཕྱིར་སྡུག་པ་དང་བྲལ་བ་སྡུག་བསྔལ་བ་ཞེས་བྱ་ཞེ་ན། སྡུག་པ་དང་བྲལ་བར་དོགས་པ་འམ། མཐོང་བ་འམ། རྗེས་སུ་དྲན་པས་ཀྱང་མྱ་ངན་དང་། སྨྲེ་སྔགས་འདོན་པ་དང་། ཡིད་མི་བདེ་བ་དང་། འཁྲུགས་པའི༌[^307]སྡུག་བསྔལ་འབྱུང་བར་བྱེད་པས་ན་སྡུག་པ་དང་བྲལ་བ༌[^308]སྡུག་བསྔལ་བའོ། །

[Block 327]
འདོད་པ་བཙལ་ཏེ་མ༌[^309]རྙེད་པ་ནི་སྡུག་བསྔལ་བ་དང་བྲལ་བ་ལ་ཡང་མི་ཕྲད་པར་འདོད་པ་དང་། བདེ་བ་དང་ཕྲད་པ་དང༌[^310]ཡང་མི་འབྲལ་བར་འདོད་པ་དེ་བཙལ་ན༌[^311]མ་གྲུབ་པའོ། །

[Block 328]
ཡང་ན་སྡུག་པ་དང་ཕྲད་པར་འདོད་པ་དང་། མི་སྡུག་པ་དང་བྲལ་བར་འདོད་པ་ལས་སྡུག་པ་དང་མ་ཕྲད་ལ།[^312] མི་སྡུག་པ་དང་ཕྲད་པར་གྱུར་པ་ནི་གང་འདོད་པ་བཙལ་ཏེ་མ༌[^313]རྙེད་པ་ཞེས་བྱའོ། །

[Block 329]
ཅིའི་ཕྱིར་གང་འདོད་པ་བཙལ་ཏེ༌[^314]མ་རྙེད་པ་སྡུག་བསྔལ་བ་ཞེས་བྱ་ཞེ་ན། སྡུག་བསྔལ་སྐྱེ་བའི་རྒྱུར་གྱུར་བའི་ཕྱིར་ཏེ། དུས་གསུམ་དུའང་བདག་གིས་གང་བཙལ་བ་དེ་མ་རྙེད་དོ་ཞེས་སྡུག་བསྔལ་སྐྱེ་བའི་ཕྱིར་རོ། །

[Block 330]
མདོར་ན་ཉེ་བར་ལེན་པའི་ཕུང་པོ་ལྔ་སྡུག་བསྔལ་བ་ཞེས་བྱ་བ་ནི་ཉེ་བར་ལེན་པའི་ཕུང་པོ༌[^315]ལྔར་སྡུག་བསྔལ་ཐམས་ཅད་འདུས་ཏེ། སྡུག་བསྔལ་གྱི་རྟེན་ཡིན་པའི་ཕྱིར་དེ་སྐད་ཅེས་བྱའོ། །

[Block 331]
ཆོས་ཐམས་ཅད་ལ་བདག་མེད་པར་རྟོགས་པ༌[^316]དང་ཞེས་བྱ་བ་ལ། ཆོས་ཐམས་ཅད་ནི་འདུས་བྱས་དང་། འདུས་མ་བྱས་དང་། ཟག་པ་དང་བཅས་པ་དང་། ཟག་པ་མེད་པའོ། །

[Block 332]
གང་ན་གང་མེད་པར་ཤེས་པ་ཆོས་ཐམས་ཅད་ལ་བདག་མེད་པར་རྟོགས་པ༌[^317]སྟེ། ཆོས༌[^318]དག་ལ་མུ་སྟེགས་ཅན་གྱིས་བརྟག་པའི༌[^319]བདག་རྟག་པ་མེད་པར་ཁོང་དུ་ཆུད་པའོ། །

[Block 333]
མྱ་ངན་ལས་འདས་པ་ཞི་བ་ལ་མངོན་པར་དགའ་བ་ཞེས་བྱ་བ་ལ། མྱ་ངན་ལས་འདས་པ་ནི་སྡུག་བསྔལ་སྤངས་པ་དང་། འདོད་ཆགས་ལ་སོགས་པ་སྤངས་པའི་ཕྱིར་ཞི་བའོ། །

[Block 334]
ཡང་ན་མྱ་ངན་ལས་འདས་པ་རྣམ་པ་གཉིས་ཏེ། ཕུང་པོའི༌[^320]ལྷག་མ་དང༌[^321]བཅས་པའི་མྱ་ངན་ལས་འདས་པ་དང་། ཕུང་པོའི་ལྷག་མ་མ་ལུས་པར་སྤངས་པའི་མྱ་ངན་ལས་འདས༌[^322]པའོ། །

[Block 335]
དེ་ལ་ཞི་བ་ཞེས་བྱ་བས་ཕུང་པོ་ལྷག་མ་དང་བཅས་པའི་མྱ་ངན་ལས་འདས་པ་བསྟན་ཏེ། ཉོན་མོངས་པ་ཐམས་ཅད་སྤངས་ནས་ཕུང་པོ་ཙམ་ཡོད་པའི་ཕྱིར་རོ། །

[Block 336]
མྱ་ངན་ལས་འདས་པ་ཞེས་བྱ་བས་ཕུང་པོའི་ལྷག་མ་མ་ལུས་པ་སྤངས་པའི་མྱ་ངན་ལས་འདས་པ་བསྟན་ཏེ། ཉོན་མོངས་པ་དང་ཕུང་པོ་གཉི་ག་ཡང་སྤངས་པའི་ཕྱིར་རོ། །

[Block 337]
མངོན་པར་དགའ་བ་ནི་དེ་ཐོབ་པར་མོས་པ་དང་། དེ་འཐོབ་པར་འདོད་པའོ། །

[Block 338]
སྐད་ཅིག་ཀྱང་སྲིད་པར་སྐྱེ་བར་མི༌[^323]འདོད་པ་ཞེས་བྱ་བ་ལ། ཅུང་ཟད་ཀྱང་ཁམས་གསུམ་དུ་སྐྱེ་བར༌[^324]མ་མོས་ཞེས་བྱ་བའི་ཐ་ཚིག་སྟེ། ཅིའི་ཕྱིར་ཞེ་ན། ཁམས་གསུམ་མཐའ་དག་རྟག་ཏུ་འདུ་བྱེད་ཀྱི་སྡུག་བསྔལ་དང་རྗེས་སུ་འབྲེལ་ཞིང་དེས་ཁྱབ་པར་མཐོང་བས་སོ། །

[Block 339]
རྟག་ཏུ་འཇིགས་པར༌[^325]ལྟ་ཞེས་བྱ་བ་འདིར་ཡང་སྲིད་པ་ལ་ཞེས་བྱ་བར་སྦྱར་ཏེ། སྡུག་བསྔལ་གྱི་སྡུག་བསྔལ་དང་ལྡན་པ་འམ། ཉོན་མོངས་པ་འབྱུང་བའི༌[^326]གནས་ཡིན་པར་མཐོང་བས་ན་རྟག་ཏུ་འཇིགས་པར༌[^327]ལྟའོ། །

[Block 340]
རྟག་ཏུ་ཡིད་མི་རྟོན་ཅེས་བྱ་བ་འདིར་ཡང་སྲིད་པ་ལ་ཞེས་བྱ་བར་སྦྱར་ཏེ། ཐང་ཅིག་བདེ་བ་རྣམས་ཀྱང་ཕྱིས་སྡུག་བསྔལ་བའི་རྒྱུར་གྱུར་པ༌[^328]འགྱུར་བའི་སྡུག་བསྔལ་དང་ལྡན་པའི་ཕྱིར་རྟག་ཏུ་ཡིད་མི་རྟོན་པའོ། །

[Block 341]
ཕུང་པོ་རྣམས་ལ་གསོད་པར་འདུ་ཤེས་དང་ཞེས་བྱ་བ་ལ། དཔེར་ན་གཤེད་པོས་གསོད་ཅིང་སྡུག་བསྔལ་སྐྱེད་པར་བྱེད་པ་དེ་བཞིན་དུ་ཕུང་པོ་ལ་བདག་ཏུ་དམིགས་ན་ཡང་སྐྱེ་རྒ་ན་འཆིའི་སྡུག་བསྔལ་སྐྱེ་བར་མཐོང་བས་དེ་དག་ཕུང་པོ་རྣམས་ལ་གསོད་པར་འདུ་ཤེས་སོ། །

[Block 342]
ཁམས་རྣམས་ལ་སྦྲུལ་གདུག་པ་ལྟ་བུར་རྟོག་པའི་འདུ་ཤེས་ཞེས་བྱ་བ༌[^329]ལ། ཇི་ལྟར་སྦྲུལ་གདུག་པས་སྡུག་བསྔལ་དང་ཉོན་མོངས་པ་བསྐྱེད་པ༌[^330]དེ་བཞིན་དུ་མིག་ལ་སོགས་པའི་ཁམས་ལ་བརྟེན་ནས་གཟུགས་ལ་སོགས་པའི་ཁམས་ལ་དམིགས་ནས་འདོད་ཆགས་དང་ཞེ་སྡང་ལ་སོགས་པའི་ཉོན་མོངས་པ་འབྱུང་བར་ཁོང་དུ་ཆུད་པས་ན་ཁམས་རྣམས༌[^331]ལ་སྦྲུལ་གདུག་པ་ལྟ་བུར་རྟོག་པའི་འདུ་ཤེས་པ་ཞེས་བྱའོ། །

[Block 343]
སྐྱེ་མཆེད་རྣམས་ལ་གྲོང་སྟོང་པ་ལྟ་བུར་འདུ་ཤེས་པ་དང་ཞེས་བྱ་བ་ལ། ཇི་ལྟར་གྲོང་སྟོང་པ་ན་སྐྱེ་བོ་དག་རྒྱུ་བ་མི་གནས་པས་སྟོང་པ་དེ་བཞིན་དུ་སྐྱེ་མཆེད་བཅུ་གཉིས་ཀྱང་མིང་དང་གཟུགས་ཙམ་དུ་ཟད་ཀྱི། བདག་དང་བདག་གིར་མེད་པར་རྟོག༌[^332]པས་ན་སྐྱེ་མཆེད་རྣམས་ལ༌[^333]གྲོང་སྟོང་ལྟ་བུར་འདུ་ཤེས་པ་ཞེས་བྱའོ། །

[Block 344]
སྐྱེ་བའི་གནས་ཐམས་ཅད་ལ་མི་སྨོན་པའི་འདུ་ཤེས་ཞེས་བྱ་བ་ལ་སྐྱེ་བའི་གནས་ནི་བཞི༌[^334]སྟེ། མངལ་ནས་སྐྱེ་བ་དང་། རྫུས་ཏེ༌[^335]སྐྱེ་བ་དང་། སྒོ་ང་ལས་སྐྱེ་བ་དང་། དྲོད་གཤེར་ལས་སྐྱེ་བའོ།[^336] །སྐྱེས་ན་དེའི་རྒྱུས་སྐྱེ་བ་དང་། རྒ་བ་དང་ན་བ་དང་འཆི་བ་ལ་སོགས་པའི་སྡུག་བསྔལ་འབྱུང་བར་མཐོང་བས་སྐྱེ་གནས་དེ་དག་ཏུ་སྐྱེ་བར་མི་འདོད་ཅིང་སྐྱེ་བ་མི༌[^337]ཚོལ་བས་ན་མི་སྨོན་པའི་འདུ་ཤེས་ཞེས་བྱའོ། །

[Block 345 [HEADING]]
###### **གཉེན་པོའི་ས་ལ་ཡོན་ཏན་དུ་ལྟ་བ།** ^1-1-3-3-2-2-0

[Block 346]
གཉེན་པོའི་ས་ལ་ཡོན་ཏན་དུ་ལྟ་བ་ཡང་རྣམ་པ་གཉིས་ཏེ། རྣམ་པར་གྲོལ་བའི་བདེ་བའི་རྟེན་དུ་གྱུར་པ་དང་། འཁོར་བ་ལས་བརྒལ༌[^338]ཞིང་སྡུག་བསྔལ་ཀུན་སྤངས་པར་བལྟ༌[^339]བའོ། །

[Block 347 [HEADING]]
###### **རྣམ་པར་གྲོལ་བའི་བདེ་བའི་རྟེན་དུ་གྱུར་པ།** ^1-1-3-3-2-2-1-0

[Block 348]
འདི་ལྟ་སྟེ་མྱ་ངན་ལས་འདས་པ་ནི་འཁོར་བའི་གཉེན་པོ་ཡིན་ཏེ། མྱ་ངན་ལས་འདས་པ་ལ་རྣམ་པར་གྲོལ་བའི་བདེ་བ་ཐམས་ཅད་ཀྱི་རྟེན་དུ་ལྟ་བས་མྱ་ངན་ལས་འདས་པ་ལ་གནས་སུ་འདུ་ཤེས་པ་ཞེས་བྱའོ། །

[Block 349 [HEADING]]
###### **འཁོར་བ་ལས་བརྒལ་ཞིང་སྡུག་བསྔལ་ཀུན་སྤངས་པ།** ^1-1-3-3-2-2-2-0

[Block 351 [HEADING]]
##### རང་སངས་རྒྱས་ཀྱི་ཐེག་པ་ལ་མཁས་པ། ^1-1-3-4-0

[Block 352]
ཉན་ཐོས་ཀྱི་ཐེག་པ་ལ་མཁས་པ་བསྟན་ནས། རང་སངས་རྒྱས་ཀྱི་ཐེག་པ་ལ་མཁས་པ་བསྟན་པའི་ཕྱིར། དེ་ལ་བྱང་ཆུབ་སེམས་དཔའི་རང་སངས་རྒྱས་ཀྱི་ཐེག་པ་ལ་མཁས་པ་གང་ཞེ་ན་ཞེས་བྱ་བ་ལ་སོགས་པ་གསུངས་ཏེ། བྱང་ཆུབ་སེམས་དཔའ་རྣམས་ཀྱིས༌[^341]ཤེས་པར་བྱ་བའི་རང་སངས་རྒྱས་ཀྱི་ཐེག་པ་ནི་བྱང་ཆུབ་སེམས་དཔའི་རང་སངས་རྒྱས་ཀྱི་ཐེག་པ་ཞེས་བྱ་སྟེ། གང་དག་བསྐལ་པ་གཅིག་གིས༌[^342]ཡེ་ཤེས་ཀྱི་ཚོགས་ཡོངས་སུ་བསྐངས་ཏེ། གཞན་གྱི༌[^343]མན་ངག་མེད་པར་འཕགས་པའི་ལམ་ཐོབ་ནས་ཁམས་གསུམ་པའི་འདོད་ཆགས་དང་བྲལ་བར་ཞུགས་པ་དེ་དག་ནི་སྙིང་རྗེ་ཆེན་པོ་མེད་པས་གཞན་ལ་ལུང་དཔོག་པའི༌[^344]བྱ་བ་མེད་པ་དང་། བདག་གཅིག་པུ་སངས་རྒྱས་པར་བྱེད་པས་རང་སངས་རྒྱས་སོ། །

[Block 353]
རང་སངས་རྒྱས་དེ་དག་རྣམ་པར་གྲོལ་བའི་སར་ཕྱིན་པར་བྱེད་པའི་ཐེག་པ་ནི་རང་སངས་རྒྱས་ཀྱི་ཐེག་པ་སྟེ། གང་ཞེ་ན་ཞེས་བྱ་བ་ནི་རང་སངས་རྒྱས་ཀྱི་ཐེག་པ་ལ་མཁས་པ་དྲིས་པའོ། །
