Enumeration Block 1:
དེ་ནི་རྣམ་པ་གསུམ་དུ་བལྟ་བར༌[^2039]བྱ་སྟེ།
Enumeration Block 2:
དེ་ནི་རྣམ་པ་བཞིར་བལྟ་བར་བྱ་སྟེ།
Enumeration Block 3:
དེ་ནི་རྣམ་པ་ལྔར་བལྟ་བར་བྱ་སྟེ།
Enumeration Block 4:
དེ་ནི་རྣམ་པ་དྲུག་དང་རྣམ་པ་བདུན་ཏེ། གཅིག་ཏུ་བསྡུས་ན་རྣམ་པ་བཅུ་གསུམ་དུ་བལྟ་བར་བྱ་སྟེ།
Enumeration Block 5:
དེ་ནི་རྣམ་པ་བརྒྱད་དུ་བལྟ་བར་བྱ་སྟེ།
Enumeration Block 6:
དེ་ནི་རྣམ་པ་དགུར་བལྟ་བར་བྱ་སྟེ།
Enumeration Block 7:
དེ་ནི་རྣམ་པ༌[^2064]བཅུར་བལྟ་བར་བྱ་སྟེ། ཕྱི་རོལ་དག་པ་ལས་བརྟེན་ཏེ་རྣམ་པ་ལྔ་དང་། ནང་དག་པ་ལས་བརྟེན་ཏེ་རྣམ་པ་ལྔའོ། །
Enumeration Block 8:
དེ་ལ་ཕྱི་རོལ་དག་པ་ལས་བརྟེན་ཏེ། བྱང་ཆུབ་སེམས་དཔའ་རྣམས་ཀྱི་སེམས་ཅན་རྣམས་ལ་དོན་སྤྱོད་པ་རྣམ་པ་ལྔ་གང་ཞེ་ན།
ཁ་ན་མ་ཐོ་བ་མེད་པ་དང་། ཕྱིན་ཅི༌[^2065]མི་ལྡོག་པ་དང་། རིམས་སུ་འབབ་པ་དང་། ཀུན་དུ་འགྲོ་བ་དང་། མཐུན་མཐུན་དུ་སྦྱོར་བ་སྟེ།
Enumeration Block 9:
དེ་ལ་སྦྱིན་པ་རྣམ་པ་དུ་མ་གང་ཡིན་པ་ནས་སྔ་མ་བཞིན་དུ་དོན་མཐུན་པའི་བར་གྱི་དགེ་བའི་ཆོས་བྱང་ཆུབ་ཀྱི་ཕྱོགས་རྣམ་པ་དུ་མ་དཔག་ཏུ་མེད་པ་དེ་དག་ནི་རྒྱུ་གསུམ་གྱིས་ཀུན་དུ་སྤྱོད་པར་རིག་པར་བྱའོ། །
རྒྱུ་གཉིས་ཀྱིས་ཕུལ་དུ་བྱུང་བར་རིག་པར་བྱའོ། །
རྒྱུ་གསུམ་གྱིས་ནི་རྣམ་པར་དག་པར་རིག་པར་བྱ་སྟེ།
Enumeration Block 10:
དེ་ལ་ཀུན་ནས་ཉོན་མོངས་པ་ཅན་མ་ཡིན་པ་ནི་རྣམ་པ་བཞིར་རིག་པར་བྱ་སྟེ།
