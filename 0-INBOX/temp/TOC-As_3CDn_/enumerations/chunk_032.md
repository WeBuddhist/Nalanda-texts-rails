Enumeration Block 1:
དེ་ནི་མདོར་བསྡུ༌[^1885]ན་རྣམ་པ་བཅུར་རིག་པར་བྱ་སྟེ། འཚམ་པ་དང་། གོམས་པ་དང་། མི་གཡེལ་བ་དང་། ལེགས་པར་ཟིན་པ་དང་། དུས་སུ་གོམས་པར་བརྩོན་པ་དང་། མཚན་མ་རྟོགས་པ་དང་ལྡན་པ་དང་། ཞུམ་པ་མེད་པ་དང་། མི་ལྡན་པ་མེད་པ་དང་། སྙོམས་པ་དང་། བྱང་ཆུབ་ཆེན་པོར་ཡོངས་སུ་བསྔོ་བ་སྟེ།
Enumeration Block 2:
དེ་ནི་རྣམ་པ་གཉིས་སུ་རིག་པར་བྱ་སྟེ། འཇིག་རྟེན་པའི་དང་། འཇིག་རྟེན་ལས་འདས་པའིའོ།[^1905] །
དེ་ཡང་ཅི་རིགས་པར་རྣམ་པ་གསུམ་དུ་རིག་པར་བྱ་སྟེ། ཚེ་འདི་ལ་བདེ་བར་གནས་པར་བྱ་བའི་བསམ་གཏན་དང་། བྱང་ཆུབ་སེམས་དཔའི་ཏིང་ངེ་འཛིན་གྱི་ཡོན་ཏན་སྒྲུབ་པའི་བསམ་གཏན་དང་། སེམས་ཅན་གྱི་དོན་བྱ་བའི་བསམ་གཏན་ནོ། །
Enumeration Block 3:
བྱང་ཆུབ་སེམས་དཔའི་སེམས་ཅན་གྱི་དོན་བྱ་བའི་བསམ་གཏན་ནི་རྣམ་པ་བཅུ་གཅིག་སྟེ།
Enumeration Block 4:
དེ་ནི་རྣམ་པ་གསུམ་དུ་བལྟ་བར་བྱ་སྟེ།
Enumeration Block 5:
རྣམ་པ་བཞིར་བལྟ་བར་བྱ་སྟེ། རྟོག་པ་དང་བཅས་དཔྱོད་པ་དང་བཅས་པ་དང་། དགའ་བ་དང་ལྡན་པ་དང་། ཚིམ་པའི༌[^1921]བདེ་བ་དང་ལྡན་པ་དང་། བཏང་སྙོམས་དང་ལྡན་པའོ། །
Enumeration Block 6:
དེ་ནི་རྣམ་པ་ལྔར་བལྟ་བར་བྱ་སྟེ། རོ་མྱང་བ་མེད་པ་དང་། བྱམས་པ་དང་ལྡན་པ་དང་། སྙིང་རྗེ་དང་ལྡན་པ་དང་། དགའ་བ་དང་ལྡན་པ་དང་། བཏང་སྙོམས་དང་ལྡན་པའོ། །
Enumeration Block 7:
དེ་ནི་རྣམ་པ་དྲུག་དང་རྣམ་པ་བདུན་ཏེ། གཅིག་ཏུ་བསྡུས་ན༌[^1922]རྣམ་པ་བཅུ་གསུམ་ཡོད་པར་རིག་པར་བྱ་སྟེ།
Enumeration Block 8:
དེ་ནི་རྣམ་པ་བརྒྱད་དུ་བལྟ་བར་བྱ་སྟེ།
Enumeration Block 9:
དེ་ནི་རྣམ་པ་དགུར་བལྟ་བར་བྱ་སྟེ།
Enumeration Block 10:
དེ་ནི་རྣམ་པ་བཅུར་རིག་པར་བྱ་སྟེ།
Enumeration Block 11:
དེ་ནི་རྣམ་པ་གཉིས་སུ་བལྟ་བར་བྱ་སྟེ། འཇིག་རྟེན་པའི་དང་། འཇིག་རྟེན་ལས་འདས་པའིའོ།[^1945] །
དེ་ཡང་མདོར་བསྡུ༌[^1946]ན་རྣམ་པ་གསུམ་དུ་རིག་པར་བྱ་སྟེ། ཤེས་བྱ་ལ་དེ་ཁོ་ན་ཁོང་དུ་ཆུད་ཅིང་རྟོགས་པར་བྱ་བ་དང་། ཇི་སྐད་བསྟན་པའི་རིག་པའི་གནས་ལྔ་པོ་རྣམས་དང་། ཚོགས་གསུམ་ལ་མཁས་པར་བྱ་བ་དང་། སེམས་ཅན་གྱི་དོན་བྱ་བའོ། །
Enumeration Block 12:
སེམས་ཅན་གྱི་དོན་བྱ་བ་ནི་སྔ་མ་བཞིན་དུ་རྣམ་པ་བཅུ་གཅིག་ཁོ་ནར་རིག་པར་བྱ་སྟེ།
Enumeration Block 13:
དེ་ནི་རྣམ་པ་གསུམ་དུ་བལྟ་བར་བྱ་སྟེ། ཆོས་བདག་མེད་པ་ཟབ་མོ་ཤེས་པར༌[^1951]དཀའ་བ་དང་། སེམས་ཅན་རྣམས་འདུལ་བའི་ཐབས་ཤེས་པར་དཀའ་བ་དང་། ཤེས་བྱ་ཐམས་ཅད་ལ་སྒྲིབ་པ་མེད་པར་ཤེས་པ་མཆོག་ཏུ་དཀའ་བའོ། །
Enumeration Block 14:
དེ་ནི་རྣམ་པ་བཞིར་བལྟ་བར་བྱ་སྟེ།
Enumeration Block 15:
དེ་ནི་རྣམ་པ་ལྔར་བལྟ་བར་བྱ་སྟེ།
Enumeration Block 16:
དེ་ནི་རྣམ་པ་དྲུག་དང་རྣམ་པ་བདུན་ཏེ། གཅིག་ཏུ་བསྡུས་ན་རྣམ་པ་བཅུ་གསུམ་ཡོད་པར་རིག་པར་བྱ་སྟེ།
Enumeration Block 17:
དེ་ནི་རྣམ་པ་བརྒྱད་དུ་བལྟ་བར་བྱ་སྟེ།
Enumeration Block 18:
དེ་ནི་རྣམ་པ་དགུར་རིག་པར་བྱ་སྟེ།
Enumeration Block 19:
དེ་ནི་མདོར་བསྡུ་ན་རྣམ་པ་བཅུར་རིག་པར་བྱ་སྟེ།
