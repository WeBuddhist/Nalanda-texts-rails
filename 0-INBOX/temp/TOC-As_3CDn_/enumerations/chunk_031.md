Enumeration Block 1:
དེ་ནི་རྣམ་པ་གསུམ་དུ་བལྟ་བར༌[^1806]བྱ་སྟེ།
Enumeration Block 2:
དེ་ནི་རྣམ་པ་བཞིར་བལྟ་བར་བྱ་སྟེ།
Enumeration Block 3:
དེ་ནི་རྣམ་པ་ལྔར་བལྟ་བར་བྱ་སྟེ།
Enumeration Block 4:
དེ་ནི་རྣམ་པ་དྲུག་དང་རྣམ་པ༌[^1816]བདུན་ཏེ། གཅིག་ཏུ་བསྡུས་ན་རྣམ་པ་བཅུ་གསུམ་དུ་ཡོད་པར་རིག་པར་བྱ་སྟེ།
Enumeration Block 5:
དེ་ནི་རྣམ་པ་བརྒྱད་དུ་བལྟ་བར་བྱ་སྟེ།
Enumeration Block 6:
དེ་ནི་རྣམ་པ་དགུར་བལྟ་བར་བྱ་སྟེ།[^1831]
Enumeration Block 7:
དེ་ནི་རྣམ་པ་བཅུར་བལྟ་བར་བྱ་སྟེ།
Enumeration Block 8:
དེ་ནི་མདོར་བསྡུ་ན་རྣམ་པ་གཉིས་སུ་རིག་པར་བྱའོ། །
ཁྱིམ་པའི་ཕྱོགས་ལ་བརྟེན་པ་དང་། རབ་ཏུ་བྱུང་བའི་ཕྱོགས་ལ་བརྟེན་པའོ། །
ཕྱོགས་གཉིས་ལ་བརྟེན་པ་དེ་ཡང་རྣམ་པ་གསུམ་དུ་རིག་པར་བྱ་སྟེ། གོ་ཆའི་བརྩོན་འགྲུས་དང་། དགེ་བའི་ཕྱོགས་ཀྱི་ཆོས་སྡུད་པ་དང་། སེམས་ཅན་གྱི་དོན་བྱ་བའོ། །
Enumeration Block 9:
དེ་ཡང་མདོར་བསྡུ་ན་རྣམ་པ་བདུན་དུ་རིག་པར་བྱ་སྟེ།
Enumeration Block 10:
དེ་ནི་རྣམ་པ་གསུམ་དུ་བལྟ་བར༌[^1865]བྱ་སྟེ།
Enumeration Block 11:
འདི༌[^1866]ནི་རྣམ་པ་བཞིར་བལྟ་བར་བྱ་སྟེ། ཉོན་མོངས་པ་ཅན་གྱི་ཆོས་རྣམ་པར་སྤོང་བར༌[^1867]བྱེད་པ་དང་། དཀར་པོའི་ཆོས་སྒྲུབ་པར་བྱེད་པ་དང་། ལས་ཡོངས་སུ་དག་པར་བྱེད་པ་དང་། ཤེས་རབ༌[^1868]རྣམ་པར་འཕེལ་བར་བྱེད་པའོ། །
Enumeration Block 12:
དེ་ནི་རྣམ་པ་ལྔར་བལྟ་བར་བྱ་སྟེ།
Enumeration Block 13:
དེ་ནི་རྣམ་པ་དྲུག་དང་། རྣམ་པ་བདུན་ཏེ་གཅིག་ཏུ་བསྡུས་ན་རྣམ་པ་བཅུ་གསུམ་དུ་རིག་པར་བྱ་སྟེ།
Enumeration Block 14:
དེ་ནི་མདོར་བསྡུ༌[^1885]ན་རྣམ་པ་བཅུར་རིག་པར་བྱ་སྟེ། འཚམ་པ་དང་། གོམས་པ་དང་། མི་གཡེལ་བ་དང་། ལེགས་པར་ཟིན་པ་དང་། དུས་སུ་གོམས་པར་བརྩོན་པ་དང་། མཚན་མ་རྟོགས་པ་དང་ལྡན་པ་དང་། ཞུམ་པ་མེད་པ་དང་། མི་ལྡན་པ་མེད་པ་དང་། སྙོམས་པ་དང་། བྱང་ཆུབ་ཆེན་པོར་ཡོངས་སུ་བསྔོ་བ་སྟེ།
