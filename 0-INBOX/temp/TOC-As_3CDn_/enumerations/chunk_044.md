Enumeration Block 1:
ཆེན་པོ་བདུན་པོ་འདི་དག་ནི་གང་དང་ལྡན་ན་བྱང་ཆུབ་སེམས་དཔའ་རྣམས་ཀྱི་ཐེག་པ་ལ་ཐེག་པ་ཆེན་པོ་ཞེས་བྱ་བར་འགྱུར་བ་སྟེ། བདུན་གང་ཞེ་ན།
Enumeration Block 2:
དེ་དག་ནི་མདོར་བསྡུ༌[^2869]ན་རྣམ་པ་བཅུར་རིག་པར་བྱ་སྟེ། རིགས༌[^2870]ལ་གནས་པ་དང་། ཞུགས་པ་དང་། བསམ་པ་མ་དག་པ་དང་། བསམ་པ་དག་པ་དང་། ཡོངས་སུ་མ་སྨིན་པ་དང་། ཡོངས་སུ་སྨིན་པ་དང་། ངེས་པར་ཞུགས་པ་མ་ཡིན་པ་དང་། ངེས་པར་ཞུགས་པ་དང་སྐྱེ་བ་གཅིག་གིས་ཐོགས་པ་དང་། སྲིད་པ་ཐ་མ་པའོ། །
Enumeration Block 3:
ཡོངས་སུ་སྨིན་པ་དེ་ཡང་རྣམ་པ་གཉིས་ཏེ།
Enumeration Block 4:
ལྔ་པོ་འདི་དག་ནི་ཡང་དག་པའི་བྱང་ཆུབ་སེམས་དཔའ་རྣམས་ཀྱི་བྱང་ཆུབ་སེམས་དཔའི་རྟགས༌[^2881]ཡིན་ཏེ། དེ་དག་དང་ལྡན་ན་བྱང་ཆུབ་སེམས་དཔའ་བྱང་ཆུབ་སེམས་དཔའ་ཞེས་བྱ་བའི་གྲངས་སུ་འགྲོའོ། །

Enumeration Block 5:
དེ་ལ་སྙིང་བརྩེ་བའི་གནས་ནི་ལྔ་སྟེ། ལྔ་གང་ཞེ་ན།
སེམས་ཅན་སྡུག་བསྔལ་བ་རྣམས་དང་། ཉེས་པར་སྤྱད་པ་སྤྱོད་པ་རྣམས་དང་། བག་མེད་པ་རྣམས་དང་། ལོག་པར་ཞུགས་པ་རྣམས་དང་། ཉོན་མོངས་པའི་བག་ལ་ཉལ་བ༌[^2888]དང་ལྡན་པ་རྣམས་སོ། །
Enumeration Block 6:

Enumeration Block 7:

Enumeration Block 8:
ལྔ་པོ་འདི་དག་ནི་བྱང་ཆུབ་སེམས་དཔའི༌[^2908]ལག་རྐྱོང་བའི་གནས་ཡིན་ཏེ། ལྔ་གང་ཞེ་ན།
