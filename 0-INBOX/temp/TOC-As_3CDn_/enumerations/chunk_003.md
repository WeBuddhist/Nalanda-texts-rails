Enumeration Block 1:
དེ་ལ་རྣམ་པ་གསུམ་དུ་རིག་པར་བྱའོ་ཞེས་སྟོན་པ། མདོར་བསྡུ་ན་བྱང་ཆུབ་སེམས་དཔའ་རྣམས་གང་ལ་སློབ་པ་དང་། ཇི་ལྟར་སློབ་པ་དང་། གང་དག་སློབ་པ་དེ་དག་ཐམས་ཅད་གཅིག་ཏུ་བསྡུས་པ་ནི་བྱང་ཆུབ་སེམས་དཔའི་སྤྱོད་པ་ཞེས་བྱའོ། །
Enumeration Block 2:
གནས་བདུན་ལ་སློབ་སྟེ། གནས་བདུན་པོ་དག་གང་ཞེ་ན། བདག་གི་དོན་དང་། གཞན་གྱི་དོན་དང་། དེ་ཁོ་ནའི་དོན་དང་། མཐུ་དང་། སེམས་ཅན་ཡོངས་སུ་སྨིན་པར་བྱ་བ་དང་། རང་གི་སངས་རྒྱས་ཀྱི་ཆོས་ཡོངས་སུ་སྨིན་པར་བྱ་བ་དང་། གནས་བདུན་པ་ནི་བླ་ན་མེད་པ་ཡང་དག་པར་རྫོགས་པའི་བྱང་ཆུབ་བོ། །
Enumeration Block 3:
མདོར་བསྡུ་ན་བདག་དང་གཞན་གྱི་དོན་ནི་རྣམ་པ་བཅུར་རིག་པར་བྱའོ། ། འབའ་ཞིག་དང་གཞན་དང་འབྲེལ་པ་དང་། ཕན་པའི་རྒྱུ་དང་། བདེ་བའི་རྒྱུ་དང་། རྒྱུར་བསྡུས་པ་དང་། འབྲས་བུར་བསྡུས་པ་དང་། ཚེ་འདི་པ་དང་། ཚེ་རབས་གཞན་པ་དང་། གཏན་དུ་བ་དང་། གཏན་དུ་བ་མ་ཡིན་པའོ། །
Enumeration Block 4:
མདོར་བསྡུ་ན་རྣམ་པ༌[^188]ལྔ་ཡོད་པར་རིག་པར་བྱ་སྟེ། ཁ་ན་མ་ཐོ་བ་མེད་པའི་མཚན་ཉིད་དང་། ཕན་འདོགས༌[^189]པའི་མཚན་ཉིད་དང་། ཚེ་འདི་པ་དང་། ཚེ་གཞན་པ་དང་། ཞི་བར་བྱེད་པའོ། །
Enumeration Block 5:
མདོར་བསྡུ་ན་བདེ་བ་རྣམ་པ་ལྔར་བསྡུ་བར་རིག་པར་བྱ་སྟེ། དེ་ལ་བདེ་བ་རྣམ་པ་ལྔ་པོ་ནི་འདི་དག་ཡིན་ཏེ། རྒྱུ་བདེ་བ་དང་། ཚོར་བ་བདེ་བ་དང་། སྡུག་བསྔལ་གྱི་གཉེན་པོའི་བདེ་བ་དང་། ཚོར་བའི་རྒྱུན་ཆད་པའི་བདེ་བ་དང་། གནོད་པ་མེད་པའི་བདེ་བ་དང་ལྔའོ། །
Enumeration Block 6:
དེ་ཡང་མདོར་བསྡུ་ན་རྣམ་པ་གཉིས་ཏེ། ཟག་པ་དང་བཅས་པ་དང་། ཟག་པ་མེད་པའོ། །
Enumeration Block 7:
གནོད་པ་མེད་པའི་བདེ་བ་ནི་མདོར་བསྡུ་ན་རྣམ་པ་བཞིར་རིག་པར་བྱ་སྟེ། མངོན་པར་འབྱུང་བའི་བདེ་བ་དང་། རབ་ཏུ་དབེན་པའི་བདེ་བ་དང་། ཉེ་བར་ཞི་བའི་བདེ་བ་དང་། རྫོགས་པར་བྱང་ཆུབ་པའི་བདེ་བའོ། །
