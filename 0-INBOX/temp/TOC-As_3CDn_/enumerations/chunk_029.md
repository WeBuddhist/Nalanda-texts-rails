Enumeration Block 1:
ཕུན་སུམ་ཚོགས་པ་གསུམ་པོ་སྦྱོར་བ་ཕུན་སུམ་ཚོགས་པ་དང་། བསམ་པ་ཕུན་སུམ་ཚོགས་པ་དང་། སྔོན་གྱི་རྒྱུ་ཕུན་སུམ་ཚོགས་པ་དང་ལྡན་པས་བདེ་བ་ལ་རེག་པར་གནས་སོ། །
Enumeration Block 2:
འདི་ནི་རྣམ་པ་གསུམ་དུ་བལྟ་བར་བྱ་སྟེ།
Enumeration Block 3:
འདི་ནི་རྣམ་པ་བཞིར་བལྟ་བར་བྱ་སྟེ། ཡང་དག་པར་བླངས་པ་དང་། རང་བཞིན་གྱི༌[^1668]ཚུལ་ཁྲིམས་དང་། གོམས་པ་དང་། ཐབས་དང་ལྡན་པའོ། །
Enumeration Block 4:
དེ་ནི་རྣམ་པ་ལྔར༌[^1675]རིག་པར་བྱ་སྟེ།
Enumeration Block 5:
དེ་ནི་རྣམ་པ་དྲུག་དང་། རྣམ་པ་བདུན་ཏེ། གཅིག་ཏུ་བསྡོམས་ན་རྣམ་པ་བཅུ་གསུམ་དུ་རིག་པར་བྱ་སྟེ།
Enumeration Block 6:
དེ་ནི་རྣམ་པ་བརྒྱད་དུ་རིག་པར་བྱ་སྟེ།
Enumeration Block 7:
དེ་ནི་རྣམ་པ་དགུར་རིག་པར་བྱ་སྟེ།
Enumeration Block 8:
དེ་ནི་རྣམ་པ་བཅུར་རིག་པར་བྱ་སྟེ།
