Enumeration Block 1:
བྱང་ཆུབ་སེམས་དཔའ་ནི་རྣམ་པ་ལྔས་སེམས་ཅན་ཐམས་ཅད་ལ་སེམས་སྙོམས་པར་རིག་པར་བྱ་སྟེ། ལྔ་གང་ཞེ་ན།
Enumeration Block 2:
སེམས་ཅན་རྣམས་ལ་བྱང་ཆུབ་སེམས་དཔའ་རྣམས་ཀྱི་ཕན་འདོགས་པའི་བྱ་བ་ཐམས་ཅད་ནི་རྣམ་པ་ལྔར་རིག་པར་བྱ་སྟེ། ལྔ་གང་ཞེ་ན།
Enumeration Block 3:
རྣམ་པ་ལྔས་སེམས་ཅན་དག་བྱང་ཆུབ་སེམས་དཔའ་ཕན་འདོགས་འདོགས་པ་ལ་ལན་དུ་ཕན་འདོགས་པར་ཉེ་བར་གནས་པ་ཡིན་ཏེ། རྣམ་པ་ལྔ་གང་ཞེ་ན།
Enumeration Block 4:
ལྔ་པོ་འདི་དག་ནི་བྱང་ཆུབ་སེམས་དཔས་རྟག་ཏུ་སྨོན་པར་བྱ་བ་ཡིན་ཏེ། ལྔ་གང་ཞེ་ན།
Enumeration Block 5:
བྱང་ཆུབ་སེམས་དཔའ་སེམས་ཅན་རྣམས་ལ་དོན་བྱ་བའི་སྦྱོར་བ་ནི་རྣམ་པ་ལྔས་འབྲས་བུ་ཡོད་པར་འགྱུར་ཏེ། ལྔ་གང་ཞེ་ན།
Enumeration Block 6:
བྱང་ཆུབ་སེམས་དཔའི་ཡང་དག་པའི་སྦྱོར་བ་ཐམས་ཅད་ནི། སྦྱོར་བ་རྣམ་པ་ལྔས་བསྡུས་པར་རིག་པར་བྱ་སྟེ། ལྔ་གང་ཞེ་ན།
རྗེས་སུ་བསྲུང་བའི་སྦྱོར་བ༌[^2771]དང་། ཁ་ན་མ་ཐོ་བ་མེད་པའི་སྦྱོར་བ་དང་། །སོ་སོར་རྟོག་པའི་སྟོབས་ཀྱི་སྦྱོར་བ་དང་། །ལྷག་པའི་བསམ་པ་དག་པའི་སྦྱོར་བ་དང་། །ངེས་པར་འགྱུར་བའི༌[^2772]སྦྱོར་བའོ། །
Enumeration Block 7:
ལྔ་པོ་འདི་དག་ནི་བྱང་ཆུབ་སེམས་དཔའི་འབྲི་བ་དང་མཐུན་པའི་ཆོས་ཡིན་པར་རིག་པར་བྱ་སྟེ། ལྔ་གང་ཞེ་ན།
Enumeration Block 8:
ལྔ་པོ་འདི་དག་ནི་བྱང་ཆུབ་སེམས་དཔའ་རྣམས་ཀྱི་ཡོན་ཏན་ལྟར་བཅོས་པའི་བྱང་ཆུབ་སེམས་དཔའི་སྐྱོན་ཡིན་པར་རིག་པར་བྱ་སྟེ། ལྔ་གང་ཞེ་ན།
Enumeration Block 9:
ལྔ་པོ་འདི་དག་ནི་བྱང་ཆུབ་སེམས་དཔའི་ཡང་དག་པའི་ཡོན་ཏན་དུ་རིག་པར་བྱ་སྟེ། ལྔ་གང་ཞེ་ན།
Enumeration Block 10:
བྱང་ཆུབ་སེམས་དཔའ་རྣམས་ནི་མདོར་ན་འདུལ་བའི་སྐྱེ་བོ་རྣམས་གནས་བཅུར་ལེགས་པ་ཁོ་ནར་འདུལ་བར་བྱེད་དེ། བཅུ་གང་ཞེ་ན།
Enumeration Block 11:
དེ་བཞིན་གཤེགས་པ་རྣམས་ནི་མདོར་བསྡུ༌[^2793]ན། རྣམ་པ་དྲུག་གིས་བྱང་ཆུབ་སེམས་དཔའ་བླ་ན་མེད་པ་ཡང་དག་པར་རྫོགས་པའི་བྱང་ཆུབ་ཏུ་ལུང་སྟོན་པར་མཛད་དེ། དྲུག་གང་ཞེ་ན།
Enumeration Block 12:
བྱང་ཆུབ་སེམས་དཔའི་ངེས་པར་ཞུགས་པ་ནི་རྣམ་པ་གསུམ་སྟེ། གསུམ་གང་ཞེ་ན།
Enumeration Block 13:
བྱང་ཆུབ་སེམས་དཔའི་ངེས་པར་བྱ་བ་ནི་ལྔ་པོ་འདི་དག་ཡིན་ཏེ། དེ་དག་མ་བྱས་ན་བྱང་ཆུབ་སེམས་དཔའ་བླ་ན་མེད་པ་ཡང་དག་པར་རྫོགས་པའི་བྱང་ཆུབ་ཏུ༌[^2801]མངོན་པར་རྫོགས་པར་འཚང་རྒྱ་བའི་སྐལ་བ་མེད་པར་འགྱུར་ཏེ། ལྔ་གང་ཞེ་ན།
Enumeration Block 14:
བྱང་ཆུབ་སེམས་དཔའི་རྟག་པར༌[^2803]བྱ་བའི་གནས་ནི་ལྔ་པོ་འདི་དག་ཡིན་ཏེ། ལྔ་གང་ཞེ་ན།
Enumeration Block 15:
བྱང་ཆུབ་སེམས་དཔའ་རྣམས་ཀྱི་གཙོ་བོར་འདོད་པ་ནི་ཆོས་བཅུ་པོ་འདི་དག་ཡིན་ཏེ། དེ་དག་ནི་བྱང་ཆུབ་སེམས་དཔའ་རྣམས་ཀྱི་མཆོག་ཏུ་འཛིན་ཅིང་། མཆོག་ཏུ་འདོགས་པ་རྣམས་ལ་འདོགས་པར་བྱེད་པ་སྟེ། བཅུ་གང་ཞེ་ན།
Enumeration Block 16:
བྱང་ཆུབ་སེམས་དཔའ་རྣམས་ཀྱི་གདགས་པ་རྣམ་པར་གཞག་པ་ནི་བཞི་པོ་འདི་དག་ཡིན་ཏེ།
Enumeration Block 17:
བཞི་གང་ཞེ་ན།
ཆོས་གདགས་པ་རྣམ་པར་གཞག་པ་དང་། བདེན་པ་གདགས་པ་རྣམ་པར་གཞག་པ་དང་། རིག་པ༌[^2808]གདགས་པ་རྣམ་པར་གཞག་པ་དང་། ཐེག་པ་གདགས་པ་རྣམ་པར་གཞག་པའོ། །
