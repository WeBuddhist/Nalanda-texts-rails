Enumeration Block 1:
ཡང་བྱང་ཆུབ་སེམས་དཔས་འདུ་བྱེད༌[^2700]དང་། འདུས་མ་བྱས་ཀྱི༌[^2701]ཆོས་ཐམས་ཅད་བདག་མེད་པ་རྣམ་པ་གཉིས་སུ་ཡང་དག་པ་ཇི་ལྟ་བ་བཞིན་དུ་རབ་ཏུ་ཤེས་ཏེ། གང་ཟག་ལ་བདག་མེད་པ་དང་། ཆོས་ལ་བདག་མེད་པའོ། །
Enumeration Block 2:
ལྔ་པོ་འདི་དག་ནི་བླ་ན་མེད་པ་ཡང་དག་པར་རྫོགས་པའི་བྱང་ཆུབ་ཀྱི་ཐེག་པ་ལ་སློབ་པའི་བྱང་ཆུབ་སེམས་དཔའི་ངོ་མཚར་རྨད་དུ་བྱུང་བའི་ཆོས་ཡིན་པར་རིག་པར་བྱ་སྟེ། ལྔ་གང་ཞེ་ན།
Enumeration Block 3:
ལྔ་པོ་འདི་དག་ནི་བྱང་ཆུབ་སེམས་དཔའི་ངོ་མཚར་མ་ཡིན་ལ་གང་དག་དང་ལྡན་ན་བྱང་ཆུབ་སེམས་དཔའ་ངོ་མཚར་རྨད་དུ་བྱུང་བའི་ཆོས་དང་ལྡན་པ་ཞེས་བྱ་སྟེ། ལྔ་གང་ཞེ་ན།
Enumeration Block 4:
བྱང་ཆུབ་སེམས་དཔའ་ནི་རྣམ་པ་ལྔས་སེམས་ཅན་ཐམས་ཅད་ལ་སེམས་སྙོམས་པར་རིག་པར་བྱ་སྟེ། ལྔ་གང་ཞེ་ན།
Enumeration Block 5:
སེམས་ཅན་རྣམས་ལ་བྱང་ཆུབ་སེམས་དཔའ་རྣམས་ཀྱི་ཕན་འདོགས་པའི་བྱ་བ་ཐམས་ཅད་ནི་རྣམ་པ་ལྔར་རིག་པར་བྱ་སྟེ། ལྔ་གང་ཞེ་ན།
Enumeration Block 6:
རྣམ་པ་ལྔས་སེམས་ཅན་དག་བྱང་ཆུབ་སེམས་དཔའ་ཕན་འདོགས་འདོགས་པ་ལ་ལན་དུ་ཕན་འདོགས་པར་ཉེ་བར་གནས་པ་ཡིན་ཏེ། རྣམ་པ་ལྔ་གང་ཞེ་ན།
Enumeration Block 7:
ལྔ་པོ་འདི་དག་ནི་བྱང་ཆུབ་སེམས་དཔས་རྟག་ཏུ་སྨོན་པར་བྱ་བ་ཡིན་ཏེ། ལྔ་གང་ཞེ་ན།
Enumeration Block 8:
བྱང་ཆུབ་སེམས་དཔའ་སེམས་ཅན་རྣམས་ལ་དོན་བྱ་བའི་སྦྱོར་བ་ནི་རྣམ་པ་ལྔས་འབྲས་བུ་ཡོད་པར་འགྱུར་ཏེ། ལྔ་གང་ཞེ་ན།
