Enumeration Block 1:
དེ་ནི་རྣམ་པ་དྲུག་དང་རྣམ་པ་བདུན་ཏེ། གཅིག་ཏུ་བསྡུས་ན་རྣམ་པ་བཅུ་གསུམ་ཡོད་པར་རིག་པར་བྱ་སྟེ།
Enumeration Block 2:
དེ་ནི་རྣམ་པ་བརྒྱད་དུ་བལྟ་བར་བྱ་སྟེ།
Enumeration Block 3:
དེ་ནི་རྣམ་པ་དགུར་རིག་པར་བྱ་སྟེ།
Enumeration Block 4:
དེ་ནི་མདོར་བསྡུ་ན་རྣམ་པ་བཅུར་རིག་པར་བྱ་སྟེ།
Enumeration Block 5:
དེ་ནི་རྣམ་པ་གསུམ་དུ་བལྟ་བར༌[^1978]བྱ་སྟེ།
Enumeration Block 6:
དེ་ལ་བྱང་ཆུབ་སེམས་དཔའ་རྣམས་ཀྱི་སྙན་པར་སྨྲ་བ་ཐམས་ཅད་ནི་མདོར་བསྡུ་ན་དེ་ནི་རྣམ་པ་གཉིས་སུ་བལྟ་བར་བྱ་སྟེ། འཇིག་རྟེན་གྱི་ཚུལ་དང་ལྡན་པ་དང་། ཡང་དག་པའི་ཆོས་བསྟན་པ་དང་ལྡན་པའོ། །
Enumeration Block 7:
དེ་ནི་རྣམ་པ་གསུམ་དུ་བལྟ་བར་བྱ་སྟེ།
Enumeration Block 8:
དེ་ནི་རྣམ་པ་བཞིར་བལྟ་བར་བྱ་སྟེ།
Enumeration Block 9:
དེ་ནི་རྣམ་པ་ལྔར་བལྟ་བར་བྱ་སྟེ།
Enumeration Block 10:
དེ་ནི་རྣམ་པ་དྲུག་དང་རྣམ་པ་བདུན་ཏེ། གཅིག་ཏུ་བསྡུས་ན་རྣམ་པ༌[^2006]བཅུ་གསུམ་དུ་བལྟ་བར་བྱ་སྟེ།
Enumeration Block 11:
དེ་ནི་རྣམ་པ་བརྒྱད་དུ་བལྟ་བར་བྱ་སྟེ།
Enumeration Block 12:
དེ་ནི་རྣམ་པ་དགུར་བལྟ་བར་བྱ་སྟེ།
Enumeration Block 13:
དེ་ནི་རྣམ་པ་ཉི་ཤུར་བལྟ་བར་བྱ་སྟེ།
Enumeration Block 14:
དེ་ནི་རྣམ་པ་གཉིས་སུ་བལྟ་བར་བྱ་སྟེ། སེམས་ཅན་ཡོངས་སུ་མ་སྨིན་པ་རྣམས་ཡོངས་སུ༌[^2032]སྨིན་པར་བྱ་བ་དང་། སེམས་ཅན་ཡོངས་སུ་སྨིན་པ་རྣམས་རྣམ་པར་དགྲོལ་བའོ། །
དེ་ཡང་སྒོ་གསུམ་དུ་རིག་པར་བྱ་སྟེ། ཚེ་འདིའི་དོན་ཡང་དག་པར་འཛིན་དུ་གཞུག་པ་དང་། ཚེ་ཕྱི་མའི་དོན་ཡང་དག་པར་འཛིན་དུ་གཞུག་པ་དང་། ཚེ་འདི་དང་ཚེ་ཕྱི་མའི་དོན་ཡང་དག་པར་འཛིན་དུ་གཞུག་པའོ། །
Enumeration Block 15:
དེ་ནི་རྣམ་པ་གསུམ་དུ་བལྟ་བར༌[^2039]བྱ་སྟེ།
Enumeration Block 16:
དེ་ནི་རྣམ་པ་བཞིར་བལྟ་བར་བྱ་སྟེ།
Enumeration Block 17:
དེ་ནི་རྣམ་པ་ལྔར་བལྟ་བར་བྱ་སྟེ།
Enumeration Block 18:
དེ་ནི་རྣམ་པ་དྲུག་དང་རྣམ་པ་བདུན་ཏེ། གཅིག་ཏུ་བསྡུས་ན་རྣམ་པ་བཅུ་གསུམ་དུ་བལྟ་བར་བྱ་སྟེ།
