Enumeration Block 1:
དེ་ནི་རྣམ་པ་དགུར་རིག་པར་བྱ་སྟེ།
Enumeration Block 2:
དེ་ནི་རྣམ་པ་བཅུར་རིག་པར་བྱ་སྟེ།
Enumeration Block 3:
དེ་ནི་རྣམ་པ་གཉིས་སུ་བལྟ་བར༌[^1712]བྱ་སྟེ། ཁྱིམ་པའི་ཕྱོགས་ལ་བརྟེན་པ་དང་། རབ་ཏུ་བྱུང་བའི་ཕྱོགས་ལ་བརྟེན་པའོ། །
ཕྱོགས་དེ་གཉིས་ལ་བརྟེན་པ་དེ་ཡང་རྣམ་པ་གསུམ་དུ་རིག་པར་བྱ་སྟེ། གཞན་གནོད་པ་བྱེད་པ་ལ་ཇི་མི་སྙམ་པའི་བཟོད་པ་དང་། སྡུག་བསྔལ་དང་དུ་ལེན་པའི་བཟོད་པ་དང་། ཆོས་ལ༌[^1713]ངེས་པར་སེམས་པ་ལ་མོས་པའི་བཟོད་པའོ། །
Enumeration Block 4:
འདུ་ཤེས་ལྔ་གང་ཞེ་ན།
སྔོན་གྱི་ཚེ་རབས་སུ་སྙིང་དུ་སྡུག་པར་གྱུར་པའི་འདུ་ཤེས་དང་། ཆོས་ཙམ་གྱི་རྗེས་སུ་འབྲང་བའི་འདུ་ཤེས་དང་། མི་རྟག་པའི་འདུ་ཤེས་དང་། སྡུག་བསྔལ་བའི་འདུ་ཤེས་དང་། ཡོངས་སུ་བཟུང་བའི་འདུ་ཤེས་སོ། །
Enumeration Block 5:
དེ་ནི་མདོར་བསྡུ་ན་རྣམ་པ་བརྒྱད་དུ་རིག་པར་བྱ་སྟེ། [^1763]གནས་ལ༌[^1764]བརྟེན་པ་དང་། འཇིག་རྟེན་གྱི་ཆོས་ལ༌[^1765]བརྟེན་པ་དང་། སྤྱོད་ལམ་ལ༌[^1766]བརྟེན་པ་དང་། ཆོས་ཡོངས་སུ་འཛིན་པ་ལ༌[^1767]བརྟེན་པ་དང་། སློང༌[^1768]མོས་ཡོངས་སུ་འཚོ་བ་ལ་བརྟེན་པ་དང་། མངོན་པར་བརྩོན་པས་དུབ་པ་ལ་བརྟེན་པ་དང་། སེམས་ཅན་གྱི་དོན་བྱེད་པ་ལ་བརྟེན་པ་དང་། འཕྲལ་གྱི་བྱ་བ་ལ་བརྟེན་པའོ། །
Enumeration Block 6:
དེ་ནི་རྣམ་པ་གསུམ་དུ་བལྟ་བར༌[^1806]བྱ་སྟེ།
Enumeration Block 7:
དེ་ནི་རྣམ་པ་བཞིར་བལྟ་བར་བྱ་སྟེ།
