Enumeration Block 1:
དེ་ནི་མདོར་བསྡུ༌[^2339]ན་རྣམ་པ་གཉིས་སུ་རིག་པར་བྱ་སྟེ། ངོ་བོ་ཉིད་དང་གནས་སོ། །
Enumeration Block 2:
གནས་ནི་མདོར་བསྡུ༌[^2340]ན་རྣམ་པ་བཞི་སྟེ།
Enumeration Block 3:
དེ་ཡང་རྣམ་པ་གཉིས་སུ་བལྟ་བར་བྱ༌[^2347]སྟེ། ངོ་བོ་ཉིད་དང་གནས་སོ། །
Enumeration Block 4:
བྱང་ཆུབ་སེམས་དཔའི་བརྟན་པའི་སྟོབས་བསྐྱེད་པ་དེའི་གནས་ནི་མདོར་བསྡུ༌[^2351]ན་རྣམ་པ་ལྔ་ཡོད་པར་རིག་པར་བྱ་སྟེ།[^2352]
Enumeration Block 5:
དེ་ལ་བྱང་ཆུབ་སེམས་དཔའ་རྣམས་ཀྱི་ཡང་དག་པའི་སྦྱོར་བ་ཐམས་ཅད་ལ་རྒྱུ་ལྔས་ཡིད་ཡོངས་སུ་མི་སྐྱོ་བར་རིག་པར་བྱའོ། །
