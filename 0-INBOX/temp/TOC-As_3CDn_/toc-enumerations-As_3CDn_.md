Enumeration Block 1:
ཆོས་བཅུ་པོ་འདི་དག་ནི། ཐེག་པ་ཆེན་པོ་བྱང་ཆུབ་སེམས་དཔའི་ལམ་འབྲས་བུ་དང་བཅས་པ་སྡུད་པར་བྱེད་པ་ཡིན་ནོ། །
བཅུ་གང་ཞེ་ན།
གཞི་དང་། རྟགས་དང་། ཕྱོགས་དང་། ལྷག་པའི་བསམ་པ་དང་། གནས་པ་དང་། སྐྱེ་བ་དང་། ཡོངས་སུ་འཛིན་པ་དང་། ས་དང་། སྤྱོད་པ་དང་། རབ་ཏུ་གནས་པའོ། །
Enumeration Block 2:
དེ་ལ་རིགས་གང་ཞེ་ན།
མདོར༌[^5]ན་རྣམ་པ་གཉིས་ཏེ། རང་བཞིན་གྱིས༌[^6]གནས་པ་དང་། ཡང་དག་པར་བསྒྲུབས་པའོ། །
Enumeration Block 3:
གཞན་ཡང་བྱང་ཆུབ་སེམས་དཔའ་ནི་རྣམ་པ་བཞིས་ན་ཉན་ཐོས་དང་རང་སངས་རྒྱས་རྣམས་ལས་ཁྱད་པར་དུ་འཕགས་པར༌[^12]རིག་པར་བྱ་སྟེ། བཞི་གང་ཞེ་ན།
དབང་པོ་ལས་གྱུར་པ་དང་། སྒྲུབ་པ་ལས་གྱུར་པ་དང་། མཁས་པ་ལས་གྱུར་པ་དང་། འབྲས་བུ་ལས་གྱུར་པའོ། །
Enumeration Block 4:
གང་དག་གིས་ན་འདི་ནི་བྱང་ཆུབ་སེམས་དཔའ་ཡིན་ནོ་ཞེས་གཞན་དག་གིས་དེ་ལྟར་ཤེས་པར་འགྱུར་བ་བྱང་ཆུབ་སེམས་དཔའི་ཕ་རོལ་ཏུ་ཕྱིན་པ་རྣམས་ཀྱི་རིགས་ཀྱི་རྟགས་ཡོད་པ་ནི་དྲུག་པོ་འདི་དག་ཡིན་ཏེ། སྦྱིན་པའི་ཕ་རོལ་ཏུ་ཕྱིན་པའི་རིགས་ཀྱི་རྟགས་དང་། ཚུལ་ཁྲིམས་དང་། བཟོད་པ་དང་། བརྩོན་འགྲུས་དང་། བསམ་གཏན་དང་། ཤེས་རབ་ཀྱི་ཕ་རོལ་ཏུ་ཕྱིན་པའི་རིགས་ཀྱི་རྟགས་སོ། །

Enumeration Block 1:
བྱང་ཆུབ་སེམས་དཔའི་དང་པོ་སེམས་བསྐྱེད་པ་དེ་ཡང་མདོར་ན་རྣམ་པ་གཉིས་ཏེ། ངེས་པར༌[^93]འབྱིན་པ་དང་། ངེས་པར་འབྱིན་པ་མ་ཡིན་པའོ། །
Enumeration Block 2:
སེམས་བསྐྱེད་པ་དེའི་ལྡོག་པ་ལ་ཡང་རྣམ་པ་གཉིས་ཏེ། གཏན་དུ་བ་དང་། གཏན་དུ་བ་མ་ཡིན་པའོ། །
Enumeration Block 3:
སེམས་སྐྱེ་བ་དེ་ཡང་རྐྱེན་བཞི་དང་། རྒྱུ་བཞི་དང་། སྟོབས་བཞིས་སྐྱེ་བར་རིག་པར་བྱའོ། །

Enumeration Block 4:
དེ་ལ་རྒྱུ་བཞི་གང་ཞེ་ན།
Enumeration Block 5:
བྱང་ཆུབ་སེམས་དཔའི་བཤེས་གཉེན་ཕུན་སུམ་ཚོགས་པ་ནི་རྣམ་པ་བཞིར་རིག་པར་བྱ་སྟེ།
Enumeration Block 6:
སྟོབས་བཞི་གང་ཞེ་ན།
ནང༌[^128]གི་སྟོབས་དང་། གཞན་གྱི་སྟོབས་དང་། རྒྱུའི་སྟོབས་དང་། སྦྱོར་བའི་སྟོབས་སོ། །
Enumeration Block 7:
བྱང་ཆུབ་སེམས་དཔའ་སེམས་ལྡོག་པའི་རྒྱུ་ནི་རྣམ་པ་བཞི་སྟེ། བཞི་གང་ཞེ་ན།
Enumeration Block 8:
འདི་གཉིས་ནི་བྱང་ཆུབ་སེམས་དཔའ༌[^133]དང་པོ་སེམས་བསྐྱེད་པ་བརྟན་པའི་ངོ་མཚར་རྨད་དུ་བྱུང་བའི་ཆོས་འཇིག་རྟེན་དང་ཐུན་མོང་མ་ཡིན་པ་སྟེ། གཉིས་གང་ཞེ་ན།
སེམས་ཅན་ཐམས་ཅད་ཆུང་མའི་ཚུལ་དུ་ཡོངས་སུ་འཛིན་པ་དང་། ཆུང་མ་ཡོངས་སུ་འཛིན་པའི་ཉེས་པས་ཀྱང་གོས་པར་མི༌[^134]འགྱུར་བ༌[^135]ཡིན་ནོ། །
Enumeration Block 9:
འདི་གཉིས་ནི་བྱང་ཆུབ་སེམས་དཔའ་དང་པོ་སེམས་བསྐྱེད་པ་བརྟན་པའི་སེམས་ཅན་རྣམས་ལ་ལྷག་པའི་བསམ་པ་བཟང་པོ་འཇུག་པར་འགྱུར་བ་ཡིན་ཏེ། གཉིས་གང་ཞེ་ན།
ཕན་པ་བྱ་བའི་ལྷག་པའི་བསམ་པ་དང་བདེ་བ་བྱ་བའི་ལྷག་པའི་བསམ་པའོ། །
Enumeration Block 10:
འདི་གཉིས་ནི་བྱང་ཆུབ་སེམས་དཔའ་དང་པོ་སེམས་བསྐྱེད་པ་བརྟན་པའི་སྦྱོར་བ་ཡིན་ཏེ། ལྷག་པའི་བསམ་པའི་སྦྱོར་བ་དང་། སྒྲུབ་པའི་སྦྱོར་བའོ། །
Enumeration Block 11:
འདི་གཉིས་ནི་བྱང་ཆུབ་སེམས་དཔའ་དང་པོ་སེམས་བསྐྱེད་པ༌[^144]བརྟན་པའི་དགེ་བའི་ཆོས་ཆེན་པོ་འདུ་བའི་སྒོ་ཡིན་ཏེ། བླ་ན་མེད་པ་ཡང་དག་པར་རྫོགས་པའི་བྱང་ཆུབ་ཡང་དག་པར་བསྒྲུབ་པའི་ཕྱིར་བདག་གི་དོན་ལ་སྦྱོར་བ་དང་། སེམས་ཅན་ཐམས་ཅད་ཀྱི་སྡུག་བསྔལ་ཐམས་ཅད་བསལ་བའི་ཕྱིར་གཞན་གྱི་དོན་ལ་སྦྱོར་བའོ།[^145] །
Enumeration Block 12:
འདི་གཉིས་ནི་བྱང་ཆུབ་སེམས་དཔའ་དང་པོ་སེམས་བསྐྱེད་པ་བརྟན་པའི་སེམས་བསྐྱེད་པ༌[^146]ནས་བཟུང་སྟེ། བྱང་ཆུབ་ཀྱི་ཕྱིར་དགེ་བ༌[^147]ཡོངས་སུ་འཛིན་པ་ནི་དེ་ལས་གཞན་པའི་དགེ་བ་ཡོངས་སུ་འཛིན་པ་ལས་ཁྱད་པར་དུ་འཕགས་པ་ཡིན་ཏེ། རྒྱུ་ཁྱད་པར་དུ་འཕགས་པ་དང་། འབྲས་བུ་ཁྱད་པར་དུ་འཕགས་པའོ། །
Enumeration Block 13:
འདི་གཉིས་ནི་བྱང་ཆུབ་སེམས་དཔའ༌[^151]དང་པོའི་སེམས་བསྐྱེད་པ་བརྟན་པའི་སེམས་བསྐྱེད་པའི་ཕན་ཡོན་ཡིན་ཏེ། སེམས་བསྐྱེད་མ་ཐག་གིས་ཀྱང་སེམས་ཅན་ཐམས་ཅད་ཀྱི་ཡོན་གནས་སུ་གྱུར་པ་དང་། བླ་མར་གྱུར་པ་དང་། བསོད་ནམས་ཀྱི་ཞིང་དང་། སྐྱེ་དགུ་རྣམས་ཀྱི་ཕ་དང་འདྲ་བར་གྱུར་པ་དང་། གནོད་པ་མེད་པའི་བསོད་ནམས་ཡོངས་སུ་འཛིན་པར་བྱེད་དོ། །
Enumeration Block 14:
དེ་ལ་རྣམ་པ་གསུམ་དུ་རིག་པར་བྱའོ་ཞེས་སྟོན་པ། མདོར་བསྡུ་ན་བྱང་ཆུབ་སེམས་དཔའ་རྣམས་གང་ལ་སློབ་པ་དང་། ཇི་ལྟར་སློབ་པ་དང་། གང་དག་སློབ་པ་དེ་དག་ཐམས་ཅད་གཅིག་ཏུ་བསྡུས་པ་ནི་བྱང་ཆུབ་སེམས་དཔའི་སྤྱོད་པ་ཞེས་བྱའོ། །

དེ་ལ་རྣམ་པ་གསུམ་དུ་རིག་པར་བྱའོ་ཞེས་སྟོན་པ། མདོར་བསྡུ་ན་བྱང་ཆུབ་སེམས་དཔའ་རྣམས་གང་ལ་སློབ་པ་དང་། ཇི་ལྟར་སློབ་པ་དང་། གང་དག་སློབ་པ་དེ་དག་ཐམས་ཅད་གཅིག་ཏུ་བསྡུས་པ་ནི་བྱང་ཆུབ་སེམས་དཔའི་སྤྱོད་པ་ཞེས་བྱའོ། །
Enumeration Block 2:
གནས་བདུན་ལ་སློབ་སྟེ། གནས་བདུན་པོ་དག་གང་ཞེ་ན། བདག་གི་དོན་དང་། གཞན་གྱི་དོན་དང་། དེ་ཁོ་ནའི་དོན་དང་། མཐུ་དང་། སེམས་ཅན་ཡོངས་སུ་སྨིན་པར་བྱ་བ་དང་། རང་གི་སངས་རྒྱས་ཀྱི་ཆོས་ཡོངས་སུ་སྨིན་པར་བྱ་བ་དང་། གནས་བདུན་པ་ནི་བླ་ན་མེད་པ་ཡང་དག་པར་རྫོགས་པའི་བྱང་ཆུབ་བོ། །
Enumeration Block 3:
མདོར་བསྡུ་ན་བདག་དང་གཞན་གྱི་དོན་ནི་རྣམ་པ་བཅུར་རིག་པར་བྱའོ། ། འབའ་ཞིག་དང་གཞན་དང་འབྲེལ་པ་དང་། ཕན་པའི་རྒྱུ་དང་། བདེ་བའི་རྒྱུ་དང་། རྒྱུར་བསྡུས་པ་དང་། འབྲས་བུར་བསྡུས་པ་དང་། ཚེ་འདི་པ་དང་། ཚེ་རབས་གཞན་པ་དང་། གཏན་དུ་བ་དང་། གཏན་དུ་བ་མ་ཡིན་པའོ། །
Enumeration Block 4:
མདོར་བསྡུ་ན་རྣམ་པ༌[^188]ལྔ་ཡོད་པར་རིག་པར་བྱ་སྟེ། ཁ་ན་མ་ཐོ་བ་མེད་པའི་མཚན་ཉིད་དང་། ཕན་འདོགས༌[^189]པའི་མཚན་ཉིད་དང་། ཚེ་འདི་པ་དང་། ཚེ་གཞན་པ་དང་། ཞི་བར་བྱེད་པའོ། །
Enumeration Block 5:
མདོར་བསྡུ་ན་བདེ་བ་རྣམ་པ་ལྔར་བསྡུ་བར་རིག་པར་བྱ་སྟེ། དེ་ལ་བདེ་བ་རྣམ་པ་ལྔ་པོ་ནི་འདི་དག་ཡིན་ཏེ། རྒྱུ་བདེ་བ་དང་། ཚོར་བ་བདེ་བ་དང་། སྡུག་བསྔལ་གྱི་གཉེན་པོའི་བདེ་བ་དང་། ཚོར་བའི་རྒྱུན་ཆད་པའི་བདེ་བ་དང་། གནོད་པ་མེད་པའི་བདེ་བ་དང་ལྔའོ། །
Enumeration Block 6:
དེ་ཡང་མདོར་བསྡུ་ན་རྣམ་པ་གཉིས་ཏེ། ཟག་པ་དང་བཅས་པ་དང་། ཟག་པ་མེད་པའོ། །
Enumeration Block 7:
གནོད་པ་མེད་པའི་བདེ་བ་ནི་མདོར་བསྡུ་ན་རྣམ་པ་བཞིར་རིག་པར་བྱ་སྟེ། མངོན་པར་འབྱུང་བའི་བདེ་བ་དང་། རབ་ཏུ་དབེན་པའི་བདེ་བ་དང་། ཉེ་བར་ཞི་བའི་བདེ་བ་དང་། རྫོགས་པར་བྱང་ཆུབ་པའི་བདེ་བའོ། །

Enumeration Block 1:
དེ་ཁོ་ནའི་དོན་གང་ཞེ་ན།
མདོར་བསྡུ་ན་རྣམ་པ་གཉིས་ཏེ། ཇི་ལྟར་ཡོད་པ་ལས་བརྩམས་ཏེ། ཆོས་རྣམས་ཀྱི་ཡང་དག་པ༌[^292]ཉིད་གང་ཡིན་པ་དང་། ཇི་སྙེད་ཡོད་པ་ལས་བརྩམས་ཏེ་ཆོས་རྣམས་ཀྱི་ཐམས་ཅད་ཉིད་གང་ཡིན་པ་སྟེ།
Enumeration Block 2:
དེ་ཁོ་ནའི་དོན་དེ་ཡང་རབ་ཏུ་དབྱེ་ན་རྣམ་པ་བཞི་སྟེ། འཇིག་རྟེན་གྱི་གྲགས་པ་དང་། རིགས་པས་གྲགས་པ༌[^293]དང་། [^294]ཉོན་མོངས་པའི་སྒྲིབ་པ་རྣམ་པར་དག་པའི་ཤེས་པའི་སྤྱོད་ཡུལ་དང་། ཤེས་བྱའི་སྒྲིབ་པ་རྣམ་པར་དག་པའི་ཤེས་པའི་སྤྱོད་ཡུལ་ལོ། །

Enumeration Block 1:
གཞི་དེ་ལས་བྱིས་པ་རྣམས་ཀྱི་རྣམ་པར་རྟོག་པ་དངོས་པོ༌[^406]གསུམ་སྐྱེད་པ༌[^407]དང་། སེམས་ཅན་དང་། སྣོད་ཀྱི་འཇིག་རྟེན་ཐམས་ཅད་སྒྲུབ་པ་རྣམ་པ་བརྒྱད་འབྱུང་བར་འགྱུར་ཏེ། འདི་ལྟ་སྟེ། ངོ་བོ་ཉིད་དུ་རྣམ་པར་རྟོག་པ་དང་། བྱེ་བྲག་ཏུ་རྣམ་པར་རྟོག་པ་དང་། རིལ་པོར་འཛིན་པའི་རྣམ་པར་རྟོག་པ་དང་། བདག་གོ་སྙམ་པའི་རྣམ་པར་རྟོག་པ༌[^408]དང་། བདག་གི་སྙམ་པའི་རྣམ་པར་རྟོག་པ་དང་། སྡུག་པར་རྣམ་པར་རྟོག་པ་དང་། མི་སྡུག་པར་རྣམ་པར་རྟོག་པ་དང་། དེ་གཉི་ག་ལས་བཟློག་པའི་རྣམ་པར་རྟོག་པའོ། །

Enumeration Block 1:
ཡོངས་སུ་ཚོལ་བ་རྣམ་པ་བཞི་དང་། ཡང་དག་པ་ཇི་ལྟ་བ་བཞིན་དུ་ཡོངས་སུ་ཤེས་པ་རྣམ་པ་བཞིས་འགྱུར་ཏེ། ཡོངས་སུ་ཚོལ་བ་རྣམ་པ་བཞི་གང་ཞེ་ན། མིང་ཡོངས་སུ་ཚོལ་བ་དང་། དངོས་པོ་ཡོངས་སུ་ཚོལ་བ་དང་། ངོ་བོ་ཉིད་དུ་བཏགས་པ་ཡོངས་སུ་ཚོལ་བ་དང་། བྱེ་བྲག་ཏུ་བཏགས་པ་ཡོངས་སུ་ཚོལ་བའོ། །
Enumeration Block 2:
ཡང་དག་པ་ཇི་ལྟ་བ་བཞིན་དུ་ཡོངས་སུ་ཤེས་པ་བཞི་པོ་དེ་དག་གང་ཞེ་ན། མིང་ཚོལ་བར་གྱུར་པ་ཡང་དག་པ་ཇི་ལྟ་བ་བཞིན་དུ་ཡོངས་སུ་ཤེས་པ་དང་། དངོས་པོ་ཚོལ་བར་གྱུར་པ་དང་། ངོ་བོ་ཉིད་དུ་བཏགས་པ་ཚོལ་བར་གྱུར་པ་དང་། བྱེ་བྲག་ཏུ་བཏགས་པ་ཚོལ་བར་གྱུར་པ་ཡང་དག་པ་ཇི་ལྟ་བ་བཞིན་དུ་ཡོངས་སུ་ཤེས་པའོ། །
Enumeration Block 3:
དེ་ལྟར་ཐམས་ཅད་ལ་དབང་བའི་བྱང་ཆུབ་སེམས་དཔའ་དེ་ལ་ཕན་ཡོན་གྱི་མཆོག་རྣམ་པ་ལྔ་ཡོད་པར་རིག་པར་བྱ་སྟེ།
Enumeration Block 4:
ཕན་ཡོན་རྣམ་པ་ལྔ་པོ་དེ་དག་གི་ལས་ཀྱང་རྣམ་པ་ལྔ་ཁོ་ནར་རིག་པར་བྱ་སྟེ།
Enumeration Block 5:
སངས་རྒྱས་དང་བྱང་ཆུབ་སེམས་དཔའ་རྣམས་ཀྱི་མཐུ་དེ་ཡང་རྣམ་པའི་རབ་ཏུ་དབྱེ་བས་རྣམ་པ་ལྔར་འགྱུར་ཏེ། མངོན་པར་ཤེས་པའི་མཐུ་དང་། ཆོས་ཀྱི་མཐུ་དང་། ལྷན་ཅིག་སྐྱེས་པའི་མཐུ་དང་། ཉན་ཐོས་དང་། རང་སངས་རྒྱས་རྣམས་དང་། ཐུན་མོང་བ་དང་། ཐུན་མོང་མ་ཡིན་པའོ། །

བྱང་ཆུབ་སེམས་དཔའ་རྣམས་ཀྱི་གདགས་པ་རྣམ་པར་གཞག་པ་ནི་བཞི་པོ་འདི་དག་ཡིན་ཏེ།
Enumeration Block 2:
བཞི་གང་ཞེ་ན།
ཆོས་གདགས་པ་རྣམ་པར་གཞག་པ་དང་། བདེན་པ་གདགས་པ་རྣམ་པར་གཞག་པ་དང་། རིག་པ༌[^2808]གདགས་པ་རྣམ་པར་གཞག་པ་དང་། ཐེག་པ་གདགས་པ་རྣམ་པར་གཞག་པའོ། །
Enumeration Block 3:
བཞི་པོ་འདི་དག་ནི་བྱང་ཆུབ་སེམས་དཔའ་རྣམས་ཀྱི་ཆོས་ཐམས་ཅད་ཡང་དག་པ་ཇི་ལྟ་བ་བཞིན་དུ་ཡོངས་སུ་ཤེས་པར་བྱ་བའི་ཕྱིར་ཡོངས་སུ་བཙལ་བའི་དངོས་པོ་ཡིན་ཏེ། མིང་ཡོངས་སུ་ཚོལ་བ་དང་། དངོས་པོ་ཡོངས་སུ་ཚོལ་བ་དང་། ངོ་བོ་ཉིད་དུའང༌[^2831]གདགས་པ་ཡོངས་སུ་ཚོལ་བ་དང་། བྱེ་བྲག་ཏུ༌[^2832]གདགས་པ་ཡོངས་སུ་ཚོལ་བའོ།[^2833] །
Enumeration Block 4:
བཞི་པོ་འདི་དག་ནི་བྱང་ཆུབ་སེམས་དཔའ་རྣམས་ཀྱི་ཆོས་ཐམས་ཅད་ཡང་དག་པ་ཇི་ལྟ་བ་བཞིན་དུ་ཡོངས་སུ་ཤེས་པ་སྟེ། བཞི་གང་ཞེ་ན།
མིང་ཡོངས་སུ་ཚོལ་བར་གྱུར་པ་ཡང་དག་པ༌[^2834]ཇི་ལྟ་བ་བཞིན་དུ་ཡོངས་སུ་ཤེས་པ་དང་། དངོས་པོ་ཡོངས་སུ་ཚོལ་བར་གྱུར་པ་ཡང་དག་པ་ཇི་ལྟ་བ་བཞིན་དུ་ཡོངས་སུ་ཤེས་པ་དང་། ངོ་བོ་ཉིད་དུ༌[^2835]གདགས་པ་ཡོངས་སུ་ཚོལ་བར་གྱུར་པ་ཡང་དག་པ་ཇི་ལྟ་བ་བཞིན་དུ་ཡོངས་སུ་ཤེས་པ་དང་། བྱེ་བྲག་གདགས་པ་ཡོངས་སུ་ཚོལ་བར་གྱུར་པ་ཡང་དག་པ་ཇི་ལྟ་བ་བཞིན་དུ་ཡོངས་སུ་ཤེས་པ་སྟེ།
Enumeration Block 5:
དཔག་ཏུ་མེད་པ་ལྔ་པོ་འདི་དག་ནི་བྱང་ཆུབ་སེམས་དཔའ་རྣམས་ཀྱི་ཐམས་ཅད་ལ་མཁས་པར་བྱེད་པར་འགྱུར་བ་སྟེ། ལྔ་གང་ཞེ་ན།
སེམས་ཅན་གྱི་ཁམས་དཔག་ཏུ་མེད་པ་དང་། འཇིག་རྟེན་གྱི་ཁམས་དཔག་ཏུ་མེད་པ་དང་། ཆོས་ཀྱི་ཁམས་དཔག་ཏུ་མེད་པ་དང་། འདུལ་བའི་ཁམས་དཔག་ཏུ་མེད་པ་དང་། འདུལ་བའི་ཐབས་དཔག་ཏུ་མེད་པའོ། །
Enumeration Block 6:
ལྔ་པོ་འདི་དག་ནི་སངས་རྒྱས་དང་བྱང་ཆུབ་སེམས་དཔའ་རྣམས་ཀྱིས་སེམས་ཅན་རྣམས་ལ༌[^2851]ཆོས་བསྟན་པའི་འབྲས་བུའི་ཕན་ཡོན་རྒྱ་ཆེ་བ་ཡིན་པར་རིག་པར་བྱ་སྟེ། ལྔ་གང་ཞེ་ན།
Enumeration Block 7:
ཆེན་པོ་བདུན་པོ་འདི་དག་ནི་གང་དང་ལྡན་ན་བྱང་ཆུབ་སེམས་དཔའ་རྣམས་ཀྱི་ཐེག་པ་ལ་ཐེག་པ་ཆེན་པོ་ཞེས་བྱ་བར་འགྱུར་བ་སྟེ། བདུན་གང་ཞེ་ན།
Enumeration Block 8:
ཆོས་བརྒྱད་པོ་འདི་དག་ནི་ཐེག་པ་ཆེན་པོ་ཐམས་ཅད་སྡུད་པར་བྱེད་པ་སྟེ། བྱང་ཆུབ་སེམས་དཔའི་སྡེ་སྣོད་བསྟན་པ་དང་། བྱང་ཆུབ་སེམས་དཔའི་སྡེ་སྣོད་དེ་ཉིད་དུ་ཆོས་ཐམས་ཅད་ཀྱི་དེ་ཁོ་ནའི་དོན་བསྟན་པ་གང་ཡིན་པ་དང་། བྱང་ཆུབ་སེམས་དཔའི་སྡེ་སྣོད་དེ་ཉིད་དུ་སངས་རྒྱས་དང་བྱང་ཆུབ་སེམས་དཔའ་རྣམས་ཀྱི་མཐུ་བསམ་གྱིས༌[^2864]མི་ཁྱབ་ཅིང་མཆོག་ཏུ་རྒྱ་ཆེ་བ་བསྟན་པ་གང་ཡིན་པ་དང་། དེ་ཚུལ་བཞིན་དུ་ཉན་པ་དང་། ཚུལ་བཞིན་དུ་སེམས་པ་སྔོན་དུ་འགྲོ་བའི་ལྷག་པའི་བསམ་པ་ཉམས་སུ་བླང་བ་གང་ཡིན་པ་དང་། ལྷག་པའི་བསམ་པ་ཉམས་སུ་བླང་བ་སྔོན་དུ་འགྲོ་བའི་བསྒོམ༌[^2865]པའི་རྣམ་པས་འཇུག་པ་དང་། བསྒོམ་པའི་རྣམ་པས་འཇུག་པ་སྔོན་དུ་འགྲོ་བའི་བསྒོམས་པའི༌[^2866]འབྲས་བུ་ཡོངས་སུ་འགྲུབ་པ་དང་། བསྒོམས་པའི༌[^2867]འབྲས་བུ་ཡོངས་སུ་འགྲུབ་པ་དེ་ཉིད་ཀྱིས༌[^2868]གཏན་དུ་ངེས་པར་འབྱིན་པ་སྟེ།

Enumeration Block 1:
ཆེན་པོ་བདུན་པོ་འདི་དག་ནི་གང་དང་ལྡན་ན་བྱང་ཆུབ་སེམས་དཔའ་རྣམས་ཀྱི་ཐེག་པ་ལ་ཐེག་པ་ཆེན་པོ་ཞེས་བྱ་བར་འགྱུར་བ་སྟེ། བདུན་གང་ཞེ་ན།
Enumeration Block 2:
དེ་དག་ནི་མདོར་བསྡུ༌[^2869]ན་རྣམ་པ་བཅུར་རིག་པར་བྱ་སྟེ། རིགས༌[^2870]ལ་གནས་པ་དང་། ཞུགས་པ་དང་། བསམ་པ་མ་དག་པ་དང་། བསམ་པ་དག་པ་དང་། ཡོངས་སུ་མ་སྨིན་པ་དང་། ཡོངས་སུ་སྨིན་པ་དང་། ངེས་པར་ཞུགས་པ་མ་ཡིན་པ་དང་། ངེས་པར་ཞུགས་པ་དང་སྐྱེ་བ་གཅིག་གིས་ཐོགས་པ་དང་། སྲིད་པ་ཐ་མ་པའོ། །
Enumeration Block 3:
ཡོངས་སུ་སྨིན་པ་དེ་ཡང་རྣམ་པ་གཉིས་ཏེ།
Enumeration Block 4:
ལྔ་པོ་འདི་དག་ནི་ཡང་དག་པའི་བྱང་ཆུབ་སེམས་དཔའ་རྣམས་ཀྱི་བྱང་ཆུབ་སེམས་དཔའི་རྟགས༌[^2881]ཡིན་ཏེ། དེ་དག་དང་ལྡན་ན་བྱང་ཆུབ་སེམས་དཔའ་བྱང་ཆུབ་སེམས་དཔའ་ཞེས་བྱ་བའི་གྲངས་སུ་འགྲོའོ། །
ལྔ་གང་ཞེ་ན།
སྙིང་བརྩེ་བ་དང་། སྙན་པར༌[^2882]སྨྲ་བ་དང་། བརྟན་པ་དང་། ལག་རྐྱོང་བ་དང་། དོན་དང་དགོངས་པ་ཟབ་མོ་ངེས་པར་འགྲེལ་པའོ། །
ཆོས་ལྔ་པོ་འདི་དག་ནི་ལྔར་བསྒྲེ་བར་རིག་པར་བྱ་སྟེ། ངོ་བོ་ཉིད་དང་། གནས་དང་། འབྲས་བུའི་ཕན་ཡོན་དང་། གོ་རིམས༌[^2883]དང་བསྡུ་བའོ། །
དེ་ལ་སྙིང་བརྩེ་བའི་ངོ་བོ་ཉིད་ནི་རྣམ་པ་གཉིས་ཏེ། བསམ་པར་གཏོགས་པ་དང་། སྒྲུབ་པར་གཏོགས་པའོ། །
Enumeration Block 5:
དེ་ལ་སྙིང་བརྩེ་བའི་གནས་ནི་ལྔ་སྟེ། ལྔ་གང་ཞེ་ན།
སེམས་ཅན་སྡུག་བསྔལ་བ་རྣམས་དང་། ཉེས་པར་སྤྱད་པ་སྤྱོད་པ་རྣམས་དང་། བག་མེད་པ་རྣམས་དང་། ལོག་པར་ཞུགས་པ་རྣམས་དང་། ཉོན་མོངས་པའི་བག་ལ་ཉལ་བ༌[^2888]དང་ལྡན་པ་རྣམས་སོ། །
Enumeration Block 6:
ལྔ་པོ་འདི་དག་ནི་བྱང་ཆུབ་སེམས་དཔའ་རྣམས་ཀྱི༌[^2901]སྙན་པར་སྨྲ་བའི་གནས་ཡིན་ཏེ། ལྔ་གང་ཞེ་ན།
ལེགས་པར་སྨྲ་བར་བྱ་བ་དང་། ལེགས་པར་ཀུན་དུ་དགའ་བར་བྱ་བ་དང་། ལེགས་པར་དབུགས་དབྱུང་བ་དང་། ལེགས་པར་བསྟབས་པ་དང་། རིགས་པས་བསྟན་པའོ། །
