* 3.8 ལྷུང་བཟེད་འབྲེལ་པ་མེད་པ་འཆང་བའི་དགེ་སློང་གི་ཀུན་ཏུ་སྤྱད་པའི་ཆོས [[ལྷུང་བཟེད་འབྲེལ་པ་མེད་པ་འཆང་བའི་དགེ་སློང་གི་ཀུན་ཏུ་སྤྱད་པའི་ཆོས་ནི་འདི་ལྟར་བྱ་སྟེ། ལྷུང་བཟེད་འབྲེལ་པ་མེད་པ་]]
* 3.9 གཅིག་པུས་རྙེད་པ་བྱིན་གྱིས་བརླབ་པའི་ཆོ་ག་དང་སྔགས [[བསྔོས་པ་ལས་བསྒྱུར་བའི་སྤང་བའི་སྐབས་ནས་ཡང་དགེ་སློང་གང་དགེ་འདུན་ལ་བསྔོས་པའི་རྙེད་པ་ཤེས་བཞིན་དུ་]]
* 3.10 དགེ་སློང་ཁྱིམ་རྣམས་སུ་སོ་སོར་གོ་བར་བྱེད་པའི་ཀུན་ཏུ་སྤྱད་པའི་ཆོས [[གནས་ངན་ལེན༌[^878]བརྗོད་པའི་ལྟུང་བྱེད་ཀྱི་སྐབས་ནས༌[^879]ཡང་དགེ་སློང་གང་ཟག་བསྙེན་པར་མ་རྫོགས་པ་ལ་]]
* 3.11 གཞོགས་འཕྱས་བྱེད་པའི་གྲངས་སུ་གཞུག་པའི་ལས [[གཞོགས་འཕྱས་བྱེད་པའི་གྲངས་སུ་གཞུག་པའི་ལས་ནི་འདི་ལྟར་བྱ་སྟེ། གནས་མལ་བཤམ་པ་བྱས་ནས་]]
* 3.12 བསྒོ་བ་རྣ་ལ་གཟོན་པའི་གྲངས་སུ་གཞུག་པ་དང་ཅང་མི་སྨྲ་བས་རྣ་ལ་གཟོན་པའི་གྲངས་སུ་གཞུག་པ [[བསྒོ་བ་རྣ་ལ་གཟོན་པའི་ལྟུང་བྱེད་ཀྱི་སྐབས་ནས་བསྒོ་བ་རྣ་ལ༌[^930]གཟོན་ན་ལྟུང་བྱེད་དོ་ཞེས་གསུངས་པའི་ཞར་ལ་]]
   * 3.12.1 བསྒོ་བ་རྣ་ལ་གཟོན་པའི་གྲངས་སུ་གཞུག་པ [[གནས་མལ་བཤམ་པ་བྱས་ནས་གཎྜཱི་བརྡུངས་ཏེ་དྲིས་པའི་ཚིག་གིས་དགེ་སློང་རྣམས་ལ་ཡང་དག་པར་བསྒོ་ནས།]]
   * 3.12.2 ཅང་མི་སྨྲ་བས་རྣ་ལ་གཟོན་པའི་གྲངས་སུ་གཞུག་པའི་ལས [[ཅང་མི་སྨྲ་བས་རྣ་ལ་གཟོན་པའི་གྲངས་སུ་གཞུག་པའི་ལས་ནི་འདི་ལྟར་བྱ་སྟེ། གནས་མལ་བཤམ་པ་བྱས་ནས་]]
* 3.13 དགེ་སློང་མའི་སྟོན་པ་བསྐོ་བ [[མ་བསྐོས་པར་སྟོན༌[^945]པའི་ལྟུང་བྱེད་ཀྱི༌[^946]སྐབས་ནས་ཡང་དགེ་སློང་གང་དགེ་འདུན་གྱིས་མ་བསྐོས་པར་]]
* 3.14 ལྷག་པོར་བྱ་བ [[སྟན་གཅིག་པའི་ཟས་ཀྱི་ལྟུང་བྱེད་ཀྱི་སྐབས་ནས༌[^962]ཡང་དགེ་སློང་གང་ཟས་ཟོས་ཟིན་ཅིང་སྤངས་པ་ལས་]]
* 3.15 དགེ་སློང་སྡིག་པ་ཅན་གྱི་ལྟ་བའི་རྣམ་པ་མི་གཏོང་བ་ལས་བཟློག་པའི་ཕྱིར་བསྒོ་བ [[ལྟ་བའི་རྣམ་པ་མི་གཏོང་བའི་ལྟུང་བྱེད་ཀྱི་སྐབས་ནས་དགེ་སློང་སྡིག་པ་ཅན་གྱི་ལྟ་བའི་རྣམ་པ་མི་གཏོང་བ་ལས༌[^970]བཟློག་པའི་ཕྱིར་]]
* 3.16 དགེ་སློང་སྡིག་པ་ཅན་གྱི་ལྟ་བའི་རྣམ་པ་མི་གཏོང་བ་ལ་སྨད་པ [[ལྟ་བའི་རྣམ་པ་མི་གཏོང་བའི་ལྟུང་བྱེད་དེ་ཉིད་ཀྱི་སྐབས་ནས་དགེ་སློང་སྡིག་པ་ཅན་གྱི་ལྟ་བའི་རྣམ་པ་མི་གཏོང་བ་ལ་སྨད་པར་བྱའོ་ཞེས་]]
* 3.17 བསྙིལ་བ་སྡུད་པའི་ལྟུང་བྱེད་ཀྱི་སྐབས་ནས་དགེ་ཚུལ་སྡིག་པ་ཅན་གྱི་ལྟ་བའི་རྣམ་པ་མི་སྤོང་བ་ལ་བཟློག་པའི་ཕྱིར་བསྒོ་བ [[བསྙིལ་བ་སྡུད་པའི་ལྟུང་བྱེད་ཀྱི་སྐབས་ནས་དགེ་ཚུལ་སྡིག་པ་ཅན་གྱི་ལྟ་བའི་རྣམ་པ་མི་སྤོང་བ༌[^1010]ལ༌[^1011]བཟློག་པའི་ཕྱིར་]]
* 3.18 བསྙིལ་བ་སྡུད་པའི་ལྟུང་བྱེད་དེ་ཉིད་ཀྱི་སྐབས་ནས་དགེ་ཚུལ་སྡིག་པ་ཅན་གྱི་ལྟ་བའི་རྣམ་པ་མི་གཏོང་བ་ལ་བསྙིལ་བ [[བསྙིལ་བ་སྡུད་པའི་ལྟུང་བྱེད་དེ་ཉིད་ཀྱི་སྐབས་ནས་དགེ་ཚུལ་སྡིག་པ་ཅན་གྱི་ལྟ་བའི་རྣམ་པ་མི་གཏོང་བ་ལ༌[^1049]བསྙིལ་བར་བྱའོ་ཞེས་]]
* 3.19 བསླབ་པ་དྲལ་ཏེ་ཁྱིམ་དུ་འཇུག་པའི་སོ་སོར་བཤགས་པར་བྱ་བའི་སྐབས་ནས་སྦྱིན་བདག་ལོངས་སྤྱོད་བསྲབས་ཤིང་ཡོངས་སུ་ཟད་དེ་ཡོངས་སུ་མཐར་ཐུག་པར་གྱུར་པ་ལ་བསླབ་པའི་སྡོམ་པ་སྦྱིན་པ [[བསླབ་པ༌[^1078]དྲལ་ཏེ་ཁྱིམ་དུ་འཇུག༌[^1079]པའི་སོ་སོར་བཤགས་པར་བྱ་བའི་སྐབས་ནས་སྦྱིན་བདག་ལོངས་སྤྱོད་བསྲབས་ཤིང་ཡོངས་སུ་ཟད་དེ་]]
* 3.20 དེ་ཉིད་ཀྱི་སྐབས་ནས་སྦྱིན་བདག་དེ་ལོངས་སྤྱོད་དག་འཕེལ་བར་གྱུར་པ་ལ་ཁྱིམ་གྱི་བསླབ་པའི་སྡོམ་པ་གཞིག་པ [[དེ་ཉིད་ཀྱི་སྐབས་ནས་སྦྱིན་བདག་དེ་ལོངས་སྤྱོད་དག་འཕེལ་བར་གྱུར་པ་ལ་ཁྱིམ་གྱི་བསླབ་པའི་སྡོམ་པ་གཞིག་པར་བྱའོ་ཞེས་]]
* 3.21 སོ་སོར་བཤགས་པར་བྱ་བ་དགེ་འདུན་ལ་རིག་པར་བྱ་བའི་ཆོ་ག་དང་སྔགས [[སོ་སོར་བཤགས་པར་བྱ་བ་དགེ་འདུན་ལ་རིག་པར་བྱ་བའི་ཆོ་ག་དང་སྔགས་ནི་འདི་ལྟར་བྱ་སྟེ།]]
* 3.22 ནགས་མ་བརྟགས་པ་ལས་གྱུར་པའི་སོ་སོར་བཤགས་པར་བྱ་བའི་སྐབས་ནས་དགེ་སློང་ནགས་ཉུལ་བ་བསྐོ་བ [[ནགས་མ་བརྟགས་པ་ལས་གྱུར་པའི་སོ་སོར་བཤགས་པར་བྱ་བའི་སྐབས་ནས། དགེ་སློང་ནགས་ཉུལ་བ༌[^1102]བསྐོ་བར་བྱའོ། །]]
* 4. ད་ནི་དགེ་སློང་མའི་རྣམ་པར་འབྱེད་པའི་སྐབས་ཀྱི་ཆོ་ག་དང་ལས་རྣམས [[ད་ནི་དགེ་སློང་མའི་རྣམ་པར་འབྱེད་པའི་སྐབས་ཀྱི་ཆོ་ག་དང་ལས་རྣམས་བརྗོད་པར་བྱ་སྟེ། སྡོམ་ལ།]]
   * 4.1 བཟློག་པའི་ཕམ་པར་འགྱུར་བའི་སྐབས་ནས་གནས་ནས་ཕྱུང་བའི་རྗེས་སུ་ཕྱོགས་པའི་དགེ་སློང་མ་ལ་བཟློག་པའི་ཕྱིར་བསྒོ་བ [[བཟློག་པའི་ཕམ་པར་འགྱུར་བའི་སྐབས་ནས་གནས་ནས་ཕྱུང་བའི་རྗེས་སུ་ཕྱོགས་པའི་དགེ་སློང་མ་ལ་བཟློག་པའི་ཕྱིར་བསྒོ་བར་བྱའོ་ཞེས་]]
   * 4.2 ཉིན་མོ་འབྲལ་བའི་དགེ་འདུན་ལྷག་མའི་གནས་སྐབས་ནས་མུ་གེའི་སྡུག་བསྔལ་བྱུང་བའི་ཚེ་དགེ་སློང་མ་ཉེ་དུ་རྣམས་དང་ལྷན་ཅིག་འབྲེལ་བའི་ཉེ་བར་སྤྱོད་པ་གནང་བ་སྦྱིན་པ [[ཉིན་མོ་འབྲལ་བའི་དགེ་འདུན་ལྷག་མའི་གནས༌[^1156]སྐབས་ནས་མུ་གེའི་སྡུག་བསྔལ་བྱུང་བའི་ཚེ་དགེ་སློང་མ་ཉེ་དུ་རྣམས་དང་ལྷན་ཅིག་འབྲེལ་བའི་ཉེ་བར་སྤྱོད་པ་གནང་བ་སྦྱིན་པར་བྱའོ་ཞེས་]]
