Enumeration Block 1:
དེ་ལ་ཕུང་པོ་ལྔ་ནི་གཟུགས་ཀྱི་ཕུང་པོ་དང་། །ཚོར་བའི་ཕུང་པོ་དང་། འདུ་ཤེས་ཀྱི་ཕུང་པོ་དང་། འདུ་བྱེད་ཀྱི་ཕུང་པོ་དང་། རྣམ་པར་ཤེས་པའི་ཕུང་པོའོ། །

Enumeration Block 2:
སྐྱེ་མཆེད་བཅུ་གཉིས་ནི། འདི་ལྟ་སྟེ། མིག་གི་སྐྱེ་མཆེད་དང་། རྣ་བའི་སྐྱེ་མཆེད་དང་། སྣའི་སྐྱེ་མཆེད་དང་། ལྕེའི་སྐྱེ་མཆེད་དང་། ལུས་ཀྱི་སྐྱེ་མཆེད་དང་། ཡིད་ཀྱི་སྐྱེ་མཆེད་དང་། གཟུགས་ཀྱི་སྐྱེ་མཆེད་དང་། སྒྲའི་སྐྱེ་མཆེད་དང་། དྲིའི་སྐྱེ་མཆེད་དང་། རོའི་སྐྱེ་མཆེད་དང་། རེག་བྱའི་སྐྱེ་མཆེད་དང་། ཆོས་ཀྱི་སྐྱེ་མཆེད་ཅེས་བྱའོ། །

Enumeration Block 3:
ཁམས་བཅོ་བརྒྱད་དག༌ནི། འདི་ལྟ་སྟེ། མིག་གི་ཁམས་དང་། གཟུགས་ཀྱི་ཁམས་དང་། མིག་གི་རྣམ་པར་ཤེས་པའི་ཁམས་དང་། རྣ་བའི་ཁམས་དང་། སྒྲའི་ཁམས་དང་། རྣ་བའི་རྣམ་པར་ཤེས་པའི་ཁམས་དང་། སྣའི་ཁམས་དང་། དྲིའི་ཁམས་དང་། སྣའི་རྣམ་པར་ཤེས་པའི་ཁམས་དང་། ལྕེའི་ཁམས་དང་། རོའི་ཁམས་དང་། ལྕེའི་རྣམ་པར་ཤེས་པའི་ཁམས་དང་། ལུས་ཀྱི་ཁམས་དང་། རེག་བྱའི་ཁམས་དང་། ལུས་ཀྱི་རྣམ་པར་ཤེས་པའི་ཁམས་དང་། ཡིད་ཀྱི་ཁམས་དང་། ཆོས་ཀྱི་ཁམས་དང་། ཡིད་ཀྱི་རྣམ་པར་ཤེས་པའི་ཁམས་ཞེས་བྱའོ། །

Enumeration Block 4:
དེ་ཡང་རྣམ་པ་གཉིས་སུ་འགྱུར་ཏེ། འབྱུང་བ་དང་། འབྱུང་བ་ལས་གྱུར་པའོ། །
དེ་ལ་འབྱུང་བ་ནི་ཆེན་པོ་བཞི་སྟེ། སའི་ཁམས་དང་ཆུའི་ཁམས་དང་མེའི་ཁམས་དང་། རླུང་གི་ཁམས་ཞེས་བྱ་བའོ། །

Enumeration Block 5:
མིག་གི་རྣམ་པར་ཤེས་པ་འདིའི་རྟེན་ནི་རྣམ་པ་གཉིས་ཏེ། ལྷན་ཅིག་སྐྱེས་པའི་མིག་དང་འདས་པའི་ཡིད་དོ། །

Enumeration Block 6:
སོ་སོའི་དབྱེ་བས་ཕྱེ་བ་ན་གཟུགས་ཀྱི་སྐྱེ་མཆེད་ནི་རྣམ་པ་གཉིས་སུ་འགྱུར་ཏེ། ཁ་དོག་དང་དབྱིབས་སོ། །
དེ་ལ་ཁ་དོག་ནི་བཞི་སྟེ། སྔོན་པོ་ལ་སོགས་པའོ། །

Enumeration Block 7:
དབྱིབས་ནི་རྣམ་པ་བརྒྱད་དེ། རིང་པོ་ལ་སོགས་པ་ནས་མི་མཉམ་པའི་བར་དུའོ། །
གཟུགས་ཀྱི་སྐྱེ་མཆེད་དེ་ཉིད་ཡང་རྣམ་པ་ཉི་ཤུར་བརྗོད་པར་བྱ་སྟེ། འདི་ལྟ་སྟེ་སྔོན་པོ་དང་། སེར་པོ་དང་། དམར་པོ་དང་། དཀར་པོ་དང་། རིང་པོ་དང་། ཐུང་ངུ་དང་། ཟླུམ་པོ་དང་། ལྷམ་པ་དང་། མཐོ་བ་དང་། དམའ་བ་དང་། མཉམ་པ་དང་། མི་མཉམ་པ་དང་། སྤྲིན་དང་། དུ་བ་དང་། རྡུལ་དང་། ཁུག་རྣ་དང་། གྲིབ་མ་དང་། ཉི་མ་དང་། སྣང་བ་དང་། མུན་པ་ཞེས་བྱ་བའོ། །

Enumeration Block 1:
དབྱིབས་ནི་རྣམ་པ་བརྒྱད་དེ། རིང་པོ་ལ་སོགས་པ་ནས་མི་མཉམ་པའི་བར་དུའོ། །

Enumeration Block 2:
གཟུགས་ཀྱི་སྐྱེ་མཆེད་དེ་ཉིད་ཡང་རྣམ་པ་ཉི་ཤུར་བརྗོད་པར་བྱ་སྟེ། འདི་ལྟ་སྟེ་སྔོན་པོ་དང་། སེར་པོ་དང་། དམར་པོ་དང་། དཀར་པོ་དང་། རིང་པོ་དང་། ཐུང་ངུ་དང་། ཟླུམ་པོ་དང་། ལྷམ་པ་དང་། མཐོ་བ་དང་། དམའ་བ་དང་། མཉམ་པ་དང་། མི་མཉམ་པ་དང་། སྤྲིན་དང་། དུ་བ་དང་། རྡུལ་དང་། ཁུག་རྣ་དང་། གྲིབ་མ་དང་། ཉི་མ་དང་། སྣང་བ་དང་། མུན་པ་ཞེས་བྱ་བའོ། །

Enumeration Block 3:
སྒྲ་ནི་རྣམ་པ་བརྒྱད་དེ། [^17]ཟིན་པ་དང་མ་ཟིན་པའི་འབྱུང་བ་ཆེན་པོ༌[^18]རྒྱུ་ལས་བྱུང་བ་དག་སོ་སོར་སེམས་ཅན་དང་སེམས་ཅན་མ་ཡིན་པར་སྟོན་པས་རྣམ་པ་བཞིའོ། །

བསྟན་བཅོས་ལས་ནི་དྲི་ཞིམ་པ་དང་། དྲི་མི་ཞིམ་པ་དང་། དྲི་མཉམ་པ་ཞེས་རྣམ་པ་གསུམ་འབྱུང་ངོ་། །

རོ་ནི་དྲུག་སྟེ། མངར་བ་དང་། སྐྱུར་བ་དང་། ལན་ཚྭ་དང་། ཚ་བ་དང་། ཁ་བ་དང་། བསྐ་བའི་བྱེ་བྲག་གིས་སོ། །

Enumeration Block 6:
རེག་བྱ་ནི་བཅུ་གཅིག་གི་བདག་ཉིད་དེ་འབྱུང་བ་ཆེན་པོ་བཞི་དང་། འཇམ་པ་ཉིད་དང་། རྩུབ་པ་ཉིད་དང་། ལྕི་བ་ཉིད་དང་། ཡང་བ་ཉིད་དང་། གྲང་བ་ཉིད༌[^26]དང་། བཀྲེས་པ་དང་། སྐོམ་པ་ཞེས་བྱ་བའོ། །

Enumeration Block 1:
ཚོར་བ་དེ་ནི་རྣམ་པ་གཉིས་སུ་འགྱུར་ཏེ། ལུས་ཀྱི་དང་སེམས་ཀྱིའོ། །

Enumeration Block 2:
ཚོར་བ་དེ་ཉིད་རྣམ་པ་གསུམ་དུ་འགྱུར་ཏེ། བདེ་བ་དང་། སྡུག་བསྔལ་དང་། བདེ་བ་ཡང་མ་ཡིན་སྡུག་བསྔལ་བ་ཡང་མ་ཡིན་པའོ། །

Enumeration Block 3:
ཚོར་བ་དེ་ཉིད་རྣམ་པ་ལྔར་འགྱུར་ཏེ། བདེ་བའི་དབང་པོ་དང་། སྡུག་བསྔལ་གྱི་དབང་པོ་དང་། ཡིད་བདེ་བའི་དབང་པོ་དང་། ཡིད་མི་བདེ་བའི་དབང་པོ་དང་། བཏང་སྙོམས་ཀྱི་དབང་པོའོ། །

Enumeration Block 4:
ཚོར་བ་དེ་ཉིད་ཡང་རྟེན་དྲུག་གི་བྱེ་བྲག་གིས་དྲུག་ཏུ་འགྱུར་ཏེ། མིག་གི༌[^46]འདུས་ཏེ་རེག་པ་ལས་བྱུང་བ་དང་། རྣ་བ་དང་། སྣ་དང་། ལྕེ་དང་། ལུས་དང་། ཡིད་ཀྱི་འདུས་ཏེ་རེག་པ་ལས་བྱུང་བའོ། །

Enumeration Block 5:
རྟེན་གྱི་བྱེ་བྲག་གིས་ནི་དྲུག་ཏུ་འགྱུར་ཏེ། མིག་གི་རྣམ་པར་ཤེས་པ་དང་མཚུངས་པར་ལྡན་པ་ནས་ཡིད་ཀྱི་རྣམ་པར་ཤེས་པ་དང་མཚུངས་པར་ལྡན་པའི་བར་དུའོ། །
ཡང་རྣམ་པ་གསུམ་དུ་འགྱུར་ཏེ། ཆུང་ངུ་དང་། ཆེན་པོར་གྱུར་པ་དང་། ཚད་མེད་པའོ། །

Enumeration Block 6:
