Enumeration Block 1:
དབྱིབས་ནི་རྣམ་པ་བརྒྱད་དེ། རིང་པོ་ལ་སོགས་པ་ནས་མི་མཉམ་པའི་བར་དུའོ། །

Enumeration Block 2:
གཟུགས་ཀྱི་སྐྱེ་མཆེད་དེ་ཉིད་ཡང་རྣམ་པ་ཉི་ཤུར་བརྗོད་པར་བྱ་སྟེ། འདི་ལྟ་སྟེ་སྔོན་པོ་དང་། སེར་པོ་དང་། དམར་པོ་དང་། དཀར་པོ་དང་། རིང་པོ་དང་། ཐུང་ངུ་དང་། ཟླུམ་པོ་དང་། ལྷམ་པ་དང་། མཐོ་བ་དང་། དམའ་བ་དང་། མཉམ་པ་དང་། མི་མཉམ་པ་དང་། སྤྲིན་དང་། དུ་བ་དང་། རྡུལ་དང་། ཁུག་རྣ་དང་། གྲིབ་མ་དང་། ཉི་མ་དང་། སྣང་བ་དང་། མུན་པ་ཞེས་བྱ་བའོ། །

Enumeration Block 3:
སྒྲ་ནི་རྣམ་པ་བརྒྱད་དེ། [^17]ཟིན་པ་དང་མ་ཟིན་པའི་འབྱུང་བ་ཆེན་པོ༌[^18]རྒྱུ་ལས་བྱུང་བ་དག་སོ་སོར་སེམས་ཅན་དང་སེམས་ཅན་མ་ཡིན་པར་སྟོན་པས་རྣམ་པ་བཞིའོ། །
ཡང་དེ་ཉིད་རེ་རེ་ཞིང་ཡིད་དུ་འོང་བ་དང་། ཡིད་དུ་མི་འོང་བའི་བྱེ་བྲག་གིས་རྣམ་པ་བརྒྱད་དོ། །

Enumeration Block 4:
དྲི་ནི་རྣམ་པ་བཞི་སྟེ། དྲི་ཞིམ་པ་དང་། མི་ཞིམ་པ་དང་། མཉམ་པ་དང་། མི་མཉམ་པ་ཉིད་དོ། །
བསྟན་བཅོས་ལས་ནི་དྲི་ཞིམ་པ་དང་། དྲི་མི་ཞིམ་པ་དང་། དྲི་མཉམ་པ་ཞེས་རྣམ་པ་གསུམ་འབྱུང་ངོ་། །

Enumeration Block 5:
རོ་ནི་དྲུག་སྟེ། མངར་བ་དང་། སྐྱུར་བ་དང་། ལན་ཚྭ་དང་། ཚ་བ་དང་། ཁ་བ་དང་། བསྐ་བའི་བྱེ་བྲག་གིས་སོ། །

Enumeration Block 6:
རེག་བྱ་ནི་བཅུ་གཅིག་གི་བདག་ཉིད་དེ་འབྱུང་བ་ཆེན་པོ་བཞི་དང་། འཇམ་པ་ཉིད་དང་། རྩུབ་པ་ཉིད་དང་། ལྕི་བ་ཉིད་དང་། ཡང་བ་ཉིད་དང་། གྲང་བ་ཉིད༌[^26]དང་། བཀྲེས་པ་དང་། སྐོམ་པ་ཞེས་བྱ་བའོ། །
