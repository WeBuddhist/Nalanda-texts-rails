Enumeration Block 1:
ཚོར་བ་དེ་ནི་རྣམ་པ་གཉིས་སུ་འགྱུར་ཏེ། ལུས་ཀྱི་དང་སེམས་ཀྱིའོ། །

Enumeration Block 2:
ཚོར་བ་དེ་ཉིད་རྣམ་པ་གསུམ་དུ་འགྱུར་ཏེ། བདེ་བ་དང་། སྡུག་བསྔལ་དང་། བདེ་བ་ཡང་མ་ཡིན་སྡུག་བསྔལ་བ་ཡང་མ་ཡིན་པའོ། །

Enumeration Block 3:
ཚོར་བ་དེ་ཉིད་རྣམ་པ་ལྔར་འགྱུར་ཏེ། བདེ་བའི་དབང་པོ་དང་། སྡུག་བསྔལ་གྱི་དབང་པོ་དང་། ཡིད་བདེ་བའི་དབང་པོ་དང་། ཡིད་མི་བདེ་བའི་དབང་པོ་དང་། བཏང་སྙོམས་ཀྱི་དབང་པོའོ། །

Enumeration Block 4:
ཚོར་བ་དེ་ཉིད་ཡང་རྟེན་དྲུག་གི་བྱེ་བྲག་གིས་དྲུག་ཏུ་འགྱུར་ཏེ། མིག་གི༌[^46]འདུས་ཏེ་རེག་པ་ལས་བྱུང་བ་དང་། རྣ་བ་དང་། སྣ་དང་། ལྕེ་དང་། ལུས་དང་། ཡིད་ཀྱི་འདུས་ཏེ་རེག་པ་ལས་བྱུང་བའོ། །

Enumeration Block 5:
རྟེན་གྱི་བྱེ་བྲག་གིས་ནི་དྲུག་ཏུ་འགྱུར་ཏེ། མིག་གི་རྣམ་པར་ཤེས་པ་དང་མཚུངས་པར་ལྡན་པ་ནས་ཡིད་ཀྱི་རྣམ་པར་ཤེས་པ་དང་མཚུངས་པར་ལྡན་པའི་བར་དུའོ། །
ཡང་རྣམ་པ་གསུམ་དུ་འགྱུར་ཏེ། ཆུང་ངུ་དང་། ཆེན་པོར་གྱུར་པ་དང་། ཚད་མེད་པའོ། །

Enumeration Block 6:
འདུ་བྱེད་ཀྱི་ཕུང་པོ་ནི་རྣམ་པ་གཉིས་ཏེ། སེམས་དང་མཚུངས་པར་ལྡན་པ་དང་། སེམས་དང་མི་ལྡན་པའོ། །

Enumeration Block 7:
ཡང་དེ་ནི་རྣམ་པ་གསུམ་སྟེ། དགེ་བ་དང་། མི་དགེ་བ་དང་། ལུང་དུ་མ་བསྟན་པའོ། །
ཡང་དབྱེ་ན་སེམས་པའི་ཚོགས་དྲུག་ཏུ་འགྱུར་ཏེ། མིག་གི་རྣམ་པར་ཤེས་པ་དང་མཚུངས་པར་ལྡན་པ་ནས་ཡིད་ཀྱི་རྣམ་པར་ཤེས་པ་དང་མཚུངས་པར་ལྡན་པའི་བར་དུའོ། །
