Enumeration Block 1:
ཆོས་མངོན་པ་ལས་ནི། རྣམ་པར་རྟོག་པ་གསུམ་འབྱུང་སྟེ། ངོ་བོ་ཉིད་ཀྱི་རྣམ་པར་རྟོག་པ་དང་། ཀུན་ཏུ་ངེས་པའི་རྣམ་པར་རྟོག་པ་དང་། རྗེས་སུ་དྲན་པའི༌[^137]རྣམ་པར་རྟོག་པའོ། །

Enumeration Block 2:
དེ་ཡང་རྣམ་པ་གཉིས་ཏེ། རྒྱུའི་ཀུན་ནས་སློང་བ་དང་། དེའི་དུས་ཀྱི་ཀུན་ནས་སློང་བའོ། །

Enumeration Block 3:
དེ་ཡང་དེ་ནི་རྣམ་པ་གཉིས་ཏེ། སོ་སོར་བརྟགས་པའི་བཏང་སྙོམས་དང་། སོ་སོར་མ་བརྟགས་པའི་བཏང་སྙོམས་སོ། །

Enumeration Block 4:
དགེ་བའི་རྩ་བ་ནི་གསུམ་སྟེ། མ་ཆགས་པ་དང་། ཞེ་སྡང་མེད་པ་དང་། གཏི་མུག་མེད་པའོ། །

Enumeration Block 5:
དགེ་བའི་རྩ་བ་གསུམ་པོ་འདི་དག་ལས་བཟློག་པ་གསུམ་ནི་མི་དགེ་བའི་རྩ་བ་སྟེ། ཆགས་པ་དང་། ཞེ་སྡང་དང་། གཏི་མུག་གོ། །

Enumeration Block 6:
ལུང་དུ་མ་བསྟན་པའི་རྩ་བ་ནི་གསུམ་སྟེ། སྲེད་པ་དང་། མ་རིག་པ་དང་། བློ་གྲོས་སོ། །
