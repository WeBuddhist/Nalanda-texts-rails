Enumeration Block 1:
ཟག་པ་ནི་འདི་ལྟར་ཟག་པ་གསུམ་སྟེ། འདོད་པའི་ཟག་པ་དང་། སྲིད་པའི་ཟག་པ་དང་། མ་རིག་པའི་ཟག་པའོ། །

Enumeration Block 2:
ཆུ་བོ་ཞེས་བྱ་བ་ལ། ཆུ་བོ་ནི་བཞི་སྟེ། འདོད་པའི་ཆུ་བོ་དང་། སྲིད་པའི་ཆུ་བོ་དང་། ལྟ་བའི་ཆུ་བོ་དང་། མ་རིག་པའི་ཆུ་བོ་ཞེས་བྱ་བའོ། །

Enumeration Block 3:
ཉེ་བར་ལེན་པ་ནི་ཉེ་བར་ལེན་པ་བཞི་སྟེ། འདོད་པ་ཉེ་བར་ལེན་པ་དང་། ལྟ་བ་ཉེ་བར་ལེན་པ་དང་། ཚུལ་ཁྲིམས་དང་བརྟུལ་ཞུགས་ཉེ་བར་ལེན་པ་དང་། བདག་ཏུ་སྨྲ་བ་ཉེ་བར་ལེན་པའོ། །

Enumeration Block 4:
མདུད་པ་ཞེས་བྱ་བ་ལ་མདུད་པ་ནི་བཞི་སྟེ། བརྣབ་སེམས་ལུས་ཀྱི་མདུད་པ་དང་། གནོད་སེམས་ལུས་ཀྱི་མདུད་པ་དང་། ཚུལ་ཁྲིམས་དང་། བརྟུལ་ཞུགས་མཆོག་ཏུ་འཛིན་པ་ལུས་ཀྱི་མདུད་པ་དང་། འདི་བདེན་པའོ་ཞེས་མངོན་པར་ཞེན་པ་ལུས་ཀྱི་མདུད་པའོ། །

Enumeration Block 5:
སྒྲིབ་པ་ཞེས་བྱ་བ་ལ་སྒྲིབ་པ་ལྔ་སྟེ། འདོད་པ་ལ་འདུན་པ་དང་། གནོད་སེམས་དང་། རྨུགས་པ༌[^283]དང་། གཉིད་དང་། རྒོད་པ་དང་། འགྱོད་པ་དང་། ཐེ་ཚོམ་མོ། །

Enumeration Block 6:
ཤེས་པ་ནི་ཤེས་པ་བཅུ་སྟེ། ཆོས་ཤེས་པ་དང་། རྗེས་སུ་ཤེས་པ་དང་། གཞན་གྱི་སེམས་ཤེས་པ་དང་། ཀུན་རྫོབ་ཤེས༌[^285]པ་དང་། སྡུག་བསྔལ་ཤེས་པ་དང་། ཀུན་འབྱུང་བ་ཤེས་པ་དང་། འགོག་པ་ཤེས་པ་དང་། ལམ་ཤེས་པ་དང་། ཟད་པ་ཤེས་པ་དང་། མི་སྐྱེ་བ་ཤེས་པའོ། །

Enumeration Block 7:
བཟོད་པ་གང་ཞེ་ན། མངོན་པར་རྟོགས་པའི༌[^302]བཟོད་པ་བརྒྱད་དེ། [^303]སྡུག་བསྔལ་ལ་ཆོས་ཤེས་པའི་བཟོད་པ་དང་། སྡུག་བསྔལ་ལ་རྗེས་སུ་ཤེས་པའི་བཟོད་པ་དང་། ཀུན་འབྱུང་ལ་ཆོས་ཤེས་པའི་བཟོད་པ་དང་། ཀུན་འབྱུང་ལ་རྗེས་སུ་ཤེས་པའི་བཟོད་པ་དང་། འགོག་པ་ལ་ཆོས་ཤེས་པའི་བཟོད་པ་དང་། འགོག་པ་ལ་རྗེས་སུ་ཤེས་པའི་བཟོད་པ་དང་། [^304]ལམ་ལ་ཆོས་ཤེས་པའི་བཟོད་པ་དང་། ལམ་ལ་རྗེས་སུ་ཤེས་པའི་བཟོད་པའོ། །

Enumeration Block 8:
རྙེད་པ༌[^306]དང་ལྡན་པ་གཉིས་ཏེ། མ་ཐོབ་པ་དང་། རྣམ་པར་ཉམས་པ་ལས་སོ་སོར་རྙེད་པ་དང་། ཐོབ་ནས་ཀུན་ཏུ་ལྡན་པའོ། །
