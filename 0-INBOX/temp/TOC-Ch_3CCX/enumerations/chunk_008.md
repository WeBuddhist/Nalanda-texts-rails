Enumeration Block 1:
དགེ་བའི་རྩ་བ་ནི་གསུམ་སྟེ། མ་ཆགས་པ་དང་། ཞེ་སྡང་མེད་པ་དང་། གཏི་མུག་མེད་པའོ། །

Enumeration Block 2:
དགེ་བའི་རྩ་བ་གསུམ་པོ་འདི་དག་ལས་བཟློག་པ་གསུམ་ནི་མི་དགེ་བའི་རྩ་བ་སྟེ། ཆགས་པ་དང་། ཞེ་སྡང་དང་། གཏི་མུག་གོ། །

Enumeration Block 3:
ལུང་དུ་མ་བསྟན་པའི་རྩ་བ་ནི་གསུམ་སྟེ། སྲེད་པ་དང་། མ་རིག་པ་དང་། བློ་གྲོས་སོ། །

Enumeration Block 4:
ཀུན་དུ་སྦྱོར་བ་ནི་ཀུན་དུ་སྦྱོར་བ་དགུ་སྟེ། འདི་ལྟ་སྟེ། རྗེས་སུ་ཆགས་པའི་ཀུན་དུ་སྦྱོར་བ་དང་། ཁོང་ཁྲོ་བའི་ཀུན་དུ་སྦྱོར་བ་དང་། ང་རྒྱལ་གྱི་ཀུན་དུ་སྦྱོར་བ་དང་། མ་རིག་པའི་ཀུན་དུ་སྦྱོར་བ་དང་། ལྟ་བའི་ཀུན་དུ་སྦྱོར་བ་དང་། མཆོག་ཏུ་འཛིན་པའི་ཀུན་དུ་སྦྱོར་བ་དང་། ཐེ་ཚོམ་གྱི་ཀུན་དུ་སྦྱོར་བ་དང་། ཕྲག་དོག་གི་ཀུན་དུ་སྦྱོར་བ་དང་། སེར་སྣའི་ཀུན་དུ་སྦྱོར་བ་ཞེས་བྱ་བའོ། །

Enumeration Block 5:
ང་རྒྱལ་བདུན་ནི་ང་རྒྱལ་གྱི་ཀུན་དུ་སྦྱོར་བར་བརྗོད་དོ། །
འདི་ལྟ་སྟེ་ང་རྒྱལ་དང་། ལྷག་པའི་ང་རྒྱལ་དང་། ང་རྒྱལ་ལས་ཀྱང་ང་རྒྱལ་དང་། ངའོ་སྙམ་པའི་ང་རྒྱལ་དང་། མངོན་པའི་ང་རྒྱལ་དང་། ལོག་པའི་ང་རྒྱལ་དང་། ཅུང་ཟད་སྙམ་པའི་ང་རྒྱལ་ལོ། །

Enumeration Block 6:
ལྟ་བ་གསུམ་པོ་དག་ལ་ལྟ་བའི་ཀུན་དུ་སྦྱོར་བ་ཞེས་བརྗོད་དོ། །
འདི་ལྟ་སྟེ། འཇིག་ཚོགས་ལ་ལྟ་བ་དང་། མཐར་འཛིན་པར་ལྟ་བ་དང་། ལོག་པར་ལྟ་བའོ། །

Enumeration Block 7:
མཆོག་ཏུ་འཛིན་པ་རྣམ་པ་གཉིས་ནི་མཆོག་ཏུ་འཛིན་པའི་ཀུན་དུ་སྦྱོར་བ་ཞེས་བསྟན་ཏེ། འདི་ལྟ་སྟེ། ལྟ་བ་མཆོག་ཏུ་འཛིན་པ་དང་། ཚུལ་ཁྲིམས་དང་བརྟུལ་ཞུགས་མཆོག་ཏུ་འཛིན་པའོ། །

Enumeration Block 8:
ངེས་པར་འཆིང་བ་ཞེས་བྱ་བ་ལ་ངེས་པར་འཆིང་བ་ནི་རྣམ་པ་གསུམ་སྟེ། འདོད་ཆགས་ཀྱི་ངེས་པར་འཆིང་བ་དང་། ཞེ་སྡང་གི་ངེས་པར་འཆིང་བ་དང་། གཏི་མུག་གི་ངེས་པར་འཆིང་བའོ། །
