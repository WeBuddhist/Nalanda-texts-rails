Enumeration Block 1:
འདུ་བྱེད་ཀྱི་ཕུང་པོ་ནི་རྣམ་པ་གཉིས་ཏེ། སེམས་དང་མཚུངས་པར་ལྡན་པ་དང་། སེམས་དང་མི་ལྡན་པའོ། །

Enumeration Block 2:
ཡང་དེ་ནི་རྣམ་པ་གསུམ་སྟེ། དགེ་བ་དང་། མི་དགེ་བ་དང་། ལུང་དུ་མ་བསྟན་པའོ། །

Enumeration Block 3:
ཡང་དབྱེ་ན་སེམས་པའི་ཚོགས་དྲུག་ཏུ་འགྱུར་ཏེ། མིག་གི་རྣམ་པར་ཤེས་པ་དང་མཚུངས་པར་ལྡན་པ་ནས་ཡིད་ཀྱི་རྣམ་པར་ཤེས་པ་དང་མཚུངས་པར་ལྡན་པའི་བར་དུའོ། །

Enumeration Block 4:
ཡང་དེ་ནི་རྣམ་པ་གསུམ་སྟེ། བདེ་བ་མྱོང་བར་འགྱུར་བ་དང་། སྡུག་བསྔལ་མྱོང་བར་འགྱུར་བ་དང་། བདེ་བ་ཡང་མ་ཡིན་སྡུག་བསྔལ་བ་ཡང་མ་ཡིན་པ་མྱོང་བར་འགྱུར་བའོ། །
ཡང་རྣམ་པ་དྲུག་སྟེ། མིག་གི་རྣམ་པར་ཤེས་པའི་འདུས་ཏེ་རེག་པ་ནས་ཡིད་ཀྱི་རྣམ་པར་ཤེས་པའི་འདུས་ཏེ་རེག་པའི་བར་དུའོ། །

Enumeration Block 5:
ཡང་དེ་ནི་རྣམ་པ་གསུམ་དུ་འགྱུར་ཏེ། སློབ་པ་དང་། མི་སློབ་པ་དང་། སློབ་པ་ཡང་མ་ཡིན་མི་སློབ་པ་ཡང་མ་ཡིན་ནོ། །

Enumeration Block 6:
དེ་ལ་བདེན་པ་ནི་བཞི་སྟེ། སྡུག་བསྔལ་དང་། ཀུན་འབྱུང་དང་། འགོག་པ་དང་། ལམ་ཞེས་བྱ་བའོ། །
ཡང་ན་རྣམ་པ་གཉིས་ཏེ། ཀུན་རྫོབ་དང་དོན་དམ་པ་ཞེས་བྱ་བའོ། །
དཀོན་མཆོག་ནི་གསུམ་སྟེ། སངས་རྒྱས་དང་། ཆོས་དང་། དགེ་འདུན་ནོ། །
