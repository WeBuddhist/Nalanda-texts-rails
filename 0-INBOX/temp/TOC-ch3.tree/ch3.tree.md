## དཀར་ཆག / Table of Contents

* 1. སྦྱོར་བ [[ད་ནི་སྦྱོར་བ་བརྗོད་པར་བྱའོ། །དེའང་རྣམ་པ་བཅུར་འགྱུར་བས་དེའི་ཕྱིར།]]
   * 1.1 གཟུགས་ལ་སོགས་པའི་སྦྱོར་བ [[དེ་ལ་གཟུགས་ལ་སོགས་པའི་སྦྱོར་བ་ནི། གལ་ཏེ་གཟུགས་ལ༌[^1290]སྤྱོད་ན། ཤེས་རབ་ཀྱི་ཕ་རོལ་ཏུ་]]
   * 1.2 གཟུགས་ལ་སོགས་པ་མི་རྟག་པ་ལ་སོགས་པའི་སྦྱོར་བ [[གཟུགས་ལ་སོགས་པ༌[^1291]མི་རྟག་པ་ལ་སོགས་པའི་སྦྱོར་བ་ནི་ཕུང་པོ་རྣམས་ནས་རྣམ་པ་ཐམས་ཅད]]
   * 1.3 གཟུགས་ལ་སོགས་པ་རྫོགས་པ་དང་མ་རྫོགས་པའི་སྦྱོར་བ [[གཟུགས་ལ་སོགས་པ་རྫོགས་པ་དང་མ་རྫོགས་པའི་སྦྱོར་བ་ནི། གཞན་ཡང་གཟུགས་ལ་སོགས་པ]]
   * 1.4 གཟུགས་ལ་སོགས་པ་ལ་ཆགས་པ་མེད་པའི་སྦྱོར་བ [[གཟུགས་ལ་སོགས་པ་ལ་ཆགས་པ་མེད་པའི་སྦྱོར་བ་ནི། ཡང་དེ་རྣམས་ལ་མ་ཆགས་པ་ཉིད་ཀྱི]]
   * 1.5 གཞན་དུ་མི་འགྱུར་བའི་སྦྱོར་བ [[གཞན་དུ་མི་འགྱུར་བའི་སྦྱོར་བ་ནི། སྦྱོར་བ་དེ་ནམ་མཁའི་བསྔགས་པ༌[^1293]འམ་བསྔགས་པ་མ་ཡིན་པ]]
   * 1.6 བྱེད་པ་པོའི་སྦྱོར་བ [[བྱེད་པ་པོའི༌[^1294]སྦྱོར་བ་ནི། སྦྱོར་བ་དེ་ནི་སྒྱུ་མའི་སྐྱེས་བུ་བསྔགས་པའམ་བསྔགས་པ་]]
   * 1.7 བྱ་དཀའ་བའི་སྦྱོར་བ [[བྱ་དཀའ་བའི་སྦྱོར་བ་ནི་བྱ་དཀའ་བ་རྣམ་པ་གསུམ་ཉིད་དོ། །]]
      * 1.7.1 ཆེད་དུ་དཀའ་བ་ཉིད [[ཆེད་དུ༌[^1295]དཀའ་བ་ཉིད་ནི་རྣམ་པ་ཐམས་ཅད་མཁྱེན་པ་ཉིད་དེ། དེ་ཉིད་ཀྱི་ཕྱིར]]
      * 1.7.2 སྦྱོར་བ་བྱ་དཀའ་བ་ཉིད [[སྦྱོར་བ་བྱ་དཀའ་བ་ཉིད་ནི་ལམ་ཤེས་པ་ཉིད་དེ། གང་དག་དེ་ལ་འབད་པར་འདོད་པ་]]
      * 1.7.3 ལས་བྱ་དཀའ་བ་ཉིད [[ལས་བྱ་དཀའ་བ་ཉིད་ནི་ཐམས་ཅད་ཤེས་པ་ཉིད་དེ་གང་དག་དེ་ལ་རྩོལ་བར༌[^1296]འདོད་པ་]]
   * 1.8 འབྲས་བུ་ཡོད་པའི་སྦྱོར་བ [[འབྲས་བུ་ཡོད་པའི་སྦྱོར་བ་ནི། གང་ཡང་རུང་བ་ཞིག་ལ་དགེ་སློང་གཅིག༌[^1298]ཅེས་མིང་དུ་མ་བསྟན་པའི]]
   * 1.9 གཞན་གྱི་རྐྱེན་གྱིས་མི་འགྲོ་བའི་སྦྱོར་བ [[གཞན་གྱི་རྐྱེན་གྱིས་མི་འགྲོ་བའི་སྦྱོར་བ་ནི། བརྒྱ་བྱིན་གྱིས་བསྲུང་བ་དང་། བསྐྱབ་པར་ཁས་བླངས་པ]]
   * 1.10 རྣམ་པ་བདུན་དུ་སྣང་བའི་ཤེས་པའི་སྦྱོར་བ [[རྣམ་པ་བདུན་དུ་སྣང་བའི་ཤེས་པའི་སྦྱོར་བ་ནི་ཡོངས་སུ་འགྱུར་བ་དང་། མཉན༌[^1302]དུ་ཚོགས་པ་དང]]
* 2. མཉམ་པ་ཉིད [[ད་ནི་མཉམ་པ་ཉིད་བརྗོད་པར་བྱ་བ་ཡིན་པས། གཟུགས་ལ་སོགས་པ་རློམ་མེད་པ། །]]
   * 2.1 གཟུགས་རློམ་སེམས་སུ་མི་བྱེད [[137]]
   * 2.2 གཟུགས་ཀྱིས་རློམ་སེམས་སུ་མི་བྱེད [[གཟུགས་ཀྱིས་རློམ་སེམས་སུ་མི་བྱེད། གཟུགས་བདག་གིས༌[^1305]ཞེས་བྱ་བར༌[^1306]རློམ་སེམས་སུ་མི་བྱེད།]]
   * 2.3 གཟུགས་བདག་གིས་ཞེས་བྱ་བར་རློམ་སེམས་སུ་མི་བྱེད [[137]]
   * 2.4 གཟུགས་ལ་རློམ་སེམས་སུ་མི་བྱེད [[137]]
* 3. མཐོང་བའི་ལམ་གྱི་སྐད་ཅིག་མ་བཅུ་དྲུག [[ད་ནི་མཐོང་བའི་ལམ་བརྗོད་པར་བྱ་བ་ཡིན་པས་ན་དེའི་ཕྱིར། སངས་རྒྱས་ཀྱི་མཐུས་]]
   * 3.1 སྡུག་བསྔལ་ལ་ཆོས་ཤེས་པའི་བཟོད་པ [[དེ་ལ་སྡུག་བསྔལ་ལ་ཆོས་ཤེས་པའི་བཟོད་པ་ནི་འདི་ཡིན་ཏེ། གཟུགས་རྟག་ཅེས་བྱ་བ་དང་]]
   * 3.2 སྡུག་བསྔལ་ལ་ཆོས་ཤེས་པ [[སྡུག་བསྔལ་ལ་ཆོས་ཤེས་པ་ནི། གཟུགས་ཤིན་ཏུ་རྣམ་པར་དག་གོ་ཞེས་ཤིན་ཏུ་རྣམ་པར་]]
   * 3.3 སྡུག་བསྔལ་ལ་རྗེས་སུ་ཤེས་པའི་བཟོད་པ [[སྡུག་བསྔལ་ལ་རྗེས་སུ་ཤེས་པའི་བཟོད་པ་ནི། གཟུགས་ལ་སོགས་པ་ནས་རྣམ་པ་ཐམས་ཅད་མཁྱེན་]]
   * 3.4 སྡུག་བསྔལ་ལ་རྗེས་སུ་ཤེས་པ [[སྡུག་བསྔལ་ལ་རྗེས་སུ་ཤེས་པ་ནི། དེ་ཅིའི་ཕྱིར་ཞེ་ན། རབ་འབྱོར་གཟུགས་ལ་སྐྱེ་བ་མེད་པ་དང]]
   * 3.5 ཀུན་འབྱུང་ལ་ཆོས་ཤེས་པའི་བཟོད་པ [[ཀུན་འབྱུང་ལ་ཆོས་ཤེས་པའི་བཟོད་པ་ནི། བཅོམ་ལྡན་འདས་ཇི་ལྟར་ན༌[^1314]ནམ་མཁའ་ཡོངས་སུ་དག་པའི་]]
   * 3.6 ཀུན་འབྱུང་ལ་ཆོས་ཤེས་པ [[ཀུན་འབྱུང་ལ་ཆོས་ཤེས་པ་ནི། ནམ་མཁའ་དང་འདྲ་བར་གཟུགས་ནས་རྣམ་པ་ཐམས་ཅད་མཁྱེན་པ]]
   * 3.7 ཀུན་འབྱུང་ལ་རྗེས་སུ་ཤེས་པའི་བཟོད་པ [[ཀུན་འབྱུང་ལ་རྗེས་སུ་ཤེས་པའི་བཟོད་པ་ནི་ནམ་མཁའ་དང་འདྲ་བར་གཟུགས་ནས་རྣམ་པ་ཐམས]]
   * 3.8 ཀུན་འབྱུང་ལ་རྗེས་སུ་ཤེས་པ [[ཀུན་འབྱུང་ལ་རྗེས་སུ་ཤེས་པ་ནི། སྒྲ་བརྙན་གཉིས་ཀྱི་དཔེས་ནམ་མཁའ་དང་འདྲ་བར་གཟུགས་ནས་]]
   * 3.9 འགོག་པ་ལ་ཆོས་ཤེས་པའི་བཟོད་པ [[འགོག་པ་ལ་ཆོས་ཤེས་པའི་བཟོད་པ་ནི། ནམ་མཁའ་དང་འདྲ་བར་གཟུགས་ནས་རྣམ་པ་ཐམས་ཅད་མཁྱེན]]
   * 3.10 འགོག་པ་ལ་ཆོས་ཤེས་པ [[འགོག་པ་ལ་ཆོས་ཤེས་པ་ནི་ནམ་མཁའ་དང་འདྲ་བར་གཟུགས་ནས་རྣམ་པ་ཐམས་ཅད་མཁྱེན་པ]]
   * 3.11 འགོག་པ་ལ་རྗེས་སུ་ཤེས་པའི་བཟོད་པ [[འགོག་པ་ལ་རྗེས་སུ་ཤེས་པའི་བཟོད་པ་ནི། ནམ་མཁའ་དང་འདྲ་བར་གཟུགས་ནས་རྣམ་པ་ཐམས་ཅད]]
   * 3.12 འགོག་པ་ལ་རྗེས་སུ་ཤེས་པ [[འགོག་པ་ལ་རྗེས་སུ་ཤེས་པ་ནི། དེ་འཛིན་པ་དང་། འཆང་བ་དང་། ཀློག་པ་དང་། ཚུལ་བཞིན་དུ]]
   * 3.13 ལམ་ལ་ཆོས་ཤེས་པའི་བཟོད་པ [[ལམ་ལ་ཆོས་ཤེས་པའི་བཟོད་པ་ནི། རབ་འབྱོར་དེ་ལ་ཤེས་རབ་ཀྱི་ཕ་རོལ་ཏུ་ཕྱིན་པ]]
   * 3.14 ལམ་ལ་ཆོས་ཤེས་པ [[ལམ་ལ་ཆོས་ཤེས་པ་ནི། ཡང་ལམ་ཤེས་པ་ཉིད་ཀྱི་སྐབས་ཀྱིས། ཕ་རོལ་ཏུ་ཕྱིན་པ]]
   * 3.15 ལམ་ལ་རྗེས་སུ་ཤེས་པའི་བཟོད་པ [[ལམ་ལ་རྗེས་སུ་ཤེས་པའི་བཟོད་པ་ནི། རབ་འབྱོར་ཕ་རོལ་ཏུ་ཕྱིན་པ་རིན་པོ་ཆེ་ལ་ནི]]
   * 3.16 ལམ་ལ་རྗེས་སུ་ཤེས་པ [[ལམ་ལ་རྗེས་སུ་ཤེས་པ་ནི་གལ་ཏེ་རིན་པོ་ཆེ་རྣམ་པ་གསུམ་གྱི་དོན་དེའང་རྣམ་པར]]
