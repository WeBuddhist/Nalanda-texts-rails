Enumeration Block 1:
ཡིད་ཆེས་པར་མི་འགྱུར་བ་ནི་རྣམ་པ་གཉིས་ཏེ། རི་དགས་མིའི་ཚིག་ཏུ་སྨྲ་བ་ཐོས་ཤིང་མི་མ་ཡིན་པར་ཤེས་པ་དང་། བདག་ཉིད་ཀྱིས་གནོད་པ་བྱས་པས་སོ། །

Enumeration Block 2:
ཉེས་དམིགས་ཀྱང་རྣམ་པ་གཉིས་ཏེ། ལུས་དང་སེམས་ཀྱིའོ། །

Enumeration Block 3:
ཉེས་དམིགས་ཀྱང་རྣམ་པ་གཉིས་ཏེ། གྲགས་པ་མེད་པ་དང་། སྐྱེ་བོ་དམ་པས་སྨད་པ་སྟེ།

Enumeration Block 4:
དགྲ་དག་ལས་གྲུབ༌[^3122]པ་ཡང་རྣམ་པ་གཉིས་ཏེ། གསད་པ༌[^3123]དང་། གཞོམ་པར་བྱ་བའོ། །

Enumeration Block 5:
གྲོགས་པོ་ལ་ཡང་རྣམ་པ་གཉིས་ཏེ། སྒྲུབ་པ་དང་། [^3124]གཞག་པའོ། །
