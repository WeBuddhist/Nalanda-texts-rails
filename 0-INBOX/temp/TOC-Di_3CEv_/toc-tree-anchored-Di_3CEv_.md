* 1. དཔེ་ [[དཔེ་ནི་གཉིས་སུ་དབྱེ་སྟེ། ཆོས་མཐུན་པ་དང་། ཆོས་མི་མཐུན་པ་ཡང་ངོ་། །]]
   * 1.1 ཆོས་མཐུན་པ་ [[དེ་ལ་ཆོས་མཐུན་པ་ནི་གང་ལ་གཏན་ཚིགས་ཀྱི་མཐུན་པའི་ཕྱོགས་ཉིད་ལ་ཡོད་པ་སྟོན་པ་སྟེ།]]
   * 1.2 ཆོས་མི་མཐུན་པ་ [[ཆོས་མི་མཐུན་པ་ཡང་། གང་ལ་བསྒྲུབ་པར་བྱ་བ་མེད་པ་ལ་རྟགས་མེད་པ་ཉིད་དུ་སྟོན་པ་སྟེ།]]
* 2. གཏན་ཚིགས་ལྟར་སྣང་བ་ [[མ་གྲུབ་པ་དང་མ་ངེས་པ་དང་འགལ་བ་སྟེ་གསུམ་པོ་རྣམས་ནི་གཏན་ཚིགས་ལྟར་སྣང་བ་རྣམས་སོ། །]]
   * 2.1 མ་གྲུབ་པ་ [[དེ་ལ་མ་གྲུབ་པའི་དབྱེ་བ་བཞི་སྟེ། གཉིས་ཀ་ལ་མ་གྲུབ་པ་དང་།]]
      * 2.1.1 གཉིས་ཀ་ལ་མ་གྲུབ་པ་ [[དེ་ལ་སྒྲ་མི་རྟག་ཉིད་སྒྲུབ་པ་ལ་མིག་གིས་གཟུང་བར་བྱ་བ་ཉིད་ཀྱི་ཕྱིར་ཞེས་པ་གཉིས་ཀ༌[^2]ལ་མ་གྲུབ་པའོ། །]]
      * 2.1.2 གང་ཡང་རུང་བ་ལ་མ་གྲུབ་པ་ [[སྒྲ་མངོན་པར་གསལ་བར་སྨྲ་བ་ལ། བྱས་པ་ཉིད་ཀྱི་ཕྱིར་ཞེས་པ་གང་རུང་ལ་མ་གྲུབ་པའོ། །]]
      * 2.1.3 ཐེ་ཚོམ་ཟ་ནས་མ་གྲུབ་པ་ [[མེ་སྒྲུབ་པ་ལ་རླངས་པ་ལ་སོགས་པའི་དངོས་པོར་ཐེ་ཚོམ་ཟ་བའི་འབྱུང་བ་འདུས་པ་བརྗོད་པ་ལྟ་བུ་ཐེ་ཚོམ་ཟ་ནས་མ་གྲུབ་པའོ། །]]
      * 2.1.4 གཞི་མ་གྲུབ་པ་ [[ནམ་མཁའ་རྗེས་སུ་ཡོད་དེ། ཡོན་ཏན་གྱི་གཞི་ཉིད་ཀྱི་ཕྱིར་ཞེས་པ་ནམ་མཁའི་ཡོད་པ་ཉིད་དུ་བརྗོད་པ་ལ་གཞི་མ་གྲུབ་པའོ། །]]
   * 2.2 མ་ངེས་པ་ [[མ་ངེས་པ་ནི་དྲུག་དུ་དབྱེ་སྟེ། ཐུན་མོང་དང་། ཐུན་མོང་མ་ཡིན་པ་དང་།]]
      * 2.2.1 ཐུན་མོང་ [[དེ་ལ་ཐུན་མོང་པ་འདི་ལྟར་གཞལ་བྱ་ཉིད་ཀྱི་ཕྱིར་སྒྲ་རྟག་ཅེས་པའོ། །]]
      * 2.2.2 ཐུན་མོང་མ་ཡིན་པ་ [[ཐུན་མོང་མ་ཡིན་པ་ནི་མཉན་བྱ་ཉིད་ཀྱི་ཕྱིར་སྒྲ་རྟག་ཅེས་པའོ། །]]
      * 2.2.3 མཐུན་ཕྱོགས་ཀྱི་ཕྱོགས་གཅིག་ལ་ཡོད་ལ་མི་མཐུན་ཕྱོགས་ལ་ཁྱད་པ་ [[མཐུན་ཕྱོགས་ཀྱི་ཕྱོགས་ཅིག་གིས་ཡུལ་ལ་ཡོད་ལ། མི་མཐུན་ཕྱོགས་ལ་ཁྱབ་པ་ནི་སྒྲ་རྩོལ་བས་བྱུང་བ་མ་ཡིན་ཏེ།]]
      * 2.2.4 མི་མཐུན་ཕྱོགས་ཀྱི་ཕྱོགས་ཅིག་གི་ཡུལ་ལ་ཡོད་ལ་མཐུན་ཕྱོགས་ལ་ཁྱབ་པ་ [[མི་མཐུན་ཕྱོགས་ཀྱི་ཡུལ་གཅིག་ལ་ཡོད་ལ་མཐུན་ཕྱོགས་ལ་ཁྱབ་པ་ནི། ཇི་ལྟར་སྒྲ་རྩོལ་བ་ལས་བྱུང་བ་ཡིན་ཏེ་མི་རྟག་པ་ཉིད་ཀྱི་ཕྱིར་ཞེས་པའོ། །]]
      * 2.2.5 གཉིས་ཀའི་ཕྱོགས་ཅིག་གི་ཡུལ་ལ་ཡོད་པ་ [[གཉིས་ཀའི་ཕྱོགས་གཅིག་གི་ཡུལ་ལ་ཡོད་པ་ནི། ཇི་ལྟར་སྒྲ་སྟག་སྟེ་ལུས་ཅན་མ་ཡིན་པ་ཉིད་ཀྱི་ཕྱིར་ཞེས་པ་འདི་ལ་རྟག་པ་ནི་ཕྱོགས་སོ། །]]
      * 2.2.6 འགལ་བ་ལ་མི་འཁྲུལ་པ་ [[འགལ་བ་ལ་མི་འཁྲུལ་པ་ནི་ཇི་ལྟར་སྒྲ་མི་རྟག་སྟེ་བྱས་པ་ཉིད་ཀྱི་ཕྱིར་བུམ་པ་བཞིན་སྒྲ་རྟག་སྟེ་མཉན་བྱ་ཉིད་ཀྱི་ཕྱིར་སྒྲ་བཞིན་ཞེས་པ་འགལ་བའི་དོན་དག་གཅིག་ལ་ཡོད་པ་ནི་གཉིས་ཀ་ལ་ཐེ་ཚོམ་གྱི་རྒྱུ་ཉིད་དོ། །]]
   * 2.3 འགལ་བ་ [[འགལ་བ་ནི་བཞིར་དབྱེ་སྟེ། ཆོས་ཀྱི་རང་བཞིན་ཕྱིན་ཅི་ལོག་ཏུ་སྒྲུབ་པར་བྱེད་པ་དང་།]]
      * 2.3.1 ཆོས་ཀྱི་རང་བཞིན་ཕྱིན་ཅི་ལོག་ཏུ་སྒྲུབ་པར་བྱེད་པ་ [[དེ་ལ་ཆོས་ཀྱི་རང་བཞིན་ཕྱིན་ཅི་ལོག་ཏུ་སྒྲུབ་པར་བྱེད་པ་ཇི་ལྟར་ན། སྒྲ་རྟག་སྟེ་བྱས་པ་ཉིད་ཀྱི་ཕྱིར་ཞེས་པའམ་བཙལ་མ་ཐག་ཏུ་བྱུང་བ་ཉིད་ཀྱི་ཕྱིར།]]
      * 2.3.2 ཆོས་ཀྱི་ཁྱད་པར་ཕྱིན་ཅི་ལོག་ཏུ་བསྒྲུབ་པར་བྱེད་པ་ [[ཆོས་ཀྱི་ཁྱད་པར་ཕྱིན་ཅི་ལོག་ཏུ་སྒྲུབ་པར་བྱེད་པ་ཇི་ལྟར་ན། མིག་ལ་སོགས་པ་གཞན་གྱི་དོན་ཡིན་ཏེ།]]
      * 2.3.3 ཆོས་ཅན་གྱི་རང་བཞིན་ཕྱིན་ཅི་ལོག་ཏུ་སྒྲུབ་པར་བྱེད་པ་ [[ཆོས་ཅན་གྱི་རང་བཞིན་ཕྱིན་ཅི་ལོག་ཏུ་སྒྲུབ་པར་བྱེད་པ་ཇི་ལྟར་ན། རྫས་དང་ལས་དང་ཡོན་ཏན་སོ་སོར་མེད་དེ་དངོས་པོའི་རྫས་གཅིག་པ་ཅན་ཉིད་ཀྱི་ཕྱིར་དང་།]]
      * 2.3.4 ཆོས་ཅན་གྱི་ཁྱད་པར་ཕྱིན་ཅི་ལོག་ཏུ་བསྒྲུབ་པར་བྱེད་པ་ [[ཆོས་ཅན་གྱི་ཁྱད་པར་ཕྱིན་ཅི་ལོག་ཏུ་སྒྲུབ་པར་བྱེད་པ་འདི་ཉིད་ནི་ཕྱོགས་སྔ་མའི་རྟགས་འདི་ཉིད་ལ་ཆོས་ཅན་གྱི་ཁྱད་པར་གང་ཡོད་པ་རྐྱེན་གྱིས་བྱས་པ་ཉིད་དང་།]]
* 3. དཔེ་ལྟར་སྣང་བ་རྣམས་ [[དཔེ་ལྟར་སྣང་བ་རྣམས་འདི་ལྟ་སྟེ། སྒྲུབ་པར་བྱེད་པའི་ཆོས་མ་གྲུབ་པ་དང་། བསྒྲུབ་པར་བྱ་བའི་ཆོས་མ་གྲུབ་པ་དང་།]]
   * 3.1 སྒྲུབ་པར་བྱེད་པའི་ཆོས་མ་གྲུབ་པ་ [[དེ་ལ་སྒྲུབ་པར་བྱེད་པའི་ཆོས་མ་གྲུབ་པ་ནི་ཇི་ལྟར་སྒྲ་རྟག་སྟེ་ལུས་ཅན་མ་ཡིན་པ་ཉིད་ཀྱི་ཕྱིར་གང་ལུས་ཅན་མ་ཡིན་པ་དེ་རྟག་པར་མཐོང་སྟེ།]]
   * 3.2 བསྒྲུབ་པར་བྱ་བའི་ཆོས་མ་གྲུབ་པ་ [[བསྒྲུབ་བྱའི་ཆོས་མ་གྲུབ་པ་ནི། འདི་ལྟར་སྒྲ་རྟག་སྟེ་ལུས་ཅན་མ་ཡིན་པ་ཉིད་ཀྱི་ཕྱིར།]]
   * 3.3 གཉིས་ཀའི་ཆོས་མ་གྲུབ་པ་ [[གཉིས་ཀ་མ་གྲུབ་པ་ནི་གཉིས་སུ་དབྱེ་སྟེ། ཡོད་པ་དང་མེད་པ་ཡང་ཞེས་སོ། །]]
      * 3.3.1 ཡོད་པ་ [[དེ་ལ་བུམ་པ་བཞིན་ཞེས་པ་ཡོད་པ་ལ་གཉིས་ཀ་ལ་མ་གྲུབ་པ་སྟེ། ལུས་ཅན་ཉིད་ཡིན་པའི་ཕྱིར་དང་།]]
      * 3.3.2 མེད་པ་ [[ནམ་མཁའ་བཞིན་ཞེས་པ་མེད་པ་གཉིས་ཀ་མ་གྲུབ་པ་སྟེ། ནམ་མཁའ་མེད་པ་ཉིད་དུ་འདོད་པ་ལའོ། །]]

   * 3.5 རྗེས་སུ་འགྲོ་བ་ཕྱིན་ཅི་ལོག་པ་ [[རྗེས་སུ་འགྲོ་བ་ཕྱིན་ཅི་ལོག་པ་ནི་གང་བྱས་པ་དེ་མི་རྟག་པར་མཐོང་ཞེས་བརྗོད་པར་བྱ་བ་ལས་གང་མི་རྟག་པ་དེ་བྱས་པ་ཡིན་ཞེས་ཟེར་བ་ལྟ་བུའོ། །]]
* 4. བདག་ཉིད་ཀྱིས་རབ་ཏུ་རྟོགས་པར་བྱ་བའི་དོན་ [[བདག་ཉིད་ཀྱིས་རབ་ཏུ་རྟོགས་པར་བྱ་བའི་དོན་ལ་ཡང་མངོན་སུམ་དང་རྗེས་སུ་དཔག་པའི་ཚད་མ་ཉིད་དག་གོ། །]]

   * 4.2 རྗེས་སུ་དཔག་པ་ [[རྗེས་སུ་དཔག་པ་ནི་རྟགས་ལས་དོན་མཐོང་བའོ། །]]
* 5. སྒྲུབ་པར་བྱེད་པའི་སྐྱོན་བརྗོད་པ་རྣམས་ [[སྒྲུབ་པར་བྱེད་པའི་སྐྱོན་བརྗོད་པ་རྣམས་ནི་སུན་འབྱིན་པ་རྣམས་སོ། །]]
* 6. སྒྲུབ་པར་བྱེད་པ་སྐྱོན་མི་འབྱུང་བ་ལ་སྐྱོན་བརྗོད་པ་རྣམས་ [[སྒྲུབ་པར་བྱེད་པ་སྐྱོན་མི་འབྱུང་བ་ལ་སྐྱོན་བརྗོད་པ་རྣམས་ནི་སུན་འབྱིན་ལྟར་སྣང་བ་རྣམས་ཏེ།]]
