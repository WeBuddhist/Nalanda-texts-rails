[^3]: བརྗོད་ན་ ༼སྣར། པེ།༽ བརྗོད་ནས་
[^4]: སྒྲུབ་པར་ ༼སྣར། པེ།༽ བསྒྲུབ་པར་

[^7]: ཡིན་པའི་ ༼སྣར། པེ།༽ ཡིན་པ་ནི་
[^8]: ཤེས་རབ་ཀྱིས་ ༼སྣར། པེ།༽ ཤེས་རབ་ཀྱི་
[^9]: བསམ་པའི་ ༼སྣར། པེ།༽ བསམས་པའི་

[^13]: རིམ་པ་ ༼སྣར། པེ།༽ རིམ་པ་ཇི་ལྟ་བ་
[^14]: འཁོར་ ༼སྣར། པེ།༽ འཁོར་དེ་

[^18]: བཞག་ ༼སྡེ།༽ གཞག་
[^19]: སྒྲ་གཅན་ ༼སྣར། པེ།༽ སྒྲ་ཅན་
[^20]: ལྷང་ ༼སྣར། པེ།༽ ལྷ་
[^21]: བསྲེགས་པ་ ༼སྣར། པེ།༽ བསྲེག་པ་
[^22]: ཐམས་ཅད་དུ་ཐམས་ཅད་ ༼སྣར། པེ།༽ ཐམས་ཅད་
[^23]: རྐྱེན་གྱི་ ༼སྣར། པེ།༽ རྐྱེན་གྱིས་
[^24]: གཉིས་ཀྱིས་ ༼སྣར། པེ།༽ གཉིས་
[^25]: བྱ་བ་ལ་སོགས་ ༼སྣར། པེ།༽ བྱ་

[^28]: གྱུར་ཏེ། ༼སྣར། པེ།༽ འགྱུར་སྟེ།
[^29]: རྣམས་ ༼སྣར། པེ།༽ རྣམ་
[^30]: བཅོམ་པས་ ༼སྡེ།༽ བཅོམ་པས་ཡང་
[^31]: ཡིན་པར་བསྟན་ ༼སྣར། པེ།༽ ཡིན་
[^32]: ཆོས་ཉིད་ ༼སྣར། པེ།༽ ཆོས་
[^33]: བཟུང་ ༼སྣར། པེ།༽ གཟུང་
[^34]: གཞན་གྱི་དབང་ ༼སྣར། པེ།༽ གཞན་
[^35]: བྱ་བ་ ༼སྣར། པེ།༽ བྱ་བ་ལ་
[^36]: སྐྱེད་པ་ ༼སྣར། པེ།༽ བསྐྱེད་པས་
[^37]: ཕྱིར་རོ། ༼སྣར། པེ།༽ ཕྱིར།
[^38]: པ་ཞེས་བྱ་བ་ལ་སོགས་པ་སྨོས་ཏེ། ༼སྣར། པེ།༽ པ་
[^39]: ལྟོས་ ༼སྣར། པེ།༽ བལྟོས་
[^40]: བསྟན་ཏེ། ༼སྣར། པེ།༽ བསྟན་ཏོ།
[^41]: གསལ་བའི་ ༼སྣར། པེ།༽ གསལ་བ་
[^42]: སྦྱོར་བ་ཉིད་ཀྱི་ ༼སྣར། པེ།༽ སྦྱོར་བ་
[^43]: ཀུན་རྫོབ་ལ་ ༼སྣར། པེ།༽ ཀུན་རྫོབ་
[^44]: ཕྱེ་ན་ ༼སྣར། པེ།༽ ཕྱེ་ནས་
[^45]: སྦྱོར་བས་ན་ ༼སྣར། པེ།༽ སྦྱོར་བས་
[^46]: ། །དེ་ལྟ་བས་ན་ ༼སྣར། པེ།༽ དེ་ལྟ་བས་
[^47]: འཁོར་ ༼སྡེ།༽ འཁོར་བའི་
[^48]: ཁྱད་པར་ཅན་གྱི་སྡེབ་སྦྱོར་ ༼སྣར། པེ།༽ ཁྱད་པར་ཅན་
[^49]: འདས་ཀྱི་ ༼སྣར། པེ།༽ འདས་ཀྱིས་
[^50]: གྱི་ ༼སྣར། པེ།༽ གྱིས་
[^51]: ཉེར་བཞག་ ༼ཅོ།༽ ཉེ་བར་བཞག་ ༼སྡེ།༽ ཉེ་བར་གཞག་
[^52]: གཞག་ ༼སྣར། པེ།༽ བཞག་
[^53]: འགྱུར་ཏེ། ༼སྣར། པེ།༽ འགྱུར་སྟེ།
[^54]: སྔོན་དུ་ ༼སྣར། པེ།༽ མངོན་དུ་
[^55]: བསྟན་ནས་དེ་བཞིན་དུ་ ༼སྣར། པེ།༽ བསྟན་ནས་
[^56]: བསལ་བ་ ༼སྡེ།༽ གསལ་བ་
[^57]: དང་ ༼སྣར། པེ།༽ དང་བླང་བར་
[^58]: མཐོང་བའི་ ༼སྣར། པེ།༽ མཐོ་བའི་
[^59]: དེ་ ༼སྣར། པེ།༽ དེ་དང་
[^60]: བསྟན་ཏོ། ༼སྣར།༽ བསྟན་ཏེ།

[^63]: སྟོབས་ཀྱི་ ༼སྣར། པེ།༽ སྟོབས་ཀྱིས་
[^64]: སེམས་དཔའི་ ༼སྣར། པེ།༽ སེམས་པའི་
[^65]: དཔའ་བའོ། ༼སྣར། པེ།༽ དཔའ་བོའོ།
[^66]: དེ་ལྟ་ ༼སྣར། པེ།༽ དེ་
[^67]: ལྟོས་ ༼སྣར། པེ།༽ བལྟོས་
[^68]: མཐོང་བའི་ལམ་ ༼སྣར། པེ།༽ མཐོང་བ་
[^69]: རྣམས་ཀྱི་ ༼སྡེ།༽ རྣམས་
[^70]: ཞུགས་པའི་ ༼སྣར། པེ།༽ ཐུག་པའི་
[^71]: རབ་ ༼སྣར། པེ།༽ བར་
[^72]: བསལ་བའི་ ༼སྣར།༽ གསལ་བའི་
[^73]: ཏུ་ ༼སྣར། པེ།༽ ཏུ་དོན་
[^74]: རིམས་ ༼སྣར། པེ།༽ རིམ་
[^75]: རྟོགས་ ༼སྣར།༽ རྟོགས་པ་དེ་ཉིད་ཀྱི་གནས་སྐབས་རྟོགས་
[^76]: སྐད་ཅིག་ ༼སྣར། པེ།༽ སྐད་ཅིག་མ་
[^77]: མངོན་སུམ་ ༼སྣར། པེ།༽ མངོན་
[^78]: ཡོད་པའི་ ༼སྣར།༽ ཡོད་པ་
[^79]: ཡན་ཆད་ཀྱིས་ ༼སྣར། པེ།༽ ཡན་ཆད་ཀྱི་
[^80]: གྲུབ་པ་ཡང་ ༼སྣར།༽ གྲུབ་པ་
[^81]: བྱ་བས་ ༼སྣར། པེ།༽ བྱ་བའི་
[^82]: དེ་བས་ ༼སྣར། པེ།༽ དེ་ལས་
[^83]: གྱུར་པ་ ༼སྣར། པེ།༽ གྱུར་
[^84]: གང་གི་ཕྱིར་ ༼སྣར། པེ།༽ གང་
[^85]: མེད་པས་ན་ ༼སྣར། པེ།༽ མེད་པས་
[^86]: བྱ་བས་ ༼སྣར། པེ།༽ བྱ་བའི་
[^87]: དེ་ལྟ་བས་ ༼སྣར། པེ།༽ དེ་ལྟ་བས་ན་
[^88]: རྣམ་པར་ ༼སྣར། པེ།༽ རྣམ་པར་སྣང་བ་
[^89]: ཙམ་གྱིས་ ༼སྣར། པེ།༽ ཙམ་གྱི་
[^90]: རྟོག་གམ། ༼སྣར།༽ ཏོགས་གི ༼པེ།༽ རྟོགས་གམ།
[^91]: འགའ་ཞིག་ནོར་ ༼སྣར། པེ།༽ ནོར་
[^92]: རྟོག་པ་ ༼སྣར། པེ།༽ རྟོགས་པ་
[^93]: བྱ་བས་ ༼སྣར། པེ།༽ བྱ་བའི་
[^94]: ཆོས་ཀྱི་ ༼སྣར། པེ།༽ ཆོས་ཀྱིས་
[^95]: འདི་ཉིད་སྒྱུ་མ་ཉིད་ ༼སྣར། པེ།༽ འདི་ཉིད་
[^96]: ཤེས་སོ་ཞེས་ ༼སྣར། པེ།༽ ཤེས་སོ་
[^97]: གཉིས་ཞེས་པ་ ༼སྣར། པེ།༽ གཉིས་
[^98]: རིག་པ་ ༼སྣར། པེ།༽ རིགས་པ་
[^99]: བསྒྲུབ་པ་ ༼སྣར། པེ།༽ བསྒྲུབས་པ་
[^100]: ཡིན་པའི་ལམ་མ་ ༼སྣར། པེ།༽ ཡིན་པའི་ལམ་
[^101]: ལྡན་པའི་ ༼སྣར། པེ།༽ ལྡང་བའི་
[^102]: བརྒྱུད་པས་ ༼སྣར། པེ།༽ བརྒྱུད་པ་ལས་
[^103]: འབབ་སྟེ། ༼སྣར། པེ།༽ འབབ་ཏེ།
[^104]: སོག་ ༼སྣར། པེ།༽ སོགས་
[^105]: བཞི་ ༼སྣར། པེ།༽ བཞི་དང་
[^106]: མངོན་པ་གཅིག་ ༼སྣར། པེ།༽ མངོན་པ་ཅིག་
[^107]: མངོན་པ་ ༼སྣར། པེ།༽ མངོན་པར་
[^108]: བཞག་ ༼སྡེ།༽ གཞག་
[^109]: འགལ་ཞེ་ ༼སྣར། པེ།༽ འགལ་ཞེས་
[^110]: ཀུན་རྫོབ་ཀྱི་ ༼སྣར། པེ།༽ ཀུན་རྫོབ་
[^111]: བྱ་བ་ཇི་ལྟ་བུ་ཅན་ ༼སྣར། པེ།༽ ཇི་ལྟ་བུ་
[^112]: ལྡན་པ་དག་ ༼སྣར། པེ།༽ ལྡན་པ་
[^113]: ནི་རིག་པ་དག་ ༼སྣར། པེ།༽ ནི་རིགས་པ་
[^114]: བསྒོམ་པའི་ ༼སྣར། པེ།༽ བསྒོམས་པའི་
[^115]: བསྟན་པས་ ༼སྣར།༽ བསྟེན་པས་
