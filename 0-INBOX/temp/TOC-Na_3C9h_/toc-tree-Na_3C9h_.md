## དཀར་ཆག / Table of Contents

* 1. རིམ་པ་དང་པོ་རྡོ་རྗེ་བཟླས་པའི་རིམ་པ
   * 1.1 དང་པོ་ཁོ་ནར་རླུང་གི་དེ་ཁོ་ན་ཉིད་བསྟན་པ
   * 1.2 ད་ནི་སྔགས་ཀྱི་དེ་ཁོ་ན་ཉིད་སྟོན་པའི་ཚིག་རྩ་བའི་རྒྱུད་ཉིད་ལ་འཇུག་པར་བྱ
      * 1.2.1 མི་རྟོག་དོན་གྱི་དེ་ཉིད
      * 1.2.2 གསང་བའི་ཡི་གེ
* 2. རིམ་པ་གཉིས་པ
   * 2.1 དེ་ཡི་རང་བཞིན་འཕྲོ་གསལ་བ
   * 2.2 དེ་ཡི་སྒྲུབ་པ
   * 2.3 ཡོངས་རྫོགས་རྣལ་འབྱོར་གྱི་གསལ་བ
* 3. རིམ་པ་གསུམ་པ་བདག་ལ་བྱིན་གྱིས་བརླབ་པའི་རིམ་པ
* 4. བཞི་པ་མངོན་པར་བྱང་ཆུབ་པའི་རིམ་པ
   * 4.1 རྣལ་འབྱོར་རྣམ་གཉིས
      * 4.1.1 དང་པོ་རིལ་པོར་འཛིན་པའི་རིམ་པ
      * 4.1.2 གཉིས་པ་རྗེས་སུ་གཞིག་པ

* 5. ལྔ་པ་ཟུང་འཇུག་པའི་རིམ་པ་ཐ་མ
