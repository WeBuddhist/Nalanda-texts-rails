## དཀར་ཆག / Table of Contents

* I. ཀླད་ཀྱི་དོན། [[༄༅༅། །རྒྱ་གར་སྐད་དུ། བཛྲ་ཨཱ་ས་ན་བཛྲ་གཱི་ཏི་བྲྀཏྟི།]]
* 1. དེའི་ཡུལ [[དེའི་ཡུལ་ནི་གཉིས་ཏེ། དཀོན་མཆོག་གསུམ་དང་། དེའི་རྒྱུ་བླ་མའོ། །དེ་ལ་སངས་རྒྱས་སྨོས་པས]]
   * 1.1 དཀོན་མཆོག་གསུམ [[དེའི་ཡུལ་ནི་གཉིས་ཏེ། དཀོན་མཆོག་གསུམ་དང་། དེའི་རྒྱུ་བླ་མའོ། །དེ་ལ་སངས་རྒྱས་སྨོས་པས]]
   * 1.2 དེའི་རྒྱུ་བླ་མ [[དེ་ནི་རྒྱུ་འབྲས་དང་རྟེན་གྱི་རང་བཞིན་ཡིན་པའི་ཕྱིར། དེའི་རག་ལས་ས༌[^1]བླ་མ་ཡིན་པས་དེའི་ཕྱིར།]]
* 2. ལྡོག་པ་དང་འཇུག་པའི་དབང་གིས [[དེ་ལ་ལྡོག་པ་དང་འཇུག་པའི་དབང་གིས་གཉིས་ཏེ། ལུས་རྣམ་པར་བསྐམས་པ་དང་སེམས་]]
   * 2.1 ལྡོག་པ [[དེ་ལ་ལྡོག་པ་དང་འཇུག་པའི་དབང་གིས་གཉིས་ཏེ། ལུས་རྣམ་པར་བསྐམས་པ་དང་སེམས་]]
   * 2.2 འཇུག་པ [[དེ་ལྟ་བུའི་ལྷག་པའི༌[^4]བྱེད་པ་སྤངས་ནས་འཇུག་པ་ནི་ལྷན་ཅིག་སྐྱེས་པ་འོད་གསལ་བའི་རང་བཞིན]]
* 3. དཔེ [[དེ་ལ་དཔེ་བཞི་སྟེ་མཛེས་མ་དང་། ཆུ་བོ་དང་། བྱང་ཆུབ་ཀྱི་ཤིང་དང་རྡོ་རྗེའོ། །]]
   * 3.1 མཛེས་མ [[མཛེས་མ་མཆོག་ལྡན༌[^7]ཁྱེར་ནས་རབ་ཏུ་མྱུར་བསྒྲུབས་པས། །ཞེས་བྱ་བ། མཚོན་བྱེད་བརྡའི་བདག་མེད་མའི་དབང་དུ་བྱས]]
   * 3.2 དཔེ་གཉིས་པ་ [[དཔེ་གཉིས་པ་ནི། ནཻ་རཉྫ་ནའི་འགྲམ་དུ་བདེ་བར་འཇུག་པས་འདུས། །ཞེས་བྱ་བ་ལ།]]
   * 3.3 དཔེ་གསུམ་པ་ [[དཔེ་གསུམ་པའི་དབང་དུ་བྱས་ནས། བྱང་ཆུབ་ཤིང་རྩར་རྡོ་རྗེ་གདན་བཞུགས་ནས། །ཞེས་བྱ་བ་ལ]]
   * 3.4 རྡོ་རྗེ [[དཔེ་བཞི་པའི་དོན་བསྟན་པའི་ཕྱིར། རྡོ་རྗེ་དཔེར་བྱས་ཏིང་ངེ་འཛིན་ལ་གནས། །ཞེས་བྱ་བ]]
* 4. དེས་བལྟ་བའི་ཡུལ [[དེས་བལྟ་བའི་ཡུལ་གཉིས་ཏེ་མེད་པ་དང་ཡོད་པའོ། །མེད་པ་མཐོང་བ་ནི་ཚུ་རོལ་མཐོང་བའི་]]
   * 4.1 མེད་པ་མཐོང་བ [[མེད་པ་མཐོང་བ་ནི་ཚུ་རོལ་མཐོང་བའི་ཤེས་པ་དང་། ཤེས་བྱ་མ་ལུས་པ་སྟེ་མེད་པ]]
   * 4.2 ཡོད་པའི་རང་བཞིན་མཐོང་བ [[ཡོད་པའི་རང་བཞིན་མཐོང་བ་ལ་གཉིས་ཏེ་རྟེན་འོད་གསལ་དང་། བརྟེན་པ་ཟག་མེད་ཀྱི་ཡོན་ཏན]]
      * 4.2.1 རྟེན་འོད་གསལ [[འོད་གསལ་ཇི་ལྟར་མཐོང་ཞེ་ན། སྐྱེ་བ་མེད་པ་རྣམ་པ་མེད་པར་མཐོང་བས་དེའི་ཕྱིར།]]
      * 4.2.2 བརྟེན་པ་ཟག་མེད་ཀྱི་ཡོན་ཏན་མཐོང་བ [[ཟག་མེད་ཀྱི་ཡོན་ཏན་ཇི་ལྟར་མཐོང་ཞེ་ན། སྒྱུ་མ་དང་རྨི་ལམ་དང་། མིག་འཕྲུལ་དང་།]]
* 5. དེ་ལ་དཔེ་གཉིས [[དེ་ལ་དཔེ་གཉིས་ཏེ། བྱ་རྒོད་རྟེན་པའི་ཤིང་གི་དཔེ་དང་། ནམ་མཁའི་མེ་ཏོག་ལ]]
   * 5.1 དང་པོ་ [[དང་པོ་ལ་གཉིས་ཏེ། བཅིང་བ་དང་བཏང་བའི་དཔེའོ། ། བྱ་རྒོད་གནས་པའི་ཤིང་དེ་]]
      * 5.1.1 བཅིང་བའི་དཔེ [[དང་པོ་ལ་གཉིས་ཏེ། བཅིང་བ་དང་བཏང་བའི་དཔེའོ། ། བྱ་རྒོད་གནས་པའི་ཤིང་དེ་]]
      * 5.1.2 བཏང་བའི་དཔེ [[བྱ་རྒོད་བཅིངས་པ་ལས་བཏང་ན་ཤ་ཁྲག་འཐུང་བས་བཀྲེས་པ་མེད་པ་དང་འདྲ་བར་ཡིད་ཀྱི]]
   * 5.2 དཔེ་གཉིས་པ་ལྡོག་པའི་དབང་དུ་བྱས་པ [[དཔེ་གཉིས་པ་ལྡོག་པའི་དབང་དུ་བྱས་ནས། ངེས་སྦྱངས་བག་ཆགས་བྲལ་བས་རྣལ་འབྱོར་མ་མཐོང་བ།]]
* a. བསྔོ་བ། [[ཆོས་ཚུལ་ཟབ་མོ་རྒྱ་མཚོ་ལྟ་བུ་འདི། །]]
* b. མཇུག་བྱང། [[རྡོ་རྗེའི་གླུའི་དོན་གསལ་བར་བྱེད་པ་མཁས་པ་ཆེན་པོ་]]
   * b.1 མཛད་བྱང། [[རྡོ་རྗེའི་གླུའི་དོན་གསལ་བར་བྱེད་པ་མཁས་པ་ཆེན་པོ་]]
   * b.2 འགྱུར་བྱང། [[པཎྜི་ཏ་དེ་ཉིད་དང་། དགེ་སློང་ཚུལ་ཁྲིམས་རྒྱལ་བས་བསྒྱུར་ཏེ]]
