━━━ ISSUE TYPES ━━━

CONNECTOR_ENDING
  The block ends with a connector particle (དང་། / ཞིང་། / ཅིང་། / ནས། / ལས། /
  སྟེ། / ཏེ།) that grammatically requires continuation. Real issue if the next
  block is the grammatical continuation. False positive if this is a closing verse
  pāda or a deliberate short citation frame.

OBJECTION_REPLY_FUSED
  The block contains both an objection marker (ཅེ་ན། / ཞེ་ན། / སྙམ་ན།) and a reply
  opener (འོ་ན།). These should always be two separate blocks. Almost always a
  real issue.

OVER_LENGTH
  The block exceeds the syllable threshold. Usually NOT wrong: a whole explanation
  unit is legitimately long. Split only if a new node opener (ordinal + title +
  ནི། / ལ་ N།) or the treatment of a new verse is buried mid-block.

SHORT_FRAGMENT
  The block is suspiciously short — may be a stray split artifact that should be
  merged with an adjacent block.

ཁ་ན་མ་ཐོ་རྣམ་གསུམ་འགྱུར། །ཞེས་བྱ་བས་ཉེས་པ་སྦོམ་པོའི་གནས་བསྟན་ཏེ། བྱོལ་སོང་ནི་རྟ་དང་བ་ལང་དང་ལུག་ལ་སོགས་པ་ལ་བྱ་སྟེ། དགེ་སྦྱོང་གིས་གསད༌[^234]སེམས་ཀྱིས་བྱོལ་སོང་བསད་ན་སྡིག་པ་སྦོམ་པོ་ཐོབ་པར་འགྱུར་ཞེས་བྱ་བར་སྦྱར་ཏེ། སེམས་ཅན་དམྱལ་བ་དང་ཞེས་བྱ་བ༌[^235]སེམས་ཅན་དམྱལ་བ་ལ་རྣམ་པ་གཉིས་ཏེ། སེམས་ཅན་དམྱལ་བ་ཆེན་པོ་དང་། ཕྱོགས་གཅིག་པའི་སེམས་ཅན་དམྱལ་བའོ། །སེམས་ཅན་དམྱལ་བ་ཆེན་པོ་ལ་ཡང་རྣམ་པ་གཉིས་ཏེ། ཚ་བའི་སེམས་ཅན་དམྱལ་བ་དང་། གྲང་བའི་སེམས་ཅན་དམྱལ་བའོ། །དེ་ལ་ཚ་བའི་སེམས་ཅན་དམྱལ་བ་ནི་མནར་མེད་པ་དང་། རབ་ཏུ་ཚ་བ་དང་། ཚ་བ་དང་། ངུ་འབོད་ཆེན་པོ་དང་། ངུ་འབོད་དང་། བསྡུས་འཇོམས༌[^236]དང་། ཐིག་ནག་དང་། ཡང་སོས་སོ། །གྲང་བའི་སེམས་ཅན་དམྱལ་བ་ཆེན་པོ་ལ་ཡང་བརྒྱད་དེ། ཆུ་བུར་དང་། ཆུ་བུར་ཆེན་པོ་དང་། པདྨ་དང་། པདྨ་ཆེན་པོ་དང་། ཨུཏྤ་ལ་དང་། ཨུཏྤ་ལ་ཆེན་པོ་དང་། ཧ་ཧ་ཞེས་ཟེར་བ་དང་། ཧུ་ཧུ་ཞེས་ཟེར་རོ། །ཕྱོགས་གཅིག་པའི་སེམས་ཅན་དམྱལ་བ་ཞེས་བྱ་བ་ནི་ལྷའི་ལོངས་སྤྱོད་ཀྱང་ཡོད་ལ་བར་འགའ་ནི་སེམས་ཅན་དམྱལ་བའི་སྡུག་བསྔལ་ཡང་མྱོང་བའོ། །དགེ་སྦྱོང་གིས་གསད༌[^237]སེམས་ཀྱིས་སེམས་ཅན་དམྱལ་བ་བསད་ན༌[^238]སྡིག་པ་སྦོམ་པོ་ཐོབ་པར་འགྱུར་ཞེས་བྱ་བར་སྦྱར་རོ། །ཡི་དགས་ཞེས་བྱ་བ་ལ། ཡི་དགས་ཞེས་བྱ་བ་ནི་ཕལ་ཆེར་གཅོང་རོང་དང་མྱ་ངན༌[^239]དག་ན་གནས་སོ། །དགེ་སྦྱོང་གིས་གསད༌[^240]སེམས་ཀྱིས་ཡི་དགས་བསད་ན་སྡིག་པ་སྦོམ་པོ་ཐོབ་པར་འགྱུར་ཞེས་བྱ་བར་སྦྱར་རོ། །ལྷ་ཡང་རུང་ཞེས་བྱ་བས་འདོད་ཁམས་ཀྱི་ལྷ་དང་། གཟུགས་ཁམས་ཀྱི་ལྷ་དང་། གནས་རིས་བཅུ་བདུན་ཞེས་བྱ་བ་ན་གནས་པའི་ལྷ་རྣམས་དགེ་སྦྱོང་གིས༌[^241]བསད་ན་སྡིག་པ་སྦོམ་པོ་ཐོབ་པར་འགྱུར་ཞེས་བྱ་བར་སྦྱར་རོ། །སྡིག་པ་སྦོམ་པོ་ཐོབ་པར་འགྱུར་ཞེས་བྱ་བ་གང་ཞེ་ན། སྡིག་པ་སྦོམ་པོའི་འབྲས་བུ་བསྟན་པའི་ཕྱིར། བསད་ན་ངན་སོང༌[^242]ལྟུང་བའི་ཞེས་བྱ་བ་སྨོས་ཏེ། དཔེར་ན་དུག་ཆེན་པོས་ཀྱང་སྐྱེས་བུ་ཆེན་པོ་གསོད་ལ། དུག་ཆུང་ངུས་ཀྱང་སྐྱེས་བུ་ཆེན་པོ་གསོད་པ་དང་། དེ་བཞིན་དུ་མེ་སྟག་ཆེན་པོས་ཀྱང་ཡུལ་ཆེན་པོ་ཚིག༌[^243]ལ་མེ་སྟག་ཆུང་ངུས་ཀྱང་ཡུལ་ཆེན་པོ་སྲེག་པ༌[^244]དང་། ཕས་ཕམ་པ་བྱུང་ན་ངན་སོང་གསུམ་དུ་སྐྱེ་བར༌[^245]འགྱུར་བ་དེ་བཞིན་དུ་ཉེས་པ་སྦོམ་པོ་བྱུང་བ་ལ་ཚུལ་བཞིན་དུ་མ་བཤགས་ན་ངན་སོང་གསུམ་དུ་ལྟུང་བར་འགྱུར་རོ་ཞེས་བྱ་བའི་དོན་ཏོ། །

ཞེས་བྱ་བས་ཉེས་བྱས་ཀྱི་གནས་བསྟན་ཏེ། དེ་ཞེས་བྱ་བ་ལ་གསད༌[^252]སེམས་ནི་མེད་ཀྱི་དགེ་སྦྱོང་གིས༌[^253]ཁྲོ་སེམས་ཀྱིས་མི་རྣམ་པ་གསུམ་ལ་བཙོགས༌[^254]ན་ཉེས་བྱས་སུ་འགྱུར་རོ། །ཁུ་ཚུར་འཚོག་པ་དང་ཞེས་བྱ་བ་ལ་གསད༌[^255]སེམས་ནི་མེད་ཀྱིས། ཁྲོ་སེམས་ཀྱིས་མི་རྣམ་པ་གསུམ་བཙོགས་ན༌[^256]ཉེས་བྱས་སུ་འགྱུར་རོ། །དེ་ལས་གཞན་པའི་གནོད་པ་དང་ཞེས་བྱ་བ་ནི་གསད༌[^257]སེམས་མེད་པར་ཁྲོ༌[^258]སེམས་ཀྱིས་མི་རྣམས་ལ་ཐལ་མོ་བསྣུན་ནམ།[^259] ལྕག་གིས་གཞུས་སམ། ལྷགས་པའི་ཚེ་གྲང་བ་ལ་བོར་ཏམ། ཚ་བའི་ཚེ་དྲོ་བ་ལ་བོར་ན་ཉེས་བྱས་སུ་འགྱུར་ཏེ་དབྱུག་པ་ལ་སོགས་པའི་གྲངས་སུ༌[^260]ཕག་པ་ཉེས་བྱས་ཀྱི་གྲངས་ཀྱང་དེ་སྙེད་ཅིག་འཐོབ་བོ། །བ་ལང་ལ་སོགས་གནོད་མི་བྱ། །ཞེས་བྱ་བ་ནི་གཞན་ཡང་བ་ལང་དང་གླང་པོ་ཆེ་དང་རྟ་དང་ལུག་ལ་སོགས་པ་ལ་ཁལ་དགལ་བ་དང་བརྡེག་པ་ལ་སོགས་པའི་གནོད་པ་མི་བྱ་སྟེ། དེ་ལྟ་བུའི་གནོད་པ་བྱས་ན་ཉེས་བྱས་སུ་འགྱུར་རོ། །རྟ་ལ་སོགས་པ་མི་བཞོན་ནོ། །ཞེས་བྱ་བ་ནི་དགེ་སྦྱོང་གིས་རྟ་དང་གླང་པོ་ཆེ་ལ་སོགས་པ་བཞོན་པར་མི་བྱ་སྟེ། ཞོན༌[^261]ན་ཉེས་བྱས་སུ་འགྱུར་རོ། །དེ་ལ་གནོད༌[^262]སེམས་མེད་ལ་ཡན་ལག་གཞན་ཡོད་ན་ནི་ཉེས་བྱས་སུ་བཞག་གོ། །གནོད༌[^263]སེམས་ཡོད་ལ་ཡན་ལག་གཞན་མི་ལྡན་ན་སྦོམ་པོའོ། །ཡན་ལག་ཐམས་ཅད་དང་ལྡན་ན་མི་དེ་ནོར་ཏེ་གཞན་བསད་ན་ཡང་སྦོམ་པོའོ། །གསད་པར༌[^264]བསམས་ཏེ་སྦྱོར་བ་བྱས་པ་ལས་མ་ཤི་ན་ཡང་སྦོམ་པོའོ། །ཡན་ལག་ཐམས་ཅད་དང་ལྡན་ན་ཕས་ཕམ་པའོ། །ཕས་ཕམ་པ་བཞི་ལས་སྲོག་གཅོད་པའི་ཕས་ཕམ་པ༌[^265]རྫོགས་སོ།། །།

### མ་བྱིན་པར་ལེན་པའི་ཕས་ཕམ་པ། ^5-2-0

[Block 206]
མ་བྱིན་པར་ལེན་པའི་གླེང་གཞི་ནི་བཅོམ་ལྡན་འདས་ཡུལ་རྒྱལ་པོའི་ཁབ་འོད་མའི་ཚལ་བྱ་ཀ་ལན་ད༌[^266]ཀ་གནས་པ་ན་བཞུགས་སོ། །དེའི་ཚེ་སྔོན་རྫ་མཁན་ལས་རབ་ཏུ་བྱུང་བའི་དགེ་སློང་ནོར་ཅན་ཞེས་བྱ་བ་ཞིག་རྒྱལ་པོའི་ཁབ་ཀྱི་དགོན་པ་ན་སྤྱིལ་པོ་བྱས་ནས་གནས་སོ། །དེ་ནས་ནོར་ཅན་གང་གི་ཚེ་རྒྱལ་པོའི་ཁབ་ཏུ་བསོད་སྙོམས༌[^267]ལ་ཞུགས་པ་དེའི་ཚེ་རྒྱལ་པོའི་ཁབ་ཀྱི་ཕྱུགས་རྫི་དང་ཤིང་ཐུན་རྣམས་ཀྱིས༌[^268]སྤྱིལ་པོ་བཤིག་དྲལ་ཅིང་རྩྭ༌[^269]དང་ཤིང་རྣམས་སོ་སོར་ཁྱེར་རོ། །དེ་ལྟ་བུ་ལན་དུ་མ་ཞིག་བྱས་པ་དང་རྫ་མཁན་ནོར་ཅན་གྱིས་བསམས་པ་འདི་ལྟ་བུ་ཐམས་ཅད་དུ་གཙེས་ཤིང་སྤྱིལ་པོ་བྱེད་པ་ཡང་ཤིན་ཏུ་ཉོན་མོངས༌[^270]ལ་དགེ་བའི་བར་ཆད་དུ་ཡང་འགྱུར་བས་འོ་ན་བདག་གིས་སྔོན་གྱི་གནས་རྗེས་སུ་བསྒྲུབ་པས་སའི་སྤྱིལ་པོ་ཞིག་བྱས་ལ་སོ་བཏང་སྟེ་གནས་སོ་སྙམ་དུ་བསམས་ནས་ཁང་བུའི་རྨང་བཏིང་ཞིང་བརྩིགས་ནས་སོ་བཏང་ནས་ཤིན་ཏུ་མཛེས་པ་མེ་ཏོག་ཛི་བ་ཀ་བཞིན་དུ་དམར་ཞིང༌[^271]འཚེར་བ་ཞིག་བྱས་ཏེ་གནས་སོ། །དུས་གཞན་ཞིག་ན་བཅོམ་ལྡན་འདས་འཁོར་དགེ་སློང་རྣམས་དང་གནས་རྒྱུ་ཞིང་གཤེགས་པས་ཁང་བུ་གཟིགས་ནས་སུའི་ཡིན། དེ་ནི་དགེ་སློང་ནོར་ཅན་གྱི་ལགས་སོ་ཞེས་སྨྲས་སོ། །འདི་ལྟ་བུའི་ཕྱིར་མུ་སྟེགས་པ་རྣམས་ང་ལ་འཕྱ་བར་འགྱུར༌[^272]གྱིས་ཁང་བུ་ཆོམས་ཤིག༌[^273]ཅེས་བཀའ་སྩལ་ནས། དགེ་སློང་རྣམས་ཀྱིས་ཁང་བུ་བཅོམ་སྟེ་གནས་སོ། །དེ་ནས་ཡང་ནོར་ཅན་གྱིས༌[^274]བསམ་པ་རྒྱལ་པོའི་ཁབ་གྱི་ཤིང་སྲུངས་ཀྱི་དཔོན་དང་བདག་མཛའ་བས་ཤིང་གི་ཁང་པ་ཞིག་བྱའོ་སྙམ་དུ་བསམས་ནས། ཤིང་སྲུངས་པ་ལ་ལྷས་ཤིང་བྱིན་པ༌[^275]འོན་ཅིག་ཅེས་སྨྲས་པ་དང་། ཤིང་སྲུངས་ཀྱི་དཔོན་པོས་ཀྱང་ལྷས་ཕུལ་ན་བཙུན་པ་ཅི་བདེར་སྣོམས་ཤིག་ཅེས་སྨྲས་ནས། རྒྱལ་པོའི་ཁབ་ཀྱི་ཞིག་རལ་བཅོས་པའི་རྒྱུ་ཤིང་བཅད་པ་དུ་མ་ཞིག་གཤགས་གཏུབས་ཏེ་ཁྱེར་བ༌[^276]གྲོང་ཁྱེར་སྲུངས་པའི༌[^277]དཔོན་པོས་མཐོང་ནས་རྒྱལ་པོ་མ་སྐྱེས་དགྲ་ལ་སྨྲས་སོ། །རྒྱུ་མཚན་ཅན་བཀུག༌[^278]སྟེ། དགེ་སློང་ཁྱོད་ནི་ཤིང་མ་བྱིན་པར་ལེན་པ་དབང་བྱས་པ་དང་། མི་དབང་གིས་བདག་ལ་སྩལ་ཏོ། །སྔོན་ཡབ་ཀྱིས་ལྷ་ཁྱོད་རྒྱལ་པོར་དབང་བསྐུར་བའི་ཚེ་ངའི་ཡུལ་དགེ་བར་གྲགས་པས་དགེ་སློང་དང་བྲམ་ཟེ་རྣམས་རྩྭ་དང་ཤིང་དང་ཆུ་མ་བྱིན་པར་མི་སྤྱོད་པ༌[^279]དེ་ཐམས་ཅད་ཅི་བདེར་སྤྱོད་ཅིག་ཅེས་ཁྱུ་མཆོག་གི་སྒྲ་ཆེན་པོ་བསྒྲགས་པ་ནི༌[^280]མི་དགོངས་སམ། རྒྱལ་པོས་སྨྲས་པ། དེ་ནི་ཡོངས་སུ་བཟུང་བ་མེད་པ་ལ་བྱའི་ཡོངས་སུ་བཟུང་བ་ལ་ནི་མ་ཡིན་ནོ་ཞེས་སྨྲས་པ་དང་། ཡོངས་སུ་མ་བཟུང་བ་ལ་ནི་རྒྱལ་པོས་མངའ་བགྱིར་ཅི་མཆིས་ཞེས་གསོལ་པ་དང་། རྒྱལ་པོ་ཤིན་ཏུ་ཁྲོས་ནས་མ་བྱིན་པར་ལེན་པའི་དགེ་སློང་བསད་པར་རིགས་ན་ཁྱོད་ད་སླན་ཆད་དེ་ལྟར་མ་བྱེད་ཅིག་ཅེས་སྤྱོས་ནས་སླར་བཏང་ངོ་། །དེ་ནས་དེ་ལྟར་གྱུར་པ་དགེ་སློང་རྣམས་ཀྱིས་བཅོམ་ལྡན་འདས་ལ་གསོལ་ཏོ། །བཅོམ་ལྡན་འདས་ཀྱིས་ཀུན་དགའ་བོ་ལ་བཀའ་སྩལ་པ། ### མ་བྱིན་པར་ལེན་པའི་ཕས་ཕམ་པ། ^5-2-0

[Block 206 — OVER_LENGTH (637 syllables)]
མ་བྱིན་པར་ལེན་པའི་གླེང་གཞི་ནི་བཅོམ་ལྡན་འདས་ཡུལ་རྒྱལ་པོའི་ཁབ་འོད་མའི་ཚལ་བྱ་ཀ་ལན་ད༌[^266]ཀ་གནས་པ་ན་བཞུགས་སོ། །དེའི་ཚེ་སྔོན་རྫ་མཁན་ལས་རབ་ཏུ་བྱུང་བའི་དགེ་སློང་ནོར་ཅན་ཞེས་བྱ་བ་ཞིག་རྒྱལ་པོའི་ཁབ་ཀྱི་དགོན་པ་ན་སྤྱིལ་པོ་བྱས་ནས་གནས་སོ། །དེ་ནས་ནོར་ཅན་གང་གི་ཚེ་རྒྱལ་པོའི་ཁབ་ཏུ་བསོད་སྙོམས༌[^267]ལ་ཞུགས་པ་དེའི་ཚེ་རྒྱལ་པོའི་ཁབ་ཀྱི་ཕྱུགས་རྫི་དང་ཤིང་ཐུན་རྣམས་ཀྱིས༌[^268]སྤྱིལ་པོ་བཤིག་དྲལ་ཅིང་རྩྭ༌[^269]དང་ཤིང་རྣམས་སོ་སོར་ཁྱེར་རོ། །དེ་ལྟ་བུ་ལན་དུ་མ་ཞིག་བྱས་པ་དང་རྫ་མཁན་ནོར་ཅན་གྱིས་བསམས་པ་འདི་ལྟ་བུ་ཐམས་ཅད་དུ་གཙེས་ཤིང་སྤྱིལ་པོ་བྱེད་པ་ཡང་ཤིན་ཏུ་ཉོན་མོངས༌[^270]ལ་དགེ་བའི་བར་ཆད་དུ་ཡང་འགྱུར་བས་འོ་ན་བདག་གིས་སྔོན་གྱི་གནས་རྗེས་སུ་བསྒྲུབ་པས་སའི་སྤྱིལ་པོ་ཞིག་བྱས་ལ་སོ་བཏང་སྟེ་གནས་སོ་སྙམ་དུ་བསམས་ནས་ཁང་བུའི་རྨང་བཏིང་ཞིང་བརྩིགས་ནས་སོ་བཏང་ནས་ཤིན་ཏུ་མཛེས་པ་མེ་ཏོག་ཛི་བ་ཀ་བཞིན་དུ་དམར་ཞིང༌[^271]འཚེར་བ་ཞིག་བྱས་ཏེ་གནས་སོ། །དུས་གཞན་ཞིག་ན་བཅོམ་ལྡན་འདས་འཁོར་དགེ་སློང་རྣམས་དང་གནས་རྒྱུ་ཞིང་གཤེགས་པས་ཁང་བུ་གཟིགས་ནས་སུའི་ཡིན། དེ་ནི་དགེ་སློང་ནོར་ཅན་གྱི་ལགས་སོ་ཞེས་སྨྲས་སོ། །འདི་ལྟ་བུའི་ཕྱིར་མུ་སྟེགས་པ་རྣམས་ང་ལ་འཕྱ་བར་འགྱུར༌[^272]གྱིས་ཁང་བུ་ཆོམས་ཤིག༌[^273]ཅེས་བཀའ་སྩལ་ནས། དགེ་སློང་རྣམས་ཀྱིས་ཁང་བུ་བཅོམ་སྟེ་གནས་སོ། །དེ་ནས་ཡང་ནོར་ཅན་གྱིས༌[^274]བསམ་པ་རྒྱལ་པོའི་ཁབ་གྱི་ཤིང་སྲུངས་ཀྱི་དཔོན་དང་བདག་མཛའ་བས་ཤིང་གི་ཁང་པ་ཞིག་བྱའོ་སྙམ་དུ་བསམས་ནས། ཤིང་སྲུངས་པ་ལ་ལྷས་ཤིང་བྱིན་པ༌[^275]འོན་ཅིག་ཅེས་སྨྲས་པ་དང་། ཤིང་སྲུངས་ཀྱི་དཔོན་པོས་ཀྱང་ལྷས་ཕུལ་ན་བཙུན་པ་ཅི་བདེར་སྣོམས་ཤིག་ཅེས་སྨྲས་ནས། རྒྱལ་པོའི་ཁབ་ཀྱི་ཞིག་རལ་བཅོས་པའི་རྒྱུ་ཤིང་བཅད་པ་དུ་མ་ཞིག་གཤགས་གཏུབས་ཏེ་ཁྱེར་བ༌[^276]གྲོང་ཁྱེར་སྲུངས་པའི༌[^277]དཔོན་པོས་མཐོང་ནས་རྒྱལ་པོ་མ་སྐྱེས་དགྲ་ལ་སྨྲས་སོ། །རྒྱུ་མཚན་ཅན་བཀུག༌[^278]སྟེ། དགེ་སློང་ཁྱོད་ནི་ཤིང་མ་བྱིན་པར་ལེན་པ་དབང་བྱས་པ་དང་། མི་དབང་གིས་བདག་ལ་སྩལ་ཏོ། །སྔོན་ཡབ་ཀྱིས་ལྷ་ཁྱོད་རྒྱལ་པོར་དབང་བསྐུར་བའི་ཚེ་ངའི་ཡུལ་དགེ་བར་གྲགས་པས་དགེ་སློང་དང་བྲམ་ཟེ་རྣམས་རྩྭ་དང་ཤིང་དང་ཆུ་མ་བྱིན་པར་མི་སྤྱོད་པ༌[^279]དེ་ཐམས་ཅད་ཅི་བདེར་སྤྱོད་ཅིག་ཅེས་ཁྱུ་མཆོག་གི་སྒྲ་ཆེན་པོ་བསྒྲགས་པ་ནི༌[^280]མི་དགོངས་སམ། རྒྱལ་པོས་སྨྲས་པ། དེ་ནི་ཡོངས་སུ་བཟུང་བ་མེད་པ་ལ་བྱའི་ཡོངས་སུ་བཟུང་བ་ལ་ནི་མ་ཡིན་ནོ་ཞེས་སྨྲས་པ་དང་། ཡོངས་སུ་མ་བཟུང་བ་ལ་ནི་རྒྱལ་པོས་མངའ་བགྱིར་ཅི་མཆིས་ཞེས་གསོལ་པ་དང་། རྒྱལ་པོ་ཤིན་ཏུ་ཁྲོས་ནས་མ་བྱིན་པར་ལེན་པའི་དགེ་སློང་བསད་པར་རིགས་ན་ཁྱོད་ད་སླན་ཆད་དེ་ལྟར་མ་བྱེད་ཅིག་ཅེས་སྤྱོས་ནས་སླར་བཏང་ངོ་། །དེ་ནས་དེ་ལྟར་གྱུར་པ་དགེ་སློང་རྣམས་ཀྱིས་བཅོམ་ལྡན་འདས་ལ་གསོལ་ཏོ། །བཅོམ་ལྡན་འདས་ཀྱིས་ཀུན་དགའ་བོ་ལ་བཀའ་སྩལ་པ། ཀུན་དགའ་བོ་ཁྱོད་སོང་ལ་རྒྱལ་པོའི་གྲོང་དཔོན་དང་དེད་དཔོན་ལམ་བྱིན་པར་ལེན་པ་ཇི་ཙམ་ཞིག་བླངས་པས་སྲོག་ལ་འབབ་པ་དང་ཡུལ་ནས་དབྱུང་བའི་ཆད་པ་གཅོད་པར་བྱེད་སྨྲོས་ཤིག་ཅེས་བཀའ་སྩལ་པ་དང་། ཀུན་དགའ་བོས་དེ་བཞིན་དུ་སྨྲས་པ་དང་། མ་ཤ༌[^281]ཀ་ལྔའམ་ལྔ་ལས་ལྷག་པ་བླངས་པས་སྲོག་ལ་འབབ་པ་དང་ཡུལ་ནས་འབྱིན་པའི་ཆད་པ་གཅོད༌[^282]དོ་ཞེས་མཆི་བ་བཅོམ་ལྡན་འདས་ལ་དེ་བཞིན་གསོལ་པས། རང་གི་ཡུལ་ནས་བྱུང་བ་ཡང་། །ཀཱར་ཥཱ་པ་ཎའི་བཞི་ཆ་བརྐུས།[^284] །དེ་བརྐུས་ཚུལ་ཁྲིམས་ཞིག་པར་འགྱུར། །ཞེས་བྱ་བ་ལ་དགེ་ཚུལ་ནི་རབ་ཏུ་བྱུང་བའི་སྡོམ་པ་ལ་གནས་པའོ། །བདག་གིས་ཀྱང་རྐུ་སེམས་དང་ལྡན་པས་མཐུ་དང་འཇབ་བུ་ཡིས་བརྐུས་ན་ཚུལ་ཁྲིམས་ཞིག་པར་འགྱུར་ཞེས་བྱ་བར་སྦྱར་ཏེ། འདི་ལྟར་རྐུ་སེམས་དང་ལྡན་པས་མཐུ་དང་འཇབ༌[^285]བུས་ཀཱར་ཥཱ་པཎའི་བཞི་ཆ་བརྐུས་ཏེ་རིན་ཐང་ཚང་ན༌[^286]ཕས་ཕམ་པའོ། །རྐུ་སེམས་མེད་ན་བསྡམ་པར་བྱ་བའི་ཉེས་བྱས་གཅིག །གཞན་གྱི༌[^287]མཐུ་དང་འཇབ་བུས་བརྐུས་ན་ཚུལ་ཁྲིམས་ཞིག་པར་འགྱུར་ཏེ། བདག་ཉིད་ཀྱིས་ནི་མ་ཡིན་གྱིས་དགེ་སློང་གྲོགས་པོ་ཞིག་ལ་རྐུར་བཅུག་པ་ལས་དེས་མཐུ་དང་འཇབ་བུས་བརྐུས་ཏེ། ནོར་བདག་ཅག་སོ་སོར་བགོས་རིན་ཐང་ཚང་ན་ཕས་ཕམ་པར་འགྱུར་རོ། །རིན་ཐང་མ་ཚང་ན་ཉེས་བྱས་སྦོམ་པོ་རེ་རེ་བརྐུས་ན་བརྐུས་ཤས་ཀྱི༌[^288]སྐལ་བ་བླངས་ན་ཉེས་པ་སྦོམ་པོ་གཅིག །འཁྲུལ་པ་མེད་པར་མི་གཞན་གྱི་ཞེས་བྱ་བ་ལ་འཁྲུལ་པ་ནི་རྨོངས་པ་དང་མི་དྲན་པ་ཡིན་ལ་དེ་མེད་པ་ནི་སེམས་རང་བཞིན་དུ་གནས་པའོ། །ཡང་བརྐུ་བར་བྱ་བའི་རྫས་གང་ཡིན་པ་དེ་ཉིད་མངོན་པར་ཐོབ་པ་ལ་བྱ་སྟེ། བརྐུ་བར་བྱ་བའི་རྫས་ཉིད་ནི་མ་ཐོབ་ཀྱི་བར་དུ་རྫས་གཞན་གྱིས་ཐོབ་པ་ལས་འཁྲུལ་ཞེས་བྱ་སྟེ་དེ་ནི་རིན་ཐང་ཚང་ཡང་ཕས་ཕམ་པར་མི་བྱ་སྟེ་སྦོམ་པོར་འགྱུར་རོ། །མི་གཞན་ཞེས་བྱ་བ་ནི་བདག་གི་ནོར་དགར་བའི་ཚིག་སྟེ། མི་གཞན་གྱི་ནོར་བརྐུས་ན་ཕས་ཕམ་པར་འགྱུར་རོ།[^289] །བདག་གི་ནོར་བརྐུས་ན་རིན་ཐང་ཚང་ཡང་སྦོམ་པོར་མི་འགྱུར་རོ། །གནས་ནས་མ་ཤ་ལྔ་ཙམ་ཞེས་བྱ་བ་ལ་གནས་ནི་ནོར་རྫས་གནས་ནས་སྤགས་ཏེ་བར་དུ་ཆོད་རིན་ཐང་ཚང་བ་ལས་ཕམ་པའོ། །དེ་ཡང་གནས་གཅིག་སྟེ་གཞི་མ་ཉམས་པ་ལ་ཚོན་ལ་སོགས་པ་མ་གྲོགས་པ་དང་། ས་སྒར་སྒུར་མེད་ན་གཞི་གཅིག་པ་ཞེས་བྱ་བ་སྟེ་ནམ་ཐ་དད་པ་གཅིག༌[^290]གིས་མ་ཆོད་ཀྱི་བར་དུ་ཕམ་པར་མི་གཞག༌[^291]གོ། །མ་ཤ་ལྔ་ཙམ་ཞེས་བྱ་བ་ནི་རྒྱ་གར་གྱི་རིན་ཐང་གཞལ་ན་དངུལ་ཞོ་གཅིག་ཙམ་བརྐུས་ན་ཕམ་པར་བརྩིའོ། །ཡང་ཁ་ཅིག༌[^292]གིས་ནི་ཞོའི་བརྒྱད་ཆ་གཅིག་ལ་བྱས་ཏེ་དེ་ཙམ་གྱིས་ནི་རིན་ཐང་ཚང་བར་བརྩིའོ། །རང་གི་ཡུལ་ནས་བྱུང་བ་གང་ཞེས་བྱ་བ་ནི་རིན་ཐང་ཚང་བ་ཡང་བརྐུས་བའི་དུས་དེ་ཉིད་ན་རིན་ཐང་ཚང་མ་ཚང་བརྩིའོ། །ཁ་ཅིག༌[^293]བརྐུས་པའི་དུས་དེ་ཉིད་ན་རིན་ཐང་མ་ཚང་ལ་དཀོན་མོད་དང་སྦྱར་ཏེ། དུས་ཕྱི་ཞིག་ན་རིན༌[^294]ཐང་ཚང་བ་ལྟ་བུ་ནི་ཕམ་པར་མི་གཞག༌[^295]སྦོམ་པོའོ། །ཀཱརྵཱ་པ་ཎའི་བཞི་ཆ་བརྐུས། །ཞེས་བྱ་བ་ནི་གོང་དུ་མ་ཤ་ལྔ་བཤད་པ་དང་འདྲའོ། །སྦྱོར་བའི་ཚེ་ན་ཉེས་བྱས་སོ་ཞེས་བྱ་བ་ནི་དང་པོ་བརྐུ་བར༌[^296]བསམས་ཏེ་སྟན་དང་ཁྲི་ལས་ལངས་པའི་དུས་ཉིད་ན་ཉེས་བྱས་སུ་འགྱུར་རོ། །རྡོ་ཁུ་རྩ་བ་འབྲས་བུ་ཤིང་། །ཞེས་བྱ་བ་ལ་རྩ་བ་ནི་བླ་སྒང༌[^297]དང་བོང་ང་ཞེས་བྱ་བ་ལ་སོགས་པའོ། །འབྲས་བུ་ནི་ཤིང་ཐོག་ལ་སོགས་པའོ། །ཤིང་ནི་སྐྱེད་ཤིང་རྣམ་པ་སྣ་ཚོགས་ཏེ། དེ་དག་བརྐུས་ཏེ་རིན་ཐང་ཚང་ན་ཕམ་པ་མ་ཚང་ན་སྦོམ་པོའོ། །སྡོང་བུ་ལོ་མ་ཤུན་པ་ཆུ། །ཞེས་བྱ་བ་ལ། སྡོང་བུ་ནི་མར་དང་སྨན་ཁྲིལ་བུའི་རིགས་སུ་གཏོགས་པའོ། །ལོ་མ་ནི་ཤིང་ལོ་ལྡུམ༌[^298]ལོངས་སྤྱད་པར་འོས་པར་རུང་བའོ། །ཤུན་པ་ནི་གྲོ་ག་ལ་སོགས་པའོ། །ཆུ་ནི་ཁྲུས་ཆུ་དང་བཏུང་ཆུ་ལྟ་བུ་སྟེ་རྒྱ་མཚོར་ཞུགས་པ་དང་མྱ་ངམ་ལྟ་བུར་འགྲོ་བ་སྟེ་ཆུ་ཤིན་དུ་དཀོན་པའི་དུས་ན་བརྐུ་བའོ། །མེ་ཏོག་ཆུ་སྐྱེས་ཐང་སྐྱེས་དང་། །ཞེས་བྱ་བ་ནི་མེ་ཏོག་ཆུ་ནས༌[^299]སྐྱེས་པ་པདྨ་དང་ཨུཏྤལ་ལ་སོགས་པའོ། །ཐང་ལས་སྐྱེས་པ་སྟེ་ནཱ་ག་གེ་སར་ལ་སོགས་པའོ། །ཞིང་དང་ལོ་ཐོག་ས་གཞི་དང་། །ཞེས་བྱ་བ་ལ་ཞིང་གི་མུ་རྐུ་བ་སྟེ། ཡུལ་གྱི་རྒྱལ་པོའི་བཀའ་ཁྲིམས་ལས་བྱུང་བ་བཞིན་རིན་ཐང་བརྩིའོ། །ལོ་ཏོག་ནི༌[^300]ཐན་པ་ཆེན་པོའི་ཚེ་གཞན་གྱི་ཞིང་ལ་ཆུ་གཏོང་བ་གཅོད་ཅིང་བདག་གི་ཞིང་ལ་ཆུ་གཏོང་བ་དང་། ཆར་པ་ཆེ་བའི་དུས་ན་བདག་གི་ཞིང་ལ་ཆུ་བཅད་ནས་གཞན་གྱི་ཞིང་ལ་བཏང་སྟེ་བདག་གི་ལོ་ལེགས་ལ་གཞན་གྱི་ལོ་ཉེས་ན་རིན་ཐང་ཚང་ན་ཕམ་པ། མ་ཚང་ན་སྦོམ་པོའོ། །ལོ་ཏོག་གཉིས་ཀ་ལ་མ་ཕན་ཡང་བླ་སྙམ་པས་ཞིང་རྐུ༌[^301]སེམས་དེ་ལྟར་བཏང་སྟེ་ཕ་རོལ་པོ་ལ་ཉེས་པ་སྦོམ་པོར་འགྱུར་རོ། །ཞིང་རྐུ་བ་ལ་རྣམ་པ་གཉིས་ཏེ། ཤགས་བཀར༌[^302]གཏོང་བ་དང་ར་བས་བསྐོར་བའོ། །དགེ་སྦྱོང་གིས༌[^303]ཞལ་ཆེ་བའམ་ཡུལ་དཔོན་གྱི་མདུན་དུ་ཤགས་བཀྱེ་ལ་དགེ་སྦྱོང་རྒྱལ་བར་བཅད་ལ་ཁྱིམ་པས་ཀྱང་སྦྱོར་བའི་བསམ་པ་བཏང་ན་ཕམ་པ། སྦྱོར་བའི་བསམ་པ་མ་བཏང་ན་སྦོམ་པོའོ། །རྒྱལ་པོས༌[^304]རྒྱལ་བར་བཅད་ན་ཡུལ་གྱི་གཙོ་བོས༌[^305]རྒྱལ་བར་གྱུར་པར་གཅད༌[^306]མ་ཐག་ཏུ་ཕམ་པའོ། །བསྐོར་བས་བརྐུ་བ༌[^307]ནི་ཞིང་ལ་ར་བ་དང་འོབས་ལྟ་བུས་སྐོར་བར༌[^308]བྱེད་པ་ན་ནམ་ལངས༌[^309]ཀྱི་སྣ་མ་ཕྲད་ཀྱི་བར་དུ་སྦོམ་པོའོ། །ཕྲད་ན་ཕམ་པར་གཞག༌[^310]གོ། །ས་གཞི་ནི་ཁངས་དང་ཚོང་དུས༌[^311]ལྟ་བུ་སྟེ། མ་བྱིན་པར་ལེན་པའི་གླེང་གཞི་ནི་བཅོམ་ལྡན་འདས་ཡུལ་རྒྱལ་པོའི་ཁབ་འོད་མའི་ཚལ་བྱ་ཀ་ལན་ད༌[^266]ཀ་གནས་པ་ན་བཞུགས་སོ། །དེའི་ཚེ་སྔོན་རྫ་མཁན་ལས་རབ་ཏུ་བྱུང་བའི་དགེ་སློང་ནོར་ཅན་ཞེས་བྱ་བ་ཞིག་རྒྱལ་པོའི་ཁབ་ཀྱི་དགོན་པ་ན་སྤྱིལ་པོ་བྱས་ནས་གནས་སོ། །དེ་ནས་ནོར་ཅན་གང་གི་ཚེ་རྒྱལ་པོའི་ཁབ་ཏུ་བསོད་སྙོམས༌[^267]ལ་ཞུགས་པ་དེའི་ཚེ་རྒྱལ་པོའི་ཁབ་ཀྱི་ཕྱུགས་རྫི་དང་ཤིང་ཐུན་རྣམས་ཀྱིས༌[^268]སྤྱིལ་པོ་བཤིག་དྲལ་ཅིང་རྩྭ༌[^269]དང་ཤིང་རྣམས་སོ་སོར་ཁྱེར་རོ། །དེ་ལྟ་བུ་ལན་དུ་མ་ཞིག་བྱས་པ་དང་རྫ་མཁན་ནོར་ཅན་གྱིས་བསམས་པ་འདི་ལྟ་བུ་ཐམས་ཅད་དུ་གཙེས་ཤིང་སྤྱིལ་པོ་བྱེད་པ་ཡང་ཤིན་ཏུ་ཉོན་མོངས༌[^270]ལ་དགེ་བའི་བར་ཆད་དུ་ཡང་འགྱུར་བས་འོ་ན་བདག་གིས་སྔོན་གྱི་གནས་རྗེས་སུ་བསྒྲུབ་པས་སའི་སྤྱིལ་པོ་ཞིག་བྱས་ལ་སོ་བཏང་སྟེ་གནས་སོ་སྙམ་དུ་བསམས་ནས་ཁང་བུའི་རྨང་བཏིང་ཞིང་བརྩིགས་ནས་སོ་བཏང་ནས་ཤིན་ཏུ་མཛེས་པ་མེ་ཏོག་ཛི་བ་ཀ་བཞིན་དུ་དམར་ཞིང༌[^271]འཚེར་བ་ཞིག་བྱས་ཏེ་གནས་སོ། །དུས་གཞན་ཞིག་ན་བཅོམ་ལྡན་འདས་འཁོར་དགེ་སློང་རྣམས་དང་གནས་རྒྱུ་ཞིང་གཤེགས་པས་ཁང་བུ་གཟིགས་ནས་སུའི་ཡིན། དེ་ནི་དགེ་སློང་ནོར་ཅན་གྱི་ལགས་སོ་ཞེས་སྨྲས་སོ། །འདི་ལྟ་བུའི་ཕྱིར་མུ་སྟེགས་པ་རྣམས་ང་ལ་འཕྱ་བར་འགྱུར༌[^272]གྱིས་ཁང་བུ་ཆོམས་ཤིག༌[^273]ཅེས་བཀའ་སྩལ་ནས། དགེ་སློང་རྣམས་ཀྱིས་ཁང་བུ་བཅོམ་སྟེ་གནས་སོ། །དེ་ནས་ཡང་ནོར་ཅན་གྱིས༌[^274]བསམ་པ་རྒྱལ་པོའི་ཁབ་གྱི་ཤིང་སྲུངས་ཀྱི་དཔོན་དང་བདག་མཛའ་བས་ཤིང་གི་ཁང་པ་ཞིག་བྱའོ་སྙམ་དུ་བསམས་ནས། ཤིང་སྲུངས་པ་ལ་ལྷས་ཤིང་བྱིན་པ༌[^275]འོན་ཅིག་ཅེས་སྨྲས་པ་དང་། ཤིང་སྲུངས་ཀྱི་དཔོན་པོས་ཀྱང་ལྷས་ཕུལ་ན་བཙུན་པ་ཅི་བདེར་སྣོམས་ཤིག་ཅེས་སྨྲས་ནས། རྒྱལ་པོའི་ཁབ་ཀྱི་ཞིག་རལ་བཅོས་པའི་རྒྱུ་ཤིང་བཅད་པ་དུ་མ་ཞིག་གཤགས་གཏུབས་ཏེ་ཁྱེར་བ༌[^276]གྲོང་ཁྱེར་སྲུངས་པའི༌[^277]དཔོན་པོས་མཐོང་ནས་རྒྱལ་པོ་མ་སྐྱེས་དགྲ་ལ་སྨྲས་སོ། །རྒྱུ་མཚན་ཅན་བཀུག༌[^278]སྟེ། དགེ་སློང་ཁྱོད་ནི་ཤིང་མ་བྱིན་པར་ལེན་པ་དབང་བྱས་པ་དང་། མི་དབང་གིས་བདག་ལ་སྩལ་ཏོ། །སྔོན་ཡབ་ཀྱིས་ལྷ་ཁྱོད་རྒྱལ་པོར་དབང་བསྐུར་བའི་ཚེ་ངའི་ཡུལ་དགེ་བར་གྲགས་པས་དགེ་སློང་དང་བྲམ་ཟེ་རྣམས་རྩྭ་དང་ཤིང་དང་ཆུ་མ་བྱིན་པར་མི་སྤྱོད་པ༌[^279]དེ་ཐམས་ཅད་ཅི་བདེར་སྤྱོད་ཅིག་ཅེས་ཁྱུ་མཆོག་གི་སྒྲ་ཆེན་པོ་བསྒྲགས་པ་ནི༌[^280]མི་དགོངས་སམ། རྒྱལ་པོས་སྨྲས་པ། དེ་ནི་ཡོངས་སུ་བཟུང་བ་མེད་པ་ལ་བྱའི་ཡོངས་སུ་བཟུང་བ་ལ་ནི་མ་ཡིན་ནོ་ཞེས་སྨྲས་པ་དང་། ཡོངས་སུ་མ་བཟུང་བ་ལ་ནི་རྒྱལ་པོས་མངའ་བགྱིར་ཅི་མཆིས་ཞེས་གསོལ་པ་དང་། རྒྱལ་པོ་ཤིན་ཏུ་ཁྲོས་ནས་མ་བྱིན་པར་ལེན་པའི་དགེ་སློང་བསད་པར་རིགས་ན་ཁྱོད་ད་སླན་ཆད་དེ་ལྟར་མ་བྱེད་ཅིག་ཅེས་སྤྱོས་ནས་སླར་བཏང་ངོ་། །དེ་ནས་དེ་ལྟར་གྱུར་པ་དགེ་སློང་རྣམས་ཀྱིས་བཅོམ་ལྡན་འདས་ལ་གསོལ་ཏོ། །བཅོམ་ལྡན་འདས་ཀྱིས་ཀུན་དགའ་བོ་ལ་བཀའ་སྩལ་པ། ཀུན་དགའ་བོ་ཁྱོད་སོང་ལ་རྒྱལ་པོའི་གྲོང་དཔོན་དང་དེད་དཔོན་ལམ་བྱིན་པར་ལེན་པ་ཇི་ཙམ་ཞིག་བླངས་པས་སྲོག་ལ་འབབ་པ་དང་ཡུལ་ནས་དབྱུང་བའི་ཆད་པ་གཅོད་པར་བྱེད་སྨྲོས་ཤིག་ཅེས་བཀའ་སྩལ་པ་དང་། ཀུན་དགའ་བོས་དེ་བཞིན་དུ་སྨྲས་པ་དང་། མ་ཤ༌[^281]ཀ་ལྔའམ་ལྔ་ལས་ལྷག་པ་བླངས་པས་སྲོག་ལ་འབབ་པ་དང་ཡུལ་ནས་འབྱིན་པའི་ཆད་པ་གཅོད༌[^282]དོ་ཞེས་མཆི་བ་བཅོམ་ལྡན་འདས་ལ་དེ་བཞིན་གསོལ་པས། རང་གི་ཡུལ་ནས་བྱུང་བ་ཡང་། །ཀཱར་ཥཱ་པ་ཎའི་བཞི་ཆ་བརྐུས།[^284] །དེ་བརྐུས་ཚུལ་ཁྲིམས་ཞིག་པར་འགྱུར། །ཞེས་བྱ་བ་ལ་དགེ་ཚུལ་ནི་རབ་ཏུ་བྱུང་བའི་སྡོམ་པ་ལ་གནས་པའོ། །བདག་གིས་ཀྱང་རྐུ་སེམས་དང་ལྡན་པས་མཐུ་དང་འཇབ་བུ་ཡིས་བརྐུས་ན་ཚུལ་ཁྲིམས་ཞིག་པར་འགྱུར་ཞེས་བྱ་བར་སྦྱར་ཏེ། འདི་ལྟར་རྐུ་སེམས་དང་ལྡན་པས་མཐུ་དང་འཇབ༌[^285]བུས་ཀཱར་ཥཱ་པཎའི་བཞི་ཆ་བརྐུས་ཏེ་རིན་ཐང་ཚང་ན༌[^286]ཕས་ཕམ་པའོ། །རྐུ་སེམས་མེད་ན་བསྡམ་པར་བྱ་བའི་ཉེས་བྱས་གཅིག །གཞན་གྱི༌[^287]མཐུ་དང་འཇབ་བུས་བརྐུས་ན་ཚུལ་ཁྲིམས་ཞིག་པར་འགྱུར་ཏེ། བདག་ཉིད་ཀྱིས་ནི་མ་ཡིན་གྱིས་དགེ་སློང་གྲོགས་པོ་ཞིག་ལ་རྐུར་བཅུག་པ་ལས་དེས་མཐུ་དང་འཇབ་བུས་བརྐུས་ཏེ། ནོར་བདག་ཅག་སོ་སོར་བགོས་རིན་ཐང་ཚང་ན་ཕས་ཕམ་པར་འགྱུར་རོ། །རིན་ཐང་མ་ཚང་ན་ཉེས་བྱས་སྦོམ་པོ་རེ་རེ་བརྐུས་ན་བརྐུས་ཤས་ཀྱི༌[^288]སྐལ་བ་བླངས་ན་ཉེས་པ་སྦོམ་པོ་གཅིག །འཁྲུལ་པ་མེད་པར་མི་གཞན་གྱི་ཞེས་བྱ་བ་ལ་འཁྲུལ་པ་ནི་རྨོངས་པ་དང་མི་དྲན་པ་ཡིན་ལ་དེ་མེད་པ་ནི་སེམས་རང་བཞིན་དུ་གནས་པའོ། །ཡང་བརྐུ་བར་བྱ་བའི་རྫས་གང་ཡིན་པ་དེ་ཉིད་མངོན་པར་ཐོབ་པ་ལ་བྱ་སྟེ། བརྐུ་བར་བྱ་བའི་རྫས་ཉིད་ནི་མ་ཐོབ་ཀྱི་བར་དུ་རྫས་གཞན་གྱིས་ཐོབ་པ་ལས་འཁྲུལ་ཞེས་བྱ་སྟེ་དེ་ནི་རིན་ཐང་ཚང་ཡང་ཕས་ཕམ་པར་མི་བྱ་སྟེ་སྦོམ་པོར་འགྱུར་རོ། །མི་གཞན་ཞེས་བྱ་བ་ནི་བདག་གི་ནོར་དགར་བའི་ཚིག་སྟེ། མི་གཞན་གྱི་ནོར་བརྐུས་ན་ཕས་ཕམ་པར་འགྱུར་རོ།[^289] །བདག་གི་ནོར་བརྐུས་ན་རིན་ཐང་ཚང་ཡང་སྦོམ་པོར་མི་འགྱུར་རོ། །གནས་ནས་མ་ཤ་ལྔ་ཙམ་ཞེས་བྱ་བ་ལ་གནས་ནི་ནོར་རྫས་གནས་ནས་སྤགས་ཏེ་བར་དུ་ཆོད་རིན་ཐང་ཚང་བ་ལས་ཕམ་པའོ། །དེ་ཡང་གནས་གཅིག་སྟེ་གཞི་མ་ཉམས་པ་ལ་ཚོན་ལ་སོགས་པ་མ་གྲོགས་པ་དང་། ས་སྒར་སྒུར་མེད་ན་གཞི་གཅིག་པ་ཞེས་བྱ་བ་སྟེ་ནམ་ཐ་དད་པ་གཅིག༌[^290]གིས་མ་ཆོད་ཀྱི་བར་དུ་ཕམ་པར་མི་གཞག༌[^291]གོ། །མ་ཤ་ལྔ་ཙམ་ཞེས་བྱ་བ་ནི་རྒྱ་གར་གྱི་རིན་ཐང་གཞལ་ན་དངུལ་ཞོ་གཅིག་ཙམ་བརྐུས་ན་ཕམ་པར་བརྩིའོ། །ཡང་ཁ་ཅིག༌[^292]གིས་ནི་ཞོའི་བརྒྱད་ཆ་གཅིག་ལ་བྱས་ཏེ་དེ་ཙམ་གྱིས་ནི་རིན་ཐང་ཚང་བར་བརྩིའོ། །རང་གི་ཡུལ་ནས་བྱུང་བ་གང་ཞེས་བྱ་བ་ནི་རིན་ཐང་ཚང་བ་ཡང་བརྐུས་བའི་དུས་དེ་ཉིད་ན་རིན་ཐང་ཚང་མ་ཚང་བརྩིའོ། །ཁ་ཅིག༌[^293]བརྐུས་པའི་དུས་དེ་ཉིད་ན་རིན་ཐང་མ་ཚང་ལ་དཀོན་མོད་དང་སྦྱར་ཏེ། དུས་ཕྱི་ཞིག་ན་རིན༌[^294]ཐང་ཚང་བ་ལྟ་བུ་ནི་ཕམ་པར་མི་གཞག༌[^295]སྦོམ་པོའོ། །ཀཱརྵཱ་པ་ཎའི་བཞི་ཆ་བརྐུས། །ཞེས་བྱ་བ་ནི་གོང་དུ་མ་ཤ་ལྔ་བཤད་པ་དང་འདྲའོ། །སྦྱོར་བའི་ཚེ་ན་ཉེས་བྱས་སོ་ཞེས་བྱ་བ་ནི་དང་པོ་བརྐུ་བར༌[^296]བསམས་ཏེ་སྟན་དང་ཁྲི་ལས་ལངས་པའི་དུས་ཉིད་ན་ཉེས་བྱས་སུ་འགྱུར་རོ། །རྡོ་ཁུ་རྩ་བ་འབྲས་བུ་ཤིང་། ### བརྫུན་དུ་སྨྲ་བའི་ཕས་ཕམ་པ། ^5-4-0

[Block 227 — OVER_LENGTH (428 syllables)]
ཕས་ཕམ་པ་བཞི་པ་བརྫུན་གྱི་གླེང་གཞི་ནི། བཅོམ་ལྡན་འདས་ཡུལ་ཡངས་པ་ཅན་གྱི་སྤྲེའུ་རྫིང་གི་འགྲམ་ན་བཞུགས་སོ། །དེའི་ཚེ་མུ་གེ་ཆེན་པོ་བྱུང་ནས་ཁ་ཟས་ཀྱིས་ཤིན་ཏུ་བྲེལ་ཏེ༌[^350]ཕ་མ་ཡང་བུ་ལ་ཁ་ཟས་མི་སྟེར་བ་ཙམ་དུ་དཀོན་པའི་ཚེ། དགེ་སློང་རྫུ་འཕྲུལ་ཅན་དང་གནས་བརྟན་རྣམས་ནི་བྱང་གི་སྒྲ་མི་སྙན་ལ་སོགས་པ་ཡུལ་གཞན་འབྱོར་ཅིང་རྒྱས་པ་དག་ཏུ་དོང་ཞིང་བདག་ཉིད་ཀྱང་ཟ། གང་ཟག་གཞན་ལ་ཡང་སྟོབས་སོ། །དེ་ལ་ཉ་པ་ལས་རབ་ཏུ་བྱུང་བའི་དགེ་སློང་ལྔ་བརྒྱ་ལ་སོགས་པ་དག་གིས་ཀྱང་དགེ་སློང་དེ་དག་ལྟར་བྱ་ཞིང་དབྱར་ཚུལ་དུ་འཇུག་ཏུ་ནི་རྫུ་འཕྲུལ་ཡང་མ་ཐོབ་ཅིང་ཐོས་པ་དག་ཀྱང་ཉུང་ཞིང་དེ་ལྟར་མི་ནུས་ཀྱིས་བདག་ཅག་གིས་ཡུལ་ཉིད་དུ་དབྱར་ཚུལ་དུ་ཞུགས་ལ་བདག་ཅག༌[^351]སོ་སོའི་ཡོན་ཏན་བསྒྲགས་ཏེ་རྙེད་པ་བསྒྲུབ་པོ་སྙམ་ནས་ཚུལ་དུ་ཞུགས་སོ། །དེ་ནས་ལྔ་བརྒྱ་པོ་དེ་དག་གིས་གཅིག་གིས་གཅིག་གི་ཡོན་ཏན་བརྗོད་པ་ལ་ཞུགས་སོ། །འདིས་རྒྱུན་དུ་ཞུགས་པའི་འབྲས་བུ་ཐོབ་བོ། །འདིས་ལན་ཅིག་ཕྱིར་འོང་བའི་འབྲས་བུ་ཐོབ་བོ། །འདིས་ཕྱིར་མི་འོང་བའི་འབྲས་བུ་ཐོབ་བོ། །འདིས་ནི་དགྲ་བཅོམ་པའི་འབྲས་བུ་ཐོབ་བོ། །འདིས༌[^352]ནི་འཇིག་རྟེན་པའི་ལམ་གྱིས་གྲུབ་བོ། །འདི་ནི་སྡེ་སྣོད་གསུམ་སྨྲ་བའོ་ཞེས་སོ་སོའི་ཡོན་ཏན་བརྗོད་པས་ཁ་ཟས་ལ་སོགས་པ༌[^353]མང་པོ་དུ་མ་རྙེད་དེ་ཤ་ཁྲག་གི་ལུས་ཤིན་ཏུ་རྟས་པས༌[^354]གནས་སོ། །དེ་ནས་དབྱར་འདས་ནས་ཚུལ་ནས་བྱུང་སྟེ། བཅོམ་ལྡན་འདས་ཀྱི་ཞབས་ལ་ཕྱག་འཚལ་དུ་ཕྱིན་ཏོ། །དང་པོར་ཀུན་དགའ་བོ་དང་ཕྲད་པ་དང་སྨྲས་པ། མུ་གེ་ཆེན་པོ་བྱུང་བའི་དུས་ན་དགེ་སློང་གཞན་རྣམས་ནི་རྨྱ་སྟེ་ལྷགས་ན། ཁྱོད་ནི་ཤིན་ཏུ་ཚོ་སྟེ་བྱུང་ན་དེ་ཅིའི་རྒྱུ་ཞེས་སྨྲས་པ་དང་། བདག་ཅག་སོ་སོའི་ཡོན་ཏན་བརྗོད་པས་རྙེད་པ་མང་པོ་བྱུང་སྟེ་ལུས་རྟས་སོ་ཞེས་སྨྲས་སོ། །ཁྱེད་ལ་ཡོན་ཏན་ཡོད་དེ་བརྗོད་དམ་མེད་དེ་བརྗོད། བདག་ཅག་ལ་ཡོན་ཏན་མེད་པར་བརྗོད་དོ་ཞེས་སྨྲས་པ་དང་། ཟང་ཟིང་ཅུང་ཟད་ཙམ་གྱི་ཕྱིར་མིའི་ཆོས་ལས་བླ་མར་གྱུར་པ་མེད་པ་ལ་ཡོད་པ་གཞན་བཞིན་དུ་སྨྲ་བ་ཤིན་ཏུ་མི་རིགས་སོ་ཞེས་ཀུན་དགའ་བོ་ལ་སོགས་པ་རྣམས་ཀྱིས་སྨྲས་སོ། །དེ་ལྟར་གྱུར་པ་བཅོམ་ལྡན་འདས་ཀྱིས་གསན་ཏོ། །དེ་ནས་བཅོམ་ལྡན་འདས་ཀྱིས༌[^355]རྣམ་པ་དུ་མས་སྨད་ནས་འདུལ་བ་ལ༌[^356]བསླབ་པའི་གནས་བཅས་སོ། །
