=== SYSTEM PROMPT ===
You are an expert in classical Tibetan Buddhist commentary (འགྲེལ་པ་) structure.

You are given a numbered list of blocks from a Tibetan verse commentary. A
rule-based segmenter has already cut them; most cuts are right. Your job is to
output the few merge/split operations that bring the blocks to the layout the
human editors of this vault use.

━━━ TARGET LAYOUT — one block per FUNCTIONAL UNIT ━━━

OPENER       A node's division announcement together with the first-child opener
             that follows it is ONE block:
               "<topic> ལ་གསུམ། A། B། C་འོ། །དང་པོ་ནི།"
             A sibling opener "གཉིས་པ་ <title> ནི།" is its own block.
ROOT QUOTE   A quoted root stanza is its own block. These blocks are tagged
             [VERSE]; they are protected — never include them in any operation.
EXPLANATION  The gloss that follows a quote ("ཞེས་པ་སྟེ། …", "ཞེས་པ་ནི། …", or a
             running explanation) is ONE block up to the next opener, quote or
             heading — even when it is long (100–250 syllables) and contains several
             sentence ends, a question and answer ("…ལོ། །གང་ལ་ན། …"), a side remark
             on a variant reading ("…ཞེས་འགྱུར་བཅོས་…"), a cross-reference
             ("འདི་དང་འོག་གི་ས་བཅད་…"), or a mantra cited in passing.
SECOND LEVEL A passage that re-reads the same stanza on another level — opening
             "སྦས་དོན་ནི།", "ངེས་དོན་ནི།", "ངེས་པའི་དོན་དུ།", "ཟབ་དོན་ནི།",
             "དེའི་ནང་གི་དོན་ལ།", "མཐར་ཐུག་གི་དོན་ནི།" or the like after the literal
             gloss — is its OWN block, never merged into the literal gloss before it
             (the editors keep the two readings apart). Within that passage, M1 applies.
FRAME        The namo line alone; each of the author's own verses one block;
             "སྨྲས་པ།" alone; the colophon ("ཅེས་ … སྦྱར་བའོ། །" + closing wishes) one block.

━━━ MERGE — adjacent blocks that are one unit ━━━

M1  CONTINUED EXPLANATION
    A block that goes on explaining the same quote/topic as the block before it —
    no new opener, no new quote, no new verse being treated — belongs to that block.
    This is the most common fix. Do NOT keep a cut just because a sentence ends.
    Exception: a SECOND LEVEL opener (see above) always starts a new block.
M2  INCOMPLETE SENTENCE
    A block ending in a connector (དང་། / ཞིང་། / ཅིང་། / ནས། / སྟེ། / ཏེ།) that
    the next block completes.
M3  OPENER CHAIN
    An enumeration block followed by "དང་པོ་ནི།" / "དང་པོ་ལ་ N།" (and further
    nested first-child enumerations) — merge them into one opener block.
M4  COLOPHON
    The parts of the closing colophon and its final wishes form one block.

━━━ SPLIT — one block that holds two units ━━━

S1  A new node opener (ordinal + title + "ནི།" or "ལ་ N།") buried mid-block:
    split before it.
S2  The treatment of a new verse/topic starts mid-block (e.g. "ཡང་ཕྱག་གང་ལ་འཚལ་ན"
    starting the next homage): split before it.
S3  An introductory opener "… ནི།" fused to the explanation of the PREVIOUS
    quote: split so the opener starts the next unit.

Never split a block only because it is long.

━━━ TOPIC SHIFT vs CONTINUATION (from the editors' corrections) ━━━

The editors' blocks are large (median ≈ 55 syllables; whole explanations of
100–250 syllables are normal). A sentence end is NOT a boundary. Inside one
explanation they cut only where the commentary turns to something new:
  START a new block at   "ཡང་ན་ …" (an alternative explanation)
                         "ཁ་ཅིག་ …", "གཞན་དག་ …" (another party's view)
                         "འོ་ན་ …" (the reply to an objection)
                         "དེ་སྐད་དུ་ …", "ཇི་སྐད་དུ་ …" (introducing a supporting quotation)
                         "དེ་ནས་ …" when it opens the next step of a procedure
                         "དཔེ་ …" / "དཔེར་ན་ …" when an example section begins
KEEP WITH the block before (merge into it):
                         "ད་ནི་ …" — a transitional "now …" line is not a new unit
                         (no heading or verse between them)
                         "ལེའུ་ … པའོ། །" — a chapter-closing line stays with the
                         explanation it closes
                         "ཞེས་ / ཅེས་ …" — the quotative closing the words just before it

━━━ HEADING / VERSE BLOCKS — always KEEP ━━━

Blocks tagged [HEADING] or [VERSE] are NEVER part of any operation.

━━━ OUTPUT FORMAT ━━━

A JSON array of operations. Blocks not mentioned are kept as-is.

[
  {"op": "merge", "blocks": [N, M]},
  {"op": "merge", "blocks": [N, M, P]},
  {"op": "split", "block": N, "after": "<verbatim unique substring ending at split point>"},
  {"op": "split", "block": N, "after": ["<sub1>", "<sub2>", "<sub3>"]}
]

Rules for the output:
- Block numbers are CONTINUOUS and INCLUDE heading and verse blocks. You may only
  merge blocks with consecutive numbers (N and N+1). Never merge across a heading
  or a verse block, and never propose a merge whose numbers skip over one.
- Each block number appears in AT MOST ONE operation.
- For each "after" substring: copy a verbatim slice from the block that ends exactly
  at the split point and is UNIQUE within that block (10–20 characters is usually enough).
- If nothing needs to change in this window, output: []
- Output ONLY the JSON array. No explanation, no commentary, no code fences.

འོ་ན་དེ་ལྟ་ན་མིག་ཉིད་མེད་དོ་ཞེས་སྨྲས་པར་འགྱུར་བས། དེ་ལྟར་སྨྲ་བར་བྱ་སྟེ། མིག་མེད་དོ་ཞེས་དེ་ཉིད་གསལ་པོར་སྨྲ་བར་བྱོས་ཤིག །སྨྲས་པ། ཁོ་བོ་ནི་མིག་ཉིད་མེད་དོ་ཞེས་མི་སྨྲ་སྟེ། ཅིའི་ཕྱིར་མིག་མེད་པར་འཇིག་རྟེན་པ་སྨྲའམ། བསྟན་བཅོས་ལས་བཤད། དེ་ལ་རེ༌[^187]ཞིག་འཇིག་རྟེན་པ་ལ་མིག་མེད་དོ་ཞེས་སྨྲ་བ་མེད་དེ། བདག་ཏུ་བརྟེན་པ༌[^188]ལ་ཉེ་བར་བརྟེན་པ་ཉིད་ཀྱི་མིག་ཡོད་བཞིན་པའི་ཕྱིར་ཏེ། མིང་དང་གཟུགས་ཀྱི་རྐྱེན་གྱིས་སྐྱེ་མཆེད་དྲུག་གོ་ཞེས་པས་མིང་དང་གཟུགས་ལ་བརྟེན་ནས་བྱུང་བའི་ཕྱིར། དེས་ན་གཟུགས་མཐོང་བ་དང་རེག་པའི་རྒྱུ་ཡིན་པའི་ཕྱིར་རོ། །

[Block 226]
གང་གི་ཚེ་འདི་ལྟར་འཇིག་རྟེན་པ་ལ་མིག་མེད་དོ་ཞེས་མེད་ན་དེའི་ཚེ་ཁོ་བོ་འཇིག་རྟེན་པ་མིག་མེད་པར་ཁས་ལེན་ནོ་ཞེས་ཇི་ལྟར་སྨྲ། དེའི་ཕྱིར་རེ་ཞིག་འཇིག་རྟེན་པ་མིག་མེད་དོ་ཞེས་མི་སྨྲའོ། །

[Block 227]
ད་ནི་བསྟན་བཅོས་ལས་ཀྱང་མིག་མེད་དོ་ཞེས་བསྟན་པ་བསྟན་བཅོས་ཞེས་བྱ་བ་ཕྱིན་ཅི་མ་ལོག་པའི་ལམ་དེས་ཉོན་མོངས་པ་འཇིག་པར་བྱེད་པས་སོ། །

[Block 228]
འགོག་པ་ནི༌[^189]འཇིག་རྟེན༌[^190]པ་སྟེ། འདི་ལྟར་འཇིག་རྟེན་ན་གསོད་པ་ན་ཆད་པ་ཆེན་པོས་འཇིག་པར་བྱེད་དོ་ཞེས་ཟེར་ལ། ཕྱིན་ཅི༌[^191]ལོག་པའི་ལམ་ཡང་ཕྱིན་ཅི་ལོག་ཉེ་བར་བསྟན་པ་ལས་ཉེ་བར་ཐོབ་པ་ཡོད་པ་མི་སྲིད་ཅེས་བྱ་སྟེ། མི་དམིགས་པའི་ཕྱིར་དེའི་ཚེ་འཇིག་རྟེན་པའི་མིག་མེད་དོ་ཞེས་མེད་པ་ཉིད་དོ། །

[Block 229]

[Block 230]
ཁོང་དུ་ཆུད་པ་མེད་པས་མེད་པ་ཉིད་ཉེ་བར་སྟོན་པར་མི་འགྱུར་ཞེས་བྱ་སྟེ། དེ་ལྟར་བསྟན་བཅོས་ལས་ཀྱང་མིག་མེད་དོ་ཞེས་ཁོ་བོ་མི་སྨྲའོ། །

[Block 231]
འདི་ལྟར་ཀུན་རྫོབ་དང་དོན་དམ་པའི་བདེན་པ་གཉིས་སུ་རྣམ་པར་གཞག་པ་ལ་ཀུན་རྫོབ་ཏུ་མིག་རང་གི་མཚན་ཉིད་སྒྱུ་མ་དང་སྨིག་རྒྱུ་དང་དྲི་ཟའི་གྲོང་ཁྱེར་གྱི་རྣམ་པ་ཁས་བླངས་ཤིང་དེ༌[^193]དོན་དམ་པར་མེད་དོ་ཞེས་རྟོག་པ་དེ་རྣམས་ནི་དབུ་མའི་བསྟན་བཅོས་ཡང་དག་པར་རྟོགས་པར༌[^194]མི་བརྗོད་དོ། །

[Block 232]
མིག་ནི་རང་གི་མཚན་ཉིད་མ་གྲུབ་པ་ཉིད་རང་གི་མཚན་ཉིད་གྲུབ་པ་ལྟ་བུར་བྱིས་པ་རྣམས་ཀྱིས་རྟོགས་པས། དེའི་ཕྱིར་ཀུན་རྫོབ་ཏུ་མིག་གི་རང་གི་མཚན་ཉིད་མེད་དོ། །

[Block 233]
གང་ཞིག་ཁོ་ན་ཀུན་རྫོབ་ཏུ་ཡང་མེད་ལ་དེ་ཁོ་ན་ཉིད་ཀྱི་ཤེས་པ་ལ་ཡང་དེ་ཉིད་མེད་པའི་ཕྱིན་ཅི་ལོག་ཏུ་བརྟགས་པ་མ་ཡིན་ཏེ། རྣལ་འབྱོར་པ་རྣམས་དེ་ཁོང་དུ་ཆུད་པ་ལ་མངོན་པར་འདོད་པ་མེད་པའི་ཕྱིར་རོ། །

[Block 234]
ཡང་ན་ཀུན་རྫོབ་ཏུ་མིག་ཡོད་ལ་དོན་དམ་པར་མེད་དོ་ཞེས་པའི་ཚིག་གི་རིགས་པ༌[^195]ཡང་གདོན་མི་ཟ་བར་ནུས་པར་རུང་ན་ཡང་། དེ་ལྟ་ན་ཡང་རང་གི་མཚན་ཉིད་ཁས་ལེན་པ་དང་སྤོང་བ་དག་ནུས་པ་དང་ལྡན་པ་མ་ཡིན་ནོ། །

[Block 235]
དེ་བཞིན་དུ་ཀུན་རྫོབ་ཏུ་ཕྱིན་ཅི་ལོག་མེད་ལ་དོན་དམ་པར་རང་བཞིན་མེད་པ་ནུས་པ་དང་ལྡན་ནོ་ཞེས་པ་ཡང་། དངོས་པོ་རྣམས་ཀྱི་རང་གི་མཚན་ཉིད་ཁས་བླངས་པ་དེ་ནི་སྒྱུ་མ་ལ་སོགས་པའི་དཔེ་རུང་བ་མ་ཡིན་ཏེ། རང་གི་མཚན་ཉིད་ཁས་བླངས་པ་ལ་སྒྱུ་མ་ལ་སོགས་པའི་དཔེ་དང་འབྲེལ་པ་མེད་པའི་ཕྱིར་དང་། སླུ་བ༌[^196]མེད་པར་ཁས་བླངས་པའི་ཕྱིར་རོ་ཞེས་བྱའོ། །

[Block 236]
གལ་ཏེ་དེ་ལྟར་མིག་སྟོང་པ་ཉིད་དུ་ཁྱོད་ལ་མ་གྲུབ་ན། ཇི་སྐད་སྨོས་པའི་རིགས་པས་མིག་བདག་དང་བདག་གི་བས་སྟོང་པར་བཤད་པས་མིག་རང་བཞིན་གྱིས་སྟོང་པར་ཅི་ཞིག་འགྲུབ་ཅི་ངེས་པར་མིག་གི༌[^197]རང་བཞིན་ཡོད་པ་གང་ཞིག་དང་བྲལ་བ་ལས་མིག་རང་བཞིན་གྱིས་སྟོང་པ་ནི་མ་ཡིན་ཏེ། གལ་ཏེ་ཡིན་ན་དེའི་ཚེ་དེ་ནི་རང་བཞིན་གྱིས་སྟོང་པ་ཉིད་མ་ཡིན་ནོ། །

[Block 237]
གལ་ཏེ་འདི་ལྟར་རང་བཞིན་མེད་པ༌[^198]དེ་ནི་སེལ་བ་མི་རུང་ལ། གང་ཞིག་གང་ན་མེད་པ་དེ་ནི་སེལ་བར་མི་རུང་ཞིང་གང༌[^199]ན་མེད་པ་དེར༌[^200]ནི་སེལ་བར་མི་བྱེད་དེ། འདི་ལྟ་སྟེ་ཆུའི་དྲོ་བའོ། །

[Block 238]
རང་བཞིན་དུ་སྐྱེས་པ་སེལ་བར་བྱེད་ན་སྐྱོན་འདིར་འགྱུར་གྱི། འོན་ཀྱང་མིག་རང་བཞིན་མེད་པར་གནས་པ་ཉིད་ལ་འཇིག་རྟེན་པ་ཕྱིན་ཅི་ལོག་ཏུ་རྨོངས་པའི་རྣམ་པར་ཤེས་པ་ལ་མིག་རང་བཞིན་མེད་པར་གནས་ཀྱང་ལོགས་སུ་བཞག་ནས་རང་བཞིན་དང་བཅས་པར་རྟོགས་ལ། དེ་ལ་མངོན་པར་ཞེན་པས་འདི་དག་ཁོ་ན་བདེན་པར་ཡོད༌[^201]གཞན་ནི་རྨོངས་པའོ་ཞེས་འདི་དག༌[^202]བདེན་པར་མངོན་པར་ཞེན་པས་མཆོག་ཏུ་འཛིན་པ་ལུས་ཀྱི་མདུད་པ་སྐྱེད་པས་འཁོར་བར་འཁོར་རོ། །

[Block 239]
འདི་དག་བདེན་པར་མངོན་པར་ཞེན་པ་མཆོག་ཏུ་འཛིན་པ་ལུས་ཀྱི་མདུད་པ་དེའི་གཉེན་པོར་ཁོ་བོས་མིག་རང་བཞིན་མེད་པར་རྣམ་པར་གནས་པ་ཉིད་མིག་རང་བཞིན་མེད་པའོ་ཞེས་པའི་ཚིག་གིས་ཤེས་པར་བྱེད་ཀྱི། ཁོ་བོས་རང་བཞིན་སེལ་བར་བྱེད་པ་ནི་མ་ཡིན་ནོ་ཞེས་བྱ་སྟེ། ཇི་སྐད་སྨོས་པའི་སྐྱོན་དུ་ཐལ་བར་མི་འགྱུར་རོ། །

[Block 240]
གལ་ཏེ་དེ་ལྟར་མིག༌[^203]རང་བཞིན་སྟོང་པར་བསྒྲུབས་ན། དེ་ལྟ་ན་མིག་དེ་ནི་རང་བཞིན་གང་ཞིག་གིས་སྟོང་པར་རྣམ་པར་གཞག་པར་ཡོད་པ་སྟེ། འདི་ལྟར་ཁང་པ་ལྷ་སྦྱིན་གྱིས་སྟོང་ངོ་ཞེས་བརྗོད་པ་ན། ལྷ༌[^204]སྦྱིན་མེད་པ་ཉིད་ལ་ཁྱིམ་ཡོད་པ་ཉིད་དུ་རྟོགས་པས་གང་དུ་གཉི་ག་ཡང་སྟོང་པར་མི་འདོད་ན། དེ་ནི་སྟོང་པ་ཉིད་དུ་མི་རུང་ངོ་ཞེས་འདིར་རྣམ་པར་རིག་པར་སྨྲ་བས་སྨྲས་པ། གཞན་དབང་ནི་ཡོད་པ་ཀུན་བརྟགས་ནི་མེད་པའི་ཕྱིར་ཁོ་བོ་ཅག་ཁོ་ན་ལ་སྟོང་པ་འཐད་ཀྱི་གང་ཞིག་སྟོང་པ་ཉིད་གང་ཞིག་གིས་སྟོང་པར་ཁས་མི་ལེན་པའི་ཕྱིར་དབུ་མ་པ་རྣམས་ལ་ནི་མ་ཡིན་ཏེ། སྟོང་པ་དེས་ཅི་ཞིག་བྱ་སྟེ་དེས་སྟོང་པ་དང་དེ་ཉིད་ཀྱིས༌[^205]སྟོང་པར་མི་རུང་ངོ་ཞེས་བྱའོ། །

[Block 241]
འདིར་གཞན་དབང་གི་རང་བཞིན་རྟེན་ཅིང་འབྲེལ་པར་འབྱུང་བ་བརྗོད་དུ་མེད༌[^206]པ་དངོས་པོ་ཙམ་ལ་དེ་ནི་རྣམ་པ་གཉིས་ཏེ་རྣམ་པར་དག་པ་དང་མ་དག་པའོ། །

[Block 242]
དེ་ལ་ཡོངས་སུ་མ་དག་པ་ནི་འཁོར་བ་ཐོག་མ་མེད་པ་ནས་གོམས་པ་པའི༌[^207]གཟུང་བ་དང་འཛིན་པར་ཡོངས་སུ་བརྟགས་པའི་དྲི་མས་བསྒོས་པའོ། །

[Block 243]
ཡོངས་སུ་དག་པ་ནི་གཟུང་བ་དང་འཛིན་པ་སྤྲོས་པའི་བག་ཆགས་ཀྱི་གནས་ངན་ལེན་སྤངས་ནས། གནས་ཡོངས་སུ་གྱུར་པ་ཡོངས་སུ་གྱུར་པ༌[^208]དག་པའི་རང་བཞིན་སངས་རྒྱས་རྣམས་ཀྱི་སོ་སོ་རང་གིས་རིག་པར་བྱ་བ། དེ་ཡང་གཞན་དབང་གི་རང་བཞིན་འདི་ནི་རང་ཉིད་ཁོ་ན་མི་འབྱུང་བ་དང་རང་བཞིན་ལ་གཞན་གྱི་རྐྱེན་གྱི་སྟོབས་ཀྱིས་སྐྱེ་བས་ན་གཞན་དབང་ངོ་། །དེ་ཡང་རང་བཞིན་ནི་དངོས་པོའི་ངོ་བོའི་ཕྱིར་དང་། གཞན་གྱི་རྐྱེན་ལས་མཐོང་བའི་ཕྱིར་གཞན་དབང་དུ་བརྗོད་ལ། གཞན་གྱི་རང་བཞིན་ལ༌[^209]ཐ་དད་པའི་ཕྱིར་དབང་གི་སྒྲ་ནི་གཙོ་བོ་ལ་འཇུག་སྟེ། འདི་ལྟར་འཇིག་རྟེན་ན༌[^210]འདིར་ནི་བདག་རང་དབང་བའོ་ཞེས་སྨྲ་བ་ན༌[^211]རང་ཉིད་གཙོ་བོར་སྨྲ་བའོ་ཞེས་བྱ་ལ། འདི་ནི་གཞན་གྱི་དབང་ལས་ཤེས༌[^212]པས་གཞན་དབང་སྟེ། གཞན་ལས་སྐྱེ་བའོ། །

[Block 244]
ཡང་ན་བརྒྱུད་ཅིང་སྐྱེད་པས༌[^213]དབང་ལ་གཞན་དབང་ནི་གཞན་གྱིས་བསྐྱེད་པའོ་ཞེས་པའི་དོན་ཏོ། །

[Block 245]
གཞན་དབང་དེ་ནི་ཀུན་རྫོབ་ཀྱི་དངོས་པོ་རང་ཡོད་པའི་ཕྱིར་དང་བརྟགས་པའི་གཟུང་བ་དང་འཛིན་པ་མེད་པའི་ཕྱིར་སྟོང་པ་ཉིད་ཁ་ན༌[^214]མ་ཐོ་བ་མེད་པར་འགྱུར་རོ། །

[Block 246]
ཇི་སྐད་དུ་མདོ་ལས་གསུངས་པ་གང་ཞིག་གང་ན་མེད་པ་དེ་ནི༌[^215]སྟོང་ལ་གང་ཡང་འདིར་ལྷག་མ་དེ་ནི་ཡོད་པ་ལ་འདིར་ཡོད་དོ་ཞེས་ཡང་དག་པ༌[^216]ཇི་ལྟ་བ་བཞིན་རབ་ཏུ༌[^217]ཤེས་སོ་ཞེས་འདི་སྐད་སྨྲ་ན་སྟོང་པ་ཉིད་ལ་ཕྱིན་ཅི་མ་ལོག་པར་ཞུགས་པའོ། །

[Block 247]
གང་དུ་དགེ་སྦྱོང༌[^218]ངམ་བྲམ་ཟེ་དག་དེ་ཡང་གང་ཞིག་གིས་སྟོང་པ་མི་འདོད་ན་དེ་ནི་སྟོང་པ་ལས་ཕྱིན་ཅི་ལོག་ཏུ་ཞུགས་པའོ་ཞེས་སོ། །

[Block 248]
འོ་ན་གལ་ཏེ་གཞན་དབང་གི་རང་བཞིན་ནི་ངོ་བོ་ཉིད༌[^219]དུ་ཡོད་པའི་ཕྱིར་རྟེན་ཅིང་འབྲེལ་པར་འབྱུང་བར་མི་འགྱུར་རོ། །

[Block 249]
སུ་ཞིག་འདི་སྐད་སྨྲ། སྐྱེ་བ་ལས་སྔ་རོལ་དུ༌[^220]གཞན་དབང་གི་རང་བཞིན་ཡོད་དོ་ཞེས་སོ། །

[Block 250]
སྐྱེས་ནས་འདིའི་རང་བཞིན་ཡོད་དོ་ཞེས་བརྗོད་དོ། །
