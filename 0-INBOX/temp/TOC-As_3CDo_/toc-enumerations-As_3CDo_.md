གཉིས་པ་ནི་ངོ་བོ་ཉིད་རྣམ་པ་གསུམ་གྱིས་ངོ་བོ་ཉིད་ཀྱི་བྱེ་བྲག་ལས་ཏེ། མཚན་ཉིད་ཀྱི་བྱེ་བྲག་དང་། བྱ་བའི་བྱེ་བྲག་དང་། གནས་སྐབས་ཀྱི་བྱེ་བྲག་གིས་སོ། །

Enumeration Block 1:
མདོར་བསྡུ་ན་བརྒྱད་ལས་ཏེ། འདི་ལྟ་སྟེ་སྦྱིན་པ་ལས་བྱུང་བའི་བསོད་ནམས་བྱ་བའི་དངོས་པོ་དང་། ཚུལ་ཁྲིམས་ལས་བྱུང་བ་དང་། བསྒོམས་པ་ལས་བྱུང་བ་དང་། ཐོས་པ་ལས་བྱུང་བ་དང་། བསམས་པ་ལས་བྱུང་བ་དང་། དེ་ལས་གཞན་པ་བསྒོམས་པ་ལས་བྱུང་བ་དང་། སོ་སོར་རྟོགས་པ༌[^932]ལས་བྱུང་བ་དང་། སེམས་ཅན་ལ་ཕན་འདོགས་པའི་དངོས་པོ་ལས་སོ། །
Enumeration Block 2:
རྣམ་པ་བཅོ་ལྔ་སྟེ། འདི་ལྟ་སྟེ། རྣམ་པར་སུན་འབྱིན་པ་གཉེན་པོ་དང་། སྤོང་བ་གཉེན་པོ་དང་། ཀུན་ཏུ་འཛིན་པ་གཉེན་པོ་དང་། ཐག་བསྲིངས་པ་གཉེན་པོ་དང་། འདོད་ཅིང་ཁས་བླངས་པའི་ཀུན་ནས་དཀྲིས་པའི་གཉེན་པོ་དང་། འདོད་ཅིང་ཁས་བླངས་པ་མེད་པའི་ཀུན་ནས་དཀྲིས་པའི་གཉེན་པོ་དང་། བག་ལ་ཉལ་གྱི་གཉེན་པོ་དང་། ཉོན་མོངས་པ་ཆུང་ངུའི་གཉེན་པོ་དང་། ཉོན་མོངས་པ་འབྲིང་གི་གཉེན་པོ་དང་། ཉོན་མོངས་པ་ཆེན་པོའི་གཉེན་པོ་དང་། རྣམ་པར་གཡེང་བའི་གཉེན་པོ་དང་། གཞན་འདེབས༌[^943]པའི་གཉེན་པོ་དང་། རྩེ་འཇིལ་བའི་གཉེན་པོ་དང་། རྣམ་པར་གནོན་པའི་གཉེན་པོ་དང་། བྲལ་བའི༌[^944]གཉེན་པོ་ལས་སོ། །
Enumeration Block 3:
དེ་ལ་ཉོན་མོངས་པ་ཅན་གྱི་ཆོས་རྣམས་ནི་གནས་གཉིས་ཀྱིས་རབ་ཏུ་ཕྱེ་བ་ཡིན་ཏེ། ཉོན་མོངས་པ་རྣམས་དང་། ཉེ་བའི་ཉོན་མོངས་པ་རྣམས་ཀྱིས་སོ། །
Enumeration Block 4:
དྲུག་སྟེ། མ་རིག་པ་དང་བཅས་ཤིང་ཡིད་དུ༌[^945]འོང་ལ་ཀུན་ནས་ཉོན་མོངས་པ་ཅན་གྱི་ཡུལ་དང་། མ་རིག་པ་དང་བཅས་ཤིང་ཡིད་དུ་མི་འོང་བ༌[^946]ལ་ཀུན་ནས་ཉོན་མོངས་པ་ཅན་གྱི་ཡུལ་དང་། ཚུལ་བཞིན་མ་ཡིན་པའི་ཡིད་ལ་བྱེད་པ་དང་བཅས་ཤིང་ཀུན་ནས་ཉོན་མོངས་པ་ཅན་གྱི་ཡུལ་དང་། མ་རིག་པ་དང་བཅས་ཤིང་རང་གི་ཉེ་བར་ལེན་པའི་ཕུང་པོ་ལྔ་པོ༌[^947]རྣམས་དང་། སེམས་ཅན་དམན་པ་དང་། མཚུངས་པ་དང་ཁྱད་པར་དུ་འཕགས་པ་རྣམས་དང་ཐོབ་པར་བྱ་བ་མ་ཐོབ་པ་ལ་ཕྱིན་ཅི་ལོག་དང་། ཡོན་ཏན་ལ་ཕྱིན་ཅི་ལོག་དང་། མ་རིག་པ་དང་ཚུལ་བཞིན་མ་ཡིན་པ་ཡིད་ལ་བྱེད་པ་དང་བཅས་ཤིང་དམ་པ་མ་ཡིན་པའི་ཆོས་ཉན་པ་དང་། མ་རིག་པ་དང་ཚུལ་བཞིན་མ་ཡིན་པ་ཡིད་ལ་བྱེད་པ་དང་བཅས་ཤིང་དམ་པ་མ་ཡིན་པའི་ཆོས་ཉན་པ་དང་ལེ་ལོའོ། །
Enumeration Block 5:
དེ་ཡང་རྣམ་པ་དྲུག་སྟེ། འདོད་ཆགས་དང་། ཁོང་ཁྲོ་བ་དང་། མ་རིག་པ་དང་། ང་རྒྱལ་དང་། ལྟ་བ་དང་། ཐེ་ཚོམ་མོ། །
Enumeration Block 6:
ཡང་ཉོན་མོངས་པ་རྣམས་ཀྱི་ཆེན་པོ་ཉིད་ནི་རྣམ་པ་དྲུག་གིས་རིག་པར་བྱ་སྟེ།
Enumeration Block 7:
འདོད་ཆགས་ཀྱི་གཞི་ནི་བཅུ་སྟེ། འདི་ལྟ་སྟེ། ཉེ་བར་ལེན་པའི་ཕུང་པོ་རྣམས་དང་། ལྟ་བ་རྣམས་དང་། མ་ཐོབ་པའི་ཡུལ་དང་། ཐོབ་པའི་ཡུལ་དང་། སྤྱད་ནས་འདས་པའི་ཡུལ་དང་། ཉེས་པར་སྤྱད་པ་དང་། བུ་དང་འདྲིས་པ་དང་། ཡོ་བྱད་དང་། ཡང་འབྱུང་བ་དང་། འཇིག་པ་རྣམས་སོ། །
Enumeration Block 8:
ཁོང་ཁྲོ་བའི་གཞི༌[^956]ཡང་བཅུ་སྟེ། བདག་ཉིད་དང་སེམས་ཅན་སྡུག་པ་རྣམས་དང་། སེམས་ཅན་མི་སྡུག་པ་རྣམས་དང་། འདས་པ་ན་གནོད་པ་དང་། ཕན་པ་བྱས་པ་དང་། མ་འོངས་པ་ན་གནོད་པ་དང་། ཕན་པ་བྱེད་པར་འགྱུར་བ་དང་། ད་ལྟར་བྱུང་བ་ན་གནོད་པ་དང་། ཕན་པ་བྱེད་པ་དང་། ཡུལ་ཡིད་དུ་མི་འོང་བ་དང་། ཕྲག་དོག་དང་། སྔོན་གོམས་པ་དང་། གཞན་དུ་བལྟ་བ་སྟེ།
Enumeration Block 9:
མ་རིག་པ་སྐྱེ་བའི་གཞི་ནི་བདུན་ཏེ། འདི་ལྟ་སྟེ། དུས་ཀྱི་གཞི་དང་། འཇིག་རྟེན་གནས་པའི་གཞི་དང་། འཕོ་བའི་གཞི་དང་། མཆོག་གི་གཞི་དང་། དེ་ཁོ་ནའི་གཞི་དང་། ཀུན་ནས་ཉོན་མོངས་པའི་གཞི༌[^959]དང་རྣམ་པར་བྱང་བའི་གཞི་དང་། མངོན་པའི་ང་རྒྱལ་གྱི་གཞིའོ། །
Enumeration Block 10:
ང་རྒྱལ་སྐྱེ་བའི་གཞི་ནི་དྲུག་སྟེ། སེམས་ཅན་དམན་པ་རྣམས་དང་། སེམས་ཅན་མཚུངས་པ་རྣམས་དང་། སེམས་ཅན་ཁྱད་པར་དུ་འཕགས་པ་རྣམས་དང་། སོ་སོ་ནང་གི་ཉེ་བར་ལེན་པའི་ཕུང་པོ་རྣམས་དང་། ཐོབ་པར་བྱ་བ་མ་ཐོབ་པ་ལ་ཕྱིན་ཅི་ལོག་དང་། ཡོན་ཏན་ལ་ཕྱིན་ཅི་ལོག་པ་སྟེ།
Enumeration Block 11:
ལྟ་བ་རྣམས་སྐྱེ་བའི་གཞི་ནི་གཉིས་ཏེ། སྒྲོ་འདོགས་པའི་གཞི་དང་། སྐུར་པ་འདེབས་པའི་གཞིའོ། །
དེ་ལ་སྒྲོ་འདོགས་པའི་གཞི་ནི་རྣམ་པ་བཞི་སྟེ། བདག་ཡོད་པར་སྒྲོ་འདོགས་པ་དང་། རྟག་པ་དང་། མི་རྟག་པ་ཉིད་དུ་སྒྲོ་འདོགས་པ་དང་། མངོན་པར་མཐོ་བའི་ཐབས་སུ་སྒྲོ་འདོགས་པ་དང་། ཐར་པའི་ཐབས་སུ་སྒྲོ་འདོགས་པའོ། །

Enumeration Block 4:

བྱ་བ་མ་ཡིན་པ༌[^2497]རང་གི་བྱ་བར་བྱེད་པ་དང་། བྱ་བ་རང་གི་བྱ་བར་བྱེད་པ་དང་། གཞན་གྱི་བྱ་བ་རང་གི་བྱ་བར་བྱེད་པའོ། །
Enumeration Block 5:
གསུམ་པོ་འདི་དག་ནི་རྒྱལ་པོའི་ཕུན་སུམ་ཚོགས་པ་ཡིན་ཏེ། རྣམ་པར་སྨིན་པ་ཕུན་སུམ་ཚོགས་པ་དང་། སྐྱེས་བུའི་རྩལ་ཕུན་སུམ་ཚོགས་པ་དང་། བསོད་ནམས་ཕུན་སུམ་ཚོགས་པའོ། །
Enumeration Block 6:
རྒྱལ་པོའི་ཚལ་ཟ་ནི་གསུམ་སྟེ་གུས་པ་དང་ལྡན་ལ་ནུས་པ་དང་མི་ལྡན་ཤེས་རབ་དང་མི་ལྡན་པ་དང་། གུས་པ་དང་ཡང་ལྡན་ནུས་པ་དང་ཡང་ལྡན་ལ༌[^2504]ཤེས་རབ་དང་མི་ལྡན་པ་དང་གུས་པ་དང་ཡང་ལྡན་ནུས་པ་དང་ཡང་ལྡན་ཤེས་རབ་དང་ཡང་ལྡན་པའོ། །
Enumeration Block 7:

Enumeration Block 1:

Enumeration Block 2:
གང་ཟག་གསུམ་པའི་ཉེ་བའི་ཉོན་མོངས་པ་ནི་ལོག་པར་སྒྲུབ་པ་ལས་བྱུང་བ་ཡིན་པར་བལྟ་བར་བྱ་སྟེ། དེ་ཡང་མདོར་བསྡུ་ན་རྣམ་པ་གསུམ་སྟེ། རབ་ཏུ་དབེན་པ་དང་ལྡན་པ་དང་། འདུ་འཛི་དང་ལྡན་པ་དང་། བསླབ༌[^2583]དང་ལྡན་པའོ། །
Enumeration Block 3:
རྣལ་འབྱོར་པ་ཟད་པར་གྱི་སྐྱེ་མཆེད་བཅུ༌[^2589]བསྒོམ་པ་ནི་བྱ་བ་ལྔ་བྱེད་པ་ཡིན་ཏེ། ལྔ་གང་ཞེ་ན།
Enumeration Block 4:

Enumeration Block 5:
ཡོངས་སུ་ཉམས་པ་ནི་གསུམ་པོ་འདི་དག་ཡིན་ཏེ་མ་ཐོབ་པའི་ཆོས་ལས་ཡོངས་སུ་ཉམས་པ་དང་། ཐོབ་པའི་ཆོས་ལས༌[^2614]ཡོངས་སུ་ཉམས་པ་དང་། ཀུན་དུ་བསྟེན༌[^2615]པས་ཡོངས་སུ་ཉམས་པའོ། །
Enumeration Block 6:
བསམ་གཏན་པ་ནི་བཞི་པོ་འདི་དག་ཡིན་ཏེ། ཉེར་བསྡོགས་ཀྱི་བསམ་གཏན་པ་དང་། ཉོན་མོངས་པ་ཅན་གྱི་ཏིང་ངེ་འཛིན་གྱི་བསམ་གཏན་པ་དང་། དག་པ་འཇིག་རྟེན་པའི་བསམ་གཏན་གྱི་བསམ་གཏན་པ་དང་། འཇིག་རྟེན་ལས་འདས་པའི་བསམ་གཏན་གྱི་བསམ་གཏན་པའོ། །
Enumeration Block 7:
དགེ་སློང་སེམས་རྣམ་པར་དག་པར་བྱ་བའི་ཕྱིར་ཞུགས་པའི་ཉེ་བའི་ཉོན་མོངས་པ་ནི་བཞི༌[^2637]སྟེ། ལྟུང་བ་དང་། རྣམ་པར་རྟོག་པ་དང་། ལུས་ལ་མངོན་པར་ཞེན་པ་དང་། ཡུལ་ལ་མངོན་པར་ཞེན་པའོ། །

Enumeration Block 1:
དགེ་སློང་སེམས་རྣམ་པར་དག་པར་བྱ་བའི་ཕྱིར་ཞུགས་པའི་ཉེ་བའི་ཉོན་མོངས་པ་ནི་བཞི༌[^2637]སྟེ། ལྟུང་བ་དང་། རྣམ་པར་རྟོག་པ་དང་། ལུས་ལ་མངོན་པར་ཞེན་པ་དང་། ཡུལ་ལ་མངོན་པར་ཞེན་པའོ། །

རྒྱུ་གསུམ་གྱིས་ན་འདི་ལས་ཕྱི་རོལ་པའི་དགེ་སྦྱོང་དང་བྲམ་ཟེ་རྣམས་དང་ཐུན་མོང་མ་ཡིན་པ་སྟེ། ཡོངས་སུ་སྦྱངས་པའི༌[^2648]ས་ལས༌[^2649]ཚོགས་ཡོངས་སུ་རྫོགས་པ་དང་། ཞི་གནས་ཀྱི་སྙིང་པོ་ལ་རོ་མྱོང༌[^2650]བར་མི་བྱེད་པ་དང་མྱ་ངན་ལས་འདས་པ་ལ་དགའ་ཞིང་ཆགས་པ་དང་ལྡན་པའི་སེམས་ལ་ཉོན་མོངས་པའི་མེ་འབྱུང་བའི་གནས་མེད་པས་སོ། །
Enumeration Block 3:
རྣམ་པར་གྲོལ་བ་ནི་གཉིས་ཏེ། ཤེས་རབ་རྣམ་པར་གྲོལ་བ་དང་། སེམས་རྣམ་པར་གྲོལ་བའོ། །
Enumeration Block 4:
དྲི་བ་འདྲི་བར༌[^2671]འདོད་པས་ནི་རྣམ་པ་བརྒྱད་ཀྱིས་དྲི་བར་བྱ་སྟེ། རྣམ་པ་བརྒྱད་གང་ཞེ་ན།
འདི་ལྟ་སྟེ། ཀུན་ཤེས་པའི་གཞི་དང་། ཀུན་ཤེས་པའི་མི་མཐུན་པའི་ཕྱོགས་དང་། ཀུན་ཤེས་པའི་འབྲས་བུ་དང་ཀུན་ཤེས་པའི་ངོ་བོ་ཉིད་དང་། ཀུན་ཤེས་པའི་འབྲས་བུའི་ཁྱད་པར་དང་། ཀུན་ཤེས་པའི་གནས་དང་། ཀུན་ཤེས་པའི་ཕན་ཡོན་དང་། ཀུན་ཤེས་པ་ཡང་དག་པར་འགྲུབ་པས་སོ། །
Enumeration Block 5:
དེ་ལ་ཀུན་ཤེས་པའི་གནས་ནི་ཏིང་ངེ་འཛིན་ཏེ་དེ༌[^2675]ཡང་རྣམ་པ་བཞིས་རིག་པར་བྱ་སྟེ།

Enumeration Block 1:
འདོད་ཆགས་དང་བྲལ་བ་ནི་རྣམ་པ་དྲུག་ཏུ་རིག་པར་བྱ་སྟེ། འདི་ལྟ་སྟེ། རང་བཞིན་གྱིས་འདོད་ཆགས་དང་བྲལ་བ་དང་། གནོད་པས་འདོད་ཆགས་དང་བྲལ་བ་དང་། སྟོན་པས་འདོད་ཆགས་དང་བྲལ་བ་དང་། ཡང་དག་ཕུལ་གྱིས་འདོད་ཆགས་དང་བྲལ་བ་དང་། ཀུན་དུ་རྨོངས་པས་འདོད་ཆགས་དང་བྲལ་བ་དང་། གཉེན་པོས་འདོད་ཆགས་དང་བྲལ་བའོ། །

Enumeration Block 2:
མདོར་བསྡུ་ན་རྣམ་པར་ཤེས་པ་ནི་རྣམ་པ་གཉིས་ཏེ། ཀུན་གཞི་རྣམ་པར་ཤེས་པ་དང་། འཇུག་པའི་རྣམ་པར་ཤེས་པའོ། །
Enumeration Block 3:

Enumeration Block 2:
བྲམ་ཟེའི་ཆོས་ལས་དགེ་སྦྱོང་གི་ཆོས་རྣམ་པ་ལྔས་ཁྱད་པར་དུ་འཕགས་ཏེ། ཆོས་རྣམ་པ་ལྔ་གང་ཞེ་ན། འདི་ལྟ་སྟེ། ཐོས་པའི་ཆོས་དང་། ཚུལ་ཁྲིམས་ཀྱི་ཆོས་དང་། ཡོངས་སུ་གཟུང་བའི༌[^2877]ཆོས་དང་། ལོངས་སྤྱོད་ཀྱི་ཆོས་དང་། རྟོགས་པའི་ཆོས་ཀྱིས་སོ། །

Enumeration Block 4:

Enumeration Block 5:
དེ་ནི་ཀུན་རྫོབ་རྣམ་པ་གསུམ་གྱིས་རྣམ་པར་འཇོག་པར་བྱེད་པའི་ཕྱིར་ཏེ། འཇིག་རྟེན་གྱི་ཀུན་རྫོབ་དང་། རིགས་པའི་ཀུན་རྫོབ་དང་། རྟོགས་པའི་ཀུན་རྫོབ་ཀྱིས་སོ། །

Enumeration Block 2:
འཐོབ་པ་ནི་མདོར་བསྡུ་ན་རྣམ་པ་བཞི་སྟེ། སེམས་ཅན་རྣམས་ཀྱི་ལས་ཀྱི་རྣམ་པར་སྨིན་པ་འཐོབ་པ་དང་། ཉན་ཐོས་ཀྱི་ཐེག་པ་འཐོབ་པ་དང་། རང་སངས་རྒྱས་ཀྱི་ཐེག་པ་འཐོབ་པ་དང་། ཐེག་པ་ཆེན་པོ་འཐོབ་པའོ། །
Enumeration Block 3:

Enumeration Block 4:

Enumeration Block 1:
དེ་ལ་སེམས་ཅན་རྣམས་ཀྱི་རྣམ་པར་སྨིན་པ་ལ་སེམས་པ་ནི་རྣམ་པ་བཞིས་བསམ་གྱིས་མི་ཁྱབ་པ་ཡིན་ཏེ། གནས་དང་དངོས་པོ་དང་། རྒྱུ་དང་རྣམ་པར་སྨིན་པ་ལས་སོ། །
དེ་ལ་བསམ་གཏན་པ་རྣམས་ཀྱི་བསམ་གཏན་པའི་ཡུལ་ནི་རྣམ་པ་གསུམ་གྱིས་བསམ་གྱིས་མི་ཁྱབ་པ་ཡིན་ཏེ། དེ་བཞིན་ཉིད་ཟད་པའི་དོན་དང་། དབང་བསྒྱུར་བ༌[^2959]དང་། ཟག་པ་ཟད་པའི་དབྱིངས་ཡང་དག་པར་འགྲུབ་པས་སོ། །
དེ་ལ་སངས་རྒྱས་རྣམས་ཀྱི་སངས་རྒྱས་ཀྱི་ནི་རྣམ་པ་ལྔས་བསམ་གྱིས་མི་ཁྱབ་པ་ཡིན་ཏེ། ཇི་སྐད་བསྟན་པ་གསུམ་པོ་དེ་དག་ཉིད་དང་། གཞན་གཉིས་ཀྱིས་ཏེ། སྒྲིབ་པ་མེད་པ་དང་། སེམས་ཅན་གྱི་དོན་གྱི་བྱ་བ་མཛད་པས་སོ། །
Enumeration Block 2:
དེ་ལ་དགོངས་པ་གང་ཞེ་ན།
མདོར་བསྡུ་ན་རྣམ་པ་བཅུ་དྲུག་སྟེ། ཡང་དག་པར་སྟོན་པའི་དགོངས་པ་དང་། འདུན་པ་བཟློག་པའི༌[^2960]དགོངས་པ་དང་། ཡང་དག་པར་འཛིན་དུ་འཇུག་པའི་དགོངས་པ་དང་། ཡང་དག་པར་གཟེངས་བསྟོད་པའི་དགོངས་པ་དང་། ཡང་དག་པར་རབ་ཏུ་དགའ་བར་མཛད་པའི་དགོངས་པ་དང་། གཟུད་པའི་དགོངས་པ་དང་། ཐེ་ཚོམ་གཅད་པའི༌[^2961]དགོངས་པ་དང་། ཡོངས་སུ་སྨིན་པར་བྱ་བའི་དགོངས་པ་དང་། ཏིང་ངེ་འཛིན་དུ་བྱ་བའི་དགོངས་པ་དང་། རྣམ་པར་གྲོལ་བར་བྱ་བའི་དགོངས་པ་དང་། དོན་གཞན་དང་འབྲེལ་པའི་དགོངས་པ་དང་། རྟོགས་པར༌[^2962]བྱེད་པ་རྣམས་ལ་ཁ་ན་མ་ཐོ་བ་མེད་པའི་དགའ་བ་དང་མཆོག་ཏུ་དགའ་བ་སྐྱེད་པའི༌[^2963]དགོངས་པ་དང་། སྨྲ་བ་པོ་ལ་ཉན་པ་རྣམས་རི་མོ་ཆེར་བསྐྱེད་པར་བྱ་བའི་དགོངས་པ་དང་། ཆོས་ཀྱི་ཚུལ་འཇུག་པར་བྱ་བའི་དགོངས་པ་དང་། དགེ་བ་མང་བར་བྱ་བའི་དགོངས་པ་དང་། མཚན་མ་ཐམས་ཅད་ཟིལ་གྱིས་མནན་པའི་དགོངས་པའོ། །
Enumeration Block 3:
སྡུག་བསྔལ་གྱི་བདེན་པ་ནས་ལམ་གྱི་བདེན་པའི་བར་དུ་རྣམ་པར་གཞག་པ་ལ་ནི་མདོར་བསྡུ་ན་སྒྲོ་འདོགས་པ་རྣམ་པ་བཞིས་སྒྲོ་འདོགས་པའི་མཐའ་ཡིན་ཏེ། བདག་ཏུ་སྒྲོ་འདོགས་པ་དང་། རྟག་པར་སྒྲོ་འདོགས་པ་དང་། གཙང་བར༌[^2964]སྒྲོ་འདོགས་པ་དང་། བདེ་བར་སྒྲོ་འདོགས་པའོ། །
Enumeration Block 4:
སྡུག་བསྔལ་གྱི་བདེན་པ་དང་། ཀུན་འབྱུང་བའི་བདེན་པ་དེ་ཡང་མདོར་བསྡུ་ན་རྣམ་པ་གསུམ་སྟེ། འདོད་པ་དང་གཟུགས་དང་གཟུགས་མེད་པ་དང་ལྡན་པའི་བྱེ་བྲག་གིས་སོ། །
Enumeration Block 5:
བདེན་པ་དེ་དག་ལས་བརྩམས། བདེན་པ་དེ་དག་ལ༌[^2975]བརྟེན། བདེན་པ་དེ་དག་ལ༌[^2976]གནས་ནས། གང་ཟག་བཅུ་གསུམ་རྣམ་པར་གཞག་པར་རིག་པར་བྱ་སྟེ། གང་ཟག་བཅུ་གསུམ་གང་ཞེ་ན།

Enumeration Block 2:

Enumeration Block 3:
བསྟན་བཅོས་ཉེ་བར་སྦྱོར་བར་འདོད་པས་བདག་ཉིད་ཡོན་ཏན་བཞི་དང་སྦྱར་ནས་བསྟན་བཅོས་ཉེ་བར་སྦྱར་བར་བྱ་སྟེ། སྔོན་གྱི་སློབ་དཔོན་རྣམས་ལ་ང་རྒྱལ་མི་བྱེད་པ་དང་། སེམས་ཅན་རྣམས་ལ་སྙིང་རྗེ་ཆེ་བ་དང་། ཆོས་མཐུན་པ་པ་རྣམས་ལ་བྱམས་པ་དང་། བདག་ཉིད་མི་སྒྲོགས༌[^3031]པའོ། །
Enumeration Block 4:
རྟོགས་པ་ནི་རྣམ་པ་བདུན་ཏེ། ཡི་གེ༌[^3045]རྟོགས་པ་དང་། ཡི་གེའི་དོན་རྟོགས་པ་དང་། འཛིན་པ་རྟོགས་པ་དང་། འཛིན་པའི་དོན་རྟོགས་པ་དང་། འཆིང་བ་རྟོགས་པ་དང་། གྲོལ་བ་རྟོགས་པ་དང་། ཆོས་ཉིད་རྟོགས་པའོ། །
Enumeration Block 5:
