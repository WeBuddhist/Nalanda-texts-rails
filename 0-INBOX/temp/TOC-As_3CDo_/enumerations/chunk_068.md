Enumeration Block 1:
གང་ཟག་གསུམ་གྱི་ཉེ་བའི་ཉོན་མོངས་པ་ནི་གནས་གསུམ་ལས་བྱུང་བ་ཡིན་པར་རིག་པར་བྱ་སྟེ། གང་ཟག་གསུམ་གང་ཞེ་ན།
ཆོས་འདི་པ་རབ་ཏུ་བྱུང་བ་དང་། འདོད་པ་ལ་ལོངས་སྤྱོད་པ་ཁྱིམ་ན་གནས་པ་དང་། འདི་ལས་ཕྱི་རོལ་པ་རབ་ཏུ་བྱུང་བའོ། །
Enumeration Block 2:
གང་ཟག་གསུམ་པའི་ཉེ་བའི་ཉོན་མོངས་པ་ནི་ལོག་པར་སྒྲུབ་པ་ལས་བྱུང་བ་ཡིན་པར་བལྟ་བར་བྱ་སྟེ། དེ་ཡང་མདོར་བསྡུ་ན་རྣམ་པ་གསུམ་སྟེ། རབ་ཏུ་དབེན་པ་དང་ལྡན་པ་དང་། འདུ་འཛི་དང་ལྡན་པ་དང་། བསླབ༌[^2583]དང་ལྡན་པའོ། །
Enumeration Block 3:
རྣལ་འབྱོར་པ་ཟད་པར་གྱི་སྐྱེ་མཆེད་བཅུ༌[^2589]བསྒོམ་པ་ནི་བྱ་བ་ལྔ་བྱེད་པ་ཡིན་ཏེ། ལྔ་གང་ཞེ་ན།
Enumeration Block 4:
ཆོས་རྣམས་ཀྱི་སྤོང་བ་ནི༌[^2610]རྣམ་པ་གསུམ་སྟེ། གཉེན་པོས་སྤོང་པ༌[^2611]དང་། ཀུན་ཏུ་སྤྱོད་པས་སྤོང་བ་དང་། འདོར་བས་སྤོང་བའོ། །
Enumeration Block 5:
ཡོངས་སུ་ཉམས་པ་ནི་གསུམ་པོ་འདི་དག་ཡིན་ཏེ་མ་ཐོབ་པའི་ཆོས་ལས་ཡོངས་སུ་ཉམས་པ་དང་། ཐོབ་པའི་ཆོས་ལས༌[^2614]ཡོངས་སུ་ཉམས་པ་དང་། ཀུན་དུ་བསྟེན༌[^2615]པས་ཡོངས་སུ་ཉམས་པའོ། །
Enumeration Block 6:
བསམ་གཏན་པ་ནི་བཞི་པོ་འདི་དག་ཡིན་ཏེ། ཉེར་བསྡོགས་ཀྱི་བསམ་གཏན་པ་དང་། ཉོན་མོངས་པ་ཅན་གྱི་ཏིང་ངེ་འཛིན་གྱི་བསམ་གཏན་པ་དང་། དག་པ་འཇིག་རྟེན་པའི་བསམ་གཏན་གྱི་བསམ་གཏན་པ་དང་། འཇིག་རྟེན་ལས་འདས་པའི་བསམ་གཏན་གྱི་བསམ་གཏན་པའོ། །
Enumeration Block 7:
དགེ་སློང་སེམས་རྣམ་པར་དག་པར་བྱ་བའི་ཕྱིར་ཞུགས་པའི་ཉེ་བའི་ཉོན་མོངས་པ་ནི་བཞི༌[^2637]སྟེ། ལྟུང་བ་དང་། རྣམ་པར་རྟོག་པ་དང་། ལུས་ལ་མངོན་པར་ཞེན་པ་དང་། ཡུལ་ལ་མངོན་པར་ཞེན་པའོ། །
