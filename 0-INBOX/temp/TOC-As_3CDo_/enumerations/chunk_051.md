Enumeration Block 1:
དེ་ལ་གནས་ངན་ལེན་ནི་མདོར་བསྡུ་ན་རྣམ་པ་གཉིས་ཏེ། ཟག་པའི་གནས་ངན་ལེན་དང་ཟག་པ་དང་བཅས་པའི་གནས་ངན་ལེན་ཏོ། །
Enumeration Block 2:
རྣམ་པ་བརྒྱད་ཡོད་དེ་འདི་ལྟ་སྟེ། ཟློག་པར་བྱེད་པ་དང་། སད་པར་བྱེད་པ་དང་། ཀུན་ཏུ་སྦྱོར་བར༌[^1811]བྱེད་པ་དང་། མཚན་མར་འཛིན་པར་བྱེད་པ་དང་། ཆགས་པར་བྱེད་པ་དང་། རྣམ་པར་འདོད་པར་བྱེད་པ་དང་། ངེས་པར་གནོད་པར་བྱེད་པ་དང་། མཆོག་ཏུ་ཆགས་པར་བྱེད་པ་སྟེ།
Enumeration Block 3:
རྒྱུ་གཉིས་ཀྱི་ཕྱིར་ཏེ། སྲེད་པ་ནི་སྨོན་པ་དང་མི་སྨོན་པར་བྱེད་པ་ཉིད་ཡིན་པའི་ཕྱིར་དང་། ཁྱབ་པར་འཇུག་པ་ཉིད་ཀྱི་ཕྱིར་ཏེ
Enumeration Block 4:
དེའི་ཁྱབ་པར་འཇུག་པ་ཉིད་ཀྱང་རྣམ་པ་གསུམ་དུ་རིག་པར་བྱ་སྟེ།
Enumeration Block 5:
རྒྱུ་གསུམ་གྱིས་ཏེ
Enumeration Block 6:
རྣམ་གྲངས་གཞན་ཡང་ཤེས་བྱ་རབ་ཏུ་རྟོགས་པར༌[^1842]བྱ་བ་དང་སྤོང་བ་མངོན་དུ་བྱ་བ་ལ་གེགས་སུ་གྱུར་པའི་ཆོས་ནི་གཉིས་ཏེ། ལོག་པར་བསྒྲུབ་པའི་རྒྱུ་དང་སྡུག་བསྔལ་སྐྱེ་བའི་རྒྱུའོ། །
Enumeration Block 7:
ཆོས་དེ་གཉིས་ཀྱི་རྒྱུ་ཡང་རྣམ་པ་གཉིས་ཏེ།
Enumeration Block 8:
གཞན་ཡང་མངོན་པར་ཞེན་པ་ནི་གཉིས་ཡོད་དེ། དབང་པོ་དང་ཡུལ་ལ་མངོན་པར་ཞེན་པ་དང་། སེམས་ཅན་གཅིག་ལ་གཅིག་མངོན་པར་ཞེན་པའོ། །
