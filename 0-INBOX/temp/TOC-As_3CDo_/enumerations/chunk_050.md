Enumeration Block 1:
མཐོང་བ་དང་བསྒོམ་པས་སྤང་བར་བྱ་བའི་ཟག་པ་ཇི་སྐད་བསྟན་པ་དེ་དག་གི་དམིགས་པ་ནི་མདོར་བསྡུ་ན་རྣམ་པ་ལྔར་རིག་པར་བྱ་སྟེ། ལོག་པར་རྣམ་པར་བརྟགས་པའི་དངོས་པོ་ལ་དམིགས་པ་དང་། ལྟ་བ་ལ་དམིགས་པ་དང་། ཚུལ་ཁྲིམས་དང་བརྟུལ་ཞུགས་ལ་དམིགས་པ་དང་། རང་གིས༌[^1766]རྣམ་པར་བརྟགས་པའི་མིང་ལ་དམིགས་པ་དང་། རང་གི་ངང་གིས་ཡེ་ཡོད་པའི་དངོས་པོ་ལ་དམིགས་པའོ། །
Enumeration Block 2:
དེ་ནི་མདོར་བསྡུ་ན་རྣམ་པ་བཞིར་བལྟ་བར་བྱ་སྟེ། རྒྱུད་ཡོངས་སུ་སྨིན་པར་བྱེད་པའི་གཉེན་པོ་དང་། ཉེ་བར༌[^1770]སྤོང་བའི་གཉེན་པོ་དང་། ཕྱོགས་གཅིག་སྤོང་བའི་གཉེན་པོ་དང་། མཐའ་དག་སྤོང་བའི་གཉེན་པོའོ། །
Enumeration Block 3:
མཐོང་བའི་ལམ་གྱི་རྣམ་པར་གཞག་པ་ནི་རྣམ་པ་གཉིས་ཏེ། བསྟན་པ་གནས་པའི་རྒྱས་པ་རྣམ་པར་གཞག་པ་སྤྲོས་པ་དང་བཅས་པ་དང་། དོན་དམ་པ་རྣམ་པར་གཞག་པ་སོ་སོ་རང་གི༌[^1779]རིག་པ་སྤྲོས་པ་མེད་པའོ། །
Enumeration Block 4:
མཐོང་བས་སྤང་བར་བྱ་བའི་ཉོན་མོངས་པའི་བག་ལ་ཉལ་ནི་ཆ་གཉིས་ཀྱིས་རྣམ་པར་གཞག་པ་ཡིན་ཏེ། དང་བའི་གཟུགས་དང་རྗེས་སུ་འབྲེལ་པ་དང་སེམས་དང་སེམས་ལས་བྱུང་བ་དང་རྗེས་སུ་འབྲེལ་པ་ལས་སོ། །
Enumeration Block 5:
གནས་ངན་ལེན་ནི་མདོར་བསྡུ་ན་རྣམ་པ་གཉིས་ཏེ། ཟག་པའི་གནས་ངན་ལེན་དང་ཟག་པ་དང་བཅས་པའི་གནས་ངན་ལེན་ཏོ། །
