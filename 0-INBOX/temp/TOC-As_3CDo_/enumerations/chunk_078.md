Enumeration Block 1:
ཆོས་རྣམས་ཀྱི་རབ་ཏུ་དབྱེ་བའི་ཚུལ་ཡང་མདོར༌[^3027]བསྡུ་ན་རྣམ་པ་ལྔར་རིག་པར་བྱ་སྟེ། འདི་ལྟ་སྟེ་རྟགས་དང་། ངོ་བོ་ཉིད་དང་། ལས་དང་། ཆོས་དང་། རྒྱུ་དང་འབྲས་བུའོ། །
Enumeration Block 2:
བསྟན་བཅོས་ནི་གསུམ་སྟེ། ཐོས་པ་ལྷུར་ལེན་པའི་བསྟན་བཅོས་དང་། རྩོད་པ་ལྷུར་ལེན་པའི་བསྟན་བཅོས་དང་། སྒྲུབ་པ་ལྷུར་ལེན་པའི་བསྟན་བཅོས་སོ། །
Enumeration Block 3:
བསྟན་བཅོས་ཉེ་བར་སྦྱོར་བར་འདོད་པས་བདག་ཉིད་ཡོན་ཏན་བཞི་དང་སྦྱར་ནས་བསྟན་བཅོས་ཉེ་བར་སྦྱར་བར་བྱ་སྟེ། སྔོན་གྱི་སློབ་དཔོན་རྣམས་ལ་ང་རྒྱལ་མི་བྱེད་པ་དང་། སེམས་ཅན་རྣམས་ལ་སྙིང་རྗེ་ཆེ་བ་དང་། ཆོས་མཐུན་པ་པ་རྣམས་ལ་བྱམས་པ་དང་། བདག་ཉིད་མི་སྒྲོགས༌[^3031]པའོ། །
Enumeration Block 4:
རྟོགས་པ་ནི་རྣམ་པ་བདུན་ཏེ། ཡི་གེ༌[^3045]རྟོགས་པ་དང་། ཡི་གེའི་དོན་རྟོགས་པ་དང་། འཛིན་པ་རྟོགས་པ་དང་། འཛིན་པའི་དོན་རྟོགས་པ་དང་། འཆིང་བ་རྟོགས་པ་དང་། གྲོལ་བ་རྟོགས་པ་དང་། ཆོས་ཉིད་རྟོགས་པའོ། །
Enumeration Block 5:
བསམ་པ་ལས་བྱུང་བའི་སའི་རྣམ་པར་གཏན་ལ་དབབ་པ་ནི། བསམ་པ་ནི་མདོར་བསྡུ་ན་རྣམ་པ་བཞི་སྟེ། དངོས་པོ་བསམ་པ་དང་། ཡོད་པ་དང་མེད་པ་བསམ་པ་དང་། རྒྱུ་དང་འབྲས་བུ་བསམ་པ་དང་། ཐེག་པ་བསམ་པའོ། །
Enumeration Block 6:
ཡང་བསམ་པ་ནི་རྣམ་པ་གཉིས་ཏེ། ཉེས་པར༌[^3050]བསམ་པ་སེམས་པ་དང་། ལེགས་པར་བསམ་པ་སེམས་པའོ། །
