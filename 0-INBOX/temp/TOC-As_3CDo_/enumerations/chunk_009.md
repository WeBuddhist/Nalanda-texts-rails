Enumeration Block 1:
དགེ་བསྙེན་གྱི་སྡོམ་པ་ནི་ཡན་ལག་གསུམ་གྱིས་བསྡུས་པ་ཡིན་ཏེ། ཡན་ལག་གསུམ་གང་ཞེ་ན། གཞན་ལ་གནོད་པའི་དངོས་པོ་ཆེན་པོ༌[^474]སྤོང་བ་ཡང་དག་པར་བླང་བའི་ཡན་ལག་དང་། ཡང་དག་པར་བླངས་པ་ལས་ཉམས་པ་ཕྱིར་གསོ་བའི་ཡན་ལག་དང་། ཡང་དག་པར་བླངས་པ་ལས་མི་ཉམས་པའི་ཡན་ལག་གོ། །
Enumeration Block 2:
བསྙེན་གནས་པའི་སྡོམ་པ་ནི་མདོར་བསྡུ་ན་ཡན་ལག་ལྔས་བསྡུས་པ་ཡིན་ཏེ། ཡན་ལག་ལྔ་གང་ཞེ་ན། གཞན་ལ་གནོད་པ་སྤོང་བ་ཡང་དག་པར་ལེན་པའི་ཡན་ལག་དང་། བདག་དང་གཞན་ལ་གནོད་པ་སྤོང་བ་ཡང་དག་པར་ལེན་པའི་ཡན་ལག་དང་། ཡང་དག་པར་བླངས་པ་ལས་ཉམས་པ་ཕྱིར་གསོ་བའི་ཡན་ལག་དང་། ཡང་དག་པར་བླངས་པ་ལས་མི་ཉམས་པར་བྱ་བའི་ཕྱིར་དྲན་པ་ཉེ་བར་འཇོག་པའི་ཡན་ལག་དང་། དྲན་པ་རྨོངས་པར་མི་འགྱུར་བའི་ཡན་ལག་གོ། །
Enumeration Block 3:
མདོར་བསྡུ༌[^509]ན་རྒྱུ་དྲུག་གིས་ཏེ། བསམ་པ་ཉམས་པ་དང་། ལུས་ཉམས་པ་དང་། སྐྱེས་པ་ཉིད་ཉམས་པ་དང་། དགེ་བའི་ཆོས་ཉམས་པ་དང་། གཞན་གྱི་དབང་དུ་གྱུར་པ་དང་། གཞན་རྗེས་སུ་སྲུང་བས༌[^510]སོ། །
Enumeration Block 4:
མ་ནིང་ནི་མདོར་བསྡུ་ན་རྣམ་པ་གསུམ་དུ་རིག་པར་བྱ་སྟེ། ཡོངས༌[^523]མ་ནིང་དང་། ཕྱོགས་གཅིག་གི་མ་ནིང་དང་། ཉམས་པའི་མ་ནིང་ངོ་། །
Enumeration Block 5:
མདོར་བསྡུ་ན་རྒྱུ་གཉིས་ཀྱིས་ཏེ། བསམ་པ་ཉམས་པ་དང་། སྐྱེས་པ་ཉིད་ཉམས་པས་སོ། །
