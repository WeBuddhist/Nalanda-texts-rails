Enumeration Block 1:
དེ་ལ་གཟུགས་ཅན་གྱི་རྫས་རྣམས་ཀྱི་སྐྱེ་བ་ནི་མདོར་བསྡུ་ན་རྣམ་པ་ལྔར་བལྟ་བར་བྱ་སྟེ་འདི་ལྟ་སྟེ། གནས་ལས་སྐྱེ་བ་དང་། ས་བོན་ལས་སྐྱེ་བ་དང་། འཕེན་པ་ལས་སྐྱེ་བ་དང་། ཕན་འདོགས་པ༌[^793]ལས་སྐྱེ་བ་དང་། གནོད་པ་བྱེད་པ་ལས་སྐྱེ་བའོ། །
Enumeration Block 2:
དེ་ལ་རྒྱུ་གསུམ་གྱིས་ན་འབྱུང་བ་ཆེན་པོ་གྱུར་པས་རྒྱུར་བྱས་པའི་གཟུགས་འགྱུར་བ་འབྱུང་བ༌[^810]སྟེ། སྐྱེས་བུའི་བྱེད་པ་དང་། ལས་དང་། སྙོམས་པར་འཇུག་པས་སོ། །
Enumeration Block 3:
དེ་ལ་རླུང་ནི་རྣམ་པ་གཉིས་ཏེ། བརྟན་པ་དང་བརྟན་པ་མ་ཡིན་པའོ། །
Enumeration Block 4:
གསུམ་སྟེ། རྒྱུ་མཐུན་པ་ལས་བྱུང་བ་དང་། རྣམ་པར་སྨིན་པ་ལས་སྐྱེས་པ་དང་། རྒྱས་པ་ལས་བྱུང་བའོ། །
དེ་ལ་རྒྱུ་མཐུན་པ་ལས་བྱུང་བ་ནི༌[^840]རྣམ་པ་བཞི་སྟེ། རྣམ་པར་སྨིན་པའི་རྒྱུ་མཐུན་པ་ལས་བྱུང་བ་དང་། རྒྱས་པའི་རྒྱུ་མཐུན་པ་ལས་བྱུང་བ་དང་། འགྱུར་བའི་རྒྱུ་མཐུན་པ་ལས་བྱུང་བ་དང་། རང་བཞིན་གྱི་རྒྱུ་མཐུན་པ་ལས་བྱུང་བའོ། །
Enumeration Block 5:
དེ་ལ་རྒྱས་པ་ལས་བྱུང་བ་ནི་རྣམ་པ་གཉིས་ཏེ་ཡུལ་ལ་ཁྱབ་པའི་རྒྱས་པ་ལས་བྱུང་བ་དང་། མཚན་ཉིད་བརྟས་པར༌[^842]བྱེད་པའི་རྒྱས་པ་ལས་བྱུང་བའོ། །
