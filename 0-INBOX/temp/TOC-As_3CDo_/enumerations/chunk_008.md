Enumeration Block 1:
སྡོམ་པ་ཡང་དག་པར་བླང་བ་དེ་ཡང་རྣམ་པ་བརྒྱར་གཏོགས་པར་རིག་པར་བྱ་སྟེ།
Enumeration Block 2:
སྡོམ་པ་དེ་ཡང་རྣམ་པ་བརྒྱད་དུ་རིག་པར་བྱ་སྟེ་ཀུན་ནས་སློང་བའི་སྡོམ་པ་དང་། ཡོངས་སུ་འཛིན་པའི་སྡོམ་པ་དང་། ཀུན་དུ་བསྲུང་པའི་སྡོམ་པ་དང་། ཕྱིར་ལེན་པའི་སྡོམ་པ་དང་། སྡོམ་པ་ཆུང་ངུ་དང་། སྡོམ་པ་འབྲིང་དང་། སྡོམ་པ་ཆེན་པོ་དང་། ཡོངས་སུ་དག་པའི་སྡོམ་པའོ། །
Enumeration Block 3:
དེ་ལ་སྡོམ་པ་རྣམ་པ༌[^458]བརྒྱད་པོ་དེ་དག་ཐམས་ཅད་གཅིག་ཏུ་བསྡུས་ནས། སྡོམ་པ་རྣམ་པ་གསུམ་རྣམ་པར་གཞག་སྟེ། ཡང་དག་པར་ལེན་པའི་སྡོམ་པ་དང་། ཀུན་དུ་འཛིན་པའི་སྡོམ་པ་དང་། ཡོངས་སུ་དག་པའི་སྡོམ་པའོ། །
Enumeration Block 4:
རྒྱུ་གསུམ་གྱིས་ཏེ།
Enumeration Block 5:
དགེ་སློང་གི་སྡོམ་པ་ནི་ཡན་ལག་བཞིས་བསྡུས་པར་རིག་པར་བྱ་སྟེ། ཡན་ལག་བཞི་གང་ཞེ་ན།
བསྙེན་པར་རྫོགས་པའི་ཡན་ལག་དང་། དེ་དང་མཐུན་པའི་ཆོས་ཀྱི་བསླབ་པའི་གཞི་ཡང་དག་པར་བླང་བའི་ཡན་ལག་དང་། གཞན་གྱི་སེམས་རྗེས་སུ་བསྲུང་བའི་ཡན་ལག་དང་། བསླབ་པའི་ཚོགས་ཡང་དག་པར་བླངས་པ༌[^468]རྗེས་སུ་སྲུང་བའི་ཡན་ལག་གོ། །
Enumeration Block 6:
དེ་ལ་དགེ་བསྙེན་གྱི་སྡོམ་པ་ནི་ཡན་ལག་གསུམ་གྱིས་བསྡུས་པ་ཡིན་ཏེ། ཡན་ལག་གསུམ་གང་ཞེ་ན།
གཞན་ལ་གནོད་པའི་དངོས་པོ་ཆེན་པོ༌[^474]སྤོང་བ་ཡང་དག་པར་བླང་བའི་ཡན་ལག་དང་། ཡང་དག་པར་བླངས་པ་ལས་ཉམས་པ་ཕྱིར་གསོ་བའི་ཡན་ལག་དང་། ཡང་དག་པར་བླངས་པ་ལས་མི་ཉམས་པའི་ཡན་ལག་གོ། །
Enumeration Block 7:
དེ་ལ་བསྙེན་གནས་པའི་སྡོམ་པ་ནི་མདོར་བསྡུ་ན་ཡན་ལག་ལྔས་བསྡུས་པ་ཡིན་ཏེ། ཡན་ལག་ལྔ་གང་ཞེ་ན།
གཞན་ལ་གནོད་པ་སྤོང་བ་ཡང་དག་པར་ལེན་པའི་ཡན་ལག་དང་། བདག་དང་གཞན་ལ་གནོད་པ་སྤོང་བ་ཡང་དག་པར་ལེན་པའི་ཡན་ལག་དང་། ཡང་དག་པར་བླངས་པ་ལས་ཉམས་པ་ཕྱིར་གསོ་བའི་ཡན་ལག་དང་། ཡང་དག་པར་བླངས་པ་ལས་མི་ཉམས་པར་བྱ་བའི་ཕྱིར་དྲན་པ་ཉེ་བར་འཇོག་པའི་ཡན་ལག་དང་། དྲན་པ་རྨོངས་པར་མི་འགྱུར་བའི་ཡན་ལག་གོ། །
