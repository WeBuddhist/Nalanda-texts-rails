Enumeration Block 1:
ཏིང་ངེ་འཛིན་སྒོམ་པ༌[^2766]ནི་རྣམ་པ་བཞི་སྟེ། ཚེ་འདི་ལ་བདེ་བར་གནས་པ་ཐོབ་པར་བྱ་བའི་ཕྱིར་དང་། ཡེ་ཤེས་དང་མཐོང་བ་ཐོབ་པར་བྱ་བའི་ཕྱིར་དང་། ཤེས་རབ་ཀྱི་རབ་ཏུ་དབྱེ་བ་ཐོབ་པར་བྱ་བའི་ཕྱིར་དང་། ཟག་པ་ཟད་པ་ཐོབ་པར་བྱ་བའི་ཕྱིར་རོ། །
Enumeration Block 2:
འདོད་ཆགས་དང་བྲལ་བ་ནི་རྣམ་པ་དྲུག་ཏུ་རིག་པར་བྱ་སྟེ། འདི་ལྟ་སྟེ། རང་བཞིན་གྱིས་འདོད་ཆགས་དང་བྲལ་བ་དང་། གནོད་པས་འདོད་ཆགས་དང་བྲལ་བ་དང་། སྟོན་པས་འདོད་ཆགས་དང་བྲལ་བ་དང་། ཡང་དག་ཕུལ་གྱིས་འདོད་ཆགས་དང་བྲལ་བ་དང་། ཀུན་དུ་རྨོངས་པས་འདོད་ཆགས་དང་བྲལ་བ་དང་། གཉེན་པོས་འདོད་ཆགས་དང་བྲལ་བའོ། །
Enumeration Block 3:
འདི་ནི་གཉིས་ཡིན་ཏེ་མཉམ་པར་མ་བཞག་པའི་ས་པའི་དམིགས་པ་དང་། མཉམ་པར་བཞག་པའི་ས་པའི་དམིགས་པའོ། །
Enumeration Block 4:
འདོད་ཆགས་དང་བྲལ་བའི་ཡོངས་སུ་ཉམས་པ་ནི་རྣམ་པ་བཅུར་རིག་པར་བྱ་སྟེ།
Enumeration Block 5:
སེམས་ཀྱི་འཇུག་པ་ནི་མདོར་བསྡུ་ན་རྣམ་པ་ལྔར༌[^2807]རིག་པར་བྱ་སྟེ། ཀུན་རྫོབ་ཀྱི་ཚུལ་རྣམ་པར་གཞག་པ་དང་། དོན་དམ་པའི་ཚུལ་རྣམ་པར་གཞག་པ་དང་། གནས་དང་གནས་པ་རྣམ་པར་གཞག་པ་དང་། ལྷན་ཅིག་དངོས་པོར་རྣམ་པར་གཞག་པ་དང་། ཀུན་ནས་ཉོན་མོངས་པ་དང་། རྣམ་པར་བྱང་བ་རྣམ་པར་གཞག་པས་སོ། །
