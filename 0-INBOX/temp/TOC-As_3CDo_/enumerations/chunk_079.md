Enumeration Block 1:
བདག་ཡོད་ན་རིང་དུ་ཕ་རོལ་དུ་སོང་ཡང་རུང་རྣམ་པ་བཞིས་རྟོག་པར་འགྱུར་ཏེ།
Enumeration Block 2:
བདག་དེ་འགྱུར་བ་མེད་པ་ཡིན་ན། [^3077]རྒྱུ་གཉིས་ཀྱིས་འགྱུར་བ་མི་རུང་སྟེ། ཕྱི་མ་ལ་ཡང་མི་རུང་བ་དང་། ཚེ་འདི་ཉིད་ལ་ཡང་མི་རུང་བའོ། །
Enumeration Block 3:
དེ་ལ་སེམས་ཅན་དུ་གདགས་པ་རྣམ་པ་དགུ་པོ་དེ་དག་ཐམས་ཅད་ནི་མདོར་བསྡུ་ན་རྒྱུ་གསུམ་གྱི་རིགས༌[^3100]པར་བྱ་སྟེ།
Enumeration Block 4:
བཏགས་པའི་ཡོད་པའི་ཆོས་རྣམས་ལ་བརྟེན་པའི་མིང་རྣམ་པ་དུ་མ་མང་པོ་སྣ་ཚོགས་དེ་དག་ཀྱང་མདོར་བསྡུ་ན་རྣམ་པ་གཉིས་སུ་རིག་པར་བྱ་སྟེ། འདུས་པ་གཅིག་ལ་བརྟེན་པ་དང་། འདུས་པ་དུ་མ་ལ་བརྟེན་པའོ། །
Enumeration Block 5:
ཆོས་གཟུགས་ཅན་དེ་དག་གི་རབ་ཏུ་དབྱེ་བ་ནི་རྣམ་པ་ལྔས་རྣམ་པར་གཞག་སྟེ། ལྔ་གང་ཞེ་ན། དངོས་པོ་དང་། རང་གི་མཚན་ཉིད་དང་། སྤྱིའི་མཚན་ཉིད་དང་། ཁམས་དང་། ལས་ཀྱིས་སོ། །
Enumeration Block 6:
གཟུགས་ཀྱི་རང་གི་མཚན་ཉིད་ནི་རྣམ་པ་གསུམ་སྟེ། དང་བ་དང་དང་བའི་གཟུང་བ་དང་། ཡིད་ཀྱི་གཟུང་བའོ། །
Enumeration Block 7:
སྤྱིའི་མཚན་ཉིད་ཀྱང་རྣམ་པ་གསུམ་དུ་རིག་པར་བྱ་སྟེ།
