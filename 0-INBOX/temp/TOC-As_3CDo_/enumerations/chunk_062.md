Enumeration Block 1:
རྟེན་ཅིང་འབྲེལ་པར་འབྱུང་བའི་གོ་རིམས་ཀྱི་རྣམ་གྲངས་ནི་མདོར་བསྡུ་ན་རྣམ་པ་བཞིས་རིག་པར་བྱ་སྟེ། འདི་ལྟ་སྟེ། འཕེན་པའི་གོ་རིམས་དང་། མངོན་པར་འགྲུབ་པའི་གོ་རིམས་དང་། ཡུལ་ལ་ཡོངས་སུ་ལོངས༌[^2288]སྤྱོད་པའི་གོ་རིམས་དང་། སྡུག་བསྔལ་ལ་ཡོངས་སུ་སྤྱོད་པའི་གོ་རིམས་ཀྱིས་སོ། །
Enumeration Block 2:
རྒྱལ་པོ་ཆེན་པོ་བཅུ་པོ་འདི་དག་ནི་རྒྱལ་པོའི་སྐྱོན་དག་ཡིན་ཏེ།
Enumeration Block 3:
བཅུ་གང་ཞེ་ན། རིགས་མི་བཙུན་པ་ཡིན། རང་དབང་མེད་པ་ཡིན། རང་བཞིན་གྱིས་གཏུམ་པ་ཡིན། འཁྲུགས་པའི༌[^2304]ཤས་ཆེ་བ་ཡིན། བྱ་དགའ་ཆུང་བ་ཡིན། དམ་པ་མ་ཡིན་པ་རྣམས་ཀྱི་ངག་ཉན༌[^2305]པ་ཡིན། མ་བརྟགས་པར་བྱེད་ཅིང་ཆོས་ལུགས་དང་མི་ལྡན་པ་ཡིན། ཆོས་ལ་མི་ལྟ་བ་ཡིན། བྱེ་བྲག་མི་ཤེས་ཤིང་བྱས་པ་མི་གཟོ་བ་ཡིན། རབ་ཏུ་མྱོས་ཤིང་གཅིག་ཏུ་བག་མེད་པར་སྤྱོད་པ་ཡིན་ནོ། །
Enumeration Block 4:
རྒྱལ་པོ་ཆེན་པོ་བཅུ་པོ་འདི་དག་ནི་རྒྱལ་པོའི་ཡོན་ཏན་དག་ཡིན་ཏེ།
Enumeration Block 5:
བཅུ་གང་ཞེ་ན། རིགས་བཙུན་པ་ཡིན། རང་དབང་ཡོད་པ་ཡིན། རང་བཞིན་གྱིས༌[^2342]མི་གཏུམ་པ་ཡིན། འཁྲུག་པའི་ཤས་མི་ཆེ་བ་ཡིན། བྱ་དགའ་ཆེ་བ་ཡིན། དམ་པ་རྣམས་ཀྱི་ངག་ཉན་པ་ཡིན། བརྟགས་ཏེ་བྱེད་ཅིང་ཆོས་ལུགས་དང་ལྡན་པ་ཡིན། ཆོས་ལ་ལྟ་བ་ཡིན། བྱེ་བྲག་ཤེས་ཤིང་བྱས་པ་གཟོ་བ་ཡིན། རབ་ཏུ་མ་མྱོས་ཤིང་གཅིག་ཏུ་བག་མེད་པར་མི་སྤྱོད་པ་ཡིན་ནོ། །
