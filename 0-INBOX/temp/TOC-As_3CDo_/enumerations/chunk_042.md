Enumeration Block 1:
བཅོམ་ལྡན་འདས་ཀྱིས་འདོད་པ་ལ་ལོངས་སྤྱོད་པ་རྣམས་ཀྱི་དཔལ་བྱེད་པའི་ཆོས་ནི་ལྔ་པོ་འདི་དག་ཡིན་ཏེ་བཟོད་པ་དང་། དེས་པ་དང་། མི་ཡོངས་སུ་བརྟག་པ་དང་། གཏོང་བ་སྤྱོད་པ་དང་། བག་ཡོད་པའོ་
Enumeration Block 2:
དེའི་མཚན་ཉིད་ནི་རྣམ་པ་གསུམ་དུ་བལྟ་བར་བྱ་སྟེ་མི་འཁྲུགས་པ་དང་ཕྱིར་གནོད་པ་མི་བྱེད་པ་དང་ཁོན་གྱི་བསམ་པ་མི་འཛིན་པའོ། །
Enumeration Block 3:
རྣམ་པའི་རབ་ཏུ་དབྱེ་བ་ལས་ནི་རྣམ་པ་བཅུ་སྟེ། གནོད་པ་བྱས་པ་བཟོད་པ་དང་། གནོད་པ་བྱེད་པ་ཉེ་བར་གནས་པ་བཟོད་པ་དང་། གནོད་པ་བྱེད་དུ་དོགས་པ་བཟོད་པ་དང་། གནོད་པ་བྱེད་པ་ལ་ཕན་འདོགས་པ་ལ་བཟོད་པ་དང་། ཕན་འདོགས་པ་ལ་གནོད་པ་བྱེད་པ་ལ་བཟོད་པ་དང་། གནོད་པ་བྱེད་པ་ཐམས་ཅད་བཟོད་པ་དང་། ཐམས་ཅད་ལས་གནོད་པ་བྱེད་པ་བཟོད་པ་དང་། གནོད་པ་བྱེད་པ་ཤད་ཀྱིས་སྦྱོང་བ་དང་དུ་ལེན་པའི་བཟོད་པ་དང་། གནོད་པ་བྱེད་པ་ལ་སོ་སོར་རྟོག་པའི་སྟོབས་ཀྱིས་བཟོད་པ༌[^1467]དང་། གནོད་པ་བྱེད་པའི༌[^1468]རང་བཞིན་གྱིས་བཟོད་པ་སྟེ།
Enumeration Block 4:
མི་ཡོངས་སུ་བརྟག་པ་ནི་དུས་གཉིས་སུ་བལྟ་བར་བྱ་སྟེ། [^1473]བསྙེན་པའི་དུས་དང་བསྐོ་བའི་དུས་སུའོ། ། དེ་ལ་བསྙེན་པའི་དུས་སུ༌[^1474]ནི་རྣམ་པ་ལྔས་མི་ཡོངས་སུ་བརྟགས་ནས་བསྙེན་པར་བྱ་སྟེ། གུས་པ་དང་ནུས་པ་དང་ཤེས་པ་དང་། སྤྱོད་པ་དང་། ཆོག་ཤེས་པས་སོ། ། གཞན་རྣམ་པ་ལྔས་ནི་མི་ཡོངས་སུ་བརྟགས་ནས་བསྐོ་བར་བྱ་སྟེ།
Enumeration Block 5:
གཏོང་བ་ནི་མདོར་བསྡུ་ན་རྣམ་པ་ལྔར་བལྟ་བར་བྱ་སྟེ། ས་གཞི་གཏོང་བ༌[^1476]དང་ལོངས་སྤྱོད་གཏོང་བ་དང་རྐྱེན་དུ་འབབ་པ་གཏོང་བ་དང་སྙོམས་པར་གཏོང་བ་དང་ཁྱད་པར་དུ་འཕགས་པ་གཏོང་བ་སྟེ།
Enumeration Block 6:
མི་འཁུ་བ་དེའང་རྣམ་པ་ལྔ་སྟེ། དམས་པ་ན་མི་འཁུ་བ་དང་ཡིད་བརྟན་པ་ལ་མི་འཁུ་བ་དང་ཉེ་བར་སྤྱོད་པས༌[^1477]མི་འཁུ་བ་དང་དམ་བཅས་པ་ལས་མི་འཁུ་བ་དང་གཞན་ལ་ཚོལ་ཞིང་མི་འཁུ་བའོ།[^1478] །
Enumeration Block 7:
དེའང་རྣམ་པ་ལྔ་ཁོ་ནར་བལྟ་བར་བྱ་སྟེ། ལོངས་སྤྱོད་སྒྲུབ་པ་ལ་བག་ཡོད་པ་དང་ལོངས་སྤྱོད་སྲུང་བ༌[^1480]ལ་བག་ཡོད་པ་དང་བདག་ཉིད་བསྲུང་བ་ལ་བག་ཡོད་པ་དང་། གྲགས་པ་བསྲུང་བ་ལ་བག་ཡོད་པ་དང་ཆོས་སྤྱོད་པ་ལ་བག་ཡོད་པའོ།[^1481] ། དེ་དག་ཐམས་ཅད་བསྡུས་ན་དཔལ་སྒྲུབ་པར་བྱེད་པའི་སྟོབས་ལྔར་འགྱུར་ཏེ། ངང་ཚུལ་བཟང་པོའི་སྟོབས་དང་གྲོགས་དང་མཛའ་བཤེས་བཟང་པོའི་སྟོབས་དང་། མི་ཞན་པའི་སྟོབས་དང་། ཡིད་གཅུགས་པའི་སྟོབས་དང་། ཆོས་ཀྱི་སྟོབས་སོ། ། དཔལ་ཡང༌[^1482]རྣམ་པ་ལྔར་བལྟ་བར་བྱ་སྟེ། སྐྱེ་དགུ་རྗེས་སུ་དགའ་བ་དང་། དབང་ཕྱུག་གི་བདག་པོ༌[^1483]དང་། དགྲ་ཐུལ་བ་དང་། བརྟེན་པ་ལ་ཕན་པ་དང་། བདེ་འགྲོར་འགྲོ་བའོ། །
Enumeration Block 8:
མདོར་བསྡུ་ན་རྣམ་པ་ལྔས་བྱེ་བྲག་ཏུ་གྱུར་པར་བལྟ་བར་བྱ་སྟེ། རིམ་པའི་བྱེ་བྲག་དང་། ཉེ་བར་སྟོན་པའི་བྱེ་བྲག་དང་འཆིང་བའི་བྱེ་བྲག་དང་། སྒྲུབ་པའི་བྱེ་བྲག་དང་། ཡང་དག་པར་འགྲུབ་པའི་བྱེ་བྲག་གིས་སོ། །
