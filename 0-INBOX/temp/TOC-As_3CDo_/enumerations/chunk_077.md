Enumeration Block 2:

Enumeration Block 3:

Enumeration Block 4:

Enumeration Block 5:

Enumeration Block 6:

ཞི་གནས་ཀྱི་རྣམ་པར་གཞག་པ་ཡང་རྣམ་པ་ལྔ་ཁོ་ནས་རིག་པར་བྱ་སྟེ། འཇིག་རྟེན་པའི་ཉེར༌[^3022]བསྡོགས་ཀྱིས་བསྡུས་པའི་ཞི་གནས་དང་། དེ་བཞིན་དུ་གཟུགས་ཀྱི་སྙོམས་པར་འཇུག་པའི་དངོས་གཞིས་བསྡུས་པ་དང་། དེ་བཞིན་དུ་གཟུགས་མེད་པའི་སྙོམས་པར་འཇུག་པའི་དངོས་གཞིས་བསྡུས་པ་དང་། འཇིག་རྟེན་ལས་འདས་པའི་ཉན་ཐོས་དང་རང་སངས་རྒྱས་ཀྱི་ཡིད་ལ་བྱེད་པས་བསྡུས་པ་དང་། འཇིག་རྟེན་ལས་འདས་པ༌[^3023]བྱང་ཆུབ་སེམས་དཔའི་ཡིད་ལ་བྱེད་པས་བསྡུས་པའོ། །
