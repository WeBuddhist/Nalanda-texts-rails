Enumeration Block 1:
སྐྱེས་བུ་གསུམ་པོ་སྐྱེས་བུ་ཐ་མ་དང་སྐྱེས་བུ་འབྲིང་དང་། སྐྱེས་བུ་མཆོག་འདི་དག་ནི་སྒྲུབ་པ་ལས་བརྩམས་པ་སྟེ།
Enumeration Block 2:
གཞན་ཡང་གང་ཟག་བཞི་སྟེ།
Enumeration Block 3:
གཞན་ཡང་གང་ཟག་རྒྱལ་པོ་གསུམ་སྟེ། གསུམ་གང་ཞེ་ན།
འདོད་པའི་ལོངས་སྤྱོད་ལྷུར་ལེན་པ་དང་། བྱ་བ་ལྷུར་ལེན་པ་དང་། ཆོས་ལྷུར་ལེན་པའོ། །
Enumeration Block 4:
གཞན་ཡང་གང་ཟག་གསུམ་སྟེ། གསུམ་གང་ཞེ་ན།
བྱ་བ་མ་ཡིན་པ༌[^2497]རང་གི་བྱ་བར་བྱེད་པ་དང་། བྱ་བ་རང་གི་བྱ་བར་བྱེད་པ་དང་། གཞན་གྱི་བྱ་བ་རང་གི་བྱ་བར་བྱེད་པའོ། །
Enumeration Block 5:
གསུམ་པོ་འདི་དག་ནི་རྒྱལ་པོའི་ཕུན་སུམ་ཚོགས་པ་ཡིན་ཏེ། རྣམ་པར་སྨིན་པ་ཕུན་སུམ་ཚོགས་པ་དང་། སྐྱེས་བུའི་རྩལ་ཕུན་སུམ་ཚོགས་པ་དང་། བསོད་ནམས་ཕུན་སུམ་ཚོགས་པའོ། །
Enumeration Block 6:
རྒྱལ་པོའི་ཚལ་ཟ་ནི་གསུམ་སྟེ་གུས་པ་དང་ལྡན་ལ་ནུས་པ་དང་མི་ལྡན་ཤེས་རབ་དང་མི་ལྡན་པ་དང་། གུས་པ་དང་ཡང་ལྡན་ནུས་པ་དང་ཡང་ལྡན་ལ༌[^2504]ཤེས་རབ་དང་མི་ལྡན་པ་དང་གུས་པ་དང་ཡང་ལྡན་ནུས་པ་དང་ཡང་ལྡན་ཤེས་རབ་དང་ཡང་ལྡན་པའོ། །
Enumeration Block 7:
ཚིག་གི༌[^2506]རྣམ་པ་བཞི་སྟེ། མི་སྙན་པ་ལ་སྙན་པར་གྲགས་པ་དང་། སྙན་པ་ལ་མི་སྙན་པར་གྲགས་པ་དང་། མི་སྙན་པ་ལ་མི་སྙན་པར་གྲགས་པ་དང་། སྙན་པ་ལ་སྙན་པར་གྲགས་པའོ། །
Enumeration Block 8:
འདོད་པ་ལ་ལོངས་སྤྱོད་པ་ནི་གསུམ་སྟེ།
Enumeration Block 9:
སྦྱིན་པར་བྱ་བའི་དངོས་པོ་ལས་བརྩམས་ནས་གང་ཟག་གསུམ་སྟེ།
Enumeration Block 10:
སྦྱིན་པའི་ཞིང་ལས་བརྩམས་ནས་གང་ཟག་གསུམ་སྟེ།
