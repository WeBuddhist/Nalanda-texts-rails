* 1.4 མཚམས་སྦྱར་བ [[དེ་ལ་མཚམས་སྦྱར་བ་ནི་རྣམ་པ་གཉིས་ཏེ། དོན་སྔ་ཕྱི་འབྲེལ་བའི་མཚམས་སྦྱར་བ་ནི་]]
   * 1.4.1 དོན་སྔ་ཕྱི་འབྲེལ་བའི་མཚམས་སྦྱར་བ [[དོན་སྔ་ཕྱི་འབྲེལ་བའི་མཚམས་སྦྱར་བ་ནི་དཔེར་ན་དགེ་སློང་དག་འཕགས་པའི་ཆོས་ཀྱི་ཕྱག་རྒྱ་]]
   * 1.4.2 སྔ་ཕྱི་ཉིད་ཀྱི་གོ་རིམས་ཀྱི་མཚམས་སྦྱར་བ [[སྔ་ཕྱི་ཉིད་ཀྱི༌[^1069]གོ་རིམས་ཀྱི་མཚམས་སྦྱར་བ་ནི་དཔེར་ན་འཕགས་པའི་བདེན་པ་རྣམས་ལས་]]
* 1.5 བརྒལ་བ་དང་ལན [[བརྒལ་བ་ནི་རྣམ་པ་གཉིས་ཏེ། སྒྲ་ལ་བརྒལ་པ་དང་། དོན་ལ་བརྒལ་བའོ། །]]
   * 1.5.1 སྒྲ་ལ་བརྒལ་པ [[འདི་ལྟ་སྟེ། ཚེ་དང་ལྡན་པ་ཤཱ་རིའི་བུ་བཞུགས་ཟིན་ཀྱང་། ཤཱ་རིའི་བུ་ཁྱོད་ད་གཟོད་དང་]]
   * 1.5.2 དོན་ལ་བརྒལ་བ [[དོན་ལ་བརྒལ་བ་ཡང་རྣམ་པ་གཉིས་ཏེ། སྔ་ཕྱི་འགལ་བར་བརྒལ་བ་དང་། རིགས་པ་དང་འགལ་བར་བརྒལ་བའོ། །]]
      * 1.5.2.1 སྔ་ཕྱི་འགལ་བར་བརྒལ་བ [[དེ་ལ་སྔ་ཕྱི་འགལ་བར་བརྒལ་བ་ནི་དཔེར་ན་ཁ་ཅིག་ལས་འདི་སྐད་དུ་སེམས་ཞེས་བྱ་བའམ།]]
      * 1.5.2.2 རིགས་པ་དང་འགལ་བར་བརྒལ་བ [[རིགས་པ་དང་འགལ་བར་བརྒལ་བ་ནི་དཔེར་ན་གཟུགས་གང་ཡིན་པ་ཅི་ཡང་རུང་བ་དེ༌[^1100]]]
