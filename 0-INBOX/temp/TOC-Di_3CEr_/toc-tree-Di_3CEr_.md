## དཀར་ཆག / Table of Contents

* I. ཀླད་ཀྱི་དོན། [[༄༅༅། །རྒྱ་གར་སྐད་དུ། པྲ་མཱ་ཎ་ས་མུཙྪཱ་ཡ་བྲྀཏྟི།]]
* 1. མངོན་སུམ་གྱི་ལེའུ། [[འདིར་ཡང་རབ་ཏུ་བྱེད་པའི་དང་པོར་རྒྱུ་དང་འབྲས་བུ་ཕུན་སུམ]]
   * 1.1 བསྟོད་པ་བརྗོད་པ། [[འདིར་ཡང་རབ་ཏུ་བྱེད་པའི་དང་པོར་རྒྱུ་དང་འབྲས་བུ་ཕུན་སུམ]]
   * 1.2 ཚད་མ་གཉིས་ཁོ་ན། [[དེ་ལ། མངོན་སུམ་དང་ནི་རྗེས་སུ་དཔག །ཚད་མ་གཉིས་ཁོ་ནའོ།]]
   * 1.3 མངོན་སུམ་རྟོག་དང་བྲལ་བ། [[དེ་ལ། མངོན་སུམ་རྟོག་དང་བྲལ་བའོ། །ཤེས་པ་གང་ལ་རྟོག་པ་མེད་པ]]
      * 1.3.1 རྟོག་པ། [[རྟོག་པ་ཞེས་བྱ་བ་འདི་ཇི་ལྟ་བུ་ཞིག་ཡིན་ཞེ་ན།]]
      * 1.3.2 དེ་ཡི་ཐ་སྙད་དབང་པོ་ལས། [[ཅི་གང་གི་ཕྱིར་གཉིས་ལ་བརྟེན་ནས། སྐྱེས་པའི]]
      * 1.3.3 ཡིད་ཀྱང་རྟོག་པ་མེད་པ། [[ཡིད་ཀྱང་དོན་དང་ཆགས་ལ་སོགས། །]]
      * 1.3.4 རྣལ་འབྱོར་པ་རྣམས་ཀྱི་མངོན་སུམ། [[རྣལ་འབྱོར་རྣམས་ཀྱི་བླ་མ་ཡིས། །]]
      * 1.3.5 རྟོག་པའང་རང་རིག། [[རེ་ཞིག་གལ་ཏེ་འདོད་ཆགས་ལ་སོགས་པའི་རང་རིག་པ་མངོན་སུམ་ཡིན་ན]]
      * 1.3.6 མངོན་སུམ་ལྟར་སྣང་། [[འཁྲུལ་དང་ཀུན་རྫོབ་ཡིད་ཤེས་དང་། །]]
      * 1.3.7 ཚད་མའི་འབྲས་བུ། [[བྱ་དང་བཅས་པར་རྟོགས་པའི་ཕྱིར། །]]
      * 1.3.8 ཤེས་པ་ཚུལ་གཉིས། [[ཅི་སྟེ་ཤེས་པ་ཚུལ་གཉིས་སོ། །]]
   * 1.4 གཞན་གྱིས་བྱས་པའི་མངོན་སུམ་བརྟག་པ། [[གཞན་གྱིས་བྱས་པའི་མངོན་སུམ་བརྟག་པར་བྱ་སྟེ།]]
      * 1.4.1 རྩོད་པ་བསྒྲུབ་པ། [[རྩོད་སྒྲུབ་སློབ་དཔོན་གྱིས]]
      * 1.4.2 རིགས་པ་ཅན་རྣམས་ཀྱི་མངོན་སུམ། [[རིགས་པ་ཅན་རྣམས་ནི་དབང་པོ་དང་དོན་ཕྲད་པ་ལས་སྐྱེས་པའི་ཤེས་པ]]
      * 1.4.3 བྱེ་བྲག་པའི་མངོན་སུམ། [[བྱེ་བྲག་པ་རྣམས་ཀྱི་མདོ་ལས་རེ་ཞིག་གང་འབྲེལ་པ་འབའ་ཞིག་ལས]]
      * 1.4.4 གྲངས་ཅན་གྱི་མངོན་སུམ། [[སེར་སྐྱ་བ་རྣམས་ཀྱིས་ནི་རྣ་བ་ལ་སོགས་པའི་འཇུག་པ་མངོན་སུམ]]
      * 1.4.5 དཔྱོད་པ་རྣམས་ཀྱི་མངོན་སུམ། [[དཔྱོད་པ་རྣམས་ནི་ཡོད་པ་དང་ཡང་དག་པར་ཕྲད་ནས་སྐྱེས་པའི]]
         * 1.4.5.1 ཡོད་པ་དང་ཡང་དག་པར་ཕྲད་ནས་སྐྱེས་པ། [[དཔྱོད་པ་རྣམས་ནི་ཡོད་པ་དང་ཡང་དག་པར་ཕྲད་ནས་སྐྱེས་པའི]]
         * 1.4.5.2 འགྲེལ་པ་བྱེད་མཁན་གྱི་འདོད་པ། [[བློ་ཡི་རྒྱུ་ཡི་ཚོགས་པ་རུ། །]]
* 2. རང་གི་དོན་གྱི་རྗེས་སུ་དཔག་པའི་ལེའུ། [[རྗེས་དཔག་རྣམ་གཉིས་ཏེ། རང་གི་དོན་དང་། གཞན་གྱི་དོན་ནོ།]]
   * 2.1 རང་གི་དོན་གྱི་རྗེས་སུ་དཔག་པ། [[དེ་ལྟར་རང་དོན་ནི།]]
      * 2.1.1 ཚུལ་གསུམ་རྟགས་ལས་དོན་མཐོང་བ། [[དེ་ལྟར་རང་དོན་ནི།]]
      * 2.1.2 འབྲས་བུ་སྔར་བཞིན། [[འདི་ཡང་འབྲས་བུ]]
      * 2.1.3 གཟུང་ཐ་དད་ཕྱིར་གཉིས་སུ་དབྱེ་བ། [[གལ་ཏེ་ཅིའི་ཕྱིར་རྗེས་སུ་དཔག་པ་ཁོ་ན་གཉིས་སུ་དབྱེ་ཞེ་ན།]]
      * 2.1.4 ཡིད་ཆེས་ཚིག་རྗེས་སུ་དཔག་པ་ཉིད། [[ཡིད་ཆེས་ཚིག་ཀྱང་མི་སླུ་བར། །]]
      * 2.1.5 ཚུལ་གསུམ་པའི་རྟགས། [[ཚུལ་གསུམ་པའི་རྟགས་ཞེས་གང་བརྗོད་པ་དེ་བརྗོད་པར་བྱ་སྟེ།]]
      * 2.1.6 ཚུལ་རེ་རེ་དང་གཉིས་གཉིས་པ། [[ཚུལ་རེ་རེ་དང་གཉིས་གཉིས་པ། །རྟགས་དོན་མིན་པར་དོན་གྱིས་བྱས།]]
      * 2.1.7 ཆོས་གཞན་དང་འབྲེལ་པ་དཔག་བྱར་འདོད་པ། [[ཁ་ཅིག་གཏན་ཚིགས་མི་འཁྲུལ་པས། །ཆོས་གཞན་དཔག་པར་བྱ་བར་འདོད།]]
         * 2.1.7.1 ཆོས་གཞན་དཔག་བྱར་འདོད་པ། [[ཁ་ཅིག་གཏན་ཚིགས་མི་འཁྲུལ་པས། །ཆོས་གཞན་དཔག་པར་བྱ་བར་འདོད།]]
         * 2.1.7.2 འབྲེལ་པ་དཔག་བྱར་འདོད་པ། [[ཆོས་དང་ཆོས་ཅན་དག་གྲུབ་ཕྱིར། །]]
         * 2.1.7.3 སྔ་མ་ལ་ལན་བརྗོད་པ། [[རེ་ཞིག་དེ་སྔ་མ་ལ་ལན་བརྗོད་པ།]]
         * 2.1.7.4 འབྲེལ་པ་དཔག་བྱར་ཟེར་བ་ལ་བརྗོད་པ། [[གང་དག་འབྲེལ་པ་དཔག་པར་བྱའོ་ཞེས་ཟེར་བ་དེ་ལ་བརྗོད་པ་དང་།]]
      * 2.1.8 ཆོས་ལ་དཔྱད་པ་གཞན། [[རྟགས་ཀྱི་རྗེས་སུ་བསྟན་བྱ་བའི། །]]
      * 2.1.9 རྟགས་དང་རྟགས་ཅན་འབྲེལ་པ། [[ཅི་སྟེ་འབྲེལ་པ་ནི་ཡང་དག་པར་འཕྲོད་པ་བཞིན་དུ་གཉིས་ཀ་དང་འབྲེལ་པ་ཡིན་པའི་ཕྱིར་]]
      * 2.1.10 རྟགས་ཀྱི་ཁྱབ་པ། [[ཅི་སྟེ་ཡང་རྟགས་ཡིན་ཡང་རྟགས་ཅན་དུ་འགྱུར་བ་ནི་དཔེར་ན་བྱས་པ་ཉིད་དང་]]
   * 2.2 རྩོད་པ་སྒྲུབ་པ། [[རྩོད་པ་སྒྲུབ་པ་ནས་ནི་མེད་ན་མི་འབྱུང་བའི་དོན་མཐོང་བ་དེ་རིག་པ]]
   * 2.3 རིགས་པ་ཅན། [[རིགས་པ་ཅན་རྣམས་ན་རེ་དེ་སྔོན་དུ་སོང་བ་ཅན་གྱི་རྗེས་སུ་དཔག་པ་ནི་རྣམ་པ་གསུམ་སྟེ།]]
      * 2.3.1 མངོན་སུམ་སྔོན་དུ་འགྲོ་བ། [[དེ་ལ་རེ་ཞིག་མངོན་སུམ་སྔོན་དུ་འགྲོ་བ་ནི་རིགས་པ་མ་ཡིན་ཏེ།]]
      * 2.3.2 སྔ་མ་དང་ལྡན་པ། [[འཁྲུལ་བའི་ཕྱིར་ན་ལྡན་པ་མིན། །ལྡན་པར་བྱེད་པ་ནི་རིགས]]
      * 2.3.3 ལྷག་མ་དང་ལྡན་པ། [[ལྷག་ལྡན་ལ]]
   * 2.4 བྱེ་བྲག་པ། [[བྱེ་བྲག་པ་རྣམས་ན་རེ་འདི་ནི་འདིའི་འབྲས་བུ་དང་རྒྱུ་དང་འབྲེལ་པ་དང་དོན་གཅིག་ལ་འདུ་བ]]
      * 2.4.1 ལྡན་པ། [[དེ་ལ་རེ་ཞིག །ལྡན་པའི་རྟོགས་པ་གྲུབ་པ་མེད། །]]
      * 2.4.2 འདུ་བ། [[འདུ་བ་ཡང་བ་ལང་གི་རྭ་ཡོད་པར་དཔོག་པའི་རྒྱུ་མ་ཡིན་ཏེ།]]
      * 2.4.3 དོན་གཅིག་ལ་འདུ་བ། [[དོན་གཅིག་ལ་འདུ་བ་ནི་རྣམ་པ་གཉིས་ཏེ། འབྲས་བུ་དང་འབྲས་བུ་གཞན་དང་།]]
      * 2.4.4 འགལ་བ། [[འགལ་བ་ནི་རྣམ་པ་བཞི་སྟེ། མངོན་སུམ]]
   * 2.5 གྲངས་ཅན་པ། [[གྲངས་ཅན་པ་རྣམས་ནི་རེ་ཞིག་འབྲེལ་བ་མངོན་སུམ་པ་གཅིག་ལས་ལྷག་པར་གྲུབ་པ་ནི་]]
      * 2.5.1 འབྲེལ་བ་རྣམ་པ་བདུན། [[དེ་ལ་འབྲེལ་བ་ནི་རྣམ་པ་བདུན་ཏེ། དེ་རྣམས]]
