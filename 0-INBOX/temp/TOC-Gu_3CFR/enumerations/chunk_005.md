Enumeration Block 1:
ལས་ནི་རྣམ་པ་གསུམ་སྟེ། བསོད་ནམས་དང་བསོད་ནམས་མ་ཡིན་པ་དང་། མི་གཡོ་བའི་མཚན་ཉིད་དོ། །
Enumeration Block 2:
འབྲས་བུ་ནི་རྣམ་པ་བཞི་གསུངས་ཏེ། རྒྱུན་ཏུ་ཞུགས་པའི་འབྲས་བུ་དང་། ལན་ཅིག་ཕྱིར་འོང་བའི་འབྲས་བུ་དང་། ཕྱིར་མི་འོང་བའི་འབྲས་བུ་དང་། དགྲ་བཅོམ་པ་ཉིད་ཀྱི་འབྲས་བུའོ། །
Enumeration Block 3:
འཕགས་པའི་བདེན་པ་ནི་བཞི་སྟེ། སྡུག་བསྔལ་བ་དང་། ཀུན་འབྱུང་བ་དང་། འགོག་པ་དང་ལམ་མོ། །
Enumeration Block 4:
དེ་ལ་ཕུང་པོ་ལྔ་ནི་སྡུག་བསྔལ་གསུམ་གྱི་སྡུག་བསྔལ་བ་སྟེ། སྡུག་བསྔལ་གྱི་སྡུག་བསྔལ༌[^149]ཉིད་དང་། འགྱུར་བའི་སྡུག་བསྔལ་ཉིད་དང་། འདུ་བྱེད་ཀྱི་སྡུག་བསྔལ་ཉིད་ཀྱིས་སོ། །
Enumeration Block 5:
དཀོན་མཆོག་ནི་གསུམ་སྟེ། སངས་རྒྱས་དཀོན་མཆོག་དང་། ཆོས་དཀོན་མཆོག་དང་། དགེ་འདུན་དཀོན་མཆོག་གོ། །
Enumeration Block 6:
ཆོས་ནི་རྣམ་པ་གསུམ་སྟེ། བསྟན་པའི་ཆོས་དང་། ལམ་གྱི་ཆོས་དང་། དོན་དམ་པའི་ཆོས་སོ། །
Enumeration Block 7:
དགེ་འདུན་ནི་འཕགས་པའི་སྐྱེས་བུ་གང་ཟག་ཡ་བརྒྱད་དོ།[^158] །རྒྱུན་དུ་ཞུགས་པ་མངོན་སུམ་དུ་བྱ་བའི་ཕྱིར་ཞུགས་པ་དང་། རྒྱུན་དུ་ཞུགས་པ་དང་། ལན་ཅིག་ཕྱིར་འོང་བ་མངོན་སུམ་དུ་བྱ་བའི་ཕྱིར་ཞུགས་པ་དང་། ལན་ཅིག་ཕྱིར་འོང་བ་དང་། ཕྱིར་མི་འོང་བ་མངོན་སུམ་དུ་བྱ་བའི་ཕྱིར་ཞུགས་པ་དང་། ཕྱིར་མི་འོང་བ་དང་དགྲ་བཅོམ་པ་ཉིད་མངོན་སུམ་དུ་བྱ་བའི་ཕྱིར་ཞུགས་པ་དང་། དགྲ་བཅོམ་པའོ། །
Enumeration Block 8:
དེ་ནི་རྣམ་པ་གཉིས་ཏེ། རེ་ལྟར༌[^159]ཐོགས་ན་སྲིད་པ་ལན༌[^160]

བདུན་པ་དང་། རིགས་ནས་རིགས་སུ་སྐྱེ་བའོ། །
Enumeration Block 9:
རིགས་ནས་རིགས་སུ་སྐྱེ་བ་རྣམ་པ་གཉིས་ཏེ།
