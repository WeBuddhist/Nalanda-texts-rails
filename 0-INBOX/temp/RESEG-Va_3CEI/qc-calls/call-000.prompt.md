━━━ ISSUE TYPES ━━━

CONNECTOR_ENDING
  The block ends with a connector particle (དང་། / ཞིང་། / ཅིང་། / ནས། / ལས། /
  སྟེ། / ཏེ།) that grammatically requires continuation. Real issue if the next
  block is the grammatical continuation. False positive if this is a closing verse
  pāda or a deliberate short citation frame.

OBJECTION_REPLY_FUSED
  The block contains both an objection marker (ཅེ་ན། / ཞེ་ན། / སྙམ་ན།) and a reply
  opener (འོ་ན།). These should always be two separate blocks. Almost always a
  real issue.

OVER_LENGTH
  The block exceeds the syllable threshold. Usually NOT wrong: a whole explanation
  unit is legitimately long. Split only if a new node opener (ordinal + title +
  ནི། / ལ་ N།) or the treatment of a new verse is buried mid-block.

SHORT_FRAGMENT
  The block is suspiciously short — may be a stray split artifact that should be
  merged with an adjacent block.

བཅོམ་ལྡན་འདས་མངོན་པར་བྱང་ཆུབ་ནས་དང་པོ་རི་དྭགས་མའི་ཚལ་དྲང་སྲོང་བབས༌[^71]པའི་གནས་སུ་འཕགས་པ་ཉན་ཐོས་པ་རྣམས་ལ་བདེན་པ་བཞི་ལས་བརྩམས་ཏེ་ཆོས་ཀྱི་འཁོར་ལོ་བསྐོར་བ་ཡང་ངོ་མཚར་རྨད་དུ་བྱུང་བ༌[^72]འཇིག་རྟེན་ཐམས་ཅད་དུ་མངོན་པར༌[^73]བྱུང་བའི་ཆོས་ཀྱི་འཁོར་ལོ་བསྐོར༌[^74]ཏོ་ཞེས་བསྒྲགས༌[^75]ཀྱང་དེ་ཡང་བླ་མ་དང་བཅས་པ་སྐབས་དང་བཅས་པ། རྩོད་པའི་གླགས༌[^76]ཡོད་པ་གཅིག་ཏུ་ངེས་པ་མ་ཡིན་ནོ། །དེའི་འོག་ཏུ་བྱང་ཆུབ་སེམས་དཔའ་རྣམས་ལ་ཐེག་པ་ཆེན་པོ་ལས་བརྩམས་ཏེ། ཆོས་ཐམས་ཅད་མ་བྱུང་བ། མ་སྐྱེས་པ། ཐོག་མ་ནས་ཞི་བ། རང་བཞིན་གྱིས་མྱ་ངན་ལས་འདས་པ་མི་མངོན་པའི་ཚུལ་གྱིས་བསྒྲགས་ཏེ། ཆོས་ཀྱི་འཁོར་ལོ་བསྐོར་བ་ཡང་ཤིན་ཏུ་དཀོན་པ་རྨད་དུ་བྱུང་བ་ལ།[^77] སྔོན་མ་བྱུང་བ་ཡིན་མོད་ཀྱི། དེ་ཡང་བླ་མ་དང་བཅས་པ་སྐབས་ཅན་གཅིག༌[^78]ཏུ་མ་ངེས་པ༌[^79]རྩོད་པ་དང་བཅས་པ་ཡིན་ནོ། །དེའི་འོག་ཏུ་བཅོམ་ལྡན་འདས་ཀྱིས་ཐེག་པ་ཐམས་ཅད་པ་ལས༌[^80]བརྩམས་ཏེ། ཆོས་ཐམས་ཅད་རང་བཞིན་གྱིས་མ་སྐྱེས་པ། མྱ་ངན་ལས་འདས་པ་སྟེ༌[^81]མངོན་པ་ཉིད་དུ་བསྒྲགས་ཏེ། ཆོས་བསྟན་པ་ནི་བླ་ན་མ་མཆིས་པ། སྐབས་མ་མཆིས་པ། རྩོད་པའི་གླགས་མ་མཆིས་པའོ་ཞེས་གསུངས་ཏེ། དང་པོར༌[^82]ཉན་ཐོས་རྣམས་ལ་ཨཱ་ཀ༌[^83]མའི་གཞུང་བཤད་དེ། ཡོད་པར༌[^84]མངོན་པ་ཉིད་དུ་མ་བསྟན་པ་ཡང་ཡོད་པ་ཉིད་རང་བཞིན་མི་འགྲུབ་པ། ཤེས་རབ་ཀྱི་ཕ་རོལ་ཏུ་ཕྱིན་པའི་ནང་དུ་སྟོང་པ་ཉིད་དུ་བསྟན་པ༌[^85]ཡང་སྟོང་པའི་རང་བཞིན་ཉིད་གྲུབ་པ་མེད་སྡོང་པོས་བརྒྱན་པ་ལ་སོགས་པར་ཡོད་པ་ཉིད་དུ་མངོན་པར་བསྒྲགས་པ་ལ་ཡང་གཞན་གྱི་དབང༌[^86]དང་། ཡོངས་སུ་གྲུབ་པའི་མཚན་ཉིད་ཡོད་པ་ལ༌[^87]བརྟེན་ཏེ་གསུངས་པའི་དཔེར་མྱ་ངན་ལས་འདས་པ་ཆེན་པོ་ལས་ཀྱང་དཔེར་ན་སྨན་པ་མཁས་པ་ཞིག་གིས༌[^88]ཡུལ་ཕྱོགས་སུ་འོ་མ་ལུས་ལ་གསོལ་བར༌[^89]སྨྲས་པས་མི་ཀུན་གྱིས༌[^90]འོ་མ་འབའ་ཞིག་འཐུངས་པས་ནད་དུ་གྱུར་ཏེ་འཆི་བ་ཡང་མང་བར༌[^91]གྱུར་ཏོ། །དེའི་གཉེན་པོར་འོ་མ་བཅད་པའི༌[^92]ཕྱིར་འོ་མ་ནི་དུག་ཡིན་གྱི་འོ་མ་ནི་སུ་ཡང་མ་འཐུང་ཤིག༌[^93]ཅེས་བསྒོ་བས་ཡུལ༌[^94]ཕྱོགས་སུ་ནད་ཉུང་བར༌[^95]གྱུར་ཏོ། །དེའི་འོག་ཏུ་ཡུལ་དེའི་རྒྱལ་པོ་ལ་སྨན་གཏང༌[^96]བའི་ཕྱིར་སྨན་འོ་མ་དང་སྦྱར་བ་དང་། སྨན་པ་ལ་རྒྱལ་པོས་བཀྱོན་ཏེ། སྔར་འོ་མ་ནི་དུག་ཡིན་ནོ་ཞེས་ཟེར་ན། ད་བཟའ༌[^97]བའི་སྨན་འོ་མ་དང་སྦྱར་རམ་ཞེས་ཟེར་བ་ལ། འོ་མ་འབའ་ཞིག་འཐུངས༌[^98]ན་ནི་དེ་སྐད་སྨྲས་པ་ཡང་བདེན་ན། ད་སྨན་དང་སྦྱར་ཏེ་ནད་ལ་ཕན་པའི་དུས་སུ་མི་གཏོང་བ༌[^99]ཡང་མ་ཡིན་ཏེ། དེ་བཞིན་གཤེགས་པའི་བསྟན་པ་ཡང་དེ་བཞིན་དུ་བལྟའོ།[^100] །

སངས་རྒྱས་བརྒྱ་སྟོང་མང་པོ་ལ་བསྙེན་བཀུར་བྱེད་པ། སངས་རྒྱས་བརྒྱ་སྟོང་མང་པོ་ལ་དགེ་བའི་རྩ་བ་བསྐྱེད་པ། སངས་རྒྱས་བརྒྱ་སྟོང་མང་པོས་ཡང་དག་པར་བསྟོད་པ་ནི། རང་གི་ལུས་དང་སེམས་ཤིན་ཏུ་བསྡུས་པས་དགེ་བའི་ལས་ཐམས་ཅད་ཀྱིས༌[^352]མཆོད་ཅིང་རིམ་གྲོ་བྱེད་པའོ། །དེ་རིམ་གྲོ་བྱེད་པ་ཡང་རྣམ་པ་བཅུར་དབྱེ་སྟེ། དེ་བཞིན་གཤེགས་པའི་རིང་བསྲེལ་དང་མཆོད་རྟེན་མངོན་དུ་བཞུགས་པ་ལ་མཆོད་ཅིང་རིམ་གྲོ་བྱེད་པ་དང་། ཡང་ན་དེ་བཞིན་གཤེགས་པ་གཞན་གྱི་རིང་བསྲེལ་དང་མཆོད་རྟེན་མངོན་དུ་བྱས་ཏེ། མཆོད་ཅིང་རིམ་གྲོ་བྱེད་པའོ། །ཡང་དེ་བཞིན་གཤེགས་པ་གཅིག་གི་མཆོད་རྟེན་ལ་ཕྱོགས་བཅུ་དུས་གསུམ་གྱི་དེ་བཞིན་གཤེགས་པའི་མཆོད་རྟེན་དུ་བསམས་ཏེ་མཆོད་ཅིང་རིམ་གྲོ་བྱས་ན་ཐམས་ཅད་ལ་རིམ་གྲོ་དང་མཆོད་པ་བྱས་པ་ཡིན་པ་དང་། དེ་ལྟ་བུའི་མཚན་ཉིད་དུ་བདག་ཉིད་མཆོད་པར་བྱེད་པ་དང་། ཡང་སྙིང་རྗེའི་སེམས་ཀྱིས༌[^353]དབུལ་ཕོངས་པ༌[^354]རྣམས་ལ་ཉམས་ཀྱིས་ཅི༌[^355]ནུས་སུ་སྦྱིན་པར་བྱས་ཏེ། ཐམས་ཅད་བདེ་བར་གྱུར་ཅིག་ཅེས་སྤྱོད་པ་དེ་གཞན་ལའང་བསྟབས༌[^356]ཤིང་མཆོད་པ་བྱེད་པ་དང་། བདག་ཇི་ལྟར་མཆོད་པ་དང་། རིམ་གྲོ་བྱེད་པ་བཞིན་གཞན་ཡང་བྱེད་དུ་འཇུག་པ་དང་། སྤོས་དང་མེ་ཏོག་དང་རིན་པོ་ཆེ་ལ་སོགས་པ་གུས་པར་འབུལ་བས་མཆོད་ཅིང་རིམ་གྲོ་བྱེད་པ་དང་། རྒྱ་ཆེན་པོའི་རིམ་གྲོ་དང་མཆོད་པ་བྱེད་པ་ནི་ཡུན་རིང་པོར་མཆོད་པ་དང་རིམ་གྲོ་བྱེད་པ་སྟེ། རྣམ་པར་དག་པའི་སེམས་ཀྱིས༌[^357]བྱང་ཆུབ་ཆེན་པོར་བསྔོས་ནས་རང་གི་ལུས་བརྒྱ་སྟོང་དུ་མས་དེ་བཞིན་གཤེགས་པ་གྲངས་མེད་པ་ལ་སྤོས་དང་མེ་ཏོག་ཚད་མེད་པས་མཆོད་ཅིང་རིམ་གྲོ་བྱས་ཏེ། ཚིག་སྙན་པ་དང་ཡིད་དུ་འོང་བ་གྲངས་མེད་པ་ཕྱོགས་བཅུར་ཁྱབ་པར་བྱས་ཏེ་མཆོད་ཅིང་རིམ་གྲོ་བྱེད་པ་དང་། ཡང་ང་རྒྱལ་དང་དྲེགས་པ་སྤངས་ཏེ་མཆོད་པ་རྣམ་པར་དག་པས་རིམ་གྲོ་བྱེད་པ་དང་། ཡང་དག་པའི་སྤྱོད་པས་མཆོད་པ་དང་རིམ་གྲོ་བྱེད་པ་ནི་ཚད་མེད་པ་བཞི་མངོན་དུ་བསྒོམས་ཏེ་སུ་ཅི༌[^358]འདོད་པ་རྣམས་ལ་དེ་བཞིན་དུ་སྟེར་བ་དང་། སྐད་ཅིག་ཙམ་ཡང་ཡང་དག་པ་ཉིད་དུ༌[^359]བཟོད་པ་དང་དད་པ་ལ་གནས་པ་ལས་མི་གཡོ་བར་མཚན་མ་མེད་པའི་སེམས་ཀྱིས༌[^360]བྱང་ཆུབ་སེམས་དཔའི་སྡོམ་པ་མི་གཏོང་བ་བསྡུ་བ་རྣམ་པ༌[^361]བཞིའི་སྤྱོད་པ་དམ་པས་མཆོད་ཅིང་རིམ་གྲོ་བྱེད་པ་ནི་སྔ་མའི་མཆོད་པ་བསྐྲུན༌[^362]ཅིང་དཔེར་ཡང་མི་བཟོད་དོ།
