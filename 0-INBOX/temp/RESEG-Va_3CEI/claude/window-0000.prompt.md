=== SYSTEM PROMPT ===
You are an expert in classical Tibetan Buddhist commentary (འགྲེལ་པ་) structure.

You are given a numbered list of blocks from a Tibetan verse commentary. A
rule-based segmenter has already cut them; most cuts are right. Your job is to
output the few merge/split operations that bring the blocks to the layout the
human editors of this vault use.

━━━ TARGET LAYOUT — one block per FUNCTIONAL UNIT ━━━

OPENER       A node's division announcement together with the first-child opener
             that follows it is ONE block:
               "<topic> ལ་གསུམ། A། B། C་འོ། །དང་པོ་ནི།"
             A sibling opener "གཉིས་པ་ <title> ནི།" is its own block.
ROOT QUOTE   A quoted root stanza is its own block. These blocks are tagged
             [VERSE]; they are protected — never include them in any operation.
EXPLANATION  The gloss that follows a quote ("ཞེས་པ་སྟེ། …", "ཞེས་པ་ནི། …", or a
             running explanation) is ONE block up to the next opener, quote or
             heading — even when it is long (100–250 syllables) and contains several
             sentence ends, a question and answer ("…ལོ། །གང་ལ་ན། …"), a side remark
             on a variant reading ("…ཞེས་འགྱུར་བཅོས་…"), a cross-reference
             ("འདི་དང་འོག་གི་ས་བཅད་…"), or a mantra cited in passing.
SECOND LEVEL A passage that re-reads the same stanza on another level — opening
             "སྦས་དོན་ནི།", "ངེས་དོན་ནི།", "ངེས་པའི་དོན་དུ།", "ཟབ་དོན་ནི།",
             "དེའི་ནང་གི་དོན་ལ།", "མཐར་ཐུག་གི་དོན་ནི།" or the like after the literal
             gloss — is its OWN block, never merged into the literal gloss before it
             (the editors keep the two readings apart). Within that passage, M1 applies.
FRAME        The namo line alone; each of the author's own verses one block;
             "སྨྲས་པ།" alone; the colophon ("ཅེས་ … སྦྱར་བའོ། །" + closing wishes) one block.

━━━ MERGE — adjacent blocks that are one unit ━━━

M1  CONTINUED EXPLANATION
    A block that goes on explaining the same quote/topic as the block before it —
    no new opener, no new quote, no new verse being treated — belongs to that block.
    This is the most common fix. Do NOT keep a cut just because a sentence ends.
    Exception: a SECOND LEVEL opener (see above) always starts a new block.
M2  INCOMPLETE SENTENCE
    A block ending in a connector (དང་། / ཞིང་། / ཅིང་། / ནས། / སྟེ། / ཏེ།) that
    the next block completes.
M3  OPENER CHAIN
    An enumeration block followed by "དང་པོ་ནི།" / "དང་པོ་ལ་ N།" (and further
    nested first-child enumerations) — merge them into one opener block.
M4  COLOPHON
    The parts of the closing colophon and its final wishes form one block.

━━━ SPLIT — one block that holds two units ━━━

S1  A new node opener (ordinal + title + "ནི།" or "ལ་ N།") buried mid-block:
    split before it.
S2  The treatment of a new verse/topic starts mid-block (e.g. "ཡང་ཕྱག་གང་ལ་འཚལ་ན"
    starting the next homage): split before it.
S3  An introductory opener "… ནི།" fused to the explanation of the PREVIOUS
    quote: split so the opener starts the next unit.

Never split a block only because it is long.

━━━ TOPIC SHIFT vs CONTINUATION (from the editors' corrections) ━━━

The editors' blocks are large (median ≈ 55 syllables; whole explanations of
100–250 syllables are normal). A sentence end is NOT a boundary. Inside one
explanation they cut only where the commentary turns to something new:
  START a new block at   "ཡང་ན་ …" (an alternative explanation)
                         "ཁ་ཅིག་ …", "གཞན་དག་ …" (another party's view)
                         "འོ་ན་ …" (the reply to an objection)
                         "དེ་སྐད་དུ་ …", "ཇི་སྐད་དུ་ …" (introducing a supporting quotation)
                         "དེ་ནས་ …" when it opens the next step of a procedure
                         "དཔེ་ …" / "དཔེར་ན་ …" when an example section begins
KEEP WITH the block before (merge into it):
                         "ད་ནི་ …" — a transitional "now …" line is not a new unit
                         (no heading or verse between them)
                         "ལེའུ་ … པའོ། །" — a chapter-closing line stays with the
                         explanation it closes
                         "ཞེས་ / ཅེས་ …" — the quotative closing the words just before it

━━━ HEADING / VERSE BLOCKS — always KEEP ━━━

Blocks tagged [HEADING] or [VERSE] are NEVER part of any operation.

━━━ OUTPUT FORMAT ━━━

A JSON array of operations. Blocks not mentioned are kept as-is.

[
  {"op": "merge", "blocks": [N, M]},
  {"op": "merge", "blocks": [N, M, P]},
  {"op": "split", "block": N, "after": "<verbatim unique substring ending at split point>"},
  {"op": "split", "block": N, "after": ["<sub1>", "<sub2>", "<sub3>"]}
]

Rules for the output:
- Block numbers are CONTINUOUS and INCLUDE heading and verse blocks. You may only
  merge blocks with consecutive numbers (N and N+1). Never merge across a heading
  or a verse block, and never propose a merge whose numbers skip over one.
- Each block number appears in AT MOST ONE operation.
- For each "after" substring: copy a verbatim slice from the block that ends exactly
  at the split point and is UNIQUE within that block (10–20 characters is usually enough).
- If nothing needs to change in this window, output: []
- Output ONLY the JSON array. No explanation, no commentary, no code fences.

ཤཱ་རིའི་བུ་ང་སྔོན་གྱི་དུས་ན་སེམས་ཅན་ཐམས་ཅད་ང་བཞིན་དུ་བླ་ན་མེད་པ་ཡང་དག་པར་རྫོགས་པའི་སངས་རྒྱས་སུ་གྲུབ་པར་བྱའོ་ཞེས་སྨོན་ལམ་བཏབ་པས། [^10]སྨོན་ལམ་དེ་ཉིད༌[^11]གྲུབ་སྟེ། སེམས་ཅན་དགྲོལ་བ་ལ་མངའ་བརྙེས་པ་དང་། སྔོན་གྱི་དུས་ན་དམ་བཅས་ཤིང༌[^12]སྨོན་ལམ་བཏབ་པ་དེ་ཉིད་སྤྱོད་པ་དང་འབྲས་བུ་མཐུན་པར་གྱུར་པ་བཞིན་སེམས་ཅན་ཐམས་ཅད་ཀྱང་སྤྱོད་པ་དེ་ལ་གཟུད་པའི་ཕྱིར་དོན་དེ་བསྟན་ཏོ། །

[Block 16 [HEADING]]
#### ཚོལ་བ། ^1-1-3-0

[Block 17]
དེ་ལ་ཚོལ་བའི་རྒྱུ་ནི་མོས་པར༌[^13]བྱ་བའི་ལེའུ་ལས།

[Block 18]
ང་སྔོན་འདས་པའི་དུས་ན་དམ་པའི་ཆོས་འདི༌[^14]འདོད་པའི་ཕྱིར་བསྐལ་པ་མང་པོར་སྐྱོ་མི་ཤེས་པས་ཚོལ་ཞིང་སྔོན་རྒྱལ་པོ་མཛད་པའི་ཚེ་ཕྱོགས་བཞིར་དུང་བུས་རྔ་བརྡུངས་ཏེ་ཆོས་ཚོལ་བ་ན་དྲང་སྲོང་ལས་ཆོས་མཉན་པའི་ཕྱིར་རིམ་གྲོ་བཀུར་སྟི་གྲངས་མེད་པར་བྱེད་པ་ནི་དགེ་བའི་བཤེས་གཉེན་ལས་ཆོས་ཐོས་པར་ཚོལ་བའི་རྒྱུ་དང་གླེང་གཞིར༌[^15]སྟོན་པའོ། །

[Block 19 [HEADING]]
#### འཛིན་པ། ^1-1-4-0

[Block 20]
དེ་ལ་འཛིན་པའི་རྒྱུ་ནི་སྔར་སྨོས་པའི་ཤིན་ཏུ་ཟབ་པ་བརྒྱད་ལས་དང་པོར་སྔོན་སངས་རྒྱས་བཅོམ་ལྡན་འདས་སངས་རྒྱས་བརྒྱ་སྟོང་གྲངས་མེད་པ་ལ་རིམ་གྲོ་དང་བསྙེན་བཀུར་བྱས་པ་སྟེ། འདི་ལ་བྱང་ཆུབ་སེམས་དཔའ་ཆུ་བོ་གང་གཱའི་བྱེ་མ་སྙེད་ཀྱི་སངས་རྒྱས་མཆོད་པར་གྱུར་པ༌[^16]ནས། རིམ་གྱིས་སངས་རྒྱས་མང་པོ་ལ་བསྙེན་བཀུར་བྱས་པ་དང་། དགེ་བའི་བཤེས་གཉེན་དང་ཡུན་རིང་དུ་འགྲོགས་པའི་ཕྱིར་མདོ་འཛིན་ཅིང་ཀློག་པས༌[^17]དབང་པོ་དྲུག་རྣམ་པར་དག་པ་དང་། སངས་རྒྱས་མང་པོ་ལ་རྟག་ཏུ་བསྙེན་བཀུར་བྱེད་པར་འགྱུར་བའི་ཕྱིར། འཛིན་ཅིང་ཀློག་པ་ཉིད་ཤིན་ཏུ་ཟབ་པར་བསྟན་ཏོ། །

[Block 21 [HEADING]]
#### ལྟས། ^1-1-5-0

[Block 22]
དེ་ལ་ལྟས་ནི་སངས་རྒྱས་བཅོམ་ལྡན་འདས་བླ་ན་མེད་པའི་འབྲས་བུ་བརྙེས༌[^18]ནས་མདོ་སྡེ་འདི་བཤད་པར་དགོངས་ཏེ། སྔར་བྱང་ཆུབ་སེམས་དཔའ་རྣམས་ལ་ལྟས་བསྟན་པའི་ཕྱིར་ལྷའི་མེ་ཏོག་འབྲུལ་བ༌[^19]དང་། ས་རྣམ་པར་གཡོ་བ་དང་། འོད་ཀྱིས་སྣང་བར་མཛད་པས་འཁོར་མང་པོ་ཞལ་དུ་ལྟ་ཞིང་དགའ་བ་དང་སྤྲོ་བའི་སེམས་ཀྱིས༌[^20]དེང་ནི་བཅོམ་ལྡན་འདས་ཀྱིས༌[^21]དམ་པའི་ཆོས་པུཎྜ་རཱི་ཀ་བཤད་པར་དགོངས་པའི་ལྟས་མང་པོ་སྟོན་པར༌[^22]མཛད་པ་སྙམ་དུ་སེམས་པ་ལ་སོགས་པ་བསམ་པ་བསྐྱེད་པའི༌[^23]ལྟས་མདོ་སྡེ་གཞན་བཤད་པ་དང་མི་འདྲ་བར་སྟོན་པ་ནི་ལྟས་ཆེན་པོའོ། །

[Block 23]
དེ་ལ་བཤད་པའི་རྒྱུ་ནི་དེ་བཞིན་གཤེགས་པ་འཇིག་རྟེན་དུ་འབྱུང་བའང་དོན་ཆེན་པོ་གཅིག་གི་ཕྱིར་ཞེས་འབྱུང་ཞེས་བྱ་བ་ནས་གནས་དེར་ཉན་ཐོས་ཀྱི་འཁོར་རྣམས་མེད་དེ། བྱང་ཆུབ་སེམས་དཔའི༌[^24]འཁོར་འབའ་ཞིག་ལ་ཆོས་སྟོན་ཏེ།[^25] རྣམ་པ་ཐམས་ཅད་མཁྱེན་པའི་ཡེ་ཤེས་ཐོབ་པའི་བར་དུ་འགྱུར་བ་ལ་སོགས་པའི་བར་དུ་རྒྱས་པར་བསྟན་ཏེ། དུས་གསུམ་གྱི་སངས་རྒྱས་བཅོམ་ལྡན་འདས་ཀུན་གྱིས༌[^26]ངེས་པའི་དོན་ཐེག་པ་ཆེན་པོ་སྟོན་པའང་དུས་དང་དབང་པོ་སྨིན་པར་སྟོན་པ་དེ་ནི་བཤད་པའོ། །

[Block 24 [HEADING]]
### གླེང་སློང་བ། ^1-2-0

[Block 25]
དེ་ལ་བཤད་པར་གླེང་སློང་བ༌[^27]ཇི་ལྟར་མདོ་ལས་གསུངས་པ་བཞིན་ཏེ། བཅོམ་ལྡན་འདས་དང་པོ་བལྟམས་པའི་ཚེ་ཕྱོགས་བཞིར་གོམ་པ་བདུན་བདུན་བོར་ཏེ། འོད་ཆེན་པོས་ཕྱོགས་སུ་སྣང་བར་མཛད་ནས་ཀུན་ལ་སེང་གེའི་སྒྲ་སྒྲོགས་པར༌[^28]དགོངས་པ་མཐའ་ཡས་པའི་སེམས་ཅན་ཐམས་ཅད་བསྒྲལ་བར་ཐུགས་དམ་བཅས་ཏེ། སྐུ་ཁད་ཀྱིས་སྐྱེས་ནས་མཁར་གྱི་སྒོ་བཞིར་གཤེགས་ཤིང་འཇིག་རྟེན་གདུལ༌[^29]བའི་ལྟས་གཟིགས་ན༌[^30]བླ་ན་མེད་པའི་ལམ་ཚོལ་བའི་ཕྱིར་ཁབ་ནས་བྱུང༌[^31]ཞིང་དཀའ་ཐུབ་རྣམ་པ་སྣ་ཚོགས་མཛད་དེ། མངོན་པར་རྫོགས་པར་སངས་རྒྱས༌[^32]བྱང་ཆུབ་ཀྱི་ཤིང་དྲུང་དུ་རྡོ་རྗེ༌[^33]གདན་ལ་བཞུགས་པའི་བར༌[^34]འཁོར་མང་པོར༌[^35]

[Block 26]
དང་པོ་ཆོས་སྟོན་པ་སྟེ། དབང་པོ་མ་སྨིན་པ་རྣམས་ལ་བཀྲི༌[^36]བ་དང་བཅས་པའི་ཆོས་སྟོན་པ་དང་། མདོ་སྡེ་འདི་སྟོན་པའི་དུས་ནི་སེམས་ཅན་དབང་པོ་སྨིན་པ་རྣམས་ལ་ངེས་པའི་དོན་བསྟན་པར༌[^37]དགོངས་ཏེ། འཕགས་པ་ཤཱ་རིའི་བུ་དང་། བྱམས་པ་བྱང་ཆུབ་སེམས་དཔའ་དང་། འཇམ་དཔལ་གཞོན་ནུར་གྱུར་པས་གསོལ་བའི་དོན་རྣམས་གཅིག་ཏུ་ངེས་པར་སྟོན་པ་ལ་སོགས་པ་ནི་གླེང་བསླང༌[^38]ནས་ཆོས་སྟོན་པའོ། །

[Block 27 [HEADING]]
### ཐེ་ཚོམ་དུ་འཛིན་པ་བསལ་བ། ^1-3-0

[Block 28]
ཐེ་ཚོམ་བསལ་བ་ནི་བཅོམ་ལྡན་འདས་མངོན་པར་རྫོགས་པར་སངས་རྒྱས་ན་བྱང་ཆུབ་སེམས་དཔའ་རྣམས་བླ་ན་མེད་པ་ཡང་དག་པར་རྫོགས་པའི་སངས་རྒྱས་སུ་འགྲུབ་པར་ལུང་སྟོན་པ༌[^39]མཛད་ཀྱི། ཉན་ཐོས་རྣམས་ནམ་དུའང༌[^40]བླ་ན་མེད་པའི་བྱང་ཆུབ་ཐོབ་པར་ལུང་མ་བསྟན་པའི་ཕྱིར། འཕགས་པ་ཤཱ་རིའི་བུ་ལ་སོགས་པ༌[^41]ཉན་ཐོས་རྣམས་ལ༌[^42]བླ་ན་མེད་པའི་བྱང་ཆུབ་ཀྱི་རྒྱུ་མེད་དོ་སྙམ་དུ་ཐེ་ཚོམ་དུ་གྱུར་པ་དང་། བྱང་ཆུབ་སེམས་དཔའ་རྣམས་ཀྱིས་ཀྱང་ཉན་ཐོས་རྣམས་ནམ་དུ་ཡང་སངས་རྒྱས་སུ་གྲུབ་པའི༌[^43]རྒྱུ་མེད་པ་སྙམ་དུ་སེམས་པ་དང་། ཁ་ཅིག་མ་ངེས་པའི་རང་བཞིན་ཅན་རྣམས་ཀྱང་ཐེ་ཚོམ་དུ་གྱུར་པ་དེ་བསལ་བའི་ཕྱིར་མདོ་སྡེ་འདི་ལས་ཉན་ཐོས་དང་བྱང་ཆུབ་སེམས་དཔའ་ལ་སོགས་ཏེ། མདོ་སྡེ་འདི་ལ་ཆུང་ངུ་ན་ཚིགས་སུ་བཅད་པ་གཅིག༌[^44]ཐོས་པ་ཙམ་གྱིས་ཀྱང་བླ་ན་མེད་པའི་སངས་རྒྱས་སུ་འགྲུབ་པར་ལུང་བསྟན་པས་དེ་དག་གི་ཐེ་ཚོམ་བསལ་ཏོ། །

[Block 29 [HEADING]]
### ལུང་སྟོན་པའི་སྤྱོད་པ་བསྟན་པ། ^1-4-0

[Block 30]
དེ་ལ་ལུང་བསྟན་པ་དང་སྤྱོད་པ་ཡང་དང་པོ་མངོན་པར་སངས་རྒྱས་པ་ནས་དེའི་བར་དུ་ཉན་ཐོས་ཀྱི་སྤྱོད་པས་མངོན་པར༌[^45]རྫོགས་པར་འཚང་རྒྱ་བར་ལུང་མ་བསྟན་གྱི།[^46] འདིར་ཐབས་ཀྱིས་དྲང་བའི༌[^47]དུས་ལ་བབ་པར༌[^48]ལུང་བསྟན་པའི་ཕྱིར་རོ། །

[Block 31]
སྤྱོད་པ་ནི་བྱང་ཆུབ་སེམས་དཔའི་ཐེག་པ༌[^49]གཅིག་པ་འདིའི་ནང་ནས་འཆད་པའི་ཕྱིར་ཏེ། མདོ་འདི་ཉིད་ལས་ཀྱང་རྒྱལ་བའི་སྲས་སེམས་ཞི་བ་དུལ་བ་དབང་པོ་རྣོ་བ་སངས་རྒྱས་མང་པོ་ལ་དགེ་བའི་རྩ་བ་བསྐྲུན་པ་རྣམས་ལ་ཐེག་པ་ཆེན་པོའི་སྤྱོད་པ་འདི་བསྟན་པའི་ཕྱིར་མདོ་འདི་གསུངས་སོ། །

[Block 32 [HEADING]]
### ཚེ་འདི་དང་གཞན་དུ་ཕན་གདགས་པའི་དོན་བསྟན་པ། ^1-5-0

[Block 33 [HEADING]]
#### ཚེ་འདི་ལ་ཕན་པ། ^1-5-1-0

[Block 34]
དེ་ལ་ཚེ་འདི་ལ་ཕན་པ་ནི་དམ་པའི་ཆོས་པུཎྜ་རཱི་ཀ་འདི་འཕགས་པ་དང་མ་རབས་སུ་གྱུར་པ་གང་གིས་ཐོས་ཀྱང་ཕན་འདོགས་པར་གྱུར་པའི་ཕྱིར་རོ།[^50] །དེ་ལ་ཡང་རྣམ་པ་གཉིས་ཏེ། འབྲས་བུ་ཐོབ་པར་ལུང་སྟོན་པས་ཕན་འདོགས་པ་དང་། འཕྲལ་དུ་མངོན་པར་གྲུབ་པར༌[^51]བྱེད་པས་ཕན་འདོགས་པའོ། །

[Block 35 [HEADING]]
##### འབྲས་བུ་ཐོབ་པར་ལུང་སྟོན་པས་ཕན་འདོགས་པ། ^1-5-1-1-0

[Block 36]
འབྲས་བུ་ཐོབ་པར་ལུང་སྟོན་པ་ནི་འཕགས་པ་ཉན་ཐོས་ལྔ༌[^52]བརྒྱ་བླ་ན་མེད་པའི་བྱང་ཆུབ་ཏུ་ལུང་བསྟན་པས་ཚེ་འདི་ལ་ཕན་འདོགས་པའོ། །

[Block 37]
དེ༌[^53]སྟོན་པ་ཡང་རྣམ་པ་དྲུག་སྟེ། ཤཱ་རིའི་བུ་ལ་སོགས་པ༌[^54]ཉན་ཐོས་ཆེན་པོ་བཞི༌[^55]མཚན་མི་མཐུན་ཏེ་སོ་སོར་ལུང་བསྟན་པ༌[^56]རྣམ་པར་ཕྱེ་སྟེ། ལུང་བསྟན་པ་དང་། འཕགས་པ་གང་པོ་ལ་སོགས་པ་ཉན་ཐོས་ལྔ་བརྒྱ་མཚན་མཐུན་པར་ལུང་བསྟན་པས་སྤྱིར་ལུང་བསྟན་པ་དང་། སློབ་པ་དང་མི་སློབ་པ་ཕལ་ཆེར༌[^57]མང་པོ་གཞན་རྣམས་དབང་པོ་ཞན་པའི་ཕྱིར་ཕྱིས་ལུང་བསྟན་པ་དང་། ལྷས་བྱིན་ལུང་བསྟན་པས་བྱམས་སྡང་མེད་པར་ལུང་བསྟན་པ་དང་། རབ་ཏུ་བྱུང་བ་དང་། ཁྱིམ་ན་གནས་པ་དང་། ལྷའི་བུ་མོ་ལ་སོགས་པ་ལུང་བསྟན་པའི་ཕྱིར་དང་། བཀོལ་བ་མེད་པར༌[^58]སྟོན་པ་སྟེ།[^59] དེ་ནི་མདོ་སྡེ་འདི་བཤད་པའི་དུས་སུ་དེ་བཞིན་གཤེགས་པ་ཉིད་ཀྱིས༌[^60]ལུང་བསྟན་པའོ། །

[Block 38]
རྟག་ཏུ་མི་བརྙས་པར་བྱང་ཆུབ་སེམས་དཔའ་ལ་སེམས་ཅན་ཐམས་ཅད་ནི་དེ་བཞིན་གཤེགས་པའི་རང་བཞིན་ཅན་ནོ་ཞེས་རྒྱུ་ལ་དགོངས་ཤིང་སྟོན་པ་སྟེ། དེ་ལ་གོང་གི་ལྔ་ནི་ཚེ་འདི་ལ་ཕན་པའི་སྒོ་ནས་ལུང་བསྟན་པའོ། །

[Block 39 [HEADING]]
##### འཕྲལ་དུ་མངོན་པར་གྲུབ་པར་བྱེད་པས་ཕན་འདོགས་པ། ^1-5-1-2-0

[Block 40]
འཕྲལ་དུ་མངོན་པར་འགྱུར་བར་བྱེད་པས་ཕན་པ་ནི་ཇི་ལྟར་མོས་པར་བྱ་བའི་ལེའུ་ལས་ཀླུའི་རྒྱལ་པོའི་བུ་མོ་དམ་པའི་ཆོས་འདི་ཐོས་པ་ཉིད་ཀྱིས་བླ་ན་མེད་པའི་འབྲས་བུ་ཐོབ་པ་འཁོར་བརྒྱད་པོ་ཐམས་ཅད་ཀྱིས་མངོན་དུ་མཐོང་བའི་ཕྱིར་ཀུན་གྱི་དགའ་བ་དང་མགུ་བ་གྲངས་མེད་པ་ཐོབ་པ་ལྟ་བུ་སྟེ། མདོ་སྡེ་འདི་བཤད་པའི་ཚེ་ལྷ་དང་མི་དང་ལྷ་མ་ཡིན་ལ་སོགས་པས་གཟུངས་དང་ཏིང་ངེ་འཛིན་གྲངས་མེད་པ་ཐོབ་པ་དང་། མིག་རྣམ་པར་དག་ཅིང་བྱང་ཆུབ་སེམས་དཔའ་ཀུན་དུ་བཟང་པོའི་སྤྱོད་པ་ལ་འཇུག་པ་ལ་སོགས་པ་ཕན་འདོགས་པ་མང་པོ་ནི་ཚེ་འདི་ཉིད་ལ་ཕན་པའོ། །
