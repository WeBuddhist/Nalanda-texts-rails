=== SYSTEM PROMPT ===
You are an expert in classical Tibetan Buddhist commentary (འགྲེལ་པ་) structure.

You are given a numbered list of blocks from a Tibetan verse commentary. A
rule-based segmenter has already cut them; most cuts are right. Your job is to
output the few merge/split operations that bring the blocks to the layout the
human editors of this vault use.

━━━ TARGET LAYOUT — one block per FUNCTIONAL UNIT ━━━

OPENER       A node's division announcement together with the first-child opener
             that follows it is ONE block:
               "<topic> ལ་གསུམ། A། B། C་འོ། །དང་པོ་ནི།"
             A sibling opener "གཉིས་པ་ <title> ནི།" is its own block.
ROOT QUOTE   A quoted root stanza is its own block. These blocks are tagged
             [VERSE]; they are protected — never include them in any operation.
EXPLANATION  The gloss that follows a quote ("ཞེས་པ་སྟེ། …", "ཞེས་པ་ནི། …", or a
             running explanation) is ONE block up to the next opener, quote or
             heading — even when it is long (100–250 syllables) and contains several
             sentence ends, a question and answer ("…ལོ། །གང་ལ་ན། …"), a side remark
             on a variant reading ("…ཞེས་འགྱུར་བཅོས་…"), a cross-reference
             ("འདི་དང་འོག་གི་ས་བཅད་…"), or a mantra cited in passing.
SECOND LEVEL A passage that re-reads the same stanza on another level — opening
             "སྦས་དོན་ནི།", "ངེས་དོན་ནི།", "ངེས་པའི་དོན་དུ།", "ཟབ་དོན་ནི།",
             "དེའི་ནང་གི་དོན་ལ།", "མཐར་ཐུག་གི་དོན་ནི།" or the like after the literal
             gloss — is its OWN block, never merged into the literal gloss before it
             (the editors keep the two readings apart). Within that passage, M1 applies.
FRAME        The namo line alone; each of the author's own verses one block;
             "སྨྲས་པ།" alone; the colophon ("ཅེས་ … སྦྱར་བའོ། །" + closing wishes) one block.

━━━ MERGE — adjacent blocks that are one unit ━━━

M1  CONTINUED EXPLANATION
    A block that goes on explaining the same quote/topic as the block before it —
    no new opener, no new quote, no new verse being treated — belongs to that block.
    This is the most common fix. Do NOT keep a cut just because a sentence ends.
    Exception: a SECOND LEVEL opener (see above) always starts a new block.
M2  INCOMPLETE SENTENCE
    A block ending in a connector (དང་། / ཞིང་། / ཅིང་། / ནས། / སྟེ། / ཏེ།) that
    the next block completes.
M3  OPENER CHAIN
    An enumeration block followed by "དང་པོ་ནི།" / "དང་པོ་ལ་ N།" (and further
    nested first-child enumerations) — merge them into one opener block.
M4  COLOPHON
    The parts of the closing colophon and its final wishes form one block.

━━━ SPLIT — one block that holds two units ━━━

S1  A new node opener (ordinal + title + "ནི།" or "ལ་ N།") buried mid-block:
    split before it.
S2  The treatment of a new verse/topic starts mid-block (e.g. "ཡང་ཕྱག་གང་ལ་འཚལ་ན"
    starting the next homage): split before it.
S3  An introductory opener "… ནི།" fused to the explanation of the PREVIOUS
    quote: split so the opener starts the next unit.

Never split a block only because it is long.

━━━ TOPIC SHIFT vs CONTINUATION (from the editors' corrections) ━━━

The editors' blocks are large (median ≈ 55 syllables; whole explanations of
100–250 syllables are normal). A sentence end is NOT a boundary. Inside one
explanation they cut only where the commentary turns to something new:
  START a new block at   "ཡང་ན་ …" (an alternative explanation)
                         "ཁ་ཅིག་ …", "གཞན་དག་ …" (another party's view)
                         "འོ་ན་ …" (the reply to an objection)
                         "དེ་སྐད་དུ་ …", "ཇི་སྐད་དུ་ …" (introducing a supporting quotation)
                         "དེ་ནས་ …" when it opens the next step of a procedure
                         "དཔེ་ …" / "དཔེར་ན་ …" when an example section begins
KEEP WITH the block before (merge into it):
                         "ད་ནི་ …" — a transitional "now …" line is not a new unit
                         (no heading or verse between them)
                         "ལེའུ་ … པའོ། །" — a chapter-closing line stays with the
                         explanation it closes
                         "ཞེས་ / ཅེས་ …" — the quotative closing the words just before it

━━━ HEADING / VERSE BLOCKS — always KEEP ━━━

Blocks tagged [HEADING] or [VERSE] are NEVER part of any operation.

━━━ OUTPUT FORMAT ━━━

A JSON array of operations. Blocks not mentioned are kept as-is.

[
  {"op": "merge", "blocks": [N, M]},
  {"op": "merge", "blocks": [N, M, P]},
  {"op": "split", "block": N, "after": "<verbatim unique substring ending at split point>"},
  {"op": "split", "block": N, "after": ["<sub1>", "<sub2>", "<sub3>"]}
]

Rules for the output:
- Block numbers are CONTINUOUS and INCLUDE heading and verse blocks. You may only
  merge blocks with consecutive numbers (N and N+1). Never merge across a heading
  or a verse block, and never propose a merge whose numbers skip over one.
- Each block number appears in AT MOST ONE operation.
- For each "after" substring: copy a verbatim slice from the block that ends exactly
  at the split point and is UNIQUE within that block (10–20 characters is usually enough).
- If nothing needs to change in this window, output: []
- Output ONLY the JSON array. No explanation, no commentary, no code fences.

མདོ་ལས་དེ་ཅིའི་ཕྱིར་ཞེ་ན་ཞེས་པ་ནས་ཤེས་པར་དཀའ་བའི་ཆོས་ཤེས་པ་རྣམས་སོ་ཞེས་པའི་བར་དུ་ནི་འདིར་གཞུང་ལས་ཤིན་ཏུ་ཟབ་པ་བརྒྱད་འབྱུང་བ་བསྟན་ཏེ། ཅིའི་ཕྱིར་ཞེས་དྲིས་པ་ནི་ཐེག་པ་རྣམ་གསུམ་རྣམ་པར་གྲོལ་བ་ཐོབ་པར་འདྲ་ན་ཁྱད་པར་ཅི་ཡོད་ཅེས་པ་ལ་ཤིན་ཏུ་ཟབ་པ་འདི་དག་གིས་འཕགས་པ་ཉན་ཐོས་པ་ལས་ཁྱད་པར་དུ་བསྟན་པའི་ཕྱིར་ཤིན་ཏུ་ཟབ་པའི་ཚིག་གི༌[^785]དོན་རྣམ་པ་བརྒྱད་སྟོན་ཏེ། སངས་རྒྱས་མང་པོ་ལ་བསྙེན་བཀུར་ཞེས་པ་ནི་གཟུང་ཞིང་འཛིན་པ་དང་། ཀློག་ཅིང་འདོན་པ་ཤིན་ཏུ་ཟབ་པ་བསྟན་ཏེ། བཅོམ་ལྡན་འདས་སྔོན་བསྐལ་པ་གྲངས་མེད་པ་གསུམ་གྱི་བར་དུ་སངས་རྒྱས་ཆུ་བོ་གང་གཱའི་བྱེ་མ་སྙེད་ལ་བསྙེན་བཀུར་བྱས་ཤིང་ལུང་མནོས་པའི་ཕྱིར་ཤིན་ཏུ་ཟབ་པའོ། །

[Block 786]
བྱང་ཆུབ་ཀྱི་སྤྱད་པ་སྤྱོད་ཅེས་པ་ནི་མངོན་པར་སྒྲུབ་པ་ཤིན་ཏུ་ཟབ་པ་སྟོན་པ་སྟེ། དེ་བཞིན་གཤེགས་པ་རྣམས་བསོད་ནམས་དང་ཡེ་ཤེས་ཀྱི་ཚོགས་གཉིས༌[^786]རྫོགས་པས་མངོན་པར་བྱང་ཆུབ་པ་སྟོན་གྱི་ཉན་ཐོས་པ་རྒྱུ་སྒྲུབ་པ༌[^787]ཙམ་དུ་ཟད་པ་མ་ཡིན་པར་བསྟན་པའི་ཕྱིར་ཤིན་ཏུ་ཟབ་པ་འདི་བསྟན་ཏོ། །

[Block 787]
བརྩོན་འགྲུས་སྤྱད་པ༌[^788]རྣམས་ཞེས་པ་ནི་འབྲས་བུ་སྒྲུབ་པ་ཤིན་ཏུ་ཟབ་པ་སྟོན་ཏེ།[^789] བརྟུན་པའི་བརྩོན་འགྲུས་ཀྱིས༌[^790]སྐྱོ་བ་དང་དུབ་པ་མེད་པར་བསྒྲུབས་པས༌[^791]འབྲས་བུ་དམ་པ་འཐོབ་པ་ནི་འབྲས་བུ་ཤིན་ཏུ་ཟབ་པའོ། །

[Block 788]
ངོ་མཚར་དང་ཞེས་པ་ནི་བསོད་ནམས་སྤེལ་བའི་སེམས་ཤིན་ཏུ་ཟབ་པ་སྟེ། བྱང་ཆུབ་སེམས་དཔའ་དེ་དཀའ་བ་སྤྱོད་ཅིང་བརྩོན་པ་མི་གཏོང་བའི་སེམས་ཕྱོགས་ཐམས་ཅད་དུ་གྲགས་པ་གཞན་གྱིས༌[^792]ཐོས་ཏེ་ངོ་མཚར་དུ་གྱུར་པ་ཤིན་ཏུ་གྲགས་པ་ཟབ་པའོ། །

[Block 789]
རྨད་ཀྱི་ཆོས་དང་ལྡན་པ་ཞེས་པ་ནི་ཆོས་དམ་པས་ཚིམ་པའི་སེམས་ཤིན་ཏུ་ཟབ་པ་སྟེ། སྔོན་མ་ཐོབ་པའི་ཆོས་དམ་པ་མངོན་དུ་གྱུར་པས་སེམས་དགའ་བ་དང་མོས་པ་སྐྱེས་པ་ཤིན་ཏུ་ཟབ་བོ། །ཤེས་པར་དཀའ་བའི་ཆོས་ཤེས་པ་ནི་བླ་ན་མེད་པ་ཤིན་ཏུ་ཟབ་པ་སྟེ། ཤེས་པར་དཀའ་བའི་ཆོས་དེ་དག་དེ༌[^793]བཞིན་གཤེགས་པ་ཉག་གཅིག་གིས་ཐུགས་སུ་ཆུད་པས་བླ་ན་མེད་པའི་ཟབ་པའོ།[^794] །ལྡེམ་པོ་དག་ཤེས་པར་དཀའོ་ཞེས་པ་ནི་འཇུག་པ་ཤིན་ཏུ་ཟབ་པ་སྟེ། མིང་དང་ཚིག་དང་། དོན་ཤིན་ཏུ་ཤེས་པར་དཀའ་བའི་ཕྱིར་དེ་བཞིན་གཤེགས་པ་རང་གིས༌[^795]རིག་པ་སྟེ། དེ་ཡང་ཤིན་ཏུ་འཇུག་པར་དཀའ་བ་དང་། བསྙད༌[^796]པར་དཀའ་བའོ། །

[Block 790]
འཇུག་པ་ནི་བདག་ཉིད་འཇུག་པའོ། །

[Block 791]
བཤད་པ་ནི་གཞན་ལ་བཤད་པར་དཀའ་བ་སྟེ། དེ་གཉི་ག་དེ་བཞིན་གཤེགས་པ་ཉག་གཅིག་གིས་སྤྱོད་ཅེས་པའོ། །

[Block 792]
ཉན་ཐོས་དང་རང་སངས་རྒྱས་ཀྱིས་ཤེས་པར་དཀའ་བ་ནི་གནས་པ་ཤིན་ཏུ་ཟབ་པ་བསྟན་པ་སྟེ། ཕྱི་ནང་གི་སྤྱོད་པ་ཐུན་མོང་མ་ཡིན་པ་བསྟན་པའོ། །

[Block 793]
མདོ་ལས་ཤཱ་རིའི་བུ་དེ་བཞིན་གཤེགས་པ་ཞེས་པ་ནས་རྣམ་པ་སྣ་ཚོགས་ཀྱི་ཐབས་མཁས་པ་དང་། ཡེ་ཤེས་དང་མཐོང་བ་དང་། རྒྱུ་དང་གཞི་དང་། དམིགས་པ་དང་། ངེས་པའི་ཚིག་དང་ཞེས་པའི་བར་དུ་ནི་སྔར་བཤད་པ་དང་ཆུད་པར་བྱ་བའི་ཆོས་དམ་པ་བསྟན། དེའི་འོག་ཏུ་དེ་བཞིན་གཤེགས་པས་དགོངས་པ་དང་སྟོན་པའི་ཆོས་སྨྲ་བ་ཉིད་ཀྱི་ཡོན་ཏན་འཆད་དེ། དེ་བཞིན་གཤེགས་པ་སྟོན་པའི་རྒྱུ་ཕུན་སུམ་ཚོགས་པའོ། །

[Block 794]
ཐབས་མཁས་པ་དང་། ཡེ་ཤེས་མཐོང་བ་དང་རྒྱུ་དང་ངེས་པའི་ཚིག་ཅེས་པ༌[^797]ཚིག་འོག་མས་གོང་མ་འབྲེལ༌[^798]ཏེ། བཅོམ་ལྡན་འདས་མངོན་པར་བྱང་ཆུབ་ནས་སེམས་ཅན་དྲང་བའི་ཆེད་དུ་གནས་དེ་དང་དེ་དག་ཏུ་དཔེ་དང་ཐབས་རྣམ་པ་སྣ་ཚོགས་ཀྱིས་ཆོས་བསྟན་ཏེ། སེམས་ཅན་ཆགས་པའི་གནས་ལས༌[^799]དགྲོལ་བར་མཛད་དོ། །

[Block 795]
དང་པོ་ཚིག་དེ་བཞི་སོ་སོར་དགྲོལ་བ་དང་དེའི་འོག་ཏུ་ཚིག༌[^800]རྣམས་ལན༌[^801]གསུམ་ཙམ་དུ་བཟླས་ཏེ་འཆད་པའོ། །

[Block 796]
དེ་ཡང་དེ་བཞིན་གཤེགས་པའི་ཡོན་ཏན་རྣམ་པ་བཞི་རྫོགས་པར་བྱ་བ་སྟེ། སེམས་ཅན་བསྒྲལ༌[^802]བའི་ཕྱིར་བྱོན་པ་དང་བཞུད་པ་སྟོན་ཅིང་ཐབས་མཁས་པ་རྫོགས་པར་མཛད་པ་སྟེ།

[Block 797]
དང་པོ་དགའ་ལྡན་གནས་ན་གནས་པ་དང་མྱ་ངན་ལས་འདས་པར་གཤེགས་པའི་བར་དུ་སེམས་ཅན་ལ་ཕན་པའི་དོན་རྣམ་པ་སྣ་ཚོགས་མཛད་པ་ནི་ཐབས་མཁས་པའོ། །

[Block 798]
ཡེ་ཤེས་མཐོང་བ་ཞེས་པ་ནི་ཆོས་རྣམ་པར་དག་པའི་རྒྱུ་བསྟན་པ་སྟེ། ཡེ་ཤེས་དང་གཟིགས་པ༌[^803]མངའ་བའི་ཕྱིར་ཆོས་རྣམ་པར་དག་པ་གཟིགས་ཤིང་མཁྱེན་པར་འོས་པ་སྟེ། སྔར་ནི་ལུས་ཀྱི་སྒོ་ནས་སེམས་ཅན་གྱི་དོན་མཛད་པ་བསྟན། འདིར་ནི་རིགས་པ༌[^804]དང་བཤད་པའི་སྒོ་ནས་སྟོན་པའོ། །

[Block 799]
ཡེ་ཤེས་མཐོང་བ་ཞེས་པ་ནི་ཡོན་ཏན་ཕུན་སུམ༌[^805]ཚོགས་པའི་མཐའ་བསྟན་ཏེ། ཆོས་སྟོན་པ་ལ་དབང་པོ་དང་མཐུན་པ་ཅི་དང་ཅིས་འདུལ་བ་མཁྱེན་པ༌[^806]གཟིགས་ཤིང་ཆོས་སྟོན་པའོ། །

[Block 800]
ངེས་པའི་ཚིག་ཅེས་པ་ནི་སོ་སོ་ཡང་དག་པར་རིག་པ་བཞིས་ཅི་རིགས་པར༌[^807]ཆོས་སྟོན་པ་སྟེ། དེ་ལ་དང་པོ་སྤྲུལ་པའི་སྐུས་ཐབས༌[^808]སྣ་ཚོགས་ཀྱིས་ཆོས་སྟོན་པ་བསྟན། དེའི་འོག་མས་ནི་ཆོས་རྣམ་པར་དག་པའི་རིགས་པས༌[^809]སེམས་ཅན་གྱི་དོན་མཛད་པ་བསྟན། དེའི་འོག་མས་ནི་ཡང་དག་པ་ཇི་ལྟ་བ་བཞིན་དུ་ཆོས་སྟོན་པའི་མཐར་ཕྱིན་པ་བསྟན། དེའི་འོག་མས་ནི་སོ་སོ༌[^810]ཡང་དག་པར་རིག་པས་སོ་སོའི་ཡིད་དང་མཐུན་པར་ཆོས་སྟོན་པ་ནི་དེ་བཞིན་གཤེགས་པ་ཉག་གཅིག་གིས༌[^811]གོ་བར་བསྟན་པའོ། །

[Block 801]
ཡང་ན་ཚིག་དེ་བཞི་ཡང་སྤྲུལ་པའི་སྐུ་དང་ལོངས་སྤྱོད་རྫོགས་པའི་སྐུ་དང་། ཆོས་ཀྱི་སྐུ་དང་། སྤོབས་པ་མཐའ་ཡས་པ་དང་ལྡན་པས་སྟོན་པ་ཞེས་སྦྱར་རོ། །

[Block 802]
མདོ་ལས་རྣམ་པར་བསྟན་པ་རྣམས་ཀྱིས༌[^812]ཡང་དག་པར་སྟོན་ཏེ། ཐབས་མཁས་པ་དེ་དང་དེས། སེམས་ཅན་དེ་དང་དེ་ལ་ཆགས་པའི༌[^813]རྣམས་རབ་ཏུ་འགྲེལ་ཏོ་ཞེས་པ་དེ༌[^814]གོང་གི་ཚིག་དེ་བཞི་ཡང་དང་ཡང་དུ་བཟླས་ཏེ་དགྲོལ་ཞིང་བཤད་པ་ལ་འདི་ནི་ཐབས་མཁས་པས་སྟོན་ཏེ། ཐབས་མཁས་པ་ནི་མུ་སྟེགས་ཅན་གྱི་རྣམས་ཐབས་སྣ་ཚོགས་ཀྱིས་ཡང་དག་པའི་བསྟན་པ་ལ་འཛུད་པར་མཁས་པས་ཐབས་མཁས་པ་སྟེ། མུ་སྟེགས་ཅན་དེ་དག་ཀྱང་དགེ་བ་ལ་འཛུད་པ༌[^815]དང་། ཐེ་ཙོམ་བཅད་པ༌[^816]དང་། ཡེ་ཤེས་དམ་པ་ལ་གཟུད་པ་དང་། བསྡུ་བ་རྣམ་པ་བཞིས་བསྡུ་ཞིང་རྣམ་པར་གྲོལ་བ་ཐོབ་པར་མཛད་པས་ཐབས་མཁས་པ་སྟེ།[^817] གོང་མ་བཞི་དང་རིམ་པ་བཞིན་དུ་སྦྱར་རོ། །

[Block 803]
ཡང་ན་ཐབས་སྣ་ཚོགས་ཀྱིས༌[^818]དྲང་ཞིང་ཆགས་པ་ལས་དགྲོལ་བ་སྟེ། ཁམས་ལ་ཆགས་པ་དང་། ས་ལ་ཆགས་པ་དང་། ཕྱོགས་ལ་ཆགས་པ་དང་། ཐེག་པ་ལ་ཆགས་པའོ། །

[Block 804]
ཁམས་ལ་ཆགས་པ་ནི་ཁམས་གསུམ་ལ་ཆགས་པའོ། །

[Block 805]
ས་ལ་ཆགས་པ་ནི་ཚུལ་ཁྲིམས་དང་། བརྟུལ་ཞུགས་དང་། བསམ་གཏན་དང་། ཏིང་ངེ་འཛིན་གྱི་ས་ལ་ཆགས་པའོ། །

[Block 806]
ཕྱོགས་ལ་ཆགས་པ་ནི་ཁྱིམ་པའི་ཕྱོགས་དང་། རབ་ཏུ་བྱུང་བའི་ཕྱོགས་ལ་སྟེ་ལས་དང་འཚོ་བ་སྣ་ཚོགས་དང་ཁེ་དང་གྲགས་པ་ལ་ཆགས་པའོ། །

[Block 807]
ཐེག་པ་ལ་ཆགས་པ་ནི་ཐེག་པ་ཆེ་ཆུང་གི་ལྟ་བ་ལ་གཙོར་འཛིན་ཅིང་ཆགས་པའོ། །

[Block 808]
མདོ་ལས་ཤཱ་རིའི་བུ་དེ་བཞིན་གཤེགས་པ་ཞེས་པ་ནས་རྨད་དུ་བྱུང་བའི་ཆོས་དང་ལྡན་ཏེ་ཞེས་པའི་བར་དུ་ནི་གོང་མའི་ཡེ་ཤེས་མཐོང་བ་ཞེས་པས༌[^819]སྟོན་ཏེ། ཆེན་པོ་ནི་བླ་ན་མེད་པ༌[^820]མཆོག་ཅེས་པ་ནི་དམ་པའོ། །

[Block 809]
དེ་ཀུན་ཀྱང་ཡེ་ཤེས་རྣམ་གཉིས་ཀྱི་འཁོར་ཏེ། ཐོགས་པ་མེད་པ་ནི་སྤོབས་པ་སོ་སོ༌[^821]ཡང་དག་པར་རིག་པ་བཞིའོ། །
