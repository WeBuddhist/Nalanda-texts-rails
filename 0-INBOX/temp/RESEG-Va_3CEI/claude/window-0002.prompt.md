=== SYSTEM PROMPT ===
You are an expert in classical Tibetan Buddhist commentary (འགྲེལ་པ་) structure.

You are given a numbered list of blocks from a Tibetan verse commentary. A
rule-based segmenter has already cut them; most cuts are right. Your job is to
output the few merge/split operations that bring the blocks to the layout the
human editors of this vault use.

━━━ TARGET LAYOUT — one block per FUNCTIONAL UNIT ━━━

OPENER       A node's division announcement together with the first-child opener
             that follows it is ONE block:
               "<topic> ལ་གསུམ། A། B། C་འོ། །དང་པོ་ནི།"
             A sibling opener "གཉིས་པ་ <title> ནི།" is its own block.
ROOT QUOTE   A quoted root stanza is its own block. These blocks are tagged
             [VERSE]; they are protected — never include them in any operation.
EXPLANATION  The gloss that follows a quote ("ཞེས་པ་སྟེ། …", "ཞེས་པ་ནི། …", or a
             running explanation) is ONE block up to the next opener, quote or
             heading — even when it is long (100–250 syllables) and contains several
             sentence ends, a question and answer ("…ལོ། །གང་ལ་ན། …"), a side remark
             on a variant reading ("…ཞེས་འགྱུར་བཅོས་…"), a cross-reference
             ("འདི་དང་འོག་གི་ས་བཅད་…"), or a mantra cited in passing.
SECOND LEVEL A passage that re-reads the same stanza on another level — opening
             "སྦས་དོན་ནི།", "ངེས་དོན་ནི།", "ངེས་པའི་དོན་དུ།", "ཟབ་དོན་ནི།",
             "དེའི་ནང་གི་དོན་ལ།", "མཐར་ཐུག་གི་དོན་ནི།" or the like after the literal
             gloss — is its OWN block, never merged into the literal gloss before it
             (the editors keep the two readings apart). Within that passage, M1 applies.
FRAME        The namo line alone; each of the author's own verses one block;
             "སྨྲས་པ།" alone; the colophon ("ཅེས་ … སྦྱར་བའོ། །" + closing wishes) one block.

━━━ MERGE — adjacent blocks that are one unit ━━━

M1  CONTINUED EXPLANATION
    A block that goes on explaining the same quote/topic as the block before it —
    no new opener, no new quote, no new verse being treated — belongs to that block.
    This is the most common fix. Do NOT keep a cut just because a sentence ends.
    Exception: a SECOND LEVEL opener (see above) always starts a new block.
M2  INCOMPLETE SENTENCE
    A block ending in a connector (དང་། / ཞིང་། / ཅིང་། / ནས། / སྟེ། / ཏེ།) that
    the next block completes.
M3  OPENER CHAIN
    An enumeration block followed by "དང་པོ་ནི།" / "དང་པོ་ལ་ N།" (and further
    nested first-child enumerations) — merge them into one opener block.
M4  COLOPHON
    The parts of the closing colophon and its final wishes form one block.

━━━ SPLIT — one block that holds two units ━━━

S1  A new node opener (ordinal + title + "ནི།" or "ལ་ N།") buried mid-block:
    split before it.
S2  The treatment of a new verse/topic starts mid-block (e.g. "ཡང་ཕྱག་གང་ལ་འཚལ་ན"
    starting the next homage): split before it.
S3  An introductory opener "… ནི།" fused to the explanation of the PREVIOUS
    quote: split so the opener starts the next unit.

Never split a block only because it is long.

━━━ TOPIC SHIFT vs CONTINUATION (from the editors' corrections) ━━━

The editors' blocks are large (median ≈ 55 syllables; whole explanations of
100–250 syllables are normal). A sentence end is NOT a boundary. Inside one
explanation they cut only where the commentary turns to something new:
  START a new block at   "ཡང་ན་ …" (an alternative explanation)
                         "ཁ་ཅིག་ …", "གཞན་དག་ …" (another party's view)
                         "འོ་ན་ …" (the reply to an objection)
                         "དེ་སྐད་དུ་ …", "ཇི་སྐད་དུ་ …" (introducing a supporting quotation)
                         "དེ་ནས་ …" when it opens the next step of a procedure
                         "དཔེ་ …" / "དཔེར་ན་ …" when an example section begins
KEEP WITH the block before (merge into it):
                         "ད་ནི་ …" — a transitional "now …" line is not a new unit
                         (no heading or verse between them)
                         "ལེའུ་ … པའོ། །" — a chapter-closing line stays with the
                         explanation it closes
                         "ཞེས་ / ཅེས་ …" — the quotative closing the words just before it

━━━ HEADING / VERSE BLOCKS — always KEEP ━━━

Blocks tagged [HEADING] or [VERSE] are NEVER part of any operation.

━━━ OUTPUT FORMAT ━━━

A JSON array of operations. Blocks not mentioned are kept as-is.

[
  {"op": "merge", "blocks": [N, M]},
  {"op": "merge", "blocks": [N, M, P]},
  {"op": "split", "block": N, "after": "<verbatim unique substring ending at split point>"},
  {"op": "split", "block": N, "after": ["<sub1>", "<sub2>", "<sub3>"]}
]

Rules for the output:
- Block numbers are CONTINUOUS and INCLUDE heading and verse blocks. You may only
  merge blocks with consecutive numbers (N and N+1). Never merge across a heading
  or a verse block, and never propose a merge whose numbers skip over one.
- Each block number appears in AT MOST ONE operation.
- For each "after" substring: copy a verbatim slice from the block that ends exactly
  at the split point and is UNIQUE within that block (10–20 characters is usually enough).
- If nothing needs to change in this window, output: []
- Output ONLY the JSON array. No explanation, no commentary, no code fences.

དེ་ལ་ལུང་ནི་གཞུང་དམ་པ་སྒྲོགས་པའི༌[^132]ལས་བྱེད། གཞུང་ནི་གདོན་པར་བྱ་བ་ཆུ་ལས་འབྱིན་པའི་མཐུ་ཡོད། སྒྲུབ་པ་ནི་འབྲས་བུ་སྨིན་པར་བྱེད་པའི་མཐུ་ཡོད། འབྲས་བུ་ནི་རྒྱུས་བསྒྲུབས་པ༌[^133]དོན་ཡོད་པར་བྱེད་པའོ། །

[Block 81 [HEADING]]
### ལེའུའི་གྲངས་དང་མིང་བསྟན་པ། ^2-3-0

[Block 82]
མདོ་སྡེ་འདིའི་ནང་ནས་ལེའུའི་གྲངས་དང་མིང་བསྟན་པ་ནི་ལེའུ་ཉི་ཤུ་རྩ་བདུན་ཞིག་ཡོད་པ་ལས།

[Block 83]
དང་པོ༌[^134]གླེང་གཞིའི་ལེའུ་དང་། ཐབས་མཁས་པའི་ལེའུ་དང་། དཔེའི་ལེའུ་དང་། དད་པའི་ལེའུ་དང་། སྨན་གྱི་ལེའུ་དང་། ལུང་བསྟན་པའི་ལེའུ་དང་། སྔོན་བྱུང་བའི་ལེའུ་དང་། དགེ་སློང་ལྔ་བརྒྱ་ལུང་བསྟན་པའི་ལེའུ་དང་། དགེ་སློང༌[^135]གཞན་ཉིས་སྟོང་ལུང་བསྟན་པའི་ལེའུ་དང་། ཆོས་སྨྲ་བའི་ལེའུ་དང་། མཆོད་རྟེན་བསྟན་པའི་ལེའུ་དང་། མོས་པ་བྱ་བའི་ལེའུ་དང་། བདེ་བ་ལ་གནས་པའི་ལེའུ་དང་། བྱང་ཆུབ་སེམས་དཔའ་སའི༌[^136]རུམ་ནས་འཐོན་པའི་ལེའུ་དང་། དེ་བཞིན་གཤེགས་པའི་ཚེའི་ཚད་ཀྱི་ལེའུ་དང་། བསོད་ནམས་ཀྱི་གཞུང་གི་ལེའུ་དང་། རྗེས་སུ་ཡི་རང་བའི་བསོད་ནམས་བསྟན་པའི་ལེའུ་དང་། སྐྱེ་མཆེད་དྲུག་རྣམ་པར༌[^137]དག་པའི་ཡོན་ཏན་གྱི་ལེའུ་དང་། རྟག་ཏུ་མི་བརྙས་པའི་ལེའུ་དང་། དེ་བཞིན་གཤེགས་པའི་རྫུ་འཕྲུལ་མངོན་པར་འདུ་བྱེད་པའི་ལེའུ་དང་། གཟུངས་སྔགས་ཀྱི་ལེའུ་དང་། སྨན་གྱི་རྒྱལ་པོའི་སྔོན་གྱི་ཚུལ་གྱི་ལེའུ་དང་། སང་སང་པོའི་དབྱངས་ཀྱི་ལེའུ་དང་། ཀུན་གྱི་སྒོའི་ལེའུ་དང་། དགེ་བའི་རྒྱན་གྱི་སྔོན་གྱི་ཚུལ་གྱི་ལེའུ་དང་། ཀུན་དུ་བཟང་པོ་མོས་པར་བྱ་བའི་ལེའུ་དང་། ཡོངས་སུ་གཏད་པའི༌[^138]ལེའུའོ། །

[Block 84]
ལེའུ་དེ་དག་ཀྱང་ཆོས་ཀྱི་དོན་ལས་བཏགས་པ་རྣམ་པ་བཞི་དང་། དཔེ་ལས་བཏགས་པ་རྣམ་པ་གསུམ་དང་། བྱང་ཆུབ་སེམས་དཔའ་གང་གིས་གསོལ་བ་འདེབས་པ༌[^139]ལས་བཏགས་པ་རྣམ་པ་བཞི་དང་། དོན་ལས་བཏགས་པ་རྣམ་པ་བཞི་དང་། དོན་དང་བྱང་ཆུབ་སེམས་དཔའ་གཉིས་ཀ་ལས་བཏགས་པ་རྣམ་པ་དགུ་དང་། མ་ངེས་པ་རྣམ་པ་གཉིས་ཏེ། བདེ་བ་ལ་གནས་པ་དང་། མཆོད་རྟེན་བསྟན་པ་གཉིས་ནི་རྒྱུ་དང་འབྲས་བུ་གཉིས་ཀར་འབྲེལ་པའི༌[^140]ཕྱིར་མ་ངེས་པ་སྟེ། སྤྱིར་ཉི་ཤུ་རྩ་བདུན་ནོ། །

[Block 85 [HEADING]]
## ལེའུ་ཉི་ཤུ་རྩ་བདུན་གྱི་རིམ་པ་བཤད་པ། ^3-0

[Block 86]
ལེའུ་ཉི་ཤུ་རྩ་བདུན་གྱི་རིམ་པ་བཤད་པ་ནི། དེ་བཞིན་གཤེགས་པས༌[^141]ཆོས་བཤད་པར་དགོངས་ཏེ། འགྲོ་བ་མང་པོ་ལ་གཟིགས་ནས་གཟེངས་བསྟོད་ཅིང་རྨུགས་པ་བསལ་ཏེ་དབང་པོ་དང་བར་བྱས་ནས་སོ་སོའི་དབང་པོ་དང་མཐུན་པར་ཆོས་བསྟན་པའི་ཕྱིར་དང་པོ་གླེང་གཞིའི་ལེའུ་བསྟན་ཏོ། །

[Block 87]
གླེང་གཞིའི་ལེའུ་བསྟན་ནས་ཡང་དག་པའི་གཞུང་ཉིད་བསྟན་པར་བཞེད་དེ། ཐེག་པ་གཅིག་པའི་གཞུང་སྟོན་པ་ཡང་བཀྲི་བ༌[^142]དང་ངེས་པའི་དོན་གྱི་དབང་པོ་རྣོ༌[^143]རྟུལ་སོ་སོར་ཕན་བཏགས་པའི༌[^144]ཕྱིར་དེའི་འོག་ཏུ་ཐབས་མཁས་པའི་ལེའུ་བསྟན་ཏོ། །

[Block 88]
དབང་པོ་རྣོ་རྟུལ༌[^145]ཆོས་རིམ་པར་ཕྱེ་སྟེ་བསྟན་ཟིན་གྱིས་ཀྱང་ཟབ་མོ་རྟོགས་པར་མི་ནུས་པས་དཔེས་གོ་བར་བྱ་བའི་ཕྱིར་དེའི་འོག་ཏུ་དཔེའི་ལེའུ་བསྟན་ཏོ། །

[Block 89]
དཔེས་དོན་ཟབ་མོ་མཐོང་ཞིང་དད་པ་བསྐྱེད་པའི༌[^146]ཕྱིར་དེའི་འོག་ཏུ་དད་པའི་ལེའུ་བསྟན་ཏོ། །

[Block 90]
དད་པ་སྐྱེས་སུ་ཟིན་གྱིས་ཀྱང་ད་དུང་ངེས་པ་ཙམ་མ་ཡིན་པས་དེ་བརྟན་པར༌[^147]བྱ་བའི་ཕྱིར་ཡང་སྨན་གྱི་དཔེའི་ལེའུ་བསྟན་ཏོ། །

[Block 91]
ཉན་ཐོས་ཆེན་པོ་བཞི་དོན་ཟབ་མོ་མཐོང་བས་དེའི་འབྲས་བུ་བསྟན་པའི་ཕྱིར་དེའི་འོག་ཏུ་ལུང་བསྟན་པའི་ལེའུ་བསྟན་ཏོ། །

[Block 92]
དབང་པོ་རྣོན་པོ་དང་བར་མ་གཉིས་ཀྱིས༌[^148]ཤེས་པ་སྐྱེས་སུ༌[^149]ཟིན༌[^150]ཀྱང་དབང་པོ་རྟུལ་བ་རྣམས་ཡང་དང་ཡང་དུ་བཟླས་ཤིང་ཆུད་པར་བྱ་བའི་ཕྱིར་སྔོན་བྱུང་བ་གྲོང་ཁྱེར་གྱི་དཔེའི་ལེའུ་བསྟན་ཏོ། །

[Block 93]
དབང་པོ་རྣོན་པོ་རྣམས་དོན་གླེངས་པ༌[^151]ཙམ་གྱིས༌[^152]ཆུད་པ་དང་། དད་པ་སྐྱེས་ཏེ་ལུང་བསྟན་པ་བཞིན་དབང་པོ་རྟུལ་པོ་རྣམས་ཀྱང་ལན་གཉིས་ལན་གསུམ་དུ་བཟླས་པས་རྟོགས་པ༌[^153]སྐྱེས་ཏེ། དེའི་ལུང་བསྟན་པར་དགོངས་པའི་ཕྱིར་དེའི་འོག་ཏུ་དགེ་སློང་ལྔ་བརྒྱ་ལུང་བསྟན་པའི་ལེའུ་བསྟན་ཏོ། །

[Block 94]
དབང་པོའི་རིགས༌[^154]པ་བཞིན་དགེ་སློང་གཞན་དག་ཀྱང་རྟོགས་པ་སྐྱེས་པའི་ཕྱིར་དེའི་འོག་ཏུ་སློབ་པ་དང་མི་སློབ་པ་རྣམས་ལུང་བསྟན་པའི་ལེའུ་བཀོད་དོ། །

[Block 95]
དབང་པོ་རྣོ་རྟུལ་རིམ་པ་གསུམ་པོ་རྣམས་སོ་སོར་ལུང་བསྟན་ཏེ། ཡུན་རིང་པོ་མ་འོངས་པའི་དུས་སུ་ཆོས་བཟང་བའི་དཔེ་ལུགས་བཞག༌[^155]པའི་ཕྱིར་དེའི་འོག་ཏུ་ཆོས་སྨྲ་བའི་ལེའུ་བཞག་གོ། །

[Block 96]
ལུང་བཞིན་བསྒྲུབས༌[^156]ཏེ་ཡང་དག་པ་ཉིད་ཆུད་པའི་རྟགས༌[^157]གཞན་དད་པ་བསྐྱེད་པའི་ཕྱིར་སྔོན་གྱི་འཕགས་པ་རྣམས་འབྱུང་བའི་མཆོད་རྟེན་གྱི་ལེའུ་བསྟན་ཏོ། །

[Block 97]
དོན་དེ་བདག་ཉིད་ཀྱིས་ཆུད་པར་མ་ཟད་ཀྱི་གཞན་གྱི་དོན་ཡང་བྱ་དགོངས་པས༌[^158]རྒྱལ་པོའི་ལུས་སུ་སྤྲུལ་ཏེ་ཆོས་སྟོན་པའི་ཕྱིར་དེའི་འོག་ཏུ་སྔོན་བྱུང་བའི་ལེའུ་བསྟན་ཏོ། །

[Block 98]
མདོ་སྡེ་འདི་ལྟ་བུ་བདག་དང་གཞན་གྱི༌[^159]རིན་ཆེ་བ་དང་གུས་པར་བྱ་བའི་ཕྱིར་བྱང་ཆུབ་སེམས་དཔའ་རྣམས་ཀྱིས་རྗེས་སུ་འཛིན་པར་གསོལ་བས་དེའི༌[^160]འོག་ཏུ་རྗེས་སུ་འཛིན་པའི་ལེའུ་བསྟན་ཏོ། །

[Block 99]
མ་འོངས་པའི་དུས་ན་ཆོས་སྒྲུབ་པའི་སྤྱོད་ལམ་མི་མཐུན་པར་བྱེད་པ་རྣམས་ཀྱི་ལུས་ཉོན་མོངས་པར་སྐྱེ་བ་ལ་སྤྱོད་ལམ་གྱི་ཚུལ་བསྟན་པས་སྤྱོད་ལམ་བསླབ་པའི་ཕྱིར་དེའི་འོག་ཏུ་བདེ་བ་ལ་གནས་པའི་ལེའུ་བསྟན་ཏོ། །

[Block 100]
ཆུ་བོ་གང་གཱའི་བྱེ་མ་སྙེད་ཀྱི་བྱང་ཆུབ་སེམས་དཔའ་རྣམས་ཀྱིས་དམ་པའི་ཆོས་འདི་ཐོས་ནས་རྗེས་སུ་འཛིན་ཅིང་སློབ་པར་དགའ་སྟེ་སྨོན་པ༌[^161]ལས་སངས་རྒྱས་བཅོམ་ལྡན་འདས་ཀྱི་སྔོན་ཡང་བྱང་ཆུབ་སེམས་དཔའ་སྐྱོན་གྱི་དྲི་མ་དང་བྲལ་བ༌[^162]རྣམས་ལངས་ནས་འདི་འཛིན་པར་སྨོན་པ་རྣམས་ལ་བསྟན་པའི་ཕྱིར་བྱང་ཆུབ་སེམས་དཔའ་རྣམས༌[^163]སའི་འོག་ནས་མང་དུ་འཐོན༌[^164]པས་དེའི་འོག་ཏུ་བྱང་ཆུབ་སེམས་དཔའ་སའི༌[^165]རུམ་ནས་འཐོན་པའི་ལེའུ་བཞག་གོ། །

[Block 101]
འཁོར་མང་པོ་རྣམས་ཀྱི༌[^166]བྱང་ཆུབ་སེམས་དཔའ་སའི་འོག་ནས་འཐོན་པ་མཐོང་ནས་འདི་ནི་དེ་བཞིན་གཤེགས་པ་ཤཱཀྱ་ཐུབ་པ་བས་སྔར་གྲུབ་པ་ཤ་སྟག་སྟེ། འདི་ནི་ཤཱཀྱ་ཐུབ་པས་སྤྲུལ་པ་མ་ཡིན་ནོ་སྙམ་པའི་དོགས་པ༌[^167]བསལ་བའི་ཕྱིར་དེ་བཞིན་གཤེགས་པ་རྣམས་ནི་ཚེ་མཐའ་ཡས་པ་སྟེ། དེའི་འོག་ཏུ་དེ་བཞིན་གཤེགས་པའི་སྐུ་ཚེའི་ཚད་ཀྱི་ལེའུ་བཞག་གོ། །

[Block 102]
དེ་བཞིན་གཤེགས་པའི་སྤྲུལ་པའི་སྐུའི་ཚེ་ཚད་དེ་ལྟ་ན་ཆོས་དང་ལོངས་སྤྱོད་རྫོགས་པའི་སྐུའི་ཡོན་ཏན་དང་ཚེ༌[^168]ཚད་ཀྱང་གྲངས་མེད་པར་ཐབས་ཀྱིས༌[^169]བསྟན་པས་སེམས་ཅན་རྣམས་དེ་ལ་མོས་པ་བསྐྱེད་པའི་ཕྱིར་དེའི་འོག་ཏུ་བསོད་ནམས་ཀྱི་རྣམ་གྲངས་དབྱེ་བའི་ལེའུ་བསྟན་ཏོ། །

[Block 103]
དེ་ལྟར་བསོད་ནམས་ཀྱི་རྣམ་གྲངས༌[^170]མེད་པར་བསྟན་པས་སེམས་ཅན་རྣམས་དད་པ་བསྐྱེད་པའི༌[^171]ཕྱིར་དེའི་འོག་ཏུ་རྗེས་སུ་ཡི་རང་བའི་ལེའུ་བཞག་གོ། །

[Block 104]
གཞན་བྱེད་པ་ལ༌[^172]རྗེས་སུ་ཡི་རང་བ་ཙམ་གྱིས་ཀྱང་བསོད་ནམས་གྲངས་མེད་པ་ཐོབ་ན། དངོས་སུ་འཆད་པ་དང་འདོན་པ་རྣམས་ལྟ་སྨོས་ཀྱང་མི་དགོས་པར་བསྟན་པའི་ཕྱིར་དེའི་འོག་ཏུ་སྐྱེ་མཆེད་དྲུག་རྣམ་པར་དག་པའི་ཡོན་ཏན་གྱི་ལེའུ་བཞག་གོ། །

[Block 105]
གང་ཆོས་སྨྲ་བ་དེ༌[^173]བླ་ན་མེད་པའི་བྱང་ཆུབ་ཏུ་འགྱུར་བས་ཆོས་སྨྲ་བ༌[^174]ལ་སྨོད་པ་ཁ་ན་མ་ཐོ་བ་ཆེ་བར་བསྟན་པའི་ཕྱིར་དེའི་འོག་ཏུ་རྟག་ཏུ་མི་བརྙས་པའི་ལེའུ་བཞག་གོ། །

[Block 106]
དེ་བཞིན་གཤེགས་པས་བསོད་ནམས་ཆེ་བའི༌[^175]རིམ་པ་བསྟན་ཀྱང་སེམས་ཅན་མོས་པ་ཆུང་བ་རྣམས་དོགས་པ་སྐྱེ་བ་ཡང་ཡོད་དེ། དེ་བསླུ་བ་མ་ཡིན་པའི་གཏན་ཚིགས་སུ་དེ་བཞིན་གཤེགས་པའི་རྫུ་འཕྲུལ་མངོན་པར་འདུ་བྱེད་པའི་ལེའུ་བཞག་གོ། །

[Block 107]
སྨན་གྱི་རྒྱལ་པོ་སྔོན༌[^176]དམ་པའི་ཆོས་འདི་ཚོལ་བ༌[^177]ལ་ལུས་དང་སྲོག་ལ༌[^178]མི་ཕངས་པས༌[^179]བརྩོན་པར་ཚོལ་བ་སྔོན་གྱི་ཚུལ་བསྟན་པའི་ཕྱིར་དེའི་འོག་ཏུ་སྨན་གྱི་རྒྱལ་པོ་བྱང་ཆུབ་སེམས་དཔའི་ལེའུ་བཞག་གོ། །

[Block 108]
ཡང་དག་པའི་ཆོས་སྤྱོད་པ་འཇིག་རྟེན་འདི་དང་ཁམས་གཞན་དག་ཏུ༌[^180]རྒྱས་པར་བསྒྲགས་པའི་ཕྱིར་དབྱངས་དམ་པ་དང་ལྡན་པའི་བྱང་ཆུབ་སེམས་དཔའ་སྒྲོགས་སུ་གཞུག་པའི་ཕྱིར་དེའི་འོག་ཏུ་སང་སང་པོའི་དབྱངས་ཀྱི་ལེའུ་བཞག་གོ། །

[Block 109]
སེམས་ཅན་རྣམས་མདོ་འདི༌[^181]འཛིན་པ་ལ་བགེགས་དང་བར་ཆད་ཆེ་བས་ཐུགས་རྗེ་ཆེན་པོ་དང་ལྡན་པའི་བྱང་ཆུབ་སེམས་དཔའ་འཕགས་པ་སྤྱན་རས་གཟིགས་ལ་བརྟེན་པའི་ཀུན་གྱི་སྒོའི་ལེའུ་བཞག་གོ། །

[Block 110]
བགེགས་དང་བར་ཆད་ཞི་བར་བྱ་བའི་ཕྱིར་གཟུངས་ཀྱི་ལེའུ་བཞག་གོ། །
