# Classification of `1-SOURCES/Text`

Scratch work — not authoritative. All 565 files are Tibetan (Tengyur) translations of Indic works; classes below use the vault `file_type` sense:
- **root-text** — an independent work (treatise, hymn, sādhana, ritual, letter, song…)
- **commentary** — explicates another specific text (‘grel pa, bshad pa, rnam bshad, ṭīkā, dka’ ‘grel, bshad sbyar, don bsdus…)
- **translation** — a second Tibetan translation of a root text that is already in the folder
