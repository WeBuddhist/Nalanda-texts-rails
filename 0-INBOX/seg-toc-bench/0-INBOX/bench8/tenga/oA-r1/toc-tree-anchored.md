## དཀར་ཆག / Table of Contents

* 1. དང་པོ་མདོར་བསྟན་པ་ [[ཕྱག་འཚལ་ཉི་ཤུ་རྩ་གཅིག་གིས་བསྟོད་པ་ལ་མདོར་བསྟན། རྒྱས་བཤད།]]
* 2. གཉིས་པ་རྒྱས་པར་བཤད་པ་ [[གཉིས་པ་རྒྱས་པར་བཤད་པ་ལའང༌། སྤྱིར་ལོ་རྒྱུས་ཀྱི་དབང་དུ་བྱས་ཏེ་]]
   * 2.1 དང་པོ་སྤྱིར་ལོ་རྒྱུས་ཀྱི་དབང་དུ་བྱས་ཏེ་ཕྱག་འཚལ་བ་ [[དང་པོ་ནི།]]
   * 2.2 གཉིས་པ་སྐུའི་རྣམ་པའི་སྒོ་ནས་ཕྱག་འཚལ་བ་ [[གཉིས་པ་སྐུའི་རྣམ་པའི་སྒོ་ནས་ཕྱག་འཚལ་བ་ལ། ལོངས་སྐུའི་རྣམ་པ་དང༌།]]
      * 2.2.1 དང་པོ་ལོངས་སྐུའི་རྣམ་པའི་སྒོ་ནས་ཕྱག་འཚལ་བ་ [[དང་པོ་ལོངས་སྐུའི་རྣམ་པའི་སྒོ་ནས་ཕྱག་འཚལ་བ་ལའང་ཞི་བའི་རྣམ་པ་དང་།]]
         * 2.2.1.1 དང་པོ་ཞི་བའི་རྣམ་པའི་སྒོ་ནས་ཕྱག་འཚལ་བ་ [[དང་པོ་ཞི་བའི་རྣམ་པའི་སྒོ་ནས་ཕྱག་འཚལ་བ་ལ། ཕྱག་འཚལ་དྲུག་གི་སྒོ་ནས་]]
            * 2.2.1.1.1 དང་པོ་ཞལ་མདངས་གསལ་ཞིང་འོད་ཟེར་འཕྲོ་བའི་སྒོ་ནས་བསྟོད་པར་མཛད་པ་ [[དང་པོ་ཞལ་མདངས་གསལ་ཞིང་འོད་ཟེར་འཕྲོ་བའི་སྒོ་ནས་བསྟོད་པར་མཛད་པ་]]
            * 2.2.1.1.2 གཉིས་པ་སྐུ་མདོག་དང་ཕྱག་མཚན་དང་སྐུའི་སྒོ་ནས་བསྟོད་པར་མཛད་པ་ [[གཉིས་པ་སྐུ་མདོག་དང་ཕྱག་མཚན་དང་སྐུའི་སྒོ་ནས་བསྟོད་པར་མཛད་པ་ནི།]]
            * 2.2.1.1.3 གསུམ་པ་རྒྱལ་དང་རྒྱལ་བའི་སྲས་ཀྱིས་གུས་པས་བསྟེན་པར་མཛད་པ་ [[གསུམ་པ་རྒྱལ་དང་རྒྱལ་བའི་སྲས་ཀྱིས་གུས་པས་བསྟེན་པར་མཛད་པས། དེ་]]
               * 2.2.1.1.3.1 དང་པོ་སངས་རྒྱས་ཀྱིས་གུས་པས་བསྟེན་པའི་ཚུལ་ [[དང་པོ་སངས་རྒྱས་ཀྱིས་གུས་པས་བསྟེན་པའི་ཚུལ་ནི། ཕྱག་འཚལ་དེ་བཞིན་]]
               * 2.2.1.1.3.2 གཉིས་པ་བྱང་སེམས་ཆེན་པོ་རྣམས་ཀྱིས་གུས་པས་བསྟེན་པའི་ཚུལ་ [[གཉིས་པ་བྱང་སེམས་ཆེན་པོ་རྣམས་ཀྱིས་གུས་པས་བསྟེན་པའི་ཚུལ་]]
            * 2.2.1.1.4 བཞི་པ་རྗེ་བཙུན་མས་མི་མཐུན་པའི་ཕྱོགས་ཐམས་ཅད་གནོན་པའི་སྒོ་ནས་བསྟོད་པར་མཛད་པ་ [[བཞི་པ་རྗེ་བཙུན་མས་མི་མཐུན་པའི་ཕྱོགས་ཐམས་ཅད་གནོན་པའི་སྒོ་ནས་བསྟོད་]]
            * 2.2.1.1.5 ལྔ་པ་འཇིག་རྟེན་སྐྱོང་བ་ཆེན་པོ་རྣམས་ཀྱིས་གུས་པའི་སྒོ་ནས་ཕྱག་འཚལ་བར་བསྟན་པ་ [[ལྔ་པ་འཇིག་རྟེན་སྐྱོང་བ་ཆེན་པོ་རྣམས་ཀྱིས་གུས་པའི་སྒོ་ནས་ཕྱག་འཚལ་བར་]]
            * 2.2.1.1.6 དྲུག་པ་ཕ་རོལ་གནོན་པའི་སྒོ་ནས་བསྟོད་པར་མཛད་པ་ [[དྲུག་པ་ཕ་རོལ་གནོན་པའི་སྒོ་ནས་བསྟོད་པར་མཛད་པ་ནི། ཕྱག་]]
         * 2.2.1.2 ཁྲོ་མོའི་ཚུལ་ལ་ཕྱག་འཚལ་བ་ [[དེའི་རྗེས་སུ་ཁྲོ་མོའི་ཚུལ་ལ་ཕྱག་འཚལ་བ་བདུན་གྱི་སྒོ་ནས་བསྟོད་པ་ལས།]]
            * 2.2.1.2.1 དང་པོ་ཁྲོས་པའི་ཞལ་གྱིས་བདུད་དང་བར་ཆད་ཐམས་ཆད་འཇོམས་པར་མཛད་པའི་སྒོ་ནས་བསྟོད་པ་ [[དང་པོ་ཁྲོས་པའི་ཞལ་གྱིས་བདུད་དང་བར་ཆད་ཐམས་ཆད་འཇོམས་པར་]]
            * 2.2.1.2.2 གཉིས་པ་གཡས་གཡོན་ཕྱག་མཚན་གྱི་སྒོ་ནས་བསྟོད་པར་མཛད་པ་ [[གཉིས་པ་གཡས་གཡོན་ཕྱག་མཚན་གྱི་སྒོ་ནས་བསྟོད་པར་མཛད་པ་]]
            * 2.2.1.2.3 གསུམ་པ་དབུ་རྒྱན་དང་བཞད་པའི་སྒོ་ནས་བསྟོད་པར་མཛད་པ་ [[གསུམ་པ་དབུ་རྒྱན་དང་བཞད་པའི་སྒོ་ནས་བསྟོད་པར་མཛད་པ་]]
            * 2.2.1.2.4 བཞི་པ་ཕྱོགས་སྐྱོང་བཅུས་ཕྲིན་ལས་བསྒྲུབ་པའི་སྒོ་ནས་བསྟོད་པར་མཛད་པ་ [[བཞི་པ་ཕྱོགས་སྐྱོང་བཅུས་ཕྲིན་ལས་བསྒྲུབ་པའི་སྒོ་ནས་བསྟོད་པར་མཛད་པ་]]
            * 2.2.1.2.5 ལྔ་པ་རིགས་བདག་གིས་དབུ་བརྒྱན་པའི་སྒོ་ནས་བསྟོད་པར་མཛད་པ་ [[ལྔ་པ་རིགས་བདག་གིས་དབུ་བརྒྱན་པའི་སྒོ་ནས་བསྟོད་པར་མཛད་པ་]]
            * 2.2.1.2.6 དྲུག་པ་རྗེ་བཙུན་མ་དེ་ཉིད་ཁྲོ་མོར་བཞུགས་ཚུལ་གྱི་སྒོ་ནས་བསྟོད་པར་མཛད་པ་ [[དྲུག་པ་རྗེ་བཙུན་མ་དེ་ཉིད་ཁྲོ་མོར་བཞུགས་ཚུལ་གྱི་སྒོ་ནས་]]
            * 2.2.1.2.7 བདུན་པ་ཐུགས་ཀའི་ཧཱུཾ་ཡིག་ལས་འོད་ཟེར་འཕྲོ་བའི་སྒོ་ནས་བསྟོད་པར་མཛད་པ་ [[བདུན་པ་ཐུགས་ཀའི་ཧཱུཾ་ཡིག་ལས་འོད་ཟེར་འཕྲོ་བའི་སྒོ་ནས་བསྟོད་]]
      * 2.2.2 ཆོས་སྐུའི་རྣམ་པའི་སྒོ་ནས་བསྟོད་པར་མཛད་པ་ [[དེའི་རྗེས་སུ་ཆོས་སྐུའི་རྣམ་པའི་སྒོ་ནས་བསྟོད་པར་མཛད་པ་]]
   * 2.3 ཕྲིན་ལས་ཀྱི་སྒོ་ནས་བསྟོད་པ་ [[དེའི་རྗེས་སུ་ཕྲིན་ལས་ཀྱི་སྒོ་ནས་བསྟོད་པ་ལའང་ཕྱག་འཚལ་བ་རྣམ་པ་]]
      * 2.3.1 དང་པོ་རྩ་བའི་སྔགས་ཀྱི་ཕྲིན་ལས་བསྟན་པའི་སྒོ་ནས་བསྟོད་པར་མཛད་པ་ [[དང་པོ་རྩ་བའི་སྔགས་ཀྱི་ཕྲིན་ལས་བསྟན་པའི་སྒོ་ནས་བསྟོད་པར་]]
      * 2.3.2 གཉིས་པ་ཁྲོ་མོའི་བཞུགས་ཚུལ་གྱིས་ཁམས་གསུམ་གནོན་པའི་སྒོ་ནས་བསྟོད་པར་མཛད་པ་ [[གཉིས་པ་ཁྲོ་མོའི་བཞུགས་ཚུལ་གྱིས་ཁམས་གསུམ་གནོན་པའི་སྒོ་ནས་བསྟོད་]]
      * 2.3.3 གསུམ་པ་བརྟན་གཡོའི་དུག་ཐམས་ཅད་སེལ་བར་མཛད་པའི་སྒོ་ནས་བསྟོད་པར་མཛད་པ་ [[གསུམ་པ་བརྟན་གཡོའི་དུག་ཐམས་ཅད་སེལ་བར་མཛད་པའི་སྒོ་ནས་བསྟོད་]]
      * 2.3.4 བཞི་པ་རྩོད་པ་དང་རྨི་ལམ་ངན་པ་སེལ་བའི་སྒོ་ནས་བསྟོད་པར་མཛད་པ་ [[བཞི་པ་རྩོད་པ་དང་རྨི་ལམ་ངན་པ་སེལ་བའི་སྒོ་ནས་བསྟོད་]]
      * 2.3.5 ལྔ་པ་རིམས་ནད་སེལ་བའི་སྒོ་ནས་བསྟོད་པར་མཛད་པ་ [[ལྔ་པ་རིམས་ནད་སེལ་བའི་སྒོ་ནས་བསྟོད་པར་མཛད་པ་ནི།]]
