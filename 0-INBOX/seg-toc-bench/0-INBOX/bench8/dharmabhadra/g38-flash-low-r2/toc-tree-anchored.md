## དཀར་ཆག / Table of Contents

* I. མཆོད་བརྗོད། [[ན་མོ་གུ་རུ་ཨཱརྱ་ཏྭ་རཱ་ཡེ། །]]
* 1. དང་པོ་མདོར་བསྟན་པ་ [[དེ་ཡང་སྒྲོལ་མར་ཕྱག་འཚལ་ཉེར་གཅིག་གིས་བསྟོད་པའི་དོན་འཆད་པ་ལ་གསུམ།]]
* 2. གཉིས་པ་རྒྱས་པར་བཤད་པ་ [[གཉིས་པ་རྒྱས་པར་བཤད་པ་ལ་གསུམ། ལོ་རྒྱུས་ཀྱི་སྒོ་ནས་བསྟོད་པ།]]
   * 2.1 དང་པོ་ལོ་རྒྱུས་ཀྱི་སྒོ་ནས་བསྟོད་པ་ [[དང་པོ་ནི།]]
   * 2.2 གཉིས་པ་སྐུའི་རྣམ་པའི་སྒོ་ནས་བསྟོད་པ་ [[གཉིས་པ་སྐུའི་རྣམ་པའི་སྒོ་ནས་བསྟོད་པ་ལ་གཉིས། ལོངས་སྐུའི་རྣམ་པའི་སྒོ་ནས་]]
      * 2.2.1 དང་པོ་ལོངས་སྐུའི་རྣམ་པའི་སྒོ་ནས་བསྟོད་པ་ [[དང་པོ་ལ་གཉིས། ཞི་བའི་རྣམ་པའི་སྒོ་ནས་བསྟོད་པ་དང༌། ཁྲོ་མོའི་རྣམ་པ་]]
         * 2.2.1.1 དང་པོ་ཞི་བའི་རྣམ་པའི་སྒོ་ནས་བསྟོད་པ་ [[དང་པོ་ལ་དྲུག ། ཞལ་མདངས་གསལ་ཞིང་འོད་ཟེར་འཕྲོ་བའི་སྒོ་ནས་བསྟོད་པ།]]
            * 2.2.1.1.1 དང་པོ་ཞལ་མདངས་གསལ་ཞིང་འོད་ཟེར་འཕྲོ་བའི་སྒོ་ནས་བསྟོད་པ་ [[དང་པོ་ནི།]]
            * 2.2.1.1.2 གཉིས་པ་སྐུ་མདོག་དང་ཕྱག་མཚན་དང་རྒྱུའི་སྒོ་ནས་བསྟོད་པ་ [[གཉིས་པ་སྐུ་མདོག་དང་ཕྱག་མཚན་དང་རྒྱུའི་སྒོ་ནས་བསྟོད་པ་ནི།]]
            * 2.2.1.1.3 གསུམ་པ་རྒྱལ་བ་དང་རྒྱལ་སྲས་ཀྱིས་གུས་པས་བསྟེན་པའི་སྒོ་ནས་བསྟོད་པ་ [[གསུམ་པ་རྒྱལ་བ་དང་རྒྱལ་སྲས་ཀྱིས་གུས་པས་བསྟེན་པའི་སྒོ་ནས་བསྟོད་པ་ནི།]]
            * 2.2.1.1.4 བཞི་པ་མི་མཐུན་ཕྱོགས་གནོན་པའི་སྒོ་ནས་བསྟོད་པ་ [[བཞི་པ་མི་མཐུན་ཕྱོགས་གནོན་པའི་སྒོ་ནས་བསྟོད་པ་ནི།]]
            * 2.2.1.1.5 ལྔ་པ་འཇིག་རྟེན་པའི་ལྷ་ཆེན་པོ་རྣམས་ཀྱིས་བཀུར་བའི་སྒོ་ནས་བསྟོད་པ་ [[ལྔ་པ་འཇིག་རྟེན་པའི་ལྷ་ཆེན་པོ་རྣམས་ཀྱིས་བཀུར་བའི་སྒོ་ནས་བསྟོད་པ་ནི།]]
            * 2.2.1.1.6 དྲུག་པ་ཕ་རོལ་འཇོམས་པའི་སྒོ་ནས་བསྟོད་པ་ [[དྲུག་པ་ཕ་རོལ་འཇོམས་པའི་སྒོ་ནས་བསྟོད་པ་ནི།]]
         * 2.2.1.2 གཉིས་པ་ཁྲོ་མོའི་རྣམ་པའི་སྒོ་ནས་བསྟོད་པ་ [[གཉིས་པ་ཁྲོ་མོའི་རྣམ་པའི་སྒོ་ནས་བསྟོད་པ་ལ་བདུན། བདུད་དང་སྒྲིབ་གཉིས་སྦྱོང་བའི་]]
            * 2.2.1.2.1 དང་པོ་བདུད་དང་སྒྲིབ་གཉིས་སྦྱོང་བའི་སྒོ་ནས་བསྟོད་པ་ [[དང་པོ་ནི།]]
            * 2.2.1.2.2 གཉིས་པ་གཡས་གཡོན་གྱི་ཕྱག་མཚན་གྱི་སྒོ་ནས་བསྟོད་པ་ [[གཉིས་པ་གཡས་གཡོན་གྱི་ཕྱག་མཚན་གྱི་སྒོ་ནས་བསྟོད་པ་ནི།]]
            * 2.2.1.2.3 གསུམ་པ་དབུ་རྒྱན་དང་བཞད་སྒྲའི་སྒོ་ནས་བསྟོད་པ་ [[གསུམ་པ་དབུ་རྒྱན་དང་བཞད་སྒྲའི་སྒོ་ནས་བསྟོད་པ་ནི།]]
            * 2.2.1.2.4 བཞི་པ་ཕྱོགས་སྐྱོང་བཅུས་འཕྲིན་ལས་བསྒྲུབ་པའི་སྒོ་ནས་བསྟོད་པ་ [[བཞི་པ་ཕྱོགས་སྐྱོང་བཅུས་འཕྲིན་ལས་བསྒྲུབ་པའི་སྒོ་ནས་བསྟོད་པ་ནི།]]
            * 2.2.1.2.5 ལྔ་པ་དབུ་རྒྱན་གྱི་སྒོ་ནས་བསྟོད་པ་ [[ལྔ་པ་དབུ་རྒྱན་གྱི་སྒོ་ནས་བསྟོད་པ་ནི།]]
            * 2.2.1.2.6 དྲུག་པ་དྲག་པོའི་བཞུགས་ཚུལ་གྱི་སྒོ་ནས་བསྟོད་པ་ [[དྲུག་པ་དྲག་པོའི་བཞུགས་ཚུལ་གྱི་སྒོ་ནས་བསྟོད་པ་ནི།]]
            * 2.2.1.2.7 བདུན་པ་ཧཱུཾ་ཡིག་ལས་འོད་ཟེར་འཕྲོ་བའི་སྒོ་ནས་བསྟོད་པ་ [[བདུན་པ་ཧཱུཾ་ཡིག་ལས་འོད་ཟེར་འཕྲོ་བའི་སྒོ་ནས་བསྟོད་པ་ནི།]]
      * 2.2.2 གཉིས་པ་ཆོས་སྐུའི་རྣམ་པའི་སྒོ་ནས་བསྟོད་པ་ [[གཉིས་པ་ཆོས་སྐུའི་རྣམ་པའི་སྒོ་ནས་བསྟོད་པ་ནི།]]
   * 2.3 གསུམ་པ་འཕྲིན་ལས་ཀྱི་སྒོ་ནས་བསྟོད་པ་ [[གསུམ་པ་འཕྲིན་ལས་ཀྱི་སྒོ་ནས་བསྟོད་པ་ལ་དྲུག ཞི་ཁྲོའི་སྔགས་ཀྱི་འཕྲིན་ལས་]]
      * 2.3.1 དང་པོ་ཞི་ཁྲོའི་སྔགས་ཀྱི་འཕྲིན་ལས་ཀྱི་སྒོ་ནས་བསྟོད་པ་ [[དང་པོ་ནི།]]
      * 2.3.2 གཉིས་པ་ཁྲོ་མོས་ས་གསུམ་གཡོ་བའི་འཕྲིན་ལས་ཀྱི་སྒོ་ནས་བསྟོད་པ་ [[གཉིས་པ་ཁྲོ་མོས་ས་གསུམ་གཡོ་བའི་འཕྲིན་ལས་ཀྱི་སྒོ་ནས་བསྟོད་པ་ནི།]]
      * 2.3.3 གསུམ་པ་བརྟན་གཡོའི་དུག་རྣམས་སེལ་བའི་འཕྲིན་ལས་ཀྱི་སྒོ་ནས་བསྟོད་པ་ [[གསུམ་པ་བརྟན་གཡོའི་དུག་རྣམས་སེལ་བའི་འཕྲིན་ལས་ཀྱི་སྒོ་ནས་བསྟོད་པ་ནི།]]
      * 2.3.4 བཞི་པ་རྩོད་པ་དང་རྨི་ལམ་ངན་པ་སེལ་བའི་འཕྲིན་ལས་ཀྱི་སྒོ་ནས་བསྟོད་པ་ [[(བཞི་པ་)རྩོད་པ་དང་རྨི་ལམ་ངན་པ་སེལ་བའི་འཕྲིན་ལས་ཀྱི་སྒོ་ནས་བསྟོད་པ་ནི།]]
      * 2.3.5 ལྔ་པ་རིམས་ནད་སེལ་བའི་འཕྲིན་ལས་ཀྱི་སྒོ་ནས་བསྟོད་པ་ [[ལྔ་པ་རིམས་ནད་སེལ་བའི་འཕྲིན་ལས་ཀྱི་སྒོ་ནས་བསྟོད་པ་ནི།]]
      * 2.3.6 དྲུག་པ་གདོན་དང་རོ་ལངས་འཇོམས་པའི་འཕྲིན་ལས་ཀྱི་སྒོ་ནས་བསྟོད་པ་ [[དྲུག་པ་གདོན་དང་རོ་ལངས་འཇོམས་པའི་འཕྲིན་ལས་ཀྱི་སྒོ་ནས་བསྟོད་པ་ནི།]]
* 3. གསུམ་པ་ཕན་ཡོན་བསྟན་པ་ [[གསུམ་པ་ཕན་ཡོན་བསྟན་པ་ལ་བཞི། བསམ་པའི་ཁྱད་པར་བསྟན་པ། དུས་ཀྱི་ཁྱད་པར་]]
   * 3.1 དང་པོ་བསམ་པའི་ཁྱད་པར་བསྟན་པ་ [[དང་པོ་ནི།]]
   * 3.2 གཉིས་པ་དུས་ཀྱི་ཁྱད་པར་བསྟན་པ་ [[གཉིས་པ་དུས་ཀྱི་ཁྱད་པར་བསྟན་པ་ནི།]]
   * 3.3 གསུམ་པ་ཕན་ཡོན་དངོས་བསྟན་པ་ [[གསུམ་པ་ཕན་ཡོན་དངོས་བསྟན་པ་ལ་གཉིས། སྒྲུབ་པ་པོ་རང་ལ་འབྱུང་བའི་ཕན་ཡོན་]]
      * 3.3.1 དང་པོ་སྒྲུབ་པ་པོ་རང་ལ་འབྱུང་བའི་ཕན་ཡོན་ [[དང་པོ་ལ་གཉིས། ཡོན་ཏན་འཐོབ་པའི་ཕན་ཡོན་དང་། སྐྱོན་ལྡོག་པའི་ཕན་ཡོན་ནོ། །]]
