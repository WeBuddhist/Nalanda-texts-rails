## དཀར་ཆག / Table of Contents

* I. མཆོད་བརྗོད། [[༄༅། །ན་མོ་བུདྡྷ་ཡ། བསྟོད་པ་འདི་ལ་དོན་གཉིས་ཏེ། བསྟོད་པ་དངོས་དང་]]
* 1. དང་པོ་བསྟོད་པ་དངོས་ [[བསྟོད་པ་འདི་ལ་དོན་གཉིས་ཏེ། བསྟོད་པ་དངོས་དང་ཕན་ཡོན་ནོ། །]]
   * 1.1 དང་པོ་སྐུའི་རྣམ་པས་ལོངས་སྐུའི་སྒོ་ནས་བསྟོད་པ་ [[དང་པོ་ལ་གསུམ། མཚན་གྱི་སྒོ་ནས་ལོ་རྒྱུས་བསྟན་པ་དང༌། སྐུའི་རྣམ་པ་དང་།]]
      * 1.1.1 མཚན་གྱི་སྒོ་ནས་ལོ་རྒྱུས་བསྟན་པ་ [[ཕྱག་འཚལ་སྒྲོལ་མ་ནི་འཁོར་བའི་དུ་ཁ་ལས་སྒྲོལ་མ། མྱུར་མ་ནི་སེམས་ཅན་གྱི་]]
      * 1.1.2 སྐུའི་རྣམ་པ་ [[ཕྱག་འཚལ་སྟོན་ཀའི་ཟླ་བ་ཀུན་ཏུ། །]]
         * 1.1.2.1 དང་པོ་ཞི་བའི་སྐུའི་སྒོ་ནས་བསྟོད་པ་ [[ཕྱག་འཚལ་སྟོན་ཀའི་ཟླ་བ་ཀུན་ཏུ། །]]
            * 1.1.2.1.1 འོད་ཟེར་གྱི་སྒོ་ནས་བསྟོད་པ་ [[ཕྱག་འཚལ་སྟོན་ཀའི་ཟླ་བ་ཀུན་ཏུ། །]]
            * 1.1.2.1.2 ཕྱག་མཚན་དང་ཡིད་ཅན་གྱི་སྒོ་ནས་བསྟོད་པ་ [[ཕྱག་འཚལ་གསེར་སྔོ་ནི་ཁ་དོག་གསེར་བཙོ་མའི་འོད་ལྟར་གསལ་བའོ། །]]
            * 1.1.2.1.3 སངས་རྒྱས་དང་བྱང་ཆུབ་སེམས་དཔས་བསྐུར་བའི་སྒོ་ནས་བསྟོད་པ་ [[ཕྱག་འཚལ་དེ་བཞིན་གཤེགས་པའི་གཙུག་ཏོར། །]]
         * 1.1.2.2 ཁྲོ་མོའི་སྐུའི་སྒོ་ནས་བསྟོད་པ་ [[ཕྱག་འཚལ་ཏུཏྟཱ་ར་ཧཱུཾ་ཡི་གེས། །]]
            * 1.1.2.2.1 མཐུའི་སྒོ་ནས་བསྟོད་པ་ [[ཕྱག་འཚལ་ཏུཏྟཱ་ར་ཧཱུཾ་ཡི་གེས། །]]
            * 1.1.2.2.2 འཇིག་རྟེན་པའི་ཆེན་པོ་རྣམས་ཀྱི་བསྟོད་པའི་སྒོ་ནས་བསྟོད་པ་ [[ཕྱག་འཚལ་བརྒྱ་བྱིན་མེ་ལྷ་ཚངས་པ། །]]
            * 1.1.2.2.3 ཕྲིན་ལས་ཀྱི་སྒོ་ནས་བསྟོད་པ་ [[ཕྱག་འཚལ་ཏྲད་ཅེས་བྱ་དང་ཕཊ་ཀྱིས། །]]
               * 1.1.2.2.3.1 ཐུན་མོང་གི་ཕྲིན་ལས་ [[ཕྱག་འཚལ་ཏྲད་ཅེས་བྱ་དང་ཕཊ་ཀྱིས། །]]
               * 1.1.2.2.3.2 ཐུན་མོང་མ་ཡིན་པའི་སྒོ་ནས་བསྟོད་པ་ [[ཕྱག་འཚལ་ཏུ་རེ་འཇིགས་པ་ཆེན་མོས། །]]
      * 1.1.3 རྒྱན་དང་ཆ་ལུགས་ཀྱི་སྒོ་ནས་བསྟོད་པ་ [[ཕྱག་འཚལ་དཀོན་མཆོག་གསུམ་མཚོན་ཕྱག་རྒྱའི། །སོར་མོས་ཐུགས་ཀར་རྣམ་པར་བརྒྱན་མ།]]
         * 1.1.3.1 དང་པོ་ཞི་བའི་ཆ་ལུགས་ཀྱི་སྒོ་ནས་བསྟོད་པ་ [[ཕྱག་འཚལ་དཀོན་མཆོག་གསུམ་མཚོན་ཕྱག་རྒྱའི། །སོར་མོས་ཐུགས་ཀར་རྣམ་པར་བརྒྱན་མ།]]
            * 1.1.3.1.1 ཕྱག་མཚན་ [[ཕྱག་འཚལ་དཀོན་མཆོག་གསུམ་མཚོན་ཕྱག་རྒྱའི། །སོར་མོས་ཐུགས་ཀར་རྣམ་པར་བརྒྱན་མ།]]
            * 1.1.3.1.2 དབུ་རྒྱན་ [[ཕྱག་འཚལ་རབ་ཏུ་དགའ་བར་བརྗིད་པའི། །]]
         * 1.1.3.2 དྲག་པོའི་ཆ་ལུགས་ཀྱི་སྒོ་ནས་བསྟོད་པ་ [[ཕྱག་འཚལ་ས་གཞི་སྐྱོང་བའི་ཚོགས་རྣམས། །]]
         * 1.1.3.3 ཐུན་མོང་གི་དབུ་རྒྱན་གྱི་སྒོ་ནས་བསྟོད་པ་ [[ཕྱག་འཚལ་ཟླ་བའི་དུམ་བུས་དབུ་རྒྱན། །ཞེས་པ་ནི།]]
         * 1.1.3.4 དྲག་པོའི་ཆ་ལུགས་ཀྱི་སྒོ་ནས་བསྟོད་པ་ [[ཕྱག་འཚལ་བསྐལ་པ་མཐའ་མའི་མེ་ལྟར། །]]
            * 1.1.3.4.1 འོད་ཟེར་གྱི་སྒོ་ནས་བསྟོད་པ་ [[ཕྱག་འཚལ་བསྐལ་པ་མཐའ་མའི་མེ་ལྟར། །]]
            * 1.1.3.4.2 བཞུགས་ཚུལ་གྱི་སྒོ་ནས་བསྟོད་པ་ [[གཡས་བརྐྱང་གཡོན་བསྐུམ་ཀུན་ནས་བསྐོར་དགའི། ཞེས་པ་ནི།]]
            * 1.1.3.4.3 ཕྱག་མཚན་གྱི་སྒོ་ནས་བསྟོད་པ་ [[ཕྱག་འཚལ་ས་གཞིའི་ངོས་ལ་ཕྱག་གི།]]
   * 1.2 ཆོས་སྐུའི་སྒོ་ནས་བསྟོད་པ་ [[ཕྱག་འཚལ་བདེ་མ་དགེ་མ་ཞི་མ། །ཞེས་པ་ནི། བདེ་མ་ནི་ཟག་མེད་ཀྱི་བདེ་བ་]]
   * 1.3 གསུམ་པ་ཕྲིན་ལས་ཀྱི་སྒོ་ནས་བསྟོད་པ་ [[ཕྱག་འཚལ་ཀུན་ནས་བསྐོར་རབ་དགའ་བའི། །]]
      * 1.3.1 གསང་སྔགས་ཀྱི་སྒོ་ནས་བསྟོད་པ་ [[ཕྱག་འཚལ་ཀུན་ནས་བསྐོར་རབ་དགའ་བའི། །]]
      * 1.3.2 དབང་གི་སྒོ་ནས་བསྟོད་པ་ [[ཕྱག་འཚལ་ཏུ་རེའི་ཞབས་ནི་བརྡབས་པས། །]]
      * 1.3.3 དུག་ཞི་བའི་སྒོ་ནས་བསྟོད་པ་ [[ཕྱག་འཚལ་ལྷ་ཡི་མཚོ་ཡི་རྣམ་པའི། །]]
      * 1.3.4 བར་ཆད་སེལ་བའི་སྒོ་ནས་བསྟོད་པ་ [[ཕྱག་འཚལ་ལྷ་ཡི་ཚོགས་རྣམས་རྒྱལ་པོ། །]]
      * 1.3.5 རིམས་ནད་སེལ་བའི་སྒོ་ནས་བསྟོད་པ་ [[ཕྱག་འཚལ་ཉི་མ་ཟླ་བ་རྒྱས་པའི། །]]
      * 1.3.6 མི་མཐུན་པ་སེལ་བའི་སྒོ་ནས་བསྟོད་པ་ [[ཕྱག་འཚལ་དེ་ཉིད་གསུམ་རྣམས་བཀོད་པས། །ཞེས་པ་ནི།]]
* 2. གཉིས་པ་ཕན་ཡོན་ [[རྩ་བའི་སྔགས་ཀྱི་བསྟོད་པ་འདི་དང༌། །ཞེས་པ་ནི། ཞི་བ་དང་ཁྲོ་མོའི་བསྟོད་པ་འདི།]]
   * 2.1 བསམ་པའི་ཁྱད་པར་ [[ལྷ་མོ་ལ་གུས་ཡང་དག་ལྡན་པའི། །ཞེས་པ་ནི།]]
   * 2.2 དུས་ཀྱི་ཁྱད་པར་ [[སྲོད་དང་ཐོ་རངས་ལངས་པར་བྱས་ཏེ། །]]
   * 2.3 ཕན་ཡོན་དངོས་རྒྱས་པར་བཤད་པ་ [[དྲན་པས་མི་འཇིགས་ཐམས་ཅད་རབ་སྟེར། །ཞེས་པ་ནི། ལྷའི་སྐུ་དྲན་པ་]]
   * 2.4 གྲངས་ཀྱི་སྒོ་ནས་ཕན་ཡོན་བསྡུས་ཏེ་རྒྱས་པར་བཤད་པ་ [[གཉིས་གསུམ་བདུན་དུ་མངོན་པར་བརྗོད་ན། །ཞེས་པ་ནི། བདག་དང་མདུན་ན་]]
* a. མཇུག་བྱང། [[བཅོམ་ལྡན་འདས་མ་སྒྲོལ་མ་ལ་ཡང་དག་པར་རྫོགས་པའི་སངས་རྒྱས་རྣམ་པར་སྣང་མཛད་ཆེན་པོས་]]
   * a.1 འགྱུར་བྱང། [[བཅོམ་ལྡན་འདས་མ་སྒྲོལ་མ་ལ་ཡང་དག་པར་རྫོགས་པའི་སངས་རྒྱས་རྣམ་པར་སྣང་མཛད་ཆེན་པོས་]]
   * a.2 མཛད་བྱང། [[ཕྱག་འཚལ་ཉི་ཤུ་རྩ་གཅིག་གི་བསྟོད་པའི་རྣམ་པར་བཤད་པ་གསལ་བའི་འོད་ཟེར་]]
