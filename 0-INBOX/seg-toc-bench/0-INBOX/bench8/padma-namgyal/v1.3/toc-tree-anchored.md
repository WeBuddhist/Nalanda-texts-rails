## དཀར་ཆག / Table of Contents

* I. མཆོད་བརྗོད། [[ཨོཾ་སྭ་སྟི།]]
* 1. རྗེ་བཙུན་སྒྲོལ་མའི་ཡོན་ཏན་གྱི་དཔངས་ལ་གོང་ནས་གོང་དུ་བསྟོད་པ་ [[དེའང་རྗེ་བཙུན་སྒྲོལ་མའི་ཡོན་ཏན་གྱི་དཔངས་ལ་གོང་ནས་གོང་དུ་བསྟོད་པར་མོས་ན་]]
   * 1.1 དང་པོ་སྦྱོར་བ་ཚོགས་བསགས་ཀྱི་རིམ་པ་ [[དང་པོ་སྦྱོར་བ་ཚོགས་བསགས་ཀྱི་རིམ་པ་ལ་ཚོགས་ཞིང་སྤྱན་འདྲེན་པ་ནི།]]
      * 1.1.1 ཚོགས་ཞིང་སྤྱན་འདྲེན་པ་ [[ཚོགས་ཞིང་སྤྱན་འདྲེན་པ་ནི།]]
      * 1.1.2 ཚོགས་བསགས་དངོས་ [[ཚོགས་བསགས་དངོས་ལ་ཡན་ལག་བདུན་ལས།]]
         * 1.1.2.1 དང་པོ་ལུས་དཔག་ཏུ་མེད་པར་སྤྲུལ་ནས་ཕྱག་འཚལ་བ་ [[དང་པོ་ལུས་དཔག་ཏུ་མེད་པར་སྤྲུལ་ནས་ཕྱག་འཚལ་བ་ནི།]]
         * 1.1.2.2 གཉིས་པ་རྗེ་བཙུན་མ་ལ་མཆོད་པ་འབུལ་བའི་ཡན་ལག་ [[གཉིས་པ་རྗེ་བཙུན་མ་ལ་མཆོད་པ་འབུལ་བའི་ཡན་ལག་ནི།]]
         * 1.1.2.3 གསུམ་པ་རང་གཞན་གྱི་སྡིག་པ་བཤགས་པའི་ཡན་ལག་ [[གསུམ་པ་རང་གཞན་གྱི་སྡིག་པ་བཤགས་པའི་ཡན་ལག་ནི།]]
         * 1.1.2.4 བཞི་པ་རང་གཞན་གྱིས་དགེ་བ་བསྒྲུབས་པ་ལ་རྗེས་སུ་ཡི་རང་བའི་ཡན་ལག་ [[བཞི་པ་རང་གཞན་གྱིས་དགེ་བ་བསྒྲུབས་པ་ལ་རྗེས་སུ་ཡི་རང་བའི་ཡན་ལག་ནི།]]
         * 1.1.2.5 ལྔ་པ་ཆོས་ཀྱི་འཁོར་ལོ་བསྐོར་དུ་གསོལ་བའི་ཡན་ལག་ [[ལྔ་པ་ཆོས་ཀྱི་འཁོར་ལོ་བསྐོར་དུ་གསོལ་བའི་ཡན་ལག་ནི།]]
         * 1.1.2.6 དྲུག་པ་སྐུ་མྱ་ངན་ལས་མི་འདའ་བར་གསོལ་བ་འདེབས་པའི་ཡན་ལག་ [[དྲུག་པ་སྐུ་མྱ་ངན་ལས་མི་འདའ་བར་གསོལ་བ་འདེབས་པའི་ཡན་ལག་ནི།]]
         * 1.1.2.7 བདུན་པ་བསྔོ་སྨོན་ཡན་ལག་ [[བདུན་པ་བསྔོ་སྨོན་ཡན་ལག་ནི། དེའང་ཡན་ལག་དང་པོ་གཉིས་ཀྱི་སྒོ་ནས་ཚོགས་བསགས།]]
   * 1.2 གཉིས་པ་སྒྲོལ་མའི་རྒྱུད་ལས་ཁོལ་དུ་ཕྱུང་བའི་བསྟོད་པའི་ཚིག་བྱིན་རླབས་ཀྱི་སྤྲིན་ཆར་གཡོ་བས་བསྟོད་པ་དངོས་ཀྱི་ཚིག་དོན་དྲན་བཞིན་དུ་དད་གུས་མིག་ནས་ཟིལ་པ་འཁྲུགས་ལུས་ནས་བ་སྤུ་གཡོ་བའི་ཀློང་ནས་དཔག་མེད་བཞི་ལྡན་གྱི་སྒོ་ནས་བསྟོད་པ་ [[གཉིས་པ་སྒྲོལ་མའི་རྒྱུད་ལས་ཁོལ་དུ་ཕྱུང་བའི་བསྟོད་པའི་ཚིག་བྱིན་རླབས་ཀྱི་སྤྲིན་ཆར་གཡོ་བས་]]
      * 1.2.1 དང་པོ་མཚན་རྒྱ་གར་སཾ་སྐྲྀ་ཏའི་སྐད་དུ་སྨོས་ [[དང་པོ་མཚན་རྒྱ་གར་སཾ་སྐྲྀ་ཏའི་སྐད་དུ་སྨོས་ན། ན་མཿཏཱ་ར་ཨེ་ཀ་]]
      * 1.2.2 གཉིས་པ་བོད་སྐད་དུ་སྨོས་ [[གཉིས་པ་བོད་སྐད་དུ་སྨོས་ན། སྒྲོལ་མ་ལ་ཕྱག་འཚལ་ཉི་ཤུ་རྩ་གཅིག་གིས་]]
      * 1.2.3 གསུམ་པ་སྐད་གཉིས་ཤན་སྦྱར་དུ་སྨོས་ [[གསུམ་པ་སྐད་གཉིས་ཤན་སྦྱར་དུ་སྨོས་ན། ན་མཿནི་ཕྱག་འཚལ། ཏཱ་ར་ནི་སྒྲོལ་མ།]]
      * 1.2.4 བཞི་པ་མཚན་དོན་ [[བཞི་པ་མཚན་དོན་དངོས་བསྟན་ལྟར་གོ་སླའོ། །]]
   * 1.3 གསུམ་པ་མཇུག་ཕན་ཡོན་གྱི་དོན་ [[གསུམ་པ་མཇུག་ཕན་ཡོན་གྱི་དོན་ནི། བསྟོད་ཡུལ་ལྷ་མོ་ལ་བསྟོད་པ་པོ་གུས་པ་]]
* a. མཇུག་བྱང། [[ཞེས་རྩ་རྒྱུད་རྒྱུད་ཀྱི་རྒྱལ་པོ་རྟོགས་པ་བདུན་བརྒྱ་པ་དང་། བཤད་རྒྱུད་ལས་]]
   * a.1 མཛད་བྱང། [[ཞེས་རྩ་རྒྱུད་རྒྱུད་ཀྱི་རྒྱལ་པོ་རྟོགས་པ་བདུན་བརྒྱ་པ་དང་། བཤད་རྒྱུད་ལས་]]
