
# ༄༅། །གཙུག་ཏོར་དྲི་མེད་ཀྱི་གཟུངས་ཆོག་བཞུགས། ^0

## ཀླད་ཀྱི་དོན། ^I-0

༄༅། །འཕགས་པ་འཇམ་དཔལ་ལ་ཕྱག་འཚལ་ལོ། ། ^I-1

གཙུག་ཏོར་དྲི་ མ་མེད་པའི་གཟུངས་ཀྱི་ཆོ་ག ། ^I-2

## གཞུང་དངོས། ^1-0

དང་པོར་བའི་ལྕི་བ་ས་ལ་མ་ལྷུང་བས་དཀྱིལ་ འཁོར་གྲུ་བཞི་པ་བྱས་ལ། དེ་ལ་ཙནྡན་དང་གུར་ཀུམ་ལ་སོགས་པས་གཏོར་ལ། མེ་ཏོག་སིལ་མའང་གཏོར་རོ། ། ^1-1

དེའི་སྟེང་དུ་གཙུག་ཏོར་དྲི་མ་མེད་པའི་ཡང་སྙིང་ གུར་ཀུམ་མམ། གི་ཝཾ་གིས་མེ་ཏོག་དཀར་པོ་འབྱུང་བའི་མྱུ་གུས་གྲོ་ག་ལ་བྲིས[^1]། དེ་ལ་དཀྱིལ་འཁོར༌[^2]དུ་བཅུག་པའི་སཱཙྪ༌[^3]ལྔའམ། བདུན་ནམ་དགུ་ཙམ་བྱས་ལ། མཎྜལ་གྱི་མེ་ཏོག་ཕུང་པོའི་སྟེང་དུ་གཞག །དེ་ནས་མཆོད་རྟེན་རེ་རེ་ལ་ལྷ་བཤོས་ལ༌[^4]སོགས་པ་མཆོད་པ་རྣམ་པ་ལྔ་རེ་རེ་བཤམས་ལ། མཎྜལ་གྱི་སྟེང་དུ་ བསྐོར་བ་ལྟར་གཞག །ཡང་མཎྜལ་གྱི་སྟེང་དུ༌[^5]གསེར་དངུལ་ལ་སོགས་པ་རིན་ པོ་ཆེའི་བུམ་པ་བཞི་ཙམ་དང་། སྐྱོགས་ལ་སོགས་པའི་སྣོད་བཞི་ཙམ་ཨ་ཀ་རུ་དང་ཏུ་རུསྐ༌[^6]ལ་སོགས་པ་དྲི་བཟང་པོས་བཀང་ལ། ཕྱོགས་མཚམས་རྣམས་སུ་གཞག་གོ། ། ^1-2

དེ་ནས་མཆོད་པ་བཤམས་པ་རྣམས་སྐུ་གཟུགས་དང་སཱཙྪ༌[^7]ལ་སོགས་པ་དཀོན་མཆོག་ལ་འབུལ༌[^8]ཞིང་། བསོད་ནམས་ཀྱི་ཡན་ལག་རྣམས་ཚང་བར་བྱ། དེ་ནས་མཆོད་གཡོག༌[^9]གཅིག་བདག་གིས་བཟླས་བརྗོད་མ་ཟིན་གྱི་ བར་དུ་ཨ་ཀ་རུ་ལ་སོགས་པའི་སྤོས་དྲི་ཞིམ་པོ་བསྲེག་དུ་གཞུག །བཟླས་པའི་ དུས་སུ་གཏམ་གཞན་དང་མ་འདྲེས་པར་བྱ། བཟླས་པ་ཟིན་པ་དང་ཡང་སྙིང་པོ་ འབའ་ཞིག་བཟླས་ཤིང་བསྐོར་བ་བརྒྱ་རྩ་བརྒྱད་བྱ། དེ་ལྟར་ཟིན་པ་དང་། རིན་པོ་ཆེའི་སྣོད་རྣམས་ཀྱི་ཆུ་ཀུན་ལས་ཅུང་ཟད་བསྡུས་ལ། ནད་པ་ལ་ཅུང་ཟད་ བླུད་ཅིང་ཁྲུས་བྱ། དེ་ལྟར་བྱས་ན་གློ་བུར་བ་ལ་སོགས་པའི་ནད་ཚབས་ཆེ་བ་ ལས་ཀྱང་ཐར་བར་འགྱུར་རོ། ། ཚེ་ཟད་པ་ལས་རིང་དུ་འཚོ་བར་འགྱུར་རོ། ། ལས་ཀྱི་སྒྲིབ་པ་ཆེན་པོ་རྣམས་ཀྱང་བྱང་བར་འགྱུར་ཏེ། དེ་དག་ལ་སོགས་པ་ཕན་ ཡོན་དཔག་ཏུ་མེད་པ་ནི་དེ་ཉིད་ཀྱི་ཆོ་ག་རྒྱ་ཆེན་པོ་ལས་ཤེས་པར་བྱའོ། ། ^1-3

ཆོ་ག་ གང་བྱེད་ཀྱང་འབྱུང་པོ་ཐམས་ཅད་པའི་གཏོར་མ་གསུམ་མམ་བཞི་གཏུང༌[^10]བར་བྱའོ། ། ^1-4

## མཛད་བྱང། ^a-0

སློབ་དཔོན་དཔལ་མར་མེ་མཛད་ཡེ་ཤེས་ཀྱིས་མཛད་པའི་གཙུག་ཏོར་དྲི་མ་མེད་པའི་གཟུངས་ཀྱི་ཆོ་ག་རྫོགས་སོ།། །། ^a-1

[^1]: བྲིས། ༼པེ། སྣར།༽ ལ།
[^2]: འཁོར། ༼པེ། སྣར། འཁོར་དུ།
[^3]: སཱཙྪ། ༼པེ། སྣར།༽ ས་ཏ་ས།
[^4]: ལྷ་བཤོས་ལ། ༼པེ། སྣར།༽ ལྷ་བཤོས་ལ།
[^5]: སྟེང་དུ། ༼པེ། སྣར།༽ བསྐོར་བ་ལྟར་བཞག
[^6]: རུསྐ་ ༼པེ། སྣར།༽ དུ་རུ་ཀ
[^7]: སཱཙྪ། ༼པེ། སྣར།༽ སཏྶ།
[^8]: འབུལ་ ༼པེ། སྣར།༽ དབུལ།
[^9]: གཡོག་ ༼པེ། སྣར།༽ ཡོན།
[^10]: གཏུང་ ༼པེ། སྣར།༽ བཏང་།
